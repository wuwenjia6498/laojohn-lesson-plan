### 一、文本介绍

【内容简介】

《神笔马良》是一本适合低年级阅读的短篇故事合集，收录《神笔马良》《牧童三娃》《大奖章》三个彼此独立的故事——三篇没有共同人物、也没有一条贯穿全书的主线，需一篇一篇分开来读。

- 《神笔马良》是民间故事式童话：穷孩子马良苦练画技、梦中得到一支神笔（画什么就活什么），先以画替穷人造福，又以画惩治贪婪的财主与皇帝，最后画出大风掀翻皇帝的船。
- 《牧童三娃》亦为民间故事式童话：牧童三娃只身追赶偷羊的黑风，冒雨救院、得花神三粒神奇种子，赴深山坳斗败蛇精、以仙水救活羊群；面对花神所赠金银珍珠，一概不取，只求夺回全村的羊。
- 《大奖章》是动物寓言：森林运动会上，旧冠军小驴自负不练、一路分心而落败，踏实苦练又照顾同伴的小熊夺得大奖章。

三篇共同指向善良、勤学、不贪、谦逊等品质，适合作低年级“分篇精读 + 横向对照”的合集读本。教学上一线贯穿：不把三篇当一个长故事梳理，情节只落到单篇，人物只作篇际的品质对照。

【作者介绍】

本书电子版无版权页与署名，作者、译者、出版社等书目信息以实际购买的版本为准，此处从略。（本书无固定页码，故事定位一律按“篇名 + 场景”。）

### 二、教学目标

【知识技能】了解《神笔马良》是一本收录《神笔马良》《牧童三娃》《大奖章》三个独立短篇的故事合集，三篇各自成篇、无共同人物与贯穿主线；能分别说出每篇的主要人物和主要事件，并借流程图理清《神笔马良》一篇的情节先后。

【过程方法】学习并运用预测、推断两项策略——由已读片段预测故事的发展、由人物的做法推断他是个怎样的人，判断都回到故事里找依据；借助预测阅读单、流程图、对比图，对单篇作梳理、对三篇的主人公作横向对照。

【情感价值】感受马良、三娃的善良与不贪，小熊的踏实与谦逊；初步懂得有了本领可以用来帮助别人，也懂得骄傲自满会误事。

### 三、教学流程

## 第1课时 · 导读课

**本节三维目标**

【知识技能】知道整本书是《神笔马良》《牧童三娃》《大奖章》三个独立故事的合集；了解《神笔马良》开头马良无笔、苦练、得神笔的情节；认识“预测”这一读书方法。

【过程方法】重点显性训练预测策略——根据已读片段猜想故事往后会怎样发展，并说清自己为什么这么猜，建立“读前预设—读中验证”的回路。

【情感价值】对整本书生出想读下去的兴趣；初步感受马良穷而有志、苦练不服输的品性。

### 一、一支画什么就活什么的笔（15 分钟）

师：亲爱的同学们大家好！

师：上课前，老师先说一件怪事。（稍停顿）有这样一支笔——画一只鸟，鸟就从纸上飞走了；画一条鱼，鱼就游进水里了；画什么，什么就活过来。要是世界上真有这么一支笔，你最想用它画点什么？

学生自由分享

参考：（学生自由说，画什么都行——想画的东西、想去的地方、想要的本领……）

师：大家想画的都很有意思。这样一支神奇的笔，这本书里真有，它就是书名里的那支“神笔”。可它的主人，偏偏是个连一支笔都买不起的穷孩子，叫马良。（稍停顿）你们大概想不到：后来就是这支笔，把一位皇帝，连人带船，一起卷进了大海。

师：一个穷孩子，一支画笔，怎么会跟皇帝斗起来、还斗赢了？这本《神笔马良》就摆在你们桌上，答案全在里头。这节课，我们先来认识马良这个人。

师：马良穷到什么地步呢？他父母早就不在了，他靠自己上山打柴、下河割草过日子。他最爱画画，可穷得连一支笔都没有。有一天，他走到学馆，向教书先生开口，想借一支笔来学画。他说的话、先生的回答，老师读给大家听——

（教师朗读，读到啐唾沫处稍停顿）

> “我很想学画，借给我一支笔可以吗？”
> 教师瞪了他一眼，“呸！”一口唾沫啐在他脸上，骂道：
> “穷娃子想拿笔，还想学画？做梦啦！”
> 说完，就将他撵出大门来。

师：（稍停顿）想借一支笔，换来的却是一脸唾沫、被撵出门。如果你就是马良，这会儿心里是什么滋味？

学生自由分享

参考：委屈、生气、难过、不服气……（说出自己真实的感受就好）

师：可马良没有就这样算了。他心里憋着一股劲——没有笔，他偏要学会画画。他后来怎么样，我们很快就会读到。不过在翻开书之前，先花一小会儿，看清楚这到底是一本怎样的书。

### 二、认识这一本书——它装着三个故事（10 分钟）

师：请把书拿起来，翻一翻前面的目录。（稍停顿）数一数：这本《神笔马良》，是一个从头讲到尾的长故事，还是好几个故事？

学生互动分享

参考：是三个故事——《神笔马良》《牧童三娃》《大奖章》。

师：对，一共三个。这一点要记清楚：这本书和“从头到尾只讲一件事”的长故事书不一样，它是一本“合集”——三个故事各自独立，人物不同、事情也不同，彼此并不相干。

师：第一个《神笔马良》，讲穷孩子马良和他的神笔；第二个《牧童三娃》，讲放羊的孩子三娃，进深山打败偷羊的蛇精、夺回全村的羊；第三个《大奖章》，讲森林里的动物开运动会，小熊、小驴、小猪赛跑。

师：所以读这本书，要一个故事一个故事地读。读完一个，先想清楚：这个故事的主人公是谁、他做了一件什么事，再翻开下一个。别把马良、三娃、小熊弄混了——他们不在同一个故事里，互相并不认识。

师：三个故事，我们今天先走进第一个、也就是书名里的这个——《神笔马良》，看看马良到底是怎么得到那支神笔的。

### 三、马良是怎么得到神笔的·大胆预测（20 分钟）

师：刚才说到，马良借不到笔，可他偏要学画。他是怎么练的？听这一段——

（教师朗读）

> 从此，他下决心学画，每天用心苦练。他到山上打柴时，就折一根树枝，在沙地里学着描飞鸟。他到河边割草时，就用草根蘸蘸河水，在岸石上学着描游鱼。晚上，回到家里，拿了一块木炭，在窑洞的壁上，又把白天描过的东西，一件一件再画一遍……

师：没有笔，他就用树枝在沙地上画，用草根蘸水在石头上画，晚上再用木炭在墙上画一遍。（稍停顿）他画一天两天就停了吗？

学生互动分享

参考：不是，他每天都练、坚持了很久。

师：他就这样练了整整一年，画什么像什么。后来有一天夜里，那支神笔来了——

（教师朗读）

> 不知道什么时候，窑洞里亮起了一道五彩的光芒，来了个白胡子的老人，把一支笔送给他说：
> “这是一支神笔，要好好用它，为咱穷苦人画画。”
> 马良接过来一看，那笔金光灿灿的；拿在手上，沉甸甸的。

师：白胡子老人送笔时，特意交代了一句话——“要好好用它，为咱穷苦人画画”。（稍停顿）故事我们今天就先读到这儿。往后会发生什么，先不急着读，我们来做一件事，叫“预测”。

师：预测，就是故事还没往下读，我们先根据已经知道的，大胆猜一猜后面会怎样，并且说说自己为什么这么猜。老师这里有三个问题，请把你猜的和理由，填到这张预测单上。不会写的字，用拼音代替。

**预测阅读单**（每人一张，先独立猜，再小组说一说）

| 我猜后面会发生什么 | 我这样猜的理由 | 读完以后，我猜对了吗 |
|---|---|---|
| 有了神笔，马良会先画些什么？ |  |  |
| 会不会有人来抢这支神笔？他们想干什么？ |  |  |
| 马良斗得过他们吗？他会怎么办？ |  |  |

师：（巡视，请两三位同学说）谁来说说你的猜想？说完猜的，别忘了讲一讲“我为什么这么猜”。

学生互动分享

参考（学生的猜想不必和这里一样，重点是**能说出理由**）：

① 有了神笔，马良会先给穷人画有用的东西——比如画牛、画农具、画粮食。理由：老人说这笔是“为咱穷苦人画画”的，马良自己就是穷孩子，他懂穷人缺什么。

② 会有坏人来抢笔，想让马良画金子、画宝贝，好让自己发财。理由：这么神的笔，贪心的人一定眼红。

③ 马良不会乖乖听坏人的，他会用神笔想办法治住他们、脱身。理由：马良手里有一支别人没有的神笔，这是他最大的本事。

师：（稍停顿）大家猜得都有道理，尤其“讲理由”这一步做得好。你们猜得对不对，老师先不说。请把这张预测单夹进书里，等你自己读到后面，回来对一对：哪几条猜中了？哪几条和你想的不一样？——这才是预测真正有意思的地方。

### 四、读法提示与一周阅读计划（15 分钟）

师：这本书就交给大家自己去读了。（稍停顿）三个故事要一个接一个读，怎样才能读完不把它们弄混？谁有好办法？

学生自由分享

参考：读完一个先停一停、想一想主人公是谁、做了什么事；也可以把它记下来……

师：都是好办法。老师也给大家一个读“合集”的小提示，帮你把三个故事读得清清楚楚。

师：每读完一个故事，就在你的“阅读记录表”上，用一句话记下两样东西——**这个故事的主人公是谁**、**他做了一件什么事**。就一句话，不用多。三个故事读完，谁是谁、做了什么，就不会混了。（稍停顿）读的时候要是心里冒出什么问题，也记在旁边，下节课我们一起聊。

**一周阅读记录表**（自己读，边读边填）

| 读的是哪个故事 | 主人公是谁 | 他做了一件什么事 | 我读到这里冒出的问题 |
|---|---|---|---|
| 神笔马良 |  |  |  |
| 牧童三娃 |  |  |  |
| 大奖章 |  |  |  |

师：时间上这样安排：这一个星期里，把三个故事读完。故事都不长，可以一两天读一个，不用赶。读慢一点没关系，读明白最要紧。

师：（总结）今天我们认识了这本《神笔马良》——它是三个独立故事的合集；也学着做了一回“预测”，猜了猜马良和他的神笔。下节课，等大家把三个故事都读完，我们再一起把故事理一理、聊一聊三个故事里的主人公。请把书和填了一半的两张单子都带来。

本课完。

## 第2课时 · 阅读交流课

**本节三维目标**

【知识技能】能分别说出三个故事的主要人物和主要事件；借流程图理清《神笔马良》情节发展的先后顺序。

【过程方法】重点显性训练推断策略——从人物的做法推断他是个怎样的人，并回到故事里找出根据；把三个故事的主人公放在一起联结对照，发现他们的共同点。

【情感价值】体会善良、勤奋、不贪、不骄傲这些品质；愿意像故事里的主人公那样，用自己的本领为别人做点好事。

### 一、三个故事，读完之后（10 分钟）

师：亲爱的同学们大家好！这一周，大家把《神笔马良》里的三个故事都读完了吧？（稍停顿）先做一件上周说好的事——请把夹在书里的那张预测单翻出来。上周我们猜了《神笔马良》后面会发生什么，现在你自己读完了，对一对：你猜的，和书里真发生的，哪几条猜中了？哪几条不一样？

学生互动分享

参考（对照预测单第三列自己核对，猜中猜不中都好）：多数同学猜中了“马良给穷人画有用的东西”“有坏人来抢笔、想让他画金子”；“马良到底怎么斗过他们”往往和书里不一样——不少同学没猜到，他最后是用画出来的大风掀翻了大船。

师：（稍停顿）这就是预测有意思的地方——猜完了，回头验一验。接着请大家说说：《牧童三娃》和《大奖章》这两个故事，你印象最深的是哪一幕？

学生自由分享

参考：三娃冒雨给大树培土；花神拿出一箱箱金银，三娃直摇头；小驴躺在树上做美梦、一蹦摔了下来；小熊冲过终点，把小猪拉来一起拍照……

师：看来三个故事大家都读进去了。那读的时候，心里有没有冒出过什么问题？谁的问题，说出来大家一起听听？

学生互动分享

参考：为什么马良卖画时故意把画画得不像（少画一张嘴、少画一条腿）？三娃为什么金银都不要，只要羊？小驴那么厉害，怎么反而输了？

师：（稍停顿）这些问题都提得好。我们再把它们分一分——有的问题，回故事里读一读就能找到答案（像“马良为什么把画画得不像”，书里写了他怕被人认出来、故意画不活）；有的问题，得自己动脑筋、聊一聊才想得明白（像“小驴那么厉害，怎么反而输了”）。能找到答案的、要自己想的，都是好问题。今天这节课，这两种问题我们都会碰到。

### 二、给《神笔马良》理一理事情的经过（15 分钟）

师：三个故事里，《神笔马良》的事情最多、最曲折。我们就拿它来练一个本事——把一件件事，按先后顺序理清楚。老师给大家一张“流程图”。

师：流程图这样用：几个方框，用箭头一个接一个串起来；一个方框里写一件事，从头到尾，按发生的先后排好。它的用处，是让“先发生什么、后发生什么”一眼看明白。

师：（稍停顿）我们一起来。马良这个故事，最开头发生的一件事是什么？

学生互动分享

参考：马良想借笔学画，被学馆先生啐了唾沫、撵出门。

师：对，这就是第一个方框——“无笔受辱”。接下来呢？一件一件往下说，请大家填到自己的流程图上。不会写的字用拼音。

**《神笔马良》故事流程图**（空白版，学生自己填）

| 顺序 | 发生了一件什么事 |
|---|---|
| 第一步 |  |
| 第二步 |  |
| 第三步 |  |
| 第四步 |  |
| 第五步 |  |

师：（巡视后请一组来说，师生一起把顺序捋顺）

**参考版**（答案来自故事，学生用自己的话说对意思即可）

| 顺序 | 发生了一件什么事 |
|---|---|
| 第一步 | 马良想借笔学画被撵走，他不服气，天天用树枝、草根、木炭苦练画画。 |
| 第二步 | 练了一年，画什么像什么；一夜梦中，白胡子老人送他一支神笔，画什么就活什么。 |

| 第五步 | 马良骗皇帝画大海、大船去“摇钱”，一路画风、掀起大浪，掀翻大船，除掉了贪心的皇帝。 |

师：（稍停顿）把这五步从头到尾连起来——一个连笔都没有的穷孩子，最后靠自己的神笔，治住了财主和皇帝。（追问）大家发现没有：马良的神笔，从没给自己画过一座金山、一屋金子。他都拿去做什么了？

学生互动分享

参考：都拿去给穷人画有用的东西了——画牛、画犁、画水车，帮大家干活、过日子。他记着老人的话，“为咱穷苦人画画”。

### 三、三个主人公，放在一起看一看（20 分钟）

师：刚才我们把马良理清楚了。现在做一件更有意思的事——把三个故事的三位主人公，放到一起比一比。他们分别是：《神笔马良》里的马良、《牧童三娃》里的三娃、《大奖章》里的小熊。

师：（稍停顿）注意，他们各在各的故事里，本来互相并不认识。我们把他们放一起，不是让他们碰面，而是想看看——**这三个人身上，有没有什么地方是相像的**。老师给大家一张对比图，一行一个主人公，一列问一个问题。

师：这一环节，我们重点练一个读书的本事，叫“推断”。推断，就是——故事里没有直接说“这个人是好是坏、是怎样的人”，可我们能从他**做的事**里，自己推想出来。而且推想完，还得能回到故事里，指出“我是从哪件事看出来的”。

**三位主人公对比图**（空白版，学生分组填）

| 主人公 | 在哪个故事里 | 他做了一件什么了不起的事 | 面对金钱或好处，他是怎么做的 | 我推断：他是个怎样的人 |
|---|---|---|---|---|
| 马良 | 神笔马良 |  |  |  |
| 三娃 | 牧童三娃 |  |  |  |
| 小熊 | 大奖章 |  |  |  |

师：先看中间两列——“做了什么了不起的事”“面对金钱或好处怎么做”，这两列可以回故事里找。填好了，最后一列“他是个怎样的人”，就靠你自己**推断**。

（学生分组填写，教师巡视）

师：好，我们一列一列对。先说马良，面对金钱或好处，他是怎么做的？

学生互动分享

参考：大财主逼他画金元宝，他死活不肯；皇帝抢了笔、许他金银还许公主，他也不真心画，反倒治住了皇帝。

师：三娃呢？

学生互动分享

参考：花神拿出一大盒金子、一大箩银子、一大串珍珠、一大箱玛瑙送他，他一样一样都摇头说“我不要”，只求找回全村的羊。

师：小熊没碰上金子。那对小熊来说，“好处”是什么？他又是怎么对待的？

学生互动分享

参考：好处就是那枚人人都想要的大奖章。小熊靠自己天天苦练，跑了第一名，赢得大奖章；得了奖章他也不独自得意，还把胆小、退缩的小猪拉过来，一起拍照。

师：（稍停顿）现在到最要紧的一步——**推断**。三个人放一起看，你推断他们是怎样的人？最后一列，你是从哪件事推出来的，说给大家听。

学生互动分享

参考（学生用自己的话说，只要**推断有根据**就好）：他们都善良、不贪心。马良宁可挨饿也不给财主画金元宝、三娃满箱金银都不要，可见不贪财；马良的笔为穷人画、三娃拼命是为全村的羊、小熊夺了奖还想着小猪，可见心里都装着别人；小熊天天练跑才拿冠军，可见还得靠自己勤奋、踏实。

师：（追问）我们再反过来看一眼——这三个故事里也有让人不喜欢的角色，比如《神笔马良》里贪心的皇帝、《大奖章》里骄傲的小驴。和马良、三娃、小熊比一比，他们又是怎样的人？你从哪件事看出来的？

学生互动分享

参考：皇帝贪心——金山画个没完，还想坐船去海上“摇钱”，最后把自己也搭了进去；小驴骄傲——上届拿过奖章就不肯练，只顾画像、做美梦，比赛中还分心去踢球、找奖章，结果输了。（从他们做的事，就能推断出“贪心”和“骄傲”。）

师：（总结）你们看，故事没有一句直接说“马良善良”“小驴骄傲”，可我们从他们**做的事**里，全推断出来了——这就是会读书。三位主人公虽在不同的故事里，身上却有一样相通的东西：善良、不贪、有了本事想着别人。

### 四、假如我也有一件宝物（15 分钟）

师：我们再回味一下这两位主人公——马良有了神笔，头一个想到的，是给村里的穷人画犁、画牛，而不是给自己画金山；三娃面对满满一箱金银珍珠，摇摇头，只要全村的羊。（稍停顿）他们有了了不起的本事和东西，先想到的都是“为别人”。

师：现在，老师也把这样一件宝物，送到你手上——**假如你也有一支马良的神笔，或者一粒三娃的神奇种子**（说一声，就能变出你要的东西），你会先想到为谁、做一件什么事？

师：（稍停顿）要是你不想靠宝物，也行——你还可以像《大奖章》里的小熊那样：**说一件你愿意靠自己踏踏实实努力去做成、还能帮上别人的事**。靠宝物也好、靠自己也好，最要紧的是——你头一个想到的是谁。

师：想好了，把它画下来或写下来，填在这张卡片上。不会写的字用拼音。想一想：你为的是谁？你要为他（们）做的这件事，能帮上什么忙？

**“我的一件宝物”心愿卡**（画一画 + 写一写）

| 我靠什么（神笔·种子·或我自己的努力） | 我想为谁 | 我要为他（们）做的一件事 | 为什么想为他（们）做这件事 |
|---|---|---|---|
|  |  |  |  |

（学生画写，教师巡视，鼓励“为别人”的心愿）

师：谁愿意上来，说说你的宝物、你要为谁做的事？

学生互动分享

参考（学生的心愿各不相同，只要落在“为谁做一件具体的事”上就好）：我想用神笔给生病的奶奶画一副能治病的药；我想用种子变出很多树，种在光秃秃的山上；我想给没有书包的小朋友画一个新书包；我愿意像小熊那样，自己每天多练练，把字写好，再去帮一帮班里写字慢的同学……

师：（请两三位分享，简单点评：都想到了别人，很好）

师：（总结）这一本《神笔马良》，我们读完了三个故事。马良、三娃、小熊，三个互不相识的人，却让我们看见了同一样宝贝——不是那支神笔、那粒种子、那枚奖章，而是他们心里的善良，和肯为别人使劲的那股劲儿。（稍停顿）希望你们手上这件“宝物”，将来也真能为身边的人，做上一件小小的好事。

全课完。
