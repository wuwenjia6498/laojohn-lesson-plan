### 一、文本介绍

【内容简介】

《神笔马良》是一本适合低年级阅读的短篇故事合集，收录《神笔马良》《牧童三娃》《大奖章》三个彼此独立的故事——三篇没有共同人物、也没有一条贯穿全书的主线，需一篇一篇分开来读。

- 《神笔马良》是民间故事式童话：穷孩子马良苦练画技、梦中得到一支神笔（画什么就活什么），先以画替穷人造福，又以画惩治贪婪的财主与皇帝，最后画出大风掀翻皇帝的船。
- 《牧童三娃》亦为民间故事式童话：牧童三娃只身追赶偷羊的黑风，冒雨救院、得花神三粒神奇种子，赴深山坳斗败蛇精、以仙水救活羊群；面对花神所赠金银珍珠，一概不取，只求夺回全村的羊。
- 《大奖章》是动物寓言：森林运动会上，旧冠军小驴自负不练、一路分心而落败，踏实苦练又照顾同伴的小熊夺得大奖章。

三篇共同指向善良、勤学、不贪、谦逊等品质，适合作低年级“分篇精读 + 横向对照”的合集读本。教学上一线贯穿：不把三篇当一个长故事梳理，情节只落到单篇，人物只作篇际的品质对照。

【作者介绍】

本书电子版无版权页与署名，作者、译者、出版社等书目信息以实际购买的版本为准，此处从略。（本书无固定页码，故事定位一律按“篇名 + 场景”。）

### 二、教学目标

【知识技能】了解《神笔马良》是一本收录《神笔马良》《牧童三娃》《大奖章》三个独立短篇的故事合集，三篇各自成篇、无共同人物与贯穿主线；能分别说出每篇的主要人物和主要事件，并借流程图理清《神笔马良》一篇的情节先后。

【过程方法】学习并运用预测、推断两项策略——由已读片段预测故事的发展、由人物的做法推断他是个怎样的人，判断都回到故事里找依据；借助预测阅读单、流程图、对比图，对单篇作梳理、对三篇的主人公作横向对照。

【情感价值】感受马良、三娃的善良与不贪，小熊的踏实与谦逊；初步懂得有了本领可以用来帮助别人，也懂得骄傲自满会误事。

### 三、教学流程

## 第1课时 · 导读课

**本节三维目标**

【知识技能】知道整本书是《神笔马良》《牧童三娃》《大奖章》三个独立故事的合集；了解《神笔马良》开头马良无笔、苦练、得神笔的情节；认识“预测”这一读书方法。

【过程方法】重点显性训练预测策略——根据已读片段猜想故事往后会怎样发展，并说清自己为什么这么猜，建立“读前预设—读中验证”的回路。

【情感价值】对整本书生出想读下去的兴趣；初步感受马良穷而有志、苦练不服输的品性。

### 一、一支画什么就活什么的笔（10 分钟）

师：亲爱的同学们大家好！

师：上课前，老师先说一件怪事。（稍停顿）有这样一支笔——画一只鸟，鸟就从纸上飞走了；画一条鱼，鱼就游进水里了；画什么，什么就活过来。要是世界上真有这么一支笔，你最想用它画点什么？

学生自由分享

参考：（学生自由说，画什么都行——想画的东西、想去的地方、想要的本领……）

师：大家想画的都很有意思。这样一支神奇的笔，这本书里真有，它就是书名里的那支“神笔”。可它的主人，偏偏是个连一支笔都买不起的穷孩子，叫马良。（稍停顿）你们大概想不到：后来就是这支笔，让一位皇帝栽了个大跟头。

师：一个穷孩子，一支画笔，怎么会跟皇帝斗起来、还斗赢了？这本《神笔马良》就摆在你们桌上，答案全在里头。这节课，我们先来认识马良这个人。

师：马良穷到什么地步呢？他父母早就不在了，他靠自己上山打柴、下河割草过日子。他最爱画画，可穷得连一支笔都没有。有一天，他走到学馆，向教书先生开口，想借一支笔来学画。他说的话、先生的回答，老师读给大家听——

（教师朗读，读到啐唾沫处稍停顿）

> “我很想学画，借给我一支笔可以吗？”
> 教师瞪了他一眼，“呸！”一口唾沫啐在他脸上，骂道：
> “穷娃子想拿笔，还想学画？做梦啦！”
> 说完，就将他撵出大门来。

师：（稍停顿）想借一支笔，换来的却是一脸唾沫、被撵出门。如果你就是马良，这会儿心里是什么滋味？

学生自由分享

参考：委屈、生气、难过、不服气……（说出自己真实的感受就好）

师：可马良没有就这样算了。他心里憋着一股劲——没有笔，他偏要学会画画。他后来怎么样，我们很快就会读到。不过在翻开书之前，我们先用几分钟，把这本书看清楚：它到底是一本什么样的书。

### 二、认识这一本书——它装着三个故事（10 分钟）

师：请把书拿起来，翻一翻前面的目录。（稍停顿）数一数：这本《神笔马良》，是一个从头讲到尾的长故事，还是好几个故事？

学生互动分享

参考：是三个故事——《神笔马良》《牧童三娃》《大奖章》。

师：对，一共三个。这一点要记清楚：这本书和“从头到尾只讲一件事”的长故事书不一样，它是一本“合集”——三个故事各是各的，人物不一样，事情也不一样，一个跟另一个没关系。

师：第一个就是《神笔马良》，讲穷孩子马良和他的神笔——今天我们就读它的开头。另外两个故事讲什么呢？（稍停顿）我们先不读文字，光看画来猜一猜。请把书翻到《牧童三娃》这一篇的开头，那儿有一幅画。

【图位:插-12｜《牧童三娃》· 开篇一幕：戴灰毡帽的孩子皱着眉抬起手，身边几个孩子看着他】

师：画上这个戴帽子的孩子，脸上是什么表情？他旁边还有几个孩子，也在看着他——像是出了什么事？（稍停顿）你猜这个故事要讲什么？

学生自由分享

参考：他皱着眉头，好像很着急、很为难；后面几个孩子在等他说话；大概是丢了什么东西、出了事，他得想办法……

师：（稍停顿）再翻到第三个故事《大奖章》的前面几页，找到画着一只猴子举着手、动物们围着它的那一幅。这一幅也只看画，先不读字。

【图位:插-26｜《大奖章》· 开篇一幕：猴子举着手向一群动物宣布，老虎、小猪、小熊、小鹿、乌龟、猫都围过来听；猴子头顶的白圈里画着一个太阳】

师：这一幅画上，动物们全围过来听猴子说话。（稍停顿）猴子头顶上还有一个白圈，那是它说出来的话——白圈里画着什么？它跟大家说的这件事，会和这个太阳有关系吗？

学生自由分享

参考：白圈里是一个太阳——说今天天气好、要出太阳了（这样答也对，画上确实没有别的线索）；顺着往下猜：天气这么好，大家还聚在一起听它说，也许是要办一件热闹的事，比如比赛、运动会……

师：（教师总结）猜得都有道理。到底是不是，等你自己读完就知道了。

师：所以读这本书，要一个故事一个故事地读。读完一个，先想清楚：这个故事的主人公是谁、他做了一件什么事，再翻开下一个。别把马良、三娃、小熊弄混了——他们不在同一个故事里，互相并不认识。

师：三个故事，我们今天先走进第一个、也就是书名里的这个——《神笔马良》，看看马良到底是怎么得到那支神笔的。

### 三、马良是怎么得到神笔的·大胆预测（30 分钟）

师：刚才说到，马良借不到笔，可他偏要学画。他是怎么练的？听这一段——

（教师朗读）

> 从此，他下决心学画，每天用心苦练。他到山上打柴时，就折一根树枝，在沙地里学着描飞鸟。他到河边割草时，就用草根蘸蘸河水，在岸石上学着描游鱼。晚上，回到家里，拿了一块木炭，在窑洞的壁上，又把白天描过的东西，一件一件再画一遍……

师：（稍停顿）先闭上眼睛，老师把最后那半句再读一遍——“晚上，回到家里，拿了一块木炭，在窑洞的壁上，又把白天描过的东西，一件一件再画一遍……”（稍停顿）你眼前看见了什么？他在什么地方画，画的又是什么？

学生自由分享

参考：黑黑的窑洞里，他对着墙壁，手里捏着一小块木炭；白天看见的鸟、鱼，一件一件又画了一遍……（学生说得出画面就好，不必齐整。）

师：睁开眼睛。（稍停顿）刚才大家在心里看见的是窑洞里那一幕；书上的画家，挑的是另外一处——他把白天在河边的样子画了下来。请翻到《神笔马良》前面几页，找到画着河边的那一幅。（稍停顿）你看这个孩子，手里握着的是什么？他蹲在什么地方？（再稍停顿）再看仔细一点——他在地上画的是什么？天上正飞着什么？

【图位:插-01｜《神笔马良》· 河边学画（地上描的是鸟，天上也飞着鸟）】

学生互动分享

参考：手里是一根细树枝；他蹲在河边的沙地上；他在地上画的是一只鸟，天上正飞着几只鸟（线是红的、画得细，看不出来的同学，老师带着一起找）——他抬头看着真鸟，就在地上描鸟，跟刚才读的“在沙地里学着描飞鸟”一模一样。（身边那只筐里装着打来的柴草，学生若说到，可顺势点出：他是打柴、割草的时候顺手就画。）

师：家里连一张纸、一支笔都没有，他就把河滩、石头、窑洞的墙壁，全当成了纸。（稍停顿）他画一天两天就停了吗？

学生互动分享

参考：不是，他每天都练、坚持了很久。

师：他就这样练了整整一年，画什么像什么。后来有一天夜里，那支神笔来了——

（教师朗读）

> 不知道什么时候，窑洞里亮起了一道五彩的光芒，来了个白胡子的老人，把一支笔送给他说：
> “这是一支神笔，要好好用它，为咱穷苦人画画。”
> 马良接过来一看，那笔金光灿灿的；拿在手上，沉甸甸的。

师：往后翻一翻，送笔这一幕书里也画了——找到画着一朵大云的那一幅。找到了吗？（稍停顿）大家看这幅画的右边，那儿还有一个人，他正在做什么？（再稍停顿）画家为什么要把他也画进来？

【图位:插-03｜《神笔马良》· 梦中赠笔（云内、云外各有一个马良）】

学生互动分享

参考：右边那个人躺在床上睡着了——那也是马良；画家把他画进来，是要告诉我们这是马良做的一个梦，神笔是梦里送来的。

师：说得好。画里把两件事画在了一块儿：马良在床上睡着，梦里遇见了送笔的老人。而老人送笔的时候，还嘱咐了一句话——“要好好用它，为咱穷苦人画画”。（稍停顿）故事我们今天就先读到这儿。往后会发生什么，这里先停一停，我们来做一件事，叫“预测”。

师：预测，就是故事还没往下读，我们先根据已经知道的，大胆猜一猜后面会怎样，并且说说自己为什么这么猜。老师这里有两个问题，请把你猜的和理由，填到这张预测单上。不会写的字，用拼音代替。

**预测阅读单**（每人一张，先独立猜，再小组说一说）

| 我猜后面会发生什么 | 我这样猜的理由 | 读完以后，我猜对了吗 |
|---|---|---|
| 有了神笔，马良会先画些什么？ |  |  |
| 会有人来抢这支神笔吗？马良又会怎么办？ |  |  |

师：（巡视，请两三位同学说）谁来说说你的猜想？说完猜的，别忘了讲一讲“我为什么这么猜”。

学生互动分享

参考（学生的猜想不必和这里一样，重点是**能说出理由**）：

① 有了神笔，马良会先给穷人画有用的东西——比如画牛、画农具、画粮食。理由：老人说这笔是“为咱穷苦人画画”的，马良自己就是穷孩子，他懂穷人缺什么。

② 会有坏人来抢笔，想让马良画金子、画宝贝，好让自己发财；可马良不会乖乖听他们的，他会用神笔想办法治住他们、脱身。理由：这么神的笔，贪心的人一定眼红；而马良手里有一支别人没有的笔，这是他最大的本事。

师：（稍停顿）大家猜得都有道理，尤其“讲理由”这一步做得好。你们猜得对不对，老师先不说。请把这张预测单夹进书里，等你自己读到后面，回来对一对：哪几条猜中了？哪几条和你想的不一样？——这才是预测真正有意思的地方。

### 四、读法提示与一周阅读计划（10 分钟）

师：这本书就交给大家自己去读了。（稍停顿）三个故事要一个接一个读，怎样才能读完不把它们弄混？谁有好办法？

学生自由分享

参考：读完一个先停一停、想一想主人公是谁、做了什么事；也可以把它记下来……

师：都是好办法。老师也给大家一个读“合集”的小提示，帮你把三个故事读得清清楚楚。

师：每读完一个故事，就在你的“阅读记录表”上，用一句话记两件事——**这个故事的主人公是谁**、**他做了一件什么事**。就一句话，不用多。三个故事读完，谁是谁、做了什么，就不会混了。（稍停顿）读的时候要是心里冒出什么问题，也记在旁边，下节课我们一起聊。

**一周阅读记录表**（自己读，边读边填）

| 读的是哪个故事 | 主人公是谁 | 他做了一件什么事 | 我读到这里冒出的问题 |
|---|---|---|---|
| 神笔马良 |  |  |  |
| 牧童三娃 |  |  |  |
| 大奖章 |  |  |  |

师：这一个星期，把三个故事读完。故事都不长，可以一两天读一个，不用赶。读慢一点没关系，读明白最要紧。

师：（总结）今天我们认识了这本《神笔马良》——它是三个独立故事的合集；也学着做了一回“预测”，猜了猜马良和他的神笔。下节课，等大家把三个故事都读完，我们再一起把故事理一理、聊一聊三个故事里的主人公。请把书和那两张单子都带来。

本课完。

## 第2课时 · 阅读交流课

**本节三维目标**

【知识技能】能分别说出三个故事的主要人物和主要事件；借流程图理清《神笔马良》情节发展的先后顺序。

【过程方法】重点显性训练推断策略——从人物的做法推断他是个怎样的人，并回到故事里找出根据；把三个故事的主人公放在一起联结对照，发现他们的共同点。

【情感价值】体会善良、勤奋、不贪、不骄傲这些品质；愿意像故事里的主人公那样，用自己的本领为别人做点好事。

### 一、三个故事，读完之后（10 分钟）

师：亲爱的同学们大家好！这一周，大家把《神笔马良》里的三个故事都读完了吧？（稍停顿）先做一件上周说好的事——请把夹在书里的那张预测单翻出来。上周我们猜了《神笔马良》后面会发生什么，现在你自己读完了，对一对：你猜的，和书里真发生的，哪几条猜中了？哪几条不一样？

学生互动分享

参考（对照预测单第三列自己核对，猜中猜不中都好）：多数同学猜中了“马良给穷人画有用的东西”“有坏人来抢笔、想让他画金子”；“马良到底怎么斗过他们”往往和书里不一样——不少同学没猜到，他最后是用画出来的大风掀翻了大船。

师：（稍停顿）这就是预测有意思的地方——猜完了，回头验一验。（稍停顿）上周我们还看了两幅画，猜过《牧童三娃》和《大奖章》讲的是什么事。现在你们读完了：那两幅画，猜中了吗？

学生自由分享

参考：发愁的孩子就是三娃，羊真的丢了；猴子宣布的正是森林运动会——上周大都猜到了。（学生顺势说起某个印象深的场面，接一两句就好，不另起一轮分享：三娃冒雨给大树培土；花神拿出一箱箱金银，三娃直摇头；小驴躺在树上做美梦、一蹦摔了下来；小熊冲过终点，把小猪拉来一起拍照……）

师：看来三个故事大家都读进去了。那读的时候，心里有没有冒出过什么问题？谁的问题，说出来大家一起听听？

学生互动分享

参考：为什么马良卖画时故意把画画得不像（少画一张嘴、少画一条腿）？三娃为什么金银都不要，只要羊？小驴那么厉害，怎么反而输了？

师：（稍停顿）这些问题都提得好。我们再把它们分一分——有的问题，回故事里读一读就能找到答案（像“马良为什么把画画得不像”，书里写了他怕被人认出来、故意画不活）；有的问题，得自己动脑筋、聊一聊才想得明白（像“小驴那么厉害，怎么反而输了”）。能找到答案的、要自己想的，都是好问题。今天这节课，这两种问题我们都会碰到。

### 二、给《神笔马良》理一理事情的经过（20 分钟）

师：三个故事里，《神笔马良》的事情最多、最曲折。我们就拿它来练一个本事——把一件件事，按先后顺序理清楚。老师给大家一张“流程图”。

师：流程图这样用：把事情按发生的先后排成一串，一行写一件事。你的单子上有五行，中间两行老师先替你写好了，你把空着的三行填上就行。它的用处，是让“先发生什么、后发生什么”一眼看明白。

师：（稍停顿）我们一起来。马良这个故事，最开头发生的一件事是什么？

学生互动分享

参考：马良想借笔学画，被学馆先生啐了唾沫、撵出门。

师：对，第一行就写这件事——马良想借一支笔，被撵出了门。（稍停顿）第二行老师已经写好了，你接着填第三行——得了神笔以后，他先拿它干什么？第四行也写好了，你只要再把最后一行填上。不会写的字用拼音。

**《神笔马良》故事流程图**（第二、四步印好，学生填第一、三、五步）

| 顺序 | 发生了一件什么事 |
|---|---|
| 第一步 |  |
| 第二步 | 一夜梦里，白胡子老人送他一支神笔，画什么就活什么。 |
| 第三步 |  |
| 第四步 | 大财主抢笔逼他画金元宝；后来皇帝又把他抓进京城，抢走神笔。 |
| 第五步 |  |

师：（巡视后请一组来说，师生一起把顺序捋顺）

师：（稍停顿）最后这一步，书里有一幅画。请翻到画着大浪和一条大船的那一幅（课前请学生在这一页夹好书签，翻起来快）。

【图位:插-11｜《神笔马良》· 结局一幕：马良在大桌上挥笔画风，浪压向皇帝的大船】

师：找到了吗？（稍停顿）这一幕，书里是这样写的——老师读一遍，大家一边听，一边看着这幅画。

（教师朗读）

> 皇帝被海水打得浑身湿漉漉的，抱着船的桅杆，不住地叫喊：
> “风太大了！船要翻了！不要再画了！……”
> 马良不去睬他，还是不住手地画风。风更大了，吹来了许多厚厚的乌云，又鸣雷，又闪电，还下起暴雨来。浪更猛了，海水像一堵倒坍的高墙，接连不断地往船上压去。
> 船翻了，船碎了，皇帝他们都沉到海底去了。

师：（稍停顿）再看这幅画：马良站在那张大桌子上挥笔，笔下的浪已经打过去了。皇帝那条大船怎么了？

学生互动分享

**参考版**（答案来自故事，学生用自己的话说对意思即可）

师：（稍停顿）把这五步从头到尾连起来——一个连笔都没有的穷孩子，最后靠自己的神笔，治住了财主和皇帝。（追问）大家发现没有：马良的神笔，从没给自己画过一座金山、一屋金子。他都拿去做什么了？

学生互动分享

参考：都拿去给穷人画有用的东西了——画牛、画犁、画水车，帮大家干活、过日子。他记着老人的话，“为咱穷苦人画画”。

### 三、三个主人公，放在一起看一看（20 分钟）

师：刚才我们把马良理清楚了。现在做一件更有意思的事——把三个故事的三位主人公，放到一起比一比。他们分别是：《神笔马良》里的马良、《牧童三娃》里的三娃、《大奖章》里的小熊。

师：（稍停顿）注意，他们各在各的故事里，本来互相并不认识。我们把他们放一起，不是让他们碰面，而是想看看——**这三个人身上，有没有什么地方是相像的**。老师给大家一张对比图，一行一个主人公，一列问一个问题。

师：这一环节，我们重点练一个读书的本事，叫“推断”。推断，就是——故事里没有直接说“这个人是好是坏、是怎样的人”，可我们能从他**做的事**里，自己推断出来。而且推断完，还得能回到故事里，指出“我是从哪件事看出来的”。

**三位主人公对比图**（空白版，学生分组填）

| 主人公 | 在哪个故事里 | 他做了一件什么了不起的事 | 面对金钱或好处，他是怎么做的 | 我推断：他是个怎样的人 |
|---|---|---|---|---|
| 马良 | 神笔马良 |  |  |  |
| 三娃 | 牧童三娃 |  |  |  |
| 小熊 | 大奖章 |  |  |  |

师：先看中间两列——“做了什么了不起的事”“面对金钱或好处怎么做”，这两列可以回故事里找。（稍停顿）上周那张阅读记录表也放在旁边——你在上面记过每个故事的主人公做了一件什么事，第三列照着它填就快了。填好了，最后一列“他是个怎样的人”，就靠你自己**推断**。

（学生分组填写，教师巡视）

师：好，我们来对这一列——面对金钱或好处，三个人各是怎么做的？一组报一位，报完了别人再补。（小熊没碰上金子，那就说说：那枚人人都想要的大奖章，他是怎么得到的？）

学生互动分享

参考（三位分开对，学生说到哪一位就对哪一位）：

① 马良——大财主逼他画金元宝，他死活不肯；皇帝抢了笔、许他金银还许公主，他也不真心画，反倒治住了皇帝。

② 三娃——花神拿出一大盒金子、一大箩银子、一大串珍珠、一大箱玛瑙送他，他一样一样都摇头说“我不要”，只求找回全村的羊。

③ 小熊——他靠自己天天苦练，跑了第一名，赢得大奖章；得了奖章也不独自得意，还把胆小、退缩的小猪拉过来，一起拍照。

师：（稍停顿）现在到最要紧的一步——**推断**。三个人放一起看，你推断他们是怎样的人？最后一列，你是从哪件事推出来的，说给大家听。

学生互动分享

参考（学生用自己的话说，只要**推断有根据**就好）：他们都善良，心里都装着别人。马良宁可挨饿也不给财主画金元宝、三娃满箱金银都不要，可见不贪财；马良的笔为穷人画、三娃拼命是为全村的羊、小熊夺了奖还想着小猪，可见心里都装着别人；小熊天天练跑才拿冠军，可见还得靠自己勤奋、踏实。

（这一问是本节的弹性点：时间紧就只谈小驴，皇帝那一半留到下课前口头带过。）

师：（追问）我们再反过来看一眼——这三个故事里，也有让人不那么喜欢的角色——《神笔马良》里的皇帝、《大奖章》里的小驴。他们各自做了些什么事？（稍停顿）先看小驴：请翻到《大奖章》比赛的那几页，找到画着小驴挂着号码布、仰着头的那一幅。

【图位:插-29｜《大奖章》· 赛跑途中的小驴（挂着号码布，仰头哼唱，四条腿拖拖拉拉）】

师：你看这一幅：比赛已经开始了，小驴在干什么？小熊和小猪呢？

学生互动分享

参考：小驴仰着头在唱歌，走得拖拖拉拉，一点也不着急；别的动物都在往前跑，就它一个不慌不忙。比赛的时候，它的心思根本不在跑上。

师：和马良、三娃、小熊比一比，皇帝和小驴又是怎样的人？你从哪件事看出来的？

学生互动分享

参考：皇帝贪心——金山画个没完，还想坐船去海上“摇钱”，最后把自己也搭了进去；小驴骄傲——上届拿过奖章就不肯练，只顾画像、做美梦，比赛中还分心去踢球、找奖章，结果输了。（从他们做的事，就能推断出“贪心”和“骄傲”。）

师：（总结）你们看，故事没有一句直接说“马良善良”“小驴骄傲”，可我们从他们**做的事**里，全推断出来了——这就是会读书。三位主人公虽在不同的故事里，身上却有一样相通的东西：心里都装着别人——有了本事、有了好东西，头一个想到的不是自己。

### 四、假如我也有一件宝物（10 分钟）

师：我们再回头看其中两位——马良有了神笔，头一个想到的，是给村里的穷人画犁、画牛，而不是给自己画金山；三娃面对满满一箱金银珍珠，摇摇头，只要全村的羊。（稍停顿）他们有了了不起的本事和东西，先想到的都是“为别人”。

师：（稍停顿）上节课一开始，老师问过大家：最想用这支笔画点什么？那时候你们想的，多半是自己想要的东西。今天老师再把这样一件宝物送到你手上，只加一个条件——**假如你也有一支马良的神笔，或者一粒三娃的神奇种子**（说一声，就能变出你要的东西），你会先想到为谁、做一件什么事？

师：（稍停顿）要是你不想靠宝物，也行——你还可以像《大奖章》里的小熊那样：**说一件事：你愿意自己踏踏实实去做成，做成了还能帮上别人**。靠宝物也好、靠自己也好，最要紧的是——你头一个想到的是谁。

师：想好了，把它画下来或写下来，填在这张卡片上。不会写的字用拼音。（稍停顿）“为什么想为他做这件事”不用写，等一会儿说给大家听就行。

**“我的一件宝物”心愿卡**（画一画 + 写一写）

| 我靠什么（神笔·种子·或我自己的努力） | 我想为谁 | 我要为他（们）做的一件事 |
|---|---|---|
|  |  |  |

（学生画写，教师巡视，鼓励“为别人”的心愿）

师：谁愿意上来，说说你的宝物、你要为谁做的事？

学生互动分享

参考（学生的心愿各不相同，只要落在“为谁做一件具体的事”上就好）：我想用神笔给生病的奶奶画一副能治病的药；我想用种子变出很多树，种在光秃秃的山上；我想给没有书包的小朋友画一个新书包；我愿意像小熊那样，自己每天多练练，把字写好，再去帮一帮班里写字慢的同学……

师：（请两三位分享，简单点评：都想到了别人，很好）

师：（总结）这一本《神笔马良》，我们读完了三个故事。马良、三娃、小熊，三个互不相识的人，却让我们看见了同一样宝贝——不是那支神笔、那粒种子、那枚奖章，而是他们心里的善良，和肯为别人使劲的那股劲儿。（稍停顿）希望你们手上这件“宝物”，将来也真能为身边的人，做上一件小小的好事。
