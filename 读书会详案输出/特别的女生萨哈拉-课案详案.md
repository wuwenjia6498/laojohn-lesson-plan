### 一、文本介绍

【内容简介】 萨哈拉·琼斯住在芝加哥，和妈妈两个人过日子。她三年级那年，爸爸离开了家，谁也不知道他去了哪儿。她一直给爸爸写信，信从课桌里散落出来，被老师交给了教导主任，塞进了装着她档案的大文件柜。因为这些信，她被安排坐在教学楼的大厅里接受“特殊教育”，同学们偷偷叫她“特别的萨哈拉”。妈妈到学校要求停掉特殊教育，宁可让她按普通标准留级。于是，萨哈拉开始了她的“第二个五年级”。没人知道，这个在学校里“从来没写过什么”的女孩，心里藏着一个当作家的梦：她把写好的东西从本子上撕下来，偷偷藏在公共图书馆 940 区书架底层的一个活页夹里。新学年，班上来了一位从别处调来的老师——波迪小姐。她插花、钉钉子挂证书、立“一定要”开头的规矩，还发给每个人一本日记本。全书十三章，由萨哈拉自己讲述这一学年：一个把自己藏起来的女孩，怎样一点一点被人读到。

【作者介绍】 本书作者是美国的爱斯米·科德尔，译者陈水平。备课依据湖南少年儿童出版社·博集天卷 2019 年版的电子版，电子版没有收作者简介，也没有作者后记和译后记。电子版为流式排版、无固定页码，全书定位一律按章节（学生手里的纸书有页码，但课上只说章号）。书前有一篇中文版前言《秘密行程里的绿荫》，是书外的文字，课上提到时须说明它不是小说正文。全书用第一人称写成，讲述者就是萨哈拉本人；正文里嵌着许多别的文字——写给爸爸的信、日记、老师的批语、一首诗、两篇作文、一张寻物字条。

### 二、教学目标（书级·三维）

【知识技能】知道全书共十三章、由萨哈拉用第一人称讲述她“第二个五年级”这一学年，能按“处境与起点（第一至四章）/ 新老师与冲突（第五至十章）/ 转折与收束（第十一至十三章）”把全书分成三段；能说出萨哈拉、妈妈、表妹瑞秋、波迪小姐、德里、巴黎、露兹等人物的身份与彼此关系；能沿着“萨哈拉在学校里写与说出来”这条主线，说出她从“作品藏起来”到“被人读到”的九个节点，并指出其中往回退的地方。

【过程方法】综合运用预测、提问、推断、比较、整合、监控、转化七项阅读策略；能借助时间轴把散在十三章里的“写”与“说”整合成一条线，借助阅读单比较萨哈拉与德里这两个留级生，借助鱼骨图追溯“心墙倒下”背后的多股原因；能品析书中把看不见的心情写成身体反应的写法，说出这样写读者感受到了什么；能在讨论中把每一个判断回扣到具体章节的原文。

【情感价值】体会一个被贴上标签的孩子，怎样在被相信、被读到中找回自己；思考一份档案、一个外号、一句评价能不能说明一个人；体会“故事不一定要完全真实”这句话里，写作给人的力量。

### 三、教学流程

## 第1课时 · 导读课

### 本课三维教学目标

【知识技能】知道《特别的女生萨哈拉》的作者、译者、版本与体例——全书十三章、各章有章名、课上一律按章节定位；听读第一章、第五章的四段原文，知道萨哈拉的处境（留级、档案、“特别的萨哈拉”）和她藏起来的作家梦。

【过程方法】重点显性训练预测与提问两个策略：能依据今天读到的原文写下有依据的预测，留到下节课验证；能从十三个章名里提出自己的问题，并分出“读下去就能找到答案的”和“要想一想、讨论才知道的”。同时学会两种阅读记号：一是标出嵌在正文里的信、日记、批语，二是标出萨哈拉“想说却没说出口”的话。

【情感价值】对“一个在学校里从来没写过什么的女孩，怎样成为作家”产生好奇，愿意用一周时间读完这本书。

### 一、课程导入·一份“不是全部”的档案（15 分钟）

师：亲爱的同学们大家好。今天这节课，我们直接从一段话开始。书先合着，听老师读。说话的是一个五年级的女孩，她和妈妈正坐在学校教导主任的办公室里，教导主任叫史丁先生。

（教师朗读，定位：第一章“我和德里”·教导主任办公室）

> 史丁先生拿出了一大沓纸，那是我的档案，我全部的故事。不，不是全部！它们只是一部分。这部分故事不包括我和妈妈去书店的事情。

师：她接着说，档案里没有记下的事还有很多：每次逛书店，她都可以自由挑自己喜欢的书，妈妈付钱时眼睛都不眨一下；她还常去图书馆挑书，让妈妈下班后读给她听。她说，妈妈一直是她最好的老师，可这些事，档案里都没有。那档案里有什么呢？有她乱七八糟、没完成的作业，还有爸爸离开后她写得凌乱潦草的日记。她刚写给爸爸的一沓信，也被史丁先生拿走了。听老师读接下来这一段。

（教师接着朗读，定位：第一章“我和德里”·教导主任办公室）

> 史丁先生把我的信也塞进了那个大文件柜里。柜门被“噔”的一声关上，好像朝我发出一声刺耳的嘲笑。那个文件柜里装满了我所有表现不好的证据，它一直在那儿候着，准备随时听命，打开柜门来证明我是个大笨蛋。

师：我想请大家先站到史丁先生的位置上。你手里只有这份档案：没完成的作业，潦草的日记，一沓写给爸爸的信。只看这些，你会认为这是一个什么样的孩子？

学生互动分享

参考：学生可能说：①学习不认真、作业都不完成的孩子；②字写得乱、不爱学习的孩子；③家里出了事、心情不好的孩子（从“爸爸离开后”的日记看出来）；④有同学会说“看不出来，因为档案只是一部分”。教师复述几种说法：“有的同学看到的是一个不完成作业的孩子，有的同学看到的是一个想爸爸的孩子，还有同学说，光凭这几张纸看不出来。”

师：再站回她自己的位置。她说档案“不是全部”，档案外面的那个她，是什么样的？请从刚才听到的话里找根据。

学生互动分享

参考：爱读书——常和妈妈逛书店、去图书馆挑书，妈妈给她朗读；她觉得档案漏掉了自己最重要的部分；她很在意别人怎么看她，“证明我是个大笨蛋”这句说明她怕被当成笨孩子。如果有同学说“她其实不笨”，教师追问：“你凭的是哪一句？”引导学生回到“不，不是全部！”这一句上。

师：（稍停顿）这一章里，还有一件档案里也没记下的事：这个女孩想当作家。她写了很多东西，可一个字都不放在学校，全都从本子上撕下来，藏到公共图书馆 940 区书架最底层的书后面，那里有她的一个活页夹，题目叫《我的痛苦人生和精彩历险》。学校说她“在这儿从来没写过什么”。所以，一个在学校里“从来没写过什么”的女孩，一个藏在图书馆书架底下的作家——这就是我们这本书的主人公，萨哈拉·琼斯。

师：大家手上这本书叫《特别的女生萨哈拉》。“特别”这两个字，书名告诉你了；书名没告诉你的是：在她的学校里，“特别的萨哈拉”是同学们取笑她的外号。为什么会有这个外号？档案里的她和档案外面的她，谁会赢？这就是我们这一周要读的。

### 二、精彩片段共读·一页空白的日记本（15 分钟）

师：先把这个外号的来历讲清楚。那一沓写给爸爸的信被交上去以后，学校给她安排了一位负责特殊教育的老师，让她坐在教学楼的大厅里上课，同学们路过时冲她发出“嘘嘘”声，偷偷叫她“特别的萨哈拉”。后来妈妈到学校，要求停掉特殊教育，宁愿让她留一级。所以，这一年她又读了一遍五年级，书里叫“第二个五年级”。

师：就在这个“第二个五年级”，班上来了一位新老师，波迪小姐。她给每个同学发了一本日记本，让大家写日记。请大家翻开书，找到第五章“新老师来了”。第一次写日记，萨哈拉想了很多很多要写的话，我来读其中一段，大家跟着看。

（教师朗读，定位：第五章“新老师来了”·第一次写日记）

> 我想告诉波迪小姐，我很会观察，很会倾听，很会思考，触觉很棒，嗅觉很棒，记忆力也很棒，可这又怎样呢？学校根本不在乎我这些长处，不是吗？我擅长的这些东西，学校从来不会记在档案里，不是吗？

师：她说，这些长处只是她一个人的秘密，她把它们藏在心底的一个大箱子里，可是钥匙找不着了，想写的时候打不开箱子。就在这时候，下课铃响了。请一位同学读这一句，就在书上紧接着的地方。

（邀请一位平时朗读功底不错的同学朗读，定位：第五章“新老师来了”·第一次写日记）

> 下课铃声响了，我一个字都没来得及写，我看着自己的日记本，上面一片空白，日记本也在瞪着我。

师：谢谢。想写的那么多，写下来的一个字也没有。书里没有直接说她为什么写不出来，请你推断一下，凭刚才读到的哪一句？

学生互动分享

参考：①“学校从来不会记在档案里”——她觉得写了也没人在乎，学校只记她不好的地方；②“藏在心底的一个大箱子里”“找不着钥匙”——她把自己藏得太久，一下子打不开了；③联系第一章：她写的信被塞进了文件柜，写下来的东西会变成“证据”，她不敢在学校写。教师复述学生找到的那一句，再追问一句：“这三种原因里，哪一种是从第一章接过来的？”引导学生把“文件柜”和“空白的日记本”连起来。

师：本子要交了，同学们一本一本往前传。她一下子慌了，抓起笔，只写了一句话。只有一句。大家猜一猜，她写了什么？

学生互动分享

参考：学生可能猜“我不知道写什么”“对不起”“我想爸爸”“我很会观察”等。教师把几种猜测复述出来，再请大家看书上那一句——

师：她写的是：“我是作家。”然后本子交上去，混在一堆本子里。她说一想到老师会看到，脸就像煮熟的大虾一样又红又烫。后来本子发回来，波迪小姐在这一句下面写了一句批语，一共四个字加一个感叹号：“我相信你！”

师：（稍停顿）一个“在学校里从来没写过什么”的孩子，第一次交上去的日记只有四个字；老师也回了她四个字。这一页日记，就是这本书里很多事情的开头。

### 三、预测阅读单·“我相信你！”之后（10 分钟）

师：我们已经读到了第五章的一页日记。接下来这个“作家”会怎么样？请大家在这张预测阅读单上，选两个问题写下你的预测，每个预测都要写清楚依据——依据就是今天听到、读到的原文。最后一栏现在空着，下节课回来再填。

| 我想预测的问题 | 我的预测 | 我的依据（今天读到的哪一句） | 读完后验证（下节课填） |
| --- | --- | --- | --- |
| 萨哈拉会不会让学校里的人读到她写的东西？ |  |  |  |
| 那个装着她档案和信的大文件柜，后来会怎么样？ |  |  |  |
| 写下“我相信你！”的波迪小姐，是一个什么样的老师？ |  |  |  |

学生填写，教师巡视。

学生互动分享

参考：示例填法——①“会，但要很久。依据：她第一次只写了一句‘我是作家’，说明她心里是想让人知道的，可她脸烫得像煮熟的大虾，说明她还很害怕。”②“她会想办法把信拿回来。依据：柜门关上时像‘刺耳的嘲笑’，她一直记着这个柜子。”③“是一个不看档案、只看人的老师。依据：别的老师只看到她没完成的作业，波迪小姐看到‘我是作家’就回了‘我相信你’。”教师请两三位同学读自己的预测，追问一句：“你是根据哪一句猜的？”只评依据找得准不准，不评预测对不对——对不对，一周后由这本书来回答。

### 四、认识这一本书·十三个章名里的问题（15 分钟）

师：这本书的作者是美国的爱斯米·科德尔，中文是陈水平翻译的。现在请大家翻到目录。这本书一共十三章，每章都有章名。请一位同学把十三个章名从头到尾读一遍，大家听。

（一位同学朗读目录：一、我和德里；二、真正的梦想；三、图书馆女孩；四、每天都有新鲜事；五、新老师来了；六、狮子的故事；七、挨揍的乔治；八、房子是怎样建起来的；九、波迪小姐来家访；十、孤儿；十一、老师和苹果；十二、名字的由来；十三、我的自传）

师：这十三个章名，有的一看就懂，比如“新老师来了”；有的让人摸不着头脑，比如“挨揍的乔治”——书里我们还没见过一个叫乔治的人。请你从章名里提两个问题，写在本子上。

学生互动分享

参考：学生可能提出：①“我和德里”里的德里是谁？他和萨哈拉是什么关系？②“挨揍的乔治”是谁？谁挨揍了？③“孤儿”说的是谁？萨哈拉的爸爸走了，她算不算孤儿？④“老师和苹果”是什么意思？⑤第十三章叫“我的自传”，她最后真的写了一本书吗？⑥“图书馆女孩”是萨哈拉自己，还是另一个人？教师把学生的问题复述出来。

师：我们把这些问题分一分。有的问题，读下去就能找到答案，比如“德里是谁”；有的问题，读完了也不一定有现成答案，需要想一想、讨论讨论，比如“萨哈拉算不算孤儿”。请你在自己写的问题旁边做个记号：读下去能找到答案的画一个圈，要想一想讨论的画一个三角。

学生互动分享

参考：画圈的多是人物是谁、发生了什么——德里是谁、乔治是谁、图书馆女孩是谁；画三角的多是要下判断的——萨哈拉算不算孤儿、她最后算不算作家、“我的自传”为什么放在最后一章。教师收口：画圈的问题，这一周读书时自己去找答案；画三角的问题，请带到第二周的课上来，那正是我们要讨论的。

师：最后讲两种记号，这本书用得上。第一种：这本书是萨哈拉自己讲的，可书里还夹着很多别人写的、她写的文字——写给爸爸的信，日记，老师写在日记本上的批语，还有一首诗。读到这些地方，请在书页边上标一个“信”“日”“批”或“诗”字。第二种：萨哈拉常常心里想说一句话，嘴上却没说出来，书里会把这句没说的话写出来，紧跟着告诉你“我没说”。读到这样的地方，在旁边画一条波浪线。

师：两种记号都是为了让你读的时候停一停：这一段是谁写的，写给谁看的？这句话她说出口了没有？读着读着，如果你发现自己搞不清现在讲的是谁的文字、是她说的还是她想的，就往前翻一翻，回到这一段的开头再读一遍，弄清楚了再往下读。

### 五、阅读计划·七天读完十三章（5 分钟）

师：这本书六万一千字，一共十三章。我们用七天读完，每天两章左右，最后一天读第十三章，再把自己做的记号从头翻一遍。

| 天数 | 阅读章节 | 完成打勾 | 我的记录（一处波浪线：她想说却没说出口的话 / 一个新问题） |
| --- | --- | --- | --- |
| 第 1 天 | 第一章、第二章 |  |  |
| 第 2 天 | 第三章、第四章 |  |  |
| 第 3 天 | 第五章、第六章 |  |  |
| 第 4 天 | 第七章、第八章 |  |  |
| 第 5 天 | 第九章、第十章 |  |  |
| 第 6 天 | 第十一章、第十二章 |  |  |
| 第 7 天 | 第十三章，翻看全书记号 |  |  |

师：记录栏每天只写一行：要么摘一句她想说却没说出口的话，写清楚是第几章；要么写一个你读的时候冒出来的新问题。下节课我们会先拿出今天这张预测阅读单，一个一个对答案。

参考：教师提示学生，第七天读完后，把预测阅读单最后一栏留着，带到课上一起填；本子上画了圈、画了三角的问题，也请带来。

本课完。

## 第2课时 · 阅读交流课1

### 本课三维教学目标

【知识技能】能按“作品藏起来 → 被人读到”这条主线，说出萨哈拉在第一、五、七、八、九、十、十一、十二、十三章的九个节点上做了什么、说了什么；能从对照的几个方面说出萨哈拉与德里这两个留级生的相同与不同。

【过程方法】重点显性训练整合与比较两个策略：能借助时间轴把分散在九章里的细节整合成一条有进有退的线，并说出这条线在哪里往回退、为什么；能借助阅读单比较萨哈拉与德里，并说出这些异同让自己对两个人有了什么新的理解。同时验证导读课的预测。

【情感价值】体会一个人的改变不是一步登天，会有退缩和反复；对德里这个“膀大腰圆”、爱惹事的男孩，生出多一层的理解。

### 一、阅读回顾·预测阅读单回头看（10 分钟）

师：亲爱的同学们大家好。一周过去了，萨哈拉的“第二个五年级”我们都陪她过完了。请大家拿出导读课填的预测阅读单，现在把最后一栏“读完后验证”填上：你猜中了吗？哪里猜中了，哪里没猜中？

学生填写。

学生互动分享

参考：①萨哈拉会不会让学校里的人读到她写的东西——会。第九章她病中写了《我居住的地方》，把本子递给表妹瑞秋看；第十二章她走上讲台，当着全班朗读自己的日记《我的名字》。猜“要很久”的同学基本猜中了，几乎是一整个学年。②文件柜——第十二章，波迪小姐任命她当“小信使”，她按字条找到一个旧储存柜，里面是一盆开花的小仙人掌和她的档案；第十三章她回家打开档案，把写给爸爸的信一封一封放出了窗外。③波迪小姐——第九章家访时她说自己没看过萨哈拉的档案，“我只看萨哈拉本人”。如果有同学预测“她会自己去把信偷回来”或“她会去找爸爸”，教师顺带核一句：书里不是这样。档案是老师用一个信封、一张字条“送”回给她的；爸爸在全书里一直没有出现、也没有回来，她最后是在脑海中写下了给爸爸的最后一封信。教师收口：没猜中的预测同样有用——它让你看清作者没有走你以为的那条路。

师：导读课上，大家还给自己从章名里提的问题画了三角——那些要想一想、讨论才知道的问题。请几位同学把自己的三角问题念一念。

学生自由分享

参考：学生可能念出：萨哈拉算不算孤儿？她最后算不算作家？第十三章为什么叫“我的自传”？教师逐个说明它们在哪一节讨论：“她算不算作家”，今天的时间轴走完就有答案；“萨哈拉算不算孤儿”，今天和德里放在一起比的时候就会碰到；“我的自传”放到思辨课。没念到的三角问题，请写在预测阅读单背面交上来，老师会在后面几节里找机会接住。

### 二、时间轴·萨哈拉从“藏起来”到“被读到”（25 分钟）

师：导读课上我们说过，学校说萨哈拉“在这儿从来没写过什么”。到了全书最后，她对妈妈说，自己在写“我的自传”。从“从来没写过”到“我的自传”，中间她走了很长一段路。今天我们用一条时间轴，把这段路整理出来。

师：请第二组说。你们组填的格子里，有没有哪一格是往回退的？

师：请大家翻到第八章，找到她看到这句批语以后的反应，开头是“为什么她就不能”。我来读后面几句。

> “作家需要写作”，就这么一句话，我感觉她好像在质问我：你不是说你是作家吗？那你怎么不写？看来你什么也不是嘛。

师：同样是一句只有几个字的批语，第五章的“我相信你！”让她往前走，第八章的“作家需要写作。”她却读成了“看来你什么也不是嘛”。为什么？

学生互动分享

参考：①她心情很差——就在这段话前面，她正委屈着：别的同学日记本上有那么多贴纸，她却一枚也没有；②她一直怕被人看成笨蛋，第一章就怕文件柜“证明我是个大笨蛋”，所以老师一句话她就往坏处想；③她自己后面也说了，“也许她不是那个意思，也许她只是实事求是”。教师收口：同一个老师、差不多的批语，她读出来的意思却随着心情变。这一格往回退，变的不是老师，是她心里那个柜子又关上了。

师：请第二组接着说第九章。她是怎么又往前走的？那时她正生着病。

学生互动分享

参考：波迪小姐来家访，她在床上装睡偷听，听到老师对妈妈说没看过她的档案，“我只看萨哈拉本人”“她将来能成为一名作家”。老师走后，她爬起来写了作业《我居住的地方》，还把本子递给了瑞秋。教师补一句转述：她爬起来之前，在心里跟自己说了一番话——让别人失望了，还能说一句对不起；要是辜负了自己的梦想，她就没法原谅自己。教师收口：这一回，推她往前走的，除了老师那句话，还有她自己。

师：（总结）大家看这条时间轴：九格里有一格往回退；第十章那格，她每天写日记，却把抄的诗不署名、偷偷放在德里椅子上，只走了半步；第一章那格是起点，其余都在往前，越到后面步子越大——第十二章那一大步，第三组的同学请自己回书上核一核，下节课我们还要细读。整合起来看，她的改变是怎么发生的？

学生互动分享

参考：①不是一下子变的，用了差不多一整个学年，从“从来没写过什么”到对妈妈说在写“我的自传”——三角问题“她最后算不算作家”，时间轴已经给了答案；②中间会退回去，退的时候往往是犯了错、心情不好、想起那个柜子的时候；③每一次往前，旁边几乎都有一个读到她、相信她的人——老师的批语、瑞秋、全班的欢呼。如果有同学问第十章为什么只算半步，教师点一句：诗不署名，她愿意把喜欢的文字给人，还不愿意让人知道是她给的；到第十二章，她读的才是自己写的、署自己名字的文字。教师收口：第③条先记下来，下节课我们专门追究，她的心墙到底是被哪些力量推倒的。

### 四、小结·带着两张单子进下一节（5 分钟）

师：今天这节课，我们用时间轴把萨哈拉的路走了一遍：九格里有进有退，越往后步子越大；又用阅读单把她和德里放在一起，看见了两个留级生的同和不同。

师：时间轴最后我们记下了一句话：每一次往前，旁边几乎都有一个读到她、相信她的人。下一节课，我们就从这句话往深处追——她的心墙是怎么倒下的？除了这个问题，我们还要细细品一品，这本书是怎样把一个孩子看不见的心情写出来的。请大家把今天的时间轴留在桌上，下节课我们接着用。

本课完。

## 第3课时 · 阅读交流课2

### 本课三维教学目标

【知识技能】能找出书中把看不见的心情写成身体反应或看得见的东西的句段，以及写出萨哈拉“想说却没说出口”的句段，说出这样写好在哪、和第一人称叙述有什么关系；能说出波迪小姐所讲的“老师和苹果”这个故事与德里、与萨哈拉的联系；能用鱼骨图说出推倒萨哈拉“心墙”的多股力量，每一股都有章节依据。

【过程方法】重点显性训练推断与监控两个策略：在文学赏析中，先说读到的感受，再回到字句找依据，并通过两组原文与老师改写版的比较说出写法的效果；在细读“老师和苹果”时，分清“书里写明了的”和“我推断出来的”，凡书里没说的不当成定论。借助鱼骨图把散在多章的原因整合起来，用文本证据支持“哪根刺最粗”的判断。

【情感价值】体会作者写心情的用心，感受一个孩子从“身体在承受”到“心墙倒下”的变化；理解一个人的改变需要别人的相信，也需要自己的坚持。

### 一、文学赏析·嘲讽“听”进了身体（25 分钟）

师：亲爱的同学们大家好。上节课我们看了萨哈拉的路怎么走，这节课先停下来，看看这本书是怎么写的。萨哈拉说自己“很会观察，很会倾听”，这本书里有很多地方，她把一个人心里看不见的东西，写成了看得见的样子。我们先读第一章里的一段：她坐在大厅里接受特殊教育，同学们经过时冲她发出“嘘嘘”声，叫她“特别的萨哈拉”。请大家翻到第一章，我来读这一段的后半部分，大家跟着看。

（教师朗读，定位：第一章“我和德里”·大厅里的特殊教育）

> 我假装没听到他们的嘲讽，但我其实听到了。不仅仅是耳朵听到了，我的双颊也听到了，所以它们变红了；我的双眼也听到了，所以它们直直地盯着墙壁，盯着我的膝盖，盯着我的鞋子；我的指甲也听到了，所以我拼命地啃着它们。嘲讽的声音穿过我的衣服，撕裂了我的皮肤，透过我的骨头，在我空洞的身体里回荡。

师：先不说这段用了什么写法。读完这一段，你觉得那一刻的萨哈拉有多难受？你自己读的时候，是什么感觉？

学生互动分享

参考：学生可能说：①难受到全身都在疼，不只是心里难过；②她躲也躲不掉，越来越难受；③读着读着自己也觉得脸发烫、坐不住；④她很孤单，“空洞的身体”像是心都被掏空了。教师复述学生的感受词：“有的同学说全身都疼，有的说躲不掉，有的说读着自己也坐不住。”

师：好，现在回到字句上。是哪几个词、哪几句话，让你有了刚才的感觉？请在书上画出来，说一说为什么是它。

学生互动分享

参考：①“双颊也听到了”“双眼也听到了”“指甲也听到了”——耳朵才会听，可她让脸、眼睛、指甲都去“听”，说明这些嘲讽她全身都接收到了；②“变红了”“直直地盯着墙壁，盯着我的膝盖，盯着我的鞋子”“拼命地啃着”——这些是能看得见的样子：脸红、不敢抬头、啃指甲；③“盯着墙壁，盯着我的膝盖，盯着我的鞋子”，目光一路往下落，越来越低；④最后一句“穿过我的衣服，撕裂了我的皮肤，透过我的骨头”，声音一层一层往里钻，一直钻到身体最里面。教师追问画③的同学：“墙壁、膝盖、鞋子，这三个地方的顺序换一换行不行？”引导学生说出目光越落越低、头越埋越深。

师：我们来做个比较。下面这段是老师改写的，不是原文，意思差不多，大家听听差在哪。

师：（老师改写版，不是原文）同学们的嘲讽我都听到了，我很难过，脸红了，眼睛不敢看别人，一直低着头，紧张得啃指甲。我的心里非常痛苦。

师：两段放在一起，哪一段让你更能感到她的难受？差在哪里？

学生互动分享

参考：原文更能感到。①改写版直接说“我很难过”“非常痛苦”，是告诉你她难过；原文一个“难过”都没写，是让你看着她的脸、她的眼睛、她的指甲，自己感到她难过；②改写版把脸红、低头、啃指甲并排一说就完了，原文用“也听到了，所以……”一句一句接下去，读起来像嘲讽一处接一处打在她身上，停不下来；③改写版没有最后一句，少了声音一层一层往里钻的感觉，难受只停在表面。教师复述学生的说法，然后收口点名：这种写法，是把看不见的心理，写成看得见的身体反应；再加上“双颊也听到了”这样把身体写成会听的人，和一句接一句的排比，读的人就跟着她一起“听到了”。

师：这本书还有一种写法，大家这一周其实一直在跟它打交道——就是你们画的波浪线：她心里想说一句话，嘴上没说出来，书里把这句没说的话写出来，紧跟着告诉你她没说。比如第一章走出办公室，她很想对妈妈说“不用感到抱歉，妈妈，我同样也没能留住爸爸”，但知道这时候最好不要插嘴；第四章门廊下，妈妈说一起努力、一步一步来，她只想告诉妈妈：她太孤独了，她做不到。

师：我们拿第八章的一处来比一比。萨哈拉偷了贴纸、被巴黎当面指责以后，课间和瑞秋一起靠在操场的铁链栅栏边。请大家翻到第八章，找到“我想对她说”这一句，我来读。

（教师朗读，定位：第八章“房子是怎样建起来的”·栅栏边）

> 我想对她说，我们去找大家玩吧，别单单两个人傻站在这里了。可我没说，我今天说不出口。我觉得离他们好远，栅栏边才是属于我的地方。

师：（老师改写版，不是原文）我靠在栅栏边，一句话也没说。

师：要是书里只写了老师改的这一句，你知道的和书里其他人知道的，有什么不一样？读原文的时候，你又知道了什么？

学生互动分享

参考：①只读改写版，读者和操场上的人一样，只看见一个靠着栅栏不说话的女孩，可能以为她冷淡、不合群；②读原文，读者知道她其实想去找大家玩，是“说不出口”，还觉得“栅栏边才是属于我的地方”——她不是不想，是不敢；③全书只有读者听得见这些没说出口的话，书里的同学、老师都听不见。教师追问：“书里谁也听不见，为什么偏偏读者听得见？”引导学生说出：因为这本书是萨哈拉自己讲的。教师收口点名：这叫第一人称叙述，讲故事的人就是“我”，所以作者能把“我”心里的话、没说出口的话都交给读者。萨哈拉在学校里说不出口的话，全写给了读这本书的人。

师：最后请大家看第十二章，她读完《我的名字》以后的几句：

（教师朗读，定位：第十二章“名字的由来”·读完之后）

> 全班人都在欢呼。他们的声音大得我都听不见自己的心墙倒下的声音了。但我知道那堵墙消失了，波迪小姐也一定感觉到了。

师：（总结）把第一章那段、栅栏边那段和这几句放在一起看。第一章的声音是嘲讽，钻进她的身体里；第十二章的声音是欢呼，大得盖过了心墙倒下的声音——同样写声音和身体，一个是伤，一个是好。“心墙”也是把看不见的心情写成一样看得见的东西。栅栏边那些话，她只敢说给读者听；到第十二章，她站上讲台，把自己写的文字当着全班念了出来，没说出口的话终于说出口了，这正是她一整年的变化。

参考：教师可再补一句：这本书一直让萨哈拉自己讲，她又是一个“很会观察”的孩子，所以连自己的心情、连没说出口的话，她都能一样一样摆到读者面前。（这是这个中文译本里的语言，我们读到的比喻和句子，都是译者陈水平的翻译。）

### 二、细读推断·故事里的故事（15 分钟）

师：这本书里，波迪小姐很爱讲故事：第六章讲伊索寓言，第七章讲华盛顿和樱桃树，第十一章讲了全书最长的一个故事——“老师和苹果”。讲完以后，全班都要讨论这个故事是什么意思。我们来细读这个故事的结尾。故事里，一个男孩长大后当了老师，有一天，一个小女孩来到他面前。

（教师朗读，定位：第十一章“老师和苹果”·波迪小姐讲的故事）

> “‘我还是一只小鸟、还是一匹马儿的时候，你每天都会给我一个苹果。现在我要把这个苹果送给你。’”波迪小姐从她桌子上拿了一个苹果，放到德里桌子上。德里看着她的脸，假装没看见那个苹果。

师：故事讲到这里，波迪小姐边讲边做了一件事：把一个苹果放到了德里的桌子上。书里没有说她为什么这样做。请你推断，凭的是哪一处？

学生互动分享

参考：①这个故事和德里有关。讲到故事里的男孩在家总挨揍、站在桌子上捶着胸脯大喊大叫时，德里站到椅子上模仿，还插话说“回家会挨打”——波迪小姐的苹果，像是故事里的小女孩递给老师的那个苹果，在告诉德里：有人记着你；②德里“假装没看见”，说明他看见了，只是不好意思。教师追问：“你是从书里哪一处，知道这个故事和德里有关的？”请学生回到第十一章德里插话的地方。

师：现在请大家注意一件事。这个故事里，小女孩说“我还是一只小鸟、还是一匹马儿的时候”，这个小女孩到底是谁？是故事前面那个老太太老师变的吗？老太太老师后来去了哪里？请大家回到书上，找一找书里写明了什么。

学生互动分享

参考：书里只写了老太太老师背上她的一袋书离开了学校、走进了树林，后来男孩发现了她的书包；小女孩是谁、老太太老师是不是死了，书里都没有直说，只有小女孩这一句话。如果有同学说“小女孩就是老太太老师”，教师追问：“书里哪一句这样写了？”请学生分清：这是我推断的，不是书里写明的。教师收口：读这本书，读到这种地方要停一下，问问自己——这是书上写的，还是我想出来的？凡是书里没说的，我们可以猜，但不能当成故事的定论。连安杰利娜说的“这就是老师的第三个愿望”，也是安杰利娜的话，不是波迪小姐的解释。

师：故事讲完，德里问：“这算什么故事？”波迪小姐说是根据自己的一个梦编的。利昂马上问：既然是编的，那它就不是个真实的故事，对吧？萨哈拉没有说出口，可她心里是这样回答的——

（教师朗读，定位：第十一章“老师和苹果”·故事讲完）

> 不，它是真的。我想，只要我写下它，它就是真的，只要我希望它是真的，那它就是真的。

师：一个编出来的故事，萨哈拉为什么说“它是真的”？还记得第七章波迪小姐讲华盛顿和樱桃树时说的话吗？她说，真实的故事不一定只发生在看得见、摸得着的真实世界，有时还发生在想象的世界中；人们渴望一个诚实的榜样，就会编出这样一个故事，故事里仍然有真实的东西。“老师和苹果”也一样，虽然是编的，可故事里有一样真实的东西——像德里这样的孩子，需要有人每天给他一个苹果。萨哈拉自己就是写故事的人，所以她说，只要写下来、只要希望它是真的，它就是真的。这个想法，第十三章她还会再说一次——她开始写一位老师带学生们的“神奇的冒险之旅”时，说自己第一次明白了，故事不一定要完全真实。

### 三、鱼骨图·心墙是怎么倒下的（15 分钟）

师：上节课的时间轴，我们记下了一句话：每一次往前，旁边几乎都有一个读到她、相信她的人。第十二章，她走上讲台读了《我的名字》，心墙倒下了。这堵墙，是被谁、被什么推倒的？一个原因说不清，我们用鱼骨图把几股原因并排摆出来。

师：鱼骨图这样填：鱼头写要追究的结果；每根大刺写一股原因，写清楚是谁、做了什么；每根大刺后面跟着小刺，写书里的依据和章节。它的用处，是看清一件事往往是好几个原因合起来造成的。今天的鱼头已经写好了，大刺请你自己定，至少四根；其中至少一根，要写上节课时间轴里没写到的事——比如家里的人、班上别的同学。

师：老师也提一根候选的刺：“全班欢呼”。它能不能算推倒心墙的原因？先别急着答，回书上核一核：欢呼是发生在心墙倒下之前，还是和心墙倒下同时？

### 四、小结·带一个问题过一周（5 分钟）

师：这节课我们做了三件事：品了这本书怎样把看不见的心情写成看得见的身体和东西，又怎样把萨哈拉没说出口的话交给读者；细读了“老师和苹果”，分清了书里写明的和我们推断的；又用鱼骨图追究了心墙为什么会倒。

师：鱼骨图上，波迪小姐是很粗的一根刺。可她说过一句很特别的话——她讨厌所谓的档案，总是到了期末才看学生的档案。下周的思辨课，我们就讨论这个问题：如果你是一位新来的老师，开学前学校把全班同学的档案交给你，你会先读，还是像波迪小姐那样到期末才看？这一周请你想一想，也可以回书里翻一翻第一章、第九章、第十章和档案有关的地方，为你的选择找到依据。

本课完。

## 第4课时 · 思辨&应用课

### 本课三维教学目标

【知识技能】能说出全书中档案出现的几个关键地方（第一章塞进文件柜、第九章波迪小姐谈档案、第十二章拿回档案、第十三章最后一封信），能结合书中情节对“新老师该不该先读学生档案”提出自己的判断。

【过程方法】重点显性训练转化策略，兼用推断与比较：能在思辨讨论中从读过的章节找证据、亮出判断、讲清理由并说出自己的选择要付出的代价；能整合全书关于德里的细节，以萨哈拉的眼光写出“德里档案里没有的一页”，让新作品和原书接得上。

【情感价值】思考一份档案、一个外号、一句评价能不能说明一个人；愿意像波迪小姐那样“只看本人”，也愿意让别人看见自己心里那个“秘密的自己”。

### 一、深度阅读发现·“这些东西”是什么（10 分钟）

师：亲爱的同学们大家好。这本书第一章，萨哈拉写给爸爸的信被塞进了文件柜；第十二章，她拿回了档案；最后一章，她把信一封一封放出窗外，看着它们像小鸟一样飞远。然后，她在脑海中写下了给爸爸的最后一封信。我来读。

（教师朗读，定位：第十三章“我的自传”·放飞信件）

> 亲爱的爸爸：
>
> 我爱你。我想你。我希望有一天你会为此感到抱歉。要是你不会，那也没关系。我再也不会让这些东西进入我的档案了。
>
> 爱你的女儿以及秘密作家
>
> 永远的萨哈拉·琼斯

师：“我再也不会让这些东西进入我的档案了”——“这些东西”指的是什么？

学生互动分享

参考：①最直接的是这些写给爸爸的信——信被老师交上去，害她进了档案、接受特殊教育；②也可以指想爸爸的痛苦、潦草的日记，那些让档案“证明我是个大笨蛋”的东西；③还可以指她过去那种把自己藏起来的样子。教师复述学生的几种理解，追问：“她不再把这些交给档案，那她交给了谁？”引导学生说出：交给了天空、交给了自己写的书——她开始写“我的自传”。

师：导读课上大家画过一个三角问题：第十三章为什么叫“我的自传”？放飞了信以后，她拿出笔记本写啊写，写的是一位老师带着学生们的“神奇的冒险之旅”。后来她对妈妈说起这本书，是这样解释的：“我的自传。因为我的生活非常有趣。”写的是老师和同学，她为什么说这是她的自传？为什么这件事要放在全书最后一章？

学生互动分享

参考：①她写的老师和同学，就是她这一年的生活，写别人的故事，也是在写她自己；②第二章表妹瑞秋说“每天的生活根本不是有趣的故事”，第一章她给藏在图书馆的活页夹起名《我的痛苦人生和精彩历险》——到最后一章，她说自己的生活“非常有趣”，她看自己的眼光变了；③放在最后，是因为这正是全书走到的地方：一个在学校里“从来没写过什么”的孩子，终于开始写她自己的书了——刚才那封信的落款，她也写的是“爱你的女儿以及秘密作家”，她还是爸爸的女儿，可她有了另一个身份：作家。教师收口：从第一章的文件柜，到第十三章的这封信和这本“自传”，档案一直跟着她。今天这节课，我们就来讨论这份档案。

### 二、思辨讨论·新老师该不该先读学生档案（20 分钟）

师：上节课留的问题，大家想了一周：如果你是一位新来的老师，开学前学校把全班同学的档案交给你，你会先读，还是像波迪小姐那样到期末才看？先听听第九章，家访那天，波迪小姐是怎么跟萨哈拉的妈妈说的。

（教师朗读，定位：第九章“波迪小姐来家访”·厨房谈话）

> “没有。”波迪小姐说，“我讨厌所谓的档案。我总是到了期末才看学生的档案，很好笑吧。如果有人老是对你说长道短，评头论足，你就会明白。”

师：萨哈拉在床上装睡，她猜妈妈一定奇怪地看了老师一眼，因为老师停了一下，又接着解释。

（教师接着朗读，定位：第九章“波迪小姐来家访”·厨房谈话）

> “如果一个孩子不老实、反应慢、不读书，时间会告诉我的。我有眼睛，自己会看，不需要什么档案。”
>
> “不过看档案可能会省时间。”
>
> “要是档案都是错的，那并不能节约时间。”

师：老师说“要是档案都是错的”，妈妈说“看档案可能会省时间”。两个人说的都有道理吗？请大家先别急着站队，在这张阅读单上写下你的选择、书里的依据、你的理由，还有——这个选择可能要付出什么代价。

师：请“先读”这边的同学先说。你们的依据在哪一章？

学生互动分享

参考：学生可能说：老师需要知道孩子过去发生了什么，比如萨哈拉的爸爸离开了，德里家里的情况，提前知道就能说话小心一点，不会刺痛他；第九章萨哈拉的妈妈也说了，看档案能省时间。教师复述“先读”一方的理由：“你们说的是：知道得早，帮得早。”

师：请“不先读”这边的同学回应。你们怎么看“帮得早”这个理由？

学生互动分享

参考：学生可能说：档案上写的不一定是这个孩子需要的帮助，萨哈拉的档案让她去了大厅接受特殊教育，结果被同学叫“特别的萨哈拉”，这个“帮助”反而害了她；波迪小姐没看档案，照样知道萨哈拉能写作、德里需要一个苹果，靠的是自己去看。教师复述：“你们说的是：档案上的帮助，可能是贴上去的标签。”

师：（追问“不先读”一方）可是第十章，特教老师来带德里去“额外辅导”，问波迪小姐“您没看他的档案吗？”。如果一个孩子真的需要帮助，老师不看档案，会不会耽误他？

参考：这是“不先读”一方要付出的代价，学生可以承认：确实可能耽误；也可以回答：波迪小姐一直在看德里的日记、在日记上跟他笔谈，她用别的办法知道德里需要什么。教师不替学生下结论。

师：（追问“先读”一方）如果你先读了萨哈拉的档案，读到的是没完成的作业、潦草的日记，教导主任还说她“在这儿从来没写过什么”，她第一次交上来的日记只有“我是作家。”四个字，你还会批“我相信你！”吗？

参考：学生可能说：会，但需要提醒自己不要被档案带着走；也可能坦白：可能不会，会觉得她在乱写。教师收口时把两边的代价都摆出来：先读，怕的是先入为主；不先读，怕的是错过。有的同学还会想出第三种办法——先看本人，看一段时间，再翻档案对一对；或者只看档案里的事实，不看别人对孩子下的判断。这些办法都可以，关键是你能说清楚自己要防的是什么。

师：（总结）这本书里，档案一直是一样“说一个人是谁”的东西。第一章它说萨哈拉是个大笨蛋，第十二章它被送回到萨哈拉手里，第十三章她说再也不让“这些东西”进入她的档案。萨哈拉自己在《我的名字》里，说过一句跟别人给的名字有关的话。请大家翻到第十二章，找到她朗读的日记快结束的地方，开头是“名字是别人给我的”，一起读一遍。

（全班齐读，定位：第十二章“名字的由来”·《我的名字》）

> 名字是别人给我的，但同时也是我自己的选择。而这些选择，让我变得与众不同。

参考：教师提示：同一个外号“特别的萨哈拉”，第一章是同学取笑她，到第十二章，她说自己喜欢上了它。别人给的标签还在，可她选择了怎么看待它。

### 三、联系生活·一个“秘密的自己”（10 分钟）

师：第十一章，萨哈拉在教室门口对波迪小姐说：每个人心中都还有一个秘密的自己。波迪小姐说，这个“秘密的自己”是藏不住的，尤其当这个自己这么棒的时候。

师：请大家想一想：别人对你的某一个判断——一句评语、一个外号、一次分数、一句“你就是这样的人”——和你心里那个“秘密的自己”，有没有对不上的时候？当时你是怎么做的：照着别人说的那样去做了，还是没有？请写在本子上，三四句话就够。按书里的办法，写完以后可以在开头画一个“P”，表示这一段是秘密，老师不收、不念；愿意分享的同学，我们请你说一说。

学生自由分享

参考：学生可能说：①别人都说我“不爱说话”，其实我在家里很能讲，只是在不熟的人面前不说；②有人说我“数学不行”，可我喜欢搭模型，做得很仔细；③被叫过一个外号，后来自己也不在乎了，甚至觉得挺好——像萨哈拉对“特别的萨哈拉”那样。教师复述学生说的具体内容，不评高低；追问一句：“书里谁像你？是萨哈拉，是德里，还是别的人？”把学生的经历接回书里。教师提醒：愿意说多少就说多少，画了“P”的不必说。

### 四、阅读成果·德里档案里没有的一页（20 分钟）

师：最后，我们来写一页东西。德里·赛克斯一定也有一份档案，萨哈拉说过，他一年级踢伤过一位老师的小腿，三年级打到过另一位老师的鼻子——虽然她也说“谁知道是真是假”。这份档案里，可能写着“爱打人”“不守纪律”“需要特殊教育”。可是这一年，萨哈拉坐在他的教室里，看见了很多档案里不会写的事。

师：请你用萨哈拉的口吻，写一页“德里档案里没有的一页”。要求有三条：第一，至少写三件档案里不会记的事，每件都要写出在第几章，其中至少一件是我们课上没讲过的——比如第五章他被调到前面、第六章他踢讲台，也可以自己回书里另找一件；第二，每件事后面写一句你从中看出的德里；第三，最后一句，像波迪小姐那样，写下你“只看德里本人”看到的他。写在下面这张单子上。

师：请两三位同学读一读自己写的这一页。其他同学听的时候做一件事：听他写的每一件事，能不能在书里找到；他看出的德里，和这件事对得上吗？

学生互动分享

参考：教师逐一请听的同学点评，复述写作同学的具体事例：“他写到了第十二章‘你也不是’这一句，他从里面看出德里会安慰别人。”如果有同学写了书里没有的事，比如“德里后来和萨哈拉成了好朋友”“德里的爸爸也走了”，教师追问：“这一件在哪一章？”提醒大家：书里没写的不能当成德里的事，这一页里每一件都要是书里真有的。愿望日记里有几句是德里和波迪小姐在本子上笔谈，书里没标每一句是谁写的，引用时说“我推断是德里写的”。

师：（总结）萨哈拉在第十三章说，她第一次明白了，故事不一定要完全真实，它应该是所有她希望能够成真的、有趣的事情。可是今天我们写的这一页，每一件事都必须是书里真有的——因为我们写的是档案旁边的“另一页”，它要比档案更真。

师：这本书的中文版前言里，引了一位书评人的话——这是书外的文字，不是小说正文——“这本书写的不是什么奇人奇事，但是它本身却很神奇。”一个留级的女孩，一个爱惹事的男孩，一位不看档案的老师，一本日记本。读完这本书，你觉得它“神奇”在哪里？这个问题，请大家带回去，写在你的读书笔记上。

全课完。
