### 一、文本介绍

【内容简介】 萨哈拉·琼斯在芝加哥上学。她三年级那年，爸爸离开了家，谁也不知道他去了哪儿。她给爸爸写了很多信，藏在课桌里，有一天信散落出来，被老师交给了教导主任史丁先生，塞进了大文件柜里的档案。因为这些信，萨哈拉被安排在教学楼大厅里接受“特殊教育”，同学们偷偷叫她“特别的萨哈拉”。妈妈到学校要求停止特殊教育，并要求按普通标准让她留级。于是，萨哈拉开始了她的“第二个五年级”。其实萨哈拉一直在写——她把写好的东西从本子上撕下来，藏在公共图书馆 940 区书架底层的书后面，题目叫《我的痛苦人生和精彩历险》，只是在学校里，她一个字也不肯写。新学年，班上来了一位新老师波迪小姐：她不许以“不许”开头定规矩，给每人发一本日记本，还说自己讨厌档案、不到期末不看学生的档案。全书十三章，就写这一学年里，萨哈拉怎样从“写了就藏起来”，一步步走到“写了让人读到”。

【作者介绍】 爱斯米·科德尔，美国作家；本书由陈水平翻译。本课使用的版本为湖南少年儿童出版社·博集天卷 2019 年 5 月版，该版为流式电子书，无固定页码，全书定位一律按章节。本版未收录作者简介，作者生平【待补：作者介绍，以实际版本为准】。本版正文前有一篇中文版前言《秘密行程里的绿荫》，是书外的推荐文字，课上提到时须说明它不是小说正文。

### 二、教学目标（书级·三维）

【知识技能】知道全书共十三章、以第一人称“我”（萨哈拉）讲述“第二个五年级”这一学年的事，能按“处境与起点（第一至四章）/ 新老师与冲突（第五至十章）/ 转折与收束（第十一至十三章）”把全书分成三段；能说出萨哈拉、妈妈、瑞秋、巴黎、德里、波迪小姐等主要人物的身份与彼此关系；能沿着“写”与“说出来”这条线，说出萨哈拉在全书九个节点上的状态变化。

【过程方法】综合运用预测、联结、推断、比较、整合、监控、转化七项阅读策略；能借助时间轴把散落在十三章里的“写”与“说”整合成一条有进有退的线，借助人物关系图辨别身边的人哪些“推”是真在推她、哪些是她自己往回缩，借助鱼骨图把“她终于走上讲台”这个结果追溯到多股原因上；能在讨论中把每一个判断回扣到具体章节的原文，而不是只凭印象。

【情感价值】体会一个被档案、外号和留级“定了性”的孩子，怎样在被看见、被相信之后重新开口；思考别人贴给我们的标签与我们自己是谁之间的关系；在“好意为什么会伤人”的讨论里，体会“推己及人”之前还要先“看”、先“听”。

### 三、教学流程

## 第1课时 · 导读课

### 本课三维教学目标

【知识技能】知道《特别的女生萨哈拉》的作者、译者、版本与体例——全书十三章、各章有章名、无页码、按章节定位；知道故事是萨哈拉用第一人称讲的，讲的是她留级后的“第二个五年级”；听读第一章、第二章、第五章的三段原文，知道萨哈拉在学校档案里的样子与她自己心里的样子并不一致。

【过程方法】重点显性训练推断与预测两个策略：能从萨哈拉的一段自述里推断出书中没有明说的原因，并说出自己凭的是哪一句；能依据今天读到的三个地方写下有依据的预测，留到下节课验证。同时学会用“卡住记录”监控自己的阅读。

【情感价值】对“学校档案里那个从不写字的孩子，其实一直在写”这一反差产生好奇，愿意用一周时间读完全书。

### 一、课程导入·一张写着“从来没写过什么”的档案卡（15 分钟）

师：亲爱的同学们大家好。今天上课，请大家先看屏幕上的一张卡片。这是一个五年级学生的情况登记——我要先说明，这张卡不是书里原样印着的，是老师照着书的第一章写到的事，一条一条整理出来的。请大家安安静静地把它从上往下读一遍。

（屏幕出示）

| 学生情况 |  |
| --- | --- |
| 姓名 | 萨哈拉·琼斯 |
| 去年 | 在教学楼大厅里接受“特殊教育” |
| 同学给她的外号 | “特别的萨哈拉” |
| 档案里装着 | 没完成的作业；爸爸离开后写得凌乱、潦草的日记；一沓写给爸爸的信 |
| 教导主任的说法 | 她在这儿从来没写过什么 |
| 今年 | 留级，重读五年级 |

师：读完了吗？现在请你只凭这张卡回答我：这是一个什么样的孩子？她喜欢上学吗？她会写作文吗？说的时候请指着卡上的某一行，告诉大家你是从哪一行看出来的。

学生互动分享

参考：学生凭卡片作判断，答案会比较一致地偏向负面——①从“没完成的作业”“留级”看出她学习不好、不认真；②从“在教学楼大厅里接受‘特殊教育’”看出她可能跟不上，或者有什么问题；③从“从来没写过什么”看出她不爱写、也不会写作文；④从外号看出同学们看不起她。也可能有同学说“写给爸爸的信”说明她心里有很多话，这一条要特别接住。教师此时不评对错，只把大家指着的那几行复述一遍：“有的同学指着‘留级’，有的同学指着‘从来没写过什么’，还有同学注意到了‘写给爸爸的信’。”

师：好，大家的判断我先记在心里。下面我要告诉大家卡片上没有写的一件事。（稍停顿）有一座公共图书馆，图书馆里有一个 940 区，940 区的书架最底下一层，一排书的后面，藏着一个活页夹。活页夹里夹着一页一页从本子上撕下来的纸，题目叫《我的痛苦人生和精彩历险》。

师：写这些字的人，就是卡片上这个萨哈拉。

师：那么问题来了：教导主任说她“在这儿从来没写过什么”。他说错了吗？

学生互动分享

参考：这一问会分出两种说法。①说错了——她明明一直在写，还写了一本书那么多；②也有同学会抓住“在这儿”三个字，说教导主任没说错，她确实没在学校写，她是写完了拿到图书馆藏起来的。教师要把第二种说法郑重接住：“这位同学抓住了‘在这儿’三个字。也就是说，档案上记的可能每一条都是真的，可它仍然没说出这个孩子真正是什么样。”

师：这正是萨哈拉自己在第一章里说的话。请大家把书翻到第一章《我和德里》，找到史丁先生拿出档案的那一段，我来读开头几句，大家跟着看。

（教师朗读，定位：第一章《我和德里》）

> 史丁先生拿出了一大沓纸，那是我的档案，我全部的故事。不，不是全部！它们只是一部分。这部分故事不包括我和妈妈去书店的事情。

师：她说，她常和妈妈逛书店，还去图书馆挑书，让妈妈给她朗读。可这些事，档案里都没有记。请大家往下找一找：哪一句说出了妈妈在她心里是什么样的人？画出来。

（学生在书上找句、画线）

学生互动分享

参考：“妈妈一直都是我最好的老师。”

师：“不，不是全部！”——请大家把这五个字圈出来。刚才大家凭一张卡片下了判断，萨哈拉在书里替自己喊了一句：那只是一部分。这本书讲的，就是档案里没有记下来的那一部分。它叫《特别的女生萨哈拉》，书名里的“特别”两个字，正是卡片上那个外号里的两个字。至于这两个字到最后是什么意思，要等你们自己读到第十二章才知道。

### 二、精彩片段共读·“我是作家。”（20 分钟）

师：一个在学校里一个字都不肯写的孩子，心里到底想不想写？我们看第二章《真正的梦想》。暑假里，萨哈拉和表妹瑞秋在厨房里玩“占卜”——把一只金鱼缸倒扣过来，当作水晶球，看看自己的将来。萨哈拉说，她在鱼缸上看到了自己的影子，还看到了自己内心深处的渴望。这一段里有两个人说话，我请两位同学分角色读：一位读萨哈拉的话和叙述，一位读瑞秋的话。请扮演萨哈拉的同学先读她开口这一句。

（萨哈拉的扮演者朗读，定位：第二章《真正的梦想》）

> “告诉你吧，我看到了！”我对瑞秋说，“我要成为一名作家。”但后面这句话是自己从我嘴里冒出来的。

师：瑞秋吸了一口气，摇了摇头，追问她说的作家是不是写书的，是不是写图书馆里摆的那种书。萨哈拉心里却觉得，自己的书要是能摆进图书馆，那挺好。下面请两位同学接着读，从瑞秋问“那你会写什么？”那一句开始。

（两位同学分角色接着读，定位：第二章《真正的梦想》）

> “那你会写什么？”
>
> “就……写东西呗。”
>
> “什么东西？”
>
> 什么东西？“每天的生活啊，有趣的故事啊。”
>
> 她看着我，好像我是个作业本似的。“每天的生活根本不是有趣的故事。”她反驳道。

师：萨哈拉不服气，顶了一句：你又没写过，怎么知道？瑞秋说，她没写过，就是因为太难了，除非有人逼她，不然她才不写呢，她没兴趣。听听萨哈拉怎么回她。

（萨哈拉的扮演者续读，定位：第二章《真正的梦想》）

> “我不用逼也会写的，我有兴趣！”我大声宣告，“等着瞧吧，我会成为有史以来最年轻的作家，我的书会收藏在图书馆里！”

师：谢谢两位同学。刚才萨哈拉开口那一句后面，叙述里紧跟着说：“但后面这句话是自己从我嘴里冒出来的。”“我要成为一名作家”，是她自己都没打算说、却冒出来的。她开口之前，叙述里还有一个词，透露她本来并不想说。请在书上找出来，画上。

（学生在书上找句、画线）

学生互动分享

参考：“妥协”——“最终我还是妥协了”，她是拗不过才开口的。

师：瑞秋回她的话里，有一句最泄气：“每天的生活根本不是有趣的故事”；她后来还洗着牌说了一句，“写书真的太难了”。再看被追问时那句“就……写东西呗”里的省略号：她其实没想好，也不踏实；可最后那句“等着瞧吧”，她是大声喊出来的。一个心里不踏实的人，偏偏喊得最响。

师：暑假在厨房里，对着表妹，她敢说“我要成为一名作家”。那么到了学校里呢？我们跳到第五章《新老师来了》。新学年，班上来了一位新老师，学生们叫她波迪小姐。波迪小姐给每人发了一本日记本，让大家写日记。这是萨哈拉第一次在这个本子上写日记，她拼命想自己该写些什么。请大家先在书上找到这一段。这一段里，她想说的话很多：想说自己老是犹豫退缩，想说对不起妈妈，可她意识到这些话“应该直接和妈妈说，而不是和老师说”；又想说自己很会观察、很会倾听，可这又怎样呢？后面几句，我来读。

（教师朗读，定位：第五章《新老师来了》）

> 学校根本不在乎我这些长处，不是吗？我擅长的这些东西，学校从来不会记在档案里，不是吗？所以它们只不过是我一个人的秘密罢了，我把这些秘密都藏在心底的一个大箱子里边。我把秘密锁在了那里，可我现在找不着钥匙了，我想要写的时候却找不到钥匙打开那个箱子了。

师：读到这儿我先停一下。她想写的东西一大堆——犹豫退缩、对不起妈妈、自己很会观察很会倾听……可是一直到下课铃响，她一个字都没来得及写，日记本上一片空白。书里没有直接说“她为什么写不出来”，但这一段里藏着线索。请你推断一下：她为什么写不出来？一定要说出你凭的是哪一句。

学生互动分享

参考：这是本课第一次显性训练推断——凭线索，不凭感觉。可以推出的有：①她觉得写了也没用，“学校根本不在乎我这些长处”“学校从来不会记在档案里”；②她把这些东西当成了只属于自己的秘密，“藏在心底的一个大箱子里边”，锁久了，“找不着钥匙了”；③她怕写给老师看，因为有些话“应该直接和妈妈说，而不是和老师说”。如果有同学联系到导入时那张卡片和第一章的档案，说她怕写下来的东西又被收进档案，这是很好的推断，但要追问一句：“这一段里有哪个词能支撑你？”——答案是“档案”。教师收口：一个“钥匙”、一个“箱子”，是萨哈拉自己打的比方，我们先记住它。

师：铃声响了。波迪小姐让大家把日记本传上去。萨哈拉一慌，只好提笔写下一句：“我是作家。”本子交上去，混进一堆日记本里，她就认不出哪本是自己的了。接着听——

（教师续读，定位：第五章《新老师来了》）

> 一想到波迪小姐会看到我写的东西，我的脸就像煮熟的大虾一样又红又烫。感觉自己像个傻瓜，我怎么会这么写呀？
>
> 不管怎么说，她是老师，还是会看我的日记，还会给我写评语：
>
> 我是作家。
>
> 我相信你！

师：（稍停顿）一节课憋出来四个字，“我是作家。”老师回了四个字，“我相信你！”请大家把这两行并排圈起来。我只问一个问题：这四个字的批语，和那张档案卡上“从来没写过什么”放在一起，你觉得这位新老师是怎样看人的？

学生互动分享

参考：①她不看过去，只看眼前这个孩子写下的这句话；②她没有因为只写了一句就批评，反而接住了这一句；③她把一个学生随手写的一句话当真了。教师不必把话说满，点到即可：一个看档案，一个看这四个字——这两种看人的方法，会在这本书里一直较劲。

### 三、预测阅读单·她会让别人读到她写的东西吗（15 分钟）

师：今天我们读了三个地方：第一章档案柜前的“不，不是全部”，第二章金鱼缸前的“我要成为一名作家”，第五章日记本上的“我是作家”“我相信你”。现在请大家做今天的预测。预测阅读单上有三个问题，每个问题写下你的预测，还要写下依据——依据只能从今天读过的这三个地方和那张卡片里找，不能凭“我猜它是个好结局”。

（学生填写预测阅读单）

| 我要预测的问题 | 我的预测 | 我的依据（今天读到的哪一句） | 读完全书后是否被证实 |
| --- | --- | --- | --- |
| ① 萨哈拉藏在图书馆的东西，最后会不会被别人读到？ |  |  |  |
| ② 学校里那份档案，最后会怎么样？ |  |  |  |
| ③ 写了“我相信你！”的波迪小姐，会成为萨哈拉身边怎样的人？ |  |  |  |

学生互动分享

参考：预测不分对错，看依据。①第一题，倾向“会被读到”的依据可能是：她在金鱼缸前大声宣告“我的书会收藏在图书馆里”；她已经在日记本上写下了“我是作家。”倾向“不会”的依据可能是：她把秘密“锁在了那里”“找不着钥匙了”；她写完一句就觉得“像个傻瓜”。②第二题，可能有人预测档案会被拿回来、会被烧掉、会被改写，也可能有人说档案什么都不会变、变的是她自己；依据多来自第一章那句“不，不是全部”。③第三题，可能有人说老师会一直相信她，也可能有人说老师会很严格、逼着她写；依据都在那四个字的批语里。教师收口时追问：“你是根据哪条线索猜的？”并说明这张单子请收好，第2课时一开头就拿出来一条一条验证。

### 四、认识这本书·读法与七天阅读计划（10 分钟）

师：读之前，先把这本书看清楚。全书十三章，每一章都有章名。请大家现在翻到目录，用一分钟把十三个章名默读一遍。

（学生默读目录）

## 第2课时 · 阅读交流课 1

### 本课三维教学目标

【知识技能】能按“处境与起点 / 新老师与冲突 / 转折与收束”把十三章分成三段；能在时间轴上标出萨哈拉“写”与“说出来”的九个节点，说出每个节点她写了什么、说了什么、被谁读到或听到；能说出萨哈拉身边六个主要人物与她的关系。

【过程方法】重点显性训练整合策略：把分散在十三章里的“写”与“说”合成一条有进有退的线，并说出这条线是从哪几个节点合出来的；借助人物关系图，为波迪小姐和自己挑的另外两个人各找出一件“把她往回推”的事，再判断这一推是对方真在推、还是她自己往回缩，并各找一处原文依据；回收导读课的预测阅读单，验证自己的预测。

【情感价值】看见萨哈拉的变化不是一条直线往上，而是进进退退的；体会身边的人很少只是“好人”或“坏人”，看起来在推她的人，未必真在推她。

### 二、时间轴·萨哈拉的九次“写”与“说”（25 分钟）

师：读完一本十三章的书，最容易的是记住几件大事，最难的是说清一个人是怎么一点一点变的。上节课我们说，这本书写的是档案里没有记下的那一部分——那一部分里最要紧的，就是萨哈拉的“写”和“说”。今天我们用一条时间轴，把她从第一章到第十三章的“写”与“说”排成一条线。

师：先给大家一个大框架。这十三章可以分成三段：第一章到第四章，是她的处境和起点；第五章到第十章，新老师来了，冲突也一件接一件；第十一章到第十三章，是转折和收束。请在书的目录页上，用横线把三段分开。

参考：①妈妈：可能判“真在推”——那几句话说得很重，“你读那么多书有什么用？还不是留级？！”萨哈拉当晚就跑出了家门。教师追问：“妈妈回过头去接着削土豆那一句，你再读一遍。”引导学生读到：她削土豆皮，“就好像要把我粗糙的表皮全部削掉，直到发现藏在里面的那个令她为之骄傲的好女儿”；同一个晚上，妈妈又追到门廊下，从身后抱住了她——话是推出去的，心却在把她往外拉。②瑞秋那句“写书真的太难了”，是瑞秋真心觉得难，未必是故意打击她。③巴黎那句话是萨哈拉偷贴纸在先，第三章巴黎主动打招呼、萨哈拉撒谎说没看见她——这一行“往回推”的，很大一部分是萨哈拉自己。④德里的大怒，是因为那首诗让他读到了“孤儿”两个字，萨哈拉本来是一片好意。教师收口：把这几行和老师填好的史丁先生那一行放在一起看——瑞秋、巴黎这两下“推”，很大一部分是萨哈拉自己在往回缩；德里那一下，来自一场误会；从第一章起一直把她往回推的，是史丁先生那个大文件柜和档案。

师：最后说波迪小姐。“作家需要写作。”这句批语，你判的是“真在推”，还是“她自己往回缩”，还是觉得它根本不算推？不同判断的同学各说一说。

学生互动分享

参考：两种归法都有依据。①算往回推——萨哈拉当时读着就是质问，觉得老师在说“看来你什么也不是嘛”；②不算推，反倒是在拉——萨哈拉自己接着想“也许她不是那个意思，也许她只是实事求是”，而且紧接着第九章，她就病中起身开始写了。教师不急着裁决：这句批语到底是推还是拉，我们下一节专门追“谁把她往外拉”的时候再回来判断。

### 四、小结·带着问题进下一节（5 分钟）

师：（总结）今天我们用一条时间轴、一张人物关系图，把萨哈拉的这一年理了一遍：她的“写”和“说”不是一路往上，第八章退过一步；她身边的人，很多“推”其实是她自己在往回缩，一直在推她的，是那个文件柜。

师：请大家把上周的“卡住记录”拿出来，看看还有哪一条没解开，在旁边画一个圈。我们紧接着的下一节课，要细读那个文件柜，还要把“她为什么终于走上了讲台”这件事彻底追一遍。带着你画了圈的那一条进来。

本课完。

## 第3课时 · 阅读交流课 2

### 本课三维教学目标

【知识技能】能从“档案”在全书的多次出现中，找出第一、九、十二、十三章这四处，说出每一处档案由谁掌握、里面装着什么；能说出导致萨哈拉在第十二章走上讲台的多股原因；能从留级与特殊教育、家里的情况、对“孤儿”二字的反应等维度比较萨哈拉与德里。

【过程方法】重点显性训练推断与比较两个策略：读“档案”反复出现的几处原文，推断作者为什么让它一再出现，并说出凭的是哪一句；借助鱼骨图把一个结果追溯到老师、同学和朋友、家里、她自己四股原因上；借助对照阅读单比较萨哈拉与德里，并说出这些异同让自己对“而且，你也不是”这句话有了什么新的理解。

【情感价值】体会一个人走出来，从来不是一个人拉了一把就够的；体会两个处境相像的孩子，怎样在对方身上看见自己。

### 一、细读推断·档案柜关上的那一声（15 分钟）

师：上节课结束时，请大家在卡住记录上圈出一条还没解开的。如果你圈的那一条和“档案”有关——比如“波迪小姐为什么开学时不看档案”“为什么档案和仙人掌放在一起”——这节课先解你的。我们就从档案读起。请翻到第一章，史丁先生拿出档案之后，萨哈拉又看了一眼档案里装的东西。这一段请一位同学读。

（邀请一位平时朗读功底不错的同学朗读，定位：第一章《我和德里》）

> 看到那份档案，妈妈的脸色又一次变得非常难看，我又开始吓得全身发软。看看档案里都有些什么：我的那些乱七八糟、没有完成的作业，还有爸爸离开后我写得凌乱而潦草的日记。唉，我怎么就没有在三年级的时候学会好好写字？我怎么就没有在四年级的时候认认真真完成作业呢？史丁先生把我的信也塞进了那个大文件柜里。柜门被“噔”的一声关上，好像朝我发出一声刺耳的嘲笑。

师：“噔”的一声。柜门关上，她听成了嘲笑。紧接着她还说，那个柜子专门收着她做得不好的地方，随时准备打开来“证明我是个大笨蛋”。请大家再细看一句：档案里有“爸爸离开后我写得凌乱而潦草的日记”。爸爸离开、日记潦草、作业没完成——这几样放在一起，书里没有直接说它们之间是什么关系，可是线索就摆在那儿。请注意两个时间：“三年级的时候”“四年级的时候”——她三年级时爸爸走了，这正好是爸爸离开的那一年和第二年。档案记下了“表现不好”，却没有记下“为什么”；也没有记下她和妈妈逛书店、读书那些事。

师：这个柜子后来还出现了好几次。第九章，波迪小姐到萨哈拉家家访，萨哈拉病着、躺在床上装睡，偷听到了妈妈和老师在厨房里的一段话。波迪小姐说她讨厌档案，一般到期末才翻；一个孩子什么样，她宁可自己慢慢看。接下来，厨房里有人接了一句，我们接着往下听。

（教师朗读，定位：第九章《波迪小姐来家访》）

> “不过看档案可能会省时间。”
>
> “要是档案都是错的，那并不能节约时间。”
>
> 水壶鸣笛了。“您是说您没有看过萨哈拉的档案？”妈妈问。
>
> “没有，我只看萨哈拉本人。”

师：“我只看萨哈拉本人。”第一课时那张档案卡，是谁在看？现在这位老师说，她不看那张卡，她看人。我们再往后跳，第十二章，萨哈拉当了“小信使”，按着字条找到了一个旧储存柜。

（教师朗读，定位：第十二章《名字的由来》）

> 柜子里有一盆小小的仙人掌，仙人掌上绽放着一朵漂亮的小红花。
>
> 在它后面，有一个棕色的文件夹，上面写着我的名字。
>
> 那是我的档案。

师：第一章是“噔”一声关上的大文件柜，第十二章是一个旧储存柜，档案前面摆着一盆开了花的仙人掌。同一份档案，作者让它出现在了两个很不一样的柜子里。你推断一下，作者为什么要这样安排？书里没有解释仙人掌是什么意思，所以请你说出自己凭的是哪些线索。

学生互动分享

参考：这一问没有标准答案，看推断有没有线索撑着。①第一章柜子是教导主任关上的，第十二章柜子是老师让萨哈拉自己去打开的——档案从别人手里，回到了她自己手里；②第一章的柜子“证明我是个大笨蛋”，第十二章档案前面放的是一朵开着的花——仙人掌长在干旱的地方，带刺，还能开花；有同学可能联想到第十二章她的《我的名字》里写的撒哈拉沙漠，这个联想可以接住，但要提醒：这是我们的推断，书里没有这样说。教师收口时念第十三章最后那封信里的一句——“我再也不会让这些东西进入我的档案了。”——档案在全书出现了这么多次，最后一次，是萨哈拉自己给它下了结论。

### 二、鱼骨图·是什么让她走上了讲台（25 分钟）

师：时间轴上，第十二章是她往前最大的一步：她自己说，“我几乎有一年没再站起来发过言了”，可这一次，她在老师的坚持下走上讲台，把《我的名字》读给了全班听。这一大步不是一下子跨出来的。上一节我们只看了谁在“推”她，这一节专门追是谁、是什么把她“拉”了出来。我们用鱼骨图把它的原因追一遍。

师：鱼骨图这样填：鱼头写要追究的结果——“第十二章，萨哈拉走上讲台朗读《我的名字》”；四根大刺各写一股原因：老师、同学和朋友、家里、她自己；每根大刺下面，写书里的事，带章号。它的用处，是看清一件事往往由好几股原因合起来造成。请大家先独立填，每根大刺至少一件，找不到的那根先空着。

### 四、小结·布置思辨准备（5 分钟）

师：（总结）这节课我们读了档案在书里的四处出现：它从一个“噔”地关上的大柜子，走到了一盆开花的仙人掌后面，最后被萨哈拉自己下了结论；我们用鱼骨图看清了，她走上讲台，是老师、朋友、家里和她自己几股力量合起来的；我们还把她和德里放在一起比了一次。

师：上节课末，大家在卡住记录上圈过一条没解开的。请一两位同学说说：你圈的那一条，今天解开了没有？是在哪个环节解开的？还没解开的，就留在单子上。

学生互动分享

参考：学生可能说，“波迪小姐为什么开学时不看档案”在第九章家访那段里解开了；“为什么第八章她不写了”在上一节时间轴的整合里解开了；也可能有人说还没解开，比如“图书馆那个活页夹后来怎么样了”——这一条书里本来就没有写，教师如实说明：卡住的地方，有时候不是没读懂，而是书故意留了白。

师：下周第 4 课时之前，请大家带着一个问题回去想——不用再读，想就行，想好了在本子上写几句：萨哈拉接过了别人给她的外号“特别的萨哈拉”，德里把他以为有人扣在他头上的“孤儿”还了回去。别人给的名字，什么时候该接过来，什么时候该还回去？想的时候，请你在书里找好依据，写上章号。

本课完。

## 第4课时 · 思辨&应用课

### 本课三维教学目标

【知识技能】能用书中原文说明萨哈拉怎样接过“特别的萨哈拉”这个外号、德里怎样把“孤儿”二字还回去；能说出“一定要看 / 一定要听 / 一定要推己及人”三条规矩，并用第十章“诗放在椅子上”一事解释三条规矩的先后。

【过程方法】重点显性训练转化与联结两个策略：在“别人给的名字，什么时候该接过来，什么时候该还回去”的讨论中，就具体情形亮出判断、举出依据，并说出自己判断的条件；把“好意为什么会伤人”联结到自己生活里一件具体的事；学波迪小姐写批语，为同桌的“档案里没有的我”写一句具体的批语，并说出它和原书怎样接上。

【情感价值】思考别人贴的标签和“我是谁”之间的关系；体会推己及人之前，还要先看、先听；愿意让一个人读到自己档案里没有的那一面。

### 一、深度阅读发现·再看一眼那张档案卡（10 分钟）

师：亲爱的同学们大家好。今天是这本书的最后一节课。请大家看屏幕——还是第 1 课时那张档案卡，一字没改。

（屏幕再次出示第 1 课时的档案卡）

师：两周前，大家凭这张卡判断过萨哈拉是个什么样的孩子。现在你们读完了整本书。请你再看一遍这张卡，然后告诉我：如果让你在这张卡上只加一行，你加什么？

学生互动分享

参考：学生可能加：“我很会观察，很会倾听，很会思考”（第五章原文）；“她在图书馆藏了一部作品”（第一、二章）；“她写的《我的名字》全班都欢呼了”（第十二章）；“她自己选择了‘特别的萨哈拉’这个名字”（第十二章）。教师逐条复述，再追问一句：“你加的这一行，学校的档案会记吗？”学生会说不会——这正是第五章萨哈拉说的，“我擅长的这些东西，学校从来不会记在档案里”。

师：第一章里，萨哈拉的妈妈教过她一句话，她记在了书里：“看书时不要从封面来判断一本书的好坏，看人时不要以貌取人。”到了第十二章，萨哈拉读完《我的名字》，班上同学七嘴八舌地说感想，其中一句“不要以貌取人”，是德里说的。第一章妈妈教给萨哈拉的话，第十二章从德里嘴里说了出来。两周前我们凭一张卡片看人，正是“以貌取人”。今天这节课，我们就来想想“别人给的名字”这件事。

### 二、思辨讨论·别人给的名字，什么时候接、什么时候还（25 分钟）

师：上周请大家回去想的问题，现在拿出来。萨哈拉和德里，都被别人起过名字。萨哈拉被同学偷偷叫作“特别的萨哈拉”；德里在椅子上读到一首诗，觉得有人在说他是“孤儿”。两个人的做法正好相反。我先请大家把两个人的原文各听一遍。萨哈拉这一段在第十二章，是她当众朗读的《我的名字》的结尾。

（教师朗读，定位：第十二章《名字的由来》·萨哈拉朗读的日记）

> 但是事实是爸爸一走，我的名字就变了。不是我改的，也不是妈妈改的。去年，我接受特殊教育的时候，有一些同学开始管我叫“特别的萨哈拉”。我知道他们是在取笑我，但我现在喜欢上了它。名字是别人给我的，但同时也是我自己的选择。而这些选择，让我变得与众不同。

（教师朗读，定位：第十章《孤儿》）

> 他骂了一句脏话，这话原谅我不能在这里写出来。全班都听见了，都看着他。他咆哮道：“这是谁放的？！”声音大得像一只愤怒的怪兽。我恨不得把自己藏进课桌里，可我知道不可能塞得进去。“我不是孤儿！”他声嘶力竭地喊，“谁说我是孤儿的！”

师：先说清两件不一样的事：萨哈拉的外号，是去年同学们真真切切叫过她的；德里的“孤儿”，书里没有一个人这样叫过他，是他从一首没署名的诗里读出来的。所以今天的问题不是“谁对谁错”，而是：别人给的名字，什么时候该接过来，什么时候该还回去？

师：思辨阅读单上有四种情形，前三种取自书里，最后一种请你自己填。每一行写下你的判断——接过来还是还回去——再写依据和理由。给大家六分钟。

（学生填写思辨阅读单）

| 情形 | 接过来，还是还回去？ | 书中依据（章） | 我的理由 |
| --- | --- | --- | --- |
| ① 第一章，同学去洗手间经过大厅时冲萨哈拉发出“嘘嘘”声，偷偷叫她“特别的萨哈拉” |  |  |  |
| ② 第十二章，萨哈拉读完《我的名字》，同学说“我就叫你特别的萨哈拉吧！” |  |  |  |
| ③ 第十章，德里从诗里读出“孤儿”两个字 |  |  |  |
| ④ 我自己（或身边的人）被别人叫过的一个名字 |  |  |  |

师：先请三位同学，各说①②③里的一行。说完之后，请大家想一想：你在哪一行判了“接过来”，在哪一行判了“还回去”——让你改主意的，是什么条件？

学生互动分享

参考：
- 情形①：可能判“还回去”或“接不住”——那是嘲笑，第一章萨哈拉说这个“特别”，“可不是像王子或公主或电影明星那种光彩照人的特别”；也会有同学说，她那时只能假装没听到。
- 情形②：可能判“接过来”——同一个外号，第十二章由同学（玛丽亚）说出来，已经成了夸奖；萨哈拉自己也说“名字是别人给我的，但同时也是我自己的选择”。
- 情形③：可能判“还回去”——德里有妈妈，“孤儿”说的就不是事实；第十一章他的愿望日记里有一句“你不是孤儿，你有妈妈”（依内容推断应是老师写的）；而且他还回去之后，还替萨哈拉也还了一次，“而且，你也不是”。
- 说到“条件”，学生可能归纳出：①这个名字说的是不是事实——说错了的，就该还回去；②说的人是嘲笑还是欣赏；③被叫的人自己有没有底气——有底气，才能把一个嘲笑的名字接过来、改成自己的意思。教师把学生说出的条件逐条复述，不急着排序。

师：（追问）情形①和情形②是同一个外号，萨哈拉的态度却正好相反。第一章她刚被这样叫的时候，书里写得很疼：“不仅仅是耳朵听到了，我的双颊也听到了”……“嘲讽的声音穿过我的衣服，撕裂了我的皮肤”。到了第十二章，她说“我现在喜欢上了它”。我们把问题往深推一步：萨哈拉接过这个名字，是在什么条件下接过来的？如果第一章就让她“接过来”，她接得住吗？

学生互动分享

参考：接不住。她是在天天写日记、被老师相信、被瑞秋读过之后，才在后来当众朗读的《我的名字》里把这个名字接过来的；“接过来”需要一个人先知道自己是谁。也有同学会说，德里面对的是一个本来就说错了的名字，还回去本来就对——这和有没有底气是两回事。教师不替学生下结论，只把两边说出的条件复述清楚：接过来，要先有底气；还回去，要分清这个名字说的是真是假。

师：最后回到你自己填的第④行。请一两位同学，用刚才大家归纳出的条件，再判一次你自己那个名字：该接过来，还是该还回去？你凭的是哪一条？不想说的，可以只在心里判。

学生互动分享

参考：学生可能说到自己的小名、绰号、因为某件事被起的外号。教师只追问一句：“你用的是哪一条条件？”——是“说的是不是事实”，还是“说的人是嘲笑还是欣赏”，还是“我自己有没有底气”。不评判学生的选择，至于你自己遇到时怎么选，答案在你自己手里。

### 三、联系生活·一份没署名的好意（10 分钟）

师：德里那么生气，起因是一首诗。可萨哈拉放那首诗，是一片好意。第十章她写过自己读这首诗的感受：

（教师朗读，定位：第十章《孤儿》）

> 当我在厨房里独自打开玉米罐头，经过厨房里那堆摞得老高的脏盘子的时候，我就想象自己好像从树后面走了出来，站到了一切美好事物的中心。虽然这一切都是想象，可弗兰克·奥哈拉告诉我这可以是真的。我只需要从树后面走出来，就能来到心中向往的“别处”。

师：大家还记得波迪小姐第一天定的三条规矩吗？“一定要看，一定要听，一定要推己及人。”什么叫推己及人，书里有一句解释：“你希望别人怎样对待你，你就怎样对待别人。”萨哈拉把自己最喜欢、最能安慰自己的诗送给德里——她是不是正好做到了推己及人？那为什么德里那么生气？

学生互动分享

参考：①她是按“推己及人”做的——这首诗安慰过她，她以为也能安慰德里；②可是德里不是她，同一首诗，她读到的是“从树后面走出来”，德里读到的是“孤儿”两个字；③她没有署名，德里不知道是谁、是什么意思，只能往坏里想。教师追问：“三条规矩是按什么顺序排的？”引导学生注意：推己及人排在第三条，前面两条是“一定要看”“一定要听”——先看清楚、听清楚对方是谁、心里疼在哪儿，推己及人才不会推错。

师：现在请大家想一件你自己的事：你有没有把自己觉得很好的东西——一句话、一个礼物、一个主意——送给别人，对方却不高兴，或者根本不领情？当时你漏掉的，是“看”，还是“听”？说一件具体的事。我们请两位同学说。

学生互动分享

参考：学生的例子会很具体，比如：把自己最爱看的书借给同学，同学根本不爱看那一类；想安慰考砸的朋友，说“没关系，下次就好了”，朋友反而更难受；给家里人买了自己喜欢的零食，家里人不爱吃。教师听完一个，就追问一句“你漏掉的是看还是听”，并把它连回书里：按这个读法，萨哈拉漏掉的是“听”——她不知道“孤儿”两个字在德里心里有多疼。

### 四、阅读成果·档案里没有的一页（15 分钟）

师：最后一件事，我们来做一页“档案”。不是学校里那种档案，是萨哈拉在第五章说的那种——“我擅长的这些东西，学校从来不会记在档案里”。请你在卡片上写下你自己擅长、但学校的档案一定不会记的一件事，再写一个能证明它的具体时刻。五六句话就够，给大家五分钟。

| 档案里没有的我 |  |
| --- | --- |
| 我擅长的一件事（学校的档案不会记） |  |
| 能证明它的一个具体时刻 |  |
| 同桌写的批语（学波迪小姐：一句话，要具体） |  |

师：写之前说清两条规矩。第一，这本书里有一个“P”的记号——日记前面画了带斜线的圆圈“P”，就表示这是秘密。今天也一样：你写完如果不想给别人看，就在卡片右上角画一个“P”，这张卡你自己收着，谁也不许看。第二，没画“P”的，写完和同桌交换，请同桌在最后一行写一句批语。

（学生写作，约 5 分钟）

师：交换之前，我们先想一想波迪小姐的批语是什么样的。她给萨哈拉写过“我相信你！”，写过“作家需要写作。”——都很短。我们读到的这两句，没有一句是“写得真好”“继续努力”这种放在谁的本子上都行的话。请你给同桌的批语，要短，要只属于这一张卡。比如，同桌写自己能听出楼下每一辆车的声音，“写得真好”就是一句谁都能用的话；“你这是第二条规矩‘一定要听’”，就是只属于他的。

（同桌交换，写批语，约 3 分钟）

学生互动分享

参考：请两位同学读一读同桌给自己写的批语，说说读到它时是什么感觉；再请写批语的同学说说，你是从卡片的哪一句里找到这句批语的。教师追问写批语的同学：“你这句批语，和书里哪一处接得上？”学生可能说接上了波迪小姐“我只看萨哈拉本人”，接上了第一课时那张只看结果的档案卡，接上了“一定要看、一定要听”。画了“P”的同学不必分享，教师可以说一句：画“P”也是这本书教给我们的。

师：（总结）这本书最后两句话是这样写的。第十三章，萨哈拉夜里爬到妈妈床上，给妈妈念了那首《我的自画像》，妈妈轻轻抚着她的头发——“她在安慰我，但我现在已经不需要安慰了。于是，这成了‘额外的奖赏’。”“额外的奖赏”是波迪小姐在第十一章说过的话。今天你们手上这张卡，被同桌读到了，也得到了一句只属于你的批语。至于它算不算一份“额外的奖赏”，就由你自己来回答。

全课完。
