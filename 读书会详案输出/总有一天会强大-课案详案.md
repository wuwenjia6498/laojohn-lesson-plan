### 一、文本介绍

【内容简介】

《总有一天会强大》是一部校园成长小说，全书四章，从头到尾由四年级男生公太用“我”来讲。公太个子矮，从一年级到四年级，排队时一直双手叉腰站在最前面。为了长高，他每天喝一升牛奶、早上在单杠上练吊挂、晚上九点就上床；体检那天早上，他还用爸爸的发蜡把头发一根根立了起来。

故事只有三天左右。第一、二章几乎都在体检那一天：同组的女生筑井视力下降，轻轻说了一句“真是不公平”，这句话从此在公太脑子里一遍遍回响。量出来的身高只有 131 厘米，比去年只长了三厘米；午饭时同学的一句“小不点儿”和另一位同学替他打抱不平的一句“可怜”，保健老师讲的篮球故事，筑井说的“身高大多是遗传的”，都让他越想越难受，甚至冒出“我再怎么努力也没有用？”的念头。第三、四章是两天后的周四，好朋友希来里请他一起去赛马场。在那里，公太一直羡慕的、个子高又总被选中的希来里，说出了他自己的烦恼。

四个章名连起来，正是公太一路走过的心事：真是不公平！——努力也没用？——希来里的烦恼——“不公平”也是公平的。书的结尾是开放的：公太没有变高，希来里也没有当上什么，可公太的脚步变了。全书围绕**公平与不公平、羡慕与嫉妒、接纳自己、梦想与坚持、换位思考**展开。

【作者介绍】

伊藤未来，1970 年生于日本神奈川县，儿童文学作家，日本儿童文艺家协会会员。曾获得产经儿童出版文化奖、野间儿童文艺奖、广介童话奖、河合隼雄物语奖等儿童文学奖项，作品有《五年级的烦恼》《月芽儿》《妈妈使用手册》等，多部作品入选日本青少年读后感全国大赛书目。本书由璃世绘图，田秀娟翻译，译林出版社出版。

**特别说明（教师备课注意）**：① 书中**没有逐页页码可引**，只有目录给出的四章起始页：第一章第 1 页、第二章第 29 页、第三章第 71 页、第四章第 101 页，课上找原文一律说“第几章·哪个场景”；② 人名易混：**健吾**（同班，午饭时说“小不点儿”）和**健太**（二年级，交流活动上说“公太比小勉矮！”）是两个人；公太、健太、田卧勇太名字相近，讲时放慢；③ “老师”在书里指好几个人，**保健老师没有名字**，不要说成中村老师；池内是男生，筑井是女生；④ 公太也是排球俱乐部成员，只是没被选为参赛选手；⑤ 书前推荐序转述情节有出入，课上一律以正文为准；⑥ 封面上的奖项说的是作者获过的奖，不是这本书获奖；⑦ 书的结尾不写公太长高、不写希来里当上骑师，课上不替作者补结局。

### 二、教学目标

**本书三维教学目标**

【知识技能】读懂全书三天里发生的事和四个章名的含义；认识公太、希来里、筑井等主要人物，说出书中几个人各自的“不公平”；理解公太对“不公平”的看法和对希来里的态度是怎样一步步变化的。

【过程方法】综合运用预测、提问、联结、推断、比较、整合、转化等阅读策略；借助阅读单、时间轴、对比图、维恩图梳理情节、对照人物、追踪变化，学会用书里的原话支持自己的看法。

【情感价值】体会每个人都有自己的烦恼，别人羡慕的地方也许正是他的苦处；学会不拿“谁的烦恼更严重”去比，说话时顾及别人的感受；在承认有些事无法改变之后，仍愿意为自己能做到的事尽力。

### 三、教学流程

## 第1课时 · 导读课

**本节三维教学目标**

【知识技能】认识全书由四章组成、由公太用“我”来讲；从开篇几个片段认识公太和他的心事。

【过程方法】重点训练预测与提问：借四个章名做预测并写下依据，读了“真是不公平”这一句后提出自己的问题；初步体会第一人称小说里“‘我’觉得”和“事实是”可能不一样。

【情感价值】对公太的处境产生关心，对“希来里会有什么烦恼”“不公平怎么会是公平的”产生好奇，愿意把书读完。

### 一、课程导入·一头立起来的头发（10 分钟）

师：亲爱的同学们大家好。今天一上来，老师先给大家读两小段，读的是一个四年级男孩每天早上要做的事。大家一边听，一边数一数：他一早上做了几件事？

（教师朗读，第一章开篇）

> 咕咚咕咚喝下两杯牛奶，我来到客厅一角，在室内单杠上练起吊挂。
> 一、二、三、四……二十。
> 这是从去年开始，我每天早上雷打不动坚持做的事情。

师：这时候妈妈催他快点，他松开单杠直奔卫生间，对着镜子，用爸爸的发蜡从发根涂起头发。接下来他又做了什么？接着听。

（教师朗读，第一章开篇·接上）

> 我先把脑后的头发立起来，再把头顶的头发立起来，然后用喷雾对着刘海的发根一喷，再整体一喷……

师：他一早上做了几件事？

学生互动分享

参考：三件——喝了两杯牛奶；在单杠上练吊挂，数到二十；用发蜡和喷雾把头发一根一根立起来。

师：喝牛奶、吊单杠、立头发。书里第一章有一幅画，画的就是他在镜子前弄头发的样子。请翻到第一章开头几页，找到画着一面镜子的那一幅。看画面最下面那一大片东西是什么。

【图位:插-03｜第一章 · 早上，公太对着镜子举着喷雾、抓着头顶的头发】

学生自由分享

参考：画面最下面一大片是男孩自己的后脑勺，头发一根根竖着，像刺一样；镜子里的他一手拿着喷雾，一手抓着头顶的头发，还在笑。

师：有同学说“像刺一样竖着”。那请你把三件事放在一起想一想：牛奶、吊单杠、把头发立起来——这个男孩每天早上忙这些，到底想要什么？他今天为什么特别在意头发？

学生互动分享

参考：他想长高。喝牛奶、吊单杠是为了以后长高；把头发立起来，是想让自己现在看起来高一点。今天也许有什么要量身高的事，所以特别用心。

师：（总结）三件事指向同一个愿望：长高。这个男孩叫公太，今天是他们学校体检的日子。头发立起来能不能帮他“高”一点？我们接着往下读。

### 二、精彩片段共读·131 厘米（15 分钟）

师：公太从一年级到四年级，排队一直双手叉腰站最前面，就连曾经比他矮一点的小良也转学了。妈妈说站前面醒目挺好，公太怎么回答？请翻到第一章早饭后那一段，找到妈妈说“站在前面多醒目”的地方，看看紧跟在后面的两句，找到后读出来。

学生互动分享

参考：“可这一点儿都不好！”“我不要醒目，我要个子高。”

师：好，现在量身高了。公太握紧拳头站上测量仪，使劲挺直腰。请一位同学接着读，读到“啪！”的时候停一下。

（邀请一位平时朗读功底不错的同学朗读，第一章·体检）

> 老师笑眯眯地把游标尺轻轻降下来。
> “啊，老天保佑……”
> 游标尺碰到了我立起来的头发。“快停下吧！”我心里默念着。
> 啪！

师：停在这儿。第一章里还有一幅画，画的就是这一瞬间。找到画着一个男孩站在量身高的架子上的那一幅，看那根横着的尺停在哪里。

【图位:插-08｜第一章 · 体检时公太站在测量仪上，横尺停在他竖起的头发尖上】

学生自由分享

参考：横尺停在他竖起来的头发尖上，还没有压到头顶。他眼睛往上瞟着尺子，嘴抿得紧紧的。

师：头发尖上——这正是他心里喊“快停下吧！”的时候。你猜，尺子会停在头发上吗？

学生自由分享

师：我们接着读完。

（同一位同学接着朗读）

> 太好了，多亏我早上花那么多工夫打理头发。就在我这么想的时候，咔，游标尺压在了我的头顶上。
> 写着“131厘米”的卡片朝我递了过来。我才比去年长高了三厘米。
> “好的，辛苦啦。”老师对我说。
> 是我太过自卑了吗？我总觉得老师看我的眼神充满了怜悯。

师：他默默接过卡片，早上立起来的头发全塌了。一早上的工夫，“咔”的一下就没了。老师想请大家注意一句话：“我总觉得老师看我的眼神充满了怜悯。”量身高的老师，真的在可怜他吗？请从这一段里找依据。

学生互动分享

参考：不一定。原文写老师是“笑眯眯地”降下尺子，说的是“好的，辛苦啦”，看不出可怜他的意思；而且公太自己也问了一句“是我太过自卑了吗？”“我总觉得”说明这是他自己的感觉，不一定是老师心里的想法。

师：（总结）要紧的是“我总觉得”这四个字，还有前面那句“是我太过自卑了吗”。这本书从头到尾都是公太用“我”来讲的，我们听到的，全是他心里的话。他觉得别人在可怜他、在笑他、过得比他好——这些是他的感觉，别人心里到底怎么想，书里有时候要过很久才揭晓。读这本书时请一直留着这个心眼：**“我”觉得的，和别人真实想的，是不是一回事？**

### 三、认识这一本书·四个章名的预测（15 分钟）

师：请大家翻到目录。这本书只有四章，每一章的名字都很特别。请一位同学把四个章名连着读出来，连标点一起读出语气。

（学生朗读目录：第一章 真是不公平！／第二章 努力也没用？／第三章 希来里的烦恼／第四章 “不公平”也是公平的）

师：第一章的章名末尾是感叹号，第二章是问号。光看标点，你觉得公太的心情在前两章是怎么走的？

学生互动分享

参考：第一章是感叹号，像是在生气、在喊“不公平”；第二章变成问号，“努力也没用？”像是开始泄气、怀疑自己，比第一章还低落。

师：第三章的名字里出现了一个新的人：希来里。他是谁？三年级冬天，排球教练一眼看中一米五的希来里，完全忽略了公太。公太说希来里人真不错，可和他在一起，心里常蒙上一层阴影。请翻到第一章上学路上那一段，找到紧跟在“蒙上一层阴影”后面、以“这种感情”开头的那一句。请一位同学读出来：公太给自己的这种心情起了个什么名字？

学生互动分享

### 四、阅读方法引导·听一听“真是不公平”（10 分钟）

师：书名里有“强大”，可前三章的章名里，一个说“不公平”，一个说“没用”，一个说“烦恼”。全书第一个说出“真是不公平”的，不是公太，是体检时和他一组的女生筑井。轮到测视力之前，筑井一直不想测，她轻声嘟囔了一句“真是不公平”——

（教师朗读，第一章·体检）

> “我哥哥一玩游戏就是好几个小时，还看电子漫画书，甚至躺着看手机，可他的视力却很好，真是让人想不通。哥哥玩的时候，我都在看天空、看远处，虽然很无聊，但这么做对眼睛好。”

师：筑井觉得什么事不公平？

学生互动分享

参考：她一直在保护眼睛，看天空、看远处，视力却不好；哥哥天天玩游戏、躺着看手机，视力却很好。她努力了，却比不努力的人差。

师：她说的是视力，可这句“真是不公平”从此一直在公太脑子里回响。听到这里，你心里冒出了什么问题？可以问公太，问筑井，也可以问作者。请在读书笔记第一页写下一个问题。

学生自由分享

参考：如“公太为什么一直记着筑井这句话？”“书里还有谁会说‘不公平’？”“公太那么努力，最后长高了吗？”“努力真的没用吗？”“‘不公平’怎么会是公平的？”

师：（总结）大家提的问题，有的读下去就能找到答案，比如“书里还有谁会说不公平”；有的读完也不一定有现成答案，要想、要讨论，比如“努力到底有没有用”。两种问题都留着：第一种读的时候去找，第二种等我们读完一起聊。

### 五、布置阅读任务·七天计划与“不公平”收集卡（10 分钟）

师：这本书一共四章，故事发生的时间只有三天左右，读起来很快。老师给大家排了七天的计划。

| 第几天 | 读到哪里 | 这一段大概在讲什么 |
| --- | --- | --- |
| 第一天 | 第一章（第 1 页起）：早上到上学路上 | 公太的“早上功课”，他和希来里怎么成了朋友 |
| 第二天 | 第一章：体检到回教室 | 测视力、量身高，筑井说“真是不公平” |
| 第三天 | 第二章（第 29 页起）：午饭到走廊窗边 | 午饭桌上的两句话，公太和筑井在窗边说话 |
| 第四天 | 第二章：保健室到第二天 | 保健老师的故事，晚饭时妈妈讲的事，希来里的邀请 |
| 第五天 | 第三章（第 71 页起） | 去赛马场，希来里的烦恼 |
| 第六天 | 第四章（第 101 页起）到全书完 | 叔叔的话，矮种马，结尾 |
| 第七天 | 回头翻看 | 整理收集卡，回到预测单填最后一栏 |

师：读的时候还有一件事要做。“真是不公平”这句话，书里不止筑井一个人说。请大家边读边当一个收集员：每碰到一个人说起自己觉得不公平的事，就记一行。

| 谁说的 | 在第几章·什么场景 | 他（她）觉得什么不公平 | 公太听了是什么反应 |
| --- | --- | --- | --- |
| 例：筑井 | 第一章·体检 | 自己护眼，视力反而不好；哥哥玩游戏，视力却很好 | 那句话在他脑子里一遍遍回响 |
|  |  |  |  |
|  |  |  |  |
|  |  |  |  |

师：（总结）这张收集卡下节课要用，我们要靠它把三天的事排出来。大家带着自己写下的那个问题去读，读完再看看自己的预测猜中了几章。

## 第2课时 · 阅读交流课1

**本节三维教学目标**

【知识技能】梳理全书三天里发生的主要事件；说出筑井、保健老师、今冈助教、妈妈各自的“不公平”和公太听完的反应。

【过程方法】重点训练整合：把收集卡上分散的条目归到时间轴上，看出公太心情的走向；借对比图把四个人的“不公平”并排对照，合出一个结论。

【情感价值】体会公太越陷越深的难受，理解“别人讲自己的难处”为什么一时安慰不了他。

## 第4课时 · 思辨&应用课

**本节三维教学目标**

【知识技能】读懂全书结尾公太的决定和最后一句话的含义。

【过程方法】重点训练转化与联结：就“见过赛道好还是没见过好”亮出立场、用书中依据讲理由；把“不公平级别”的问题联结到自己的生活；把公太想通的东西转化成一段新的对话。

【情感价值】理解“承认有些事改变不了”和“继续努力”可以同时成立；说话时顾及别人的那一份难处，不拿自己的烦恼去比别人的。

### 一、深度阅读发现·结尾的两句话（10 分钟）

师：亲爱的同学们大家好。今天先把全书的结尾读一读。公太深深地吸了一口气，抬头望着灰色的天空，想了很多：人们会羡慕别人、嫉妒别人，因为我们不是机器人，大家都是不同的人。他想到希来里可能当不上骑师，自己也可能永远站在最前排。请一位同学从“这个世界上”读起。

（邀请一位平时朗读功底不错的同学朗读，第四章·结尾）

> 这个世界上充满了各种各样的不公平。
> 可是，就算是这样，不管是今天还是明天，我还是要喝牛奶，还是要在单杠上练习吊挂；为了提高弹跳力，我还是会继续悄悄练习。
> 虽然奇迹不会因此而发生，但我决不能只等着奇迹来临。只要是我能办到的事，我都会尽自己最大的努力。
> 我讨厌放弃。

师：想到这儿，公太告诉希来里，自己和“不公平”打交道的时间可比他长多了，希来里很意外。下面是全书最后几行，请这位同学接着读。

（同一位同学接着朗读，第四章·结尾）

> 希来里一边笑，一边向检阅场跑去。挥着长胳膊、迈着长腿的他简直就像一匹纯种马。我呢，就像矮种马。
> 果然不公平。我这么想着，向希来里的背影追去。
> 希来里有希来里的烦恼，我有我的烦恼……
> “不公平”也是公平的！
> 这么想着，我脚步轻快地向前奔去。

师：结尾有两句话挨得很近：“果然不公平”和“‘不公平’也是公平的！”这两句矛盾吗？

学生互动分享

参考：不矛盾。“果然不公平”是说事实没变：希来里还是比他高、跑得像纯种马；“‘不公平’也是公平的”是说他的想法变了：每个人都有自己的烦恼，不公平落在每个人身上。事实没变，看法变了。

师：再联系全书的开头。牛奶、吊挂、站最前排，开头有，结尾也有。变了的是什么？

学生互动分享

参考：做的事没变，还是喝牛奶、练吊挂；可开头他是为了“个子高”去做，后来听说身高大多是遗传的，一度觉得做了也没用；结尾他知道奇迹不会因此发生，还是要做，“我讨厌放弃”。第一章末他在楼梯上被希来里超过、心里烦躁；结尾他追着希来里，“脚步轻快”。

师：（总结）开头和结尾一对照：事情一样，心情不一样。书名叫《总有一天会强大》，可结尾公太并没有长高。你可以想一想：这个“强大”，说的是哪一种强大？先不急着答，带着它往下走。

> 有能够憧憬的梦想和不知道梦想是什么，哪种生活会更幸福呢？

乙方：**没见过赛道更好**——不知道，就不会比较，也就不会因为够不着而难受。

### 三、联系生活·不公平有没有“级别”（10 分钟）

师：在窗边，公太心里说视力和个子的不公平“级别根本不一样”，嘴上劝筑井戴上眼镜就能看清远处，筑井反过来让他穿双厚底鞋。两个人都觉得对方的烦恼“没那么严重”。请大家回想自己的一件具体的事：你有没有一次，觉得别人的烦恼“不就是……嘛”，后来才知道他其实很难受？或者反过来，你的烦恼被别人一句“这有什么”就带过去了，当时是什么滋味？

学生自由分享

参考：如“同学为一次没考好哭了，我心想就一次小测；后来才知道他家里对分数要求特别严”“我练琴总练不好很着急，别人说‘多练练就好了’，我听了更难受”。

师：有同学说到“多练练就好了”。这句话和书里哪一句很像？

学生互动分享

参考：像保健老师讲田卧勇太时，公太听出来的意思——“没能成为参赛选手，是因为自己还不够努力”；也像筑井说的“你不试试怎么知道？”。说的人是好意，可听的人觉得自己的难受被看轻了。

师：（总结）把自己的事和书接上，就会发现：别人的烦恼，在我们眼里常常“没那么严重”，因为我们不是他。公太在窗边想到了一句话：“视力2.0的我，是不会明白筑井所感到的不公平的。”第三节课我们先放着的那句话，现在可以拿出来了：中村老师对小勉说，“如果别人的话让自己不高兴，那就不要对另一个人说相同的话。”书里没说公太听了为什么心里像被扎了几下，可就在那天中午，他刚在心里嫌过筑井的不公平“级别”低。这两句话，都可以带回我们自己的生活里用。

### 四、阅读成果·下周一，筑井又说了那句话（20 分钟）

师：最后我们来创编一段。书在周四结束了，下面这个情境是我们自己想出来的，书里没写：

**下周一早上，筑井戴着新配的眼镜来上学。她走到公太旁边，叹了口气：“戴上眼镜，看东西是清楚了，可还是觉得……真是不公平。”**

如果是从赛马场回来的公太，他会怎么回答？请你以公太“我”的口吻，写一段一百五十到两百字的对话，要有他说出口的话，也要有他心里的话。写之前，请对照三条标准：

| 标准 | 具体要求 |
| --- | --- |
| 一、用上他想通的东西 | 公太的回答里，要看得出他在赛马场想通了什么（至少用上一样：希来里的烦恼、“奇迹”、“不公平”也是公平的、“我讨厌放弃”），用自己的话说，不照抄原句 |
| 二、不说伤人的话 | 不能说书里那一类让人难受的话：把对方说成可怜的人，劝对方再努力一点，把对方的烦恼说成小问题，或者轻描淡写地说一句：戴上眼镜不就好了 |
| 三、像公太本人 | 他仍然是那个个子矮、会偷偷在意的公太，心里话可以有一点别扭、一点不好意思，不要一下子变成讲大道理的人 |

参考（教师示范，仅供参照写法，不是原书内容）：

筑井扶了扶眼镜，又说了一遍：“真是不公平。”要是上周的我，心里一定会想：你的不公平，级别可比我低多了。可我现在不想比了。我想起希来里在终点前叹气的样子。“我以前也一直这么想，”我说，“后来我发现，连希来里都有他的不公平。”筑井瞪大了眼睛：“他？他还有什么不满意的？”我笑了笑，没说他的秘密。“反正……每个人都有一份。你那份，我是真的不太懂，因为我眼睛一直很好。”筑井愣了一下，说：“那你那份，我也不太懂。”“那就扯平了。”我说。说完我才发现，我的脸有点烫。

师：听完同学的作品，请大家对照标准评一评：哪一句最像赛马场回来的公太？哪一句要是放在第一章，公太绝对说不出来？

参考：如示范里“你那份，我是真的不太懂，因为我眼睛一直很好”，接住了窗边那句“视力2.0的我，是不会明白筑井所感到的不公平的”；第一章的公太只会在心里比“级别”，不会把这句话说出口。“我没说他的秘密”也看得出他在顾及希来里。

师：（总结）写出来的公太，可能有的说了一个道理，有的只是把自己的难受也讲出来，和筑井“扯平”。好的回答，不在于说得多漂亮，而在于他终于不比了，愿意承认“我不懂你那份”。这本书讲的“强大”，也许就从这一句开始。两个星期，我们跟着公太走过了三天：从“真是不公平！”到“‘不公平’也是公平的！”。合上书之前，请大家把第一节课写下的那个问题翻出来看一看，它现在有答案了吗？没有答案也没关系，有的问题本来就要留给以后的自己。
