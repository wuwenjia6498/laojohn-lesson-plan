### 一、文本介绍

【内容简介】 公太是四（1）班的男生，个子很矮：从一年级到四年级，排队向前看齐的时候，他都只能双手叉腰站在最前面。为了长高，他每天早上喝两杯牛奶、在客厅的单杠上练吊挂，给自己定下每天一升牛奶、晚上九点上床的规矩。他最好的朋友希来里，三年级就有一米五，被排球俱乐部的教练一眼看中，后来成了参赛选手。体检那天，公太量出来只有 131 厘米，比去年只长了三厘米；同组的女生筑井视力下降、要配眼镜，轻轻说了一句“真是不公平”。这句话在公太心里一遍遍回响。接下来的一天里，他又听保健老师、妈妈说起各自的“不公平”，又想起去年冬天今冈助教讲过的烦恼，却越想越难受。直到两天后，希来里带他去赛马场看马，说出了自己藏了很久的心事——原来，公太一直羡慕的希来里，也在羡慕公太。全书四章，故事只发生在三天里，由公太自己讲述。

【作者介绍】 作者伊藤未来，1970 年生于日本神奈川县，儿童文学作家、日本儿童文艺家协会会员，曾获产经儿童出版文化奖、野间儿童文艺奖、广介童话奖、河合隼雄物语奖等奖项，作品还有《五年级的烦恼》《月芽儿》《妈妈使用手册》等。全书用第一人称写成，讲故事的“我”就是公太。

### 二、教学目标（书级·三维）

【知识技能】知道全书四章、故事只发生在三天里，能按“体检那天 / 第二天 / 两天后的周四”说出公太经历的主要事情；能说出公太、希来里、筑井、保健老师、今冈助教、妈妈、希来里的叔叔等人物的身份，以及他们各自说出的“不公平”；能沿着“公太怎样看待不公平、怎样对待希来里”这条线，说出公太在三天里的变化。

【过程方法】综合运用预测、提问、联结、推断、比较、整合、转化七项阅读策略；能借助时间轴把三天里公太的变化整合成一条有起有落的线，借助对比图比较四个人的“不公平”，借助维恩图比较公太与希来里；能品析书中把难受的心情写成身体上的感觉的写法，说出这样写读者感受到了什么；能在思辨讨论中把自己的判断回扣到具体章节和场景。

【情感价值】体会每个人都有自己的烦恼，羡慕别人的人，也可能正被别人羡慕；思考面对改变不了的事，怎样接纳自己，又怎样不轻言放弃；懂得说话时体谅别人的感受。

## 第1课时 · 导读课

### 本课三维教学目标

【知识技能】知道《总有一天会强大》的作者；听读第一章的四段原文，知道公太的烦恼（个子矮）和他为长高做的事，知道他和好朋友希来里之间的复杂心情；知道希来里天天把牛奶让给公太这个还没解开的谜。

【过程方法】重点显性训练预测与提问两个策略：能依据章名和今天读到的原文写下有依据的预测，留到下节课验证；能从章名里提出自己的问题，并分清哪些读下去就有答案、哪些要讨论。同时学会两种阅读记号：分清公太“嘴上说的”和“心里想的”，标出每一处有人说出或想到“不公平”的地方。

【情感价值】对“一个拼命想长高的男孩，三天里会遇到什么”产生好奇，愿意用一周时间读完这本书。

### 一、课程导入·一杯让出去的牛奶（10 分钟）

师：亲爱的同学们大家好。这本书里有一杯牛奶，每天午饭的时候，从一个男孩手里，让给另一个男孩喝。

师：先说喝牛奶的这个。他叫公太，四年级，就是这本书里讲故事的“我”，个子很矮。他说自己其实并不怎么爱喝牛奶，上幼儿园的时候，配点心的牛奶常常剩下；可二年级的时候，一个六年级的学生告诉他“喝牛奶能长个儿”，从那天起，他就给自己定下了每天喝一升牛奶的目标。

师：再说让牛奶的这个。他叫希来里，是公太最好的朋友。三年级的时候，他就有一米五，排球俱乐部的教练一眼就看中了他，完全没看站在旁边的公太；最近一次体检，他一米五八。公太是这样说这个朋友的，请大家听。

（教师朗读，定位：第一章“真是不公平！”·上学路上）

> 希来里这小子真不错。虽然他人是不错，但是和希来里在一起的时候，我的心里常常蒙上一层阴影。
>
> 这种感情，可能就是嫉妒吧。P14

师：（稍停顿）公太嫉妒的，就是这个人。可就是这个人，每天中午都做同一件事。公太在书里说：“最近，希来里每天都拜托我帮他喝掉牛奶。”体检那天中午，希来里拜托他喝牛奶，还搭上了一颗樱桃。

师：一个拼命想长高，本来不爱喝牛奶，每天硬喝一升；一个已经一米五八，却天天把自己的牛奶让出去。希来里为什么不喝？请你猜一猜，说说你猜测的依据。

学生互动分享

参考：学生可能猜：①他不爱喝牛奶；②他知道公太想长高，在帮好朋友；③他吃饱了，喝不下；④他有什么不想让别人知道的原因。教师逐一复述，不评对错：“有的同学说他不爱喝，有的说他在帮公太，还有同学觉得这里面藏着他不想说的事。”

师：公太天天替他喝，从来没多问一句。一直到第三章，公太才突然想明白，心里冒出一句“怪不得”。答案在哪儿，老师不说。这一周读书，看看你能不能比公太更早发现。

### 二、精彩片段共读·立起来的头发和叉腰站最前（20 分钟）

师：公太为了长高，不只是喝牛奶。第一章一开头，他咕咚咕咚喝下两杯牛奶，就到客厅的单杠上练吊挂，然后拿起爸爸的发蜡，把头发一根一根立起来。那天正好体检。量身高的时候，这头头发派上了用场——请大家听老师读。

（教师朗读，定位：第一章“真是不公平！”·体检·量身高）

> 游标尺碰到了我立起来的头发。“快停下吧！”我心里默念着。
>
> 啪！
>
> 太好了，多亏我早上花那么多工夫打理头发。就在我这么想的时候，咔，游标尺压在了我的头顶上。
>
> 写着“131厘米”的卡片朝我递了过来。我才比去年长高了三厘米。P23

师：“啪”和“咔”，中间只隔了一句话。从“太好了”到“我才比去年长高了三厘米”，他的心情是怎么变的？

学生互动分享

参考：“啪”的时候他以为头发帮了忙，心里一喜，觉得“太好了”；“咔”的一下，游标尺压到了头顶，立起来的头发一点用也没有；拿到卡片，只长了三厘米，一下子泄了气。

师：（稍停顿）“一喜一落，就在‘啪’和‘咔’之间。”也是在这次体检上，和公太同组的女生筑井，视力下降了，要配眼镜。公太的视力是 2.0，个子矮；筑井一直在努力保护眼睛，视力却下降了。她轻轻说了一句话，这句话就是这本书第一章的章名：“真是不公平！”

师：公太为什么这么在意个子？请大家往前翻，回到第一章那天早上。他喝完牛奶、立好头发，妈妈说他“差不多到我这儿了”，他高兴了一下，又马上低落下去。接着他说起了排队的事：上二年级之前，他曾经比一个叫小良的女生高一点点，心想到了二年级，自己就能伸出胳膊站在后面了，可小良放春假时转学了。请一位同学读接下来的几句。

（邀请一位平时朗读功底不错的同学朗读，定位：第一章“真是不公平！”·排队）

> 结果，我依旧双手叉腰站在第一排。
>
> 虽然妈妈若无其事地对我说：“站在前面多醒目啊，不是挺好吗？”可这一点儿都不好！
>
> 我不要醒目，我要个子高。P9

师：谢谢。站在第一排的人要双手叉腰，后面的人要伸出胳膊。站最前面的人，从一年级叉腰叉到四年级。妈妈说站在前面多醒目、不是挺好吗，为什么这句话一点也安慰不了他？

学生互动分享

参考：①妈妈说的是“醒目”，公太要的是“个子高”，两个人说的不是一回事；②“醒目”恰恰是他最不想要的，站在最前面，大家一眼就看出他最矮；③妈妈是“若无其事”说的，她不觉得这是件大事，可对公太来说是天天都要面对的事。教师复述学生的说法，追问：“书里哪一句话，最能说明他心里怎么想？”引导学生指出“我不要醒目，我要个子高。”

### 三、预测阅读单·四个章名里的故事（15 分钟）

师：这本书的作者是日本的伊藤未来，田秀娟翻译。请大家翻到目录。全书只有四章，请一位同学把四个章名连同起始页读一遍。

（一位同学朗读目录：第一章 真是不公平！ 第 1 页；第二章 努力也没用？ 第 29 页；第三章 希来里的烦恼 第 71 页；第四章 “不公平”也是公平的 第 101 页）

师：四个章名，第一个带感叹号，第二个带问号，第四个里面有一对引号。只看章名，你心里冒出了什么问题？请写一个在本子上。

学生互动分享

参考：学生可能提出：①“努力也没用？”是谁在问？公太那么努力，最后有用吗？②希来里个子高、又被教练看中，他能有什么烦恼？③“不公平”也是公平的——这句话听起来自相矛盾，到底是什么意思？是谁说的？④第一章说“真是不公平”的是筑井，后面还有谁会说？教师复述学生的问题，请学生在自己的问题旁边做个记号：读下去就能找到答案的，画一个圈；读完了也要想一想、讨论讨论才知道的，画一个问号“？”。比如“谁说的这句话”画圈，“努力到底有没有用”画问号。

师：现在请大家在这张预测阅读单上，选两个问题写下你的预测。每个预测都要写清楚依据，依据只能是今天听到、读到的东西：章名，或者刚才那三段原文。最后一栏现在空着，读完书再回来填。

| 我想预测的问题 | 我的预测 | 我的依据（章名，或今天读到的哪一句） | 读完后验证（下节课填） |
| --- | --- | --- | --- |
| 公太那么努力长高，书里会说“努力也没用”吗？ |  |  |  |
| 希来里个子高、被教练看中，他会有什么烦恼？ |  |  |  |
| 希来里为什么天天把牛奶让给公太？ |  |  |  |
| 我自己的问题： |  |  |  |

学生填写，教师巡视。

学生互动分享

参考：示例填法——①“努力也有用，只是没让他长高。依据：章名后面是问号，不是肯定的句子，说明作者也在问。”②“希来里可能也嫌自己哪里不好。依据：第三章章名专门叫‘希来里的烦恼’，说明他也有。”③“他心里有事。依据：第三章章名叫‘希来里的烦恼’，他让牛奶可能和这份烦恼有关。”教师请两三位同学读自己的预测，追问：“你是凭哪一句猜的？”只评依据找得准不准，不评猜得对不对。教师收口：第四章的章名，等你读到的时候，看看是谁说出来的，那个人说的时候，公太是什么反应。

### 四、阅读方法引导·分清嘴上说的和心里想的（10 分钟）

师：这本书是公太自己讲的，有一个特点要提前告诉大家：公太心里想的话，书里大多不加引号；嘴上说出来的话，才加引号。他常常心里想的是一句，嘴上说的是另一句。我们读一小段，是上学路上，希来里搂住他肩膀的那一下。

（教师朗读，定位：第一章“真是不公平！”·上学路上）

> 我不由得踉跄了一下，回了一声“早”。希来里顺势搂住了我的肩膀。
>
> 别这样！会把我头发弄变形的。
>
> 呀，希来里这家伙是不是又长个儿了？
>
> “好重。”我从他胳膊下面钻了出来。

师：这一小段里，哪些是公太嘴上说出来的，哪些只在心里想？他心里想的，希来里知道吗？

学生互动分享

参考：说出来的是“早”和“好重”，都带引号；“别这样！会把我头发弄变形的。”和“希来里这家伙是不是又长个儿了？”没有引号，是心里想的。希来里不知道：他只听到公太说“好重”，以为是嫌他压得重，不知道公太是怕头发塌了、又在偷偷比个子。教师收口：这本书里，只有读者听得见公太心里的话，书里的人都听不见。

师：所以这一周读书，请大家做两种记号。第一种：读到公太嘴上说的和心里想的不一样的地方，在旁边画一条波浪线。第二种：这本书里，“不公平”这个词会被好几个人说出来、想到。每读到一处，就在书页边上画一个三角“△”，旁边写上是谁说的或想的。读完全书，你会发现说这句话的人一直在换。

师：记录栏每天至少记一处“△”：谁说的，在哪一章哪个场景，他觉得什么不公平。下节课，我们就用这些记录，把书里所有的“不公平”放在一起看。还有那杯牛奶：读到和希来里的牛奶有关的地方，在页边写一个“奶”字。到交流课上看看，谁比公太先找到了线索。

参考：教师提示学生，第一天读到的“△”就有两处：筑井说的，和公太自己心里一遍遍回响的。预测阅读单和本子上画了问号的问题，下节课都带来。

## 第2课时 · 阅读交流课1

### 本课三维教学目标

【知识技能】能按“体检那天 / 第二天 / 两天后的周四”梳理全书主要事情，说出公太在十个节点上对“不公平”的想法和对希来里的态度；能说出筑井、保健老师、今冈助教、妈妈、希来里各自的“不公平”是什么，以及公太听完的反应。

【过程方法】重点显性训练整合与比较两个策略：能借助时间轴把分散在四章里的细节整合成一条有起有落的线，找出最低点和转折点；能借助对比图比较四个人的“不公平”，并和希来里的那一段对照，说出这些异同让自己对公太的变化有了什么新理解。同时验证导读课的预测。

【情感价值】体会一个人的想法不是一下子转过来的，会越陷越深，也会因为看见别人的处境而松动；体会别人的烦恼，自己不一定看得见。

## 第3课时 · 阅读交流课2

### 本课三维教学目标

【知识技能】能找出第二章午饭一段里把难受写成身体感觉的句子，说出这样写读者感受到了什么，说出“可怜”这句话和全书的关系；能找出希来里亲口说出烦恼以前、书里透露这份烦恼的线索；能用维恩图说出公太与希来里的相同点和不同点。

【过程方法】重点显性训练推断与比较两个策略：在文学赏析中，先说读到的感受，再回到字句找依据，并通过原文与老师改写版的比较说出写法的效果；在细读中凭书中线索推断希来里没说出口的心事，说出凭的是哪一句；借助维恩图比较两个人，用文本证据说出交集里最出人意料的一条。

【情感价值】体会好心的同情有时也会伤人，学会体谅别人的感受；体会每个人都可能藏着别人看不见的烦恼。

参考：①“喉咙深处猛地哽住了”“胸口深处一阵刺痛”——难受不是说出来的，是喉咙和胸口感觉到的，读的人好像自己的嗓子也堵住了；②“可怜……”单独一行，后面是省略号——他在心里把这两个字又念了一遍，愣在那里；③“没事，我不在意。”是嘴上说的，可前后都是哽住、刺痛，嘴上说的和身体感觉到的对不上；④“大口大口地扒进嘴里”——他不说话，拼命吃饭，是在掩饰。教师追问画①的同学：“喉咙哽住，平时什么时候会这样？”引导学生说出：想哭又不能哭的时候。教师顺带提一句：嘴上说“没事，我不在意”，喉咙和胸口却在难受，这正是这一周该画波浪线的地方——嘴上说的和心里感到的不一样。

师：我们来做个比较。下面这段是老师改写的，不是原文，意思差不多，大家听听差在哪。

师：（老师改写版，不是原文）听了池内的话，我心里很难过。我说：“没事，我不在意。”然后就低头吃饭。

师：两段放在一起，哪一段让你更能感到他的难受？差在哪里？

学生互动分享

参考：原文更能感到。①改写版直接说“我心里很难过”，是告诉你他难过；原文没有写“难过”两个字，写的是喉咙哽住、胸口刺痛，让你跟着他的身体一起难受；②改写版没有“可怜……”那一行，读不出他愣住、在心里反复念这两个字的那一下；③改写版的“低头吃饭”很平常，原文是“大口大口地扒进嘴里”，看得出他在拼命装没事。教师复述学生的说法，然后收口点名：这种写法，是把看不见的心情，写成身体上的感觉——喉咙、胸口说出了嘴巴没说的话。在这个中文译本里，公太难受的时候，常常是这样写的。

师：接着往下想。就在这几句后面，公太说，比起健吾叫他“小不点儿”，池内的话更让他受伤；他还在心里问了自己好几个问题，最后一个是“这么说来，最在意我身高的居然不是我？”。池内明明是在帮他，为什么“可怜”比“小不点儿”更让他受伤？再听他在保健室里回想这件事时说的话。

（教师朗读，定位：第二章“努力也没用？”·保健室）

> 这两句话虽然都很令人沮丧，但它们只是说出了事实，而那句一本正经想替我伸张正义的话更让我难受。

师：“这两句话”，是二年级的健太说的“公太比小勉矮！”，和六年级的菜菜子说的“公太虽然比小勉矮，但年龄比小勉大。”公太为什么觉得这两句“只是说出了事实”，而池内那句更让他难受？

学生互动分享

参考：①比别人矮，是事实，他自己也知道；可“可怜”是在给他下判断，好像个子矮就是一件让人同情的坏事；②池内是好心，可越是一本正经地替他说话，越说明大家都觉得他的矮是个问题，比他自己还在意；③被人可怜，就像被人看低了。教师收口：喉咙哽住、胸口刺痛，写的就是这种说不出来的委屈。这一段让我们看到全书的一个想法：好心的话，也可能伤人。第二章里，中村老师对小勉说过一句话：“如果别人的话让自己不高兴，那就不要对另一个人说相同的话。”公太听完，“心脏像是被扎了几下”，同样是把心情写成身体上的感觉。这一周读书时，你可能还碰到过：第三章赛马场，希来里说那些对他来说都不是最重要的，公太“感到一股热血往脑袋上涌”。公太一路上的难受、生气，书里都让我们在他身上感觉得到。

### 二、细读推断·一杯牛奶里的秘密（15 分钟）

师：第三章，希来里说出想当骑师、在节食的时候，公太突然想通了一件事。请大家翻到第三章，找到这一句，开头是“啊，对了”。

（全班齐读，定位：第三章“希来里的烦恼”·赛马之后）

> 啊，对了！怪不得之前希来里总拜托我帮他喝掉牛奶。

师：导读课上，我们猜过希来里为什么不喝自己的牛奶，这一周大家还在页边写了“奶”字。“怪不得”，说明前面早就发生过。午饭那一句，导读课上老师已经念过了。除了它，在希来里亲口说出来以前，书里还有一处线索露出了希来里的烦恼，你比公太早发现了吗？说出在哪一章哪个场景，凭的是哪一句。

学生互动分享

师：我们细看车上这一处。希来里说“没用的”，公太是怎么想的？请一位同学读。

>
> 和我不一样，希来里总是那个能被选中的孩子。

师：谢谢。读到这里，还没看到第三章后面的时候，你能推断出希来里的“没用的”是什么意思吗？凭的是哪几处？

学生互动分享

参考：①“本来很想成为一名像木边那样的骑师”——“本来”说明现在不想了，或者觉得不行了；②“没用的”和第二章公太说的“我再怎么努力也没有用？”是一样的话，说明希来里也碰上了努力解决不了的事；③转身看窗外，是不想让人看见他的脸；④再加上每天请人喝牛奶，可以推断他在为自己的身体发愁，比如不想长得太快、太重。教师追问：“凭牛奶这一条，能推断出他想变矮吗？”引导学生分清：能推断出他在控制吃喝，但想当骑师、骑师要个子矮，是第三章后面才写明的；推断要凭线索，线索不够的地方，不能说成书里写的。

师：（总结）这些线索公太都亲眼看到了，牛奶还是他亲口喝的，可他一直到第三章才“怪不得”。他一直觉得希来里“总是这么开朗、这么无忧无虑”，是“总是那个能被选中的孩子”；那几天他又满脑子都是自己的个子；希来里也没说，把烦恼藏了起来，就像公太把嫉妒藏起来一样。书里的线索一直摆在那里，公太看不见，是因为他只盯着自己。我们读的时候也一样，有些事要读到后面，再回头看，才发现早就写过了。

### 四、小结·带一个问题过一周（5 分钟）

师：这节课我们品了书里怎样把公太的难受写成喉咙和胸口的感觉，看清了好心的“可怜”为什么最伤人；又回头找到了希来里藏在牛奶里的线索；最后用维恩图看见，这两个好朋友一样在为身体拼命，一样在羡慕对方。

师：下周的思辨课，我们讨论一个问题。全书最后，公太说“虽然奇迹不会因此而发生”，可他还是决定每天喝牛奶、练吊挂。如果你是公太的好朋友，你会劝他接着这样做，还是劝他别再为个子费这个劲？这一周请你想一想，也可以回书里翻一翻：第二章保健室和晚饭时的回忆，第四章结尾。为你的选择找到依据。

本课完。

## 第4课时 · 思辨&应用课

### 本课三维教学目标

【知识技能】能说出全书开头与结尾都写到的事（喝牛奶、练吊挂、双手叉腰站最前），说出公太在结尾做了什么决定；能结合书中情节，对“该不该劝公太继续为长高努力”提出自己的判断。

【过程方法】重点显性训练转化策略，兼用联结与推断：能在思辨讨论中从读过的章节找证据、亮出判断、讲清理由，并说出自己的选择要付出的代价；能把书中“羡慕别人，别人也羡慕你”的体会联结到自己的生活；能整合全书，以公太的口吻给体检那天早上的自己写一封信，让新作品和原书接得上。

【情感价值】思考面对改变不了的事，接纳自己和不轻言放弃怎样同时做到；体会每个人都有自己的烦恼，学会用体谅的眼光看身边的人。

### 一、深度阅读发现·开头和结尾（10 分钟）

师：亲爱的同学们大家好。这本书第一章开头，公太咕咚咕咚喝下两杯牛奶，在客厅的单杠上练吊挂；那时候他告诉我们，排队时他都只能双手叉腰站在最前面。全书结尾，他在赛马场，抬头望向天空。我来读他这时候心里想的。

（教师朗读，定位：第四章“‘不公平’也是公平的”·全书结尾）

> 无论多么想当骑师，希来里也有可能无法当上骑师，甚至连站在起跑线上的机会都没有。我也是。可能我永远都只能按照高矮顺序双手叉腰站在最前排。
>
> 这个世界上充满了各种各样的不公平。
>
> 可是，就算是这样，不管是今天还是明天，我还是要喝牛奶，还是要在单杠上练习吊挂；为了提高弹跳力，我还是会继续悄悄练习。

师：开头喝牛奶、练吊挂、叉腰站最前；结尾还是喝牛奶、练吊挂、叉腰站最前。三天过去，公太做的事一样也没变。那到底什么变了？

学生互动分享

参考：①开头喝牛奶是为了长高，心里盼着自己能变高；结尾他已经知道“可能我永远都只能……站在最前排”，还是要喝——他不再是等着变高才高兴；②开头他一个人跟个子较劲，结尾他想到的是“希来里也有可能无法当上骑师……我也是”，他把自己和希来里放在一起看了；③开头他看见希来里就烦躁、往前猛跑，结尾他追着希来里跑，“脚步轻快”。教师复述学生的说法，收口：事情一样，心不一样了。可是，他这样做，到底对不对？这就是今天要讨论的。

学生互动分享

参考：学生可能说：不放弃是好事，可也要看在什么事上；公太本来就不爱喝牛奶，每天一升是硬灌；第三章他自己都说了，他比希来里还努力，“每次被选为参赛选手的还是希来里”；第二章在保健室，他也想过“一开始就有的差距并没有缩小”。教师复述：“你们说的是：在改不了的事上硬拼，可能只会越拼越难受。”

参考：学生可能说：他喝牛奶不是为了等奇迹，是因为“我决不能只等着奇迹来临”；也可能承认：确实可能白费，这就是代价。教师不替学生下结论。

师：（追问“劝他别费劲”一方）可是第四章，公太对希来里说：“如果自己想做的事情和适合自己做的事情恰好一样，那简直就是奇迹，是吧？”他想打排球，个子却是他的短处，他自己说过要猛练体力和弹跳力来弥补。按你们的说法，是不是该劝他连排球也别打了？

参考：学生可能说：不是，排球可以接着打，只是别再为个子发愁；也可能说：要不要打排球是他自己的事，朋友只能劝他别跟个子较劲。教师收口时把两边的代价都摆出来：劝他接着做，怕他一直跟个子过不去；劝他别费劲，怕他连自己能办到的事也一起放下。有的同学会想出第三种办法：练弹跳接着练，牛奶喝不下就别硬喝一升；或者努力照样努力，只是不再和希来里比。这些办法都可以，关键是你说清楚自己要防的是什么。

师：（总结）第四章的章名，是“‘不公平’也是公平的”。叔叔说“不公平这件事，对每个人都是公平的”的时候，公太觉得没什么好高兴的；全书最后，他自己想到这句话，却脚步轻快。请大家翻到全书结尾，从“果然不公平”读到全书最后一句，一起读。

（全班齐读，定位：第四章“‘不公平’也是公平的”·全书最后几行）

> 果然不公平。我这么想着，向希来里的背影追去。
>
> 希来里有希来里的烦恼，我有我的烦恼……
>
> “不公平”也是公平的！
>
> 这么想着，我脚步轻快地向前奔去。

参考：教师提示：公太没有说不公平消失了，他说的是“果然不公平”；可他知道了，希来里有希来里的烦恼。他没有停下来等奇迹，是追着希来里的背影跑。

### 三、联系生活·你羡慕的人，也许在羡慕你（10 分钟）

师：今冈助教对公太说过一句话：“也许是你不知道。”那时候公太不信会有人羡慕他。请大家想一想：你有没有羡慕过身边哪个人天生就有的东西？比如个子、跑得快、嗓子好听。再想一想：他会不会也羡慕你的什么？请写在本子上，三四句话就够。只写是什么事，不写同学的名字，也不说班上谁的身体怎么样。愿意分享的同学，我们请你说一说。

学生自由分享

参考：学生可能说：①我羡慕表哥个子高，可他总说我跑得快、他跑不过我；②我羡慕同桌嗓子好，唱歌好听，可她说羡慕我胆子大、敢上台讲话；③我想不出来别人会羡慕我什么。教师复述学生说的具体事情，不评高低；对说“想不出来”的同学，教师接一句：“公太在第三章以前，也想不出来。”再追问一句：“书里谁像你？是公太、希来里，还是今冈助教？”把学生的经历接回书里。

### 四、阅读成果·写给体检那天早上的自己（20 分钟）

师：最后，我们来写一封信。请你当公太，在赛马场回来的那天晚上，给体检那天早上正在往头发上涂发蜡的自己写一封信。那个早上的公太，还不知道这三天会发生什么。

师：写信有三条要求。第一，信里至少写到这三天里的两件事，每件写清楚在哪一章，其中至少一件是我们课上没讲过的，比如第三章在终点前看比赛，或者第四章在矮种马体验区和希来里的对话，也可以自己回书里另找一件。第二，书里没写的事不能写进信里：不能告诉他“你以后会长高”“你会当上参赛选手”，全书结尾没有这样写。第三，信里要回答那个早上的公太最在意的一个问题，比如：头发还要立起来吗？个子矮就一定不好吗？牛奶还要喝吗？回答要和刚才的讨论、和书的结尾接得上。

学生互动分享

参考：教师逐一请听的同学点评，复述写信同学的具体事例：“他写到了第四章矮种马那段对话，他想告诉早上的自己：别老跟希来里比。”如果有同学写了书里没有的事，比如“后来你长到了一米五”“希来里放弃了当骑师”，教师追问：“这一件在哪一章？”提醒大家：结尾是开放的，书里没写的，不能写成发生过的事。如果有同学的回答和结尾不一样，比如劝自己别喝牛奶了，只要理由来自书里、自己说得清，也可以，请他说说理由。

师：（总结）书前的推荐序里有这样一句话，这是书外的文字，不是小说正文：“这本书留给我们深思的细节有很多，需要你们细细地读，静静地想，得出属于你的答案。”这本书叫《总有一天会强大》，可书里没有写公太最后变得多高、多强。读完了，你觉得“强大”在这本书里指的是什么？这个问题，请大家带回去，写在你的读书笔记上。
