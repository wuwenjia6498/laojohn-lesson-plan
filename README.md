# 老约翰深度阅读 · 课案生产工作台

本项目是"老约翰深度阅读读书会"系列课程的内容生产工作台，包含 AI 辅助从电子书生成书籍档案、课案详案、投屏课件 PPT、书目卡、招生海报、阅读指南、思维导图等全套配套物料所需的 SKILL 和脚本。

> ⚠ **移动硬盘注意**：本项目存放在移动硬盘上，盘符随挂载不同而变动（如 `h:\`、`e:\`）。所有 SKILL 和脚本中以 `<项目根目录>` 表示项目所在路径，执行前通过 Cursor 工作区路径或 PowerShell `(Get-Location).Path` 确认实际盘符，不要硬编码。

## 封面图管理（所有 SKILL 共用）

新增一本书时，只需把书封图放入 `书籍封面\` 目录，按书名命名（不含书名号）：

```
书籍封面\俗世奇人.png
书籍封面\格列佛游记.png
书籍封面\<书名>.jpg
```

- `laojohn-book-card`：渲染脚本通过 `--covers <项目根目录>\书籍封面` 参数取封面
- `laojohn-course-poster`：渲染脚本通过 `--covers <项目根目录>\书籍封面` 参数取封面
- `laojohn-reading-guide`：AI 直接从此目录读图并转 base64 内联进 HTML

**一次放图，多个 SKILL 都能用，无需重复操作。**

## 品牌资产管理（`品牌资产\`）

存放所有物料共用的固定品牌素材，不随书目变化：

| 文件 | 用途 | 更换方式 |
|------|------|---------|
| `logo.png` | 书目卡/海报右上角品牌 Logo | 直接替换此文件，重跑渲染即可 |
| `qrcode.png` | 海报上的报名/关注二维码 | 直接替换此文件，重跑渲染即可 |

渲染命令通过 `--logo <项目根目录>\品牌资产\logo.png` 和 `--qr <项目根目录>\品牌资产\qrcode.png` 传入脚本。

## 典型生产流程

一本书从零到全套物料，按顺序执行：

```
0. 放入封面图    → 书籍封面\<书名>.jpg
1. 准备电子书    → PDF / 全文文本（建档硬闸，无原文不开写）
2. 生成书籍档案  → [laojohn-book-profile]        → 书籍档案\<书名>书籍档案.md
3. 生成课案详案  → [laojohn-lesson-plan]        → 课案输出\<书名>-课案详案.md
3b. 详案冷启动复盘 → [laojohn-detail-review]     → 派 fresh 子 agent / 新会话，出审稿三件套报告
4. 生成书目卡    → [laojohn-book-card]           → 书目卡输出\<书名>_书目卡.*
5. 提炼中间稿+讲稿 → [laojohn-ppt-draft]         → 课件中间稿输出\<书名>\*.md ＋ 课件讲稿输出\<书名>\*.md/.docx
6. 编译课件PPT   → [laojohn-ppt]                → 课件PPT输出\<书名>\*.pptx
7. 制作招生海报  → [laojohn-course-poster]       → 课程海报输出\<书名>_海报.*
8. 生成阅读指南  → [laojohn-reading-guide]       → 阅读指南输出\<书名>_阅读指南.*
8b. 生成阅读单   → [laojohn-reading-sheet]        → 阅读单输出\<书名>\<阅读单名>-空/-示范.*
8c. 生成阅读测评 → [laojohn-reading-assessment]   → 测评输出\<书名>_阅读测评.md/.docx
9. 生成抢先看导图 → [laojohn-lesson-mindmap]     → 抢先看思维导图\<书名>_抢先看.*
10. 生成教学导图  → [laojohn-teaching-mindmap]   → 教学思维导图\<书名>_教学导图.*
11. 生成反馈话术  → [laojohn-course-feedback]     → 课程反馈话术输出\《书名》_课程反馈话术.*
```

> 写作课（习作课）是独立平行分支：`laojohn-writing-lesson` 吃「习作主题 + 年级」，不进上面这条以书籍档案为源头的链路，产物落 `写作课输出\`。其详案同样可复用 `laojohn-ppt-draft → laojohn-ppt` 链出投屏 PPT 与逐页讲稿（ppt-draft 自动判型走写作课模式），成稿亦可走 `laojohn-detail-review` 冷启动复盘。

## 注意事项

- **书籍档案是课案的事实源头**：`laojohn-book-profile` 产出的档案是 `laojohn-lesson-plan` 的唯一事实依据——详案不会再翻原书，档案错一处详案就跟着错。建档必须基于电子书/PDF 原文，禁止凭模型记忆填写情节、页码或「可引用原文」。
- **JSON 是内容源头**：`书目卡输出`、`课程海报输出`、`阅读指南输出`、`抢先看思维导图`、`教学思维导图` 下的 `.json` 文件是各类产物的内容数据，修改字段后重跑渲染脚本即可更新图片/HTML，请妥善保存。
- **两种思维导图别搞混**：`laojohn-lesson-mindmap` 出的是**书的概况**（精彩抢先看，面向学生），`laojohn-teaching-mindmap` 出的是**教学设计骨架**（面向备课老师）。拿不准时先问用户要哪种。
- **书目卡内容简介**：由 AI 按课案「内容简介」段提炼，提炼完成后保存在 `<书名>_书目卡.json` 的 `summary` 字段，如需修改直接编辑 JSON 后重渲染。
- **盘符问题**：插入移动硬盘后在 Cursor 中确认工作区路径再执行任何脚本命令。
- **引号规范**：所有课案 `.md` 一律使用中文弯引号 `"内容"` / `'嵌套'`（U+201C/201D、U+2018/2019），严禁 ASCII 直引号（U+0022/0027）。`md_to_laojohn_docx.py` 内置行级安全网会在转 docx 前自动修正并给出警告，但源 `.md` 本身就应正确，不依赖安全网兜底。如需批量修复旧文件，运行根目录下的 `fix_quotes_md.py`。
