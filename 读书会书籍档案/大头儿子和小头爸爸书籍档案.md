## ⚠ 结构性事实声明（动笔前必读）

**本书是合集，不是长篇。** 共 **24 篇**，分四辑、每辑 6 篇。篇与篇之间**没有情节主线、没有先后因果**，任取一篇都独立成立。

**但本书与《快乐王子》《俗世奇人》那类纯短篇集有一点不同：它有固定的人物班底。** 大头儿子出现在全部 24 篇；小头爸爸、围裙妈妈、胖外婆、隔壁大大叔各主要活动在自己所属的那一辑。

**「人物贯穿」不等于「情节贯穿」。** 全书没有一条可梳理的故事线，也没有一个可追踪的成长过程——大头儿子在第 1 篇和第 24 篇是同一个年纪、同一副样子，篇与篇之间可以任意调换顺序。因此：

> **下游任何产物都不得对本书做「全书情节主线梳理」「全书成长曲线」「全书故事山」「人物关系总图（跨辑）」。** 这类工具只能落到**单篇**，或落到**辑内**（同一辑的 6 篇共享一位大人）。

**第一辑 · 大头儿子和小头爸爸**

- **两个人的小屋**：交代小屋里住着「一个大，一个小」，两人互相取的称呼 → 同桌吃饭、同床睡觉、同一个脚盆洗脚 → 大头儿子差点吞硬币被木尺打手心、小头爸爸打碎盘子被羽毛打脚心 → 冬夜被窝里，爸爸问他长大想做什么。
- **会叫的大皮鞋**：小头爸爸在公园长椅上睡着 → 大头儿子把他的一只皮鞋扔进废物箱、另一只挂上树 → 爸爸醒后要鞋 → 废物箱那只鞋里传出「吱——吱——」，是一只小白老鼠 → 树上那只鞋里是「叽——叽——」，是一只鸟 → 两人把两只小动物一起带回家。
- **写信和读信**：大头儿子提出让爸爸上班前留一封信 → 第二天早晨读到「大头儿子，再见！」 → 他也开始每天写一封给爸爸 → 两人各自读信，从此每天写一封、读一封。
- **大狼灰**：爸爸把「大灰狼」故意说成「大狼灰」 → 讲故事屡屡被打断（拉窗帘、锁门、钻被窝） → 改为角色扮演，大头儿子做大狼灰、爸爸做大灰狼 → 爸爸在他脸上画四只眼睛 → 他照镜子后扑过去，爸爸逃到门外。
- **开心事**：父子俩躺在床上编儿歌 → 爸爸编了一首「天爸爸浇花」 → 大头儿子编了一首「树叶像冰糖」 → 爸爸半夜爬起来把它抄下来寄给编辑部 → 此后每天带回一本小人儿书都找不到 → 有一天一本图画书从门底下塞进来，上面印着他的名字和儿歌。
- **可爱的小屋**：大头儿子想把家搬到玩具店那儿 → 去看发现整排都是商店、没有空房子 → 楼上老爷爷同意换房 → 回家下车时看见房顶的鸽子和窗台上开花的仙人掌 → 问老爷爷家有没有这些，爸爸说好像没有 → 他说不搬了。

**第二辑 · 大头儿子和围裙妈妈**

- **红围裙**：写围裙妈妈那条印着外国面包师的红围裙 → 一天她怎么也找不到 → 大头儿子一边帮着找一边偷笑 → 晚上爸爸拿着鲜花回来，从口袋里抽出红围裙，说今天是她的生日 → 父子俩忙很久只忙出一碗面 → 她吃得又香又快，说「就是没放盐」。
- **洋娃娃**：围裙妈妈家里到处摆着洋娃娃 → 一晚父子俩看电影未归，她有点害怕，把所有娃娃抱进卧室 → 一个一个拿起来，想起每个娃娃的来历 → 忘了天黑也忘了害怕 → 父子俩回来时她已睡着。
- **害怕**：母子夜里赶路 → 走位换过三种（儿子在前 → 妈妈在前 → 并排走） → 真的碰上一只「大老虎」拦路 → 一问一答四个回合（手涂辣椒、脚沾泥巴、耳朵有耳屎、鼻子有鼻涕） → 「大老虎」拿掉面具，原来是爸爸来接他们。
- **有趣的事情**：围裙妈妈要讲今天碰到的趣事 → 刚开口就打嗝不止 → 喝热茶没用、学虎叫狼吼没用、做深呼吸也没用 → 父子俩合伙打一声响嗝把她吓住 → 嗝跑了，趣事也忘了 → 两人说她打嗝本身就是最有趣的事。
- **将来的事情**：围裙妈妈揉着面团看云、想起小时候 → 照镜子发现皱纹白发，捂脸哭起来 → 父子俩一个说「你今天特别美」、一个说「变成了大花脸」 → 她再照镜子，看见脸上的面粉像云 → 笑起来，重新揉面、想将来的事情。
- **变成一条鱼**：全家在海边，围裙妈妈只肯坐在太阳伞下 → 她连说四个「我不游，海里有……」，父子俩逐一化解 → 父子俩游完回来，说沙滩上有个「粉红色的大蘑菇」、蘑菇下坐着「傻傻的妈妈」 → 她跳进海里 → 三人在海里回头看伞，各说一句「变成了什么」。

**第三辑 · 大头儿子和胖胖的外婆**

- **空屋子**：大头儿子指着胖外婆圆滚滚的肚子说要生小弟弟 → 外婆说那是小弟弟留下的「空屋子」 → 他不停往外婆碗里夹鱼夹虾要她装满 → 外婆只吃鱼头、把鱼肉虾肉都夹给他 → 饭后两人去小树林，给「空屋子」装新鲜空气。
- **开满鲜花的葱地**：外婆在院子里种葱 → 大头儿子嫌光长葱没劲 → 外婆在葱地旁挂鸟窝，想让小鸟带来种子 → 头两天没鸟来，第三天放了水和小米，鸟就来了 → 葱地里陆续长出绿点、各种叶子，最后开出花 → 他在葱地里钻来钻去闻花，外婆急着喊别踩坏葱。
- **捉香味**：外婆只爱每天在胸前戴一朵白兰花 → 玩捉迷藏，大头儿子蒙着眼两次都一下子捉住她 → 外婆不服，自己蒙上眼试 → 她站在原地不敢迈步，忽然闻到香味正从自己胸前飘出 → 明白他蒙着眼是在「捉香味」。
- **大口袋**：外婆衣服前有一个装满东西的大口袋 → 大头儿子想变成一样东西钻进去 → 说变玻璃弹子，外婆说会被送给哭的小孩；说变梳子，外婆说会被弄脏 → 他看见墙上两人的合影，想到自己变没了外婆再去搂谁 → 说还是做外孙 → 外婆摸出一块巧克力给他。
- **最最好吃的东西**：大头儿子爱吃甜的、外婆爱吃香的 → 说好来的是小人儿就用甜的招待、是大人就用香的 → 来的却是一个中学生 → 大头儿子提议把两种掺在一起 → 两人合做三份点心 → 中学生说这真是最最好吃的东西。
- **回到从前**：下雨天外婆喊背痛 → 大头儿子用小拳头捶、戴拳击手套捶、扔小足球，外婆都说不行 → 最后用自己的大头捶，外婆说好了 → 他把头靠在外婆背上，外婆的背摇起来，唱起从前的童谣 → 他说这是小时候听过的，外婆说现在背不动他了。

**第四辑 · 大头儿子和隔壁大大叔**

- **新邻居**：隔壁搬来一位刚留学回来的邻居 → 大头儿子敲门，一层层往上抬头才看见一张留大胡子的黑面孔 → 大胡子叔叔的女儿从他腿后探出头，念了一首「大头大头」的童谣 → 互相取名，大头儿子叫他「隔壁大大叔」。
- **过生日**：小眼睛想给爸爸做件高兴的事 → 大头儿子提议让他再做一次小毛头、两个孩子做他的爸爸妈妈 → 喂奶糊、不许说话、必须哭（用眼药水代替眼泪）、被摇睡 → 醒来发现「爸爸」「妈妈」正在吃他的生日蛋糕 → 他一头钻进蛋糕里。
- **数呼噜**：大大叔通宵画画很困 → 提议玩「我假装晕过去、你们来救我」 → 两个孩子拖手、抱脚、推他都推不动，喊也喊不醒，真害怕了 → 找来小头爸爸，一听是在打呼噜 → 两个孩子给他枕好盖好，坐在门口替他守着、数他的呼噜。
- **两座纸房子**：大大叔用两只装冰箱洗衣机的大纸箱做了两座纸房子 → 两个孩子各抢一座钻进去，吃饭天黑睡觉都不出来，还在门上写了 101 号和 102 号 → 熄灯后两人都害怕 → 一阵大风把房子吹得直摇，以为刮台风 → 跑出来一看是天花板上的电风扇 → 大大叔在卧室里偷偷地笑。
- **飞走的信**：大大叔爱画虫子和鬼吓唬两个孩子 → 两人抢下笔，要画一张给国外的妈妈寄去 → 小眼睛画了新家门前又细又长又弯的小路 → 三人各在路边画一只动物代表自己（大狗熊、眯眯眼老鼠、大脑袋兔子） → 大大叔把画折成小鸟，配上绿气球 → 四人叠罗汉般站高，把小鸟放飞。
- **开心极了的大胡子**：一位背大包、满脸是汗的陌生阿姨来找人 → 小眼睛开门叫「妈妈」 → 妈妈说小鸟是昨天飞到她身边的，并逐一指认三只动物是谁 → 两个孩子抢刷子要刷大胡子，大大叔戴上口罩藏起胡子 → 他笑得太用力把口罩绷掉，大家一起去「刷」那一捧大胡子。

## 五、重复出现的事物/场景

> 本书**篇内重复**（同一篇里的三次／四次结构）远多于**跨篇复现**。两类分开记。

**A. 跨篇复现的母题**

| 母题 | 出现的篇 | 各次的客观情形 |
|---|---|---|
| 「大头大头，下雨不愁」童谣 | 新邻居 / 开心极了的大胡子 | 首次四句（到「我有大头」止），末篇六句（多出「人家有大头，我有妈妈的手」）。⚠ **两个版本，勿混用** |
| 信 | 写信和读信 / 飞走的信 | 前者是父子每天互写一封、当面不读；后者是三人合画一张画折成小鸟，让它「自己飞到国外去」 |
| 白兰花 | 捉香味 / 回到从前（图上） | 外婆胸前每天戴一朵；《捉香味》里它是谜底 |
| 「小毛头」 | 过生日 / 回到从前 | 前者是大大叔被两个孩子当小毛头养一天；后者是大头儿子伏在外婆背上「好像又变成了小毛头」 |
| 「一下、两下、三下」三拍数数 | 空屋子 / 捉香味 / 回到从前 | 分别用于做深呼吸、吸鼻子闻香味、用大头捶背。**三篇同在第三辑** |
| 装扮／假扮 | 大狼灰 / 害怕 / 过生日 / 数呼噜 | 分别是：孩子扮大狼灰、爸爸戴面具扮大老虎、大人扮小毛头、大人假装晕过去 |

**B. 篇内的重复结构（每篇自成一套，不跨篇）**

- 《变成一条鱼》：四次「我不游，海里有……」＋逐次化解。
- 《害怕》：三种走位（儿子在前／妈妈在前／并排）＋一问一答四回合。
- 《大口袋》：两次「我想变成……」被否决＋第三次自己改主意。
- 《回到从前》：四次捶背（小拳头 → 拳击手套 → 小足球 → 大头）。
- 《大狼灰》：三次「等一等，等一等」打断讲故事。
- 《有趣的事情》：三种止嗝办法（热茶／吓一跳／深呼吸）＋第四次意外奏效。
- 《开满鲜花的葱地》：三天（第一天没鸟、第二天还是没有、第三天放了水和小米）。
- 《两个人的小屋》：两组对称的「有一次」（木尺打手心「痛死了」／羽毛打脚心「痒死了」）。

## 档案使用提醒（事实层注意事项）

1. **无页码陷阱**：本书依据的 docx 版**无固定页码**，档案与图单一律按「辑名 · 篇名」定位。**任何下游产物中出现「第 X 页」均属编造。** 另：《数呼噜》中段有一行孤零零的「88」（夹在「大头儿子再抱他的大脚，可大脚也晕过去了」与「抱也抱不动」之间），是页码残留窜进正文，不是内容——**该篇那句话被这个数字从中间劈开，不是原文断句**。

2. **合集陷阱（头号）**：本书**有固定人物班底但没有情节主线**，极易被误当长篇处理。**下游不得做「全书情节主线梳理」「全书成长曲线」「全书故事山」「跨辑人物关系总图」**；这类工具只能落到单篇，或落到辑内（同一辑共享一位大人）。第七节已把可用的链条降级列为**单篇候选**，照那里取。

3. **同一童谣两个版本**：「大头大头，下雨不愁……」在《新邻居》是**四句**、在《开心极了的大胡子》是**六句**（多出「人家有大头，我有妈妈的手」）。**须按篇逐字取用，不得混用版本**，也不得把六句版当作首次出现的那一版。

4. **称谓边界**：① **第二辑正文一律称小头爸爸为「爸爸」**，不出现「小头爸爸」四个字——引用第二辑原文时不得替换成「小头爸爸」。② 「隔壁大大叔」这个名字是**大头儿子在《新邻居》里现起的**，他本人自称「大胡子」；第四辑正文两种称呼都用。③ 「小眼睛」是**女孩**（原文：「这是我的女儿，叫‘小眼睛’。」），不得写成男孩。④ 大头儿子的妈妈全书只作「围裙妈妈」，外婆只作「胖外婆」，均无本名。

5. **第一辑辑名是推断值**：docx 里书名之后直接排 6 篇、无独立辑名，前 6 篇归第一辑是**依版式推断**。对外物料若要写「全书分四辑」，可写；但**不要断言「第一辑名叫《大头儿子和小头爸爸》」是原书明示的**。
