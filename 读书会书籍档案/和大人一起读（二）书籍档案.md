### 分篇梗概

**一、家人朋友情感故事（7 篇）**

**① 《看电视》**（蒲华清，儿童诗）：「我」家看电视很奇妙——足球迷爸爸把球赛换成京剧，奶奶听得入迷 → 奶奶又悄悄换回球赛，自己不看电视只看「我们」→ 妈妈改完文稿走出书房，大家提议不看球赛，让妈妈听音乐、看舞蹈 → 末节说每个人心里都装着一个秘密，「不说你也知道」。原文没有点明秘密是什么。

**② 《棉鞋里的阳光》**（野军）：妈妈给奶奶晒棉被，说棉花里钻进阳光盖着更暖和 → 奶奶午睡时，小峰想到棉鞋里也有棉花，悄悄把奶奶的棉鞋摆到阳光下 → 奶奶起床穿鞋，奇怪棉鞋怎么这么暖和 → 小峰说棉鞋里有好多阳光。

**③ 《借生日》**（李想）：琪琪过生日，枕边有新衣服、大布熊和巧克力；她问妈妈怎么从来不过生日，妈妈说忘了 → 琪琪没穿新衣服 → 妈妈上班时发现包里装着大布熊和巧克力 → 琪琪说把自己的生日借给妈妈，今天是妈妈的生日 → 妈妈问什么时候还，琪琪说把妈妈的生日还给她，这样妈妈就不会忘记自己的生日。

**④ 《小熊的礼物》**（谢明芳）：熊妈妈洗衣、做饭、扫地，三次对小熊说「妈妈没空」→ 妈妈生日快到了，小熊想送「空」当礼物 → 依次问小猪、毛毛虫、乌龟「空」在哪里，都说没吃过、没看过、没见过 → 猫头鹰让他回家多给妈妈帮忙 → 小熊帮着分衣服、洗菜、整理报纸，家务很快做完，妈妈有空陪他玩了，「妈妈已经收到他送的礼物了」。

**⑤ 《假如我是你》**（[英国] 理查德·汉密尔顿，范晓星 译）：戴西晚上不想睡觉，和爸爸玩互换角色的游戏，两人轮流说「假如我是你，你是我……」→ 戴西想到做爸爸要干这么多事 → 打着哈欠说愿意永远做爸爸的小戴西。

**⑥ 《可贵的沉默》**（王圣民，以老师「我」的口吻写）：「我」在课上问爸爸妈妈知不知道孩子的生日、会不会祝贺，孩子们都说知道、会祝贺，教室里很热闹 → 「我」再问谁知道爸爸妈妈的生日、谁给爸爸妈妈祝贺过，教室里一片沉默 → 「我」问怎么才能知道，孩子们七嘴八舌想办法 → 下课时「我」建议孩子们悄悄了解父母的生日 → 家长会上父母们都说孩子变懂事了。

**⑦ 《去年的树》**（[日本] 新美南吉，孙幼军 译）：鸟儿天天给好朋友树唱歌，冬天要南飞，约好明年回来唱歌 → 春天回来，树只剩树根，被伐木人砍倒拉到山谷 → 鸟儿问工厂大门，树已做成火柴运到村子 → 问煤油灯旁的小女孩，火柴用光了，火还在灯里亮着 → 鸟儿盯着灯火看了一会儿，唱起去年唱过的歌，唱完又看了一会儿，飞走了。

**二、古代聪明孩子故事（7 篇）**

**⑧ 《皮球浮上来了》**：孩子们的皮球跳进树洞，掏不出来 → 文彦博让大家打水灌进树洞 → 水满了，皮球浮上来了。

**⑨ 《司马光》**：小伙伴掉进假山下装满水的大水缸 → 别的孩子慌了，有的哭、有的喊着去找大人 → 司马光拿石头砸破水缸 → 水流出来，小伙伴得救。

**⑩ 《曹冲称象》**：别人送曹操一头大象，官员们议论它有多重 → 有人说造大秤，有人说谁也提不起大秤，曹操直摇头 → 七岁的曹冲说出办法：大象上船画线、换装石头到同一条线、称石头 → 照办，果然称出了大象的重量。

**⑪ 《聪明的徐文长》**：老师让学生提两桶满水走过紧贴水面的竹桥，不准弄湿鞋底 → 一个学生拎桶直接走，桥被压低，鞋湿透了 → 徐文长把两只水桶放在桥两边的河水里，牵着绳子走过去，鞋一点儿也没湿。原文写明是「传说」。

**⑫ 《这个徒弟我收下了》**：七岁的华佗想到蔡医生的药铺当学徒 → 蔡医生让他把两只打架的羊分开 → 华佗两手各拿一把青草在羊面前晃，羊争着吃草，停止了争斗 → 蔡医生说「这个徒弟我收下了」。原文写明是「传说」。

**⑬ 《谁能把房间装满》**：先生给每个学生一枚铜钱，看谁买来的东西能把屋子装满 → 有的带稻草、有的拿树苗，都装不满 → 韩愈点燃一支蜡烛，烛光照亮了整个屋子 → 先生连声称赞。原文写明是「传说」。

**⑭ 《三击掌》**：五岁的甘罗在演兵场，秦王问谁能在十击掌内查出士兵多还是武器多 → 文官武将都不吭声，甘罗说三击掌就能查出 → 第一掌让士兵拿兵器，第二掌让拿到兵器的人集合 → 只剩几个士兵空手站在原地，第三掌时甘罗报告「士兵多，武器少」。原文写明是「传说」。

    琪琪神秘地笑了笑，说：“等会儿再告诉您。”
    妈妈要上班去了。她拎起包，咦，这么重？打开一看，里面装着一只大布熊和一盒巧克力。
    “琪琪，这是妈妈给你的生日礼物啊！”妈妈说着要往外拿，琪琪赶紧跑过去，按住了妈妈的手。
    “妈妈，我把我的生日借给您，所以今天是您的生日，这大布熊和巧克力是我给您的生日礼物，我祝您生日快乐！”琪琪说。
    妈妈抱起琪琪，问：“你把生日借给妈妈，妈妈什么时候还你？”
    “把您的生日还给我，这样您就不会忘记自己的生日啦！到那一天，我再穿新衣服。”
    妈妈亲了亲琪琪，笑了，琪琪也笑了。

    洗完衣服，妈妈又到厨房做饭，小熊拿着故事书，要妈妈讲故事。
    “宝宝乖，妈妈没空，下次再说吧。”熊妈妈说。
    饭后不久，妈妈开始扫地、拖地板，小熊拿出拼图，要妈妈陪他完成。
    “宝宝乖，妈妈没空，你自己拼拼看吧。”熊妈妈说。
    熊妈妈的生日快到了，小熊心想：“妈妈总是说她‘没空’，我就送妈妈‘空’当礼物吧！”

## 五、重复出现的事物/场景

- **篇内重复的句式**：
  - 《小熊的礼物》：「宝宝乖，妈妈没空，……」三轮（洗衣服→做饭→扫地拖地）；「‘空’在哪里？」问三轮（小猪→毛毛虫→乌龟），三个回答都是「……我都吃过／看过／见过，但是我从来没……过‘空’！」；结尾帮忙三件事与开头三件家务一一对应（洗衣服—分类、做饭—洗菜、扫地—整理报纸）。
  - 《去年的树》：鸟儿问了三次（树根→门先生→小女孩），每问一次就「向……飞去」；结尾「盯着灯火看了一会儿」「又对着灯火看了一会儿」前后两次。
  - 《假如我是你》：「假如我是你，你是我，亲爱的爸爸／女儿……」父女轮流说了四次。
  - 《看电视》：首节「每个周末，我们全家人都看电视，我家看电视，真有些奇妙」与末节「每天，我们全家人都看电视，我家看电视，可真有些奇妙」首尾呼应，字句略有不同（见档案使用提醒）。
  - 《可贵的沉默》：「……请举手！」四次；「热闹—沉默—又热闹」。
- **跨篇复现的母题**（只记出现，不作关联解读）：
  - **生日**：《借生日》《小熊的礼物》（熊妈妈生日快到了）《可贵的沉默》三篇都写到给爸爸妈妈过生日、送礼物；《借生日》《可贵的沉默》都写到「忘了／不知道」大人的生日。
  - **妈妈很忙**：《看电视》妈妈改文稿一脸疲劳、《借生日》妈妈要上班、《小熊的礼物》熊妈妈忙家务。
  - **奶奶**：《看电视》《棉鞋里的阳光》。
  - **用水解决问题**：《皮球浮上来了》灌水让球浮起、《司马光》砸缸放水、《曹冲称象》看船在水里下沉、《聪明的徐文长》把桶放进河水里。
  - **大人想不出、孩子想出来**：《曹冲称象》官员们、《三击掌》文官武将、《谁能把房间装满》其他学生、《聪明的徐文长》其他学生；原文都写了别人先试或议论、主角后出场。
  - **「传说」**：《聪明的徐文长》《这个徒弟我收下了》《谁能把房间装满》《三击掌》四篇原文明写「传说」，《皮球浮上来了》《司马光》《曹冲称象》三篇没有。

## 六、可作横向对照的内容（篇际对照为主）

- 对照组：《借生日》↔《小熊的礼物》；可对照维度：送给妈妈的是什么（不是买来的东西）/ 妈妈原来的状况（忘了过生日、总说没空）/ 孩子怎么想到的 / 妈妈最后的反应
