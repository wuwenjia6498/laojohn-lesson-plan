## 三、内容结构 [必填]

- 章节结构：全书分**三部**,本电子版把每部各切成上、下两节,故目录为六节:第一部上/下、第二部上/下、第三部上/下,另加一篇「附录」(书外,见第二节)。**各节无标题,只有序号。**
  - **第一部(上/下)·尘世**:乔纳森在原鸥群中痴迷练飞、屡次失败、突破速度,最终因“不负责任”被鸥群大会当众放逐到“远崖”;独居远崖数日后,两只发光的海鸥来接他去“更高的地方”。
  - **第二部(上/下)·更高的世界**:乔纳森抵达一个海鸥稀少、人人练飞的世界,与苏利万结为同伴、拜长者“江”为师;得知这里也不是天堂、“天堂就是尽善尽美”,学会以思想的速度瞬移;江离去后,乔纳森决意返回尘世当导师。末尾切换视角,写年轻海鸥弗莱契·林德刚被放逐、正满心怨恨,乔纳森的声音进入他脑海。
  - **第三部(上/下)·返回与传承**:乔纳森在远崖教弗莱契等八只弃儿飞行,随后带队返回鸥群、公然授课;鸥群由排斥转为围观、再到有鸥越界求学(罗维尔、梅纳德);弗莱契撞崖“死而复生”引发鸥群骚乱与“魔鬼”指控;乔纳森把学生交给弗莱契、化为透明消失;弗莱契接手教新学员,全书以“咱们从水平飞行开始”收束。

- **全书事件序列**(按书中先后):
  - 清晨渔船边近千只海鸥争食;乔纳森独自在远处练习慢速飞行,一再失去平衡摔下来。(第一部上)
  - 交代鸥群共识:飞行只为觅食;而乔纳森“重要的不是吃而是飞”,整日独自低飞滑翔,父母为他担忧。(第一部上)
  - 母亲责问他为何不好好吃、瘦得皮包骨头;父亲劝他“飞行的目的就是为了吃”。乔纳森顺从地试着随群争食数日,受不了,又独自飞出去饿着肚子学飞。(第一部上)
  - 转攻速度:从一千英尺垂直疾降,时速一到七十英里就失控翻滚坠海;领悟高速飞行时须让翅膀静止不动,从两千英尺再试,十秒内达时速九十英里、创下海鸥飞行纪录。(第一部上)
  - 改变姿势时再度失控,在时速九十英里下“在半空中爆炸”,重重撞入海面。夜里在月光下的海面苏醒,心中响起一个空洞的声音劝他认命;他屈服、发誓今后做一只平凡的海鸥。(第一部上)
  - 飞回岸途中,那个声音因“海鸥从来不在黑暗中飞行”再度惊呼,反复念叨他该有“猎鹰的短翅”;乔纳森由此顿悟——收拢双翅、只用翼梢飞行,就等于短翅。他从海面跃升两千英尺垂直俯冲,达时速一百四十英里并能控制,誓言随即被抛在脑后。(第一部上)
  - 次日拂晓,他从五千英尺高空俯冲,穿越四千英尺高度达到极速,在一千英尺处已无法停住、也不知道在此速度下如何转弯;闭着眼睛以时速二百一十四英里(书中另处写作二百一十二英里)从正在吃早餐的鸥群中穿过,无人伤亡。(第一部下)
  - 当天他继续在训练区揣摩高速转弯,发现转动一两根翼梢羽毛即可急转与旋转,学会翻斤斗、横滚、定点翻滚、倒转、定点回旋等特技,成为“世界上第一只做特技动作的海鸥”。(第一部下)
  - 深夜返回海滩,鸥群正集会等他。长者命他“站到中间”——他误以为是表彰,实为受辱;长者宣布他“太轻率,太不负责任”“冒犯了海鸥家族的尊严和传统”,判其放逐远崖。(第一部下)
  - 乔纳森当众抗议(海鸥从不对全体会议反驳),陈述已经有了“学习,进行发明创造,取得自由”的生活目的,请求最后一次机会;鸥群齐呼“开除他”,一同转身不理睬。(第一部下)
  - 独居远崖:他继续学习,学会高速疾降捕深水鱼、空中睡觉、夜航百英里、穿雾冲上晴空、乘风深入内陆食昆虫;痛苦不在孤独,而在同类不肯相信。(第一部下)
  - 黄昏时两只羽翼发光的海鸥出现在他两侧,飞行技术与他完全同步;他们说来自他的鸥群、要带他到更高的地方去,并告知他“一个阶段学完了”。乔纳森随他们上升,消失在另一片天空。(第一部下)
  - 抵达新世界:他自觉身体也变得晶莹,速度倍增而更省力;测出水平飞行约在时速二百七十三英里到顶,略感失望——想不到新躯体也有力所不能及。向导离去。(第二部上)
  - 他发现这里海鸥极少、每只都以把最喜欢的事做得尽善尽美为生活重心;初到时极累,在沙滩上睡着。与同伴苏利万结识,用“以心传心”的方式交谈。(第二部上)
  - 苏利万解释:大多数海鸥要经历千世万世才领悟生活中有比吃喝、打架、争夺权势更重要的事,而乔纳森一世就到了这里;并说“我们是根据这个世界上学到的东西去选择另一个世界的”。(第二部上)
  - 乔纳森向即将离世的海鸥长者“江”发问,得知**这个世界也不是天堂**——“天堂不是空间,也不是时间。天堂就是尽善尽美。”江当场瞬移演示,称想去哪儿只要一转念就成。(第二部上)
  - 江开始教他“像思想一样快”地飞:秘诀是不再把自己局限在有限的躯体里;乔纳森苦练多日毫无进展,江一再说“把信心丢在脑后”、只需领悟什么是飞行。(第二部上)
  - 乔纳森终于顿悟自己是“一只尽善尽美的、没有局限的海鸥”,睁眼时已与江同在另一个星球的岸边(绿色天空、两颗星星代替太阳)。众鸥敬畏,他说自己才刚刚开始学。(第二部下)
  - 江提出下一步先学飞向过去与未来,再学“最困难、最有威力、也是最有趣的一课”——理解仁慈和爱。此后江在众鸥面前浑身发亮至无法逼视而消失,留下最后一句要乔纳森“继续在爱上面下功夫”。(第二部下)
  - 乔纳森渐渐思念尘世,想到那里也可能有海鸥正因说出真理而成为弃儿;苏利万劝阻(“飞得高,看得远”“他们连自己的翅膀梢都看不见呢”),但也提到若当年江不回去教他,乔纳森未必有今天。乔纳森决意返回,与苏利万道别。(第二部下)
  - 视角切换:年轻海鸥弗莱契·林德因绕着海鸥长者做桶式翻滚而被放逐,正满怀怨恨飞向远崖、发誓要做“一个真正的叛逆”;一个柔和的声音进入他脑海,要他不要怨恨、宽恕鸥群并帮助他们提高认识,并问他是否愿意为飞行而这样做。弗莱契答“我愿意”,那只发光的海鸥说“咱们从水平飞行开始吧”。(第二部下)
  - 乔纳森在远崖训练弗莱契(十六点垂直慢滚屡屡失败、暴躁自责,乔纳森纠正他“要坚定,可也要平稳”);到第三个月底又收了六名学生,全是弃儿。(第三部上)
  - 学生们爱练特技,却听不进“身体就是思想的可见形式”一类道理,包括弗莱契在内没有一个相信可以用观念飞行。(第三部上)
  - 乔纳森宣布回鸥群。学生们顾虑“一万年来弃儿不得返回”的鸥群法律,最终跟上;八只海鸥排成双菱形队形、以时速一百三十英里穿过鸥群会议海滩并列队特技降落,乔纳森落地后若无其事地开始讲评这次飞行。(第三部上)
  - 鸥群震动;长者传话“别理睬他们”,跟弃儿说话或看一眼者同被放逐。海鸥们背对他们,乔纳森索性就在会议沙滩上空公开授课,头一次逼学生施展全部才能(马丁·威廉练成低速飞行、查理士·罗兰德飞上二万四千英尺、弗莱契完成十六点垂直慢滚加三个横翻斤斗)。(第三部上)
  - 夜里学生圈外渐渐围上一圈偷听的好奇海鸥,不等天亮又悄悄溜走。(第三部上)
  - “还乡”一个月后,特兰斯·罗维尔第一个越界求学、随即被判弃儿,成为第八个学生;次夜断翅的科克·梅纳德爬来求助,乔纳森只说“我是说你自由了”,梅纳德当即展翅飞入夜空高呼“我能飞啦”。(第三部上)
  - 拂晓近千只海鸥聚来听讲;乔纳森讲自由是海鸥的本性、“只有通向自由的法律才是唯一的真正法律”,并否认自己特殊——差别只在于有些海鸥已经开始认识并发挥自己的潜能。围观者中有来问问题的、有来膜拜的、有来嘲弄的;有鸥称他是“鸥神之子”。(第三部上)
  - 一周后,弗莱契示范高速飞行时为避让一只初次学飞的小鸟,以每小时二百多英里撞上花岗岩峭壁。他在“另一个地方”与乔纳森对话,得知自己只是把意识水平改变得太快、并未死去,可以选择留下或回去;他选择回去继续教新生。(第三部下)
  - 弗莱契在悬崖脚下、四千只海鸥围观中睁眼醒来。鸥群一半高呼“鸥神之子”、一半高呼“魔鬼”,群起围攻要啄死乔纳森;乔纳森带弗莱契瞬移到半英里外脱身。(第三部下)
  - 次日弗莱契质问怎么能去热爱一群想啄死自己的暴徒;乔纳森答爱的不是仇恨与邪恶,而是要看到每只海鸥的美德、并帮助他们认识自己的美德,并举弗莱契自身由“建造痛苦的地狱”到“建造自己的天堂”为例。(第三部下)
  - 乔纳森宣布把鸥群交给弗莱契、自己要去别的鸥群;弗莱契抗拒。乔纳森身体开始变透明,叮嘱不要造他的谣言、不要把他奉为神明,末了要弗莱契别相信肉眼看见的东西、要用智慧去观察,随即消失在空中。(第三部下)
  - 弗莱契面对一群新学员,先讲“一只海鸥是关于自由的无限观念”,见学员茫然,叹气改口“咱们从水平飞行开始”——同时恍然大悟他的朋友确实不比自己更神圣。全书以他看出学员“真正的本质”、“他的学习航程开始了”作结。(第三部下)

- 主要人物的**客观信息**:
  - **乔纳森·利文斯顿(乔)**:海鸥,全书主角。原属岸边一个海鸥群(开篇写渔船边飞来近千只,第三部下另处写“这一群海鸥共四千只”)。以练习飞行本身为目的,不以觅食为重心。因高速穿越早餐鸥群、被长者宣布“不负责任”而放逐远崖。独居期间自学高速疾降捕深水鱼、空中睡觉、夜航、穿雾等技能。后被两只发光海鸥接往另一个世界,拜长者江为师,学会以思想速度瞬移。自愿返回尘世收徒授课,末尾把学生托付弗莱契后化为透明消失。书中被部分海鸥称作“鸥神之子”,他本人明确拒绝这一称呼。
  - **乔纳森的父亲、母亲**:海鸥,只在第一部上出现。母亲责问他为何不吃、瘦得皮包骨头;父亲劝他冬天将至、应学觅食,并说他飞行的目的就是为了吃。此后不再出场。
  - **海鸥长者(原鸥群的长者)**:原鸥群最高权威。主持大会,命乔纳森“站到中间”受辱、宣布放逐;后又下令鸥群不得理睬返回的弃儿。与第二个世界的长者“江”是**两个不同角色**。
  - **江(Chiang)**:第二个世界里的海鸥长者,乔纳森的老师,书中说他不久就要离开那个世界。年老但飞得比群中任何一个都快,能瞬移。告诉乔纳森这个世界不是天堂、“天堂就是尽善尽美”,教他以思想速度飞行,并提出下一课是理解仁慈和爱。最后浑身羽毛发亮至无法逼视而消失,最后一句话是要乔纳森继续在爱上面下功夫。
  - **苏利万(苏利)**:第二个世界里的海鸥,乔纳森的同伴与陪练。以心传心交谈,向乔纳森解释多数海鸥须经千世万世才能领悟。曾劝阻乔纳森返回尘世,最后送别。
  - **弗莱契·林德**:年轻海鸥,第三部主角之一。因绕着海鸥长者做桶式翻滚而被原鸥群放逐,初时满怀怨恨、扬言做“一个真正的叛逆”;经乔纳森在空中出声引导后成为其首徒。练十六点垂直慢滚屡败、性急自责。后示范飞行时为避让小鸟撞上花岗岩峭壁,在“另一个地方”与乔纳森对话后醒来,被鸥群同时称为“鸥神之子”与“魔鬼”。乔纳森消失后接手教新学员。

- (第二部 下·乔纳森论友谊与时空) “苏利，亏你说得出口！”乔纳森责备他说，“可别这么傻！我们每天要实践的都是什么呢？如果我们的友谊是建立在空间和时间之类的东西上，那么最后我们一旦征服了空间和时间，岂不也就破坏了我们之间的手足之情！可是我们一旦征服了空间，剩下的就是此地；我们一旦征服了时间，剩下的就是此刻。而在此地、此刻中，难道我们就不可能彼此见一两面吗？”
- (第二部 下·苏利万送别) 海鸥苏利万不禁噗嗤一笑。“你这个疯子，”他和蔼地说，“要是有谁能教导地上哪只海鸥看到一千英里以外，那就只有你乔纳森·利文斯顿了。”他眼望着沙滩说，“再见吧，乔，我的朋友。”
- (第三部 上·乔纳森纠正弗莱契) 乔纳森低头望着他，点点头。“你在停住时候这样用力，是怎么也不成的。弗莱契，你一开头就减速每小时四十英里！你动作要平稳些！要坚定，可也要平稳，记住了吗？”
- (第三部 上·学生顾虑返群时的回答) “我们有自由想去哪儿就去哪儿，想成为什么就成为什么。”乔纳森回答。说罢，就从沙滩上起飞，朝向东方，朝向鸥群的栖居之地飞去。
- (第三部 上·被误解的代价) 乔纳森叹了口气。他想。这就是被误解的代价。他们要么叫你魔鬼，要么称你上帝。
- (第三部 下·乔纳森的困惑) “怎么搞的，”乔纳森觉得纳闷，“世界上最难办的事怎么倒是使一只鸟儿确信他自己是自由的，而且可以亲自加以证明，只要他肯略微花费点时间练习练习？这样的事为什么竟会这样难呢？”
- (第三部 下·乔纳森交棒) “……是鸥神的独子，对不对？”乔纳森叹了口气，眺望着大海。“你已不再需要我了，你只需要不断寻找你自己，每天找一点，要找到那只真正的、无限的弗莱契。他就是你的导师。你只需要理解他，拿他来实践。”

## 五、重复出现的事物/场景

- **“咱们从水平飞行开始”**:出现两次。① 第二部下,乔纳森对刚答应宽恕鸥群的弗莱契说“咱们从水平飞行开始吧……”;② 第三部下全书结尾,弗莱契对茫然的新学员叹气改口说“咱们从水平飞行开始。”两处措辞略有差异(前者带“吧”与省略号),引用时须按各自出处逐字取用、勿混。
- **“远崖”**:出现多次。① 第一部下,乔纳森被判放逐、独自在此度过数日并自学多项技能;② 第二部下,刚被放逐的弗莱契愤愤飞向此处;③ 第三部上,乔纳森在此训练八名弃儿学生;④ 第三部下,乔纳森提到弗莱契当初“开始在远崖为自己建造痛苦的地狱”。
- **速度数字**:全书反复以具体时速标记进展——七十英里(失控临界)→ 九十英里(第一次纪录,随即撞海)→ 一百四十英里(短翅顿悟后)→ 二百一十四英里(俯冲极速)→ 二百五十/二百七十三英里(第二个世界的水平飞行上限)→ 一百三十英里(八鸥编队返群)→ 一百五十英里(弗莱契练习)→ 二百多英里(弗莱契撞崖时)。**注意:穿越早餐鸥群那次,同一节内先写“二百一十四英里”、后写“二百一十二英里”,系原文自相出入,见末节提醒。**
- **“站到中间”**:第一部下,书中明确说明此举“要不是极大的羞耻,就是极大的光荣”——乔纳森误判为后者,长者宣布为前者。
- **发光 / 变透明**:出现三次,均伴随人物离场或跨界——① 两只“羽翼像星光一样灿烂”的海鸥接走乔纳森;② 江“浑身羽毛变得越来越亮,最后变得光辉夺目”后消失;③ 乔纳森“全身闪亮,开始变成透明”后消失。
- **“鸥神之子”**:出现多次,均为**他人对乔纳森的称呼**——弗莱契转述鸥群的话;乔纳森自嘲地拿它称呼自己;弗莱契撞崖复活时鸥群高呼;乔纳森临别明确要求不要把他奉为神明。

## 六、可作横向对照的内容

- 对照组:**乔纳森 ↔ 鸥群(含其父母)**;可对照维度:飞行的目的(手段/目的) / 对“吃”的态度 / 对失败的反应 / 对规矩的态度 / 生活的时间尺度(“尽可能多活些日子” vs “学习,进行发明创造,取得自由”)。
- 对照组:**第一部的乔纳森 ↔ 第三部的乔纳森**;可对照维度:独自练飞还是教人飞 / 面对鸥群是抗议还是宽恕 / 追求速度数字还是“尽善尽美” / 被放逐还是主动返回。
- 对照组:**乔纳森(第一部被放逐时) ↔ 弗莱契(第二部末被放逐时)**;可对照维度:被逐的缘由 / 被逐后的第一反应(继续学习 vs 立誓报复) / 谁在此时出现 / 后来各自成了什么角色。
- 对照组:**原鸥群的长者 ↔ 第二个世界的长者江**;可对照维度:对“学习”的态度 / 使用权威的方式(判决 vs 提问) / 留给乔纳森的最后一句话 / 各自代表的“法律”(鸥群法律 vs “只有通向自由的法律”)。
- 对照组:**乔纳森的原鸥群 ↔ 第二个世界的鸥群**;可对照维度:海鸥数量 / 生活重心 / 对飞行的看法 / 对“天堂”的认定(书中明说第二个世界也不是天堂)。
- 对照组:**梅纳德(断翅求助) ↔ 弗莱契(撞崖“复活”)**;可对照维度:身体状况 / 乔纳森的处理方式 / 鸥群的反应(欢呼“我能飞啦” vs 分裂为“鸥神之子”与“魔鬼”)。

## 七、贯穿全书的变化线索

- 变化主线:**乔纳森与“鸥群”的关系**(从被群体驱逐,到主动返回群体做导师,再到把群体交出去)。
- 状态节点(按先后):
  - 节点①(第一部 上):独自在远离渔船和海岸的地方练飞;父母担忧劝阻,他试着随群争食几天后受不了,又独自飞出去。
  - 节点②(第一部 上):撞海后在夜里屈服,发誓今后要做一只平凡的海鸥,“这样会使大家都高兴”。
  - 节点③(第一部 上):同夜悟出短翅、达时速一百四十英里,“刚刚发过的誓已经忘掉了”。
  - 节点④(第一部 下):被长者当众判为“太轻率,太不负责任”,他大声抗议、请求最后一次机会,鸥群齐呼开除并集体转身。
  - 节点⑤(第一部 下):独居远崖,“使他痛苦的倒不是孤独,而是其他海鸥不肯相信飞行的光荣在等待他们”。
  - 节点⑥(第二部 下):在新世界想到尘世也可能有弃儿,不顾苏利万劝阻,决定回去当导师。
  - 节点⑦(第二部 下):对满怀怨恨的弗莱契说的第一句话是“不要怨恨他们……宽恕他们吧,帮助他们提高认识”。
  - 节点⑧(第三部 上):带八只弃儿列队飞回鸥群会议海滩,落地后若无其事地开始讲评;面对“别理睬他们”的封锁,索性在会议沙滩上空公开授课。
  - 节点⑨(第三部 上):当众否认自己特殊——“不,不比你们强,也不比我强”。
  - 节点⑩(第三部 下):被鸥群围攻要啄死后,次日对弗莱契讲要看到每只海鸥的美德。
  - 节点⑪(第三部 下):把鸥群交给弗莱契,叮嘱不要把他奉为神明,随即消失。

- (另一条可选主线:**弗莱契从“弃儿”到“导师”**——满怀怨恨扬言报复 → 答应宽恕、从水平飞行学起 → 练慢滚屡败暴躁自责 → 完成十六点垂直慢滚加三个横翻斤斗 → 撞崖后选择回去教新生 → 接手全班,末尾恍悟他的朋友确实不比自己更神圣。)
