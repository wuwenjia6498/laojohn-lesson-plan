### 分篇梗概

**《小狗的小房子》**（完整篇 · **建议课堂精读篇**）
小狗住在院子里一座薄木板钉的小房子里，一叫就被女主人骂；小猫住在屋里，被女主人整天搂着亲，嫌烦 → 两人商量去小河边玩，小猫怕老狼、怕下雨，出主意把小狗的小房子一起抬去，又要带上两把小椅子 → 刚出栅栏门小猫就嫌沉撂了挑子，小狗一个人钻到房子底下把它扛了起来 → 一路穿过树林，小狗被房子压得只看得见脚下的小路，小猫说蝴蝶漂亮，他也跟着说「真的，可真好看」；小猫嫌小椅子咚咚响吓跑了蝴蝶，怪他 → 到河边，小狗放下房子就躺倒睡着；小猫叫醒他要他钓鱼，两人为「小猫钓鱼还是小狗钓鱼」争了一通，小狗只好把尾巴放进水里当虫子，什么也没钓着 → 改玩过家家，小猫嫌小椅子响，小狗来回跑着捡木片、捡石头把椅子修好 → 小猫追大蚂蚱追到树林边，喊小狗来捉；小狗说小狗不会上树，小猫说「会嘛」，他就照她说的助跑起跳 → 没抓住树杈，摔下来撞了头，一动不动，小猫以为他死了，大哭着拍他耳朵；小狗醒来，脚上划了大口子，小猫解下自己脖子上的白缎带替他包住 → 小狗站不起来，小猫怕自己走开老狼来了，就学他的样子去顶小房子，顶不动，改用推的，又想出用锯好的木头段当轮子，把房子推到小狗身边、把他拉进去 → 一路推回家，推几步就得把滚出来的木头搬到前面，进了树林还得躲树枝；她想休息，一想到小狗要洗伤口上药就不肯歇 → 到家时太阳已经下山，她高兴得哭起来冲房子里喊「咱们到家啦」，小狗什么也没看见——他早就睡着了 → 过了几天，小狗又在院子里蹦蹦跳跳，小猫问还去不去小河边，小狗说去，还要给小房子安上四个真正的轮子。
> **本篇有完整主线与固定主角**，是两篇里唯一可做单篇故事山／单篇变化追踪的。**「小狗扛着房子去 ↔ 小猫推着房子回」是全篇最规整的一组对称结构**（见第六节）。

**《小老虎粗尾巴》**（**节选 · 仅五节，第五节未完**）
- **名字惹的麻烦**：小老虎花花随父母搬进新村子，认识了小黑熊白白和小白兔红眼睛 → 一只小花猫跑来，说「花花」是她的名字、她五月生的比他早，要他改 → 小老虎回家求妈妈改名；妈妈说没道理、老虎最厉害，他说人家是女孩子、又是先叫的，还是给我改吧 → 他给自己取名「粗尾巴」（因为红眼睛说他尾巴又长又粗）。
- **气球和雪糕**：妈妈买了两个气球给他，他用「两只手说话」的方式讨要，妈妈一眼看穿是想送白白，又买了两个 → 妈妈讲了猴子阿姨拿三个气球飞上天、只敢先放走一个才慢慢落下来的事，叮嘱他不要一次拿四个 → 他带着气球和雪糕跳过篱笆去找白白，两人比赛拿着气球跳，跳过樱桃树、跳上房顶。
- **比上树**：小猫花花在大榆树上炫耀爬得高，白白爬上去跟她比 → 花花不服气一路往高处爬，粗尾巴当裁判 → 花花说「你用什么办法都行，可上来以后，一定要抓住树枝才算！」，两人各自跑回家取来四个气球 → 粗尾巴牵着四个气球飞过花花、抓住细枝；花花再往上蹿，细枝断了，一头栽下来 → 粗尾巴撒手放掉全部气球，接住了她，两个一起砸在地上，他的屁股肿得像个绿气球 → 花花的爸爸买来蛋糕和巧克力答谢，妈妈买了四个气球给他和白白；花花仍说爬树比赛自己第一。
- **钓鱼**：白白约粗尾巴两个人去很远的绿水湖钓鱼，说那里藏着吃小孩的怪物 → 鱼漂一动不动，白白丢石头、换鱼饵 → 换成小鱼后立刻上钩，鱼竿被拽进水里、折断、鱼线也断 → 白白用他爸的粗线和大钢钩重新绑好再钓，这回变成一场拔河 → 最后露出水面的是**一条大鳄鱼**。
- **活汽艇（未完）**：白白喊「快跑」自己就逃，粗尾巴看出鳄鱼是在哭 → 鱼钩钩住了鳄鱼肚子，粗尾巴爬进他嘴里把钩子摘下来 → 白白举着大石头盯着、警告他不许再吃小动物，鳄鱼答应了 → 鳄鱼请他们坐在背上游湖，游过荷花塘，越游越快，「简直就是一艘汽艇」——**文本到此中断**。

## 五、重复出现的事物/场景

- **小房子（篇内重复，《小狗的小房子》全篇的核心物件）**：① 开篇小狗从它里面跑出来；② 小猫出主意把它抬去河边（列了避狼、避雨、过家家三条用处）；③ 小狗一个人扛着它穿过树林；④ 河边放下它，两人在里面玩过家家；⑤ 小猫把它当成保护小狗的壳，垫木头推回家；⑥ 结尾小狗说要给它安四个真正的轮子。**是全篇唯一贯穿始终的物件**。
- **小椅子（篇内重复）**：出发前小猫坚持要带 → 路上在房子里打滚咚咚响、被指吓跑蝴蝶 → 河边玩过家家时唧唧响，小狗跑去捡木片捡石头修好。
- **敲/叫的声音（篇内呼应）**：开篇小狗一叫就被女主人骂，小猫却说夜里靠这个声音才不害怕；结尾小狗「为了让小猫高兴，他有时候还小声地汪汪叫几下」。
- **气球（《小老虎粗尾巴》篇内跨节复现）**：第二节妈妈买了四个（红、白给自己，黄、绿送白白）＋猴子阿姨的故事（不要一次拿四个、要先放走一个）→ 第三节四个气球成了比上树的「办法」，又被全部撒手放掉 → 第三节末花花妈妈重新买了四个赔给他们。**同一件东西在两节里换了三种用处**。
- **「野孩子」（篇内提及两次）**：花花的妈妈说白白是野孩子、不让花花跟他玩；花花后来自己也用「那是野孩子的玩意儿」回绝摔跤。

## 七、贯穿全书的变化线索

**全书层面：不适用**（两篇独立，无贯穿主线；且第二篇文本残缺）。降级为单篇候选：

- **《小狗的小房子》· 可做单篇故事山／单篇变化追踪**。变化主线：**谁在照顾谁**（这一条只记客观情形，不评「成长」）。
  - 节点①（开篇）：小猫说夜里靠小狗叫才不害怕；小狗听了「觉得非常高兴」。
  - 节点②（出发前）：小猫嫌沉把房子放下说不去了，小狗说「你别管啦，我一个人扛着」。
  - 节点③（树林里）：小狗被房子压得只看得见脚下的小路，小猫说蝴蝶好看，他答「真的，可真好看」；随后被怪罪吓跑了蝴蝶。
  - 节点④（河边）：小猫叫他钓鱼、嫌他懒、嫌小椅子响；他把尾巴放进水里，又跑去捡木片捡石头修椅子。
  - 节点⑤（树下）：小猫喊他上树，他摔下来不省人事；小猫先笑「你可真笨」，随后哭喊「不许你死」。
  - 节点⑥（树下）：小猫解下自己的白缎带包住他流血的脚。
  - 节点⑦（回家路上）：小猫顶不动房子、改用推、想出木头当轮子；「她真想休息一会儿。可是一想：小狗还要洗洗伤口，还要上药……小猫就不肯休息了」。
  - 节点⑧（到家）：太阳下山，小猫高兴得哭起来喊小狗看；「小狗什么也没看见。他躺在小房子里觉得很舒服，早就呼噜呼噜地睡着啦！」
  - 节点⑨（过了几天）：小狗仍要去小河边，还要给房子安四个真正的轮子。

- **《小老虎粗尾巴》：不适用**。各节自成一件事，且**文本残缺、结局未知**——**不得**做成长阶梯、心情曲线或「他后来变成了怎样的老虎」这类判断。

## 档案使用提醒（事实层注意事项）

1. **【头号陷阱】第二篇是残缺文本**：《小老虎粗尾巴》只到第五节「活汽艇」中途，**没有结局**。下游任何产物**不得**对它做整体梳理、结局判断、主旨总括或人物成长结论，**不得**出现「最后……」「这个故事告诉我们……」这类收束句，**更不得**替它补写、猜测或从别处补足后续情节。用它只能落到**已有五节里的单个场景**。若课堂要给学生一个完整故事，**只能用《小狗的小房子》**。
2. **【第二陷阱】不得当长篇梳理**：本书是两篇独立童话，**不得**做「全书情节主线梳理 / 全书成长曲线 / 人物关系总图」。这些只能落到单篇，且只有《小狗的小房子》适合套故事山。
3. **无页码**：本档案依据的 docx **无固定页码、无目录、无版权页**，定位一律「篇名 + 场景/小节名」。**任何下游产物中出现「第 X 页」均属编造**。⚠ 特别注意：**插图上印着页码**（`插-02`＝11、`插-03`＝20、`插-04`＝26、`插-06`＝34–35、`插-14`＝73 等），那是**另一个印本**的页码，与本档案的文字来源未必是同一版本，**不得据此给正文标页**。
4. **docx 标点缺陷（引用前必查）**：本 docx 的**感叹号 318 个、问号 89 个几乎全是半角**（`!` `?`），冒号、逗号也有十余处半角；另有 **19 处右引号被写成 ASCII 直引号**（`"`）、2 处单引号同样。**本档案第四节的引文已统一规范为全角、字词一字未改**。下游若绕过本档案、直接从 docx 取字，**必然违反全仓「正文一律全角弯引号」的铁律**，须先跑一遍 `fix_quotes_md.py` 再用。
5. **docx 转换错字（引用前必查）**：已发现「没抓住**树权**」「快抓住**树权**」「攀上一个高树**权**」等多处（应为「树杈」，全篇无一处写对）、「小白**免**」（应为小白兔）、「小黑**能**不吭声」（应为小黑熊）、「白白给粗尾**卫**打气」「跟**相**尾巴一起撑住鱼竿」（应为粗尾巴）、「**技**着噌一下子就没入水里」（应为「接着」）、「也被**址**进水里」（应为「拽」）、「他喘**看**气告诉白白」（应为「喘着气」）、「红眼**晴**」（应为红眼睛）、「**瞎**，白请他吃大蛋糕」（疑为「嗐」）、「呜……**·**小狗死了」（多一间隔号）；另有**破折号失真**——片段9「两只手说话呢**—**这只手」在 docx 里只有一个 `—`（同书别处作「加——油」），引用时按 docx 原样照录、未擅自补长。**这些是转换失真、不是作者原文**；第四节引文凡涉及处均已就地标注。要投屏或齐读某段，**须先逐字过一遍该段**。
6. **跨行断裂（引用须合并）**：docx 有多处把一句话拆成两段，直接按段取用会得到不通的句子。已知处：「什么颜／色的小狗都会钓鱼」「你到小河边，／捡一块石头来」「就得停下来，／把这段木头移到前边去」「这个可不容易摘下来，／钩得太靠里啦」。**取用整句前先合并。**
7. **引号残缺**：docx 有若干段落**缺开头引号或缺结尾引号**（如「不能躺着钓鱼。故事里的小狗不是躺着钓鱼的！”」缺前引号；第 226 段「好吧？妈妈笑着说：」处两句话的引号全乱）。引用这些段落时须**先补齐引号再上屏**，本档案第四节所选片段已避开最严重的几处。
8. **两篇各有一个「花花」**：第二篇里小老虎的**原名**是花花，小花猫的名字**也是**花花——这正是第一节冲突的起因；改名之后正文一律称他「粗尾巴」。**不得把两个「花花」混为一谈**，也不得在讲第一篇时提到「花花」（第一篇里没有这个名字）。
9. **「白白是黑的」不是错**：小黑熊叫白白，原文明写「可你是黑的，为什么叫‘白白’呢？」——**因为他姓白**。这是书里的笑点，不是转换错误，**不得**当成错字改掉，也不得说成「他是白色的小熊」。
10. **猴子阿姨没有当场出场**：她飞上天的事是**老虎妈妈讲给粗尾巴听的故事**，属故事中的故事。引用时须说明是「妈妈讲的」，**不得**当作正文当场发生的情节。
11. **书内/书外边界**：本档案第一、二节里凡涉及出版信息与作者的判断均为「无从确认、留待回填」，**没有任何书外材料**。可逐字引用的书内原文**只有第四节关键片段与备用引文池**；机读块中留（待补充）的字段，**不得从记忆、网络印象或同名其他版本回填**。
12. **插图与原文的四处不一致**：见第十节末警示③，`插-07`／`插-12`／`插-23`／`插-24` 均属「画面与原文对不上」，**师话按画面说**；`插-06`（两个一起追蚂蚱）同属此类。反过来，`插-16`（四个气球的颜色）与 `插-18`（四个气球的数量）是**可以让学生数、让学生对**的验证点。
