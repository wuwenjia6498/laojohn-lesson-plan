### 分篇梗概

**《孤独的小螃蟹》**（8 小节：小青蟹不见了／小螃蟹的梦／小纸鸟／咚咚鼓／树的眼泪／咔嚓咔嚓剪头发／一只大钳子／小青蟹回来了）
小螃蟹与邻居小青蟹住在两个并排的小泥洞里，每天靠敲墙互相打招呼 → 小青蟹说要去找一个更好的地方住，走了 → 小螃蟹每天仍敲两下墙，是敲给自己听的 → 他外出找过小青蟹，见到一列真火车，回来后梦见自己开小火车，梦里小青蟹拒绝上车 → 救下一只乱飞摔落的小纸鸟，拆开发现纸上画的是一只小螃蟹，替它重画了一只鸟 → 捡到一只空可乐罐当鼓敲，邻居先嫌吵，后来都来听 → 夜里爬进老松树的树洞，找到一颗内含小蚂蚁的琥珀，幻想自己也凝固在树的眼泪里 → 给哭泣的狮子剪好了头发 → 为救掉进土坑的小乌龟，拉断了一只大钳子，长出的新钳子又小又白，他躲在洞里不见人；后来发现土坑上立起一座石头小屋，里面供着他那只断钳和一句纪念的话 → 一天夜里墙那边又传来敲声，小青蟹回来了；当晚他梦见开着小火车，这一次小青蟹坐在车上。
> **本篇有完整主线与固定主角**，是两篇里唯一可做单篇故事山／变化追踪的。

**《恐龙鲁鲁》**（16 小节：胆小的鲁鲁／鲁鲁的蛋壳／鲁鲁和青蛙／变成大恐龙／狐狸的坏主意／鲁鲁在城里／大尾巴的用处／大嗓门／唱歌和下雨／鲁鲁变成气球／最大的一泡尿／鲁鲁的牙齿／喷嚏的用处／鲁鲁去看戏／大棉鞋／特别大的蛋糕）
一枚在山顶待了几千万年的恐龙蛋裂开，小恐龙鲁鲁出生，没有妈妈，胆子很小，一有风吹草动就缩回蛋壳 → 他背着半只蛋壳走，蛋壳先后当过他的摇篮、小船、雨伞、太阳帽 → 饿极了，池塘边的青蛙们捉虫喂他、教他捉虫；他本是食肉恐龙，从此再不吃青蛙 → 狐狸来抓他，他躲进翻扣的小船，青蛙们从船缝送虫给他吃，他吃着吃着突然长大，顶翻小船，吓跑狐狸 → 狐狸改口劝他一起捉青蛙吃，被他一尾巴甩飞 → 此后各节各讲一件事：进城闯祸被罚学交通规则；把大尾巴吊到脖子上、背小朋友上幼儿园；一嗓子吼跑抓小鸡的狐狸，练嗓练哑了；唱歌会震破云层下雨，先被大家嫌、后被农民请去唱；喝可乐胀成气球飘上天，正好撞见老鼠七兄弟野餐失火，一泡尿浇灭了火；用牙齿替大家咬开硬壳果，自己没尝到果仁，大家做了蛋糕谢他；感冒时被豆腐店老板雇去打喷嚏推风车，青蛙送药治好了他；用身子当桥让动物们过河看戏，等到最后戏已散场，他说没关系；冬天用大脚踩碎路上的冰，冻出冻疮，全城老奶奶给他做了四只大棉鞋 → 最后一节，动物们用一只恐龙形状的大蛋糕给他过两岁生日，他想：有朋友，多好啊。
> **本篇各节之间基本无因果**（除前 5 节有「出生→得食→变大」的弱链条外，其余各节可任意抽换顺序），**不可套成长曲线**。

## 五、重复出现的事物/场景

**《孤独的小螃蟹》· 篇内重复**
- **敲墙声**（一／二末／八，共四处以上）：小螃蟹用大钳子敲两下「咚，咚」，小青蟹回敲「笃，笃」。小青蟹走后他仍每天敲，「他是敲给自己听的」；结尾墙那边回敲，成为小青蟹归来的信号。**这是本篇最清晰的一条形式线索**。
- **吐泡泡**（一末）：难过时吐一大堆泡泡把自己藏起来。
- **小火车的梦**（二／八末）：两次出现，见下节篇内对照。
- **月亮**（四／五）：敲鼓的夜晚与树洞之夜均以月亮起兴。

**《恐龙鲁鲁》· 篇内重复**
- **蛋壳**（一／二）：先是躲避处，后成为摇篮/小船/雨伞/太阳帽；第三节后不再出现。
- **狐狸**（四／五／八）：三次出场，均为反面角色，三次都没得逞。
- **青蛙**（三／四／五／十三）：喂养、送食、送药，是鲁鲁反复受惠的一方。
- **「身体某处特别大」引出的事**（七尾巴／八嗓门／十二牙齿／十三鼻孔／十五脚）：五节共用同一构造——某个「太大」的部位先惹麻烦、后派上用场。**这是《恐龙鲁鲁》各节之间唯一稳定的结构性重复**。

**跨篇母题（无共同人物，仅母题相似）**
- **帮了别人、自己有所失**：小螃蟹救小乌龟断了一只大钳子；鲁鲁当桥让大家过河、自己没看成戏；鲁鲁替大家咬开硬壳、自己没尝到果仁。

## 六、可作横向对照的内容

> 合集的对照价值主要在**篇与篇之间**，以及**篇内前后**。以下只列可对照的维度线索，不下结论。

- **篇内对照（孤独的小螃蟹 · 最有价值的一组）**：第二节的梦 ↔ 第八节末的梦；可对照维度：小青蟹在不在车上／她说了什么／小螃蟹醒来后的反应。
  - 原文依据：第二节「小青蟹却说：“什么呀，我要坐真正的大火车……”／小螃蟹忽然觉得自己的小火车很没劲。」↔ 第八节末「车上坐着好些小甲虫，小青蟹也坐在他的小火车上。」
  - ⚠ 这一组**有两幅插图恰好对应**（`插-03` 车厢里只有甲虫、`插-10` 青绿色的小青蟹坐在车上），见第十节。
- **篇内对照（孤独的小螃蟹）**：断钳之前 ↔ 断钳之后；可对照维度：钳子的样子／他愿不愿意见人／他怎么看自己。
- **篇内对照（恐龙鲁鲁）**：变大之前 ↔ 变大之后；可对照维度：怕不怕／吃什么／别人怎么对他／他能为别人做什么。
- **篇际对照**：小螃蟹 ↔ 鲁鲁；可对照维度：各自「与众不同的地方」是什么（一大一小的钳子 ↔ 太大的尾巴/嗓门/脚）／这处不同先带来什么麻烦、后来怎么用上／朋友在各自故事里起的作用。
- **篇际对照**：小纸鸟（心里装的不是自己，所以乱飞）↔ 鲁鲁（本是食肉恐龙，却再不吃青蛙）；可对照维度：「本来是什么」与「后来成了什么」。

## 七、贯穿全书的变化线索

**全书层面：不适用**（两篇独立，无贯穿主线）。降级为单篇候选：

- **《孤独的小螃蟹》· 可做单篇变化追踪**。变化主线：小螃蟹独自度日期间做的事。
  - 节点①（一 小青蟹不见了）：小青蟹走后，他仍每天敲两下墙，「他是敲给自己听的」；难过时吐泡泡把自己藏起来。
  - 节点②（二 小螃蟹的梦）：梦里开小火车，小青蟹拒绝上车，他「忽然觉得自己的小火车很没劲」。
  - 节点③（三 小纸鸟）：替小纸鸟重画了一只鸟，小纸鸟飞走时他挥着大钳子。
  - 节点④（四 咚咚鼓）：被邻居嫌吵，仍推着罐子到没人的地方敲；后来邻居都来听。
  - 节点⑤（七 一只大钳子）：断钳后堵住洞口不见人；见到石头小屋里供着断钳与那句话后，「他很想哭出来，不过不是因为难过」，此后夜里出洞，并想「以后，我在白天也要出去」。
  - 节点⑥（八 小青蟹回来了 末）：再次梦见开小火车，这一次小青蟹坐在车上。
  - > 各节点只记客观情形，不评「成长」。

- **《恐龙鲁鲁》：不适用**。除前五节有「出生 → 被青蛙喂养 → 突然变大」的弱链条外，其余各节可任意抽换顺序，**不要套成长阶梯或心情曲线**。

## 档案使用提醒（事实层注意事项）

1. **【头号陷阱】不得当长篇梳理**：本书是两篇独立童话，下游任何产物**不得**做「全书情节主线梳理 / 全书成长曲线 / 人物关系总图」。这些只能落到单篇，且《恐龙鲁鲁》连单篇也不适合套故事山（各节无因果）。
2. **角色不跨篇**：小螃蟹与鲁鲁分属两个故事世界，不得互相类比为「同一世界的角色」；做篇际对照时须显式说明是「两个故事放在一起看」。
3. **无页码**：本档案依据的 docx 无固定页码，定位一律「篇名 + 小节名」。**任何下游产物中出现「第 X 页」均属编造。** 另：docx 正文第 313 段孤零零一个「**76**」，是印刷页码窜进正文的残留，**不是内容**，不得当作书中文字引用。
4. **第二篇篇名**：docx 篇名行印作「**恐龙鲁兽**」，但正文通篇作「鲁鲁」，同书另一版本作「恐龙鲁鲁」——**一律用《恐龙鲁鲁》**，不要把「鲁兽」当成角色别名或写进任何产物。
5. **docx 转换错字（引用前必查）**：已发现「用钳子**茄**着」（疑为「蘸」）、「他**支**成了一只鼓」（疑为「变」）、「小**鸟**龟」（应为小乌龟）、「小**场**蟹」（应为小螃蟹）、「被填平**丁**」（应为「了」）、「从戏院里跑**4**来」（「4」为残留）、「放着的是**—一**只大钳子」（多一破折号）。**这些是转换失真、不是作者原文**；上面第四节的引文凡涉及处均已就地标注。要投屏或齐读某段，须先逐字过一遍该段。
