### 分篇梗概（按篇独立列出；篇与篇之间无先后因果）

**1. 神笔马良**
穷孩子马良靠打柴割草过日子、喜欢画画却连一支笔也没有 → 到学馆借笔被画师辱骂、吐唾沫撵出门 → 立志苦练：山上折树枝在沙地描飞鸟、河边用草根蘸水在岸石描游鱼、夜里用木炭在窑洞壁上再画一遍 → 一年一年地苦练下去、从没有一天间断，画技逼真（画母鸡引来老鹰、画黑毛狼吓得牛羊不敢吃草），却始终没有笔 → 一夜梦中白胡子老人赠“神笔”、嘱“你要好好用它”，醒来笔真在手 → 半夜叫醒伙伴报喜，画鸟能飞、画鱼能游 → 天天替穷人画犁耙、耕牛、水车、骡子 → 邻近大财主派家丁抓他、逼画金元宝，他不肯，被关马厩不给饭 → 雪夜财主偷看，见马良画火炉烤火、吃热饼，动了杀心夺笔 → 马良画梯子翻墙逃走，财主追爬（画的梯子）摔下 → 马良画骏马逃走，财主带家丁追，马良画弓箭射中财主坐骑咽喉、财主跌下马 → 马良逃到远方市镇卖画，怕人知道故意画不活（少嘴断腿）→ 画白鹤时不慎溅墨点睛、白鹤飞走，惊动全镇 → 官员奏报皇帝，皇帝派人强抓马良进京画画 → 马良恨皇帝：叫画龙偏画大壁虎、叫画凤偏画大乌鸦，二者乱爬乱叫打架、弄脏宫殿 → 皇帝夺笔、打入天牢，自己画金山成塌下的石头堆、画金砖成扑来的大蟒蛇 → 皇帝只得放马良出来、假意许金银公主、还笔要他画画 → 皇帝要画摇钱树，马良先画大海、再画海中小岛与金光大树（“摇钱树”）→ 皇帝要画船去海中央摇钱，带娘娘太子公主大臣将军上船 → 马良画风，皇帝嫌慢连喊“风大些”，及至害怕连喊“风够了”，马良只顾不停画风 → 风越来越大、船翻船碎，皇帝一行沉入海底 → 皇帝死后“神笔马良”故事传开，马良去向众说不一（有说回家乡种地、有说到处给穷人画画）。

**2. 牧童三娃**
杨家洼三面高山、一片大草原、家家养羊 → 近来羊常被一阵“浓烟似的黑风”卷走、每天少三五只，全村愁苦 → 十五岁牧童三娃决心找羊，伏地察看、亲见黑风卷走三五只羊，丢下羊鞭飞奔追赶 → 追过山背、山坡、山冈，脚肿起泡，黑风绕过山峰不见 → 乌云压顶下起暴雨，三娃躲进一株大树下、爬上树杈 → 见水冲树根、恐树被冲倒，冒雨培土、又挖排水沟引水入山涧、救了树 → 靠树昏睡，醒来见一“绝顶标致的仙女”道谢——原来自己身在大院墙檐下，救的是仙女（花神）的院子 → 花神先后取出金子、银子、珍珠、玛瑙相赠，三娃一律摇头“我不要”，只求找回村里的羊 → 花神告知羊是“深山坳的蛇精”抢去、离此一千里，愿送他去，并赠三粒种子（急需时说一声就变出所需之物）→ 花神扯下披肩化牡丹叶（金凤凰）载三娃飞越千山万水到深山坳（醒觉后知院子实为一株大牡丹花）→ 三娃寻到蛇精石洞、喝令还羊，蛇精吐黑烟闭合石门 → 三娃用第一粒种子变凿子凿开石门 → 蛇精扑咬，三娃屡屡闪避、被蛇精尾巴团团缠住 → 三娃用第二粒种子变涂毒宝剑，刺入蛇精脑袋、砍下蛇头 → 深入石洞层层找羊，最里一层只见一地羊骨头，三娃痛哭 → 用第三粒种子变仙水洒向羊骨，羊群复活、围到他身旁 → 三娃带羊乘牡丹叶飞回杨家洼，全村感激 → 从此杨家洼的羊不再丢失、越养越多。

**3. 大奖章**（作者原分一~十五节，此处串本篇事件）
森林要开运动会，报信的猴大哥骑摩托车通知荡秋千的小熊、小猪等去报名（节一、二）→ 报名处，小熊报赛跑，小猪犹豫、被狐狸奚落后赌气也报赛跑；挂着金色大奖章的“驴冠军”小驴也报赛跑，狐狸一味谄媚吹捧（节三）→ 清晨小熊早早练跑、小猪迟到，猴大哥告知“小驴也参加赛跑了”、激励二人苦练（节四）→ 小驴不练跑，只顾让狐狸给它画像，轻蔑小熊小猪“就是练上十年也是白练”（节五）→ 小熊耐心扶小猪爬坡、练过独木、绕树跑圈；小驴躺在树丫上看画像、做夺冠美梦，一蹦从树上摔下（节六）→ 运动会开幕，撑竿跳、链球等项目先赛（节七）→ 赛跑起跑：小驴迟到、慢腾腾穿跑鞋耽误发令，小猪两度惊慌（抢跑、听枪声吓坐在地），小驴让小熊小猪先跑、扬言“一下就追上”（节八）→ 小熊小猪先先后后跑，小驴迟迟才起跑追赶、一度赶超并嘲笑二人（节九~十一）→ 小驴中途分心：跑去踢足球出风头、发现胸前奖章不见、钻进树丛找奖章、长尾巴缠住树枝、猛拉扯断一截尾巴（节十一~十三）→ 小熊小猪不泄气继续跑、越过险坡（小猪抱头缩身滚下坡），小驴拖着断尾巴追赶（节十二~十四）→ 小熊领先冲过终点线，掌声欢呼四起（节十四）→ 大奖章挂上小熊胸前、白兔献花，小熊把畏缩的小猪拉来一起拍照；猴大哥劝低头想走的小驴“可别再骄傲了”“改了缺点就好”，小驴慢慢抬头、与小熊互相祝贺，众人把小熊高高抛起（节十五）。

  - 可引用原文（逐字，成段）：
    从此，他下决心学画画，每天用心苦练。他到山上打柴时，捡起一根枯树枝，在沙地里学着描飞鸟。他到河边割草时，用草根蘸蘸河水，在岸石上学着描游鱼。晚上，回到家里，他拿一块木炭，在窑洞的壁上，又把白天描过的东西，一件一件再画一遍……P4-5

- **片段3（神笔马良·白胡子老人赠神笔）**
  - 定位：《神笔马良》，马良梦中得笔。
  - 内容概述：夜里窑洞亮起五彩光芒，白胡子老人赠马良一支“神笔”、嘱他“你要好好用它”，马良惊醒发现笔真在手里。
  - 可引用原文（逐字，成段）：
    不知道什么时候，窑洞里亮起五彩的光芒，来了个白胡须老人，把一支笔送给他，说：
    “这是一支神笔，你要好好用它。”
    马良接过来一看，那支笔金光灿灿的，拿在手上，沉甸甸的。P6

- **片段4（神笔马良·画风翻船·结局）**
  - 定位：《神笔马良》结尾，皇帝乘船入海摇钱。
  - 内容概述：皇帝乘马良所画大船入海摇钱，嫌风小连喊“风大些”，害怕时连喊“风够了”“船要翻了”，马良只顾不停画风，终致船翻船碎、皇帝一行沉海。
  - 可引用原文（逐字，成段）：
    皇帝被海水打得浑身湿淋淋的，抱着船的桅杆，不住地叫：
    “风太大了！船要翻了！不要再画了！……”
    马良还是不住手地画风。风更大了，吹来了许多厚厚的乌云，又鸣雷，又闪电，还下起暴雨来。浪更猛了，海水像一堵堵倒塌的高墙，接连不断地往船上压去。
    船翻了。船碎了。坏皇帝呢？不见了，大概沉到海底去了。P22-23

- **片段5（牧童三娃·羊群失踪·全村发愁）**
  - 定位：《牧童三娃》开篇，黑风卷羊。
  - 内容概述：杨家洼的羊近来常被一阵黑风卷走、每天少三五只；羊是村人的命根子，老人、姑娘、孩子、小伙子都为此发愁，却不知羊到哪里去了。
  - 可引用原文（逐字，成段）：
    但是不知道怎么的，近来，放在草原上的羊儿，常常不见了。不是你家的，便是我家的，每天总要少去三五只。羊儿可是人们的命根子呀！那些快活的老年人，都板起发愁的脸孔了。那些俏皮的姑娘，也都忧郁起来了。那些爱闹腾的孩子，都瞪着眼睛发呆了。那些喜欢开玩笑的小伙子，也没有这份心思来唱歌了。但是羊儿呀，仍是天天在少，到哪里去了呢？谁也不知道。

- **片段6（牧童三娃·辞金求羊）**
  - 定位：《牧童三娃》，花神以珍宝相赠。
  - 内容概述：花神先后取出金子、银子、珍珠、玛瑙相赠，三娃一律摇头“我不要”；花神奇怪地问他到底要什么，三娃只求找回村里被黑风卷走的羊。
  - 可引用原文（逐字，成段）：
    花神拿出一大盒金子，对三娃说：“这金子给你吧！”
    三娃摇摇头，回答道：“我不要。”
    花神拿出一大箩银子，对三娃说：“这银子给你吧！”
    三娃摇摇头，回答道：“我不要。”
    花神拿出一大串珍珠，对三娃说：“这珍珠给你吧！”
    三娃摇摇头，回答说：“我不要。”
    花神拿出一大箱玛瑙，对三娃说：“这玛瑙给你吧！”
    三娃摇摇头，回答说：“我不要。”
    花神感到十分奇怪，问他：“这不要，那不要，那么，你要什么呢？”
    三娃很快就回答她了：“我要找回我们村里的羊啊！我们村里的羊天天让一阵黑风刮走三五只，我是来找羊的。”

- **片段7（牧童三娃·三娃斗蛇精）**
  - 定位：《牧童三娃》，三娃与蛇精搏斗。
  - 内容概述：蛇精将三娃身子团团缠住、冷笑他“动不了”，三娃取出第二粒种子变成涂毒宝剑，插进蛇精脑袋、终将蛇头砍下。
  - 可引用原文（逐字，成段）：
    他手上的种子，就变成一把锋利的宝剑了，而且宝剑的尖上涂着黑色的毒药。他很快地将它插进了蛇精的脑袋。
    “哎哟！”蛇精大叫了一声，身子一松，放开了三娃，嘴里淌出许多紫黑色的血来。
    三娃急忙从蛇精身上跳下来，提起宝剑，瞄准它的脑袋，又是一剑劈去。蛇精的头被砍下来，尾巴一伸，滚下山去了。

- **片段8（牧童三娃·仙水复活羊群）**
  - 定位：《牧童三娃》，三娃在石洞最里层。
  - 内容概述：三娃在洞里只找到一地羊骨头、痛哭，忽记起还有一粒种子，变成仙水洒向羊骨，羊群复活、亲切地围到他身旁。
  - 可引用原文（逐字，成段）：
    手上的种子变成一盅黄颜色的仙水了。他把这盅仙水往羊骨头上一洒，顿时升起了一阵白雾，迷得三娃睁不开眼睛。雾很快就散了，啊！这些羊儿都活转来了。
    他真高兴呀！他吹了一声口哨，羊儿们像久别的伙伴见到亲人似的，都向他身旁围上来了。

- **片段9（大奖章·小驴轻蔑苦练）**
  - 定位：《大奖章》节五，小驴让狐狸画像、拒绝练跑。
  - 内容概述：猴大哥催小驴练跑、告知小熊小猪早已在练，小驴却轻蔑地说这两个“小傻瓜”就算练十年也是白练。
  - 可引用原文（逐字，成段）：
    猴大哥看见这情况，便跟小驴说：“小驴，你怎么还不去练跑？小熊、小猪它们，早就在练跑啦！”
    小驴一听，轻蔑地说：“这两个小傻瓜！让它们去练吧！就是练上十年也是白练！”
    猴大哥听了有点火冒，说：“那不见得吧！”

- **片段10（大奖章·小驴做梦摔下树）**
  - 定位：《大奖章》节六，小驴躺在树丫上。
  - 内容概述：小驴躺在树上睡着、做梦冲过终点夺冠、大奖章飞来挂上胸口、众人献花，它高兴得一蹦，却从树丫上摔下、好梦惊醒。
  - 可引用原文（逐字，成段）：
    小驴睡得香甜，大声打着呼。它做梦了：它正在参加跑步比赛，一口气冲过了终点线。顿时，那枚大奖章从远处飞来了，悬挂在它的胸口上。它走过大家面前，路两旁向它投来了成束成束的鲜花。它乐得蹦了起来。一蹦，它从树丫上摔下来，好梦被惊醒了。

- **片段11（大奖章·小熊夺冠·劝勿骄傲）**
  - 定位：《大奖章》节十五，颁奖之后。
  - 内容概述：大奖章挂上小熊胸前后，小驴狼狈低头想走，猴大哥叫住他、劝他别再骄傲、改了缺点就好；小驴慢慢抬起头，与小熊互相祝贺。
  - 可引用原文（逐字，成段）：
    小驴狼狈地低着头，转身想走。猴大哥喊道：“唉，小伙子，可别再骄傲了！”
    小驴耷拉两耳，转过身来，听猴大哥说：“以后好好努力，改了缺点，就好嘛！”
    小驴慢慢抬起头来，猴大哥过去拉它，说：“来，一块儿拍照吧！”

## 五、重复出现的事物/场景（合集，注明篇内/跨篇）

- **神奇宝物母题（跨篇复现的母题，仅前两篇）**：《神笔马良》的“神笔”（画什么活什么）与《牧童三娃》的“三粒种子”（急需时说一声就变出所需之物）都属“善良主人公获神奇宝物、以之惩恶救人”的母题；**《大奖章》无奇幻元素**，是纯现实的动物寓言，不含此母题。

## 六、可作横向对照的内容（篇际对照 + 篇内对照）

> 合集的对照价值主要在**篇与篇之间**；本书亦有鲜明的篇内人物对照。只列维度、不下结论。

- **篇际对照A：马良（《神笔马良》）↔ 三娃（《牧童三娃》）**；可对照维度：主人公身份（穷孩子/牧童）、本领来源（苦练得神笔/花神赠种子）、帮助对象（村里穷苦人/全村羊群与乡亲）、面对财宝的态度（马良拒为财主画金元宝/三娃拒收金银珍珠玛瑙）、对手（财主与皇帝/蛇精）。
- **篇际对照B：反面人物的贪与傲——财主、皇帝（《神笔马良》）↔ 小驴（《大奖章》）**；可对照维度：性格缺点（贪婪/骄傲）、行为表现（逼画金元宝金山、乘船摇钱/赛前不练只顾画像拍照）、结局（沉海而死、笔画皆败/落后失冠、被劝改缺点）。
- **篇内对照C：小熊 ↔ 小驴（《大奖章》）**；可对照维度：赛前态度（早起苦练、扶助同伴/轻蔑苦练、只顾画像）、赛中表现（专心跑完/屡屡分心）、结果（夺大奖章/落后）、赛后（拉小猪同拍照/被劝勿骄傲）。
- **篇内对照D：马良 ↔ 皇帝（《神笔马良》，同持神笔）**；可对照维度：用笔目的（为穷人画生产工具/为自己画金山金砖摇钱树）、画笔结果（画什么成什么/金山成石堆、金砖成蟒蛇）。

## 档案使用提醒（事实层注意事项）

> 只记事实层陷阱，不做教学判断。

- **无页码陷阱**：本档案依据的电子版为纯文本、无固定页码，任何下游产物中出现“第X页”均属编造（片段1–4 已按纸质书核出页码，只许照搬这几处）；定位一律用「篇名 + 场景」，《大奖章》可附作者原分的“一~十五”节次。
