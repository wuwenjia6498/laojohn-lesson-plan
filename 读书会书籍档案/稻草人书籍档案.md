- 作者简介：叶圣陶（1894—1988），江苏苏州人，我国现代著名文学家、教育家、出版家，中国现代童话创作的拓荒者。早年长期从事小学教育，具备一线教学经验，深谙儿童心理与儿童阅读需求。作为文学研究会的重要成员，他秉持“为人生”的文学理念，于 20 世纪 20 年代应《儿童世界》约稿集中创作童话，《稻草人》童话集也是我国第一部原创白话童话集。除童话创作外，叶圣陶深耕语文教育，主持、编写多套民国及新中国中小学国文、语文教科书，诸多散文篇目长期入选小学语文教材，对我国现代语文教育体系影响深远。其童话既有浪漫诗意的幻想书写，也立足现实体察普通民众的生存境遇，形成现实与幻想交融的创作特质，这一特点也集中体现在这本童话集当中。（2026-10-10 用户人工补充，非电子版原有；下游作者介绍以此为准。）

- **★《稻草人》**：一个插在田里、不能移动半步的稻草人，一夜之间目睹三件他无力阻止的事。
  夜里看守稻田，为主人（一位接连死了丈夫和儿子、又遭两年水灾的老妇人）今年的好收成高兴 → 一只灰褐色小蛾飞来落在稻叶上，他摇扇子赶不走 → 小蛾下的子留在叶尖，他靠扇子拍打身体想警告主人，主人看不懂，走了 → 几天后肉虫吃光稻叶，只剩光秆儿 → 河边渔妇夜里拉罾捕鱼，舱里生病的孩子咳嗽喊渴，只能喝一碗河水 → 渔妇捕到一条七八寸长的鲫鱼，扔进稻草人脚边的木桶 → 鲫鱼向他求救，他只能摇头，鲫鱼误以为他冷漠而发怒 → 又一个女人走到河岸边，说丈夫要把她卖掉，纵身跳河，稻草人昏了过去 → 第二天早晨，农人发现河里有死尸，渔妇的鲫鱼死了，老妇人看见光秆儿放声大哭，大家跑过来时，看见稻草人倒在田地中间。

- **★《小白船》**：一男一女两个孩子乘白色小船，被大风吹到陌生的地方，靠答对三个问题回了家。
  两个孩子登上停在小溪边的小白船，唱《鱼儿歌》→ 忽起大风，船像飞鱼一样向前，女孩儿哭着想妈妈、小床、小黄猫 → 男孩儿落帆、用桨顶住岸边把船停下，两人上了一片没有人的旷野 → 吃野柿子，一只小白兔跑来，男孩儿掰柿子喂它 → 一个身子特别高、脸长得很可怕的人跑来，说小白兔是他的，夺走了兔子 → 他提出三个问题（鸟儿为什么要唱歌、花儿为什么香、为什么你们乘的是小白船），答对就送他们回去 → 两个孩子一一答出 → 那个人划着桨送他们回到原来停泊的地方。

- **★《一粒种子》**：一粒稀奇的种子在四个人手里两年也不发芽，落到农夫田里却开出了花。
  国王把种子种在白玉盆里，用御花园筛过的土、金缸滤过的水，两年不发芽，怒而扔进池子 → 渔夫捞起叫卖，富翁买去种在白金缸里、雇四个考试选出的花匠日夜看管，两年不发芽，怒而扔到墙外 → 商人在店门口拾到，种在店旁，一年不发芽，扔到街上 → 清道夫扫进垃圾车，兵士在军营旁拾到种下，一年多不发芽，用全身力气远远扔出 → 种子落进一片麦田，年轻的农夫用锄刨个坑埋了，照常耕、锄、浇 → 没几天钻出碧绿的嫩芽，长成小树，开出红瓣金蕊、比西瓜还大的花，浓郁的香味沾在身上永远不散 → 乡村的人都来看花，回去时脸上挂着微笑、满身香味。

- **《芳儿的梦》**：一个孩子为妈妈的生日想礼物，最后在梦里摘星星串成项链。
  姊姊用凤仙花扎成大花球要送给妈妈作生日礼物 → 芳儿想找一件更稀罕的，想遍了家里、街上、野外所有东西都不合适 → 他向月亮、向云请教，月亮和云指向身边的星星 → 他明白了，要送妈妈一条星星串成的项链，先跟姊姊跳绳，才附耳告诉她 → 夜里入梦：月亮姊姊牵他飞上天，他摘了几百颗星星，月亮姊姊给他丝绳串成项链 → 他捧着项链跑回家挂在妈妈脖子上，妈妈变成了仙女 → 手脚一动，梦醒了，妈妈正伏在他的枕头旁边，笑得跟梦里一模一样。

- **《梧桐子》**：一颗没等身体强壮就先飞走的梧桐子，独自经历了一段旅程。
  梧桐子们站在窗沿上唱歌，其中一颗想出去旅行，母亲说他身体还不够强壮、再等些时候 → 他不服，怂恿哥哥弟弟一起走，起风时只有他一个飞了出去 → 力乏坠地，落在田边，一个十五六岁栽菜秧的姑娘把他拾起带回家、放在窗前桌上、捻着玩 → 一只麻雀衔起他飞出窗外，半空里张嘴，他掉进又松又软的泥里 → 春雨春风后他醒来，换了一身绿衣，周围是小草，小草们叫他「领袖」 → 燕子当邮差替他送信，母亲与哥哥弟弟都回了信，各自报告落脚的地方 → 他心安了，笔挺地站在那儿，身子只顾往高里长。

- **★《鲤鱼的遇险》**：一群鲤鱼把鸬鹚当客人欢迎，结果被劫进木桶，最后靠自己的泪水活了下来。
  鲤鱼们住在清澈的小河里，好朋友是天鹅和鸳鸯，他们相信凡是太阳月亮星星照到的地方都跟自己的小河一样快活 → 一条小船来了，船舷上歇着十几头黑色鸬鹚，鲤鱼们把鸬鹚当作天鹅鸳鸯的同类，恳切地邀请他们下水 → 鸬鹚跳进水里，一口一条衔上船，吐进木桶 → 剩下的鲤鱼产生了新的信念：凡是太阳月亮星星照到的地方都跟自己的小河一样，是可怕的地狱 → 木桶里只有薄薄一片水，鲤鱼们半边身子干着，只能用一只眼睛朝天看；他们想出三个办法又各自被驳倒 → 他们一齐诅咒木板墙、诅咒强盗、诅咒这个世界 → 身上忽然潮润起来，一条聪明的小鲤鱼看出那是他们自己的泪水 → 泪水越流越多，浮起木桶、汆到河上，鲤鱼们一条条跳出木桶回了家 → 同伴与天鹅鸳鸯相见，又流了许多激动的泪水，所以小河永远没有干涸的日子。

- **《眼泪》**：一个人到处寻找「同情的眼泪」，走遍城市没找到，最后在乡下一个孩子身上找到了。
  他在草根底下、排水沟里、尘土中、风中到处寻找 → 快活人嘲笑他，并告诉他三处有眼泪的地方：车站码头的离别、摇篮和母亲怀里的婴儿、戏院舞台上的悲剧 → 他一一否掉，说自己要找的是同情的眼泪；快活人不信有这种眼泪，转身唱歌跳舞去了 → 他到马路边（骡子、赶车人、人力车夫）、到会场门口（打过大仗的人得胜归来受万人欢呼）、到大工厂（男工女工、对着食物发呆的女工）三处寻找，都没找到 → 他来到乡间，一个妇人在杨树下宰鸡，一个孩子冲出草屋，拉住她拿刀的右手，眼泪成串地掉下来 → 他捧起这些眼泪，说要把它们送还给所有的人，第一个要送给快活人。

- **★《画眉》**：一只养在黄金笼里、专为主人唱歌的画眉，飞出笼后见到三种人，从此为别的缘由而唱。
  画眉住在黄金鸟笼里，碧玉水罐、玛瑙食罐，阔公子哥儿亲自取山泉水、亲手拣谷子，只为爱听它唱歌 → 它接连不断地为哥儿、为哥儿的姊妹兄弟唱，始终不明白自己唱的有什么意义 → 一天哥儿忘了关笼门，它飞了出去，飞过草原、旷野、长江、黄河，落在一座城楼上 → 见街上有人拉着车飞跑，明白飞跑的人是为别人跑 → 落在楼房栏杆上，见楼上阔人吃饭、楼下厨子在油烟里忙碌，明白做菜的人是为别人做 → 落在胡同的屋顶上，见一个黑大汉逼一个十三四岁的女孩子一遍遍唱，明白她唱也是为别人 → 它决定不回鸟笼，住在乱树林子里，高兴飞就飞、高兴唱就唱 → 从此它的歌是为自己、为一切不幸的东西而唱，听见的人都忘了劳累和愁苦。

- **《花园外》**：一个孩子在花园门外站了许多天，三次在想象里走进花园，始终没走进去一步。
  各种华丽的车辆载着心里装满快乐的人奔向花园 → 长儿站在花园门口不止一天，母亲（老给人家洗衣服）听说他要逛花园，发怒说「你配逛花园？」 → 他飞奔进门，被看门的大汉抓住肩膀，要他买票，一推倒地，车夫们狂笑 → 他不敢再往里跑，天天在门外走来走去 → 一辆马车送来两个衣服闪光的孩子，一跳一跳地走进花园，没有人拦他们 → 长儿三次陷入想象：在树林里采果子、在花坛边拾香糖采花（要采一束插在母亲床头）、在亭子边指挥乐队 → 三次都被撞醒，「原来他还在花园门口，并没走进花园一步」 → 那两个孩子捧着糖果出来，撞了他，高傲地上了马车走了 → 他望着远去的马车，又回头看看花园的大门。

- **《祥哥的胡琴》**：父亲留下一把胡琴，他跟泉水、风、小鸟儿学会拉琴，在都市音乐厅被轰下台，回家拉给母亲听。
  父亲临死只把墙上的胡琴传给他 → 母亲反复对他说「你要像爸爸一样会拉」，满四岁时把胡琴交到他手里 → 他拉出锯木头一样的声音，打鱼老汉、洗衣老太太、街上孩子都讥笑他，他只顾一边拉一边走 → 他在山里遇见泉水、风、小鸟儿，三位各教他一种曲调，他把三种融成新的曲调 → 母亲说他拉得跟爸爸一样好了，让他带着胡琴拉给世界上所有的人听 → 都市音乐厅请他演奏，广告写着「田野的音乐家」；他一上台，听众嫌他的胡琴像乞丐的，人声盖过琴声，纷纷走出去洗耳朵 → 他提着胡琴走出音乐厅，回过头对那座大理石建筑微微一笑 → 回到小溪边的破屋子，母亲说「人家不要听你的，我要听」 → 从此琴声从破屋子传出，泉水、风、小鸟儿相和，田野成了没有围墙的大音乐厅，农夫、磨坊工人、小铁匠、死了儿子的老母亲都感到甜美。

- **《快乐的人》**：一个周身裹着一层透明幕的人，事事都觉得快乐，直到幕被刺破。

- **《含羞草》**：一棵与玫瑰做邻居的小草，三次为看见的事羞愧得合拢叶子。

  - 定位：《稻草人》· 星斗之夜，稻草人想起主人的身世
  - 内容概述：交代老妇人接连失去丈夫与儿子、又遭两年水灾的经历，以及稻草人为她今年的收成高兴。
  - 可引用原文（逐字，成段）：
    「她以前哪里笑过呢？八九年前，她的丈夫死了。她想起来就哭，眼睛到现在还红着；而且成了毛病，动不动就流泪。她只有一个儿子，娘儿两个费苦力种这块田，足足有三年，才勉强把她丈夫的丧葬费还清。没想到儿子紧接着得了白喉，也死了。她当时昏过去了，后来就落了个心痛的毛病，常常犯。这回只剩她一个人了，老了，没有气力，还得用力耕种，又挨了三年，总算把儿子的丧葬费也还清了。可是接着两年闹水，稻子都淹了，不是烂了就是发了芽。她的眼泪流得更多了，眼睛受了伤，看东西模糊，稍微远一点儿就看不见。她的脸上满是皱纹，倒像个风干的橘子，哪里会露出笑容来呢！」

- **片段3**
  - 定位：《稻草人》· 木桶边，鲫鱼求救与稻草人的回答（一轮对话）
  - 内容概述：鲫鱼向稻草人哀求，稻草人只能摇头；他心里说的那番话鲫鱼听不见，于是把摇头当成了冷漠。
  - 可引用原文（逐字，成段）：
    「鲫鱼向上的一只眼睛看见稻草人，就哀求说：“我的朋友，你暂且放下手里的扇子，救救我吧！我离开我的水里的家，就只有死了。好心的朋友，救救我吧！”
    听见鲫鱼这样恳切的哀求，稻草人非常心酸；但是他只能用力摇动自己的头。他的意思是说：“请你原谅我，我是个柔弱无能的人哪！我的心不但愿意救你，并且愿意救那个捕你的妇人和她的孩子，除了你、渔妇和孩子，还有一切受苦受难的。可是我跟树木一样，定在泥土里，连半步也不能自由移动，我怎么能照我的心愿去做呢！请你原谅我，我是个柔弱无能的人哪！”
    鲫鱼不懂稻草人的意思，只看见他连连摇头，愤怒就像火一般地烧起来了。」

- **片段4**
  - 定位：《稻草人》· 结尾，第二天早晨
  - 内容概述：三条线（投河的女人、渔妇与鲫鱼、老妇人与稻田）在同一个早晨收束，稻草人倒在田地中间。
  - 可引用原文（逐字，成段）：
    「第二天早晨，农人从河岸经过，发现河里有死尸，消息立刻传出去。附近的男男女女都跑来看。嘈杂的人声惊醒了酣睡的渔妇，她看那木桶里的鲫鱼，已经僵僵地死了。她提了木桶走回船舱；生病的孩子醒了，脸显得更瘦了，咳嗽也更加厉害。那老农妇也随着大家到河边来看；走过自己的稻田，顺便看了一眼。没想到才几天工夫，完了，稻叶稻穗都没有了，只留下直僵僵的光秆儿。她急得跺脚，捶胸，放声大哭。大家跑过来问她劝她，看见稻草人倒在田地中间。」

- **片段5**
  - 定位：《一粒种子》· 国王得到种子后的独白
  - 内容概述：国王说明他为什么看重这粒种子——因为「世界上就没有第二棵」。与后面富翁的独白句式相仿，可两两并读。
  - 可引用原文（逐字，成段）：
    「他说：“我的园里，什么花都有了。北方冰雪底下开的小白花，我派专使去移了来。南方热带，像盘子那样大的莲花也有人送来进贡。但是，这些都是世界上平常的花，我弄得到，人家也弄得到，又有什么稀奇？现在好了，有这样一粒种子，只有一粒。等它钻出芽来，开出花来，世界上就没有第二棵。这才显得我最尊贵，最有权力。哈！哈！哈！……”」

- **片段6**
  - 定位：《一粒种子》· 结尾，种子在农夫田里发芽开花
  - 内容概述：客观记录从嫩芽到开花的全过程，以及花的颜色、香味与乡村人来看花的情形。
  - 可引用原文（逐字，成段）：
    「没几天，在埋那粒种子的地方，碧绿的像小指那样粗的嫩芽钻出来了。又过几天，拔干，抽枝，一棵活像碧玉雕成的小树站在田地里了。梢上很快长了花苞，起初只有核桃那样大，长啊，长啊，像橘子了，像苹果了，像柚子了，终于长到西瓜那样大，开花了：瓣是红的，数不清有多少层，蕊是金黄的，数不清有多少根。由花瓣上，由花蕊里，一种新奇的浓郁的香味放出来，不管是谁，走近了，沾在身上就永远不散。
    年轻的农夫还是照常工作，在田地里来来往往。从这棵稀奇的花旁边走过的时候，他稍微站一会儿，看看花，看看叶，嘴边透出和平的微笑。
    乡村的人都来看这稀奇的花。回去的时候，脸上都挂着和平的微笑，满身都沾上了浓郁的香味。」

- **片段7**
  - 定位：《鲤鱼的遇险》· 出事前，鲤鱼们的第一种信念
  - 内容概述：鲤鱼们由自己小河的经验推出一条信念——凡是太阳、月亮和星星照到的地方都跟他们的小河一样快活，并把它唱成赞美的歌（此句为概述，逐字原文见下）。
  - 可引用原文（逐字，成段）：
    「大鲤鱼把他的信念告诉小鲤鱼，鲤鱼哥哥也这样告诉鲤鱼弟弟，鲤鱼姊姊也这样告诉鲤鱼妹妹。大家都说：“这话不错，咱们这条河的确如此。咱们这条河有太阳月亮星星照着，因而可以相信，凡是太阳月亮星星照到的地方，都跟咱们这条河一个样。世界多么快活呀！咱们真幸福，生活在这样快活的世界上。”」

- **片段8**
  - 定位：《鲤鱼的遇险》· 出事后，鲤鱼们的第二种信念
  - 内容概述：同样的推理方式、相反的结论——与片段7 是同一句式的镜像，两段并读即见变化。
  - 可引用原文（逐字，成段）：
    「大鲤鱼把这个新的信念告诉小鲤鱼，鲤鱼哥哥也这样告诉鲤鱼弟弟，鲤鱼姊姊也这样告诉鲤鱼妹妹。大家都说：“这话不错，咱们这条河现在变了。不然，咱们这样恳切地欢迎客人，怎么客人反倒把咱们的同伴劫走了呢！咱们这条河也变了，说不定别的地方早就变了，整个世界早就变了。咱们造了什么孽，碰上了这个可怕的时代！”」

- **片段9**
  - 定位：《鲤鱼的遇险》· 木桶里，小鲤鱼看出是自己的泪水
  - 内容概述：桶里的鲤鱼发现身上潮润起来，先猜是强盗悔悟、木板墙破了，最后由一条小鲤鱼指出那是他们自己的泪水。
  - 可引用原文（逐字，成段）：
    「不知过了多少时间，很奇怪，鲤鱼们的身上反而觉得潮润了点儿。难道那些强盗悔悟了，觉得自己做错了事，特地打了水来救助它们了？难道木板墙破了，外边的水渗进来了？大家正在议论纷纷，一条聪明的小鲤鱼看出来了。他说：“强盗怎么会来救助咱们呢？木板墙自己怎么会破呢？咱们还没干死，是咱们自己救了自己。大家没觉察吗，沾湿咱们的就是咱们自己的泪水呀！泪水从咱们的心底里，曲曲折折地流到咱们的眼睛里，一滴一滴流出来，千滴万滴，积在自己躺着的这个地方，沾湿了咱们的身子，挽救了咱们快要干死的性命！”」

- **片段10**
  - 定位：《画眉》· 结尾，画眉明白了唱歌的意义
  - 内容概述：画眉见过三种「为别人做」的人之后，决定不回鸟笼，并说明它此后为什么而唱。
  - 可引用原文（逐字，成段）：
    「他开始飞，往荒凉空旷的地方飞。晚上，他住在乱树林子里；白天，他高兴飞就飞，高兴唱就唱。饿了，就随便找些野草的果实吃。脏了，就到溪水里去洗个澡。四外不再有笼子的栏杆围住它，他愿意怎么样就怎么样。有时候，他也遇见一些不幸的东西，他伤心，他就用歌声来破除愁闷。说也奇怪，这么一唱，心里就痛快了，愁闷像清晨的烟雾，一下子就散了。要是不唱，就憋得难受。从这以后，他知道什么是歌唱的意义和趣味了。
    世界上，到处有不幸的东西，不幸的事儿——都市，山野，小屋子里，高楼大厦里。画眉有时候遇见，就免不了伤一回心，也就免不了很感慨地唱一回歌。他唱，是为自己，是为值得自己关心的一切不幸的东西，不幸的事儿。他永远不再为某一个人或某几个人的高兴而唱了。」
    ⚠ 本段第一句里「四外不再有笼子的栏杆围住**它**」的「它」，电子版如此，与同段其余各处的「他」不一致（原书用字或转换所致，**引用时照录、不要改**）。

- **片段11**
  - 定位：《小白船》· 旷野上，那个人提出三个问题（一轮完整问答）
  - 内容概述：三问三答的完整回合，是本篇的转折与收束点。
  - 可引用原文（逐字，成段）：
    「那个人说：“第一个问题，鸟儿为什么要唱歌？”
    “他们要唱给爱他们的人听。”女孩儿抢先回答。
    那个人点点头说：“算你答得不错。第二个问题：花儿为什么香？”
    男孩儿回答说：“香就是善，花是善的标志。”
    那个人拍手说：“有意思。第三个问题是，为什么你们乘的是小白船？”
    女孩儿举起右手，好像在课堂上回答老师似的：“因为我们纯洁，只有小白船才配让我们乘。”
    那个人大笑起来，他说：“好，我送你们回去。”」

- **片段12**
  - 定位：《稻草人》· 夜里，稻草人恨自己不能动
  - 内容概述：稻草人看见女人要寻死，想救而不能，心里连喊四句祈祷。
  - 可引用原文（逐字，成段）：
    「他恨自己，不该像树木一样定在泥土里，连半步也不能动。见死不救不是罪恶吗？自己就正在犯着这种罪恶。这真是比死还难受的痛苦哇！“天哪，快亮吧！农人们快起来吧！鸟儿快飞去报信吧！风快吹散她寻死的念头吧！”他这样默默地祈祷；可是四围还是黑洞洞的，也没有一丝儿声音。他心碎了，怕看又不能不看，就胆怯地死盯着站在河边的黑影。」

- （《花园外》· 三次想象的收束句）原文：「原来他还在花园门口，并没走进花园一步。」——**全篇原样重复三次**，是本篇最明显的重复句。
- （《花园外》· 结尾）原文：「长儿呆呆地望着远去的马车，又回过头来看看花园的大门。他似乎进去逛过了，但是仍旧不知道花园里的情景、虽然只隔着一道围墙，而且花园的大门还敞开着呢！」（⚠ 「情景」后电子版误作顿号「、」，应为逗号，属转换缺陷）
- （《祥哥的胡琴》· 音乐厅里的听众）原文：「隐隐约约听得他们在说：“从来没听过这样的曲子！”“乏味透了！”“不知从哪儿来的乞丐！”“是个骗子！冒充音乐家的骗子！”“把咱们的耳朵都弄脏了，非赶快回去洗一洗不可！”」
- （《祥哥的胡琴》· 母亲的话）原文：「人家不要听你的，我要听。你不要再出去了，在家里拉给我听吧。听了你的胡琴，我织起草席来更有劲了。」
- （《祥哥的胡琴》· 结尾）原文：「祥儿的胡琴带领大自然的一切奏起乐来，那美妙的声音，好像轻纱一般盖在人们的身上。又倦又乏的农夫恢复了精神，又困又累的磨坊工人又来了劲头，被火红的铁屑灼伤的小铁匠忘记了痛，死掉了儿子的老母亲得到了安慰……所有的人都感到甜美、感到舒适。他们异口同声地说：“感谢祥哥的胡琴。”而这祥哥的胡琴，正是大理石音乐厅里的听众们所不愿意听的。」
- （《快乐的人》· 那层幕）原文：「他周身包围着一层极薄的幕，这是天生的，没有谁给他围上，他自己也不曾围上。这层幕很不容易说明白。假若说像玻璃，透明得跟没有东西一样倒是像了，但是这层幕没有玻璃那么厚。假若说像蛋壳，把他裹得严严的倒是像了，但是蛋壳并不透明。总之，这层幕轻到没有重量，薄到没有质地，密到没有空隙，明到没有障蔽。他被这么一件东西包围着，但是他自己不知道被这么一件东西包围着。」
- （《快乐的人》· 结尾）原文：「有一天，大家传说他死了，害的什么病，都不大清楚。后来有人说：“他并不是害病死的。有一个恶神在地面游行，要使地面上没有一个快乐的人，忽然查出了他，就把他的透明无质的幕轻轻地刺破了。”」
- （《含羞草》· 小草的第一次回应）原文：「哪样舒服，哪样不舒服，我也不是不明白，只是，咱们来到这世界，难道就专为求舒服吗？我以为不见得，并且不应该。咱们不能离开同伴，自个儿过日子。并且，自己舒服了，看见旁边有好些同伴正在受罪，又想到就因为自己舒服了他们才受罪，舒服正是罪过，这时候舒服还能不变成烦恼吗？」
- （《含羞草》· 三次羞愧的同一句）原文：「一阵羞愧通过小草的全身，破梳子般的叶子立刻合拢来，并且垂下去，正像一个害羞的孩子，低着头，垂着胳膊。」——**全篇原样重复三次**（第二、三次前面多一个「又」字：「又是一阵羞愧通过小草的全身……」），三次后面接的原因各不相同。
- （《含羞草》· 全篇最后一句）原文：「这小草，人们叫他“含羞草”，可不知道他羞愧的是上边讲的一些事儿。」（原书此处用弯双引号包住「含羞草」三字）
- （《梧桐子》· 母亲的话）原文：「你应该出去旅行，哪有不让你去的道理呢？可是现在，你的身体还不够强壮，再等些时候吧！」
- （《芳儿的梦》· 芳儿想到礼物）原文：「姊姊送给妈妈一个花球，我送给妈妈一个星星串成的项链。明天，我要把星星项链亲手挂在妈妈的脖子上，让无数耀眼的光从妈妈身上射出来，不是非常美丽吗？」
- （《芳儿的梦》· 结尾）原文：「芳儿的手和腿一动，他的梦就醒了。妈妈正伏在他的枕头旁边，脸上的慈祥的笑，正跟芳儿在梦中看到的一个模样。」

## 五、重复出现的事物/场景

> 本书是合集，以下**既有「篇内重复」也有「跨篇复现的母题」**，已分别标明。跨篇母题只是同类事物在不同篇里各自出现，**不构成篇与篇之间的情节联系**。

- **【篇内重复】《一粒种子》的四段循环**：种子每到一处→被隆重（或潦草）种下→守候一年或两年→不发芽→主人说同一类的气话→被扔掉。四次循环之后才是农夫那一段。四个人分别是国王、富翁、商人、兵士。
- **【篇内重复】《花园外》的「原来他还在花园门口，并没走进花园一步」**：三次想象各自被撞醒，收束句一字不差地重复三次。
- **【篇内重复】《含羞草》的「一阵羞愧通过小草的全身……」**：三次羞愧用同一段描写（第二、三次前加「又」），后面接的原因各不相同（玫瑰以无聊为光荣／医生不给没钱的人治病／要建市场却不管人家有没有地方住）。
- **【篇内重复】《画眉》的「他很烦闷，想起一个人当了别人的……」**：三次见闻后各有一段近乎相同的感慨，只换中间的比喻（两条腿／做菜机器／乐器）。
- **【篇内重复】《鲤鱼的遇险》的「大鲤鱼把……告诉小鲤鱼，鲤鱼哥哥也这样告诉鲤鱼弟弟……」（此处为句式示意、非完整引文，逐字原文见片段7、8）**：前后两种相反的信念，用同一段传播句式各说一次（见片段7、片段8）。
- **【篇内重复】《祥哥的胡琴》的学艺三段**：泉水、风、小鸟儿三位各教一次，每次都是「你听着我的曲调，把胡琴和着我的调子拉吧」→ 合成一体 → 分不出哪是谁的 → 教他的一方告辞。
- **【跨篇母题】眼泪 / 哭**：《稻草人》稻草人一夜哭了几次；《鲤鱼的遇险》鲤鱼的泪水救了自己；《眼泪》全篇在找「同情的眼泪」；《含羞草》蜜蜂「哭丧着脸」飞回；《花园外》长儿未哭。（各篇中「眼泪」的所指并不相同，**用时须分清是哪一篇的哪一种**。）
- **【跨篇母题】被固定、不能动**：《稻草人》定在泥土里连半步也不能动；《鲤鱼的遇险》鲤鱼在木桶里「身子都动弹不了」；《画眉》画眉被关在笼中（后来飞出）；《花园外》长儿被挡在门外；《梧桐子》落地后「一动也不能动」。
- **【跨篇母题】为别人做工、成果归别人**：《画眉》拉车的人、厨房的人、卖唱的女孩子；《快乐的人》采桑人（当了棉衣才凑齐买桑叶的钱）、纺纱厂女工；《花园外》给人家洗衣服的母亲；《祥哥的胡琴》被逼着唱／拉的对照。
- **【跨篇母题】富与穷的对面而立**：《花园外》车里的人 ↔ 门外的长儿；《画眉》楼上吃饭的人 ↔ 楼下做菜的人；《快乐的人》桑林主人 ↔ 采桑人；《含羞草》玫瑰 ↔ 小草、要诊费的医生 ↔ 没钱的蜜蜂。

## 六、可作横向对照的内容（篇际对照为主）

> 只列可对照的对象与维度，**不下结论**。涉及的原文多数已在第四节备齐。

- 对照组：**《稻草人》稻草人 ↔ 《眼泪》寻找眼泪的人**；可对照维度：看见了什么 / 能不能动 / 结果找没找到（或救没救成） / 篇末的处境。
- 对照组：**《快乐的人》他 ↔ 《眼泪》寻找眼泪的人**；可对照维度：走过的地方（都路过了工厂与街市） / 看见的是什么 / 隔着什么（一层幕 ↔ 无） / 对同一片景象的两种描述（桑林、纺纱厂在《快乐的人》里被写成诗，在《眼泪》里被写成困苦）。
- 对照组：**《一粒种子》国王 / 富翁 / 商人 / 兵士 ↔ 年轻的农夫**（篇内四对一）；可对照维度：为什么要这粒种子 / 怎么照料（白玉盆·筛过的土 ↔ 锄一个坑） / 守候期间做什么（专门等 ↔ 照常工作） / 结果。
- 对照组：**《鲤鱼的遇险》出事前的信念 ↔ 出事后的信念**（篇内前后）；可对照维度：推理的起点（都是自己的小河） / 推出的结论 / 传播的方式（两段句式几乎相同） / 最后靠什么脱险。
- 对照组：**《画眉》笼中的唱 ↔ 树林里的唱**（篇内前后）；可对照维度：为谁唱 / 唱的时候心里明不明白 / 听的人是谁 / 唱完之后的感觉。
- 对照组：**《画眉》画眉 ↔ 《祥哥的胡琴》祥儿**；可对照维度：为谁演奏 / 听众是什么人 / 被听众怎么对待 / 最后在哪里演奏、听众换成了谁。
- 对照组：**《花园外》长儿 ↔ 坐马车来的两个孩子**（篇内）；可对照维度：怎么到花园门口 / 进不进得去 / 门口的大汉如何对待 / 出来时手里有什么。
- 对照组：**《含羞草》玫瑰花苞 ↔ 小草**；可对照维度：想要什么 / 用什么标准判断好坏（舒服 / 得奖 ↔ 公平 / 同伴） / 结局（被剪走 ↔ 被买走摆在窄巷里）。
- 对照组：**《小白船》《芳儿的梦》 ↔ 《稻草人》《花园外》**（明亮想象类 ↔ 现实苦难类）；可对照维度：故事发生在哪里 / 主人公遇到困难时有没有人帮 / 结尾停在什么情形上。（⚠ 只列维度，**不得据此断言作者写作前后期的转变**——电子版无任何这方面的说明。）
- 对照组：**《梧桐子》那颗先飞走的 ↔ 他的哥哥弟弟们**（篇内，靠回信呈现）；可对照维度：什么时候离开 / 落在哪里 / 现在过得怎么样。

## 七、贯穿全书的变化线索

降级为**单篇候选**（供下游在单篇范围内取材，均已在第四节备有原文）：

- **单篇反转 ·《鲤鱼的遇险》**：安逸（第一种信念）→ 鸬鹚被当客人欢迎 → 同伴被劫走 → 第二种信念（世界是地狱）→ 木桶里三个办法全被驳倒 → 一齐诅咒 → 发现是自己的泪水 → 泪水浮起木桶 → 跳出回家。
- **单篇故事山 ·《一粒种子》**：国王（两年）→ 富翁（两年）→ 商人（一年）→ 兵士（一年多）→ 农夫（没几天发芽、开花）。
- **单篇转变 ·《画眉》「为谁唱」的三个节点**：笼中为哥儿唱（不明白有什么意义）→ 飞出后见三种人、三次感慨地唱 → 决定不回笼，为自己、为一切不幸的东西而唱。

- **单篇三段 ·《花园外》三次想象**：树林采果 → 花坛拾糖采花 → 亭边指挥乐队，每次都以同一句收束。

## 档案使用提醒（事实层注意事项）

> 下游看不到原书，本节是本档案通读全文时发现的、**最容易用错的事实层陷阱**。只记事实，不做教学判断。

1. **不得当长篇梳理（头号陷阱）**。本书是**十二篇独立短篇的合集**，**没有主线、没有跨篇复现的角色**。任何下游产物**不得**做「全书情节主线梳理 / 全书成长曲线 / 全书人物关系总图 / 按时间顺序串起全书事件」。这类工具只能落到**单篇**（候选见第七节）。同一个「稻草人」只属于第一篇，**不是全书的主角**。

2. **无页码**。本电子版为流式 docx，**无固定页码**；本档案任何定位一律「篇名 ＋ 场景」。下游产物中出现「第X页」均属编造。**另有四幅插图上印着原纸质版的页码（9 / 35 / 69 / 124），那是扫描件带进来的，同样不可当作定位依据。**

3. **署名两种、同一人**：前十一篇篇末署「叶绍钧」，《含羞草》署「叶圣陶」——**叶绍钧是本名、叶圣陶是笔名，同一人**。对外物料统一写「叶圣陶」；**若要引用篇末注记，须照录该篇实际的署名，不要统一改写**。

4. **两篇有原题**：《画眉》原题《画眉鸟》、《花园外》原题《花园之外》（见第二节表）。**对外一律用现题**；提到原题时须注明是「原题」，不可混为两篇作品。

5. **「祥哥」只在两处出现**。《祥哥的胡琴》正文**通篇称「祥儿」**，「祥哥」仅见于**篇名**与**全篇最后一句**（「感谢祥哥的胡琴」）。下游写师话、参考答案、题干时**不得说「祥哥说……」「祥哥走上台」**——那是原文没有的说法。

6. **《含羞草》里主角一直叫「小草」**。全篇称「小草」，「含羞草」三个字**只在最后一句才出现**（「这小草，人们叫他“含羞草”」）。若在篇中提前用「含羞草」称呼他，会破坏原文的收束方式。

7. **三个无名主角**。《快乐的人》主角全篇只称「他」；《眼泪》两个人物只有「（寻找眼泪的）他」与「快活人」；《稻草人》里的老妇人、渔妇、投河的女人**都没有名字**。下游**不得给他们起名字**，也不得把「快活人」写成人名以外的身份（原文没交代他是谁）。

8. **⚠ 电子版有三处「串行错乱」，绝不可逐字引用**（文字被打乱后拼接，读起来不通）：
   - 《梧桐子》· 从麻雀嘴里掉下来那一段：「……落到地上一定没有命了。我的母他还没想完，身子已经着地了，他吓得……」
   - 《快乐的人》· 纺纱厂里那句：「……那她们只做那最轻松的工作，些妇女也十分幸福，管理机器。」
   - 《含羞草》· 玫瑰讲「舒服是生活的尺度」整段：「……说完，怎么能懂得什她又想，像小草这么卑贱的东西，她就用教师的么叫舒服……」
   **这三处只可概述、不可引用**；本档案第四节与引文池**均已避开**。若详案要用这几处的意思，须回纸质版核对后再补进本档案。

9. **⚠ 电子版另有转换错字，引用前须核**（本档案第四节所选片段已避开这些位置）：
   - 《祥哥的胡琴》：「只**颜**演奏」（应为「只顾」）、「**明关**再见吧」（应为「明天」）、「泉水**睁睁**」（疑为拟声词之误，**存疑，不要引用这半句**）。
   - 《花园外》：「**她**在树荫下奔来奔去」（长儿是男孩，此处「她」为误字）、「**失树**一棵挨着一棵」（疑为「大树」）、「耍**粑**戏」（应为「把戏」）、「不知道花园里的情景**、**虽然……」（顿号应为逗号）。
   - 《小白船》：「伸手就把小白**免**夺走了」（应为「兔」）。
   - 《鲤鱼的遇险》：「才**钴**进河底的烂泥里」（应为「钻」）。
   - 《快乐的人》：「出了大门，两个人互相看看**、**脸上现出狡**绘**的笑容」（顿号应为逗号；「狡绘」应为「狡狯」）。
   - **规则**：这类明显错字，引用时**按正字处理并在旁注明**，或干脆避开该句；**不要把错字原样投屏给学生**。

10. **⚠ 正文里窜进两行盗版水印**：《眼泪》与《画眉》之间夹着孤零零的一行「100」和一行「更多资料+微信GDD52580领取」。**那不是正文内容**，任何产物中都不得出现。

11. **标点形态**：电子版的感叹号、问号**多为半角**（`!` `?`），个别对话的收尾引号误作半角直引号。本档案引用时**只订正标点形态（统一为全角与弯引号）、字词一律未动**；第四节部分片段为避免嵌套，把内层对话引号排作 `“”`，**并已逐条注明——下游投屏或朗读时须恢复原书的双引号形态，字词不得改动**。

12. **同一句式在篇内重复多次，用时须分清是第几次**：《一粒种子》的两组气话（国王＝富翁一句、商人＝兵士另一句）、《画眉》的三段感慨（只换「两条腿／做菜机器／乐器」）、《含羞草》的三次羞愧（第二、三次多一个「又」字）、《花园外》三次「原来他还在花园门口，并没走进花园一步」、《鲤鱼的遇险》前后两种信念。**混用版本会造成看似逐字、实则拼错的引文。**

13. **书内／书外边界**：第二节的作期与首刊注记虽印在电子版正文里，但属于**编者注记、不是童话正文**——可以照录、须注明出处，**但不得被冠以「书里写道」当作故事原文引用**。第一、九节里未填的出版信息与拓展资源，**一律留待人工回填，禁止凭记忆补**。

14. **等级与课时已确认**：本档案按 **L3（三年级、四课时）** 建档，2026-08-18 经用户拍板确认。（建档当时是按电子书所在目录名「快乐读书吧用书」推定的，此项已落定。）
