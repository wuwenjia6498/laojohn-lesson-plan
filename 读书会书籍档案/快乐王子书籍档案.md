## 二、作者&背景

> 本节全部为**书外信息**，不得进入第四节「可引用原文」栏，不得被冠以“书里写道”。

- 作者简介 【书外·来源：本书译本序，苏福忠撰】
  - 王尔德一八五四年生于爱尔兰首府都柏林；父亲威廉·王尔德是外科医生，母亲是作家、伦敦诗歌戏剧沙龙主持人，笔名“斯珀兰扎”。
  - 早年就读都柏林三一学院、牛津马格达兰学院，以诗《拉凡纳》获纽迪盖特奖。
  - 一八八一年出版第一部集子《诗集》；一八八四年与康斯坦丝·洛伊德结婚，婚后生有二子。
  - 一八九一年发表唯一长篇小说《道连·格雷的画像》；戏剧有《温德米尔夫人的扇子》（1892）、《一个无关紧要的女人》（1893）、《理想丈夫》（1895）、《认真的重要》（1895）、《莎乐美》（1895）。
  - 因同性恋之罪被判刑两年；出狱后移居法国，用“塞巴斯蒂安·梅尔莫斯”之名写作，作长诗《雷丁监狱之歌》，狱中书信结集为《从深处》（1905）。四十六岁在巴黎去世。
- 写作缘起 【书外·来源：本书译本序，苏福忠撰】
  - 序中称“正是由于对儿子的爱，王尔德曾致力于儿童文学创作，其中主要是童话故事”。
  - 第一部童话集《快乐王子童话集》一八八八年出版，收五篇；第二部《石榴之家》一八九一年出版，收四篇，**是题送他妻子的**。
- 译序要点 【书外·来源：本书译本序，苏福忠撰】
  - 序中指出王尔德童话除一般童话的惩恶扬善主题外，还以唯美主义观点探讨“幸福”“心之美”等命题。
  - 序中亦提到王尔德爱写冷僻植物名，“给孩子们和读者带来了许多冷僻的生字，犯了童话创作的大忌”。
  - ⚠ 译序为**译者/序者的评论与解读，不是本书正文事实**，下游若引用须标为序言观点，不得当作童话正文情节。

### 全书事件序列（按篇独立列出；篇与篇之间无先后因果）

**1. 快乐王子**
王子像立于高圆柱上，满身贴金叶、蓝宝石为眼、剑柄嵌红宝石，受市民称赞 → 一只小燕子因恋着芦苇误了南飞，夜宿王子脚下 → 被王子的泪惊动，得知王子生前住“无愁宫”、死后立高处才看见城中苦难 → 燕子第一次送出剑柄红宝石，给病孩与做绣活的裁缝母亲 → 第二次取下王子一只蓝宝石眼睛，送给顶楼写戏的年轻人 → 第三次取下另一只眼睛，送给卖火柴的女孩 → 王子失明，燕子决定永远留下，替王子巡城并转述所见 → 燕子把金叶一片片啄下分送穷人，王子变得灰暗难看 → 严寒到来，燕子吻别王子后死在他脚下，王子的铅心裂成两半 → 市长与市参议员嫌像难看，拆像熔化，为铸谁的像争吵不休 → 铅心熔不掉，与死鸟一同被扔进垃圾堆 → 上帝命天使取来“这个城里两件最珍贵的东西”，天使取回铅心与死鸟。

**2. 夜莺与蔷薇**
年轻学生因园中没有红蔷薇而痛哭，教授的女儿说过只要送一朵红蔷薇就同他跳舞 → 橡树上的夜莺听见，认定他是“忠实的情人” → 夜莺先后求白蔷薇树、黄蔷薇树、红蔷薇树；红蔷薇树说今年不会再开花，唯一办法是夜莺用胸脯抵住刺、彻夜歌唱、以心血染红花 → 夜莺权衡后决定赴死，先向学生唱最后一支歌，学生听不懂，只记在笔记本上评价她“没有一点真诚” → 月出后夜莺整夜抵刺歌唱，蔷薇由白转红；刺入心时唱“由死来完成的爱”，花变深红 → 夜莺死在草丛中，心上还带着蔷薇刺 → 正午学生发现红蔷薇，摘去送给教授的女儿 → 少女嫌它配不上衣服，说御前大臣的侄儿送了她珠宝 → 学生怒斥她忘恩负义，把花丢到街上被车轮碾过 → 学生断言爱情不实际，回屋去读一本满是灰尘的大书。

**3. 自私的巨人**
孩子们放学后总在巨人花园里玩 → 巨人拜访康华尔的吃人鬼七年后归来，赶走孩子，筑高墙挂“不准擅入，违者重惩”的布告牌 → 从此园中只有冬天、北风、雹、霜、雪，春天与秋天都不来 → 一天早晨巨人听见梅花雀歌唱，看见孩子们从墙洞爬进来，树都开了花，只有最远的角落里一个太小的孩子够不着树枝、仍是冬天 → 巨人心软，抱起那个孩子放上树枝，树立刻开花；孩子抱住他的颈项亲吻他 → 巨人砍倒围墙，把花园给了孩子们 → 那个被他抱上树的孩子此后再没出现，巨人年年想念 → 多年后巨人老了，一个冬天早晨看见最远角落里一棵开满白花的树下站着那个孩子，孩子手脚有钉痕 → 孩子说“这是爱的伤痕”，并说要带巨人去他的园子——天堂 → 当天下午孩子们看见巨人躺在树下死了，满身盖着白花。

**4. 忠实的朋友**（框架故事：绿梅花雀讲给老河鼠听）
老河鼠对母鸭大谈友谊，梅花雀便讲一个“忠实的朋友”的故事 → 小汉斯独居茅屋、以卖花为生，最好的朋友是有钱的磨面师大修 → 磨面师常摘走汉斯园中的花果，口口声声“真朋友应当共享一切”，却从未给过汉斯东西 → 冬天汉斯挨饿受冻，磨面师以“人在困难时候应该让他安静”为由从不探望；他的小儿子提议请汉斯来家里，被他斥责 → 开春磨面师下山探望，得知汉斯为过冬卖掉了小车，便许诺送他一辆破小车 → 磨面师随即以此为由，索走汉斯的木板、装满一大篮花、要他扛面粉去赶集、补谷仓顶、赶羊上山 → 汉斯的花两天没浇水，仍不敢拒绝 → 暴风雨之夜磨面师来敲门，要汉斯替他去请医生，却不肯借出新灯笼 → 汉斯摸黑走了三小时找到医生，回程迷路，淹死在沼地深洞里 → 葬礼上磨面师自称最好的朋友、走在队伍最前头，事后只惋惜那辆小车“破烂得没有办法，我又不能拿它卖钱” → 河鼠听完得知故事有教训，大怒地“呸”了一声回洞去；母鸭与梅花雀议论收场。

**5. 了不起的火箭**
王子迎娶俄国公主，全国庆祝，婚礼与宴会后定于午夜放烟火 → 御花园高台上众烟火交谈：小爆竹、罗马花筒、轮转炮、蓝色烟火、炮仗、火球各自发言 → 一个高个子火箭以咳嗽引起注意，自夸出身名门、极其敏感、富有同情心 → 他假想王子夫妇日后可能溺死独生子，为此落泪，被众烟火斥为“骗人” → 眼泪把火药浸湿，午夜放烟火时他独独放不响，别的烟火全部成功 → 他自认是被留到“举行大典”时才用 → 次日工人把他当“坏火箭”丢过墙，落进阴沟烂泥 → 他先后对小蛙、蜻蜓、大白鸭高谈阔论，都被冷落 → 两个男孩把他当“旧棍子”捡去烧火煮水 → 他终于被点着、飞上天、爆炸，但男孩已睡熟，“可是没有一个人看见他”“可是没有人听见他” → 剩下的棍子落在一只鹅背上；他说完“我知道我要大出风头的”就灭了。

**6. 少年国王**
加冕日前夜，十六岁的少年国王独坐房中 → 交代身世：他是老王独女与身份低微者所生，出生一周即被抱走交给牧羊人夫妇抚养，生母产后不到一小时死去，老王临终认他为继承人 → 他被指定为继承人后表现出强烈的爱美之情，四处搜求珍宝，最费心思的是加冕的金线王袍、红宝石王冠、珍珠节杖 → 第一个梦：顶楼织坊里饥饿的织工正为他织加冕王袍，织工说“我们都戴着链子，虽然链子是肉眼看不见的” → 第二个梦：奴隶船上潜水少年一次次下海取珠，最后一次带回最美的珍珠后耳鼻流血而死，船长说这颗珠子“应当用来装饰小王的节杖” → 第三个梦：干河床上众人为国王王冠上的红宝石采矿，死与贪欲争执，疟疾、热病、瘟疫先后降下，人全死了；香客让他照镜子，镜中是他自己 → 醒后他拒穿王袍、拒戴王冠，改穿牧羊人的皮衣，折荆棘做冠，手拿牧人杖 → 贵族嘲笑，百姓喊他“国王的弄臣”，一个男人反问他能有什么补救办法，说富人这个“阔兄长的名字叫该隐” → 老主教劝他回宫，说世上苦难非一人能担 → 他在基督像前跪祷；贵族持剑闯入要杀他 → 阳光穿过彩色玻璃窗在他四周织成金袍，枯杖开出白百合，荆棘开出红玫瑰 → 百姓跪拜，主教说“比我伟大的已经给你加冕了”，跪倒在他面前 → 他穿过人丛回宫，没有一个人敢看他的脸。

**7. 西班牙公主的生日**
西班牙公主十二岁生日，国王准她邀请玩伴入宫同乐 → 国王在窗内回忆亡妻：王后从法国嫁来后憔悴而死，遗体经香料保存放在黑大理石礼拜堂；国王每月去跪唤“我的王后！我的王后！” → 公主见窗帘垂下、父亲走开，便去看生日游艺 → 依次上演：男孩化装的假斗牛戏、法国走绳师、意大利傀儡戏《莎福尼士巴》、非洲变戏法人、跳舞班男孩的“圣母舞”、吉卜赛人的弦琴与熊猴表演 → 最有趣的是小矮人的跳舞：他驼背拐脚、大头，前一天刚被两个贵族在软木树林里发现带回宫，他的父亲是烧炭夫 → 他完全不知道自己难看，跳完向每个人鞠躬 → 公主把头上的白蔷薇丢给他，他当真了，跪下按花在唇上 → 公主吩咐他午睡后再跳一次，他跑进花园狂喜 → 花讥笑他丑陋，日晷与孔雀附和；鸟和蜥蜴喜欢他，因为他冬天分黑面包给鸟吃 → 他幻想带公主回树林，细数林中万物 → 他进宫寻找公主，穿过大厅、御殿等房间 → 在最亮的一间屋子里看见“一个小小的人形”，几番试探后发现那是镜子，怪物就是他自己 → 他绝望大叫，撕碎白蔷薇，倒地痛哭 → 公主带玩伴进来，以为他在演戏，命他起来跳舞；唐·彼德洛用绣花手套打他的脸颊 → 御前大臣按住他的心，说“因为他的心碎了” → 公主皱眉说：“以后凡是来陪我玩的人都要没有心的才成”，跑到花园里去。

**8. 打鱼人和他的灵魂**
年轻打鱼人网中捞起熟睡的小人鱼，以“随唤随唱”为条件放她走 → 他夜夜唤她唱歌，渔获满船，却渐渐荒废本业 → 他求娶人鱼，人鱼说他有人的灵魂，必须送走灵魂才能相爱 → 神父斥其疯狂，说灵魂比全世界的黄金都贵重；商人说灵魂“连半个破银元也不值” → 他去找海湾洞窟里的年轻女巫，女巫索价是“跟我一块儿跳舞” → 月圆之夜山顶女巫聚会，出现一个穿黑天鹅绒衣服的男人；打鱼人无意中画十字唤圣名，众女巫尖叫逃散 → 他扣住女巫逼问，得到绿蛇皮刀柄小刀与方法：背对月亮，从双脚四周切开影子——影子就是灵魂的身体 → 灵魂求他给一颗心同行，他拒绝：“我的心是属于我的爱人的” → 灵魂被切离，说每年回来唤他一次；打鱼人潜入海底与人鱼同住 → 第一年灵魂归来，讲东方之行与“智慧镜”，劝他换回智慧；打鱼人答“爱比‘智慧’好” → 第二年灵魂归来，讲南方之行与皇帝的“财富指环”；打鱼人答“爱比‘财富’好” → 第三年灵魂讲一个戴面网、赤脚跳舞的少女，只有一天路程；打鱼人想起人鱼没有脚不能跳舞，上岸让灵魂回到体内 → 灵魂领他一路作恶：偷银杯、打小孩、打晕收留他的商人抢走九包金子 → 他质问，灵魂答“你把我送到世界上去的时候，你并没有给我一颗心” → 他要再切走灵魂，灵魂说一个人一辈子只能送走灵魂一次，收回后必须永远留住 → 他缚手封口回到小海湾，日日唤人鱼，两年不见踪影，灵魂先以恶、再以善引诱，均无效 → 海上响起人鱼族的哀叫，小人鱼的尸体被浪送到他脚下 → 他抱尸痛哭，潮水逼近，他的心因充满爱而碎裂，灵魂由此得以进入，海浪盖住了他 → 神父拒绝祝福，命人把两具尸体埋在漂洗工地角上、不做记号 → 三年后祭日，祭坛上出现无人识得的奇异白花，神父讲不出上帝的愤怒，讲的却是“那个叫做‘爱’的上帝” → 次日清晨神父祝福了海与世间万物；但漂洗工地的角上从此寸草不生，人鱼也不再来这个海湾。

**9. 星孩**
寒夜里两个穷樵夫归家，见一颗星落下 → 他们在柳树丛后找到的不是金子，而是裹在绣星金线斗篷里的婴孩 → 一个樵夫主张丢下，另一个抱回家；妻子起初生气，后落泪收下；斗篷与琥珀项链收进柜子 → 星孩与樵夫的孩子一同长大，容貌出众，却骄傲残酷：轻视同伴、向穷人和残疾人丢石头、刺瞎鼹鼠眼睛、剪梅花雀翅膀 → 一个讨饭女人进村，星孩带头丢石子；樵夫说出十年前拾到他的经过，女人晕倒 → 女人凭金线斗篷与琥珀项链认出他是自己被强盗偷走的儿子 → 星孩当众羞辱她，说宁肯亲毒蛇蟾蜍也不亲她，女人哭着走进树林 → 星孩容貌立刻变成蟾蜍脸、毒蛇鳞；同伴把他赶走 → 他悔悟出发寻母；鼹鼠、梅花雀、松鼠各以他从前的伤害回绝 → 三年走遍全世界不得消息 → 他在一座城门被兵士驱赶，一个人以“一碗甜酒的价钱”把他当奴隶卖给老魔术家 → 魔术家关他在地牢，命他三天分别取回白金、黄金、红金，否则受罚 → 他救出陷阱里的小兔，兔子三次带他找到三块金钱 → 三次都在城门口把钱给了乞讨的大麻风病人，三次受罚（第一次挨打，第二次挨打上链，第三次被威胁处死） → 第三次回城时守兵躬身行礼，众人欢呼他漂亮；僧侣与大臣迎他为国王之子 → 他从盾牌里看见自己容貌已恢复 → 他不肯受冠，仍要去寻母；转身看见讨饭女人与大麻风病人 → 他跪下亲母亲脚上的伤口、恳求饶恕，两人都不作声；他再求，两人同说“起来” → 他站起，看见他们原来是国王和王后：大麻风病人是父亲，讨饭女人是母亲 → 他即位，公正仁慈，赶走魔术家，厚赏樵夫一家 → **但他“只活了三年。他死后继承他的却是一个很坏的国王”**。

  - 定位：《快乐王子》· 燕子夜宿像下，被泪惊动后王子的自述
  - 内容概述：燕子问王子为何哭泣，王子说出生前住在无愁宫、高墙隔断墙外景象，死后立在高处才看见城中的丑恶与穷苦。
  - 可引用原文（逐字，成段）：
    “从前我活着，有一颗人心的时候，”王子慢慢地答道，“我并不知道眼泪是什么东西，因为我那个时候住在无愁宫里，悲哀是不能够进去的。白天有人陪我在花园里玩，晚上我又在大厅里领头跳舞。花园的四周围着一道高墙，我就从没有想到去问人墙外是什么样的景象，我眼前的一切都是非常美的。我的臣子都称我做快乐王子，不错，如果欢娱可以算作快乐，我就的确是快乐的了。我这样地活着，我也这样地死去。我死了，他们就把我放在这儿，而且立得这么高，让我看得见我这个城市的一切丑恶和穷苦，我的心虽然是铅做的，我也忍不住哭了。”

  - 内容概述：像被拆下熔化，市长与市参议员为该铸谁的像争吵；熔不掉的铅心与死燕子一同被扔在垃圾堆上，上帝命天使取来城中两件最珍贵的东西。

- （《少年国王》·百姓中一人的反驳）原文：“皇上，您不知道穷人的生活是从富人的奢华中来的吗？我们就是靠您的阔绰来活命的，您的恶习给我们面包吃。给一个严厉的主子做工固然苦，可是找不到一个要我们做工的主子却更苦。您以为乌鸦会养活我们吗？您对这些事又有什么补救办法？您会对买东西的人说：‘你得出这么多钱买下’，又对卖的人说：‘你得照这样价钱卖出’吗？我不相信。所以您还是回到您的宫里去，穿上您的紫袍、细衣吧。您跟我们同我们的痛苦有什么关系呢？”
- （《少年国王》·该隐）原文：“富人和穷人不是弟兄吗？”少年国王问道。“是的，”那个人答道，“那个阔兄长的名字叫该隐[10]。”
  - （[10] 为原书脚注号，注文：「该隐杀死他的兄弟亚伯，事见《圣经·旧约》。」）
- （《少年国王》·结尾加冕）原文：百姓们敬畏地跪了下来，贵族们把宝剑插回剑鞘，向他行着敬礼，主教脸色发白，他的手颤抖着。“比我伟大的已经给你加冕了。”他大声说，跪倒在国王的面前。
- （《西班牙公主的生日》·小矮人不知自己丑）原文：关于矮人的最有趣的事也许就是他一点也不觉得自己难看。的确他好像很快乐，而且很有精神似的，孩子们笑的时候，他也笑，而且笑得跟他们中间任何人一样随便，一样快乐
- （《西班牙公主的生日》·花与鸟的两种态度）原文：“他实在太难看了，不应当让他到我们在的任何地方来玩，”郁金香嚷道。／可是鸟儿却喜欢他。他们常常看见他在林子里玩，有时像妖精似地追逐在空中旋转的落叶跳舞，有时蹲在一棵老橡树的洞孔里，把他的硬壳果分给松鼠们吃。他们一点儿也不介意他的丑陋。
- （《西班牙公主的生日》·蜥蜴的评语）原文：他们大声说：“不是每个人都可以像蜥蜴那样地漂亮。那是过分的要求了。并且说起来虽然有点不近情理，但事实却是这样，要是我们闭上眼睛不看他，他倒也并不太难看。”
- （《打鱼人和他的灵魂》·神父论灵魂）原文：世间再没有比人的灵魂更宝贵的东西，任何地上的东西都不能跟它相比。把全世界的黄金集在一块儿，才有它那样的价值，它比国王们的红宝石贵重得多。
- （《打鱼人和他的灵魂》·商人论灵魂）原文：人的灵魂对我们有什么用处？它连半个破银元也不值。
- （《打鱼人和他的灵魂》·两种估价的并置）原文：“这是一件多么奇怪的事！神父对我说，灵魂的价值比得上全世界的黄金，商人们却说它不值半边破银元。”
- （《打鱼人和他的灵魂》·影子即灵魂的身体）原文：“人们所谓身体的影子，并不是身体的影子，却是灵魂的身体。你把背朝着月亮站在海滩上，从你双脚的四周切开你的影子，那就是说你的灵魂的身体，你再叫你的灵魂离开你，它就会照你的话做的。”
- （《打鱼人和他的灵魂》·三次拒绝的定式）原文：可是年轻的打鱼人笑了。“爱比‘智慧’好，”他大声说，“而且小鱼人爱我。”／“不，世界上并没有比‘智慧’更好的东西，”灵魂说。／“爱更好，”年轻的打鱼人答道
- （《打鱼人和他的灵魂》·灵魂不可再送走）原文：“那个女巫教给你的魔法再也不灵了。因为我不能离开你，你也不能把我赶走。一个人一辈子只可以把他灵魂送走一次，可是谁把他的灵魂送走以后又收了回来，就得永远留住它，这是他的惩罚，也是他的报酬。”
- （《打鱼人和他的灵魂》·临终的告白）原文：爱比‘智慧’更好，比‘财富’更宝贵，比人间女儿们的脚更漂亮。火不能烧毁它，水不能淹没它。
- （《打鱼人和他的灵魂》·结尾的花与不毛地）原文：他也祝福了牧神和森林中跳舞的小东西，以及从树叶缝中偷偷张望的亮眼睛的东西。在上帝的世界中所有的东西他都祝福了，人们充满了快乐和惊奇。可是从此在漂洗工地的角上再也长不出任何一种鲜花来，那个地方仍然成了从前那样的不毛地。
- （《星孩》·冷风与硬心肠）原文：“吹进硬心肠人家里来的风不总是冷风吗？”他反问道。妻子并不回答，却更靠近炉火了。
- （《星孩》·美貌带来祸害）原文：可是他的美貌给他带来了祸害。因为他变得骄傲、残酷而自私了。他看不起樵夫的儿女，也看不起村子里别的小孩，说他们出身微贱，而他自己却是很高贵的，从一颗星生出来的
- （《星孩》·老牧师的劝告）原文：苍蝇是你的弟兄。你不要害它。那些在林子里飞来飞去的野鸟有它们的自由。不要图你高兴就把它们捉来。蛇蜥和鼹鼠都是上帝造的，各有各的地位。你是谁，怎么可以给上帝的世界带来痛苦呢？就连耕田的马、牛也知道赞美上帝的。”
- （《星孩》·三只动物的回绝）原文：鼹鼠答道：“我的眼睛已经给你弄瞎了。我怎么会知道呢？”／梅花雀答道：“我的翅膀已经给你在取乐的时候剪掉了。我怎么会飞呢？”／松鼠回答：“你已经杀了我的母亲。难道你还想杀死你的母亲吗？”
- （《星孩》·自己造出来的世界）原文：三年来他走遍了全世界，在这个世界中他得不着爱，得不着亲切，也得不着仁慈，然而这正是他从前得意的时候为他自己创造的世界啊。
- （《星孩》·兔子的回答）原文：“不是这样，”兔子答道，“这不过是你怎样待我，我也怎样待你罢了。”
- （《星孩》·第三次施舍）原文：星孩又动了怜悯心，给了他那块红金，一面说：“你的需要比我的更大。”然而他的心却是很沉重的，因为他知道有什么样的恶运在等待他。

- （《快乐王子》·燕子诀别时王子的话）原文：“小燕子，我很高兴你到底要到埃及去了，”王子说，“你在这儿住得太久了，不过你应该亲我的嘴唇，因为我爱你。”
- （《快乐王子》·市长清点像上少了什么）原文：“他脚下还有一只死鸟！”市长又说，“我们的确应该发一个布告，禁止鸟死在这个地方。”书记员立刻把这个建议记录下来。
- （《夜莺与蔷薇》·学生正午发现红蔷薇）原文：“啊，真是很好的运气啊！”他嚷起来；“这儿有一朵红蔷薇！我一辈子没有见过一朵这样的蔷薇。它真美，我相信它有一个长的拉丁名字。”
- （《星孩》·星孩顶撞樵夫）原文：星孩气得一张脸通红，顿着脚说：“你是什么人，敢来管我的行动？我不是你的儿子，不要听你的吩咐。”
- （《星孩》·城门口自陈身世）原文：“我的母亲就跟我一样也是个讨饭的，我以前待她很坏，我求你们准许我进去，让我求到她的饶恕，说不定她会在这座城里。”

## 五、重复出现的事物/场景

> 以下均为**篇内**重复，非跨篇重复（各篇独立，无共用意象由作者显性串联）。

- **《快乐王子》· “燕子，燕子，小燕子”**：王子每次请托前的呼唤，全篇出现四次（请送红宝石、请送第一只眼睛、请送第二只眼睛，及中间一次挽留）。
- **《快乐王子》· 王子身上被取走的三样宝物**：剑柄红宝石 → 一只蓝宝石眼睛 → 另一只蓝宝石眼睛 → 之后是一片片金叶。
- **《夜莺与蔷薇》· “给我一朵红蔷薇，我要给你唱我最好听的歌”**：夜莺对白、黄、红三棵蔷薇树各说一次，句式完全相同。
- **《夜莺与蔷薇》· “靠紧些，小夜莺”**：蔷薇树催促夜莺抵紧刺，出现两次，字句相同。
- **《自私的巨人》· 花园里的季节**：孩子在→春；筑墙后→只有冬天与北风、雹、霜、雪；孩子爬回→树开花，唯余最远角落是冬天；结尾冬日角落里的树开满白花、枝为黄金、垂银果。
- **《忠实的朋友》· 磨面师“我就要把我的小车给你”**：这句许诺贯穿全篇，每次索取劳役前都要重提，直到葬礼后小车仍在他家里。
- **《了不起的火箭》· “啊哼！啊哼！”**：火箭说话前的咳嗽，全篇多次出现，用来引起注意。
- **《了不起的火箭》· 被误认为“代表团”**：工人来收拾园子时一次、两个男孩来打水时一次，他都判定对方是“代表团”。
- **《少年国王》· “他又睡着了，做梦了，他的梦是这样的”**：三个梦的固定引入句，三次字句一致。
- **《少年国王》· 王袍、王冠、节杖三样加冕物**：先作为他倾力搜求的对象出现，再在三个梦中分别对应织工的袍子、潜水人的珍珠（节杖）、矿工的红宝石（王冠），最后被拒绝、并由日光与花朵替代。
- **《打鱼人和他的灵魂》· 灵魂每年归来的固定套式**：“走近一点，我好跟你讲话，因为我看见了好些奇奇怪怪的东西”，第一年与第二年完全相同、第三年略变。
- **《打鱼人和他的灵魂》· “我的灵魂对我有什么用处呢？我不能够看见它。我不可以触摸它。我又不认识它。”**：打鱼人对自己、对神父、对商人各说一次。
- **《打鱼人和他的灵魂》· 灵魂作恶后的“安静点，安静点”**：偷银杯、打小孩两次之后灵魂的回答，字句相同。
- **《星孩》· 金线斗篷与琥珀项链**：拾得时裹身与佩戴 → 收进柜子 → 母亲凭此认子 → 认子时取出对证。
- **《星孩》· 白金 / 黄金 / 红金三次任务**：三天各一次，每次都是“兔子带路找到 → 城门口给大麻风病人 → 空手回去受罚”，第三次结局逆转。

## 六、可作横向对照的内容

> 只列对照对象与可对照维度，不下结论。

- 对照组：《快乐王子》里的**快乐王子** ↔ 《少年国王》里的**少年国王**；可对照维度：知道苦难之前的处境（无愁宫 / 欢乐宫与搜求珍宝）、得知苦难的途径（立在高处亲眼看见 / 三个梦）、采取的行动（拆下自身宝物送人 / 拒穿王袍改着牧人衣）、他人的反应（市长嫌难看拆像 / 贵族要杀他）、结局的性质。
- 对照组：《快乐王子》里的**燕子** ↔ 《夜莺与蔷薇》里的**夜莺**；可对照维度：为谁付出、付出的代价、对方是否知情、对方最终如何对待其成果、书中结尾的处置（进天堂的园子 / 死在草丛、花被车轮碾过）。
- 对照组：《忠实的朋友》里的**磨面师所说的友谊** ↔ **他实际的所作所为**；可对照维度：许诺与兑现、索取与给予、对困难时期的态度、葬礼上的自陈与私下的惋惜。
- 对照组：《西班牙公主的生日》里的**小矮人照镜前** ↔ **照镜后**；可对照维度：对自己外貌的认知、对公主行为的解读、对树林与王宫的态度、身体状态。
- 对照组：《西班牙公主的生日》里**花与日晷、孔雀的态度** ↔ **鸟与蜥蜴的态度**；可对照维度：评判依据（外形 / 相处经历）、所举理由、对小矮人行为的解释。
- 对照组：《星孩》**变丑前** ↔ **变丑后**；可对照维度：对生母的称呼与态度、对同伴的支配关系、对动物的做法、对乞讨者的做法、他人如何对待他。
- 对照组：《打鱼人和他的灵魂》里灵魂带回的**智慧** ↔ **财富** ↔ **跳舞的少女**；可对照维度：诱惑的内容、打鱼人回答的句式与理由、他是否动摇、结果。
- 对照组：《打鱼人和他的灵魂》里**神父对灵魂的估价** ↔ **商人对灵魂的估价**；可对照维度：估价的高低、依据、对打鱼人的处置方式。
- 对照组：《了不起的火箭》里**火箭的自述** ↔ **周围众物对他的评价与实际遭遇**；可对照维度：自称的出身与才能、自称的同情心、实际引起的反应、最终结局与他最后一句话。

## 七、贯穿全书的变化线索

> ⚠ 本书为短篇合集，**没有贯穿全书的变化线索**。以下是**篇内**最清晰的两条变化主线，供纵向追踪类设计取材。

**线索A《星孩》· 对生母的态度**
- 节点①（《星孩》· 讨饭女人进村）：星孩带头朝她丢石子、嘲笑她；被樵夫责备时说“我不是你的儿子，不要听你的吩咐”。
- 节点②（《星孩》· 认亲当场）：女人跪地伸臂求他相认，他说“倘使你真的是我母亲，那么你还是走得远远的，不到这儿来让我丢脸，倒好得多”；又说宁肯亲毒蛇蟾蜍也不亲她。
- 节点③（《星孩》· 女人走后）：他在水井旁看见自己成了蟾蜍脸、毒蛇鳞；说“我要去，要走遍全世界去找她，不把她找到，我就不休息”。
- 节点④（《星孩》· 寻母三年）：走遍全世界得不到消息，常觉得她就在前面走着，追到脚被石头弄出血。
- 节点⑤（《星孩》· 城门被拒时的自陈）：对守兵说“我的母亲就跟我一样也是个讨饭的，我以前待她很坏”。
- 节点⑥（《星孩》· 被拥为国王时）：拒绝王冠与节杖，说“我不配的，因为我不认我的生母”。
- 节点⑦（《星孩》· 重逢）：跪下亲母亲脚上的伤口、用眼泪洗它们，连说三句“母亲……”求她收留。

**线索B《自私的巨人》· 对花园与孩子的处置**
- 节点①（孩子们放学后总在园里玩，园中“我们在这儿多快乐！”）：巨人不在家。
- 节点②（巨人归来）：粗暴赶走孩子，说“我自己的花园就是我自己的花园……除了我自己以外，我不准任何人在里面玩”，筑高墙、挂“不准擅入 违者重惩”。
- 节点③（园中只剩冬天）：他坐在窗前自语“我不懂为什么春天来得这样迟”。
- 节点④（看见孩子从墙洞爬回、最小的孩子够不着树枝）：他“心也软了”，自语“我是多么自私啊”。
- 节点⑤（他抱起小孩放上树枝、砍倒围墙）：说“孩子们，花园现在是你们的了”。
- 节点⑥（年老）：坐在扶手椅上看孩子玩，说“我有许多美丽的花，可是孩子们却是最美丽的花”；并说不再恨冬天，“因为他知道这不过是春天在睡眠”。
- 节点⑦（结尾）：孩子们发现他死在树下，满身盖着白花。

2. **篇名用词是本译本的固定叫法，不得替换成通行译名**：
   - 是**《夜莺与蔷薇》**，不是“夜莺与玫瑰”；全篇的花一律写作“蔷薇”，写成“玫瑰”即与原文不符。
   - 是**《打鱼人和他的灵魂》**，不是“渔夫和他的灵魂”；正文中人物称“年轻的打鱼人”。
   - 是**《了不起的火箭》**、**《西班牙公主的生日》**、**《星孩》**（不是“星孩子”“小星星孩子”）。
   - 目录中“快乐王子”一词有三个层级：书名 / 第一辑辑名 / 篇名。下游写“《快乐王子》”时须明确指的是整本书还是那一篇。

3. **两个“宫”极易混**：《快乐王子》里王子生前住的是**“无愁宫”**；《少年国王》里少年国王住的是**“欢乐宫”**。不可互换。

4. **《忠实的朋友》是“故事中的故事”**：小汉斯与磨面师的情节是**绿梅花雀讲给老河鼠听的**，外层还有老河鼠、母鸭的对话框架，结尾河鼠因“故事里有教训”而生气离开。下游不得把它当作平铺直叙的独立故事，也不得把外层对话与内层情节混为一谈。全篇内层对话在原书中带有外层引号包裹，引用时按本档案所录形态照录。

5. **磨面师的名字只出现一次**：原文仅在“最忠实的却要算磨面师大修”处点名一次，其后全篇一律称“磨面师”。下游不得反复使用“大修”作为常用称呼，也不得给他另编名字。

6. **《自私的巨人》里的小孩带有明确的宗教符号**：手掌与脚背各有钉痕，自称“这是爱的伤痕”，并说要带巨人去“我的园子，那就是天堂”。这是原文写死的事实，不得删改，也不得由下游替换成世俗化解释后再冠以“书中说”。巨人拜访的是“康华尔地方的吃人鬼”，不是别的角色。

7. **《快乐王子》里燕子是“他”、芦苇是“她”、夜莺（另一篇）是“她”**：译本的人称代词是固定的，转述时不要改性别。王子的心是**铅做的**，不是金的——燕子在文中专门确认过“怎么，他并不是纯金的？”。

8. **《星孩》的结局不是圆满收场**：星孩即位后施行公正仁慈，但原文末段明写“他只活了三年。他死后继承他的却是一个很坏的国王”。下游若写“从此过上幸福生活”即与原文相悖。

9. **《打鱼人和他的灵魂》的结局同样有两面**：坟上开出奇异白花、神父转而祝福万物；但原文末句写明“从此在漂洗工地的角上再也长不出任何一种鲜花来，那个地方仍然成了从前那样的不毛地”，人鱼也不再来这个海湾。不得只取前半截。

10. **《打鱼人和他的灵魂》中灵魂东行/南行的见闻是“灵魂的转述”**，不是打鱼人亲历，也不构成本书的现实层情节；引用时须标明是灵魂讲述的内容。另：原文一处作“而且小鱼人爱我”（“小鱼人”），与全篇通用的“小人鱼”不一致，属本版排印实况，逐字引用时照录、不要擅自改字，也不要据此认为书中另有一个角色。

11. **《西班牙公主的生日》中的国王身份不确定**：本书脚注原文即写“似指西班牙国王腓力二世……但也有不合史实的叙述。在有些地方又像是指腓力五世”。下游**不得断言**这位国王是哪一位历史人物，也不得把篇中的历史细节当作史实讲给学生。

12. **本书含小学课堂需预先知悉的成人向内容**（属事实层告知，不作教学判断）：《打鱼人和他的灵魂》有女巫安息日聚会、情欲诱惑、杀人越货、“肉体的爱是淫邪的”等表述；《西班牙公主的生日》有王后遗体防腐、判处异教徒火刑、宗教裁判所等描写；《少年国王》有奴隶船、鞭打、潜水人溺毙、瘟疫杀死全部人等描写；《星孩》有刺瞎鼹鼠、剪断鸟翅、买卖奴隶、大麻风病人等描写。

13. **译序与正文的边界**：第二节“作者&背景”与第九节的全部内容出自**译本序（苏福忠撰）**或电子版元数据，属**书外信息**，绝不可当作童话正文引用，也不得冠以“书里写道”。序中对各篇的评价（如“心之美”“唯美主义”云云）是序者观点，不是王尔德童话的正文事实。

14. **书目元数据的缺口**：字数、页数、获奖三项本版电子书未载，机读块中留“(待补充)”等人工回填；**下游对外物料遇到这三项一律留空白，不得写“待补充”、不得凭记忆或网络补值**。出版年 2010 取自电子版 OPF 元数据，纸质版版次仍待人工核实。
