## 二、作者&背景

> 本节全部为**书外信息**，不得进入第四节「可引用原文」栏，不得被冠以「书里写道」。

- 作者简介 【书外·来源：本书译本序，苏福忠撰】
  - 王尔德一八五四年生于爱尔兰首府都柏林；父亲威廉·王尔德是著名外科医生，母亲是作家，主持伦敦诗歌戏剧沙龙，笔名「斯珀兰扎」。
  - 早年在都柏林三一学院研习古典名著，后入牛津马格达兰学院，以诗《拉凡纳》获纽迪盖特奖；在牛津时张扬唯美主义，即「为艺术而艺术」。
  - 一八八一年出版第一部集子《诗集》，并赴美巡回讲学一年；一八八四年与康斯坦丝·洛伊德结婚，婚后生有二子。
  - 一八九一年发表唯一长篇小说《道连·格雷的画像》；戏剧有《温德米尔夫人的扇子》（1892）、《一个无关紧要的女人》（1893）、《理想丈夫》（1895）、《认真的重要》（1895）、《莎乐美》（1895）。
  - 因官司被判刑两年；出狱后移居法国，用「塞巴斯蒂安·梅尔莫斯」之名写作，有长诗《雷丁监狱之歌》，狱中书信结集为《从深处》（1905）。出狱三年多后在巴黎去世，享年四十六岁。
- 写作缘起 【书外·来源：本书译本序，苏福忠撰】
  - 序中称「正是由于对儿子的爱，王尔德曾致力于儿童文学创作，其中主要是童话故事」。
  - 《快乐王子童话集》一八八八年出版，收五篇；《石榴之家》一八九一年出版，收四篇，**是题送他妻子的**。
- 译序观点 【书外·来源：本书译本序，苏福忠撰】
  - 序者认为王尔德童话遵循惩恶扬善等一般主题，又以唯美主义观点探讨「幸福」「心之美」等命题；并说他爱写冷僻植物名，「犯了童话创作的大忌」。
  - ⚠ 以上是**序者的评论**，不是童话正文事实；下游若引用须标明「译序认为」。

### 分篇梗概（篇与篇之间无先后因果）

**第一辑《快乐王子》**

**1.《快乐王子》**
王子像立于高圆柱上，满身贴金叶、蓝宝石为眼、剑柄嵌大红宝石，市民各有称赞 → 一只小燕子因恋着芦苇误了南飞，夜里停在王子两脚之间 → 王子的泪滴落在他身上；王子说生前住在「无愁宫」，死后被立在高处，才看见城里的丑恶和穷苦 → 燕子第一次送出剑柄红宝石，给绣花的女裁缝与她发热要吃橙子的孩子 → 第二次取下王子一只蓝宝石眼睛，送给顶楼里冻饿写戏的年轻人 → 第三次取下另一只眼睛，送给把火柴掉进沟里的卖火柴女孩 → 王子失明，燕子决定永远陪伴他，为他讲异国见闻，又替他巡城 → 燕子把金叶一片片啄下送给穷人，王子变得灰暗难看 → 严寒到来，燕子吻王子的嘴唇后死在他脚下，王子的铅心裂成两半 → 市长与市参议员嫌像难看、拆像熔化，为铸谁的像争吵 → 铅心熔不掉，与死燕子一同被扔在垃圾堆上 → 上帝命天使取来「这个城里两件最珍贵的东西」，天使带回铅心和死鸟。

**2.《夜莺与蔷薇》**
年轻学生哭诉：她说过只要送她一朵红蔷薇就同他跳舞，可他园里没有 → 常青橡树上的夜莺听见，认定他是「忠实的情人」 → 夜莺依次求草地中央的白蔷薇树、日晷仪旁的黄蔷薇树、学生窗下的红蔷薇树；红蔷薇树说今年不会再开花，唯一办法是夜莺在月光下用胸脯抵住刺、唱一整夜、用心血染红花 → 夜莺权衡后决定去做，只求学生做一个忠实的情人；学生听不懂；夜莺给橡树唱了最后的歌 → 学生拿出笔记本，断定夜莺「只有外表的东西，没有一点真诚」 → 月出后夜莺抵刺唱了一整夜，花由浅白到染红晕，刺入心时花变深红 → 夜莺死在青草丛中，心上带着刺 → 正午学生摘下红蔷薇送到教授家 → 教授的女儿说怕它配不上衣服，御前大臣的侄儿送了她珠宝 → 学生骂她忘恩负义，把花丢进路沟，被车轮碾过 → 学生说爱情不实际，回屋读一本满是灰尘的大书。

**3.《自私的巨人》**
孩子们放学后总在巨人花园里玩 → 巨人去看康华尔的吃人鬼、住了七年后回家，赶走孩子，筑高墙、挂布告牌「不准擅入」「违者重惩」 → 春天来了，唯独巨人花园仍是冬天，雪、霜、北风、雹住进来；夏天、秋天也不来 → 一天早晨巨人听见梅花雀歌唱，看见孩子们从墙洞爬进来坐在树上、树都开了花，只有最远角落里一个够不着树枝的小孩身边仍是冬天 → 巨人心软，悄悄把小孩抱上树，树立即开花，小孩抱住他的颈项吻他 → 巨人砍倒围墙，把花园给了孩子们 → 那个小孩此后再没出现，巨人一直想念 → 多年后巨人老了；一个冬天早晨，最远角落一棵开满白花、枝如黄金、垂着银果的树下站着那个小孩，手脚各有钉痕 → 小孩说「这是爱的伤痕」，要带巨人去他的园子——天堂 → 当天下午孩子们看见巨人死在树下，满身盖着白花。

**4.《忠实的朋友》**（框架故事：外层是池塘边的对话，内层是绿梅花雀讲给老河鼠听的故事）
外层：老河鼠向母鸭夸说友谊最高贵；梅花雀问他忠实的朋友有什么义务、他又怎样报答，河鼠不明白，梅花雀便讲故事 → 内层：小汉斯独住小茅屋、以园中花果为生，最「忠实」的朋友是有钱的磨面师 → 磨面师每次路过都摘走花果，口称「真朋友应当共享一切」，却从未给过汉斯东西；冬天汉斯挨饿受冻，磨面师以「人在困难时候，应该让他安静」为由不去探望；他的小儿子提议请汉斯来家，被他斥责 → 开春磨面师下山，得知汉斯为过冬卖掉了小车，便说要把自己那辆破小车送他 → 以此为由，磨面师先后要走汉斯的木板和一满篮樱草，又让他扛面粉赶集、补谷仓顶、赶羊上山、常常跑腿；汉斯的花没人照料 → 暴风雨之夜磨面师来求汉斯替他去请医生，却不肯借出新灯笼 → 汉斯走了约三个钟头请到医生，回程迷路，淹死在沼地 → 葬礼上磨面师以「最好的朋友」自居走在最前头，事后惋惜那辆小车「我又不能拿它卖钱」 → 外层：河鼠追问磨面师的结局，得知故事有「教训」后大怒，「呸」了一声回洞；母鸭说讲带教训的故事「常常是一件很危险的事」，叙述者「我」表示完全同意。

**5.《了不起的火箭》**
王子迎娶坐驯鹿天鹅雪车而来的俄国公主，婚礼、宴会、舞会后，午夜大放烟火 → 御花园高台上众烟火交谈：小爆竹、罗马花筒、轮转炮、蓝色烟火、炮仗、火球 → 绑在长棍子上的火箭以咳嗽开场，自夸出身、自称敏感、富有同情心 → 他设想王子夫妇将来可能失掉独生子而落泪，众烟火叫「骗人！」 → 眼泪浸湿了火药，午夜别的烟火全部成功，只有他放不响 → 他以为自己被留到大典时用；次日工人当他是「坏火箭」丢过墙，落进阴沟烂泥 → 他先后对小蛙、蜻蜓、大白鸭高谈阔论，都被丢下 → 两个男孩把他当「旧棍子」捡去烧火煮水，然后睡着了 → 他终于着火飞上天、爆炸，但「可是没有一个人看见他」「可是没有人听见他」 → 剩下的棍子落在一只鹅背上；他说「我知道我要大出风头的」，灭了。

**第二辑《石榴之家》**

**6.《少年国王》**
加冕日前夜，十六岁的少年国王独坐房中 → 身世：老王独女与一个身份比她低得多的人所生，出生一周即被偷走交农家夫妇抚养，由牧羊人养大，一直以为自己是牧人的儿子；生母不久死去；老王临终认他为继承人 → 入宫后他迷恋美的东西，最费心思的是加冕用的金线王袍、红宝石王冠、珍珠节杖 → 第一个梦：顶楼织坊里饥饿的织工正为「小王」织加冕袍 → 第二个梦：奴隶船上潜水人一次次下海采珠，最后一次带回最美的珍珠后死去，船长说这颗珠子「应当用来装饰小王的节杖」 → 第三个梦：干河床上一大群人在挖掘，「死」与「贪欲」争执，疟疾、热病、瘟疫降下，人全死了；香客说他们在找国王王冠上的红宝石，让他照银镜，镜中是他自己 → 醒后他拒穿王袍王冠，换上牧羊时的皮衣和粗羊皮外套，拿牧人杖，折荆棘做圈当王冠 → 贵族嘲笑，百姓喊「国王的弄臣」；一个男人说穷人靠富人的奢华活命，富人那位「阔兄长的名字叫该隐」 → 老主教劝他回宫穿王袍 → 他在基督像前跪祷，贵族持剑闯进来要杀他 → 阳光透过彩色玻璃窗在他四周织成金袍，枯杖开出白百合，荆棘开出红玫瑰 → 百姓跪下，贵族收剑行礼，主教说「比我伟大的已经给你加冕了」 → 他回宫，没有人敢看他的脸。

**7.《西班牙公主的生日》**
西班牙公主满十二岁，国王特许她请任何小朋友进宫玩 → 愁闷的国王在窗内回忆早逝的法国王后，她的遗体用香料保存在宫中黑大理石礼拜堂，国王每月去跪唤；国王放下窗帘走开 → 公主去看生日游艺：假斗牛戏、走绳、傀儡戏、变戏法、圣母舞、吉卜赛人的弦琴与熊、猴表演 → 最有趣的是小矮人的舞：他驼背弯腿、大头，前一天才被贵族在树林里发现带进宫，父亲是穷烧炭夫；他一点不知道自己难看 → 公主半开玩笑地把发间的白蔷薇丢给他，他当真了；公主吩咐他午睡后再跳 → 他在花园里狂喜，众花嫌他丑，日晷仪说「烧炭夫的孩子也是烧炭夫」，孔雀附和；鸟和蜥蜴喜欢他（他冬天常把黑面包分给鸟） → 他幻想带公主回树林一起生活 → 他入宫寻找公主，穿过几间华丽的屋子 → 在最亮的一间屋子里，他看见一个模仿他一举一动的「怪物」，最后明白那是镜子里的自己 → 他绝望痛哭、撕碎白蔷薇，倒在地上 → 公主一行进来，以为他在演戏；唐·彼德洛用手套打他的脸，要他跳舞 → 御前大臣按他的心，说他永不会跳舞了，「因为他的心碎了」 → 公主说「以后凡是来陪我玩的人都要没有心的才成」，跑进花园。

**8.《打鱼人和他的灵魂》**
年轻打鱼人网到熟睡的小人鱼，以「随唤随唱」为条件放了她 → 他夜夜唤她唱歌、渔获满船，后来听得入迷，荒废了打鱼 → 他求人鱼做新娘，人鱼说必须先送走他的灵魂 → 神父斥他，说灵魂比全世界的黄金更宝贵；商人说灵魂「连半个破银元也不值」 → 他去找海湾洞窟里的红发女巫，代价是同她跳舞 → 月圆之夜山顶女巫聚会，出现一个穿黑天鹅绒西班牙式衣服的男人；打鱼人无意中画十字、唤圣名，女巫们尖叫飞散 → 他逼女巫说出方法：背对月亮站在海滩上，用绿蛇皮刀柄小刀从双脚四周切开影子——影子是「灵魂的身体」 → 灵魂求他给一颗心同行，他拒绝；灵魂被切离，说每年回来唤他一次；打鱼人入海与人鱼同住 → 第一年灵魂讲东方见闻与「智慧镜」，求回到他体内，他答「爱比‘智慧’好」 → 第二年讲南方见闻与「财富指环」，他答「爱比‘财富’好」 → 第三年讲一天路程外一个赤脚跳舞的少女；他想起人鱼没有脚不能跳舞，上岸让灵魂回到体内 → 灵魂一路让他偷银杯、打小孩、打晕收留他的商人并拿走九包金子；灵魂说这是因为「你并没有给我一颗心」 → 他想再切走灵魂，灵魂说一辈子只能送走一次，收回后必须永远留住 → 他捆手封口回到小海湾，一年年唤人鱼，她不再出现；灵魂先以恶、再以善引诱他，都无效 → 第二年过去，小人鱼的尸体被浪送到他脚下；他抱尸痛哭，心因充满爱而碎裂，灵魂由此进入；海浪盖住了他 → 神父拒绝祝福海，命人把两人埋在漂洗工地角上、不做记号 → 第三年后的祭日，祭坛上出现奇异白花，神父讲的不再是上帝的愤怒，而是「那个叫做“爱”的上帝」 → 次晨神父祝福了海与世间万物；但漂洗工地角上从此寸草不生，人鱼也不再来这个海湾。

**9.《星孩》**
寒冬夜里两个穷樵夫看见一颗星落下，在柳树丛后找到裹在绣星金线斗篷里的熟睡婴孩 → 一个主张丢下，另一个抱回家；妻子起初不肯，最后落泪收下；斗篷和琥珀项链收进柜子 → 星孩长得极美，却骄傲、残酷而自私：看不起别的孩子，向穷人和残疾人丢石头，刺瞎鼹鼠眼睛、拿石子打大麻风病人；樵夫夫妇和老牧师劝他，他不听 → 一个讨饭女人进村，星孩带头向她丢石子；樵夫说出十年前在林中拾到他，女人晕倒 → 女人凭金线斗篷与琥珀项链认出他是被强盗偷走的儿子 → 星孩当面拒认，说宁肯亲毒蛇、亲蟾蜍也不亲她；女人哭着走进树林 → 同伴说他像蟾蜍一样难看；他到井边一看，脸像蟾蜍、身上长了蛇鳞 → 他悔悟，出发寻母；鼹鼠、梅花雀、松鼠各以他从前的伤害作答 → 三年走遍全世界，得不到消息，到处受人嘲弄 → 在一座城门口被兵士驱赶，被当奴隶以「一碗甜酒」的价钱卖给一个老魔术家 → 魔术家命他三天内分别取回白金、黄金、红金 → 他从陷阱里救出小兔，兔子三次带他找到金钱 → 三次在城门口把金钱给了乞讨的大麻风病人，前两次回去挨打、上链 → 第三次进城，守兵和市民称他漂亮，僧侣大臣迎他为国王的儿子；他在盾牌里看见自己的美貌恢复了 → 他不肯受冠，仍要去寻母；转身看见讨饭女人与大麻风病人，跪下亲母亲脚上的伤口求饶恕 → 两人说「起来」，他看见他们原来是国王和王后 → 他即位，公正仁慈，赶走魔术家，厚待樵夫一家 → **但他只活了三年，继位的是一个很坏的国王。**

## 四、关键片段 [必填]

- **片段1**
  - 定位：《快乐王子》· 开篇·众人看像
  - 内容概述：交代王子像的样子；市参议员、聪明的母亲、失意的人、孤儿院的孩子与数学先生各说一句。
  - 可引用原文（逐字，成段）：

> 快乐王子的像在一根高圆柱上面，高高地耸立在城市的上空。他满身贴着薄薄的纯金叶子，一对蓝宝石做成他的眼睛，一只大的红宝石嵌在他的剑柄上，灿烂地发着红光。
> 他的确得到一般人的称赞。一个市参议员为了表示自己有艺术的欣赏力，说过：“他像风信标那样漂亮，”不过他又害怕别人会把他看作一个不务实际的人（其实他并不是不务实际的），便加上一句：“只是他不及风信标那样有用。”
> “我真高兴世界上究竟还有一个人是很快乐的，”一个失意的人望着这座非常出色的像喃喃地说。

- **片段2**
  - 定位：《快乐王子》· 王子自述为什么哭
  - 内容概述：王子说生前住在无愁宫、不知眼泪为何物；死后立在高处，看见城里的丑恶和穷苦。
  - 可引用原文（逐字，成段）：

> “从前我活着，有一颗人心的时候，”王子慢慢地答道，“我并不知道眼泪是什么东西，因为我那个时候住在无愁宫里，悲哀是不能够进去的。白天有人陪我在花园里玩，晚上我又在大厅里领头跳舞。花园的四周围着一道高墙，我就从没有想到去问人墙外是什么样的景象，我眼前的一切都是非常美的。我的臣子都称我做快乐王子，不错，如果欢娱可以算作快乐，我就的确是快乐的了。我这样地活着，我也这样地死去。我死了，他们就把我放在这儿，而且立得这么高，让我看得见我这个城市的一切丑恶和穷苦，我的心虽然是铅做的，我也忍不住哭了。”

- **片段3**
  - 定位：《快乐王子》· 第一次送宝石后·「虽然天气这么冷，我却觉得很暖和」
  - 内容概述：燕子送完红宝石回来，说自己觉得暖和，王子答那是因为做了好事。
  - 可引用原文（逐字，成段）：

> 燕子回到快乐王子那里，把他做过的事讲给王子听。他又说：“这倒是很奇怪的事，虽然天气这么冷，我却觉得很暖和。”
> “那是因为你做了一件好事，”王子说。小燕子开始想起来，过后他睡着了。他有这样的一种习惯，只要一用思想，就会打瞌睡的。

- **片段4**
  - 定位：《快乐王子》· 第二只眼睛·燕子决定留下
  - 内容概述：王子请燕子取下另一只眼睛给卖火柴女孩；燕子照做后决定永远陪伴失明的王子。
  - 可引用原文（逐字，成段）：

> “我愿意陪你再过一夜，”燕子说，“我却不能够取下你的眼睛。那个时候你就要变成瞎子了。”
> “燕子，燕子，小燕子，”王子说，“你就照我吩咐你的话做罢。”
> 他便取下王子的另一只眼睛，带着它飞到下面去。他飞过卖火柴女孩的面前，把宝石轻轻放在她的手掌心里。“这是一块多么可爱的玻璃！”小女孩叫起来；她一面笑着跑回家去。
> 燕子又回到王子那儿。他说：“你现在眼睛瞎了，我要永远跟你在一块儿。”
> “不，小燕子，”这个可怜的王子说，“你应该到埃及去。”
> “我要永远陪伴你，”燕子说，他就在王子的脚下睡了。

- **片段5**
  - 定位：《快乐王子》· 燕子之死与铅心破裂
  - 内容概述：严寒中燕子吻别王子死去，王子的铅心裂成两半。
  - 可引用原文（逐字，成段）：

> 可怜小燕子却一天比一天地更觉得冷了，可是他仍然不肯离开王子，他太爱王子了。他只有趁着面包师不注意的时候，在面包店门口啄一点面包屑吃，而且拍着翅膀来取暖。
> 但是最后他知道自己快要死了。他就只有一点气力，够他再飞到王子的肩上去一趟。“亲爱的王子，再见罢！”他喃喃地说，“你肯让我亲你的手吗？”
> “小燕子，我很高兴你到底要到埃及去了，”王子说，“你在这儿住得太久了，不过你应该亲我的嘴唇，因为我爱你。”

> 呼呼！呼呼！轮转炮走了，她一路旋转着。轰隆！轰隆！罗马花筒走了。然后爆竹们到处跳舞，蓝色烟火使得每样东西都带着深红色。“再见，”火球嚷着就飞向天空去，撒下了不少蓝色小火星来，砰！砰！炮仗们响应道，他们非常快活。每个都很成功，就除了那个了不起的火箭。他哭得一身都湿透了，他完全不能燃放了。他身上最好的东西便是火药，火药被眼泪浸湿，哪里还有什么用处。所有他的穷亲戚们，他平日间不屑对他们讲话，偶尔讲一两句话总要带一声冷笑，现在他们都飞上天空去了，就像一些开放火红花朵的出色的金花。“好呀！好呀！”宫里的人全叫起来；小公主高兴地笑了。

- （《了不起的火箭》· 「坏」与「大」）原文：

> “坏火箭，坏火箭？”他在空中旋转翻过墙头的时候一面自言自语，“不可能！大火箭，那个人是这样说的。‘坏’和‘大’，说起来声音简直是一样，的确常常是一样的，”他落进烂泥里去了。

> “他不留在这儿多傻！”火箭说。“我相信他并不常有这种进修的机会。不过我倒一点儿也不在乎。像我这样的天才总有一天会给人赏识的，”他在烂泥里又陷进去一点儿。

- （《了不起的火箭》· 大白鸭论用处）原文：

> “我并不看重这个，”鸭子说，“因为我看不出它对什么人有益处。要是你能够像牛一样地耕田，像马一样地拉车，像守羊狗一样地看羊，那才算一回事。”

- （《少年国王》· 荆棘王冠）原文：

> 少年国王随手折下一枝爬在露台上面的荆棘，把它折弯，做成一个圆圈，放在他自己的头上。“这就是我的王冠。”他答道。

- （《少年国王》· 百姓中的男人）原文：

> “富人和穷人不是弟兄吗？”少年国王问道。

- （《少年国王》· 快乐应当穿愁苦做的衣服吗）原文：

> “那么快乐应当穿愁苦做的衣服吗？”少年国王说。他把他的三个梦对主教讲了。

- （《西班牙公主的生日》· 他一点也不觉得自己难看）原文：

> 关于矮人的最有趣的事也许就是他一点也不觉得自己难看。

- （《西班牙公主的生日》· 鸟儿为何喜欢他）原文：

> 可是鸟儿却喜欢他。他们常常看见他在林子里玩，有时像妖精似地追逐在空中旋转的落叶跳舞，有时蹲在一棵老橡树的洞孔里，把他的硬壳果分给松鼠们吃。他们一点儿也不介意他的丑陋。

- （《西班牙公主的生日》· 公主看他倒地）原文：

> “他的跳舞很有趣，”公主说，“可是他演戏更有趣。的确他差不多跟木偶人一样地好，不过不用说他还不够自然。”她摇着她的大扇子，喝彩。

> 可是年轻的打鱼人笑了。“爱比‘智慧’好，”他大声说，“而且小鱼人爱我。”

- （《打鱼人和他的灵魂》· 一辈子只能送走一次）原文：

- （《打鱼人和他的灵魂》· 心碎而灵魂进入）原文：

> 他的灵魂要求他走开，可是他不肯，他的爱太大了。海水逐渐逼近，它要用它的浪盖住他，他知道他的死期就在目前的时候，他疯狂地吻着人鱼的冰冷的嘴唇，他的那颗心碎了。他的心因为充满了爱而碎裂的时候，灵魂就找到一个入口进去了，它好像以前一样地跟他成为一体了。海用浪盖住了年轻的打鱼人。

- （《打鱼人和他的灵魂》· 末段）原文：

> 早晨，天刚刚发亮，他便同僧侣，乐手，拿蜡烛的，摇香炉的，还有一大群人走到海边，祝福了海，以及海中的一切野东西。他也祝福了牧神和森林中跳舞的小东西，以及从树叶缝中偷偷张望的亮眼睛的东西。在上帝的世界中所有的东西他都祝福了，人们充满了快乐和惊奇。可是从此在漂洗工地的角上再也长不出任何一种鲜花来，那个地方仍然成了从前那样的不毛地。人鱼们也不再像平日那样到这个海湾里来，因为他们都到海中别的地方去了。

- （《星孩》· 两个樵夫的分歧）原文：

> 可是另一个人却回答道：“不，把这个小孩丢在这儿，让他冻死在雪里，会是一件坏事情，虽然我跟你一样穷，还要养活好几口人，锅子里的东西又很少，可是我要把他带回家去，我的妻子会照应他的。”

- （《星孩》· 美貌带来的祸害）原文：

> 三年来他走遍了全世界，在这个世界中他得不着爱，得不着亲切，也得不着仁慈，然而这正是他从前得意的时候为他自己创造的世界啊。

- （《星孩》· 兔子的话）原文：

> “不是这样，”兔子答道，“这不过是你怎样待我，我也怎样待你罢了。”它说完便连忙跑开了，星孩也就走回城去。

## 五、重复出现的事物/场景

> 以下均为**篇内重复**；各篇之间作者没有显性串联的共用意象。次数均已按电子版全文检索复核。

- **《快乐王子》·「燕子，燕子，小燕子」**：王子的呼唤共 **7 次**——请送红宝石、求陪一夜、两次「你不肯陪我再过一夜么」、讲顶楼的年轻人、两次「你就照我吩咐你的话做罢」。
- **《快乐王子》· 王子身上被取走的东西**：剑柄红宝石 → 一只蓝宝石眼睛 → 另一只蓝宝石眼睛 → 满身金叶一片片啄下。
- **《快乐王子》· 燕子「要到埃及去」**：燕子多次说朋友在埃及等他、今晚就走，最后一次说「我现在不是到埃及去……我是到死之家去的」。
- **《夜莺与蔷薇》·「给我一朵红蔷薇」「我要给你唱我最好听的歌」**：中间夹「她大声说」，对三棵蔷薇树各说一次，字句相同（3 次）。
- **《夜莺与蔷薇》·「靠紧些，小夜莺……不然，蔷薇还没有完成，白天就来了」**：树催促 2 次，字句相同。
- **《夜莺与蔷薇》· 夜莺「像影子似地」飞**：去时「像影子似地穿过树林，又像影子似地飞过了花园」，回时「像影子似地掠过花园，又像影子似地穿过了树丛」，两处语序互换。
- **《自私的巨人》· 花园的季节**：孩子在→春天；筑墙后→只有冬天，雪、霜、北风、雹；孩子爬回→开花，只余最远角落是冬天；结尾冬日最远角落一棵树开满白花。
- **《忠实的朋友》· 小车**：磨面师先说「我会把我的小车给你」，接着连说三次「我已经把我的小车给了你」/「既然把我的小车给了你」，此后又一再改口「我就要把我的小车给你」——**小车始终没有给出**，葬礼后他说「我差不多已经把我的小车给他了」。
- **《了不起的火箭》·「啊哼！啊哼！」**：火箭的咳嗽 3 次（开场一次，对小蛙两次）。
- **《了不起的火箭》·「代表团」**：工人来收拾园子、两个男孩来岸边，他两次判定对方是「代表团」。
- **《少年国王》· 三个梦的引入句**：第一个「他睡着了，做了一个梦，他的梦是这样的」，第二、三个是「他又睡着了，做梦了，他的梦是这样的」——**第一句与后两句字句不同**。每个梦都以「大叫一声，便醒过来了」/「便醒了」收尾。
- **《少年国王》·「他把他的三个梦……讲了」**：对朝臣、对百姓、对主教各讲一次。
- **《打鱼人和他的灵魂》·「我不能够看见它。我不可以触摸它。……不认识它」**：共 **4 次**（对自己、对神父、对商人、对女巫）；前两次是「我又不认识它」，后两次是「我也不认识它」。
- **《打鱼人和他的灵魂》· 灵魂归来的开场白**：「走近一点，我好跟你讲话，因为我看见了好些奇奇怪怪的东西」共 3 次；**第一年、第三年有「了」，第二年作「我看见好些」，无「了」**。
- **《打鱼人和他的灵魂》·「安静点，安静点」**：灵魂在偷银杯、打小孩、打商人抢金子之后各答一次，共 **3 次**。
- **《打鱼人和他的灵魂》·「爱比……」**：「爱比‘智慧’好」「爱比‘财富’好」各一次，最后对人鱼尸体说「爱比‘智慧’更好，比‘财富’更宝贵，比人间女儿们的脚更漂亮」。
- **《打鱼人和他的灵魂》·「我做了一件奇怪的事，不过我做的也算不了什么」**：灵魂讲智慧镜、财富指环时各一次。
- **《星孩》· 金线斗篷与琥珀项链**：拾得时裹身与佩戴 → 收进柜子 → 母亲说出信物 → 樵夫取出对证 → 母亲再说「我也认得那些信物」。
- **《星孩》· 三块金钱**：白金、黄金、红金三天三次；每次兔子带路找到 → 城门口给大麻风病人 → 前两次回去受罚；兔子两次说「还是你先对我起怜悯心的」。
- **《星孩》·「起来」**：讨饭女人与大麻风病人把手放在他头上，各说一次「起来」。

## 六、可作横向对照的内容

> 合集的对照主要在**篇与篇之间**。只列对象与维度，不下结论；所涉原文已在第四节备齐或可按定位回查。

- 篇际：《快乐王子》**快乐王子** ↔ 《少年国王》**少年国王**；可对照维度：知道苦难之前的处境（无愁宫 / 欢乐宫与搜求珍宝）、得知苦难的途径（立在高处亲眼看 / 三个梦）、采取的行动（拆下自身宝物送人 / 拒穿王袍改穿牧人衣）、旁人的反应（市长嫌难看拆像 / 贵族要杀他）、结尾的处置（上帝取走铅心 / 日光织袍、主教跪倒）。
- 篇际：《快乐王子》**燕子** ↔ 《夜莺与蔷薇》**夜莺**；可对照维度：为谁付出、付出什么、对方是否知情、付出的成果最后去了哪里（穷人得救、铅心进天堂 / 红蔷薇被车轮碾过）。
- 篇际：《快乐王子》**市长、美术教授** ↔ 《夜莺与蔷薇》**学生、教授的女儿** ↔ 《了不起的火箭》**大白鸭**；可对照维度：各自用什么标准衡量一样东西（美不美 / 有没有用 / 值不值钱 / 实不实际）。
- 篇际：《自私的巨人》**巨人** ↔ 《星孩》**星孩**；可对照维度：起初怎样对待别人、因什么受了冷落或惩罚（花园只有冬天 / 变成蟾蜍脸）、转变的触发点、转变后的做法、结尾。
- 篇际：《夜莺与蔷薇》**学生「她只有外表的东西」** ↔ 《西班牙公主的生日》**公主「以后凡是来陪我玩的人都要没有心的才成」** ↔ 《打鱼人和他的灵魂》**没有心的灵魂**；可对照维度：书中「心」这个词指什么、谁有心谁没有心。
- 篇际：《西班牙公主的生日》**小矮人照镜** ↔ 《星孩》**星孩照井**；可对照维度：照之前对自己相貌的认识、照见了什么、照后的反应、结局。
- 篇际：《忠实的朋友》**磨面师说的友谊** ↔ 《快乐王子》**燕子与王子**；可对照维度：谁给谁什么、说的与做的、结局。
- 篇内：《忠实的朋友》**磨面师所说** ↔ **磨面师所做**；可对照维度：许诺与兑现、索取与给予、困难时期的态度、葬礼上的自陈与事后的惋惜。
- 篇内：《忠实的朋友》**外层河鼠** ↔ **内层磨面师**；可对照维度：两人怎样谈友谊、河鼠为何说「我很喜欢那个磨面师」、听到「教训」后的反应。
- 篇内：《了不起的火箭》**火箭的自述** ↔ **他的实际遭遇**；可对照维度：自称的出身与才能、自称的同情心、实际引起的反应、最后一句话。
- 篇内：《西班牙公主的生日》**花、日晷、孔雀** ↔ **鸟和蜥蜴**；可对照维度：评判依据（外形 / 相处经历）、所举理由。
- 篇内：《打鱼人和他的灵魂》**神父对灵魂的估价** ↔ **商人的估价**；以及灵魂带回的**智慧 / 财富 / 跳舞的少女**三次诱惑；可对照维度：内容、打鱼人的回答、是否动摇、结果。
- 篇内：《星孩》**变丑前** ↔ **变丑后**；可对照维度：对生母、对同伴、对动物、对乞讨者的做法，以及别人怎样对待他。

## 七、贯穿全书的变化线索

> **不适用**：本书为短篇合集，没有贯穿全书的主线与主角。以下降级为**单篇**候选（单篇故事山 / 单篇转变），不得在全书层面套成长阶梯或时间轴。

- **单篇转变候选A《星孩》· 对生母的态度**
  - 节点①（讨饭女人进村）：带头向她丢石子；对樵夫说「我不是你的儿子，不要听你的吩咐」。
  - 节点②（认亲当场）：说「倘使你真的是我母亲，那么你还是走得远远的」，宁肯亲毒蛇蟾蜍也不亲她。
  - 节点③（井边）：看见自己变丑，说「这一定是我的罪过给我招来的」，决定走遍全世界去找她。
  - 节点④（城门口）：对守兵说「我的母亲就跟我一样也是个讨饭的，我以前待她很坏」。
  - 节点⑤（被迎为国王时）：拒受王冠，说「我是不配的，因为我不认我的生母」。
  - 节点⑥（重逢）：跪下亲她脚上的伤口，连说三句「母亲……」求她收留。
- **单篇转变候选B《自私的巨人》· 对花园与孩子的处置**
  - 节点①（归来）：赶走孩子，筑墙挂牌。
  - 节点②（只剩冬天）：坐在窗前说「我不懂为什么春天来得这样迟」。
  - 节点③（看见角落的小孩）：「他的心也软了」，说「我是多么自私啊！」。
  - 节点④（抱孩子上树后）：砍倒围墙，说「孩子们，花园现在是你们的了」。
  - 节点⑤（晚年）：说「孩子们却是最美丽的花」；不再恨冬天。
  - 节点⑥（结尾）：死在树下，满身盖着白花。
- **单篇故事山候选**：《了不起的火箭》（自夸 → 哭湿放不响 → 被丢进阴沟 → 被当柴烧 → 无人看见的爆炸）；《快乐王子》（三次送宝 → 金叶 → 燕子死、铅心裂 → 拆像 → 上帝取宝）；《夜莺与蔷薇》（求花 → 决定 → 彻夜歌唱 → 花成鸟死 → 花被碾过）。

## 档案使用提醒（事实层注意事项）

1. **不得当长篇梳理（头号陷阱）**：本书是 9 篇独立短篇的合集。下游任何产物**不得**做「全书情节主线梳理」「全书人物关系总图」「全书成长曲线」；这些只能落到单篇。「快乐王子」既是书名、第一辑辑名，又是第一篇篇名，下游写《快乐王子》时须写明指整本书还是那一篇。

2. **无页码红线**：流式电子书，无固定页码；定位一律按篇名 + 场景。任何下游产物出现「第X页」均属编造。

3. **译名以本译本为准**：是《夜莺与蔷薇》不是「夜莺与玫瑰」，篇中的花一律是「蔷薇」；是《打鱼人和他的灵魂》，人物称「年轻的打鱼人」，不是「渔夫」；是《星孩》。⚠ 但**《少年国王》结尾荆棘开出的是「玫瑰花」**（「开着比红宝石还要红的玫瑰花」），本译本两个词都有，按篇照用、不要统一。

4. **两个「宫」**：快乐王子生前住「**无愁宫**」，少年国王住「**欢乐宫**」，不可互换。

5. **《忠实的朋友》是故事中的故事**：小汉斯与磨面师的情节是绿梅花雀讲给老河鼠听的；外层还有母鸭，全篇最后一句「我完全同意她的话」的「我」是叙述者。内层对话在原书里是外层双引号里套单引号，第四节已照录，**引用时不得把单引号改成双引号或删掉外层引号**。

6. **磨面师的名字只出现一次**：仅「最忠实的却要算磨面师大修」一处，此后一律称「磨面师」。下游不得反复用「大修」称呼他。

7. **小车从没给出**：磨面师先说要送，接着三次说「我已经把我的小车给了你」，此后又改回「就要给」，葬礼后说「我差不多已经把我的小车给他了」，小车仍在他家里。**下游不得写「磨面师把小车送给了汉斯」**。

8. **重复句的字句差异**（逐字取用时最易混）：
   - 「燕子，燕子，小燕子」共 7 次，不是三四次；
   - 打鱼人说灵魂无用共 4 次，前两次「我又不认识它」、后两次「我也不认识它」；
   - 灵魂开场白第二年无「了」字；
   - 「安静点，安静点」共 3 次；
   - 《少年国王》第一个梦的引入句与后两个不同。

9. **人称代词照译本**：燕子是「他」、芦苇是「她」、夜莺是「她」、橡树是「他」、轮转炮是「她」、雪与霜是「她们」、北风与雹是「他」。王子的心是**铅做的**（燕子专门确认「怎么，他并不是纯金的？」）。

10. **《打鱼人和他的灵魂》排印实况**：一处作「而且小鱼人爱我」（「小鱼人」），全篇其余都作「小人鱼」。逐字引用时照录，不要改字，也不要据此认为另有一个角色。灵魂东行、南行的见闻（智慧镜、财富指环、跳舞的少女）都是**灵魂的转述**，引用时须标明是灵魂讲的。

11. **两篇的结尾都有「后半句」，不得只取前半截**：
    - 《星孩》：即位后公正仁慈，但「他只活了三年。他死后继承他的却是一个很坏的国王」——不是「从此幸福」。
    - 《打鱼人和他的灵魂》：神父最终祝福万物，但漂洗工地角上从此长不出鲜花，人鱼也不再来这个海湾。

12. **《自私的巨人》里那个小孩带有原文写死的宗教符号**：手掌与脚背的钉痕、「这是爱的伤痕」「那就是天堂」。不得删改，也不得替换成世俗化解释后冠以「书中说」。巨人拜访的是「康华尔地方的吃人鬼」。

13. **《西班牙公主的生日》的国王不能坐实为某位历史人物**：本书脚注原文即说「似指」腓力二世、「在有些地方又像是指」腓力五世，并多处注明与史实不合。篇中历史细节不得当史实讲。

14. **《少年国王》的身世多处是「传闻」**：生父两种说法、生母死因三种说法，原文写「这就没有人知道了」「至少人们偷偷地互相传述的故事就是这样的内容」；能确定的只有「老王临死……承认孩子是他的继承人」。不得把某一种传闻写成定论。

15. **成人向内容的事实告知**（不作教学判断）：《打鱼人和他的灵魂》有女巫安息日聚会、诱惑、偷盗、打晕他人抢金、「肉体的爱是淫邪的」等表述；《西班牙公主的生日》有王后遗体防腐、判处异教徒火刑、宗教裁判所；《少年国王》有奴隶船、鞭打、潜水人死去、瘟疫令人全死；《星孩》有刺瞎鼹鼠、剪鸟翅、杀松鼠的母亲、买卖奴隶、大麻风病人。

16. **两组插图版本不同**：第十节 `插-01`–`插-30` 彩图出自未知版本，与本档案引文所据电子版不是同一版本，画面与巴金译文多处不一致（见第十节警示）；`插-31`–`插-49` 是电子版自带黑白插图，版本相同，但多幅只是装饰画、归属未定。**师话涉及画面一律按画面说，涉及文字一律按本档案原文说，不得互相替代**。
