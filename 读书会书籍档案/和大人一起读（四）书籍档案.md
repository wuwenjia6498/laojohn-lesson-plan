### 分篇梗概

**① 《勿贪多》**：小明放学回家，把手伸进糖果瓶抓了一大把糖，手被瓶口卡住出不来，急哭了 → 妈妈说一次不拿这么多手就容易拿出来，「记住，什么都不能贪多」。
- 寓意（原文点明，妈妈的话）：「记住，什么都不能贪多。」

**② 《自己去吧》**（李少白）：小鸭请妈妈带它去游泳，妈妈说小溪的水不深，自己去游吧，过了几天小鸭学会了游泳 → 小鹰请妈妈带它去山那边，妈妈说自己去看吧，过了几天小鹰学会了飞翔。

**③ 《一次比一次有进步》**（方崇智）：燕子妈妈让小燕子去菜园看冬瓜和茄子有什么不一样 → 第一次说出冬瓜大、茄子小 → 第二次说出冬瓜是绿的、茄子是紫的 → 第三次说出冬瓜的皮上有细毛、茄子的柄上有小刺 → 燕子妈妈说「你一次比一次有进步」。

**④ 《丁一小写字》**（任溶溶）：丁一小写不好字，先怪纸不好，换了姐姐的纸；又怪笔不好，换了姐姐的笔，还是写不好 → 姐姐用丁一小丢掉的纸和笔，坐得端端正正，一笔一笔写得很工整 → 丁一小明白是自己不认真，照着姐姐的样子写，字也写好了。

**⑤ 《乌鸦兄弟》**（金江）：乌鸦兄弟的窝破了个洞，两个都想对方会去修，谁也没修 → 洞越来越大，又都想对方会修 → 冬天风雪里两个缩在破窝里喊冷，还是都等对方 → 窝被吹到地上，两只乌鸦都冻僵了。

**⑥ 《骆驼和羊》**：骆驼说长得高好，羊说长得矮好，各要做一件事证明 → 园子围墙边，骆驼一抬头吃到树叶，羊够不着 → 又窄又矮的门前，羊走进去吃草，骆驼钻不进 → 两个都不认输，去找老牛评理。
- 寓意（原文点明，老牛的话）：「你们俩都只看到自己的长处，看不到自己的短处，这是不对的。」

**⑦ 《两只小狮子》**：一只小狮子刻苦练习滚扑撕咬，另一只懒洋洋晒太阳 → 小树问懒狮子怎么不学本领，懒狮子说爸爸妈妈是草原上的大王 → 狮子妈妈说将来我们老了、不在了，你靠谁，要学会生活的本领，做一只真正的狮子。

**⑧ 《三个小伙伴》**（胡木仁）：小野猪、小象、小袋鼠一起上山栽树 → 没锄头，小野猪用硬嘴巴拱出树坑 → 没工具运肥料，小袋鼠用皮口袋运来肥料 → 没水桶，小象用长鼻子吸水浇树 → 小树栽好了，三个小伙伴手拉手围着小树，真高兴。

**⑨ 《好天气和坏天气》**（冰波）：老奶奶去看两个儿子：做蜜饯的大儿子盼晴天，做雨伞的小儿子盼下雨 → 老奶奶觉得晴天雨天都是坏天气，坐在门口哭 → 老爷爷让她倒过来想：晴天大儿子高兴，下雨小儿子高兴 → 老奶奶高兴起来：每天都是好天气。

**⑩ 《雨来了》**（儿歌，3 节）：雨来了，小蜗牛说不怕，把房子背来了；小蘑菇说不怕，备好伞一把；小甲虫说不怕，有一件防雨褂。

**⑪ 《书本里的蚂蚁》**（王一梅）：小蚂蚁睡在一朵红色小花的花蕊里，小姑娘把花夹进一本旧书，蚂蚁被夹扁，像一个字 → 书里的字和它说话，它成了一个会走路的字，每天在书里跑来跑去，书里的字也学着它活动起来 → 小姑娘打开旧书，每天都读到不一样的新故事 → 她看见书里的蚂蚁，明白了字每到晚上就走来走去 → 小姑娘再也没有买过故事书。

**⑫⑬⑭ 《小红帽（一）（二）（三）》**：
- （一）奶奶送给小女孩一顶红绒小帽，人们叫她「小红帽」→ 妈妈让她给生病的奶奶送蛋糕和葡萄酒，嘱咐她别离开大路 → 森林里碰见狼，她不知道狼凶残，把奶奶家在哪里告诉了狼 → 狼心里打算把她俩都吃掉。
- （二）狼劝小红帽看花听鸟，小红帽离开大路去采花 → 狼赶到奶奶家，骗开门，吞了奶奶，穿上奶奶的衣服躺在床上 → 小红帽到了奶奶家，问「奶奶，你的耳朵／眼睛／手怎么这么大啊」「你的嘴怎么大得可怕啊」→ 狼跳起来吞掉了小红帽。
- （三）猎人听见打鼾进屋，发现是狼，没开枪，剪开狼肚皮救出小红帽和奶奶 → 小红帽往狼肚里塞石头，狼醒来想逃，倒下摔死了 → 奶奶吃蛋糕、喝葡萄酒，精神好了起来 → 小红帽想：如果妈妈不允许，以后别再独自离开大路跑进森林深处。

- **片段1**
  - 定位：《勿贪多》全篇
  - 内容概述：抓了一大把糖，手卡在瓶口，妈妈说出道理。
  - 可引用原文（逐字，全篇）：
    放学了，小明回到家里，看见桌子上放着一个玻璃瓶，里面装满了花花绿绿的糖果，很诱人。
    小明急忙丢下书包，把手伸进瓶子里，满满地抓了一大把糖。可是他的手被瓶口卡住了，怎么也出不来。他越是使劲往外拉手就被卡得越疼。急得小明大哭起来。
    妈妈闻声赶来，看见他的样子，不禁笑了，说：“你啊！如果一次不拿这么多，手就容易拿出来了。记住，什么都不能贪多。”

- **片段2**
  - 定位：《一次比一次有进步》全篇
  - 内容概述：小燕子三次去菜园，一次比一次看得仔细。
  - 可引用原文（逐字，全篇）：
    菜园里，冬瓜躺在地上，茄子挂在枝上。
    屋檐下，燕子妈妈对小燕子说：“你到菜园里去，看看冬瓜和茄子有什么不一样。”小燕子去了，回来说：“妈妈，妈妈，冬瓜大，茄子小！”
    燕子妈妈说：“你说得对。你能不能再去看看，还有什么不一样？”小燕子又去了，回来说：“妈妈，妈妈，冬瓜是绿的，茄子是紫的！”
    “很好。可是，你能不能再去仔细看看，它们还有什么不一样？”小燕子又去了，回来高兴地说：“妈妈，妈妈，我发现冬瓜的皮上有细毛，茄子的柄上有小刺！”
    燕子妈妈笑了，说：“你一次比一次有进步！”

- **片段3**
  - 定位：《丁一小写字》全篇
  - 内容概述：丁一小先怪纸、再怪笔，看了姐姐写字才明白原因在自己。
  - 可引用原文（逐字，全篇）：
    丁一小写字，写来写去写不好。他想：“肯定是我的纸不好！”他把姐姐的纸拿来写。
    他用姐姐的纸写字，写来写去写不好。他想：“肯定是我的笔不好！”他把姐姐的笔拿来写。
    他用姐姐的纸、姐姐的笔写字，写来写去还是写不好。他想：“到底是什么原因呢？”
    姐姐拿起丁一小丢掉的纸和笔，坐得端端正正，一笔一笔认真地写。瞧，她写的字多工整！
    丁一小明白了：“不是我的纸、我的笔不好，是我自己不认真。”
    他像姐姐一样，坐得端端正正，一笔一笔认真地写。瞧，他的字也写好了。

- **片段4**
  - 定位：《乌鸦兄弟》全篇
  - 内容概述：兄弟俩三次都等对方修窝，最后窝被吹掉、两个都冻僵了。
  - 可引用原文（逐字，全篇）：
    乌鸦兄弟俩同住在一个窝里。
    有一天，窝破了一个洞。
    大乌鸦想：老二会去修的。
    小乌鸦想：老大会去修的。
    结果谁也没有去修。
    后来洞越来越大了。
    大乌鸦想：这下老二一定会去修了，难道窝都这样破了，他还能住吗？
    小乌鸦想：这下老大一定会去修了，难道窝都这样破了，他还能住吗？
    结果又是谁也没有去修。
    一直到了寒冷的冬天，西北风呼呼地刮着，大雪纷纷地飘落。乌鸦兄弟俩都蜷缩在破窝里，哆嗦地叫着：“好冷啊！好冷啊！”
    大乌鸦想：这样冷的天气，老二一定耐不住，他会去修了。
    小乌鸦想：这样冷的天气，老大还耐得住吗？他一定会去修了。
    可是谁也没有动手，只是把身子蜷缩得更紧了些。
    风越刮越凶，雪越下越大。
    结果，窝被吹到地上，两只乌鸦都冻僵了。

- **片段5**
  - 定位：《骆驼和羊》全篇
  - 内容概述：骆驼用吃树叶证明高好，羊用进矮门证明矮好，老牛评理。
  - 可引用原文（逐字，全篇）：
    骆驼长得高，羊长得矮。骆驼说：“长得高好。”羊说：“不对，长得矮才好呢。”骆驼说：“我可以做一件事情，证明高比矮好。”羊说：“我也可以做一件事情，证明矮比高好。”
    他们俩走到一个园子旁边。园子四面有围墙，里面种了很多树，茂盛的枝叶伸出墙外来。骆驼一抬头就吃到了树叶。羊抬起前腿，扒在墙上，脖子伸得老长，可还是吃不着。骆驼说：“你看，这可以证明了吧，高比矮好。”羊摇了摇头，不肯认输。
    他们又走了几步，看见围墙上有个又窄又矮的门。羊大模大样地走进门去吃园子里的草。骆驼跪下前腿，低下头，往门里钻，怎么也钻不进去。羊说：“你看，这可以证明了吧，矮比高好。”骆驼摇了摇头，也不肯认输。
    他们俩找老牛评理。
    老牛说：“你们俩都只看到自己的长处，看不到自己的短处，这是不对的。”

## 五、重复出现的事物/场景

- **篇内重复**：
  - 《一次比一次有进步》：小燕子三次去菜园、三次「妈妈，妈妈，……！」，发现一次比一次细（大小 → 颜色 → 细毛和小刺）。
  - 《丁一小写字》：「写来写去写不好」三次（自己的纸笔 → 姐姐的纸 → 姐姐的纸和笔）；「坐得端端正正，一笔一笔认真地写」姐姐一次、丁一小一次。
  - 《乌鸦兄弟》：大乌鸦想／小乌鸦想成对出现三轮，每轮后「结果谁也没有去修」「结果又是谁也没有去修」「可是谁也没有动手」。
  - 《三个小伙伴》：「没有……，怎么办呢？」「不要紧，不要紧，我有……」三轮。
  - 《骆驼和羊》：「你看，这可以证明了吧，高比矮好／矮比高好」「摇了摇头，不肯认输」各两次，一正一反。
  - 《雨来了》：「雨来了，快回家！」「……，说不怕」三节。
  - 《小红帽（二）》：「奶奶，你的……怎么这么大啊？」四问四答。
  - 《好天气和坏天气》：「儿子啊，你（现在）最盼望什么？」问两次；「好天气」「坏天气」在两个儿子口中正好相反。
- **跨篇复现的母题**（只记出现，不作关联解读）：
  - **妈妈教孩子**：《勿贪多》《自己去吧》《一次比一次有进步》《两只小狮子》《小红帽》。
  - **下雨**：《好天气和坏天气》（小儿子盼下雨）、《雨来了》。
  - **兄弟／两个儿子**：《乌鸦兄弟》、《好天气和坏天气》两个儿子。
  - **动物用身体本领做事**：《三个小伙伴》（嘴巴、皮口袋、鼻子）、《骆驼和羊》（高、矮）、《雨来了》（蜗牛壳、蘑菇伞、甲虫壳）。

## 七、贯穿全书的变化线索

- **全书层面：不适用**（无贯穿主线与固定主角）。
- 单篇可追踪的变化（降级候选）：
  - 《一次比一次有进步》·小燕子的发现：冬瓜大、茄子小 → 冬瓜绿、茄子紫 → 冬瓜皮上有细毛、茄子柄上有小刺。
  - 《丁一小写字》·丁一小找原因：怪纸 → 怪笔 → 「到底是什么原因呢？」→ 看姐姐写字 → 「是我自己不认真」→ 字也写好了。
  - 《乌鸦兄弟》·窝：破了一个洞 → 洞越来越大 → 冬天风雪 → 窝被吹到地上。
  - 《好天气和坏天气》·老奶奶：去两个儿子家 → 坐在门口哭 → 听老爷爷倒过来想 → 高兴起来。

## 档案使用提醒（事实层注意事项）

1. **【篇数与分篇】本书 14 个篇题、12 个故事／儿歌**：《小红帽（一）（二）（三）》是一个故事分三段，**须当一个完整故事用**；只用（一）或（二）会停在狼要吃人或刚吃了人的地方。
2. **【头号陷阱】不得当长篇梳理**：除《小红帽》外，各篇独立，下游任何产物**不得**做「全书情节主线梳理 / 全书成长曲线 / 人物关系总图」；角色不跨篇。
3. **无页码**：docx 无固定页码，定位一律「篇名 + 场景」。**任何下游产物中出现「第 X 页」均属编造。** ⚠ 《书本里的蚂蚁》正文里的「第一百页」「第五十页」「第二百页」是**故事里那本旧书的页码**，属于情节，不是本书页码，引用时不得混淆。
4. **寓意只引原文点明的**：《勿贪多》（妈妈：「记住，什么都不能贪多。」）、《骆驼和羊》（老牛：「你们俩都只看到自己的长处，看不到自己的短处，这是不对的。」）原文点明了道理；其余各篇原文没有一句点明道理的话，下游提炼道理时须明确是推断，不得写成「书上说……」。
5. **《乌鸦兄弟》的结局**：原文结尾是「窝被吹到地上，两只乌鸦都冻僵了」，没有写之后怎样，下游不得续写「后来它们修好了窝」之类当作原文。
6. **《三个小伙伴》本领与插图不符**：原文小袋鼠用皮口袋运肥料、小象用鼻子吸水浇树；`插-09` 画的是袋鼠抱树苗、小象没浇水。讲本领一律按原文，不拿这张图核。
7. **《小红帽》的内容提示（事实层，不作教学判断）**：原文写狼吞了奶奶和小红帽、猎人剪开狼肚皮、往狼肚里塞石头、狼摔死、猎人带着狼皮回家。复述时按原文措辞，不得增删。原文结尾小红帽的想法是「如果妈妈不允许，以后可别再独自离开大路，跑进森林深处去了」，引用时保留「如果妈妈不允许」这一前提。
8. **篇题后的「①」**：docx 多数篇题后带「①」注码（《勿贪多》《两只小狮子》《雨来了》无），docx 中没有对应的注文。引用篇名、上屏时一律去掉。
9. **docx 格式问题**：全文引号多为半角直引号、引号前后多有空格；《好天气和坏天气》老爷爷的一句话被拆成两段（见第四节注）。本档案已统一为中文弯引号、去空格、合段，**字词未改**。下游若直接从 docx 取字，须同样处理，并在投屏、齐读前对照纸本核一遍。
10. **作者署名**：《勿贪多》《骆驼和羊》《两只小狮子》《雨来了》《小红帽》这 5 个故事（7 个篇题）docx 未署作者与译者，**不得凭记忆补作者名**。
