### 分篇梗概

**一、儿歌／童诗（4 首）**

**① 《小小竹排画中游》**（儿歌）：写小竹排顺水而流，两岸有鸟、鱼、树木、禾苗，末句点出这是「江南鱼米乡」。无情节。

**② 《春水《六三》》**（童诗，5 行）：柳花飞时燕子来，芦花飞时燕子去，末句说柳花与芦花「一样的洁白」。无情节。

**③ 《小兔子乖乖》**（童谣，两段对唱）：门外有人唱「小兔子乖乖，把门儿开开」→ 小兔子答「不开」，因为妈妈没回来 → 门外再唱同样的话 → 小兔子答「就开」，因为妈妈回来了。⚠ **原文没有写第一次敲门的是谁**（见档案使用提醒）。

**④ 《青蛙写诗》**（童诗）：下雨了，青蛙要写诗 → 小蝌蚪说要当小逗号 → 水泡泡说能当小句号 → 荷叶上的一串水珠说可以当省略号 → 青蛙的诗写成了「呱呱，呱呱，呱呱呱……」。

**二、童话故事（5 篇）**

**⑤ 《松鼠和松果》**（林颂英）：松鼠学会摘松果吃，摘了一个又一个 → 忽然想到光摘不栽，总有一天松树会没有 → 想出办法：每次吃一个，就在土里埋下一个 → 春天埋松果的地方长出了小松树。

**⑥ 《三只白鹤》**：三只白鹤把吃剩的一条大鱼埋在地里 → 三只分别记住「太阳下面」「白云下面」「柳树旁边」→ 第二天，第一只朝太阳飞，第二只朝白云飞，第三只飞到大柳树旁 → 篇末以问句收尾：「哪只白鹤能找到埋在地里的大鱼呢？」**原文没有给出答案。**

**⑦ 《狗熊请客》**（樊发稼）：狗熊要在生日请朋友吃饭，但刚搬家、大家不知道新家在哪 → 他看见房顶上栖息着一只鸽子，决定在信里把「房顶上有一只鸽子」当作新房子的标记 → 生日那天准备了丰盛饭菜，从清早等到天黑，一个客人也没来 → 篇末以问句收尾，请小朋友想一想是怎么回事。**原文没有给出答案。**

**⑧ 《小猫咪穿鞋子》**：小猫咪羡慕人穿鞋，找来四只鞋子穿上 → 依次问公鸡、麻雀、大白鹅、大黄狗「这鞋子好看吗」「那你怎么不穿鞋子啊」，四位都说好看，又各说了自己不穿鞋的理由 → 小猫咪以为只有自己可以穿鞋 → 猫妈妈说猫的脚心像听诊器，穿鞋就感觉不出地面的动静 → 晚上小猫咪脱鞋，和妈妈一起把脚掌贴在地上，听出打夯、走路、纸片被风吹的声音 → 妈妈告诉他老鼠出洞了，他扑上去捉到一只大老鼠 → 从此再也不想穿鞋子。

**⑨ 《比画风》**（方轶群）：小猫、小狗、小猪一起画画，小猫说自己什么都会画 → 小狗问：你能画风吗？→ 三个伙伴轮流画：小猫画白云、小猪画烟囱冒的烟、小狗画被吹弯的小树、小猫画斜斜的雨丝、小猪画飘动的旗子、小猫画转动的纸风车、小猪画挂帆的木船 → 正画着，真的吹来一阵大风，把他们的帽子都吹走了。

**三、成语／俗语故事（6 篇）**

**⑩ 《胸有成竹》**：宋朝画家文与可爱画竹，院里栽满竹子，每天观察 → 一幅新画的嫩竹被猫当成真竹子抓着玩 → 有人问秘诀，他说竹子的样子就在心中，只是把心中的竹子画到纸上。

**⑪ 《画龙点睛》**：梁朝画家张僧繇在安乐寺墙上画了四条龙，都没点眼睛 → 他说点上眼睛龙就会飞走，大家不信、一再要求 → 他点上其中两条的眼睛，随即电闪雷鸣，两条龙飞向天空，没点眼睛的两条留在墙上。

**⑫ 《望梅止渴》**：曹操带兵路过无水之地，找水、挖井都不成 → 他大声说「有水啦」，又说前面有一大片梅林 → 将士们想到梅子的酸味，嘴里流出口水，不那么难受了 → 大军继续前进，走出了这个地方。

**⑬ 《磨刀不误砍柴工》**：老人给两个儿子各一把没开刃的斧子，比谁砍柴多、回来早 → 大儿子拿斧就上山，斧子太钝，砍不倒树，累得腰酸背疼 → 小儿子先到井边把斧子磨锋利，很快砍了一大捆 → 太阳偏西小儿子挑着一担柴回家，太阳落山大儿子才背着一小捆回来 → 老人说出「磨刀不误砍柴工」。

**⑭ 《程门立雪》**：宋朝杨时先后拜程颢、程颐为师 → 一次与同学游酢冒雪去请教程颐，程颐正午睡，两人不忍打扰，站在门外等 → 程颐醒来时门外积雪已一尺多厚，两人成了雪人 → 末段说明两人当时学问已高，仍如此谦虚、尊敬师长，故事被传为美谈。

**⑮ 《惊弓之鸟》**：魏国射箭能手更羸随魏王打猎，说不用箭、只拉弓就能让大雁掉下来 → 拉弦一响，大雁往上飞、拍了两下翅膀就掉了下来 → 更羸解释：这只大雁飞得慢是因为受过箭伤，叫得悲惨是因为失群，听到弦响拼命往高处飞，伤口裂开就掉了下来。

  - 内容概述：兄弟俩拿同样没开刃的斧子砍柴，一个直接上山、一个先磨斧，结果相反，老人点出俗语。

    从前有位老人，他有两个儿子。
    两个儿子长大了，老人想考考他们。一天，他从集市上买回两把没开刃的斧子，对他的两个儿子说：“你俩一人拿一把斧子上山去砍柴，看谁砍得多，回来得早。”
    大儿子想：要砍得多、砍得快，就得抓紧时间。于是他赶忙拿起斧子、扁担和绳子，匆匆上了山。到了山上，他拼命地砍啊砍，但是，因为斧子太钝，砍了十几下，连一棵小小的枯树也没砍倒。不一会儿，他就累得腰酸背疼了。
    小儿子从父亲手里接过斧子一看，斧刃厚厚的，就赶紧到井边去磨，不一会儿就磨锋利了。他拿上锋利的斧子和扁担、绳子，来到了山上，几下就砍倒了一棵枯树，很快砍了一大捆柴。
    太阳刚刚偏西，他就挑着沉甸甸的一担柴回家了。
    太阳落山了，大儿子才背着一小捆柴，疲惫地回到家里。老人看看他们砍的柴，又看看他们的斧子，意味深长地说：“你们两个，上山早、花力气大的是老大，下山早、砍柴多的是老二。为什么呢？这是因为老二在砍柴前先磨快了斧子。这就叫作‘磨刀不误砍柴工’啊！”

## 五、重复出现的事物/场景

- **篇内重复的句式（本书最突出的形式特征）**：
  - 《小兔子乖乖》：「小兔子乖乖，把门儿开开。快点儿开开，我要进来」前后出现两次，字句相同（标点有差，见片段1注），答句一「不开」一「就开」。
  - 《小猫咪穿鞋子》：「这鞋子好看吗？」「好看！好看！」「那你怎么不穿鞋子啊？」三句一组，重复四轮（公鸡→麻雀→大白鹅→大黄狗）；晚上听声音「咚！咚！／嚓！嚓！／沙！沙！＋妈妈说」重复三轮。
  - 《比画风》：「风画出来了！」出现三次（小猫画白云、小猪画烟、小猪画旗子）；「你还能画吗？」「我还能画！」轮流出现。
  - 《三只白鹤》：「第一只……第二只……第三只……」在记位置、第二天去找两处各出现一轮。
  - 《青蛙写诗》：「……说：我要／我能／我们可以当……号」三轮。
- **跨篇复现的母题**（只记出现，不作关联解读）：
  - **画画**：《比画风》（动物画风）、《胸有成竹》（文与可画竹）、《画龙点睛》（张僧繇画龙）三篇都写画画；后两篇都写「画出来的东西被当成／变成真的」——猫把画上的竹子当成真的、点了眼睛的龙飞走了。
  - **篇末留问不给答案**：《三只白鹤》《狗熊请客》两篇以问句收尾。
  - **鸟**：《小小竹排画中游》「鸟儿唱」、《春水《六三》》燕子、《小猫咪穿鞋子》麻雀、《比画风》树上的小鸟、《狗熊请客》鸽子、《惊弓之鸟》大雁。
