## ⚠ 结构性事实声明（动笔前必读）

**本书是寓言合集，不是长篇故事。** 电子版共 **71 则**寓言，**篇与篇之间没有任何情节主线、没有贯穿始终的固定主角、没有先后因果**；拆成 71 篇后每篇仍独立成立。角色虽反复出现（狐狸出现在 8 篇、狼出现在 7 篇、狮子出现在 6 篇、猴子出现在 4 篇），但**同名角色在不同篇里是不同的个体**——《乌鸦和狐狸》里骗到乳酪的狐狸，与《狐狸和葡萄》里够不着葡萄的狐狸、《悔过的狐狸》里当上看鸡人的狐狸，彼此毫无关系，**不得当作同一只狐狸的连续经历**。

由此推出四条硬约束，下游任何产物均适用：

1. **禁做全书级的情节梳理**（故事山、事件链、时间轴、人物关系总图）——没有全书情节可梳理。
2. **禁做全书级的成长曲线/变化阶梯**——没有贯穿人物，无从追踪变化。
3. **对照只能发生在篇与篇之间**（篇 A ↔ 篇 B），这是本书最有价值的取材面，见第六节。
4. **定位一律用「篇名 + 场景」**。本书电子版**无固定页码**，任何产物中出现「第 X 页」均属编造。

**另一条与长篇书完全不同的体例事实：本书大多数篇目自带作者写明的「寓意」段。** 呈现方式有三种，须分清（否则会把作者的话当成叙述、或把没写的道理替它编一句）：

| 呈现方式 | 篇数 | 说明 |
|---|---|---|
| **寓意在篇首**，与故事之间用一行 `×××` 分隔 | 13 篇 | 先说理、后讲故事。如《乌鸦和狐狸》《狼和小羊》《猎人》《隐士和熊》 |
| **寓意在篇末**，故事之后用一行 `×××` 分隔 | 29 篇 | 先讲故事、后点题。如《磨坊主》《特利施卡的外套》《猴子和眼镜》 |
| **无 `×××` 分隔** | 29 篇 | 又分两类：一类由角色末句台词承担（《四重奏》夜莺的话、《树叶和树根》树根的话、《勤勉的熊》农夫的话）；一类**完全不点明**（《狐狸和葡萄》《狼和鹤》《狮子打猎》《农夫和羊》） |

**`×××` 是电子版的分隔符，不是原书排版**，不得抄进任何对外产物。**「完全不点明」的那些篇，绝不许替作者补写一句道理**——那正是这本书留给读者自己想的地方。

**1. ★乌鸦和狐狸**（389 字）｜乌鸦得到一小块乳酪、叼在嘴上准备吃早餐 → 狐狸闻香而至，接连夸它的脖子、眼睛、羽毛、嘴，说它若会唱歌准是鸟中之王 → 乌鸦昏头昏脑，提高嗓门大叫 → 乳酪掉落，被狐狸叼走。｜**寓意**（篇首）：“已经向人们说过不知多少次，奉承拍马是卑鄙而且有害的。可总是没有用处，奉承拍马的人，总会在我们心里钻到空子。”

**2. 橡树和芦苇**（529 字）｜十月里橡树对芦苇说它连一只麻雀都负担不了、一丝微风就发抖，自夸威严挺立、可以给芦苇遮荫 → 芦苇答自己虽摇摆却绝不折断，反倒是橡树危险 → 雹雨北风骤至，芦苇伏倒，橡树被连根拔起。｜**寓意**：原文未点明（由结局本身承担）。

**3. 青蛙和牯牛**（190 字）｜青蛙看到牯牛想比大小，鼓起肚子拼命胀 → 同伴三次回答“差得远哩”“一点儿也没，看不出来”“还是老样子嘛” → 青蛙把肚皮胀破，死了。｜**寓意**：原文未点明。

**4. 山雀**（326 字）｜山雀夸口要把大海烧干，消息传遍全世界，鸟兽聚集、猎人带汤匙来赴宴喝鱼汤 → 众人默默等待，海没有烧起来，也没有发烫 → 山雀满怀羞愧飞走。｜**寓意**（篇末）：“尽管并不是具体针对哪一个人，但这里我还是要补充一句：事情还没有做成，就不应该夸下海口。”

**5. 鹰和鸡**（433 字）｜鹰从高空飞落，歇在烤干棚上，又飞到另一个棚 → 孵蛋的鸡对同伴说鹰没什么可尊敬的、自己也能从这个棚飞到那个棚 → 鹰答“鹰有时候飞得比鸡还低，但鸡却永远不能高飞到云里去!”｜**寓意**（篇末）：“当你看出人家有才能的时候，不要白白浪费精力去吹毛求疵，而应该看到人家的优点和长处，向人家学习，迎头赶上去。”

**6. 狗的友谊**（713 字）｜看家狗波耳亢和巴尔鲍斯晒太阳闲聊，越谈越投机，约定做这一时代的友谊榜样、握爪拥抱亲吻 → 厨子从厨房扔出一根骨头 → 两狗争先扑上去互相撕咬、狗毛乱飞，最后用一盆冷水才分开。｜**寓意**（篇末）：“世上到处充满这样的友谊……听上去，好像两人一条心，可是只要扔给他们一根骨头，就会像上面的两只狗一样。”

**7. 蜘蛛和蜜蜂**（459 字）｜商人的布匹销路好、顾客蜂拥 → 蜘蛛眼红，整夜不睡在窗台织网，打扮得漂漂亮亮坐等顾客 → 天亮拖把一抹，网和“铺子”都掉了下来 → 蜘蛛问谁织得漂亮，蜜蜂答蛛网不能当衣服穿、不会蔽寒取暖。｜**寓意**（篇首）：“无论怎样引人注目，我还是要把你的聪明估计得很低，除非你的聪明的确能够有益于人。”

**8. 椋鸟**（331 字）｜椋鸟从小学会金翅雀的叫声、叫得以假乱真、人人赞扬 → 它眼红众人赞夜莺，改学夜莺 → 唱出叽喳咝沙、羔羊咩咩、小猫喵喵的怪调，把鸟全吓跑。｜**寓意**（篇首）：“各人有各人的才能，可有些人往往对别人的成就感到眼红，干着根本不适合自己的事情……如果你想在事业上获得成就，那你应该做适合你的事业。”（篇末另有一句：“好好地唱得像金翅雀，总比拙劣地学夜莺叫要来得好。”）

**9. 蚂蚁大力士**（625 字）｜蚂蚁力气大、能背两颗麦粒、敢咬蛆虫斗蜘蛛，在蚁冢内声名大盛 → 听多了赞美，坐上干草车进城显身手 → 拖树叶、翻筋斗、跳跃，没有人瞧、没有人注意 → 对猫抱怨城里人糊涂盲目 → 那天回家时变得聪明些了。｜**寓意**（篇末，原文照录·句首的引号是原书强调用法）：“聪明”的蠢才就是这样的没有自知之明，自以为名满天下，恍然大悟时方才知道自己的名声仅仅限于蚁冢的范围而已。

**10. 勤勉的熊**（229 字）｜熊见农夫做车轭赚钱，也去砍树；白桦、胡桃、榆树砍倒无数，车轭却一根也做不成 → 请教农夫，农夫说顶要紧的是“你所没有的东西——耐心”。｜**寓意**：原文未另设寓意段，由农夫末句承担。

**12. 狮子和蚊子**（526 字）｜狮子轻视蚊子，蚊子挑战决战 → 从后面、眼睛、耳朵、背上、额头、鼻孔轮番叮咬 → 狮子狂怒吼叫、爪子乱刨，野兽全逃散 → 狮子筋疲力尽倒地求饶 → 蚊子讲和后飞到森林宣扬胜利。｜**寓意**（开篇议论，无 `×××`）：“对无力的弱者不要讥笑，对无力的弱者不要欺侮!无力的敌人有时也会作强有力的报复。因此，不要过分相信你自己的威力!”

**13. ★四重奏**（511 字）｜猴子、驴子、山羊、笨熊拿来乐谱和四件乐器要演四重奏，咿咿呀呀奏不出名堂 → 猴子说位子没坐对、驴子说该坐成一排，重排两次都不成，吵得更凶 → 请教路过的夜莺 → 夜莺说要有娴熟的技巧和敏锐的听觉，“无论你们怎样坐，你们一个也不配当演奏家”。｜**寓意**：原文未另设寓意段，由夜莺末句承担。

**14. ★树叶和树根**（431 字）｜夏天树叶向和风夸耀自己茂密壮观、给牧童路人歇凉、招引牧女跳舞、黄莺来婉转歌唱 → 地下发出一个谦虚温和的声音，要求也感谢感谢树根 → 树叶斥其无耻、竟敢来争长短 → 树根说自己深埋地下黑暗里，春天树上还会生新叶，但树根枯了树也枯，树叶也就完蛋。｜**寓意**：原文未另设寓意段，由树根末句承担。

**16. 小箱子**（374 字）｜有人拿来一只精致锃亮、连锁都没有的小箱子 → 聪明工匠自称有两手，转来转去、按这只钉那只钉，绞尽脑汁、汗出了又出，最后疲倦透了只得放下 → 其实小箱子没有什么机关，一打就开。｜**寓意**（篇首）：“我们常常遇到这样的情况：有些事看起来很复杂，其实只需稍稍用心揣摩一下，事情就会极其简单。”

**17. ★杰米扬的汤**（488 字）｜杰米扬一个劲儿劝老福卡喝鱼汤，福卡说吃不下、已吃过三盆 → 杰米扬不让他休息不让他停止，福卡大汗如注又吃了一盆、还装作津津有味 → 杰米扬叫“好，再来一盆吧” → 福卡赶紧拿起帽子腰带手杖，用足全力跑回家，再也不上门。｜**寓意**（篇末）：“我的作家，你不妨自认为是稀有的天才，可是如果你不懂得适当的节制，老是在人家的耳旁聒噪不休，久而久之，你的诗歌和散文，就要比杰米扬的汤更加令人讨厌。”

**18. 狮子和狐狸**（109 字·全书最短）｜狐狸初次见到狮子差一点儿吓死 → 过些日子再见，觉得狮子好像并不可怕 → 第三次索性同狮子讲起话来。｜**寓意**（篇末，分行诗体）：“有种东西当我们还没有把它仔细琢磨，／我们总是这样感到害怕。”

**19. 一只桶**（310 字）｜有人借朋友的桶用两三天，桶还回来跟以前一样能盛水 → 只是借桶的人用它盛过酒，从此桶里老是散发酒味、放进去的任何东西都带酒味 → 主人蒸了晾、晾了蒸折腾将近一年，酒味消不掉，最后只好把桶丢掉。｜**寓意**（篇末）：“做父亲的人，你们千万不要忘记这个寓言。年轻人沾染了不好的习气，哪怕只沾染过一次，往后在他的一切言行里，照样全部反映出来。”

**20. 卵石和钻石**（339 字）｜钻石被商人偶然发现、献给国王、镶上金子做了皇冠的装饰品 → 卵石羡慕，求乡下人带它上京城 → 乡下人把它装上大车带进城 → 卵石确实派上了用场，不过只是用来铺路筑道。｜**寓意**：原文未点明。

**70. 公鸡和珍珠**（142 字·分行诗体）｜公鸡在肥料堆里翻掘扒找，忽然发现一颗珍珠 → 他说这东西有什么用处、无非是毫无价值的废物、人们把它抬得这么高岂不愚鲁；在我看来，能找到一粒大麦要高兴得多，尽管并不起眼，但能够吃饱下肚。｜**寓意**（篇末）：“无知的人总是这样判断事情，／凡是他们不理解的东西，他们都觉得无用。”

**71. 小乌鸦**（453 字·后半分行诗体）｜一只兀鹰从天空扑向羊群，抓走一只小羊羔；一只年岁不大的乌鸦看在眼里，心动了：要抓就该抓大的，否则何必把爪子弄脏 → 它飞临羊群上空，从众多羊羔、公羊、母羊中反复观察比较，最后挑中一头巨大肥壮、只有结实的狼才能对付的公羊 → 摆好架势扑下去、使尽全力紧抓羊毛，这才知道猎物吃不消；羊毛浓密蓬乱错综缠绕，爪子怎么也拔不出来，自己反倒当了俘虏 → 牧羊人把他解下来，剪光翅翼，送给孩子们耍弄。｜**寓意**（篇末）：“人与人之间也常常发生同样的事情，／如果一个小骗子要去模仿／大骗子：／大盗巨贼滑了过去，小偷小摸却挨打挨揍。”

  - 定位：狼和小羊 · 河边五个回合的对答
  - 内容概述：狼每提一条罪名，小羊都当场辩倒；狼最后不再找理由，直接宣布罪状就是“我要把你吃掉”。
  - 可引用原文（逐字，成段）：“那倒是我在撒谎喽?!世上从来没有见过，像你这样横蛮无理的!
    “哦，我想起来了，前年夏天吧，你还在这里得罪过我，朋友，这是我永远不会忘掉的!”
    “请原谅!我从娘胎出生还不到一年。”小羊说。
    “那准是你的哥哥。”
    “我没有哥哥。”
    “那一定是你的干亲或是亲家一伙，总而言之，是你们的一路货，你们自己，你们的牧人和你们的牧羊犬，你们个个都想来谋害我，一有机会，总想把我一口吞掉，他们欠下的这一笔债，今天我就来跟你清算。”
    “哎呀，我有什么罪呢?”

  - 定位：天鹅、梭子鱼和虾 · 三个方向拉一辆车（全篇正文）
  - 内容概述：三位用尽力气，车却纹丝不动；原因是三个方向。
  - 可引用原文（逐字，成段）：一天，梭子鱼、虾和天鹅，想一起拉动一辆装满东西的小车。他们用足狠劲，身上青筋根根暴起。可是无论他们怎样地拖呀，拉呀，推呀，小车还是在原地，一点儿也没有移动。倒不是小车重得动不了，而是另有缘故：天鹅使劲往天上冲，虾努力向后倒拖，梭子鱼又朝着池塘拉。究竟哪个对，哪个错，我不知道，我也不想寻根究底，我只知道小车还是停在老地方。

- **片段5**
  - 定位：狐狸和葡萄 · 够不着之后（全篇正文）
  - 内容概述：狐狸盯着葡萄眼睛牙齿发亮，够不着，走时说葡萄没成熟、都是酸的。
  - 可引用原文（逐字，成段）：饥饿的狐狸越过果园的墙头，看到了一串串的葡萄。狐狸的视线一落到葡萄上，眼睛和牙齿都发亮了。多汁的葡萄在阳光中亮晶晶的像碧玉一般，唯一的遗憾是葡萄都挂得高高的，狐狸无论怎样也够不着，眼睛瞅得见，牙齿可咬不着!
    白费了整整一个钟头，狐狸只好跑开去了。走的时候，他愤愤地说道：“算了!虽然看上去挺好，实际上却都没成熟!没有一颗不是酸的!我又何必叫我的牙齿酸得咯咯咯地发响呢?”

- **片段6**
  - 定位：猴子和眼镜 · 摆弄眼镜与摔碎眼镜
  - 内容概述：猴子把眼镜戴在头顶、套在尾巴、嗅、舔，都不管用，于是骂人骗它、把眼镜摔碎。
  - 可引用原文（逐字，成段）：后来他弄到了一副眼镜，翻来弄去，一会儿把它带在头顶上，一会儿把它套在尾巴上，一下把它嗅嗅，一下把它舔舔，无论怎样摆弄，眼镜却不起作用。
    “呸，见它的鬼!”猴子嚷道，“傻瓜才会相信人们的那套鬼话。什么眼镜不眼镜，完全是在捉弄我，其实一点儿用处也没有。”
    猴子又气又难受，抓起眼镜向石头摔去，只见玻璃碎片闪闪飞溅。

- **片段7**
  - 定位：特利施卡的外套 · 两次改衣（全篇故事部分）
  - 内容概述：截袖补肘，袖子短了；被人嘲笑后，又截下摆补袖子，衣服更古怪，他却得意洋洋。
  - 可引用原文（逐字，成段）：特利施卡发现外套袖管的肘部磨破了，“行，那不费什么时间。几根线，一根针，一缝就成!”他把袖管截下四分之一，补在肘部。外套好好的，跟新的一模一样，只是袖管短了四分之一。得了，得了，就是短点儿，穿着又何妨呢?
    可是瞧啊，街上的人都在嘲笑他。“嘿，我又不是傻瓜，”特利施卡说道，“我一定使他们立刻闭嘴。我自有办法补救!谢天谢地!我会把袖子拼得比原来还要长哩!”
    他把下摆截下来，补好了袖管。虽然他穿了件古怪的外套，虽然一般的外套都要比他的长得多，可是特利施卡却得意洋洋。

- **片段8**
  - 定位：磨坊主 · 迁怒于鸡
  - 内容概述：磨坊无法工作后，磨坊主去勘查漏水原因，却看见鸡在河边喝水，拿木棒把鸡全打死。
  - 可引用原文（逐字，成段）：于是他到水闸那里，仔细勘查漏水的原因，他忽然看到，有几只鸡在河边喝水。
    “这些畜生，”他连忙嚷起来，“你们不来偷水喝，我已经感到水不够用了，你们再来偷水喝，我的水就更少了。”
    于是他拿起木棒，把鸡统统打死了。
    难道这就是磨坊主改正他错误的办法吗?
    结果，他走进自己住处，水没有了，鸡也没有了。

- **片段9**
  - 定位：大象和哈巴狗 · 哈巴狗的自白
  - 内容概述：小狗劝哈巴狗别出丑，哈巴狗说出自己吠叫的真实动机。

## 五、重复出现的事物/场景

> 本书为合集，以下均为**跨篇复现的母题**（不是同一件事物），只记客观复现情况。

- **动物开口讲道理**：几乎每篇皆是；讲道理的一方与做事的一方常常不是同一个（《狗的友谊》两狗先论友谊后抢骨头、《小猫和八哥》八哥讲道理小猫动口、《仁慈的狐狸》狐狸号召众鸟出力）。
- **法庭与审判**：《梭子鱼》（法官是驴马山羊、检察官是狐狸）、《农夫和羊》（法官是狐狸）、《青蛙们要一个国王》（鹤王边吃边审）。三篇互不相干，但都写“判决”。
- **一个人/一只动物夸口，随后被事实打脸**：《山雀》（要烧干大海）、《蚂蚁大力士》（进城显身手）、《大象和哈巴狗》（对大象吠叫）、《撒谎的人》（山岳般的黄瓜）、《鹰和蜘蛛》（蜘蛛自称不比鹰低）。
- **舍不得小的、丢掉大的**：《狐狸》（舍不得尾巴上一撮毛）、《贪心的人和母鸡》（想要鸡肚子里的金子）、《命运女神和乞丐》（再来一小把）、《磨坊主》（心疼鸡喝的水）。
- **“帮忙”反而坏事**：《隐士和熊》（砸石头赶苍蝇）、《苍蝇和马车》（自称干了一切工作）、《小树》（求人砍掉四周的树）、《农夫和雇工》（救命反被骂）。
- **桶**：《一只桶》（染上酒味的桶）、《两只桶》（车上一满一空两只桶）。两篇的桶毫无关系。

## 六、可作横向对照的内容（篇际对照）

> 合集最有价值的取材面。**只列可对照的维度，不下结论**。所涉原文均已在第四节备齐。

- **对照组 A：《乌鸦和狐狸》↔《布谷鸟和公鸡》**；可对照维度：谁在奉承 / 奉承的话说了什么 / 被奉承者的反应 / 结果谁吃亏。（前者是单向奉承、有人得利有人失物；后者是互相吹捧、被第三者当场戳穿。）
- **对照组 B：《狼和小羊》↔《农夫和羊》**；可对照维度：被告是谁 / 指控的理由 / 被告的辩解 / 判决怎么下 / 结局。（两篇的被告都是羊，一篇由狼直接吞，一篇走完了整套法庭程序，结果相同。）
- **对照组 C：《狐狸和葡萄》↔《公鸡和珍珠》**；可对照维度：面对的是什么东西 / 得到了没有 / 说了什么话 / 说的话是否与事实相符。（一个够不着就说酸，一个够得着却说没用。）
- **对照组 D：《天鹅、梭子鱼和虾》↔《四重奏》**；可对照维度：几位参与 / 各自使的力气 / 出了什么问题 / 有没有第三方点破。（前者无人点破、车停在原地；后者夜莺一句点破。）
- **对照组 E：《狗的友谊》↔《狗、人、猫和鹰隼》**；可对照维度：结盟时说了什么 / 考验是什么 / 谁守住了谁没守住。（前者两位都没守住，后者四位中只有狗守住。）
- **对照组 F：《隐士和熊》↔《苍蝇和马车》**；可对照维度：帮忙的动机 / 帮忙的具体动作 / 实际起到的作用 / 被帮的一方结局。（一个真心帮忙害死了朋友，一个根本没帮上却居功。）
- **对照组 G：《一只桶》↔《两只桶》**；可对照维度：桶的状态 / 影响到了什么 / 作者点明的道理。（两篇同以桶起兴、道理完全不同，是“同一件东西讲两个理”的现成例子。）
- **对照组 H：《特利施卡的外套》↔《磨坊主》**；可对照维度：最初的小毛病是什么 / 采取了什么办法 / 办法带来了什么新问题 / 最后剩下什么。（一个越补越短，一个越修越没有。）
- **对照组 I：《橡树和芦苇》↔《小树》**；可对照维度：谁在说话 / 对“遮蔽”的看法 / 风暴来时各自的处境。（一个嫌自己不够强，一个嫌别人挡着自己。）
- **对照组 J：《猴子和眼镜》↔《猴子和镜子》**；可对照维度：面对的器物 / 用它做了什么 / 别人怎么说 / 最后怎么处理。（同为猴子、同为一件能“看清”的器物，一个摔碎、一个当耳边风。）
- **对照组 K：寓意点明与否 —— 《狼和小羊》（篇首点明）↔《狐狸和葡萄》（全篇不点）**；可对照维度：作者说了没有 / 读者要不要自己想 / 两种写法读起来有什么不同。（这是本书**体例层面**的对照，第三节的三种寓意呈现方式即其事实基础。）

## 档案使用提醒（事实层注意事项）

1. **无页码陷阱**：本书电子版**无固定页码**（无封面、无版权页、无目录）。**任何下游产物中出现“第 X 页”均属编造**；定位一律用「篇名 + 场景」。插图上残留的印刷页码（23/81/143/171/185）**不是本电子版的页码**，同样不得引用。

2. **合集陷阱（头号）**：**不得把本书当长篇梳理**。全书 71 篇无主线、无贯穿人物，**禁做全书情节主线梳理、全书成长曲线、人物关系总图**；这类工具只能落到单篇，且本书单篇多为百字到数百字的小故事，多数篇目连“故事山”都撑不满——可用的单篇候选已在第七节列出，超出该范围即无事实依据。

3. **⚠ 电子版的标点缺陷（引用前必读）**：电子版正文的**叹号与问号全部是半角** `!` `?`（如“你多么漂亮啊!”），另有零星半角括号与半角逗号混入（如《贪心的人和母鸡》“有一个人(他是谁?我也不知道),他不懂得手艺”、《小猫和八哥》‘“我的朋友”,八哥说道’、《农夫和雇工》“还要问为什么,笨蛋!”）。第四节的引文**照原样录入**。下游引用时：
   - **可以**把半角 `!` `?` `,` `(` `)` 规范为全角——这是排版规范化，不算改动文字，且项目全角标点铁律要求如此；
   - **不可以**改动任何一个汉字。
   - 另有两处**引号混用**：《狗的友谊》里波耳亢与巴尔鲍斯互称奥烈斯特、庇拉德那一句，以及《四重奏》里猴子那句「叫树林哪，山岭啊，都会和着咱们的音乐节奏跳起舞来」的收尾——这两处的**收尾引号在电子版里是 ASCII 直引号 U+0022**，其余全书用的是中文弯引号。属电子版转换缺陷，引用时统一为弯引号即可，不算改字。

4. **寓意的三种呈现，不可混同**（详见第三节的表）：13 篇寓意在篇首、29 篇在篇末、29 篇无 `×××` 分隔。后一类里，一部分由**角色台词**承担（夜莺、树根、农夫、宝刀的末句），另一部分**作者完全不点明**（《狐狸和葡萄》《狼和鹤》《狮子打猎》《农夫和羊》《杂色羊》等）。**对不点明的篇目，绝不许替作者补写一句道理**——那是本书留白之处，也是最好的思辨入口。同理，**`×××` 是电子版的分隔符、不是原书排版**，不得抄进任何产物。

5. **同名角色不是同一个**：狐狸出现在 12 篇、狼 7 篇、狮子 6 篇、猴子 4 篇、熊 7 篇，**篇篇是不同的个体**。不得写“狐狸在书里先骗了乌鸦，后来又去偷鸡”这类跨篇串联；也不得据此做“狐狸性格发展”一类分析。**《狐狸》一篇里的狼是救助者**（咬掉狐狸尾巴使其脱身），与其它篇里的狼形象相反，尤其容易写错。

6. **人名陷阱**：**“福卡”在两篇里是两个不相干的人**——《杰米扬的汤》里被劝汤的客人叫老福卡，《一个遭遇不幸的农夫》里出主意的邻居也叫福卡。引用时须带篇名。全书专名极少（杰米扬、福卡、特利施卡、斯捷潘、卡尔贝奇、克里梅奇、克里母、波耳亢、巴尔鲍斯、茹奇卡），**除此之外的角色一律没有名字，不得为教学方便替它们起名**。

7. **《椋鸟》有两处寓意**：篇首 `×××` 前一段（“各人有各人的才能……”）与篇末最后一句（“好好地唱得像金翅雀，总比拙劣地学夜莺叫要来得好。”）。引用时须说明取的是哪一处，不得把两处拼成一句。

8. **《狮子和狐狸》极短（109 字）且分行排印**，故事只有三句、寓意两行诗。**它不足以支撑一个完整教学环节**，若要用只能作对照或引子。

9. **书内/书外边界**：本档案第一、二、九节**没有任何书外信息可用**（电子版无前言后记）。第四节「关键片段」与「备用引文池」是**唯一**可逐字引用、可冠以“书里写道”的内容。作者生平、创作年代、俄国社会背景、本书在中国的出版流传情况——**电子版一概没有，一律不得凭记忆补写**，需要就交人工补充并标 `【书外·来源：xxx】`。
