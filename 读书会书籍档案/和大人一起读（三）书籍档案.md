### 分篇梗概

**一、童话与生活故事（4 篇）**

**① 《象鼻桥》**（经绍珍）：大雨冲坏了小桥，两岸的动物都等对方去修，桥一直没修好，大家很不方便 → 一天清早，两只大象站在两岸，把长鼻子搭在一起，架起「象鼻桥」→ 两只大象静静站了好几天，动物们感动又惭愧，齐心修了新桥 → 给新桥起名叫「象鼻桥」。

**② 《下雨了》**（赵骥良）：下雨了，奶奶担心没带伞的小玲淋湿 → 小玲回来，衣服没湿，是同学小敏送她回来的，奶奶说小敏是好孩子 → 带了伞的小宝却全身湿透回来，奶奶以为他把伞弄丢了 → 小宝说把伞借给了路远的同学 → 奶奶说他也是个好孩子。

**③ 《三个儿子》**（[苏联] 符·奥谢耶娃）：三个妈妈在井边打水，两个夸自己的儿子聪明有力气、唱歌好听，第三个说儿子「没什么特别的地方」，老爷爷坐在旁边休息 → 三个妈妈拎水回家，走走停停，很累 → 迎面跑来三个孩子：一个翻跟头，一个唱歌，一个接过妈妈的水桶提着走了 → 老爷爷说：「我可只看见一个儿子。」

**④ 《七颗钻石》**（[俄国] 列夫·托尔斯泰，王志耕 译）：大旱灾，小姑娘夜里为生病的母亲找水，累得睡着，醒来水罐里装满了水 → 她自己没喝，跑回家时被小狗绊倒，水却没洒，她喂小狗喝水，水罐变成银的 → 母亲让她喝，水罐又变成金的 → 过路人讨水，她把水罐递给过路人，水罐里跳出七颗钻石、涌出清水 → 七颗钻石升上天，变成七颗星星，就是大熊星座。

**二、民间故事与神话传说（6 篇，含两组分篇）**

**⑤⑥ 《金斧头（一）（二）》**（鲁风）：
- （一）穷孩子程实在地主家干活，砍柴时把斧头掉进深河，急哭了 → 白胡子老爷爷下河，先后捞上金斧头、银斧头，程实都说不是自己的 → 捞上铁斧头，程实说是自己的 → 老爷爷说他诚实，随后不见了，原来是位仙人。
- （二）地主听说程实不要金斧头、银斧头，气得直跺脚 → 装成打柴的穷人，故意把破斧头扔进河里大哭 → 老爷爷捞上铁斧头，地主说不是；捞上银斧头，地主说最好要金的 → 老爷爷捞上金斧头，地主两手各拿一把金、银斧头，笑得合不拢嘴 → 老爷爷不见了，地主高兴得又蹦又跳，一脚踏空掉进河里 → 程实用自己的铁斧头砍柴卖，一家人生活得越来越好。

**⑦ 《除三害》**（朱家栋）：周处年轻时横行霸道，村民把山里的猛虎、河里的恶龙和周处合称「三害」→ 有人出主意夸周处本领高，让他去杀虎斩龙 → 周处打死老虎，又下河和恶龙搏斗三天三夜，没了动静 → 人们以为三害都除了，欢呼起来 → 周处浑身是伤爬上岸，听到人们的话，呆住了 → 他认识到自己的错误，痛改前非，成了受人敬重的人。

**⑧⑨ 《包公审石头（一）（二）》**（鲁风、吕倩如）：
- （一）爸爸死了、妈妈病了的小孩儿卖油条，卖得一百个铜钱，铜钱被他油乎乎的手弄得油乎乎的 → 他坐在石头上睡着了，醒来钱全没了，哭起来 → 包公路过，说一定是石头偷了钱，要审问石头。
- （二）人们跑来看热闹 → 包公审石头，石头不说话，包公叫手下打石头 → 看热闹的人笑包公糊涂，包公罚每人往水盆里丢一个铜钱 → 有一个人丢下铜钱后水面浮起一层油花，被抓住 → 小偷把一百个铜钱还给小孩儿，大家明白了包公审石头的用意。

**⑩ 《哪吒闹海》**（洪汛涛）：李靖的儿子哪吒一出生，太乙真人收他为徒，送他乾坤圈和混天绫 → 七岁时在东海洗澡，巡海夜叉凶他，哪吒用乾坤圈打死夜叉，又用混天绫缠住、用乾坤圈打死龙王三太子 → 龙王要上天宫告状，哪吒在南天门拦住他，打倒他、揭他鳞片，龙王只好答应不告 → 四海龙王绑了李靖，要水淹陈塘关，哪吒怕连累父母和百姓，说「我一人做事一人当」，含泪自尽 → 太乙真人用荷叶、荷花、嫩藕摆成人形，让哪吒重新活过来。

  - 定位：《象鼻桥》全篇
  - 内容概述：小桥坏了大家互相等，两只大象用鼻子搭桥，大家惭愧后合力修新桥。
  - 可引用原文（逐字，全篇）：
    小河两岸住着许多小动物。每天他们来来往往，走过小桥，摘野果，采蘑菇，走亲戚，看朋友，可热闹啦！
    一天，大雨冲坏了小桥。桥这边的动物想，让桥那边的动物来修吧。桥那边的动物也想，让桥这边的动物去修吧。就这样，你等我，我等你，小桥一直没有修好。
    小鸡生病了，不能去河对岸看病。山羊爷爷也不能到河这边看望小孙子了。大家都觉得很不方便。
    一天清早，河上突然出现了一座奇怪的桥。啊，原来是两只大象分别站在河的两岸，把他们的长鼻子搭在一起，架起了一座“象鼻桥”。动物们从“桥”上高高兴兴地走过，脚步放得轻轻的，一边走一边唱起了欢快的歌。
    两只大象在河边静静地站了好几天，动物们非常感动，也很惭愧。于是，大家齐心合力，修建了一座新桥。
    为了感谢这两只热心的大象，大家给新桥起了个名字，叫“象鼻桥”。

- **片段2**
  - 定位：《下雨了》全篇
  - 内容概述：没带伞的小玲没淋湿，带了伞的小宝却淋湿了，奶奶两次说「好孩子」。
  - 可引用原文（逐字，全篇）：
    下雨了。奶奶望着窗外的雨点儿，心里很着急。她想：“小宝带了雨伞，不要紧；小玲没有带雨伞，衣服会淋湿的。”
    “嘭嘭嘭！”有人敲门。
    奶奶拉开门，小玲蹦着跳着进来了。奶奶摸着小玲的衣服，奇怪地问：“小玲，你的衣服怎么没淋湿？”
    小玲高兴地回答奶奶说：“是我们班里的小敏送我回来的。”
    奶奶称赞道：“她真是个好孩子！”
    “嘭嘭嘭！”小宝回来了。他的衣服全湿了，头发上有水珠滴下来。奶奶说：“你是不是把伞弄丢了？”
    “没有。”小宝对奶奶说，“我把伞借给路远的同学了。”
    奶奶望着小宝，高兴地给他擦干头发，说：“你也是个好孩子，快去换衣服吧！”

- **片段3**
  - 定位：《三个儿子》全篇
  - 内容概述：两个妈妈夸儿子、一个不夸；三个孩子跑来，老爷爷只看见一个儿子。
  - 可引用原文（逐字，全篇）：
    三个妈妈在井边打水，一位老爷爷坐在旁边的石头上休息。
    一个妈妈说：“我的儿子既聪明又有力气，谁也比不过他。”
    又一个妈妈说：“我的儿子唱起歌来赛过黄莺，谁都没有他那样好的嗓子。”
    另外一个妈妈什么也没说。
    那两个妈妈问她：“你怎么不说说你的儿子啊？”
    这个妈妈说：“他没什么特别的地方。”三个妈妈打了水，拎着水桶回家去，老爷爷跟在她们后边慢慢地走着。
    一桶水可重啦！水直晃荡，三个妈妈走走停停，胳膊都痛了，腰也酸了。
    这时，迎面跑来三个小孩子。
    一个孩子翻着跟头，像车轮子在转，真好看！三个妈妈被他迷住了。
    一个孩子唱起歌来像黄莺，歌声真好听。另一个孩子跑到妈妈跟前，接过妈妈手里沉甸甸的水桶，提着走了。
    一个妈妈问老爷爷：“看见了吗？这就是我们的三个儿子。怎么样啊？”
    “三个儿子？”老爷爷说，“不对吧，我可只看见一个儿子。”

- **片段4**
  - 定位：《金斧头（一）》全篇
  - 内容概述：程实掉了斧头，老爷爷三次下河，程实不要金斧头、银斧头，只认自己的铁斧头。
  - 可引用原文（逐字，全篇）：
    从前，有个孩子叫程实。他家里很穷，爸爸妈妈没办法，就让他到地主家里干活。
    程实每天从早干到晚，要做许许多多的事，可是地主还总说他偷懒。
    有一天，程实上山砍柴，走过独木桥，一不小心，把斧头掉到河里了。这条河的水很深很急，东西掉下去很难找回来。没有斧头，怎么砍柴呢？砍不到柴，地主又要打他骂他了。程实急得哭了。
    突然来了一位白胡子老爷爷，他问程实：“孩子，你为什么哭啊？”
    程实把掉斧头的事告诉了老爷爷。
    老爷爷说：“不要哭了，我下去给你捞斧头。”说完，老爷爷扑通一声跳进河里，不一会儿，捞了一把金斧头上来。他举着斧头问程实：“你丢的是这把吗？”程实一看，这是一把金光闪闪的斧头，漂亮极了，连忙摇头，说：“老爷爷，谢谢您！这把斧头不是我的！”
    老爷爷又扑通一声跳进河里，捞上来一把银斧头。“那你丢的是这把吗？”

    说完，老爷爷就不见了。程实这才知道老爷爷是位仙人。

## 五、重复出现的事物/场景

- **篇内重复**：
  - 《金斧头（一）》：老爷爷三次下河（金→银→铁），程实两次说「老爷爷，谢谢您！这把斧头不是我的／也不是我的！」。
  - 《金斧头（二）》：老爷爷三次下河，顺序倒过来（铁→银→金），地主的反应与程实相反。
  - 《包公审石头（二）》：「石头，石头，……」包公对石头说了三次；「快说，快说！」两处。
  - 《下雨了》：「嘭嘭嘭！」两次敲门；奶奶两次说「好孩子」（「她真是个好孩子！」「你也是个好孩子」）。
  - 《三个儿子》：「三个」贯穿全篇——三个妈妈、三个孩子、两个夸儿子一个不夸、三个孩子三件事。
  - 《七颗钻石》：水罐四变（装满水 → 银的 → 金的 → 跳出七颗钻石）；小姑娘三次把水让给别人（小狗、母亲、过路人）。
  - 《除三害》：「三」——三害、第三天、三天三夜。
- **跨篇复现的母题**（只记出现，不作关联解读）：
  - **水**：《象鼻桥》（河上的桥）、《七颗钻石》（旱灾找水）、《金斧头》（斧头掉进河）、《除三害》（河里恶龙）、《包公审石头》（水盆里的油花）、《哪吒闹海》（东海）。
  - **妈妈／母亲**：《三个儿子》三个妈妈、《七颗钻石》生病的母亲、《包公审石头（一）》小孩儿卖油条给妈妈买药。
  - **好孩子／好人得好报**：《下雨了》奶奶称赞两个孩子；《金斧头》程实一家生活越来越好、地主掉进河里；《七颗钻石》七颗钻石升天。
  - **「仙人／神仙」**：《金斧头》白胡子老爷爷是仙人；《哪吒闹海》太乙真人。
