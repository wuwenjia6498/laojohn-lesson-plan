# 《推荐一个好地方》· 写作课教学设计

四年级上册·第一单元 校内同步写作（推荐类习作）

[授课提示：本课开场老师讲的那件事、示范用的那个小村子，都是拟写的，供老师照着讲。老师若有自己真去过、真喜欢的地方，请整体换成自己的——推荐这件事，讲自己真去过的地方才有说服力，教学步骤与讲法不变。]

## 第1课时 · 写作指导课

### 一、创设情境，明确任务（约 5 分钟）

〖PPT 第3页 · 创设情境 · 同一个地方，介绍了两回，差别在哪里？〗

师：前些日子，老师有一位朋友带着孩子从外地来玩几天，问我：可以带孩子去哪里玩？我推荐了一个地方，说：“那里很不错，你们可以去玩玩。”他听完点了点头，没有再接话，但我看得出来，他并没有打算去。

师：过了一会儿，我又补充了几句：那个村子在山坳里，十月满山的柿子可以随意采摘；村口有一家现做米糕的小店，无论什么时候去，都能买到热乎乎的米糕；村后有一条小溪，水很浅，孩子可以下去玩水；住的院子里还有一棵老树，晚上坐在树下能看见星星。他听完，就准备带着孩子去了。

师：同一个地方，同一个人介绍，第一回对方没有反应，第二回就准备出发了。请大家说一说，这两回的介绍差在哪里？

参考：第二回说得多／说了柿子、米糕，还有小溪／第一回只有一句“那里很不错”。

师：大家说到了关键。地方本身没有变，差别全在我们怎样介绍。

〖PPT 第4页 · 创设情境 · 今天的任务：开一场“好地方推荐会”〗

师：所以今天这两节课，我们专门来练这件事。每人推荐一个自己真正去过的好地方，写成一篇推荐稿。写完后，我们就在这间教室里开一场“好地方推荐会”：先读给同桌听，再请几位同学上台读给全班听，最后全班投票，选出大家最想去的那个地方。

师：也就是说，今天听你推荐的都是班里的同学。你读完稿子，如果有人对你说“我也很想去”，就说明你推荐成功了；如果大家听完没有兴趣，多半是因为你只笼统地说了这里很不错，没有讲清楚亮点在哪里，和老师一开始说的那句空话是同一个问题。

### 二、唤起记忆，找出你的好地方（约 8 分钟）

〖PPT 第5页 · 唤起记忆 · 三个问题，想起来就举手说一句〗

师：推荐一个地方，前提是你真的去过、真的记得。老师先问几个问题，想起来的同学就举手，一句话说完即可。第一个问题：你去过的地方里，哪一处的味道，你到现在还记得？

学生互动分享（举手抽说三四位；其余同学带着任务听：听同学说的是哪一处地方，想一想自己有没有哪个地方也记得这么清楚）
参考：街边糖水铺的桂花芋圆、老街烤肠、海边现烤鱿鱼

师：第二个问题：哪一处的声音，你现在还想得起来？

参考：海边的浪声／庙会上的锣声／鸟叫。

师：第三个问题：哪一处地方，你回来以后还向别人说起过？

学生互动分享（举手抽说两三位）

师：味道、声音、回来后还向人说起，这三样说明的是同一件事：那个地方你是真的去过，也真的记住了。只有自己印象深刻的地方，才能让别人听了心生向往。

〖PPT 第6页 · 唤起记忆 · 选一个你真心觉得好的地方，不一定要远〗

师：接下来把范围放宽。好地方不一定要远：可以是身边的，学校后面的那条小路、小区里的花园、你常去的那家书店；可以是家乡的，一个公园、一座山、一条老街；也可以是外出旅游去过的，一处古镇、一个乐园、一家博物馆。选一个你自己真心觉得好的。

师：选好了先不说地名。向同桌说三样东西：在那里你看到过什么、听到过什么、吃到或玩到过什么。请同桌来猜一猜，这是一个什么样的地方：是安静的，还是热闹的？是吃东西的地方，还是看风景的地方？

学生互动分享（同桌两两互说，各说一轮；教师走到两三组学生身边，做第一位听众）

〔应答·学生只报了地名，说不出三样东西〕不追问“好在哪里”，改问具体的：“你到那里，第一眼看见的是什么？”“那天你在那里吃了什么？”问出一样，就让他接着说第二样。

〖PPT 第7页 · 唤起记忆 · 理由从哪里找：它到底好在哪里？〗

师：好，地方有了。等一会儿要写的是理由，也就是那个地方到底好在哪里。理由可以从这几个方面找：那里的景色好看，那里有好吃的，那里有好玩的项目，或者那里有一段来历、一个故事。对着你选的地方想一想，你能找出几条。先记在心里，一会儿要用。

（教师总结）真正去过、还记得住味道和声音的地方，才推荐得出去；理由就从风景、饮食、游玩项目、地方传说或故事这几个方面去找。

### 三、学写法：一条理由写一段，先亮理由再写具体（约 13 分钟）

〖PPT 第8页 · 判断对比 · 这两段话，哪一段才算推荐？〗

师：动笔之前，我们先要分清：今天要写的文章，究竟是什么样子。同样一处地方，不同的写法，效果大不相同。老师读两段文字，请大家分辨，哪一段才是真正的“推荐”。

师：第一段：“十月三日那天，我们全家去了山里的一个小村子。早上七点半出发，路上开了两个多小时。到了先在村里转了转，中午在房东家吃的饭，下午上山摘柿子，四点多就往回赶了。这一天过得很开心。”

师：第二段：“离城两个多小时，山坳里有个小村子，是个让人住下了就不想走的好地方。最值得去的是十月里满山的柿子，随便你摘。村后那面坡上全是柿子树，叶子落光了，只剩一树一树的果子挂着。”

师：哪一段才算推荐？

参考：第二段。

师：第一段哪里不对？它把那天的事写得很清楚，几点出发、中午吃饭、下午摘柿子，一件不落。

参考：它没有说好在哪里／它只是记录了当天发生的事。

师：按时间顺序从头到尾一件件罗列，别人读完只知道你的行程，却无法判断自己想不想去。第二段不一样，一开头就点明：这是一个让人住下就不想走的地方，紧接着介绍亮点：满山的柿子可以采摘。今天我们写的不是出游记事，而是推荐稿，要讲清地点，说清它的好处，让没去过的人心生向往。如果只是顺着时间记录一整天的经历，文章就跑题了。

〖PPT 第9页 · 学写法 · 今天这一招：一条理由写一段〗

师：那么，怎样才能打动别人？先说第一点：推荐理由不必太多，也不能只有一条。刚才老师一口气说了四样，落到写作里，选出最吸引人的两三条就足够了。选定的理由要分开写，每一条独立成段，不要混在一起。段落分清楚，读者一眼就能看出你的几个亮点。

〖PPT 第10页 · 学写法 · 看老师把“特别好吃”变成一段话〗

师：还有更关键的一点。先听这句话：“村口有一家现做米糕的店，特别好吃，你去了一定要尝尝。”这样的介绍，能让你们产生想去尝一尝的念头吗？

参考：不能／不知道究竟有多好吃／感觉很一般。

师：是的，这句话只给出了结论。“好吃”谁都会说，没有说服力。同样的内容，请大家看老师换一种方式来写。

〔教师示范·当场把“米糕特别好吃”这一条写具体，读给学生听〕村口那家米糕店，天不亮就开始蒸糕。一排竹蒸笼摞得比人还高，白汽从笼缝里直往外冒，隔着两条巷子就闻得到那股米香。做糕的奶奶拿着木槌，笃、笃、笃轻轻敲打米团。敲上一会儿，她掀开蒸笼，热腾腾的水汽扑面而来，一块米糕垫着荷叶递到我手上，还叮嘱：“趁热吃，凉了口感就不软糯啦。”米糕烫得很，我只能双手来回轮换捧着。一口咬下去，质地软软糯糯，中间裹着红豆沙，甜而不腻。一块下肚，手心还留着荷叶淡淡的清香，那天早晨，我一连吃下两块。

师：两种写法比一比，这一回你们想不想尝？

参考：想／有点饿了。

师：第二种写法多出来的是什么？

参考：写了白汽／有敲打的声音／写了咬下去的感觉。

师：白汽、米香、笃笃的敲打声、烫手的触感、绵密的红豆沙……这些都是亲身在场才能看见、闻到、摸到、尝到的细节。把这些内容写进文字，读者读起来，就像跟着你一起到了现场。

〖PPT 第11页 · 学写法 · 先亮理由，再写现场的细节〗

今天我们学习这样一种写法：一条理由单独成一段，每一段先亮明观点，接着写出现场令你印象深刻的细节，也就是看得见、闻得到、听得见、尝得着的画面。

不要只空泛地写“很好”“很不错”。这样笼统的评价人人都会写，既没有画面感，也无法打动读者、说服读者。

师：这样的写法，本单元的课文《观潮》也用到了。课文写大潮来临，依次写出听到的声响、看到的景象，一层一层铺展开来。作者不直接夸赞，而是借助这些画面，让我们真切感受到大潮的雄伟壮观。大家在学校里学到这篇课文时，可以留意这一点。

师：现在轮到大家试一试。回想刚才和同桌交流的内容，选一条理由，说一句带有细节的话，要让人听了仿佛亲眼看见、身临其境，不要只说“好玩”“好看”。想好后先小声说一说。

学生自由分享（教师点评时重点关注：你抓住的是颜色、声音，还是吃到的味道？）

师：记住今天这个写法：一条理由写成一段，先亮出观点，再补上现场的真实细节。

### 四、借助推荐卡，理清思路（约 11 分钟）

〖PPT 第12页 · 推荐卡 · 用推荐卡理清思路〗

师：脑子里想到的素材零零散散，如果直接动笔，很容易又写成流水账。我们先用推荐卡理一理思路。大家手上这张就是推荐卡，每一格只写词语，不必写完整的句子，自己能看懂就可以。第二格标注的是“总说”，用几个字概括：这是一处怎样的地方。

| 项目              | 我的关键词 |
| --------------- | ----- |
| 推荐的地方（在哪里） |  |
| 总说：是个什么样的地方     |       |
| 理由一 · 好在哪       |       |
| 理由一 · 让你印象深刻的东西 |       |
| 理由二 · 好在哪       |       |
| 理由二 · 让你印象深刻的东西 |       |

师：老师先填一张给大家看。老师推荐的就是刚才说的那个小村子。

| 项目              | 我的关键词         |
| --------------- | ------------- |
| 推荐的地方（在哪里） | 城外两小时·山坳小村 |
| 总说：是个什么样的地方     | 住下就不想走        |
| 理由一 · 好在哪       | 满山柿子随你摘       |
| 理由一 · 让你印象深刻的东西 | 一树一树的果子 |
| 理由二 · 好在哪       | 村口米糕店现蒸现做     |
| 理由二 · 让你印象深刻的东西 | 白汽、米香、笃笃声、烫手  |

师：看清楚了，每一格只有几个词，最长的一格也只有四个词。下面两格最重要，要写下你在那里看见的、闻到的、吃到的事物。等到动笔写作时，单单“白汽”这一个词，就能展开成一句话。现在大家动手填写卡片，不必强求填满六格，先写出一组素材就很好。

〖PPT 第13页 · 推荐卡 · 轮到你：先填卡，再向小组说〗

学生动笔写作（填卡约 3 分钟；教师巡视）

〔应答·学生几条理由填的是同一个方面〕例如两条都写吃的，就提醒他换一个方面：“除了吃的，那里的景色怎么样？有什么好玩的？有没有什么来历？”帮他把理由二换到另一个方面。

师：填好的同学四人一组开始交流。每人限时半分钟，看着推荐卡，介绍地点并说出两条推荐理由。其余三人商量后给出反馈：两条理由中，哪一条更吸引人。一轮交流结束，各组推选一名代表准备向全班展示。

[四人小组交流，推选代表；教师巡视，选择两三个小组进入倾听。]

师：请小组代表来分享。其余同学先听，第二节课的推荐会上，大家都有机会展示。

[学生代表分享地点与两条理由。教师有针对性地点评：区分两条理由的不同角度，指出卡片中最适合展开写作的细节素材。]

### 五、出示示范文，发现写法（约 8 分钟）

〖PPT 第14页 · 教师示范文 · 老师的那张卡，变成了一篇推荐稿〗

师：大家的卡上都有内容了。现在老师把刚才填的那张卡，写成完整的一篇给大家看。看的时候留心一件事：卡上那几格词语，是怎样变成一段一段的话的。

> 【教师示范文】
> 
> 离城两个多小时，山坳里有个小村子。我去年秋天在那里住了两天，回来至今还时时想起它。这是个让人住下了就不想走的好地方。
> 
> 最值得去的，是村后的柿子山坡。十月里满山的柿子，随你摘。村后那面坡上全是柿子树，叶子落光了，只剩下一树一树的果子，金红金红地挂着，远看像谁在半山腰点了一片小灯笼。房东递给我一根顶头带钩的长竹竿，教我怎么把最高的那几个够下来。竿子一勾，柿子咚地落进草里，捡起来捧在手心，沉甸甸、硬邦邦的。咬一口，脆生生、甜丝丝，果肉紧实爽口，清甜的果香瞬间在嘴里散开了。
> 
> 第二样值得去的，是村口那家米糕店。经常天不亮就开始蒸糕，一排竹蒸笼摞得比人还高，白汽从笼缝里直往外冒，隔着两条巷子就闻得到那股米香。做糕的奶奶拿着木槌，笃、笃、笃轻轻敲打米团。敲上一会儿，她掀开蒸笼，热腾腾的水汽扑面而来，一块米糕垫着荷叶递到我手上，还叮嘱：“趁热吃，凉了口感就不软糯啦。”米糕烫得很，我只能双手来回轮换捧着。一口咬下去，质地软软糯糯，中间裹着红豆沙，甜而不腻。
> 
> 你要是也想找个地方待上两天，就去这个小村子。上山勾一竿柿子，下山趁热吃一块米糕。去过之后，这份滋味，会长久留在你的心里。

〖PPT 第15页 · 读示范文 · 读完，先想两个问题〗

师：先看结构。这篇一共写了几条理由？每条各占几段？

参考：两条／一条一段。

师：每一段的第一句起什么作用？

参考：点明理由，告诉读者这一段要写什么。

师：对，每一段一开头就把理由亮出来了：一段写“最值得去的，是村后的柿子山坡”，一段写“第二样值得去的，是村口那家米糕店”。开门见山，读者一眼就能抓住段落的重点，条理十分清晰。

师：再看开头和结尾。开头一句话总写这个地方的特点：一个让人住下就不想走的好地方。结尾顺势发出邀请，请大家也来这里做客。总分总的结构，完整而规整。

师：请大家重点看写米糕的这一段，是不是特别熟悉？

师：就是它。最初的推荐卡上，只有简简单单四个词：白汽、米香、笃笃声、烫手。大家发现了吗？卡片上的一个词语，在这里可以扩写成一句有画面的话。你们卡片上的词语，一会儿也能这样一步步变成完整、生动的段落。

师：最后请大家再默读一遍示范文，找一找：哪一句话让你眼前浮现出画面，或者仿佛尝到、闻到了味道？

学生互动分享

〖PPT 第16页 · 旁批表 · 每一句都在做一件事：看看好句子好在哪里〗

师：把大家选出的这几句话整理一下，对照着看：

| 示范文里的句子 | 这一句好在哪里 |
| ---------------------------- | --------------------- |
| 这是个让人住下了就不想走的好地方 | 开头一句总说，先点明这个地方的特点 |
| 最值得去的，是村后的柿子山坡。十月里满山的柿子，随你摘。 | 一条理由一段，段首亮明理由 |
| 金红金红地挂着，远看像谁在半山腰点了一片小灯笼 | 写颜色，还打了比方，柿子的样子看得见了 |
| 柿子咚地落进草里，捡起来捧在手心，沉甸甸、硬邦邦的 | 一个声音，一个手上的感觉，人像站在了树下 |
| 白汽从笼缝里直往外冒，隔着两条巷子就闻得到那股米香    | 写闻得到的气味，“好吃”落到了实处     |
| 她还叮嘱：“趁热吃，凉了口感就不软糯啦。” | 记下做糕奶奶说的话，读的人像站到了摊子跟前 |
| 你要是也想找个地方待上两天，就去这个小村子 | 结尾一句邀请，把读者请过去 |

师：这篇示范文写的是老师亲身去过的小村子。而大家心里想推荐的地方，它独一无二的风景和感受，只有你们自己最清楚。写作不必刻意模仿示范文，写得像不像并不重要。真正关键的是守住两个要求：每条推荐理由各写一段，每一段都写进自己亲眼看见、亲身感受、亲口品尝的真实细节。如果还有特别想写的理由，先把前面的理由写扎实，再简要增补一段即可。

〖PPT 第17页 · 第一课时收束 · 三样素材备齐，下节课动笔〗

师：这节课我们已经做好了准备，每个人手里都有了三样写作素材：选定的推荐地点、填好的推荐卡、说过一遍的口头推荐。大家稍作休息，下节课就用这些素材，正式动笔完成推荐稿。

本课完。

## 第2课时 · 当堂写作与评改课

### 一、看着推荐卡，写下开头的几句（约 5 分钟）

〖PPT 第19页 · 写作热身 · 看着推荐卡，写下开头的两句〗

师：请把推荐卡拿出来，找到第二格“总说：是个什么样的地方”。

师：稿纸的第一行最容易写，把第一格和第二格连起来说成一句话就可以了。老师卡上填的是“城外两小时·山坳小村”和“住下就不想走”，连起来就是：“离城两个多小时，山坳里有个小村子，是个让人住下了就不想走的好地方。”现在把你的那两格连成一句话，空两格，写在第一行。

学生动笔写作

师：第一句写完，后面就顺了。看理由一的第一格“好在哪”，把那几个词说成一句话，另起一行、空两格写下来。这是这一段的第一句，就像老师那篇里的“最值得去的，是村后的柿子山坡。十月里满山的柿子，随你摘”。

学生动笔写作

〖PPT 第20页 · 写作热身 · 盯住一样东西，跟着三个问题一句一句写〗

师：理由亮出来了，接下来就要用细节把内容写扎实。找到卡片上“理由一·让你印象深刻的东西”这一格，从中挑一样最想写的事物，盯住它，跟着老师的问题一句一句写。

师：第一句，写它的颜色和样子。请动笔。

学生动笔写作

师：第二句，走近它，还能看到哪些细节？留意它的大小、外形上的特点，写下来。

学生动笔写作

师：第三句，站在近处感受一下：你听见了什么、闻到了什么？如果可以触摸、品尝，也写下摸到的感觉或入口的滋味。

学生动笔写作

师：停一停，回头看这几行。我们先用卡片里的“总说”概括这个地方的特点，再用“理由一·好在哪”作为段落的开头亮出观点，然后围绕印象深刻的事物展开描写，文字就有了画面感。请大家接着把第一段写完。写第二条理由时，沿用同样的写法：先用“理由二·好在哪”点明观点，再围绕“理由二·让你印象深刻的东西”，用这三个问题写出细节。

### 二、自由写作，把推荐稿写完（约 20 分钟）

〖PPT 第21-22页 · 自由写作 · 把整篇写完，三件事记在心里〗

师：现在接着往下写，用十七八分钟把整篇写完。三件事记在心里：每条理由分一段，每段开头先亮理由；每一段里写上你在那里看见的、闻到的、吃到的；最后一句，把读者邀请过去。写的时候不必回头修改，一口气写到底。

学生动笔写作

[教师巡视，只做正向介入，不纠错字、不改病句、不打断书写顺畅的学生。按学情分四类处理：]

[接不下去型：写完开头几行就停住，盯着稿纸。把他领回推荐卡：“你这几行已经把第一样东西写出来了。看看‘理由二’那一格，第二条还没有写，接着往下写它。”]

[内容空泛型：整段都是“那里特别好玩，去了就不想回来”一类的话。请他先选出那里最具体的一样东西，就这一样问他“它是什么样子”“玩起来是什么感觉”，答出一句就让他直接写进去。]

[书写顺畅型：不打断，走过时轻声说一句“接着写”，为他留出书写空间。]

[草草收尾型：每条理由各写两三句就搁笔说“写完了”，篇幅明显偏短。先肯定再推一步：“第一条你写的是那里的景色，很好。那天你站在那里，还听见了什么、闻到了什么？补上一两句。”]

[临近时间提示：把手上这一句写到句号，停在顺手的地方。没有写完的不必赶，后面还有一段自改的时间可以接着补。]

### 三、交流评议，修改收束（约 20 分钟）

[同桌互读（约 4 分钟）]

〖PPT 第23页 · 交流评议 · 同桌互读，一句话反馈：“我想去”吗？〗

师：请大家把写好的稿子读给同桌听。交流规则很简单：听的同学听完先只给一句反馈：“我想去”或者“我还不太想去”。然后补充说明：打动你的是哪一条理由；如果不太想去，就说清楚哪一条理由没有吸引到你。两人轮流朗读、互相倾听，交流才算完成。

[学生两两结对朗读互评；教师巡视，走近多组倾听交流]

[好地方推荐会（约 9 分钟）：邀请 4 名学生展示，每人朗读开头的总说句和最出彩的一条理由，时长控制在一分钟以内；展示结束后组织全班投票]

〖PPT 第24页 · 交流评议 · “好地方推荐会”正式开场〗

师：推荐会现在开始。有请四位同学上台分享。不必朗读全文，读出开头概括特点的总说句，再读出你最有信心的一条理由即可。台下的同学认真听，心里想一想：听完这份推荐，你是否向往这个地方。

学生互动分享（4 位同学依次朗读；每一位分享完毕，教师随机邀请一两位听众发言，说说自己被哪一处内容打动。教师顺势点评，聚焦文本细节：指出哪一句写出了声音，哪些由推荐卡关键词展开的语句画面感最强；同时温和地提出一处可以增补的建议。邀请听众发言时尽量兼顾全班，不重复邀请同一批同学）

师：四个地方都推荐完了。现在投票：你最想去哪一个？想去哪一处，就为它举手，每人只能选一处。

学生互动分享（全班举手投票，教师统计并当场宣布票数最高的地方）

[带标准修改（约 5 分钟）：行文细节、错别字延迟到此时统一处理]

〖PPT 第25页 · 修改收束 · 改一改：三档标准与三点自查〗

师：听完别人的，再回到自己的稿子上修改。对照这份评价标准，看一看自己达到了哪一档。

| 档位 | 自检 |
| ------ | -------------------------- |
| 写完了 | 写清推荐的地点，完整写出两三条理由。 |
| 写具体了 | 每条理由角度不重复，每一段都写出现场真实的所见所感。 |
| 写得让人想去 | 读者读完心生向往，能说出被文中哪一处细节打动。    |

师：已经完成初稿的同学，对照三点逐一检查：第一，每条理由是否分段，段落开头有没有清楚地亮出观点；第二，如果段落里只有“很好”“很不错”这类笼统评价，就补一句具体的内容：你看见了什么、闻到了什么；第三，文末有没有写上邀请的话。还没有写完的同学，先把正文写完，再对照三点修改其中一处。修改时顺带订正错别字，多余的词句圈画删去，缺漏的内容补上，不会写的字可以请教同桌或举手问老师。

学生动笔写作（自改；教师巡视答疑）

[收尾（约 2 分钟）]

〖PPT 第26页 · 收尾 · 带回家读给家人听〗

师：两节课下来，每位同学都完成了自己的推荐稿。还记得开头那个例子吗？只说一句“那里很不错”，很难打动别人；把柿子、米糕这些真切的事物细细讲出来，就能吸引别人。今天我们练习的，正是把亲眼所见、亲耳所闻、亲口所尝写进文字。

师：稿子今天就写好了，带回家读给家人听，问问他们想不想去。等学校里上到这个单元的习作时，大家心里就有数了，下笔也会更从容。

（教师总结）这节课我们掌握了推荐一个好地方的写法：选出两三条最有吸引力的理由，一条理由独立成段；段首亮明观点，接着写出真实细节；开头总体概括，结尾发出邀请。这套写法不只适用于推荐地方，将来推荐书籍、影片，同样可以使用。

本课完。

## 附：习作讲评指导环节（可选 · 单次课课后用 / 系列课作下次课开场用）

> 本环节供教师灵活取用：可在单次课课后批阅学生习作后集中讲评一次，也可作为系列课下一次课的开场（约 15–20 分钟）；不计入本课 45+45 分钟，讲评的是学生当堂完成的稿子，不布置新的写作任务。
> 讲评中凡出现 ＿＿＿ 处，务必换成本班学生习作里的真实句子，切勿虚构。

### 选稿（课前准备）

课后通读全班习作，紧扣本课核心技法：每条理由分段写、段首亮明观点、段落嵌入实景细节，筛选三篇典型稿件投屏讲评，匿名展示，兼顾示范、修改、纠错三类样本：

1. 优秀范例：每条理由角度独立、不重复，每段都有看得见、闻得到、尝得着的实景细节，用于全班对照学习，明确“写具体”的标准。

2. 中等提升范例：整体结构规范，分段清楚，段首能准确亮出理由，基本功扎实；不足在于段落内容偏笼统，只有概括性评价，缺少实景细节，用来示范“如何补一句细节，让段落具体起来”。

3. 典型问题范例：全文写成流水式的出游记录，只记录游玩过程；或者两条理由角度重叠、内容重复，没有清楚的推荐逻辑，重点模糊。用于带领全班一起找出问题、共同修改。

课前为三篇稿件各拟一句简短评语，点明与本课技法相关的亮点与不足，便于课堂讲评。

### 讲评流程（每篇约 3–5 分钟，围绕本课技法点）

〖PPT 第27页 · 习作讲评 · 习作讲评环节（可选·课后或下次课开场）〗

师：上次推荐会上，有四位同学把稿子读给了全班，每个人也都读给同桌听过。老师课后把每一篇都读完了，今天选三篇出来，只看一件事：理由有没有分开写，段落里有没有具体的内容。

师：先看第一篇。他写“＿＿＿”（读该篇写得最具体的一两句），大家听，这几个字一出来，那样东西就到了眼前。再看他的两条理由，一条说的是＿＿＿（口头概括第一条落在哪个方面），一条说的是＿＿＿（第二条的方面），角度清楚、互不重复，读的人不会觉得他在重复。

（教师总结）理由分得清楚，每段都有实景细节，这就是完全符合本课写法的优秀示范文。

师：第二篇结构很整齐，几条理由几段话，段首也亮出了理由。只是这一句“＿＿＿”（读该篇只报结果的那一句），只有笼统的夸赞，没有具体的画面，写完就草草收尾了。大家想一想，这一句后面如果再补一句，补什么好？他写的是哪个地方？那里有什么是我们能看见、能闻到的？

学生互动分享

师：对，就补这样一句。改这一处不必重写整段，只要在那句话后面添一句具体的内容。

师：第三篇不说是谁写的，我们一起帮他想办法。他这篇＿＿＿（口头概括该篇的问题，如：从早上出发写到下午回家，一天的事写全了，却没有说这个地方好在哪里）。这样一篇，要改成推荐稿，第一步该改哪里？

学生互动分享

师：大家的思路很准确。这篇文章不缺素材，缺的是梳理和取舍。只要从全文素材里选出两个最吸引人的亮点，分成两段，段首亮明理由，就能改成一篇合格的推荐稿。

### 收尾（点回技法、引向今后的写作）

师：看完三篇习作的对比，大家应该清楚了写作的关键：真正打动别人的，不是空泛的夸赞，而是扎实的方法：几条理由，一条一段，段首亮明观点，段落里写进亲眼所见、亲耳所闻、亲身所感的实景细节。

师：今后无论是推荐地方，还是推荐书籍、物品，大家都可以用这套方法自查：我的几条理由角度是否不同？每一条理由，有没有能让别人看得见、感受得到的具体细节？

本环节完。
