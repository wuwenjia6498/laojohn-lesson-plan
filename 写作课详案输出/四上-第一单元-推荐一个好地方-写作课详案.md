# 《推荐一个好地方》· 写作课教学设计

四年级上册·第一单元 校内同步写作（推荐类习作）

[授课提示：本课开场老师讲的那件事、示范用的那个小村子，都是拟写的，供老师照着讲。老师若有自己真去过、真喜欢的地方，请整体换成自己的——推荐这件事，讲自己真去过的地方才有说服力，教学步骤与讲法不变。]

## 第1课时 · 写作指导课

### 一、创设情境，明确任务（约 5 分钟）

〖PPT 第3页 · 创设情境 · 同一个地方，说了两回——差在哪儿？〗

师：前阵子，老师有位朋友，带着孩子从外地过来玩几天，问我：能带孩子上哪儿玩？我推荐了个地方，说“那儿挺好的，你们可以去玩玩”。他听完点点头，没接话，看得出来，他应该没打算去。

师：过了一会儿，我补充了几句：那村子在山坳里，十月满山的柿子随你摘；村口有家现做米糕的小店，不管什么时候去，都能买到热乎乎的米糕；村后有条小溪，水很浅，孩子能下去踩水；住的院子里还有棵老树，晚上坐在树底下能看见星星。他听完，就准备带着孩子去了。

师：同一个地方，同一个人说，头一回人家没动，第二回就准备出发了。你们说说，这两回差在哪儿？

参考：第二回说得多／说了柿子、米糕，还有小溪／第一回就一句“那儿挺好的”。

师：你们说到关键点啦！地方本身没差别，差别全在我们怎么介绍。

〖PPT 第4页 · 创设情境 · 今天的任务——开一场“好地方推荐会”〗

师：所以今天这两节课，咱们专门练这件事。每人推荐一个自己真正去过的好地方，写成一篇推荐稿。写完后，我们就在这间教室里开一场“好地方推荐会”。先念给同桌听，再请几位上来念给全班，最后全班投票，选出大家最想去的那个地方。

师：换句话说，今天听你推荐的都是班里同学。等你读完稿子，如果有人跟你说 “我也好想去这里”，就说明你介绍成功了；要是大家听完毫无兴致，多半你只笼统说了这里很不错，没讲清楚亮点在哪，和我一开始说的空话是一个问题。

### 二、唤起记忆，找出你的好地方（约 8 分钟）

〖PPT 第5页 · 唤起记忆 · 三个问题——想起来就举手说一句〗

师：推荐一个地方，前提是你真去过、真记得。老师先问几个问题，想起来的就举手，一句话说完就行。第一个：你去过的地方里，哪一处的味道，你到现在还记得？

学生互动分享（举手抽说三四位；其余同学带着任务听——听同学说的是哪一处地方，想想自己有没有哪个地方也记得这么清楚）
参考：街边糖水铺的桂花芋圆、老街烤肠、海边现烤鱿鱼

师：第二个：哪一处的声音，你现在还想得起来？

参考：海边浪的声音／庙会上敲锣／鸟叫。

师：第三个：哪一处，你回来以后还跟人说起过？

学生互动分享（举手抽说两三位）

师：味道、声音、跟人说起过——这三样都说明同一件事：那个地方你是真去过、真记住了。只有自己印象深刻的地方，才能把别人说得心生向往。

〖PPT 第6页 · 唤起记忆 · 挑一个你真心觉得好的地方——不一定要远〗

师：接下来把范围打开。好地方不一定要多远：可以是身边的，学校后面那条小路、小区里的花园、你常去的那家书店；可以是家乡的，一个公园、一座山、一条老街；也可以是出门旅游去过的，一处古镇、一个乐园、一家博物馆。挑一个你自己真心觉得好的。

师：挑好了先别说地名。跟同桌说三样东西：那儿你看到过什么、听到过什么、吃到或摸到过什么。同桌来猜，猜猜这是个什么样的地方。是安静的，还是热闹的？是吃东西的地方，还是看风景的地方？

学生互动分享（同桌两两互说，各说一轮；教师走到两三组跟前当第一位听众）

〔应答·学生只报了地名说不出三样东西〕不追问“好在哪”，改问具体的：“你到那儿，第一眼看见的是什么？”“那天你在那儿吃了什么？”问出一样，就让他接着往下说第二样。

〖PPT 第7页 · 唤起记忆 · 理由从哪儿找——它到底好在哪儿？〗

师：好，地方有了。等会儿要写的是理由，就是那地方到底好在哪儿。理由可以从这几个方面找：那儿的景好看，那儿有好吃的，那儿有好玩的项目，或者那儿有一段来历、一个故事。对着你选的地方想一想，你能找出几条来。心里先记着，待会儿要用。

（教师总结）真去过、还记得住味道声音的地方，才推荐得出去；理由就从风景、吃的、玩的、地方传说/故事等这几方面去找。

### 三、学写法：一条理由写一段，先亮理由再写具体（约 13 分钟）

〖PPT 第8页 · 判断对比 · 这两段话，哪一段才算推荐？〗

师：准备动笔前，我们先要分清：今天要写的文章，到底是什么样子。同样一处地方，不同人写，效果天差地别。我来读一读两段文字，请大家分辨，哪一段才是真正的 “推荐”。

师：第一段——“十月三号那天，我们全家去了山里的一个小村子。早上七点半出发，路上开了两个多小时。到了先在村里转了转，中午在房东家吃的饭，下午上山摘柿子，四点多就往回赶了。这一天过得很开心。”

师：第二段——“离城两个多小时，山坳里有个小村子，是个让人住下了就不想走的好地方。最值得去的是十月里满山的柿子，随便你摘。村后那面坡上全是柿子树，叶子落光了，只剩一树一树的果子挂着。”

师：哪一段才算推荐？

参考：第二段。

师：第一段哪儿不对？它把那天的事写得挺清楚呀，几点出发、中午吃饭、下午摘柿子，一件不落。

参考：它没说好在哪／它只是记录当天发生的事情。

师：按时间从头到尾挨个罗列。别人看完只知道你的行程，却没法判断自己想不想去。第二段不一样，一上来就点明：这是个让人住下就不想走的地方，紧接着介绍亮点 —— 满山柿子可以采摘。今天我们写的不是出游记事，而是推荐稿，要讲清地点，说清它的好处，吸引没去过的人心生向往。要是单纯顺着时间记录一整天的经历，文章就跑题了。

〖PPT 第9页 · 学写法 · 今天这一招——一条理由写一段〗

师：那怎样才能打动别人？先说第一点：推荐理由不用太多，也不能只有一条。刚才我和朋友聊天一口气说了四样，落到写作里，挑选最吸引人的两条就足够。大家选定两条理由分开书写，一条独立成段，不要混在一起。段落划分清楚，读者一下子就能看清你的两个亮点。

〖PPT 第10页 · 学写法 · 看老师把“特别好吃”，变成一段话〗

师：还有更关键的一点。先听听这句话：“村口有家现做米糕的，特别好吃，你去了一定要尝尝。” 这条介绍，能勾起你们想去尝尝的想法吗？

参考：没有／不知道究竟有多好吃／感觉一般。

师：没错，这句话只给出了结论。“好吃” 谁都会说，没有说服力。同样的内容，大家看看我换一种方式描写。

〔教师示范·当场把“米糕特别好吃”这一条写具体，念给学生听〕村口那家米糕店，天不亮就开始蒸糕。一排竹蒸笼摞得比人还高，白汽从笼缝里直往外冒，隔着两条巷子就闻得到那股米香。做糕的奶奶拿着木槌，笃、笃、笃轻轻敲打米团。敲上一会儿，她掀开蒸笼，热腾腾的水汽扑面而来，一块米糕垫着荷叶递到我手上，还叮嘱：“趁热吃，凉了口感就不软糯啦。”米糕烫得很，我只能双手来回轮换捧着。一口咬下去，质地软软糯糯，中间裹着红豆沙，甜而不腻。一块下肚，手心还留着荷叶淡淡的清香，那天早晨，我一连吃下两块。

师：两个写法比一比，这回你们想不想尝？

参考：想／有点饿了。

师：多出来的是什么东西？

参考：写了白汽／有敲的声音／写了咬下去什么感觉。

师：白汽、米香、笃笃的敲打声、温热的触感、绵密的红豆沙…… 这些都是亲身在场才能看见、闻到、感受、品尝到的细节。把这些内容写进文字，读者读起来，就好像跟着你一同去到了现场。

〖PPT 第11页 · 学写法 · 先亮理由，再写现场的细节〗

今天我们学习这样一种写法：一条理由单独成一段，每一段先摆明你的观点，接着写上现场令你印象深刻的细节 —— 也就是看得见、闻得到、听得见、尝得着的画面。

不要只空洞地写 “很好”“很不错”。这样笼统的评价人人都会写，既没有画面感，也无法打动、说服读者。

师：其实这样的写法，咱们语文书本单元的《观潮》早就用到了。课文描写大潮来临，依次写下听到的声响、看到的景象，一层一层铺展开。作者不靠直接夸赞，而是借助这些画面，让我们真切感受到大潮的雄伟壮观。

师：现在轮到大家试一试。回想刚刚和同桌聊的场景，挑选一条理由，说一说带有细节的句子，要能让人仿佛亲眼看见、亲口尝到。不要简单说 “好玩”“好看”。想好先小声读一读。

学生自由分享（教师点评时重点关注：你抓住的是颜色？声音？还是吃到的味道？）

师：记住今天这个写法。一条理由写成一个段落，先亮出观点，再补充现场真实的细节。

### 四、借助推荐卡，理清思路（约 11 分钟）

〖PPT 第12页 · 推荐卡 · 推荐卡〗

师：脑海里想到的素材零零散散，如果直接动笔，很容易又写成流水账。咱们先用推荐卡梳理思路。大家手上这张就是推荐卡，每一格只写词语，不用写完整句子，自己能看懂就可以。第二栏标注的是 “总说”，简单用几个字概括：这是一处怎样的地方。

| 项目              | 我的关键词 |
| --------------- | ----- |
| 推荐的地方（在哪儿）      |       |
| 总说：是个什么样的地方     |       |
| 理由一 · 好在哪       |       |
| 理由一 · 让你印象深刻的东西 |       |
| 理由二 · 好在哪       |       |
| 理由二 · 让你印象深刻的东西 |       |

师：老师先填一张给你们看。老师推荐的就是刚才那个小村子。

| 项目              | 我的关键词         |
| --------------- | ------------- |
| 推荐的地方（在哪儿）      | 城外两小时·山坳小村    |
| 总说：是个什么样的地方     | 住下就不想走        |
| 理由一 · 好在哪       | 满山柿子随你摘       |
| 理由一 · 让你印象深刻的东西 | 金红、小灯笼、长竹竿、脆甜 |
| 理由二 · 好在哪       | 村口米糕店现蒸现做     |
| 理由二 · 让你印象深刻的东西 | 白汽、米香、笃笃声、烫手  |

师：看清楚了，每格就几个词，最长的一格也才四个词。下面两格最重要，要写下你在那里看见的、闻到的、吃到的事物。等到动笔写作，单单 “白汽” 这个词，就能拓展成一句话。现在大家动手填写卡片，不用焦虑一定要填满六格，先写出一组素材就很棒。

〖PPT 第13页 · 推荐卡 · 轮到你——先填卡，再跟小组说〗

学生动笔写作（填卡约 3 分钟；教师巡视）

〔应答·学生两条理由填的是同一个方面〕比如两条都在写吃的，就提醒他换个方面写：“除了吃的，那儿的景怎么样？有什么好玩的？有没有什么来历？”帮他把理由二换到另一个方面去。

师：完成填写的同学四人一组开展交流。每人限时半分钟，结合推荐卡，介绍地点并说出两条推荐理由。其余三人商议后做出反馈：两条理由中，哪一条更吸引人。一轮交流完毕，各组选出一名代表准备全班展示。

（四人小组互动交流，推选代表；教师巡视，选择性进入小组倾听。）

师：来，请小组代表进行分享。其余同学耐心等候，第二节课的推荐活动中，大家都可以展示。

（学生代表分享地点与两条理由。教师针对性点评，厘清两条理由的不同角度，点评卡片中最适合拓展写作的细节素材。）

### 五、出示示范文，发现写法（约 8 分钟）

〖PPT 第14页 · 教师示范文 · 老师的那张卡，变成了一篇推荐稿〗

师：你们卡上都有东西了。现在老师把刚才填的那张卡，整篇写出来给你们看。看的时候留心一件事：卡上那几格词，是怎么变成一段一段的话的。

> 【教师示范文】
> 
> 离城两个多小时，山坳里有个小村子。我去年秋天在那儿住了两天，回来到现在还老想着它。这是个让人住下了就不想走的好地方。
> 
> 最值得去的，是村后的柿子山坡。十月里满山的柿子，随你摘。村后那面坡上全是柿子树，叶子落光了，只剩下一树一树的果子，金红金红地挂着，远看像谁在半山腰点了一片小灯笼。房东递给我一根顶头带钩的长竹竿，教我怎么把最高的那几个够下来。竿子一勾，柿子咚地落进草里，捡起来还是温的。咬一口，脆甜，汁水顺着手指往下淌。
> 
> 第二样值得去的，是村口那家米糕店。经常天不亮就开始蒸糕，一排竹蒸笼摞得比人还高，白汽从笼缝里直往外冒，隔着两条巷子就闻得到那股米香。做糕的奶奶拿着木槌，笃、笃、笃轻轻敲打米团。敲上一会儿，她掀开蒸笼，热腾腾的水汽扑面而来，一块米糕垫着荷叶递到我手上，还叮嘱：“趁热吃，凉了口感就不软糯啦。”米糕烫得很，我只能双手来回轮换捧着。一口咬下去，质地软软糯糯，中间裹着红豆沙，甜而不腻。
> 
> 你要是也想找个地方待上两天，就去这个小村子。上山勾一竿柿子，下山趁热吃一块米糕。去过之后，这份滋味，会长久留在你的心里。

〖PPT 第15页 · 读样稿 · 读完，先想两个问题〗

师：先看框架。这篇一共写了几条理由？每条各占几段？

参考：两条／一条一段。

师：每一段的头一句在干什么？

参考：点明理由，告诉读者这一段要写什么。

师：对，每段话一开头就把理由亮出来了——一句写“最值得去的，是十月里满山的柿子”，一句写“第二样值得去的，是村口那家米糕店”。开门见山，读者一眼就能抓住段落重点，条理特别清晰。

师：我们再看开头和结尾。文章开头一句话，总写这个地方的特点——是一个让人住下就不想走的好地方。结尾则顺势发出邀请，推荐大家也来这里做客。总分总结构，完整又规整。

师：大家重点看看写米糕的这一段，是不是特别熟悉？

师：就是它。最开始我们的推荐卡上，只有简简单单四个词：白汽、米香、笃笃、烫手。大家发现没有？课堂卡片上的一个词语，在这里就能扩写成一整句生动的画面。你们卡片上的词语，待会儿也能这样一步步长成完整、生动的段落。

师：最后大家再默读一遍范文，找一找：哪一句话让你眼前浮现出画面，或者仿佛尝到、闻到了味道？

学生互动分享

〖PPT 第16页 · 旁批表 · 每一句都在做一件事——把秘密摆出来〗

师：把你们挑选出的这几句话梳理下，对照着看——

| 示范文里的句子                      | 这一句在做什么               |
| ---------------------------- | --------------------- |
| 这是个让人住下了就不想走的好地方             | 开头一句总说，先给这地方一个说法      |

| 她还叮嘱：“趁热吃，凉了口感就不软糯啦。”          | 记下做糕的奶奶那句话，读的人像站到了摊子跟前 |

师：这篇范文写的是我亲身去过的小乡村。其实大家心里想推荐的地方，独一无二的风景和感受，只有你们自己最了解。写作不用刻意模仿范文的样子，写得像不像一点都不重要。真正关键的是守住两个要求：两条推荐理由各写一段，每一段都融入自己亲眼看见、亲身感受、亲口品尝的真实细节。如果还有特别想写的第三条理由，先把前两条写扎实，再额外简单增补一段即可。

〖PPT 第17页 · 课时一收束 · 三样素材备齐——下节课动笔〗

师：这节课我们已经做好了充足准备，大家手里都备齐了三样写作素材：确定好的推荐地点、梳理完整的推荐卡、打磨到位的口头推荐语句。大家稍作休息，下节课我们就结合这些内容，正式动笔完成推荐稿。

本课完。

## 第2课时 · 当堂写作与评改课

### 一、看着推荐卡，写下开头的几句（约 5 分钟）

〖PPT 第19页 · 写作热身 · 看着推荐卡——写下开头的两句〗

师：把推荐卡拿出来，找到第二格，“总说：是个什么样的地方”那一格。

师：稿纸的第一行是最容易写的，把第一格和第二格连起来说一句，就可以了。老师卡上填的是“城外两小时·山坳小村”和“住下就不想走”，连起来就是——“离城两个多小时，山坳里有个小村子，是个让人住下了就不想走的好地方。”现在把你那两格连成一句，空两格，写在第一行。

学生动笔写作

师：第一句写完，往下就顺了。看理由一的第一格“好在哪”，把那几个词说成一句话，另起一行、空两格写下来。这是这一段的头一句，就像老师那篇里的“最值得去的，是村后的柿子山坡。十月里满山的柿子，随你摘。”。

学生动笔写作

〖PPT 第20页 · 写作热身 · 盯住一样东西——跟着三问，一句一句写〗

师：理由亮出来了，就要用细节把内容写扎实。找到卡片上【理由一・让你印象深刻的东西】这一栏，从里面挑一样最想写的事物，盯住它，跟着老师的问题一句一句写。

师：第一句，写一写它的颜色、模样。动笔。

学生动笔写作

师：第二句，当你走近它，又能观察到哪些细节？留意模样大小、外表特征，写下来。

学生动笔写作

师：第三句，站在近处感受一番：你听见了什么、闻到了什么？倘若可以触摸、品尝，也写下触感或是入口的滋味。

学生动笔写作

师：停一停，回头看这几行。我们先用卡片里的 “总说” 概括这个地方的特点，再把【理由一・好在哪】作为段落开头亮出观点，再借助印象深刻的事物铺展描写，文字才有画面感。大家继续完成第一段。等到写第二条理由时，沿用这套写法：先用【理由二・好在哪】点明观点，再围绕【理由二・让你印象深刻的东西】，借助这三个问题挖掘细节。

### 二、自由写作，把推荐稿写完（约 20 分钟）

〖PPT 第21页 · 自由写作 · 把整篇写完——三件事记在心里〗

师：现在接着往下写，写十七八分钟，把整篇写完。三件事记在心里：两条理由分两段，每段开头先亮理由；每段里写上你在那儿看见的、闻到的、吃到的；最后一句，把人邀请过去。写的时候不用回头改字，一口气写到底。

学生动笔写作

[教师巡视，只做正向介入，不纠错字、不改病句、不打断书写顺畅的学生。按学情分四类处理——]

[接不下去型：写完开头几行就停住、盯着稿纸——把他领回推荐卡：“你这几行已经把第一样东西写出来了。看看‘理由二’那格，第二条还没上场呢，接着往下写它。”]

[内容空泛型：整段都是“那儿特别好玩，去了就不想回来”一类的话。请他先挑出那儿最具体的一样东西，就着这一样问他“它什么样子”“玩起来什么感觉”，答出一句就让他直接写进去。]

[书写顺畅型：不打断，走过时轻声一句“接着写”，为其留出书写空间。]

[草草收尾型：两条理由各写了两三句就搁笔说“写完了”、篇幅明显偏短——先肯定再推一步：“第一条你说的是那儿的景，好。那天你站在那儿，还听见什么、闻到什么？补上一两句。”]

[临近时间提示：把手上这一句写到句号，停在顺手的地方。没写完的不用赶，后面还有一段自改的时间可以接着补。]

### 三、交流评议，修改收束（约 20 分钟）

[同桌互念（约 4 分钟）]

〖PPT 第22页 · 交流评议 · 同桌互念——一句话反馈：“我想去”吗？〗

师：请大家把写好的文稿读给同桌听。交流规则很简单：倾听的同学听完只先给出一句反馈 ——“我想去” 或是 “我还不太想去”。接着补充说明：打动你的是哪一条理由；如果兴趣不大，就讲清楚哪一条没能让你感受到吸引人的地方。两人轮流朗读、互相倾听，交流才算完成。

（学生两两结对朗读互评；教师巡视，走进多组聆听交流）

[好地方推荐会（约 9 分钟）：邀请 4 名学生展示，每人朗读开头总说与最出彩的一条理由，时长控制在一分钟之内；展示结束组织全班投票]

〖PPT 第23页 · 交流评议 · “好地方推荐会”——正式开场〗

师：推荐会开场。有请四位同学上前分享。不必朗读完整文章，读出开头概括特点的总说句，再展示你最有信心的一条理由即可。台下同学认真倾听，心里想一想：听完这份推荐，你是否向往这个地方。

学生互动分享（4 位同学依次念；每一位分享完毕，教师随机邀请一两位听众发言，说说自己被哪一处内容打动。教师顺势点评，聚焦文本细节：点明哪句话写出声音、哪些由推荐卡关键词拓展而成的语句画面感最强；同时温和提出一处可以增补完善的建议。挑选听众发言时尽量兼顾全班，不重复邀请同一批同学）

师：四个地方都推荐完了。现在投票：你最想去哪里？心仪哪一处，就为它举手，每人只能选择一处。

学生互动分享（全班举手投票，教师统计并当场宣布票数最高的地方）

[带标准修改（约 5 分钟）：延迟到此刻统一处理行文细节、订正错别字]

〖PPT 第24页 · 修改收束 · 改一改——三档标准 + 三点自查〗

师：听完别人的，再回自己的稿子上改。对照这份评价标准，看一看自己达到哪一档。

| 档位     | 自检的话                       |
| ------ | -------------------------- |
| 写成了    | 写清推荐地点，完整写出两条理由。           |
| 写好了    | 两条理由角度不重复，每一段都写下现场真实的所见所感。 |
| 写得让人想去 | 读者读完心生向往，能说出被文中哪一处细节打动。    |

师：完成初稿的同学，对照三点逐一调整：第一，两条理由是否分段书写，段落开头有没有清晰亮出观点；第二，如果段落里只有 “很好”“很不错” 这类笼统评价，补充一句感官细节，写下看见、闻到的画面；第三，检查文末是否写上邀约的语句。尚未写完的同学，优先完成正文，只需要修改一处内容即可。同时整理错别字，多余词句圈画删减，缺漏的内容补齐，不会书写的字可以请教同桌或是举手提问。

学生动笔写作（自改；教师巡视答疑）

[收尾（约 2 分钟）]

〖PPT 第25页 · 收尾 · 带回家——念给家里人听〗

师：经过两节课的学习，每位同学都完成了自己的推荐稿。还记得最开始举的例子吗？只一句 “那儿挺好”，很难打动别人；可当你细细讲出柿子、米糕这些真切事物，就能够吸引他人。今天我们练习的，正是把亲身所见、所闻、品尝到的感受落实在文字里。

师：稿子今天就写好了，带回家可以念给家里人听，问问他们想不想去。

（教师总结）这节课我们掌握了写作方法：推荐一处地点，挑选两条最有吸引力的理由，一条独立成段；段首摆明观点，接着填充真实细节，开头总体概括、结尾发出邀请。这套写法不仅适用写景，将来推荐书籍、影片，同样可以使用。

本课完。

## 附：习作讲评指导环节（可选 · 单次课课后用 / 系列课作下次课开场用）

> 本环节供老师灵活取用：可在单次课课后批读学生习作后集中讲评一次，也可作系列课下一次课的开场（约 15–20 分钟）；不计入本课 45+45 分钟，评的是学生当堂完成的稿子，不布置新的写作任务。
> 讲评中凡出现 ＿＿＿ 处，务必换成本班学生习作里的真实句子，切勿虚构。

### 选稿（课前准备）

课后通读全班习作，紧扣本课核心技法：**两条理由分段写、段首亮明观点、段落嵌入实景细节**，筛选三篇典型稿件投屏讲评，匿名展示，兼顾示范、修改、纠错三类样本：

1. 优秀范例：两条理由角度独立不重复，每段都配有看得见、闻得到、尝得着的实景细节，用于全班对标学习，明确“具体写实”的写作标准。

2. 中等提升范例：整体结构工整规范，分段清晰，段首能准确亮出核心理由，基本功扎实。唯一不足是段落内容偏笼统，仅有概括性评价，缺少落地的实景细节，专门用来示范“如何一句话补齐细节、盘活段落”。

3. 典型问题范例：全文写成流水式出游记录，单纯记录游玩过程，或是两条理由角度重叠、内容重复，没有清晰的推荐逻辑，重点模糊。用于带领全班集体问诊问题、共同修改完善。

课前为三篇稿件各拟定一句简短评语，精准点明贴合本课技法的亮点与不足，方便课堂高效讲评。

### 讲评流程（每篇约 3–5 分钟，围绕本课技法点）

〖PPT 第26页 · 习作讲评 · 习作讲评环节（可选·课后或下次课开场）〗

师：上次推荐会上，有四位同学把稿子念给了全班，每个人也都念给同桌听过。老师课后把每一篇都读完了，今天挑三篇出来，只看一件事：理由有没有分开写，段里有没有具体的东西。

师：先看第一篇。他写“＿＿＿”（念该篇写得最具体的一两句），你们听，这几个字一出来，那样东西就在跟前了。再看他这两条，一条说的是＿＿＿（口头概括第一条落在哪个方面），一条说的是＿＿＿（第二条的方面），角度清晰、互不重复，读的人不会觉得他在重复。

（教师总结）理由分层清晰，每段都有实景细节，这就是完全贴合我们本节课写法的优质范文。

师：第二篇结构很齐整，两段两条，段头也亮了理由。就是这一句——“＿＿＿”（念该篇只报结果的那一句），只有笼统夸赞，没有具体画面，写完就草草收尾。大家想想，这一句底下要是再补一句，补什么好？他写的是哪个地方来着，那儿有什么是我们能看见、能闻到的？

学生互动分享

师：对，就补这么一句。改这一处不用重写整段，就是在那句话后面添一句具体的。

师：第三篇不说是谁写的，咱们一起帮他想办法。他这篇＿＿＿（口头概括该篇的问题，如：从早上出发写到下午回家，一天的事写全了，可没说这地方好在哪儿）。这样一篇，要改成推荐，第一步该动哪儿？

学生互动分享

师：大家的思路非常准确。这篇文章不缺素材，缺的是梳理与取舍。只需从全文素材里，挑选两个最亮眼、最吸引人的特色，分成两段、段首亮明理由，就能改成一篇合格的好地方推荐稿。

### 收尾（点回技法、引向今后的写作）

师：看完三篇习作的对比，大家应该清楚了写作关键：真正打动别人的，不是空泛的夸赞，而是扎实的方法——两条理由，一条一段，段首亮明观点，段落里填充亲眼所见、亲耳所闻、亲身所感的实景细节。

师：今后不管是推荐地方，还是推荐书籍、好物，大家都可以用这套方法自查：我的两个理由角度是否不同？每一条理由，有没有能让别人看得见、感受得到的具体细节？

本环节完。
