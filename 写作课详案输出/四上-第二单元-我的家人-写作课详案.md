# 《我的家人》· 写作课教学设计
四年级上册·第二单元 校内同步写作（写人习作）

[授课提示：本课第三、四、五环节里老师用来做示范的那位姥爷，取自教材习作页上印着的那段话，是教材里那位同学的姥爷，不是授课老师自己的家人。老师照着讲即可，不必换成自己家的人——本课要求学生写自己最熟的家人，老师若拿自家人做示范，学生容易照着老师那一家的样子写。]

## 教案提纲表

| 课题·课时 | 四上·第二单元《我的家人》　│　写人·校内同步　│　2课时连排（每节45分钟） |
| --- | --- |
| 能力阶段 | 写清楚 → 写具体（本课） → 写生动 → 写深刻·有章法 |
| 同类习作顺序 | 写人：猜猜他是谁 → 身边有特点的人 → 我的家人（本课） → 自画像 → “漫画”老师 → 他＿＿了／形形色色的人 |
| 教材要求 | 统编四上·第二单元习作：结合具体事例写出家人的特点，把印象最深的地方写出来。 |
| 学习目标 | 手上一段能带回家读的话：写的是家里的一位家人，中间有**一件他真做过的事**，事里有他的动作和他说的一句话。家里人听完会说，这写的可不就是他。 |
| 核心技法 | 先想起一件他真做过的事，再从这件事里看出他是个什么样的人——**倒过来写**：让那件事替你把话说完，读的人自己就认出他（想先直说一句他是个什么样的人、再拿这件事把这句话撑住，同样成立）；一堆事里挑**印象最深、别人家写不出的那一件**。 |

## 第1课时 · 写作指导课

### 一、创设情境，明确任务（约 6 分钟）

师：我们先看几句话。这几句是书上给的例子，写的都是自己家里的人，一人一句，都很短。

〔材料〕投屏出示教材习作页上的五段话（奶奶脾气特别好、总是笑眯眯的，还特别会做好吃的；爸爸是卡车司机，工作很忙，一有空就给我们讲故事；姥爷已经退休了，每天练习书法，一年三百六十五天从不间断；妈妈酷爱运动，跑步、跳绳、打羽毛球都充满热情；妹妹今年四岁，很淘气，也很聪明）。

师：这五位家人，要是让你挑一位认识认识，你最想认识哪一位？说说你挑他的理由。

学生互动分享（举手抽说三四位；其余同学带着任务听——听听别人挑的跟自己挑的一样不一样）

参考：会讲故事的爸爸／练书法的姥爷，一年三百六十五天太厉害了／妹妹，四岁很好玩。

师：老师跟不少同学挑的一样，我最想认识这位会讲故事的爸爸。可这一句我读了两遍，还是没读出他到底怎么个会讲法。

师：你们说说看，他是怎么讲故事的？

参考：（学生答不上来，多半会说）没写／不知道／书上没说。

师：对，这句话没告诉我们。它说了他一有空就给我们讲故事，可他怎么讲的、讲的时候什么样子，一个字也没有。所以我读完，还是不认识他。

师：今天这两节课，我们就来写这么一段话：每人挑家里一位家人，写完之后让从来没见过他的人读一读，读完就像认识了他。

师：这段话写完，有两个人要读到。第一个是坐在你旁边的同桌，他不认识你家里的任何一个人，读完他要能告诉你，他觉得这是个什么样的人。第二个更要紧：这段话你带回家，读给你写的那位听。他听完会给你一句评价，说这一段写得像不像他。

师：这两节课就写这一段。这个单元的习作，写的正是《我的家人》。

### 二、想一想，你家那位这个月做过什么（约 10 分钟）

师：动笔之前，我们先把材料准备足。老师不问你家里人是什么样的人，先问一件更简单的事——他最近做过什么。

师：拿出学习单，翻到最上面那几行空格。给你一小会儿工夫，把你家某一位这个月做过的事写下来，能想起几件写几件。不用写整句，三五个字一件，自己看得懂就行。想到什么写什么，先别挑。

[发放学习单；教师同时提示只写事、不写评价，写“给自行车打气”“半夜起来关窗”这样的，不写“他很能干”。]

学生动笔写作（约 2 分钟；教师走两三排看学生写下的条数，遇到只写了一条的，走近问一句“上个星期天他在家干什么”）

师：好，笔停一下。你们写下了几件？

学生互动分享（举手抽说三四位，只报条数与其中一件）

参考：三件／五件／我写了两件，一件是他修台灯，一件是送我上学。

师：不少同学一下子写出了三四件。这说明什么？说明家里人这些事，你根本不用想，它自己就冒出来了。因为你天天见着他。

师：现在跟同桌说其中一件。就说事，不评价。说完，听的那位同学不说好不好，只回两句：头一句问你，这件事你是什么时候看见的；第二句问你，他当时说了句什么。

学生互动分享（同桌两两互说，各说一轮；教师走到两三组跟前当第一位听众）

〔应答·学生只报了一个词说不出经过〕不追问“他是个什么样的人”，改问具体的：“那天他在哪儿？手里拿着什么？”问出一样，就让他接着往下说。

师：刚才有位同学说，他爸爸修台灯修到十一点。你们听——他一句评价都没给，可我们听着，心里已经有个数了。这就是今天要学的本事，下一步我们就来说说它。

### 三、学写法：先有一件事，再有一个人（约 12 分钟）

师：这道题到底要我们写什么，得先弄清楚。老师写了两段话，都是写自己家里人的。我读一遍，你们边听边看，听完告诉我，哪一段是这道题要的。

〔材料〕两段话投屏出示，教师念读时同步呈现；后面判断、以及回头数“有几件事”都要回看这两段，念完先不撤屏。

师：第一段——“我家有四口人。爸爸个子很高，站在门口能碰到门框上沿，他在工地上开吊车，早出晚归。妈妈头发短短的，说话嗓门大，她做的红烧肉是全家最爱吃的一道菜。妹妹今年五岁，扎两个小辫子，一天到晚在屋里跑来跑去。还有我，我是四年级的学生。我们一家人过得很热闹。”

师：第二段——“我家妹妹五岁。上个星期天早上我在写作业，她搬了张小板凳坐到我旁边，把下巴搁在桌沿上看我写。看了一会儿，她伸手把我的橡皮拿走了，说：‘哥哥你写错了我帮你擦。’我说我没写错。她想了想，又把橡皮放回来，小声说：‘那你写错了再叫我。’然后一直坐在那儿等着，等到我写完。”

师：哪一段是这道题要的？

参考：第二段。／我选第一段，第一段四个人都写到了。

师：选第一段的同学，你说说，第一段哪一点让你觉得它对？

参考：它四个人都写到了／它写了门框、吊车，还有小辫子／它没有空着的地方。

师：这几样你们都看准了。

师：那我们回到题目上来看。这次习作要求上写着一句话：结合具体事例写出家人的特点。“事例”，就是一件事。你们回头数一数，第一段里有几件事？

参考：没有／一件也没有。

师：一件也没有。四个人，样样都交代了，可没有一个人在做事。第二段呢，只写了一位，就写了一件事——妹妹拿橡皮那一回。所以第一段不是写得不好，是没有按这道题的要求写。

师：这里还要说清一句：题目上写着，可以写一个家人，也可以写家里的几个人。写几个人当然行，但每个人都得有他自己那一件事，不能一人一句排下去。

师：那这件事该怎么挑、怎么写？我们来看今天这个写法。

师：还记得刚才屏幕上那位姥爷吗——“姥爷已经退休了，每天练习书法，一年三百六十五天从不间断。”这句话没写错，意思也清清楚楚。可我们刚才说了，读完还是不认识他。

师：现在老师给这位姥爷添一件事，你们再听听有什么不一样。

〔教师示范·当场把教材那句结论写成一件事，念给学生听〕去年腊月，姥爷答应给楼下几户人家写春联。那天下午他把八仙桌搬到窗底下，红纸裁成一条一条铺开，砚台压在最边上那张纸角上。写第一副的时候，“福”字最后那一笔他收得很慢，笔尖在纸上顿了一下才提起来。写完一副，他直起腰，捏着红纸的两个角，轻轻放到旁边的椅子上晾着，然后接着写第二副。那天下午他一直写到天黑。

师：听完这一段，这位姥爷是个什么样的人？

参考：很认真／他答应了人家就一直写／写到天黑都没停。

师：你们再听听自己刚才说的这几句。老师那一段里，从头到尾没有给姥爷下过一句结论，可你们刚才那几句，说的正是他这个人。

师：这就是今天要学的写法，它跟我们平时想的顺序倒过来了。平时我们是先想好他是个什么样的人，再去找一件事来证明；今天反过来，先想起一件他真做过的事，把这件事写清楚，让读的人自己看出来。

师：那么两种写法，哪一种更好？其实两种都能用。“我姥爷很有毅力”这句话，写在开头当第一句，一点问题都没有，读的人一下就知道你要写什么。最好的办法是搭着用：先直说一句，再拿一件事把这句话撑住。你自己挑：想先直说，就先写那一句；想让读的人自己发现，就直接从那件事写起。

师：不过直说也有讲究。“他很好”“他很能干”这种话，安在谁身上都成立，写上去等于没写。要直说，就直说得像“说出口就一定做完”这样——只有他对得上。

师：接下来是今天的第二件事，也是最要紧的一件——挑哪一件事。

师：你们刚才在学习单上写了三件、四件、五件。这么多件，不能都写。挑哪一件？老师给你们一个挑的办法：挑别人家写不出来的那一件事。

师：什么叫别人家写不出来？比如有同学写“妈妈每天给我做饭”。这一件，全班一大半人的妈妈都做。再比如刚才那位姥爷写春联写到手抖，这一件，就只有他家有。

师：现在你们自己看学习单上写的那几件事，一件一件过：这一件，别人家有没有？哪一件是只有你家才有的？想好了先别说，等会儿要填到表上。

师：还有一个更简单的办法，两个你用哪个都行：把学习单合上想一想，哪一件事你现在还看得见当时的样子——他站在哪儿、手里拿着什么、说了句什么。现在还看得见的那一件，就是你印象最深、也最写得出来的那一件事。

（教师总结）今天两件事：头一件是倒过来写，先写他做过的一件事，让这件事替你说话；第二件是怎么挑，挑别人家写不出、你自己还看得见的那一件事。

### 四、借助选事表，理清思路（约 9 分钟）

师：先看老师的一张表。这是老师写那位姥爷之前填的，你们看看，老师是怎么用它的。

[投屏出示下方教师示范填好的表，先不发空表。]

| 项目 | 我的关键词 |
| --- | --- |
| 我写家里哪一位 | 姥爷 |
| 想起来的事（几件都行） | 写春联、教我握笔、早上练字 |
| 挑中的是哪一件 | 写春联 |
| 挑它的理由 | 只有他家有 |
| 这件事里，他做了什么 | 搬桌、裁纸、按膝盖 |
| 这件事里，他说了哪一句 | 再写两副，人家等着贴 |
| 最后回来填：他是个什么样的人 |  |

师：你们看第二格，老师想起来三件事。第三格挑的是写春联。为什么挑它、不挑“早上练字”？

参考：早上练字别人家老人也在做／写春联只有他家有。

师：你们看出来了。再看第五格、第六格，我填的是搬桌、裁纸、按膝盖——这几个词不是形容词，全是他的动作。就靠这几个词，那半个下午我才能重新写出来。

师：最后一格我空着。那一格要等前面都填完了，回头再填。

师：现在轮到你们。表在学习单的下半页。每一格填几个词，三五个字，自己看得懂就行，不用写整句。只有一格例外——他说的那一句话，要照他原来的说法写下来。跟老师一样，那一格先空着。

| 项目 | 我的关键词 |
| --- | --- |
| 我写家里哪一位 |  |
| 想起来的事（几件都行） |  |
| 挑中的是哪一件 |  |
| 挑它的理由 |  |
| 这件事里，他做了什么 |  |
| 这件事里，他说了哪一句 |  |
| 最后回来填：他是个什么样的人 |  |

学生动笔写作（约 4 分钟；教师巡视，重点看第三格与第四格是不是挑出来了、第五格填的是不是动作）

[教师巡视：① 第二格只写出一件的，问一句“上个星期他在家干什么”，帮他再想出一件；② 第五格填成“很认真”“很辛苦”的，指着格子说“这一格要填他的手在干什么”；③ 第四格空着的，把第二格几件念给他听，问“这几件里，哪一件别人家没有”。]

师：笔停一下。请几位同学说说，你挑中的是哪一件，为什么挑它。

学生互动分享（举手抽说三位；其余同学带着任务听——听听他挑的那一件，是不是别人家写不出的）

参考：我挑我爸爸修台灯，修到十一点，别人家爸爸不会修／我挑我奶奶找老花镜，她找了半天，镜子在她头上／我挑妈妈做饭，因为她天天做饭。

师：最后这位同学，妈妈天天做饭这一件，全班一多半人的妈妈都在做。你再想想，你妈妈做饭的时候，有哪一回是跟平常不一样的？

参考：有一回她炒糊了一锅菜，还说是故意炒的。

师：这一件就只有你家有了，就写这一件。

师：好，现在把最后那一格填上。写完前面六格，你再回头看一眼那件事——这件事里的他，你会用哪个词来说他？填一个词，或者一句短话。

学生动笔写作（约 1 分钟）

（教师总结）先把事挑出来、把动作和话填进去，最后才回头给他下那一句结论。这一格填得出来，说明你挑的那件事是对的。

### 五、出示示范文，发现写法（约 8 分钟）

师：你们手上都有一张填好的表了。老师那张表也填完了，最后一格我填的是“说出口就一定做完”。现在老师把这张表写成了一段完整的话，你们边听边看，看表里那几个词是怎么变成一段话的。

〔材料〕示范文投屏出示，教师念一遍；后面几处要回到文里指认具体句子，念完不撤屏。

> 【教师示范文】
>
> 我姥爷是那种说出口就一定做完的人。
>
> 去年腊月，楼下几户人家托姥爷写春联，他一口应下来。那天下午，他把八仙桌从里屋搬到窗底下，红纸裁成一条一条铺开，砚台压在最边上那张纸角上。姥爷写字的时候不许人说话，我就搬了个小板凳坐在旁边看。
>
> 写第一副的时候，“福”字最后那一笔他收得很慢，笔尖在纸上顿了一下，才慢慢提起来。写完一副，他就直起腰，捏着红纸的两个角，轻轻放到旁边的椅子上晾着。
>
> 我在边上数着，一副，两副。屋里静得很，只听见笔尖擦过红纸的沙沙声。写到第三副，他忽然停下笔，把毛笔搁在砚台边上，两只手在膝盖上按了按。我这才看见，他的手在抖。
>
> 我说：“姥爷，你歇会儿吧，明天再写。”
>
> 他没抬头，把笔又拿起来，说：“再写两副，人家等着贴。”
>
> 结果那天下午他一直写到天黑，屋里暗下来才开灯。桌上、椅子上、地上，摊满了晾着的红纸，一共十七副。姥爷把手在裤子上擦了擦，说了句：“成了。”
>
> 我姥爷平时话不多，一年到头就在那张八仙桌上写字。可那天下午我明白了，他说“再写两副”的时候，是真的会写完的。

师：先看这段话是怎么搭起来的。开头第一句，老师写了什么？

参考：说姥爷是说出口就一定做完的人。

师：对，老师先直说了一句。这就是刚才说的“搭着用”：先一句话把他点出来，再拿这一整件事把这句话撑住。你们要是想让读的人自己发现，把开头这一句去掉，直接从“去年腊月”写起，也一样成立。

师：那中间这一大段，写的是几件事？

参考：一件。／就是写春联那一件。

师：一件。从搬桌子写到天黑，从头到尾就这一件。所以你手上那张表挑中的那一件，够你写一整段了，不用再凑第二件。

师：再看得细一点。这一段里，哪一句让你读着就知道姥爷写得很吃力？

参考：两只手在膝盖上按了按／他的手在抖。

师：这两句里，老师有没有写“姥爷很累”“姥爷很辛苦”？

参考：没有。

师：没有。只写了他两只手按膝盖、手在抖。这就是我们前面说的，让那件事替你把话说出来。

师：还有一句更要紧的，是姥爷自己说的那一句。哪一句？

参考：“再写两副，人家等着贴。”

师：就这九个字。你把这句话换成“姥爷说他要坚持写完”，还是这个姥爷吗？

参考：不是了／没那个味儿了。

师：所以他说的那一句，照他原来的说法写下来，那个味儿才在。你们表上第六格填的那句话，动笔时就照原样搬进去。

师：我们把刚才找出来的这几句并在一起，老师再添上两句你们没提到的，一块儿看一眼。

| 示范文里的句子 | 这一句在做什么 |
| --- | --- |
| 我姥爷是那种说出口就一定做完的人 | 开头先直说一句，把人点出来 |
| 把八仙桌从里屋搬到窗底下，红纸裁成一条一条铺开 | 事情的开头，交代他在干什么 |
| “福”字最后那一笔他收得很慢 | 他的动作，写得慢、写得细 |
| 我这才看见，他的手在抖 | 不说累，用动作让人看出来 |
| “再写两副，人家等着贴。” | 他说的那一句，照原话写 |
| 一共十七副 | 一个具体数目，比“写了很多”实在 |

师：等会儿动笔，你不用样样都学。先做到两样：他做了什么，他说了哪一句。这两样在，人就立在纸上了。

本课完。

## 第2课时 · 当堂写作与评改课

### 一、借助选事表，写下第一组句子（约 5 分钟）

师：把上节课那张选事表拿出来，放在稿纸旁边。

师：先看最后一格，你上节课回头填的那个词。第一句就写它。开头空两格，照着那一格写一句短话：我姥爷是那种说出口就一定做完的人；我妹妹是个爱管事的小孩。写完这一句，先停下来等一等。

师：上节课说过，这一句你也可以不放在开头。想让读的人自己看出来的，就把它先写在稿纸最下面一行，等整段写完了再决定要不要搬上去。

学生动笔写作（约 1 分钟）

师：好。接下来我们把那件事请出来。老师问几个问题，你不用回答我，直接往纸上写。写三五个字也行，写一句也行，想到就写，别停下来琢磨。

师：第一个问题：那件事发生的时候，他人在哪儿、手里拿着什么？

学生动笔写作

师：第二个：他当时在做什么，手上那个动作，是怎么做的？

学生动笔写作

师：第三个：那会儿他说了一句什么话？照他原来的说法写，他当时怎么说的，你就怎么写。

学生动笔写作

师：这三个问题的答案，你手上就有了。看一眼你写下的这几行，把它们连起来，就是这件事的开头。

师：接下来这半节课都归你们自己。从刚才写的地方接着往下写——这件事后来怎么样了，你当时是怎么想的，都写进去。碰上写不出来的字，先空着，或者画个圈做个记号，等会儿再补，别停笔去查。

（教师总结）你手上这几行，头一句说的是这个人，后面几行已经进到那件事里了。开头这一步过去了，接着往下讲就行。

### 二、自由写作（约 20 分钟）

学生动笔写作（约 20 分钟；教师全程不纠错、不打断，只做正向巡视）

[教师巡视：本环节不指出错别字、不改病句、不纠格式，一律留到下一环节。四类学情各给一句指导语——]

[写完开头就停住的：把他已经写下的那几行念给他听，说“这几行就是开头，你已经写出来了”，再问一句“那件事后来怎么样了，他最后做完没有”，推他接着往下写。不要让他从第一句重写。]

[内容空泛、通篇写“他很好、他很能干”的：指着他选事表第五格，说“这一格你填了他的动作，把这个动作写到纸上去”，一次只提一个动作。]

[书写顺畅的：不打断，留出书写空间，走过时点一下头即可。]

[写了三五行就搁笔说“写完了”的：先肯定一句“这件事你交代清楚了”，再追问一处细节，如“他说那句话的时候，人是站着还是坐着”，请他把这一处补进去再收。]

〔应答·学生问“可不可以写两个人”〕可以。请他按同样的办法办：一个人一段，每一段各写各的那一件事，两段的事不能是同一件。写完一位再起第二段。

### 三、交流评议，修改收束（约 20 分钟）

师：笔先放下。写完的、没写完的都一样，我们现在来读一读。

[同桌互念环节（约 6 分钟）：两人一组，各念一遍自己写的，每人约 2 分钟，余下时间用于问答。]

师：先跟同桌念。你念的时候，同桌只做一件事：听完，问你一个问题，就问他还想知道的那件事。比如“他修台灯修到十一点，那他修好了没有”“你奶奶找到老花镜的时候说什么了”。

师：被问到的那位同学，当场回答。要是你答得出来、纸上又没写，那就赶紧补到纸上去——这一句多半正是你漏掉的那句话。

学生互动分享（同桌两两互念，各念一轮，听者各提一个问题；教师走到三四组跟前听，遇到听者问不出问题的，替他起个头：“你想不想知道后来怎么样了？”）

师：好，请两位同学念给全班听。每一位念完，我都请一位同学提一个问题，还是刚才那个办法。

学生互动分享（全班两位念读，每位念完请一位听众提一个问题，作者当场答，教师就作者补出的那句点评一句；约 5 分钟）

〔应答·听众提不出问题、只说“写得好”〕请他说得具体些：“这一段里，你最想知道的是哪一处？他做完这件事以后怎么样了？”把问题落到那件事上。

师：刚才有几位补上的那句话，比原来纸上的还要好。你们脑子里装着的东西，比写下来的多——有人问一句，它就出来了。

师：接下来我们自己改一遍。对着这四条看自己那一页。

| 我写到了没有 | 自检的话 |
| --- | --- |
| 有没有一件事 | 我写的是他真做过的一件事，不是一句话带过 |
| 事里有没有他 | 这件事里有他的动作，也有他说的一句话 |
| 挑得对不对 | 这一件，别人家写不出来 |
| 认得出他吗 | 把开头那句话盖住，光读中间这件事，还看得出他是个什么样的人 |

师：四条对下来，缺哪一条就补哪一条。用修改符号把稿子理一遍：多的字圈掉，漏的字补上，错的字改正。要补的句子直接写在行间，不用重抄。

学生动笔写作（约 5 分钟；教师巡视，对照四条个别指导）

〔应答·学生说“第三条我做不到，我写的事别人家也有”〕不必推翻重写。请他在这件事里再找一处只有他家才有的细节补进去——他说的那一句话、他当时的一个小动作，往往就是那一处。

师：改好了的，再跟同桌念一遍。这回同桌不提问题了，他听完只说一句话：你写的这位，是个什么样的人。

师：他说完，你再去看上节课那张选事表，你自己填的那个词还在那儿。两个对得上，这一段就成了：你没有告诉他，他自己看出来了。

学生互动分享（同桌两两互念改后的稿子，听者各说一句“这是个什么样的人”，作者对照选事表最后一格；约 2 分钟）

〔应答·同桌说出来的跟最后一格对不上〕不是写坏了。请作者问同桌一句“你是从哪一句看出来的”，多半是那件事里还缺他的一个动作或者一句话；补上去，再念一遍。

师：最后一件事。这段话现在写在你手上，它真正的读者还没读到——就是你写的那一位。今天回去，找个他不忙的时候，把这一段读给他听。他听完多半会给你一句话，说写得像，或者说不像，你把什么什么给写漏了。

师：不管他说哪一句，你都听得出来，那句话跟同桌给你的评价不一样——因为这回，是他本人在说。

本课完。

全课完。

## 附：习作讲评指导环节（可选 · 单次课课后用 / 系列课作下次课开场用）

> 本环节供老师灵活取用，不计入两节连排的 45＋45 分钟：既可在单次课后另找时间集中讲评一次，也可作为系列课下一次课的开场（约 15–20 分钟），先讲评上次的习作，再进入新内容。
>
> 下面凡是 ＿＿＿ 的地方，务必换成本班学生真实写下的句子，不要用别的班的例子代替。

### 选稿（课前准备）

课后通读全班稿子，挑出三篇：一篇较好、一篇中等、一篇有典型问题，覆盖不同层次，不要三篇都从写得最好的几位里挑。三篇各用一句话对着本课的写法记下它好在哪、欠在哪：

- 较好的一篇：事挑得准，别人家写不出，事里有动作也有话。记下最能看出这个人的那一句是 ＿＿＿（抄下原句）。
- 中等的一篇：事挑对了，动作有了，可他说的那一句还没写进去，或者写成了书面话。记下缺的是哪一样 ＿＿＿。
- 有典型问题的一篇：写的还是“他很好、他很能干”这一类，事情只用一句话带过。记下他原本可以展开的那件事是 ＿＿＿。

投屏时不出现学生姓名，只念稿子。第三篇不点名。

### 讲评流程（每篇约 3–5 分钟，围绕本课技法点）

师：上次课我们写了自己的家人。今天不挑毛病，就看一件事：那件事，写出来没有。

师：先听第一篇。（念较好的那一篇）

师：这一篇里，那位家人做的是哪一件事？

学生互动分享（请两位说出那件事）

师：他这一句最能让人看见这个人——“＿＿＿”（念该生写得最传神的那一两句）。你们注意，他没有给这位下一句结论，他写的是这位做了什么。上节课我们说的就是这个。

师：再听第二篇。（念中等的那一篇）

师：这一篇事也挑得好，动作也写出来了。可有一样还没写进去，你们猜是哪一样？

参考：他说的话／没写他说什么。

师：对。（转向作者）你写的那位当时说了句什么，你还记得吗？

师：（学生答出后）就这一句，补到 ＿＿＿ 这个地方去（指出该补进的位置）。补上这一句，这一段就齐了。

师：最后一篇，我们一起来想想办法。（念有典型问题的那一篇，不点名）

师：这一篇里写到 ＿＿＿（念他一句话带过的那件事），就这么一句。你们说说，这件事要是展开写，可以往里加些什么？

学生互动分享（引学生说出“加他的动作”“加他说的话”“加那天他在哪儿”）

（教师总结）加的都是同一样东西——那件事当时到底是怎么发生的。这一句话里其实藏着一整段。

### 收尾（点回技法、引向今后的写作）

师：今天这三篇，好就好在把一件事讲出来了。往后你再写一个人，不管写的是家里人、同学，还是路上遇见的谁，都可以把这句结论先放一放，先想想他做过哪一件事，把那件事讲清楚。讲清楚了，他是个什么样的人，读的人自己就看出来了。

本环节完。
