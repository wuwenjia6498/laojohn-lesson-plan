# 《我的家人》· 写作课教学设计

四年级上册·第二单元 校内同步写作（写人习作）

[授课提示：本课第三至第五环节示范用到的爷爷形象，来自教材习作页给出的示例，是文本里的人物，并非教师本人的家人。课堂上直接依托教材内容来讲就可以，不要替换成自己家里的亲人。
如果教师拿自家家人举例示范，不少学生会模仿老师的素材思路，局限写作，不利于学生写自己真实熟悉的家人。]

## 教案提纲表

| 课题·课时  | 四上·第二单元《我的家人》　│　写人·校内同步　│　2课时连排（每节45分钟）                                                                                              |
| ------ | ------------------------------------------------------------------------------------------------------------------------------------ |
| 能力阶段   | 写清楚 → 写具体（本课） → 写生动 → 写深刻·有章法                                                                                                        |

| 教材要求   | 统编四上·第二单元习作：结合具体事例写出家人的特点，把印象最深的地方写出来。                                                                                               |
| 学习目标   | 通过写一件自家真实发生过的小事，来学习怎么写出一位家人的特点。 |

## 第1课时 · 写作指导课

### 一、创设情境，明确任务（约 6 分钟）

〖PPT 第3页 · 创设情境 · 书上这四位家人——你最想认识哪一位？〗

师：我们先看几句话。这几句是书上给的例子，写的都是自己家里的人，一人一句，都很短。

〔材料〕投屏出示教材习作页上的4段话（我奶奶脾气特别好，总是笑眯眯的。她还特别会做好吃的，我最喜欢吃奶奶做的饭；我爸爸是卡车司机，他很忙，一年到头很少在家。他很会讲故事，一有空就讲给我和弟弟听；我爷爷已经退休了，他每天练习书法，一年三百六十五天从不间断，非常有毅力；我妹妹今年四岁。她很淘气，也很聪明）。

师：这4位家人，要是让你挑一位认识认识，你最想认识哪一位？说说你挑他的理由。

学生互动分享

参考：会讲故事的爸爸／练书法的爷爷，一年三百六十五天不间断，太厉害了／妹妹，四岁很好玩。

〖PPT 第4页 · 创设情境 · 这位爸爸，到底怎么个会讲法？〗

师：老师跟不少同学挑的一样，我最想认识这位会讲故事的爸爸。可这一句我读了两遍，还是没看出他讲故事到底好在哪儿。

师：你们说说看，他是怎么讲故事的？

参考：没写／不知道／书上没说。

师：对，这句话没告诉我们。它说了爸爸一有空就给我们讲故事，可他怎么讲的、讲的时候什么样子，一个字也没有。所以我读完，还是不认识他。

〖PPT 第5页 · 创设情境 · 这两节课的任务——写一段让人“认识”他的话〗

师：今天这两节课，我们就来写这么一段话：每人挑家里一位家人，写完之后让从来没见过他的人读一读，读完就像认识了他。

师：写好之后，有两位听众要来读我们的文字。第一位就是你的同桌，他并不认识你的家人，读完要能说一说，他感受到这位家人是怎样的人。第二位，也是更重要的，就是把习作带回家读给他听；不方便当面读的，读给家里另一位听也行。看看他会不会觉得，你写的就像真实的他。

师：这两节课，我们就重点完成这一段习作，也就是本单元的习作《我的家人》。

### 二、想一想，家人最近做过哪些事（约 10 分钟）

〖PPT 第6页 · 清点小事 · 先别想特点——想想他最近做过哪些事〗

师：动笔写之前，我们先来搜集写作素材。老师先不问大家这位家人有什么性格特点，我们先来想一想：他最近都做过哪些事情。

师：接下来我要给大家每个人发一张空白小纸条。请你想一想家里的一位亲人，把他最近一段时间做过的事简单记下来，想到几件就记几件。不用写完整句子，三至五个字记录事件就可以，自己能看懂就行，想到什么记什么，暂时不用挑选。

[发放空白小纸条；教师提示：只记录发生的事情，不要写评价。比如写“修自行车”“夜里起来关窗户”这类事实，不要写“他很能干”这种评价的句子。]

学生动笔记录（约 2 分钟；教师巡视两三排，查看学生记录的事件数量。如果学生只写出一件，就轻声追问：“上个星期天，他在家做些什么？”帮学生打开思路）

师：好，请大家停笔。谁来说说，你一共记下了几件事？

学生互动分享（点 3‑4 名学生，只说数量，再简单说其中一两件事即可）
参考示例：三件 / 五件 / 我记了两件，一件是爸爸修台灯，一件是送我上学。

师：很多同学一下子就想出了三四件事。是啊，我们天天和家人生活在一起，他们做过的很多事，我们都看在眼里。

〖PPT 第7页 · 清点小事 · 挑一件，说给同桌听〗

师：接下来，请你和同桌说一说其中一件事。只讲发生了什么，不要评价这个人好不好。同桌听完，不需要点评写得好不好，只问两个问题：第一，这件事你是什么时候看到的？第二，当时他说了什么话？

学生互动分享（同桌两人轮流讲述；教师走到几组学生身边，参与倾听）

〔课堂应答预案：如果学生只能说出一个词语，讲不出事情经过，不要问“他是个怎样的人”，换成具体问题引导：“那时候他在什么地方？手上拿着什么东西？”学生答出一点，就鼓励他继续往下讲。〕

师：刚刚我听到有同学分享，爸爸修台灯一直忙到十一点。你看，他没有说爸爸有多辛苦，可听完这件事，我们心里就能感受到一些东西。这就是我们这节课要学习的写作方法，接下来我们就一起来研究。

### 三、学写法：借助一件事，写出家人特点（约 12 分钟）

〖PPT 第8页 · 判断对比 · 这两段话，哪一段更符合这次习作的要求？〗

师：我们先来弄明白本次习作到底要写什么。老师写了两段文字，都是介绍家里人的，我读给大家听，同学们看着屏幕，听完想一想，哪一段更符合这次习作的要求。

〔材料〕投屏出示两段文字，教师朗读；后面课堂判断、梳理事例环节都要回看这两段，读完先不要关闭页面。

师：第一段 ——“我家有四口人。爸爸个子很高，站在门口能碰到门框上沿，他在工地上开吊车，早出晚归。妈妈头发短短的，说话嗓门大，她做的红烧肉是全家最爱吃的一道菜。妹妹今年五岁，扎两个小辫子，一天到晚在屋里跑来跑去。还有我，我是四年级的学生。我们一家人过得很热闹。”

师：第二段 ——“我家妹妹五岁。上个星期天早上我在写作业，她搬了张小板凳坐到我旁边，把下巴搁在桌沿上看我写。看了一会儿，她伸手把我的橡皮拿走了，说：‘哥哥你写错了我帮你擦。’我说我没写错。她想了想，又把橡皮放回来，小声说：‘那你写错了再叫我。’然后一直坐在那儿等着，等到我写完。”

师：大家说一说，哪一段更符合习作要求？
参考：第二段。／我选第一段，第一段把家里四个人都写出来了。

师：选第一段的同学，来说说，你觉得第一段好在哪里？
参考：它四个人都写到了／写到了门框、吊车，还有小辫子／内容写得满满的。

师：你们观察到的这些确实都写出来了。我们回到习作要求来看，书上告诉我们，要结合具体事例写出家人的特点。什么叫事例？就是实实在在发生的一件事。大家数一数，第一段里面，完整写了哪一件事？
参考：没有／一件也没有。

师：没错，一件完整的事例都没有。虽然介绍了四个人，写了外貌、工作，但是没有写谁具体做了什么事。再看第二段，只写了妹妹一个人，完整记录了拿橡皮这件小事。不是说第一段写得不好，只是它没有落实本次习作“写事例”的要求。

师：这里跟大家补充一点：习作可以写一位家人，也可以写好几位家人。本课我们重点练习写好其中一位，用一件具体事例把他写清楚。如果想写多位家人，请重点详写一位，其他人简单介绍即可，不必每个人都完整写一件大事。

〖PPT 第9页 · 学写法 · 老师给这位爷爷，补上一件事〗

师：那事情要怎么选、怎么写呢？我们一起来学习写作的方法。
大家还记得屏幕上教材里写的那位爷爷吗：“爷爷已经退休了，每天练习书法，一年三百六十五天从不间断。”这句话意思写得很清楚，可读完之后，我们还是想象不出爷爷真实的样子。

师：现在老师给这句话补上一件真实发生的小事，大家听听对比一下。
〔教师示范，把教材的概括语句扩写成事件，朗读给学生〕
去年腊月，爷爷答应给楼下几户人家写春联。那天下午他把八仙桌搬到窗底下，红纸裁成一条一条铺开，砚台压在最边上那张纸角上。写第一副的时候，“福”字最后那一笔他收得很慢，笔尖在纸上顿了一下才提起来。写完一副，他直起腰，捏着红纸的两个角，轻轻放到旁边的椅子上晾着，然后接着写第二副。那天下午他一直写到天黑。

师：听完这段故事，你觉得这是一位怎样的爷爷？
参考：做事很认真／答应别人的事就会坚持做完／一直写到天黑，特别有耐心。

师：大家刚刚说出了这么多感受。老师这段话里，并没有直接写“爷爷很认真、很有耐心”，但是大家却能读出爷爷的品质。

〖PPT 第10页 · 学写法 · 今天这一招——倒过来写〗

师：这就是一个好用的写作思路。平时很多同学习惯先定下人物的特点，再找一件事来证明。今天我们可以换个思路：先回忆一件真实发生的事，把这件事写具体，读文章的人自然就能感受到人物的特点。

师：那两种写法哪种更好呢？其实都可以用。你也可以开头直接点明特点，比如第一句就写“我爷爷很有毅力”，读者一下子就能抓住重点。最好的方式是两者结合：开头直接说出家人的特点，后面用一件具体的事把这个特点支撑起来。大家可以自由选择：可以开头直接点明特点，也可以直接叙述事情，让读者自己体会。

师：这里提醒大家，如果写特点，尽量少用“他很好”“他很能干”这类笼统的话，几乎所有家人都可以套上这些评价，读者很难分清写的到底是谁。当然不是不能写这类句子，只要后面的事例足够具体，同样可以写好。如果能写更贴合这个人的特点，读者一读，就能认出你笔下的家人。

〖PPT 第11页 · 学写法 · 记了这么多事，挑哪一件？〗

师：学会叙事的思路之后，接下来是很关键的一步 —— 挑选要写的事情。
刚刚大家在学习单上记下了三四件甚至更多的小事，我们不需要全部写进作文，要做筛选。老师给大家一个选材的小建议：尽量挑选带有自家独特生活细节、不容易和别的同学撞题材的事。

师：什么叫不容易撞题材？举个例子，很多同学都会写“妈妈每天给我做饭”，不少同学家里都会发生这件事。但是像刚刚爷爷帮邻居写春联这件事，就是他家独有的经历。

师：现在看一看学习单上记录的一件件小事，想一想：哪一件带着我们家独有的细节？先在心里想一想，等会儿我们会填到表格当中。

师：还有一个简单的挑选方法，两个方法任选其一就可以：合上学习单，回忆回忆，哪一件事，你现在脑海里还能浮现当时的画面 —— 他站在哪里、手上拿着什么、说了什么话。脑海里画面越清晰，这件事就越好写，也是你印象最深的事。

（教师总结）今天我们学到两个要点：第一，可以倒过来写，先写他做过的事情，通过事件展现人物的特点；第二，挑选素材，优先选自己印象深刻、脑海里有画面，尽量带有自家专属细节的事例。

### 四、借助素材记录卡，理清写作思路（约 9 分钟）

〖PPT 第12页 · 素材记录卡 · 素材记录卡〗

师：接下来我们一起来看一张素材记录卡。老师以教材里的爷爷为例，已经提前填好了一份示范表格，大家看一看老师是怎样借助表格梳理素材的。
[投屏出示教师填写好的示范表格，暂时不发放空白学习单。]

| 项目             | 我的关键词          |
| -------------- | -------------- |
| 我写家里哪一位        | 爷爷             |
| 想起来的事（几件都行）    | 写春联、教我握笔、早上练字  |
| 挑中的是哪一件        | 写春联            |
| 挑它的理由          | 这件事是我们家独有的经历   |
| 这件事里，他做了什么具体动作 | 搬桌、裁纸、压好红纸、按膝盖 |
| 这件事里，他说了什么话    | 再写两副，人家等着贴     |
| 最后回来填：他是个什么样的人 |                |

师：大家看第二栏，老师一共想到了三件事，最后选了“写春联”这件事。为什么放弃“早上练字”，偏偏选这件呢？
参考：很多老人都会早上练字，写春联这件事只有他家才有。

师：没错，你们看得很仔细。再看第五栏、第六栏，老师写下的“搬桌、裁纸、压好红纸”都是实实在在的动作，没有写夸赞的词语。有了这些动作关键词，我们就能把当时的场景回想起来。
师：最下面这一栏，老师先空着。要等前面所有内容都填完之后，再回过头填写。

〖PPT 第13页 · 素材记录卡 · 轮到你——填自己的素材记录卡〗

师：现在轮到大家自己填写。空白表格就在学习单下半部分。每一栏只需要写三五个关键词，自己看得懂就可以，不用写成完整长句子。只有一处需要注意：家人当时说过的那句话，尽量按照原话记录下来。和示范一样，最后一栏先不要填写。

| 项目             | 我的关键词 |
| -------------- | ----- |
| 我写家里哪一位        |       |
| 想起来的事（几件都行）    |       |
| 挑中的是哪一件        |       |
| 挑它的理由          |       |
| 这件事里，他做了什么具体动作 |       |
| 这件事里，他说了什么话    |       |
| 最后回来填：他是个什么样的人 |       |

学生填写表格（约 4 分钟；教师巡视，重点查看学生有没有选定事例、第五栏填写的是不是具体动作）

【巡视指导要点】
① 如果第二栏只写了一件事，可以轻声问问：“上个星期他在家还做过什么？”启发学生再多想出一件事例；
② 如果第五栏填了“很认真”“很辛苦”这类评价词语，就提醒学生：“这里我们写下他手上正在做的动作就可以”；
③ 如果第四栏挑事理由空着，就把他写下的几件事念一遍，引导思考：“这几件事情当中，哪一件带有我们家独有的小细节？”

〖PPT 第14页 · 素材记录卡 · 说说看——你挑中了哪一件事？〗

师：好，请大家停下笔。我们请三位同学分享一下，你选中了哪一件事，为什么挑选它。
其余同学认真倾听，想一想这件事例是不是带着他家独有的细节。

参考发言示例：
我选爸爸修台灯，一直修到十一点。
我写奶奶找老花镜，找了半天，眼镜其实就戴在她头上。
我打算写妈妈做饭，她每天都会做饭。

师：最后这位同学，“妈妈每天做饭”这件事，班上很多同学的妈妈都会做。你再回忆回忆，妈妈做饭的时候，有没有哪一次和平时不太一样？
参考：有一回停电，她打着手电炒菜；我过生日那天，她天还没亮就起床炖汤。

师：像这样带有特殊小细节的事情，就很适合作为我们的写作素材。

师：现在，大家可以把表格最下方那一栏填上了。看完前面梳理好的整件事，想一想，你想用哪个词语或是简短的句子评价这位家人？

学生填写（约 1 分钟）

（教师总结）我们先挑选事例，记下人物的动作、语言，最后再概括人物的特点。如果你能顺利填好最后一栏，就说明你挑选的这件事例是合适的。

【备课提示：优先建议学生写一位家人。若学生主动要写多位：素材记录卡只需要给重点详写的那一位填写完整；其余家人简略写，不需要单独填素材记录卡。不建议基础薄弱学生选择写多人。】

### 五、出示示范文，梳理写作方法（约 8 分钟）

〖PPT 第15页 · 教师示范文 · 那张表格，变成了完整的片段〗

师：现在大家都填好了素材记录卡。老师的表格也梳理完毕，最后一栏我写下的是“说到做到”。接下来，我就依据这张表格，把素材扩写成完整片段，请大家边看屏幕边听我读，仔细想一想，表格里的关键词是怎样变成作文段落的。

〔材料〕投屏出示完整示范文，教师朗读；课堂分析时要反复回看文本，读完不要关闭页面。

> 【教师示范文】
> 
> 我爷爷是那种说到做到的人，答应别人的事就一定会做好。
> 
> 去年腊月，楼下几户人家托爷爷写春联，他一口应下来。那天下午，他把八仙桌从里屋搬到窗底下，红纸裁成一条一条铺开，砚台压在最边上那张纸角上。爷爷写字的时候不许人说话，我就搬了个小板凳坐在旁边看。
> 
> 写第一副的时候，“福”字最后那一笔他收得很慢，笔尖在纸上顿了一下，才慢慢提起来。写完一副，他就直起腰，捏着红纸的两个角，轻轻放到旁边的椅子上晾着。
> 
> 我在边上数着，一副，两副。屋里静得很，只听见笔尖擦过红纸的沙沙声。写到第三副，他忽然停下笔，把毛笔搁在砚台边上，两只手在膝盖上按了按。我这才看见，他的手在抖。
> 
> 我说：“爷爷，你歇会儿吧，明天再写。”
> 
> 他没抬头，把笔又拿起来，说：“再写两副，人家等着贴。”
> 
> 结果那天下午他一直写到天黑，直到屋里暗下来他才开了灯。只见桌上、椅子上、地上，摊满了晾着的红纸，一共十七副春联。爷爷把手在裤子上擦了擦，说了句：“终于写完了。”
> 
> 我爷爷平时话不多，一年到头就在那张八仙桌上写字。可那天下午我真切感受到，爷爷真是一个说到做到的人。

师：我们先来看看这篇的结构。开头第一句话写的是什么？

参考：说爷爷是一个说到做到的人。

师：没错，开头直接点明人物的特点。这就是我们刚刚讲到的两种写法结合使用：先用一句话概括人物，再用一整件事来印证这个特点。当然大家也可以做另一种选择，如果想让读者自己感受人物，把开头这句话删掉，直接从场景写起，同样可以。

〖PPT 第16页 · 读样稿 · 开头有两种写法——都行〗

师：这里老师把两种开头给大家理一理。
师：第一种：先写特点，再接事件。就像示范文：我爷爷是一个说到做到的人。去年腊月，楼下邻居来找爷爷写春联。 

师：第二种，不直接说出人物特点，一上来就写当时看到的画面。还是写爷爷这件事，就可以这样开头：“去年腊月的一个下午，爷爷把八仙桌搬到窗下，准备帮邻居写春联。” 

师：第二种写法，人物特点不用写在段落开头。大家构思的时候，可以把这个特点记在草稿或者素材记录卡上，等全部写完，再做决定：要么把特点挪到段落开头，要么干脆不用这句话，完全靠事情让读者读懂这个人。

【备课提示：这是构思层面的处理，不需要现在动笔写；等到第二课时动笔写作，我们再来落实。】

〖PPT 第17页 · 读样稿 · 再细读——想两个问题〗

师：那中间这么长一大段，一共写了几件事？
参考：就一件，写爷爷写春联这件事。

师：对，从头到尾就围绕一件事展开。这也告诉大家，我们选好的那一件事，就足够写一大段内容，不用硬凑第二件事情。

师：我们再细读文本，哪处细节能让我们感受到爷爷写春联的时候很吃力？
参考：两只手在膝盖上按了按 / 他的手在抖。

师：大家发现没有，文中并没有直接写“爷爷很累”“爷爷十分辛苦”，只写出了按膝盖、手发抖这些动作。读者读完，自然就能体会到爷爷的辛苦。

师：片段里还有一处很关键，就是爷爷说的那句话，谁找出来了？
参考：“再写两副，人家等着贴。”

师：就是这句话。假如我们改成概括的话：“爷爷说他要坚持写完”，读起来的感觉还一样吗？
参考：不一样，没有原来的味道。

师：所以写习作的时候，要尽量还原人物当时真实说出口的话。大家学习单表格里记下的那句话，写片段的时候，就直接用上。

〖PPT 第18页 · 旁批表 · 每一句，都在做什么〗

师：我们把刚刚找到的关键句子整理出来，大家一起来看一看每句话起到什么样的作用。

| 示范文里的句子                 | 这一句在做什么            |
| ----------------------- | ------------------ |
| 我爷爷是那种说到做到的人            | 开头直接点明人物特点         |
| 把八仙桌从里屋搬到窗底下，红纸裁成一条一条铺开 | 交代事情开端，交代他在干什么     |
| “福”字最后那一笔他收得很慢          | 细致刻画人物的动作，写得慢、写得细  |
| 我这才看见，他的手在抖             | 不说累，靠动作传递感受        |
| “再写两副，人家等着贴。”           | 记录人物当时的原话          |
| 一共十七副                   | 用具体数字，代替模糊的“写了很多” |

师：待会儿大家动笔，不需要把上面这些技巧全部用上。优先做到两点：写清人物做了什么动作，记下他说过的话。把这两点落实好，笔下的家人形象就能立起来。

本课完。

〖PPT 第19页 · 课时分隔 · 当堂写作与评改课〗

## 第2课时 · 当堂写作与评改课

### 一、借助素材记录卡，写下开头片段（约 5 分钟）

〖PPT 第20页 · 写下开头 · 素材记录卡放旁边——先只写开头〗

师：把上节课那张素材记录卡拿出来，放在稿纸旁边。注意，现在我们先不抄表格里的动作和人物对话，这些留到后面写经过的时候再用。

师：先看一看表格最后一栏，就是你填的家人特点。如果你打算把特点放在开头，就空两格，把它扩写成一句简短的话。比如：我爷爷是一个说到做到的人；我妹妹是个爱管事的小孩。写完这一句，先暂停一下。

师：还记得上节课讲的，这句话也不一定非要放在作文开头。还记得两种开头方式吗？想直接写场景、不先点明特点的同学，可以先把特点句抄写在稿纸的最下方备用，等整段写完，再决定把它挪到段落开头，或是直接删掉不用。

学生动笔写特点句（要么写在段落开头，要么抄写在稿纸底部，约 1 分钟）

师：好了，接下来我们来写事情的开篇，只要交代清楚这件事是在什么时间、什么场景下开始的就够了，不用写中间的动作、对话和结果。大家可以想一想：这件事是在哪一个时刻发生的？当时眼前是什么情景？把这个开篇写出来就可以。

师：举个例子，写爷爷，开篇写到：“去年腊月的一个下午，爷爷把八仙桌搬到窗底下。”写到这里就停下，后面写春联、手发抖、说话这些内容，先不要写。

〖PPT 第21页 · 自由写作 · 顺着开头，把整件事写完整〗

师：现在我们只完成了故事的开头部分。接下来的时间交给大家，顺着这个开头继续往下写。写经过的时候，就可以翻看旁边的素材记录卡，把表格里记下的动作、当时说的话，补充到习作当中，把事情后续的经过、结局，还有你当时心里的想法都写进去。遇到不会写的字，可以先空出来或者画小圆圈标记，全部写完之后再来补，千万不要停下来查字典打断思路。

学生动笔写事件开篇（约 2 分钟）

（教师总结）现在我们已经完成作文的开头，要么点明了家人的特点，要么交代好了事情发生的场景，大家顺着往下把整件事写完整就可以。

【备课提示】巡视的时候，如果发现学生过早把素材记录卡的动作、对话全部写出来，轻声提醒：“这部分留到后面写经过，我们现在只要写好开头。”

### 二、自由写作（约 20 分钟）

学生动笔写作（约 20 分钟；教师全程不纠错、不打断，只做正向巡视）

[教师巡视：本环节不指出错别字、不改病句、不纠格式，修改统一留到下一评议修改环节。学生写事件经过的时候，可以翻看手边的素材记录卡，调取之前记下的动作、人物原话等素材。四类学情对应指导语 ——]

[写完开头就停住写不下去的：把他已经写下的那几行念给他听，说“这几行就是开头，你已经写出来了”，再追问：“那件事后来怎么样了，他最后做完没有？”引导学生继续往下写，不要让学生重新改写开头。

【个别帮扶备用话术（对应原先的三个细节问题，只对卡壳学生单独提问，不对全班讲）：回忆一下，当时他手上在做什么？有没有说过什么话？后来又发生了什么？】

[内容空泛，通篇只会写“他很好、他很能干”这类评价的：手指素材记录卡中记录动作的那一栏，提示学生：“表格这里记下了他当时的动作，试着把这一个动作写到作文里”，一次只提示补充一个动作即可。]

[行文流畅、写作推进顺利的：不去打断干扰，路过点头示意，留给学生安静书写的空间即可。]

[只写了三五行就放下笔，说自己已经写完的：先给予肯定：“这件事的大体经过你已经交代清楚了。”再追问一处细节，例如：“他说那句话的时候，人是站着还是坐着？”请学生把这一处细节补充完整。]

〔课堂应答预案·学生提问“可不可以写两个人”〕
可以写多位家人。但要分清详略：把本节课学到的方法，用在其中一位家人身上，给他写一件完整事例；其他家人简单写几句就可以，不用每人都展开完整故事。先写完详写的这一位，再写其他人。

### 三、交流评议，修改收束（约 20 分钟）

〖PPT 第22页 · 交流评议 · 读给同桌听——他只提一个问题〗

师：请大家停下笔。不管习作有没有全部写完，我们一起来交流读一读。

[同桌互念环节（约 6 分钟）：两人一组，轮流朗读自己的习作，每人大约 2 分钟，读完互相提问交流。]

师：先读给你的同桌听。你朗读的时候，同桌只做一件事：听完提出一个自己还想了解的问题。比如“他修台灯修到十一点，那最后修好了没有？”“奶奶找到老花镜的时候说了什么？”
师：被提问的同学当场作答。如果你心里知道答案，但是作文里没有写，就直接把这句话补充到习作上，这往往就是你漏掉的细节。

学生互动分享（同桌两两互念，各完成一轮；教师走到几组旁边倾听。遇到学生不会提问，可以引导启发：“你想不想知道后来发生了什么？”）

师：接下来，请两位同学把片段读给全班同学听。每一位读完，请一位同学按照刚才的方法提一个问题。
学生互动分享（全班 2 名学生朗读，读完各请一名同学提问，作者现场作答，教师针对补充的细节做简要点评；约 5 分钟）

〔应答预案：听众只会评价“写得很好”，提不出问题〕引导学生落到事件上：“那读完这一段，你最想了解哪个地方？做完这件事之后又发生了什么？”

师：刚刚不少同学补充的内容，让片段变得更出彩。很多细节藏在我们脑子里，经过提问，就能把它挖掘出来。

〖PPT 第23页 · 修改收束 · 对照四条，自己改一改〗

师：接下来我们自主修改习作。如果你写了多位家人，重点检查你详写的那一段，对照下面四条看一看。简略写的部分不用套用这几条标准。

| 检查要点       | 自查提示                  |
| ---------- | --------------------- |
| 有没有一件完整的小事 | 写清家人一件真实小事，不简单一笔带过    |
| 有没有写出他的动作和话 | 这件事里有他的动作，也有他说的那句话     |
| 选材是不是自家独有的 | 事例贴合自家生活，有专属小细节       |
| 能不能认出这个人   | 把开头那句话盖住，只读事情也能看出人物特点 |

师：对照四条标准，缺少哪一点就补充修改哪一点。使用修改符号调整文稿，多余的圈掉，遗漏的直接写在行间空白处，不需要整篇重新抄写。

学生动笔修改（约 5 分钟；教师巡视，对照四条标准逐份看）

〔应答预案·学生说“第三条我达不到，这件事很多人家都会发生”〕不用全部推翻重写。试着在这件事中增加一处自家独有的小细节，可以是一句原话，或是一个特别的小动作，就能让内容不一样。

〖PPT 第24页 · 修改收束 · 改完再念一遍——听的人只说“他是个怎样的人”〗

师：修改完成后，再把习作读给同桌听一遍。这一轮同桌不再提问题，听完之后只说：你笔下的这位家人，是一个怎样的人。
师：听完同桌的评价，你可以对照上节课素材记录卡最后一栏填写的人物特点。如果两者大致吻合，就说明你依靠事件，让读者自己读懂了这个人。

学生互动分享（同桌互读修改后的习作，听者说出人物特点，作者对照素材记录卡；约 2 分钟）

〔应答预案·同桌读出的特点，和素材记录卡填写的不一致〕不算写失败。可以问问同桌：“你是从哪句话读出来的？”大多是缺少关键动作或者人物语言，把细节补上之后再读一读。

师：最后布置课后小任务。这篇习作真正的读者，就是文中写到的家人。如果写了好几位家人，就挑详写的那一段读给对应的家人听。回家等他有空的时候读给他听。家人听完，可能会说写得很像，也可能会告诉你哪些地方写漏了。
师：家人给出的评价和同桌的感受往往会不一样，因为这是当事人自己的感受。

本课完。

〖PPT 第25页 · 习作讲评 · 习作讲评环节（可选·课后或下次课开场）〗

## 附：习作讲评指导环节（可选 · 单次课课后用 / 系列课作下次课开场用）

> 本环节供老师灵活取用，不计入两节连排的 45＋45 分钟：既可在单次课后另找时间集中讲评一次，也可作为系列课下一次课的开场（约 15–20 分钟），先讲评上次的习作，再进入新内容。
> 
> 下面凡是 ＿＿＿ 的地方，务必换成本班学生真实写下的句子，不要用别的例子代替。

### 选稿（课前准备）

课后通读全班稿子，挑选三篇范例：一篇优秀、一篇中等、一篇带有典型问题，覆盖不同写作水平，不要三篇都选自写得最好的学生。对照本课写作要点，简单标注每一处的优点与不足：

- 优秀习作：事例贴合自家生活，含有家人的动作与原话。记下最能体现人物特点的句子：＿＿＿（抄写学生原句）。
- 中等习作：事例选取得当，写出了人物动作，缺少人物的原话，或是对话写得不够自然。记下缺失的内容：＿＿＿。
- 典型问题习作：大多是空洞夸赞家人，例如“他很好、他很能干”，事件只简单一笔带过。记下原本可以展开描写的那件事：＿＿＿。

投屏展示文稿时隐去学生姓名，朗读文稿即可；第三篇习作全程不点名。

### 讲评流程（每篇约 3–5 分钟，围绕本课技法点）

师：上节课我们写了自己的家人。今天讲评不刻意挑错，我们重点看一看：有没有把一件真实的小事写出来。

师：先来听第一篇习作。（朗读优秀习作）
师：大家想一想，这篇里面写了家人的哪一件事？
学生互动分享（请两位学生说一说这件事）
师：文中这一处最能让我们感受到家人的特点 ——“＿＿＿”（读出学生写得传神的句子）。大家可以发现，小作者没有直接评价这个人怎么样，而是写下了家人实实在在的行动。这正是我们上节课练习的写作方法。

师：再来听第二篇。（朗读中等习作）

师：这一篇选的事例很不错，也写出了家人的动作。但是还有一处细节可以再丰富一些，大家猜一猜可以补充什么？

参考答案：可以加上家人当时说的话；如果他当时没有说话，也可以加上神态、表情或者心里的样子。

师：没错。（看向习作作者）你还记得当时这位家人有没有说过什么话吗？

师：（学生回忆回答后）如果他当时说了话，你就把这句话补充到 ＿＿＿ 这个位置。要是他并没有开口说话，那就不用硬编对话，可以补上他当时的神情、动作细节。加上这些，这段内容就更丰满了。

师：最后一篇，我们一起来想想修改办法。（朗读典型问题习作，全程不点名）

师：文章里写到 ＿＿＿（读出一笔带过的那件事），只用简短一句话交代完毕。大家想一想，如果要把这件事展开，我们可以增添哪些内容？

学生互动分享（教师追问一句：他当时做了什么？说了哪一句？当时是在哪儿？）

（教师总结）大家说到的这些细节，还原了事情当时发生的经过。简简单单一句话背后，其实可以写出一整段生动的故事。

### 收尾（点回技法、引向今后的写作）

师：今天三篇习作带给我们的启发就是，写人要落脚到具体的小事上。以后再去描写一个人，无论是家人、同学还是生活中遇到的其他人，都可以先不急着给出评价。想一想他做过哪一件小事，把这件事写具体。事情写清楚了，这个人是什么样子，读者自然就能体会出来。

本环节完。

场景原型： 让从没见过他的人读完就认识这位家人（当堂同桌与全班念读，听众提问追问；写完带回家读给被写的那一位听、请他评“像不像”，作课后延伸不设回收承诺——官方评改活动「读给同桌听查不通顺／回家读给家人听请他们评评写得像不像」的连排当堂化）
实体载体： （无·官方评改活动已自含当堂念读与课后带回；写人线已用人物图鉴册／称号卡／朗读会三种载体，本篇不再另套）
热身动作： 限时清点自家一位这个月做过的事（能想起几件写几件、只写事不写评价）＋同桌互说其中一件、听者只回“这件事你什么时候看见的”（清点速记类）
主反馈游戏： 追问补写（听完不评好坏，只提一个“还想知道的事”，作者当场答；答得出而纸上没写的立即补进去——把反馈直接变成修改动力，官方“读给同桌听”的当堂化落地）
第二层反馈： 改完之后同桌对表（自改完成后再跟同桌互念一轮，听的人不提问题、只说一句“你写的这位是个什么样的人”，作者翻回素材记录卡最后一格自己填的那个词对照——对得上即“我没告诉他、他自己看出来了”；这一轮同时承担 L4「这样改好在哪」的回收，非互挑、非画记号）
开场钩子： 素材追问式·好奇者（先请学生从教材那五段介绍里挑一位“最想认识的”并说理由，学生答完老师承认自己挑的也是那位会讲故事的爸爸，随即追问“他怎么个会讲法”——学生答不上来，缺口由学生自己撞见而非老师宣布）
主技法： 先想起一件他真做过的事、再从这件事里看出他是个什么样的人（方向倒过来，不先下结论）；一堆事里挑印象最深、别人家写不出的那一件（辅：事里要有他的动作和他说的那一句原话，属三下旧知只作快速唤起、不重教）
审题辨析形态： 两段对照判断（同写自己家：一段四口人各写两三句、门框吊车短发小辫子样样有画面却一件事也没有／一段只写妹妹一位、讲拿橡皮那一件完整的事；判据落在“题目要的事例有没有”而非写得细不细，预期有学生选反例，师话先承认反例“不糙、每人身上都有看得见的东西”再回题目要求）
技法引出装置： 给教材那位爷爷添一件事（承接开场投屏的教材原句“每天练习书法、一年三百六十五天从不间断”，老师当场把这句结论写成一件事的单点示范念给学生听，段里不给任何结论词，由学生自己说出这位爷爷是个什么样的人，由此点破方向倒过来；单点示范刻意收在“写到天黑”，把“手在抖”与那句原话整个留给 ④ 示范文去发现，不剧透；随即三步对比交回选择权——原句没写错、两种搭着用、并划开“很好／很能干”这类谁都套得上的话；再让学生回自己学习单上清点的几件事逐件过“别人家有没有”）
示范文题材： 虚构小作者的第一人称日常家庭（教材气泡里那位练书法的爷爷·腊月写春联写到手抖、十七副；素材源自教材页原句而非自造，与四上《小小“动物园”》同题材域但那篇是家庭群像三人分写、本篇是单人单事，且不取授课老师家人）
互动组织： ②同桌两两互说（回问两条）＋举手抽说报条数／③举手判断＋由选反例的学生自述其长处＋举手抽说／④举手抽说（回文指认句子，四轮）／⑤看教师填好的表口头答挑事理由＋举手抽说三位说自己的挑事理由＋全班听众任务／⑦同桌两两互念提问补写＋全班两位念、听众各提一问＋自改后同桌再互念一轮对表
话轮骨架： ③两段对照→让选反例的学生自己说它好在哪→回到题目数“有几件事”→补一句“写几个人也行但各有各的事”→教师给教材原句添事的单点示范（不含结论词）→学生说出这是个什么样的人→教师命名（倒过来写）→三步对比交回选择权→划开万能评价与具体特点→学生回自己单子上逐件过挑事判据｜④先问开头写了什么→再问中间几件事→问哪一句看出吃力→反问“有没有写累”→问他说的哪一句→换句试验→并排旁批表｜⑦同桌互念提问补写→全班两位念＋听众各提一问→对照四条自改→改后同桌再互念一轮由听者说出“是个什么样的人”、作者对表→收尾交课后（⑤ 亦已换串：先出示教师填好的表并口头答挑事理由→再发空表让学生填，与基准篇「先说必要性→发表→教师示范填」相反）
