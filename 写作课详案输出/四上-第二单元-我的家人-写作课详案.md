# 《我的家人》· 写作课教学设计

四年级上册·第二单元 校内同步写作（写人习作）

[授课提示：本课第三至第五环节示范用到的爷爷形象，来自教材习作页给出的示例，是文本里的人物，并非教师本人的家人。课堂上直接依托教材内容来讲就可以，不要替换成自己家里的亲人。
如果教师拿自家家人举例示范，不少学生会模仿老师的素材思路，局限写作，不利于学生写自己真实熟悉的家人。]

## 教案提纲表

| 课题·课时  | 四上·第二单元《我的家人》　│　写人·校内同步　│　2课时连排（每节45分钟）                                                                                              |
| ------ | ------------------------------------------------------------------------------------------------------------------------------------ |
| 能力阶段   | 写清楚 → 写具体（本课） → 写生动 → 写深刻·有章法                                                                                                        |

| 学习目标 | 通过记叙一件自家真实发生的小事，学习写出一位家人的特点。 |

## 第1课时 · 写作指导课

### 一、创设情境，明确任务（约6分钟）

〖PPT 第3页 · 创设情境 · 教材中的五位家人，你最想认识哪一位？〗

师：我们先来读几段话。这几段话是教材中给出的例子，写的都是自己的家人，一人一段，篇幅都很短。

〔材料〕投屏出示教材习作页上的5段话（我奶奶脾气特别好，总是笑眯眯的。她还特别会做好吃的，我最喜欢吃奶奶做的饭；我爸爸是卡车司机，他很忙，一年到头很少在家。他很会讲故事，一有空就讲给我和弟弟听；我姥爷已经退休了，他每天练习书法，一年三百六十五天从不间断，非常有毅力；我妈妈酷爱运动。跑步、跳绳、打羽毛球……她对各种运动都充满了热情，还经常带我和妹妹一起锻炼身体；我妹妹今年四岁。她很淘气，也很聪明）。

师：这五位家人中，如果请你选一位来认识，你最想认识哪一位？请说一说理由。

学生互动分享

参考：会讲故事的爸爸／练书法的姥爷，一年三百六十五天不间断，很了不起／四岁的妹妹，又淘气又聪明。

〖PPT 第4页 · 创设情境 · 这位爸爸是怎样讲故事的？〗

师：老师和不少同学的选择一样，最想认识这位会讲故事的爸爸。可是这句话我读了两遍，仍然看不出他是怎样讲故事的。

师：请大家说一说，他是怎样讲故事的？

参考：没有写／不知道／书上没有说。

师：是的，这句话没有告诉我们。它只写了爸爸一有空就讲故事，至于他是怎样讲的、讲故事时是什么样子，一个字也没有写。所以读完这句话，我们仍然不认识他。

〖PPT 第5页 · 创设情境 · 这两节课的任务：写一篇让人“认识”他的作文〗

师：今天这两节课，我们就来写这样一篇作文：每人选一位家人来写，写完之后请从未见过他的人读一读，读完就像认识了他一样。

师：写好之后，我们的习作会有两位读者。第一位是你的同桌，他并不认识你的家人，读完要能说出他感受到的这位家人是怎样的人。第二位更重要，就是你所写的这位家人：把习作带回家读给他听，看他是否觉得你写的就是真实的他。

师：这两节课，我们重点完成这篇习作，也就是本单元的习作《我的家人》。

### 二、回忆家人小事，搜集写作素材（约10分钟）

〖PPT 第6页 · 回忆家人小事 · 先不想特点，想一想他做过哪些事〗

师：动笔之前，我们先来搜集写作素材。老师暂时不问这位家人有什么性格特点，请大家先回忆：他最近做过哪些事情。

师：接下来，老师给每位同学发一张空白小纸条。请你想一想家中的一位亲人，把他最近一段时间做过的事，或者给你留下深刻印象的事简单记下来，想到几件就记几件。不必写成完整的句子，用三五个关键词记录事件即可，自己能看懂就好。暂时不做挑选，想到什么就记什么。

〔发放空白小纸条；教师提示：只记录发生的事情，不写评价。例如记录“修自行车”“夜里起来关窗户”这类事实，不写“他很能干”这类评价性语句。〕

学生动笔记录（约2分钟；教师巡视，查看学生记录的事件数量。若学生只写出一件，可轻声追问：“上个星期天，他在家做了些什么？”帮助学生打开思路）

师：请大家停笔。谁来说一说，你一共记下了几件事？

学生互动分享（请3至4名学生发言，先说数量，再简要说其中一两件事）
参考：三件／五件／我记了两件，一件是爸爸修台灯，一件是爸爸送我上学。

师：不少同学很快就想出了三四件事。我们天天和家人生活在一起，他们做过的许多事，我们都看在眼里。

〖PPT 第7页 · 清点小事 · 挑一件，说给同桌听〗

师：接下来，请你选其中一件事说给同桌听。只讲发生了什么，不作评价。同桌听完不必点评好坏，只问两个问题：第一，这件事你是什么时候看到的？第二，当时他说了什么话？

学生互动分享（同桌轮流讲述；教师深入几个小组倾听）

〔课堂应答预案：若学生只能说出一个词语，讲不出事情经过，不要问“他是个怎样的人”，而应换成具体问题引导：“那时候他在什么地方？手里拿着什么？”学生答出一点，就鼓励他继续往下讲。〕

师：刚才老师听到一位同学讲，爸爸修台灯一直忙到十一点。这位同学没有说爸爸有多辛苦，可是听完这件事，我们自然就感受到了爸爸的辛苦。这正是本节课要学习的写作方法，接下来我们一起来研究。

### 三、学写法：借助一件事，写出家人特点（约12分钟）

〖PPT 第8页 · 判断对比 · 这两段话，哪一段更符合这次习作的要求？〗

师：我们先来明确本次习作要写什么。老师写了两段文字，都是介绍家人的。请同学们看着屏幕听老师读，听完想一想，哪一段更符合本次习作的要求。

〔材料〕投屏出示两段文字，教师朗读；后续判断、梳理事例环节需回看这两段，读完暂不关闭页面。

师：第一段：“我家有四口人。爸爸个子很高，站在门口能碰到门框上沿，他在工地上开吊车，早出晚归。妈妈头发短短的，说话嗓门大，她做的红烧肉是全家最爱吃的一道菜。妹妹今年五岁，扎两个小辫子，一天到晚在屋里跑来跑去。还有我，我是四年级的学生。我们一家人过得很热闹。”

师：第二段：“我家妹妹五岁。上个星期天早上我在写作业，她搬了张小板凳坐到我旁边，把下巴搁在桌沿上看我写。看了一会儿，她伸手把我的橡皮拿走了，说：‘哥哥你写错了我帮你擦。’我说我没写错。她想了想，又把橡皮放回来，小声说：‘那你写错了再叫我。’然后一直坐在那儿等着，等到我写完。”

师：请大家说一说，哪一段更符合习作要求？
参考：第二段。／我选第一段，第一段把家里四个人都写出来了。

师：选第一段的同学，请说一说第一段好在哪里。
参考：四个人都写到了／写到了门框、吊车，还有小辫子／内容很丰富。

师：大家观察到的这些内容，第一段确实都写到了。我们回到习作要求来看：教材要求结合具体事例写出家人的特点。什么是事例？就是实实在在发生过的一件事。请大家数一数，第一段完整地写了哪一件事？
参考：没有／一件也没有。

师：是的，一件完整的事例都没有。第一段虽然介绍了四个人，写了外貌和工作，却没有写谁具体做了什么事。再看第二段，只写了妹妹一个人，却完整记录了拿橡皮这件小事。这并不是说第一段写得不好，只是它没有落实本次习作“写事例”的要求。

师：需要说明的是，这次习作可以写一位家人，也可以写几位家人。本课重点练习写好其中一位，用一件具体事例把他写清楚。如果想写多位家人，就重点详写一位，其余简要介绍即可，不必每个人都完整写一件事。

〖PPT 第9页 · 学写法 · 老师给这位姥爷补上一件事〗

师：事情该怎么选、怎么写呢？我们一起来学习。
师：大家还记得教材中写的那位姥爷吗？“姥爷已经退休了，每天练习书法，一年三百六十五天从不间断。”这句话意思很清楚，可是读完之后，我们仍然想象不出姥爷真实的样子。

师：现在老师为这句话补上一件真实发生的小事，请大家听一听，比较一下。
〔教师示范：将教材中的概括性语句扩写为具体事件，朗读给学生听〕
去年腊月，姥爷答应给楼下几户人家写春联。那天下午他把八仙桌搬到窗底下，红纸裁成一条一条铺开，砚台压在最边上那张纸角上。写第一副的时候，“福”字最后那一笔他收得很慢，笔尖在纸上顿了一下才提起来。写完一副，他直起腰，捏着红纸的两个角，轻轻放到旁边的椅子上晾着，然后接着写第二副。那天下午他一直写到天黑。

师：听完这段话，你觉得这是一位怎样的姥爷？
参考：做事很认真／答应别人的事就会坚持做完／一直写到天黑，特别有耐心。

师：大家说出了这么多感受。老师的这段话并没有直接写“姥爷很认真、很有耐心”，大家却能从中读出姥爷的品质。

〖PPT 第10页 · 学写法 · 今天学习的思路：倒过来写〗

师：这是一种很实用的写作思路。平时很多同学习惯先确定人物的特点，再找一件事来证明。今天我们换一种思路：先回忆一件真实发生的事，把这件事写具体，读者自然就能感受到人物的特点。

师：两种写法哪一种更好呢？其实都可以。你也可以在开头直接点明特点，比如第一句就写“我姥爷很有毅力”，读者一读就能抓住重点，后面再用一件具体的事支撑这个特点。两种写法大家自由选择：可以开头点明特点，也可以直接叙述事情，让读者自己体会。

师：提醒大家，如果要写特点，尽量少用“他很好”“他很能干”这类笼统的评价。这些评价几乎适用于所有家人，读者很难分辨写的究竟是谁。当然，这类句子并非不能写，只要后面的事例足够具体，同样可以写好。如果特点写得更贴合这个人，读者一读就能认出你笔下的家人。

〖PPT 第11页 · 学写法 · 记了这么多事，挑哪一件？〗

师：明确了叙事的思路，接下来是很关键的一步：挑选要写的事情。
师：刚才大家在小纸条上记下了三四件甚至更多的小事，这些事不需要全部写进作文，要有所筛选。老师给大家一条选材建议：尽量挑选带有自家独特生活细节、不容易与其他同学重复的事。

师：什么叫不容易重复？例如，很多同学都会写“妈妈每天给我做饭”，这件事在不少同学家里都会发生。而像姥爷帮邻居写春联这件事，就是他家独有的经历。

师：现在请看一看小纸条上记录的这些小事，想一想：哪一件带有自家独有的细节？先在心里想好，稍后我们会填入表格。

师：还有一个简单的挑选方法，两种方法任选其一即可：合上小纸条，回忆一下，哪一件事你现在还能在脑海中浮现当时的画面：他站在哪里、手里拿着什么、说了什么话。画面越清晰，这件事就越好写，它也往往是你印象最深的事。

（教师总结）今天我们学习了两个要点：第一，可以倒过来写，先写他做过的事，通过事件展现人物的特点；第二，挑选素材时，优先选自己印象深刻、脑海中有画面、带有自家独有细节的事例。

### 四、借助素材记录卡，理清写作思路（约9分钟）

〖PPT 第12页 · 素材记录卡 · 老师的示范表格〗

师：接下来我们一起来看一张素材记录卡。老师以教材中的姥爷为例，提前填好了一份示范表格，请大家看一看老师是怎样借助表格梳理素材的。
〔投屏出示教师填好的示范表格，暂不要求学生填写自己的表格。〕

| 项目             | 我的关键词          |
| -------------- | -------------- |
| 我写家里哪一位 | 姥爷 |
| 想起来的事（几件都可以） | 写春联、教我握笔、早上练字 |
| 挑中的是哪一件        | 写春联            |
| 挑它的理由          | 这件事是我们家独有的经历   |
| 这件事里，他做了什么具体动作 | 搬桌、裁纸、压好红纸、按膝盖 |
| 这件事里，他说了什么话    | 再写两副，人家等着贴     |
| 最后回来填：他是个什么样的人 |                |

师：请看第二栏，老师一共想到了三件事，最后选了“写春联”。为什么不选“早上练字”，而选这一件呢？
参考：很多老人都会早上练字，写春联这件事是他家独有的。

师：是的。再看第五栏、第六栏，老师写下的“搬桌、裁纸、压好红纸”都是实实在在的动作，没有一个夸赞的词语。有了这些动作关键词，就能把当时的场景回想起来。
师：最后一栏，老师先空着，等前面各栏都填完之后再回头填写。

〖PPT 第13页 · 素材记录卡 · 轮到大家，填自己的素材记录卡〗

师：现在请大家填写自己的素材记录卡，空白表格就在小纸条的下半部分。每一栏只需写三五个关键词，自己看得懂即可，不必写成完整的长句。只有一处需要注意：家人当时说的那句话，尽量按原话记录。和示范一样，最后一栏先不填。

| 项目             | 我的关键词 |
| -------------- | ----- |
| 我写家里哪一位        |       |
| 想起来的事（几件都可以） |  |
| 挑中的是哪一件        |       |
| 挑它的理由          |       |
| 这件事里，他做了什么具体动作 |       |
| 这件事里，他说了什么话    |       |
| 最后回来填：他是个什么样的人 |       |

学生填写表格（约4分钟；教师巡视，重点查看学生是否选定事例、第五栏填写的是否为具体动作）

【巡视指导要点】
① 若第二栏只写了一件事，可轻声询问：“上个星期他在家还做过什么？”启发学生再想出一件事例；
② 若第五栏填了“很认真”“很辛苦”这类评价性词语，提醒学生：“这一栏只写他当时手上正在做的动作”；
③ 若第四栏的选材理由空着，就把学生写下的几件事读一遍，引导思考：“这几件事当中，哪一件带有你家独有的小细节？”

〖PPT 第14页 · 素材记录卡 · 说一说：你挑中了哪一件事？〗

师：请大家停笔。我们请三位同学分享：你选定了哪一件事，为什么选它。
其余同学认真倾听，想一想这件事例是否带有他家独有的细节。

参考：
我选爸爸修台灯，一直修到十一点。
我写奶奶找老花镜，找了半天，眼镜其实就戴在她头上。
我打算写妈妈做饭，她每天都会做饭。

师：最后这位同学写的“妈妈每天做饭”，班上很多同学的妈妈都会做。请你再回忆一下，妈妈做饭的时候，有没有哪一次和平时不一样？
参考：有一回停电，她打着手电炒菜；我过生日那天，她天还没亮就起床炖汤。

师：像这样带有特别细节的事情，就很适合作为写作素材。

师：现在，大家可以填写表格的最后一栏了。回看前面梳理好的整件事，想一想：你想用哪个词语或哪句简短的话来评价这位家人？

学生填写（约1分钟）

（教师总结）我们先挑选事例，记下人物的动作和语言，最后再概括人物的特点。如果最后一栏能顺利填好，就说明你选的这件事例是合适的。

【备课提示：优先建议学生写一位家人。若学生主动提出写多位：素材记录卡只需为重点详写的那一位填写完整；其余家人简略带过，不必单独填写素材记录卡。不建议基础薄弱的学生写多位家人。】

### 五、出示示范文，梳理写作方法（约8分钟）

〖PPT 第15页 · 教师示范文 · 看一看：表格怎样变成完整片段〗

师：现在大家都填好了素材记录卡。老师的表格也梳理完毕，最后一栏填的是“说到做到”。接下来，老师依据这张表格，把素材扩写成完整的片段。请大家边看屏幕边听老师读，想一想表格里的关键词是怎样变成作文段落的。

〔材料〕投屏出示完整示范文，教师朗读；后续分析需反复回看文本，读完暂不关闭页面。

> 【教师示范文】
> 
> 我姥爷是那种说到做到的人，答应别人的事就一定会做好。
> 
> 去年腊月，楼下几户人家托姥爷写春联，他一口应下来。那天下午，他把八仙桌从里屋搬到窗底下，红纸裁成一条一条铺开，砚台压在最边上那张纸角上。姥爷写字的时候不许人说话，我就搬了个小板凳坐在旁边看。
> 
> 写第一副的时候，“福”字最后那一笔他收得很慢，笔尖在纸上顿了一下，才慢慢提起来。写完一副，他就直起腰，捏着红纸的两个角，轻轻放到旁边的椅子上晾着。
> 
> 我在边上数着，一副，两副。屋里静得很，只听见笔尖擦过红纸的沙沙声。写到第三副，他忽然停下笔，把毛笔搁在砚台边上，两只手在膝盖上按了按。我这才看见，他的手在抖。
> 
> 我说：“姥爷，你歇会儿吧，明天再写。”
> 
> 他没抬头，把笔又拿起来，说：“再写两副，人家等着贴。”
> 
> 结果那天下午他一直写到天黑，直到屋里暗下来他才开了灯。只见桌上、椅子上、地上，摊满了晾着的红纸，一共十七副春联。姥爷把手在裤子上擦了擦，说了句：“终于写完了。”
> 
> 我姥爷平时话不多，一年到头就在那张八仙桌上写字。可那天下午我真切感受到，姥爷真是一个说到做到的人。

师：我们先来看这个片段的结构。开头第一句写的是什么？

参考：说姥爷是一个说到做到的人。

师：是的，开头直接点明人物的特点。这就是刚才讲到的另一种写法：先用一句话概括人物，再用一整件事印证这个特点。当然，大家也可以另作选择：如果想让读者自己感受人物，就删去开头这句话，直接从场景写起。

〖PPT 第16页 · 读样稿 · 开头有两种写法，都可以〗

师：老师把两种开头方式梳理一下。
师：第一种，先写特点，再接事件。例如示范文的开头：我姥爷是一个说到做到的人。去年腊月，楼下邻居来找姥爷写春联。

师：第二种，不直接说出人物特点，开篇就写当时看到的画面。同样写姥爷这件事，可以这样开头：“去年腊月的一个下午，姥爷把八仙桌搬到窗下，准备帮邻居写春联。”

师：第二种写法，人物的特点不必写在段落开头。构思时，可以先把这个特点记在小纸条或素材记录卡上，等全部写完再作决定：可以把特点句移到段落开头，也可以不用这句话，完全靠事情让读者读懂这个人。

师：挑选事例时，尽量抓住家人与众不同的特点，优先选印象最深、脑海中能浮现画面的事情。

【备课提示：此处是构思层面的处理，不需要现在动笔；第二课时动笔写作时再落实。】

〖PPT 第17页 · 读样稿 · 再细读：想两个问题〗

师：中间这一大段，一共写了几件事？
参考：只有一件，姥爷写春联。

师：是的，从头到尾只围绕一件事展开。这也说明，我们选出的这一件事，足够写成一大段，不必勉强再写第二件。

师：我们再细读文本：哪一处细节能让我们感受到姥爷写春联时很吃力？
参考：两只手在膝盖上按了按／他的手在抖。

师：请大家注意，文中并没有直接写“姥爷很累”“姥爷十分辛苦”，只写了按膝盖、手发抖这些动作。读者读完，自然就能体会到姥爷的辛苦。

师：片段中还有一处很关键，就是姥爷说的那句话。谁找到了？
参考：“再写两副，人家等着贴。”

师：就是这句话。假如改成概括性的表述：“姥爷说他要坚持写完”，读起来的感觉还一样吗？
参考：不一样，没有原话那么有味道。

师：所以写作文时，要尽量还原家人当时说的原话。大家在素材记录卡中记下的那句话，写片段时直接用上。

〖PPT 第18页 · 旁批表 · 每一句，都在做什么〗

师：我们把刚才找到的关键句整理出来，一起看一看每句话起到了什么作用。

| 示范文里的句子                 | 这一句在做什么            |
| ----------------------- | ------------------ |
| 我姥爷是那种说到做到的人 | 开头直接点明人物特点 |
| 把八仙桌从里屋搬到窗底下，红纸裁成一条一条铺开 | 交代事情开端，写他在做什么 |
| “福”字最后那一笔他收得很慢 | 细致刻画动作，写得慢、写得细 |
| 我这才看见，他的手在抖             | 不说累，靠动作传递感受        |
| “再写两副，人家等着贴。”           | 记录人物当时的原话          |
| 一共十七副                   | 用具体数字，代替模糊的“写了很多” |

师：下节课动笔时，不必把这些方法全部用上，优先做到两点：写清人物做了什么动作，记下他说过的话。这两点落实好，笔下的家人形象就能立起来。

第1课时完。

〖PPT 第19页 · 课时分隔 · 当堂写作与评改课〗

## 第2课时 · 当堂写作与评改课

### 一、借助素材记录卡，写下开头片段（约5分钟）

〖PPT 第20页 · 写下开头 · 素材记录卡放在旁边，先只写开头〗

师：请把上节课的素材记录卡拿出来，放在稿纸旁边。注意，现在先不抄写表格里的动作和人物语言，这些留到写事情经过时再用。

师：先看表格的最后一栏，也就是你填的家人特点。如果打算把特点放在开头，就空两格，把它扩写成一句简短的话。例如：我姥爷是一个说到做到的人；我妹妹是个爱管事的小孩。写完这一句，先停笔。

师：上节课讲过，这句话不一定要放在作文开头。还记得两种开头方式吗？想直接写场景、不先点明特点的同学，可以先把特点句写在稿纸最下方备用，等整段写完，再决定是移到段落开头，还是删去不用。

学生动笔写特点句（写在段落开头或稿纸底部，约1分钟）

师：接下来写事情的开篇，只需交代清楚这件事在什么时间、什么场景下开始，不写中间的动作、对话和结果。大家可以想一想：这件事是在哪一个时刻发生的？当时眼前是什么情景？把这个开篇写出来即可。

师：例如写姥爷，开篇可以写：“去年腊月的一个下午，姥爷把八仙桌搬到窗底下。”写到这里就停下，后面写春联、手发抖、说话这些内容，先不要写。

〖PPT 第21-22页 · 自由写作 · 顺着开头，把整件事写完整〗

师：现在我们只完成了事情的开头。接下来的时间交给大家，顺着这个开头继续往下写。写经过时，可以查看旁边的素材记录卡，把表格里记下的动作、当时说的话、他的神态等补充到作文中，把事情后续的经过、结局，以及你当时的想法都写进去。遇到不会写的字，可以先空着或画小圆圈标记，全部写完之后再补，不要停下来查字典而打断思路。

学生动笔写事件开篇（约2分钟）

（教师总结）现在我们已经完成了作文的开头：或者点明了家人的特点，或者交代了事情发生的场景。接下来，大家顺着开头把整件事写完整即可。

【备课提示】巡视时，若发现学生过早地把素材记录卡上的动作、对话全部写出来，轻声提醒：“这部分留到后面写经过时再用，现在只写好开头。”

### 二、自由写作（约20分钟）

学生动笔写作（约20分钟；教师全程不纠错、不打断，只做正向巡视）

〔教师巡视：本环节不指出错别字、不改病句、不纠格式，修改统一留到评议修改环节。学生写事情经过时，可查看手边的素材记录卡，调用先前记下的动作、人物原话等素材。四类学情对应的指导语如下：〕

〔写完开头就停住、写不下去的：把他已经写下的几行读给他听，告诉他“这几行就是开头，你已经写出来了”，再追问：“那件事后来怎么样了？他最后做完了吗？”引导学生继续往下写，不要让学生重新改写开头。〕

【个别帮扶备用话术（只对写不下去的学生单独提问，不面向全班）：回忆一下，当时他手上在做什么？有没有说过什么话？后来又发生了什么？】

〔内容空泛、通篇只写“他很好”“他很能干”这类评价的：指着素材记录卡中记录动作的那一栏，提示学生：“表格里记下了他当时的动作，试着把这个动作写进作文”，一次只提示补充一个动作。〕

〔行文流畅、写作顺利的：不打断、不干扰，经过时点头示意，留给学生安静书写的空间。〕

〔只写了三五行就放下笔、说自己已经写完的：先予以肯定：“这件事的大体经过你已经交代清楚了。”再追问一处细节，例如：“他说那句话的时候，是站着还是坐着？”请学生把这一处细节补充完整。〕

〔课堂应答预案：学生提问“可不可以写两个人”〕
可以写多位家人，但要分清详略：把本课学到的方法用在其中一位家人身上，为他写一件完整的事例；其他家人简单写几句即可，不必每人都展开完整的事。先写完详写的这一位，再写其他人。

### 三、交流评议，修改收束（约20分钟）

〖PPT 第23页 · 交流评议 · 读给同桌听：他只提一个问题〗

师：请大家停笔。无论习作是否全部写完，我们一起来交流。

〔同桌互读（约6分钟）：两人一组，轮流朗读自己的习作，每人约2分钟，读完互相提问交流。〕

师：先读给同桌听。你朗读时，同桌只做一件事：听完提出一个自己还想了解的问题。例如“他修台灯修到十一点，最后修好了吗？”“奶奶找到老花镜的时候说了什么？”
师：被提问的同学当场作答。如果你知道答案，作文里却没有写，就直接把这句话补进习作，这往往就是你漏掉的细节。

学生互动分享（同桌互读，各完成一轮；教师到几个小组旁倾听。若学生不会提问，可引导：“你想不想知道后来发生了什么？”）

师：接下来，请两位同学把片段读给全班听。每位读完，请一位同学按刚才的方法提一个问题。
学生互动分享（2名学生面向全班朗读，读完各请一名同学提问，作者当场作答，教师就补充的细节作简要点评；约5分钟）

〔应答预案：听者只会评价“写得很好”，提不出问题〕引导学生落到事件上：“读完这一段，你最想了解哪个地方？做完这件事之后又发生了什么？”

师：刚才不少同学补充的内容，让片段更加生动了。很多细节藏在我们的脑海中，经过提问，就能被挖掘出来。

〖PPT 第24页 · 修改收束 · 对照四条，自己改一改〗

师：接下来自主修改习作。如果写了多位家人，重点检查详写的那一段，对照下面四条检查要点逐一检查。简略写的部分不必套用这几条标准。

| 检查要点       | 自查提示                  |
| ---------- | --------------------- |
| 有没有一件完整的小事 | 写清家人的一件真实小事，不是一笔带过 |
| 有没有写出他的样子 | 这件事里有他的动作，也有他说的那句话 |
| 选材是不是自家独有的 | 事例贴合自家生活，有自家独有的小细节 |
| 能不能认出这个人   | 把开头那句话盖住，只读事情也能看出人物特点 |

师：对照四条标准，缺少哪一点就补充修改哪一点。用修改符号在原稿上修改：多余的圈掉，遗漏的写在行间空白处，不必整篇重抄。

学生动笔修改（约5分钟；教师巡视，结合四条标准作个别指导）

〔应答预案：学生说“第三条我达不到，这件事很多人家都会发生”〕不必推翻重写。试着在这件事中增加一处自家独有的小细节，可以是一句原话，也可以是一个特别的小动作，就能与其他同学的习作区分开。

〖PPT 第25页 · 修改收束 · 改完再读一遍：听的人只说“他是个怎样的人”〗

师：修改完成后，再把习作读给同桌听一遍。这一轮同桌不再提问，听完只说一句：你笔下的这位家人是一个怎样的人。
师：听完同桌的评价，对照上节课素材记录卡最后一栏填写的人物特点。如果两者大致吻合，就说明你依靠事件让读者读懂了这个人。

学生互动分享（同桌互读修改后的习作，听者说出人物特点，作者对照素材记录卡；约2分钟）

〔应答预案：同桌读出的特点与素材记录卡填写的不一致〕这不算失败。可以询问同桌：“你是从哪句话读出来的？”多数情况是缺少关键动作或人物语言，把细节补上之后再读一读。

师：最后布置一个课后小任务。这篇习作真正的读者，就是文中写到的家人。回家后，等他有空时读给他听；如果写了几位家人，就把详写的那一段读给相应的家人听。家人听完，可能会说写得很像，也可能会告诉你哪些地方写漏了。
师：家人的评价和同桌的感受可能不一样，因为家人是当事人，有切身的感受，反馈不同是正常的。

第2课时完。

全课完。

〖PPT 第25页 · 习作讲评 · 习作讲评环节（可选·课后或下次课开场）〗

## 附：习作讲评指导环节（可选 · 单次课课后用／系列课作下次课开场用）

> 本环节供教师灵活取用，不计入两节连排的45＋45分钟：既可在单次课后另行安排时间集中讲评，也可作为系列课下一次课的开场（约15–20分钟），先讲评上次的习作，再进入新内容。
> 
> 下文凡标有＿＿＿之处，务必替换为本班学生真实写下的句子，不得用其他例子代替。

### 选稿（课前准备）

课后通读全班习作，选出三篇样例：一篇优秀、一篇中等、一篇存在典型问题，覆盖不同写作水平，不要都选自写得最好的学生。对照本课写作要点，简要标注各篇的优点与不足：

- 优秀习作：事例贴合自家生活，含有家人的动作与原话。记下最能体现人物特点的句子：＿＿＿（抄写学生原句）。
- 中等习作：事例选取得当，写出了人物动作，但缺少人物原话，或对话写得不够自然。记下缺失的内容：＿＿＿。
- 典型问题习作：多为空洞地夸赞家人，如“他很好”“他很能干”，事件只一笔带过。记下本可展开描写的那件事：＿＿＿。

投屏展示时隐去学生姓名，朗读即可；第三篇习作全程不点名。

### 讲评流程（每篇约3–5分钟，围绕本课技法点）

师：上节课我们写了自己的家人。今天讲评不刻意挑错，重点看一看：有没有把一件真实的小事写出来。请大家记住，挑选事例要抓住家人与众不同的特点，选印象最深的小事写具体。

师：先来听第一篇习作。（朗读优秀习作）
师：请大家想一想，这篇习作写了家人的哪一件事？
学生互动分享（请两位学生说一说这件事）
师：文中这一处最能让我们感受到家人的特点：“＿＿＿”（读出学生写得传神的句子）。大家可以发现，小作者没有直接评价这个人怎么样，而是写下了家人实实在在的行动。这正是我们上节课练习的写作方法。

师：再来听第二篇。（朗读中等习作）

师：这一篇选的事例很好，也写出了家人的动作，但还有一处细节可以更丰富。大家想一想，可以补充什么？

参考：可以加上家人当时说的话；如果他当时没有说话，也可以加上神态、表情或心理活动。

师：是的。（面向习作作者）你还记得当时这位家人有没有说过什么话吗？

师：（学生回答后）如果他当时说了话，就把这句话补在＿＿＿这个位置。如果他没有开口，就不必编造对话，可以补上他当时的神情、动作等细节。加上这些，这一段就更丰满了。

师：最后一篇，我们一起来想一想修改办法。（朗读典型问题习作，全程不点名）

师：文中写到＿＿＿（读出一笔带过的那件事），只用一句话就交代完了。大家想一想，如果要把这件事展开，可以增添哪些内容？

学生互动分享（引导学生想到：补充人物动作、人物说过的话、事情发生时的场景）

（教师总结）大家说到的这些细节，还原了事情当时的经过。简单的一句话背后，其实可以写出一整段生动的内容。

### 收尾（点回技法、引向今后的写作）

师：今天三篇习作给我们的启发是：写人要落到具体的小事上。以后描写一个人，无论是家人、同学还是生活中遇到的其他人，都可以先不急于评价，先想一想他做过哪一件小事，把这件事写具体。事情写清楚了，这个人是什么样子，读者自然就能体会到。

本环节完。

主反馈游戏： 追问补写（听完不评好坏，只提一个“还想知道的事”，作者当场答；答得出而纸上没写的立即补进去——把反馈直接变成修改动力，官方“读给同桌听”的当堂化落地）
第二层反馈： 改完之后同桌对表（自改完成后再跟同桌互念一轮，听的人不提问题、只说一句“你写的这位是个什么样的人”，作者翻回素材记录卡最后一格自己填的那个词对照——对得上即“我没告诉他、他自己看出来了”；这一轮同时承担 L4「这样改好在哪」的回收，非互挑、非画记号）
开场钩子： 素材追问式·好奇者（先请学生从教材那五段介绍里挑一位“最想认识的”并说理由，学生答完老师承认自己挑的也是那位会讲故事的爸爸，随即追问“他怎么个会讲法”——学生答不上来，缺口由学生自己撞见而非老师宣布）
主技法： 先想起一件他真做过的事、再从这件事里看出他是个什么样的人（方向倒过来，不先下结论）；一堆事里挑印象最深、别人家写不出的那一件（辅：事里要有他的动作和他说的那一句原话，属三下旧知只作快速唤起、不重教）
审题辨析形态： 两段对照判断（同写自己家：一段四口人各写两三句、门框吊车短发小辫子样样有画面却一件事也没有／一段只写妹妹一位、讲拿橡皮那一件完整的事；判据落在“题目要的事例有没有”而非写得细不细，预期有学生选反例，师话先承认反例“不糙、每人身上都有看得见的东西”再回题目要求）
技法引出装置： 给教材那位爷爷添一件事（承接开场投屏的教材原句“每天练习书法、一年三百六十五天从不间断”，老师当场把这句结论写成一件事的单点示范念给学生听，段里不给任何结论词，由学生自己说出这位爷爷是个什么样的人，由此点破方向倒过来；单点示范刻意收在“写到天黑”，把“手在抖”与那句原话整个留给 ④ 示范文去发现，不剧透；随即三步对比交回选择权——原句没写错、两种搭着用、并划开“很好／很能干”这类谁都套得上的话；再让学生回自己学习单上清点的几件事逐件过“别人家有没有”）
