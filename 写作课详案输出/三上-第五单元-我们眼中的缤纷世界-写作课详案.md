# 《我们眼中的缤纷世界》· 写作课教学设计
三年级上册·第五单元 校内同步写作（观察作文）

[教具准备：本课无需采购。投屏两样：一段 30 至 60 秒的蚂蚁搬东西短片（第一环节整段放一遍、第二环节再放一遍，无需另备第二段）；教材习作页（出示题面用，页上那幅配图随页面一同出现，插-01 已在同名图单登记）。短片须拍到三件事：很多蚂蚁在同一片地方来回走（有的往一个方向去，有的空着身子回来）、有蚂蚁搬着比自己大的东西、看得见蚂蚁窝的洞口而且蚂蚁在洞口进进出出。⚠ 别找「蚂蚁排成一条长龙」的片子：野外蚂蚁多是密集往返，排成直线长龙的画面基本只出现在人为摆食物的摆拍视频里，那类片子镜头远、看不清蚂蚁，也与本课「留心观察身边的事物」相抵。教师可用任何同类短片替换，第二环节的问题与参考答案、第三环节用三个词口述搬家那一处接龙，都只落在这三件事上。
⚠ 本详案不附带短片，只写要求：备课时已试用过 B 站「观察蚂蚁窝：一群蚂蚁忙碌地协力把食物搬运进窝」（UP 主青提乌瓦，BV1fS4y1w71P）第 60 至 100 秒这一段，三件事齐全；该片标注「未经作者授权，禁止转载」，不得随教案分发，授课教师请自行在 B 站打开播放，或改用自拍素材。其余要上屏的（第三环节两段对照、空白卡与教师示范卡、示范文与旁批表）都在本详案里，照抄上屏即可。学生单一张：观察发现卡在上、三档自检表在下。]

[授课提示：第五环节的示范文《一杯菊花茶》是教师按三年级学生的口吻拟写的，写的是一个孩子看奶奶泡菊花茶的经过；观察发现卡的教师示范填写与旁批表都取自这一篇，三处内容须保持一致，改其中一处要连着改另外两处。]

## 教案提纲表

| 课题·课时 | 三上·第五单元《我们眼中的缤纷世界》　│　观察作文·校内同步　│　2课时连排（每节45分钟） |
| --- | --- |
| 能力阶段 | 写清楚（本课） → 写具体 → 写生动 → 写深刻·有章法 |
| 同类习作顺序 | 写景状物：缤纷世界（本课）／这儿真美 → 我的乐园／动物朋友／游＿＿ → 心爱之物／我最喜爱的季节 |
| 教材要求 | 统编三上·第五单元习作：留心观察，把看到的写下来（观察起步）。 |
| 学习目标 | 通过用多种感官细致观察一样身边的事物，来学习怎么把观察所得写成一篇短文。 |
| 核心技法 | 使用“观察发现卡”。先用眼睛、耳朵、手、鼻子、嘴巴把它看个仔细，把发现记在卡上，没有的那一格空着；再从卡上选出印象最深的一两处，先写出它的样子，再加上像什么或者耳朵听到、手摸到、鼻子闻到、嘴巴尝到的感觉；要是这一处会变，就按刚开始、过了一会儿、最后的顺序写。 |

## 第1课时 · 写作指导课

### 一、创设情境，明确任务（约 6 分钟）

[投屏播放蚂蚁搬东西的短片，整段放一遍。这一遍只看个大概，不提要求]

师：上课先看一段短片。看完告诉老师，它们在做什么。

学生互动分享（请两三位同学说）

参考：蚂蚁在搬东西／好多蚂蚁在爬来爬去／它们在搬家。

师：一群蚂蚁在搬东西。楼下花坛边上、墙根底下，常常能看见这样一群。那老师想问一句：真正蹲下来，从头到尾看过一次的，有几个人？

学生互动分享（举手表态即可，再请一两位说说看到过什么）

参考：见过，可是没蹲下来看过／看一眼就走了／我看过，它们在搬饼干渣。

师：有同学说见过，可是没蹲下来看过；有同学说看一眼就走开了；也有同学真看过它们搬东西。

师：身边天天见得到的小动物，不止蚂蚁。猫、狗、鸟、金鱼、蜗牛，大家身边多半也有这么一只。可是它叫起来是什么声音？身上摸着什么感觉？有没有一个只有它才有的怪毛病？这几个问题，能马上答上来的人就不多了。天天见得到，不等于看清楚了。

师：这节课，我们就来把这样一只小动物看个仔细，再把看到的、听到的、摸到的、闻到的写下来。

师：这一篇写完以后要读给同组的三位同学听。听的人要说出他写的哪一样，你在自己那只身上也见过、可是从来没留意；或者哪一样，是你从来没想到还能写下来的。同组的同学说得出一样，就说明你看得仔细，也写清楚了。

[投屏出示教材习作页。题面字号放大，保证最后一排能看清；页上那幅配图随页面一同出现，不单独讲解]

【图位:插-01｜教材习作页原有配图（随题面一同出示）】

师：这就是语文书第五单元的习作《我们眼中的缤纷世界》。教材上说，要把最近观察时印象最深的事物写下来。

师：大家最近如果仔细观察过别的东西，也可以写那样东西；没有的，今天就写你身边那只天天见得到的小动物。

师：这个单元导语页上还有一句话，法国的罗丹说的：“生活中不缺少美，只是缺少发现美的眼睛。”今天我们就来试一试，一只天天见到的小动物，仔细看了以后，能不能有新的发现。

### 二、观察体验，看一群蚂蚁在搬什么（约 8 分钟）

> **可压缩预案**：回忆唤醒的四问时间紧时合成两问（摸过它吗、它叫起来什么声音），各请两位。

[把刚才那段短片再放一遍，这一遍请学生各选一只盯着看]

师：刚才那段短片，我们再看一遍。这一遍请大家选一只盯着看，看它一路做了些什么。

师：它们是朝一个方向走，还是来回都有？搬的东西有多大？走到洞口那里，又是怎么回事？

学生互动分享（请三四位同学各说一处，教师复述每位同学的发现）

参考：来回都有，有的去有的回／有一只驮的东西比它自己还大／驮着东西的都往洞口那边去／空着身子的是从洞口出来的／洞口挤成一小团。

师：来回都有，驮着东西的往洞口去，空着身子的从洞口出来，有一只驮的比它自己还大。这里面还藏着一个变化：那一只驮着东西的，刚开始在哪里，过了一会儿走到哪里，最后怎么样了？

学生互动分享（请两位同学说）

参考：刚开始它在草根那边／过了一会儿驮着东西一路往洞口挪／最后钻进洞口不见了。

师：刚开始、过了一会儿、最后。一件事是怎么变的，就是这样一段一段看出来的。等一会儿写变化的时候，我们就用这三个词。

师：下面请大家回想一下自己那只小动物。老师问四个问题，想到了就举手说。第一问，你摸过它吗？摸上去是什么感觉？

学生互动分享（请两位同学说）

参考：毛软软的，暖暖的／壳硬硬的，滑溜溜／摸不着，它一靠近就跑。

师：毛是软的、暖的，壳是硬的、滑的，也有同学说摸不着，它一靠近就跑。这些都是手上知道的事。第二问，它叫起来是什么声音？它走动、吃东西的时候有没有声音？

学生互动分享（请两三位同学说）

参考：喵喵叫，饿的时候叫得特别长／吃东西咔嚓咔嚓的／爪子在地板上嗒嗒嗒／金鱼不出声。

师：叫声、啃东西的声音、爪子踩在地板上的声音，都被大家听出来了；还有同学说金鱼不出声，这也是一种发现。第三问，凑近它，闻到过什么味道吗？

学生互动分享（请两位同学说）

参考：晒过太阳以后有一股暖烘烘的味／没什么味／鱼缸边上有点腥。

师：有闻到暖烘烘味道的，也有说没什么味的。第四问，你那只小动物有没有一个只有它才有的怪毛病？

学生互动分享（请两三位同学说）

参考：它只在我写作业的时候趴到我本子上／它怕吸尘器，一响就钻到沙发底下／它吃东西要先用爪子按一按／它认得我的脚步声。

（教师总结）刚才大家想起来的，有手摸到的毛和壳，有耳朵听到的叫声和脚步声，有鼻子闻到的味道，还有那个只有它才有的怪毛病。教材习作页上说，观察时可以用眼睛看，用耳朵听，还可以用手摸，用鼻子闻，有时还可以尝一尝。小动物不尝，尝一尝今天用不上；碰不到、闻不着的，那一格空着也行。写蚂蚁的同学，眼睛看到的、它像什么、还有它的变化，这三样最容易写出东西来。

### 三、学写法：选一两处印象最深的，写清楚（约 15 分钟）

师：看仔细了，下面来说怎么写。投屏上这两段，都是老师照着楼下那群蚂蚁写的。题目要求把最近观察时印象最深的事物写下来，大家听完告诉老师，哪一段把印象最深的地方写清楚了？

[投屏出示两段，教师逐段读]

师：第一段：“我家楼下有一群蚂蚁。它们是黑色的，背上油亮油亮的，最大的一只也不过米粒那么大。头上两根触角细得像头发丝，一刻不停地摆来摆去。六条腿跑起来飞快，一眨眼就从这块砖跑到了那块砖。它们力气大得出奇，能拖动比自己大好几倍的东西。墙根底下有一个小洞口，那就是它们的家。太阳一落山，它们就都回去了。”

师：第二段：“我家楼下那群蚂蚁里，有一只搬着一小块饼干渣，那块渣子比它的脑袋还大。它用两只前脚把渣子举过头顶，走三步停一下，像是在换口气。走到一道水痕跟前，整条队伍乱了：刚开始它们挤在水边打转，谁也不肯下去；过了一会儿，有一只贴着边上试着绕了半圈；最后，整条线都改走那边了，水痕上一只也没有。”

师：两段写的都是这群蚂蚁，写的也都是观察到的东西。哪一段把印象最深的地方写清楚了？

学生互动分享（先举手表态，再请两三位说理由）

参考：第一段吧，它什么都写到了／第二段，它把绕开水痕写得很清楚／第二段有举着饼干渣的那一只，第一段没有。

师：有同学选第一段，理由是它什么都写到了。这是第一段的长处：颜色、大小、触角、腿脚、力气，连它们什么时候回家都写到了，句句也都不空，说明写的人观察的时候样样都看了。可是请大家再想一想，第一段读完，这一群蚂蚁和别处的蚂蚁有什么不一样？

参考：说不出来／哪儿的蚂蚁都是这样的。

师：是的，说不出来，因为每一样都只有一句，哪一处都没有写细。第二段只写了两处，一只举着饼干渣的蚂蚁，一段绕开水痕的过程，可是每一处都写清楚了，读完就记住了这一群蚂蚁。这才叫把印象最深的地方写清楚。

师：所以今天的写法分三步。第一步，细看，刚才我们看短片、想自己那只小动物，就是在做这件事，眼睛、耳朵、手、鼻子都用上，样样都看。第二步，选一两处，从看到的东西里选出印象最深的一两处来写。其他的可以一句带过，也可以不写，由大家自己定。第三步，把选出来的这一两处写清楚。

师：这个单元的课文《搭船的鸟》，作者仔细看了一只翠鸟，写清楚的也正是这两样：色彩艳丽的羽毛，还有敏捷的身手。看得仔细，才有东西可以选。

师：第三步“写清楚”怎么做？老师选洞口来写，有蚂蚁的地方都有一个洞口，大家都找得到；等一会儿轮到大家圈，还是要先选你那只才有的。只写一句，是这样：“洞口有蚂蚁进进出出。”写清楚了，是这样：

〔教师示范·把一句扩成几句〕洞口只有铅笔头那么大，四周堆着一圈新翻上来的细土，像一座小小的火山口。进去的那些多半驮着东西，出来的却是空着身子，在洞口挤成一小团，谁也不让谁。我把耳朵贴到地面上，一点声音也听不见。

师：请大家比一比，后面这一段多出来的是什么？

学生互动分享

参考：说了洞口像小火山口／有进去的驮东西、出来的空着身子／有贴着地面听，听不见声音。

师：对，多出来的是三样：洞口是什么样，像什么；进去的和出来的有什么不一样；耳朵贴上去听到什么。看到的和听到的放在一起，这一处就写清楚了。

师：所以写清楚，就是把这一处的样子写出来，再加上它像什么，或者耳朵听到、手摸到、鼻子闻到、嘴巴尝到的感觉。

师：教材里还有一篇例文《我家的小狗》。那位作者观察得很仔细，发现那只叫“王子”的狗，认“狗”字的时候叫得最欢。一只狗认字，这是只有那一只才有的一处，他把它写下来了，读的人就记住了。大家等一会儿要找的，也是这样一处。

师：还有一种情况：你印象最深的是一个会变的过程，比如蚂蚁搬家、小狗见到你、金鱼抢食。写会变的东西，用三个词把它按顺序写清楚：刚开始，过了一会儿，最后。我们一起用这三个词，把短片里那一队蚂蚁搬家说一遍。请第一位同学说“刚开始”，第二位说“过了一会儿”，第三位说“最后”。

学生互动分享（请三位同学接着说，每人一句）

参考：刚开始洞口边上只有几只在爬／过了一会儿驮着东西的一只接一只往洞口去／最后洞口挤成一团，东西一件一件都搬进去了。

师：很好，三句连起来，搬家的过程就清楚了。

师：现在请大家试一试。就写刚才你想起来的、自己那只小动物的那一处，写两句话：第一句写它是什么样，第二句加上它像什么，或者耳朵听到、手摸到、鼻子闻到、嘴巴尝到的感觉。写在大家手里那张单子的空白处，三分钟。

学生动笔写作

师：请三位同学把自己写的两句读给大家听。

学生互动分享（请三位同学读，教师就每一位指出他加上了哪一种：像什么、听到的、摸到的，还是闻到的；覆盖面广一些，不只请前面发过言的同学）

师：刚才三位读的，有的加了它像什么，有的加了手摸到的，还有的加了耳朵听到的。加上这样一句，这一处就比原来清楚了。

师：写法就说到这里。动笔之前，我们先用一张卡把刚才的发现理一理。

### 四、借助观察发现卡，理清思路（约 8 分钟）

师：这张卡叫观察发现卡。卡上只填词，不写句子，一格两三个词就够了。

[投屏出示空白卡；同款空白卡印在学生手里的单子上]

| 项目 | 关键词 |
| --- | --- |
| 我观察的是 | |
| 眼睛看到 | |
| 耳朵听到 | |
| 手摸到 | |
| 鼻子闻到 | |
| 嘴巴尝到 | |
| 它的变化（刚开始→过了一会儿→最后） | |
| 印象最深的一两处（圈出来） | |

师：老师先填一张。老师这张卡填的是一杯菊花茶，不是小动物。这是老师备课时拟的一个例子：一个三年级的孩子看奶奶泡菊花茶，一边看一边把发现记下来。

[投屏逐格填写教师示范卡，边填边读]

| 项目 | 关键词 |
| --- | --- |
| 我观察的是 | 一杯菊花茶 |
| 眼睛看到 | 干花小、灰黄；泡开变白，水变黄 |
| 耳朵听到 | （空着） |
| 手摸到 | 杯子烫 |
| 鼻子闻到 | 淡香，像草，像药 |
| 嘴巴尝到 | 先苦，后甜 |
| 它的变化（刚开始→过了一会儿→最后） | 沉底→浮起来张开→水变黄 |
| 印象最深的一两处（圈出来） | 张开的过程、味道 |

师：请大家看，每一格只有几个词。“耳朵听到”这一格老师空着，因为泡茶的时候没有听到什么特别的声音，没有就空着，不用硬填。最后一格最重要，老师从上面几格里选了两处，圈出来，等一会儿动笔就重点写这两处。

师：轮到大家了。请大家想着自己那只小动物，把记得的看到的、听到的、摸到的、闻到的填进卡里，每格两三个词，没有的那一格空着。小动物不尝，“嘴巴尝到”这一格就空着。

师：“它的变化”那一格也不要落下。你那只小动物做一件事的时候，常常是一段一段变过来的，比如它见到你、它抢东西吃，就填进这一格。

师：填完以后，请在最后一格写上印象最深的一两处，圈出来。三分钟。

学生动笔写作（填卡约 3 分钟；教师巡视）

〔应答·学生要写最近观察过的别的事物〕允许，卡照样填：“我观察的是”那一格写那样东西，下面几格凭记忆填；水果这类尝得了的，“嘴巴尝到”那一格可以填；“它的变化”一格填不出也可以空着，印象最深的一两处照样要圈。

〔应答·学生最后一格圈了四五处〕不否定，请他再看一遍卡上的词，问：“这几处里，哪一处是你那只才有的，或者是你今天第一次想起来的？”让他留下一两处，其余的划掉。

〔应答·学生“手摸到”“鼻子闻到”两格空着〕请他再想一次：抱过、碰过它吗，毛或者壳在手上什么感觉，凑近有没有味道；碰不到、闻不着就空着，不勉强。

师：填好的同学，先把圈出的那一两处小声说给同桌听，一句话就行：我圈的是哪一处。

学生互动分享（同桌两两互说，同时进行；教师走到两三组听，留意有没有人圈的是“很可爱”“很好看”这类谁身上都有的）

师：请两位同学说给全班听：你圈的是哪一两处，为什么选它？

学生互动分享（请两位同学说，教师就每一位复述他选的那一两处，并指出是不是他那只才有的）

### 五、出示示范文，发现写法（约 8 分钟）

> **可压缩预案**：时间紧时，“其余几格去了哪里”一问可以不问，句子层保留“读到哪一句好像也闻到、尝到了”一问，旁批表带读一遍即可。

[收起投屏上的教师示范卡，只出示示范文]

师：老师把刚才那张卡上的菊花茶写成了一篇短文。这是老师写的，老师是把自己当成一个三年级的孩子来写的，写的是他看奶奶泡茶。请大家听，一边听一边留意：卡上圈的那两处，到了短文里各是哪几句？

> 【教师示范文】
>
> 一杯菊花茶
>
> 奶奶泡菊花茶的时候，我凑过去看。
>
> 干菊花装在一个小罐子里，一朵一朵缩成小团，灰黄灰黄的，比我的指甲盖还小，一点也不像花。
>
> 奶奶抓了几朵丢进玻璃杯，热水冲下去。刚开始，菊花全沉在杯底，一动不动。过了一会儿，一朵一朵慢慢浮上来了，缩着的花瓣一根一根松开，像睡醒的人伸懒腰。最后，每朵花都张得圆圆的，白花瓣，黄花心，水也跟着变成了淡淡的黄色。
>
> 我端起杯子，杯壁烫手，只好捧着杯口闻。一股淡淡的香气飘上来，有点像草，又有点像药。我吹了吹，小心地喝了一口。先是苦的，舌头缩了一下；咽下去以后，嘴里却慢慢回上来一点甜。
>
> 原来一朵这么小的干花，泡在水里会变成这个样子。

师：卡上圈出的那两处，菊花张开的过程和味道，到了这一篇里各是哪几句？

参考：张开的在中间那一段／刚开始、过了一会儿、最后那几句／味道在最后，先苦后甜。

师：对。张开的过程写在第三段，从“热水冲下去”一直到“水也跟着变成了淡淡的黄色”，用了刚开始、过了一会儿、最后三个词；味道写在第四段后半，先苦，咽下去以后回甜，也是一个变化。卡上还有几格：干花的样子、杯子烫、闻到的香，这几样在这一篇里去了哪里？

参考：干花的样子写了一段／杯子烫就一句／闻的也就一两句。

师：对，干花的样子写在第二段，一段就交代完了；杯子烫只有一句；闻到的香也只有一两句。卡上填了这么多格，重点写的只有两处，其余的一句带过，这就是选一两处写清楚。

师：再看句子。读到哪一句，大家好像自己也闻到、尝到了，或者眼前有了那杯茶？请找一句。

学生互动分享（请两三位同学各找一句）

参考：像睡醒的人伸懒腰／舌头缩了一下／有点像草，又有点像药。

师：老师把自己写得最用心的几句排成了一张表，每句用了什么，看一眼就明白。大家刚才找的那几句，看一看在不在这张表里；不在表里的，也说一说它用了什么。

| 示范文里的句子 | 这一句用了什么 |
| --- | --- |
| 一朵一朵缩成小团，灰黄灰黄的，比我的指甲盖还小 | 眼睛看到的：形状、颜色、大小 |
| 刚开始……过了一会儿……最后…… | 写变化的三个词 |
| 缩着的花瓣一根一根松开，像睡醒的人伸懒腰 | 打了个比方 |
| 杯壁烫手 | 手摸到的 |
| 有点像草，又有点像药 | 鼻子闻到的，用像什么说清楚 |
| 先是苦的，舌头缩了一下；咽下去以后，嘴里却慢慢回上来一点甜 | 嘴巴尝到的，也写出了变化 |

师：菊花茶是老师举的例子，大家写自己那只小动物，不用写得像老师这一篇。写小动物的同学，重点看这张表的头三行：它是什么样、它像什么、它是怎么变的；小动物不尝，“嘴巴尝到”那一格空着，照样能写清楚。休息回来，我们就照着自己的卡动笔。请大家把观察发现卡收好。

本课完。

## 第2课时 · 当堂写作与评改课

### 一、借助观察发现卡，写下第一组句子（约 5 分钟）

师：请大家把观察发现卡拿出来，放在稿纸旁边，看最后一格，找到自己圈出的第一处。我们先把这一处写下来，一句一句来。

师：稿纸第一行，开头空两格，先用一句话交代自己观察的是什么，比如“楼下那只花猫，我天天上学都能碰见”，也可以用自己的说法。这样交代一句就够了，要紧的在后面那一处。

师：接着就写圈出的第一处：这一处在它身上的什么地方，是什么颜色、什么形状。如果你圈的第一处就是第一节课练笔写过的那一处，把那两句誊上来，接着往下加。

学生动笔写作

师：再加一句：它像什么，或者你的耳朵听到什么、手摸到它是什么感觉、鼻子闻到什么、嘴巴尝到什么。

学生动笔写作

师：如果你这一处是会变的，比如它搬东西、它见到你的时候，就接着用刚开始、过了一会儿、最后，各写一句。不会变的这一步就不用写。

学生动笔写作

师：写到这里，第一处已经有几句了。这几句就是这篇习作的第一段，后面接着往下写。

### 二、自由写作，写成一篇观察短文（约 20 分钟）

师：接下来二十分钟，请大家把这篇习作写完。写的时候记住三件事：第一，重点写卡上圈出的一两处，把它写清楚，其他看到的可以一句带过，也可以不写；第二，写清楚就是先写它的样子，再加上它像什么，或者耳朵听到、手摸到、鼻子闻到、嘴巴尝到的感觉；第三，会变的用刚开始、过了一会儿、最后。写错了不用擦，接着往下写，改的事等一会儿再做。

学生动笔写作

[巡视指导：教师按学情轻声提示，全程不打断学生思路，不指出错别字。第一圈在动笔约 4 分钟时巡视，重点看第一处有没有写开；第二圈在约 13 分钟时巡视，重点看有没有写到第二处]

〔应答·学生写成了“我每天放学回家都能看见它，然后就去写作业”这样的经过〕轻声提示：“你做了什么先放一放，写它是什么样的。看一眼你的卡，圈的第一处是什么？就写它。”

〔应答·学生反复写“很可爱”“很好看”“很乖”〕轻声问：“它哪一处让你觉得可爱？摸上去什么感觉？叫起来什么声音？”请他把这一句补成两句。

〔应答·学生写得顺畅〕从旁边走过，不停留，不说话。

〔应答·学生写了三四行就搁笔〕先肯定他写清楚的那一处，再问：“你卡上圈的第二处是什么？接着写它。”只写了一处也可以，问他这一处还有没有耳朵听到、手摸到、鼻子闻到的可以补，或者它像什么。

师（约 17 分钟时轻声提醒一次）：还有三分钟。写到结尾的同学，写一句今天观察下来的感受，一句就够。

师（20 分钟整）：请大家停笔，稿纸留在桌上。没有写完的同学记住接下来要写哪一处，等修改的时候再补。

### 三、交流评议，修改收束（约 20 分钟）

[本环节当堂做四件事：小组轮读听新发现、各组推一处到全班、对照标准自改、同桌互改纠错。没有写完的学生照常参加，读和改自己已经写出来的那部分。逐篇的深度讲评见文末附加的“习作讲评指导环节”。]

[小组轮读（约 8 分钟）：四人一组，每人读自己圈的那一两处，其余三人各说一处]

师：现在回到上课时说好的那件事。四人一组，轮流读自己写的那一两处，就读重点写的那几句，不用读全篇。

师：读的同学读完，其他三位同学每人说一样：他写的哪一样，你在自己那只身上也见过、可是从来没留意；或者哪一样，是你从来没想到还能写下来的。说得出一样，说明他看得仔细，也写清楚了。

师：如果听完三个人都说不出来，也不用勉强说，那就说明这一处还要写得更细一点，等一会儿修改的时候重点改它。

学生互动分享（四人小组轮流读，每人约 1 分钟，其余三人各说一句；教师走到两三个组旁听，不打断）

〔应答·三位听的同学都说不出一处〕请作者把写得最细的那一句再读一遍；仍说不出，就告诉他：“修改的时候，把这一处再加一句：耳朵听到、手摸到、鼻子闻到的，或者它像什么。”不追着听的同学要评价。

〔应答·听的同学说的是自己也写了的那一处〕这是正常情况，告诉他：“你也注意到了，很好。那他写的这一处，有没有哪一句是你没写出来的？”

[全班分享（约 3 分钟）：各组推一处，请两组]

师：请每个小组推一处，就推刚才组里同学听了以后觉得最没想到的那一处，由作者把那几句读给全班听。

学生互动分享（请两组，每位读自己那几句；教师就每一位指出具体的句子）

〔教师示范·轻点评说法〕“他写那只猫的耳朵缺了一个角，说转过头来像被剪过一刀，这一处只有他那只猫才有。”“她写她家那两条金鱼抢食，说抢到的那一条贴着缸底不动，尾巴还一下一下地摆，这一处很多人见过，可是只有她写下来了。”

（教师总结）都是身边的小动物，刚才几组读出来的发现各不相同。这就是题目说的“我们眼中的缤纷世界”：同一样东西，每个人看到的不一样，仔细看的人看得最多。

[对照标准自改（约 5 分钟）]

师：接下来改自己的习作。请大家先对照单子上这三条，一条一条对，看自己今天到了哪一条。

| 档位 | 自检的话 |
| --- | --- |
| 基础 | 我写出了观察到的东西，写了它的颜色和样子。 |
| 良好 | 我选了一两处印象最深的写清楚了：除了样子，还加上了一样别的感官，或者写了一句它像什么；句子读得通。 |
| 优秀 | 我写的那一两处，同组同学说得出一样：他在自己那只身上也见过却没留意的，或者他没想到还能写下来的；感官用上了两样以上，或者用刚开始、过了一会儿、最后写出了变化。 |

师：刚才没有写完的同学，先用一两句把没写的那一处补上。补完以后，请大家对着这三条一条一条查，看自己今天到了哪一条。

学生互动分享（各自对照三档自检表判断，不必出声；教师巡视，随机问两位“你对到哪一条”）

师：对到哪一条，就照那一条改。只到基础这一条的，给你写的那一处再补一样：补一样感官，耳朵听到的、手摸到的、鼻子闻到的都可以；或者补一句它像什么。两样补上一样即可。

师：到良好这一条的，把另一样也补上；这一处如果会变的，就用刚开始、过了一会儿、最后写出它的变化，补上哪一样都算。到优秀这一条的，这几句不用动。刚才组里同学说不出新发现的那一处，也照这个办法加一句。

师：加完以后，请自己读一遍，用修改符号把习作理一遍：多的字圈掉，漏的字补上，错的字改正，读不通的句子改通。三分钟。

学生动笔修改

[同桌互改（约 3 分钟）]

师：请和同桌交换习作，只读一遍：读到读不通的地方或者错字，用铅笔在旁边画一个小圈，等一会儿还给他自己改。自己刚才没看出来的，同桌往往看得出来。

学生互动分享（同桌交换，读一遍、画圈）

师：请拿回自己的习作，看一看同桌画的圈，把那几处改一改。

[收尾（约 1 分钟）]

师：今天大家把天天见得到的那只小动物想了个仔细，也写下了自己的发现。教材上说，交流以后可以说一说最近观察的感受。谁来用一句话说一说，今天仔细想了那只小动物，你有什么感受？

学生自由分享（请一两位同学各说一句）

师：大家说的这些感受，都是今天仔细看过以后才有的。回去再碰见它的时候，可以多看一眼，看一看今天写的那一处是不是还那样。习作交给老师。下课。

本课完。

全课完。

## 附：习作讲评指导环节（可选 · 单次课课后用 / 系列课作下次课开场用）

> 说明：本环节不计入两节连排的 45+45，是给授课老师的一块可灵活取用的讲评指导环节。可以在课后通读习作后另找时间集中讲评一次，也可以作为下一次写作课的开场，用约 15 分钟，先讲评再进新课。讲评的是学生当堂完成的这一篇，不布置新的写作任务。
>
> 真实性提示：下面师话里凡 ＿＿＿ 处，务必换成本班学生习作里真实写出的句子，不要虚构。

### 选稿（课前准备）

教师课后通读全班习作，围绕本课的写法（选一两处印象最深的写清楚；写清楚靠看到、听到、摸到、闻到、尝到的和像什么；变化用三个词）选出三篇：

- 一篇较好的：选了一两处，每一处都有颜色形状，加了像什么或者耳朵听到、手摸到、鼻子闻到的，读完记得住那只小动物。
- 一篇中等的：选了一两处，可是每一处只有一句“是什么样”，没有加上像什么和别的感官。
- 一篇有典型问题的：或者每一样都写了一句，没有一处写细；或者写成了“我每天回家都能看见它”的经过，它本身什么样没有写。

[三篇投屏出示，不读作者姓名；讲评前为每篇拟一句评语，写明对照本课写法好在哪里、欠在哪里]

### 讲评流程（每篇约 3–5 分钟，围绕本课技法点）

师：大家的习作老师都读过了。这次讲评只看两件事：有没有选一两处印象最深的地方来写，选出来的这一两处有没有写清楚。别的今天先不评。

师：先看第一篇。请大家听这几句：＿＿＿（读该生写得最清楚的一两句）。这几句写的是哪一处？他是怎么把它写清楚的？

学生互动分享

参考：写的是＿＿＿／他说了像什么／他写了摸到的。

（教师总结）对，他写的是＿＿＿（点出那一处），先写了它的样子，再加上＿＿＿（点出他用的是像什么、听到的、摸到的、闻到的还是尝到的）。这就是把一处写清楚。

师：第二篇选的这一处很好，是＿＿＿（点出该生选的那一处），只是这一处只有一句：“＿＿＿”（读出那一句）。我们一起帮他加一句。这一处像什么？耳朵听到什么，手摸上去、鼻子闻起来是什么感觉？

学生互动分享（请全班补一两个说法）

师：加上刚才大家说的“＿＿＿”（填补出的说法），这一处就清楚多了。改自己的习作也是这样，找到只有一句的那一处，给它加一句。

师：第三篇不点名，我们一起想办法。这一篇＿＿＿（按该篇的情况说：每一样都写了一句，读完记不住哪一处最特别；或者写的是自己做了什么，它什么样没有写）。要改，第一步从哪里入手？

学生互动分享

参考：选一处写细／先写那只小动物是什么样。

（教师总结）第一步是回到自己的观察发现卡，看最后一格圈的那一两处，把其中一处写细，其他的一句带过。写不出来的时候，多半是选的那一处还没有看仔细。

### 收尾（点回技法、引向今后的写作）

师：第一篇选了一处写清楚了，第二篇补上一句以后也清楚了。今后大家观察什么，都可以这样做：样样都看，只写印象最深的一两处，把它写到别人读了记得住。

本环节完。

场景原型: 身边那只熟悉的小动物、各人眼中不同：开场看一段蚂蚁搬东西的短片，问「真正蹲下来看过一回的有几个人」，再唤醒对自己那只小动物的回忆，写下印象最深的一两处读给同组同学，听的人说出一样「自己那只身上也见过却没留意的」或「没想到还能写下来的」（官方情境「多感官观察一种事物，写印象最深处」按连排改造用短片＋回忆唤醒替代课前观察；官方反馈「小组互读」保留，判据由三上六已用的「我仿佛看到了」换成「哪一样是我没留意过的」）
实体载体: （无·官方落点是当堂互读，不套展示载体；成败标准＝同组三人各能说出一处新发现）
热身动作: 看一段蚂蚁搬东西的短片抓动作与变化（来回往返／搬比自己大的种子／洞口进进出出）＋四问回忆唤醒自己那只小动物（摸过它吗／叫起来什么声音／凑近什么味道／有没有只有它才有的怪毛病）（动物短视频＋回忆怪癖类，池 1 动物行备选；⚠ 素材要求已按实拍核定，不用「排成长龙」那类摆拍片）
主反馈游戏: 小组轮读只读重点写的那一两处，其余三人各说一处“他写到的、我没注意过的”＋各组推一处“最没想到的发现”到全班读（官方「小组互读＋全班赏发现」的当堂化）
第二层反馈: （无·同桌交换只做纠错画圈，不另设闪光点反馈；全员被听见由四人小组轮读承担，三档自检按档位驱动改法）
开场钩子: 图像揭示式·发现者（放一段蚂蚁搬东西的短片，先问「它们在做什么」学生当场答得出，再问「真正蹲下来从头到尾看过一回的有几个人」，多半没有；老师不装不懂，只说天天见得到不等于看清楚了。⚠ 教材习作页配图只随题面一同出示、不单独发问——它是该页自带的装饰配图，不作引出写作对象的跳板）
主技法: 细看→选一两处→写清楚（多感官细看后，从卡上选印象最深的一两处写清楚，其余一句带过或不写；写清楚＝样子＋像什么／手鼻嘴的感觉；会变的用刚开始、过了一会儿、最后）
审题辨析形态: 两段对照判断（同写楼下一群蚂蚁：反例写了颜色、大小、触角、腿脚、力气、洞口、作息七样，句句具体、有比喻有动作，在「具体不具体」这一维上不输正例，错只错在样样一句、没有一处写透，换一群蚂蚁照样成立／正例只写举饼干渣的那一只和绕开水痕的过程两处但每处写透；判据落在「有没有把印象最深的一两处写清楚」而非「写得全不全」）
技法引出装置: 教师现场扩句示范（把“洞口有蚂蚁进进出出”一句当场扩成一段、只留在洞口这一处：像小火山口、进的空手出的驮东西、贴地听不见声音）＋三人接龙用刚开始／过了一会儿／最后口述蚂蚁搬家
示范文题材: 虚构小作者的第一人称日常（三年级的“我”看奶奶泡一杯菊花茶：干花张开的变化、先苦后甜的味道）
互动组织: ②全班逐步举手抽说（每步两三位）/③举手表态＋抽说理由＋三人接龙＋练笔抽读/④同桌两两互说各报一处＋抽两位说给全班/⑦四人小组轮读＋三人各说一处新发现→各组推一处到全班→同桌交换画圈纠错
话轮骨架: ①短片整体看→问蹲下来看过没有→点破天天见得到不等于看清楚→出题面｜②短片再看一遍盯住一只→找细节→找变化串三个词→四问回忆唤醒→总结四感｜③两段对照→接住选反例的（承认看得全）→追问“和别处的蚂蚁有什么不一样”→教师命名三步→课文佐证→教师扩句示范→学生比多出什么→三人接龙变化词→两句练笔抽读｜④（第五环节）收起示范卡→带任务听→找两处各在哪几句→问其余四格去了哪里→找一句像闻到尝到的→旁批表→放行写自己的｜⑦小组轮读重点句＋三人各说一处新发现→各组推一处全班读＋轻点评→三档自检按档位改法→修改符号自改→同桌互改画圈纠错→说一句观察感受收尾
