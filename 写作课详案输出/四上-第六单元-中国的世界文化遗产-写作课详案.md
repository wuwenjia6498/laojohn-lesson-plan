# 《中国的世界文化遗产》· 写作课教学设计
四年级上册·第六单元 校内同步写作（说明性习作）

[授课提示：本课不安排课前查资料，资料由老师当堂发放，课前须做好三件事。① 资料卡五张：学生用四张（长城、故宫、兵马俑、苏州园林），老师示范用一张（莫高窟）。每张约一百五十到二百字，从教材资料袋或权威资料（如各遗产地的官方介绍）摘录，内容不分栏、照资料原样写成一两段，须包含：在哪里、什么时候建的、样子有什么特别、为什么能成为世界文化遗产，有的话再加一则相关的故事或传说；每张卡上印一张照片。莫高窟那张请选一幅画有人物弹琵琶、跳舞、飘在半空的壁画照片，与示范文第二、三段相合，最好能看清一个飘在半空的人身上有几道带子。② 本课凡“＿＿”处都是客观数据或名称（地点、朝代、年数、数量等），此处数据以教材资料袋/权威资料为准，课前请照资料卡填好再出示，不要现场估。示范文第四段是对莫高窟资料卡“为什么珍贵”那句话的转述，请对照资料卡核一遍意思，不相符就按资料改写这一句。第三环节投屏的西湖〔材料〕第二段和那一句西湖资料也有“＿＿”，西湖不在五张资料卡里，请另照权威资料填好。③ 发卡按竖列、先选后发：四处分成两组，长城／故宫一组，兵马俑／苏州园林一组；单数竖列从第一组里举手选一处，双数竖列从第二组里选一处，每列按多数定，整列拿同一处。这样左右相邻的同桌拿的一定不同、前后桌一定相同；座位不是竖列排的，保证这两条即可。两组卡各按可能需要的最多份数备齐。本课未引用教材习作页原文，如需投屏题面，请照教材习作页实物拍照投屏，不要凭本稿或记忆复述。]

## 教案提纲表

| 课题·课时 | 四上·第六单元《中国的世界文化遗产》　│　观察·说明·校内同步　│　2课时连排（每节45分钟） |
| --- | --- |
| 能力阶段 | 写清楚 → 写具体（本课） → 写生动 → 写深刻·有章法 |
| 同类习作顺序 | 观察·说明：植物朋友／小实验／国宝大熊猫 → 观察日记／世界文化遗产（本课） → 介绍一种事物 |
| 教材要求 | 统编四上·第六单元习作：搜集整理资料，有条理介绍一处文化遗产。 |
| 学习目标 | 通过把资料分成几个方面、用自己的话来介绍，来学习怎么写介绍一处文化遗产的习作。 |
| 核心技法 | 使用“资料整理表”。把资料分成几个方面，选三个方面，一个方面写一段，每段开头点明讲哪个方面；读懂资料后合上卡片，用自己的话来写，名字和数字照资料写准确；写进一处让自己吃惊的地方。 |

## 第1课时 · 写作指导课

### 一、创设情境，明确任务（约 5 分钟）

师：请大家说一说，中国有哪些地方是世界文化遗产？去过的、听说过的、在书上读到过的，都可以说。
学生互动分享（举手抽说四五位）
参考：长城／故宫／兵马俑／我去过颐和园／杭州西湖。
师：大家知道得不少。刚才说到长城的同学，老师再问一个问题：长城是什么时候开始修建的？它为什么能成为世界文化遗产？
参考：很早很早以前修的／好像是秦始皇修的？／因为它很长。
师：有同学说是秦始皇修的，有同学说因为它很长，可是到底从什么时候开始修、为什么这么珍贵，大家都说不太准。很多地方的名字我们都很熟悉，可是它在哪里、是哪个朝代建的，不少人说不清楚。这些内容，资料上都有。

[出示一叠资料卡，逐张亮出名称：长城、故宫、兵马俑、苏州园林、莫高窟]

师：这是老师为今天准备的资料卡，一共五张，每一张介绍的是一处中国的世界文化遗产。长城、故宫、兵马俑、苏州园林这四张是发给大家的；莫高窟这一张，老师已经先拿来试着写了一篇介绍，稍后请大家看一看。
师：每位同学都会拿到一张卡。拿哪一处，稍后由各竖列自己选定；同一竖列的同学拿到的是同一处，左右的同桌拿到的不一样。今天每位同学要写一篇介绍，读者就是你的同桌。他手里没有你这张卡，你写的这一处遗产，他能知道多少，取决于你写了多少。
师：写完以后，要过两关。第一关，前后桌和你拿的是同一张卡，他会拿着卡来核对：数字和名字有没有写错，有没有哪一句和卡上一字不差。第二关，同桌读完以后，要能说出这处遗产在哪里，还要说出一件他原来不知道的事。
师：这就是语文书第六单元的习作，题目叫《中国的世界文化遗产》。这个单元学过的《长城》《颐和园》《秦兵马俑》，介绍的也都是这样的地方。

### 二、观察体验，读懂资料卡（约 11 分钟）

师：我们先来选卡。第一、三、五竖列的同学，请从长城和故宫里选一处；第二、四、六竖列的同学，请从兵马俑和苏州园林里选一处。想写哪一处，就请举手，每一列按举手人数较多的那一处确定。
学生互动分享（各竖列举手选定，约 1 分钟）

[按各竖列选定的那一处发放资料卡，每人一张]

师：拿到卡以后，请大家先不读文字，只看卡上的照片。请用一分钟仔细看一看：它是什么颜色、什么形状，哪一处你最想再多看一眼。
学生自由分享（各自看照片，约 1 分钟）
师：请几位同学说一说，照片上你最想再多看一眼的是哪一处？
学生互动分享（举手抽说两三位，覆盖不同竖列）
参考：长城上隔一段就有一个方方的楼子／故宫的屋顶是黄的，一排一排／兵马俑一排一排站着，每个脸都不一样／园林里有一座小桥，桥下是水。
师：长城上方方的楼子、故宫黄色的屋顶、兵马俑各不相同的脸、园林里的小桥，几位同学说的都是照片上看得见的东西。这些内容，稍后写“它是什么样子”的时候，都能用上。

师：现在请大家读卡上的文字。读的时候请拿一支笔，做两个记号。第一个记号：读不懂的词，或者特别长、读一遍记不住的句子，在下面画一条横线。第二个记号：读到哪一处让你吃了一惊，可能是一个数字，也可能是一件事物，就在它旁边画一个感叹号。感叹号只画一处，请选最让你吃惊的那一处。
学生自由分享（各自默读资料卡并标画，约 3 分钟）
师：读完的同学，请和前后桌对一对：你画了横线的词，他懂不懂？两个人都不懂的，请举手问老师。再看一看对方的感叹号画在哪里。
学生互动分享（前后桌两两互对；教师巡视，对两人都不懂的词用一句通俗的话解释，如“始建于”就是“开始建造是在”）
〔应答·学生说整张卡都读不懂〕请他先只读卡上带数字的那几句，读一句问自己一句“这个数字说的是什么”，其余句子留到第三环节，一起学习如何读懂、如何表述。
师：请一两位同学说一说，你的感叹号画在哪里？为什么让你吃惊？
学生互动分享（举手抽说两位）
参考：我画在城墙的长度上，那也太长了／我画在兵马俑每个脸都不一样，那么多人，怎么做出来的。
师：一位同学吃惊的是城墙有那么长，一位同学吃惊的是兵马俑那么多，每一张脸却都不一样。你画了感叹号的这一处，稍后要写进你的文章里；它为什么让你吃惊，资料卡上不会写，只有你自己写得出来。画了横线的长句子，请大家选出一句，先记住它，下一个环节我们就从这样的句子学起。

### 三、学写法：用自己的话介绍资料（约 12 分钟）

师：动笔之前，我们先明确这篇习作要写成什么样子。屏幕上的这两段话，都和杭州西湖有关。请大家读一读，想一想：哪一段是今天这篇习作要写的样子？

〔材料〕第一段：暑假，爸爸妈妈带我去了杭州西湖。我们租了一条小船，船慢慢往湖中间划，湖水绿绿的，风一吹，凉凉地扑在脸上。岸边的柳枝垂到水面上，船一碰，枝条就晃起来。上岸以后，妈妈给我买了一碗藕粉，又甜又黏，我一口气吃完了。那天我们一直玩到天黑才回去。

〔材料〕第二段：西湖在浙江杭州，是中国的一处世界文化遗产。资料上说，从＿＿（朝代）起，一代又一代的人在这里挖湖泥、修长堤、造亭子，湖上的＿＿、湖边的＿＿，都是这样一点一点修起来的。读完资料我才明白，西湖能成为世界文化遗产，看重的不只是风景好看，还有这么多年来人们在湖边留下的东西。

学生互动分享（各自默读后举手判断）
参考：第二段／第一段，它写得更好玩。
师：选第一段的同学，请你说一说，第一段哪一点让你觉得它好？
参考：有划船，有风，还有藕粉，我好像也坐在船上。
师：说得对，第一段写的内容都看得见、摸得着，是写得很生动的一段。请大家想一想：读完第一段，你知道了西湖的哪些事？
参考：能划船，湖水是绿的／岸边有柳树／有藕粉卖。
师：读完第二段，你又知道了西湖的哪些事？
参考：知道是一代一代的人修起来的／知道它在杭州。
师：是的。第一段让我们知道去西湖玩得怎么样，第二段让我们知道西湖本身是怎么来的。第一段写的是“我去西湖玩了一次”，那是游记要写的内容；今天这篇习作，要介绍的是这处遗产本身：它在哪里，是什么样子，是什么时候、怎样建成的，为什么珍贵。这是审题时要记住的一条要求。去过的同学，那次经历也用得上，结尾写自己的感受时，可以选一两句放进去。

师：第二段里有“资料上说”这几个字。介绍文化遗产，内容大多来自资料。可是资料上的句子，常常又长又难懂。请看屏幕上的这一句，它是西湖资料卡上的。

〔材料〕西湖资料卡上的一句：西湖位于浙江省杭州市，自＿＿（朝代）起历经历代疏浚与修筑，逐步形成了＿＿的整体格局。

师：请同桌两人试一试：一个人照着屏幕把这句话读给对方听，听的人不看屏幕，听完说一说自己记住了什么。然后两人交换。
学生互动分享（同桌两两互读互说，约 1 分钟）
师：请说一说，听完以后你记住了什么？
参考：在杭州／就记住了西湖和杭州／后面那个什么格局没记住。
师：有同学只记住了西湖在杭州，也有同学说后半句的“格局”没记住。这样一句话读完，记住的常常只有“杭州”这样的地名。听的人其实很认真，只是这一句里难懂的词太多了。下面请大家看老师怎样把它变成自己的话。

[收起投屏，教师边说边做]
〔教师示范·把资料句变成自己的话〕第一步，读懂这一句，圈出关键的词：“杭州”“＿＿（朝代）”，还有“格局”前面的“＿＿”，这些名字和数字要照抄准确。第二步，把卡片合上，不看原句，用自己的话说一遍：“西湖在杭州。从＿＿开始，一代又一代的人挖湖里的泥，修湖上的堤，西湖就一点一点变成了今天＿＿的样子。”第三步，照着说的写下来，写的时候可以加上“资料上说”。
师：“位于”，老师说成了“在”；“疏浚”是把湖底的泥挖出来，老师就直接说“挖湖里的泥”；“逐步形成了……的整体格局”，老师说成了“一点一点变成了今天……的样子”，“格局”前面那几个字照资料保留。意思没有变，数字和名字也没有变，可是听的人一听就懂。

师：现在请大家拿出自己的资料卡，找到刚才从画了横线的长句子中选出的那一句。先读懂它，圈出里面的名字和数字；然后把卡片合上，说给前后桌听。前后桌拿的是同一张卡，他看着卡听你说，听完请判断：意思对不对，数字和名字说得准不准。
学生互动分享（前后桌两两互说互查，约 2 分钟；教师巡视，听到学生合上卡后仍一字一字背原句的，提示他“不必背原句，用平时说话的方式说”）
师：请一位同学把自己的那一句说给全班听。
学生互动分享（举手抽说一位，前后桌同学说一句“意思对、数字准”或指出哪里不对）
参考：资料上说，故宫是＿＿时候开始建的，皇帝在里面住过，一共住了＿＿个皇帝。

（教师总结）用自己的话介绍资料，可以分三步：先读懂，圈出名字和数字；再合上卡片，用自己的话说一遍；最后照着说的写下来。名字和数字要照资料写准确，一两个词用资料上原来的说法也可以，但不必整句照抄，因为读的人需要的是读得懂。

### 四、借助资料整理表，理清思路（约 8 分钟）

师：一张资料卡上，好几项内容混在一起：在哪里、什么样子、什么时候建的、为什么珍贵，有的还有一个故事。如果从头到尾照着卡上的顺序写，读的人会越读越乱。所以动笔之前，我们要先分一分：把资料卡上的内容分成几个方面，一个方面写一段。今天我们用这张资料整理表来分。

[投屏并发放空白表]

| 方面 | 资料卡上的名字和数字（照抄） | 我自己的说法（关键词） |
| --- | --- | --- |
| 开头：它在哪里、叫什么 |  |  |
| 方面：它是什么样子 |  |  |
| 方面：它是什么时候建的 |  |  |
| 方面：它为什么珍贵 |  |  |
| 方面：它有什么故事或传说 |  |  |
| 让我吃惊的一处（写进哪一段） |  |  |
| 结尾：我的感受 |  |  |

师：表格中间的四行是四个方面，请大家选出三个，在这一行前面打✓，一个方面写一段。资料卡上画了感叹号的那一处，请填进“让我吃惊的一处”这一行，再写明打算放进哪一段。老师先用莫高窟那张卡填一张，请大家看一看。

| 方面 | 资料卡上的名字和数字（照抄） | 我自己的说法（关键词） |
| --- | --- | --- |
| 开头：它在哪里、叫什么 | ＿＿（地点）、莫高窟 | 山崖上的石洞、洞里有画 |
| ✓ 方面：它是什么样子 | 保存下来的洞＿＿个 | 照片：弹琵琶、跳舞、飘在半空、带子往后飞 |
| ✓ 方面：它是什么时候建的 | ＿＿（朝代）开始凿、＿＿多年 | 一个朝代接一个朝代、没有电钻电灯 |
| ✓ 方面：它为什么珍贵 | （卡上那一句长句） | 以前的人什么样，画替他们留下来 |
| 方面：它有什么故事或传说 | （卡上有一则） | （不写） |
| 让我吃惊的一处（写进哪一段） | ＿＿多年 | 回头看照片：一个人的带子就好几道，一锤一锤、一笔一笔；写进“什么时候建的”那一段 |
| 结尾：我的感受 |  | 想走进去看、站近一点、不碰 |

师：请看老师这张表。第二列只抄名字和数字；第三列是老师合上卡片以后想到的说法，只记几个词。卡上的故事老师没有选，因为三个方面已经能把莫高窟介绍清楚了，再把故事放进来，这一篇就太长了。老师吃惊的是那个年数，所以把它放进“什么时候建的”那一段。
师：请大家用四分钟填好自己的表。第二列照着卡片抄准确，第三列要合上卡片再写；第三环节里你合上卡片说给前后桌听的那一句，可以先把关键词记在它所属的那一行。最后，选出三个方面打✓。
学生动笔写作（约 4 分钟；教师巡视，对第三列又抄了原句的学生，请他把卡翻过去扣在桌上再填）
师：填好的同学，请看着表，小声把你要介绍的那一处说给自己听一遍：先说哪个方面，再说哪个方面，让你吃惊的那一处放在哪里。哪里说不下去，就在那一行再补一两个关键词。
学生自由分享（各自小声说一遍，约 1 分钟）

### 五、出示示范文，发现写法（约 9 分钟）

师：老师照着刚才那张表，把莫高窟写成了一篇介绍。老师写的时候，把自己当作一名和大家同龄的四年级学生。请大家默读，读的时候找一句读起来眼前就有画面的句子，在下面画一条线。

> 【教师示范文】
> 一张资料卡上的莫高窟
>
> 在＿＿（地点），有一处中国的世界文化遗产，叫莫高窟。我没有去过那里，是从一张资料卡上认识它的。读完这张卡我知道了：它是开在山崖上的一个个石洞，洞里的墙上画满了画。
>
> 先说它的样子。资料卡上印着一张洞里的照片。墙上画着好多人，有的抱着琵琶在弹，有的抬起一只脚在跳舞，还有几个人没站在地上，飘在半空中，身上的带子往后飞，像被风吹起来一样。照片上的颜色有红的、蓝的、绿的，有的地方已经褪了色，看不太清了。资料卡上说，像这样画着画的洞，现在保存下来的有＿＿个。
>
> 再说它是什么时候建的。资料上说，莫高窟是从＿＿（朝代）开始凿的。后来一个朝代接着一个朝代，人们又凿了新的洞，画了新的画，前前后后一共＿＿多年。读到这个数字，我愣了一下，又去看资料卡上那张照片：光是一个飘在半空的人，身上的带子就画了好几道。那时候没有电钻，也没有电灯，洞是一锤一锤凿出来的，画是一笔一笔画上去的。我这才明白，那么多年是怎么过去的。
>
> 它为什么这么珍贵呢？资料卡上那句话很长，我读了两遍才弄明白。用我自己的话说就是：很多年以前的人长什么样、穿什么衣服、弹什么乐器，我们谁也没见过，可是墙上的画把他们留了下来，一直留到今天。
>
> 我很想有一天能走进那些洞里，看一看照片上那几个飘在半空中的人。我想站得离墙近一点，可是我不会伸手去碰它。

学生自由分享（默读示范文并画线，约 2 分钟）

师：我们先来看段落。如果把第二段和第三段换一换位置，先讲什么时候建的，再讲它的样子，读起来会不会乱？
学生互动分享（举手抽说两三位）
参考：不会乱／不会，每一段一开头就说了它讲什么／第三段开头说“再说”，换过来就要改成“先说”。
师：有同学说不会乱，因为每一段一开头就说了它讲什么；也有同学注意到，换过来以后“再说”要改成“先说”。每一段的第一句，先告诉读的人这一段要讲哪个方面。有了这一句，读的人一看到第一句，就知道下面读到的是什么，所以顺序换一换也不会乱，只是“先说”“再说”这样的词要随之调整。
师：我们再看表上“让我吃惊的一处”那一行。老师记的是“回头看照片：一个人的带子就好几道，一锤一锤、一笔一笔”。到了文章里，它们写在哪一段？扩充成了哪几句？
参考：在第三段／“读到这个数字，我愣了一下，又去看资料卡上那张照片”／“洞是一锤一锤凿出来的，画是一笔一笔画上去的”。
师：是的，都在第三段。资料卡上只有一个年数，拿到这张卡的同学都看得到；老师读到这个年数，愣了一下，又回头去看照片上那几道带子，想到每一道都要一笔一笔画出来。这几句是老师自己读的时候想到的，换一张卡就写不出来。读的人看到这里，也就明白老师为什么吃惊了。
师：最后，请说一说刚才默读时，你在哪一句下面画了线？
学生互动分享（举手抽说两三位）
参考：“有的抱着琵琶在弹，有的抬起一只脚在跳舞”／“身上的带子往后飞，像被风吹起来一样”。
师：大家找得很准。这几句先写人在做什么，再写带子怎么飘，最后打了一个比方，读的人眼前就有了画面。老师把这篇示范文里用到的写法列成了一张表，请大家看一看。

〔示范文旁批对照〕

| 示范文里的句子 | 这一句用了什么写法 |
| --- | --- |
| 先说它的样子。／再说它是什么时候建的。／它为什么这么珍贵呢？ | 一个方面一段，每段开头一句说明这一段讲哪个方面 |
| 资料上说，莫高窟是从＿＿（朝代）开始凿的 | 用“资料上说”引出资料，朝代和数字照资料写准确 |
| 读到这个数字，我愣了一下，又去看资料卡上那张照片 | 资料里让自己吃惊的一处，写出自己读到它时想到了什么 |
| 洞是一锤一锤凿出来的，画是一笔一笔画上去的 | 读懂资料以后，用自己的话说出来 |
| 有的抱着琵琶在弹……像被风吹起来一样 | 写样子：先写人在做什么，再写带子怎么飘，最后打一个比方 |
| 我想站得离墙近一点，可是我不会伸手去碰它 | 结尾的感受：用一个动作说出心里的想法 |

师：最后我们来说一说感受。介绍一处文化遗产，感受可以有三种写法。第一种，结尾只写一句“它真伟大”。这样写也可以，读的人知道你喜欢它，但不知道你为什么会这样想。第二种，像老师这样，在结尾写一两句，联系前面介绍的内容来说：老师写的是想走进去看一看那几个人，想站得近一点却不去碰它，这是因为前面写了它已经留存了那么多年。第三种，每一段都加上“真壮观”“太伟大了”“我好喜欢”，这样的句子多了，介绍的内容反而不突出了。选第一种，结尾算是写了感受；要达到第二节课评改时的优秀一档，就要用第二种。第三种里多出来的那些句子，要适当删去。

（教师总结）这一篇用到了今天学的两种写法：一个方面写一段，每段开头说明这一段讲哪个方面；资料读懂以后，名字和数字照资料写准确，其余的内容用自己的话来说。另外，还要把让自己吃惊的那一处写进去，结尾写一两句自己的感受。

师：第一节课就上到这里。请大家把资料卡和资料整理表一起收好，休息一下以后，我们就照着这张表动笔。

本课完。

## 第2课时 · 当堂写作与评改课

### 一、借助资料整理表，写下第一组句子（约 5 分钟）

师：请大家把资料整理表和资料卡放在稿纸旁边，先看表上第一行“开头”。
师：第一句就照着这一行来写：它在哪里，叫什么名字，是中国的一处世界文化遗产。这一句单独成一段。
学生动笔写作
师：请另起一段，写你打了✓的“样子”这个方面。没有选“样子”的同学，请写你表上打✓的第一个方面。先写这一段的第一句，说明这一段讲的是哪个方面。
学生动笔写作
师：写样子的同学，请看资料卡上的照片。先看整体：它是什么颜色、什么形状，写一句。
学生动笔写作
师：再凑近看一看：照片上或者资料卡上说的哪一处最特别，写一句。
学生动笔写作
师：最后想一想它像什么，打一个比方，再写一句。没有选“样子”的同学，请照着表上第三列的关键词，把这一段写出两三句。
学生动笔写作
师：开头一段，加上刚才写的这一段，你这篇介绍的前两段就写好了。接下来，请按照表上打✓的顺序，一个方面写一段，继续往下写。

### 二、自由写作（约 20 分钟）

师：接下来的时间留给大家写作。资料卡可以放在旁边，用来查名字和数字；写句子的时候，请看着表上第三列的关键词来写，一直写到结尾的感受。遇到错字、写不顺的地方，先接着往下写，写完以后我们再统一修改。
学生动笔写作（连续书写，教师巡视，不打断、不当场纠正错别字与标点）

[巡视分层指导：
① 写完开头和第一个方面以后接不下去：不要求他重新开头，请他看表上打✓的第二行，问“这一行你记了哪几个词？先把第一个词写成一句话”，写出第一句后再往下写。
② 一段里大段照着资料卡抄：请他把资料卡翻过去扣在桌上，问“这一段你想告诉同桌什么？先说给老师听一听”，学生说完，提示他照着刚才说的写；原来那几句先不擦，修改时再换。
③ 书写顺畅：不打断，经过时只看一眼每段的第一句有没有说明这一段讲哪个方面，不出声。
④ 三个方面都写了，但每段只有一句：先肯定他三个方面都写到了，再指着其中一段问“资料卡上这个方面还写了什么？同桌最想知道哪一项？”，请他在这一段再补两三句。]

[格式与错字：本篇没有格式方面的硬性要求，错别字、病句、标点全部留到第三环节处理，写作期间不指出。]

### 三、交流评议，修改收束（约 20 分钟）

师：请大家停笔。还没写完的同学，请在稿纸上记下下一段准备写哪个方面，修改的时候再补上。

[前后桌核对（约 6 分钟）]
师：我们先过第一关。请前后桌交换稿子，前后桌两人拿的是同一张卡。读对方稿子的时候，请把资料卡放在旁边，做两件事：第一，把稿子里的名字和数字逐个和卡上对一对，不一样的画一个圈；第二，如果有一句话和卡上一字不差，就在这一句下面画一条横线。读完以后，把稿子还给作者。
学生互动分享（前后桌交换默读、标画，约 5 分钟；教师巡视，提醒学生对照资料卡逐个核对数字，不要粗略看过）

[对照三档，先判断再改（约 3 分钟）]
师：请大家拿回自己的稿子。修改之前，请先看这三档标准，想一想自己的稿子现在在哪一档，还差哪一条。
〔三档标准〕
基础一档：介绍了一处文化遗产在哪里、是什么，语句通顺。
良好一档：分两三个方面介绍，一个方面一段；大部分句子是自己的话，名字和数字与资料卡一致。
优秀一档：三个方面条理清楚，每段开头说明讲哪个方面；资料用自己的话说明白了，没有这张卡的人也读得懂；写进了一处让自己吃惊的地方；结尾有一两句联系前面介绍说出的感受。
师：再请大家看前后桌画的横线。画了横线的那一句，抄的是资料上的原话，这句话本身没有写错；需要判断的是，同桌手里没有这张卡，他能读懂吗？能读懂的，可以保留，在前面加上“资料上说”；读不懂的，就按照第一节课学的三步，换成自己的话：先读懂，圈出名字和数字；再合上卡片说一遍；最后照着说的写下来。

[自改（约 6 分钟）]
师：请大家修改三处。第一处，画了圈的名字和数字，对着资料卡改正。第二处，画了横线、你判断同桌读不懂的那一句，把卡片合上，用自己的话重新写。第三处，按照你刚才对照三档找出的那一条来改：段落没有分开的，一个方面另起一段；资料卡上画了感叹号的那一处还没写进去的，补进表上定好的那一段；结尾没有写感受的，补上一两句；每一段都写了“真伟大”“真壮观”的，只留下最想说的那一句。改完以后，请用修改符号把稿子整理一遍：多余的字圈掉，漏的字补上，错的字改正。
学生动笔写作（自改，约 5 分钟；教师巡视，优先看第一处、第二处有没有落实）
师：请一位同学把修改前和修改后的那一句都读一遍。
学生互动分享（举手抽说一位，读改前、改后两句；教师请一位拿另一处资料卡的同学说哪一句听得懂、为什么）
参考：第二句听得懂，第一句有个词我不知道什么意思／第二句说的是平常的话。

〔应答·学生整篇写成了去那里玩的经过〕先肯定他写得生动，再请他拿出资料整理表，问“同桌读完，能说出它为什么是世界文化遗产吗？”；请他在玩的经过前面补一段，写表上打✓的一个方面，原来写的那次经历选一两句留到结尾作感受。

[第二关，收尾（约 5 分钟）]
师：现在我们过第二关。请同桌交换稿子。同桌两人手里的卡不一样，这一次，你就是那个没有卡的读者。请默读同桌的介绍，读完告诉他两件事：这处遗产在哪里；还有一件你原来不知道的事是什么。
学生互动分享（同桌交换默读，各说两件事，约 4 分钟）
师：请两位读者说一说，你从同桌的稿子里知道了什么？
学生互动分享（举手抽说两位读者，各说一句）
参考：我知道了兵马俑是＿＿年被发现的／我知道了苏州园林最早是＿＿（朝代）的人修的。
师：一位读者从同桌的稿子里知道了兵马俑是哪一年被发现的，一位读者知道了苏州园林最早是哪个朝代的人修的，这些都是他们手里那张卡上没有的。同桌没能说出来的那一项，请作者在稿纸上记下来，看一看是哪一段还没写清楚。请把资料卡夹在自己的稿子里，一起收好。

本课完。

## 附：习作讲评指导环节（可选 · 单次课课后用 / 系列课作下次课开场用）

> 本环节供教师灵活选用：可在单次课课后使用，也可作为系列课下一次课的开场（约 15–20 分钟），不计入两节课的 45＋45 分钟。
> 凡下文“＿＿＿”处，务必换成本班学生当堂完成的真实习作里的句子，不得虚构。

### 选稿（课前准备）

从当堂完成的稿子里选三篇，投屏时不显示姓名，三篇最好写的不是同一处：
- 一篇好的：三个方面分段清楚，每段开头说明讲哪个方面；有一两句资料是用自己的话说的，读的人没有卡也读得懂；写进了一处读资料时让自己吃惊的地方。
- 一篇中等的：方面分清了，但有一段大部分照着资料卡抄，读起来很难懂。
- 一篇待改进的：几项内容混在一段里写，或者写成了去那里玩的经过。

### 讲评流程（每篇约 3–5 分钟，围绕本课技法点）

师：下面我们一起来看三篇同学的习作。看的时候，请大家注意三点：一是有没有做到一个方面写一段，每段开头有没有说明这一段讲哪个方面；二是资料有没有用自己的话说清楚；三是有没有写进一处让自己吃惊的地方。

师：先看第一篇。请大家听这一段：“＿＿＿”（读该生用自己的话转述资料写得最清楚的一段）。手里没有这张卡的同学，听完以后，你知道了什么？
学生互动分享
师：请看这一句：“＿＿＿”（读该生读懂资料以后、用自己的话说出来的那一句）。这一句的意思资料卡上有，作者把它换成了平常说的话，没有卡的同学一听就懂。这一篇每一段的开头都说明了这一段讲哪个方面，读起来很清楚。
师：再听这一句：“＿＿＿”（读该生写自己读资料时吃惊的那一句）。资料卡上只写了那个数字或那件事，作者读到它时想到了什么，是他自己写出来的，换一个人就写不出这一句。

师：再看第二篇。这一篇方面分得很清楚，像“＿＿＿”（读该生说明方面的段首句）这样的句子，每一段都有。请大家再听这一句：“＿＿＿”（读该生照抄资料、难懂的那一句）。没有这张卡的同学，这一句你听懂了吗？
学生互动分享
师：这一句里的“＿＿＿”（读其中难懂的词），作者可以先把它读懂，再合上卡片说一遍。请大家帮他想一想，可以怎么说？
学生互动分享
（教师总结）名字和数字保留，难懂的词换成平常说的话，这一句大家就能读懂了。

师：最后看第三篇。请大家听这一段：“＿＿＿”（读该生几项内容混在一起，或写成游玩经过的一段）。这一段里写了好几项内容。请大家帮作者分一分：哪几句是写样子的，哪几句是写什么时候建的？
学生互动分享
（教师总结）分开以后，一个方面放一段，每段开头先用一句话说明这一段讲什么，这一篇就有条理了。

### 收尾（点回技法、引向今后的写作）

师：把这三篇放在一起看，介绍得清楚的那一篇，做到了三点：一个方面写一段，每段开头先说明讲哪个方面；资料读懂以后，用自己的话来写，名字和数字照资料写准确；还写进了一处读资料时让自己吃惊的地方。以后用资料介绍别的事物，比如介绍一种动物、一项发明，也可以先分方面，再合上资料，用自己的话来写。

本环节完。

热身动作: 各竖列先在两处里举手选定＋只看资料卡照片一分钟、举手说最想再多看一眼的一处＋默读资料卡，读不懂的词与长句画横线、最让自己吃惊的一处画感叹号（只画一处），前后桌（同卡）对词并互看感叹号画在哪＋抽两位说为什么吃惊（图组类·看照片；避开四上最近两篇的演练类）
主反馈游戏: 前后桌同卡核对（官方「核对资料准确」的当堂化：对卡把不一样的名字数字画圈、与卡上一字不差的句子画横线，横线驱动自改第二处）
第二层反馈: 第二关·同桌（异卡、第 1 节未听过其介绍）交换整篇默读，各说「在哪儿＋一样原来不知道的事」（官方「了解清楚了吗」）＋请两位读者当众说
开场钩子: 任务揭幕式·尝试者（先请学生报出知道的世界文化遗产、追问长城何时修为何珍贵说不准，再亮出五张资料卡，说明莫高窟那张老师已先拿来试写了一篇，随即交代发卡方式、读者与两关成败标准；单元交代后置）
主技法: 把资料卡上的内容分成几个方面、挑三个方面一个方面一段、段首一句说明讲哪个方面＋读懂一句资料后合上卡片用自己的话写、名字数字照资料写准（三步：圈名字数字→合上卡说一遍→照说的写）＋在资料里找一处让自己吃惊的地方写进相应那一段（防同卡同稿；2026-10-04 张祖庆视角审后加）；辅：结尾一两句跟着前面介绍说出的感受（三档：一句空泛的／一两句跟着介绍说的／每段都喊伟大壮观）
审题辨析形态: 两段对照判断（同写杭州西湖：反例是一段生动的游玩经过——划船、风、柳枝、藕粉，有画面有感受；错在写的是「我去玩了一次」、读完说不出它为什么是世界文化遗产；正例是一段介绍——在哪儿、一代代人修起来、为什么珍贵。判据落在「没去过的人读完能不能说出这处遗产本身」，由选反例的学生自己说它好在哪，教师承认生动，并把游玩经历回收为结尾感受的素材）
技法引出装置: 同桌照念资料长句→听者复述只记住地名（体验在前）→教师收起投屏当场三步示范把西湖资料句变成自己的话（〔教师示范〕）→逐词对照「位于→在／疏浚→挖湖里的泥／逐步形成→一点一点变成」→学生拿自己卡上画横线的长句里选定的那一句合上卡说给同卡前后桌、对方对卡判意思对不对数字准不准（产出记进⑤表第三列）→抽一位→教师总结三步
示范文题材: 资料与知识介绍·同龄「我」凭一张资料卡写一处没去过的遗产（莫高窟：照片上的弹琵琶、跳舞、飘在半空的人；读到年数愣了一下、回头看照片上一个人的带子就画了好几道、一锤一锤一笔一笔；客观数据全部按资料卡填；非旅行见闻、非小区家庭日常）
互动组织: ①全班举手抽说四五位＋追问一位／②各竖列举手选处＋各自看照片＋举手抽说两三位＋默读标画（横线／感叹号）＋前后桌（同卡）对词互看感叹号＋举手抽说两位／③各自默读举手判断＋请选反例者说好处＋同桌互念资料句听者复述＋前后桌（同卡）合卡互说互查＋举手抽说一位／⑤教师示范填＋各自填表＋自说自听一遍／④默读并画画面句＋举手抽说换段位置乱不乱＋转化问吃惊行与第三列＋举手抽说画线句／⑦前后桌（同卡）交换核对画圈画横线＋各自对照三档自判＋自改三处＋抽一位读改前改后、异卡听者判哪句听得懂＋同桌（异卡）交换整篇默读各说两样＋抽两位读者当众说（全课只用前后桌同卡、同桌异卡两套搭档）
