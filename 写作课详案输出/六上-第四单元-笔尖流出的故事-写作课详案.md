# 《笔尖流出的故事》· 写作课教学设计
六年级上册·第四单元 校内同步写作（虚构故事习作）

## 教案提纲表

| 课题·课时 | 六上·第四单元《笔尖流出的故事》　│　想象·校内同步　│　2课时连排（每节45分钟） |
| --- | --- |
| 能力阶段 | 写清楚 → 写具体 → 写生动 → 写深刻·有章法（本课） |
| 同类习作顺序 | 想象：续写故事／编童话 → 奇妙的想象／这样想象真有趣 → 我和＿＿过一天 → 奇思妙想 → 故事新编／二十年后的家乡 → 神奇探险 → 变形记／笔尖流出的故事（本课） → 插上科学翅膀 |
| 教材要求 | 统编六上·第四单元习作：据环境与人物，创编完整故事。 |
| 学习目标 | 通过给人物设一个麻烦、再让事情转一个弯，来学习怎么写一个虚构的生活故事。 |
| 核心技法 | 使用“故事构思表”。先定下主要人物想做成什么，给他设一个麻烦，让事情在关键处转一个弯，把人物怎么应对的过程展开写；转弯前后写一句人物心里的话，环境选一处跟着故事写。 |

## 第1课时 · 写作指导课

### 一、创设情境，明确任务（约 5 分钟）

[投屏出示教材习作页上的三组环境与人物，三行并列，不加任何标题。]

〔材料〕投屏三组：第一组，开满丁香花的校园；淘气包张明、雷厉风行的班长王寒冰、充满活力的年轻班主任李军。第二组，冬日黄昏时车来人往的街头；充满爱心的少年陆天、志愿者徐明。第三组，月光下的村庄；铁蛋、铁蛋远道而来的表哥。

师：请大家先看投屏上这三组文字。每一组都是一个地方，加上两三个人。这三组人现在都好好的，什么事也没有。现在请大家判断一下：如果今天必须让其中一组人遇上一件麻烦事，你会选哪一组？请举手表态，选第一组的举手，选第二组的举手，选第三组的举手。

学生举手表态

师：请几位同学说一说，你为什么选这一组？你觉得他们会遇上什么麻烦？

学生互动分享

参考：选第一组，淘气包和班长肯定要闹矛盾／选第三组，村里晚上黑，表哥是城里来的，会出事／第二组，街上人多，可能有人走丢了。

师：很好，三组都有人选，理由也各不相同。这三组人物和环境，就印在大家的语文书这个单元的习作页上，题目叫“笔尖流出的故事”。这个单元学的是小说，读的是别人编的故事；今天轮到大家自己来编一个。

师：先说清楚今天写出来的故事给谁看。这篇故事不是写完交给老师就算完成了，它要读给人听：第二节课写完以后，三人一组，每个人把自己的故事读给组里另外两位听，读到最要紧的地方停一停，让他们猜一猜后面会怎样。他们猜不到，说明你的故事立住了；他们猜到了，还要请他们再说一句：是你前面的铺垫让人跟得上，还是事情根本没有转弯。前一种也是一种本领，后一种就要回去补。所以今天写故事，心里要装着两位读者。

师：教材给了三组，可以从中选一组，也可以自己另设一个地方、几个人物。选哪一组，等一下看完两段话再定。

### 二、观察体验，站进环境里说三项（约 8 分钟）

[投屏只留三个环境短语：开满丁香花的校园、冬日黄昏时车来人往的街头、月光下的村庄。人物名暂时收起。]

师：故事发生在一个地方，写故事的人要先站进那个地方去。现在两人一组，同桌配合：一位读出其中一个环境，另一位听完立刻说出站在那里能看见的一样东西、能听见的一种声音、身上能感觉到的一种感觉，三项一口气说完，想的时间不超过五秒。说完换过来，换另一个环境。三个环境轮一遍。

学生互动分享（同桌两两互说）

师：请几位同学把刚才说得最准的一组三项说给大家听。先说第二个环境，冬日黄昏的街头。

学生互动分享

参考：看见路灯一盏一盏亮起来／听见公交车关门的声音／风刮在脸上，脸是木的／看见呼出来的白气／听见自行车铃。

师：很好，“脸是木的”“呼出来的白气”，这两项一说，冬天的感觉就出来了。再请两位同学说月光下的村庄。

学生互动分享

参考：看见月亮把路照得白白的／听见狗叫，一声接一声／脚底下的土路是硬的，有点凉／听见青蛙叫。

师：对，月光把路照得发白，狗叫，蛙叫，凉的土路，这些都是月光下的村庄才有的。现在老师加一个条件：同样是这条冬日黄昏的街，如果陆天正在找一个走丢的小孩，他看见的还是路灯和白气吗？

学生互动分享

参考：他会看每个人的脸／他听不见铃声了，只盯着人／他会觉得路灯太暗，什么都看不清。

师：是的。人一有了心事，同一个地方在他眼里就变了样子。刚才说的那些看见的、听见的，请大家记在心里，等一下填构思表的时候，环境那一格就从这里面选。

### 三、学写法：设置冲突，写出转折（约 15 分钟）

师：这次习作要写什么，动笔之前先要看清楚。投屏上有 A、B 两段，都是老师写的，用的都是第一组的人物。请大家默读一遍，然后判断：哪一段读完，你看见的是一个故事，而不只是一幅画面。

〔材料〕A段：丁香花开了，一串一串挂在教学楼前，风一吹，香味顺着走廊飘进教室。张明趴在窗台上数花，数到第三十七串就乱了。王寒冰抱着作业本从他身后走过，脚步又快又重，鞋跟敲得地砖当当响。李老师站在花树底下，正仰着头打电话，笑得肩膀一抖一抖的。

〔材料〕B段：那张纸条是从王寒冰的本子里滑出来的，张明捡起来，捏在手心里，捏了整整一节课。上面写着三个名字，都是今天早读迟到的，第一个就是他。放学铃一响，王寒冰抱着本子往办公室走，他隔着五步跟在后面。丁香树下，李老师正好迎面走来。张明把手伸进口袋，又抽了出来。

学生互动分享

参考：B段／A段，A段环境和人都写出来了，三个人都有。

〔应答·有学生选 A 段〕先肯定：A 段的环境写得实，丁香的香味、鞋跟敲地砖、笑得肩膀抖，三个人各有各的样子，这一段用来写“校园一角”是合格的。再追问：请该生往下想一想，A 段读完，这三个人接下来要做什么？谁想做成一件事？有没有一件事做不成？学生答不出，就说明这一段里没有“事”，只有“人”和“景”。

师：请选 B 段的同学说一说，你在 B 段里看见了什么事？

学生互动分享

参考：张明捡到了记迟到的纸条，他自己也在上面／他想把纸条藏起来／他不知道该不该还给王寒冰。

师：对。B 段里有一个人想做一件事，又拿不定主意，前面还站着李老师。读到最后一句，手伸进口袋又抽出来，大家会想知道他到底还不还。A 段呢，环境写得实，人物也有样子，可是没有一件事在等着发生。这就是今天这篇习作的要求：写一个故事，要围绕你选的那个主要人物，写清楚他们之间发生了什么，有起因，有经过，有结果。光有地方、光有人，不算故事。

师：那么，怎么才能让一个故事有事发生，而且发生得让人想往下读？老师再给大家一个故事，用第二组的人物，很完整，也很顺。请听：

〔材料〕投屏梗概：冬日黄昏，街头车来人往。陆天放学路过，看见志愿者徐明在路口发传单，就帮他一起发。天黑透了，传单发完了，两个人道了别，各自回家。

师：这个故事有起因、有经过、有结果，一句也没漏。可是读完，大家想不想知道后面怎么样了？

学生互动分享

参考：不想，因为已经完了／太顺了，没什么好猜的。

师：是的，太顺了。现在请每个人往这个梗概里加一句话，这句话必须用“偏偏”开头。加在哪里都可以。想好的同学请举手说。

学生互动分享

参考：偏偏最后一张传单被风卷到了马路中间／偏偏有个老奶奶拿了传单，说上面找的人她认识／偏偏陆天发现传单上找的走失老人，就是刚才跟他问过路的那位。

师：很好。“偏偏”一加，事情就不顺了，人物就要做点什么。小说里把这个叫作冲突，说得直接一点，就是给人物设一个麻烦。这个单元的《桥》，全篇就是这么写的：山洪来了，老汉守在桥头指挥全村人过桥，洪水一步一步逼上来，一路都是麻烦，读的人一路替他捏着一把汗。

师：有了麻烦，接下来要写的就是人物怎么应对。请看陆天追传单这一处，老师用两种写法各写了一遍：

〔教师示范·一句带过〕陆天跑过去，把传单捡了回来。

〔教师示范·展开写〕陆天往马路中间跑了两步，一辆车按着喇叭从他左边擦过去，他停住，又往前挪了半步。传单贴在地上，被车轮碾过一道印子。他弯腰去够，指尖刚碰到纸角，身后有人一把拽住了他的书包带。

师：第一种写法是可以的，事情交代清楚了，传单捡回来了。第二种把这件事拆开来写，请大家比一比，读第二种的时候，你的心是不是跟着陆天一起悬了一下？

学生互动分享

参考：第二种看着着急／第二种有车擦过去，更危险／第二种最后不知道是谁拽住了他。

师：对，最后那一句，有人拽住了他的书包带。事情到这里转了一个弯：陆天本来是去捡传单，现在有人把他拉住了，后面的事就往另一个方向走了。这个弯，小说里叫转折。麻烦是让人物有事做，转折是让读的人猜不到。《桥》的结尾就是一个大转折，读到最后一段，才交代出人物之间的关系，前面读过的每一句，回头再看都变了味道。

师：有的同学会问，两种写法能不能搭配着用？当然可以。小麻烦一句带过，最要紧的那一个麻烦展开来写，什么地方展开、什么地方带过，由写故事的人自己定。

师：再看刚才展开写的那一段。陆天为什么非要去捡那张传单？他心里那句话是什么？

学生互动分享

参考：那是最后一张／他怕徐明白跑一趟／捡回来今天就算做完了。

师：对。麻烦来了以后，最值得写的就是人物心里在想什么。刚才展开写的那一段里，如果加一句“他心里只有一个念头：那是最后一张”，陆天为什么非要去捡，读的人就明白了。这个单元的《穷人》，最突出的就是这一点，桑娜做了一个决定以后，作者用很长一段写她心里翻来覆去地想；屋外是风雨，屋里是暖的，环境也在跟着人物走。

师：请一位同学把今天学的写法说一遍：写一个故事，要做到哪几件事？

学生互动分享

参考：给人物一个麻烦，然后转一个弯／麻烦的地方要展开写，写他怎么做的／写他心里怎么想。

（教师总结）写法就是这三件：设一个麻烦，转一个弯，麻烦到转弯之间写人物怎么应对、心里怎么想。环境跟着故事走，选一处写。《桥》从头到尾在设麻烦，结尾转了一个大弯；今天大家写的故事，走的是同一条路，只是把山洪换成了自己选的那一组人和那一个地方。

### 四、借助故事构思表，理清思路（约 9 分钟）

[发学习单。学习单上印有“故事构思表”空白版与写稿用的横线格。投屏同步出示表头。]

师：请拿出学习单，看“故事构思表”。这张表填的是词，不是句子。前六格是故事的骨架，必填；后两格各写几个词即可。表上的格子顺序不一定就是你写的顺序，格子也可以合并，你如果习惯列一串关键词而不填表，也可以，但“遇上的麻烦”和“事情在哪里转弯”这两格必须有。

| 项目 | 关键词 |
| --- | --- |
| 选定的一组（人物·环境） | |
| 主要人物想做成什么 | |
| 遇上的麻烦 | |
| 事情在哪里转弯 | |
| 人物怎么应对 | |
| 结果 | |
| 环境选一处写 |  |
| 心里话放在哪一步 | |

师：老师先填一张，用第三组的人物。请看投屏。

| 项目 | 关键词 |
| --- | --- |
| 选定的一组（人物·环境） | 月光下的村庄·铁蛋、表哥 |
| 主要人物想做成什么 | 带表哥捉泥鳅，让他看看自己行 |
| 遇上的麻烦 | 手电筒掉进水里，田里全黑 |
| 事情在哪里转弯 | 岸上的表哥打开了手机的灯 |
| 人物怎么应对 | 黑里用手摸；顺着光找到手电 |
| 结果 | 捉了七条；桶换到靠表哥那只手 |
| 环境选一处写 | 月光照田埂发白、蛙叫；光没了只剩月亮 |
| 心里话放在哪一步 | 表哥刚到时；表哥往后退时；手电掉了以后 |

师：请大家看第三格和第四格。麻烦是手电掉了，转弯是表哥打开了手机的灯。这两格一填，故事的中间就有了。第二格“想做成什么”也很要紧，铁蛋想让表哥看到自己能行，正因为他想做成这件事，手电掉了才算得上麻烦。现在请大家填自己的表。先定第一格选哪一组，然后直接填第三格和第四格，最后回头填其余的。五分钟。

学生动笔填表

[巡视。第三格空着的，问一句“你这个人物最想做成什么？做这件事的时候，什么东西最可能出岔子？”；第四格空着的，问一句“麻烦出了以后，谁来了、什么东西亮了、什么话说出口了，事情就不一样了？”。填得快的，请该生给第五格再添两个词。]

师：请两位同学说一说自己的第三格和第四格，大家一起判断：这个弯有没有转成。

学生互动分享

参考：第一组，张明和王寒冰。麻烦是张明把班长的名单撕了，转弯是王寒冰自己也迟到了／第三组，麻烦是表哥掉进水沟，转弯是铁蛋背不动他，一头牛过来了。

〔应答·报出的“转弯”只是麻烦的延续〕如学生说“麻烦是手电掉了，转弯是他又掉了一只鞋”，请该生判断：这一句是事情变了方向，还是麻烦又多了一个？再多一个麻烦不叫转折，转折要让事情往另一个方向走。请该生再想一个。

师：很好。表填到这里，每个人手里都有了一个人物、一个麻烦和一个弯。接下来看老师怎么把那张表写成一个故事。

### 五、出示示范文，发现写法（约 8 分钟）

师：请看投屏，这是老师照着刚才那张表写的故事。请大家默读一遍，读的时候带一个任务：找出事情出岔子的那一句，和事情转弯的那一句。

> 【教师示范文】月亮底下
>
> 表哥是傍晚到的。他拖着一只带轮子的箱子，轮子在村里的土路上一路跳。铁蛋站在门口看着，没去接。妈妈说过，表哥在城里念书，什么都懂。铁蛋想，什么都懂，那也不会捉泥鳅。
>
> 吃过晚饭，月亮上来了。铁蛋拎起桶，把手电筒往裤兜里一插，冲屋里喊：“去不去？捉泥鳅。”表哥出来了，脚上还是那双白球鞋。
>
> 田埂被月光照得发白，两边的水田黑黢黢的，蛙叫得一阵一阵。铁蛋走得快，表哥在后面深一脚浅一脚。到了地方，铁蛋把裤腿一卷就下了水，泥凉凉的，从脚趾缝里挤上来。他回头，表哥站在田埂上没动。“下来啊。”“这里面……有什么？”“泥鳅。”铁蛋把手电往水里一照，一条泥鳅正贴着泥往前钻，他一伸手，捏住了，往桶里一甩。表哥往后退了半步。铁蛋心里说，果然。
>
> 第三条泥鳅是在田角上照见的。铁蛋追过去，脚下一滑，手电筒脱了手，扑通一声掉进水里。光没了。田里一下子黑得什么都看不见，只剩月亮在头顶上，照不到水底。铁蛋在泥里摸，摸到的全是软的、滑的。他不敢说话。要是空着手回去，明天妈妈准会问，表哥也在旁边看着。
>
> 田埂上忽然亮了一下。表哥蹲下来，把手机的灯打开，往水里照。“往左边一点。”他说。铁蛋顺着光摸过去，指头碰到一个硬的、凉的东西，是手电筒的铁壳。他把它捞上来，甩了甩水，按开关，没反应。表哥没说话，只是把手机举得更低了些，光正好铺在铁蛋面前那片水上。
>
> 那天晚上他们一共捉了七条。回去的路上，桶换到了铁蛋另一只手上，靠表哥的那一边。表哥的白球鞋上全是泥点子，他自己没看，铁蛋看见了。

师：先看骨架。铁蛋想做成什么？

学生互动分享

参考：带表哥去捉泥鳅／想让表哥看看他厉害。

师：对。事情在哪一句出了岔子？

学生互动分享

参考：手电筒掉进水里那一句／“光没了”。

师：是的，手电筒脱了手，光没了，麻烦就在这一句。事情又在哪一句转了弯？

学生互动分享

参考：表哥打开手机的灯／“田埂上忽然亮了一下”。

师：对，田埂上忽然亮了一下。前面表哥一直站在岸上没动，铁蛋心里说“果然”，到这一句，站在岸上的人反过来帮了下水的人，事情就往另一个方向走了。再看句子。请大家找一找，哪一句是铁蛋心里的话？

学生互动分享

参考：“什么都懂，那也不会捉泥鳅”／“果然”／“要是空着手回去，明天妈妈准会问”。

师：很好，三处都找到了。请注意，铁蛋心里的话，一次都没写“我讨厌表哥”“我很着急”这样的话，写的是他心里在盘算什么。再看环境：月光下的村庄，哪几句写出来了？

学生互动分享

参考：田埂被月光照得发白／蛙叫得一阵一阵／只剩月亮在头顶上，照不到水底。

师：对。请大家注意最后那一句，麻烦一来，同样的月亮，前面是把田埂照得发白，现在变成了照不到水底。环境跟着麻烦变了。老师把这几处列成一张表，一共七处，大家对照着看。

| 示范文里的句子 | 这一句用的写法 |
| --- | --- |
| 田埂被月光照得发白，两边的水田黑黢黢的，蛙叫得一阵一阵。 | 环境：先把月光下的村庄写出来 |
| 铁蛋想，什么都懂，那也不会捉泥鳅。 | 心里话：人物一出场就有了自己的想法 |
| 手电筒脱了手，扑通一声掉进水里。光没了。 | 麻烦：事情在这一句出了岔子 |
| 田里一下子黑得什么都看不见，只剩月亮在头顶上，照不到水底。 | 环境：麻烦来了，环境跟着变 |
| 他不敢说话。要是空着手回去，明天妈妈准会问，表哥也在旁边看着。 | 心里话：麻烦来了以后人物在盘算什么 |
| 田埂上忽然亮了一下。表哥蹲下来，把手机的灯打开，往水里照。 | 转折：事情在这一句转了弯 |
| 回去的路上，桶换到了铁蛋另一只手上，靠表哥的那一边。 | 结果：不说心情，用一个动作收尾 |

师：最后看结尾。老师没有写“铁蛋从此喜欢上了表哥”，只写了桶换了一只手，换到靠表哥那一边。大家读到这一句，知道铁蛋心里变了吗？

学生互动分享

参考：知道／他不想让表哥再拎重的／他不嫌表哥没用了。

师：是的。故事的结尾，可以直接说人物变了，也可以像这样让一个动作替他说。两种都可以，看你自己的故事写到哪一步更顺手。这张表和这篇故事请大家留着，第二节课动笔的时候，遇到不知道该往哪里写，就回来看一眼第三格和第四格。休息一下，回来就写。

本课完。

## 第2课时 · 当堂写作与评改课

### 一、借助故事构思表，定下从哪里起笔（约 3 分钟）

师：请把第一节课填的故事构思表摆在稿纸旁边，先看第三格“遇上的麻烦”和第四格“事情在哪里转弯”。今天写故事，不一定从第一句开头写起。老师给三个起笔的地方，请大家自己定：一是从麻烦发生的那一刻写起，先把出岔子的那几句写出来；二是从人物想做那件事写起，先写他为什么非做不可；三是从转弯那一句写起，先把最让读的人猜不到的那一段写出来。哪一处你最有话说、最该写得厚，就从哪一处起笔。请在那一格旁边标一个“1”。

学生各自判断，在构思表上标“1”

师：请两位同学说一说，你先写哪一格，为什么？

学生互动分享

参考：我先写麻烦那一格，因为表哥掉水沟那一段我想好了／先写转弯，一头牛过来那一下我怕等会儿忘了。

师：好。标了“1”的同学，请就从这一处落笔，把这一处写出来，写三句以上。

学生动笔写作

师：写下的这一段，多半落在故事的中间。写完它，再回头补前面：人物是谁、想做什么，然后往后接：转弯以后事情怎么走，结果怎样。整篇写下去，五六百字。

### 二、自由写作（约 26 分钟）

师：现在往下写。写的时候记住：麻烦到转弯之间，写人物怎么做的；转弯前后，给他一句心里的话；环境选一处写，最好跟着麻烦变一变。故事写成什么样都可以，不一定非要有一个圆满的结尾，也不一定非要写出一个道理，围绕你的人物把事情写完整即可。写的时候不改错字，不回头看，一口气写到结尾。

学生动笔写作

[巡视，只看不改，不指出错别字、不改病句、不打断。按四类情形介入，每类一句话：]

[接不下去：指着该生的构思表问“你表上还有哪两格没写进去？哪一格接在这一段后面最顺？”只问顺序，不替学生想内容。]

[内容空泛：指着该生写麻烦的那一句问“这个麻烦出来以后，他手上第一个动作是什么？”让该生在那一句后面添两句动作。]

[书写顺畅：不打断，不站在旁边看。]

[草草收尾：先肯定该生写得具体的那一处，再问“转弯以后事情往哪里走了？还差结果那一格没写进去。”请该生续写。]

[写到二十分钟时提示一次：还有六分钟，没写到结果的同学，请先把转弯以后的事写完，前面的开头可以短一些。]

### 三、交流评议，修改收束（约 16 分钟）

师：请停笔。三人一组，每组按座位就近组合。现在开故事会，每人两分钟：读自己的故事，从麻烦发生那一句读起，读到转弯前一句停下，先不往下读。另外两位各说一句，猜后面会怎样。猜完，作者再把转弯那一段读出来。然后请一位听的人说一句：读到哪一处，你最想知道后来怎样。轮流来，一人读完换下一位。

[组织：三人一组，就近组合，多出的两位学生并入邻组。教师巡视各组，听两位学生读到转弯前的那一处停顿，记下两位转弯没被猜中的作者，留作全班点评。三人轮完约六分钟。]

学生互动分享（三人小组轮读）

师：没被猜中的同学，说明转弯转得住。被猜中的同学，请组里两位听的人再说一句：是前面的铺垫让人跟得上，还是事情根本没有转弯。前一种同样是故事写到位的表现，后一种等一下改的时候先补。现在把稿子在组里顺时针传给下一位。读对方的稿子，找到人物心里的话那一句，在句末写一个“心”字；如果通篇没找到，就在你觉得最该有一句心里话的地方写一个“心”字。找完把稿子传回作者。

学生互动分享（组内换稿标注）

师：稿子拿回来了，请对照学习单上的自评表看一看自己这一篇。

| 档位 | 自检要点 |
| --- | --- |
| 我做到了 | 故事围绕我选的那个人物，有开头有结果；他遇上了一个麻烦，事情转了一次弯。 |
| 我做得更好 | 麻烦到转弯之间写了人物怎么做的，三句以上；有一句人物心里的话；环境写了一处。 |
| 我还能加 | 转弯前后各有一句心里的话；环境跟着麻烦变了样子；结尾用一个动作收住。 |

师：看完自评表，改两处。刚才被判“没有转弯”的同学，第一处先补转弯：在麻烦后面加一句让事情换方向的话。其余同学的第一处，看同学在你稿上写“心”字的地方：已经有心里话的地方，看一看能不能再添半句他在盘算什么；还没有的地方，补一句。第二处，看麻烦到转弯之间，你是不是一句就带过去了。带过去了的，把人物手上的动作拆开来添两三句。改的时候用修改符号：多的字圈掉，漏的字补上，错的字改正，不重抄。

学生动笔修改

[约四分钟。巡视，遇到把心里话直接写成“我很着急”的，问一句“他着急的时候在盘算什么？把盘算的那句写下来”。]

师：请刚才组里没被猜中的一位同学，把你转弯那一句读给全班听。

学生互动分享

〔应答·轻点评〕就该生读的那一句说清楚它为什么让人猜不到：前面铺垫的是什么，这一句往哪个方向走了。再指出一处可改的：麻烦到转弯之间他的动作有没有拆开写。只就具体的那一句予以肯定，不评整篇。

师：今天每个人的故事都有了两位读者，也都在最要紧的地方被人猜过一次。这就是写故事的人和读故事的人之间的事：你设的麻烦，他替你着急；你转的弯，他猜不到。这个单元读《桥》《穷人》的时候，大家是读的人；今天大家是写的人，写的和读的，做的是同一件事。请把稿子和构思表一起收进学习单里。

本课完。

全课完。

## 附：习作讲评指导环节（可选 · 单次课课后用 / 系列课作下次课开场用）

> 本环节为可选取用的深度讲评模块，单次课可在课后另找时间使用，系列课可作为下一次课的开场（约 15–20 分钟）；不计入两节课的 45＋45 分钟。它评的是当堂已经写完的故事，不构成课后写作任务。
>
> 凡 `＿＿＿` 处，务必换成本班学生习作里的真实句子，不使用本稿示范文里的句子代替。

### 选稿（课前准备）

从当堂完成的故事里挑三篇：一篇“转弯转得住”的（麻烦到转弯之间写了人物怎么做的，转弯让读的人猜不到），一篇“有麻烦但转弯一句带过”的（麻烦设得好，转弯只用一句交代），一篇“麻烦和转弯分不清”的（后面那一件只是前一件麻烦的延续，事情没有换方向）。各篇用一句话对照本课写法点明好在哪里、欠在哪里。讲评时投屏该篇的相关段落，不署名，先征得作者同意。

### 讲评流程（每篇约 3–5 分钟，围绕本课技法点）

师：这次讲评只看一点：故事里的麻烦和转弯。麻烦设得成不成，转弯转得住不住，麻烦到转弯之间人物做了什么。其他的先不看。

师：先看第一篇。老师读这一段：“＿＿＿”（读该篇从麻烦发生到转弯出现的那几句）。麻烦是＿＿＿（说出该篇人物遇上的麻烦），到了“＿＿＿”（读转弯那一句）这里，事情往另一个方向去了。请大家说一说，读到转弯那一句之前，你猜到了吗？

学生互动分享

（教师总结）这一篇转弯转得住，原因在于前面写的是＿＿＿（说出该篇转弯前铺垫的内容），读的人顺着这个方向猜，作者却把事情带到了另一个方向。

师：第二篇，麻烦设得好：“＿＿＿”（读该篇写麻烦的那一句）。请大家找一找，从麻烦到转弯，中间隔了几句？

学生互动分享

师：是的，只有一句。作者写的是“＿＿＿”（读该篇一句带过的那一处）。如果把人物这时候手上的动作拆开来写两三句，读的人的心就会跟着悬起来。请这位作者说一说，你的人物在这一处先做了什么，再做了什么？

学生互动分享

（教师总结）麻烦之后、转弯之前，是整篇故事最该写厚的地方，人物怎么应对，就写在这里。

师：第三篇，不说是谁写的。请听：“＿＿＿”（读该篇写麻烦与写“转弯”的两句）。请大家判断一下：第二件事，是事情换了方向，还是麻烦又多了一件？

学生互动分享

师：对，麻烦又多了一件，事情还是朝着原来的方向走。转折的意思是换方向：帮手来了、真相出来了、人物自己改了主意，都算。请大家替这个故事想一想，从哪里可以转一个弯？

学生互动分享

（教师总结）改的时候不必推倒重写，只在第二件麻烦那里换一个方向，后面的结果跟着调整即可。

### 收尾（点回技法、引向今后的写作）

师：今天讲评看的三篇，说的都是同一件事：写故事，先给人物设一个麻烦，再让事情转一个弯，中间把人物怎么做的写厚。往后写任何故事，动笔前先问自己两句：我的人物遇上什么麻烦？事情在哪里转弯？这两句答得出来，故事就立得住。

本环节完。
