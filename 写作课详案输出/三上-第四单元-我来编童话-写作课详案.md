# 《我来编童话》· 写作课教学设计

三年级上册·第四单元 校内同步写作（想象习作）

[授课提示：本课词语取自教材本单元习作页。习作页把词语排成三竖列——左列角色（每格两个）、中列时间、右列地点，横着一行为一组：“西红柿、茄子｜夏天｜菜园”“松鼠、孔雀｜星期天｜森林”“铅笔、橡皮｜深夜｜文具盒”。上课时把整张表投屏出示；教材明说角色可以自己再添，也允许从每一竖列各选一个自行搭配。教材页与此不符时以学生手上的课本为准，教学步骤与讲法不变。]

## 教案提纲表

| 课题·课时  | 三上·第四单元《我来编童话》　│　想象·校内同步　│　2课时连排（每节45分钟）                                                      |
| ------ | --------------------------------------------------------------------------------------------- |
| 能力阶段   | 写清楚（本课） → 写具体 → 写生动 → 写深刻·有章法                                                                 |
| 同类习作顺序 | 想象：续写故事／编童话（本课） → 奇妙的想象／这样想象真有趣 → 我和＿＿过一天 → 奇思妙想／故事新编 → 二十年后的家乡 → 神奇探险 → 变形记／笔尖流出的故事 → 插上科学翅膀 |
| 教材要求   | 统编三上·第四单元习作：从角色·时间·地点三列词语里选一组，发挥想象编一个完整的童话；写完给故事加题目、题目居中，再用学过的修改符号改一遍。                        |
| 学习目标   | 通过给几个词语编出一个故事，来学习怎么把一个童话写完整。                                                                  |
| 核心技法   | 使用“童话构思表”。照着角色、时间地点、起因、经过、结果这条线，把故事编完整；再在经过里添一处波折，让角色开口说话。                                    |

## 第1课时 · 写作指导课

### 一、创设情境，明确任务（约 4 分钟）

〖PPT 第3页 · 创设情境 · 今天的任务——开一场童话故事会〗

师：同学们，先说一件事：这两节课的最后，我们教室里要开一场童话故事会。这场故事会上讲的童话，不是从书上找来的，也不是老师带来的，是你们自己编的：一人编一个，写完就讲给大家听。

师：老师也算一个。接下来讲怎么写的时候，老师就用其中一组词语编。今天这间教室里，连老师带同学，每人手里都会有一个新故事。

〖PPT 第4页 · 创设情境 · 故事好不好，听的人说了算〗

师：讲故事，最要紧的是有人听。今天你的听众就坐在你身边——全班同学。一个故事编得好不好，不用老师打分，听的人会告诉你：讲到一半，有人追着问“后来呢？后来怎么样了？”，你这个故事就抓住人了；讲完了，有人说“真想不到，你怎么编出来的”，那就更好了。如果讲完以后没有人想接一句话，那多半是故事太平淡了，我们就回到稿子上再改一改。

师：写好的故事，讲完以后我们收进讲台上这个空册子，做成我们班自己的童话集。今天这两节课上完，这本册子里就装着全班每人一个新故事。今天要写的故事，也正是我们这学期语文书第四单元的习作练习——《我来编童话》。

### 二、回顾童话，从词语里想出画面（约 9 分钟）

〖PPT 第5页 · 回顾童话 · 这些课文里，哪些事平常日子里不会发生？〗

师：编童话之前，先想一想我们这个单元的童话——《宝葫芦的秘密》《在牛肚子里旅行》《一块奶酪》。每个故事里，哪些事是平常日子里不会发生的？

参考：那个宝葫芦，想要什么就有什么／蟋蟀被牛吃到肚子里去了，后来又出来了／蚂蚁会说话，还商量着一起搬奶酪。

师：对。一只葫芦能让人要什么有什么，蟋蟀在牛肚子里走了一趟还能回来，一路上还跟同伴说着话，一群蚂蚁凑在一起商量事情。这些事生活里没有，童话里就有。这三个故事，都是别人一点一点编出来的；今天轮到你们自己编一个。

〖PPT 第6页 · 词语想画面 · 这几个词凑一起——你看见了什么画面？〗

师：知道了童话长什么样，接下来要找故事从哪儿来。投屏上这些词语是教材给我们的，排成了三竖列：左边一列是角色，中间一列是时间，右边一列是地点。横着看，一行就是一组——第一组：西红柿和茄子、夏天、菜园；第二组：松鼠和孔雀、星期天、森林；第三组：铅笔和橡皮、深夜、文具盒。也可以从每一竖列里各选一个，自己配一组；书上还说了，除了这上面的角色，你喜欢的别的角色照样能添加进来。

师：我们先不编故事，只说画面。请大家盯着其中一组词看一看：这几个词凑在一起，你的脑海里浮现出了什么画面？比如看着第一组，老师脑海里浮现出来的是：夏天的菜园热浪滚滚，一个西红柿红得发亮，旁边的茄子紫得发黑，两个挨在一块儿，谁也不理谁。现在从这一列开始开火车，一人说一个画面，说哪组都行。不用说故事，就说你看见了什么。

学生互动分享（开火车，一列每人一句；两列即可，不求全班轮完）

〔应答·学生说不出画面〕给学生起个头，把词语放进半句话里让他接：“夏天的菜园里，西红柿跟茄子说了句什么？”“星期天的森林里，松鼠碰上了孔雀，谁先开的口？”“深夜的文具盒一合上，铅笔和橡皮在里面干什么？”接出半句就算说对了。

师：大家听，同样几个词，有人看见西红柿在跟茄子比谁长得高，有人看见孔雀在森林里开屏、松鼠看呆了，有人看见深夜的文具盒里铅笔和橡皮吵起来了——画面全都不一样。这就对了：画面有了，故事就能够接着编下去了。你刚才说的那个画面，先在心里留着，接下来就会用到。

（教师总结）几个词语一凑，画面就出来了——故事就从这个画面开始编。

### 三、学写法：把故事编完整，经过里添一处波折（约 14 分钟）

〖PPT 第7页 · 判断对比 · 这两段话，哪一段才是童话？〗

师：动笔之前，要先弄清楚这次到底写什么。投屏上有两段话，都用上了“西红柿、茄子、夏天、菜园”这一组词。听老师读完，比一比：哪一段才是童话？

师：第一段：“夏天的早上，我跟着奶奶去菜园。西红柿一个个红得发亮，叶子上还挂着水珠；旁边一畦茄子，紫得发黑，把枝条坠得弯了下去。奶奶摘了三个西红柿放进篮子，又让我把那个最大的茄子摘下来。回家的路上，篮子沉甸甸的，我手心里全是菜叶的味道。”

师：第二段：“夏天的早上，菜园里的西红柿把身子挺了挺，问旁边的茄子：‘你今天怎么一直低着头？’茄子小声说：‘我的紫外衣上，被虫子啃了一个洞。’”

师：这两段，哪一段是童话？

参考：第二段。

师：第一段写得也不错：什么颜色、什么样子都交代了，人也在动。它怎么就不算童话？

参考：那是真的事／菜没有说话／没有神奇的事。

师：对。第一段句子写得很好，但它好在把一件真事写清楚了——夏天跟奶奶去了一趟菜园，看见的、摸到的都记下来，这叫记事。第二段里，西红柿会挺身子、会开口问话，茄子会为身上一个洞难过——菜开口说话了，神奇的事发生了，这才有童话的味道。

师：童话就是这样的故事：动物、植物，连桌子、椅子这些物品，都能开口说话；故事里会发生神奇的、想不到的事；有的故事讲完，还能让人明白一个道理。所以判断是不是童话，不看句子漂不漂亮，看故事里有没有生活里不会发生的事。

师：今天这篇要写的是：选一组词语，或者自己再添几个角色，编一个童话——让角色开口说话，让神奇的事发生，选的那组词都要在故事里露面；千万别写成自己夏天真去菜园摘过菜这样的记事文。

〖PPT 第8页 · 学写法 · 今天这一招——把故事编完整〗

师：光有童话的味道还不够，一个故事还得编完整。什么叫完整？听故事的人心里有几个问题等着你回答：故事里有谁？这是角色。什么时候、在什么地方？这是时间和地点。事情是怎么开始的？这叫起因。中间发生了什么？这叫经过。最后怎么样了？这叫结果。角色、时间地点，加上起因、经过、结果，一样不缺，听的人才觉得听到了一个完整的故事。刚才第二段就有了个好开头：夏天的早上（时间）、菜园（地点）、西红柿和茄子（角色）、茄子的外衣被虫子啃了个洞（起因）——接下来该编经过了。

〖PPT 第9页 · 学写法 · 老师顺着编完了——完整，可你想听下去吗？〗

师：经过怎么编，这里面有个要紧的地方。老师把这个故事顺着往下编了一版，大家听一听：

师：“西红柿说：‘别急，我去请螳螂来。’螳螂挥着两把大刀赶过来，三两下就把那条菜青虫夹住了。茄子挺起身子，说了声谢谢。”

师：把这两段连起来听，完整吗？角色、时间、地点都有了，事情也从头到尾交代完了。但是大家听着，想不想追问一句“后来呢”？

参考：不想／听完就完了／太平淡了。

〖PPT 第10页 · 学写法 · 看老师动个手术——给经过添一处波折〗

师：问题就出在这儿：这个故事从头到尾顺顺当当，没有一点让人担心的地方。看老师当场给它动个手术，就添几句话。

〔教师示范·当场往平淡段里加进一处波折〕螳螂刚站到茄子跟前，正要挥刀 —— 就在这时，一阵大风刮过菜园，螳螂被吹得直打转，眼看就要被卷出篱笆去。西红柿大喊：“抓住我的叶子！”螳螂死死抓住那片叶子，稳住身子，回到茄子背上，三两下就把那条菜青虫吃掉了，茄子也开心地抬起了头。

师：再问一遍：这一次两版比一比，哪一版更想听下去？

参考：第二版。

师：第二版多了什么？

参考：多了刮大风／螳螂差点被吹跑，抓住了叶子。

〖PPT 第11页 · 学写法 · 添波折，路子有三条〗

师：对，多了一场麻烦：眼看虫子就要被夹住了，忽然刮起大风，螳螂差点被吹跑，听的人心一下提起来——这回还救得成吗？故事里冒出来的这种麻烦，就叫波折。波折一来，听众的心就跟着揪起来了。想要故事更吸引人，设置波折有三种简单思路：让角色遇到一个困难，让他碰上一个意外，或者在要紧关头来一个帮手。刚才这版，意外和帮手都有了。

师：我们这个单元的《在牛肚子里旅行》，用的也是这两样：红头一头栽进牛嘴里、被吞进肚子，这是天大的意外；青头隔着牛肚子一路给它出主意，这是帮手。麻烦有多大，故事就有多让人揪心。

师：困难是什么样呢？比如角色急着要去一个地方，偏偏半路横着一条河，怎么也过不去——这就是遇上了一个困难。引出波折的话也是现成的：“忽然”“就在这时”“谁知”，一说出口，麻烦就上场了。

师：麻烦上场了，总得有个了结：麻烦解决了没有、最后怎么样，这就是结果，故事到这儿才算写完。

师：还有一个地方大家注意到了吗：西红柿大喊：“抓住我的叶子！”角色一开口，故事就热闹了。写角色的语言，记住两点：说话人后面点一个冒号，说出来的话要标上双引号。这是这学期标点的重点，写的时候不要忘记。

师：现在轮到大家试一试。就用你刚才选中的那组词和脑海里的画面，设想一处故事里的意外波折，用“忽然”或者“就在这时”起头，口头说一句。想好了先自己默念一遍。

学生自由分享（教师抽两三位说，落到具体：肯定他的波折是困难、意外还是帮手，点一句妙在哪）

师：很好，麻烦都想出来了。今天这一招，就是照着“角色、时间地点、起因、经过、结果”这条线把故事编完整，写到经过，添一处波折。就像红头掉进牛肚子那样，让听的人替他捏一把汗。

### 四、借助童话构思表，理清思路（约 10 分钟）

〖PPT 第12页 · 童话构思表 · 童话构思表〗

故事光在脑子里想，容易写着写着就乱，我们先用一张表把它整理一下。每人手里发了一张童话构思表，一格里只写关键词，能提醒自己即可，不写长句。

| ------------ | ----- |
| 我选的词语（或自定角色） |       |
| 角色           |       |
| 时间·地点        |       |
| 起因（事情怎么开始的）  |       |
| 经过（波折是什么）    |       |
| 结果（最后怎么样了）   |       |

〖PPT 第13页 · 童话构思表 · 老师先填一张——用第三组词铅笔、橡皮、深夜、文具盒〗

师：老师先填一张给大家看。开头说过老师也编一个，老师用的是第三组词——铅笔、橡皮、深夜、文具盒；书上说角色可以自己添，老师就又添了一个卷笔刀进来。

〖PPT 第14页 · 理清思路 · 轮到你——先填表，再讲给同桌听〗

师：看清楚了：每格只写几个词就可以了。现在轮到大家了，请把自己的故事填进去。填“经过”的时候想一想：你的波折是设置固有困难、插入突发意外，还是在困境中安排帮手解围？

学生动笔写作（填表约 4 分钟；教师巡视）

〔应答·学生“经过”一格填不出波折〕不批评，把三个方向指出来供学生选择：“你的角色会遇到什么难事？会不会出个意外？要不要来个帮手？”挑中一条，帮他缩成两三个词填进去。

师：填好的同学，和同桌换着讲：看着自己的表，把故事从头到尾说一遍，一两分钟即可。听的人不要闲着，听完追问一句，“后来呢？”或者“他为什么这么做？”问到对方答不上来的地方，意味着你的故事框架少了关键情节，需要补一补。

学生互动分享（同桌两两互动，讲完互换；教师到两三组跟前听）

师：请一两位同学把自己的故事说给大家听。

学生互动分享（请一两位说故事梗概；教师反馈落到具体地方，如指出他的波折设在哪一步、结果收得干脆不干脆）

### 五、出示示范文，发现写法（约 8 分钟）

〖PPT 第15页 · 教师示范文 · 老师表里的那个故事——深夜的文具盒〗

师：你们的故事都有了框架。现在，老师把刚才填在表里的那个故事，整个讲给你们听——大家当第一批听众，一边听一边留心：老师是怎么照着那张表，把几个词编成一个故事的。

> 【教师示范文】
> 
> 　　　　　深夜的文具盒
> 
> 夜深了，文具盒里黑黑的。铅笔翻来覆去睡不着，小声说：“完了，我的尖断了。小主人明天第一节课就要听写。”
> 
> “断了就削呀。”橡皮迷迷糊糊地翻了个身。
> 
> “卷笔刀在书包最外面那个口袋里，我出不去。”铅笔的声音都发抖了。
> 
> 橡皮一下子醒了，把文具盒的盖子顶开一条缝：“我背你出去。”
> 
> 铅笔趴在橡皮背上，两个从文具盒里钻出来，一步一步往书包外层的口袋挪。眼看就要到了——就在这时，睡在床上的小主人翻了个身，胳膊碰到了床头柜上的书包。书包猛地一晃，橡皮一把将铅笔推到旁边，自己却被书脊硌了一下，两个人也不由自主地滚进了语文和数学书的夹缝里。
> 
> “你怎么样？”橡皮把铅笔从两本书中间拽出来。
> 
> “我还好。可卷笔刀还在外面……”铅笔有点沮丧。
> 
> 橡皮没说话，重新把铅笔驮到背上，这次他们贴着书包内壁绕了个弯，慢慢地走。终于，他们钻进了外层口袋，卷笔刀就蹲在口袋底部。
> 
> 铅笔钻进卷笔刀，转了三圈。木屑落下来，像下了一场小小的雪。等他退出来的时候，笔尖又亮又尖。
> 
> 回到文具盒里，橡皮身上多了一道深深的印子。铅笔看着那道印子，没再说话，只是往橡皮身边挪了挪。两个人挨在一起，静静地等着天亮。

师：先看框架。故事里有谁？什么时候、什么地方？

参考：铅笔、橡皮，还有书包外层口袋里的卷笔刀／深夜，文具盒里。

师：起因、经过、结果，各在哪儿？

参考： 铅笔的尖断了，小主人明天要听写／中间橡皮背他去外层口袋，半路主人翻身碰到书包，两个滚进书缝，橡皮拽出铅笔重新驮着绕路走／最后尖削好了，两个人挨在一起等天亮。

师：构思表里那些内容，一个都没落下。再听一遍中间那段——波折是哪一处？

参考：小主人翻了个身，胳膊碰到了床头柜上的书包，书包一晃，两个滚进了语文书和数学书的夹缝里。

师：对，眼看就要到卷笔刀跟前了，主人一个翻身碰了书包，两个一起滚进书缝里——麻烦一下子升级了。注意看，橡皮是怎么做的？他一把将铅笔推到旁边，自己却被书脊硌了一下。等他从书缝里把铅笔拽出来，一句话没说，重新驮上铅笔绕路走。这一段里，橡皮两次护住了铅笔，越看越让人替他捏把汗。

〖PPT 第16页 · 旁批表 · 每句在做什么——把编故事的秘密摆出来〗

师：老师把大家说的这些句子理成一张小表，对着看：

| 示范文里的句子                                                            | 这一句在做什么                    |
| ------------------------------------------------------------------ | -------------------------- |
| 深夜的文具盒                                                             | 题目要居中——教材上特意提了这一条          |
| 夜深了，文具盒里黑黑的。铅笔翻来覆去睡不着                                              | 开头一口气交代了时间、地点、角色           |
| “完了，我的尖断了。小主人第一节课就是听写。”                                            | 起因就在这句话里；铅笔一开口，童话的味道出来了    |
| “卷笔刀在书包最外面那个口袋里，我出不去。”                                             | 对话——冒号、引号，一样不少             |
| 小主人翻了个身，胳膊碰到了床头柜上的书包。书包猛地一晃，橡皮一把将铅笔推到旁边，自己却被书脊硌了一下，两个人也不由自主地滚进了夹缝里 | 波折上场；一个翻身带来一连串麻烦，读者心跟着提起来了 |
| 木屑落下来，像下了一场小小的雪                                                    | 打了个比方，画面就看得见了              |
| 两个人挨在一起，静静地等着天亮                                                    | 结尾写结果，说完这句就收住，干净利落         |

师：老师选的是第三组词，中间还添了一个卷笔刀进来。接下来动笔，请大家照自己表上填的关键词来编，编出你自己的童话故事——和老师的像不像，一点都不重要，关键是要编得完整、有波折。

师：这节课到这儿，你手里已经有三东西：选定的一组词，填好的构思表，还有想好的那个波折。休息一下，回来我们就把它写成真正的童话——故事会等着它们呢。

本课完。

〖PPT 第17页 · 课时分隔 · 当堂写作与评改课〗

## 第2课时 · 当堂写作与评改课

### 一、借助构思表，写下故事的开头（约 5 分钟）

〖PPT 第18页 · 写作热身 · 第一句最好写——把两格连起来〗

师：请把童话构思表拿出来，找到上面两格：“角色”和“时间·地点”。

师：童话的第一句最好写：把这两格连起来说就可以了。老师表上填的是“深夜、文具盒里、铅笔和橡皮”，连起来就是：“夜深了，文具盒里黑黑的，铅笔翻来覆去睡不着。”老师那篇的第一句，就是这么来的。现在，请把你那两格连成一句话写下来。

学生动笔写作

师：第一句写完，后面就顺了，顺着第一句往下写，想到什么写什么，不会写的字，画个圈占住位置接着往下写。先不用管写得好不好，把起因写出来。

学生动笔写作（约 3 分钟；教师不出声巡视，不作任何纠正）

师：停一下笔，看一看这几行：你的童话已经开了头，起因也快出来了。接下来往下写，把经过和结果写完；写到经过，不要忘了把表上那个波折放进去。

### 二、自由写作，把故事写完（约 19 分钟）

〖PPT 第19页 · 自由写作 · 把故事写完——三件事记在心里〗

师：现在接着往下写，写十六七分钟，把整个故事写完。三件事记在心里：照构思表写到底；波折不要落下；角色开口说话，冒号、引号用上。写的时候不用回头改字，一口气写完再说；题目也先不用想，写完了再回头起。开始吧。

学生动笔写作

[教师巡视，只做正向介入，不纠错字、不改病句、不打断书写顺畅的学生。按学情分四类处理——]

[接不下去型：写完开头几行就停住、盯着稿纸。把学生引回构思表：“看看‘经过’那格，你写的波折还没上场呢。让它现在就出来——是谁碰上了什么麻烦？”]

[内容空泛型：整段都是“他们玩得很开心”一类的话。先接住这一句，再往前推一步：“他们玩得很开心，这句老师读懂了。如果再写上他们说了什么、做了什么，老师就能看见他们了。你添两句试试，再比比哪一种更有画面感。”]

[书写顺畅型：不打断，走过时轻声一句“接着写”，为其留出书写空间。]

[草草收尾型：写了几句就搁笔说“写完了”、篇幅明显偏短。先肯定再推一步：“麻烦解决得也太快了，说说看，中间是怎么解决的？把这一步写出来，故事才有意思。”]

[临近时间提示：写到哪儿都行，先把手上这一句落个句号；实在没写完的，记住后面想怎么编，评议完还有时间补。]

### 三、交流评议，修改收束（约 21 分钟）

[同桌互讲环节（约 4 分钟）：童话故事会第一场——同桌互为第一位听众]

〖PPT 第20页 · 童话故事会 · 故事会开场——第一场，讲给同桌听〗

师：故事会现在开场。第一场，讲给你的同桌听。拿着稿子，把自己的童话从头到尾读一遍。听的人有两件事：听完告诉他，你觉得哪儿最神奇；再从他的故事里选出一句最喜欢的，读给他听。两人都讲完、都听完，才算完。

学生互动分享（同桌两两互讲互听；教师到几组跟前当听众）

[全班童话故事会（约 8 分钟）：先请 2 位同学讲完整故事，评议顺畅、时间有余再加第三位；控制在每人两分半以内]

〖PPT 第21页 · 童话故事会 · 第二场——讲给全班听〗

师：第二场来了。请两三位同学，把自己的童话完完整整讲给全班听。台下的同学都是评委，听的时候想三件事：他的故事完整吗？哪儿最神奇？哪儿最有趣？听完说给大家。

学生互动分享（2–3 位同学朗读全篇；每篇读完，先请一两位听众按三个角度说感受，教师再轻点评。点评落到具体句上，如指出哪一句波折来得妙、哪一句对话像真的有人在说；每篇顺便指出一个可以改动的点）

[带标准修改（约 6 分钟）：延迟到此刻统一处理格式与错字]

〖PPT 第22页 · 修改收束 · 改一改——三个问题过一遍，再起个题目〗

师：故事讲过了，现在回到自己的稿子上，改一改。对着三个问题过一遍：第一，角色、时间地点、起因、经过、结果，缺不缺？缺了补上。第二，经过里那处波折在不在？如果从头顺到尾，就用“就在这时”这个转折句给它添个麻烦。第三，角色说话的地方，冒号、引号用对没有？

师：改完还剩最后一件事——给你的故事起个题目，写在空着的那第一行，写在正中间。一时想不出的，就从故事里选一样最重要的事物来当题目，老师那篇就叫《深夜的文具盒》。起完题目，用修改符号把稿子理一遍：多的字圈掉，漏的字补上，写错的改过来；画了圈的字问同桌或者举手问老师，补进去。写完后给故事加一个题目，注意题目要居中。

学生动笔写作（自改；教师巡视答疑）

〔三档标准·教师掌握（供教师判断用，不必念给学生）〕基础过关：用给的词编出了一个故事，角色、时间、地点写清楚了，故事有头有尾。良好达标：起因、经过、结果都齐了，句子读得通。优秀进阶：故事完整有趣，想象丰富新奇，情节有波折，对话生动，能给读者带来惊喜。

[点亮与收尾（约 3 分钟）]

〖PPT 第23页 · 收束 · 装满我们班的童话集〗

师：刚才第一场里，同桌从你的故事里选出了精彩的一句。被挑中的同学，请几位站起来，把那一句大声读给全班，让大家听一听，今天教室里冒出了哪些好句子。

学生互动分享（请五六位被同桌选中句子的作者起立，各读一句；教师逐句接一句具体的肯定）

师：现在收故事。把你的稿子传给本列最前面的同学，一列一摞；排头的同学负责把这一摞放进册子。我们班的童话集，今天装满了——里面每一个故事，都是今天现编出来的、以前世界上没有的故事。册子就放在教室书架上，来上课时都可以翻一翻别人写的故事。回家以后，把你自己这个童话讲给家里人听一听，他们一定没听过。

（教师总结）今天这两节课，你们用书上给的几个词编出了一个完整的童话——有角色，有时间地点，起因、经过、结果一样不缺，中间还有一处让人替角色着急的波折。往后不管编什么故事，这条线都用得上。

本课完。

〖PPT 第24页 · 习作讲评 · 习作讲评环节（可选·课后或下次课开场）〗

## 附：习作讲评指导环节（可选 · 单次课课后用 / 系列课作下次课开场用）

> 本环节供教师灵活取用：可在单次课课后批阅学生习作后集中讲评一次，也可作为系列课下一次课的开场（约 15–20 分钟）；不计入本课 45+45 分钟，讲评的是学生当堂完成的稿子，不布置新的写作任务。
> 讲评中凡出现 ＿＿＿ 处，务必替换为本班学生习作中的真实句子，切勿虚构。

### 选稿（课前准备）

课后通读全班稿件，围绕本课技法点（把故事编完整、经过里有波折、对话用冒号引号、写完加题目）选出三篇：

- 一篇较好的：要素样样齐全，波折设得妙，对话像真的有人在说——用来让全班看见“编完整、有波折”长什么样。
- 一篇中等的：故事完整，但经过一句就滑过去了，波折没展开——用来演示“把波折放大”怎么改。
- 一篇有典型问题的：要素缺了一两样（多为没交代时间地点，或没有结果），或通篇没有一处对话——用来带全班一起出主意。

三篇均投屏出示，不念作者姓名；讲评前给三篇各拟一句话，对照本课技法写明它好在哪里、欠缺在哪里。

### 讲评流程（每篇约 3–5 分钟，围绕本课技法点）

师：上次故事会上，大家的童话都讲过一遍了。老师课后又把每一篇都读了一遍，今天选三篇出来，我们只看两件事：故事编完整没有，波折写出来没有。

师：先看第一篇。这个故事里，“＿＿＿”（读该篇波折处最妙的一两句），大家听：麻烦一冒出来，读者的心是不是瞬间就被抓住了？这就是波折该有的样子。再听他这句对话：“＿＿＿”（读该篇一句生动的对话），冒号、引号都在，话也像真的从角色嘴里说出来的。

（教师总结）要素齐、波折妙，这篇就是照着我们那条线编出来的。

师：第二篇故事也完整，就是中间快了点。他写“＿＿＿”（读该篇经过部分一带而过的那句），一句话，麻烦就解决了。大家想一想，如果把这一步拆开——麻烦是怎么来的、角色先做了什么、又是怎么解决的——多写两三句，这个故事会不会更好听？

学生互动分享

师：对，波折不是提一下就够了，要让它多留一会儿，听的人才来得及替角色着急。

师：第三篇不说是谁写的，我们一起帮他出主意。这个故事“＿＿＿”（口头概括该篇缺的要素，如：讲完了事情，可没交代最后怎么样了）。故事停在半路，听的人心里悬着。谁来帮他想一个结尾？

学生互动分享

师：你们出的这些主意都能用。回头他选一个，把结果补上，这个故事就全了。

### 收尾（点回技法、引向今后的写作）

师：三篇看下来，好就好在用上了这节课的写法——照着“角色、时间地点、起因、经过、结果”这条线编完整，经过里添一处波折。往后再编故事，先问自己这两句：线走全了没有？麻烦上场了没有？

本环节完。
