# 《我的心爱之物》· 写作课教学设计

五年级上册·第一单元 校内同步写作（状物习作）

[授课提示：开场那只旧帆布包与示范文里的那件事，都是备课时拟写的例子。正文已经避开“这是我每天背的”这类说法，老师照着讲不会说到自己头上；学生若问是不是老师的，直说“这是老师找来给你们看的”即可。老师手边真有一样用了多年的旧物，换成自己的更好。这一课讲的就是“东西背后有事”，讲自己那一件才立得住；替换时把五处一并换掉：开场三问的答案（年头、价钱、坏过又修的那件事）、第三环节当场念的那一小段、构思表的教师示范填写、示范文、旁批表里逐句引用的句子。手边没有合适旧物的，按稿子拿任一件旧物当例子讲即可，教学步骤与技法讲法不变。]

## 第1课时 · 写作指导课

### 一、创设情境，明确任务（约 5 分钟）

〖PPT 第3页 · 创设情境 · 先猜两个数——桌上这只旧包〗

师：（拿出一只旧帆布包放在桌上）老师今天带来了一样东西。大家看一看，猜一猜这个包用了几年？

参考：三年／五六年／看着挺旧了，得有十年吧。

师：九年。再猜一猜：这样一个包，当初买来花了多少钱？

参考：一百多／几十块钱。

师：五十八元。五十八元的包用了九年，中间还坏过一次，主人自己用针线缝好了。商店里的新包很多，主人却一直没有去换，还是用这一只。大家想一想，这是为什么？

参考：用惯了／换了不习惯／有纪念意义／舍不得吧。

师：大家说得都有道理。一样东西在主人心里的分量，和它值多少钱，往往没有多大关系。今天这两节课，我们每个人都来写这样一样东西，写自己的心爱之物。它可以是玩具、文具、一件旧衣服，也可以是你养的小动物、你种的一盆花。只要它对你有着特别的意义，都可以写。

〖PPT 第4页 · 创设情境 · 今天的任务——办一场心爱之物展览会〗

师：写完以后，我们就在教室里举办一场“心爱之物展览会”。先把稿子传给旁边的同学，请他根据你写的内容，辨认出你的这件东西；再请几位同学读给全班听。

师：不过，我们这场展览会有些特别：大家要写的东西，此刻多半还在家里的柜子上、抽屉里、窗台上，谁也搬不来。展台上只摆你写的这一篇文章。听的人看不到实物，只能通过你的文字来认识它。这件东西对你究竟特别在哪里，别人信不信，全看这一篇文章。

〖PPT 第5页 · 创设情境 · 什么算写成功了？〗

师：怎样才算写成功了？读完之后，听的人能说出它的样子，还能说出它为什么偏偏是你的。怎样算没有写成功？从头到尾都是“我很喜欢它”“它对我很重要”，听完一遍，别人既记不住它的样子，也说不出它为什么是你的。

### 二、观察体验，找到你的心爱之物（约 8 分钟）

〖PPT 第6页 · 观察体验 · 摸一摸手边那一样——找买来那天没有的痕迹〗

师：我们先从手边的东西说起。请从身上、桌上、书包里找出一样东西，要用得最久的那一样。铅笔盒、水杯、橡皮，或者挂在书包上的小挂件，都可以。

[待大多数学生拿到东西后再往下问；一时找不出的，让他就近观察同桌的物品，跟着听。]

师：拿在手里，摸一摸。它身上有哪些痕迹，是刚买回来时没有的？

参考：橡皮少了一个角／水杯盖上的字掉了／铅笔盒角上磕掉一块漆／贴纸翘边了／笔杆上有牙印。

师：和同桌说一说：这些痕迹里，哪一处是别人手上那一件所没有的？

学生互动分享（同桌两人各说一遍；教师俯身到两三组旁边倾听，做他们的第一位听众）

师：（请一位刚才发言的同学）你那道划痕，是怎么来的？

参考：上次赶作业，橡皮从桌上掉下去，被椅子腿压了一下。

师：大家听，这一说就不一样了。刚才说到的磨掉的漆、翘边的贴纸、掉在地上磕坏的那一块，都不是买来时就有的，而是它跟着你一天天用下来留下的。别人手上那一件，就没有这几处痕迹。

〖PPT 第7页 · 观察体验 · 把范围放大——选定你要写的那一件〗

师：现在把范围放大。今天要写的，不一定是手上这一样。它此刻也许正放在你家的书桌上、床头，或者柜子的最上层。想一想：你的那一件放在哪里？上一次拿起它是什么时候？

学生互动分享（举手抽说两三位；教师听到“养的仓鼠”“种的多肉”一类的回答，明确予以肯定）

〔应答·学生说不出哪一件最心爱，在两三样之间反复更换〕不问“哪个最喜欢”，改问“哪一样搬家时你会第一个装进箱子”，或者“哪一样丢了你会找上一整天”。答出来的那一样，就是它了。

（教师总结）选定了就不要再换。接下来的两节课，我们只做一件事：让没见过它的人，通过一篇文章看见它。

### 三、学写法：写专属于它的印记与痕迹，用一件事作证（约 14 分钟）

〖PPT 第8页 · 判断对比 · 同写一块滑板——哪一段读完，你觉得这东西对他不一样？〗

师：老师这里有两段话，写的是同一样东西。听完以后请告诉老师，哪一段读完，你会觉得这样东西对他来说不一样。

师：第一段：“我最心爱的东西是一块滑板。它是深蓝色的，板面长八十厘米，宽二十厘米，板底印着一只张着嘴的老虎，四个轮子是橡胶的，滑起来几乎没有声音。踩上去往前一蹬，风从耳边呼呼地吹过，那种痛快的感觉没法形容。周末我常带着它去广场，一玩就是一下午，累得满头大汗也不想回家。它给我带来了很多快乐，我非常喜欢它。”

师：第二段：“我那块滑板，板尾的漆磨掉了一大片，露出底下的木头，摸上去毛毛的。那片漆是去年夏天磨掉的，我在小区那道斜坡上练急停，摔了七八回，每回都是板尾先蹭地。现在我一低头，就能看见那片木头色。”

师：大家判断一下，是哪一段？

参考：第二段。／第一段吧，它写得挺细的。

师：两段都有人选。选第一段的同学也有道理。第一段写得确实不粗糙：颜色、尺寸、图案都交代了，风从耳边吹过、玩一下午不想回家，画面感也有。可是老师要问一句：第一段这些话里，有哪一句是只有他那块滑板才写得出来的？

参考：好像都能／别人的滑板也这样／换一块也一样。

师：是的。第一段的这些话，换到任何一块同款滑板上，一个字都不用改。第二段就不同了：板尾磨掉的那片漆、练急停摔的那七八次，别人的滑板上没有。今天要写的不是一篇产品介绍，而是要让读的人明白：这样东西为什么偏偏是你的。凡是换成别人的那一件也照样成立的话，写了等于没写。

师：那么第二段是怎么做到的？老师再读一遍，大家边听边数：它和第一段的差别，一共有几处。

师：“我那块滑板，板尾的漆磨掉了一大片，露出底下的木头，摸上去毛毛的。那片漆是去年夏天磨掉的，我在小区那道斜坡上练急停，摔了七八回，每回都是板尾先蹭地。现在我一低头，就能看见那片木头色。”

参考：它写了磨掉的那块漆／它讲了摔跤那回事／它没说八十厘米那些每个滑板都具备的特点。

师：这两处，凡是找到的同学都看出了门道。还有一处最不容易发现，藏在结尾：第一段最后写了什么？第二段有没有？

参考：第一段写了“我很喜欢它”。／第二段一句喜欢都没有。

〖PPT 第9页 · 学写法 · 今天练三条写法〗

师：三处差别都找出来了。老师给它们各起一个名字，今天就练习这三条写法。

〖PPT 第10页 · 写法一 · 商品标签上的话不算样子〗

师：第一条，写样子，只选它身上的印记和痕迹来写。颜色、长短、材料，是商品标签上的内容，谁的滑板都写得出来；大家找出来的那块磨掉的漆，还有磨白的边、掉漆的角、缺的一块、补过的地方，才是只有你那一件才有的。

师：要写小动物、写花草的同学，道理是一样的，只是要换一种方式找记号：右耳尖上的一小撮白毛、缺了一个角的叶子、笼子边上啃出的一道印。这些，别人家的那一只、那一盆上也没有。

〖PPT 第11页 · 写法二 · 找一件因为它才发生过的事〗

师：第二条，就是大家说的摔跤那件事。只有样子还不够，还要用一件事来作证。这件事必须是“因为它”才有的：那道划痕是怎么来的，它坏了那一次你是怎么处理的，你带着它经历过什么。有了这一件事，别人才会相信你说的“心爱”是真的。

〖PPT 第12页 · 写法三 · 把这三句划掉——喜欢的劲儿淡了吗？〗

师：第三条，就是大家刚才在结尾处发现的那一点：不直接说“我很喜欢它”，只写事情、只写动作，别人同样感受得到。老师读一小段给大家听，这一小段写的就是桌上这个包。

〔教师示范·先读带有直接抒情句的一小段，再当场划掉这几句重读一遍〕“这个包我特别喜欢。背带断过一次，是从书店出来的那次，被一包书压断的。我从鞋子上解下一根鞋带，把断掉的背带两头系紧，打了个死结，就这样提着包往家走。晚上回到家翻出针线，自己一针一线缝了起来，针脚歪歪扭扭的，直到现在我也没有拆掉。它对我太重要了。每天出门，我第一个拿起的就是它。我真是一天也离不开它。”

师：现在老师先把其中的三句话划掉：“这个包我特别喜欢”“它对我太重要了”“我真是一天也离不开它”。剩下的部分再听一遍：“背带断过一次，是从书店出来的那次，被一包书压断的。我从鞋子上解下一根鞋带，把断掉的背带两头系紧，打了个死结，就这样提着包往家走。晚上回到家翻出针线，自己一针一线缝了起来，针脚歪歪扭扭的，直到现在我也没有拆掉。每天出门，我第一个拿起的就是它。”

师：划掉这三句以后，喜欢的感觉是变淡了，还是没有？

参考：没淡／好像还更明显了／听得出来他舍不得。

师：划掉的那三句，放到任何人的心爱之物上都能用。留下来的这几句——歪歪扭扭的针脚、出门第一个拿起它——只有这个帆布包才有。所以，喜欢除了直接说出来，还有一种写法：把它藏在事情和动作里，让别人自己读出来。两种写法都可以，结合起来用更好。

〖PPT 第13页 · 口头练笔 · 这一招，《桂花雨》就在用〗

师：这种写法，课本里这个单元的课文也在用。《桂花雨》整篇写的是小时候在院子里摇桂花这件事：抱着桂花树使劲摇，桂花落了满头满身，接着一家人把落下的桂花收起来晒干，做糕点、泡茶。作者从头到尾没有写过一句“我很想念家乡”，可读完的人都明白她的思念。这个单元要学的正是这种写法：把感情放进一件具体的事里，让读的人自己体会出来。今天大家写自己的心爱之物，用的也是同一个方法。

师：现在轮到大家试一试。想一想你选定的那件东西，说一句“因为它才发生过的事”，这一次先不用“喜欢”一类的词。想好了，先小声说一遍。

学生互动分享（举手抽两三位同学分享；教师点评只点一处：他说的哪一句只有他那一件才有，换到别人的东西上就不成立）

〔应答·学生说的事和那件东西没有关系（如“我带着它去过外婆家”）〕追问一句“那天它出了什么事，或者它派上了什么用场”，把事情引回到东西本身。

### 四、借助构思表，理清思路（约 9 分钟）

〖PPT 第14页 · 构思表 · 我的心爱之物·构思表〗

师：动笔之前，我们先用一张构思表把要写的内容理一理。每一栏只写几个关键词，不必写成完整的句子，自己看得懂就行。

| 项目                  | 我的关键词 |
| ------------------- | ----- |
| 它是什么                |       |
| 只属于它的特别痕迹           |       |
| 它是怎么来的              |       |
| 和它之间发生过的一件事         |       |
| 它如今放在哪里，你平时和它相处的小故事 |       |

〖PPT 第15页 · 构思表 · 老师先填一张——全是词，没有一句整话〗

师：老师先填一张给大家看。填的就是桌上这个包。

| 项目                  | 我的关键词             |
| ------------------- | ----------------- |
| 它是什么                | 深灰帆布包·背了九年        |
| 只属于它的特别痕迹           | 下角磨白、侧袋一个洞、一道歪针脚  |
| 它是怎么来的              | 上班第一年·小店门口·五十八块   |
| 和它之间发生过的一件事         | 书店出来·背带崩断·鞋带绑着拎回家 |
| 它如今放在哪里，你平时和它相处的小故事 | 挂在门后·出门先摘它        |

师：大家看老师这张表，和平时写作文的句子相比，有什么不一样？

参考：全是词／没有一句整话／很短。

师：对，一栏几个词就够了，等一会儿动笔时再把它们变成句子。第二栏和第四栏最重要，对应的就是今天三条写法里的前两条。第三栏是来历：它是谁送的，是自己攒钱买的，还是哪一次捡回来的；动笔时一句话带过即可，不必展开。第四栏也不用写经过，记下是哪一件事就行，动笔时再写细。

学生动笔写作（填表约 3 分钟；教师巡视）

〔应答·学生第四栏空着，说“它没发生过什么事”〕不催他想大事，改问三个问题：它有没有坏过、丢过？你有没有带着它去过什么地方？有没有哪一天你专门为它做过什么（清洗、修理、藏起来）？答出一样就填上。

师：填完的同学，小声地把要写的内容从头对自己说一遍：它是什么，什么样子，怎么来的，发生过什么事。说到哪一栏说不下去了，那里就是你还没有想清楚的地方。

学生自由分享（自说自听；教师巡视，听到说不下去的，顺势追问一句）

师：请两位同学说给大家听。其余同学注意听一件事：他讲的内容里，哪一处只有他那一件才有。什么叫只有他才有？就是这句话放到别人的东西上，就说不通。

学生互动分享（举手抽说两位；教师顺势指出他表上哪一格最值得展开）

### 五、出示示范文，发现写法（约 9 分钟）

〖PPT 第16页 · 教师示范文 · 那张表，变成了一篇文章〗

师：大家的构思表都填好了。现在老师把刚才填的那张表，写成一篇完整的文章给大家看。看的时候留意一件事：表上的那几个关键词，是怎样变成一段一段的话的。

> 【教师示范文】
> 
> 我家门后的挂钩上，常年挂着一只深灰色的帆布包。
> 
> 它两个下角早磨白了，表层的布都快磨破了。右边侧袋破了一个洞，起先只有指甲盖那么大，现在能塞进一只拳头。最显眼的是背带靠肩那一段，缝着一道线，针脚一会儿密一会儿疏，歪歪扭扭地爬过去，线的颜色也明显比包身浅一些——那是我自己缝的。
> 
> 包是我上班第一年买的，在一家小店门口的架子上挂着，五十八元。那时候我每天要装的东西很多，一摞作业本、水杯，还有太阳伞。选来选去我看中了这一只，它开口宽，大大小小的物件往里放很方便。
> 
> 那道针脚是第三年冬天留下的。那天我从书店出来，抱了六七本书塞进包里，走到路口，背带“啪”的一声断了，包从肩上滑下来，砸到地上，书撒了一地。我蹲下去，把书一本一本捡起来，风把书页吹得哗哗响。断掉的背带散着细碎的线头。我从鞋上抽了根鞋带，把断掉的两端扎牢，打了个死结，一路拎回家。晚上我找出针线，坐在灯下缝了半个多小时，手指都扎了三四回。缝完看了半天，那道线歪歪扭扭的，难看得很，但是我没拆。
> 
> 后来包又旧了些。出门的时候，我总是先把它从挂钩上摘下来，甩到肩上，再回头关门。有几回同事说，这包该换了。我说等它彻底坏得不能用了再换。今天早上，我又是这么摘下它，走出门去。

〖PPT 第17页 · 读示范文 · 五个段落——这个框架你照着用就行〗

师：先看整篇的框架。它一共分了几段？每一段分别写了什么？

参考：五段／第一段说它是什么／中间写样子、写怎么来的、写发生过的那件事／最后写现在。

师：开头一句话，点出这件东西；中间样子、来历、发生过的那件事各占一段；结尾落在一个动作上。这个框架大家可以照着用。

师：我们再看细一些。第二段写这个包的样子，写了哪几处？

参考：磨白的角／破洞／那道针脚。

师：颜色、大小、什么牌子，一样也没有写，写的全是它跟了我这些年留下的印记。这就是今天的第一条写法：只选它身上的印记和痕迹来写。

师：那件事写在第几段？读完那一段，你相信写这篇文章的人舍不得这个包吗？

参考：第四段／相信／他都拿鞋带绑着拎回去了。

师：可是整篇文章里，老师有没有写过一句“我很喜欢这个包”？

参考：没有。

师：一句也没有。可大家照样感受得到，写的人舍不得它。这就是今天的第三条写法：喜欢不直接说，读的人从字里行间也能读出来。

师：最后再默读一遍，找一找：哪一句话让你读着读着，眼前就浮现出了这个包的样子？

学生互动分享

师：这节课到这里，大家手上已经有了三样东西：选定的那件物品、填好的构思表，还有刚才自己说通顺的那几句话。休息一下，回来就动笔。

## 第2课时 · 当堂写作与评改课

### 一、借助构思表，写下开头几句（约 5 分钟）

〖PPT 第20页 · 写作热身 · 第一栏连成开头一句，第二栏挑一处细节〗

师：请拿出构思表，找到第一栏“它是什么”。

师：这一栏里的几个词，连起来其实就是一句话。老师表上填的是“深灰帆布包·背了九年”，连起来就是：“门后的挂钩上，常年挂着一只深灰色的帆布包。”你的那一句是什么？现在空两格，写在第一行。

学生动笔写作

师：再看第二栏。这一栏里你写了好几个词，先不要一样一样都写，只选你最想写的那一处。

师：接下来把这一处写清楚，写三四句话就可以，让别人一看就认得出它。可以从这三个方面选着写：一是这处痕迹有多大、什么形状，颜色一句带过即可，眼睛只盯住这一处，先不把整件东西从头写到尾；二是这一处是什么样子，是磨出来的印子、一道划痕、一个缺口，还是后来修补过的地方；三是用手摸上去是什么感觉，如果有气味、有声响，也可以写进去。三个方面不必都写全，哪一样最符合你的那一件，就写哪一样。

学生动笔写作

师：停一停，回头把这几行读一遍。读的时候想一想：只看这一小段，别人能不能认出这就是你的那一件。然后接着往下写：先写它是怎么来的，再写你和它之间的那件事。

### 二、自由写作，把整篇写完（约 23 分钟）

〖PPT 第21页 · 自由写作 · 一口气写完整篇——记住三件事〗

师：现在一口气往下写，用二十分钟左右，把整篇写完。记住三条写法：样子，选它身上独有的几处来写，不必样样写到；中间写一件你和它之间真实发生过的事，把经过写清楚、写具体；喜欢可以藏在细节里，不必直接说“我很喜欢它”。结尾像老师那一篇一样，落在一个你平时和它相处的小动作上。写的时候不用回头改错别字、改句子，先一口气写完。

学生动笔写作

[教师巡视，只做正向介入，不纠错别字、不改病句、不打断书写顺畅的学生。按学情分四类处理：]

[接不下去型：写完开头几行就停住，盯着稿纸。把他引回构思表：“样子你已经写出来了。看第四栏，那件事还没有写，就从那天是怎么开始的写起。”]

[内容空泛型：整段都是“它对我很重要”“我一天也离不开它”一类的话。请他先指出那件东西上最具体的一处，就这一处问“它是什么样子”“那次是怎么弄成这样的”，答出一句就让他直接写进去。]

[书写顺畅型：不打断，走过时轻声说一句“接着写”，给他留出书写的空间。]

[草草收尾型：样子和事情各写了两三句就搁笔，说“写完了”，篇幅明显偏短。先肯定再推一步：“它坏过这一次，你写出来了。那你当时是怎么把它修好的？后来又是怎么爱护它的？把这几句补上，这件事就完整了。”]

[临近时间时提示：把手上这一句写到句号，停在合适的地方。没写完的不用赶，后面还有一段自改的时间可以接着补。]

### 三、交流评议，修改收束（约 17 分钟）

[传稿互读（约 4 分钟）：稿子朝同一个方向传给下一位，保证每个人的稿子都有邻座读到。读的人只读写样子的那一段，读完在稿末写下自己猜的是什么东西，再传回作者本人（猜对＝独有的样子写准了）。]

〖PPT 第22页 · 交流评议 · 稿子朝同一个方向传——邻座只读“样子”那一段〗

师：请大家停笔，把稿子朝同一个方向传给旁边的同学。拿到稿子的同学，只读他写样子的那一段。读完在稿子最后写一句：你猜他写的是什么东西。写完再把稿子传回去。

学生互动分享（只读写样子的那一段，在稿末写下猜测的是什么东西；教师控制节奏，一轮约 4 分钟）

师：现在拿回自己的稿子，看一看邻座猜的是什么。猜对了，说明你写的那些磨损、修补、残缺的地方，确实只有你的那一件才有；猜错了，或者他写不出来，说明写样子的那一段还停留在谁都有的样子上，那正是等一会儿要修改的地方。

〖PPT 第23页 · 交流评议 · 心爱之物展览会——开场〗

师：接下来请三位同学上台，读给大家听一听。

[心爱之物展览会（约 6 分钟）：三位学生依次朗读]

师：展览会开始。上台的同学不用整篇读，读开头那一句，再读你和它之间那件事的那一段就可以。台下的同学听完说两句：一句说你记住了它身上的哪一处，一句说你从这些文字里看出，这件东西对他有什么不一样。

学生互动分享（三位依次朗读；每一位读完，教师先请一两位同学点评，再自己补一句，只落在一点上：他写的哪一处痕迹，是别人的那一件所没有的。）

[对照标准修改（约 5 分钟）：按下面的档位表，各自修改三处：样子、事情、结尾。]

〖PPT 第24页 · 修改收束 · 先给自己定一个档位〗

师：现在对照这张表看一看，自己的这一篇到了哪一档，再按照标准往下改。

| 档位    | 自检的话                                                  |
| ----- | ----------------------------------------------------- |
| 写完整   | 它是什么、什么样子、怎么来的，都写清楚了。                     |
| 写具体   | 能写出物品独一无二的专属痕迹，不堆砌通用外形；完整讲述一件和物品相关的专属往事，把事情经过写细致、写清楚。 |
| 写得打动人 | 全篇没有写“我很喜欢它”，可读的人说得出这东西对我要紧。                |

师：改之前，我们回头看一眼那两段写滑板的话。上节课老师读的，一句是“它是深蓝色的，板面长八十厘米”，一句是“板尾的漆磨掉了一大片，露出底下的木头”。同样写滑板，哪一句更让你相信写的就是他自己的那一块？为什么？

参考：第二句／第一句商店里也这么写／磨损的痕迹是作者专属的、独一无二的经历印记。

〖PPT 第25页 · 修改收束 · 照着标准改——重点三处〗

师：现在就按照这个标准修改自己的文章，重点改三处。第一处，写样子的那一段：颜色、大小这些少写，确实要写的，一句带过；多添几处只有你那一件才有的地方，磨白的边角、缺了的一小块、修补过的地方。写小动物、写花草的同学，就换成只有它才有的那几处记号。第二处，写事情的那一段：如果只写了结果、没写经过，就补上一两句当时的动作和场景，把这件事写完整。第三处，从头看一遍那些直接说喜欢的句子。文中如果有“我很喜欢它”“它对我很重要”这样的话，试着划掉一两句，改用细节和事情来表达；保留也可以，两种写法都好，只是划掉以后再读一遍，看看这份心意是不是反而更清楚了。

师：这三处改完，再看一眼结尾。看看结尾是不是落在你平时和它相处的一个小动作上；如果不是，就添上这样一句。

师：最后用修改符号从头理一遍：错别字改过来，漏掉的字补上，多余的话删去。还没有写完的同学，先把正文补完，修改时选最重要的那一处细节改就可以。

学生动笔写作（自改；教师巡视答疑）

[收尾（约 2 分钟）]

〖PPT 第26页 · 收束 · 写一件物品——这套写法以后都用得上〗

师：大家发现了吗？今天写的这些心爱之物，大多不是什么贵重的东西：边角磨白了，缺了一块，修补过一次。不少同学一个“喜欢”、一个“舍不得”都没有写，可那份心意藏在文字里，我们全都读出来了。

师：下课以后，你可以把这篇文章放在那件东西旁边，也可以读给家人听，让他们知道，这件平常的东西身上，藏着属于你的一段故事。

师：今天这一套写法，以后写别的东西同样用得上：样子不必样样写到，抓住它身上独有的几处；再配上一件因它而发生的事；心意不必直接说，藏在细节里，读的人自然读得出来。以后写一处景、写一个人，也是这样的方法。

〖PPT 第27页 · 习作讲评 · 习作讲评环节（可选·课后或下次课开场）〗

## 附：习作讲评指导环节（可选 · 单次课课后用 / 系列课作下次课开场用）

> 本环节供教师灵活取用：可在单次课课后批阅学生习作后集中讲评一次，也可作为系列课下一次课的开场（约 15–20 分钟）；不计入本课 45+45 分钟，讲评的是学生当堂完成的稿子，不布置新的写作任务。
> 讲评中凡出现 ＿＿＿ 处，务必替换为本班学生习作中的真实句子，切勿虚构。

### 选稿（课前准备）

从本班当堂完成的稿子中选 2–3 篇，对照本课三条技法各选一类：一篇“三条都做到了”的（样子挑了独一份的几处、有一件因为它才发生的事、全篇没直说喜欢）；一篇“事写出来了、样子还停在颜色尺寸上”的中等篇；一篇“通篇在说很喜欢、看不出为什么”的待改进篇。每篇对照技法用一句话记下好在哪里、欠缺在哪里。讲评时投屏或朗读，不具名、不排名次。

### 讲评流程（每篇约 3–5 分钟，围绕本课技法点）

师：上次那场展览会，东西一样也没有搬来，全靠大家写的文字。今天我们回头看三篇稿子，只看一件事：读的人有没有通过文字看见那件东西，相不相信它对作者来说不一样。别的先不评。

师：先看第一篇。他写样子的这一段里有这样一句：“＿＿＿”（读该生写样子最见痕迹的一两句）。大家听，这几句话是从他那一件东西上来的，换到别人的东西上就不成立。

师：他那件事写在后面：“＿＿＿”（读该生写事的关键一两句）。这一句里有动作。有了这个动作，他一个“喜欢”都没有写，我们也相信了。

（教师总结）第一篇三条都做到了：样子选得准，事情有经过，喜欢没有说出口。

师：第二篇的那件事写得好：“＿＿＿”（读该生写事最具体的一句）。可是回头看他写样子的这一段，写的是“＿＿＿”（读该生停留在颜色、尺寸、材质上的那一句）。这一句放到商店里的同款上，一个字都不用改。

师：那么应该怎么改？

学生互动分享

师：对，把这一句换成它身上磨损、残缺、修补过的那一处。样子一换，前后就连贯了：上面写它身上的印记，下面写这个印记是怎么来的。

师：第三篇老师不念名字，只读一句：“＿＿＿”（读一句典型的直接说喜欢、却看不出原因的话）。这样的句子，我们班好几篇稿子上都有。老师想问问大家：把这一句划掉，剩下的内容还能不能让人看见这件东西？

学生互动分享

师：那就说明它还需要补充。补一处它身上磨损、残缺、修补过的地方，或者补一件因它而发生的事。补上以后，那句直接说喜欢的话，划掉也不可惜了。

（教师总结）这三篇不分高下，欠缺的是不同的东西：一篇缺一处别人那件上没有的样子，一篇缺一件事的经过，还有一篇两样都要补。

### 收尾（点回技法、引向今后的写作）

师：讲了三篇，其实反复说的就是那三条：样子选独有的几处，事情选因它而发生的那一件，喜欢不说出口。这三条不只写心爱之物管用。以后写一只小动物、写你常走的那条路，同样是这个方法：先找出它身上别处没有的几处痕迹，再找出和它一起发生过的那件事。稿子改好了，自己收好。

本环节完。

开场钩子: 实物道具式·回忆者（拿出一只用了九年的旧帆布包，先让学生猜年头与价钱；措辞不声明包属授课老师，用「主人」指代，老师换成自己的旧物则改说「我」）
主技法: 样子只挑它身上独一份的那几处写＋用一件因为它才发生过的事作证＋全篇不直说“我很喜欢它”
审题辨析形态: 两段对照判断（同写一块滑板：反例刻意写得细且比正例长——颜色尺寸图案、风从耳边呼呼过、玩一下午不想回家样样不少，可句句搬到任何一块同款滑板上都成立／正例只写板尾磨掉的那片漆与练急停摔出来的来历；判据落在“有哪一句只有他那块才写得出”而非“写得多不多”，预期会有学生选反例、参考答案与师话已备接住）
技法引出装置: 当场划句比对（老师先念一小段带三句直说“特别喜欢/太重要/离不开”的话，当场把这三句划掉重念一遍，让学生判断喜欢的劲儿淡没淡，得出“喜欢写在事情和动作里”）
示范文题材: 老师现在的日常生活（门后挂了九年的旧帆布包·背带崩断后自己缝的那道歪针脚）
