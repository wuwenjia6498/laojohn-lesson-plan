# 《我的心爱之物》· 写作课教学设计

五年级上册·第一单元 校内同步写作（状物习作）

[授课提示：开场那只旧帆布包与示范文里的那件事，都是备课时拟写的例子。正文已经避开“这是我每天背的”这类说法，老师照着讲不会说到自己头上；学生若问是不是老师的，直说“这是老师找来给你们看的”即可。老师手边真有一样用了多年的旧物，换成自己的更好——这一课讲的就是“东西背后有事”，讲自己那一件才立得住；替换时把五处一并换掉：开场三问的答案（年头、价钱、坏过又修的那件事）、第三环节当场念的那一小段、构思表的教师示范填写、示范文、旁批表里逐句引用的句子。手边没有合适旧物的，按稿子拿任一件旧物当例子讲即可，教学步骤与技法讲法不变。]

## 教案提纲表

| 课题·课时 | 五上·第一单元《我的心爱之物》　│　写景状物·校内同步　│　2课时连排（每节45分钟） |
| --- | --- |
| 能力阶段 | 写清楚 → 写具体 → 写生动（本课） → 写深刻·有章法 |
| 同类习作顺序 | 写景状物：缤纷世界／这儿真美 → 我的乐园／动物朋友／游＿＿ → 心爱之物（本课）／＿＿即景 |
| 教材要求 | 统编五上·第一单元习作：写出心爱之物的样子和它承载的情感。 |
| 学习目标 | 一篇能顶替实物的介绍：听的人从没见过你那件东西，光听你念完，能说出它长什么样，也能说出它为什么偏偏是你的。 |
| 核心技法 | 把“心爱”写成看得见的东西——样子只挑它身上**独一份的那几处**写，再用**一件因为它才发生过的事**作证，全篇不写“我很喜欢它”，让读的人自己看出来。（辅：开头一句话说清它是什么，中间样子、来历、那件事各成一段，结尾收一句。） |

## 第1课时 · 写作指导课

### 一、创设情境，明确任务（约 5 分钟）

师：（拿出一只旧帆布包放到桌上）老师带了样东西给你们看。你们看一眼，猜猜这个包用了几年？

参考：三年／五六年／看着挺旧了，得有十年吧。

师：九年。再猜一个：这样一个包，当初买多少钱？

参考：一百多／几十块钱。

师：五十八块。五十八块的包用了九年，中间还坏过一回，主人自己拿针线缝上了。外面商店里现在就有卖新的，一直没去换。你们说说看，这是为什么？

参考：用惯了／换了不习惯／有纪念意义／舍不得吧。

师：你们说到点子上了。一样东西在主人心里的分量，跟它值多少钱，往往没有多大关系。今天这两节课，我们每人写一样这样的东西，就是你自己的心爱之物。它可以是玩具、文具、一件旧衣服，也可以是你养的小动物、你种的一盆花，只要它对你不一样。

师：写完了，我们就在这间教室里开一场“心爱之物展览会”。稿子先传给旁边的同学，让他隔着你写的那几行字认一认你那件东西，再请几位念给全班听。

师：不过我们这场展览会有点特别：东西都不在。你那件这会儿在家里的柜子上、抽屉里、窗台上，谁也搬不来。展台上只有你写的这张稿子。听的人手里没有实物，全靠这张稿子认识它。他信不信它对你不一样，就看你写的这几行字。

师：什么算写成了？念完之后，听的人能说出它长什么样，还能说出它为什么偏偏是你的。什么算没写成？从头到尾都是“我很喜欢它”“它对我很重要”，一圈听下来，别人既记不住它长什么样，也说不出为什么是你的。

### 二、观察体验，找到你的心爱之物（约 8 分钟）

师：我们先从手边的东西说起。把身上、桌上、书包里的东西找一样出来，找你用得最久的那一样。铅笔盒、水杯、橡皮、挂在书包上的小东西，都行。

[等大多数学生把东西拿到手上再往下问；一时找不出的，让他就近看同桌那一样，跟着听。]

师：拿在手里，摸一摸。老师问一个问题：它身上有哪些痕迹，是刚买回来那天没有的？

参考：橡皮上划了好多道／水杯盖上的字掉了／铅笔盒角上磕掉一块漆／贴纸翘边了／笔杆上有牙印。

师：跟同桌说一说：这些痕迹里，哪一处是别人手上那一件没有的。

学生互动分享（同桌两人各说一遍，一人说完换另一人；教师蹲到两三组旁边听，做他们的第一个听众）

师：（请一位说过的同学）你那道划痕，是怎么来的？

参考：上次赶作业，橡皮从桌上掉下去，被椅子腿压了一下。

师：你们听，这一下就不一样了。刚才说的那些磨掉的漆、翘边的贴纸、掉下去磕的那一块，都不是买来就有的，是它跟着你过日子，一天一天留下来的。别人手上那一件就没有这几处。

师：现在把范围放大。今天要写的不一定是手上这一样。它可能这会儿正在你家书桌上、床头、柜子最上层。想一想：你那件在哪儿放着？你上一次拿起它是什么时候？

学生互动分享（举手抽说两三位；教师听到“养的仓鼠”“种的多肉”这类，明确肯定，不必都是物件）

〔应答·学生说不出哪一件最心爱、在两三样之间来回换〕不问“哪个最喜欢”，改问“哪一样你搬家会第一个装进箱子”，或者“哪一样丢了你会去找一整天”。答出来的那一样就是它。

（教师总结）挑定了就别再换。接下来的两节课，我们要做的事只有一件：让没见过它的人，隔着一张稿纸看见它。

### 三、学写法：写独一份的样子，用一件事作证（约 14 分钟）

师：我这儿有两段话，写的是同一样东西。听完你们告诉我，哪一段读完，你会觉得这东西对他不一样。

师：第一段——“我最心爱的东西是一块滑板。它是深蓝色的，板面长八十厘米，宽二十厘米，板底印着一只张着嘴的老虎，四个轮子是橡胶的，滑起来几乎没有声音。踩上去往前一蹬，风从耳朵边呼呼地过，那种痛快劲儿没法说。周末我常带着它去广场，一玩就是一下午，累得满头汗也不想回家。它给我带来了很多快乐，我非常喜欢它。”

师：第二段——“我那块滑板，板尾的漆磨掉了一大片，露出底下的木头，摸上去毛毛的。那片漆是去年夏天磨掉的，我在小区那道斜坡上练急停，摔了七八回，每回都是板尾先蹭地。现在我一低头，就能看见那片木头色。”

师：你们判断一下，是哪一段？

参考：第二段。／第一段吧，它写得挺细的。

师：两边都有人举手。说第一段的同学有道理——第一段写得确实不糙：颜色、尺寸、图案都交代了，风从耳朵边过、玩一下午不想回家，画面也有。可我要问一句：第一段这些话里，有哪一句是只有他那块滑板才写得出来的？

参考：好像都能／别人的滑板也这样／换一块也一样。

师：对了。第一段那些话，搬到任何一块同款滑板上，一个字都不用改。第二段不一样：板尾那片磨掉的漆、练急停摔的那七八回，别人那块上没有。今天要写的不是一份介绍，是要让读的人明白：这样东西为什么偏偏是你的。凡是换成别人那一件也照样成立的话，写了也白写。

师：那第二段是怎么做到的？我把它再念一遍，你们边听边数：它跟第一段的差别，一共有几处。

师：“我那块滑板，板尾的漆磨掉了一大片，露出底下的木头，摸上去毛毛的。那片漆是去年夏天磨掉的，我在小区那道斜坡上练急停，摔了七八回，每回都是板尾先蹭地。现在我一低头，就能看见那片木头色。”

参考：它写了磨掉的那块漆／它讲了摔跤那回事／它没说八十厘米那些。

师：前两处你们都找着了。还有一处最不好找，藏在结尾：第一段末了写了什么，第二段有没有？

参考：第一段写了“我很喜欢它”。／第二段一句喜欢都没有。

师：三处都出来了。老师给它们各起个名字，今天就练这三条。

师：第一条，写样子只挑它身上独一份的那几处。颜色、长短、材料是商品标签上的东西，谁的滑板都写得出；你们找出来的那块磨掉的漆，还有磨白的边、掉漆的角、缺的一块、补过的地方，才只有你那一件才有。

师：写的是养的小动物、种的花的同学，道理是一样的，只是那几处换个找法：找只有它才有的记号，右耳尖上那一小撮白毛、叶子缺掉的那个角、笼子边上被啃出的一道印。这些也是别人家那一只、那一盆上头没有的。

师：第二条，就是你们说的摔跤那回事——光有样子还不够，要用一件事作证。这件事得是“因为它”才有的：那道划痕是怎么来的，它坏过一回你怎么办的，它跟你去过哪儿、替你挡过什么。有了这一件事，别人才相信你说的“心爱”是真的。

师：第三条最难，就是你们最后找出来的那一处：全篇不写“我很喜欢它”。我先念一小段给你们听。这是老师照着这个包写的一小段，先听一遍——

〔教师示范·先念带直说句的一小段，再当场把那几句划掉重念一遍〕“这个包我特别喜欢。背带断过一回，是从书店出来那回，一包书压断的。我从鞋上抽下鞋带，穿过两个断头打了个死结，一路拎回家，晚上找出针线自己缝上了，针脚歪歪扭扭，一直没拆。它对我太重要了。每天出门，我第一个抓的就是它。我真是一天也离不开它。”

师：现在老师把三句话划掉：“这个包我特别喜欢”“它对我太重要了”“我真是一天也离不开它”。剩下的再听一遍——“背带断过一回，是从书店出来那回，一包书压断的。我从鞋上抽下鞋带，穿过两个断头打了个死结，一路拎回家，晚上找出针线自己缝上了，针脚歪歪扭扭，一直没拆。每天出门，我第一个抓的就是它。”

师：划掉三句以后，喜欢的劲儿是淡了，还是没淡？

参考：没淡／好像还更明显了／听得出来他舍不得。

师：划掉的那三句，谁写谁的东西都能安上去，安得一点不费劲。留下来的这几句——歪歪扭扭那道针脚、出门第一个抓它——只有那个包才有。所以喜欢不用说出口，把它写在事情和动作里，读的人自己就看出来了。

师：轮到你们试一句。想想你选定的那一样，说一句“因为它才有过的事”，说的时候不许出现“喜欢”两个字。想好了先小声说一遍。

学生互动分享（举手抽说两三位；教师点评时只点一处：他说的哪一句是别人搬不走的）

〔应答·学生说的事跟那样东西没关系（如“我拿它去过外婆家”）〕追问一句“那天它出了什么事，还是它派上了什么用场”，把事情往东西身上拉回来。

### 四、借助构思表，理清思路（约 9 分钟）

师：动笔之前，我们先用构思表把要写的收一收。每一格只写词，不写整句，自己看得懂就行。

| 项目 | 我的关键词 |
| --- | --- |
| 它是什么 |  |
| 它身上独一份的那几处 |  |
| 它是怎么来的 |  |
| 因为它发生过的那一件事 |  |
| 现在它放在哪儿、我常对它做什么 |  |

师：老师先填一张给你们看。填的就是桌上这个包。

| 项目 | 我的关键词 |
| --- | --- |
| 它是什么 | 深灰帆布包·背了九年 |
| 它身上独一份的那几处 | 下角磨白、侧袋一个洞、一道歪针脚 |
| 它是怎么来的 | 上班第一年·小店门口·五十八块 |
| 因为它发生过的那一件事 | 书店出来·背带崩断·鞋带绑着拎回家 |
| 现在它放在哪儿、我常对它做什么 | 挂在门后·出门先摘它 |

师：你们看老师这张表，跟平时写作文的句子比，哪儿不一样？

参考：全是词／没有一句整话／很短。

师：对，一格几个词就够，等会儿动笔再让它们长成句子。第二格和第四格最要紧，是今天那三条里的前两条。第三格是来历。它是谁给你的，还是自己攒钱买的，还是哪一回捡回来的；动笔时一句话带过就行，不用铺开。第四格不用写清楚经过，只写清是哪一件，等会儿动笔再展开。

学生动笔写作（填表约 3 分钟；教师巡视）

〔应答·学生第四格空着，说“它没发生过什么事”〕不催他想大事，改问三句：它有没有坏过、丢过？有没有你带着它去过什么地方？有没有哪一天你专门为它做过什么（洗、修、藏起来）？答出一样就填上。

师：填完的同学，小声把要写的从头说给自己听一遍——它是什么，什么样子，怎么来的，出过什么事。说到哪儿说不下去了，那一格就是你还没想清的。

学生自由分享（自说自听；教师巡视，听到说不下去的就地追问一句）

师：请两位说给大家听。其余同学听一件事：他说的这些里面，哪一处是别人搬不走的。所谓别人搬不走，就是这句话换到别人那一件上就说不通了。

学生互动分享（举手抽说两位；教师顺势点出他表上哪一格最值得展开）

### 五、出示示范文，发现写法（约 9 分钟）

师：你们表上都有东西了。现在老师把刚才填的那张表，整篇写出来给你们看。看的时候留意一件事：表上那几个词，是怎么变成一段一段的话的。

> 【教师示范文】
>
> 门后的挂钩上，常年挂着一只深灰色的帆布包。
>
> 它两个下角早磨白了，布纹稀得能看见底。右边侧袋破了一个洞，起先只有指甲盖那么大，现在能塞进一只拳头。最显眼的是背带靠肩那一段，缝着一道线，针脚一会儿密一会儿疏，歪歪扭扭地爬过去，颜色也比包身浅一截——那是我自己缝的。
>
> 包是上班第一年买的，在一家小店门口的架子上挂着，五十八块。那时候我每天要装的东西多，一摞作业本、水杯、伞，挑来挑去就挑中它，图它口子大。
>
> 那道针脚是第三年冬天留下的。那天我从书店出来，抱了六七本书塞进包里，走到路口，背带“啪”地一声从肩上滑下来，包砸在地上，书撒了一地。我蹲下去一本一本捡，风把书页吹得哗哗响。断口毛毛的，接不上。我从鞋上抽下一根鞋带，穿过那两个断头，打了个死结，一路拎回家。晚上找出针线，坐在灯下缝了半个多小时，手指扎了三四回。缝完看了半天，那道线难看得很，我没拆。
>
> 后来包又旧了些。出门的时候，我总是先把它从挂钩上摘下来，甩到肩上，再回头关门。有几回同事说，这包该换了。我说等它彻底背不动了再说。今天早上，我又是这么摘下它，走出门去。

师：先看整篇的框架。它一共分了几段，每一段各写的是什么？

参考：五段／第一段说它是什么／中间写样子、写怎么来的、写那件事／最后写现在。

师：开头一句话，把东西摆出来；中间样子、来历、那件事各占一段；结尾收在一个动作上。这个框架你们照着用就行。

师：我们再往细里看。第二段写样子，写了哪几处？

参考：磨白的角／破洞／那道针脚。

师：颜色、大小、什么牌子，一样也没写。写的全是这个包用出来的地方。这就是今天第一条。

师：那件事写在第几段？读完那一段，你信不信写这篇的人舍不得这个包？

参考：第四段／信／他都拿鞋带绑着拎回去了。

师：可这一整篇里，我有没有写过“我很喜欢这个包”？

参考：没有。

师：一次也没有。可你们刚才都说信。这就是今天第三条：喜欢不说出来，读的人反而更信。

师：最后再默读一遍，找一找：哪一句你读着读着，眼前就有这个包了？

学生互动分享

师：把你们挑出来的几句放在一起，对着看——

| 示范文里的句子 | 这一句在做什么 |
| --- | --- |
| 它两个下角早磨白了，布纹稀得能看见底 | 写样子，挑的是用出来的痕迹，不是买来就有的 |
| 右边侧袋破了一个洞，起先只有指甲盖那么大，现在能塞进一只拳头 | 同一处前后一比，年头就出来了 |
| 针脚一会儿密一会儿疏，歪歪扭扭地爬过去 | 这道线别人那个包上没有，是独一份的地方 |
| 包是上班第一年买的……五十八块 | 交代来历，一句带过，不铺开 |
| 背带“啪”地一声从肩上滑下来，包砸在地上，书撒了一地 | 那件事最要紧的一下，声音和动静都在里头 |
| 我从鞋上抽下一根鞋带，穿过那两个断头，打了个死结 | 一串动作，舍不得扔就落在这几下上 |
| 出门的时候，我总是先把它从挂钩上摘下来 | 每天都做的一个小动作，替他说了那句没说出口的话 |

师：这一篇写的就是桌上这个包。你们那一件是什么样、出过什么事，只有你自己知道，不用写得像老师这篇。要守住的只有那三条：样子挑独一份的几处，事情挑因为它才有的那一件，全篇不写“我很喜欢它”。

师：这节课到这儿，你们手上有三样东西：挑定的那一件、填好的构思表、刚才说顺了的那几句话。休息一下，回来就动笔。

本课完。

## 第2课时 · 当堂写作与评改课

### 一、看着构思表，写下开头几句（约 5 分钟）

师：把构思表拿出来，找到第一格“它是什么”。

师：这一格里的几个词，连起来其实就是一句话。老师表上填的是“深灰帆布包·背了九年”，连起来就是：“门后的挂钩上，常年挂着一只深灰色的帆布包。”你那一句是什么，现在空两格，写在第一行。

学生动笔写作

师：再看第二格。你在那一格里写了好几处，先别都写，只挑其中一处，就是你最想写的那一处。

师：接下来把这一处写到别人能认出来为止，三四句。有三个方向，你自己挑着用：一是它什么颜色、什么形状，多大一块——写的是这一处，不是整件东西；二是凑近看，这一处上头还有什么，是磨的，是划的，是缺了一块，还是补过的；三是它摸上去什么感觉，有没有声音、有没有味道。不用三样都写全，哪一样最像你那一件，就先写哪一样。

学生动笔写作

师：停一停，回头把你写的这几行读一遍。读的时候想一件事：光凭这几行，别人认不认得出它。后面就好写了，接着写它是怎么来的，再写因为它发生过的那一件事。

### 二、自由写作，把整篇写完（约 23 分钟）

师：现在一口气往下写，写二十分钟左右，把整篇写完。三件事记在心里：样子只挑独一份的那几处；中间要有一件因为它才发生过的事，那件事的经过要写清楚；全篇不写“我很喜欢它”。写到最后，像老师那篇一样，用它现在的一个小动作收一句。写的时候不用回头改字，先写到底。

学生动笔写作

[教师巡视，只做正向介入，不纠错字、不改病句、不打断书写顺畅的学生。按学情分四类处理——]

[接不下去型：写完开头那几行就停住、盯着稿纸——把他领回构思表：“样子你已经写出来了。看第四格，那件事还没上场呢，从那天怎么开头的写起。”]

[内容空泛型：整段都是“它对我很重要”“我一天也离不开它”一类的话——请他先指出那件东西上最具体的一处，就着这一处问“它什么样”“那回是怎么弄成这样的”，答出一句就让他直接写进去。]

[书写顺畅型：不打断，走过时轻声一句“接着写”，为其留出书写空间。]

[草草收尾型：样子和事情各写了两三句就搁笔说“写完了”、篇幅明显偏短——先肯定再推一步：“你写了它坏过一回，好。那天你是怎么弄回去的，后来怎么办的？把这两句补上。”]

[临近时间提示：把手上这一句写到句号，停在顺手的地方。没写完的不用赶，后面还有一段自改的时间可以接着补。]

### 三、交流评议，修改收束（约 17 分钟）

[传稿互认（约 4 分钟）：全排朝同一方向传一位，人人被邻座读到；读的人在稿末写下自己猜的是什么东西，再传回作者]

师：笔放下，稿子朝一个方向传给旁边的同学。拿到别人稿子的，先别通读，只看他写样子的那一段。看完在他稿子最下面写一样东西——你觉得他写的是什么。写完传回去。

学生互动分享（全排朝同一方向传一位；读一段、在稿末写下猜的东西、传回作者。教师控节奏，一轮走完约 4 分钟）

师：拿回自己的稿子，看一眼他写的是什么。跟你那件对上了，说明你那几处样子写准了——他手里没有实物，光凭你那几行字就认出来了。对不上，多半你写的是它跟别人那一件一样的地方，等会儿改稿先改这里。

师：每一排推一位出来。待会儿请其中三位念给全班听。

[心爱之物展览会（约 6 分钟）：三位学生依次念，每人只念开头那句和写那件事的那一段，约一分钟；每念完一位，请一两位听众说一句]

师：展览会开场。请上来的同学不用念整篇，念开头那一句，再念你写那件事的那一段。台下的同学听完说一句就行：你记住了它身上哪一处，或者，你听出那样东西对他有多要紧。

学生互动分享（三位依次念；每一位念完，教师随机请一两位听众说反应，再顺势点评一处具体的句子——点明是哪一句让人看见了它、哪一句让人信了它对他不一样。请听众发言时有意匀开，不重复请同一批同学）

[带标准修改（约 5 分钟）：延迟到此刻统一处理行文与错别字]

师：听完别人的，回自己的稿子上改。先对着这张表，看看自己写到哪一档。

| 档位 | 自检的话 |
| --- | --- |
| 写成了 | 它是什么、什么样子、怎么来的，我都写清楚了。 |
| 写好了 | 样子里有几处只有我那一件才有；我还写了一件因为它才发生的事，经过写清楚了。 |
| 写得让人信 | 我全篇没写“我很喜欢它”，可听的人能说出它对我有多要紧。 |

师：动手之前先判一句。上节课那两段滑板，我各抽一句出来：一句是“它是深蓝色的，板面长八十厘米”，一句是“板尾的漆磨掉了一大片，露出底下的木头”。写的是同一块滑板，你更信哪一句是他的？为什么？

参考：第二句／第一句商店里也这么写／磨掉的漆是他自己摔出来的。

师：拿这把尺子回自己的稿子上改。对着三条：第一，样子那一段里，把整件东西的颜色尺寸这类谁都写得出的话划掉一句，换成它身上磨的、缺的、补过的那一处，写小动物、写花的就换成只有它才有的那个记号；第二，那件事只有结果没有经过的，补一两句当时的动作；第三，找一找有没有“我很喜欢它”“它对我很重要”这样的句子，有就划掉，再读一遍，看看少了什么没有。

师：三条改完，再看一眼结尾，是不是停在它现在的一个小动作上。不是的话，添一句。

师：再用修改符号把稿子理一遍：写错的字改过来，漏掉的字补上，多出来的字圈掉。还没写完的同学，先把正文补完，改一处就行。

学生动笔写作（自改；教师巡视答疑）

[收尾（约 2 分钟）]

师：今天这些稿子上写的，多半是不值钱、也搬不上台的东西——磨白的边、缺了角的盖子、补过的一道线。可刚才念的时候，没有一个人把“喜欢”两个字写出来，我们全听出来了。

师：稿子带回去。愿意的话，把它放在那件东西旁边，或者念给家里人听听。那样东西在你这儿是怎么回事，他们多半还不知道。

（教师总结）这节课的方法，往后还用得上：写一样东西，样子挑它身上独一份的那几处，再用一件因为它才发生过的事作证，不把“喜欢”说出口，读的人自己会看出来。以后写一处地方、写一个人，也是这个办法。

本课完。

全课完。

## 附：习作讲评指导环节（可选 · 单次课课后用 / 系列课作下次课开场用）

> 本环节供老师灵活取用：可在单次课课后批读学生习作后集中讲评一次，也可作系列课下一次课的开场（约 15–20 分钟）；不计入本课 45+45 分钟，评的是学生当堂完成的稿子，不布置新的写作任务。
> 讲评中凡出现 ＿＿＿ 处，务必换成本班学生习作里的真实句子，切勿虚构。

### 选稿（课前准备）

从本班当堂完成的稿子里挑 2–3 篇，对着本课三条技法各挑一类：一篇“三条都做到了”的（样子挑了独一份的几处、有一件因为它才发生的事、全篇没直说喜欢）；一篇“事写出来了、样子还停在颜色尺寸上”的中等篇；一篇“通篇在说很喜欢、看不出为什么”的待改进篇。每篇用一句话对着技法记下它好在哪、欠在哪。讲评时投屏或朗读，不具名、不排名次。

### 讲评流程（每篇约 3–5 分钟，围绕本课技法点）

师：上次那场展览会，东西一样没搬来，全靠你们写的字。今天我们回头看三篇稿子，只看一件事：读的人有没有隔着纸看见那样东西、信不信它对他不一样。别的先不挑。

师：先看第一篇。他写样子这一段里有这么一句——“＿＿＿”（念该生写样子最见痕迹的一两句）。你们听，这几个字是从他那一件身上长出来的，换到别人那一件上就安不上去。

师：他那件事写在后头——“＿＿＿”（念该生写事的关键一两句）。这一句里有动作。有了这个动作，他一个“喜欢”都没写，我们也信了。

（教师总结）第一篇三条都在：样子挑得准，事情有经过，喜欢没说出口。

师：第二篇的那件事写得好——“＿＿＿”（念该生写事最具体的一句）。可回头看他写样子这一段，写的是“＿＿＿”（念该生停在颜色、尺寸、材质上的那一句）。这一句放到商店同款上，一个字都不用改。

师：那要怎么改？

学生互动分享

师：对，把这一句换成它身上那处磨的、缺的、补过的地方。样子一换，前后就接上了。上面写它身上的印子，下面写这印子是怎么来的。

师：第三篇我不念名字，只念一句：“＿＿＿”（念一句典型的直说喜欢、看不出所以然的话）。这样的句子，我们班好几张稿子上都有。我想问问大家：把这一句划掉，剩下的还能不能让人看见这样东西？

学生互动分享

师：那就说明它还得补。补一处它身上磨的、缺的、补过的地方，或者补一件因为它才发生的事。补上以后，那句直说喜欢的话，划掉也不可惜了。

（教师总结）这三篇不分高下，缺的是不一样的东西：一篇差一处别人那件上没有的样子，一篇差一件事的经过，还有一篇是两样都要补。

### 收尾（点回技法、引向今后的写作）

师：讲了三篇，其实来回就是那三条：样子挑独一份的几处，事情挑因为它才有的那一件，喜欢不说出口。这三条不只写心爱之物管用——往后写你家养的那只猫、写你常去的那条路，一样是这么办：先找出它身上别处没有的那几处痕迹，再找出跟它一块儿发生过的那件事。稿子改好了自己收着。

本环节完。
