# 《我的心爱之物》· 写作课教学设计

五年级上册·第一单元 校内同步写作（状物习作）

[授课提示：开场那只旧帆布包与示范文里的那件事，都是备课时拟写的例子。正文里教师对学生明说“这只包是老师特意为这节课找来的”，包的年头、价钱与缝补那件事由教师讲出，不冒充自己的经历；学生若追问，直说“故事是老师照着这只包写的”即可。示范文里的“我”是成年人，出示时只说“这是老师写的”，不必另作解释。教师手边真有一样用了多年的旧物、也愿意讲它，可以换成自己的，但要把七处一并换掉：开场交代的年头、价钱、坏过又修的那件事；第三环节当场读的那一小段（带抒情句、全划掉、只留一句三版必须逐字一致，差别只许在划掉的那几句）；构思表的教师示范填写；示范文；旁批表里逐句引用的句子；第二课时起步里引述的示范文起笔句；第五环节讲解示范文与结课时师话里点到的包和缝背带。手边没有合适旧物的，按稿子讲即可，教学步骤与方法讲法不变。]

## 教案提纲表

| 课题·课时  | 五上·第一单元《我的心爱之物》　│　写景状物·校内同步　│　2课时连排（每节45分钟）                     |
| ------ | --------------------------------------------------------------- |
| 能力阶段   | 写清楚 → 写具体 → 写生动（本课） → 写深刻·有章法                                   |
| 同类习作顺序 | 写景状物：缤纷世界／这儿真美 → 我的乐园／动物朋友／游＿＿ → 心爱之物（本课）／我最喜爱的季节                  |
| 教材要求   | 统编五上·第一单元习作：写出心爱之物的样子和它承载的情感。                                   |
| 学习目标 | 通过写一件物品上独有的痕迹和一件因它而起的事，来学习怎么写一篇状物的习作。 |
| 核心技法 | 使用“构思表”。样子只挑磨损的、修补过的、别处找不到的那几处来写，能写出前后变化的更好；再用一件因它而发生的事作证；喜爱之情可以直接说，也可以放进动作和细节里，两种写法自己选、可以搭配；结尾收在一个和它相处的日常小动作上。 |

## 第1课时 · 写作指导课

### 一、创设情境，明确任务（约 4 分钟）

〖PPT 第3页 · 创设情境 · 桌上这只旧包：从哪里看出它用了很久〗

师：（拿出一只旧帆布包放到桌上；手边没有实物的，直接投屏出示 PPT 上的图片）这只包是老师特意为这节课找来的。请大家仔细看一看：从哪里能看出它已经用了很久？看到一处就说一处，看到几处说几处。

参考：角上都磨白了／带子上有一道缝过的线／侧面破了一个小洞。

师：大家观察得很仔细。磨白的角、缝过的背带，都不是买来那天就有的。这只包用了九年，当初买的时候五十八元；背带断过一次，缝上以后接着用，没有换新的。外面的商店里随时可以买到新包，看着这些磨白的角和这道针脚，大家猜一猜，它的主人为什么一直没有换？

参考：用惯了，换了不习惯／舍不得，有纪念意义／自己缝过的，扔了可惜。

师：大家说得都有道理。一件东西在主人心里的分量，往往和它值多少钱没有多大关系。老师把这只包的故事写成了一篇文章，这节课后半段给大家看。今天这两节课，我们每人也来写这样一件物品，就是自己的心爱之物。它可以是玩具、文具、一件旧衣服，也可以是你养的小动物、你种的一盆花，只要它对你有着特别的意义，都可以写。

〖PPT 第4页 · 创设情境 · 今天的任务：办一场心爱之物展览会〗

师：大家写完以后，我们就在这间教室里开一场“心爱之物展览会”。写完的习作先传给旁边的同学，请他读一读，试着从文字里认识你的心爱之物。之后我们再请几位同学，把自己的习作读给全班同学听。

师：不过这场展览会有一个特别的地方：大家要写的物品大多放在家里，有的在柜子上，有的收在抽屉，还有的摆在窗台，没有办法搬到教室里来。展台上没有实物，只有我们写下的习作。同学们看不到真实物件，只能依靠文字去了解它。能不能让大家感受到你对它的珍视，就要看你的习作写得怎么样了。

〖PPT 第5页 · 创设情境 · 怎样算写得成功？〗

师：那怎样才算把这篇习作写好呢？读完你的习作，别的同学能够清楚说出这件物品的模样，还能明白它对于你的意义为什么格外特别。反过来，如果读完之后，大家说不清这件物品长什么样，也说不出它为什么对你格外特别，这篇习作就不算成功。

### 二、观察体验，找到你的心爱之物（约 8 分钟）

〖PPT 第6页 · 观察体验 · 摸一摸手边的物品：找买来那天没有的痕迹〗

师：我们先从手边的物品说起。请从身上、桌上、书包里找一件出来，找你用得最久的那一件。铅笔盒、水杯、橡皮、挂在书包上的小物件，都可以。

[等大多数学生把物品拿到手上再往下问；一时找不出的，让他就近看同桌那一件，跟着听。]

师：请把它拿在手里，摸一摸。它身上有哪些痕迹，是刚买回来那天没有的？

参考：橡皮少了一个角／水杯盖上的字掉了／笔袋上被划了一道／贴纸翘边了／笔杆上有牙印。

师：请和同桌说一说：这些痕迹里，哪一处是只属于你这一件物品的？

学生互动分享（同桌两人各说一遍，教师到两三组旁边倾听，做他们的第一个听众）

师：（请一位说过的同学）你那道划痕，是怎么来的？

参考：上次赶作业，橡皮从桌上掉下去，被椅子腿压了一下。

师：是的，说出了来历，这道划痕就有了自己的故事。刚才说的那些磨掉的漆、翘边的贴纸、掉下去磕的那一块，都不是买来就有的，都是它陪伴你一天天生活，慢慢留下来的专属印记。换成别人的同款物品，是不会有这些痕迹的。

〖PPT 第7页 · 观察体验 · 把范围放大：选定你要写的那一件〗

师：现在我们把范围放大。今天要写的不一定是手上这一件。它可能现在正放在你家的书桌上、床头、柜子最上层。想一想：你的那一件放在哪里？你上一次拿起它是什么时候？

学生互动分享（随机抽取两三位学生；教师听到“养的仓鼠”“种的多肉”这类，明确予以肯定）

〔应答·学生说不出哪一件最心爱、在两三件之间来回更换〕不问“哪个最喜欢”，改问“哪一样你搬家会第一个装进箱子”，或者“哪一样丢了你会特别着急，想要尽力去找”。答出来的那一样就是它了。

（教师总结）确定好写作对象之后，接下来这两节课都围绕它来写。我们集中完成一件事：借助笔下的文字，让没有见过这件物品的人，仿佛亲眼见到它一样。

### 三、学写法：写专属于它的印记与痕迹，用一件事作证（约 15 分钟）

〖PPT 第8页 · 判断对比 · 同写一块滑板：哪一段读完，能感到它对作者不一样〗

师：关于一块滑板，老师准备了两段描写。听完以后请大家说一说：哪一段读完，你会觉得这块滑板对写它的人不一样。

师：第一段：“我最心爱的东西是一块滑板。它是深蓝色的，板面长八十厘米，宽二十厘米，板底印着一只张着嘴的老虎，四个轮子是橡胶的，滑起来几乎没有声音。踩上去往前一蹬，风从耳朵边呼呼地过，那种痛快劲儿没法说。周末我常带着它去广场，一玩就是一下午，累得满头汗也不想回家。它给我带来了很多快乐，我非常喜欢它。”

师：第二段：“我那块滑板，板尾的漆磨掉了一大片，露出底下的木头，摸上去毛毛的。那片漆是去年夏天磨掉的，我在小区那道斜坡上练急停，摔了七八回，每回都是板尾先蹭地。现在我一低头，就能看见那片木头色。”

师：请大家判断一下，是哪一段？

参考：第二段。／第一段吧，它写得挺细的。

师：选第一段的同学，你说一说，第一段哪一点让你觉得它写得好？

参考：颜色、尺寸都写了，很细／有风从耳边呼呼过的画面／写了玩一下午不想回家。

师：说得都对，这些确实是它的好处。但是大家再想一想：如果换成另外一块一模一样的滑板，这段话是不是照样能用？这里面有没有只属于“他这一块滑板”的细节？

参考：好像都能／别人的滑板也这样／换一块也一样。

师：说得对。第一段的那些话，放到任何一块同款滑板上，一个字都不用改。第二段不一样：板尾那片磨掉的漆、练急停摔的那七八回，别人那块上没有。今天要写的不只是一份介绍，还要让读的人明白：这件物品对你为什么特别。如果写的内容放在别人的物品身上也完全适用，读的人就看不出它为什么偏偏是你的心爱之物。

师：那第二段是怎么做到的？老师把它再读一遍，大家边听边找：它和第一段的差别在哪里。

师：“我那块滑板，板尾的漆磨掉了一大片，露出底下的木头，摸上去毛毛的。那片漆是去年夏天磨掉的，我在小区那道斜坡上练急停，摔了七八回，每回都是板尾先蹭地。现在我一低头，就能看见那片木头色。”

参考：它写了磨掉的那块漆／它讲了摔跤那回事／它没写八十厘米那种每块滑板都一样的话。

〖PPT 第9页 · 学写法 · 两处差别，两个方法〗

师：两处差别都找出来了：一处是样子只写了那片磨掉的漆，一处是写了练急停摔出来的那件事。老师给它们各起一个名字。今天一共要练三个方法，前两个方法就从这两处差别里来。

〖PPT 第10页 · 方法一 · 写样子：只挑属于它的痕迹〗

师：第一个方法是：写样子的时候，只挑属于它的印记与痕迹来写。颜色、长短、材料是商品标签上的内容，谁的滑板都写得出这几项；大家找出来的那块磨掉的漆，还有磨白的边、掉漆的角、缺的一块、补过的地方，这才是你这件物品独有的细节。

师：打算写小动物、写花草的同学，道理是一样的，只是那几处痕迹要换一个找法：找只有它才有的记号，右耳尖上那一小撮白毛、叶子缺掉的那个角、笼子边上被啃出的一道印。这些独特的标记，在别的小动物、别的花草身上是看不到的。写的是别人送的、比赛得的、自己做的那几件，找法也一样：奖杯底座上刻的那行名字和日期，贝壳边上那一处缺口，围巾上织错了的那一针，只有你这一件上有。

〖PPT 第11页 · 方法二 · 找一件和它相关的事〗

师：第二个方法，就来自刚才滑滑板摔跤这个小故事。只写出物品的模样还不够，我们还要用一件事来承载这份情感。这件事要和这件物品紧密相关：比如这道划痕是怎么产生的，物品损坏时你是怎样修补照料它的，或是你带着它经历过的难忘瞬间。有了这样真实具体的故事，别人才相信你说的“心爱”是真的。

〖PPT 第12页 · 方法三 · 喜爱写在哪里：三版一起听〗

师：第三个方法，讲的是喜爱之情写在哪里。这篇习作要写出自己的喜爱之情，这是题目的要求。喜爱可以直接说出来，也可以放进事情和动作里，让别人自己读出来。两种写法怎么用，我们用一小段话来试一试。这是老师照着这个包写的一小段，先听第一版。

〔教师示范·先读带有直接抒发感受句子的一小段，再当场把那几句划掉重读一遍〕“这个包我特别喜欢。背带断过一回，是从书店出来那回，包里装了一大摞书，直接把背带扯断的。我把断开的两头拉过来，打了个死结临时接上，就这样拎着包往家走。晚上回家翻出针线，自己一针一线缝了起来，缝出来的针脚歪歪扭扭的，但我一点也不介意。它对我太重要了。每天出门，我第一个抓的就是它。我真是一天也离不开它。”

师：第二版。老师把三句直接抒发感受的话都划掉：“这个包我特别喜欢”“它对我太重要了”“我真是一天也离不开它”。剩下的再听一遍：“背带断过一回，是从书店出来那回，包里装了一大摞书，直接把背带扯断的。我把断开的两头拉过来，打了个死结临时接上，就这样拎着包往家走。晚上回家翻出针线，自己一针一线缝了起来，缝出来的针脚歪歪扭扭的，但我一点也不介意。每天出门，我第一个抓的就是它。”

师：第三版。老师只留一句，前两句照样划掉，把“我真是一天也离不开它”留在末尾：“背带断过一回，是从书店出来那回，包里装了一大摞书，直接把背带扯断的。我把断开的两头拉过来，打了个死结临时接上，就这样拎着包往家走。晚上回家翻出针线，自己一针一线缝了起来，缝出来的针脚歪歪扭扭的，但我一点也不介意。每天出门，我第一个抓的就是它。我真是一天也离不开它。”

师：三版都听完了。第一版有三句直接说喜欢的话，第二版一句也没有，第三版留了一句。大家比一比：第二版划掉三句以后，喜爱之情有没有变淡？第三版留下的那一句，放在末尾是不是多余？

参考：没有变淡，好像还更明显了／第三版那一句放在最后挺好的／第一版三句连着说，有点重复。

师：划掉的那三句，放到任何人的心爱之物上都能用；留下来的那几句，歪歪扭扭的那道针脚、出门第一个抓它，却是专属于这个帆布包的细节，喜爱藏在里面，读的人自己就能读出来。所以写喜爱有两种写法：一种像第一版那样直接说出来，一种像第二版那样放进事情和动作里。两种写法都对，也可以像第三版这样搭配着用，事情写足了，末尾点一句。要留心的只有一点：直接说的话，留一句就够；一连说三遍，读的人反而记不住那件事。

〖PPT 第13页 · 口头练笔 · 这种写法，《桂花雨》也在用〗

师：这个单元的《桂花雨》，整篇写的是小时候在院子里摇桂花那件事：抱着桂花树使劲摇，花落了一头一身，一家人把桂花收起来晒干，做糕点、泡茶。作者对故乡的思念，就放在摇桂花这件事里，读的人自己就读出来了。大家写心爱之物，也这样把喜爱放进一件事里。

师：现在轮到大家试一试。想一想你选好的心爱之物，说一说一件和它有关的事。这一次先试第二种写法：只说事情和动作，“喜欢”这个词先留着不说，看一看别人能不能听出来。想好以后，请先小声说一遍。

学生互动分享（随机抽取两三位同学分享；教师点评聚焦一点：找出发言里专属于他个人经历、不能套用到别人物品上的那句话）

〔应答·学生说的事和那件物品没有关系（如“我拿它去过外婆家”）〕追问一句“那天它出了什么事，还是它派上了什么用场”，把事情拉回到物品本身。

### 四、借助构思表，理清思路（约 9 分钟）

〖PPT 第14页 · 构思表 · 我的心爱之物·构思表〗

师：动笔之前，我们先用构思表把要写的内容理一理。每一栏只写关键词即可，不必写完整的句子，自己看得懂就可以。

| 项目                  | 我的关键词 |
| ------------------- | ----- |
| 它是什么                |       |
| 只属于它的特别痕迹           |       |
| 它是怎么来的              |       |
| 和它相关的一件难忘往事         |       |
| 它如今放在哪里，你平时和它相处的小细节 |       |

〖PPT 第15页 · 构思表 · 老师先填一张，全是关键词，没有完整的句子〗

师：老师先填一张给大家看。填的就是桌上这个包。

| 项目                  | 我的关键词                   |
| ------------------- | ----------------------- |
| 它是什么                | 深灰帆布斜挎包·背了九年            |
| 只属于它的特别痕迹           | 下角磨白、侧袋磨开一个不起眼的小洞、一道歪针脚 |
| 它是怎么来的 | 上班第一年·第一个月工资·小店门口·五十八元 |
| 和它相关的一件难忘往事         | 书店出来·背带崩断·打了个死结拎回家      |
| 它如今放在哪里，你平时和它相处的小细节 | 挂在门后·出门先摘它              |

师：大家看老师这张表，全是词，没有一句完整的话。一栏写几个词就够了，动笔时再把它们变成完整的句子。第二栏和第四栏最重要，是今天前两个方法要用的。第三栏是来历：它是谁给你的，是自己攒钱买的，还是哪一次捡回来的。动笔时一句话带过即可，不必展开讲。第四栏不必写清楚经过，只要记下这件事是什么，等到正式写作的时候，再把细节扩展开就可以。

学生动笔写作（填表约 3 分钟；教师巡视）

〔应答·学生第四栏空着，说“它没发生过什么事”〕可以试着问他三句话：它有没有坏过、丢过？你有没有带着它去过什么地方？有没有哪一天你专门为它做过什么（清洗、维修、收藏起来）？答出一项就填上。

师：填完的同学，可以小声地把要写的内容完整说一说：说一说这是一件什么物品，它有哪些特别的印记，它是怎么来到你身边的，还有你和它之间发生过的那件往事。如果讲到某一处说不下去、不顺畅，就说明这一部分你还没有梳理明白，可以再回头完善构思表。

学生自由分享（自说自听；教师巡视，听到说不下去的顺势追问一句）

师：请两位同学说给大家听。其余同学留心听一件事：在他讲的内容里，哪一处是只属于他那件心爱之物的。所谓只属于它，就是这句话放到别人的物品上就不合适了。

学生互动分享（从举手的学生中抽取两位；分享前先让他自己说一句“我打算把哪一栏写厚”，教师只确认理由说不说得通，不替他点）

### 五、出示示范文，发现写法（约 9 分钟）

〖PPT 第16页 · 教师示范文 · 那张表，变成了一篇文章〗

师：大家的构思表都填好了。现在老师把刚才填的那张表，整篇写出来给大家看。看的时候留意一件事：表上那几个关键词，是怎么变成一段一段的话的。

> 【教师示范文】
> 
> 我家门后的挂钩上，常年挂着一只深灰色的帆布斜挎包。
> 
> 它两个下角早磨白了，表层的布都快磨破了。右边侧袋磨开了一个不起眼的小洞，起先只有一粒米那么大，如今已经能伸进一根手指了。最显眼的是背带靠肩那一段，缝着一道线，针脚一会儿密一会儿疏，歪歪扭扭地爬过去，线的颜色也明显比包身浅一些——那是我自己缝的。
> 
> 包是我上班第一年，领到第一个月工资时买下的，就在一家小店门口的架子上挂着，五十八元。那时候我每天要装的东西很多，一摞作业本、水杯，还有太阳伞。选来选去我看中了这一只，它开口宽，大大小小的物件往里放很方便。
> 
> 那道针脚是第三年冬天留下的。那天我从书店出来，抱了八九本书塞进包里，走到路口，背带一下子断了，包从肩上滑下来，砸到地上，书撒了一地。我蹲下去，把书一本一本捡起来，风把书页吹得哗哗响。断掉的背带垂在两边，散着细碎的线头，我把断开的背带两端拉过来，打了个死结临时接上，就这样拎着包一路走回了家。晚上我找出针线，坐在灯下缝了半个多小时，才把断掉的背带缝好，手指都扎了三四回。缝完看了半天，那道线歪歪扭扭的，难看得很。我伸手扯了扯，挺牢的，就这样吧。
> 
> 后来包又旧了些。出门的时候，我总是先把它从挂钩上摘下来，甩到肩上，再回头关门。有几回同事说，这包该换了。我说等它彻底坏得不能用了再换。今天早上，我又是这么摘下它，走出门去。

〖PPT 第17页 · 读示范文 · 五个段落：这个框架可以照着用〗

师：先看整篇的框架。每一段各写的是什么？

参考：第一段说它是什么／中间写样子、写怎么来的、写发生过的那件事／最后写现在。

师：开头一句话，把物品点出来；中间三段，依次写样子、来历和与这只包相关的那件事；结尾收在一个动作上。这个框架大家照着用就可以。

师：我们再仔细看一看。第二段写背包的样子，写了哪几处？

参考：磨白的角／侧袋磨开的小洞／那道针脚。

师：这一段里颜色、大小、品牌，一项也没有写，写的全是这只包陪着我这些年留下的印记。这就是今天的第一个方法：只挑属于它的印记与痕迹来写。

师：和它相关的那件事写在第几段？读完那段话，你是不是相信写这篇文章的人舍不得这个包？

参考：第四段／相信／背带断了他也没扔，打个结拎回家，晚上还自己缝了半个多小时。

师：再看构思表。第四栏老师填的只有“书店出来·背带崩断·打了个死结拎回家”十几个字，到了文章里，这一栏变成了第四段。大家找一找，多出来的是什么？

参考：书撒了一地、风吹得书页哗哗响／蹲下去一本一本捡／晚上缝了半个多小时，手指扎了三四回／缝完扯了扯，说“就这样吧”。

师：多出来的全是动作和细节，喜爱之情就在这些动作里。这一篇老师用的是第二种写法，从头到尾没有直接说“我很喜欢这个包”。大家写的时候，两种写法自己选，也可以在结尾点一句。

师：最后再默读一遍，找一找：哪一句你读着读着，眼前就浮现出这个包的样子了？

学生互动分享

〖PPT 第18页 · 旁批表 · 把挑出的句子放在一起：这一句在做什么〗

| 示范文里的句子 | 这一句在做什么（句子表达效果） |
| --- | --- |

师：谁挑的句子不在表上？请说一说它在做什么。

学生互动分享（一两位；教师就他挑的句子补一句它落在哪个方法上）

师：这一篇写的就是桌上这个包。《桂花雨》写摇桂花，老师写缝背带，用的是同一个方法：感情放在一件事里。你的心爱之物是什么样、你和它之间发生过哪些事，只有你自己清楚，不必刻意模仿老师这篇。动笔时用上今天的三个方法：挑专属于它的痕迹写样子，选一件你和它之间的事，喜爱之情直接说或者放进细节里，自己选。

师：这节课到这里。大家手上已经准备好了三项内容：选定的心爱物品、填好的构思表、刚才已经说顺的思路。休息一下，回来就动笔。

## 第2课时 · 当堂写作与评改课

### 一、看着构思表，定下从哪里起笔（约 4 分钟）

〖PPT 第20页 · 定下起点 · 画圈定最厚的一处，再标 1、2、3〗

师：请把构思表拿出来。第二栏到第五栏一共四处内容：它的样子、来历、那件事、如今和它相处的小细节。这四处不必写得一样多。先判断一下：哪一处你最有话说，该写得最厚？多数同学选的会是第四栏那件事，也可能是第二栏的痕迹。在那一栏前面画一个圈。

学生动笔写作（在表上画圈）

师：再想一想，整篇从哪一句起笔。老师的示范文是从“我家门后的挂钩上，常年挂着一只深灰色的帆布斜挎包”起的，一句话把物品亮出来；你也可以从那处痕迹起，也可以从那件事起。在你打算第一个写的那一栏前面标“1”，剩下的按打算写的顺序标“2”“3”，画了圈的那一栏也标上它的顺序号。

学生动笔写作

师：请两位同学说一说，画了圈的是哪一处，为什么它最有话说。

学生互动分享（随机抽取两位；教师不评优劣，只确认他说得出理由）

师：定好以后就动笔，直接写在稿纸上。先写你画了圈的那一处，写四五句。如果它落在文章中间，就先留出前面的位置，等一会儿再补开头；如果你就从它起笔，它就是开头。写完这几句不用停，接着按表上的顺序往下写。

学生动笔写作

### 二、自由写作，把整篇写完（约 25 分钟）

〖PPT 第21-22页 · 自由写作 · 一口气写完整篇，记住三个方法〗

师：现在接着往下写，把整篇写完，时间是二十多分钟。记住三个方法：样子重点写它独有的痕迹，不必面面俱到；中间写一件你和它之间的事，把经过写具体；喜爱之情直接说或者放进细节里都可以，也可以搭配着用。结尾可以像老师的示范文那样，收在你日常和它相处的一个小动作上。写的时候一直往下写，先把全文写完，错别字和语句等一会儿再改。

学生动笔写作

[教师巡视，只做正向介入，不纠错字、不改病句、不打断书写顺畅的学生。按学情分四类处理：]

[接不下去型：写完起步那一处就停住、盯着稿纸。不问他写什么，问顺序：“你表上还有哪几处没写？哪一处接在这后面最顺？”他说出一处，就让他接着写那一处。]

[内容空泛型：整段都是“它对我很重要”“我一天也离不开它”一类的话。请他先指出那件物品上最具体的一处，针对这一处问“它什么样”“那回是怎么变成这样的”，答出一句就让他直接写进去。]

[书写顺畅型：走过时轻声一句“接着写”，不打断他写下去。]

[草草收尾型：样子和事情各写了两三句就停笔说“写完了”、篇幅明显偏短。先肯定再推一步：“你能写出它曾经损坏的经历，很好。那当时你是怎么修补它的？之后又是怎么爱护、对待它的？把这部分内容补充完整就更好了。”]

[临近时间提示：把手上这一句写到句号，停在合适的地方。没有写完的不必赶，后面还有一段自改的时间可以接着补。]

### 三、交流评议，修改收束（约 16 分钟）

[传稿互读（约 4 分钟）：全班稿件同向传递，每位同学的习作都能被邻座读到。读者重点读写样子的那一段，判断这些痕迹是只属于作者这一件、还是换一件同款也能用，在稿件末尾写下“只有这一件才有”或“换一件也能用”，传回作者本人。]

〖PPT 第23页 · 交流评议 · 习作互传：聚焦物品细节段落〗

师：请大家放下笔，把自己的习作传给旁边的同学。拿到同学习作的同学，重点读他写样子的那一段。读完只判断一件事：写的这些痕迹，是只有作者这一件才有，还是换一件同款也能用？在习作末尾写下你的判断，从这两句话里选一句：“只有这一件才有”，或者“换一件也能用”。写完交还给作者。

学生互动分享（读一段、在稿件末尾写下判断。教师把控节奏，一轮走完约 4 分钟）

师：请拿回自己的习作，看一看同学写的那句判断。如果他写的是“只有这一件才有”，说明样子抓准了；如果写的是“换一件也能用”，这一段就是等一会儿要改的第一处。

〖PPT 第24页 · 交流评议 · 心爱之物展览会：开场〗

师：接下来请每一排推选一位同学，老师从推选出来的同学里请三位上台，读自己的习作。

[心爱之物展览会（约 6 分钟）：三位学生依次朗读]

师：我们的展览会现在开场。上台的同学读三处：文章开头、写样子的那一段、写那件事的那一段。台下的同学认真听，听完说两点：一是你记住了这件物品身上的哪一处痕迹，二是你从哪一句里感受到它对作者的特别意义。

学生互动分享（三位依次朗读；每一位读完，教师随机抽取学生点评。每轮点评结束，教师作针对性点评：指出哪一处细节描写生动具体，让读者能“看见”物品；哪一段叙事真实动人，让读者体会到这份专属情谊。）

[带标准修改（约 4 分钟）：先问自己三个问题改三处，再用修改符号处理错别字、漏字与多余的句子。三档标准供教师掌握，不读给学生。]

〖PPT 第25页 · 修改收束 · 三档标准（教师掌握，可不投屏）〗

〔三档标准·教师掌握（不必读给学生）〕下表供教师判断学生习作所处档位，用于巡视点拨与附录讲评。

| 档位    | 自检                                                    |
| ----- | ----------------------------------------------------- |
| 写完整   | 它是什么、什么样子、怎么来的，都写清楚了。文章结构齐全、内容通顺。                     |
| 写具体   | 能写出物品独一无二的专属痕迹，不堆砌通用外形；完整讲述一件和物品相关的专属往事，把事情经过写细致、写清楚。 |
| 写得打动人 | 情感真挚：把喜爱放进细节和故事里，或者在事情写足后点上一句，读的人都能感受到这件物品对你的意义。 |

〖PPT 第26页 · 修改收束 · 照着标准修改：先问自己三个问题〗

师：刚才这几篇听下来，大家对自己那一篇还有哪里可以再改，心里多半有数了。现在就改自己的习作，先问自己三个问题。第一问，同学写的判断是不是“换一件也能用”？如果是，就把颜色、大小这类通用的话缩成一句，添上一处只有你这一件才有的痕迹；写小动物、植物的，换成只属于它的记号。第二问，那件事是不是只写了结果、没写经过？如果是，就补一两句当时的动作和画面。第三问，直接说喜欢的话是不是一连说了三遍或者更多？如果是，就留下一句放在最合适的地方，其余的换成一处细节。只写事情、一句不点也可以，两种写法都能写好。

师：三问改完，再看一看结尾：如果还没有收在你和它相处的一个小动作上，就补上一句。

师：最后用修改符号改错别字、补漏字、删多余的句子。还没有写完的同学，先补完正文，只改一处。

学生动笔写作（自改；教师巡视答疑）

[收尾（约 2 分钟）]

〖PPT 第27页 · 收束 · 写一件物品：这套方法以后同样适用〗

师：今天写的心爱之物，多半不是精致贵重的东西，它们有磨白的边角、细小的缺口、修补过的痕迹。如果你把喜爱放进了这些细节和那件事里，读的人不用你说，也能体会到。

## 附：习作讲评指导环节（可选 · 单次课课后用 / 系列课作下次课开场用）

> 本环节供教师灵活取用：可在单次课课后批读学生习作后集中讲评一次，也可作系列课下一次课的开场（约 15–20 分钟）；不计入本课 45+45 分钟，评的是学生当堂完成的习作，不布置新的写作任务。
> 讲评中凡出现 ＿＿＿ 处，务必换成本班学生习作里的真实句子，切勿虚构。

### 选稿（课前准备）

从当堂学生习作当中挑选 2–3 篇样本，分别对应三种不同层次，覆盖本课三项核心技法：

一篇优秀范例：做到三项要求，样子选的是物品独有的痕迹；写了一件和这件物品紧密相关的事；喜爱之情或者放在细节里，或者在事写足后点了一句，读完能感受到。

一篇中等习作：已经写出了和心爱之物有关的事件，但外形描写只停留在颜色、大小、材质这类所有同款物品都通用的介绍，缺少专属印记。

一篇待改进习作：通篇反复直接说喜欢，缺少独一无二的外形痕迹，也没有具体的事作支撑。

每一篇样本，对照本课三项核心技法简要批注优点与待改进之处。讲评过程中采用匿名朗读或者投屏展示，不公布作者姓名，不进行优劣排名。

### 讲评流程（每篇约 3–5 分钟，围绕本课技法点）

师：还记得我们那场特别的心爱之物展览会吗？大家的心爱之物都没有带到教室，读者只能依靠文字认识它。今天我们一起来回看三篇习作，评议的时候我们只看一个问题：读完文字，我们能不能仿佛亲眼看见这件物品，能不能感受到它对于作者那份独一无二的意义。其他问题暂时不作点评。

师：先来欣赏第一篇习作。大家听一听它描写外形的片段：“＿＿＿”（朗读文中刻画专属痕迹的一到两句话）。

师：听完这几句，大家有没有发现，这些细节只属于作者手里的那一件物品，放到别人同款的物品上，就套用不上了。这就是我们一直在找的、专属于它的印记。

师：我们再往后看他写的那件往事：“＿＿＿”（朗读叙事部分最关键的一两句）。

师：这句话里有实实在在的动作与画面。不需要作者直接说出“我很喜欢它”，我们自然而然就能感受到这份珍视。

（教师总结）第一篇三项要求都做到了：抓住了物品独有的痕迹来描写外形，写下了完整真切的往事，喜爱之情读的人自己就能感受到。

师：再来看看第二篇。它记录的这件往事写得很具体：“＿＿＿”（朗读习作中叙事最生动的一句）。但是回过头来看外形描写：“＿＿＿”（读出仅介绍颜色、大小、材质的句子）。像这样的文字，就算换到任意一件同款物品身上，也完全适用。

师：那我们可以怎样修改这一处呢？

学生互动分享

师：说得对。我们把这句通用的介绍，换成这件物品身上独有的印记，比如一处磨损、缺口或是修补过的痕迹。外形细节一改，文章前后就能呼应起来：前面写下它身上留下的印记，后面再讲一讲这道印记背后发生的故事。

师：最后来看第三篇，依旧匿名朗读其中一句话：“＿＿＿”（读出直接抒发喜爱，缺少具体支撑的典型语句）。我们班上不少同学的习作里，都出现过类似的句子。大家想一想：如果把这句直接抒情的话删掉，剩下的内容还能不能让读者看清这件物品，感受到你的心意？

学生互动分享

师：那就说明文章还需要补充内容。可以添上一处专属于它的痕迹，也可以补上一件和它有关的事。细节和故事到位之后，直接说喜欢的话留一句就够，情感照样传得出去。

（教师总结）三篇习作处在不同的完成阶段，各有写得好的地方，也各有还要补的地方：第二篇已经把故事写扎实了，还差一处独一无二的外形印记；第三篇能够直接表达自己的情感，但缺少一件具体的往事作为支撑；还有一部分同学，专属痕迹和相关故事两处都还需要再补充完善。

### 收尾（点回技法、引向今后的写作）

师：今天讲评的三篇习作，核心依旧是我们学到的三个方法：挑选专属于物品的痕迹刻画外形，选取一件因它而起的事，喜爱之情直接说或者放进细节里都可以。这几个方法并不只适用于本次心爱之物的习作。以后写家里养的小猫、常去散步的小路，都可以用上这个思路：先找到它身上与众不同的印记，再写下你和它之间发生过的事。修改完善后的习作大家自行收好。

本环节完。
