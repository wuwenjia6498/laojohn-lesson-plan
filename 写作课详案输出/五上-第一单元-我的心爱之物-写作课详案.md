# 《我的心爱之物》· 写作课教学设计

五年级上册·第一单元 校内同步写作（状物习作）

[授课提示：开场那只旧帆布包与示范文里的那件事，都是备课时拟写的例子。正文已经避开“这是我每天背的”这类说法，老师照着讲不会说到自己头上；学生若问是不是老师的，直说“这是老师找来给你们看的”即可。老师手边真有一样用了多年的旧物，换成自己的更好——这一课讲的就是“东西背后有事”，讲自己那一件才立得住；替换时把五处一并换掉：开场三问的答案（年头、价钱、坏过又修的那件事）、第三环节当场念的那一小段、构思表的教师示范填写、示范文、旁批表里逐句引用的句子。手边没有合适旧物的，按稿子拿任一件旧物当例子讲即可，教学步骤与技法讲法不变。]

## 第1课时 · 写作指导课

### 一、创设情境，明确任务（约 5 分钟）

〖PPT 第3页 · 创设情境 · 先猜三个数——桌上这只旧包〗

师：（拿出一只旧帆布包放到桌上）老师带了样东西给你们看。你们看一眼，猜猜这个包用了几年？

参考：三年／五六年／看着挺旧了，得有十年吧。

师：九年。再猜一个：这样一个包，当初买多少钱？

参考：一百多／几十块钱。

师：五十八块。五十八块的包用了九年，中间还坏过一回，主人自己拿针线缝上了。外面商店里就有卖新包的，但主人一直没买，还是用这个。你们说说看，这是为什么？

参考：用惯了／换了不习惯／有纪念意义／舍不得吧。

师：你们说到点子上了。一样东西在主人心里的分量，跟它值多少钱，往往没有多大关系。今天这两节课，我们每人写一样这样的东西，就是你自己的心爱之物。它可以是玩具、文具、一件旧衣服，也可以是你养的小动物、你种的一盆花，只要它对你的意义不一样，都可以写。

〖PPT 第4页 · 创设情境 · 今天的任务——办一场心爱之物展览会〗

师：写完了，我们就在这间教室里开一场“心爱之物展览会”。稿子先传给旁边的同学，让他通过你写的这篇作文，认一认你这件东西，再请几位同学念给全班听。

师：不过我们这场展览会有点特别：你们写的这些东西这会儿可能在家里的柜子上、抽屉里、窗台上，都不在现场，谁也搬不来。展台上只有你写的这篇作文。听的人看不见实物，全靠这篇作文认识它。他相不相信这个东西对你有特别的意义，就看你写的这篇文章了。

〖PPT 第5页 · 创设情境 · 什么算写成功了？〗

师：什么算写成功了？念完之后，听的人能说出它长什么样，还能说出它为什么偏偏是你的。什么算没写成功？从头到尾都是“我很喜欢它”“它对我很重要”，一圈听下来，别人既记不住它长什么样，也说不出为什么是你的。

### 二、观察体验，找到你的心爱之物（约 8 分钟）

〖PPT 第6页 · 观察体验 · 摸一摸手边那一样——找买来那天没有的痕迹〗

师：我们先从手边的东西说起。把身上、桌上、书包里的东西找一样出来，找你用得最久的那一样。铅笔盒、水杯、橡皮、挂在书包上的小东西，都行。

[等大多数学生把东西拿到手上再往下问；一时找不出的，让他就近看同桌那一样，跟着听。]

师：拿在手里，摸一摸。老师问一个问题：它身上有哪些痕迹，是刚买回来那天没有的？

参考：橡皮少了一个角／水杯盖上的字掉了／铅笔盒角上磕掉一块漆／贴纸翘边了／笔杆上有牙印。

师：跟同桌说一说：这些痕迹里，哪一处是别人手上那一件没有的。

学生互动分享（同桌两人各说一遍，教师蹲到两三组旁边听，做他们的第一个听众）

师：（请一位说过的同学）你那道划痕，是怎么来的？

参考：上次赶作业，橡皮从桌上掉下去，被椅子腿压了一下。

师：你们听，这一下就不一样了。刚才说的那些磨掉的漆、翘边的贴纸、掉下去磕的那一块，都不是买来就有的，是它跟着你过日子，一天一天留下来的。别人手上那一件就没有这几处。

〖PPT 第7页 · 观察体验 · 把范围放大——选定你要写的那一件〗

师：现在把范围放大。今天要写的不一定是手上这一样。它可能这会儿正在你家书桌上、床头、柜子最上层。想一想：你那件在哪儿放着？你上一次拿起它是什么时候？

学生互动分享（举手抽说两三位；教师听到“养的仓鼠”“种的多肉”这类，明确肯定）

〔应答·学生说不出哪一件最心爱、在两三样之间来回换〕不问“哪个最喜欢”，改问“哪一样你搬家会第一个装进箱子”，或者“哪一样丢了你会去找一整天”。答出来的那一样就是它了。

（教师总结）挑定了就别再换。接下来的两节课，我们要做的事只有一件：让没见过它的人，隔着一张稿纸看见它。

### 三、学写法：写专属于它的印记与痕迹，用一件事作证（约 14 分钟）

〖PPT 第8页 · 判断对比 · 同写一块滑板——哪一段读完，你觉得这东西对他不一样？〗

师：我这儿有两段话，写的是同一样东西。听完你们告诉我，哪一段读完，你会觉得这东西对他不一样。

师：第一段——“我最心爱的东西是一块滑板。它是深蓝色的，板面长八十厘米，宽二十厘米，板底印着一只张着嘴的老虎，四个轮子是橡胶的，滑起来几乎没有声音。踩上去往前一蹬，风从耳朵边呼呼地过，那种痛快劲儿没法说。周末我常带着它去广场，一玩就是一下午，累得满头汗也不想回家。它给我带来了很多快乐，我非常喜欢它。”

师：第二段——“我那块滑板，板尾的漆磨掉了一大片，露出底下的木头，摸上去毛毛的。那片漆是去年夏天磨掉的，我在小区那道斜坡上练急停，摔了七八回，每回都是板尾先蹭地。现在我一低头，就能看见那片木头色。”

师：你们判断一下，是哪一段？

参考：第二段。／第一段吧，它写得挺细的。

师：两边都有人举手。说第一段的同学有道理——第一段写得确实不糙：颜色、尺寸、图案都交代了，风从耳朵边过、玩一下午不想回家，画面也有。可我要问一句：第一段这些话里，有哪一句是只有他那块滑板才写得出来的？

参考：好像都能／别人的滑板也这样／换一块也一样。

师：对了。第一段那些话，搬到任何一块同款滑板上，一个字都不用改。第二段不一样：板尾那片磨掉的漆、练急停摔的那七八回，别人那块上没有。今天要写的不是一份介绍，是要让读的人明白：这样东西为什么偏偏是你的。凡是换成别人那一件也照样成立的话，写了也白写。

师：那第二段是怎么做到的？我把它再念一遍，你们边听边数：它跟第一段的差别，一共有几处。

师：“我那块滑板，板尾的漆磨掉了一大片，露出底下的木头，摸上去毛毛的。那片漆是去年夏天磨掉的，我在小区那道斜坡上练急停，摔了七八回，每回都是板尾先蹭地。现在我一低头，就能看见那片木头色。”

参考：它写了磨掉的那块漆／它讲了摔跤那回事／它没说八十厘米那些每个滑板都具备的特点。

师：前两处你们都找着了。还有一处最不好找，藏在结尾：第一段末了写了什么，第二段有没有？

参考：第一段写了“我很喜欢它”。／第二段一句喜欢都没有。

〖PPT 第9页 · 学写法 · 今天练三个写作小妙招〗

师：三处差别都找出来了。老师给它们各起个名字，今天就练习这三个写作小妙招。

〖PPT 第10页 · 妙招一 · 商品标签上的话不算样子〗

师：第一条，写样子只挑属于它的印记与痕迹来写。颜色、长短、材料是商品标签上的东西，谁的滑板都写得出这几样；你们找出来的那块磨掉的漆，还有磨白的边、掉漆的角、缺的一块、补过的地方，才是只有你那一件才有的。

师：写的是养的小动物、种的花的同学，道理是一样的，只是那几处换个找法：找只有它才有的记号，右耳尖上那一小撮白毛、叶子缺掉的那个角、笼子边上被啃出的一道印。这些也是别人家那一只、那一盆上头没有的。

〖PPT 第11页 · 妙招二 · 找一件因为它才发生过的事〗

师：第二条，就是你们说的摔跤那回事——光有样子还不够，要用一件事作证。这件事得是“因为它”才有的：那道划痕是怎么来的，它坏过一回你怎么处理的，你带着它经历过哪些难忘的小事。有了这一件事，别人才相信你说的“心爱”是真的。

〖PPT 第12页 · 妙招三 · 把这三句划掉——喜欢的劲儿淡了吗？〗

师：第三条就是我们刚刚对比发现的表达小妙招：我们可以试着不靠直白说出“我很喜欢它”，只用故事和动作，就能让别人感受到这份喜爱。我先念一小段给你们听。这是老师照着这个包写的一小段，先听一遍 ——

〔教师示范·先念带有直接抒发感受句子的一小段，再当场把那几句划掉重念一遍〕“这个包我特别喜欢。背带断过一回，是从书店出来那回，一包书压断的。我从鞋子上解下一根鞋带，把断掉的背带两头系紧，打了个死结，就这样拎着包往家走。晚上回家翻出针线，自己一针一线缝了起来，缝出来的针脚歪歪扭扭的，直到现在我也没有拆掉。它对我太重要了。每天出门，我第一个抓的就是它。我真是一天也离不开它。”

师：现在老师把三句直接抒发感受的话先暂时划掉：“这个包我特别喜欢”“它对我太重要了”“我真是一天也离不开它”。剩下的再听一遍——“背带断过一回，是从书店出来那回，一包书压断的。我从鞋子上解下一根鞋带，把断掉的背带两头系紧，打了个死结，就这样拎着包往家走。晚上回家翻出针线，自己一针一线缝了起来，缝出来的针脚歪歪扭扭的，直到现在我也没有拆掉。每天出门，我第一个抓的就是它。”

师：划掉三句以后，喜欢的劲儿是淡了，还是没淡？

参考：没淡／好像还更明显了／听得出来他舍不得。

师：划掉的那三句，放到任何人的心爱之物上都能用。留下来的这几句 —— 歪歪扭扭那道针脚、出门第一个抓它 —— 却是专属于这个帆布包的细节。所以除了直接说出心中的喜爱，我们还有另一种写法：把喜爱藏进事情和动作里，读者自己就能体会出来。两种写法都可行，搭配在一起效果会更好。

〖PPT 第13页 · 口头练笔 · 这一招，《桂花雨》就在用〗

师：这样的写法，课本里这个单元的课文就在用。《桂花雨》整整一篇写的是小时候在院子里摇桂花那件事——抱着桂花树使劲摇，花落了一头一身，接着一家人把落下的桂花收起来晒干，做糕点、泡茶。作者从头到尾没写过一句“我很想念家乡”，可读完的人都明白她想。这个单元学的正是这一招：把感情放进一件具体的事里，让读的人自己读出来。今天你们写自己那一样东西，用的是同一个办法。

师：轮到你们试试看。我们先来挑战一种新写法：想想你选定的那一样东西，说一句“因为它才有过的事”，这一次先不使用“喜欢”这类直接抒情的词语。想好了先小声说一遍。

学生互动分享（举手抽两三位同学分享；教师点评时只点一处：他说的哪一句是独属于自己，别人无法用的）

〔应答·学生说的事跟那样东西没关系（如“我拿它去过外婆家”）〕追问一句“那天它出了什么事，还是它派上了什么用场”，把事情往东西身上拉回来。

### 四、借助构思表，理清思路（约 9 分钟）

〖PPT 第14页 · 构思表 · 我的心爱之物·构思表〗

师：动笔之前，我们先用构思表把要写的收一收。每一格只写关键词就行，不用写完整的句子，自己看得懂就行。

| 项目                  | 我的关键词 |
| ------------------- | ----- |
| 它是什么                |       |
| 只属于它的特别痕迹           |       |
| 它是怎么来的              |       |
| 和它之间发生过的一件事         |       |
| 它如今放在哪里，你平时和它相处的小故事 |       |

〖PPT 第15页 · 构思表 · 老师先填一张——全是词，没有一句整话〗

师：老师先填一张给你们看。填的就是桌上这个包。

| 项目                  | 我的关键词             |
| ------------------- | ----------------- |
| 它是什么                | 深灰帆布包·背了九年        |
| 只属于它的特别痕迹           | 下角磨白、侧袋一个洞、一道歪针脚  |
| 它是怎么来的              | 上班第一年·小店门口·五十八块   |
| 和它之间发生过的一件事         | 书店出来·背带崩断·鞋带绑着拎回家 |
| 它如今放在哪里，你平时和它相处的小故事 | 挂在门后·出门先摘它        |

师：你们看老师这张表，跟平时写作文的句子比，哪儿不一样？

参考：全是词／没有一句整话／很短。

师：对，一栏几个词就够，等会儿动笔再把它们变成长句子。第二栏和第四栏最重要，是今天那三条写作小妙招里的前两条。第三栏是来历。它是谁给你的，还是自己攒钱买的，还是哪一回捡回来的；动笔时一句话带过就行，不用展开讲。第四栏不用写清楚经过，只要记下这件事是什么，等到正式写作的时候，再把细节扩展开就可以。

学生动笔写作（填表约 3 分钟；教师巡视）

〔应答·学生第四栏空着，说“它没发生过什么事”〕不催他想大事，改问三句：它有没有坏过、丢过？你有没有带着它去过什么地方？有没有哪一天你专门为它做过什么（清洗、维修、藏起来）？答出一样就填上。

师：填完的同学，小声把要写的从头说给自己听一遍——它是什么，什么样子，怎么来的，发生过什么事情。说到哪一栏说不下去了，那里就是你还没想清楚的。

学生自由分享（自说自听；教师巡视，听到说不下去的顺势追问一句）

师：请两位说给大家听。其余同学留心听一件事：在他讲的内容里，哪一处是只属于他的心爱之物。所谓只属于他，就是这句话放到别人的物品身上就不合适了。

学生互动分享（举手抽说两位；教师顺势点出他表上哪一格最值得展开）

### 五、出示示范文，发现写法（约 9 分钟）

〖PPT 第16页 · 教师示范文 · 那张表，变成了一篇文章〗

师：你们的构思表都填好了。现在老师把刚才填的那张表，整篇写出来给你们看。看的时候留意一件事：表上那几个关键词，是怎么变成一段一段的话的。

> 【教师示范文】
> 
> 我家门后的挂钩上，常年挂着一只深灰色的帆布包。
> 
> 它两个下角早磨白了，表层的布都快磨破了。右边侧袋破了一个洞，起先只有指甲盖那么大，现在能塞进一只拳头。最显眼的是背带靠肩那一段，缝着一道线，针脚一会儿密一会儿疏，歪歪扭扭地爬过去，线的颜色也明显比包身浅一些——那是我自己缝的。
> 
> 包是我上班第一年买的，在一家小店门口的架子上挂着，五十八块。那时候我每天要装的东西很多，一摞作业本、水杯，还有太阳伞。选来选去我看中了这一只，它开口宽，大大小小的物件往里放很方便。
> 
> 那道针脚是第三年冬天留下的。那天我从书店出来，抱了六七本书塞进包里，走到路口，背带“啪”地一声断了，包包从肩上滑下来，砸到地上，书撒了一地。我蹲下去，把书一本一本捡起来，风把书页吹得哗哗响。断掉的背带散着细碎的线头。我从鞋上抽了根鞋带，把断掉的两端扎牢，打了个死结，一路拎回家。晚上我找出针线，坐在灯下缝了半个多小时，手指都扎了三四回。缝完看了半天，那道线歪歪扭扭的，难看得很，但是我没拆。
> 
> 后来包又旧了些。出门的时候，我总是先把它从挂钩上摘下来，甩到肩上，再回头关门。有几回同事说，这包该换了。我说等它彻底坏得不能用了再换。今天早上，我又是这么摘下它，走出门去。

〖PPT 第17页 · 读示范文 · 五个段落——这个框架你照着用就行〗

师：先看整篇的框架。它一共分了几段，每一段各写的是什么？

参考：五段／第一段说它是什么／中间写样子、写怎么来的、写发生过的那件事／最后写现在。

师：开头一句话，把东西亮出来；中间样子、来历、发生的那件事各占一段；结尾收在一个动作上。这个框架你们照着用就行。

师：我们再往细里看。第二段写背包的样子，写了哪几处？

参考：磨白的角／破洞／那道针脚。

师：颜色、大小、什么牌子，一样也没写，写的全是这只包陪伴我留下的印记。这就是今天第一条小妙招，只挑属于它的印记与痕迹来写。

师：共同经历的那件事写在第几段？读完那段话，你相不相信写这篇文章的人舍不得这个包？

参考：第四段／相信／他都拿鞋带绑着拎回去了。

师：可这一整篇里，我有没有写过“我很喜欢这个包”？

参考：没有。

师：一次也没有。可你们依然能够感受到我对它的感情。这就是今天学到的第三个小妙招：不用直白说出喜爱，读者也能从文字里体会到这份心意。

师：最后再默读一遍，找一找：哪一句你读着读着，眼前就浮现出这个包的样子了？

学生互动分享

## 第2课时 · 当堂写作与评改课

### 一、看着构思表，写下开头几句（约 5 分钟）

〖PPT 第20页 · 写作热身 · 第一栏连成开头一句，第二栏挑一处细节〗

师：把构思表拿出来，找到第一栏“它是什么”。

师：这一栏里的几个词，连起来其实就是一句话。老师表上填的是“深灰帆布包·背了九年”，连起来就是：“门后的挂钩上，常年挂着一只深灰色的帆布包。”你那一句是什么，现在空两格，写在第一行。

学生动笔写作

师：再看第二栏。你在那一栏里写了好几个关键词，先别都展开写，只挑其中一个，就是你最想写的那一个关键词来写。

师：接下来把这一处细节写清楚，让别人一看就能认出它，写上三四句话就可以。大家可以从三个角度任选其一展开：第一，描写这一处痕迹的颜色、形状和大小，注意只聚焦这个细节，不要把整件物品从头写到尾；第二，仔细观察，写写这一处是什么样子，是磨损留下的印记、一道划痕、一处缺口，还是后来修补过的痕迹；第三，写写手摸上去的触感，如果有特别的气味或者声响也可以加上。这三点不需要全部写完，哪一点最能体现这件物品的特点，就重点写哪一点。

学生动笔写作

师：停一停，回头把你写的这几行读一遍。读的时候想一想：只看这一小段细节描写，别人能不能认出这就是你的那件心爱之物。后面接着往下写就可以了：先写写它的来历，再写下你和它之间难忘的那件往事。

### 二、自由写作，把整篇写完（约 23 分钟）

〖PPT 第21页 · 自由写作 · 一口气写完整篇——记住三件事〗

师：现在一口气往下写，写二十分钟左右，把整篇写完。大家牢记三个写作要点：重点描写物品独有的专属痕迹，不用面面俱到；中间写一件你和它亲身经历的难忘往事，把事情的经过写具体、写清楚；抒情可以藏在细节里，不用直白写出“我很喜欢它”。结尾可以参考老师的范文，用你日常和它相处的一个小动作收尾。写作过程中不用回头修改错别字和语句，先专心把全文完整写完。

学生动笔写作

[教师巡视，只做正向介入，不纠错字、不改病句、不打断书写顺畅的学生。按学情分四类处理——]

[接不下去型：写完开头那几行就停住、盯着稿纸——把他领回构思表：“样子你已经写出来了。看第四栏，亲身经历的那件事还没写呢，从那天怎么开头的写起。”]

[内容空泛型：整段都是“它对我很重要”“我一天也离不开它”一类的话——请他先指出那件东西上最具体的一处，就着这一处问“它什么样”“那回是怎么弄成这样的”，答出一句就让他直接写进去。]

[书写顺畅型：不打断，走过时轻声一句“接着写”，为其留出书写空间。]

[草草收尾型：样子和事情各写了两三句就搁笔说“写完了”、篇幅明显偏短——先肯定再推一步：“你能写出它曾经损坏的经历，特别棒！那当时你是怎么修补它的？之后又是怎么爱护、对待它的？把这部分内容补充完整就更好了。”]

[临近时间提示：把手上这一句写到句号，停在顺手的地方。没写完的不用赶，后面还有一段自改的时间可以接着补。]

### 三、交流评议，修改收束（约 17 分钟）

[传稿互读（约 4 分钟）：全班稿件同向传递，每位同学的习作都能被邻座阅读。读者重点品读外形细节段落，感受物品的专属特点，判断是否写出了独有的个人痕迹，读完写下感受后传回作者本人。]

〖PPT 第22页 · 交流评议 · 稿子朝同一个方向传——邻座只读“样子”那一段〗

师：请大家停下笔，将习作稿子统一朝同一个方向传给身边的同学。拿到别人习作的同学，重点品读文中描写物品样子、外观细节的段落，用心感受：这些描写，是随便哪一件同款物品都有的普通样子，还是只属于作者这一件的独特痕迹。判断好之后，直接把稿子传回原作者。

学生互动分享（读一段、在稿件末尾写下你的简单感受。教师控节奏，一轮走完约 4 分钟）

师：现在拿回自己的习作，回想一下刚刚同伴的阅读判断。如果你写的磨损、修补、专属印记等细节，让人一眼就能看出独一无二，说明外形描写抓得很准；如果读起来和普通物品没区别，看不出专属特点，这就是我们接下来重点修改的地方。

〖PPT 第23页 · 交流评议 · 心爱之物展览会——开场〗

师：接下来请每一排推选一位同学，我会随机邀请三位同学，上台分享自己的习作。

[心爱之物展览会（约 6 分钟）：三位学生依次念]

师：展览会开场。上台的同学不用朗读整篇作文，只读文章开头，以及你和物品发生难忘故事的段落即可。台下的同学认真倾听，听完后简单分享两点感受：一是你记住了这件物品的哪一处独特细节，二是你从文字里感受到这件物品对作者的特殊意义。

学生互动分享（三位依次念；每一位念完，教师随机抽取学生点评。每轮点评结束，教师针对性点评：精准指出哪一处细节描写生动具象，让读者能亲眼“看见”物品；哪一段叙事真实动人，让读者真切体会到这份专属情谊。）

[带标准修改（约 5 分钟）：集中统一修正语句、错别字、语序问题，对标习作档位标准，针对性优化全文。]

〖PPT 第24页 · 修改收束 · 先给自己定一个档位〗

师：听完大家的分享与点评，相信大家都找到了自己习作的优缺点。现在请大家对照这份自评标准，给自己的习作定一个档位，再有针对性地修改完善。

| 档位    | 自检的话                                                  |
| ----- | ----------------------------------------------------- |
| 写完整   | 它是什么、什么样子、怎么来的，都写清楚了。文章结构齐全、内容通顺。                     |
| 写具体   | 能写出物品独一无二的专属痕迹，不堆砌通用外形；完整讲述一件和物品相关的专属往事，把事情经过写细致、写清楚。 |
| 写得打动人 | 依靠细节和故事寄托情感，让读者读完就能体会到这件物品的珍贵、感受到真挚心意。                |

师：修改之前，老师给大家举一组对比例子，大家认真体会。之前有两位同学写滑板，一句写“它是深蓝色的，板面长八十厘米”，另一句写“板尾的漆磨掉了一大片，露出底下的木头”。同样是写滑板，大家更相信哪一句是作者专属的滑板？为什么？

参考：第二句／第一句商店里也这么写／磨损的痕迹是作者专属的、独一无二的经历印记。

〖PPT 第25页 · 修改收束 · 照着标准改——重点三处〗

师：大家说得非常好！现在就用这个标准修改自己的习作。重点做好三处修改：第一，优化外形段落：颜色、大小这类基础的通用描写尽量少写，如果要写，一句话带过即可，多增添专属于你的独特痕迹，比如磨损的边角、细小的缺口、修补的印记等；如果写的是小动物、植物，就替换成只属于它的专属特征。第二，如果叙事段落只有结果、缺少过程，就补充一两句关键动作、场景细节，让故事更完整。第三，检查全文，试着弱化直白抒情的语句。如果文中有“我很喜欢它”“它对我很重要”这类直接表态的句子，可以尝试删掉，改用细节和故事传递情感；当然保留直白抒情也可以，两种写法都出彩，试着用细节藏情，读完再感受一下，文章的真情实感会不会更自然真挚。

师：三处内容修改完成后，再检查一遍结尾。看看结尾是否落在你和物品日常相处的小动作上，做到自然收束、余味悠长，如果没有，就补充一句贴合文意的结尾。

师：最后用规范的修改符号梳理全文：修正错别字、补全漏字、删去冗余语句。还没有写完习作的同学，优先补完正文内容，重点优化一处核心细节即可。

学生动笔写作（自改；教师巡视答疑）

[收尾（约 2 分钟）]

〖PPT 第26页 · 收束 · 写一件物品——这套写法以后都用得上〗

师：大家发现没有，今天我们写的心爱之物，大多不是精致贵重的东西，它们或许有着磨白的边角、残缺的缺口、修补过的痕迹。很多同学没有直白写出“喜爱”“不舍”这类词语，但藏在细节的真心，我们所有人都能真切体会到。

师：课后大家可以把习作放在对应的物品旁边，也可以读给家人听。让家人了解，这件普通的物品，藏着属于你的专属故事与珍贵回忆。

师：最后老师总结一下本节课的写作方法，这个方法适用所有写物作文：写一件物品，不用堆砌通用外形，重点抓住它独有的专属痕迹，搭配一件独一无二的专属往事寄托情感。不必直白抒情，藏在细节里的心意，读者自然能读懂。这套写法，后续写景物、写人物，同样适用。

〖PPT 第27页 · 习作讲评 · 习作讲评环节（可选·课后或下次课开场）〗

## 附：习作讲评指导环节（可选 · 单次课课后用 / 系列课作下次课开场用）

> 本环节供老师灵活取用：可在单次课课后批读学生习作后集中讲评一次，也可作系列课下一次课的开场（约 15–20 分钟）；不计入本课 45+45 分钟，评的是学生当堂完成的稿子，不布置新的写作任务。
> 讲评中凡出现 ＿＿＿ 处，务必换成本班学生习作里的真实句子，切勿虚构。

### 选稿（课前准备）

从本班当堂完成的稿子里挑 2–3 篇，对着本课三条技法各挑一类：一篇“三条都做到了”的（样子挑了独一份的几处、有一件因为它才发生的事、全篇没直说喜欢）；一篇“事写出来了、样子还停在颜色尺寸上”的中等篇；一篇“通篇在说很喜欢、看不出为什么”的待改进篇。每篇用一句话对着技法记下它好在哪、欠在哪。讲评时投屏或朗读，不具名、不排名次。

### 讲评流程（每篇约 3–5 分钟，围绕本课技法点）

师：上次那场展览会，东西一样没搬来，全靠你们写的字。今天我们回头看三篇稿子，只看一件事：读的人有没有隔着纸看见那样东西、信不信它对他不一样。别的先不挑。

师：先看第一篇。他写样子这一段里有这么一句——“＿＿＿”（念该生写样子最见痕迹的一两句）。你们听，这几个字是从他那一件身上长出来的，换到别人那一件上就安不上去。

师：他那件事写在后头——“＿＿＿”（念该生写事的关键一两句）。这一句里有动作。有了这个动作，他一个“喜欢”都没写，我们也信了。

（教师总结）第一篇三条都在：样子挑得准，事情有经过，喜欢没说出口。

师：第二篇的那件事写得好——“＿＿＿”（念该生写事最具体的一句）。可回头看他写样子这一段，写的是“＿＿＿”（念该生停在颜色、尺寸、材质上的那一句）。这一句放到商店同款上，一个字都不用改。

师：那要怎么改？

学生互动分享

师：对，把这一句换成它身上那处磨的、缺的、补过的地方。样子一换，前后就接上了。上面写它身上的印子，下面写这印子是怎么来的。

师：第三篇我不念名字，只念一句：“＿＿＿”（念一句典型的直说喜欢、看不出所以然的话）。这样的句子，我们班好几张稿子上都有。我想问问大家：把这一句划掉，剩下的还能不能让人看见这样东西？

学生互动分享

师：那就说明它还得补。补一处它身上磨的、缺的、补过的地方，或者补一件因为它才发生的事。补上以后，那句直说喜欢的话，划掉也不可惜了。

（教师总结）这三篇不分高下，缺的是不一样的东西：一篇差一处别人那件上没有的样子，一篇差一件事的经过，还有一篇是两样都要补。

### 收尾（点回技法、引向今后的写作）

师：讲了三篇，其实来回就是那三条：样子挑独一份的几处，事情挑因为它才有的那一件，喜欢不说出口。这三条不只写心爱之物管用——往后写你家养的那只猫、写你常去的那条路，一样是这么办：先找出它身上别处没有的那几处痕迹，再找出跟它一块儿发生过的那件事。稿子改好了自己收着。

本环节完。

场景原型: 心爱之物展览会（官方情境的连排改造：实物一律不在场，展台上只有稿子，全靠文字顶替实物；稿子人人被邻座读到、再请三位念给全班）
实体载体: （无·官方展览会已自含当堂念读；东西不在场是本课情境的核心设定，故不另套展示墙/册子，覆盖面靠传稿一轮、人人被邻座读到兑现）
热身动作: 摸手边随身用得最久的一样东西，找出买来那天没有的痕迹（实物类·学生自带随身物，不布置课前准备）
主反馈游戏: 心爱之物展览会·三位学生念开头那句与写那件事的那一段，听众说出记住了它身上哪一处（官方反馈活动）
第二层反馈: 全排朝同一方向传稿一位，邻座只读写样子那一段、在稿末写下自己猜的是什么东西再传回作者（对得上＝独一份的样子写准了；书面默读，比朗读省时且更贴「靠文字认出它」的情境）
开场钩子: 实物道具式·回忆者（拿出一只用了九年的旧帆布包，先让学生猜年头与价钱；措辞不声明包属授课老师，用「主人」指代，老师换成自己的旧物则改说「我」）
主技法: 样子只挑它身上独一份的那几处写＋用一件因为它才发生过的事作证＋全篇不直说“我很喜欢它”
审题辨析形态: 两段对照判断（同写一块滑板：反例刻意写得细且比正例长——颜色尺寸图案、风从耳边呼呼过、玩一下午不想回家样样不少，可句句搬到任何一块同款滑板上都成立／正例只写板尾磨掉的那片漆与练急停摔出来的来历；判据落在“有哪一句只有他那块才写得出”而非“写得多不多”，预期会有学生选反例、参考答案与师话已备接住）
技法引出装置: 当场划句比对（老师先念一小段带三句直说“特别喜欢/太重要/离不开”的话，当场把这三句划掉重念一遍，让学生判断喜欢的劲儿淡没淡，得出“喜欢写在事情和动作里”）
示范文题材: 老师现在的日常生活（门后挂了九年的旧帆布包·背带崩断后自己缝的那道歪针脚）
话轮骨架: ③两段对照→接住选反例的→追问哪句只有他写得出→学生数出三处差别→教师命名三条→当场划句比对→学生口头一句练笔｜④出示示范文→问分几段→问样子写了哪几处→问信不信/有没有写“喜欢”→默读挑句→旁批表｜⑦传稿邻座默读猜物→拿回比对→展览会三位念＋听众反应→自检表→抽两句判断→改三条→修改符号→收尾
互动组织: ②同桌两两互说＋举手抽说／③口头一句练笔抽说／④自说自听＋举手抽说两位／⑦排内传稿邻座默读猜物（非同桌）＋全班展览会三位念
