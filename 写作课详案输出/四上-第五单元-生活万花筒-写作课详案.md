# 《生活万花筒》· 写作课教学设计
四年级上册·第五单元 校内同步写作（记事习作）

[授课提示：本课要投屏三处教材页面，请提前放进课件：第一环节投屏统编四上第五单元“初试身手”左边那幅跑步比赛的图，以及习作页的题面与八个参考题目；第三环节投屏本单元“梳理与交流”的四条。第 1 课时第四环节的记事构思表每人一张，请课前印好。开场的跑步比赛图来自教材，第三环节的两段拍蚊子的话与第五环节的示范文都是拟写的例子，不涉及授课老师本人的经历，无需替换。]

## 教案提纲表

| 课题·课时 | 四上·第五单元《生活万花筒》　│　记事·校内同步　│　2课时连排（每节45分钟） |
| --- | --- |
| 能力阶段 | 写清楚 → 写具体（本课） → 写生动 → 写深刻·有章法 |
| 同类习作顺序 | 记事：那次玩得真高兴 → 看图画，写一写／中华传统节日 → 生活万花筒（本课）／心儿怦怦跳 → 我学会了 → 那一刻，我长大了 → 多彩的活动／围绕中心意思写／传承好家风 → 家乡的风俗／让真情自然流露／心愿 |
| 教材要求 | 统编四上·第五单元习作：把一件事的经过写清楚。 |
| 学习目标 | 通过按顺序写清起因、经过、结果，来学习怎么写一件事的记事习作。 |
| 核心技法 | 使用“记事构思表”。先把事情的起因、经过、结果按先后排清楚，经过分成几步；再选出最关键的一步，把当时看到的、听到的、想到的写具体，有人说话的把原话写下；其他几步略写一下，交代清楚就可以了，结尾写一两句感受。 |

## 第1课时 · 写作指导课

### 一、创设情境，明确任务（约 5 分钟）

[投屏统编四上第五单元“初试身手”左边那幅图：操场跑道上三个穿蓝色运动服的同学正在跑步比赛，场边的同学挥着三角小彩旗和啦啦队手花加油。暂不出示右图与页上文字。]

师：请大家看屏幕上这幅图。图上正在发生一件什么事？
学生互动分享（举手抽说两三位）
参考：在跑步比赛／三个同学在跑道上跑，03号选手跑在前面／旁边的人举着小旗子和手花在加油。
师：是的，是一场跑步比赛，跑道上三位同学正在跑，场边的同学在加油。老师再问一个问题：这场比赛最后是谁得了第一？
参考：不知道／看不出来／图上只画了他们正在跑的时候，开头和后来都没画。
师：对，图上只画了他们正在跑的时候，比赛怎么开始、后来怎么样，都没有画。一幅图确实只能画下一件事里的一个画面，前前后后发生了什么，看图的人只能猜。写作文也是同样的道理。假如这场比赛是你自己参加的，从开始到结束你都在场，起因、经过、结果你心里全都清楚；可是读你作文的人没有参加，他和刚才看这幅图的我们一样，只能从纸上知道这件事：你写下多少，他就知道多少，你没有写的，他一点也猜不到。

师：今天这两节课，每个人写一件自己印象深的事，读的人就是你的同桌。我们来自不同的学校，你经历的这件事，同桌并没有在场。第二节课写完以后，请你把稿子读给同桌听，他听完要能说出两点：一是用一两句话说一说这件事是怎么开始的、最后怎么样了；二是说出你写得最详细的是哪一步。这两点他都说得出来，就说明你把这件事写清楚了。

师：这就是语文书第五单元的习作，题目叫《生活万花筒》。

[投屏统编四上第五单元习作页的题面与八个参考题目：捉蚊趣事、一件烦心事、她收到了礼物、爷爷戒烟了、照片里的温暖、家庭风波、教室里的掌声、窗外的故事。]

师：请看题面上这句话：“选一件你印象深的事，按一定的顺序把这件事写清楚。”这件事可以是自己亲身经历的，可以是看到的，也可以是听说的。今天这两节课要完成的就是这样一篇习作：写一件事，写到一个不在场的人读完，就能说出这件事的经过。

### 二、选定一件事，讲给同桌听（约 9 分钟）

师：我们先来选一件事。请看屏幕上这八个题目，这是课本给出的参考，有开心的事，有烦心的事，也有有趣的、让人感动的事。请大家想一想，最近一段时间，或者更早以前，哪一件事你现在想起来还很清楚。可以从这八个题目里选，也可以自己另外选一件。想好以后，请在草稿纸的左上角写一句话，写清楚谁做了一件什么事，写一句就可以。

学生动笔写作（约 1 分钟；教师巡视，遇到拿不定主意的学生就提示：这几天家里、小区里、路上有没有发生过什么事）

师：有的同学同时想到了两件，一时拿不定主意，可以用这样一个办法来定。写的是自己亲身经历的事，就问一问自己：这件事我现在能不能说出它的第一步、第二步、第三步。三步都说得出来，就写这一件。写的是自己看到的、听说的事，你不在场，中间说不了那么细，就换一个问法：这件事是怎么开始的、最后怎么收场的，你知不知道。两头知道，中间有个大概，也可以写。两个问法都过不去的，就先换另外一件。

学生动笔写作（各自定下一件事）

师：请大家把自己刚才写下的这件事讲给同桌听。同桌两人一组，一人先讲，一人先听。讲的人用一分钟，从这件事是怎么开始的讲起，一直讲到结束；中间你先做了什么、后来又发生了什么，按先后一件一件说下来，不要跳过。听的人不要打断，听完以后只说一句话：你讲的这件事里，哪一步最关键。说完以后两人交换。

学生互动分享（同桌两两互讲，各约一分钟；教师巡视，遇到跳过中间某一步的学生，提示“中间那一步先补上”）

师：请几位同学来说一说，同桌讲的那件事，你替他找出的最关键的是哪一步。
学生互动分享（举手抽说三位，请听的一方说）
参考：他讲的是他家停电，最关键的是找到蜡烛点着的时候／她讲的是考试发卷子，最关键的是老师叫到她名字的时候／他讲的是弟弟摔倒，最关键的是他跑过去扶弟弟。
师：很好。找蜡烛、叫名字、扶弟弟，几位同学找出来的都是那件事里最关键的一步。同桌替你找出来的这一步，请先记在草稿纸上那句话的旁边，等一会儿填表的时候要用。

### 三、学写法：按顺序写清楚，把最关键的一步写具体（约 13 分钟）

师：事情选好了，我们再来看清楚题目的要求。屏幕上这两段话，写的都是一个四年级同学在家里拍蚊子这件事。请大家默读一遍，读完想一想：读完哪一段，你能说出这只蚊子是怎么被拍死的。

〔材料〕第一段：昨天晚上我刚睡着，耳边就响起了嗡嗡声。我开灯一看，胳膊上已经起了一个红包，又痒又疼。我叫来爸爸，我们俩费了好大的劲，找了半天，终于把它打死了。看着墙上那个小黑点，我心里真痛快，这只蚊子再也不能咬人了。今天晚上我总算可以睡个好觉了。

〔材料〕第二段：昨天晚上我刚睡着，耳边就响起了嗡嗡声。我开灯，叫来爸爸。爸爸让我先把灯关掉，等蚊子自己飞出来。黑暗里我们坐了一会儿，嗡嗡声又来了。爸爸打开手电，光柱在白墙上慢慢地移，我屏住呼吸跟着看，屋里太静了，我连自己的心跳都听得见。我心里想：这只蚊子可千万别再飞走了。光柱慢慢移到床头那一边，白墙上忽然照出一个小黑点，一动不动。我一眼就看见了，立刻迫不及待抓过拖鞋，慢慢凑上前，“啪”的一声。蚊子被拍扁在墙上，借着爸爸手电的光，我看见白墙上留下一小片红印子。今天晚上我总算可以睡个好觉了。

师：读完哪一段，你能说出蚊子是怎么被拍死的？
学生互动分享
参考：第二段。／我觉得是第一段，它写了胳膊上起包，还写了心里真痛快。
师：有同学选了第二段，也有同学选了第一段。我们先来听一听选第一段的同学：第一段什么地方吸引了你？
参考：起因写得清楚，蚊子咬了一个包／最后写了心里的感受，很真实。
师：说得对。第一段的起因写得清楚，结尾的感受也写得很真实，这两处都是好的。现在请大家回答开头那个问题：读完第一段，蚊子是怎么被拍死的，说得出来吗？
参考：说不出来／就说找了半天，怎么找的没写。
师：那么读完第二段呢？
参考：先关灯等它飞出来，再用手电照，最后我自己拿拖鞋拍的。
师：是的，先关灯等，再用手电照，最后用拖鞋拍，这位同学一步一步都说出来了。同样是这一件事，第一段的经过只有一句“费了好大的劲，找了半天，终于把它打死了”，读的人不知道中间发生了什么；第二段把经过一步一步写出来了。今天这篇习作叫《生活万花筒》，题目的要求是“把这件事写清楚”。一件事写得清楚不清楚，主要看经过：起因和结果一两句就交代完了，经过才是这件事的主体，经过没有写出来，这件事就等于没有讲给别人听。这是今天审题要记住的一条要求。

师：第二段是怎么写的，才让大家说得出来？我们来看清楚它的做法。刚才这位同学说的三步，正是按先后排下来的。请大家再看第二段，三步里，哪一步写得最详细？
参考：手电找那一步／中间那一步。
师：是的，中间那一步写得最详细。这一步里写了哪些内容，让你读的时候像是自己也在旁边看着？
参考：光柱在墙上慢慢移／小黑点一动不动／屏住呼吸，能听见自己的心跳／还写了心里想的。
师：大家找出来的是光柱、小黑点、自己的心跳，还有他心里想的那句话。这些可以归成三样：看到的，是光柱和小黑点；听到的，是自己的心跳；想到的，是“这只蚊子可千万别再飞走了”。拍蚊子这件事里，这一步最关键，写的人就把它写得特别详细，把当时这三样都写了下来。前后两步写得就简单多了：关灯等蚊子飞出来，用了一两句；拿起拖鞋拍下去，也只有一两句，略写一下交代清楚就可以了。

师：这就是今天要学的写法，一共两条。第一条，按顺序写：先起因，再经过，最后结果，经过分成几步，按先后排好。第二条，选出经过里最关键的一步，把它写具体，写下当时看到的、听到的、想到的。语文书这个单元的“梳理与交流”里，正好把这两条都说到了，请看屏幕。

[投屏统编四上第五单元“梳理与交流”的四条，请一位学生读第三条、一位读第四条]

师：第三条说的是顺序：这个单元的课文《爬天都峰》，就是按照爬山前、爬山中、爬上峰顶后的顺序来写的，前、中、后，一步一步不乱。第四条说的是写具体：《麻雀》这一课，作者就是把看到的、听到的、想到的都写下来，才写出了麻雀和猎狗相遇时的情形。刚才第二段里手电找蚊子那一步，用的正是第四条说的这个写法。

师：下面就用自己刚才选的那件事来练一练。刚才同桌听完你讲的事，替你找出了最关键的一步，就是你记在草稿纸上那句话旁边的那一步。请大家想一想那一步：当时你看到的是什么？请用一句话说给同桌听，只说看到的，先不说心里怎么想。说完以后，听的人只回一句：我看见了，或者我还没看见。
学生互动分享（同桌两两互说互判，各约半分钟；教师巡视，听到只说“很黑”“很乱”这类词的，提示“再说一样具体的东西”）
师：请两位同学说一说，你说的是哪一句，同桌回你的是什么。
学生互动分享（举手抽说两位）
参考：我说“我摸到抽屉最里面，摸出一根蜡烛”，他说看见了／我说“当时很黑”，他说还没看见，我又加了一句“连桌子都看不清”。
师：同桌说“看见了”，说明这一句写下来，读的人也能看见。同桌说“还没看见”的，等一会儿填表的时候，把那一处再补两三个关键词。

师：还有一点要说清楚。不是每一步都要写得那么详细。课本的例文《小木船》里，“我”和陈明的矛盾持续了很长一段时间，课文只用“转眼几个月过去了”一句话就交代过去了。这中间的那一段日子不是这件事最关键的地方，一句话带过，读的人照样清楚。最关键的那一步，才值得多写几句、写得详细一些。这样一篇习作才有详有略，读的人也就知道你这件事里最关键的是哪一步。

（教师总结）写一件事，先按顺序把起因、经过、结果排清楚，经过分成几步；再选出最关键的一步，把看到的、听到的、想到的写具体，其他几步略写一下，交代清楚就可以了。

### 四、借助记事构思表，理清思路（约 9 分钟）

师：现在我们按这两条，把自己那件事理一理。请拿出老师发的记事构思表。这张表每一行填一样内容，只记关键词，写成句子留到第二节课再说。

[投屏并发放空白表]

| 项目 | 关键词 |
| --- | --- |
| 我写的这件事（谁，做了什么） | |
| 时间、地点、在场的人 | |
| 起因（这件事为什么会发生） | |
| 经过·第一步 | |
| 经过·第二步 | |
| 经过·第三步（不够可以加一行，多了可以并成一步） | |

| 结果 | |
| 我的感受（一句） | |

师：老师先示范填一张。填的是一个四年级同学独自坐电梯、电梯停在半路的事。

| 项目 | 关键词 |
| --- | --- |
| 我写的这件事（谁，做了什么） | 我，被困在电梯里 |
| 时间、地点、在场的人 | 上个星期五放学，小区电梯，我一个人 |
| 起因（这件事为什么会发生） | 电梯到七楼，一顿，灯闪，不动了 |
| 经过·第一步 | 按开门键、按“8”，都没反应 |
| 经过·第二步 | 找到红色按钮，按下去，有人回话 |
| 经过·第三步（不够可以加一行，多了可以并成一步） | 站着等，数灯，门被撬开 |
| 最关键的是第几步；那一步里看到、听到、想到的 | 第二步。看：门缝黑、红按钮；听：风扇呼呼、喇叭里的回话；想：电梯一直不开怎么办 |
| 结果 | 物业叔叔扶我跳下来 |
| 我的感受（一句） | 最漫长的十一分钟 |

师：请看老师这张表。经过分成了三步，填的都是关键词；第七行圈定的是第二步，那一行写的也是关键词，看到的两样、听到的两样、想到的一样，没有一个完整的句子。下面请大家填自己的表。第一行照抄你刚才写在草稿纸左上角的那一句，就是“谁做了一件什么事”那一句；第七行，先想一想刚才同桌听完你讲的事、替你找出的最关键的那一步，它排在你填的经过里的第几步，就在这一行填第几步，再往后写那一步里的三样，每一样记两三个关键词。请用四分钟填好。

学生动笔写作（约 4 分钟；教师巡视，对经过只写出一步的学生提示“它前面发生了什么，后面又怎么样了”；对第七行写成整句的学生提示“只留关键词”）

师：填好以后，请在经过的三步里，把第七行填的那一步圈出来，第二节课这一步要写得最详细。

学生动笔写作（各自圈定）

师：请三位同学说一说：你写的是哪件事，你圈的是哪一步，你为什么选这件事来写。
学生互动分享（举手抽说三位）
参考：我写停电那天晚上，圈的是我摸黑找到蜡烛那一步，选它是因为那天全家都靠我那根蜡烛／我写弟弟摔倒，圈的是他哭着不让我碰那一步，我到现在还记得他的哭声／我写班里发卷子，圈的是老师叫到我名字那一步，选它是因为叫到名字的时候我手心都出汗了。
师：很好。这几位同学说的理由，都落在自己圈出来的那一步上：全家都靠那根蜡烛，弟弟的哭声，叫到名字时手心出汗。如果你选这件事的理由落在另外一步上，就再看一看，是不是那一步更关键。第二节课把这一步写具体，读的人就知道你为什么记得这件事。

### 五、出示示范文，发现写法（约 9 分钟）

师：老师按照刚才那张表，把坐电梯这件事写成了一篇文章，写的时候代入的是一个四年级同学的视角。我们先不看整篇，只看其中的一段。请对着老师那张表读一读：这一段写的是表上的哪一步；表上那几个关键词，到了文章里扩展成了几句；文章里有、表上没有的，又是哪些。

> 【教师示范文】（先看其中一段）
> 我先按了一下开门键，没有反应。又按了一下“8”，还是没有反应。我盯着门上那条缝，缝里黑黑的，什么也看不见。电梯里很安静，只听得见顶上风扇转的声音，呼呼的。我心里想：电梯要是一直不开，怎么办？这时候我看见门边有一个红色的按钮，上面写着“紧急呼叫”，我赶忙一把按了下去。等了几秒钟，喇叭里传来一个陌生叔叔的声音。我心里一紧，急忙说自己被困在电梯里。他接着问道：“你是在哪一栋、几楼的电梯里？”我赶紧报出楼号，声音止不住地发抖。那个叔叔在喇叭里叮嘱：“别按别的键，站在原地等着，我们五分钟就到。”

学生互动分享（同桌对照表说一说，随后举手抽说两位）
参考：是第二步，按按钮那一步／表上就几个词，文里写了十来句／文里多了按钮上的字“紧急呼叫”／多了两句对话，表上没有／多了“我心里一紧”／多了“声音止不住地发抖”。
师：是的，表上只有几个词，到了文章里就扩展成了十来句。看到的写成了句子，听到的把当时的原话写了出来，想到的也写了进去。表上没有的那两句对话，是写的时候想起来补上的。这里还有一处要说明：这一段前面两句写的是第一步，按开门键、按“8”；从“我盯着门上那条缝”起，才是圈出来的第二步。老师把两步写在了一段里，第二步写得最详细。大家写的时候，很短的那一步可以像老师这样附在前面，圈出来的那一步要写得比其他几步都详细。下面请大家看整篇。

> 【教师示范文】
> 漫长的十一分钟
>
> 上个星期五放学，我一个人坐电梯上楼。电梯上到七楼的时候，忽然一顿，灯闪了两下，就不动了。楼层的数字停在“7”上，门也不开。
>
> 我先按了一下开门键，没有反应。又按了一下“8”，还是没有反应。我盯着门上那条缝，缝里黑黑的，什么也看不见。电梯里很安静，只听得见顶上风扇转的声音，呼呼的。我心里想：电梯要是一直不开，怎么办？这时候我看见门边有一个红色的按钮，上面写着“紧急呼叫”，我赶忙一把按了下去。等了几秒钟，喇叭里传来一个陌生叔叔的声音。我心里一紧，急忙说自己被困在电梯里。他接着问道：“你是在哪一栋、几楼的电梯里？”我赶紧报出楼号，声音止不住地发抖。那个叔叔在喇叭里叮嘱：“别按别的键，站在原地等着，我们五分钟就到。”
>
> 我就站在原地，数电梯顶上那一圈小灯，一共八个，有一个是坏的。数完一遍，外面一点动静也没有。我蹲下去，过一会儿又站起来，手心里全是汗，自己也记不清数了多少遍。后来外面终于传来脚步声，有人喊：“里面的小朋友，往后站一点！”门被撬开了，电梯的地板比外面高出一大截，我是被物业的叔叔扶着跳下来的。
>
> 我在电梯里一共待了十一分钟。十一分钟平时差不多就是一个课间，跑出去玩一会儿就过去了，可那天关在电梯里，我觉得比一个下午还长，这是我长这么大过得最漫长的十一分钟。

师：现在请各自默读整篇，一边读一边留意两处：正文分了几段，哪一段最长；另外找出一句，读到它的时候，你会觉得自己也站在那部电梯里。
学生动笔圈画（各自默读约 1 分钟，把找到的那一句画出来）

师：我们先来数一数段落。正文一共写了几段，哪一段最长？
参考：四段／第二段最长。
师：对，正文四段，第二段最长。第二段就是刚才看过的那一段，第一步和第二步都在里面，圈出来的第二步写得最详细，所以这一段最长。我们再看第一段，起因用了几句？
参考：两三句。
师：两三句就交代清楚了：放学、坐电梯、到了七楼停住。第三段写的是第三步和结果：站着等、数灯、门被撬开、被扶出来，虽然也写了几句，但是比第二段短得多。这就是刚才说的：最关键的一步写得特别详细，其他几步略写一下，交代清楚就可以了。

师：我们再来说一说大家画线的那一句。
学生互动分享（举手抽说两三位）
参考：“缝里黑黑的，什么也看不见”／“只听得见顶上风扇转的声音，呼呼的”／“我说了楼号，声音有点抖”。
师：大家画出来的这几句，写的都是当时眼睛看到、耳朵听到的具体事物：门缝里黑黑的，风扇呼呼地响，报楼号的声音止不住地发抖。读的人顺着这几句，也就看见了当时的样子。老师把这些句子和它们的做法列成了一张表。这张表里最重要的，是写着看到的、听到的、想到的那三行。这三样，就是等一会儿大家要写的。

〔示范文旁批对照〕

| 示范文里的句子 | 这一句用了什么 |
| --- | --- |
| 电梯上到七楼的时候，忽然一顿，灯闪了两下，就不动了 | 起因：一两句交代清楚，不多写 |
| 我先按了一下开门键，没有反应。又按了一下“8”，还是没有反应 | 经过的第一步：两个动作，按先后写 |
| 缝里黑黑的，什么也看不见 | 圈定的这一步写具体：看到的 |
| 只听得见顶上风扇转的声音，呼呼的 | 圈定的这一步写具体：听到的，用上了声音 |
| 我心里想：电梯要是一直不开，怎么办？ | 圈定的这一步写具体：想到的 |
| “别按别的键，站在原地等着，我们五分钟就到。” | 听到的话照原样写下来 |
| 我赶紧报出楼号，声音止不住地发抖 | 圈定的这一步写具体：说话的声音抖了，这也是当时听得见的 |
| 数电梯顶上那一圈小灯，一共八个，有一个是坏的 | 第三步：几句话交代过去，写得比第二段短得多 |
| 我是被物业的叔叔扶着跳下来的 | 结果：一句交代 |
| 这是我长这么大过得最漫长的十一分钟 | 结尾的感受：写的是这件事留给自己的真实感觉 |

师：我们接着来看结尾部分。前面三段记叙的是事发当时的经过，结尾用来抒发事后的感受。大家留意一处细节：从电梯故障停下，到我被人扶着走出电梯，一共过去了十一分钟。十一分钟放在平时并不算长，可困在狭小封闭的电梯里，内心惶恐不安，每一秒都被无限拉长，等待的煎熬不必直白写出，读者就能体会。感受不用写得很长，一句或者两三句都行，写下经历这件事后自己真实的想法就可以。

（教师总结）示范文是照着那张表写出来的：按顺序写，起因、三步经过、结果；最关键的第二步写得最详细，看到的、听到的、想到的都在里面；其他几步略写一下，交代清楚就可以了；结尾写自己的感受。

师：第一节课的内容就到这里。请把记事构思表收好，休息回来，我们就照着这张表动笔。

## 第2课时 · 当堂写作与评改课

### 一、借助记事构思表，先写圈定的那一步（约 5 分钟）

师：请把记事构思表摆在稿纸旁边，找到第七行，也就是上一节课你在经过里圈出来的、最关键的那一步。

师：我们先不从头写，先写这一步。请看着第七行的关键词，回想当时的情形：那一步里你做了什么、看见了什么，有没有人说话。老师问三句，每问一句，请大家在草稿纸上写一句。第一句：当时你最先看见的是什么？请把它写成一句话。
学生动笔写作
师：第二句：那时候你听见了什么？当时有人说话的，请把那句话照原样写下来，加上引号。
学生动笔写作
师：第三句：那时候你心里想的是什么？请照着“我心里想”往下写一句。写的是自己看到的事，这三句就写你站在旁边看见的、听见的；写的是听说的事，你不在场，看到的、听到的写不出来，就把讲这件事的人告诉你的那几句写下来，再写一句你听到的时候心里想的。
学生动笔写作

师：这三句写下来，就是你这篇里写得最详细的一步。这一步在文章的中间，不是开头。现在请拿出稿纸，照着表往下写：先把时间、地点交代清楚，再写起因，接着按第一步、第二步往下写；写到你圈的这一步，把草稿纸上刚写的那三句——看到的一句、听到的一句、心里想的一句——接进去，还想到什么，就接着往下加。

学生动笔写作

### 二、自由写作（约 18 分钟）

师：下面的时间都用来写。请按表上的顺序一直写到结果，最后写下自己的感受。中途遇到不会写的字、拿不准的标点，先接着往下写，等全篇写完再统一改。

学生动笔写作（连续书写；教师巡视，期间不指出错别字与标点）

[巡视分层指导：
① 写了起因就停住：不请他重写开头，请他看表上“经过·第一步”那一行，问“事情发生以后，你先做的是什么”一类的问题，把第一步先写成一两句；问的是下一步是什么，不替他补内容。
② 三步都写了，但每一步都只有一句：指着他圈出来的那一步，问“当时你看见了什么，听见了什么”，请他把草稿纸上那三句（看到的、听到的、心里想的各一句）接进去；只补这一步，其他两步不动。
③ 写得顺畅：不打断，只在经过时看一眼三步的顺序有没有乱，不出声。
④ 写到结果就搁笔、篇幅很短：先肯定他起因、经过、结果都有了，再问“你圈的那一步，当时有人说话吗，说的是什么”，请他把那句原话补进去；那件事里没有人说话的，改问“当时你看见的是什么样子”，请他补一两句看到的。
⑤ 写完等着的：请他默读一遍，看有没有漏字，有没有哪一句话没有写完。]

[本篇没有硬格式要求；错别字、病句、标点一律留到第三环节，写作期间不指出。]

### 三、交流评议，修改收束（约 22 分钟）

师：好，时间到了，请大家停笔。没有写完的同学也不要紧，同桌要听的就是你现在已经写好的这些内容，改完以后再往下补。

[同桌互读（约 6 分钟）]
师：第一节课说过，你的稿子要读给一个不在场的人听。现在请同桌两人一组，一人先读，一人先听。读的人从头读起，读到自己写完的地方为止。听的人听完，说两句话：第一句，用自己的话说一遍，这件事是怎么开始的，最后怎么样了；第二句，说出你觉得他写得最详细的是哪一步。说完以后两人交换。
师：读的人听完同桌这两句，要回头对照自己的表：同桌说的起因和结果，对不对？同桌指出的你写得最详细的那一步，和你第七行圈的是不是同一步？两处都对上了，就说明你把这件事写清楚了，重点也写出来了；有一处没有对上，等一会儿就改这一处。
学生互动分享（同桌轮流读、听、说，各约三分钟；教师巡视，听的人只说“写得挺好”的，提示“先说这件事怎么开始的”）

[全班交流（约 4 分钟）]
师：请两位同学把自己圈的那一步读给全班听，只读这一步。听的同学有一个任务：听完以后请说一说，这一步里你听到了哪几个动作，或者哪一句话。
学生互动分享（两位朗读者由教师在巡视中从圈出的那一步写得具体的学生里指定；每位读完，请一位听众说）
参考：他写了摸墙、摸到抽屉、划火柴三个动作／她写了老师叫名字那句话，“下一个，请上来”，她还写了自己站起来腿有点软。
师：听的同学能说出动作和那句话，就说明这一步写具体了。请两位作者把同学指出的那一句在稿子上做一个记号，那是你这篇里写得最清楚的地方。

[先判断再改（约 3 分钟）]
师：改之前，请回想一下刚才同桌听完你的稿子以后是怎么说的，看一看自己属于哪一种情况。第一种，同桌没能说出这件事是怎么开始的，或者没能说出最后怎么样了：那就是起因或者结果漏掉了，请补上一两句。第二种，同桌指出的你写得最详细的那一步，和你第七行圈的不是同一步：那就说明你圈的那一步还没有写详细，请回到那一步，把看到的、听到的、想到的三样里少的那一样补上，当时有人说话的，把他的原话补上去。第三种，两句都对上了：请看一看其他两步有没有写得比圈出来的那一步还长，如果有，就把它压短一些，把省下来的话挪到最关键的那一步去。请在稿纸上角写下你是第几种。
学生动笔写作（各自判断、写下情况；教师抽问一位：你是第几种，打算改哪里；再追一句：补上这一处，同桌再听一遍能多说出什么）
参考：我是第二种，同桌指的是最后一步，我圈的是中间那步，我打算补上爸爸说的那句话／补上以后，他就知道爸爸当时是怎么说的了。

[自改（约 7 分钟）]
师：请大家拿回自己的稿子，看一看刚才写在稿纸上角的是第几种，就照这一种的改法，在稿子上改一处。改完以后，再用修改符号把稿子理一遍：多的字圈掉，漏的字补上，错的字改正。
学生动笔写作（自改，约 7 分钟；教师巡视，优先看第二种情况的学生有没有补进看到的、听到的或想到的）

〔三档标准〕
基础一档：写的是一件事，起因、经过、结果都有，按先后写，语句通顺。
良好一档：经过分成了两三步，顺序清楚；有一步写得比别的步详细，写出了当时看到的或听到的；结尾有感受。
优秀一档：起因和结果交代简洁，经过三步以上、顺序清楚；圈出来的那一步写得最详细，比其他几步都长，看到的、听到的、想到的三样都有，当时有人说话的写下了原话；同桌能说出起因结果、指得出这一步；结尾的感受写的是这件事留给自己的真实感觉。写的是看到的、听说的事，第三样按听来的内容写，同样按上面三档判。

〔应答·学生说同桌指的那一步和自己圈的不一样，但他觉得同桌指的那一步更关键〕先问他为什么当时圈的是另一步；如果他现在也觉得同桌指的那一步更关键，允许他改圈，把第七行换成那一步，再照第二种情况给它补三样。最关键的一步是作者自己定的，同桌指出来的只是现在写得最详细的那一步；两者对不上时，请他选定其中一步，再把稿子改到与它一致。

[收尾（约 2 分钟）]
师：请把稿子收好。第一节课开始的时候，我们看了一幅跑步比赛的图，看图的人说不出比赛怎么开始、谁得了第一。刚才你的同桌没有在场，他听完你的稿子，却能说出这件事怎么开始、最后怎么样，还指得出你写得最详细的那一步。这件事，现在有一个不在场的人也说得清楚了。

本课完。

## 附：习作讲评指导环节（可选 · 单次课课后用 / 系列课作下次课开场用）

> 本环节供老师灵活取用：可在单次课课后使用，也可作为系列课下一次课的开场（约 15–20 分钟），不计入两节课的 45＋45 分钟。
> 凡下文 `＿＿＿` 处，务必换成本班学生当堂完成的真实习作里的句子，不得虚构。

### 选稿（课前准备）

从当堂写成的稿子里选出三篇，投屏时隐去姓名：
- 一篇好的：起因、经过、结果按顺序写清楚，经过分了三步以上，圈出来的那一步写得最详细、比其他几步都长，看到的、听到的、想到的三样都有，结尾一句感受写的是这件事留给自己的真实感觉。
- 一篇中等的：顺序清楚，三步都有，但每一步差不多长，圈出来的那一步没有写详细，当时看到的、听到的都没有写出来。
- 一篇待改进的：起因和感受写了不少，经过只有一句“费了好大劲”“想了很多办法”，读完说不出这件事是怎么办成的。

### 讲评流程（每篇约 3–5 分钟，围绕本课技法点）

师：这次讲评，我们看的是这三篇习作能不能让一个没有在场的人读完就说出这件事的经过。具体看两处：起因、经过、结果是不是按顺序写清楚了；作者圈出来的最关键的那一步有没有写具体。

师：我们先看第一篇。请大家听这一段：“＿＿＿”（读该生写得最详细的那一步）。这一步里，你听到了哪些动作，哪一句话？
学生互动分享
师：是的，这些动作和那句话，都写在这一段里了。这一句“＿＿＿”（读其中写看到的或听到的那一句）写的是当时眼前的一样具体东西，读的人没有在场，也知道当时是什么样子。这一篇从起因到结果一步不乱，最关键的一步又写得最详细，所以听的人能说出这件事的经过。

师：我们再看第二篇。这一篇的顺序很清楚，“＿＿＿”（读该生交代起因或某一步的一句）这样的句子每一步都有。请大家再听这一步：“＿＿＿”（读该生本该写详细却只有一句的那一步）。这一步是这件事最关键的一步，读完它，你能说出当时是什么样子吗？
学生互动分享
师：这里只要把当时看到的补上一样，听到的话补上一句，这一步就写出来了。作者可以在这一句后面接着往下加。

师：我们最后看第三篇。请听老师读其中一段：“＿＿＿”（读该生起因与感受写得多、经过只有一句的部分）。这一段的起因写得清楚，感受也写得很真实。老师想请大家帮作者想一想：中间这件事是怎么办成的，可以分成哪几步？作者不用现在回答，大家先替他猜一猜。
学生互动分享
（教师总结）大家能替作者猜出两三步，就说明这件事的经过本来就有，只是没有写出来。作者把这几步按先后补上，再把其中一步写详细，这一篇就完整了。

### 收尾（点回技法、引向今后的写作）

师：从这三篇可以看到，能让人读完就说出经过的一件事，都做到了两条：按顺序把起因、经过、结果写清楚，经过分成几步；最关键的一步写具体，看到的、听到的、想到的都在里面。以后不管写一件开心的事、烦心的事，还是看到的、听到的事，先把它分成几步，再定下哪一步最关键。
