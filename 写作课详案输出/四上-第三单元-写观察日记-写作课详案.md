# 《写观察日记》· 写作课教学设计
四年级上册·第三单元 校内同步写作（观察日记）

[教具准备：本课需老师课前发三杯黄豆。发法照发豆芽的常规做法，同一袋豆子、同样的杯子——第一杯在六天前的傍晚下水泡一夜，第二天早上把水沥干，盖一块拧过的湿布放在避光处，此后每天早晚各冲一次水、冲完仍沥干；第二杯在三天前的傍晚照同样的法子下水；第三杯上课前一晚下水，上课时仍泡在水里，就是第一天的样子。三杯各自下水的日期与星期课前记好，上课时报给学生并写在投屏上]

[异常处理：豆子全程闷在水里会发酸发臭，故第一、二杯务必沥干后湿布捂养。课前一天揭开湿布看一眼，若已发酸发臭，弃用实物，改用同一组豆子隔天拍的三张对比照片投屏出示；来不及发豆子的同此办理，教学步骤与讲法不变]

[授课提示：示范文里老师养蚕那一段是拟写的，供老师照着讲；老师自己真养过、种过、记录过什么，换成自己的更好。]

## 教案提纲表

| 课题·课时 | 四上·第三单元《写观察日记》　│　观察·日记·校内同步　│　2课时连排（每节45分钟） |
| --- | --- |
| 能力阶段 | 写清楚 → 写具体（本课） → 写生动 → 写深刻·有章法 |
| 同类习作顺序 | 观察·说明：植物朋友／小实验／国宝大熊猫 → 观察日记（本课） → 介绍一种事物 → 世界文化遗产 |
| 教材要求 | 统编四上·第三单元习作：连续观察，用日记记下变化。 |
| 学习目标 | 下课的时候，手上有三则写成的观察日记：每一则的第一句都写出今天哪儿跟上次不一样，中间用比较的说法把这一处写清楚，最后添一句当时心里的话；念给同组的同学听，他能端着盘子指出你写的是哪一处。 |
| 核心技法 | 一天写一则，每一则只抓变了的那一处来写——先点出今天哪儿不一样，再用“原来……现在……”“由……变成……”“渐渐地”“越来越”这些说法把这一处写清楚，最后添一句当时心里怎么想；三则各写一处新发现，不把上一则说过的再说一遍（辅：日记第一行的日期、星期、天气）。 |

## 第1课时 · 写作指导课

### 一、创设情境，明确任务（约 6 分钟）

师：老师从六天前起，在办公室窗台上发了三杯豆芽，一直发到今天。我们先来看看实物。

[端出三杯黄豆并排放在讲台上，杯身分别贴“第一天”“第三天”“第六天”；前两杯揭开湿布，第三杯仍带水。同时投屏出示三杯各自下水的日期与星期]

师：这三杯是同一袋豆子倒出来的，杯子一样大，发的方法也一样：前一天晚上下水泡一夜，第二天早上把水沥掉，盖上一块湿布接着放，每天冲两回水。不一样的只有一件事：下水的日子不一样。左边这一杯是六天前下的水，到今天正好是第六天；中间这一杯是三天前下的，今天是第三天；右边这一杯昨天晚上才下水，还泡在水里，今天是它的第一天。

[此处的日期与星期照课前记下的实际情况报给学生，投屏上的那三行就是学生待会儿写日记要抄的]

师：所以你们现在一眼看过去，看到的其实是同一颗豆子第一天、第三天、第六天的样子。

师：这三杯是老师特意为今天这两节课发的。这六天它一天一个样子，可是我一直没有做记录，就等着你们今天来记。这六天里它到底是怎么一点一点变过来的，光凭眼前这三杯，你们说得清楚吗？

参考：说得清／看得出来／第一杯最小，最后那杯发芽了。

师：看是看得出来的，可是过两天再问，多半就只剩下一句“它长大了”。写下来就不一样了：这六天有了记录，往后第七天、第十天再看，就能对着它接着往下记。今天这两节课就做一件事：眼前这三杯正好是它第一天、第三天、第六天的样子，一天记一则，写成一组观察日记。

师：写完以后在小组里念，听的那几位同学手里就端着那盘豆子。你写的是哪一处，他得能在豆子上给你指出来。指得出来，说明你写准了、也写清楚了；指不出来，可能就是你只写了一句“豆子变大了”，没有说清楚到底哪儿变了、变成了什么样子。

### 二、观察体验，看清眼前这几颗（约 9 分钟）

师：要写它这几天是怎么变的，先得把它看清楚。每组桌上有一个盘子，里面三颗豆子，标着第一天、第三天、第六天。可以看，可以用手指碰一碰、翻个面，也可以凑近闻一闻。

[每组发一个浅盘，内放第一天、第三天、第六天的豆子各一两颗并标好天数，盘底垫一小块湿纸巾]

师：看的时候有一个要求：不能说“它变大了”“真神奇”这一类的话。这是结论，不看也说得出来。请大家只说你眼睛看见了什么、手上摸到了什么、鼻子闻到了什么。

师：四个人围着盘子，一人说一样，转着圈往下说。前面的同学说过的，后面就不能再说了，要往下找新的。

学生互动分享（四人一组围着盘子轮流说，每人一样，不重复；教师走到两三组跟前当第一位听众）

参考：那颗小的还是圆的／皮上有一道印子／大的那颗皮撑开了／摸上去滑滑的／捏起来硬硬的／有一股豆子味／黄的地方发白了／最大那颗裂开了一条缝／缝里有白色的东西／芽是白的，弯弯的，很短。

师：停一停。刚才各组说出来的都不少。现在每组报一样：在你们说过的那些里面，挑最不容易看见的那一样，报给全班听。哪一组先来？

学生互动分享（举手抽说三四组，每组只报一样最不容易看见的；教师接话时复述他说的那一处，如“皮上有一道白印”“芽尖是弯的”）

（教师总结）刚才你们说出来的，全是眼睛看见、手上摸到的东西——皮、纹、缝、芽、颜色、软硬。这些看清楚了，日记才有东西可写。

### 三、学写法：跟上次比，写出变了的那一处（约 14 分钟）

师：准备动笔之前，我们先要弄清楚一件事：观察日记的一则，到底该写什么。下面两段话，写的都是第三天这一杯。听完请你告诉我，哪一段才是今天该写的。

师：第一段是这样的：“今天是第三天。我又去看了那杯豆子。它们挨挨挤挤地堆在杯子里，圆圆的，黄澄澄的，像一颗颗小珠子。我伸手指按了按，硬硬的，一点也不软。窗台上的太阳照过来，豆子上头亮晶晶的。我看了好一会儿才走。”

师：第二段是这样的：“今天是第三天。豆子跟前天不一样了。前天它还是圆鼓鼓的一整颗，皮绷得紧紧的；今天皮松了，最深的一道纹裂开了，缝里挤出一点白，米粒那么大。我盯着那条缝看了半天。”

师：哪一段才是今天该写的？

参考：第二段。

师：第一段颜色写了，形状写了，按上去什么感觉、太阳照着什么样，一样一样都写到了，句子比第二段还长，问题到底出在哪儿？

参考：它没有说出哪儿不一样了／它写的还是第一天那个样子。

师：说得对。第一段写了那么多句，没有一句是拿今天跟前天比着写的，写的全是它本来就有的那些样子：圆的、黄的、硬的。观察日记一天一则，每一则要回答的只有一件事：跟上次比，今天哪儿不一样了。这一段一句也没有，所以三则日记摆到一起，读的人看不出它变过。这也是这次习作最容易出的毛病。

师：那么怎么才能找出“不一样的那一处”呢？我们当场来找一回。

[请学生从本组盘里把第一天、第三天那两颗挑出来并排摆好，凑近了比；教师同步投屏出示这两颗的对比照片，供全班对齐口径。按“皮、大小、颜色、缝”几处逐一带着比]

师：把你们盘里第一天和第三天那两颗挑出来，并排摆在跟前，凑近了看。一处一处地比，先看皮。第一天那颗的皮是什么样子，第三天那颗的皮又是什么样子？

参考：第一天绷得紧紧的／第三天有点发皱了／松下来了。

师：再看颜色，看大小。

参考：第三天那颗胖了一点／黄里带白／有一条缝。

师：找出来了。不过只是这么说，还不算写出来。老师把你们找出来的这一处，写成一句话给你们看——

[在投屏上现场把这一句打出来，写完停两秒，让学生看清它是分成两截的]

〔教师示范·当场把找出的一处写成一句〕原来那层皮是紧绷绷贴在身上的，现在松了，皱出好几道纹。

师：你们听这句话，它里面有两截：原来什么样，现在什么样。两截一摆，变化就出来了。这样的说法还有几个，都很好用：由……变成了……；渐渐地……；越来越……。

师：今天要学的写法，就是三件事。第一，每一则的第一句先点出今天哪儿不一样了，而不是“今天我又去看豆子”。第二，把这一处用刚才那几种说法写清楚，让人知道它原来什么样、现在什么样。第三，最后添一句你当时心里怎么想的——是等不及了，是舍不得碰，还是有点失望。

师：老师照着这三件事，把第三天那一则写成一段，你们听。

〔教师示范·当场把「今天豆子哪儿不一样」写成一段〕今天是第三天。豆子跟前天不一样了。前天它还是圆鼓鼓的一整颗，皮紧紧地绷在身上，摸上去硬邦邦的；今天那层皮松了，皱出好几道纹，最深的一道裂开了，缝里挤出一点白，米粒那么大，像刚冒出来的一颗小牙。杯壁上蒙着一层水汽，凑近了有一股淡淡的豆腥味。我伸手指碰了碰那点白，软软的，一按就往里陷，赶紧又把手缩了回来。才第三天，它就顶出这么一点来，我怕手上一使劲，明天就没得看了。

师：现在轮到你们写。就写你刚才在盘子里看见的任意一处，用上“原来……现在……”，写成一句；写完在后面再添一句，说说你那个时候心里怎么想的。一共两句。

学生动笔写作

师：谁写好了，念给大家听一听。

学生互动分享（举手抽说两三位，每位念两句；教师反馈落到他这两句上，如指出他比的是皮、是颜色还是芽，比清楚了没有，最后那句心里话是不是他自己那会儿真想的）

（教师总结）今天的写法就是这一句：一天写一则，每一则只抓变了的那一处，先点出来，再用“原来……现在……”这样的说法写清楚，最后添一句当时心里的话。

### 四、借助观察记录表，理清思路（约 9 分钟）

师：三则日记要写三处不一样的地方，光在脑子里想，很容易串到一块儿去。我们先用一张表把它排一排。这张表叫作观察记录表，每一格只填词语，最多三五个字，不用写完整的句子，自己认得出意思就可以。

[发放观察记录表；投屏出示同款空白表]

| 第几天 | 日期·星期·天气 | 我看到的 | 跟上次比，不一样在哪 | 那会儿我心里 |
| --- | --- | --- | --- | --- |
|  |  |  |  |  |
|  |  |  |  |  |
|  |  |  |  |  |

师：第二格照着投屏上那三行抄，日期、星期、天气都在上面。日记的第一行就写这三样，这是写日记的规矩，三则都要有。

师：老师先填一张给大家看。

[投屏逐格填写教师示范表，边填边念]

| 第几天 | 日期·星期·天气 | 我看到的 | 跟上次比，不一样在哪 | 那会儿我心里 |
| --- | --- | --- | --- | --- |
| 第一天 | 照投屏抄 | 圆、黄、硬 | 没得比 | 想快点 |
| 第三天 | 照投屏抄 | 皮松、有缝 | 缝里挤出白 | 想拨开看 |
| 第六天 | 照投屏抄 | 白芽、弯的 | 那点白长成芽 | 有点得意 |

师：请大家看清楚，每一格最多两三个词语，一句完整的话都没有。可就是这么几个词，待会儿一个词就能拉出一两句话来。第四格是最要紧的一格，三行里填的必须是三处不同的地方，不要三行都填“变大了”。

学生动笔写作（填表约 3 分钟；教师巡视）

〔应答·学生三行填的是同一处变化〕不否定他填的，指着盘子问一句：“大小以外，皮呢？颜色呢？水呢？”让他就着眼前这几颗再找一处，自己换掉其中一行。

〔应答·学生说自己家里正养着、种着别的东西〕允许他改写自己的那一样（家里的猫、阳台上的蒜、每晚的月亮都行），提醒他同样是三则、三处不同的变化；表照填不误。

师：填出两行就可以开口说了。现在小声把你这三行连起来说给自己听一遍：第一天我看见了什么，第三天哪儿不一样了，第六天又不一样在哪里。说得磕磕绊绊的地方，就是还没有想清楚的地方。

学生互动分享（自说自听，小声说给自己听一遍，说不顺处回表上补词）

师：请两位同学说一说，你三行填的是哪三处？

学生互动分享（举手抽说两位；教师反馈落到他填的那三处上，点出三处是不是真的各不相同）

### 五、出示示范文，发现写法（约 7 分钟）

师：你们表上都填好内容了。老师自己也写过一组，记的不是豆子，是去年春天养的一盒蚕。听的时候请留意一件事：三则日记，第一句各在写什么。

> 【教师示范文】
>
> 四月九日 星期四 晴
>
> 今天我从同事那里领回来一小盒蚕。盒子一打开，我差点没找着它们。十几条小东西趴在桑叶上，黑黑的，细得像一段一段的线头，比我的指甲盖还短。我用手指碰了碰盒子边，它们一动不动，只有嘴那一头在轻轻地动。桑叶上有几个针眼大的小洞，原来是它们咬的。就这么点大，也会吃东西了。
>
> 四月十一日 星期六 阴
>
> 才隔了两天，它们身上的黑就退掉了大半。前天还是一段段黑线头，今天从头那一节起，渐渐地变成了灰白色，只有尾巴尖上还留着一点黑。个头也长了，最长的那一条趴直了有小半个指节。我把新桑叶铺上去，它们爬得比前天快多了，一片叶子上很快就挤满了。
>
> 四月十四日 星期二 晴
>
> 今天早上一掀开盒盖，我先听见了声音——沙沙沙，沙沙沙，像谁在远处下小雨。凑近了看，那些蚕已经全白了，身子一节一节的，比前天胖了一圈，趴在叶子上一口挨着一口地啃，叶子边上很快就啃出一个个半圆的缺口。有一条爬到盒角上不动了，昂着头，一动不动待了很久。我查了查资料，原来这是要蜕皮了。我在旁边守了十分钟，它还是那个姿势。我把盒盖轻轻合上，明天再来看它。

师：先看框架。这一组写了几则？每一则最前面那一行写的是什么？

参考：三则／前面写着日期、星期，还有天气。

师：第二则和第三则的第一句，各在做什么？

参考：第二则说的是黑色退掉了／第三则说的是听见声音了。

师：说得对。第二则第一句写的是颜色变了，第三则第一句写的是多了一样东西：声音。三则各说一处新的，没有一则是把上一则再说一遍。第一天没有可比的，那就把它原来的样子写清楚，好给后面几天打个底。

师：还要再挑一处。哪一句念完，你就知道那个时候盒子里正在发生什么？请你指一句出来。

学生互动分享

师：我们把这几句梳理一下，对照着看——

[投屏出示旁批对照表，逐行带读]

| 示范文里的句子 | 这一句在做什么 |
| --- | --- |
| 四月九日 星期四 晴 | 日记的第一行：日期、星期、天气 |
| 细得像一段一段的线头，比我的指甲盖还短 | 第一天没有可比的，就把原来的样子写清楚，给后面几天打个底 |
| 才隔了两天，它们身上的黑就退掉了大半 | 一则的第一句，先点出今天哪儿不一样了 |
| 前天还是一段段黑线头，今天从头那一节起，渐渐地变成了灰白色 | 用“前天……今天……渐渐地……”把这一处写清楚 |
| 就这么点大，也会吃东西了 | 最后添一句当时心里的话，不是“我真高兴”这样的空话 |
| 沙沙沙，沙沙沙，像谁在远处下小雨 | 把听见的写成声音，读的人也听见了 |
| 叶子边上很快就啃出一个个半圆的缺口 | 不说“吃得快”，而是写吃出来的样子 |
| 我把盒盖轻轻合上，明天再来看它 | 收在一个动作上，不硬加一句道理 |

师：蚕和豆子不是一回事，可是记录的方法是同一套：第一句点出今天哪儿变了，中间把这一处写清楚，最后添一句心里的话。

师：这节课就上到这里。中间休息一会儿，回来我们就开始写。记录表放在手边，三杯豆子还摆在讲台上，写的时候想再看一眼，随时过来。

本课完。

## 第2课时 · 当堂写作与评改课

### 一、看着记录表，写下第一组句子（约 5 分钟）

[发放稿纸；投屏仍留着三则的日期、星期、天气那三行]

师：观察记录表摆在手边，先看第一行。三则日记按天数往下排，所以先落笔的是第一天那一则。稿纸第一行照着投屏上第一行抄：日期、星期、天气。

学生动笔写作

师：空两格，开头第一句就写这件事本身：今天这一杯刚下水。老师是这么开头的——“今天，杯子里泡下了一把黄豆。”你也起一句，说法可以是你自己的。

学生动笔写作

师：第一天这一则最省事，它没有可比的，只要把豆子刚下水的样子写清楚就行。写清楚了，后面两则才看得出它变过。接下来老师问一句，你们写一句，眼睛盯着第一行第三格那几个词。

师：那个时候它是什么颜色、什么形状？

学生动笔写作

师：凑近了看，皮上有没有纹、有没有印子，哪一处的黄深一点？

学生动笔写作

师：捏在手里是什么感觉，凑到鼻子跟前有没有味道？有一样就写一样，没有就跳过去。

学生动笔写作

师：最后一句：刚泡下的那个时候，你心里在想什么？照着第五格那几个字写出来。

学生动笔写作

师：笔停一下，把这几行从头读一遍。豆子刚下水的样子已经写在纸上了，这就是底子。写第二则、第三则的时候，第一句就有得比了：眼前这一颗跟你刚写下的这几行一对照，哪儿不一样，第一句就写哪儿。

### 二、自由写作，写成一组观察日记（约 20 分钟）

师：接着往下写。第一则写完就写第二则，第二则写完再写第三则，中间不要停笔。三则写完，大约需要十七八分钟。

师：往下写的时候，心里盯住三件事：每一则先写日期、星期、天气那一行；每一则的第一句点出今天哪儿不一样；三则写的必须是三处不同的地方。写错的字先放着，不要回头改，一路写下去。

学生动笔写作

[教师巡视，只做正向介入，不纠错字、不改病句、不打断书写顺畅的学生。按学情分四类处理——]

[接不下去型：写完第一则就停住、盯着稿纸——把他领回记录表：“第一则你已经写出来了。表上第二行填的是哪一处？就从那一处接着写第二则。”不要让他从头一句重写]

[内容空泛型：整则都是“豆子长大了，我很高兴”这类话——请他低头看自己盘里那一颗，问他“大在哪儿，是皮撑开了还是芽长了”，答出一句就让他直接写进去]

[书写顺畅型：不打断，走过时轻声一句“接着写”，为其留出书写空间]

[草草收尾型：一则只写两三句就搁笔说“写完了”、篇幅明显偏短——先肯定再推一步：“你写了皮上有缝，好。那条缝有多长，缝里露出来的是什么颜色？补上一两句。”]

[临近时间提示：到点先停笔，写到哪儿算哪儿；后面自改那段时间还能回来接着补]

### 三、交流评议，修改收束（约 20 分钟）

[组内轮读并对照实物（约 6 分钟）：四人一组，人人念一则，其余三人端着盘子对照]

师：先在小组里念。四个人一组，每人念一则，念你自己最有把握的那一则。念的同学只管念自己的，另外三位手里端着盘子，一边听一边找：他写的那一处，在豆子上是哪儿？找着了就指给他看。

师：要是三个人翻来覆去都找不着，也不要急着说他写错了。回他一句：你写的这一处我没有找着，请你再补一句，说说它长什么样。

学生互动分享（前后桌四人一组，人人念一则、其余三人对着盘子指认；教师走到两三组跟前听）

[全班念读（约 4 分钟）：请两位念，每位约两分钟]

师：刚才小组里都念过一轮了。现在请两位同学念给全班听。念完以后，请两位同学说一说：他写的哪一处，你在这三杯里对得上。

学生互动分享（两位同学依次念；每位念完请两位同学对着讲台上的三杯说出对得上的那一处；教师随后轻点评，落到具体句上——如指出他这一句比的是皮还是芽、用的是哪一种说法。请同学回答的时候换着来，几轮下来不要总是同几位）

[同桌互读画记号（约 3 分钟）]

师：稿子跟同桌交换一下。他那三则里，每一则都找一找：哪一句说出了今天跟上一回不同的地方。找着了，就在那一句旁边画一个小箭头。三则应该有三个箭头。

学生互动分享（同桌交换互读，各画箭头）

师：拿回自己的稿子看一眼：三个箭头都在吗？少了一个，说明那一则没有写出新的变化，等一下就改它。

[带标准修改（约 5 分钟）：延迟到此刻统一处理内容与错字]

师：修改之前，先对照这三句话看一看，自己达到了哪一档。

| 档位 | 自检的话 |
| --- | --- |
| 写成了 | 我写出了三则，每一则前面都有日期、星期、天气。 |
| 写清楚了 | 每一则的第一句都点出了今天变了的那一处，中间写出了它原来什么样、现在什么样，最后还有一句我当时心里的话。 |
| 让人对得上 | 别人听完，能在盘子里指出我写的是哪一处；三则写的是三处不同的地方。 |

师：对照这三条修改三处：第一，哪一则的第一行漏了日期、星期或者天气，就补上。第二，哪一则跟上一则说的是同一处，就换一处写，或者把它写得再细一点，细到别人能在盘子里找得着。第三，哪一句还停留在“变大了”“很神奇”上，就把它换成你眼睛真正看见的样子。改完再把文字看一遍：多余的圈掉，遗漏的补上，写错的改正。写不出的字，可以问同桌，或者举手问老师。

学生动笔写作（自改；教师巡视答疑）

[收尾（约 2 分钟）]

师：这三杯豆芽发了六天，一个字都没有记。今天记下它的这三则，是你们写的。刚才朗读的时候，同学能在豆子上指出你写的那一处，靠的不是“豆子长大了”这句话，而是你写出了皮是怎么松的、缝里挤出了什么、芽长到了多长。

师：这三杯老师还留着，明天就是第七天，芽还会接着往上长。今天这三则记下来了，往后接着记就有底子了。家里正种着、养着什么东西的同学，也是一样。

（教师总结）这节课我们学的是：一天写一则，每一则只抓变了的那一处，先点出来，再用“原来……现在……”“渐渐地”把它写清楚，最后添一句心里的话。今后写植物、写小动物、写天上的月亮，这套方法同样可以使用。

本课完。

全课完。

## 附：习作讲评指导环节（可选 · 单次课课后用 / 系列课作下次课开场用）

> 本环节供老师灵活取用：可在单次课课后批读学生习作后集中讲评一次，也可作系列课下一次课的开场（约 15–20 分钟）；不计入本课 45+45 分钟，评的是学生当堂完成的稿子，不布置新的写作任务。
> 讲评中凡出现 ＿＿＿ 处，务必换成本班学生习作里的真实句子，切勿虚构。

### 选稿（课前准备）

课后通读全班稿件，紧扣本课技法点（每一则点出变了的那一处、写清原来什么样现在什么样、三则各写一处），挑出三篇：

- 一篇较好的：三则各抓一处不同的变化，中间有“原来……现在……”这样的比较说法，用来让全班看清“把变化写清楚”是什么样子。
- 一篇中等的：三则都点出了变化，但是其中一则只给出了一个结果（“豆子又长大了一点”），没有写出到底哪儿大了，专门用来示范这一处怎么补。
- 一篇有典型问题的：三则说的是同一处，或者通篇都在写“我很喜欢它”“真神奇”，几乎看不出它长过。用来带着全班一起会诊、共同修改。

三篇一律投屏出示，不念作者姓名；讲评之前为三篇各拟一句评语，写明它对照本课技法好在哪里、欠在哪里。

### 讲评流程（每篇约 3–5 分钟，围绕本课技法点）

师：上次大家写的稿子，老师都读完了。今天只看两件事：每一则有没有说出今天哪儿变了；变了的地方有没有写出它长什么样。别的地方今天先不挑。

师：先看第一篇。他第二则的第一句是这样的：“＿＿＿”（念该则的头一句），下面接着写的是“＿＿＿”（念他写这一处时最具体的一两句）。大家听一听，他写的这一处，你们在杯子上找得着吗？

学生互动分享

（教师总结）他这一句没有停在“大了一点”上，前一半说的是前几天的样子，后一半说的是今天的样子。两截摆在一起，读的人就知道它这两天是怎么走过来的。

师：第二篇我们只看一处。他这一则点出了变化，可是接下来只有一句：“＿＿＿”（念那句只报结果的话）。这一句缺的是什么？

参考：没有说清楚哪儿变了／不知道它是什么样子。

师：那么给他补一句，应该补什么？

参考：写它是什么颜色／有多长／原来是什么样的。

师：说得对，把它原来的样子说出来，再说现在的样子，两截一摆就够了。一句话，不用写多。

师：第三篇不点名字，我们一起给他出出主意。这一篇三则写的是同一处，翻来覆去都在说它变大了。要把这一篇改回来，第一步应该改哪里？

学生互动分享

（教师总结）第一步是回到东西跟前，再看一遍——皮、颜色、缝、芽、水，一处一处地过。找出三处不同的，三则才各有各的话说。写不出新东西，多半不是不会写，而是看得还不够细。

### 收尾（点回技法、引向今后的写作）

师：三篇看下来，写得好的好在同一处：每一则都抓住了今天新变的那一样，还把它长什么样说了出来。今后你们记什么都用得上——记一盆花，记一只小狗长个儿，记这几天的天气。看一回，记一回，记的就是它跟上一回的不一样。

本环节完。
