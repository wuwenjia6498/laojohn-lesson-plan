# 《写观察日记》· 写作课教学设计

四年级上册·第三单元 校内同步写作（观察日记）

[教具准备：本课需老师课前发三杯黄豆。发法照发豆芽的常规做法，同一袋豆子、同样的杯子——第一杯在六天前的傍晚下水泡一夜，第二天早上把水沥干，盖一块拧过的湿布放在避光处，此后每天早晚各冲一次水、冲完仍沥干；第二杯在三天前的傍晚照同样的法子下水；第三杯上课前一晚下水，上课时仍泡在水里，就是第一天的样子。三杯各自下水的日期与星期课前记好，上课时报给学生并写在投屏上]

[异常处理：豆子全程闷在水里会发酸发臭，故第一、二杯务必沥干后湿布捂养。课前一天揭开湿布看一眼，若已发酸发臭，弃用实物，改用同一组豆子隔天拍的三张对比照片投屏出示；来不及发豆子的同此办理，教学步骤与讲法不变]

[授课提示：示范文里老师养蚕那一段是拟写的，供老师照着讲；老师自己真养过、种过、记录过什么，换成自己的更好。]

## 第1课时 · 写作指导课

### 一、创设情境，明确任务（约 6 分钟）

〖PPT 第3页 · 创设情境 · 讲台上这三杯豆子——同一颗黄豆的三天〗

师：六天前，老师在办公室亲手泡了几杯黄豆，一直细心养护到今天。大家先来看讲台这边。

[端出三杯黄豆并排放在讲台上，从左到右依次是第一天、第三天、第六天，与投屏上三张卡片的左右次序一致；杯身按此顺序贴“第一天”“第三天”“第六天”；左边第一天那杯仍泡在水里，另两杯揭开湿布。同时投屏出示三杯各自下水的日期与星期]

师：这三杯黄豆，全部来自同一袋豆子，用的杯子、养护方法也完全一样：头天晚上泡水静置一夜，第二天早上把水沥干，盖上湿布避光摆放，每天早晚各冲水一次。唯一不一样的，就是浸泡的时间。

左边这杯是昨晚刚泡的，现在还泡在水里，是黄豆最初第一天的样子；中间这杯是三天前泡的，今天是第三天；右边这杯是六天前泡的，今天刚好是第六天。

[此处的日期与星期照课前记下的实际情况报给学生，投屏上的内容即为学生抄写的日记时间信息]

师：所以大家眼前看到的，其实就是同一颗黄豆，在第一天、第三天、第六天的完整生长变化过程。

师：老师特意为这节课准备了这三组黄豆，六天里看着它一天天变化，一直没有记录，就是等着大家今天来观察、来记录。光用眼睛看，你们说得清它这几天哪儿变了吗？
参考：看得出来变化 / 豆子长大了 /／第一杯最小，最后那杯发芽了。

师：大家现在能看出区别，可过几天多半就记不清细节了，只会笼统说“豆子长大了”。但文字记录不一样，今天我们把变化写下来，后续豆芽继续生长，我们还能接着续写、持续观察。

〖PPT 第4页 · 创设情境 · 今天的任务——给豆子写一组观察日记〗

今天两节课，我们就完成一个核心任务：对照黄豆第一天、第三天、第六天的生长状态，一天写一篇，完成一组完整的观察日记。

师：写完后小组内轮流朗读，其他同学看着豆子，要能指出你写的是哪一处。如果大家能找出来，说明你写得准确、具体；如果找不出来，就说明你的描写太笼统，只说了“豆子变大了”，没有写清具体哪里变了、变成了什么样。

### 二、观察体验，看清眼前这几颗（约 9 分钟）

〖PPT 第5页 · 观察体验 · 豆子就在盘里——看清眼前这几颗〗

师：想要写好观察日记，第一步就是学会细致观察。每组桌上都有一个托盘，里面摆放着第一天、第三天、第六天的黄豆，大家可以认真看、轻轻触碰、翻面观察，也可以凑近闻一闻气味。

[每组发一个浅盘，内放第一天、第三天、第六天的豆子各一两颗并标好天数，盘底垫一小块湿纸巾]

师：观察的时候，老师提个小要求：先别说“变大了、真神奇”这类总结性的空话。大家专注感受，只用说出自己眼睛看到的、手摸到的、鼻子闻到的真实细节。

师：四人小组合作观察，轮流分享自己发现的细节，尽量不重复别人说过的内容，多多挖掘新的小变化。

〖PPT 第6页 · 观察体验 · 每组报一个——最不容易发现的细节〗

学生互动分享（四人一组围着盘子轮流交流，每人分享一处细节；教师巡视各组，倾听学生发言）

参考：初始的豆子圆圆的 / 豆皮上有浅浅的纹路 / 成熟的豆子豆皮撑开了 / 触感有的硬、有的顺滑 / 带着淡淡的豆香 / 豆子颜色微微发白 / 豆皮裂开缝隙 / 缝隙里冒出白色的小嫩芽 / 嫩芽短短弯弯的

师：大家先停一下，老师发现每个小组都观察得特别仔细！现在请每组推选一个最细微、最不容易发现的细节，和全班分享一下。

学生互动分享（随机抽取三四组，每组分享一处细微细节；教师复述学生的发现，如“豆皮上有淡淡的白印”“小芽的顶端是弯弯的”）

（教师总结）大家刚刚发现的豆皮、纹路、裂缝、嫩芽、颜色、软硬这些细节，都是实打实观察到的真实内容，有了这些细节，我们的观察日记就有内容、不空洞了。

### 三、学写法：跟上次比，写出变了的那一处（约 15 分钟）

〖PPT 第7页 · 判断对比 · 同写第三天的豆子——哪段才是合格的观察日记？〗

师：动笔写作前，我们先搞懂观察日记的核心写法。老师带来两段描写第三天黄豆的文字，大家仔细听，判断一下，哪一段才是合格的观察日记？

师：头一段是这样：“今天是第三天。我又去看了那杯豆子。它们挨挨挤挤地堆在杯子里，圆圆的，黄澄澄的，像一颗颗小珠子。我伸手指按了按，硬硬的，一点也不软。窗台上的太阳照过来，豆子上头亮晶晶的。我看了好一会儿才走。”

师：第二段是这样：“今天是第三天。豆子跟前天不一样了。前天它还是圆鼓鼓的一整颗，豆皮绷得紧紧的；今天皮松了，最深的一道纹裂开了，缝里挤出一点白，米粒那么大。我盯着那条缝看了半天。”

师：哪一段是今天该写的？

参考：第二段。

师：头一段颜色写了，形状写了，按上去什么感觉、太阳照着什么样，一样样都写到了，句子比第二段还长，问题到底在哪儿？

参考：它没说哪儿不一样了／写的还是豆子原本的样子，没有和之前对比。

师：第一段全是豆子本来就有的样子，没有和前一天做对比，看不出任何生长变化。

〖PPT 第8页 · 学写法 · 今天这一招——只抓变了的那一处〗

观察日记最重要的一点：一天一则，每一则都要写出和上一次相比，新出现的变化。如果只写固有样子，三则日记放在一起，完全看不出事物的生长过程，这也是大家写观察日记最容易犯的错误。

〖PPT 第9页 · 学写法 · 现场实操——把第一天和第三天摆在一起比〗

师：接下来我们现场实操，来找一找黄豆的变化。

[请学生从本组盘里取出第一天、第三天的豆子，并排对比观察；教师同步投屏对比照片，统一观察口径，从豆皮、大小、颜色、缝隙等角度引导观察]

师：大家把两天的豆子放在一起，仔细对比。先看豆皮，第一天的豆皮是什么状态？第三天的豆皮又有什么不一样？

参考：第一天豆皮紧绷贴在豆子上 / 第三天豆皮变松、有点发皱

师：再对比看看大小、颜色，有没有新变化？

参考：第三天那颗胖了一点／黄里带白／有一条缝。

师：找出来了。但只是这么说还不算写出来。老师把你们找出来的这一处，写成一句话给你们看——

〔教师示范·当场把找出的一处写成一句〕原来那层皮是紧绷绷贴在身上的，现在变得松松的，还出现好几道细纹。

师：大家看这句话，用了原来…… 现在……的对比句式，生长变化一下子就写清楚了。这样的说法还有几个：由……变成了……；渐渐地……；越来越……，都是写变化好用的说法。

师：书里那篇《爬山虎的脚》，叶圣陶写那些脚，可不是看一眼就写完的——今天看一回，隔几天再看一回，前后看了好些日子。

师：所以他那篇里到处是这样的词：不几天、以前、原先、现在、后来、逐渐。有了这些词，哪个时候什么样，一节一节就接上了——没搭着墙的那些脚慢慢枯掉，搭着墙的，细丝和小圆片一点点变成了灰色。我们今天写豆子，靠的也是这几个词。

〖PPT 第10页 · 学写法 · 每一则都照这三个要点写〗

师：今天我们核心掌握三个写作要点：

第一，每篇日记开头，直接点明今天新出现的变化，不用写“我又来看豆子了”这类空话；

第二，用上对比句式，写清事物之前的样子和现在的状态，把变化写具体；

第三，结尾加上一句自己当时真实的想法、感受——是等不及了，是舍不得碰，还是有点失望。

〖PPT 第11页 · 教师示范 · 照着三个要点，老师写一篇第三天的日记〗

师：老师照着这三个要点，完整写一篇第三天的观察日记，大家认真听。

〔教师示范·当场把「今天豆子哪儿不一样」写成一段〕今天是第三天。豆子跟前天不一样了。前天它还是圆鼓鼓的一整颗，皮紧紧地绷在身上，摸上去硬邦邦的；今天那层皮松了，出现好几道皱纹，最深的一道裂开了，缝里挤出一点白，米粒那么大，像刚冒出来的一颗小牙。杯壁上蒙着一层水汽，凑近了有股淡淡的豆腥味。我伸手指碰了碰那点白，软软的，一按就往里陷，赶紧又把手缩了回来。才第三天，它就顶出这么一点来，我怕手上一使劲，明天就没得看了。

师：轮到你们写。就写你刚才在盘子里看见的任意一处，用上“原来……现在……”写一句话，最后加上一句自己的真实感受，完成两句简短练笔。

学生动笔写作

师：谁写好了，念给大家听。

学生互动分享（随机抽取两三位学生朗读练笔内容；教师反馈落到他这两句上，如指出他对比的是豆皮、是颜色还是芽，对比清楚了没有，最后那句想法是不是他刚才盯着豆子时真想到的）

（教师总结）今天大家要记住这个核心写法：一天一则，每一则只抓一处新变化，先点明变化，用对比句式写具体，最后加上内心想法，观察日记就写到位了。

### 四、借助观察记录表，理清思路（约 8 分钟）

〖PPT 第12页 · 观察记录表 · 观察记录表〗

师：三则日记要写三处不一样的地方，脑子里想着容易串。先用一张表排一排。这张表叫观察记录表，表格只填关键词，简单清晰即可，自己能看懂就行。

[发放观察记录表；投屏出示同款空白表]

| 第几天 | 日期·星期·天气 | 我看到的 | 跟上次比，不一样在哪 | 内心感受 |
| --- | -------- | ---- | ---------- | ---- |
|     |          |      |            |      |
|     |          |      |            |      |
|     |          |      |            |      |

师：第二格照投屏上那三行抄，日期、星期、天气都在上面。日记的头一行就写这三样，这是日记的规矩，三则都要有。

师：老师先填一张给你们看。

[投屏逐格填写教师示范表，边填边念]

| 第几天 | 日期·星期·天气 | 我看到的  | 跟上次比，不一样在哪 | 内心感受 |
| --- | -------- | ----- | ---------- | ---- |
| 第一天 | 照投屏抄     | 圆、黄、硬 | 没得比        | 想快点  |
| 第三天 | 照投屏抄     | 皮松、有缝 | 缝里挤出白      | 想拨开看 |
| 第六天 | 照投屏抄     | 白芽、弯的 | 那点白长成芽     | 有点得意 |

师：看清楚了，每一格最多两三个词，一句整话都没有。可就是这几个词，每个词待会儿都能扩充出一两句来。最重要的是第四栏，三天的变化必须各不相同，不能三篇都只写“豆子变大了”。

〖PPT 第13页 · 观察记录表 · 轮到你——填表，再顺着说一遍〗

学生动笔写作（填表约 3 分钟；教师巡视）

〔应答·学生三行填的是同一处变化〕不否定他填的，指着盘子问一句：“大小以外，豆子皮呢？颜色呢？水呢？”让他就着眼前这几颗再找一处变化，自己换掉其中一行。

〔应答·学生说自己家里正养着、种着别的东西〕允许他改写自己的那一样（家里的猫、阳台上的蒜、每晚的月亮都行），提醒他同样是三则、三处不同的变化；表照填不误。

### 五、出示示范文，发现写法（约 7 分钟）

〖PPT 第14页 · 教师示范文 · 老师养蚕时写的一组日记——每篇开头写了什么新变化？〗

师：大家的思路都梳理清楚了。老师给大家带来一篇示范文，是我之前养蚕写的观察日记。大家认真听，重点找一个关键点：三则日记，每一篇开头分别写的是什么新变化？

> 【教师示范文】
> 
> 四月九日 星期四 晴
> 
> 今天我从同事那里领回来一小盒蚕。盒子打开，我差点没找着它们。十几条小东西趴在桑叶上，黑黑的，细得像一段一段的线头，比我的指甲盖还短。我用手指碰了碰盒子边，它们一动不动，只有嘴那一头在轻轻地动。桑叶上有几个针眼大的小洞，原来是它们咬的。就这么点大，也会吃东西了。
> 
> 四月十四日 星期二 阴
> 
> 才隔了五天，它们身上的黑就退掉了大半。上次还是一段段黑线头，今天从头那一节起，渐渐地变成了灰白色，只有尾巴尖上还留着一点黑。个头也长了，最长的那一条趴直了有小半个指节。我把新桑叶铺上去，它们爬得比上次快多了，一片叶子上很快就挤满了。
> 
> 四月二十日 星期一 晴
> 
> 今天早上一掀盒盖，我先听见了声音——沙沙沙，沙沙沙，像远处在下小雨。凑近了看，那些蚕已经全白了，身子一节一节的，比上次胖了一圈，趴在叶子上一口挨着一口地啃，叶子边上很快就啃出一个个半圆的缺口。有一条爬到盒角上不动了，昂着头，一动不动待了很久。我查了查，这是要蜕皮了。我在旁边守了十分钟，它还是那个姿势。我把盒盖轻轻合上，明天再来看它。

师：先来梳理结构，这是几则日记？每一则开头都有什么固定内容？

参考：三则日记；开头都写了日期、星期、天气。

师：再看第二篇、第三篇的开头，分别写了什么？

参考：第二篇写蚕的颜色变浅了；第三篇写蚕啃桑叶的声音、形态变了。

师：没错！三则日记，每一则都写一处全新的变化，不会重复之前的内容。第一天没有前一次可比，就把它一开头的样子写清楚，后面两则才有的比。

师：大家找一找，文中哪些句子把变化写得特别具体、能让人直观看到画面？

学生互动分享

〖PPT 第15页 · 旁批表 · 每句在做什么——把写变化的秘密摆出来〗

师：老师给大家整理一下示范文的写作技巧，大家对照学习。

[投屏出示旁批对照表，逐行带读]

| 示范文里的句子                       | 这一句在做什么                         |
| ----------------------------- | ------------------------------- |
| 四月九日 星期四 晴                    | 日记的头一行：日期、星期、天气                 |
| 细得像一段一段的线头，比我的指甲盖还短           | 头一天没得比，就把原来的样子写清楚，铺垫后续变化        |
| 才隔了五天，它们身上的黑就退掉了大半            | 开篇直接点明当日全新变化                    |
| 上次还是一段段黑线头，今天从头那一节起，渐渐地变成了灰白色 | 用“上次……今天……渐渐地……”这种对比句式，清晰写出生长变化 |
| 就这么点大，也会吃东西了                  | 结尾加入真实感悟，不写空洞套话                 |
| 沙沙沙，沙沙沙，像远处在下小雨               | 把听见的写成声音，读的人也听见了                |
| 叶子边上很快就啃出一个个半圆的缺口             | 不说“吃得快”，用具体形态体现变化               |
| 我把盒盖轻轻合上，明天再来看它               | 自然收尾，贴合真实观察场景，不强行升华道理           |

师：不管是观察蚕，还是观察黄豆，写作方法都是通用的：开头点出新变化，中间用对比写具体，结尾加真实感受。

师：第一课时内容就到这里，大家休息十分钟。待会第二课时，我们结合表格和实物，完整写完三篇观察日记。

### 一、看着记录表，写下第一组句子（约 5 分钟）

### 二、自由写作，写成一组观察日记（约 20 分钟）

〖PPT 第18页 · 自由写作 · 写完三篇——盯住这三件事〗

师：接着往下完成剩下两篇日记。写完第一篇再写第二篇，尽量连贯书写，不要频繁停笔。完整写完三篇，大概需要十七八分钟。

写作的时候留意三点：每篇日记开头，必须写好日期、星期、天气；每一篇开头要点明当天出现的新变化；三篇日记捕捉到的变化不能重复。写错的字先做标记，不用立刻停下来修改，先把全文写完。

学生动笔写作

[教师巡视，顺势引导，不随意打断正在写作的学生。根据不同学情灵活处理]

[写不下去的学生：写完第一篇就停滞]

[内容写得十分笼统，通篇只有“豆子长大了，我很开心”]

[时间临近尾声提示]

### 三、交流评议，修改收束（约 20 分钟）

[组内轮读并对照实物（约 6 分钟）：四人一组，人人念一则，其余三人端着盘子对照]

〖PPT 第19页 · 交流评议 · 端着盘子听——在豆子上找出他写的那一处〗

师：先在小组内互相交流。四个人轮流读一读自己最满意的一篇日记。朗读的同学认真读，其他同学端好托盘，一边听一边寻找：他描写的细节，对应豆子上哪一处？找到之后指出来。

学生互动分享（两名学生依次朗读；每读完一篇，请两名学生发言对应实物细节。教师点评时说清：他比的是哪两天、变的那一处写清了没有，尽量轮换发言同学）

[同桌互读画记号（约 3 分钟）]

师：把习作和同桌互换。大家在对方每一篇日记里，找出点明“当天变化”的那句话，在旁边画上小箭头。三篇日记，应该能找到三处这样的句子。

[带标准修改（约 5 分钟）]

〖PPT 第21页 · 修改收束 · 改一改——三档标准 + 三处重点〗

师：修改之前，大家对照三条标准，自查习作完成情况。

| 档位     | 自检的话                                            |
| ------ | ----------------------------------------------- |
| 写出来了   | 我写出了三则，每一则前面都有日期、星期、天气。                         |
| 写清楚了   | 每一则的第一句都点出了当天产生的新变化，写明白豆子之前、现在两种样子，结尾加上自己真实的想法。 |
| 写得能对上  | 别人读完文字，可以在豆子上找到对应的细节；三则分别写三处不一样的变化。             |

师：按照三条标准，重点修改三处内容：第一，补上缺失的日期、星期、天气；第二，如果两篇日记写了同一个变化，重新寻找新细节扩充或者改写；第三，删掉“豆子变大了、真神奇”这类空洞语句，换成你亲眼观察到的模样。修改完成后通读一遍，修正错别字，补充遗漏内容。遇到不会写的字，可以询问同桌或者举手请教老师。

学生动笔修改习作（教师巡视答疑）

〖PPT 第22页 · 收束 · 豆子还在长——日记也接着写下去〗

师：这三杯黄豆培育了六天，最开始没有留下任何文字记录。今天大家写下的三则日记，就是属于你们的观察记录。刚刚交流的时候，同学们能根据文字找到豆子上对应的细节，靠的不是一句简单的“豆子长大了”，而是写清楚豆皮怎么变松、缝隙冒出什么、嫩芽长成什么样子。

师：这些黄豆老师会继续养护，明天进入第七天，嫩芽还会继续长长。今天的记录打好基础，想要继续观察的同学，后续还可以接着写。家里养植物、养小动物的同学，也可以用同样的方法记录。

（教师总结）这节课我们掌握的方法：一天一篇观察日记，每一篇抓住一处新变化，先点明变化，借助“原来…… 现在……”“渐渐地”把细节写具体，最后加上内心真实感受。以后观察植物、小动物、自然景象，都可以用上这个方法。

## 附：习作讲评指导环节（可选 · 单次课课后用 / 系列课作下次课开场用）

> 本环节供老师灵活取用：可在单次课课后批读学生习作后集中讲评一次，也可作系列课下一次课的开场（约 15–20 分钟）；不计入本课 45+45 分钟，评的是学生当堂完成的稿子，不布置新的写作任务。
> 讲评中凡出现 ＿＿＿ 处，务必换成本班学生习作里的真实句子，切勿虚构。

### 选稿（课前准备）

课后通读全班稿件，围绕本课技法点（每一则点出变了的那一处、写清原来什么样现在什么样、三则各写一处）挑出三篇：

- 一篇较好的：三则各抓一处不同的变化，中间有“原来……现在……”这样的比法，用来让全班看见“写清楚了变化”长什么样。
- 一篇中等的：三则都点出了变化，但其中一则只报了个结果（“豆子又长大了一点”），没写出到底哪儿大了，用来演示这一处怎么补。
- 一篇有典型问题的：三则说的是同一处，或者通篇在写“我很喜欢它”“真神奇”，几乎看不出它长过。用来带全班一起出主意。

三篇均投屏出示，不念作者姓名；讲评前给三篇各拟一句话，写明它对着本课技法好在哪、欠在哪。

### 讲评流程（每篇约 3–5 分钟，围绕本课技法点）

〖PPT 第23页 · 习作讲评 · 习作讲评环节（可选·课后或下次课开场）〗

师：昨天的稿子老师都读了。今天只看两件事：每一则有没有说出今天哪儿变了；变了的地方有没有写出它长什么样。别的地方今天先不挑。

师：先看第一篇。他第二则的头一句是这样的：“＿＿＿”（念该则的头一句），底下接着写的是“＿＿＿”（念他写这一处时最具体的一两句）。你们听听，他写的这一处，你们在杯子上找得着吗？

学生互动分享

（教师总结）他这一句没有停在“大了一点”上，前一半说的是前几天的样子，后一半说的是今天的样子。两截摆在一起，读的人就知道它这两天是怎么走过来的。

师：第二篇我们只看一处。他这一则点出了变化，可接下来只有一句：“＿＿＿”（念那句只报结果的话）。这一句缺的是什么？

参考：没说清哪儿变了／不知道它什么样。

师：那给他补一句，该补什么？

参考：写它什么颜色／有多长／原来是什么样的。

师：对，把它原来的样子说出来，再说现在的样子，两截一摆就够了。一句话，不用多写。

师：第三篇不点名字，我们一起给他出个主意。这一篇三则写的是同一处，翻来覆去都在说它变大了。要救回来，第一步该动哪儿？

学生互动分享

（教师总结）第一步是回到东西跟前，再看一遍——皮、颜色、缝、芽、水，一处一处过。找出三处不同的，三则才各有各的话说。写不出新东西，多半不是不会写，是看得还不够细。

### 收尾（点回技法、引向今后的写作）

师：三则看下来，写得好的好在同一处：每一则都抓住了今天新变的那一样，还把它长什么样说了出来。往后你们记什么都用得上——记一盆花，记一只小狗长大，记这几天的天气。看一回，记一回，记的是它跟上回的不一样。

本环节完。
