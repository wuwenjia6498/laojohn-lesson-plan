# 《写观察日记》· 写作课教学设计

四年级上册·第三单元 校内同步写作（观察日记）

[教具准备：本课需老师课前发三杯黄豆。发法照发豆芽的常规做法，同一袋豆子、同样的杯子——第一杯在六天前的傍晚下水泡一夜，第二天早上把水沥干，盖一块拧过的湿布放在避光处，此后每天早晚各冲一次水、冲完仍沥干；第二杯在三天前的傍晚照同样的法子下水；第三杯上课前一晚下水，上课时仍泡在水里，就是第一天的样子。三杯各自下水的日期与星期课前记好，上课时报给学生并写在投屏上]

[异常处理：豆子全程闷在水里会发酸发臭，故第一、二杯务必沥干后湿布捂养。课前一天揭开湿布看一眼，若已发酸发臭，弃用实物，改用同一组豆子隔天拍的三张对比照片投屏出示；来不及发豆子的同此办理，教学步骤与讲法不变]

[授课提示：示范文里老师养蚕那一段是拟写的，供老师照着讲；老师自己真养过、种过、记录过什么，换成自己的更好。]

## 第1课时 · 写作指导课

### 一、创设情境，明确任务（约 6 分钟）

〖PPT 第3页 · 创设情境 · 观察讲台上这三盘豆子〗

师：六天前，老师在办公室泡了几盘黄豆，一直养护到今天。请大家先看讲台这边。

[端出三盘黄豆并排放在讲台上，从左到右依次是第一天、第三天、第六天，与投屏上三张卡片的左右次序一致；盘身按此顺序贴上“第一天”“第三天”“第六天”标签；左边第一天那盘仍泡在水里，另两盘揭开湿布。同时投屏出示三盘各自泡水的日期与星期]

师：这三盘黄豆，全部来自同一袋豆子，用的盘子、养护方法也完全一样：前一天晚上泡水静置一夜，第二天早上把水沥干，盖上湿布避光摆放，每天早晚各冲水一次。唯一的区别，就是浸泡时间的长短。

左边这盘是昨晚刚泡的，现在还泡在水里，是黄豆第一天的样子；中间这盘是三天前泡的，今天是第三天；右边这盘是六天前泡的，今天刚好是第六天。

[此处的日期与星期按课前记录的实际情况告知学生，投屏上的内容即为学生抄写的日记时间信息]

师：所以大家眼前看到的，就是同一批黄豆在第一天、第三天、第六天的生长变化过程。

师：这三盘黄豆是老师特意为这节课准备的。六天里，老师看着它们一天天变化，却一直没有记录，就是留着请大家今天来观察、来记录。只凭眼睛看，大家能说清楚它们这几天有哪些细微变化吗？
参考：看得出变化／豆子长大了／第一盘最小，最后一盘发芽了。

师：大家现在能看出区别，可是过几天，细节多半就记不清了，只能笼统地说一句“豆子长大了”。文字记录就不同了：今天把变化写下来，往后豆芽继续生长，我们还可以接着写、持续观察。

〖PPT 第4页 · 创设情境 · 今天的任务——给豆子写一组观察日记〗

今天两节课，我们完成一项任务：对照黄豆第一天、第三天、第六天的生长状态，一天写一则，完成一组完整的观察日记。

师：写完以后，小组内轮流朗读，其他同学对照实物豆子，要能准确找到你描写的位置。找得到，说明你写得准确、具体；找不到，说明描写太笼统，只说了“豆子变大了”，没有写清楚具体哪里变了、变成了什么样。

### 二、观察体验，看清眼前这几颗（约 9 分钟）

〖PPT 第5页 · 观察体验 · 豆子就在盘里——看清眼前这几颗黄豆〗

师：要写好观察日记，第一步是细致观察。每组桌上有一个托盘，里面放着第一天、第三天、第六天的黄豆。大家可以仔细看、轻轻摸、翻过来看，也可以凑近闻一闻。

[每组发一个浅盘，内放第一天、第三天、第六天的豆子各一两颗并标好天数，盘底垫一小块湿纸巾]

师：观察时，老师提一个要求：先不要说“变大了”“真神奇”这类概括性的话，只说自己眼睛看到的、手摸到的、鼻子闻到的具体细节。

师：四人小组合作观察，轮流说出自己发现的细节，尽量不重复别人说过的，多找一找新的小变化。

〖PPT 第6页 · 观察体验 · 每组报一个——最不容易发现的细节〗

学生互动分享（四人一组围着盘子轮流交流，每人分享一处细节；教师巡视各组，倾听学生发言）

参考：第一天的豆子圆圆的／豆皮上有浅浅的纹路／第六天的豆皮撑开了／摸起来有的硬、有的滑／有淡淡的豆香／豆子颜色微微发白／豆皮裂开了缝／缝里冒出白色的小芽／小芽短短的、弯弯的

师：请大家先停一下。刚才各小组观察得很仔细。现在请每组推选一处最细微、最不容易发现的细节，和全班分享。

学生互动分享（随机请三四组发言，每组分享一处细节；教师复述学生的发现，强化细节感知，如“豆皮上有淡淡的白印”“小芽的顶端是弯的”）

（教师总结）大家刚才发现的豆皮、纹路、裂缝、嫩芽、颜色、软硬，都是亲眼观察到的细节。有了这些细节，观察日记才有内容，不会空洞。

### 三、学写法：跟上次比，写出变了的那一处（约 15 分钟）

〖PPT 第7页 · 判断对比 · 同样写第三天的豆子——哪一段才是合格的观察日记？〗

师：动笔之前，我们先弄清楚观察日记的核心写法。老师带来两段描写第三天黄豆的文字，请大家仔细听，判断一下：哪一段才是合格的观察日记？

师：第一段是这样写的：“今天是第三天。我又去看了那盘豆子。它们挨挨挤挤地堆在盘子里，圆圆的，黄澄澄的，像一颗颗小珠子。我伸手指按了按，硬硬的，一点也不软。窗台上的太阳照过来，豆子上面亮晶晶的。我看了好一会儿才走。”

师：第二段是这样写的：“今天是第三天。豆子跟前天不一样了。前天它还是圆鼓鼓的一整颗，豆皮绷得紧紧的；今天皮松了，最深的一道纹裂开了，缝里挤出一点白，米粒那么大。我盯着那条缝看了半天。”

师：哪一段才是今天应该写的？

参考：第二段。

师：第一段写了颜色，写了形状，按上去什么感觉、太阳照着什么样，一样一样都写到了，句子比第二段还长。问题出在哪里？

参考：它没有说哪里不一样了／写的还是豆子原本的样子，没有和之前对比。

师：说得对。第一段写的全是豆子本来就有的样子，没有和前一天对比，看不出任何生长变化。

〖PPT 第8页 · 学写法 · 今天的方法——只抓变了的那一处〗

观察日记最重要的一点：一天一则，每一则都要写出和上一次相比新出现的变化。如果只写固有的样子，三则日记放在一起，就看不出事物的生长过程。这是写观察日记最容易出现的问题。

〖PPT 第9页 · 学写法 · 当场练习——把第一天和第三天放在一起比〗

师：接下来我们当场练习，找一找黄豆的变化。

[请学生从本组盘里取出第一天、第三天的豆子，并排对比观察；教师同步投屏对比照片，统一观察口径，从豆皮、大小、颜色、缝隙等角度引导观察]

师：请大家把两天的豆子放在一起，仔细对比。先看豆皮：第一天的豆皮是什么样的？第三天的豆皮有什么不一样？

参考：第一天豆皮紧绷绷地贴在豆子上／第三天豆皮变松了、有点发皱

师：再对比一下大小和颜色，有没有新的变化？

参考：第三天那颗胖了一点／黄里带白／有一条缝。

师：变化找出来了，但只是这样说，还不算写出来。老师把大家找出的这一处，写成一句话——

〔教师示范·当场把找出的一处写成一句〕原来那层皮紧绷绷地贴在豆子上，现在变松了，还出现了好几道细纹。

师：大家看这句话，用了“原来……现在……”的对比句式，变化一下子就写清楚了。类似的句式还有“由……变成了……”“渐渐地……”“越来越……”，都是写变化的常用句式。

师：叶圣陶先生写过一篇《爬山虎的脚》。他写爬山虎的脚，不是看一眼就写成的——今天看一回，隔几天再看一回，前后观察了许多天。

师：所以这篇文章里常常出现这样的词：不几天、以前、原先、现在、后来、逐渐。有了这些词，什么时候是什么样，一段一段就衔接上了——没有触着墙的脚慢慢萎了，触着墙的，细丝和小圆片逐渐变成灰色。我们今天写豆子，靠的也是这几个词。

〖PPT 第10页 · 学写法 · 每一则都照这三个要点写〗

师：今天我们重点掌握三个写作要点：

第一，每则日记开头，直接点明今天新出现的变化，不写“我又来看豆子了”这类没有内容的话；

第二，用上对比句式，写清事物之前的样子和现在的状态，把变化写具体；

第三，结尾加上一句自己当时真实的想法、感受——是等不及，是舍不得碰，还是有些失望。

〖PPT 第11页 · 教师示范 · 照着三个要点，老师写一则第三天的日记〗

师：老师照着这三个要点，完整地写一则第三天的观察日记，请大家认真听。

〔教师示范·当场把“今天豆子哪里不一样”写成一段〕今天是第三天。豆子跟前天不一样了。前天它还是圆鼓鼓的一整颗，皮紧紧地绷在身上，摸上去硬邦邦的；今天那层皮松了，出现好几道皱纹，最深的一道裂开了，缝里挤出一点白色的芽，米粒那么大，像刚冒出来的一颗小牙。盘壁上蒙着一层水汽，凑近了有股淡淡的豆腥味。我伸出手指碰了碰那个新芽，软软的，一按就往里陷，我赶紧又把手缩了回来。才第三天，它就顶出这么一点来，我怕手上一用力，明天就看不到它了。

师：现在轮到大家写。就写你刚才在盘子里看到的任意一处，用“原来……现在……”写一句，再加上一句自己的真实感受，完成两句话的练笔。

学生动笔写作

师：写好的同学，请读给大家听。

学生互动分享（随机请两三位学生朗读练笔；教师反馈紧扣这两句话，如指出对比的是豆皮、颜色还是芽，对比是否清楚，最后一句感受是否真实）

（教师总结）今天要记住的核心写法是：一天一则，每一则只抓一处新变化，先点明变化，再用对比句式写具体，最后加上内心想法，观察日记就写到位了。

### 四、借助观察记录表，理清思路（约 8 分钟）

〖PPT 第12页 · 观察记录表 · 先用一张表理清三处变化〗

师：三则日记要写三处不同的变化，只靠记忆容易混淆，我们先用一张表理一理。这张表叫观察记录表，只填关键词，简单清楚、自己能看懂就可以。

[发放观察记录表；投屏出示同款空白表]

| 第几天 | 日期·星期·天气 | 我看到的 | 跟上次比，不一样在哪里 | 内心感受 |
| --- | -------- | ---- | ---------- | ---- |
|     |          |      |            |      |
|     |          |      |            |      |
|     |          |      |            |      |

师：第二栏照投屏上的三行抄写，日期、星期、天气都在上面。日记的第一行就写这三项，这是日记的格式要求，三则都要有。

师：老师先填一张示范。

[投屏逐格填写教师示范表，边填边读]

| 第几天 | 日期·星期·天气 | 我看到的 | 跟上次比，不一样在哪里 | 内心感受 |
| --- | -------- | ----- | ---------- | ---- |
| 第一天 | 照投屏抄 | 圆、黄、硬 | 无从对比 | 想让黄豆快点长大 |
| 第三天 | 照投屏抄 | 皮松、有缝 | 缝里挤出白色的东西 | 想拨开看 |
| 第六天 | 照投屏抄 | 白芽、弯的 | 那点白长成了芽 | 有点得意 |

师：请大家注意，每一格最多两三个词，没有一句完整的话。可就是这几个词，稍后每一个都能扩展成一两句话。最重要的是第四栏，三天的变化必须各不相同，不能三则都只写“豆子变大了”。

〖PPT 第13页 · 观察记录表 · 轮到你——填表，再顺着说一遍〗

学生动笔写作（填表约 3 分钟；教师巡视）

〔应答·学生三行填的是同一处变化〕不否定他所填的内容，指着盘子追问：“除了大小，豆皮呢？颜色呢？水呢？”让他对照眼前的豆子再找一处变化，自己替换其中一行。

〔应答·学生说自己家里正养着、种着别的东西〕允许他改写自己观察的对象（家里的猫、阳台上的蒜、每晚的月亮都可以），提醒他同样要写三则、三处不同的变化；表格照常填写。

师：填完表格的同学，小声顺着表格说一遍：第一天我看见了什么，第三天哪里不一样了，第六天又有什么不同。说得不顺的地方，就是还没有想清楚的地方。

师：谁来说一说自己找到的三处不同变化？

### 五、出示示范文，发现写法（约 7 分钟）

〖PPT 第14页 · 教师示范文 · 老师养蚕时写的一组日记——每则开头写了什么新变化？〗

师：思路理清楚了。老师给大家带来一组示范文，是老师以前养蚕时写的观察日记。请大家认真听，重点关注一个问题：三则日记，每一则开头分别写了什么新变化？

> 【教师下水文 · 示范】
> 
> 四月九日 星期四 晴
> 
> 今天我从同事那里领回来一小盒蚕。盒子打开，我差点没找着它们。十几条小东西趴在桑叶上，黑黑的，细得像一段一段的线头，比我的指甲盖还短。我用手指碰了碰盒子边，它们一动不动，只有嘴那一头在轻轻地动。桑叶上有几个针眼大的小洞，原来是它们咬的。就这么点大，也会吃东西了。
> 
> 四月十四日 星期二 阴
> 
> 才隔了五天，它们身上的黑就退掉了大半。上次还是一段段黑线头，今天从头那一节起，渐渐地变成了灰白色，只有尾巴尖上还留着一点黑。个头也长了，最长的那一条趴直了有小半个指节。我把新桑叶铺上去，它们爬得比上次快多了，一片叶子上很快就挤满了。
> 
> 四月二十日 星期一 晴
> 
> 今天早上一掀盒盖，我先听见了声音——沙沙沙，沙沙沙，像远处在下小雨。凑近了看，那些蚕已经全白了，身子一节一节的，比上次胖了一圈，趴在叶子上一口挨着一口地啃，叶子边上很快就啃出一个个半圆的缺口。有一条爬到盒角上不动了，昂着头，一动不动待了很久。我查了查，这是要蜕皮了。我在旁边守了十分钟，它还是那个姿势。我把盒盖轻轻合上，明天再来看它。

师：先来梳理结构，这是几则日记？每一则开头都有什么固定内容？

参考：三则日记；开头都写了日期、星期、天气。

师：再看第二则、第三则的开头，分别写了什么？

参考：第二则写蚕的颜色变浅了；第三则写蚕啃桑叶的声音和形态变了。

师：对。三则日记，每一则都写一处新的变化，不重复之前的内容。第一天没有对比对象，就把最初的样子写清楚，作为后续观察的基础。

师：请大家找一找，文中哪些句子把变化写得具体，让人能看到画面？

学生互动分享

〖PPT 第15页 · 旁批表 · 每句在做什么——把写变化的方法找出来〗

师：老师把示范文里的写作方法整理成一张表，大家对照着看。

[投屏出示旁批对照表，逐行带读]

| 示范文里的句子 | 这一句在做什么 |
| ----------------------------- | ------------------------------- |
| 四月九日 星期四 晴 | 日记的第一行：日期、星期、天气 |
| 细得像一段一段的线头，比我的指甲盖还短 | 第一天无从对比，就把最初的样子写清楚，为后续变化作铺垫 |
| 才隔了五天，它们身上的黑色就退掉了大半 | 开头直接点明当天的新变化 |
| 上次还是一段段黑线头，今天从头那一节起，渐渐地变成了灰白色 | 用“上次……今天……渐渐地……”这种对比句式，清晰写出生长变化 |
| 就这么点大，也会吃东西了 | 结尾写真实感受，不写空话套话 |
| 沙沙沙，沙沙沙，像远处在下小雨 | 把听到的写成声音，读者如闻其声 |
| 叶子边上很快就啃出一个个半圆的缺口             | 不说“吃得快”，用具体形态体现变化               |
| 我把盒盖轻轻合上，明天再来看它 | 自然收尾，贴合真实观察情境，不刻意升华 |

师：无论观察蚕还是观察黄豆，写法是相通的：开头点出新变化，中间用对比写具体，结尾写真实感受。

师：第一课时到这里结束，大家课间休息。第二课时，我们结合表格和实物，完整写出三则观察日记。

| 档位 | 自检要点 |
| ------ | ----------------------------------------------- |
| 基础档 | 写出了三则，每一则开头都有日期、星期、天气。 |

## 附：习作讲评指导环节（可选 · 单次课课后用 / 系列课作下次课开场用）

> 本环节供教师灵活选用：可在单次课课后批阅学生习作后集中讲评一次，也可作为系列课下一次课的开场（约 15–20 分钟）；不计入本课 45+45 分钟，讲评对象为学生当堂完成的习作，不布置新的写作任务。
> 讲评中凡出现 ＿＿＿ 处，务必换成本班学生习作里的真实句子，切勿虚构。

### 选稿（课前准备）

课后通读全班习作，围绕本课技法点（每一则点出变化之处、写清原来什么样和现在什么样）选出三篇：

- 一篇较好的：三则各抓一处不同的变化，中间有“原来……现在……”这样的对比，用来让全班看到“写清楚了变化”是什么样子。
- 一篇中等的：三则都点出了变化，但其中一则只写了结果（“豆子又长大了一点”），没有写出到底哪里大了，用来示范这一处怎么补。
- 一篇有典型问题的：三则写的是同一处，或者通篇在写“我很喜欢它”“真神奇”，几乎看不出它的生长过程，用来带全班一起想办法。

三篇均投屏出示，不读作者姓名；讲评前为三篇各拟一句评语，写明对照本课技法好在哪里、欠在哪里。

### 讲评流程（每篇约 3–5 分钟，围绕本课技法点）

〖PPT 第24页 · 习作讲评 · 习作讲评环节（可选·课后或下次课开场）〗

师：大家的习作老师都读过了。今天只看两件事：每一则有没有写出今天哪里变了；变了的地方有没有写出它是什么样。其他方面今天先不评。

师：先看第一篇。这位同学第二则的第一句是：“＿＿＿”（读出该则的第一句），接着写的是“＿＿＿”（读出写这一处最具体的一两句）。大家听一听，他写的这一处，在盘子上能找到吗？

学生互动分享

（教师总结）这一句没有停留在“大了一点”上，前半句写的是前几天的样子，后半句写的是今天的样子。两半放在一起，读的人就知道它这几天是怎么变化的。

师：第二篇只看一处。这一则点出了变化，可接下来只有一句：“＿＿＿”（读出那句只写结果的话）。这一句缺了什么？

参考：没有说清楚哪里变了／不知道它是什么样。

师：那么补一句，应该补什么？

参考：写它是什么颜色／有多长／原来是什么样。

师：对，先写它原来的样子，再写现在的样子，两部分一对比就够了。一句话，不必多写。

师：第三篇不点名，我们一起帮这位同学想办法。这一篇三则写的是同一处，反复在说它变大了。要修改，第一步应该从哪里入手？

学生互动分享

（教师总结）第一步是回到观察对象跟前，再看一遍——豆皮、颜色、缝隙、嫩芽、水，一处一处地看。找出三处不同，三则才各有各的内容。写不出新内容，多半不是不会写，而是看得还不够细。

### 收尾（点回技法、引向今后的写作）

师：三篇看下来，写得好的好在同一处：每一则都抓住了当天新出现的变化，还写出了它是什么样。今后大家记录什么都用得上——记一盆花，记一只小狗长大，记这几天的天气。看一次，记一次，记的是它和上一次的不同。

本环节完。
