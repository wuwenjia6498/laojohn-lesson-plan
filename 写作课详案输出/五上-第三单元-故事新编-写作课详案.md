# 《故事新编》· 写作课教学设计

五年级上册·第三单元 校内同步写作（想象习作）

## 教案提纲表

| 课题·课时  | 五年级上册·第三单元《故事新编》　│　想象·校内同步　│　2课时连排（每节45分钟）                                                    |
| ------ | --------------------------------------------------------------------------------------------- |
| 能力阶段   | 写清楚 → 写具体 → 写生动（本课） → 写深刻·有章法                                                                 |
| 同类习作顺序 | 想象：续写故事／编童话 → 奇妙的想象／这样想象真有趣 → 我和＿＿过一天 → 奇思妙想 → 故事新编（本课）／二十年后的家乡 → 神奇探险 → 变形记／笔尖流出的故事 → 插上科学翅膀 |
| 教材要求   | 统编五年级上册·第三单元习作：展开想象，给经典故事换个新编法。                                                               |
| 学习目标   | 通过先定新结局、再倒回去找出哪一处变了，来学习怎么写一篇故事新编。                                                             |
| 核心技法   | 使用“构思表”。先定下新结局，再倒回去找出是哪一处变了——编龟兔赛跑的，这一处从课本列的五条新情节里挑，编别的故事就自己想一件；让后面两三件事都从这一处接下来，最要紧的那一幕，把他的动作拆开一步一步写，配上他说的、心里想的和旁边人的反应。                                |

## 第1课时 · 写作指导课

### 一、创设情境，明确任务（约 4 分钟）

师：《龟兔赛跑》最后是谁赢的？

参考：乌龟。／乌龟赢了，兔子睡着了。

师：对。不过老师这里的这一只没睡。它跑到那棵树底下，停下来回头看了一眼，乌龟还在老远的地方，慢腾腾的。它就接着往前跑了。

学生自由分享

参考：那乌龟不就输了。／那还有什么好比的。／这不是原来的故事了。

师：这就是老故事好用的地方：原来那个样子，每个人脑海里都存着一份。

师：今天这两节课，我们每人挑一个自己最熟的老故事，重新编一个。第二节课写完，就在这间教室里开一场故事新编会。念的人不报故事名，只念自己改动的那一段；听的人手边什么材料都不用，这些老故事你们本来就知道。听完只回答两句话：他改的是哪一处？改了以后，后面哪几件事跟着变了？

师：这两句就是今天判断写成没写成的标准。听的人拿它判你，你自己写的时候也照着对一对。

师：这就是本学期语文书上第三单元的习作，题目叫“故事新编”。课本上还说，编完以后可以配上插图，跟大家一起分享这些有趣的故事。分享这一步，我们今天就在课上做完。

### 二、打开故事库，选定老故事（约 5 分钟）

师：我们动笔之前先解决一件事：你要编的是哪一个老故事。给你们二十秒，各自在脑海里回想一遍：你从小听到大的那些故事里，哪几个到今天还能一口气把结局说出来。

学生自由分享

师：请报出来听一听。一人报一个，别人报过的就跳过。

学生互动分享

参考：狐假虎威。／掩耳盗铃。／画蛇添足。／小红帽。／精卫填海。／漏。／后羿射日。／丑小鸭。／拔苗助长。／守株待兔。

师：（教师总结）你们报的这些故事大致是三类：寓言，像狐假虎威、掩耳盗铃、画蛇添足；童话，像小红帽、丑小鸭；神话和民间故事，像精卫填海、后羿射日、漏。三类都能拿来编。

师：现在各自定一个。课本这次把话说在前面了：要选一个自己熟悉的故事来编。所以定的时候多想一层：这个故事，全班是不是都知道。今天写完是要念给同学听的，听的人要听出你改在哪里；他如果根本不知道原来是什么样，你改得再巧他也听不出来。

师：定好了和同桌说一句，问他知不知道你选的这一个。如果他说没听过，就换一个，换成刚才全班报出来的那几个里的一个。

学生互动分享

[教师巡视：留意选到冷门故事的学生，请该生换掉，换成刚才全班报出来的那几个之一。这次习作要求选熟悉的故事，同桌一听是陌生的，就说明这一个不合适。]

### 三、学写法：先定结局，再倒回去找那一处（约 16 分钟）

师：同样是新编《龟兔赛跑》的开头，老师写了两段。我读一遍，你们听完判断：哪一段更像我们这次要编的故事新编。

[投屏：出示下面两段话，教师逐段读一遍。]

〔教师示范·当场念出的第一段〕兔子和乌龟又比了一回。这回乌龟背上了一只喷气背包，一按开关就窜出去老远。兔子从路边推出一辆红色的跑车，油门一踩，车屁股后头冒出两股白烟。路两边站满了看比赛的动物，举着牌子喊加油，喊声一阵高过一阵。半道上蹦出来一只会说话的松鼠，冲它们俩挥手，说了一句“你们两个都很棒”。终点线前立着一块大屏幕，上面滚动着它们的名字，一个红的一个蓝的。最后它们一前一后冲过终点，裁判举着秒表看了半天，说两个数字一模一样。

〔教师示范·当场念出的第二段〕兔子和乌龟又比了一回。跑到半路，前头忽然多出一段又长又陡的下坡。兔子在坡顶刹住脚，探头往下看了看，坡面滑得发亮，它怕栽跟头，只好侧着身子一步一步往下挪。乌龟爬到坡边，把头往壳里一缩，四条腿也收了，整个身子贴着坡面滚了下去，咕噜咕噜一路滚到坡底，回头一看，兔子还在半坡上。

师：哪一段更像我们这次要编的故事新编？

参考：第一段吧，第一段热闹。／第一段想得更奇，喷气背包、跑车、大屏幕都有。／第二段。

师：说第一段的同学，请你说一说，你觉得它哪一点编得对？

参考：它改的地方多。／它想得跟别人不一样。／新编不就是要编得离奇一点吗。

师：你们说的这几点，都看准了。那老师来做一个实验：把第一段里那只会说话的松鼠整个抽掉，你们看，前后接不接得上？

参考：接得上。／一点不影响。／照样跑它的。

师：再拿第二段试一次。把“多出一段又长又陡的下坡”那一句抽掉。

参考：那就塌了。／后面全没着落了。／那乌龟滚什么呀。

师：那请大家说一说，这两段的差别到底在哪里。一句话说清楚。

参考：第二段后面的事都是从那段下坡来的。／第一段是一样一样往上堆，互相不挨着。／第一段里那些花样，抽掉哪一样都不碍事。

师：（教师总结）说到点子上了。你们说的这件事，正是编新故事时最要紧的一条：后面的每一件事，都能在前面找到出处。

师：那这一处改动，怎么找？课本给了一条路，这一次你们自己走一趟。

[投屏：出示教材第 46 页习作页，只出上面那一行四个结局；下面那几条新的情节先不出，等两组念完再出。]

师：课本上让我们先设想故事的结局，给了四个：乌龟和兔子都赢了；乌龟和兔子都没能赢；兔子赢了；乌龟又赢了。让我们统一都挑最后这一个结局：乌龟又赢了。

师：四人一组，往回推一条路出来。要让乌龟又赢，半路要先出一件什么事？出了这件事，兔子怎么样、乌龟怎么样，一步一步推到那个结局。三四步能推到即可，不必写得太长。每组留下最顺的一条，接下来念给全班，给你们两分钟。

学生互动分享

[教师巡视：只对推不下去的组问一句“你们那件事出了以后，最先受影响的是谁”，不替学生定路线。]

师：请两组来念一念。其余同学听一件事：他那条路上，有没有哪一步是硬塞进去的。

学生互动分享

参考：我们挑的是兔子看见一片萝卜地——它拔一个啃，吃撑了，走两步歇一下，乌龟从它旁边爬过去了。／我们挑的是半路下起大雨，兔子怕淋湿躲进树洞，想着等雨停，一等就晚了。

师：这两条都接得住。

[投屏：接着出示教材第 46 页下半页那几条新的情节。]

师：课本上其实也列好了。你们自己推出来的这两条，萝卜地和下大雨，它上面都列着。课本一共给了五条：路遇不测、急中出错、遇到诱惑、赛道变化、天气变化。

师：编龟兔赛跑的同学，这次动笔就从这五条里挑一条，不必另想别的，课本给的这五条稳当。编别的故事的同学，那一处改动由你自己想。你的主角半路上会出什么事，只有你想得出来。这五条可以拿来参考，看一看有没有一条正对得上你那个故事；对不上就别硬往上套，自己想的那一件只要后面接得住，一样算数。

师：老师接着问一个难一点的问题：萝卜地和下大雨这两条，哪一条你更能把出事的那一刻写出来，写到让别人像看见一样？说出你的理由。

学生互动分享

[组织提示：请两位学生说，每位一句理由，不展开。学生说到“这一条我写得出他当时什么样”这一类答案就收住，它正是下面要接的那一层。]

参考：萝卜地那条吧，我能写出兔子啃萝卜的样子。／下雨那条，我写得出它躲在哪儿、雨打在身上什么感觉。

师：（教师总结）你们挑的理由都落在同一件事上：这一条出了以后，那一刻你写得出来。不管是从课本这五条里挑，还是自己想一件，都得这样衡量一下。还有一条也说在前面：你定的这一件，要是那个故事里本来就有，那等于没改；得是原来没有的，才算真改了。

师：这一趟你们自己走完了。归纳起来，这是一个什么办法？

参考：先想好结局，再倒回去找。／找一件能带出后面那串事的。

师：（教师总结）就这两句：先定新结局，再倒回去找出是哪一处变了；这一处定下来，后面的事一件一件从它接下去。往后我们就把它叫作“改一处，后面跟着变”。

师：那改好几处行不行？下节课真正动笔有二十五分钟，一处改透就够你写的；真写顺了还有时间，再添一处也可以，前提是每一处都接得住。

师：动笔之前还有一件事要各自定下来：你那个故事的新结局。编龟兔赛跑的，就从课本给的那四个结局里挑一个；编别的故事的，新结局得你自己定。想一想：它原来的结局是什么，你想把它变成什么。

参考：守株待兔原来是苗全枯了、人也没等着兔子，我想让他真等着一只。／小红帽原来是猎人把她们救出来的，我想让她自己想办法脱身。

师：定下新结局，再倒回去定那一处改动。现在和同桌各说两句：你的新结局是什么，你打算改哪一处，为什么是它。不用讲整个故事。

学生互动分享

[组织提示：同桌两人同时说，约一分钟；说完请两位学生说给全班听。人人都说到，是为了下一个环节填表时心里已经有了那一处。]

参考：我编守株待兔，新结局是他真等着一只；我改的是他在树桩边搭了个草棚遮太阳，兔子把那草棚当成了草丛，一头钻进去，正落在他手边。／我编小红帽，新结局是她自己脱身。我改的是出门前外婆和她说好了暗号：她敲门，外婆要在里头咳三声。那天她敲完门，里头一声也没有。／我编丑小鸭，我改的是路上一群野鸭子留它一块儿过冬，这一条正好是课本上说的“遇到诱惑”。

师：（教师总结）刚才发言的几位，有的挑的是课本上那一条，有的是自己想的，都说出了定它的理由。还有一件事先说在前面：你改动的那一处正在发生的时候，就是这一篇里最要紧的一幕，那一幕要写得让人看见；别处照原来的故事带过去即可。往下怎么编，我们用一张表理一理。

### 四、借助构思表，理清思路（约 8 分钟）

师：手上这张表一共六格，一次填完：编的哪个故事、它原来的结局、你要的新结局、是哪一处变了、跟着变的两三件事、最要紧的那一幕。每格只写关键词，不写整句，三分钟填完。第四格填的就是你刚才和同桌说过的那一处改动，写清楚它落到你的故事里是件什么事。

| 想一想                  | 写下关键词 |
| -------------------- | ----- |
| 我编的老故事               |       |
| 它原来的结局               |       |
| 我要的新结局               |       |
| 是哪一处变了（编龟兔赛跑的从课本五条里挑） |       |
| 跟着变的事（两三件）           |       |
| 最要紧的那一幕：谁在做什么        |       |

师：老师先当着大家的面填一张。老师编的是《狐假虎威》。

| 想一想                  | 写下关键词     |
| -------------------- | --------- |
| 我编的老故事               | 狐假虎威        |
| 它原来的结局               | 老虎信了狐狸      |
| 我要的新结局               | 老虎看清了       |
| 是哪一处变了（编龟兔赛跑的从课本五条里挑） | 路遇不测·老虎掉进坑  |
| 跟着变的事（两三件）           | 百兽不跑、反倒围住狐狸 |
| 最要紧的那一幕：谁在做什么        | 老虎踩塌枯枝      |

师：每一格都是几个词，最长的一格也不过十来个字。第四格如果拿不定主意，后面几格都填不实，不要写得含糊。

学生动笔写作

师：填完请从头看一遍，在第六格上画一道横线。第二节课，那一格就是你要花最多笔墨的地方，其他格一两句带过。

师：接着请小声把这张表从头到尾说给自己听一遍：我编的是哪个故事，原来的结局是什么，我改的是哪一处，后面哪几件事跟着来了。说到哪一格说不顺，那一格就是还没想清楚的地方，做个记号。

[教师蹲点：走到三四位学生跟前，当学生的第一位听众，只在学生说不顺的那一格追问一句“那这一处变了以后，谁最先发觉”。]

学生自由分享

师：请两位说给全班听。其余同学听一件事：他改的那一处，和他后面那几件事，接得上接不上。

学生互动分享

参考：我编的是拔苗助长，原来是苗全枯了，我改成苗真的长高了——那天夜里下了一场透雨。／我编的是漏，原来老虎和贼互相吓跑了，我改成它们俩撞上以后一块儿躲雨，谁也没敢先动。

师：（教师总结）两位说的都接得上。接下来看一看老师那张表，写出来是什么样子。

### 五、出示示范文，发现写法（约 12 分钟）

师：我们先看其中一段。就是老师表上最后那一格，“老虎踩塌枯枝”这六个字变出来的那一段。

[投屏：先只出示下面这一段。]

> 【教师示范文】（片段，先出示这一段）
> 
> 山路上铺着一层新落的枯枝。狐狸身子轻，一溜就过去了。老虎跟上来，前爪刚踩实，那层枯枝“咔”的一声塌下去。它身子往下一沉，两只前爪在土壁上刨了两下，没抓住，重重摔进坑里。这是猎人挖的陷阱，一人多深。老虎仰起脸，只看得见头顶一个圆圆的天，和坑沿上那半截尾巴。

师：表上那一格只有六个字。这一段里，哪几样内容是从这六个字里铺开的？

参考：先写狐狸身子轻，一溜就过去了，老虎跟上来才塌。／写它两只前爪刨了两下，没抓住。／写它掉下去以后仰起脸，看见头顶一个圆圆的天。

师：（教师总结）一格六个字，铺开就是这一段。再看一件事。这一段里新添进来的只有一处：猎人挖的这个坑。山路、枯枝、狐狸那条翘着的尾巴，原来的故事里本来就有。

师：现在我们看整篇。这一遍请自己默读，一边读一边留意三件事：开头这一段在做什么；跟原来的故事比，变的是哪几处；哪一句你想学过来、用到自己那一篇里去。读完这三件事一件一件说。

[投屏：出示整篇示范文，学生默读，约一分半钟。这一篇全程只通读这一次，后面三问都从这一遍里来，不再重读。]

> 【教师示范文】
> 
> 自从跟着狐狸在林子里走过一趟，老虎就再没怀疑过它的话。那一趟走下来，野兔、山鹿、野猪，见了狐狸远远地就躲开，老虎跟在后头看得清清楚楚——狐狸说自己是天帝派来管百兽的，看来一点不假。这天狐狸又找上门来，说趁着天好，再去巡一趟。
> 
> 狐狸尾巴翘得老高走在前头，老虎跟在七八步外。前边草丛一动，两只野兔窜出去老远。狐狸回过头：“看见没有？”
> 
> 山路上铺着一层新落的枯枝。狐狸身子轻，一溜就过去了。老虎跟上来，前爪刚踩实，那层枯枝“咔”的一声塌下去。它身子往下一沉，两只前爪在土壁上刨了两下，没抓住，重重摔进坑里。这是猎人挖的陷阱，一人多深。老虎仰起脸，只看得见头顶一个圆圆的天，和坑沿上那半截尾巴。
> 
> 狐狸探头看了一眼，接着往前走。没走出二十步，那两只野兔从草丛里探出脑袋来了。这一回它们没跑，一只朝它这边挪了两步，另一只干脆坐下来，慢慢啃起草根。草丛里又出来几个，还有一只花斑豹。花斑豹低下头，鼻子几乎碰到狐狸脸上，闻了一闻。狐狸往后退，一直退到坑边。
> 
> 坑底下的老虎没有急着往上蹿。它仰着脸，看见狐狸的影子越缩越小，也看见了那些不肯跑开的脑袋。它这才明白过来：从前它们跑，跑的不是这只狐狸。
> 
> 老虎后退两步，一纵身翻上坑沿。围着的那几个“呼啦”一下散了。林子里只剩狐狸站在原地，尾巴垂了下来。
> 
> 要是照从前，这一趟走完，老虎还得信它一辈子。这一回它没能走完，半路栽进了坑里，倒把事情看清楚了。

师：开头这一段在做什么？

参考：写老虎从前为什么会信狐狸。／把原来那个故事顺带说进去了。／它没有专门解释，就从这一天又要去巡一趟写起。

师：（教师总结）它没有跳出故事去说“老故事里怎么怎么样”，是从老虎为什么信它写起，顺手把原来的故事交代清楚了。你们的开头也这么写：从故事里起笔，别站在外头说明。

师：中间几段，跟原来的故事比，变的是哪几处？

参考：老虎半路掉进坑里了。／百兽没跑，反倒把狐狸围住了。／老虎最后没再信它。

师：（教师总结）新添进去的改动只有一处：老虎掉进了猎人的坑。百兽不跑、狐狸威风落空，这两样都是跟着来的，不是另外添的。老师编的不是龟兔赛跑，这一处是自己想出来的，想完回头一看，正好合上课本列的“路遇不测”。最后一句把新结局和原来的结局摆在一起，一句话交代新在哪里，不用多说。

师：刚才让你们留意的第三件事，挑出来的是哪一句？

学生自由分享

[组织提示：请两位学生报自己挑的那一句，只报不评；其中一位接着答下面“为什么挑它”，另一位不必答。]

参考：两只前爪在土壁上刨了两下，没抓住。／另一只干脆坐下来，慢慢啃起草根。／花斑豹低下头，鼻子几乎碰到狐狸脸上。

师：你为什么挑这一句？

参考：它没有直接说老虎摔得重，可我读出来了。／它写的是野兔怎么坐下来的，不是“它们不怕了”几个字。／它没说狐狸害怕，我知道它怕了。

师：请把你们挑出来的这几句摆在一起看：

| 示范文里的句子                | 这一句用了什么              |
| ---------------------- | -------------------- |
| 两只前爪在土壁上刨了两下，没抓住       | 一个动作拆成几步写，不写“它掉了下去”  |
| 另一只干脆坐下来，慢慢啃起草根        | 借旁边的反应，写出这一处改动带来的变化  |
| 花斑豹低下头，鼻子几乎碰到狐狸脸上，闻了一闻 | 一句话配一处细节，人物当时的处境就出来了 |
| 从前它们跑，跑的不是这只狐狸         | 心里想的一句，不直接说“它明白了”    |

师：这篇是老师编的，你们每个人编的那个故事不一样，写出来当然也不一样，不用照着老师这一篇的样子写。要守住的是两件事：改动集中在一处，后面的事从它接下去；那一幕照刚才表上那几种写法写足。

师：这节课就上到这里。你们手上有三样东西：定下来的那个老故事、一张填好的表、还有刚才自己说过一遍的那条故事线。休息一下，回来就动笔。

本课完。

## 第2课时 · 当堂写作与评改课

### 一、看着构思表，定下从哪儿起笔（约 3 分钟）

师：请把第一节课那张表拿出来。这一篇从哪一句起笔、哪一段写得最厚，动笔之前先在表上定下来。

师：第一件事，定开头。看你表上第二格，那是这个老故事原来的结局。开头就用一两句话把原来的故事交代清楚，让读的人知道你编的是哪一个、它原来什么样，再拐进你的“这一回不一样”。这一两句要从故事里起笔，像老师那一篇那样把它写进去，别用“老故事里怎么怎么样”这样的话开头。请在第二格旁边写一个“1”，那就是你的第一句。

师：第二件事，定顺序。第五格里跟着变的那两三件事，你打算先写哪一件、后写哪一件，就在那几件事旁边标上“2”“3”“4”。画了横线的第六格排在哪一步，也一并标上。它是这一篇写得最厚的地方，前后都要给它让路。

学生动笔写作

师：标完请两位说一说：你从哪一句起笔，画横线的那一格排在第几步，为什么这么排。

学生互动分享

参考：我从“守株待兔那个人原来天天守在树桩边等”起笔；画横线那一格排第三步，因为得先下起雨、他先躲进树洞，才有后面那一幕。／我把它排在最后，前面两件事都是往那儿引的，最要紧的留到最后写。

[教师巡视：只看标号有没有落到格子上，不评顺序好坏。标不出来的学生问一句“你这一篇第一句想写什么”，先把这一句定下来再往下标。]

### 二、自由写作（约 25 分钟）

师：请按你刚才标好的顺序写下去，记住三件事：改一处，后面跟着变；改动那一段要写得让人看见；结尾一句话，把新结局和原来的结局摆在一起，交代新在哪里。整篇四百五十字上下，写二十五分钟。

学生动笔写作

[教师巡视：只作正向介入，不指错别字、不改格式、不改病句。按四类学情分别处理：]

[接不下去型：写完开头几句就停住]：把学生引回构思表上标了号的那几格，提示学生这一处改动之后还有谁会发觉、会做点什么，照着往下写一件。不必让他从第一句重写。

[内容空泛型：只交代结果，如“百兽都不怕了”]：提供具体素材提示：请学生说出是哪一只先不怕的，它当时做了什么动作，把这一句写下来。

[书写顺畅型：一路写下去]：不打断，留出书写空间，走开。

[草草收尾型：写了三两句就搁笔说写完了]：先肯定学生改的那一处找得准，再追问改动之后还有哪一件事跟着变了，推他把那一件事补上再收。

### 三、交流评议，修改收束（约 17 分钟）

[即时反馈环节（约 6 分钟）：请三位学生念，每位念完请两位听众各答一句。按每位约一分半钟倒推，不超过三位；有意留给平时话不多的学生。]

师：请放下笔，我们开故事新编会。念的人不报故事名，只念你改动的那一段。听的人听完回答两句话：他改的是哪一处？后面哪几件事跟着变了？

学生互动分享

参考：他改的是那个人没在树桩边等，他去锄地了。／后面就都不一样了，地没荒，秋天还收了粮食，兔子倒是自己撞上来了，他也没当回事。

师：（教师总结）两句都答上来了，就说明他这一处改得立得住。听的人答不上第二句的，作者自己心里就有数了：后面那几件事还没跟上来。

师：现在每个人的稿子都要有人读到。请拿着你的稿子离开座位，找一个还没听过你这一篇的同学，两个人交换着读。读完在对方稿子的最后一行写一句：原来的故事到这里是＿＿＿，你改成了＿＿＿。写完把稿子换回来，回自己座位。

[组织提示：交换一轮即可，约三分钟；提醒学生只找一位、换完就回座。]

学生互动分享

师：请看你手上这张纸最后那一行。他写的那两处，和你自己想的对得上，说明你写清楚了；对不上，或者他那一行只填了半句，那一处接下来先改。

[自评与修改（约 8 分钟）：对照定档约 1.5 分钟，找欠展开的那一句约 1.5 分钟，学生动笔修改约 3.5 分钟，收尾约 1.5 分钟。教师控住节奏。前面的讨论一旦拖长，动笔修改的时间就没有了。]

师：接着请对着这三条，看一看自己这一篇落在哪一条上。

| 我对着看 | 我这一篇                                                                                                            |
| ---- | --------------------------------------------------------------------------------------------------------------- |
| 做到了  | 开头一两句交代了原来的故事；改动集中在一处，是原来没有的；后面有两三件事是从这一处接下来的；改动那一段里，他做了什么、说了或想了什么、旁边的人有什么反应，我都写了；结尾一句话，把新结局和原来的结局摆在了一起 |
| 差一点  | 改动写清楚了，但后面有一件事和它接不上；或者改动那一段只交代了结果；或者结尾没说清新在哪里                                                                   |
| 先改这里 | 前面和原来的故事一样，只在结尾添了一句；或者改了好几处，件件不相干                                                                               |

师：动手改之前先做一件事。在自己稿子上找一句只交代了结果、没让人看见的句子，和同桌换着看一眼，各说一句：这一句如果展开，该添哪一样。

学生互动分享

参考：我写的是“老虎不害怕了”，该添它当时在干什么。／我写“大家都笑了”，可以写谁先笑的。

师：那这样的句子，是不是每一句都要展开？

参考：不用吧。／不要紧的地方留着就行。

师：（教师总结）对。故事里不要紧的地方，一句带过正合适，整篇都是慢镜头反倒累赘。要展开的只有一处：你改动的那一处。

师：现在对着上面那三条，你自己定先改哪一处，挑你觉得最需要补的那一条动手。开头交代得不清楚，就补开头；中间有一件事和你的改动接不上，就把它换掉；改动那一段缺哪一样，就补哪一样；结尾没把新旧两个结局摆到一起的，补一句。改一处改透，比三处各动一点更好。用修改符号：多的字圈掉，漏的字补上，错的字改正。给你们三分半钟。

学生动笔写作

师：请改完的同学把稿子收好。同一批老故事，原来什么样全班都知道；今天从你们手里出来的，一人一个不一样的版本。课本上说编完还可以配一幅插图，今天来不及画；稿子你自己收着，想配就配一张，不是作业。

本课完。

全课完。

## 附：习作讲评指导环节（可选 · 单次课课后用 / 系列课作下次课开场用）

> 本环节供教师灵活取用：单次课可在课后批读之后集中讲评一次，系列课可作下一次课的开场（约 15–20 分钟）。它评的是学生当堂已经写完的稿子，不计入 45+45 两节，也不需要学生回家再写。
> 
> 文中的 ＿＿＿ 处，务必替换为本班学生习作中的真实句子；讲评前先把稿子读一遍，按下面的选稿标准挑出来。

### 选稿（课前准备）

从本班当堂完成的稿子中选 2–3 篇，覆盖三个层次，各用一句话对照本课技法点明它好在哪里、欠缺在哪里：

一篇较好的：改动集中在一处，后面两三件事都从这一处接下来，那一幕写得看得见。
一篇中等的：改动找得准，后面的事只跟上来一件，但那一幕只交代了结果。
一篇有典型问题的：或是前面照抄原故事、只在结尾添了一句；或是改了好几处，件件不相干。

[投屏时不写作者姓名，讲评时也不点名；待改进那一篇只读片段，不读整篇。]

### 讲评流程（每篇约 3–5 分钟，围绕本课技法点）

师：上次那一篇故事新编，老师都读完了。今天只看三件事：改动是不是集中在一处、是不是原来没有的；后面的事有没有跟着变，改动那一段写没写得让人看见；结尾有没有一句话交代新在哪里。其他的先放一放。

师：先看这一篇。他改的那一处是＿＿＿（读出该生改动的那一处），往后我数了一下，跟着来的有＿＿＿（读出从这一处接下来的那两三件事）。你们听，这几件事是不是都能在那一处上找到出处。

学生互动分享

师：再听他写那一幕的这一句：“＿＿＿”（读该生把改动写得最看得见的一两句）。这一句里有他的动作，也有他当时的样子。

师：（教师总结）他这一处没有只把结果交代完，而是把当时的动作、当时的样子写了下来，所以我们听得见、也看得见。

师：再看第二篇。他这一处改得准，后面也跟上来了。有一处可以再往上添：他写“＿＿＿”（读只交代结果的那一句），这一句把事情交代完了，但我们没看见。如果把这一处换成他当时做了什么、说了一句什么，这一幕就撑得住了。

师：（教师总结）他改的那一处准，后面的事也跟着变了；差的就是刚才说的那一句：把交代结果换成写出当时做了什么、说了什么。

师：还有一篇，老师不说是谁写的，只念开头这几句：“＿＿＿”（读前半段与原故事几乎相同的那几句）。你们听出来了，这几句跟原来的故事一样。那问题出在哪里？

学生互动分享

参考：他还没改。／他把改的放到最后一句去了。／前面应该也跟着变。

师：（教师总结）对。他不是没想法，是那一处改动放得太靠后，前面没有跟着动。补的办法很简单：把改动往前挪，挪到故事刚开头的地方，后面的事自然就跟着变了。

### 收尾（点回技法、引向今后的写作）

师：这几篇好就好在同一件事上：改一处，后面跟着变。往后你们编故事、写想象类的文章，都可以先定结局，再倒回去找那一处；找准了，后面的事就一件一件接得下去。

本环节完。
