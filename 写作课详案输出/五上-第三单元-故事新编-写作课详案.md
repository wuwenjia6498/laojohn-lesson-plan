# 《故事新编》· 写作课教学设计

五年级上册·第三单元 校内同步写作（想象习作）

## 教案提纲表

| 课题·课时  | 五年级上册·第三单元《故事新编》　│　想象·校内同步　│　2课时连排（每节45分钟）                                                                              |
| ------ | ----------------------------------------------------------------------------------------------------------------------- |
| 能力阶段   | 写清楚 → 写具体 → 写生动（本课） → 写深刻·有章法                                                                                           |
| 同类习作顺序 | 想象：续写故事／编童话 → 奇妙的想象／这样想象真有趣 → 我和＿＿过一天 → 奇思妙想 → 故事新编（本课）／二十年后的家乡 → 神奇探险 → 变形记／笔尖流出的故事／插上科学翅膀                           |
| 教材要求   | 统编五年级上册·第三单元习作：展开想象，给经典故事换个新编法。本单元习作要素：按照自己的想法新编故事。                                                                                         |
| 学习目标   | 通过先定新结局、再倒回去找出哪一处变了，来学习怎么写一篇故事新编。                                                                                       |
| 核心技法   | 使用“构思表”。先定下新结局，再倒回去找出是哪一处变了，后面两三件事都跟着变；那一幕把动作拆开写，配上心里想的和旁边人的反应；开头把老故事带出来，结尾让人看出和原来不一样。 |

## 第1课时 · 写作指导课

### 一、创设情境，明确任务（约 4 分钟）

〖PPT 第3页 · 创设情境 · 《龟兔赛跑》的结局，这一回不一样了〗

师：同学们，大家都听过《龟兔赛跑》的故事，还记得故事最后是谁赢了吗？

参考：乌龟赢了！／是乌龟，因为兔子中途睡大觉了。

师：对。那老师来讲一个不一样的版本：这次兔子可没有偷懒睡觉。它跑到大树底下，停下脚步回头一望，只见乌龟还远远落在后面，正一步一步慢慢往前爬。兔子没有骄傲松懈，牢牢抓住先机，向着终点奋力往前冲。

学生自由分享

参考：那这下乌龟肯定要输了。／这么一来比赛就没悬念了。／这和我们以前听的故事不一样了。

师：大家说得很好。经典老故事妙就妙在这里：故事的结局、情节，我们心里早就都有印象，只要一变，大家马上就听出来了。

〖PPT 第4页 · 创设情境 · 今天的任务：办一场故事新编分享会〗

师：今天这两节课，我们就来做一件有意思的事：选一个大家耳熟能详的老故事，发挥想象重新编写。等到写完，我们就在班里举办一场“故事新编分享会”。分享的时候，朗读的同学不说出故事原来的名字，从改动的那一处读起，一直读到结尾；听完之后，请大家回答两个问题：第一，他改动了故事里的哪一处情节？第二，改动之后，又引发了哪些新的事情？

师：这两个问题听的人答不答得上来，就是我们评判这次习作写得好不好的标准。不光听别人分享的时候可以用它来评判，大家自己写的时候，也可以拿这两个问题对照检查。

师：这就是本学期语文书上第三单元的习作，题目叫“故事新编”。课本上还说，编完以后把习作誊抄下来，可以配上插图贴到教室的墙报上。今天我们先在课堂上把分享这一步做了；想配插图的同学，回去可以自己画，那不是作业。

### 二、打开故事库，选定老故事（约 6 分钟）

〖PPT 第5页 · 打开故事库 · 想一想：哪些老故事，你现在还能说出结局〗

师：在正式动笔之前，我们先要确定一件事：你打算改写哪一个老故事。给大家二十秒时间，想一想从小到大听过的故事，有哪些直到现在，你都能轻轻松松说出它的结局。

学生自由分享

师：谁愿意来说一说？一人说一个，前面同学讲过的故事不重复。

学生互动分享

参考：狐假虎威。／掩耳盗铃。／画蛇添足。／小红帽。／精卫填海。／漏。／后羿射日。／丑小鸭。／拔苗助长。／守株待兔。

师：（教师总结）大家报出来的这些故事，大致可以分成三类。一类是寓言故事，比如《狐假虎威》《掩耳盗铃》《画蛇添足》；一类是童话故事，像《小红帽》《丑小鸭》；还有一类是神话、民间故事，例如《精卫填海》《后羿射日》《漏》。这三类故事，我们都可以拿来做故事新编。这个单元学的《猎人海力布》《牛郎织女》也是民间故事，想编它们的同学也可以。

〖PPT 第6页 · 打开故事库 · 选定你要改写的那一个：两条标准〗

师：接下来，请同学们确定自己要改写的故事。提醒大家两点：第一，选自己十分熟悉的故事；第二，想一想这个故事班上其他同学是不是也了解。等一下写完，我们要读给全班听，如果听的人完全不清楚原来的故事，就算你的改动再巧妙，大家也听不出新在哪里。

师：想好之后，转头和同桌说一说，问一问同桌有没有听过你选的这个故事。如果同桌表示没听过，就换一个，优先选大家都听过的经典故事。

学生互动分享

[教师巡视：重点关注选了冷门故事的学生，引导其换成刚才课堂上大家报出来的篇目。本次习作的前提是选用熟悉的故事，如果同桌都没有听过，说明这个故事不太适合本次习作。]

### 三、学写法：先定结局，再倒回去找改动的那一处（约 14 分钟）

〖PPT 第7页 · 学写法 · 同样新编《龟兔赛跑》，哪一段更像故事新编〗

师：同样是新编《龟兔赛跑》，老师这里有两段开头。请大家先听，听完再判断。

[投屏：出示下面两段话，教师逐段读一遍。]

〔教师示范朗读第一段〕兔子和乌龟又比了一回。这回乌龟背上了一只喷气背包，一按开关就窜出去老远。兔子从路边推出一辆红色的跑车，油门一踩，车屁股后头冒出两股白烟。路两边站满了看比赛的动物，举着牌子喊加油，喊声一阵高过一阵。半道上蹦出来一只会说话的松鼠，冲它们俩挥手，说了一句“你们两个都很棒”。终点线前立着一块大屏幕，上面滚动着它们的名字，一个红的一个蓝的。最后它们并排冲过终点线，裁判举着秒表核对许久，宣布两个选手用时一模一样。

〔教师示范朗读第二段〕兔子和乌龟又比了一回。跑到半路，前头忽然多出一段又长又陡的下坡。兔子在坡顶刹住脚，探头往下看了看，坡面滑得发亮，它怕栽跟头，只好侧着身子一步一步往下挪。乌龟爬到坡边，把头往壳里一缩，四条腿也收了，整个身子贴着坡面滚了下去，咕噜咕噜一路滚到坡底，回头一看，兔子还在半坡上。

师：听完这两段，大家想一想，哪一段更像我们要写的故事新编？

参考：第一段吧，第一段热闹。／第一段想象特别新奇，有喷气背包、跑车还有大屏幕。／是第二段。

师：选第一段的同学，请说一说，你觉得它好在哪里？

参考：改动的内容很多。／想法和别人不一样。／故事新编不就是要写得离奇有趣吗。

〖PPT 第8页 · 学写法 · 做一个小实验：删掉一句，故事还成立吗〗

师：对，这几样第一段确实都有。那我们来做一个小实验：如果把第一段里那只会说话的松鼠直接删掉，大家看一看，前后故事还能读得通吗？

参考：接得上。／一点都不受影响。／比赛照样可以继续进行。

师：再拿第二段试一次。假如把“多出一段又长又陡的下坡”这一句删掉，会发生什么？

参考：故事就不成立了。／后面的情节全都没有着落。／乌龟都没有地方可以滚下去了。

师：那请大家说一说，这两段最核心的差别是什么。一句话说清楚。

参考：第二段后面发生的所有事，都是由这个下坡引出来的。／第一段是把各种新奇的东西堆在一起，互相之间没有关系。／第一段里随便去掉哪个新奇设定，故事都不受影响。

师：（教师总结）第二段后面的每一件事，都是从那段下坡来的，这就是差别。编新故事最要紧的也是这一条：后面发生的每一件事，都要能在前面找到它的来处。

师：那么，这个关键的改动处该怎么找？课本给了一条路，我们一起来试一试。

[投屏：出示教材第 46 页习作页面的上半部分，只到四个结局；下面五类情节的两块先遮住，等小组推完再揭开。]

〖PPT 第9页 · 学写法 · 课本第 46 页给了四个新结局〗

师：课本给《龟兔赛跑》设想了四个不一样的结局：乌龟和兔子都赢了；乌龟和兔子都没能赢；兔子赢了；乌龟又赢了。课本下面还给了几条新情节，我们先不看它，自己来推一推。今天统一选最后这个结局来练：乌龟又赢了。

〖PPT 第10页 · 小组活动 · 四人小组倒推：要让乌龟又赢了，中途会发生什么〗

师：请四人小组合作，从这个结局往回倒推情节。想一想，要让乌龟再次取胜，比赛中途可以发生一件什么事？出现这件事之后，兔子会是什么状态，乌龟又会怎么做，一步步推到最后的结局。推出三到四步就可以，不用写长。每个小组选出一条最顺的思路，等一下分享给全班。给大家两分钟。

学生互动分享

[教师巡视：遇到无从下手的小组，只提问引导：“发生这件事之后，最先受到影响的是谁？”不替学生构思情节。]

师：请两个小组来分享推导的思路。其他同学认真听，重点辨别：小组说的情节里，有没有哪一步是硬加进去的，和前面没有关联。

学生互动分享

参考：我们想到路上有一大片萝卜地，兔子看见了忍不住停下来拔萝卜吃，吃得肚子鼓鼓的，走两步就要歇一歇，乌龟就趁机从旁边爬过去了。／我们设想跑着跑着天上下起大雨，兔子怕淋雨，就躲进树洞里避雨，想等雨小再出发，就这样耽误了比赛。

〔应答·听众指出某一步和前面没关联〕请推的那一组补一句“这一步是从前面哪一件来的”，补得上就算接上，补不上就把那一步拿掉再接。

〖PPT 第11页 · 学写法 · 课本的五条情节，和你选哪一条〗

[投屏：揭开教材第 46 页下半部分的五类情节。]

师：现在看课本列的五条：路遇不测、急中出错、遇到诱惑、赛道变化、天气变化。如果刚才有小组推到了萝卜地或者下大雨，它们就在这五条里，是“遇到诱惑”和“天气变化”，大家想到的，课本也想到了。

师：等一下写《龟兔赛跑》的同学，可以直接从这五条里选一条来改写，课本给的这几条很稳妥，也可以自己想一条新的。改写别的故事的同学，关键的改动处要自己想：你的主角中途会遇到什么，只有你能想到。这五条可以当参考，贴合你的故事就用，不贴合就不用硬套。只要改动之后后面的事能顺理成章接下来，就是好想法。

师：再问一个难一点的问题。如果推出来两三条都接得上，选哪一条？就拿萝卜地和下大雨来说，哪一条你更能把出事的那一刻写出来，写到让别人像看见一样？说出你的理由。

学生互动分享

[组织提示：请两位学生作答，每人只说一句理由。当学生说出“我能写出它当时的样子”这类想法就收尾，衔接下一步。]

参考：萝卜地那条吧，我能写出兔子啃萝卜的样子。／我选下雨那条，我写得出它躲在哪儿、雨打在身上什么感觉。

师：（教师总结）选的标准就一条：这件事发生的那一刻，你能不能把它细细写出来。不管是用课本的提示，还是自己想的情节，都拿这一条来衡量。还有一点要提醒大家：你设想的这件事，如果原来的故事里本来就有，那就不算改动；一定要是原故事没有发生过的，才算真正的新编。

〖PPT 第12页 · 核心技法 · 把今天的方法记下来：改一处，后面跟着变〗

师：刚才我们完整走了一遍，这就是这次习作的构思方法：先定下新结局，再倒回去找出是哪一处变了；这一处定下来，后面所有的事都顺着它发展。我们把它记成一句话：改一处，后面跟着变。

师：那能不能同时改好几处？这次就改一处。下节课动笔写作有二十六分钟，写四百五十字左右，把一处改透就足够了；改的地方多、彼此又不相干，反而接不起来。

### 四、借助构思表，理清思路（约 9 分钟）

〖PPT 第13页 · 动笔构思 · 先定新结局，再和同桌说一说你改哪一处〗

师：现在请每位同学定下自己那个故事的新结局。编《龟兔赛跑》的同学，从课本四个结局里选一个；编别的故事的同学自己定：原来的结局是什么，你打算改成什么样。定好新结局，再倒回去想，是哪一处变了。

师：请和同桌互相说两件事：你的新结局是什么？准备改动哪一处，为什么这样改？不用讲完整篇故事。

学生互动分享

[组织提示：同桌两人各说半分钟，约一分钟。同桌若听不出“为什么这样改”，就请他追问一句“这一处变了，后面第一件跟着变的是什么”。]

参考：我改《守株待兔》，新结局是农夫真等到一只兔子；改的是农夫在树桩旁搭了个草棚遮阳，兔子把草棚当成灌木丛，一头钻进来。／我改《小红帽》，新结局是小红帽自己脱险；改的是出门前和外婆约好暗号，敲门后外婆要咳三声，这天屋里一点声响都没有。／我改《丑小鸭》，改的是路上野鸭子邀它一起过冬，这属于课本说的“遇到诱惑”。

〖PPT 第14页 · 构思表 · 故事构思表〗

师：改动发生的那个瞬间，就是整篇故事最重要的一幕；其余和原来一样的内容，几句带过就可以。要把这些理清楚，我们借助一张构思表。大家手上的构思表有六格：改编的老故事、它原来的结局、你要的新结局、是哪一处变了、跟着变的两三件事、最关键的那一幕。每一格只填关键词，不写完整句子。

| 想一想           | 写下关键词 |
| ------------- | ----- |
| 我编的老故事        |       |
| 它原来的结局        |       |
| 我要的新结局        |       |
| 是哪一处变了        |       |
| 跟着变的事（两三件）    |       |
| 最关键的那一幕：谁在做什么 |       |

〖PPT 第15页 · 构思表 · 老师先填一张：改编《狐假虎威》〗

师：老师先当着大家的面填一张。老师编的是《狐假虎威》。

| 想一想           | 写下关键词              |
| ------------- | ------------------ |
| 我编的老故事        | 狐假虎威               |
| 它原来的结局        | 老虎相信狐狸的话           |
| 我要的新结局        | 老虎识破狐狸的把戏          |
| 是哪一处变了        | 路遇不测·老虎踩塌坡上的枯枝，滑进土沟    |
| 跟着变的事（两三件）    | 野兔不跑了、百兽围到沟沿、狐狸被逼到沟边 |
| 最关键的那一幕：谁在做什么 | 老虎滑进沟底，百兽围到沟沿   |

师：大家看，每一格只有几个词，最多十几个字。第四格是整张表的根基，这一格写得模糊，后面几格就填不实。现在请大家填，第四格就填刚才和同桌说过的那一处，写清在你的故事里具体发生了什么。给大家三分钟。

[学生独立填写构思表；教师巡视，走到三四位学生身边，遇到无从下手的只追问一句“这一处变了以后，谁会第一个察觉到”，不替学生填。]

师：填完的同学，把整张表通读一遍，在你觉得最该写长的那一格下面画一条横线，多数人会落在第六格。第二节课写作的时候，画横线的这一幕就是你要花最多笔墨的地方。

〖PPT 第16页 · 构思表 · 请两位同学说一说自己的构思〗

师：请两位同学把构思说给全班听。听的同学重点判断：这位同学的第四格和第五格，能不能顺理成章接起来。

学生互动分享

参考：我编的是《拔苗助长》，原来禾苗全枯死了，我想让禾苗真的长高；改的是夜里下了一场大雨，跟着变的是苗都活了，农夫第二天又去拔。／我编的是《漏》，原来老虎和贼互相吓跑了，我改成它们俩撞上以后一块儿躲雨，谁都不敢先动。

〔应答·第五格接不上第四格〕请听的同学指出是哪一件接不上，再请作者说“这一件是从哪一处来的”，说不上来就当场在第五格改一个词，不当众替他编。

师：（教师总结）第四格和第五格接得上，这张表就立住了。接下来看老师那张表上的关键词，是怎样变成一篇文章的。

### 五、出示示范文，发现写法（约 12 分钟）

〖PPT 第17页 · 教师示范文 · 十二个字的关键词，怎样写成两段〗

师：老师照着刚才那张表写了一篇，篇幅比大家要写的稍长一些，用的都是五年级同学写得出来的句子。我们先看关键的那一幕，就是构思表第六格“老虎滑进沟底，百兽围到沟沿”这十二个字写成的两段。

[投屏：先只出示下面两段。]

> 【教师示范文】（片段）
> 
> 山林一侧的坡面上落着一层枯枝，枯枝下面的泥土早已被雨水泡得松散。狐狸身子轻，一个侧身就跨了过去。老虎紧随其后跟上来，前爪刚踩上去，厚厚的枯枝 “咔” 地一声骤然折断，脚下的泥土也跟着往下坍塌。老虎顺着垮塌的土坡滑落到半人多深的土沟当中。它两只前爪使劲扒着倾斜的沟壁，却抓不住半点着力点，重重跌坐在沟底。
> 
> 狐狸朝沟下瞟了一眼，便继续向前赶路。可还没走出几步，刚才逃走的两只野兔又从草丛探出头。这一回它们没有逃跑，一步步向着土沟的沟口聚拢过来。别的野兽也纷纷跟了过来，全都围到沟沿边上。一只野兔就地趴下，低头啃起地上的草根；连一头花斑豹也凑到沟沿，低下脑袋，鼻子几乎贴到狐狸的脸上，仔细嗅了嗅。狐狸吓得连连后退，被逼到土沟的边沿。

师：表上只有十二个字，请大家读一读，想一想：这两段里，哪些内容是从这十二个字铺开来的？

参考：先写狐狸身子轻顺利过去，老虎一踩上去枯枝、泥土就垮掉。／写老虎爪子扒土坡、抓不稳的动作。／写野兔围过来、花斑豹凑到狐狸脸前。

师：（教师总结）关键词只有十二个字，铺开来就是两段。大家再留意一下：这两段真正新添的设定只有一样，坡上那层枯枝底下的土是松的。

〖PPT 第18页 · 教师示范文 · 新编《狐假虎威》〗

师：接下来读整篇。请大家默读，读的时候想三个问题：第一，开头写了什么，起了什么作用；第二，构思表第四格、第五格那十几个字，到了文章里各长成了哪几句；第三，找一两句你觉得可以学过来、用到自己习作里的句子。读完我们依次交流。

> 【教师示范文】
> 
> 自从跟着狐狸在森林里走过一趟，老虎就再也没有怀疑过狐狸的说辞。那一趟走下来，野猪、小鹿、兔子，见了狐狸全都四散逃窜，老虎跟在后头看得清清楚楚，狐狸说自己是天帝派来管百兽的，在它看来这话似乎千真万确。这天狐狸又找上门，提议趁着天气晴好，再到山林里巡视一番。

> 
> 山林一侧的坡面上落着一层枯枝，枯枝下面的泥土早已被雨水泡得松散。狐狸身子轻，一个侧身就跨了过去。老虎紧随其后跟上来，前爪刚踩上去，厚厚的枯枝 “咔” 地一声骤然折断，脚下的泥土也跟着往下坍塌。老虎顺着垮塌的土坡滑落到半人多深的土沟当中。它两只前爪使劲扒着倾斜的沟壁，却抓不住半点着力点，重重跌坐在沟底。
>

> 
> 沟沿上发生的一切，全都尽收在老虎的眼底。这一刻它终于恍然大悟：当初百兽四散奔逃，惧怕的根本不是狐狸。
> 
> 老虎蹬住斜坡，后腿用力一蹬，纵身翻上沟沿。围在旁边的野兽呼啦一下子全部散开。树林里只剩下狐狸呆呆站在原地，高高扬起的尾巴也终于垂落了下来。

〖PPT 第19页 · 读示范文 · 默读全文，思考三个问题〗

师：先交流第一个问题：开头写了什么，起了什么作用？

参考：写老虎从前为什么会相信狐狸。／悄悄地把原来的老故事交代出来。／没有生硬介绍老故事，直接从再次巡山这件事写起。

师：（教师总结）是的，开头借着老虎的心思，把原来的故事带出来了，不用跳出故事去说“老故事里狐假虎威是怎样的”。开头把老故事带出来有两种写法：一种像这样从故事里起笔，顺着人物的处境带出来；另一种先用一两句直接回顾老故事的结局，再用“可是这一回”“如果”转到你的新编。两种都可以，只要读的人一两句之内就知道你编的是哪个故事、原来是怎么收场的。

师：第二个问题，构思表第四格、第五格那十几个字，到了文章里各长成了哪几句？文章里有、表上没有的是什么？

参考：第四格“踩塌枯枝滑进土沟”长成了第三段整段。／第五格三件事长成了第四段，野兔不跑、花斑豹凑过来、狐狸退到沟边。／表上没有的是第二段狐狸回头说“看见没有”，还有老虎恍然大悟那一段。

师：（教师总结）整篇真正新添的改动只有一处：老虎踩塌枯枝，滑进路边的土沟。野兽不再逃跑、狐狸威风扫地，都是这一处带出来的，不是另外加上去的。老师编的不是《龟兔赛跑》，这一处是老师自己想的，回头对照课本，刚好属于“路遇不测”这一类。结尾要把这一次怎么收场交代清楚，让人看出和原来不一样：结局变了算，结局一样、但是得到这个结局的过程变了，也算，比如“乌龟又赢了”，新就新在这一次乌龟是怎么赢的。老师这一篇收在狐狸尾巴垂下来的画面上，新结局自然就出来了；也可以直接用一句话点明新在哪里。两种收法都可以，都不必多讲。

师：第三个问题，你找出了哪一句想学过来用？

学生自由分享

参考：两只前爪使劲扒着倾斜的沟壁，却抓不住半点着力点。／一只野兔就地趴下，低头啃起地上的草根。／花斑豹低下脑袋，鼻子几乎贴到狐狸的脸上，仔细嗅了嗅。

师：你为什么选这一句？

参考：没有直接写老虎摔得很惨，但我能感受到当时的凶险。／写野兔啃草根，不是干巴巴写“野兽不再害怕狐狸”。／没有直接写狐狸害怕，但是我能读出狐狸的慌张。

〖PPT 第20页 · 旁批表 · 这几句话，各自用了什么写法〗

| 示范文里的句子                 | 这一句用了什么                |

### 一、借助构思表，定下从哪里起笔（约 3 分钟）

〖PPT 第22页 · 动笔之前 · 借助构思表：定开头，定那一幕的位置〗

### 二、自由写作，把整篇写完（约 26 分钟）

〖PPT 第23页 · 自由写作 · 完整写下你的故事新编：三个要求（第24页为计时页）〗

师：接着开头往下写，把整篇写完。三条要求在屏幕上留着，写的时候自己对着看：第一，改动只有一处，后面的事都从它接下来；第二，画横线的那一幕写得最长，动作拆开一步一步写，配上心里想的和旁边人的反应，其余的几句带过；第三，结尾交代清楚这一次怎么收场，让人看出和原来不一样，停在一个画面上，或者用一句话点明，都可以。整篇四百五十字左右，写的时候不停下来改字，时间是二十六分钟。

[投屏：出示三条要求，学生写作期间一直留在屏幕上，不逐条读。]

学生动笔写作

[教师巡视：只作鼓励性的提示，不指错别字、不改格式、不改病句。按四类学情分别处理：]

[接不下去型：写完开头几句就停住]：把学生引回构思表，问“表上第五格还有哪一件没写？哪一件接在这后面最顺？”，顺着表往下续写，不从头重写。

[内容空泛型：只交代结果，如“百兽都不怕了”]：提供具体素材提示：第一个发现变化的角色是谁，他做了什么动作，是什么神态，把概括的结果换成画面。

[书写顺畅型：一路写下去]：不打断，留出书写空间，巡回观察即可。

[草草收尾型：写了三两句就搁笔说写完了]：先肯定找准了改动处，再追问：这一处改动之后，还有哪一件事跟着变了？把缺的那一件补上再收尾。

学生互动分享

参考：他改的是农夫那一处：农夫不守树桩了，去地里干活。／跟着变的是地里长出了庄稼，秋天收了粮食，兔子撞过来他也没当回事。

[组织提示：交换一轮即可，约三分钟；一人一评。找不到只交代结果的句子，就在那一幕最好的一句下面画线、写“这句看得见”。]

学生互动分享

### 讲评流程（每篇约 3–5 分钟，围绕本课技法点）

师：上次大家写的故事新编，老师全部读完了。今天讲评，我们只看三件事：第一，改动是不是集中在一处，是原故事里没有的；第二，后面的事是不是从这一处接下来的，改动的那一幕能不能让人看见；第三，结尾有没有交代清楚这一次怎么收场，让人看出和原来不一样。其余细节先不评。

师：接下来看第二篇。他找准了改动处，后面的事也接得上。有一处还可以更好，请看这一句：“＿＿＿”（读出只概括结果、没有画面的句子）。这句话把事说完了，但是没有画面，我们看不见现场。如果写出角色当时做了什么动作、旁边的人是什么反应，读的人就看得见这一幕了。

师：（教师总结）这篇改动选得准，后面的事也跟着发生了；差的只是这一句，把交代结果换成动作和反应，画面就有了。

师：还有一篇，老师不说作者，只读开头一段：“＿＿＿”（读出和原故事几乎重合的前半段）。大家听一听，发现了什么？

学生互动分享

参考：前面一直是老故事，还没有出现改动。／改动只放在最后一句。／改动出得太晚，前面的事都没跟着变。

师：（教师总结）是的，这位同学不是缺创意，是改动放得太靠后，前面的事没有被带动起来。改法很简单：把这一处改动往前挪，放在故事靠前的位置，后面的事自然就跟着变了。

### 收尾（点回技法、引向今后的写作）

师：这几篇用的是同一个方法：改一处，后面跟着变。以后大家编故事、写想象类的习作，都可以先想好新结局，再倒回去找那个关键的改动处。找准了这一处，后面的事就能一件接一件顺下来。
