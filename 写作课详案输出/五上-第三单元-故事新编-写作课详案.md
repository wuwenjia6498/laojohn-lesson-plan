# 《故事新编》· 写作课教学设计
五年级上册·第三单元 校内同步写作（想象习作）

## 教案提纲表

| 课题·课时 | 五年级上册·第三单元《故事新编》　│　想象·校内同步　│　2课时连排（每节45分钟） |
| --- | --- |
| 能力阶段 | 写清楚 → 写具体 → 写生动（本课） → 写深刻·有章法 |
| 同类习作顺序 | 想象：续写故事／编童话 → 奇妙的想象／这样想象真有趣 → 我和＿＿过一天 → 奇思妙想 → 故事新编（本课）／二十年后的家乡 → 神奇探险 → 变形记／笔尖流出的故事 → 插上科学翅膀 |
| 教材要求 | 统编五年级上册·第三单元习作：展开想象，给经典故事换个新编法。 |
| 学习目标 | 通过先定新结局、再倒回去找出哪一处变了，来学习怎么写一篇故事新编。 |
| 核心技法 | 使用“构思表”。先定下新结局，再倒回去找出是哪一处变了；让后面两三件事都从这一处接下来，最要紧的那一幕把动作拆成几步慢慢写。 |

## 第1课时 · 写作指导课

### 一、创设情境，明确任务（约 4 分钟）

师：《龟兔赛跑》最后是谁赢的？

参考：乌龟。／乌龟赢了，兔子睡着了。

师：对。不过老师这里的这一只没睡。它跑到那棵树底下，停下来回头看了一眼，乌龟还在老远的地方，慢腾腾的。它就接着往前跑了。

学生自由分享

参考：那乌龟不就输了。／那还有什么好比的。／这不是原来的故事了。

师：这就是老故事好用的地方：原来那个样子，每个人脑海里都存着一份。

师：今天这两节课，我们每人挑一个自己最熟的老故事，重新编一个。第二节课写完，就在这间教室里开一场故事新编会。念的人不报故事名，只念自己编的那一篇；听的人手边什么材料都不用，这些老故事你们本来就知道。听完只回答两句话：他改的是哪一处？改了以后，后面哪几件事跟着变了？

师：这两句就是今天判断写成没写成的标准。听的人拿它判你，你自己写的时候也照着对一对。

师：这就是本学期语文书上第三单元的习作，题目叫“故事新编”。课本上还说，编完以后可以配上插图，跟大家一起分享这些有趣的故事。分享这一步，我们今天就在课上做完。

### 二、打开故事库，选定老故事（约 6 分钟）

师：我们动笔之前先解决一件事：你要编的是哪一个老故事。给你们二十秒，各自在脑海里过一遍：你从小听到大的那些故事里，哪几个到今天还能一口气把结局说出来。

学生自由分享

师：请报出来听一听。一人报一个，别人报过的就跳过。

学生互动分享

参考：三只小猪。／掩耳盗铃。／画蛇添足。／小红帽。／精卫填海。／漏。／后羿射日。／丑小鸭。／拔苗助长。／守株待兔。

师：（教师总结）你们报的这些故事大致是三类：寓言，像掩耳盗铃、画蛇添足；童话，像三只小猪、丑小鸭；神话和民间故事，像精卫填海、后羿射日、漏。三类都能拿来编。

师：现在各自定一个。定的时候多想一层：这个故事，全班是不是都知道。今天写完是要念给同学听的，听的人要听出你改在哪里；他如果根本不知道原来是什么样，你改得再巧他也听不出来。

师：定好了和同桌说一句，问他知不知道你选的这一个。他如果说没听过，换不换由你自己决定。

学生互动分享

[教师巡视：留意选到冷门故事的学生，提示他刚才全班报出来的那几个故事都是稳妥的选择，换与不换由他自己决定。]

### 三、学写法：先定结局，再倒回去找那一处（约 15 分钟）

师：同样是新编《龟兔赛跑》的开头，老师写了两段。我读一遍，你们听完判断：哪一段是照着这次习作的要求编的。

[投屏：出示下面两段话，教师逐段读一遍。]

〔教师示范·当场念出的第一段〕兔子和乌龟又比了一回。这回乌龟背上了一只喷气背包，一按开关就窜出去老远。兔子一看不对，从路边推出一辆红色的跑车，油门一踩，车屁股后头冒出两股白烟。跑到半路，天上落下来一道光，一只外星人把它们俩一起吸了上去。等它们醒过来，人已经在月亮上了。月亮上没有跑道，它们就绕着一个大坑跑，跑了三圈，谁也没分出输赢。

〔教师示范·当场念出的第二段〕兔子和乌龟又比了一回。跑到半路，前头忽然多出一段又长又陡的下坡。兔子在坡顶刹住脚，探头往下看了看，坡面滑得发亮，它怕栽跟头，只好侧着身子一步一步往下挪。乌龟爬到坡边，把头往壳里一缩，四条腿也收了，整个身子贴着坡面滚了下去，咕噜咕噜一路滚到坡底，回头一看，兔子还在半坡上。

师：哪一段是照着这次要求编的？

参考：第一段吧，第一段热闹。／第一段想得更奇，喷气背包、跑车、外星人都有。／第二段。

师：说第一段的同学，你说说，你觉得它哪一点编得对？

参考：它改的地方多。／它想得跟别人不一样。／新编不就是要编得离奇一点吗。

师：你们说的这几点，都看准了。那老师来做一个实验：把第一段里外星人那一句整个抽掉，你们看，前后接不接得上？

参考：接得上。／一点不影响。／照样跑它的。

师：再拿第二段试一次。把“多出一段又长又陡的下坡”那一句抽掉。

参考：那就塌了。／后面全没着落了。／那乌龟滚什么呀。

师：那你们说说，这两段的差别到底在哪儿。一句话说清楚。

参考：第二段后面的事都是从那段下坡来的。／第一段是一样一样往上堆，互相不挨着。／第一段抽掉哪一句都行。

师：（教师总结）说到点子上了。这次习作有一条要求叫“想象合理”，讲的就是你们刚说的这件事：后面的每一件事，都能在前面找到出处。

师：那这一处改动，怎么找？课本给了一条路，这一次你们自己走一趟。

[投屏：出示教材第 46 页习作页，只出上面那一行四个结局；下面那几条新的情节先不出，等两组念完再出。]

师：课本上让我们先定结局，给了四个：乌龟和兔子都赢了；乌龟和兔子都没能赢；兔子赢了；乌龟又赢了。就都挑最后这一个：乌龟又赢了。

师：四人一组，往回推一条路出来。要让乌龟又赢，半路要先出一件什么事？出了这件事，兔子怎么样、乌龟怎么样，一步一步推到那个结局。三四步能推到即可，不必写得太长。每组留下最顺的一条，接下来念给全班，给你们两分钟。

学生互动分享

[教师巡视：只对推不下去的组问一句“你们那件事出了以后，最先受影响的是谁”，不替学生定路线。]

师：请两组来念一念。其余同学听一件事：他那条路上，有没有哪一步是硬塞进去的。

学生互动分享

参考：我们挑的是兔子看见一片萝卜地——它拔一个啃，吃撑了，走两步歇一下，乌龟从它旁边爬过去了。／我们挑的是半路下起大雨，兔子怕淋湿躲进树洞，想着等雨停，一等就晚了。

师：这两条都接得住。

[投屏：接着出示教材第 46 页下半页那几条新的情节。]

师：课本上其实也列了几条。你们自己推出来的这两条，萝卜地和下大雨，它上面都列着。这几条是最容易想到的。

师：老师接着问一个难一点的问题：这两条，你如果是评委，更愿意读哪一条？说出你的理由。

学生互动分享

[组织提示：请三位说，每位一句理由，不展开。听到“这一条我一下就想到了”这一类答案就收住，它正是下面要接的那一层。]

参考：下雨那条吧，画面好写。／萝卜地那条，是兔子自己贪嘴，怪不着别人。／下雨我一下就想到了，没什么意思。

师：（教师总结）最后那位说的这一层，正是这次习作难的地方。接得住只是底线，底线之上还有一层：这一处改得值不值。有人挑“兔子又睡着了”，接当然接得住，但它和原来那一篇一模一样，读的人一点新东西也读不到。课本上列的那几条是给你们起头用的；一眼扫过去人人都想得到的那几种，不要停在那里：从清单再往外走一步，那一条才是你自己的。

师：这一趟你们自己走完了。归纳起来，这是一个什么办法？

参考：先想好结局，再倒回去找。／找一件能带出后面那串事的。

师：（教师总结）就这两句：先定新结局，再倒回去找出是哪一处变了；这一处定下来，后面的事一件一件从它接下去。往后就管它叫“改一处，后面跟着变”。

师：那改好几处行不行？行。如果你有把握一路改下去、每一处都接得住，那更好。只是下节课真正动笔只有二十来分钟，先把一处改透是最稳当的；写顺了，再往上添。

师：现在和同桌各说两句：你打算把哪一处改了，为什么挑它。不用讲整个故事。

学生互动分享

[组织提示：同桌两人同时说，约一分钟；说完请两位说给全班听。人人都说到，是为了下一个环节填表时心里已经有了那一处。]

参考：守株待兔那个人，那天没在树桩边等，他去锄地了——这样后面收成好不好就有得写。／我让丑小鸭一直没变成天鹅，我想看看它自己怎么办。／小红帽抄了近道——原来她是听话才出的事，我想倒过来试试。

师：（教师总结）刚才发言的几位，改的都是一处，也都说出了挑它的理由。还有一件事先说在前面：你改动的那一处正在发生的时候，就是这一篇里最要紧的一幕，那一幕要写得让人看见；别处照原来的故事带过去就行。往下怎么编，我们用一张表理一理。

### 四、借助构思表，理清思路（约 8 分钟）

师：手上这张表一共六格，一次填完：编的哪个故事、它原来的结局、你要的新结局、是哪一处变了、跟着变的两件事、最要紧的那一幕。每格只写关键词，不写整句，三分钟填完。第四格填之前先想一想：这一处，是不是别人一眼就想得到的。

| 想一想 | 写下关键词 |
| --- | --- |
| 我编的老故事 |  |
| 它原来的结局 |  |
| 我要的新结局 |  |
| 是哪一处变了（挑一个不是一眼就想得到的） |  |
| 跟着变的事（一两件） |  |
| 最要紧的那一幕：谁在做什么 |  |

师：老师先当着大家的面填一张。老师编的是《狐假虎威》。

| 想一想 | 写下关键词 |
| --- | --- |
| 我编的老故事 | 狐假虎威 |
| 它原来的结局 | 百兽全跑了 |
| 我要的新结局 | 百兽没跑 |
| 是哪一处变了（挑一个不是一眼就想得到的） | 老虎瘸了腿 |
| 跟着变的事（一两件） | 一步一歇、野猪回头 |
| 最要紧的那一幕：谁在做什么 | 狐狸回头看 |

师：每一格都是几个词，最长的一格八个字。第四格定不下来，后面几格都填不实，不要写得含糊。

学生动笔写作

师：填完从头看一遍，在第六格上画一道横线。第二节课，那一格就是你要花最多笔墨的地方，其他格一两句带过。

师：接着小声把这张表从头到尾说给自己听一遍：我编的是哪个故事，原来的结局是什么，我改的是哪一处，后面哪几件事跟着来了。说到哪一格说不顺，那一格就是还没想清楚的地方，做个记号。

[教师蹲点：走到三四位学生跟前，当学生的第一位听众，只在他说不顺的那一格追问一句“那这一处变了以后，谁最先发觉”。]

学生自由分享

师：请两位说给全班听。其余同学听一件事：他改的那一处，和他后面那几件事，接得上接不上。

学生互动分享

参考：我编的是拔苗助长，原来是苗全枯了，我改成苗真的长高了——那天夜里下了一场透雨。／我编的是漏，原来老虎和贼互相吓跑了，我改成它们俩撞上以后一块儿躲雨，谁也没敢先动。

师：（教师总结）两位说的都接得上。接下来看一看老师那张表，写出来是什么样子。

### 五、出示示范文，发现写法（约 12 分钟）

师：我们先看其中一段。就是老师表上最后那一格，“狐狸回头看”这五个字变出来的那一段。

[投屏：先只出示下面这一段。]

> 【教师示范文】（片段，先出示这一段）
>
> 狐狸走得正得意，尾巴翘起来，一摇一摇。走了几十步，它觉出不对：路两边的草丛静得出奇，没有一只脚在跑。它回过头。老虎离它有七八步远，正把左前腿抬着，一顿一顿地往前挪，每挪一下就把身子往一边歪。野猪从草棵子里探出半个脑袋，看着老虎，没动。接着是野鹿，接着是两只兔子。狐狸张了张嘴，一个字也没说出来。

师：表上那一格只有五个字。这一段里，哪几样内容是从这五个字里铺开的？

参考：他回头看见老虎抬着一条腿，一顿一顿地走。／野猪探出脑袋，没跑。／狐狸张嘴说不出话。

师：（教师总结）一格五个字，铺开就是这一段。再看一件事。这一段里新添进来的只有一处：老虎瘸了腿。草丛、野猪、野鹿、兔子，原来的故事里本来就有。

师：现在看整篇。这一遍自己默读，一边读一边留意三件事：开头这一段在做什么；跟原来的故事比，变的是哪几处；哪一句你想学过来、用到自己那一篇里去。读完这三件事一件一件说。

[投屏：出示整篇示范文，学生默读，约一分半钟。这一篇全程只通读这一次，后面三问都从这一遍里来，不再重读。]

> 【教师示范文】
>
> 老故事里，狐狸走在前头，老虎跟在后头，百兽一见，撒腿就跑。这一回不一样——那天早上，老虎的左前腿瘸了。
>
> 头天夜里它踩上了猎人埋在土里的夹子，咬着牙掰开，腿上留下两排血口子。天亮它还是出了洞——狐狸前一天夸了海口，说要带它走一趟林子。
>
> 狐狸走得正得意，尾巴翘起来，一摇一摇。走了几十步，它觉出不对：路两边的草丛静得出奇，没有一只脚在跑。它回过头。老虎离它有七八步远，正把左前腿抬着，一顿一顿地往前挪，每挪一下就把身子往一边歪。野猪从草棵子里探出半个脑袋，看着老虎，没动。接着是野鹿，接着是两只兔子。狐狸张了张嘴，一个字也没说出来。
>
> 野猪先走过去，绕到老虎侧面，低下头，把肩膀顶在它胸口底下。老虎没有躲。野鹿从坡上叼下一把带绒毛的叶子，放在血口子边上。两只兔子蹲在几步外，谁也没跑。
>
> 狐狸站在原地。它张了几次嘴，喊了一声“看什么看”，声音不大，没人理它。它想往前走，又觉得前头空落落的——从前是老虎在后头，它才走得动。
>
> 日头升高时，野猪驮着老虎往洞口去了。狐狸跟在最后，走了一段，停下来，把嘴里叼的那半片叶子放在地上，转身钻进了草丛。
>
> 老故事里，百兽怕的是狐狸后面那只老虎。这一回它们没怕，是看清了后面那只是谁。

师：开头这一段在做什么？

参考：交代原来的故事是什么样。／说这一回不一样。

师：中间几段，跟原来的故事比，变的是哪几处？

参考：老虎瘸了。／百兽没跑，还围上来了。／狐狸最后自己走开了。

师：（教师总结）新添进去的改动只有一处：老虎瘸了腿。百兽没跑、狐狸走开，这两样都是跟着来的，不是另外添的。最后一句把新结局和原来的结局摆在一起，一句话交代新在哪里，不用多说。

师：刚才让你们留意的第三件事，挑出来的是哪一句？

学生自由分享

参考：野鹿从坡上叼下一把带绒毛的叶子。／正把左前腿抬着，一顿一顿地往前挪。／狐狸张了张嘴，一个字也没说出来。

师：你为什么挑这一句？

参考：它没有直接说老虎伤得重，可我读出来了。／它写的是怎么挪的，不是“瘸着走”三个字。／它没说狐狸慌，我知道它慌了。

师：请把你们挑出来的这几句摆在一起看：

| 示范文里的句子 | 这一句用了什么 |
| --- | --- |
| 正把左前腿抬着，一顿一顿地往前挪 | 一个动作拆成几步写，不写“它瘸着走” |
| 野猪从草棵子里探出半个脑袋，看着老虎，没动 | 借旁边的反应，写出这一处改动带来的变化 |
| 它张了几次嘴，喊了一声“看什么看”，声音不大 | 一句话配一处细节，人物当时的处境就出来了 |
| 从前是老虎在后头，它才走得动 | 心里想的一句，不直接说“它慌了” |

师：这篇是老师编的，你们每个人编的那个故事不一样，写出来当然也不一样，不用照着老师这一篇的样子写。要守住的是两件事：改动集中在一处，后面的事从它接下去；那一幕照刚才表上那几种写法写足。

师：这节课就上到这里。你们手上有三样东西：定下来的那个老故事、一张填好的表、还有刚才自己说过一遍的那条故事线。休息一下，回来就动笔。

本课完。

## 第2课时 · 当堂写作与评改课

### 一、借助构思表，先写画横线的那一格（约 5 分钟）

师：请把第一节课那张表拿出来，看你画了横线的那一格，也就是第六格：最要紧的那一幕。

师：接下来三分钟，只写这一格里的事，笔不要停。写什么由你自己定：当时他在做什么，一个动作一个动作地写；他说了一句什么话；旁边的人是什么反应；他心里在想什么。这几样你挑着写，先写哪一样、写几句，你自己拿主意。想到什么写什么，不用管顺序，也不用管写得好不好。碰上写不出的字，空在那里做个记号，不要停。

[教师计时三分钟。此间不作提示、不巡视点评，让学生连续书写。]

学生动笔写作

师：请停一下笔。回头看你写的这些，圈出两三句你最想留在文章里的。

学生动笔写作

师：这几句写的是你改动之后的那一段，是这一篇里最要紧的地方，但它不是开头。开头要先用一两句话交代原来的故事是什么样，再拐进你的“这一回不一样”。现在从开头写起，一路写到中间，把你圈出的这几句放进去。

### 二、自由写作（约 23 分钟）

师：往下写，记住三件事：改一处，后面跟着变；改动那一段要写得让人看见；结尾一句话，把新结局和原来的结局摆在一起，交代新在哪里。整篇四百五十字上下，写二十三分钟。

学生动笔写作

[教师巡视：只作正向介入，不指错别字、不改格式、不改病句。按四类学情分别处理：]

[接不下去型：写完开头几句就停住]：把学生引回刚才三分钟写下的那几句，提示他这一处改动之后还有谁会发觉、会做点什么，照着往下写一件。不必让他从第一句重写。

[内容空泛型：只交代结果，如“百兽都不怕了”]：提供具体素材提示：请学生说出是哪一只先不怕的，它当时做了什么动作，把这一句写下来。

[书写顺畅型：一路写下去]：不打断，留出书写空间，走开。

[草草收尾型：写了三两句就搁笔说写完了]：先肯定学生改的那一处找得准，再追问改动之后还有哪一件事跟着变了，推他把那一件事补上再收。

### 三、交流评议，修改收束（约 17 分钟）

[即时反馈环节（约 6 分钟）：请三位学生念，每位念完请两位听众各答一句。按每位约一分半钟倒推，不超过三位；有意匀给平时话不多的学生。]

师：请放下笔，我们开故事新编会。念的人不报故事名，只念你改动的那一段。听的人听完回答两句话：他改的是哪一处？后面哪几件事跟着变了？

学生互动分享

参考：他改的是那个人没在树桩边等，他去锄地了。／后面就都不一样了，地没荒，秋天还收了粮食，兔子倒是自己撞上来了，他也没当回事。

师：（教师总结）两句都答上来了，就说明他这一处改得立得住。听的人答不上第二句的，作者自己心里就有数了：后面那几件事还没跟上来。

师：现在每个人的稿子都要有人读到。请拿着你的稿子离开座位，找一个还没听过你这一篇的同学，两个人交换着读。读完在对方稿子的最后一行写一句：原来的故事到这里是＿＿＿，你改成了＿＿＿。写完把稿子换回来，回自己座位。

[组织提示：交换一轮即可，约三分钟；提醒学生只找一位、换完就回座。]

学生互动分享

师：看你手上这张纸最后那一行。他写的那两处，和你自己想的对得上，说明你写清楚了；对不上，或者他那一行只填了半句，那一处接下来先改。

[自评与修改（约 8 分钟）：对照定档约 1.5 分钟，找欠展开的那一句约 1.5 分钟，学生动笔修改约 3.5 分钟，收尾约 1.5 分钟。教师控住节奏。前面的讨论一旦拖长，动笔修改的时间就没有了。]

师：接着请对着这三条，看一看自己这一篇落在哪一条上。

| 我对着看 | 我这一篇 |
| --- | --- |
| 做到了 | 开头一两句交代了原来的故事；改动集中在一处，而且不是一眼就想得到的那一种；后面有两三件事是从这一处接下来的；改动那一段里，他做了什么、说了或想了什么、旁边的人有什么反应，我都写了；结尾一句话，把新结局和原来的结局摆在了一起 |
| 差一点 | 改动写清楚了，但后面有一件事和它接不上；或者改动那一段只交代了结果；或者结尾没说清新在哪里 |
| 先改这里 | 前面和原来的故事一样，只在结尾添了一句；或者改了好几处，件件不相干 |

师：动手改之前先做一件事。在自己稿子上找一句只交代了结果、没让人看见的句子，和同桌换着看一眼，各说一句：这一句如果展开，该添哪一样。

学生互动分享

参考：我写的是“老虎不害怕了”，该添它当时在干什么。／我写“大家都笑了”，可以写谁先笑的。

师：那这样的句子，是不是每一句都要展开？

参考：不用吧。／不要紧的地方留着就行。

师：（教师总结）对。故事里不要紧的地方，一句带过正合适，整篇都是慢镜头反倒累赘。要展开的只有一处：你改动的那一处。

师：现在对着上面那三条，你自己定先改哪一处，挑你觉得最需要补的那一条动手。开头交代得不清楚，就补开头；中间有一件事和你的改动接不上，就把它换掉；改动那一段缺哪一样，就补哪一样；结尾没把新旧两个结局摆到一起的，补一句。改一处改透，比三处各动一点强。用修改符号：多的字圈掉，漏的字补上，错的字改正。给你们三分半钟。

学生动笔写作

师：请改完的同学把稿子收好。同一批老故事，原来什么样全班都知道；今天从你们手里出来的，一人一个不一样的版本。课本上说编完还可以配一幅插图，今天来不及画；稿子你自己收着，想配就配一张，不是作业。

本课完。

全课完。

## 附：习作讲评指导环节（可选 · 单次课课后用 / 系列课作下次课开场用）

> 本环节供教师灵活取用：单次课可在课后批读之后集中讲评一次，系列课可作下一次课的开场（约 15–20 分钟）。它评的是学生当堂已经写完的稿子，不计入 45+45 两节，也不需要学生回家再写。
>
> 文中的 ＿＿＿ 处，务必替换为本班学生习作中的真实句子；讲评前先把稿子读一遍，按下面的选稿标准挑出来。

### 选稿（课前准备）

从本班当堂完成的稿子中选 2–3 篇，覆盖三个层次，各用一句话对照本课技法点明它好在哪里、欠缺在哪里：

一篇较好的：改动集中在一处，后面两三件事都从这一处接下来，那一幕写得看得见。
一篇中等的：改动找得准，后面的事跟上来一两件，但那一幕只交代了结果。
一篇有典型问题的：或是前面照抄原故事、只在结尾添了一句；或是改了好几处，件件不相干。

[投屏时不写作者姓名，讲评时也不点名；待改进那一篇只读片段，不读整篇。]

### 讲评流程（每篇约 3–5 分钟，围绕本课技法点）

师：上次那一篇故事新编，老师都读完了。今天只看三件事：改动是不是集中在一处、值不值得改；后面的事有没有跟着变，改动那一段写没写得让人看见；结尾有没有一句话交代新在哪里。其他的先放一放。

师：先看这一篇。他改的那一处是＿＿＿（读出该生改动的那一处），往后我数了一下，跟着来的有＿＿＿（读出从这一处接下来的那两三件事）。你们听，这几件事是不是都能在那一处上找到出处。

学生互动分享

师：再听他写那一幕的这一句：“＿＿＿”（读该生把改动写得最看得见的一两句）。这一句里有他的动作，也有他当时的样子。

师：（教师总结）他这一处没有只把结果交代完，而是把当时的动作、当时的样子写了下来，所以我们听得见、也看得见。

师：再看第二篇。他这一处改得准，后面也跟上来了。有一处可以再往上添：他写“＿＿＿”（读只交代结果的那一句），这一句把事情交代完了，但我们没看见。如果把这一处换成他当时做了什么、说了一句什么，这一幕就撑得住了。

师：（教师总结）他改的那一处准，后面的事也跟着变了；差的就是刚才说的那一句：把交代结果换成写出当时做了什么、说了什么。

师：还有一篇，老师不说是谁写的，只念开头这几句：“＿＿＿”（读前半段与原故事几乎相同的那几句）。你们听出来了，这几句跟原来的故事一样。那问题出在哪里？

学生互动分享

参考：他还没改。／他把改的放到最后一句去了。／前面应该也跟着变。

师：（教师总结）对。他不是没想法，是那一处改动放得太靠后，前面没有跟着动。补的办法很简单：把改动往前挪，挪到故事刚开头的地方，后面的事自然就跟着变了。

### 收尾（点回技法、引向今后的写作）

师：这几篇好就好在同一件事上：改一处，后面跟着变。往后你们编故事、写想象类的文章，都可以先定结局，再倒回去找那一处；找准了，后面的事就一件一件接得下去。

本环节完。
