# 《二十年后的家乡》· 写作课教学设计

五年级上册·第四单元 校内同步写作（想象习作）

[授课提示：本课拟写的材料分属三个地方，供老师照着讲。① 老师门口那条街，共四处：开场念的笼统版、第三环节投屏重现的同一段、第三环节当场改写的具体版、第四环节提纲表示范填的第一行。② 第三环节两段对照里的菜市场，共两段：它只是判断题材料，与老师的家乡无关，可单独换、也可照用。③ 示范文里的老家，共两处：示范文三段、旁批表里逐字引用的句子。老师若愿意换成自己熟悉的地方，① 的四处必须一起换、③ 的两处必须一起换，同一组里漏一处课上就会前后对不上；① 与 ③ 本就是两个不同的地方（一处是现在住的，一处是老家），不必强行并成一个。若不便更换，照本讲亦可，只需在开场说明这是老师写的一段话，不必声称是自己的家乡。
另：开场“念给一位朋友听、他猜了三年”这一段，是本课贯穿到底的主线（开场埋下 → 第三环节回照 → 第二课时靠“猜隔了多少年”验收），请勿删去；但它若与老师的实际情形不符，照本讲会变成断言一件没发生过的事。两条替换口径任选：① 换个听的人——“我念给隔壁班一位老师听”“我念给家里人听”；② 干脆不设听众——“我把它搁了两天再自己读，一读也觉得像没过几年”。两种都保住“笼统写就看不出是二十年后”这个结果，后面的回照与验收一字不用改。]

## 教案提纲表

| 课题·课时  | 五上·第四单元《二十年后的家乡》　│　想象·校内同步　│　2课时连排（每节45分钟） |
| ------ | ------------------------------------------------------------------------------------------------------------- |
| 能力阶段   | 写清楚 → 写具体 → 写生动（本课） → 写深刻·有章法 |
| 同类习作顺序 | 想象：续写故事／编童话 → 奇妙的想象／这样想象真有趣 → 我和＿＿过一天 → 奇思妙想／故事新编 → 二十年后的家乡（本课） → 神奇探险 → 变形记／笔尖流出的故事 → 插上科学翅膀 |
| 教材要求   | 统编五上·第四单元习作：展开合理想象，描绘未来家乡。 |
| 学习目标   | 一篇让人一读就知道“这是二十年后”的想象习作：挑三个方面，一个方面一段，每段先点明这一处变成了什么样，再往下写一句它具体的模样。念给同学听，同学要能猜出你写的是隔了多少年，还能说出是从哪一句听出来的。 |
| 核心技法   | 挑三个方面各写一段，用**现在这样、二十年后那样**的对照把变化摆出来——每段开头先用一句话点明这一处变成了什么样，**紧接着补上一句具体的**：那儿成了什么模样，人在那儿做什么。（辅：动笔前先列一张提纲，一个方面一行；开头交代自己是怎么回到家乡的，结尾收一句。） |

## 第1课时 · 写作指导课

### 一、创设情境，明确任务（约 5 分钟）

师：这两节课，我们要写的是二十年后的家乡。备课的时候，老师自己先动手试了一段，写完念给一位朋友听，没告诉他写的是哪一年。我请他猜：你听听看，我写的是隔了多少年以后？

师：我先把那段念给你们听——“二十年后，我回到了家乡。家乡的变化真大呀。街道变得更干净了，楼房也更高了，人们的生活比以前方便了许多。到处都是绿树和鲜花，家乡变得越来越美丽了。”

师：他听完想了想，说：三年吧。

学生互动分享（学生多半会笑；教师不解释、不追问原因，只把学生的反应接住）

师：我当时也愣了一下。我写的是二十年，他听成了三年。你们先记住这件事，一会儿我们专门来说它。

师：先说今天的任务。每人写一篇《二十年后的家乡》，写你自己家乡二十年后的样子。写完以后，我们在这间教室里开一场未来分享会：先在四人小组里，每人把自己写的念一段给同组听；同组的人不看稿子，只听，然后猜一件事——你写的这是隔了多少年。猜完还要说出是从哪一句听出来的。然后再请几组各推一位，念给全班听。

师：所以今天这篇写成没写成，标准很清楚：念完之后，听的人能不能听出这是二十年后，而不是三年后；还能不能指着你的某一句话说，就是这句让我听出来的。

师：算一算，二十年后是哪一年？你们那时候多大？

参考：2046年／三十一岁／三十岁多一点。

师：三十来岁的你，某一天回到你现在住的这个地方。今天要写的，就是你站在那儿看见的样子。

### 二、观察体验，找到“会变的那几处”（约 9 分钟）

师：要写二十年后，得先看清现在。不过在看现在之前，我们先做一件更容易的事。你先想一想，自己见过哪些变化。

师：这三年里，你身边有哪一处变了样？可以是你住的小区、你上学走的那条路、你常去的一家店、你家楼下的一块空地。三年前它是什么样，现在是什么样。

师：四人一组，每人说一处变化，一个一个轮着说，人人都要说到。说的时候说两句就行：三年前那儿什么样，现在什么样。

学生互动分享（四人小组轮说，人人开口；教师走到三四组跟前听，挑两三个说得具体的，等会儿请他们说给全班）

参考：楼下那块空地以前是堆土的，现在铺了塑胶跑道／路口原来没有红绿灯，去年装上了／小区门口那家文具店关了，换成了一家水果店。

师：请刚才这三位说给全班听。

学生互动分享（举手抽说三位，教师复述其中一位说的两句，不作评价）

师：三年，就能变出这么多。二十年，是三年的六倍还多。

〔应答·学生说“我家那儿什么都没变”〕不否定，改问更小的东西：“你现在书包里有什么东西，是三年前没有的？”“你家最近换过什么？”找到一样，就往下接：“这种东西二十年后会变成什么样？”

师：现在把眼光挪到现在的家乡。老师给几个方向，你对着自己家乡想一想，哪几处是你最熟、最有话说的。

师：第一，是你每天走的那条路。路上有什么，什么时候最堵，什么时候最安静。第二，是你们那儿的水和树：有没有河、有没有塘，岸边什么样；有没有一片林子、一排树。第三，是你常去的地方，学校、球场、书店、菜市场、街角那家店都算。第四，是家里人做的事，爸爸妈妈爷爷奶奶每天忙什么，用什么工具忙。

师：不用四个方向都想。挑你最熟的两三处，在心里过一遍：它现在到底什么样。想到了就先记着，一会儿要写进提纲。

（教师总结）你亲眼见过的变化，是想象二十年后最好的起点；接下来我们要做的，是把这些你最熟的地方，往前推二十年。

### 三、学写法：一个方面一段，把“变了”写成看得见的画面（约 15 分钟）

师：准备动笔之前，我们先把题目看准。我手里有两段开头，写的都是二十年后回到家乡，可只有一段写的是这道题。听完你们告诉我，是哪一段。

师：第一段——“二十年后，我回到了家乡。清早的菜市场里挤满了人，卖菜的阿姨把青菜一把把码在木板上，水珠还挂在叶子上。旁边卖豆浆的推车冒着白气，几个上学的孩子端着塑料杯，一边吹一边喝。街口的早点摊前排着队，油条刚捞出来，滋滋地响。”

师：第二段——“二十年后，我回到了家乡。早晨的菜市场搬到了地底下一层，地面上原来摆摊的那条街，现在是一条长长的花廊。买菜的人在地下挑好菜，付过钱扫一下码，菜就顺着一条小传送带送到地面的取货口，出来时已经装好袋，还是凉的。我妈妈从前拎着两大袋菜走十分钟回家，现在她两手空空地走在花廊底下。”

师：哪一段写的是这道题？

参考：第二段。／第一段吧，它写得挺细的，菜市场我都看见了。

师：有意思，两边都有人。选第一段的同学，我请你替它说句话：你觉得它好在哪儿？

参考：它写得细／那个画面我看得见／青菜上的水珠都写出来了／有声音，油条滋滋地响。

师：这些好处我一条都不反驳，你说的都在。我只追问一件事：第一段里，有哪一样东西，是现在还没有的？

参考：没有／都是现在就有的／现在的菜市场就长这样。

师：这就是分界线了。第一段每一句都写得具体，可它具体写出来的是现在的菜市场。题目要的是二十年后。所以第一段不是写得不好，是写的不是这道题。它跑题了。第二段呢？

参考：菜搬到地底下了／有传送带／妈妈不用拎袋子了。

师：所以今天这篇，写什么、要留意什么，就清楚了：写你家乡二十年后的样子，写进去的每一处，都得是现在还没有的。光有画面不够，得是二十年后才有的画面。

师：那怎么才能让人一读就知道这是二十年后？这就要说回我一开头念的那一段了。

〔投屏：把开场那段“街道变得更干净了……”重新出示，与后面的改写版并排留位〕

师：先说一句公道话。那段话里的每一句，都没写错。“街道变得更干净了”“楼房也更高了”“人们的生活方便了许多”——意思清清楚楚，一个字都没说岔，读的人完全明白我要说什么。要是把它当成一句总的交代，它是合格的。

师：问题出在别的地方。你们帮我判断一下：这三句话，安到别的城市去，成不成立？

参考：成立／哪儿都能这么说／我家那儿也可以这么说。

师：那你们再判断一句：安到三年后，成不成立？三年后，街道能不能更干净一点？

参考：能。／三年也够了。

师：所以我那位朋友猜三年，不怪他。这几句话，放在三年后是对的，放在二十年后也是对的。那他就只好往近了猜。

师：现在看第二种写法。还是我家门口那条街，我换个写法再写一遍，你们听听有什么不一样。

〔教师示范·当场把“街道变得更干净了”这一条改写具体，念给学生听〕现在这条街，一到下午四点半就堵得动不了，喇叭声连成一片，路两边停满了车，走路的人得从车缝里侧着身子挤过去。二十年后，车都收到了地底下，地面上腾出来的一整条，全铺成了走路的道。从前划车位的那一溜，种上了两排树。放学的时候，孩子们从树底下走回家，走在路当中，谁也不用往边上躲。

师：这一回，你们听着像是隔了多少年？

参考：二十年／挺久的／反正不是三年。

师：你们是从哪儿听出来的？能不能说出具体是哪一句？

参考：车都收到地底下了／原来停车的地方种上树了／他先说现在堵，后来说不堵了。

学生互动分享（举手抽说三四位；教师把学生说的原样复述一遍，不急着下结论）

师：今天要用的两条写法，你们刚才其实已经自己说出来了，我只把它们收拢一下。

师：第一条，把现在的样子也写进去。不是只写二十年后什么样，而是“现在这样——二十年后那样”，两头摆在一起。刚才有同学说“他先说现在堵，后来说不堵了”，说的就是这一条。可以用“现在……二十年后……”，也可以用“从前……如今……”“过去……现在……”，哪个顺口用哪个。

师：第二条，变化以后的样子，要写成看得见的一个画面。不写“路更宽了”，写“孩子们从树底下走回家，走在路当中，谁也不用往边上躲”。里面有人、有动作、有地方，读的人眼前才立得起东西来。

师：那么第一种写法，就是“街道变得更干净了”这种，以后你们还能不能用？

参考：不能用了／可以用／看情况。

师：能用，而且很有用。你们看：我要是在刚才那段前面先加一句“最先变样的是我家门口那条街”，再接后面那一长串，读的人是不是一下就知道这一段要说的是哪一处？

参考：知道了／更清楚了／不用猜了。

师：所以这两种写法不是二选一，最好是搭着用：一段开头，先用一句话点明这一处变成了什么样；紧接着，再用几句具体的把它撑住。前面那一句让读的人知道这一段说的是哪一方面，后面那几句让他看见这一方面到底成了什么样。两样都写上，他才跟得上，也才看得见。

师：至于哪一处该多写几句具体的、哪一处一句话带过就够，你们自己定。你最有话说的那一处，就多写几句。

师：这个“一个方面一段、段首先点明”的做法，写地方用得上，写人、写物一样用得上。往后你写一个人有几处特点，也是一处一段，段首先点出是哪一处，后面拿具体的把它写足。

师：现在每人挑一处地方。就在刚才心里过的那两三处里，挑你最有话说的那一处。用今天这两条，自己小声说两句：第一句点明它变成了什么样，第二句往下说具体的样子。

学生互动分享（各自小声说给自己听一遍；教师巡视，挑两三位说得出画面的，请他们说给全班）

参考：我们小区门口那条路，二十年后不堵了——原来接孩子的车排到路口，现在车都停到楼底下去了，门口空出一块地，铺了跑道，放学的人在那儿跑步。

〔应答·学生只说得出第一句、接不下去具体的〕不要求他当场补完，改问一个小问题：“那儿站着的是谁？他在干什么？”问出一个人、一个动作，就够接下一句了。

（教师总结）两条写法记住了：现在什么样、二十年后什么样，摆在一起；变化以后的样子，写成一个看得见的画面。开头那句概括也留着用，放在段首，正好告诉别人这一段说的是哪一处。

### 四、借助提纲表，理清思路（约 8 分钟）

师：动笔之前还差一步。今天要写三个方面，一个方面一段，先把这三段排出来，动笔的时候就不会写着写着不知道下一段该写什么了。

〔发放：每人一张提纲表，三行三列，空白〕

师：这张表只填词语，不填句子。每一格写三五个字，你自己回头认得出来就行，别写成一句完整的话。待会儿写作文的时间要留足，表填得太满反而费工夫。

师：我先用刚才那条街填一行给你们看。第一格填哪一方面：门口那条街。第二格填它现在什么样：四点半堵、车缝里挤。第三格填二十年后什么样：车进地下、种两排树、走路当中。

〔投屏：教师示范填写第一行〕

| 哪一方面 | 现在什么样 | 二十年后什么样 |
| --- | --- | --- |
| 门口那条街 | 四点半堵、车缝里挤 | 车进地下、种两排树、走路当中 |
|  |  |  |
|  |  |  |

师：大家看第三格。我写的是“车进地下、种两排树、走路当中”，不是“这条街变得又宽又漂亮”。填的时候尽量落到具体的东西上：一样东西、一个动作、一处地方。这样等会儿动笔，一格就能撑开一句话。

师：现在你们填。三行，三个方面，挑你最有话说的三处。哪一处你能想出人在那儿干什么，就先填哪一处。

〔教师巡视：重点看第三列。只填了“更好了/更方便了”这类词的学生，走过去问一句“更方便是什么样子？谁在那儿做什么？”，把他问到一样具体的东西为止，再让他改填〕

学生互动分享（同桌两两交换看表，各看一遍；看的人只回一句：哪一格你看了就有画面，哪一格你还看不出样子）

师：请两位把自己填的其中一行念出来——只念三个格。

学生互动分享（举手抽说两位）

参考：河边／夏天有味道、不让去／能看见石头、有人钓鱼。／我家楼下／堆纸箱、没地方玩／改成球场、晚上有灯。

〔应答·学生三行都填不满〕不硬凑，填两行也可以动笔：“填两处也够写一篇，两处写足了，比三处都写一句强。”

（教师总结）表上这三行，就是待会儿正文的三段。一行一段，段首先点明这一方面，后面把第二格和第三格摆到一起写。

### 五、出示示范文，发现写法（约 8 分钟）

师：最后看一篇完整的。这是老师照着今天这两条写的一篇，写的是我回老家看见的样子。先听我念一遍，一边听一边数：它一共写了几个方面。

【教师示范文】

> 二十年后的一个夏天，我出差路过老家，临时决定下车回去看看。
>
> 最先让我认不出来的是村东那条河。小时候那条河水是浑的，一到夏天就发绿，岸边堆着塑料袋和碎砖，大人都不许我们靠近。二十年后再去看，河水清得能看见底下的鹅卵石，一群小鱼贴着水底游。岸边修了一道木栈道，几位老人坐在栈道边的椅子上钓鱼，脚边的水桶里养着刚钓上来的鱼。有个小孩蹲在浅水里捞什么东西，裤腿卷到膝盖，他妈妈就在旁边看着，不喊他上来。
>
> 我上过的那所小学，操场也换了样子。从前是一块水泥地，跑起来摔一跤就蹭破皮，下过雨要等两天才干得了。现在铺的是一层软的、带点弹性的地面，颜色是深红的，雨停半个钟头就能下脚。跑道边上立着一块牌子，学生跑完一圈，牌子上就跳出他这一圈用了多少秒。我去的时候正是下午，一群孩子在那儿追着跑，有个男孩跑完盯着牌子看了半天，回头朝同学喊了一声，声音大得整个操场都听见了。
>
> 变得最不起眼、我却看了最久的，是奶奶抓药这件事。从前奶奶配一副药，要坐四十分钟的车去县城，排一上午的队，回来天都黑了。现在镇上的卫生院里就有一台配药的机器，医生把方子输进去，机器在里面转一阵，几味药就分好装成小袋送出来，一副药一袋，袋子上印着哪天吃、吃几次。奶奶那天带我去看，她把药袋一袋一袋摊在桌上数，数完抬头跟我说，现在省下的那一天，够她跟老姐妹们打一下午牌了。
>
> 回城的车上，我一直在想那条河。我小时候没在里面踩过水，那个蹲在浅水里的小孩，替我踩上了。

师：它一共写了几个方面？分别是哪几个？

参考：三个／河、操场、抓药。

师：每一段的第一句，都在做同一件事。你们看这三句：“最先让我认不出来的是村东那条河”“我上过的那所小学，操场也换了样子”“变得最不起眼、我却看了最久的，是奶奶抓药这件事”——它们在做什么？

参考：告诉你这段写什么／点出是哪一处。

师：这就是我们刚才说的那句概括，它没有消失，它排在了每一段的最前面。

师：再看一处。这三段里，哪一句让你觉得，你真的看见了二十年后？自己挑一句，读出声来。

学生互动分享（各自默读挑句，举手抽说三位；教师把学生挑的句子原样复述一遍，问一句“这一句里有什么，让你看见了”）

参考：小孩蹲在浅水里捞东西那句／男孩盯着牌子看完回头喊那句／奶奶把药袋摊在桌上数那句。

师：你们挑出来的这三句，有个共同点。里头都有一个人，在做一件具体的事。把变化写成有人在做事的样子，读的人就看见了。

〔投屏：示范文旁批对照表，逐句对照着看〕

| 示范文里的句子 | 这一句在做什么 |
| --- | --- |
| 最先让我认不出来的是村东那条河 | 段首点明：这一段写的是河 |
| 小时候那条河水是浑的，一到夏天就发绿 | 先摆出现在什么样 |
| 河水清得能看见底下的鹅卵石，一群小鱼贴着水底游 | 二十年后什么样，两头摆在一起 |
| 有个小孩蹲在浅水里捞什么东西，裤腿卷到膝盖 | 有人、有动作，画面立起来 |
| 从前奶奶配一副药，要坐四十分钟的车去县城，排一上午的队 | 从前那样 |
| 现在镇上的卫生院里就有一台配药的机器 | 如今这样，变化一目了然 |

师：最后看结尾。我没有写“家乡变得越来越美好了”这样一句总结，我只是又回到了那条河，说了那个小孩。结尾可以像我这样，回到前面写过的某一样东西上收住；也可以写一句你心里的话。哪种收得住，就用哪种。

（教师总结）一篇里三个方面，一个方面一段；段首一句点明这一处，接着把现在和二十年后摆在一起，再往下写成一个有人在做事的画面。下节课就照这张提纲表写。

## 第2课时 · 当堂写作与评改课

### 一、看着提纲表，写下第一组句子（约 5 分钟）

师：把上节课那张提纲表拿出来，摆在稿纸旁边。找到第一行第三格，就是你写“二十年后什么样”的那一格。

师：接下来三分钟，就写这一处，别的先不管。三分钟里笔不要停：想到哪句写哪句，写错了不用擦，碰上写不出来的字，先空在那儿做个记号，等会儿再回来补。这三分钟不评好坏，也不用管开头怎么写，就从这一处下笔。

师：给你们几个方向，自己挑先写哪个，不用都写：那儿现在是什么样子；二十年后成了什么样；那儿有什么人，他在做什么；他为什么这么做。哪个你话最多，就从哪个开始。

〔限时三分钟，教师计时；学生书写期间教师不讲话、不巡视打断，站在讲台侧一起计时〕

师：笔放下。

师：刚才这三分钟，你手上已经有一段的大半了。剩下的两段，写法一模一样。

### 二、自由写作，把整篇写完（约 24 分钟）

师：现在从头写起，把整篇写完。顺序你自己定：可以接着刚才那一段往下写，也可以先补一个开头。

师：开头写你是怎么回到家乡的——坐车回去、出差路过、正好放假，都行，一两句话交代清楚就往下走。中间三段，就是你表上那三行，一行一段。结尾收一句：回到你前面写过的某样东西上，或者写一句你心里的话。

师：写的时候记着两件事就够了：每段开头先点明这一处，段里把现在和二十年后摆到一起。

师：还有一句：现在不要停下来改错别字，也不要回头数字数。碰上写不出来的字，照样先空着做个记号，先把整篇写完，改的时间等会儿单给。

〔教师巡视：全程不打断、不当众纠错。只对两类学生走过去低声提示——① 半天不动笔的，问一句“你表上第一行填的是哪一处”，把他带回自己的表；② 三段都写成一两句就收尾的，问“那儿有人吗？他在干什么”，问出一个动作再走开〕

〔应答·学生问“可以写得特别夸张吗，比如整座城市飞起来”〕可以写，接着追一句让他落地：“那飞起来以后，人在上面怎么过日子？早上出门是什么样？”能接着说出人在里头做什么，这个想象就立得住。

〔应答·学生说“我们那儿二十年后也不会变”〕换一处小的问：“你天天走的那条路呢？你家那部电梯呢？”从最小的一处入手，不必是整座城。

### 三、交流评议，修改收束（约 16 分钟）

师：笔停一下，我们开分享会。

师：四人一组，每人挑自己写得最满意的一段念出来，一个一个来，每人都要念到。听的三个人不看稿子，只听，念完回答两件事：第一，你听着这是隔了多少年；第二，你是从哪一句听出来的，把那一句复述一遍。

学生互动分享（四人小组轮读，人人念、人人被听见；教师巡到各组，听两三位学生的猜年判断）

〔应答·组内听不出年份〕不让念的人当场辩解，改让听的人接着说：“那你听见的是哪一处？”听的人说出那一处，念的人就知道该往哪儿补——多半是那一段只写了变化，没写人在里头做什么。

师：再请三组各推一位念给全班——推那位让你们一听就猜出是二十年的同学。

学生互动分享（三组各推一位，全班念三位；每念完一位，请两位听众各说一句“我是从哪句听出来的”）

师：（教师轻点评：每位念完只说一句，点在本课两条写法上——“这一句里有人在做事，所以我们都听出来了”“这一处你把从前和现在摆在一起了”。不评词句好坏、不排名次）

师：现在各自看自己的稿子，对着这四条自己过一遍。前两条数一数就行，后两条要你自己挑、还要说得出为什么。

| 查一查 | 自检的话 |
| --- | --- |
| 分段 | 我写了几个方面？是不是一个方面一段？ |
| 段首 | 每一段的第一句，有没有点明这一段写的是哪一处？ |
| 哪一段摆得最清楚 | 三段里，哪一段把“现在什么样”和“二十年后什么样”摆得最清楚？另外两段差在哪儿？ |
| 哪一句最看得见 | 全篇里，哪一句最让人看见了二十年后？它凭什么比别的句子强？ |

师：后两条挑出来的那一段、那一句，就是你自己的尺子。你已经写出过一处最好的了，接下来照着它改另外两处。

师：查完动手改，改三处就够，都是往上添，不用划掉什么。

师：第一，拿你挑出的那一段比一比：另外两段里，哪一段只写了二十年后、没写现在什么样，就在那一段补一句现在的样子。一句就行。

师：第二，你挑出的那一句里，有人在做事。另外两段里，哪一段从头到尾没有人出现，就添一个人进去，让他在那儿做一件事——走路、蹲着、喊一声、数东西，都算。

师：第三，哪一段的开头没有那句点明的话，就在段首补一句，告诉读的人这一段写的是哪个地方。

师：还有一种情况要单说。你要是写了“家乡变得越来越美好了”“人们的生活更幸福了”这样的句子，不用把它划掉。那是一句正正经经的话，意思也没错。你把它挪到那一段的最前面去，让它领着后面几句；它要是已经在段首了，就在它后面补一句具体的，把它撑住。这句话放对了地方，就是段首那句点明的话。

〔教师巡视：重点看第三条与最后这一条的落实；发现有学生把概括句整句划掉的，走过去说一句“不用划，挪到段首去”〕

师：改完的，把改过的那几句自己小声读一遍，只读改的那几句。读的时候问自己一句：现在看得见了没有。

学生互动分享（各自小声读改动处；教师巡视，挑一两位读得出画面的，请他念给全班听）

师：稿子自己收好。今天这两条写法，不只写家乡用得上——往后写你的房间十年后什么样、写学校二十年后什么样，都是这么写：一个方面一段，段首点明，把两头摆在一起，最后落到有人在做事的那一句上。

师：稿子上要是还留着做了记号、没写出来的字，趁现在补上，别搁着。

本课完。

全课完。

## 附：习作讲评指导环节（可选 · 单次课课后用 / 系列课作下次课开场用）

> 本环节评的是学生已在第2课时当堂写完的稿子，不是新布置的写作任务。单次课可在课后用它做一次集中讲评；若本班是系列课，可作下一次课的开场，约 15–20 分钟。当堂的即时反馈（分享会猜年份、自评自改）解决的是“写没写到位”，本环节解决的是“为什么这样写更立得住”。

### 选稿（课前准备）

从收上来的稿子里挑 2–3 篇，围绕本课两条写法挑，不按总分高低挑：

- 一篇两条都用上了的：三段各有段首点明，段里“现在什么样／二十年后什么样”摆在一起，且至少有一处写到人在做事。
- 一篇变化写足、人物缺位的：想象大胆、变化也具体，但通篇没有人出现，读着像一份说明。这一篇最有讲头。
- 一篇概括句用得好的（有则选）：学生把“变得更方便了”这类句子放在了段首，后面用具体的句子接住——正是本课说的搭配用法，值得当众表扬。

〔选稿说明·教师掌握，不必念给学生〕三篇的作者课前不必知会。念稿时只念内容、不报姓名，评完再问作者愿不愿意认领。

### 讲评流程（每篇约 3–5 分钟，围绕本课技法点）

师：先看第一篇。听他的第二段。＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿

[念完请两位听众各说一句：你听出这是隔了多少年，从哪一句听出来的]

师：他这一段里，＿＿＿＿＿＿＿＿这一句是段首点明，＿＿＿＿＿＿＿＿这一句把从前和现在摆到了一起。两条都在。

师：第二篇。再听这一段。＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿

师：这一篇想得很大胆，变化也写得具体。我问一个问题：这一段里，有人吗？

参考：没有／只有东西／像介绍。

师：那我们一起给他添一个人进去。这地方二十年后，谁会来这儿？他来干什么？

学生互动分享（举手抽说两三位，教师把学生说的接成一句，念给全班听）

[把学生现场添的这一句与原段并读一遍，让全班听出前后差别；不要求原作者当场改稿]

师：第三篇里有一句“＿＿＿＿＿＿＿＿”。上节课我们说过，这样的句子不用划掉，放对地方就是好句子。他把它放在了段首，后面紧跟着＿＿＿＿＿＿＿＿。这就是搭着用。

### 收尾（点回技法、引向今后的写作）

师：这几篇合起来看，站得住的都是同一样东西：段首点明写的是哪一处，段里把从前和现在对照着写，最后落到有人在做事的那一句上。

师：概括的话和具体的话，各有各的用处。概括的话告诉别人这一段说什么，具体的话让别人看见。哪一段该多写几句具体的，你自己定。

师：这两条，往后写“十年后的学校”“未来的房间”，同样管用。
