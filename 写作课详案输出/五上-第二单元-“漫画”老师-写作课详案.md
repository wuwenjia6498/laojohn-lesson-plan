# 《“漫画”老师》· 写作课教学设计

五年级上册·第二单元 校内同步写作（写人习作）

## 教案提纲表

| 课题·课时 | 五上·第二单元《“漫画”老师》　│　写人·校内同步　│　2课时连排（每节45分钟） |
| --- | --- |
| 能力阶段 | 写清楚 → 写具体 → 写生动（本课） → 写深刻·有章法 |
| 同类习作顺序 | 写人：猜猜他是谁 → 身边有特点的人 → 小小动物园 → 自画像 → “漫画”老师（本课） → 他＿＿了／形形色色的人 |
| 教材要求 | 统编五上·第二单元习作：用具体事例，漫画式突出人物特点。 |
| 学习目标 | 一篇能顶替一幅画的“漫画像”：听的人从没见过你写的这位老师，听完之后，好几个人说出的是同一处——他身上最突出的那个特点。 |
| 核心技法 | 像画漫画一样，只挑一两处最突出的地方重点展开刻画——每一处单独写成一个段落，段落开头先点明这个特点，再选用一件最能体现他个人特质的事例，把人物特点写饱满。 |

## 第1课时 · 写作指导课

### 一、创设情境，明确任务（约 6 分钟）

师：教过你们的老师里头，有没有哪一位，你不用看照片，也想得起他上课的样子？想得起来的同学，冲我点一下头。

[等大部分同学点头了再往下说；一时想不起来的，提示他往前想，以前教过他的老师也算。]

师：好，都想得起来。那我先问一件跟你们自己有关的事：假如有人把你写进一篇文章，专门抓住你身上最鲜明的一个特点，进行放大描写，你希望他写你的哪一点？又最不希望他写你的哪一点？

学生互动分享（随机抽取三四位学生；教师不评价，只把学生说的两类原样复述一遍）

参考：写我跑得快就行／怕他写我个子矮／写我上课爱走神那就完了／我头发乱糟糟的，不要写这点。

师：你们自己分得很清楚：同样是对人物特点做放大刻画，有的写法会让你欣然接受，有的写法却会让你心生抵触。今天我们要写的这篇习作，描写对象是老师，描写的分寸边界同样要守住。

师：你们先听这个片段：有位老师总把袖子挽到胳膊肘，一年到头没放下来过。对这个细节进行放大刻画，就可以写成这样：“我上了三年他的课，没见他把袖子放下来过，我怀疑那两只袖子是缝上去的。”

参考：（笑）／这个有意思／有点像在编排他。

师：你们笑了，这个细节的描写就已经到位了。可这样写到底算不算取笑老师？描写的分寸该怎么拿捏，等下我们讲写法的时候再专门确定。

师：漫画你们都见过吧？报纸上、书上，有时候会给一个真人画一幅漫画像。那样的一幅画，跟这个人的照片比，哪儿不一样？

学生互动分享（随机抽取两三位；教师不逐一评价，只把学生说到的合在一起）

参考：头画得特别大／鼻子画得特别夸张／画得不太像，可是一眼就知道是谁／画出来很好笑。

师：你们说的其实是同一件事。漫画不是把这个人样样都画得很像——眼睛、鼻子、嘴巴，画的人根本没打算一样一样都画像。可你一眼就把他认出来了，还觉得有意思。他到底是怎么做到的，等会儿讲写法的时候我们再说。

师：今天这个题目就叫《“漫画”老师》。你们注意，“漫画”这两个字上头加了引号——加了引号，意思就变了：今天不用你们画画，一支画笔也用不着。这两节课，我们每人用文字给一位老师“画”出这样一幅像。写一位你们学校里教过你的老师，现在教你的、以前教你的，都可以。

师：写完，我们就在这间教室里念念。听的人有一个难题：你写的这位老师，在座的谁也没见过。他长什么样、是个什么性格脾气，全通过你那几行字体现出来。

师：什么算“画”成功了？念完之后，会有两位同学在你的稿子末尾各写下一句：他从这段话里看见了这位老师身上的哪一处特点。两个人写的是同一处，你这幅像就画准了。漫画就是这么回事：一眼认出，而且认出的是他身上的同一样东西。什么算没画成？两个人写的完全不一样，或者干脆写不上来，那这幅像就没有画出来。

### 二、观察体验，学一学他上课的样子（约 9 分钟）

师：心里那位老师，你们应该已经选好了。现在请再仔细想一想：他上课的时候，有没有一个常做的动作，或者一句老挂在嘴边的话？

参考：他讲着讲着就把眼镜往上推／他老说“坐正了坐正了”／他喜欢敲两下桌子／他一转身粉笔就在手里转。

〔应答·学生说“我们老师没什么特别的动作”〕可以从三个方向引导他：他讲到高兴的地方是什么样子；他要你们安静下来的时候怎么做；他手里除了粉笔还老拿着什么。三个方向里，总有一个能答得上来。

师：跟同桌互相扮演一下。把你们老师那个常做的动作做一遍，或者用他的口气把那一句常说的话说出来。同桌看完，能说出来你学的这位老师是个什么样的人，就说明你们的扮演是过关的。

[先说清楚：学的是他上课时最有意思的那个动作、那一句常说的话，不是挑他的毛病。看见有学生学的是老师的口吃、走路姿势这类身体上的短处，当场换一个方向问他：“他上课时你最爱看的是哪一个动作？”]

学生互动分享

师：还是刚才那个动作，你们再往他身上仔细看一眼。他做这个动作的时候，手上、脸上、身上，有哪一处动作或是表情神态是最显眼的？还是跟你的同桌说一说，两个人各说一句。

参考：他一推眼镜，眉毛就跟着往上跑／他手指头上全是粉笔灰／他一着急就脸红／他讲课的时候老攥着那支笔。

学生互动分享

师：请三位同学模仿给大家看一下。其余同学看完，说一说：你看出了他模仿的是个什么样的老师。

学生互动分享（随机抽取三位同学当众学一遍；每一位学完，请一两位同学说自己看出了什么，教师不复述、只点评一句他们说到的那一处细节）

参考：这位老师性子挺急的／他很爱管上课纪律／他上课好像很有意思。

师：还有一件事，请你们再认真回想一下。他上一次是在发生什么事情时做的这个动作？那天班里发生了什么？想得起来的，跟同桌说一说；一时想不起来的，就说说他做这个动作做得最多的是什么时候。

学生互动分享（同桌之间，各说一句；教师走到三四组学生身旁旁听，听见说得具体的记下这位同学，等会儿构思时请他先回答）

参考：上回我们吵得太厉害，他就敲了两下桌子／他讲他小时候的事，眼镜往上推了好几回／有一次我们整张卷子都做错了，他把粉笔头一放，反倒气笑了。

师：你们看，刚才那三位同学一个字都没解释，只学了一个动作、说了一句他常说的话，我们就看出这三位老师不一样了。你们刚才学的那一个动作、那一句常说的话，还有刚跟同桌说的那一回事，就是今天写这篇习作最重要的材料。等会儿构思的时候还要用它们。

### 三、学写法：一处一段，用一件事把它写足（约 13 分钟）

师：老师这里准备了两段文字，写的是同一位老师。我念给你们听，你们边听边想：哪一段听下来，这位老师的模样能在脑海里清清楚楚地浮现出来。

师：第一段——“我们的语文老师姓周。她个子不高，剪着齐耳的短发，戴一副细边的眼镜，笑起来眼睛弯弯的。她说话不紧不慢，声音很温和，从来没有跟我们发过脾气。她的字写得特别漂亮，一笔一画都很工整，我们都想照着她的字练。她还很爱看书，办公桌上常年摞着一摞书，摞得比水杯还高。下雨天她会站在门口，提醒我们路上小心。她对我们非常关心，是一位好老师。”

师：“我们的语文老师有个改不掉的小习惯：讲课一投入，就会下意识推眼镜。上个星期分析课文，她越讲越投入，身子不住往前倾，眼镜一次次滑到鼻尖。她习惯性地一皱鼻子，耸起鼻梁把眼镜顶回去。可那副眼镜总是不听话，没一会儿又滑下来，她无奈地小声嘀咕：‘这眼镜怎么总往下滑。’台下不少同学看见了，低着头憋住笑，她自己浑然不觉，依旧专注地讲着课文。”

师：你们说说看，哪一段听完，这位老师的模样是清楚的？

参考：第二段。／第一段吧，第一段把她的样子、脾气、爱好都写到了。／我也选第一段，我们平时写人不都是这么写的。

师：说第一段的同学也有他的道理。第一段写得确实不算简单：长相、说话、写的字、爱好、下雨天怎么做，五六样都交代到了，还写了摞得比水杯还高的那摞书，画面也有。我要问你们一句：读完第一段，你们记住她哪一处了？

参考：记不住／好像哪一样都记得一点／忘了。

师：差别就在这儿。第一段确实样样都写了，但一样也没写充分，读完像看了一张人物标签清单；第二段只抓住一处特点，把这一处写到底，那位老师反倒有了模样。画漫画不能鼻子、眼睛平均使劲，写老师也是一样的道理：把五六处平均分配着墨，人物形象就鲜活不起来。你们要做的，是从里头挑出最突出的一两处特点，重点展开刻画。

师：那第二段到底做了几件事，才把这位老师写得这么清楚？我把前面几句再念一遍，你们边听边找。

师：“我们的语文老师有个改不掉的小习惯：讲课一投入，就会下意识推眼镜。上个星期分析课文，她越讲越投入，身子不住往前倾，眼镜一次次滑到鼻尖。她习惯性地一皱鼻子，耸起鼻梁把眼镜顶回去。可那副眼镜总是不听话，没一会儿又滑下来，她无奈地小声嘀咕：‘这眼镜怎么总往下滑。’台下不少同学看见了，低着头憋住笑，她自己浑然不觉，依旧专注地讲着课文。”

参考：它一开头先点明老师下意识推眼镜这个小习惯／用上星期分析课文的课堂事例展开具体细节／抓住眼镜滑落、耸鼻梁顶回眼镜、小声嘀咕等一连串动作与语言进行刻画。

师：你们找出来的这几点，归起来是两条写法。我先把这两条写法给你们讲清楚。

师：第一条，一个特点单独写成一个段落，段落开头先把这一个特点点明。比如这段范文开头就是“我们的语文老师有个改不掉的小习惯：讲课一投入，就会下意识推眼镜”，读者一上来就明白这一段要聚焦什么。如果要写下一个特点，就接着再写一段。

师：第二条，点明还不算完，后面还要搭配一件具体事例把特点写饱满。这件事要专属于这个人的典型经历——讲课投入时眼镜反复滑落，还会小声吐槽眼镜；换作别的老师，未必会出现这样的情景。刚才那一段里，这件事是怎么写出来的？你们数一数，一共写了几样东西。

参考：写了她皱鼻耸鼻梁顶回眼镜的动作／她嘴里那句“这眼镜怎么总往下滑”／她浑然不觉、仍专注讲课的模样。

师：正好三样。这三样，我们就分别叫作：人物的动作、人物说的一句话、人物当时的样子。三者都要兼顾。缺少动作，纸上的人物就没有动态；如果没有人物的话语和神态模样，我们既听不见人物的心声，也看不清人物的状态。

师：刚上课我们留下一个问题没有定下来：放大刻画人物和取笑人物，分寸究竟在哪里。现在我们就一起来明确这份描写的分寸。老师准备了针对同一件小事的三种写法，大家听完之后做一番辨析。

〔教师示范·同一件事的三种说法，一句一句念给学生听〕第一种：“语文老师上课总被滑落的眼镜困扰。”第二种：“她低声念叨‘这眼镜怎么总往下滑’，底下不少同学悄悄低下头憋着笑。”第三种：“她一节课眼镜要滑下来十几次，我们怀疑她连一副合适的眼镜都配不好。”

师：这三种，哪一种你读着最有意思？哪一种你觉得写得过头了？

参考：第二种好玩／第三种太夸张了／第三种像在放大她的缺点／第一种没意思，放到任何一位老师身上都适用。

师：你们说得对。第一种是个结论，套到哪个老师身上都说得通。第二种围绕眼镜滑落这件真实发生的小事展开刻画，同学们暗自憋笑的场面，只有在她的课堂上才会出现，读者读后会心一笑，也能真切认出这个人物。第三种就不一样了：一节课滑落十几次属于刻意编造，“连一副合适的眼镜都配不好”是编造不存在的情节，或是专门抓住别人的短处去刻意放大，就变成了取笑。

师：所以第三条：放大刻画，只针对真实发生的事情。动笔放大描写之前，可以先问自己一句：这段话，我敢不敢当着这个人的面念给他听。敢于当面念出来，就说明这个人物刻画是妥当的。

师：拿这三条回头看刚上课说的那句挽袖子的话。他的袖子是真挽着的，一年到头没放下来过，这是真事；说袖子像缝上去的，谁听了都知道是句玩笑话，没有刻意放大他的缺点；把这句话当面念给本人听，是说得出口的。因此这段描写是合理的放大刻画，并不是取笑。

师：现在你们自己来说一句。想想刚才模仿的那位老师，还有你学的那个动作，把它放大刻画着说一说。想好了先小声说一遍。

学生互动分享（随机抽取两至三位同学展示；教师仅围绕一点开展点评：人物放大刻画的内容，是否来自真实的细节）

〔应答·学生放大到了老师的长相短处，如“他的肚子像装了个球”〕不当众驳回，先接住那一句里真实的部分，再换个方向问他：“他上课时你最爱看的是哪一个动作？把那个动作放大着说给我听听。”

### 四、借助人物特点卡，理清思路（约 9 分钟）

师：真正动笔之前，先把想好的这些内容落到纸上。这张特点卡马上发到你们手里。填的时候记住一条：一格里几个词就够，不用写成句子，你自己回头看得懂就行。

| 项目 | 我的关键词 |
| --- | --- |
| 写哪位老师 |  |
| 长相上最突出的一处 |  |
| 说话或脾气方面最突出的一处 |  |
| 上课时的一个习惯动作、一句常说的话 |  |
| 圈定：最突出的一两处特点 |  |
| 这一两处各配一件什么事 |  |

师：我这儿有一张已经填好的，你们先看看。卡上填的是一位科学老师，姓刘，等会儿你们还会读到写他的那篇作文。

| 项目 | 我的关键词 |
| --- | --- |
| 写哪位老师 | 教科学的刘老师 |
| 长相上最突出的一处 | 十指洗不掉的颜色 |
| 说话或脾气方面最突出的一处 | 手上有活就先干完再说 |
| 上课时的一个习惯动作、一句常说的话 | 随手往外套口袋里掏 |
| 圈定：最突出的一两处特点 | 那双手·那两个口袋 |
| 这一两处各配一件什么事 | 跟到水池边看他洗手／用铁丝修眼镜腿 |

师：这张卡上的字，跟你们平时写的句子比一比，哪儿不一样？

参考：全是词／一句整话都没有／短得很。

师：没错，每一格几个词就够用，完整的句子留到动笔的时候再写。

学生动笔填写人物特点卡（填上面四格约 2 分钟；教师巡视）

师：前面三格里你写了三处特点，我们现在看看第五格。我先在自己这张卡上圈一次给你们看。我圈的是那双手和那两个口袋：手上洗不掉的颜色，换一位老师就说不通了；口袋总是鼓着，随手就往里掏，也是他一个人才有的。剩下那一格“手上有活就先干完再说”，我没圈，因为好些老师都有这个特点，圈了也认不出是他。

师：轮到你们自己判断：哪一处最像他，哪一处换个老师就说不通？把它圈出来，圈一处或者两处，不要三处都圈。三处都圈，就又回到之前面面俱到、人物形象模糊的写法。

〔应答·学生三处都想留、拿不定主意〕不替他挑，问他一句：“这三处里头，哪一处你刚才学给同桌看过？”学过的那一处通常就是最显眼的那一处。

师：第六格，给圈出来的那一处配一件事。这件事不用大，只要是因为他这一处特点才发生的就行。写不出来的同学，往这三个方向想：他这一处在哪一件事上表现得最明显；因为这一处，班里出过什么事；他这一处让你记到今天，这印象是哪一天留下的。

学生动笔填写（填第五、六两格约 2 分钟；教师巡视，看见第六格空着的问一句上面那三个方向）

师：我想听两位同学说说。其余同学带着一个问题听：换一位老师来，这件事干得成干不成。

学生互动分享（随机抽取两位；每一位说完，请一两位同学点评一句“换个老师干得成干不成”，教师顺势点出他哪一处最值得展开）

### 五、出示示范文，发现写法（约 8 分钟）

师：卡填到这一步，材料就齐了。下面我们看一篇完整的文章，写的就是刚才卡上那位科学老师。读的时候留意一件事：卡上那几个词，最后是怎么铺开成一段一段的话的。

> 【教师示范文】
>
> 教我们科学的是刘老师。第一次上他的课，我盯着他的手看了半节课。
>
> 他有全年级最脏的两只手。说脏也不准确，是洗不掉：十个指头上总带着颜色，今天蓝一块，明天紫一道，指甲缝里还黑黑的。我们私下打赌，他洗手的时候，从指缝里流下去的水一定是彩色的。上个学期有一回，几个同学特意跟到水池边上去看。他一边搓手一边问我们围着干什么。水哗哗地流，清的，一点颜色也没有。他把湿手一举，说：“这不叫脏，这是做实验留下的痕迹。”
>
> 除了这双手，他身上第二显眼的是他那件深灰色夹克上的两个口袋。
>
> 那两个口袋从来没有瘪下去过，走起路来两边都往下坠。上课要用的东西他基本不拿箱子装，全在口袋里头：磁铁、放大镜、几节干电池，还有一小卷细铁丝。我们私下说，那两个口袋底下通着实验室，只管掏，掏一整个学期也掏不空。
>
> 上个月有一节课，讲到一半，前排一个同学的眼镜腿掉了，低着头在桌上摸。他走下讲台，把那副眼镜拿过去，对着灯先看了看断口，从口袋里摸出那卷铁丝，剪下一小段，把镜腿抵在桌角上，然后一圈一圈往镜腿上绕铁丝，绕完用指甲把毛刺按平，又把眼镜在自己鼻梁前比划了几下，才递回去：“先用着，比原来那个结实。”说完转身接着往下讲。剩下的半节课，他一个字也没再提这件事。
>
> 从那以后，我们班有个说法：东西坏了先别急着扔，去翻翻刘老师的口袋——里面总能掏出点物件来修好它。他那两只手为什么老也洗不干净，我大概也想明白了。

师：我们先整体看一遍。这一篇一共写了这位老师的几处？各写在哪儿？

参考：两处／手写在前头／后面写他夹克外套上那两个口袋。

师：一处一段，段落开头先把这一处点明——第二段头一句是“他有全年级最脏的两只手”，第三段单起一句“除了这双手，他身上第二显眼的是他那件深灰色夹克上的两个口袋”。开头一句话点出写的是谁，结尾一句写自己现在怎么看他。你们这一篇也可以照这个样子搭起来。

师：下面这一步我不讲了，交给你们自己找。下面有六条提示，说的是这一篇里六个句子各自在做什么。你们回到文章里，一条一条把对应的那一句话找出来，找到就在文章上划下来。同桌两个人分着找，前三条一个人、后三条一个人，找完互相对一遍。

[投屏只出示下面这一栏（六条提示），文中对应的句子不出示。学生手上是完整的示范文，自己回文中找对应句子、划线。教师巡视，看见找错的先不纠正，留到下面核对时由别的同学说出来。]

| 这一句在做什么 |
| --- |
| 段落开头一句就把最突出的那一处点明 |
| 把这一处进行了放大描写，读着好笑，可放大的是真实存在的痕迹 |
| 那件事里他的动作，一步一步写下来 |
| 那件事里他说的话，换个人说不出来 |
| 那件事里他当时的样子 |
| 结尾不夸他，只写现在我们怎么看他 |

学生动笔写作（同桌分工回文中找句子、在示范文上划线，约 2 分钟；教师巡视，记下找得快的两三位，核对时先请他们）

师：一条一条对。第一条，谁找到了？

参考：“他有全年级最脏的两只手。”

师：第二条呢？

参考：“我们私下打赌，他洗手的时候，从指缝里流下去的水一定是彩色的。”

师：这一句好笑。可你们注意，他写完这句打赌，紧跟着就写了几个同学真跟到水池边去看，水流其实是清澈的。虽然用了放大描写，但没有把玩笑猜想当成真实情况，也没有专挑老师的短处去写。

师：中间三条挨在一块儿，你们一起报出从文中找的句子。

参考：动作是“把镜腿抵在桌角上，然后一圈一圈往镜腿上绕铁丝，绕完用指甲把毛刺按平，又把眼镜在自己鼻梁前比划了几下”／他说的话是“先用着，比原来那个结实”／当时的样子是“说完转身接着往下讲。剩下的半节课，他一个字也没再提这件事。”

师：三样齐了，而且全在修眼镜那一件事里头。最后一条“结尾不夸他，只写现在我们怎么看他”呢？

参考：“东西坏了先别急着扔，去翻翻刘老师的口袋——里面总能掏出点物件来修好它。”

师：这一句他一个字也没夸这位老师，只写了现在他们班怎么看他。

〔应答·学生把中间三条找串了，比如把“他把湿手一举，说：‘这不叫脏，这是做实验留下的痕迹。’”当成那件事里他说的话〕不说找错了，先接住：“这一句也是他说的话，没错。可它出在哪一段？”学生自己就会往后翻到修眼镜那一件事上。

师：你们再想想：换一位老师碰上眼镜腿掉了这件事，多半会怎么办？

参考：让他先凑合戴着／叫他放学回家找人修／可能就说一句“怎么这么不小心”。

师：多半就是这样。可这位老师口袋里正好有铁丝，也正好肯当场把那副眼镜接过去修好。所以这件事，别的老师身上发生不了。刻画人物，最重要的就是写这样一件独属于他自己会做的事。

师：这一篇写的是教科学的刘老师。你们要写的那一位老师是什么脾气、跟你们之间有过哪些事，只有你们自己清楚，所以内容不必照着这一篇来。要守住的是三条：一处特点写一段话、段落开头先把这一处特点点明；后面跟一件只有他才做得出来的事，事里有他的动作、他说的一句话、他当时的样子；放大刻画只放大真实发生过的事情。

师：第一节课就上到这里。中间休息一下，回来我们就动笔。

本课完。

## 第2课时 · 当堂写作与评改课

### 一、看着特点卡，写下第一段（约 5 分钟）

师：把特点卡拿出来，看你圈出来的那一处特点。开始动笔之前，老师先交代一句：起头空两格，用一句话说清楚你写的是哪位老师，就像刚才那一篇开头的“教我们科学的是刘老师”。听你念的人一个都没见过他，这一句不能省。

学生动笔写作

师：下面另起一段，从你圈的那一处写起。先写段落开头那一句，把这一处点明。老师卡上圈的是“那双手”，段落开头那一句就是“他有全年级最脏的两只手”。你那一句该怎么说，想好了就写在下一行。

学生动笔写作

师：接着往下写三四句，一直写到没见过他的人也能对上号。下面有四个方向，你们自己挑着用，先写哪一样、写几句，都由你们自己定：他这一处是什么样的，别人身上没有的是哪一点；他做这个动作的时候，手上、脸上是什么样子；他嘴里常说的是哪一句话；你觉得可以放大的细节，就放大刻画。这四样不必写全，哪一样最像他，就先写哪一样。

学生动笔写作

师：笔停一停，把刚写下的这几行从头读一遍。一边读一边问自己：光凭这几行，一个没见过他的人能不能对上号。这几行站住了，接下来就好写了。接着写那件事：他这一处特点是在哪一件事上显出来的，就从那天怎么开的头写起。

### 二、自由写作，把整篇写完（约 23 分钟）

师：接下来的二十分钟，你们一口气把整篇写完，中间不要停。有三件事得记在心里：一处一段，段落开头先把这一处特点点明；那件事里，他的动作、他说的一句话、他当时的样子，三样都得有；放大刻画只放大真实发生的事。写到最后添一句，说说你现在怎么看这位老师。写的过程中不用回头修改，先一路写到底。

学生动笔写作

[教师巡视，只做正向介入，不纠错字、不改病句、不打断书写顺畅的学生。按学情分四类处理——]

[接不下去型：第一段写完就停下，笔搁着不动——请他把特点卡摆到手边：“这一处你写出来了。第六格上不是配了一件事吗，就写那件事：那天先发生了什么，他做了哪个动作。”]

[内容空泛型：整段都是“他对我们很关心”“他是一位好老师”一类的话——先请他把那位老师的一个动作学一遍给你看，再顺着问“他做这个动作的时候，脸上是什么样”“上一回是在什么事上做出这个动作的”，他答出一句，就请他照着这句写下去。]

[书写顺畅型：不打断，走过时轻声一句“接着写”，给他留出接着写下去的空间。]

[草草收尾型：两处各写三两句就搁笔说“写完了”、篇幅明显偏短——先肯定再推一步：“他常做的那个动作你已经写出来了，好。那天他做完这个动作说了什么，说完你们又怎么样了？把这两句补上。”]

[临近时间提示：提醒学生把手上这一句写完整再停笔；没写完的，记住自己接下来要写什么，后面还有一段修改时间可以补。]

### 三、交流评议，修改收束（约 17 分钟）

[两轮换人互念（约 5 分钟）：第一轮同桌，第二轮前后桌换人；每人只念一段、约 40 秒；听的人只在稿件末尾写下“看见的那一处细节”，不评好坏。5 分钟＝两轮学生动作 3.7 分钟＋三段师话 1.3 分钟，师话须计入，别只算学生念的时间]

师：笔放下。先跟同桌换稿子，各自念一段给对方听。只念你写那一处特点、描写那件事的地方，念四十秒左右就够。听的人不用点评，就在他那张稿纸的末尾写下三五个字——你从他念的这段里，看见了这位老师身上的哪一处特点。

学生互动分享（同桌互动，一人念一遍，听者在稿件末尾写下一处特点；教师控节奏，学生动作一轮约 1 分 50 秒）

师：现在换个人。前后桌转过来，跟刚才不是同一个人，再念一遍，听的人照样在稿件末尾写下一个特点。

学生互动分享（前后桌换人，再走一轮，听者在稿末写下第二处；教师提醒念的人不必念整篇，仍念刚才那一段）

师：拿回自己的稿子，看这两个人写的是不是同一个特点。写的一样，说明你这幅像画准确了。两个人都没见过这位老师，光凭你这几行字，看见的是同一样东西。两个人写得不一样，也不用急，等会儿改稿先改这里：多半是你把特点铺得太分散，多处细节平均用力，需要挑选一到两处重点把它写饱满。

[全班朗读分享（约 5 分钟）：请三位学生依次朗读，每位只朗读展开事例的段落，时长约 40 秒；每读完一位，请两位同学各发表一点感受，教师针对文中某一处具体语句做点评肯定，三位都念完再统一比一次]

师：请三位同学念给全班听。念的人不用念整篇，只念你写那件事的那一段，四十秒左右。台下的同学听完，我请两位，每人说一句：你听出来的是他身上的哪一处特点。

学生互动分享（三位依次念；每一位念完，教师请两位听众各答一句，随即针对文中某一处具体语句做点评肯定：哪一句让台下认出了他。三位都念完，教师把六个答案摆到一起比一次：落在同一处的是哪几位同学写的。）

[带标准修改（约 6 分钟）：延迟到此刻统一处理行文与错别字。老师交代约 1.5 分钟 → 自己改约 2.5 分钟 → 两句判断当改后自查、随即同桌互说（不换稿、各凭第一轮听到的那一段说一句）约 1 分钟 → 补改约 1 分钟。自检表不带读，学生自己看；两句判断已后移到改稿之后，改前交代只留自检表与改三条]

师：别人的稿子听完了，现在回到自己的稿子上。先对着这张表，看看你写到了哪一档。

| 档位 | 自检的话 |
| --- | --- |
| 写得认得出 | 我写的是哪位老师、他最突出的是哪一处特点，别人读了说得出来。 |
| 写得够具体 | 围绕特点搭配真实事例，事例写清人物的动作、说的话、当时的神态模样。|
| 写得有张力 | 对真实细节做适度放大，文字生动鲜活；内容得体，这段话可以当面读给这位老师听。|

师：这张表你们自己看，我不念了。看完就回自己的稿子上改，改三条：第一，把“他很严”“他很关心我们”这样谁都写得出的话找出一句，换成他真做过的那一件事；第二，那件事要是只交代了结果、没写经过，就补上他当时做的一两个动作、他嘴里那句话，还有他当时是什么神态模样；第三，看看有没有哪一句放大过了头。编出来的、专说他短处的，划掉。

学生动笔写作（自己对着三条改；教师巡视答疑，正文还差一截的同学，先请他往下写完）

师：笔停一下，我这儿有两句话，写的是同一位老师：一句是“他对我们要求很严”，一句是“他讲评作业的时候从来不念名字，只把本子举起来，让全班看一眼那一页”。你们更相信哪一句写的是他本人？

参考：第二句／第一句谁都能写／第二句是他自己的做法。

师：那你们低头看一眼刚才改出来的那一句，它像左边这一句，还是像右边这一句。像左边的，等会儿还得再改一次。

师：现在转过去跟同桌说话，稿子不用换。第一轮大家听过对方朗读的片段，请结合刚刚听到的内容，对照自检表互相评价：对方的习作停在哪一个档位？如果想要往上提升一档，还缺少哪一处内容？两人轮流发言，每人只说一点即可。

学生互动分享（同桌两两互评，依据刚才听到的朗读片段各发表一点看法；教师巡视，遇到只做笼统夸奖“写得挺好”的学生，引导他落实到文中具体语句）

〔应答·同桌无法说出还差哪一处〕教师抛出更聚焦的小问题引导：“刚才他朗读事例部分，那位老师说的原话，你听到了吗？如果没有听到，往往就是这里有所缺失。”如果听到了，继续追问：“那这件事里老师当时的神态模样，他有没有写出来？”

师：把同桌指出的这一点，补充到自己的习作当中。补完之后通读文稿，用平时课堂学过的修改符号：订正错别字、补全遗漏细节、圈画删除多余内容。

学生动笔写作（补改；教师巡视答疑）

[收尾（约 1 分钟）]

师：今天这些稿子上，没有一幅图画。但刚才几位同学一读，台下很快就能抓住人物身上标志性的细节：某个习惯性动作，或是一句独有的口头表达。写作也是这个道理，不必面面俱到，抓住人物最鲜明的特点，读者就能牢牢记住这个人。

师：还有一个要点，课堂前面已经提到，这里再强调一遍：做放大描写之前，先问自己一句话：这段话，敢当面念给这位老师听吗？写的是真实发生过的事情，才经得起这样的检验。大家把习作收好。

（教师总结）今天学到的写作方法，以后写任何人物都可以用：先筛选出人物身上一两处独有的细节，一处写成一个段落；段落开头直接点明这个特点，后面搭配一件只有他才会发生的事例，把人物的动作、原话、当时的神态模样具体写出来。一个人的故事有很多，不需要全部写进作文。选准少数重点细节写充分，读者反而更能记住这个鲜活的人。

## 附：习作讲评指导环节（可选 · 单次课课后用 / 系列课作下次课开场用）

> 本环节供老师灵活取用：可在单次课课后批读学生习作后集中讲评一次，也可作系列课下一次课的开场（约 15–20 分钟）；不计入本课 45+45 分钟，评的是学生当堂完成的稿子，不布置新的写作任务。
> 讲评中凡出现 ＿＿＿ 处，务必换成本班学生习作里的真实句子，切勿虚构。

### 选稿（课前准备）

从本班当堂完成的稿子里挑 2–3 篇，对着本课三条技法各挑一类：一篇“三条都做到了”的（一处一段、段落开头点明，事里动作与话都在，放大的是真事）；一篇“事写出来了、可两三处平摊着写”的中等篇；一篇“通篇是评价、看不出他哪一处特别”的待改进篇。每篇用一句话对着技法记下它好在哪、欠在哪。讲评时投屏或朗读，不具名、不排名次。

### 讲评流程（每篇约 3–5 分钟，围绕本课技法点）

师：写完那节课上，我们念了几篇，听的人只说一句：从这段话里看见了这位老师身上的哪一处。今天回头看三篇稿子，看的还是这一条——没见过这位老师的人，读完能不能说出他身上的哪一处。其余的问题今天先放一放。

师：先看第一篇。他那一段开头一句是——“＿＿＿”（念该生段首点出那一处的那句话）。一句话下去，我们就知道这一段要看什么了。

师：后面那件事，他写了这么几句——“＿＿＿”（念该生写这件事里动作与话最见样子的一两句）。这几句里有他的动作，也有他说的一句话。有了这两样，我们没见过他，也认得出他了。

（教师总结）第一篇三条都在：一处一段、段落开头点得清楚，事里有动作有话，进行放大描写的那一句也是真事。

师：第二篇的事情选得准，你们听这一句：“＿＿＿”（念该生写事最具体的一句）。可他前半篇一口气写了好几处：“＿＿＿”（念该生把两三处平摊着写的那几句）。这几处一样长，读完反倒不知道该记住哪一处。

师：那你们说说，该怎么改？

学生互动分享

师：对，留一处，把留下的这一处往下写足，剩下的删掉或者一笔带过。第二篇缺的不是材料，是舍不得删。

师：第三篇不说是谁写的，我只念其中一句：“＿＿＿”（念一句典型的只有评价、看不出所以然的话）。这一类句子，班里不止一张稿子上有。大家判断一下：把这一句放到别的老师身上，说不说得通？

学生互动分享

师：说得通，那这一句就还没写到他身上。补一件他真做过的事，哪怕只是一节课上的一分钟：他当时做了什么，说了哪一句。补上以后，这句评价留不留都不要紧了。

（教师总结）这三篇各有各的情况：第一篇三条都在；第二篇差在没挑，几处都舍不得删；第三篇差在只有评价、没有事。

### 收尾（点回技法、引向今后的写作）

师：讲了三篇，来回还是那三条：挑一两处，一处一段、段落开头先把这一处点明；后面跟一件只有他才做得出来的事；放大只放大真事。往后写你家里的一位长辈、写你的一个同学，也是这么办：先找出他身上别人没有的那一处，再找出跟这一处对得上的那一件事。改好以后，稿子自己留着。

本环节完。
