# 《“漫画”老师》· 写作课教学设计

五年级上册·第二单元 校内同步写作（写人习作）

## 教案提纲表

| 课题·课时 | 五上·第二单元《“漫画”老师》　│　写人·校内同步　│　2课时连排（每节45分钟） |
| --- | --- |
| 能力阶段 | 写清楚 → 写具体 → 写生动（本课） → 写深刻·有章法 |
| 同类习作顺序 | 写人：猜猜他是谁 → 身边有特点的人 → 小小动物园 → 自画像 → “漫画”老师（本课） → 他＿＿了／形形色色的人 |
| 教材要求 | 统编五上·第二单元习作：用具体事例，漫画式突出人物特点。 |
| 学习目标 | 一篇能顶替一幅画的“漫画像”：听的人从没见过你写的这位老师，听完之后，好几个人说出的是同一处——他身上最突出的那一处。 |
| 核心技法 | 像画漫画一样，**只挑一两处最突出的地方**放大着写——一处单独写一段，段首先点出这一处，再用**一件只有他才做得出来的事**把它写足（他的动作、他说的一句话、他当时的样子，三样都要有）；放大**只放大真事**，敢念给他本人听。（辅：开头一句话点出写的是谁，结尾一句写你对他的看法。） |

---

## 第1课时 · 写作指导课

### 一、创设情境，明确任务（约 6 分钟）

师：教过你们的老师里头，有没有哪一位，你不用看照片，也想得起他上课的样子？想得起来的同学，冲我点一下头。

[等大半个班点过头再往下说；一时想不起来的，提示他往前想，以前教过他的老师也算。]

师：好，都有人。那我先问一件跟你们自己有关的事：假如有人把你写进一篇文章，专挑你身上最扎眼的一处，往大里写——你愿意他挑哪一处？又最怕他挑哪一处？

学生互动分享（举手抽说三四位；教师不评价，只把学生说的两类原样复述一遍）

参考：写我跑得快就行／怕他写我个子矮／写我上课爱走神那就完了／我头发乱，别写这个。

师：你们自己分得很清楚：同样是往大里写，有的写出来你乐意，有的写出来你就不乐意。今天要写的这一篇，写的是老师，这条界一样得守。

师：先听一句。有位老师总把袖子挽到胳膊肘，一年到头没放下来过。这一处往大里写，可以写成这样——“我上了三年他的课，没见他把袖子放下来过，我怀疑那两只袖子是缝上去的。”

参考：（笑）／这个有意思／有点像在编排他。

师：你们笑了，这一句就算写成了。可它到底算不算取笑他？这条界画在哪儿，我们等会儿讲写法的时候专门定。

师：今天这两节课，我们每人用文字给一位老师画一幅画像。画的不是照片那样的像，是漫画那样的像。漫画你们都看过：画一个人，鼻子眼睛不必样样画准，抓住他身上最显眼的那一处，往大里画，别人一眼就认出来了。今天我们用文字来画。写一位你们学校里教过你的老师，现在教你的、以前教你的，都可以。

师：写完，我们就在这间教室里念。听的人有一个难处：你写的这位老师，在座的谁也没见过。他长什么样、是个什么脾气，全在你那几行字上。

师：什么算画成了？念完之后，我请三四位听众各说一句：你从这段话里看见了这位老师身上的哪一处。要是他们说的是同一处，你这幅像就画准了。漫画就是这么回事：一眼认出，而且大家认出的是他身上的同一样东西。什么算没画成？几个人说的全不一样，或者干脆说不上来。那多半是你把他身上五六样都写了一遍，哪一样都没写足。

### 二、观察体验，学一学他上课的样子（约 6 分钟）

师：那位老师你们已经想好了。现在再往细里想一想：他上课的时候，有没有一个常做的动作，或者一句老挂在嘴边的话？

参考：他讲着讲着就把眼镜往上推／他老说“坐正了坐正了”／他喜欢敲两下桌子／他一转身粉笔就在手里转。

师：跟同桌学一学。把他那个动作做一遍，或者用他的口气把那句话说出来。同桌看完只回你一句：你学的这位老师，是个什么样的人。两个人轮着来，各学一遍。

[先说清楚：学的是他上课时最有意思的那个动作、那句话，不是挑他的毛病。看见有学生学的是老师的口吃、走路姿势这类身体上的短处，当场换一个方向问他：“他上课时你最爱看的是哪一个动作？”]

学生互动分享（同桌两两，一人学一遍，听的人回一句；教师走到两三组跟前，做他们的第一个听众）

师：请三位学给大家看。其余同学看完，说一句：你看出他是个什么样的老师。

学生互动分享（举手抽说三位当众学一遍；每一位学完，请一两位同学说自己看出了什么，教师不复述、只点一句他们说到的那一处）

参考：这位老师挺急的／他是不是很爱管纪律／他上课好像很有意思。

师：你们看，刚才那三位一个字都没解释，只学了一个动作、说了一句他常说的话，我们就看出这三位老师不一样了。你们刚才学的那个动作、那句话，就是今天最要紧的材料。等会儿构思的时候还要用它，先记牢。

〔应答·学生说“我们老师没什么特别的动作”〕换三个方向问他：他讲到高兴的地方是什么样子；他要你们安静下来的时候怎么做；他手里除了粉笔还老拿着什么。三个里头总有一个答得上来。

### 三、学写法：一处一段，用一件事把它写足（约 13 分钟）

师：老师这里准备了两段文字，写的是同一位老师。我念给你们听，你们边听边想：哪一段听下来，这位老师的模样能在脑海里清清楚楚地出现。

师：第一段——“我们的语文老师姓周。她个子不高，剪着齐耳的短发，戴一副细边的眼镜，笑起来眼睛弯弯的。她说话不紧不慢，声音很温和，从来没有跟我们发过脾气。她的字写得特别漂亮，一笔一画都很工整，我们都想照着她的字练。她还很爱看书，办公桌上常年摞着一摞书，摞得比水杯还高。下雨天她会站在门口，提醒我们路上小心。她对我们非常关心，是一位好老师。”

师：第二段——“我们的语文老师有个改不掉的毛病：笔一到手，就顺手别在头发上。上个星期改作业，她突然在讲台上翻起来，教案掀了两遍，粉笔盒都倒出来了，嘴里念叨着‘我那支红笔呢’。前排一个同学憋不住，抬手指了指自己的头顶。她一摸，红笔正插在马尾上。全班笑翻，她也跟着笑，把笔拔下来的时候，还带下来一根头发。”

师：你们说说看，哪一段听完，这位老师的模样是清楚的？

参考：第二段。／第一段吧，第一段把她的样子、脾气、爱好都写到了。／我也选第一段，我们平时写人不都是这么写的。

师：说第一段的同学也有他的道理。第一段写得确实不算简单：长相、说话、字、爱好、下雨天怎么做，五六样都交代到了，还写了摞得比水杯还高的那摞书，画面也有。我要问你们一句：读完第一段，你们记住她哪一处了？

参考：记不住／好像哪一样都记得一点／忘了。

师：差别就在这儿。第一段样样都写，一样也没写足，读完像看了一张名单；第二段只写了一处，把这一处写到底，那位老师反倒有了模样。画漫画不能鼻子眼睛平均使劲，写老师也是一样的道理：把五六处平摊开来写，谁也立不起来。你们要做的，是从里头挑出一两处，往大里写。

师：那第二段到底做了几件事，把这位老师写得这么清楚的？我把前面几句再念一遍，你们边听边找。

师：“我们的语文老师有个改不掉的毛病：笔一到手，就顺手别在头发上。上个星期改作业，她突然在讲台上翻起来，教案掀了两遍，粉笔盒都倒出来了，嘴里念叨着‘我那支红笔呢’。前排一个同学憋不住，抬手指了指自己的头顶。她一摸，红笔正插在马尾上。”

参考：它一开头就说了笔别在头发上这件事／后面讲了上星期改作业那一回／写了她说的那句话。

师：你们找出来的这几样，归起来是两条。我先把这两条给你们说清楚。

师：第一条，一处单独写一段，段首先把这一处点出来。第二段头一句就是“她有个改不掉的毛病：笔一到手，就顺手别在头发上”，读的人一上来就知道这一段要看什么。你要写两处，就写两段，一段一处，不要混在一起。

师：第二条，点出来还不算完，后面得跟一件事把它写足。这件事得是只有他才做得出来的那一件——她把粉笔盒都倒出来找一支笔，可那支笔正插在她自己头上；换一位老师，这件事根本发生不了。刚才那一段里，这件事是怎么写出来的？你们数一数，一共写了几样东西。

参考：写了她把粉笔盒倒出来找／她嘴里那句“我那支红笔呢”／她自己也跟着笑，拔笔还带下来一根头发。

师：正好三样。我们就照这三样来叫：他的动作、他说的一句话、他当时的样子。三样都要有。少了动作，这个人在纸上就不会动；他说的话和他当时的样子要是也没写，我们既听不见他，也看不见他。

师：刚上课我们留下一个问题没定：往大里写，这条界画在哪儿。现在来定它。老师这儿有同一件事的三种说法，你们听完排一排。

〔教师示范·同一件事的三种说法，一句一句念给学生听〕第一种：“周老师老是找不着笔。”第二种：“她一开口说‘我笔呢’，全班先抬头看她的头顶。”第三种：“她一个学期能弄丢三十支笔，我们怀疑她根本记不住事。”

师：这三种，哪一种你读着最有意思？哪一种你觉得过头了？

参考：第二种好玩／第三种太夸张了／第三种像在说她记性差／第一种没意思，谁都这么写。

师：你们排得对。第一种是个结论，谁的老师都能安上去。第二种把“笔总在她自己头上”这件真事往前推了一步。全班一听见那句话就抬头看她的头顶，这一下只有她班上才有，读的人笑一下，也认得出她。第三种不一样：一个学期丢三十支是编出来的，“根本记不住事”是往她的短处上说。放大她真做过的事，读的人会觉得有意思。可要是编出没有的事，或者专挑人家的短处放大，那就成了取笑。

师：所以第三条：放大只放大真事。放大之前先自己问一句——这一句我敢不敢当着他的面念给他听。敢念，就是这幅像画对了。

师：拿这三条回头看刚上课那句袖子。他的袖子是真挽着的，一年到头没放下来过，这是真事；说袖子像缝上去的，谁听了都知道是句玩笑话，没往他的短处上说；这一句当着他的面念，念得出口。所以那一句站得住，它是放大，不是取笑。

师：现在你们自己来说一句。想想刚才学的那位老师，还有你学的那个动作，把它往大里说一说。想好了先小声说一遍。

学生互动分享（举手抽说两三位；教师只点一处——他放大的是不是真有的那一样）

〔应答·学生放大到了老师的长相短处，如“他的肚子像装了个球”〕不当众驳回，先接住那一句里真实的部分，再换个方向问他：“他上课时你最爱看的是哪一个动作？把那个动作放大着说给我听听。”

### 四、借助人物特点卡，理清思路（约 10 分钟）

师：真正动笔之前，先把想好的这些落到纸上。这张卡马上发到你们手里。填的时候记住一条：一格里几个词就够，不用写成句子，你自己回头看得懂就行。

| 项目 | 我的关键词 |
| --- | --- |
| 写哪位老师 |  |
| 长相上最显眼的一处 |  |
| 说话或脾气上的一处 |  |
| 上课时的一个习惯动作、一句常说的话 |  |
| 圈定：最突出的一两处 |  |
| 这一两处各配一件什么事 |  |

师：我这儿有一张已经填好的，你们先看看。卡上填的是一位科学老师，姓刘，等会儿你们还会读到写他的那一篇。

| 项目 | 我的关键词 |
| --- | --- |
| 写哪位老师 | 教科学的刘老师 |
| 长相上最显眼的一处 | 十指洗不掉的颜色 |
| 说话或脾气上的一处 | 手上有活就先干完再说 |
| 上课时的一个习惯动作、一句常说的话 | 白大褂两个鼓口袋·随手就掏 |
| 圈定：最突出的一两处 | 那双手·那两个口袋 |
| 这一两处各配一件什么事 | 跟到水池边看他洗手／用铁丝修眼镜腿 |

师：这张卡上的字，跟你们平时写的句子比一比，哪儿不一样？

参考：全是词／一句整话都没有／短得很。

师：没错，每一格几个词就够用，句子留到动笔的时候再写。先把上面四格填了。中间那三格，想得起来的就写，一时写不出来的跳过去也行，要紧的是最下面两格。

学生动笔写作（填上面四格约 2 分钟；教师巡视）

师：第五格，前面三格里你写了三处，这一步自己判一判：哪一处最像他，哪一处换个老师就说不通？把它圈出来，圈一处或者两处，不要三处都圈。三处都圈，就成了刚才那段谁也记不住的话。

〔应答·学生三处都想留、拿不定主意〕不替他挑，问他一句：“这三处里头，哪一处你刚才学给同桌看过？”学过的那一处通常就是最显眼的那一处。

师：第六格，给圈出来的那一处配一件事。这件事不用大，一节课上的一分钟就够，只要是因为他这一处才发生的。写不出来的同学，往这三个方向想：他这一处表现得最明显的是哪一回；因为这一处，班里出过什么事；他这一处让你记到今天，是哪一天留下的。

学生动笔写作（填第五、六两格约 2 分钟；教师巡视，看见第六格空着的问一句上面那三个方向）

师：我想听两位说说。其余同学带着一个问题听：换一位老师来，这件事干得成干不成。

学生互动分享（举手抽说两位；每一位说完，请一两位同学回一句“换个老师干得成干不成”，教师顺势点出他哪一处最值得展开）

### 五、出示示范文，发现写法（约 10 分钟）

师：卡填到这一步，材料就齐了。下面看一篇完整的，写的就是刚才卡上那位科学老师。读的时候留意一件事：卡上那几个词，最后是怎么铺开成一段一段的话的。

> 【教师示范文】
>
> 教我们科学的是刘老师。第一次上他的课，我盯着他的手看了半节课。
>
> 他有两只全年级最脏的手。说脏也不准确，是洗不掉：十个指头上总带着颜色，今天蓝一块，明天紫一道，指甲缝里还嵌着黑。我们私下打赌，他洗手的时候，从指缝里流下去的水一定是彩色的。上个学期有一回，几个同学特意跟到水池边上去看。他一边搓手一边问我们围着干什么，水哗哗地流，清的，一点颜色也没有。他把湿手一举，说：“这不叫脏，这叫化学。”
>
> 除了这双手，他身上第二显眼的是白大褂上那两个口袋。
>
> 那两个口袋从来没有瘪下去过，走起路来两边都往下坠。上课要用的东西他基本不拿箱子装，全在里头：磁铁、放大镜、几节干电池，还有一小卷细铁丝。我们私下说，那两个口袋底下通着实验室。
>
> 上个月讲杠杆，讲到一半，前排一个同学的眼镜腿掉了，低着头在桌上摸。他走下讲台，把那副眼镜拿过去，对着灯先看了看断口，从口袋里摸出那卷铁丝，剪下一小段，就着桌角一圈一圈往镜腿上绕，绕完用指甲把毛刺按平，吹掉铁屑，又把眼镜架到自己鼻梁上试了试，才递回去：“先用着，比原来那个结实。”说完转身接着讲杠杆，剩下的半节课，他一个字也没再提这件事。
>
> 从那以后，我们班有个说法：东西坏了先别急着扔，去问问刘老师的口袋。他那两只手为什么老也洗不干净，我大概也想明白了。

师：我们先整体看一遍。这一篇一共写了这位老师的几处？各写在哪儿？

参考：两处／手写在前头／后面写他白大褂的口袋。

师：一处一段，段首先点出这一处——第二段头一句是“他有两只全年级最脏的手”，第三段单起一句“除了这双手，他身上第二显眼的是白大褂上那两个口袋”。开头一句话摆出写的是谁，结尾一句写自己现在怎么看他。你们这一篇也可以照这个样子搭。

师：再往细看。写手的那一段里，哪一句是放大的？

参考：打赌他洗手流下去的水是彩色的／全年级最脏的手。

师：放大的是真有的事——他手上确实常年洗不掉颜色。可你们注意，他写完这句打赌，紧跟着就写了几个同学真跟到水池边去看，水是清的。放大归放大，他没有让这句假话留在纸上，也没有一句是编排老师的短处。

师：那件修眼镜的事，刚才说的三样东西，你们各找一句出来。

参考：动作是他绕铁丝、按毛刺、吹铁屑／他说的话是“先用着，比原来那个结实”／样子是他把眼镜架到自己鼻梁上试了试。

师：三样齐了。你们再想想：换一位老师碰上这件事，多半会怎么办？

参考：让他先凑合戴着／叫他放学回家找人修／可能就说一句“怎么这么不小心”。

师：多半就是这样。可这位老师口袋里正好有铁丝，也正好肯当场蹲下来给他绕上。所以这件事，别的老师身上发生不了。写老师，最要紧的就是这样一件事。

师：最后各自默读一遍，从里头挑一句：你觉得哪一句写得最像他本人？

学生互动分享（举手抽说三四位；教师把学生挑出的句子逐一收拢，不逐句点评）

师：你们挑出来的这几句，我们放在一起比一比。

| 示范文里的句子 | 这一句在做什么 |
| --- | --- |
| 他有两只全年级最脏的手 | 段首一句就把最突出的那一处点出来 |
| 我们私下打赌，他洗手的时候，从指缝里流下去的水一定是彩色的 | 这一处的放大，读着好笑，可放大的是真有的颜色 |
| 他把湿手一举，说：“这不叫脏，这叫化学。” | 那一处后面跟的事里，他说的那一句 |
| 那两个口袋从来没有瘪下去过，走起路来两边都往下坠 | 第二处也是段首一句点出来，同样挑的是看得见的地方 |
| 我们私下说，那两个口袋底下通着实验室 | 第二处的放大，一句就够，多了就假了 |
| 就着桌角一圈一圈往镜腿上绕，绕完用指甲把毛刺按平，吹掉铁屑 | 那件事里他的动作，一步一步写下来 |
| “先用着，比原来那个结实。” | 那件事里他说的话，短，可换个人说不出来 |
| 又把眼镜架到自己鼻梁上试了试 | 那件事里他当时的样子，也是最好笑的一下 |
| 说完转身接着讲杠杆，一个字也没再提这件事 | 事情收得快，反倒更像他 |
| 东西坏了先别急着扔，去问问刘老师的口袋 | 结尾不夸他，只写现在我们怎么看他 |

师：这一篇写的是刘老师。你们笔下的那一位是什么脾气、跟你们之间有过哪些事，在座只有你自己知道，所以内容不必照着这一篇来。要守住的是三条：一处一段、段首先点出来；后面跟一件只有他才做得出来的事，事里有他的动作、他说的一句话、他当时的样子；放大只放大真事。

师：第一节课就上到这里。你们现在手上有三样东西：定下来的那位老师、圈好的那一两处、配上的那一件事。中间休息一下，回来我们就动笔。

本课完。

## 第2课时 · 当堂写作与评改课

### 一、看着特点卡，写下第一段（约 5 分钟）

师：把特点卡拿出来，看你圈出来的那一处。开写之前先交代一句：起头空两格，用一句话说清楚你写的是哪位老师，就像刚才那一篇开头的“教我们科学的是刘老师”。听你念的人一个都没见过他，这一句不能省。

学生动笔写作

师：下面另起一段，从你圈的那一处写起。先写段首那一句，把这一处点出来。老师卡上圈的是“那双手”，段首那一句就是“他有两只全年级最脏的手”。你那一句该怎么说，想好了就写在下一行。

学生动笔写作

师：接着往下写三四句，一直写到没见过他的人也能对上号。下面有四个方向，你们自己挑着用，先写哪一样、写几句，都由你们自己定：他这一处是什么样的，别人身上没有的是哪一点；他做这个动作的时候，手上、脸上是什么样子；他嘴里常说的是哪一句；你觉得可以放大的，就放大一句。这四样不必写全，哪一样最像他，就先写哪一样。

学生动笔写作

师：笔停一停，把刚写下的这几行从头读一遍。一边读一边问自己：光凭这几行，一个没见过他的人能不能对上号。往下就顺了。接着写那件事：他这一处是在哪一回显出来的，就从那天怎么开的头写起。

### 二、自由写作，把整篇写完（约 23 分钟）

师：接下来的二十分钟，你们一口气把整篇写完，中间不要停。有三件事得记在心里：一处一段，段首先点出来；那件事里，他的动作、他说的一句话、他当时的样子，三样都得有；放大只放大真事。写到最后添一句，说说你现在怎么看这位老师。写的过程中不用回头改字，先一路写到底。

学生动笔写作

[教师巡视，只做正向介入，不纠错字、不改病句、不打断书写顺畅的学生。按学情分四类处理——]

[接不下去型：第一段写完就停下，笔搁着不动——请他把特点卡摆到手边：“这一处你写出来了。第六格上不是配了一件事吗，就写那一回：那天先发生了什么，他做了哪一下。”]

[内容空泛型：整段都是“他对我们很关心”“他是一位好老师”一类的话——先请他把那位老师的一个动作学一遍给你看，再顺着问“他做这一下的时候，脸上是什么样”“上一回是在什么事上做的”，他答出一句，就请他照着这句写下去。]

[书写顺畅型：不打断，走过时轻声一句“接着写”，为其留出书写空间。]

[草草收尾型：两处各写三两句就搁笔说“写完了”、篇幅明显偏短——先肯定再推一步：“他常做的那个动作你已经写出来了，好。那天他做完这个动作说了什么，说完你们又怎么样了？把这两句补上。”]

[临近时间提示：提醒学生把手上这一句写完整再停笔；没写完的，记住自己接下来要写什么，后面还有一段修改时间可以补。]

### 三、交流评议，修改收束（约 17 分钟）

[两轮换人互念（约 4 分钟）：第一轮同桌，第二轮前后桌换人；每人只念一段、约 40 秒；听的人只在稿末写下“看见的那一处”，不评好坏]

师：笔放下。先跟同桌换稿子，各自念一段给对方听。只念你写那一处、写那件事的地方，念四十秒左右就够。听的人不用点评，就在他那张稿纸的末尾写下三五个字——你从他念的这段里，看见了这位老师身上的哪一处。

学生互动分享（同桌两两，一人念一遍，听者在稿末写下一处；教师控节奏，一轮约 2 分钟）

师：换人。前后桌转过来，跟刚才不是同一个人，再念一遍，听的人照样在稿末写下一处。

学生互动分享（前后桌换人，再走一轮，听者在稿末写下第二处；教师提醒念的人不必念整篇，仍念刚才那一段）

师：拿回自己的稿子，看这两个人写的是不是同一处。写的一样，说明你这幅像画准了。两个人都没见过这位老师，光凭你这几行字，看见的是同一样东西。两个人写得不一样，也不用急，等会儿改稿先改这里：多半是你把两三处平摊着写了，得挑一处写足。

[全班念读（约 4 分钟）：三位学生依次念，每人只念写那件事的那一段、约 40 秒；每念完一位请两位听众各说一句，三位都念完再统一比一次]

师：请三位念给全班听。念的人不用念整篇，只念你写那件事的那一段，四十秒左右。台下的同学听完，我请两位，每人说一句：你听出来的是他身上的哪一处。

学生互动分享（三位依次念；每一位念完，教师请两位听众各答一句，随即就着他念的稿子夸一句，夸到具体那一句上：哪一句让台下认出了他。三位都念完，教师把六个答案摆到一起比一次：落在同一处的是哪几位。请听众发言时有意匀开，不重复请同一批同学）

[带标准修改（约 7 分钟）：延迟到此刻统一处理行文与错别字。师话交代约 2 分钟 → 自己改约 2.5 分钟 → 同桌交换、按三档表各指一处约 1.5 分钟 → 补改约 1 分钟]

师：别人的听完了，现在回到自己的稿子上。先对着这张表，看看你写到了哪一档。

| 档位 | 自检的话 |
| --- | --- |
| 画出来了 | 我写的是哪位老师、他最突出的是哪一处，别人读了说得出来。 |
| 画准了 | 那一处后面跟着一件事，事里有他的动作、他说的一句话、他当时的样子。 |
| 画成了一幅漫画 | 有一两句把那一处放大了，读的人会笑一下；放大的都是真事，我敢念给他听。 |

师：动手之前，你们先替我判一句。这儿有两句话，写的是同一位老师：一句是“他对我们要求很严”，一句是“他讲评作业的时候从来不念名字，只把本子举起来，让全班看一眼那一页”。你们更相信哪一句写的是他本人？为什么？

参考：第二句／第一句谁都能写／第二句是他自己才做的。

师：就按刚才这个判法，回自己的稿子上改。改三条：第一，把“他很严”“他很关心我们”这样谁都写得出的话找出一句，换成他真做过的那一件；第二，那件事要是只交代了结果、没写经过，就补上他当时做的一两下，或者他嘴里那句话；第三，看看有没有哪一句放大过了头。编出来的、专说他短处的，划掉。

学生动笔写作（自己对着三条改；教师巡视答疑，正文还差一截的先请他往下写完）

师：笔停一下，跟同桌换稿子。这一回不用通篇挑毛病。对着刚才那张表看一看，他停在哪一档，然后在他稿子上指出一处——要往上走一档，还差的是哪一句。指一处就够。

学生互动分享（同桌交换，各在对方稿上指出一处；教师巡视，听见泛泛说“写得挺好”的，请他指到具体哪一行）

〔应答·同桌指不出可改处〕给他一个更小的问题：“他写那件事的时候，那位老师说的话在哪一句？找不着，就是这儿还缺。”找得着的，再问一句“那位老师当时是什么样子，他写了没有”。

师：拿回自己的稿子，把同桌指的那一处补上。补完，稿子上的字再理一遍：写错的改过来，漏掉的补上，多出来的圈掉，用我们平时的修改符号。

学生动笔写作（补改；教师巡视答疑）

[收尾（约 2 分钟）]

师：今天这些稿子上，一幅画也没有。可刚才几位一念，台下的同学马上就说得出他身上的哪一处：一句常说的话，一个常做的动作。这就是漫画的本事：不必样样画准，抓住那一处，人就认得出了。

师：还有一句话，今天讲过一回，出了这间教室也照样管用：放大之前先问自己敢不敢念给他听。写的是他真做过的事，就敢念。稿子自己收好。

（教师总结）今天这个办法，往后写谁都用得上：先在他身上挑一两处别人身上没有的，一处写一段，段首点出来，后面跟一件只有他才做得出来的事，把他的动作、他说的话、他当时的样子写下来。一个人身上的事写不完，也用不着都写。挑准那一处写足，读的人反而更认得出他。

本课完。

全课完。

## 附：习作讲评指导环节（可选 · 单次课课后用 / 系列课作下次课开场用）

> 本环节供老师灵活取用：可在单次课课后批读学生习作后集中讲评一次，也可作系列课下一次课的开场（约 15–20 分钟）；不计入本课 45+45 分钟，评的是学生当堂完成的稿子，不布置新的写作任务。
> 讲评中凡出现 ＿＿＿ 处，务必换成本班学生习作里的真实句子，切勿虚构。

### 选稿（课前准备）

从本班当堂完成的稿子里挑 2–3 篇，对着本课三条技法各挑一类：一篇“三条都做到了”的（一处一段、段首点出来，事里动作与话都在，放大的是真事）；一篇“事写出来了、可两三处平摊着写”的中等篇；一篇“通篇是评价、看不出他哪一处特别”的待改进篇。每篇用一句话对着技法记下它好在哪、欠在哪。讲评时投屏或朗读，不具名、不排名次。

### 讲评流程（每篇约 3–5 分钟，围绕本课技法点）

师：上次课我们念了几篇，听的人只说一句：从这段话里看见了这位老师身上的哪一处。今天回头看三篇稿子，看的还是这一条——没见过这位老师的人，读完能不能说出他身上的哪一处。其余的问题今天先放一放。

师：先看第一篇。他那一段开头一句是——“＿＿＿”（念该生段首点出那一处的那句话）。一句话下去，我们就知道这一段要看什么了。

师：后面那件事，他写了这么几句——“＿＿＿”（念该生写这件事里动作与话最见样子的一两句）。这几句里有他的动作，也有他说的一句话。有了这两样，我们没见过他，也认得出他了。

（教师总结）第一篇三条都在：一处一段、段首点得清楚，事里有动作有话，放大的那一句也是真事。

师：第二篇的事情选得准，你们听这一句：“＿＿＿”（念该生写事最具体的一句）。可他前半篇一口气写了好几处：“＿＿＿”（念该生把两三处平摊着写的那几句）。这几处一样长，读完反倒不知道该记住哪一处。

师：那要怎么改？

学生互动分享

师：对，留一处，把留下的这一处往下写足，剩下的删掉或者一笔带过。第二篇缺的不是材料，是舍不得删。

师：第三篇不说是谁写的，我只念其中一句：“＿＿＿”（念一句典型的只有评价、看不出所以然的话）。这一类句子，班里不止一张稿子上有。大家判断一下：把这一句放到别的老师身上，说不说得通？

学生互动分享

师：说得通，那这一句就还没写到他身上。补一件他真做过的事，哪怕只是一节课上的一分钟：他当时做了什么，说了哪一句。补上以后，这句评价留不留都不要紧了。

（教师总结）这三篇各有各的情况：第一篇三条都在；第二篇差在没挑，几处都舍不得删；第三篇差在只有评价、没有事。

### 收尾（点回技法、引向今后的写作）

师：讲了三篇，来回还是那三条：挑一两处，一处一段、段首点出来；后面跟一件只有他才做得出来的事；放大只放大真事。往后写你家里的一位长辈、写你的一个同学，也是这么办：先找出他身上别人没有的那一处，再找出跟这一处对得上的那一件事。改好以后，稿子自己留着。

本环节完。
