# 《变形记》· 写作课教学设计
六年级上册·第一单元 校内同步写作（想象习作）

## 教案提纲表

| 课题·课时 | 六上·第一单元《变形记》　│　想象·校内同步　│　2课时连排（每节45分钟） |
| --- | --- |
| 能力阶段 | 写清楚 → 写具体 → 写生动 → 写深刻·有章法（本课） |
| 同类习作顺序 | 想象：续写故事／编童话 → 奇妙的想象／这样想象真有趣 → 我和＿＿过一天 → 奇思妙想 → 故事新编／二十年后的家乡 → 神奇探险 → 变形记（本课）／笔尖流出的故事 → 插上科学翅膀 |
| 教材要求 | 统编六上·第一单元习作：以变形后的视角展开想象，写出新奇的体验。 |
| 学习目标 | 通过站到变形后那件事物的位置上去看、去感受，来学习怎么写一篇想象故事。 |
| 核心技法 | 使用“变形构思表”。先定下自己变成什么、变了以后有多大、在哪里、做得到什么、做不到什么；再挑一件只有它才会遇上的事，把这一件写详细；末了留下一句心里的话。 |

## 第1课时 · 写作指导课

### 一、创设情境，明确任务（约 6 分钟）

师：同学们，请先想一件事，想清楚了举手告诉我。假如今天早上你一睁眼，发现自己只有一支笔那么高，还躺在自己的床上，你遇到的第一个麻烦会是什么？

学生互动分享

参考：下不了床。／被子太重了，掀不开。／我的书包比我还高。／喊人也没人听得见吧。

师：你们说的这几样，全是平时不用操心的事：被子有多重、床有多高、说话的声音有多大，我们谁也没想过。可是身量一变，它们一下子都成了要紧事。请你们再往下想一想：如果这一个上午你都得这么过，你眼里的这间屋子，还是原来那间屋子吗？

学生互动分享

参考：不是了。桌子腿像柱子一样。／地板一下变得好远好远。

师：其实这样的想象，就印在你们语文书上。这个单元的习作，题目叫《变形记》：让我们想象自己变成另一种事物，可以小到一只蚂蚁、一棵草、一粒石子，也可以大到一头大象、一辆汽车，甚至是一个星球。变形以后，你生活的世界也跟着变了样。

师：今天两节课，我们每个人写一篇变形以后的故事，写完开一场分享会。分享会有一条规则：念的人不许说出自己变成了什么，只念其中写得最详细的那一段。听的人光凭这一段，要说出两件事：第一，说话的这个“我”是什么；第二，是哪一句让你认定的。听的人说得出来，你这一篇就写成了。

师：写完还有一件事：稿子要在同桌手里过一遍，看一看有没有哪一句露了破绽。所以今天你写的这一页，至少会有一位同学从头到尾读一遍。

### 二、观察体验，换一个位置看世界（约 7 分钟）

师：先不急着定你要变成什么。我们先做一件很小的事：请把下巴放到桌面上，让眼睛和桌面一样高，就从这个高度往前看一看。看三十秒，然后告诉我，从这个高度看出去，哪一样东西跟你平时坐着看的不一样了。

[教师同步俯身示范一次，留约三十秒，提醒学生看具体的一样东西，不要说“都不一样了”]

学生互动分享（举手抽说三四位，注意覆盖面，不只请常发言的学生）

参考：铅笔一下变得好长。／桌子那一头看不见了。／橡皮把我的水杯挡住了。／笔袋像一座小山包。

师：请注意，你们并没有走出这间教室，也没有换一样东西来看，只是眼睛低了三十厘米：原来看得见的，被挡住了；原来不起眼的，忽然挡在了最前面。这就是变形以后发生的第一件事：屋子还是这间屋子，但是你看它的位置换了，看见的东西就跟着换了一批。

师：接着往下推一步。假如你现在只有一粒米那么大，就站在自己这张桌子上：这支笔、这块橡皮、桌面上那道缝，在你眼里各是什么？请一列同学每人说一样东西，说过的不再重复。

学生互动分享（开火车，一列每人一句）

参考：笔是一根倒着的电线杆。／橡皮是一块大石头，我推不动。／那道缝是深沟，我会掉下去。／水杯是一口井，井口比我还高。

（教师总结）身量一变，你身边这些东西的大小、用处、危不危险，全跟着变。这些跟着变了样的东西，就是接下来要写进你故事里的东西。

### 三、学写法：站到它的位置上，用“我”来说（约 14 分钟）

师：动笔之前，先把这道题看清楚。老师这里有两段话，写的都是“我变成了一把伞”。请你们判断，哪一段真写对了这道题。

师：第一段：“雨点噼里啪啦地砸下来，整条街一下子模糊了。我被撑开在雨里，看见远处的高楼罩在灰蒙蒙的雨雾里，路两边的梧桐叶被打得直往下垂。人们低着头匆匆走过，有人小跑着躲到屋檐底下。我心想，这场雨来得真急，可雨里的城市也真好看。”

师：第二段：“哗的一声，我被撑开了。四十几根伞骨一根根绷直，绷得我浑身发紧。雨点砸在我背上，一下接一下，像有人在我头顶擂鼓。我底下只看得见一颗黑脑袋，和一双踩进水洼里的球鞋。风从侧面撞过来，我整个人往后仰，那只攥着我的手立刻紧了紧，那手心是热的，还有点汗。”

师：这两段话，哪一段里说话的真是那把伞？

学生互动分享

参考：第二段。／我选第一段，它把那场雨写得挺全的。

师：选第一段的同学，请你说一说：第一段哪一点让你觉得它对？

学生互动分享

参考：它把雨、街、树、行人都写到了，读着眼前有画面，我们平时写下雨不都是这么写的。

师：这几点你们都注意到了。那我再问一句：第一段里写“看见远处的高楼”“路两边的梧桐叶”，一把撑开的伞，能看见这些吗？

学生互动分享

参考：看不见吧，它上头是雨，底下是人的脑袋。／它只看得见自己底下那一点。

师：所以第一段写的是一个撑伞的人看见的东西，不是伞看见的东西；到了最后一句“我心想这场雨来得真急”，说话的已经完全是那个人了。第二段不一样：伞骨绷直、雨点砸在背上、底下一颗黑脑袋和一双球鞋、手心是热的，句句都要站在那把伞的位置上才写得出来。

师：这道题的要求就在这里：不是写“我看见一样东西变了形”，是你自己变成了它。从头到尾用“我”来说，而且你说的、看的、做的，都必须是它做得到的。这就是今天第一个写法：站到它的位置上，用“我”来说。

师：这个写法不是老师想出来的。你们这个单元有一篇《花之歌》，纪伯伦通篇让一朵花自己开口：花做的事、看见的东西，全是一朵花做得到、看得见的。它随着季节醒来又凋谢，白天迎着光，夜里望着星星，喝的是露水，听的是鸟叫。作者一次也没有跳回来替它解说。

师：不过只靠这一条，还不够准确。老师念一段话，先不告诉你们说话的这个“我”是什么。你们听完回答两件事：第一，我是什么；第二，是哪一句让你认定的。

〔教师示范·当场念一段不点明身份的话〕早上七点半，我被人一把攥住，攥得发烫。他手心里全是汗，我在里面滑了半圈。接着我被举到半空，眼前忽然一亮，一个方方正正的小口子正对着我。他手一松，我从那道口子里跌了进去，沿着一条冰凉的铁槽子往下滚，咣当，咣当，撞了三四下，撞得我眼前发花。到底了，我卡在一道窄缝里，上不去，也下不来。头顶上咚咚响了两下，有人在拍我上面那块玻璃。

学生互动分享

参考：硬币。／是一块钱吧，投到那个卖饮料的机器里了。／我猜是硬币，被人攥着，后来投进去了。

师：你们靠的是哪几句认出来的？

参考：被人一把攥住、手心有汗。／从那个小口子跌进去、在铁槽子里往下滚。／还有卡住了，有人拍玻璃。

师：请注意，这段话里老师一次也没有写“硬币”两个字，也没写它是圆的、是一块钱。你们能认出它，靠的就是这几件事：被攥住、从投币口跌下去、在铁槽里翻滚、卡住。这几件事只有一枚硬币遇得上；换成一支笔、一块橡皮，这几句话一句也用不上。

师：回过头看你们上课时说的那几样，像下不了床、掀不开被子、书包比人还高，也是这一类：只有变小了才会碰上的麻烦。现在这个问题交给你们：想一想你打算变成的那样东西，它会遇上一件什么事，是别的东西都遇不上、只有它才碰得着的？先各自小声说给自己听一遍，再说给大家听。

学生自由分享

参考：我变成一把钥匙，被人插进锁孔里转了两圈。／变成一只风筝，线断了，我一直往上飘。／我要变成小区那部电梯，一天上上下下几百趟。

〔应答·学生说的那件事换成别的东西也成立〕学生若答“我变成小鸟，飞到天上看风景”，先肯定他选定了对象，再追问一句：“变成风筝、变成气球，是不是也能飞到天上看风景？有没有一件事，是只有一只鸟才碰得上的？”把学生的思路引到只属于这个身份的那件事上。

师：这就是今天第二个写法：从这些事里挑出一件当作重点，把这一件写详细，其余的一两句交代过去。一篇变形故事，读的人过后记得住的，往往就是被你写足的那一件事。

师：《花之歌》那朵花也是这样：作者没有把一朵花的一年从头记到尾，写的只是它做得到的那几件事。今天你们这一篇，用的就是这两条写法：站到它的位置上说话，再挑一件别的东西碰不上的事写足。

### 四、借助变形构思表，理清思路（约 9 分钟）

师：现在把你要变成的那样东西定下来。定的时候有一条要求：挑你真见过、真熟悉的东西。你天天见它，才写得出它身上的细节。

[发放“变形构思表”，每人一张。教师提醒：拿不定主意的学生，从自己书包里、教室里、上学路上三处各找一样东西，选其中最熟悉的一样]

师：定好了，我们用一张表把思路理一理。这张表一共五栏，每一栏只填几个词，不写整句。老师先填一张给大家看，填的就是刚才那枚硬币：

| 要想清楚的 | 我填的关键词（每栏几个词，不写整句） |
| --- | --- |
| 我变成了什么 | 一元硬币 |
| 变了以后：多大·在哪里·做得到什么·做不到什么 | 指甲盖大／外套口袋里／不会动，只能被人拿 |
| 从这个位置看出去，哪几样东西变了样（挑两三样） | 布纹像沟／饼干渣／伸进来的手指像吊车 |
| 只有它才会遇上的那一件事 | 被投进投币口，卡住了 |
| 末了心里的那一句话 | 又回到布纹里，等下一趟 |

师：第二栏里那句“不会动，只能被人拿”，请大家留意。填这一栏的时候，除了填它做得到的，也把它做不到的填上一两样。变形以后哪些事你做不到，往往比你做得到什么更有意思。

师：再看最后一栏。老师填的是“又回到布纹里，等下一趟”。这枚硬币没有说自己高兴不高兴，说的是它心里正转着的念头。你那样东西经过第四栏那件事以后，心里会转着什么？填这一栏，就填它心里正想的，不填“我明白了一个道理”。

师：现在轮到你们了。五栏里，第四栏最要紧，就是接下来要写详细的那一件事，填完把它圈起来。第四栏和第五栏这两栏都要填上，中间那几栏一时填不出来的，可以先空着。

学生动笔写作

[教师巡视，重点看两处：第一，第二栏有没有写出“做不到的事”；第三栏是不是还停在“变小了”“变大了”这种笼统的说法，若是，提示学生落到具体的一样东西上。第二，第四栏那件事是不是只有这个身份才碰得上；第五栏空着的，提示学生写它心里正想的]

师：填好的同学，和同桌交换，看一看对方的表。看的人只回一句话：他第四栏那件事，换成别的东西碰不碰得上？碰得上，就请他回到表上再换一件事。

学生互动分享（同桌两两互看构思表）

（教师总结）一张表填下来，你变成什么、看见什么、遇上什么、末了想说什么，就都有了着落。

### 五、出示示范文，发现写法（约 9 分钟）

师：表都填好了。最后，老师把自己这张表变成一篇完整的文章，给大家做个示范。请一边默读，一边拿笔画出几句：你觉得只有那枚硬币才写得出来、换成别人、换成别的东西都写不出来的句子。

> 【教师示范文】
>
> 　　我是从一阵天旋地转里醒过来的。
> 　　醒来的时候，我躺在一片布纹里。那些布纹一道一道，深得像田埂之间的沟，沟底积着饼干渣和一小团线头。我想翻个身，翻不动：我这时候只有一个指甲盖那么大。头顶那道口子透进一线光。我只能等。
> 　　早上七点半，一只手伸了进来。五根手指头在我头顶张开，像一台吊车，罩得整片布纹都黑了。他一把把我攥住。手心里全是汗，我在里面滑了半圈，被攥得发烫。
> 　　我被举到半空。眼前忽然一亮，一个方方正正的小口子正对着我，口子里面黑洞洞的。他的手一松，我跌了进去。
> 　　里面是一条冰凉的铁槽子。我贴着槽壁往下滚，咣当，咣当，一路撞过去，撞得我眼前发花。我拼命想停住，可是我没有手，也没有脚，连翻个身都由不得自己。铁槽子拐了个弯，我一头栽下去，卡住了：一边是槽壁，一边是一道窄缝，上不去，也下不来。
> 　　外面安静了两秒。接着，咚咚咚，有人在拍我头顶上那块玻璃，拍得整条槽子都在响。又过了一会儿，机器咔哒一声，槽子底下松开了。我从那道缝里滑出来，掉进一个浅浅的方盒子里，滚了半圈，面朝上停住了。
> 　　那只手又伸过来了。这一回它捏得很轻，把我从盒子里拈起来，在袖口上蹭了蹭，蹭掉我身上那层灰。我又被塞回了那片布纹里，落在饼干渣和线头中间。
> 　　他抬脚往前走。我跟着一颠一颠，贴着他的腿，能听见他在哼歌。布纹底下还是黑的，可是这一回我知道，等他下次把手伸进来，我又要出去一趟了。

师：读完了。先请几位同学说一说：你画的是哪一句？

学生互动分享（举手抽说四五位，教师就着学生报出的句子逐句点明写法）

师：大家说的这几句，老师整理成一张表，每一句凭什么只有它写得出来，一看就明白：

| 示范文里的句子 | 这一句只有它写得出来 |
| --- | --- |
| 那些布纹一道一道，深得像田埂之间的沟 | 身量小到指甲盖，布纹才成得了沟（打比方） |
| 五根手指头在我头顶张开，像一台吊车 | 从口袋底下往上看，才看得见这样一只手 |
| 我没有手，也没有脚，连翻个身都由不得自己 | 写它做不到的事 |
| 咣当，咣当，一路撞过去，撞得我眼前发花 | 听得见的声音，加上身上的感觉 |
| 有人在拍我头顶上那块玻璃 | 人在机器外面，它在机器里面 |

师：接下来看第二个问题：这一篇一共八段，哪一段最长？

学生互动分享

参考：写在铁槽子里那一段最长。／掉进去以后那两段。

师：对，最长的是掉进去以后、在铁槽子里翻滚到卡住那一段。前面写醒来、写被攥住，都比它短得多，几句就带过去了。这就是刚才说的第二个写法：挑一件只有它才遇得上的事，把这一件写详细，别的地方交代一句就过去。你们语文书上这一单元的习作要求，写的也正是这一条：把重点部分写得详细一些。

师：还有一个问题：这一篇里，这个“我”有没有哪一句变回了人？

学生互动分享

参考：没有。／它一直在被拿、被投、被卡住，自己动不了。

师：最后看结尾那一句：“等他下次把手伸进来，我又要出去一趟了。”这是它心里的一句话。老师没有写“我觉得很幸福”“我明白了一个道理”，只写了它心里想的这一件事，读的人自己能品出味道来。你们那张表的第五栏，写的就是这样一句话。

师：休息回来我们就动笔。请先收好你的变形构思表，下节课见。

本课完。

## 第2课时 · 当堂写作与评改课

### 一、自由写作，写完这一篇（约 29 分钟）

师：请把上节课那张变形构思表拿出来，摆在稿纸旁边。先看第四栏，就是你圈起来的那一件事。

师：这一篇不一定要从“我怎么变的”写起。老师给大家三个可以起笔的地方，你自己挑一个。第一个，从醒来那一刻写起，先交代自己成了什么、有多大、在哪里；第二个，直接从你圈的那件事当中写起，比如老师那一篇，如果从“我跌进那道口子”起笔，一样成立；第三个，从第三栏那两三样变了样的东西写起，一开头就把这个新世界摆在读者眼前。挑好了，就在表上给它标一个“1”。

师：再想一想：这一篇里哪一处你最有话说、该写得最厚？多半就是第四栏那件事。就从你标了“1”的那一处落笔，先把这一处写下来，前后怎么接，等一下再说。写的时候不要停下来查字，也不要回头改字，一口气把这一处写完。

学生动笔写作

师：（约三分钟后）请先停一下笔，抬头听一句。你刚才写的这一段，如果写的是那件事的中间那一段，它就落在你这一篇的中间，前面还要补一小段，交代你是怎么变的、变成了什么；如果你是从醒来写起的，那它就是开头，接着往下写就行。

师：接着往下写，把整篇写完。往下写的时候盯住两件事。第一，从头到尾用“我”，不要中途跳回来替它解说，这是这道题的规则。第二，你圈的那一件事写详细：它是怎么开始的、当中最要紧的那一下你身上是什么感觉、后来是怎么收尾的，一步一步写下去；别的地方一两句交代过去就行。加上刚才写的那一段，我们一共写二十五分钟左右。

学生动笔写作

[教师安静巡视。初稿阶段只做正向引导，不当场纠正错别字、不改格式、不打断思路。此时每位学生手上已有自己挑定的那一段，本环节是顺着它往下写、把整篇补齐。按学情分类提示：]

[接不下去型：写完自己挑的那一处就停住]：把学生引回构思表，问的是顺序不是素材：“你表上还有哪两栏没写？第二栏里那几样它做不到的事，接在这一段后面顺不顺？”
[内容空泛型]：引导落到具体的感觉上：“‘我觉得特别新奇’这一句可以留着。再往下添几句：你在那个位置上，眼前是什么、身上什么感觉、耳朵里什么声音？添完自己读一读，看哪一种更能把人带进那个位置。”
[书写顺畅型]：不打断，留出安静的书写时间，只轻声肯定一句：“写得不错，接着往下写。”
[草草收尾型：那件事只写了两三句就停笔]：先肯定，再追问把这件事写下去：“这一件你只交代了结果。它是怎么发生的？当中最要紧的那一下，你再补几句。”

师：（临近收束）写完的同学，自己小声读一遍，看看是否通顺；没写完的不用赶，停在一个句号上，记住下一句要写什么。

### 二、交流评议，修改收束（约 16 分钟）

师：请停笔。第一件事，请和同桌交换稿子。读的时候只做一件事：找一找有没有哪一句，说话的又变回了人。比如站到了它看不见的地方，或者说出了它不可能知道的事。找到了，就在那一句旁边画一道横线，还给同桌；一句也找不出来，就在稿子最后写上“一句也没有”。

学生互动分享（同桌两两交换默读，各在对方稿上标注）

师：请拿回自己的稿子，看一看同桌有没有画上横线。被画上横线的那一句，先不急着改，记住它，等一下第一个就改它。

师：下面开分享会。请三位同学念一念自己写得最详细的那一段，只念这一段，不要说出你变成了什么。听的同学准备回答两个问题：第一，说话的这个“我”是什么；第二，是哪一句让你认定的。

学生互动分享

[每位学生念完，请两位听众各答一句，一句答“我”是什么，一句答凭哪一句认定。两问都答得上，说明这一段的位置站住了；答得出是什么却说不出凭哪一句，提示这位学生回去把那几样只有它才碰得着的细节再添一笔。三位学生的答案不作横向比较，也不评名次]

师：接下来对着三条标准，看一看自己这一页写到了哪一档。

| 我写到了哪一档 | 对着稿子自己看一看 |
| --- | --- |
| 第一档 | 我写出了自己变成什么、遇上了一件什么事，这件事有头有尾。 |
| 第二档 | 从头到尾都是“我”在看、在听、在想，中间没有变回人；那一件事比别处写得详细。 |
| 第三档 | 我写的那几样，只有变成它才看得见、才碰得着；末了那句心里话，是从这件事里来的，不是硬贴上去的。 |

师：看完就开始改，改三处。第一处，同桌画横线的那一句，或者你自己觉得最像一个人在旁边说话的那一句，把它改成站在它的位置上说的话；顺手把多写的字划掉、漏的字补上、写错的字改过来。第二处，看你那件重点的事够不够详细，不够就添两句，添的是当时的声音、动作和你身上的感觉。第三处，看你这一篇末了那句心里话：它是不是从这件事里来的？如果写的是“我明白了一个道理”，就换成它心里正想的。今天不求一次改到完美，把前两处改到位就可以。

学生动笔写作

[教师巡视，重点帮助两类学生：一类是通篇写的还是旁观者看见的东西，帮学生找出一句改起；一类是重点那件事只有结果，帮学生把当中最要紧的那一下补出来]

师：（收尾）改好的同学，把这一页收进自己的本子里。今天没有轮到上台念的同学，如果愿意，回家可以把你写得最详细的那一段念给家里人听一听，看他们能不能听出你变成的是什么。这不是作业，愿意念就念。

（教师总结）变形以后怎么写，今天练的就是两条：站到它的位置上，从头到尾用“我”来说；挑一件只有它才遇得上的事，把这一件写详细。下课。

全课完。

## 附：习作讲评指导环节（可选 · 单次课课后用 / 系列课作下次课开场用）

> 说明：本环节不计入两节连排的 45＋45 分钟，是供授课教师灵活取用的讲评指导环节。教师可在课后通读全班习作后另找时间集中讲评一次，也可在下一次写作课开场用约 15 分钟，先讲评再进入新课，由教师按实际情况安排。
>
> 真实性提示：下面师话中凡 ＿＿＿ 处，务必换成本班学生这一次习作里真实写出的句子。

### 选稿（课前准备）

教师课后通读全班习作，挑出两到三篇代表作，覆盖不同层次，不只挑写得好的：

一篇较好的：通篇站在变形后那个位置上说话，重点那件事写得详细，读的人一听就知道他变成了什么。
一篇中等的：位置基本站住了，但那件事只交代了经过，没有写足；或者选的事换成别的东西也碰得上。
一篇有典型问题的：中途变回了人——写的是一个人在旁边看着这样东西，或者说出了它不可能知道的事。

[操作：把选中的几篇誊清或拍图投屏；不具名，或先征得学生同意]

### 讲评流程（每篇约 3–5 分钟，围绕本课技法点）

讲评只对着这节课教的两条：一是这个“我”从头到尾有没有站住；二是那件重点的事，挑得准不准、写没写详细。别的毛病这一次不铺开讲。每一篇都先肯定一处写得好的，再点一处可改的地方。

师：第一篇，请大家先听这一句：＿＿＿（读该生最像那个身份的一两句）。它好在哪里？好在这句话里的＿＿＿（点出该生用的具体细节，如某个只有那个位置才看得见的东西、某种换了别的东西就没有的感觉），换成一个人站在旁边，是写不出来的。

（教师总结）这就是我们那节课练的第一条：站到它的位置上，用它做得到、看得见的东西来说话。

师：第二篇，位置站得很稳，还差一步。他挑的那件事是＿＿＿（摘出该篇的重点事件），但是这件事只写了两三句就过去了。我们一起帮他想一想：这件事发生的时候，他身上是什么感觉，耳朵里是什么声音，眼前是什么？

学生互动分享

（教师总结）挑准了事，还要把这一件写足。别的地方一句带过没关系，重点那一段要让读的人跟着经历一遍。

师：第三篇，老师想请大家一起看一个地方：＿＿＿（读出该篇中途变回人的那一两句）。请你们判断，说这句话的，是那样东西，还是一个站在旁边的人？他应该怎么改，才是从它那个位置说出来的？

学生互动分享

### 收尾（点回技法、引向今后的写作）

师：今天讲评的这几篇，好就好在用上了那节课的两条写法：这个“我”一句也没有跳出来，还挑了一件只有它才遇得上的事写详细。往后再写想象类的文章，遇到要换一个身份来写的时候，第一件事仍旧是先问自己：站在它这个位置上，我看得见什么，做得到什么，做不到什么。

本环节完。
