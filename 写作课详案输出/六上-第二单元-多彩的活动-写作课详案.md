# 《多彩的活动》· 写作课教学设计
六年级上册·第二单元 校内同步写作（记事习作）

## 教案提纲表

| 课题·课时 | 六上·第二单元《多彩的活动》　│　记事·校内同步　│　2课时连排（每节45分钟） |
| --- | --- |
| 能力阶段 | 写清楚 → 写具体 → 写生动 → 写深刻·有章法（本课） |
| 同类习作顺序 | 记事：那次玩得真高兴 → 看图画，写一写／中华传统节日 → 生活万花筒／心儿怦怦跳 → 我学会了 → 那一刻，我长大了 → 多彩的活动（本课）／围绕中心意思写／传承好家风 → 家乡的风俗／让真情自然流露／心愿 |
| 教材要求 | 统编六上·第二单元习作：点面结合写活动，写出场面与感受。 |
| 学习目标 | 通过点面结合写场面，来学习怎么写一次活动的记事习作。 |
| 核心技法 | 使用“场面定格表”。先按顺序把活动过程理成几步，选出印象最深的一步定格；写这个场面时先写“面”，整个场面看到的和听到的，再落到“点”，一两个人的动作、神态、语言，各是各的样子；最后跟着这个场面写一两句体会。 |

---

## 第1课时 · 写作指导课

### 一、创设情境，明确任务（约 6 分钟）

师：上课。请大家先想一件事：这一年里参加过的活动当中，哪一次到现在你还记得当时的声音？是哨声，是加油声，是掌声，还是别的什么声音？想到了就说一说，是哪一次活动，什么声音。

学生互动分享

参考：运动会，四百米最后一圈全班都在喊／拔河，绳子中间的裁判吹哨子／朗诵会，我们一起读到最后一句，底下鼓掌／研学去插秧，脚踩在泥里的声音／去敬老院，屋里很静，只有一位老爷爷一直在咳嗽。

师：大家说的这些活动，老师一场也没在场。这个班的同学来自不同的学校、不同的班级，你说的那一场拔河，坐在你前后左右的同学多半也没在场。老师还发现一件事：平时听人讲一场活动，往往只能听到“特别热闹”“特别激动”，追问一句到底热闹成什么样，讲的人就说不上来了。今天要做的，就是把你参加过的一次活动写下来，写给没在场的人读，让读的人像自己也在场一样。

师：这个题目就印在语文书第二单元的习作里，叫《多彩的活动》。请看投屏。

[投屏出示教材习作页题面与两幅图（左图是操场跑道上的拔河比赛，右图是水田里的插秧）。教师读题面：“祖国在我心中”朗诵会、学校运动会、“六一”儿童节演出，田间劳动、端午节看赛龙舟、看望孤寡老人，这些校内外活动，你参加过哪些？再读三条要求：写清楚活动过程，把印象深刻的部分作为重点来写；写活动的场面时，既要关注整个场景，也要注意同学的表现，写一写他们的动作、语言、神态；把活动中的体会写下来。]

师：教材说得很清楚：选一次活动写下来，和同学分享你的经历。两幅图，一幅是校内的拔河，一幅是校外的插秧，校内校外的活动都可以写。这篇习作从一开始就是写给人读的。第二节课写完以后，稿子会传给一位没在场的同学读，读的人要在你的稿子末尾写两行：第一行，他读完看见了一个什么样的场面；第二行，他记住了你写的哪个人，那个人在干什么。这两行他写得出来，你这次活动就写成了；如果他只写得出“很热闹”，说明那个场面还留在你的脑子里，没有到纸上。

### 二、观察体验，回到那一刻（约 7 分钟）

师：先定下写哪一次。请每人在稿纸的右上角写下活动的名称，刚才说过的可以照写，也可以换一次更有话说的。想不起来的，可以从投屏上教材列出的这几项活动里选：朗诵会、运动会、儿童节演出、田间劳动、看赛龙舟、看望老人。

[学生写活动名称，约半分钟。]

师：写好了活动名称，现在请把这次活动里印象最深的那一刻找出来。这一刻可能是最紧张、最热闹的，比如哨声响的那一秒、轮到你上台的那一秒；也可能是最安静的，比如敬老院里一屋子人都不说话的那一秒。找到了以后，回答四个问题，每个问题只在稿纸角上写几个关键词，三五个字即可。第一问：那一刻，你听得最清楚的一个声音是什么？第二问：那一刻，你往四周看，最多的是什么，是人、是旗子，还是水？第三问：那一刻，你自己的手、脚、嗓子在干什么？第四问：那一刻，你眼睛盯着的是谁，他在干什么？

[投屏出示四问，学生写关键词，约 2 分钟。教师巡视，看到第四问空着的，提示该生：那一刻你正对面站的是谁，或者离你最近的是谁。]

师：请两位同学到前面来，摆出你那一刻的姿势，保持十秒钟不动：拔河的就摆拉绳的样子，插秧的就弯下腰，朗诵的就抬头站好。其余同学看着他们，说出你看到的一个动作和一个神态。

学生互动分享

参考：他身子往后仰，脚蹬着地／他咬着牙，脸都皱起来了／她两只手垂着，手指头攥得紧紧的／他弯着腰，头一直低着看地。

师：很好，这就是把一个人的样子说出来：动作是身子后仰、脚蹬地，神态是咬牙、皱着脸。请刚才摆姿势的两位把大家说的记到稿纸角上，其余同学也给自己第四问里的那个人补一个动作词、一个神态词。再请两位同学说一说，你第二问和第四问各写了什么。

学生互动分享

参考：四周最多的是人，两边站满了人；我盯着班长，他站在旁边喊“稳住”／最多的是水，一大片；我盯着农民伯伯的手，他一按一退。

师：大家在稿纸角上记的，有那一刻的四周，也有那一刻的一个人。一次活动写下来该是什么样子，请先看下面这两段话，看完由大家来判断。

### 三、学写法：点面结合写场面（约 12 分钟）

师：老师用投屏上那幅拔河图写了两段话，两段写的都是拔河比赛。请大家读一读这两段，判断哪一段符合这次习作的要求。

[投屏出示两段，均为教师自拟。]

第一段：哨声一响，我两只手死死攥住绳子，绳子上的毛刺扎进手心里。我把脚跟往后一蹬，身子往后仰，鞋底在跑道上蹭出两道印子。绳子一点一点往对面滑，我的手心磨得发烫，胳膊酸得抬不起来。我咬着牙，心里只有一个念头：不能松手。

第二段：哨声一响，操场上几十个人一齐喊了起来，两边的加油声撞在一块儿，分不清是哪个班的。绳子中间那根红布条一会儿往左一会儿往右，两队人全都仰着身子，鞋底在跑道上蹭出一片沙沙声。排在最后的大个子把绳子在腰上绕了一圈，脸憋得通红，一步一步往后挪。班长站在队伍旁边，两只手往下压，一声一声地喊：“稳住！稳住！”红布条一点一点向我们这边过来了。

师：哪一段符合要求？请说出理由。

学生互动分享

参考：第二段／我选第一段，手心磨得发烫，写得很真，我拔河的时候也是这样。

师：选第一段的同学，你的理由站得住。第一段写得真：毛刺扎进手心、鞋底蹭出印子，这些都是拔过河的人才写得出的。请选第一段的同学再读一遍，读完回答一个问题：这一段读完，你看见了几个人？

学生互动分享

参考：一个／就他自己／对面的人一个都没有。

师：对，只看见一个人。这一段里只有“我”和一根绳子，把“我”换成一个人独自拉一根拴在树上的绳子，这段话一个字都不用改。可是题目写的是“活动”，活动是一群人一起做的事，读的人要看见的是那个场面，不是只看见你一个人。这就是这次习作要写清楚的：一次活动，要有整个场面，也要有场面里的人，还要写清楚活动的过程和你的体会。

师：再看第二段。第二段里，哪几句写的是整个操场上的人都在做的事，哪几句只写了一个人？请分开找。

学生互动分享

参考：整个操场的：几十个人一齐喊、红布条一会儿左一会儿右、两队人仰着身子、鞋底一片沙沙声／写一个人的：大个子把绳子绕在腰上，班长喊“稳住”。

师：是的。写整个操场的这几句，叫作“面”：几十个人喊、两队人仰身子、一片沙沙声，写的是整个场面看到的和听到的。写大个子、写班长的那几句，叫作“点”：一个人的动作、神态和他说的话。先写面，再落到点，这就是这次习作的写法，叫点面结合。语文书第二单元的导语页就写着这两句：了解文章是怎样点面结合写场面的，尝试运用点面结合的写法记一次活动。这个单元的课文《狼牙山五壮士》，写五位战士在山顶上打击敌人那一段，先合起来写他们一同向敌人射击，接着就一个一个写下去，班长怎么指挥，副班长怎么打枪，年纪最小的两个战士怎么瞄准。先合写，再一个一个写，课文这一段和刚才的第二段，用的是一样的写法。

[投屏出示导语页那两句语文要素，旁边出示两个字：面、点。]

师：第二段里的两个“点”，大个子和班长，请大家比一比，这两个人写得一样不一样？

学生互动分享

参考：不一样，一个在拉，一个在喊／大个子写的是动作和脸，班长写的是手和话。

师：对，两个点各是各的样子：一个写他的动作和脸色，一个写他的手势和喊的话。如果两个人都写成“使劲拉、脸通红”，就等于只写了一个人。点要落在不同的人身上，写出不同的样子，《狼牙山五壮士》里那几位战士也是一人一个样。

师：现在请大家听老师把第二段读两遍，比一比各少了什么。第一遍，老师只读写“面”的句子，把写大个子和班长的那两句跳过去。

〔教师示范·只读“面”的句子〕哨声一响，操场上几十个人一齐喊了起来，两边的加油声撞在一块儿，分不清是哪个班的。绳子中间那根红布条一会儿往左一会儿往右，两队人全都仰着身子，鞋底在跑道上蹭出一片沙沙声。红布条一点一点向我们这边过来了。

师：第二遍，老师只读写“点”的句子。

〔教师示范·只读“点”的句子〕排在最后的大个子把绳子在腰上绕了一圈，脸憋得通红，一步一步往后挪。班长站在队伍旁边，两只手往下压，一声一声地喊：“稳住！稳住！”

师：两遍各少了什么？

学生互动分享

参考：第一遍热闹是热闹，可是一个人的脸都看不清／第二遍只有两个人，不知道周围在干什么，像在空地上练习。

师：说得很好。只有面，读的人知道热闹，却记不住任何一个人；只有点，读的人看见两个人，却不知道他们身在什么场面里。面和点合在一起，读的人才既看见整个操场，又记住了大个子和班长。写的时候，先用两三句把面写出来，再用两三句落到一两个人身上，写他的动作、神态、语言。

师：还有一点要说清楚。第二段只写了拔河最紧张的那一阵，前面怎么分队、怎么站位，后面谁赢了，一句都没写。这次习作要求写清楚活动过程，可是过程里不是每一步都要这样细写。教材说，把印象深刻的部分作为重点来写。所以整篇的写法是：过程按顺序交代清楚，每一步一两句带过；印象最深的那一步定格下来，用点面结合写成一整段；最后跟着这个场面写一两句体会。下面这张表就按这个顺序来填。

### 四、借助场面定格表，理清思路（约 9 分钟）

师：请大家看这张表，一共九格，每格只填几个关键词。老师先用一次插秧的活动填一遍给大家看，就是投屏上右边那幅图里的那种活动。

[投屏出示空白表，教师逐格填写；每格只填词，不写句子。]

| 项目 | 关键词（每格只填几个字） |
| --- | --- |
| 活动·时间·地点 | 劳动实践课·五月·郊区稻田 |
| 过程顺序（三四步） | 坐车→田埂上听讲→下田插秧→洗脚上车 |
| 定格哪一步 | 下田插秧 |
| 面·看到的整体 | 几十个人弯腰·裤腿卷到膝盖·水面晃眼 |
| 面·听到的整体 | 泥水咕叽·老师喊“往后退”·“我的鞋！” |
| 点·第一个人（谁·动作·神态·话） | 农民伯伯·三根一捏·一按一退·不看手 |
| 点·第二个人（谁·动作·神态·话） | 小宇·秧苗浮起来·捞起再按·泥点到眉毛·“别过来” |
| 那一刻的我 | 脚陷泥里·腰直不起来·插得歪 |
| 体会（一句） | 一碗饭里有多少次弯腰 |

师：填的时候要注意三点。“定格哪一步”这一格，从过程顺序里选一步，只选一步，是你印象最深、最有话说的那一步。“面”那两格填整个场面看到的和听到的，“点”那两格填一两个人，两个人要各不一样，第二个人一时想不出，可以先空着。“那一刻的我”单独占一格，写自己那一刻在干什么，这样“我”也在场面里，不会像第一段那样只剩一个人。

师：现在请大家填自己的那一次活动。刚才找出来的那一刻，就填在“定格哪一步”；稿纸角上写的四问答案，声音填到“面·听到的整体”，四周最多的东西填到“面·看到的整体”，自己的手脚嗓子填到“那一刻的我”，盯着的那个人填到“点·第一个人”，动作词和神态词一起填过去。习惯先列提纲再写的同学，也可以把这九格改成自己的提纲，只要面、点、过程、体会这几项都在。给大家四分钟。

学生动笔写作

[学生填表约 4 分钟。教师巡视，看到“面·看到的整体”空着的，问该生：站在你的位置往四周看，最多的是什么，是人、是旗子还是水；看到“点”里的人与“定格哪一步”不在同一步的，提醒该生：这个人要在你定格的那一刻里。]

师：填好以后，请和同桌互相说一遍自己定格的那一步：先说面，再说点。听的人只回答一句：听完以后，你最先看见的是谁。如果他最先看见的人和你表上“点·第一个人”不是同一个，先把他说的那个人记在表的空白处，动笔的时候再定写谁。

学生互动分享

师：表填好了，请先收好。下面来看老师照着这张表写出来的一篇习作。

### 五、出示示范文，发现写法（约 11 分钟）

师：这一篇是老师写的，写的时候老师把自己当成六年级的一个学生，写他插秧那一天。先请大家只读中间定格的那两段，读的时候对着刚才那张表，数一数：表上“面”两格、“点”两格里的那几个词，到了这两段里各变成了几句话。

[先投屏出示示范文第二、三自然段，教师填好的那张插秧表留在投屏一侧；学生默读约 1 分钟；全文稍后再出示。]

> 【教师示范文】
>
> 田里的一上午
>
> 五月的劳动实践课，我们坐了一个多小时的车，到郊区的一片稻田去插秧。下车先在田埂上听农民伯伯讲：秧苗三根一撮，插进泥里一指深，人要退着走，一行才直。听着不难，我以为半个小时就能插完一块。
>
> 真下了田才知道不是那么回事。整块水田里，几十个人一齐弯着腰，白衬衫的后背一片挨着一片。校服裤腿都卷到了膝盖上面，小腿上全是泥。水面被太阳照得发亮，晃得人睁不开眼。泥水在脚底下咕叽咕叽地响。田埂上老师一声接一声地喊“往后退，别踩着秧”。田里不知道谁喊了一声“我的鞋！”，一阵笑声顺着水面传过来。
>
> 农民伯伯就在我旁边那一行。他左手攥着一把秧，右手拇指和食指一捏，分出三根，往泥里一按，手一收，人已经退了半步。他不看手，眼睛盯着前面那一行，一按一退，一按一退，身后的秧苗排得像用尺子画过。小宇在我另一边，插下去的秧苗一会儿就浮起来一撮，他伸手捞起来，再按下去，泥点溅到了眉毛上。他顾不上擦，冲我喊：“你别过来，我这一行马上就直了。”
>
> 我的两只脚陷在泥里，每退一步都要先把脚拔出来，泥水沿着小腿往下淌。弯了半个小时，腰直不起来，回头看，我插的那一行歪歪扭扭，像一条蛇。
>
> 回去的车上，裤腿上的泥干成了灰白色。我一直在想，一碗米饭里的每一粒，都有人这样弯过一次腰。

师：表上“面·看到的整体”那一格三个词，到了示范文里变成了几句？“点·第一个人”那一格，变成了几句？

学生互动分享

参考：看到的变成了三句，几十个人弯腰、裤腿卷起来、水面发亮，还多了后背一片挨着一片／听到的也是三句，泥水响、老师喊、有人喊我的鞋／农民伯伯写了三句，一捏一按一收退半步，还有眼睛不看手。

师：对。表上几个词，到了示范文里变成了几句连着的话：看到的写了三句，听到的写了三句；农民伯伯那一格三个词，写成了三句话，他的动作拆成了一捏、一按、一收、退半步，一个动作一个小句。这就是从表到文：表上只记词，写的时候把每个词拆开，写成一句一句的话。

师：现在请大家读整篇。读完回答两个问题：第一，坐车、听讲、洗脚上车这几步，各用了几句？第二，最后一段的体会是几句，它是跟着前面哪件事说的？

[投屏出示全文，学生默读约 2 分钟。]

学生互动分享

参考：坐车一句，听讲两句，洗脚上车没写，直接写回去的车上／体会两句，跟着裤腿上的泥说的，泥干了想到米饭。

师：是的。过程里的几步，多的两句，少的一句，洗脚上车干脆没写；定格的那一步，面和点写了两大段，加上写“我”的一小段。这就是把印象深刻的部分作为重点来写。体会只有两句，而且是从裤腿上的泥说起，跟着的是刚写完的这件事。

师：老师把这篇用到的写法，一格一格列在这张表的右边，左边空着。前四格请大家从示范文里找句子，一格找一句，找到了就读出来；后两格老师直接出示。

[投屏出示旁批表，只出示右边各格，左边留空；前四格学生每找到一句，教师再出示对应的左边一格，后两格由教师直接出示并读一遍。学生找到的句子与表内不同时，只要用的是那一格的写法即算对。]

| 示范文里的句子 | 这一句用了什么写法 |
| --- | --- |
| 整块水田里，几十个人一齐弯着腰，白衬衫的后背一片挨着一片。 | 面·整个场面看到的 |
| 泥水在脚底下咕叽咕叽地响。田埂上老师一声接一声地喊“往后退，别踩着秧”。 | 面·整个场面听到的 |
| 右手拇指和食指一捏，分出三根，往泥里一按，手一收，人已经退了半步。 | 点·第一个人的动作，拆成几步一句一句写 |

〔教师示范·另一种结尾〕这次插秧让我懂得了劳动的艰辛。我们每一个人都要珍惜粮食，从小事做起，做热爱劳动的好少年！

## 第2课时 · 当堂写作与评改课

### 一、自由写作（约 29 分钟）

师：请把场面定格表拿出来，找到“定格哪一步”那一格。这一篇里最重要的就是定格的那一段，所以先定这一段从哪一句起笔，再写。老师说三种起笔的方法，说完由大家自己定。第一种，从“面·看到的整体”起笔，先写你站在那里往四周看到的景象；第二种，从“面·听到的整体”里最大的那个声音起笔，先写这一声响，再写周围；第三种，从“那一刻的我”起笔，先写自己的手脚在干什么，再抬头写周围的人。三种都可以，哪一种最有话说就选哪一种。第一节课同桌说的他最先看见的人，和你表上的不是同一个、已经记在空白处的同学，现在先定下写谁。请在表上要起笔的那一格旁边写一个“1”，再想好一句话：我为什么从这一格起笔。

[学生在表上标“1”，约半分钟。教师请两位学生各说一句：从哪一格起笔，为什么。]

学生互动分享

参考：我从声音起，哨子一响所有人一起喊，那一下最清楚／我从自己起，我那时候脚陷在泥里拔不出来，写起来最有话。

师：定下来就动笔，先只写定格的这一段，从标了“1”的那一格写起，写三四句，把面和点都带出来。

学生动笔写作

[学生写定格那一段的起笔三四句，约 2 分钟。]

师：刚写的这几句，落在整篇的中间。这一段前面要交代活动是什么、怎么开始、前几步是怎么进行的，按表上“过程顺序”每一步写一两句；这一段后面接活动的结束和体会。现在接着写完整篇，大约二十五分钟。记住三件事：定格的那一段先面后点，点落在一两个不同的人身上；过程各步一两句带过；结尾跟着这件事写一两句体会。写的时候不回头改字改句，先把整篇写完。这个学期的习作在五百字上下，写到六百字也可以。

学生动笔写作

[教师巡视约 25 分钟，不打断、不当场纠错。按四种情况介入：]

[① 接不下去：请该生拿出表，问表上哪几格还没写进去、哪一格接在后面最顺，只问顺序，不给素材。]

[② 内容空泛：定格那一段只写了“热闹极了”“紧张极了”的，问该生那一刻最多的是什么人在做什么、最大的声音是什么，请该生选一项补进去。]

[③ 书写顺畅：不打断。]

[④ 草草收尾：写了两三百字就停笔的，先肯定该生定格的那一步选得准，再问“表上第一个人你只写了一句，他当时脸上的神态和他说的话呢”，请该生续写下去。]

[写不完的，当堂把定格那一段和结尾的体会写完；过程里的步骤来不及写全的，先空着，不留课后任务。]

### 二、交流评议，修改收束（约 16 分钟）

师：请停笔。稿子写到哪里算哪里，评改只看纸上已经有的部分。先按教材的要求做第一件事：自己读一遍，看语句通不通顺，前后连不连贯，读到不通的地方做个记号，先不改。

[学生自读约 1 分钟。]

师：现在把稿子传给没在场的人读。请每人把稿子往后传给后面一位同学，最后一排传给第一排。拿到稿子的同学请默读，读完在稿子末尾写两行：第一行写“我看见的场面：”，用一句话写出你读到的整个场面是什么样子；第二行写“我记住的人：”，写出作者写了谁、他在干什么。写得出就写，写不出就在那一行写“没看见”，实话实说。

[传稿默读并写两行，约 4 分钟。教师巡视，看到第一行只写“很热闹”“很紧张”的，提醒该读者：把你看见的那个场面里最多的东西写出来，是人、是旗子，还是水。]

学生互动分享

师：请把稿子传回作者。作者请读一读末尾这两行，对照三种情况定改哪一处。第一种，第一行写着“没看见”，或者只写了“很热闹”，说明面没有写出来，就在定格那一段开头补两句整个场面看到的和听到的。第二种，第二行写着“没看见”，说明点没有落下来，就选一个人，补上他的动作和他的一句话。第三种，两行都写出来了，但第二行的人不在你定格的那一刻里，说明点没有放在面里，把这个人挪到那一段里去写。三种情况都没有的，再看结尾，体会有没有跟着这件事，还是说到“每一个人”上去了。只改这一处，改完通读一遍，刚才自读时做了记号的不通的地方一并改顺，再用修改符号把多的字划掉，漏的字补上，错的字改正。给大家五分钟。

学生动笔写作

[教师巡视约 5 分钟，先看第一行写着“没看见”的那几位补了什么，再看结尾。巡视中点评时按下面三档判断，不读给学生。]

〔三档标准·教师掌握（供教师判断用，不必读给学生）〕基础：活动过程写清楚了，有简单的场面描写，语句通顺。良好：过程清楚，定格的那一段先面后点，点落在了一两个人身上，重点部分比较具体。优秀：面有整体的看和听，点各是各的样子，点在面里；过程详略分明；体会跟着这件事，不空说。

师：最后请两位同学读自己在别人稿子上写的第一行，读完请那篇的作者把让他看见场面的那两句读出来，大家听一听，面是怎么落到句子上的。

学生互动分享

参考：我看见的场面是，礼堂里灯全关了，只有台上一束光，底下全是黑的，一百多个人没有一点声音／作者读：报幕的一走，礼堂的灯全灭了，台上只剩一束光照着我们六个人，台下黑压压一片，连翻纸的声音都没有。

（教师总结）今天这篇是写给没在场的人读的。读的人在你稿子上写下了他看见的场面和记住的人，说明那个场面已经从你的脑子里到了纸上；写着“没看见”的那一行，就是刚才改的地方。这一课的写法，先写面，再落到点，是《狼牙山五壮士》这样的课文也在用的写法，也是今天大家自己用过一遍的写法。请把稿子交上来。

本课完。

全课完。

## 附：习作讲评指导环节（可选 · 单次课课后用 / 系列课作下次课开场用）

> 本环节供老师灵活取用：单次课可在课后批阅后另找时间讲评，系列课可作下一次课的开场，约 15–20 分钟，不计入两节课的 45＋45 分钟。
> 下文凡 ＿＿＿ 处，务必换成本班学生当堂完成的真实习作里的句子，不得虚构。

### 选稿（课前准备）

[从当堂完成的稿子里选三篇，投屏出示时不写姓名：一篇定格那一段先面后点、两个点各是各的样子的（好）；一篇面写出来了、点只有一个人或两个人写成了一个样的（中）；一篇过程各步平均用力、没有定格出一段的（待改进）。每篇各用一句话对着本课写法记下好在哪、欠在哪。]

### 讲评流程（每篇约 3–5 分钟，围绕本课技法点）

师：今天讲评只看一件事：定格的那一段，先面后点做到了没有，点是不是各是各的样子。

师：第一篇。这一段开头写的是“＿＿＿”（读该篇写整个场面的一两句），读到这里，我们看见了整个＿＿＿（操场／礼堂／田）；接下来落到了＿＿＿（第一个人）和＿＿＿（第二个人）身上，一个写的是“＿＿＿”（读第一个人的动作句），一个写的是“＿＿＿”（读第二个人的神态句或他说的话）。两个人不一样，这就是点落对了。

（教师总结）面在前，两个点各有各的样子，读的人先看见全场，再记住两个人。

师：第二篇。这一篇的面写得清楚，“＿＿＿”（读该篇写面的句子），可是点只有一个：“＿＿＿”（读那个人的句子）。请大家想一想，那一刻的场面里还有谁，作者也可以写一写？

学生互动分享

师：对，再补一个人，写他和第一个人不一样的地方，这一段就完整了。

师：第三篇。这一篇从头到尾每一步都写了三四句，“＿＿＿”（读该篇过程里两三步的句子），读完以后，请大家说一说：这次活动，作者印象最深的是哪一步？

学生互动分享

师：如果大家说的都不一样，就说明作者还没有定格。请作者自己选出一步，把那一步写成先面后点的一整段，其余各步减到一两句。

（教师总结）三篇看下来，写活动最要紧的是定格那一步，那一步先面后点，点各是各的样子。

### 收尾（点回技法、引向今后的写作）

师：以后写任何一次活动，先问自己两句：整个场面我写了吗，场面里的人我写了几个、各是什么样子。这两句问过了，场面就在纸上了。

本环节完。
