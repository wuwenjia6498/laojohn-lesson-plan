# 《我和＿＿过一天》· 写作课教学设计

四年级上册·第四单元 校内同步写作（想象习作）

[授课提示：示范文里那位神笔马良，是老师拟写的示例。老师若对别的神话或童话人物更熟悉，换成那一位更好，教学步骤与讲法不变。]

## 教案提纲表

| 课题·课时  | 四上·第四单元《我和＿＿过一天》　│　想象·校内同步　│　2课时连排（每节45分钟）                                                                    |
| ------ | ------------------------------------------------------------------------------------------------------------- |
| 能力阶段   | 写清楚 → 写具体（本课） → 写生动 → 写深刻·有章法                                                                                 |
| 同类习作顺序 | 想象：续写故事／编童话 → 奇妙的想象／这样想象真有趣 → 我和＿＿过一天（本课） → 奇思妙想／故事新编 → 二十年后的家乡 → 神奇探险 → 变形记／笔尖流出的故事 → 插上科学翅膀                 |
| 教材要求   | 统编四上·第四单元习作：与神话人物想象一天，情节合理。                                                                                   |
| 学习目标 | 通过想象与一位神话、童话人物共度一天，学习根据人物特点选取事件，把一件事写具体。 |
| 核心技法 | 借助“这一天构思表”构思：先明确人物的专属本领，再选一件换了别人便无法完成的事；重点场面放慢写，写出人物的动作、人物的语言和“我”的心理活动。 |

## 第1课时 · 写作指导课

### 一、创设情境，明确任务（约 5 分钟）

〖PPT 第3页 · 创设情境 · 同一场大雨，换一个人物，办法就不一样〗

师：我们先来做一个想象小游戏。下午突然下起大雨，你要回家，却被困在屋檐下，雨越下越大。现在，老师请一位人物站到你身边：孙悟空。这场雨，还拦得住你吗？

学生互动分享（举手抢答两三位，快问快答，不展开；教师简要回应后即请下一位）

参考：一个筋斗云就到家了／他变出一把伞给我／他背着我从雨上飞过去／他一棒把乌云捅开，雨就停了。

师：现在请孙悟空退场，换一位人物站到你身边：神笔马良。

参考：他画一把伞／画一条不下雨的路／画一辆车送我回家。

师：大家发现了吗？同样的雨天，同样的困境，人物不同，解决问题的办法完全不同。雨没有变，变的是人物的本领。

〖PPT 第4页 · 创设情境 · 请他专程陪你一天，你最想邀请谁？〗

师：刚才只是请人物短暂地帮个忙。如果让你最喜欢的神话、童话人物哪里也不去，从早到晚专门陪伴你一整天，你最想邀请谁？

学生互动分享（随机请四五位学生作答，只说人物名字，不展开）

师：孙悟空、哪吒、神笔马良、嫦娥……每个人邀请的都不一样。老师再问一句：你专门邀请他，最想用到他的什么本领？

参考：他会飞／他力气大／他会七十二变／我想让他带我到天上去看一看。

师：原来大家看中的，都是人物独一无二的本领。请大家想一想：如果这一整天，他只是默默地跟着你，陪你走路、玩耍，全程一点本领也不用，那邀请他还有意义吗？

〖PPT 第5页 · 创设情境 · 明确任务：写下奇妙的一天〗

师：对，这样的邀请就没有意义了。所以今天，我们要想象和他度过神奇的一天。这两节课的核心任务只有一个：把这奇妙的一天写成一篇完整的想象作文。

师：写完后进行小组互评，四人一组互读习作，找出文中只有这位人物才能完成的事，并画上横线。

同时还要开展班级分享：请几位同学朗读自己文章中最精彩的片段。

评价的标准只有一条：文章里的人物，有没有写出专属于他的样子和本领。如果把你文章里的人物名字划掉，换成同桌的名字，故事一个字都不用改，那么这一天谁陪你都一样，这位神奇的人物就等于没有请到。

### 二、回想人物，说说他的本领和性格（约 7 分钟）

[投屏出示一组神话与童话人物的图片（孙悟空、哪吒、女娲、神笔马良、嫦娥、葫芦娃等），约 30 秒，仅供学生辨认与选择人物，此后一直留在屏上]

〖PPT 第6页 · 回想人物 · 抢答：他有哪些专属本领？〗

师：要写好人物，首先要了解人物。我们先用抢答的方式来梳理，一人说一个特点，不重复。先说孙悟空，他有哪些专属本领？

学生互动分享（举手抢答，每人说一点；教师复述并强化学生的回答，如“金箍棒能变小，收在耳朵里”）

参考：七十二变／会翻筋斗云／火眼金睛／金箍棒能变大变小／拔一把毫毛能变出一群小猴子／他还钻进过妖怪的肚子里。

师：再换一位：哪吒。

参考：脚踩风火轮／有一条混天绫／会变三头六臂／水性极好，身手敏捷。

〖PPT 第7页 · 回想人物 · 他是什么性格？会怎么说话？〗

师：人物的本领大家都很熟悉，但只写本领，人物还是不够鲜活。孙悟空这个人物，性格怎么样？

参考：性子急／爱开玩笑／不服输／爱打抱不平

师：你从哪里看出他性子急？

参考：他做事不等别人／别人话还没说完，他就跳起来了。

师：对，别人话还没说完他就跳起来了。一个人的性格，就藏在他的一举一动、一言一行里。写作文，不仅要写他会什么，还要写出他做事的风格、说话的语气，这样人物才真实，才不会千篇一律。

师：我们再来试一试。假如他现在推门进来，站在门口，第一句话会说什么？请用他的语气说给大家听。谁来试一试？

学生互动分享（请两三位学生当场用自己所选人物的语气说一句话；教师回应时点出这句话像人物的地方，如“‘俺老孙’三个字一出口，就听出是他了”）

（教师总结）理清人物的本领、性格、说话风格，才算真正把人物“请到”了自己的故事里。

### 三、学写法：构思一件“非他不可”的专属事件（约 18 分钟）

[两段文字同步投屏出示，逐段朗读，读完均留在屏上供学生回看]

〖PPT 第8页 · 判断对比 · 哪一段里的孙悟空才是真正的孙悟空？〗

师：动笔之前，先要弄清一件事：这一天到底该写什么。同一个题目《我和孙悟空过一天》，老师写了两个小片段，写的是同一个场景：在游乐园排队等过山车。老师把两段都读给大家听，听完后请大家判断，哪一段里的孙悟空才是真正的孙悟空。

师：第一段：“过山车前排着长长的队伍，太阳晒得人发晕。孙悟空踮起脚往前看了看，缩回身子对我说：‘还早呢，起码还得等半个钟头。’我们跟着队伍一步一步往前挪，挪到快中午才坐上。”

师：第二段：“过山车前排着长长的队伍，太阳晒得人发晕，站得我腿都发酸。孙悟空见我满头大汗，吹了一口仙气，变出两片大大的树荫，罩在我们头顶。他挠挠头对我说：‘排队实在太熬人了，咱们先在树荫底下歇一会儿。’”

师：大家说，是哪一段？

参考：第二段。

师：可是第一段也不能说没有写具体。太阳、他的动作、他说的话、排队的时间，一样不少。大家为什么不选它？

参考：踮起脚往前看，谁都会／那就是一个普通人在排队／他一身本领一点也没用上。

师：这句话说到了关键。如果老师把第一段里的“孙悟空”三个字划掉，换成同桌的名字，这段话需要修改吗？

参考：不需要／一个字都不用改。

师：这就是本次习作最大的误区：故事写完整了，却没有写出人物的专属特点，换成谁都一样。

师：写这篇想象作文，核心不是写“玩了一天”，而是写只有这个人物才能陪你完成的一天。

〖PPT 第9页 · 教师示范段 · 老师把一件事写详细给大家看〗

师：老师给大家读一段示范文，请大家认真体会。

〔教师示范·当场把这一天里的一件事写成一段〕我家住六楼，是一栋老楼的顶楼。楼道里没有灯，一到傍晚楼道就漆黑一片，奶奶眼神不好，傍晚买菜上楼总容易磕磕绊绊。那天下午我把这件烦心事说给马良听。他没答话，蹲下去，把一张草稿纸铺在第一级台阶上，握着笔在纸上画了一整排明亮的壁灯。画完，他站起身，只见一幅幅灯的图样从纸上飘出，顺着楼梯依次定格在每层墙壁上，化作真实的暖光壁灯，从一楼一直排到六楼。“你瞧，”他说，“这些灯光，都是取自我家后山今年中秋节那晚的月光。”我抬头望着暖融融的灯光，心里诧异极了。

〖PPT 第10页 · 学写法 · 把“马良”换成“孙悟空”，哪里不对？〗

师：现在我们来做一件事。老师把这一段里的“马良”换成“孙悟空”，其他一个字不改，大家再听一遍：“孙悟空没有答话，蹲下身，把一张草稿纸铺在第一级台阶上……”

[此段先整段投屏出示再朗读；读到此处停住，同时把屏上的“马良”二字改为“孙悟空”，让学生对照屏幕自己接着往下读；不必读完整段]

师：不用读完，看大家的表情就知道了。哪里不对？

参考：孙悟空不会画画。

师：对。这件事，马良做得成，孙悟空做不成。他不会画画，他会的是翻筋斗云、七十二变。反过来问一句：如果那天陪着我的是孙悟空，奶奶上楼这件事，他会怎么解决？

参考：他背着奶奶一下就上去了／他变出一套灯具／他吹一口气把奶奶送上楼。

〖PPT 第11页 · 学写法 · 本课要点：这一天写什么事，由人物来定〗

师：这就是本课的核心：人物决定事件。画画助人是马良的专属本领，腾云驾雾是孙悟空的本领。人物换了，相应的事件和做法必须跟着换，不能生搬硬套。

师：大家在课本里学过的盘古，就是这样写的：一斧劈开天地；天地要合拢，他就头顶天、脚踏地撑在中间，天每天升高一丈，他也跟着长高一丈。这些事，离开了他那样高大的身躯、那样巨大的力气，换谁都做不成。

师：他倒下以后，呼出的气息变成了风和云，汗水变成了雨露，这些也是别人替代不了的。神话人物做什么事，从来都由他的本领决定。

师：教大家一个通用的构思方法：先想一想生活中你解决不了的难题，比如够不着的、搬不动的、来不及的、坏了修不好的；再对照你选的人物，用他的专属本领来解决这个难题。这件事就是独一无二、非他不可的。

〖PPT 第12页 · 小练笔 · 最精彩的场面放慢写：写三句话〗

师：事件选好之后，还有一步。这一天不必从早写到晚，选一两件事就够了；重点场面一定要放慢节奏写细节，写全三点：人物连贯的动作、专属于他的一句话、你当时真实的心理活动。

师：大家找一找，刚才的示范段里，哪里是动作描写，哪里是语言描写？

参考：他蹲下身、铺纸、握笔、站起身／“这些灯光，都是取自我家后山今年中秋节那晚的月光。”是他说的话。

师：动作和语言都找出来了。还有最关键的第三点：心理描写。它其实也在这一段里，就是最后一句“我抬头望着暖融融的灯光，心里诧异极了”，一句话带过了。

纸上画出来的壁灯居然变成真的了，要是奶奶知道这壁灯是画出来的，肯定不敢相信。

师：这一句心理描写写的不是马良，而是“我”。他施展本领的时候，你在旁边产生的想法，就是真实的心理活动。

师：现在请大家写小练笔。想一想你选的人物和构思的专属事件，写三句话：第一句写他的动作，第二句写他的专属语言，第三句写你的内心想法。

学生动笔写作

师：请两位同学分享自己写的句子。

学生互动分享（随机抽选；教师有针对性地点评：他选的这件事是不是只有这个人物才能做成，语言是否贴合人物形象，心理活动是否真实）

师：最后补齐文章的开头和结尾。这一天总要有个开头、有个收尾：他是怎么出现的，最后又是怎么离开的。这两处各写一两句即可，不必多写。老师写的开头是笔盒里凭空多出一支笔，结尾是他把笔放回去，下楼走了。

（教师总结）本次习作的核心写法：这一天写什么事，由人物来定；选一件只有这个人物才能完成的事；重点场面放慢写细节，写全动作、语言、心理活动。

### 四、借助“这一天构思表”，理清思路（约 8 分钟）

〖PPT 第13页 · 构思表 · 这一天构思表（空白·与发放表同款）〗

师：很多同学想法很多，写出来却杂乱无章。我们用构思表来梳理思路，只填关键词，简洁清楚、自己能看懂就行，不必写长句子。

〖PPT 第14页 · 构思表 · 这一天构思表（教师示范）〗

师：老师先填一张示范给大家看。

[投屏逐格填写教师示范表，边填边念]

| 项目                 | 我的关键词                                |
| ------------------ | ------------------------------------ |
| 我邀请的人物 | 神笔马良 |
| 他的本领·他的性格 | 画什么，什么就活了／话少、认真 |
| 我们怎么相遇 | 笔盒里多出一支笔 |
| 这一天做的事（选一两件，非他不可） | 画一只麻雀／画一排壁灯 |
| 最精彩的场面：他的动作／他的话／我的心理 | 蹲下画图／“这些灯光，都是取自我家后山今年中秋节那晚的月光。”／诧异极了 |
| 最后怎么分别 | 把笔放回／下楼离开 |

师：请大家重点关注第四栏，事件必须与人物的本领相匹配，不能写谁都能做的普通小事。实在想不出来，就回看第二栏的人物本领，顺着本领去找事件。

〖PPT 第15页 · 构思表 · 轮到你了：先填表，再在小组内交流〗

学生动笔写作（填表约 3 分钟；教师巡视）

〔应答·学生选的事换成谁都能做，如一起吃饭、一起逛街〕不否定学生所填的内容，指着表上第二栏问一句：你观察得很仔细，但这么厉害的人物，一身本领完全没有用上，是不是太可惜了？试着结合他的本领，换一件只有他能做的事。

〔应答·学生想写的人物不属于神话、童话，如动画片角色、球星〕动画片里的角色可以写，只要人物的本领、性格鲜明，就符合要求；尽量不写普通的真实人物，因为缺少神奇本领，不符合想象习作的要求。

师：四人小组轮流说一说，每人半分钟，讲清三点：邀请的人物、他做的专属事件、为什么只有他能做。其他组员只需判断一句话：这件事，你的同桌能不能做到？如果人人都能做到，说明事件选错了，需要更换。

学生先在组内交流分享，教师再引导学生上台分享

师：谁愿意分享一下自己独一无二的专属事件？

学生上台分享（随机抽选；教师点评事件与人物形象的匹配程度）

### 五、出示示范文，发现写法（约 7 分钟）

〖PPT 第16页 · 教师示范文 · 补齐首尾，那一段就成了完整的一天〗

师：大家的构思表都填好了。老师把刚才那一段前后补齐，写成了完整的一天，读给大家听。听的时候请大家留意一个问题：老师写这一天，选了几件事。

> 【教师示范文】
> 
> 星期六早上，我在书桌前写字，笔盒里多出一支笔。木头杆，笔尖秃秃的。我拿它在草稿纸上画了一只麻雀。那只麻雀抖了抖翅膀，从纸上跳下来，落在台灯上，歪着头看我。
> 
> 门口站着一个男孩，比我高半个头，光着脚。“那支笔是我的，”他说，“我叫马良。”
> 
> 我家住六楼，是一栋老楼的顶楼。楼道里没有灯，一到傍晚楼道就漆黑一片，奶奶眼神不好，傍晚买菜上楼总容易磕磕绊绊。那天下午我把这件烦心事说给马良听。他没答话，蹲下去，把一张草稿纸铺在第一级台阶上，握着笔在纸上画了一整排明亮的壁灯。画完，他站起身，只见一幅幅灯的图样从纸上飘出，顺着楼梯依次定格在每层墙壁上，化作真实的暖光壁灯，从一楼一直排到六楼。“你瞧，”他说，“这些灯光，都是取自我家后山今年中秋节那晚的月光。”我抬头望着暖融融的灯光，心里诧异极了。
> 
> 天快黑的时候，奶奶提着菜上楼。她走进亮堂堂的楼道，脚步一顿，抬头看着墙上的灯，疑惑地说：“楼道里什么时候装灯了？”我摇摇头，没敢告诉她，这些灯是马良画出来的。
> 
> 马良把笔放回我的笔盒，走到门口。“这些灯不会消失，以后夜里走路就安全了。”他说完就下楼了。我趴在栏杆上往下望，整栋楼道暖光满满，再也不会黑漆漆的了。

〖PPT 第17页 · 读示范文 · 先看这一天是怎么展开的〗

师：先看文章的框架。这一天，老师写了几件事？这两件事，如果换成孙悟空来做，做得成吗？

参考：两件／画麻雀，画壁灯／孙悟空做不成，他不会画画／他得用别的办法。

师：两件。哪一件写得详细？

参考：画壁灯那一件／第三段最长。

师：开头写的是什么，结尾写的是什么？

参考：开头是笔盒里多了一支笔／结尾是他把笔放回去，走了。

师：开头交代怎么相遇，结尾交代怎么分别，中间选两件事，写得最细致的是画壁灯这一件。一天就是这样安排的。

师：我们再看一处。读到哪一句时，你的脑海里就出现了画面？说说是哪一句。

学生互动分享

〖PPT 第18页 · 旁批表 · 每一句在做什么：列出来对照着看〗

师：我们把这几句话整理成一张小表，对照着看。

[投屏出示旁批对照表，逐行带读]

| 示范文中的句子 | 这一句的作用是什么 |
| -------------------------- | --------------- |
| 笔盒里多出一支笔。木头杆，笔尖秃秃的 | 开头写怎么相遇，一两句带过 |
| 那只麻雀抖了抖翅膀，从纸上跳下来 | 快速点明人物的专属本领 |
| 蹲下身，把一张草稿纸铺在第一级台阶上 | 细化核心动作，放慢精彩场面 |
| “这些灯光，都是取自我家后山今年中秋节那晚的月光。” | 人物的语言，这一句别人说不出来 |
| 我摇摇头，没敢告诉她，这些灯是马良画出来的 | 写出“我”真实的心理活动 |

师：老师请来的是马良，大家请来的是不同的人物，写出来的事自然各不相同，这也是这个题目的有趣之处。

师：第一节课就上到这里。构思表先不要收起来，下节课我们要结合构思表，完整地写完这篇作文。

本课完。

〖PPT 第19页 · 课时分隔 · 当堂写作与评改课〗

## 第2课时 · 当堂写作与评改课

### 一、借助构思表，完成作文开篇（约 5 分钟）

[发放稿纸；投屏保留第1课时的构思表示例]

〖PPT 第20页 · 写开头 · 看构思表第三行：先写你们怎么相遇〗

师：请把构思表拿出来，看第三行，你们是怎么相遇的。接下来的三分钟，先动笔写文章的开头。

师：怎么写？他是从哪里出现的，你第一眼看见的是什么，那时你正在做什么。写三四句就够，不必写太长。遇到不会写的字先空着，保证写作的流畅。

学生动笔写作（约 3 分钟；教师安静巡视，不作任何提示与纠正）

师：请停笔。开头已经写在稿纸上了，接下来就接着这几句往下写。

师：往下写之前，再看一眼构思表上的核心事件和精彩细节：这一天你要写哪件事，最精彩的场面是什么。上节课写的动作、语言、心理三句练笔，要预留好位置，写到那件事时直接放进去。

### 二、自由写作，写成这一天（约 20 分钟）

〖PPT 第21-22页 · 自由写作 · 写成这一天：抓住这两点〗

师：接着刚才的几句往下写。中间选一两件事，核心事件放慢写详细，上节课的三句练笔就放进这件事里；最后写你们是怎么分别的。

师：往下写的时候要抓住两点：一是事件只有你选的人物才能完成，别人做不到；二是精彩场面的细节必须齐全，他做了什么、说了哪句话、你心里怎么想，三点都要写到。错别字先不管，先一口气写完。

学生动笔写作

[教师巡视，只做正向介入，不纠正错别字、不修改病句、不打断书写顺畅的学生。按学情分四类处理：]

[接不下去型：写完开头几行就停住，盯着稿纸。引导学生回到构思表：“相遇那一段你已经写出来了，现在直接看构思表第四栏，从你选定的专属事件接着往下写。”]

[内容空泛型：整段都是“我们玩得很开心”“他的本领真大”之类的话。请学生看构思表第五栏，想一想人物做事的具体动作，把动作写出来。]

[书写顺畅型：不打断，走过时轻声说一句“接着写”，为其留出书写空间]

[草草收尾型：写了几句就搁笔说“写完了”，篇幅明显偏短。先肯定，再推进一步：“他把事情办成了，办的时候是什么样子？他说了什么？再写得丰富一些。”]

[临近时间提示：到时间先停笔，写到哪里算哪里；后面的修改环节还可以回来继续补写]

### 三、交流评议，修改收束（约 20 分钟）

[传稿一轮（约 4 分钟）：四人一组，稿纸朝同一个方向传给相邻的一位同学]

〖PPT 第23页 · 交流评议 · 传稿一轮：找出“非他不可”的那一句〗

师：四人小组的稿纸向右传递，互相阅读。请大家找出文中只有主人公才能完成的独特情节，画上横线。如果通篇都是普通小事，没有专属人物的特点，就在文末标注“换谁都行”。读完后传回本人。

学生互评操作

师：拿回自己的稿纸看一看，横线画在了哪一句上？被标注的同学也不要着急，稍后修改时重点优化。

[全班故事会（约 6 分钟）：请三位学生朗读自己写得最详细的那一段，每位约两分钟]

〖PPT 第24页 · 交流评议 · 奇幻故事会：他写的那位人物，还是不是他？〗

师：故事会现在开始。请三位同学只朗读自己最精彩的核心片段。全班同学认真倾听并判断：这段描写，是不是写出了专属这个人物的特点？从哪一句能看出来？

学生互动分享（三位学生依次朗读；每位读完后请一两位同学说出判断和依据；教师随后简要点评，落到具体句子上，如指出他写的这件事与人物的哪一项本领相衔接、哪一句话像是这位人物说出来的。）

[带标准修改（约 8 分钟）：内容与错别字延后到此环节统一处理]

〖PPT 第25页 · 修改收束 · 自检与修改〗

师：修改之前，我们对照下面三个要点检查自己的作文，看看哪些做到了，哪些还需要补充完善。

| 要点 | 自检 |
| ---- | ------------------------------- |
| 文章结构 | 文章完整，写出了怎么相遇、这一天做了什么事、最后怎么分别。 |
| 细节达标 | 精彩场面写全：他的动作、他说的一句话、“我”的心理活动，三点都有。 |
| 人设贴合 | 这一天里的事，换成别人做不成；同组同学在我的文中画出了那道横线。 |

师：如果你的文章有下面这几个问题，请及时修改。

- 缺少相遇或告别场景的，及时补齐；
- 被标注“换谁都行”的，补写人物运用专属本领的动作，优化事件；
- 细节不全的，补全动作、语言、心理描写（大部分同学容易缺少心理描写，要重点补充）。

学生动笔写作（自主修改；教师巡视答疑）

[收尾（约 2 分钟）]

师：这篇作文的亮点，不在于想象多么新奇，而在于人物立得住，事件专属于这个人物，换了别人就不成立。这才是你文章最大的亮点。

师：请把稿纸收好。以后再遇到这类题目，不要一开始就想去哪里玩，先想一想他会什么本领。

（教师总结）这节课学习的要点是：这一天写什么事，由你选的人物来定；选一件非他不可的事，把最精彩的部分写详细，写出他的动作、他的一句话、“我”的心理活动。抓住人物的本领和性格，写独一无二的故事，细化动作、语言、心理描写，就是一篇优秀的想象作文。

本课完。

## 附：习作讲评指导环节（可选 · 单次课课后用 / 系列课作下次课开场用）

> 本环节供教师灵活取用：可在单次课课后批阅学生习作后集中讲评一次，也可作为系列课下一次课的开场（约 15–20 分钟）；不计入本课 45+45 分钟，讲评的是学生当堂完成的稿件，不布置新的写作任务。
> 讲评中凡出现“＿＿＿”处，务必替换为本班学生习作中的真实句子，切勿虚构。

### 选稿（课前准备）

课后通读全班稿件，围绕本课技法点（事件由人物决定、事件要与人物本领相匹配、人物施展本领的那一段写出动作、语言、心理）挑出三篇：

- 一篇较好的：事件与人物的本领相衔接，人物施展本领的那一段三点齐全，用来让全班看到这一天应该怎样写。
- 一篇中等的：事件选对了，但那个场面一句话就带过去了，动作和语言都没有写出来，用来演示这一处怎么放慢写。
- 一篇有典型问题的：通篇是一起吃饭、一起逛街、一起玩，把名字换掉照样成立，用来带全班一起想办法修改。

三篇均投屏出示，不念作者姓名；讲评前为三篇各拟一句评语，写明它对照本课技法好在哪里、欠缺在哪里。

### 讲评流程（每篇约 3–5 分钟，围绕本课技法点）

〖PPT 第26页 · 习作讲评 · 习作讲评环节（可选·课后或下次课开场）〗

师：大家上次写的稿子老师都读过了。今天只看两件事：这一天里的事，是不是非他不可；最精彩的场面，有没有写详细。

师：先看第一篇。他写的这件事是“＿＿＿”（用一句话说出该篇选的事件），下面这几句是这样写的：“＿＿＿”（读他写这件事时最具体的一两句）。大家听一听，这几句动作，是不是人物用他的本领做出来的？

学生互动分享

（教师总结）他选的这件事，正好用上了人物的本领；动作、语言、心理描写三点齐全。

师：第二篇我们只看一处。他这件事选得没有问题，但写到最精彩的地方只有一句：“＿＿＿”（读那句一带而过的话）。这一句缺的是什么？

参考：不知道他是怎么做的／他没有说话／没有写自己心里想什么。

师：那么给他补写，先补哪一点？

参考：先写他手上在做什么／让他说一句话。

师：对，把他动手的几个动作拆开来写，再让他开口说一句话。两三句就够，不必多写。

师：第三篇不点名，我们一起来帮他想办法。这一篇从头到尾写的是一起去了哪里、吃了什么，把名字换掉，故事一个字都不用改。要修改这篇文章，第一步该改哪里？

学生互动分享

（教师总结）第一步是回过头去想人物会什么本领。本领想清楚了，事件就跟着出来了：他会飞，就让他带你去一个平常去不了的地方；他会画画，就让他画一样家里正缺的东西。事件选对了，这一天才真正属于他。

### 收尾（回扣技法，引向今后的写作）

师：三篇看下来，写得好的都好在同一处：那件事，只有他做得成。以后大家编故事，只要故事里有一个人物，就先问自己一句：这件事，换个人来做得成吗？如果换个人也做得成，说明这个人物还没有写出来。

本环节完。
