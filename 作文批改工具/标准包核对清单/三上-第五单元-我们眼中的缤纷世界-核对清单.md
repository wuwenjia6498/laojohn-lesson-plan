## ① 覆盖度自问（必填 · 第一项）

**问：这三条判完，本课核心技法算不算判过了？**

核心技法（提纲表原文）：使用“观察发现卡”。先用多种感官把它看仔细，把发现记在卡上；再圈出印象最深的一两处，写出它的样子，加上它像什么，或者听到、摸到、闻到、尝到的感觉；会变的，按先后顺序写出变化。

| 技法分解 | 对应判据 |
|---|---|
| 用多种感官看仔细，记在卡上 | 不直接判——观察与填卡在稿纸上看不到，结果落在②（写出的感觉）上 |
| 圈出印象最深的一两处（来写） | ① 重点写卡上圈出的一两处，把它写清楚 |
| 写出它的样子，加上像什么或听到、摸到、闻到、尝到的感觉 | ② 写清楚就是先写它的样子，再加上它像什么，或者耳朵听到、手摸到、鼻子闻到、嘴巴尝到的感觉 |
| 会变的，按先后顺序写出变化 | ③ 短时间内能看完的变化，用刚开始、过了一会儿、最后 |

**答：算判过了，三项一一对应。** 这三条本就是老师在动笔前把核心技法三项逐条念给学生听的版本。

⚠ 第③条 text 只说“短时间内能看完的变化”，而核心技法说的是“会变的，按先后顺序写出变化”，详案 L179 另说慢慢变化的“写清楚哪一天看到的是什么样子即可”。text 逐字不能改，已在 judge_by 放宽段补上慢变化的口径。

## ② 三条判据逐句核对

**来源**：第2课时〖PPT 第28页 · 自由写作 · 把习作写完：记住三件事〗下的师话，L356：

**切分时砍掉的**：第①条尾部“其他看到的可以一句带过，也可以不写”——它是放宽许可，不是可答是／否的判断项。砍掉后**前置**写进第①条 judge_by 的放宽段（“其余几处写得少或者没写，不许扣分”），并写进 `anti_patterns.secondary_trait_allowance`，判定口径不丢。

**为什么不用锚点一**：修改收束（L406–L424）是“达到哪一档，就按那一档修改”的档位驱动式改法，只有三档自检表和补写动作，没有三条自查问句。

**需要人复核的点：**

- 第①条 text 里“卡上圈出的”指观察发现卡，批改看不到卡。judge_by 写明“以稿纸上写得最多的一两处当作卡上圈出的那一两处”——请确认可以接受。
- **第①条与三年级不判详略**：服务端对三年级把 `whole_piece.detail` 记“不适用”，结构段里不许提详略、重点、主次。第①条 text 本身带“重点写”三个字，但它判的是本课技法“选一两处写清楚”，不是整篇详略安排。judge_by 已写明其余几处写少或不写都不扣分，并要求评语只说“写清楚”“写了几句”、不说详略主次。**请人确认这两条规则不会让模型在第①条的评语里说出“重点不突出”“详略不当”一类话**——若 Phase 0 实测里出现，要再收紧。
- 第①条门槛“一两处各写了三句以上 → 达成；有一处写了两句 → 部分达成”是我按详案 L147（每一项都只写了一句，没有一处写详细）和 L350（第一处已经写了好几句）定的，详案本身没给数字。

## ④ depends_on 判断与理由

**三条各自独立，不设 depends_on。**

- 第①条判有没有一两处写到三句以上，第②条判写了样子后有没有加上像什么或一种感觉，第③条判写了变化的有没有按先后分步。
- 课上两段对照的反例（样样一句）第①条未达成，但其中“头上两根触角细得像头发丝”仍可判第②条——两条不互为前提。
- 若设②依①，①只要“部分达成”②就会被连带记成不适用，一篇写了两句、其中已经加上比喻的稿子会丢掉第②条，过严。

**第③条的“不适用”不是 depends_on 触发的**，是判据自身的条件：详案 L346 明说“这一处没有变化的，这一步不必写”，优秀档也是“感官两种以上，或者写出了它的变化”二选一。judge_by 已把排除分支前置到开头：通篇没写变化 → 记“不适用”，不许写成“没有写出变化”。服务端 `tidy_advice` 对无 depends_on 的“不适用”会留空 advice，前端走中性色。**请人确认这样处理可以接受**（另一个选择是只在写了变化时才判、没写时判“达成”，但那会让老师误以为学生写了变化）。
