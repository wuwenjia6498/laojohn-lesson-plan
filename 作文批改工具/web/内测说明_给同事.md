## 开测前自己核一遍（不发给同事）

- 服务跑在前台终端，**关窗口即停、电脑休眠即断**——测试期间别锁屏。
- 确认是 mock 模式（启动时打印「模式：MOCK」），**别在这台机上配密钥**：配了 key 又开在办公室网里，同网段谁都能刷。
- 防火墙已确认放行（`D:\python\python.exe` 在公用网络配置下已有入站 Allow 规则，当前以太网正是公用网络）。换机器或换 python 路径要重新确认。
- 内网 IP 会随路由器分配变化，每次开测前用 `Get-NetIPAddress` 确认一遍再发出去。
