## P03 | 页型:原文齐读
眉标：白兔传说
标题：她死后，书里写了一个传说
正文：据说，那团圆媳妇的灵魂，也来到了东大桥下。说她变了一只很大的白兔，隔三差五地就到桥下来哭。有人问她哭什么？她说她要回家。
　　——节选自《呼兰河传》

## P04 | 页型:引导问题
眉标：凄凉的细节
标题：作者为什么偏要写这一段
要点：
- 故事到“她死了”，本可以结束
- 这只哭着“要回家”的白兔，让你心里是什么滋味
  参考：她活着时哭喊“我要回家”，没有一个人当真；这个最小的愿望，到死也没实现——作者用这个传说，让我们记住这个连名字都没留下的姑娘。
配图建议：白兔传说·东大桥下｜书中插页｜建议元素：白兔、桥、夜色

## P05 | 页型:原文齐读
眉标：祖父
标题：书快结尾时，还有这样一句
正文：呼兰河这小城里边，以前住着我的祖父，现在埋着我的祖父。
　　——节选自《呼兰河传》

## P06 | 页型:引导问题
眉标：一句牵挂
标题：你心里最放不下的，是谁

  参考：小团圆媳妇、祖父、逃荒的小主人、有二伯、冯歪嘴子……书中确有的人，说得出一句牵挂，都可以。

## P09 | 页型:要点小结
眉标：新工具
标题：六面体讨论图，这样用
要点：
- 六个面：联系、描述、比较、争论、应用、分析
- 围着“看客”一个话题，从六个角度去想
- “争论”“分析”两面，每组都要认真写满
- 其余四面，每组各挑一面写一写
- 判断要能回到书里找到例子
配图建议：无

## P10 | 页型:填空表格
眉标：分组讨论
标题：六面体讨论图 · “看客”
副标题：“争论”“分析”两面必须写满，其余四面各组挑一面写；每条想法都要带上书中依据。
表格：
| 面 | 这一面要想的问题 | 我们组的想法（含书中依据） |
| --- | --- | --- |
| 联系 | 书里的“看客”，让你联想到今天生活里、网络上的什么现象？ |  |
| 描述 | 书里的“看客”具体是什么样子的？举一两个书中的场面。 |  |
| 比较 | “看客”和书里真正对别人好的人（比如祖父）比，差在哪儿？ |  |
| 争论 | 这些“看热闹”的人，到底算不算坏人？说出你的理由。 |  |
| 应用 | 如果当时你在场，你会怎么做？今天遇到“围观”，你该怎么做？ |  |
| 分析 | 作者为什么要反复写“看客”？他想借他们说什么？ |  |

## P11 | 页型:要点小结
眉标：争论收口
标题：可怕的，也许不是某一个坏人
要点：
- 他们大多不是要故意害人
- 只是“随大流”“看个热闹”
- 可谁都不觉得有错的热闹，把一个大活人看死了
- 真正可怕的，是一群普通人凑在一起的冷漠
配图建议：无

## P12 | 页型:要点小结
眉标：谜底
标题：同一座城，反复响起“没有一个人”
要点：
- 大泥坑边：“没有一个人说把泥坑子用土填起来”
- 烫澡时：“并没有一个人上前去帮忙她”
- 看客里：没有一个人觉得自己做错了什么
- 填不平的坑、伸不出的手，是同一种冷漠
- 这就是导读课“为什么没人填坑”的真正答案
配图建议：无

## P13 | 页型:引导问题
眉标：两种活法
标题：一个闹给人看，一个默默要生根
正文：他觉得在这世界上，他一定要生根的。要长得牢牢的。
　　——节选自《呼兰河传·第七章》
要点：
- 有二伯：假装上吊、假装跳井，闹给人看
- 冯歪嘴子：众人等着看他绝望，他却要“生根”
- 你更愿意像谁那样活？放在心里，不用现在回答
配图建议：无

## P17 | 页型:引导问题
眉标：前后对照
标题：两个词之间，你走过了一本书
要点：
- 念出两头：第一节课写的词，和现在写的词
- 变或不变都可以，关键说得出那个“因为”
  参考：有人从“天很美”走到“又美又荒凉”；有人从“填不平的坑”走到“冷的不是坑，是人心”；两次都写“美”也行——现在的“美”更厚实了。
配图建议：无
