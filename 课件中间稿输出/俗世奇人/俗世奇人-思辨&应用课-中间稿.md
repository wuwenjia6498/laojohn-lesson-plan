## P44 | 页型:填空表格
眉标：思辨工具
标题：六面体讨论图 · 工具介绍
副标题：围绕一个主题，从六个固定角度依次展开，避免"说一句就散"。
表格：
| 面 | 这一面在问什么 |
| --- | --- |
| 联系 | 这件事和你自己/今天/现实生活，有什么联系？ |
| 描述 | 这件事具体长什么样？有哪些表现？ |
| 比较 | 它和别的事（或反面）比起来，有什么不同？ |
| 争论 | 这件事会有人反对吗？反方的理由是什么？ |
| 应用 | 在今天，我们能怎么用上这件事？ |
| 分析 | 把以上五面合起来看，你最终的判断是什么？ |

## P46 | 页型:填空表格
眉标：汇报参考
标题：六面体讨论 · 参考汇总
副标题：各组发言后，对照参考结果，校准本组判断。
表格：
| 面 | 本组讨论结果（参考） |
| --- | --- |
| 联系 | 想到苏七块——楼下修车师傅"先收钱再干活"；想到刷子李——老画家"不满意不收钱" |
| 描述 | 绝活：刷子李一身黑刷不出白点、泥人张桌下捏像、蓝眼一眼辨真伪；死规矩：苏七块七块银元、刷子李白点白刷 |
| 比较 | 绝活靠日复一日的"练"；死规矩靠不论亲疏的"忍"——两者都重要，规矩对人的考验更长 |
| 争论 | 死规矩不是为了别人，是为了自己——为了不被人情绑架、为了把事情做彻底，这不是制度能替代的 |
| 应用 | 学习：自己擅长的那一门；不抄、不糊弄、写完检查。工作：绝活让你不可替代，规矩让你被信任 |
| 分析 | 今天比百年前更需要"绝活"和"规矩"——世界更复杂，真本事和真诚信反而成了最稀缺的东西 |

## P47 | 页型:引导问题
眉标：人物速写
标题：仿照冯骥才——做一段 1 分钟的"我心中的俗世奇人"
要点：
- 写谁：身边一位真实的"靠绝活或规矩立身"的小人物
- 怎么写：不说他"很厉害"，只用一件具体小事让人觉得他"真厉害"
- 模仿冯骥才：动作 + 神态 + 一句"津味儿"白话
- 1 分钟内说完，随机请 3 位同学分享
配图建议：俗世奇人·封面｜书封｜建议元素：津门人物群像

## P48 | 页型:要点小结
眉标：合上书之后
标题：四节课下来，我们一起做了三件事
要点：
- 认识了一本"短篇小说集"——36 篇合成一座天津卫人物画廊
- 看清了贯穿全书的两条暗线——死规矩 + 公共空间
- 用上了这本书——写出今天的"俗世奇人"
- 带走两个词：绝活——愿意一辈子练下去的那一件；规矩——不论对谁都不肯松动的底线
