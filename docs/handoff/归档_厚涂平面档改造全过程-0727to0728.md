## 一、启动时的判断依据（原 `style-tokens.md` §「2026-07-27 厚涂改造的判断依据」）

抽查 一上（秋）第1次 六张成品图（主-01 / 练-01 / 备-01~04），对照厚涂绘本内页（《大狼和小狼》《雨天》一类），确认旧令牌下配图仍停在「教辅配图档」。根因四条，**其中三条在代码、不在详案**：

1. **薄媒介 vs 厚媒介**。旧令牌「水彩淡彩叠加彩色铅笔」是两个薄媒介，模型的先验解法必然是「线稿打底 + 柔和上色」，负面词「不要描一圈黑色轮廓」压不过正面词「彩色铅笔」——实测六张图全部出现细棕勾线。目标绘本用厚媒介（油画棒 / 厚水粉），形体靠色块边缘定形，根本不需要线。故令牌整体换为厚涂档。〔**已回滚**：现行仍是水彩淡彩叠彩铅〕
2. **画风事实源实际是三处，旧文档只登记了两处**。`_STYLE_REF_INSTR` 里硬编码的媒介描述漏改会让所有跟随图退回旧媒介——已在文件头改为三处口径。〔**仍有效**，三处口径留在活文件头〕
3. **陈列柜效应主要来自 build_prompt 的硬编码句**。旧句「画面必须同时清晰包含以下全部元素」把所有要素设为等权、等清晰、互不遮挡，虚实、遮挡、大小对比这些绘本语言全被禁掉——这是「教科书样」的**主要**贡献项，比画风段本身影响更大。已改为「近景教学层」句式：可读性护栏从全画面收缩到近景教学层，画面其余部分释放给色域与氛围；`must_see` 内容与机器验收链路完全不动。〔**仍有效且仍在跑**：`imgspec_parser.py` `build_prompt`〕
4. **重试循环劣化画风**。`process_strict` 缺项重生的追加句会把模型推向逐项摊平，重试越多越像教辅——已改为「补画进近景教学层、其余仍按色域与氛围处理」。〔**仍有效且仍在跑**：`generate_images.py` 缺项重生话术〕

**核心取舍**：绘本语言（大色域、虚实、遮挡）与教学硬约束（3 朵花要数得清、要素要圈得住）本质冲突，不能全要。解法是**把可读性护栏从全画面收缩到「近景教学层」**，教学硬约束一条不丢，机器验收链路不动。〔**仍有效**——已提回活文件〕

## 二、四轮措辞迭代（母图 备-03 · 全部作废，只留教训）

**第二轮（v1 实测后）**：首版厚涂令牌出图漂到「油画写生档」而非目标绘本档，三条召唤词被证实——① 「粗纹纸纹透出」「像真实画在纸上再扫描进书里的原作」在召唤纸边，白边反而更重，否定句「满幅出血」压不住，改为正面描述「已经裁切好的绘本内页、颜色覆盖到图像最外一圈边缘」；② 「颜料有明显厚度与堆叠」「笔触短促、有方向性」在模型先验里指向 alla prima 油画写生（笔触塑造体积：猫毛刷出圆柱感、窗框做木纹转折），媒介改「油画棒与蜡质色粉笔」＋明写「物体是平的色块、不做体积感、接近剪贴画」；③ 删「配色低饱和」时没补替代表述导致饱和度失控，补回「低饱和、以浊色为主（掺灰的绿、掺土的黄、掺灰的蓝），仅跳色允许高饱和」。**教训：正面描述目标画法，别用否定句去压强召唤词；删旧约束时必须补等价替代。**〔教训**仍有效**——已提回活文件〕

**第三轮（v2 实测后，画风档位曾在此定稿）**：v2 平面化、浊色、蜡质颗粒、剪贴式剪影均已咬住，档位定稿；收尾两件事——

- **白边改走工程解，令牌不再承担此责任**：两轮措辞（否定句、正面句）都压不净白边，定案为 `generate_images.py` 的 `trim_border()` 落盘后自动裁边（四边逐行扫白带 + 中心裁回 4:3，阈值 `_TRIM_LUMA`/`_TRIM_STD`，四边裁量超任一边 15% 判异常不裁）。**后续调令牌时不要再往里加满幅出血相关措辞**——现存出血句保留（能减少裁量），但白边达标与否以裁边后为准。〔`trim_border` **仍有效**，已在活文件净收益表登记〕

**第四轮＝最后一次措辞迭代，风格控制主责移交锚图（v3 实测后定案）**：v3 修好了舒适感，却回弹三处——猫身一圈等粗红棕描边（勾线回来了）、浊色被冲掉（饱和度上去）、整体漂向商业萌系档。祸源是「讨喜」「剪影形状」这类词在往模型默认萌系档拉。三轮修订每次都按下葫芦起了瓢，**结论：文字撑不住风格**，与 `image-spec.md` 既有结论「画风不靠形容词、靠参考图」一致。

本轮只做最后一次微调（删「讨喜」、「剪影形状」改「外形」避免被理解成描轮廓、追加「不沿角色轮廓描一圈线／外缘不得有连续封闭轮廓线」、造型规则前重申色彩优先级），随即**转入阶段二：全期风格锚图**。

## 四、随改造一并作废的造型规则（令牌与代码里均已不存在）

- **主体角色造型规则（平面化的代价补偿）**：v2 的猫显得病恹恹（眼睛下垂细缝、嘴角向下、身体摊平），因为「不做体积感」把塑造舒适感的手段一并收走了。解法是**靠形状与五官补、不是退回体积塑造**：主体剪影要饱满讨喜（睡卧团成一团）、五官明确传达情绪（眼弯嘴平、可加腮红）、主体下方一块单色投影托底。毛糙边同时加了限定：只适用于画面内部色块交界，不适用于图像最外边缘。

〔**全部作废**：这套规则是「不做体积感」的代价补偿，而「不做体积感」＝厚涂平面档的核心，随改造终止一并失去前提。0730 核查确认 A / B 两档令牌与 `imgspec_parser.py` / `generate_images.py` 里都没有这些措辞。**重启改造前不要单独把它加回令牌**——现行水彩淡彩档本就有体积与光影，「投影托底」「剪影饱满」在这一档会朝商业萌系拉（与第四轮的回弹祸源同型）。〕
