## 三、A 约束层（`ability-ladder.md` 期6 分教点 B 原文摘录）

- **不可越阶**：补上听得见的（语言）与想出来的（心理）两问，**四问至此配齐**；仍不讲动作链、比喻拟人、多图串联（各留其课次）。**「语言」这一问只写人物说的话，不承担推进情节**（对话推进留二上第 14 次）。
- **课时结构（本条特有，不照搬课型表）**：**第 1 节 ＝ 方法回顾＋补【两想】两问（15′）→ 新图圈画 → 当堂写作**（练习课通用结构里的「方法回顾(5′)」在本课扩为 15 分钟，因为要补两问的新授）；**第 2 节仍按练习课通用结构走**（当面批改 → 修改提升 → 朗读分享）。
- **支架强度**：发提示卡的**【两想】面**（③语言 ④心理，看不见的照画面想）——**两张薄卡分次发、到本课才拼成完整四问卡**（低年级一次拿两张薄卡比一次拿一张信息量大的卡更好接受，这是分次发的理由，不是权宜之计）。课内分层：想不出心理者用「他心里可能在想什么」单问起步；已会者要求四问里稳定用上两问以上、**且说得出各自的画面依据**。
- **例文要求**：在第 2 次例文的基础上**加写语言与心理两处**，批注这两处是从画面上哪一点「想」出来的（防脱离画面编造）。主图须**含一处意外点**——【两想】两问靠它落地，无意外点即一票否决。

### ⚠ 「在第 2 次例文的基础上」怎么读（歧义，先定了再写）

**不是**把第 2 次那篇（写元宝叼走球鞋）搬过来加两句——第 3 次有自己的主图，而 `model-essay.md` 与门禁 2 都要求**例文逐句回溯本课主图的必须可见元素清单**，搬过来就越清单了。

**正确读法＝形态承接**：新写一篇写**本课主图**的例文，结构上比第 2 次多出语言与心理两段/两处，让老师看得出「四问配齐是什么样」。可以在师话里点一句「上次我们写到脸上就停了，今天再往下加两样」，做**教学上的承接**，但**例文本身是新的**。

## 四、与第 2 次的三个咬合点（丢了就露馅）

### 1. 两张薄卡要拼成完整四问卡

第 2 次发的【两看】面（已印，学生随身），卡面实际长这样：

```
细节四问 ·【两看】
① 他在怎么做？    动作
② 他脸上什么样？  表情
看得见的，用眼睛找
```

第 2 次的详案里明说了：「**卡的背面现在是空的，下次课老师再发一张贴上去，两张拼起来才是完整的四问**」。所以本课的【两想】面**必须与它同形对仗**：

```
细节四问 ·【两想】
③ 他会说什么？    语言
④ 他心里想什么？  心理
看不见的，照着画面想
```

配套物料侧同理——`laojohn-picture-materials` 的支架小卡走 `type: "quad"`、**2 个 boxes**（第 2 次已验证 2 盒能正常渲染，`.quad` 是 2 列 grid、`align-content:center`）。

### 2. 核心口诀是规定动作，必须整句说

「**看得见的用眼睛找，看不见的照着画面想**」——`ability-ladder` 期6 明写各课次一律保留、不得删改。第 2 次说这句时，**后半句是预告**（「那是下一次课的事」）；**本课要把后半句兑现**，这是两课之间最自然的接口，别浪费。冷审 Pass B 也不得按「对仗句每课限一句」删它。

### 3. 感官归类判据（已两次实测命中的固定错法）

**拟声词与声音细节属「听得见的」，按两看两想归【两想】侧**（照着画面想出来的声音）。例文批注与 `〔圈画核对·X〕` **不得把拟声词标成「看得见的」**——这是已两次命中的错法，本课教【两想】，风险最高。

## 五、反同质化清单（第 2 次已经用掉的，本课换掉）

| 维度 | 第 2 次用掉的 | 本课要求 |
|---|---|---|
| H1 | `细节四问——把动作和表情写出来` | 换写法（同一方法的第二课，副题点【两想】） |
| 课时小标题 | 第1课时 `从"他在追狗"到"看得见他在追狗"`（句式①从…到…）／第2课时 `动作和表情，写下来再改一遍` | 两句式都别复用；第 2 课时仍须收束到「写下来／改」 |
| 环节名构词法 | 「两句话摆一起」「他在做什么」「他脸上的样子」「在图上圈两处」「老师先写一段」「新的一张图」「回头改两处」「念给全班听」 | 冒号前半截同一构词法 ≤2 次、无 `X一X` 复叠动词连排；**别与上表任何一条同形** |
| 开场方式 | 出示主图 → 学生说一句 → 老师给「平淡 vs 生动」两句对比 → 数第二句多说了什么 | **换一种**（本课是练习课，第 1 节起手是「方法回顾」，天然不同——别又做成对比句） |
| 两问的引出方式 | 动作＝「看图找」（老师逐处指身子／手／脚）；表情＝「反问」（只念动作那几句，让学生听出少了脸） | §13.1 要求并列点引出句两两不同构；**这两种切入都已用掉**，语言与心理再换两种 |
| 追问链拆法 | 存量三套已用：①「先用了哪一问？→ 还有呢？→ 教师清点」②「用上了哪几问，一个一个说 → 接着说 → 四问都在里头了」③（第 2 次）「你是从哪儿看出来的？→ 指一指 → 教师归并命名」 | **换第四套**；四问的清点与两看两想的归并**由教师话轮说**，不许一句 `参考：` 报全 |
| 禁止再现的两句 | `参考：四个都用上了——动作、表情、语言、心理。`／`参考：〔几样〕是看得见的；〔几样〕是想出来的。` | 逐字与近似**一律禁用**（tone_gate 已机检） |
| 学生称呼 | 「（对第二个说的那位同学）」「（对说得短的那位）」 | 别整篇复用同一种指认方式 |

## 六、本轮（0804）新立的规则，写图位规格前先看

`image-spec.md` §A 硬线区新增**三条**，都是第 2 次出图实际栽出来的，本课直接受用：

1. **逆着运动方向的朝向**（回头看／扭身看）——四件几何写全了仍不够，要另加「头与身体的相对关系」＋两条偷懒禁令（严禁头朝行进方向、**严禁只把眼珠转过来而头不转**）。
2. **表情类五官要写两端的相对高低，不能写形容词**——「扬起／皱起／抿着嘴」都是结果词。**本课主图要写「吃惊」和「相视而笑」两种表情，正撞这一条。**
3. **同一处画面写两条要求时，先自问能不能在同一个姿势里共存**——「提离箱底」与「爪扒箱沿」物理打架，模型二选一、另一条静默落空。

**配套的正反真图对照**在 `.claude/skills/laojohn-picture-writing/assets/测试件/反例对照-0804/`（四组，含 README 说明各对应哪条硬线）。写规格前扫一眼，比读文字快。

另外两条工程修复（已落地，知道即可）：
- `generate_images.py` 落盘新增 `ensure_real_png()`——模型常返回 JPEG 字节，旧代码原样写成 `.png`，**Photoshop 打不开**（详见 `references/imggen-pipeline.md` 新增节）。
- `图位/_历史/` 已入 gitignore（废版只留本地）；有复用价值的失败样本，**先裁诊断切片进 `assets/测试件/反例对照-<日期>/`** 再让原件留本地。
