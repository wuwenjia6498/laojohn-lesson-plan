# 换机装机清单

换电脑、重装系统或重装 Claude Code 之后，从上到下照做一遍，就能像旧机器一样跑全仓流水线。**最后一步跑 `setup_check.py`，全绿才算装完。**

- 这份清单只管「装什么、拷什么」。日常同步、冲突处理、为什么这样设计，见 `docs\协作同步说明.md`。
- 本清单的机检面是根目录 `setup_check.py`，依赖清单是根目录 `requirements.txt`。三处要一起改。
- 2026-10-16 重装 Claude Code 时整理（当时缺：Python 包一半、ffmpeg、写作海报字体解码包）。

## 一、装软件

```powershell
# Python：装官方版（python.org 或 winget），勾选加入 PATH。之后一律用 python，不用 python3
winget install Python.Python.3.13        # 3.13 最稳；3.15 也能跑（个别包要替代，requirements.txt 已处理）

# Office（Word + PowerPoint）：docx/pptx 转 PDF/PNG 只有 COM 这一条路，必须是本机装的桌面版

# ffmpeg（备课视频、宣传片）
winget install --id Gyan.FFmpeg -e

# Git
winget install Git.Git

# 编辑器 Cursor，然后开自动保存（见第五步）

# 可选：Node（只有官方 skill 新建路径用，本仓生产不依赖）、gh（只在终端看 PR/issue 时用）
winget install OpenJS.NodeJS.LTS
winget install GitHub.cli                # 装完 gh auth login
```

**不要装 LibreOffice / pandoc**：本仓不走那条路（CLAUDE.md §5）。
**不要用 Playwright 自带的 ffmpeg**：它出不了 mp4，脚本会主动跳过它。

## 二、拿仓库

**项目在移动硬盘上、整盘带过来的**：跳过克隆，直接进第三步。

**新克隆**：先让仓库主人邀请你进私有仓库，再按 `docs\协作同步说明.md` 第一节配身份、克隆。要点：

```bash
git clone https://github.com/wuwenjia6498/laojohn-lesson-plan.git
cd laojohn-lesson-plan
git config --local user.name  "<你的 GitHub 用户名>"
git config --local user.email "<你的 GitHub 邮箱>"   # 别照抄 git log 里的历史作者
```

## 五、Claude Code 与编辑器

**1. 记忆联接**（最重要。联接断了不报错，只表现为 Claude「什么都不记得」）

先在项目里打开一次 Claude Code，让它生成用户目录下的项目文件夹，再做联接。路径里的 `<编码>` 是项目路径把 `:` 和 `\` 换成 `-`，例如 `D:\laojohn-lesson-plan` → `D--laojohn-lesson-plan`（`setup_check.py` 会把实际路径打印出来）。

```powershell
# 原目录若已存在且有内容，先改名留底（合并步骤见协作同步说明第三节）
Rename-Item "$env:USERPROFILE\.claude\projects\<编码>\memory" "memory_backup"
cmd /c mklink /J "$env:USERPROFILE\.claude\projects\<编码>\memory" "<项目根>\.claude\memory"
```

⚠ **项目在移动硬盘，盘符一变，`<编码>` 就变**，联接要按新盘符再建一次。

**2. 用户级 skill**

```bash
git clone https://github.com/wuwenjia6498/handdraw-style-prompter.git "$USERPROFILE/.claude/skills/handdraw-style-prompter"
```

其他用户级 skill（如 `h3-prompt-writing`）从旧机器 `~\.claude\skills\` 拷。随 claude.ai 账号同步的 skill 会自动出现，不用管。

**3. Cursor 自动保存**：在 `%APPDATA%\Cursor\User\settings.json` 里加

```json
"files.autoSave": "afterDelay",
"files.autoSaveDelay": 1000
```

不开的话，编辑器里没保存的手改会被脚本读写冲掉，而且救不回来。

**4. 不用配的**：`.claude\settings.json`（SessionStart 记忆索引机检 hook）随仓库走，克隆即有。

## 六、自检（必做）

```bash
PYTHONUTF8=1 python setup_check.py
```

每项打印 `[OK]` / `[缺]` / `[提醒]`，`[缺]` 后面直接给补救命令。补完再跑，直到最后一行是「全部通过」。

然后在 Claude Code 里问一句：**「编辑器里没保存的手改有什么风险」**。答得出「会被脚本读写冲掉、Cursor 已开自动保存」，记忆联接就是通的。

## 七、可选：抽一条线回归

自检只证明「东西在」，想确认「真能出件」，各抽一份输出到临时目录比对（**别覆盖正式产物**）：

```bash
# 读书会 PPT（旧样式，不依赖 AI 图）
PYTHONUTF8=1 python .claude/skills/laojohn-ppt/scripts/build_ppt.py \
  --input "读书会课件中间稿输出/俗世奇人/俗世奇人-导读课-中间稿.md" --output "<临时目录>/test.pptx"

# 写作课海报（验毛笔字解码与插画抠底）
PYTHONUTF8=1 python .claude/skills/laojohn-writing-poster/scripts/render_writing_poster.py \
  "写作课海报输出/三上-第一单元-猜猜他是谁/三上-第一单元-猜猜他是谁-习作海报.json" --out-base "<临时目录>/poster"
```

海报标题应是毛笔字；若是楷体，说明 `fonttools`/`brotlicffi` 没装上。
