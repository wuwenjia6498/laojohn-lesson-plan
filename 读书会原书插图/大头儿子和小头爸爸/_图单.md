| 插-14 | 大头儿子和隔壁大大叔 · 过生日 | 单页。客厅沙发上，隔壁大大叔（大黑胡子）仰面躺着，脖子上系着一块**粉色围嘴**，睁一只眼笑着。沙发前的小圆桌上放着一只**生日蛋糕**：白色奶油花边、红色果粒、插着一支点燃的彩色蜡烛，已切走一块、露出彩虹夹层。桌两侧站着小眼睛（黑短发、红外套、驼色围巾）和大头儿子（黑上衣、格子灯笼裤、棕靴），两人各举一把**小叉子**（一红柄一蓝柄），叉尖上挑着奶油，隔着大大叔的身子朝对方举。**咬合点**：「等“小毛头”醒来时，好哇，他看见他的“爸爸”和“妈妈”正坐在那儿吃他的生日蛋糕呢！」——蛋糕被切、两人举叉、大大叔躺着看，三项可对。⚠ 原文两人是**坐着**吃，画面是**站着**；粉色围嘴是画面独有的道具，原文未写 | |
| 插-15 | 大头儿子和隔壁大大叔 · 两座纸房子（前半：做房子） | 单页。水泥地上立着一座**纸箱做的房子**：瓦楞纸屋顶、贴着一根砖纹烟囱（冒出一缕白烟）、箱面上剪出门洞和窗、接缝处贴着数条胶带。小眼睛（黑短发扎两个小揪、红上衣背带裙）站在房子前，双手捧着一块**剪出两个方窗的纸板**；大头儿子（浅蓝条纹连体睡衣）站在房子右后方，高举一块画着格子的纸板，另一只手拿着彩笔。地上散落彩色蜡笔、剪刀、一支胶枪、一块纸板和一只草莓图案的粉色水壶。**咬合点**：「他把冰箱和洗衣机拿出来放好，然后用一把剪刀和一支彩笔，将两只大纸箱做成了两座漂亮的纸房子」——大纸箱、剪刀、彩笔三样都在画面里。⚠ **画文不一致（重要）**：原文明写房子是**隔壁大大叔做的**，画面里在动手做的是**两个孩子**、大大叔不在场；且画面只有**一座**成型。**不要用这张图问「是谁做的房子」** | |
| 插-16 | 大头儿子和隔壁大大叔 · 两座纸房子（后半：夜里“刮台风”） | 单页。房间熄了灯，一片灰暗。天花板正中一台**绿色叶片的电风扇**在转，画面里布满自上而下的白色风线；两侧墙上各有一扇细长的亮窗。地面上并排立着**两座相连的纸箱房子**（左小右大，各有烟囱和窗、贴着胶带）：左边小房子的门洞里，小眼睛盘腿坐着、双手**捂住脸**；右边大房子的门洞里，大头儿子（浅蓝条纹睡衣）盘腿坐着、抱着一只黄色小狮子玩偶，皱眉抬眼往上看。地上仍散着蜡笔、剪刀、水壶和玩具。**咬合点（本篇最强）**：「忽然，一阵大风呼啦啦吹过来，把两座纸房子吹得左右直摇，马上就要倒下来了」＋「原来是天花板上的电风扇在呼啦啦、呼啦啦地吹……」——**谜底（电风扇）与两人害怕的样子画在同一张图上**，学生看图能先于书中人物发现真相。⚠ 两处对不上：原文两座房子是**各自分开**的，画面里**连在一起**；原文说两人「分别在门上写了101号和102号」，**画面上找不到门牌号** | |
| 插-17 | 大头儿子和隔壁大大叔 · 开心极了的大胡子 | 单页。米色沙发上四个人挤成一堆：隔壁大大叔（大黑胡子）仰头张大嘴笑，**一只淡蓝色口罩挂在左耳上、已脱离口鼻**；他怀里坐着小眼睛（黑短发、紫色圆点连衣裙），仰头大笑；右侧大头儿子（藏蓝上衣）张嘴笑着、一手搭在沙发背上；后方沙发靠背上趴着一位**长黑发女性**（橙色上衣配蓝白条纹袖），笑着伸出手。右后方立着一盏深蓝灯罩的落地灯。**角色**：后方长发女性＝小眼睛的妈妈（依「大头儿子在家里等小头爸爸，却等来一位陌生的阿姨」及结尾一家团聚）。**咬合点**：「他的大胡子和大嘴巴一使劲，竟把口罩也给绷掉了」——**绷掉的口罩就挂在耳朵上**，这个细节画得清清楚楚，**学生能自己找出“口罩去哪了”**。⚠ 画面里**只有四人**，小头爸爸不在场 | 课案详案 · 第2课时环节二「一本书里的四个大人」：说到第四辑那一支时看图，找“口罩去哪了” |
