## 角色识别与判读口径（选图前必读）

- **各篇人物不跨篇复现**。插-05 夜莺篇的学生与插-12 忠实的朋友篇的小汉斯，画家都画成白衬衫、背带裤的青年，造型相近，**不是同一人**，不要让学生把两幅连起来认。
- **三幅归属未锁定**：插-08（花园属哪一篇）、插-11（小屋属谁）、插-18（宫中行走者是谁），另有插-17（场景）、插-22（镜中人）只能倾向判定。各条已列候选，**选用前须再核**。
- ⚠ **凡数量类观察，先查本条**：插-14 驯鹿（原文六匹）、插-12 羊群（原文「一大群」）、插-21 猴子（原文「几个」）——画面数目与原文对不上或原文没给数，**不得让学生数数**。能对上的只有：插-21 吉卜赛小孩正好两个、插-28 樵夫正好两个、插-26 孔雀一白一蓝两只。

| 插-01 | 快乐王子 · 开篇·高圆柱上的像 | 竖幅。一尊通身金黄的王子立像，头戴小王冠，披斗篷，右手持一柄细长的剑斜指地面，立在圆形石座上；背景是浅色天空和粉蓝色点状的花丛。**咬合点**：「快乐王子的像在一根高圆柱上面，高高地耸立在城市的上空。他满身贴着薄薄的纯金叶子」——通身金色可对。⚠ 画面上**眼睛与剑柄的宝石看不清**，不要让学生在图里找蓝宝石、红宝石；原文是「高圆柱」，画面石座很矮，城市也没画出来，师话按画面说 |  |
| 插-02 | 快乐王子 · 燕子恋芦苇 | 竖幅。米白底上，一只深蓝黑色、剪刀尾的燕子在上方展翅飞；下方一丛**橙红色**的芦苇（芦穗低垂）随风弯向一侧。**咬合点**：「因为他恋着那根最美丽的芦苇」「风一吹，芦苇就行着最动人的屈膝礼」——芦苇弯腰的姿态可对。⚠ 原文河边「长满了芦苇」，画面只是一丛；芦苇画成橙红色是画家用色 |  |
| 插-03 | 快乐王子 · 燕子把蓝宝石送给卖火柴女孩 | 竖幅，黑底。左侧一只燕子衔着一颗**蓝色宝石**飞来，周围一圈金黄色光点；右侧一个红色长发、穿灰褐色旧衣的女孩蹲坐着，**双手并拢摊开**接向燕子，**光着双脚**。**咬合点**：「她没有鞋、没有袜，小小的头上没有一顶帽子」——赤脚、没戴帽子学生一眼可见；「把宝石轻轻放在她的手掌心里」——摊开的掌心可对。⚠ 原文她是「站着」，画面是蹲坐；画面里**没有火柴** |  |
| 插-04 | 快乐王子 · 灰暗的像与脚下的死燕子 | 竖幅。同一尊王子像，通身已变成**灰绿色**，没有一点金色；背景是成片光秃秃的深色枝干；放大可见石座上、王子两脚前方躺着一只**仰面的小燕子**。**咬合点**：「最后快乐王子就变成灰暗难看的了」＋「他脚下还有一只死鸟！」——与插-01 并排看，金色→灰色的变化学生能自己说出来。⚠ 死燕子很小，投屏须放大；原文燕子死前下着雪，画面看不出雪 |  |
| 插-05 | 夜莺与蔷薇 · 学生躺在草地上·夜莺在橡树上 | 竖幅。上方横伸一根褐色粗树枝，叶子蓝绿色，枝头站着一只**棕褐色小鸟**；下方浅色草地上，一个白衬衫、背带、褐色短裤、白长袜的青年**仰面躺着、双手枕在脑后**，睁着眼。**咬合点**：「夜莺在她的常青橡树上的巢里听见了他的话」「突然她张开她的棕色翅膀」——棕色小鸟、树上可对。⚠ 原文学生是「扑倒在草地上，双手蒙住脸哭起来」，后文也是「仍然躺在草地上……泪水还不曾干去」，**画面是仰躺、双手枕头、没有哭**，师话按画面说，不得说「图里他在哭」 |  |
| 插-06 | 夜莺与蔷薇 · 蔷薇染红晕而花心仍白 | 竖幅，深蓝黑底、蓝色大叶子。正中一朵盛开的蔷薇：**花瓣外缘一圈粉红，花心仍是白的**。**咬合点**：「一层娇嫩的红晕染上了蔷薇花瓣……所以蔷薇的心还是白的，因为只有夜莺的心血才可以把蔷薇的心染红」——外红内白正是这一句的瞬间，学生能自己读出「刺还没到心」。⚠ 也可能被读成刚开的白蔷薇；对读时须先念这句原文再看图 |  |
| 插-07 | 夜莺与蔷薇 · 夜莺死在草丛中 | 竖幅，黑夜。顶上一轮白色圆月；中部一大片黑色花丛，点缀着许多白色小蔷薇，最高处**只有一朵红蔷薇**；下方浅绿草地上躺着一只褐色小鸟，**一根黑色的刺茎扎进它的胸口**，伤口处有红色。**咬合点**：「因为她已经死在长得高高的青草丛中了，心上还带着那根蔷薇刺」——刺扎在胸口可直接对上；「明月听见它，居然忘记落下去」——月亮还在天上可对。⚠ 原文那棵是长在学生窗下的红蔷薇树，四周的**白蔷薇是画家添的**，不要据此说「书里写这棵树上还有白花」 |  |
| 插-08 | 自私的巨人（**归属未定**）· 花园 | 竖幅。浅绿色天空下几棵大树，前景一大丛开着**白色小花**的灌木，右下有粉红色花和黄色草丛；画面里**没有人物**。归属判断：按原文件编号位于巨人篇诸图之间，可对「这是一个可爱的大花园，园里长满了柔嫩的青草。草丛中到处露出星星似的美丽花朵」；但原文点名的「十二棵桃树」画面看不出，**也可能是别篇（如小汉斯的花园、小矮人的树林）**。**选用前须再核**，师话只说「一个开满花的园子」，不要断言是巨人花园哪一时刻 |  |
| 插-09 | 自私的巨人 · 最远角落的冬天与够不着树枝的小孩 | 竖幅。一棵光秃秃的深褐色大树，枝上挂着雪；树下地面是一个**白色雪圈**，圈外是绿草地和绿灌木；雪圈里站着一个穿橙褐色衣服的**小小孩**，仰头望树，空中飘着雪点。**咬合点**：「只有在一个角落里冬天仍然留着……一个小孩正站在那里。他太小了，他的手还挨不到树枝」＋「这株可怜的树仍然满身盖着霜和雪」——**圈外绿、圈内白**，学生能自己看出「只有这一处还是冬天」 |  |
| 插-10 | 自私的巨人 · 满身白花的老巨人 | 竖幅。一个白发、闭眼、面带笑意的老人站着，**双手交握**在胸前，从衣服到裤腿**落满了白色小花**。**咬合点**：「他已经死了，满身盖着白花」——满身白花可对。⚠ 原文是「巨人躺在一棵树下」，**画面是站着、看不到树**，也看不出已死；师话按画面说，不得说「图里画的是他死了躺在树下」。`_备选\插-10_裁切版.jpg` 是同图只剩上半身的裁切版 |  |
| 插-11 | 忠实的朋友（**归属倾向小汉斯**）· 小屋与花园 | 竖幅。蓝绿天空下几棵树，中间一座**白墙、绿顶、红色烟囱**的小房子，一条白色小路弯进门口，房前屋后开满白、粉、紫、红各色花。归属判断：可对「他一个人住在一间小茅屋里，每天在他的园子里工作。在他那一带地方没有一个花园像他的那样可爱的」；但**原文点名的花（美洲石竹、紫罗兰、樱草……）画面辨认不出**，房子也不是茅草顶。按原文件编号位于本篇，**选用前须再核**，不要让学生在图里认花名 |  |
| 插-12 | 忠实的朋友 · 小汉斯赶羊上山 | 竖幅。蓝天下的灰白色山坡，一个戴灰色鸭舌帽、白衬衫、背带、深蓝长裤的青年站在坡上远望；他身旁、身前是挤在一起的**白色羊群**。**咬合点**：「因为我明天还要你把我的羊赶到山上去」「汉斯只好带它们上山去」——山坡、羊群可对。⚠ 原文小汉斯有「一张很滑稽的、和善的圆脸」，画面看不出圆脸；羊的只数原文未写，**不要数羊**；造型与插-05 学生相近，不是同一人 |  |
| 插-13 | 忠实的朋友 · 暴风雨夜赶路 | 竖幅，通幅灰色。斜斜的大雨中，一个人撑着一把被风吹翻的**黑伞**，斗篷向后扬起，弓身往前走；**手里没有灯笼**。**咬合点**：磨面师不肯借灯笼（「对不起，这是我的新灯笼」），小汉斯答「好，不要紧，我不用它了」——**画面里他手中空空、没有灯笼**，学生可以自己看出来；「风刮得很厉害，他几乎站不稳了」——弓身顶风可对。⚠ **原文没有伞**，小汉斯是穿戴「宽大的皮衣和那顶暖和的红色便帽」、缠着围巾出门的，画面灰色看不出红帽；伞是画家添的，不得说「书里写他打着伞」。`_备选\插-13_裁切版.jpg` 是同图裁切放大版 |  |
| 插-14 | 了不起的火箭 · 驯鹿拉天鹅雪车 | 横构图的竖幅。灰色树林雪地里，**驯鹿拉着一辆金黄色天鹅形雪车**向左奔跑，车上坐着一个通身白色、看不清面目的人。**咬合点**：「坐着六匹驯鹿拉的雪车从芬兰一路赶来的。雪车的形状很像一只金色大天鹅」——天鹅形、金色可对；「她那件银鼠皮的长外套一直盖到她的脚」「她的脸色苍白」——通身白色可对。⚠ **画面只见两匹驯鹿，原文是六匹，不得让学生数驯鹿** |  |
| 插-15 | 了不起的火箭 · 阴沟里的小蛙与火箭 | 竖幅。前景一支斜躺的红色火箭，尾端是一个黑色圆筒口；右上一只**青绿色、带斑点**的青蛙趴着看它，眼睛是发亮的橙色；背景是红色和白色的芦苇丛。**咬合点**：「随后一只小蛙（他有一对嵌宝石的发光的眼睛和一件绿色斑点的上衣）向着火箭泅水过来了」——发亮的眼睛、绿色带斑点都可对。⚠ 原文火箭落在「阴沟」「烂泥里」，画面看不出泥水；原文火箭「绑在一根长棍子的头上」，画面棍子不明显。`_备选\插-15_裁切版.jpg` 是同图裁切放大版 |  |
| 插-16 | 了不起的火箭 · 白天天空中的烟火 | 竖幅。**大片蓝天**下一朵紫蓝色烟火炸开；下方是黄绿色草地、远处几棵树和右侧一丛灌木；**画面里没有一个人**。归属判断：按「蓝天」与「无人」倾向本篇结尾——「他们要在青天白日里燃放我，让每个人都看得见」＋「可是没有一个人看见他」，学生可以自己从「大白天、一个人也没有」读出火箭最后这一飞的处境。⚠ 也可能被读成婚礼午夜的烟火，但原文那场在「午夜」、园里挤满人；**选用时先念结尾原文再出图**，不要说「图里是婚礼的烟火」 |  |
| 插-17 | 少年国王（**场景未定**）· 戴王冠坐在宝座上 | 竖幅，深蓝底。一个短发少年头戴**镶红绿宝石的金王冠**，披红色短斗篷，白衣白裤黑鞋，**跷着二郎腿**、一手托腮、一手搭在蓝色宝座扶手上，正面看人。归属判断：少年、棕色头发，可对「他把他的棕色鬈发从前额向后掠回去」；但**原文他从没戴过这顶王冠**——加冕前夜他只是「靠在豪华的长沙发椅上」想象自己穿王袍，加冕日拒穿，最后头上是荆棘圈。画面可能是他「在想象中看见他自己穿着华贵的王袍」，**不得说「书里写他戴着王冠坐在宝座上」** |  |
| 插-18 | 少年国王（**归属倾向少年国王**）· 宫中拱廊与喷泉间行走 | 竖幅。灰色粗柱与白色拱门，红色地面，右侧一座白色喷泉在喷水；左下角一个很小的人物，**头戴小王冠**、穿深蓝长外套，向画面外走去。归属判断：可对「他总是立刻跑下那道装饰着镀金的铜狮和亮云斑石级的大楼梯，从一间屋子走到另一间屋子，从一条走廊走到另一条走廊」；戴王冠这一点同插-17，原文加冕前他并未戴冠。另一候选是《西班牙公主的生日》小矮人入宫寻公主，但小矮人「驼背，拐脚」，画中人身形端正，不符。**选用前须再核** |  |
