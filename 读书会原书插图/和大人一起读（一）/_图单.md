**⚠ 本书最需防错处**：
1. **《小兔子乖乖》原文没写敲门的是谁**——童谣只有「我要进来」，大灰狼完全是画面给的。`插-03` 狼与 `插-05` 兔妈妈**穿戴一模一样**（橙底白点头巾、紫裙、粉围巾），全靠**尾巴**区分：`插-04` 门外露的是灰色蓬松大尾巴，`插-06` 门外露的是白色圆尾巴。这是本书最好的看图推理材料，但讲「狼」时须说明是「画上画的」，不能说「书上写着大灰狼来了」。
2. **《程门立雪》《胸有成竹》两图都有两个古人，谁是谁原文锁不住**，写「未定」，不要让学生指认名字。
3. **多处画文不一致**（《松鼠和松果》多出一只松鼠、《比画风》开篇没画小猪、《磨刀不误砍柴工》画的不是枯树、《程门立雪》没成雪人等），见各行 ⚠；这些地方一律**师话按画面说**。

**2026-10-09 裁切/压平**：去掉了翻拍带进来的书脊、邻页、页边阴影；只占半页的画面已裁掉空白，**图片不再统一是整页比例**。图单里「画面在上/下半部」「满版」「单页」等说法指的是原书版面，不是现在的图片。跨页图中缝无法翻拍压平，原样保留。逐张裁切框见 `_清洗记录.json`「裁切」。

| 插-15 | 胸有成竹 | 满版。竹林和一块太湖石前，两位古人站在书案边。左边一位穿蓝色长袍、戴黑色高帽、留长须，右手执毛笔，左手按着纸，纸上画着几枝墨竹；案上一方砚台。右边一位穿白色长袍、戴黑色高帽，拱着手站在旁边看。**咬合点**：「文与可特别爱画竹子」「他家院子里栽满了青翠的竹子」——竹林、执笔画竹都在图上。角色：执笔画竹者依「文与可特别爱画竹子」判为**文与可**；**白袍人未定**（候选：「有人问文与可画竹的秘诀」里的那个人；原文未写他的样子）。⚠ 原文「猫把画上的竹子当成真的」那段**画面没有画猫** | |
| 插-16 | 画龙点睛 | 单页，画面在上半部。漫天白色祥云中，**两条青黑色的龙**张着大嘴、瞪着大眼睛，身子缠绕着腾空而起；龙身旁有红色火焰形和一角金黄色的屋檐。右下方一个穿红色长袍的古人，一手高举毛笔，身子向后仰，一手张开，像是被吓了一跳。**咬合点（本篇最强）**：「他刚刚画完……两条龙腾云驾雾，飞向天空」——**飞走的正好是两条，可以数**；两条龙的眼睛都画得很醒目，正是“点上了眼睛”的那两条。角色：执笔者依「张僧繇只好挥动画笔」判为**张僧繇**。⚠ 原文还有「没有点上眼睛的那两条龙，依然留在墙壁上」，**画面没有画墙壁和另外两条龙**；「电闪雷鸣」画面也没有闪电，不要让学生在图上找 | |
| 插-17 | 望梅止渴 | 满版。橙黄色的天空、一轮红日，远处是长着树的绿色山丘，地上一片枯黄。一位古人（黑袍、发髻、长须）骑在黑马上，一手高举马鞭指向前方，头顶一个白色对话框，框里画着**一枝结满青梅子的梅枝**。他身后是一位骑马的武将（方格铠甲、戴帽）和几个举着长矛的士兵。**咬合点**：「曹操指着前方，说：“这条路我熟悉，前面不远处有一大片梅林……”」——举鞭指前方、对话框里的梅子都可对。角色：骑马举鞭者依「曹操指着前方」判为**曹操**。⚠ 对话框里的梅子是**曹操说出来的，不是真的看见了**，讲时要点明；地上枯黄、看不到水，与「路过一个没有水的地方」一致 | |
| 插-18 | 磨刀不误砍柴工（大儿子） | 单页。一个年轻人（灰上衣、棕裤、发髻）双手高举斧子，用力砍向一棵细树，皱着眉、咬着嘴，头上冒着汗珠；**斧刃上有缺口**，树干上只有几道浅浅的砍痕；脚边地上一盘绳子。**咬合点**：「因为斧子太钝，砍了十几下，连一棵小小的枯树也没砍倒。不一会儿，他就累得腰酸背疼了」——汗珠、浅砍痕、钝斧子都可对。角色：依「斧子太钝」「没砍倒」判为**大儿子**（灰衣，与 `插-19` 蓝紫衣的小儿子靠衣服区分）。⚠ 原文是「枯树」，画面这棵树**枝叶茂盛，不是枯树**，师话按画面说「一棵小树」即可 | |
| 插-19 | 磨刀不误砍柴工（小儿子） | 满版。左上角一个圆形小图：一双手按着斧子在一块长条**磨刀石**上磨。大图：一个年轻人（蓝紫上衣、棕裤、发髻）肩挑扁担，扁担两头各挂**一大捆柴**，一手拎着斧子，笑眯眯地快步走过一座小木桥；桥下流水，远处是竹林和草顶的房子。**咬合点**：「就赶紧到井边去磨，不一会儿就磨锋利了」＋「他就挑着沉甸甸的一担柴回家了」——**磨斧子和挑柴回家画在同一页，一前一后就是全篇的道理**；与 `插-18` 并排看，一个满头大汗砍不动、一个笑着挑柴回家，学生自己能说出差在哪儿。⚠ 原文是「到井边去磨」，小圆图里**看不到井**；「太阳刚刚偏西」画面也看不出时间 | |
| 插-20 | 程门立雪 | 满版。大雪纷飞，一座屋顶积满雪的院门前，两扇红色大门紧闭（门上一对铜环）。门前站着两个人，都闭着眼、袖着手，静静地等：左边一位穿棕色斗篷、戴棕色帽子，侧身；右边一位穿深紫色斗篷、里面是青色长袍、戴黑色高帽，正对画面。右侧一棵挂着雪的枯树。**咬合点**：「他们不忍心打扰他，就静静地站在门外等候」＋「寒风呼啸，大雪纷飞」——关着的门、漫天大雪、两人闭眼静立都可对。角色：两人＝**杨时和游酢**，但**哪位是杨时未定**（原文没写两人的样子），不要让学生指认。⚠ 原文「门外的积雪已经有一尺多厚了，他俩也成了雪人」，画面地上积雪不深、两人身上只落了些雪点，**没有成雪人**，师话按画面说 | |
