**⚠ 排序（本批原文件名顺序与正文完全不同，已重排）**：按正文篇目先后连号，原文件名→新编号对照见 `_清洗记录.json`，补图或反查时**一律照那张表，别按文件名数字猜**。两处判断要说明：①《雨来了》两幅按诗句先后排，蜗牛（`图片优化 (2)`）在前，蘑菇＋甲虫（`图片优化.png`）在后；② `图片优化 (7)`（桌上的篮子、葡萄酒、切开的蛋糕和一束野花）判为《小红帽（三）》结尾「奶奶吃着小红帽送来的蛋糕，喝着葡萄酒」，排在最后——依据是**蛋糕已经切开、旁边有一束野花**（对上小红帽路上采的花）；它也可能是《小红帽（一）》妈妈准备蛋糕和葡萄酒的那一刻，见该行 ⚠。

**⚠ 出处栏与「无页码」口径**：出处一律写篇名，与 docx 篇题同口径（《小红帽》原书分（一）（二）（三）三篇，照写）。**本书 docx 版无页码**，详案/物料出现「第 X 页」一律属编造。docx 正文引号多为半角直引号，本图单引用时已统一改成弯引号，文字一字未动。

**⚠ 本书最需防错处**：
1. **《丁一小写字》哪个孩子是丁一小，靠动作认**：原文没写两人的样子；画面里挠头、伸手往旁边够的男孩判为丁一小，端端正正写字的女孩判为姐姐（依「坐得端端正正，一笔一笔认真地写」）。
2. **《小红帽（二）》狼的脸露在外面**：原文写「软帽拉得低低的，盖住了面孔」，画面上狼的脸、眼镜和牙齿全露着；眼镜是画面添的。讲「耳朵、眼睛、手、嘴」那段问答时可以用图，但**不要说「画上和书上写的一样」**。
3. **《两只小狮子》那只“刻苦”的小狮子画得像在玩球**，看不出「练习滚扑撕咬」；讲时说「一只在翻滚扑腾，一只躺着晒太阳」即可。

**配图覆盖情况**：全书 14 篇中 **9 篇有图**（《骆驼和羊》《雨来了》各 2 幅，其余各 1 幅，共 13 幅；《小红帽》三篇共 5 幅）。**未配图的 5 篇**＝《勿贪多》《自己去吧》《一次比一次有进步》《三个小伙伴》《好天气和坏天气》。

| 插-01 | 丁一小写字 | 单页，画面在下半部。一张长桌前坐着两个孩子：左边女孩（扎马尾、黄上衣）挺直身子、低头握笔写字，笑眯眯的，身旁一盏台灯；右边男孩（浅绿上衣）一手挠着头，一手拿着笔伸向女孩那边，侧眼看着她。桌上各摊着一张写了字的纸，各有一只文具盒。身后是木栏和一个书架。**咬合点**：「姐姐拿起丁一小丢掉的纸和笔，坐得端端正正，一笔一笔认真地写」——一个坐得端正、一个挠头的对比一眼可见。角色：挠头的男孩＝**丁一小**，写字的女孩＝**姐姐**（依动作推定，原文没写两人样子）。⚠ 男孩伸手的方向像是去拿姐姐那边的东西，可对上「他把姐姐的笔拿来写」，但**画面看不准拿的是纸还是笔**，不要追问 | |
| 插-02 | 乌鸦兄弟 | 单页，画面在下半部。一棵大树，灰白色的树冠上落着雪片，几道黑线表示大风斜着刮过，左下方有落叶被卷着飞。树杈上一个草窝，**两只黑乌鸦紧紧挤在一起**，缩着身子，嘴边画着发抖的小弯线。**咬合点**：「乌鸦兄弟俩都蜷缩在破窝里，哆嗦地叫着：“好冷啊！好冷啊！”」＋「西北风呼呼地刮着，大雪纷纷地飘落」——风、雪、缩成一团、发抖都可对。⚠ 窝上的**洞画面里看不清**，不要让学生在图上找洞；结尾「窝被吹到地上」没画 | |
| 插-03 | 骆驼和羊（吃树叶） | 单页，画面在下半部。一道黄色木栅栏围墙，墙里伸出茂盛的枝叶。一头骆驼站在墙外，**一抬头就叼到了墙头的叶子**；它前面一只白色小羊用后腿站起来，两只前蹄扒在墙上，伸长脖子往上够，却差得远。**咬合点（本篇最强）**：「骆驼一抬头就吃到了树叶。羊抬起前腿，扒在墙上，脖子伸得老长，可还是吃不着」——几乎逐字画出来了，**一高一矮的差别学生一眼能说出** | |
| 插-04 | 骆驼和羊（钻小门） | 单页，画面在上半部。围墙上一个又窄又矮的拱形小门（门边一扇铁栅门），骆驼**跪着前腿、低着头**，只把脑袋探进门洞，身子进不去；门里的空地上，小羊正低头吃草，身旁长着各种花草。**咬合点（本篇最强）**：「羊大模大样地走进门去吃园子里的草。骆驼跪下前腿，低下头，往门里钻，怎么也钻不进去」——**与 `插-03` 并排看正好倒过来**：上一张骆驼得意，这一张羊得意，全篇「各有长处、各有短处」的道理就在两张图里 | |
| 插-05 | 两只小狮子 | 单页，画面在上半部。草原上，一轮红太阳，远处是木栅栏和山坡。前面一只小狮子仰面靠在石头上，两手枕在脑后，翘着腿，懒洋洋地眯着眼；后面一只小狮子躺在草地上，四脚朝天抱着一只紫色的球翻滚，身下扬起一团尘土。左边一棵大树。**咬合点**：「一只小狮子整天练习滚扑撕咬，非常刻苦。另一只却懒洋洋地晒太阳，什么也不干」——一动一静的对比可对，晒太阳的那只最好认。⚠ 动的那只**看起来像在玩球**，不太像「刻苦练习」；原文和懒狮子说话的是「一棵小树」，画面左边的是**一棵粗大的树**，狮子妈妈也没画 | |
| 插-06 | 雨来了（蜗牛） | 单页，画面在下半部。两朵灰黑色的乌云正在下雨，绿草地上，一只背着**紫色螺旋壳**的小蜗牛伸着两只触角，笑眯眯地举着一只小手。**咬合点**：「雨来了，快回家！小蜗牛，说不怕，我把房子背来啦！」——背上的壳就是「房子」，**学生看图能自己说出房子在哪儿** | |
| 插-07 | 雨来了（蘑菇和甲虫） | 单页，画面在下半部。雨点落下来，右边一朵乌云。草地上一朵黄色的蘑菇长着笑脸，举着两只细胳膊；旁边一只小甲虫（蓝色硬壳上有花斑）抬头看着它。**咬合点**：「小蘑菇，说不怕，我已备好伞一把」＋「小甲虫，说不怕，我有一件防雨褂！」——蘑菇的伞形帽子、甲虫的硬壳，**正是诗里的「伞」和「防雨褂」**，可以让学生在图上指出来 | |
| 插-08 | 书本里的蚂蚁 | 满版。深蓝色背景上闪着星光和几只彩色蝴蝶，一个小姑娘（扎马尾、粉色裙子、白色荷叶领）张大嘴惊喜地看着桌上摊开的一本旧书，一只手按着书页；书页上爬着**一只黑蚂蚁**。书边放着一朵白色小花。她的裙子半透明，隐约印着一些字。**咬合点**：「这时候，小姑娘突然看到了住在书里的黑蚂蚁，问：“你是一个字吗？”」——小姑娘、旧书、书页上的蚂蚁、那朵花都在。⚠ 原文是「**红色**的小花」，画面的花是**白色**的，不要追问花的颜色；书页上**没有画字**，看不出「密密麻麻的小字」 | |
| 插-09 | 小红帽（一）（出门） | 单页，画面在上半部。小路上，小红帽（红兜帽、红斗篷、红裙、白围裙、红白条纹袜）双手提着一只小篮子，笑着站着；脚边两只小兔子，远处一座小房子。**咬合点**：「奶奶送给她一顶红绒缝制的小帽子。小姑娘戴上这顶帽子非常好看」＋「这儿有一块蛋糕和一瓶葡萄酒，给你奶奶送去吧」——红帽子、手里的篮子可对。⚠ 原文狼问的是「你那围裙下边装的什么来着？」，画面是**提着篮子**；远处的房子是她家还是奶奶家**看不出来**，不要问 | |
| 插-10 | 小红帽（一）（遇见狼） | 满版。树林里，小红帽（背对画面、手提篮子）抬手跟一只**又高又大的灰狼**打招呼；狼立着身子，黄眼睛斜着、嘴角咧着笑，抬起一只前爪。**咬合点**：「小红帽一走进森林，就碰见一只狼。可她却不知道这是一种多么凶残的动物，因此并不怕它」＋「“你好啊，小红帽。”狼说。“你好啊，狼先生。”」——小红帽抬手打招呼、一点不怕；狼的笑一看就不怀好意，**学生能从狼的表情读出“小红帽不知道的事”** | |
| 插-11 | 小红帽（二）（床上的狼） | 满版。紫色帐子被**一只小手**从右边撩开，床上是那只狼：戴着奶奶的粉色碎花软帽和一副圆框眼镜，咧着嘴露出一排尖牙，两只长着尖爪的大爪子搭在红色被子上。**咬合点（本篇最强）**：「她随即走到床前，撩开帐子」＋「奶奶，你的眼睛怎么这么大啊？」「奶奶，你的手怎么这么大啊？」「可是奶奶，你的嘴怎么大得可怕啊？」——撩帐子的手、大眼睛、大爪子、满嘴尖牙都画了，**问答一句句能在图上找到**。⚠ 原文「软帽拉得低低的，盖住了面孔」，画面上**脸全露着**；眼镜是画面添的；耳朵被帽子挡住，看不出「大」 | |
| 插-12 | 小红帽（三）（得救） | 满版。林间草地上，那只狼仰面躺着，舌头耷拉出来，**肚皮上有一道缝起来的线**；猎人（格子鸭舌帽、灰胡子、格子外套）拄着一杆猎枪站在狼旁边。后面，小红帽和奶奶（灰发、绿上衣、白围裙）手拉着手，开心地蹦着。地上散着几块石头。**咬合点**：「狼一醒过来就想逃走，可石头沉甸甸的，它刚一站起来，马上又倒了下去，摔死了」＋「三个人都很开心」——死狼、猎人、团聚的祖孙都在。⚠ 原文没写把狼肚子**缝起来**，缝线是画面添的；猎人的表情是平静的，不太像「开心」 | |
| 插-13 | 小红帽（三）（蛋糕和葡萄酒） | 单页，画面在下半部。红白格子桌布上，一只柳条篮里插着一瓶葡萄酒、搭着一块蓝格布；篮边一束野花（黄、紫）；右边一个**已经切开的**奶油蛋糕，旁边一块切下的蛋糕放在盘里，还有一杯茶、一把叉子、一把刀。画面里没有人。**咬合点**：「奶奶吃着小红帽送来的蛋糕，喝着葡萄酒，精神好了起来」——蛋糕被切开吃了、葡萄酒、还有小红帽路上采的花，**学生能从这一桌东西说出故事的结局**。⚠ 画面没有人，也可能被理解成《小红帽（一）》里妈妈准备的东西；依「蛋糕已切开＋有野花」判为结尾，讲时以「故事最后，奶奶……」引出即可 | |
