**⚠ 本书最需防错处**：
1. **《丁一小写字》哪个孩子是丁一小，靠动作认**：原文没写两人的样子；画面里挠头、伸手往旁边够的男孩判为丁一小，端端正正写字的女孩判为姐姐（依「坐得端端正正，一笔一笔认真地写」）。
2. **《小红帽（二）》狼的脸露在外面**：原文写「软帽拉得低低的，盖住了面孔」，画面上狼的脸、眼镜和牙齿全露着；眼镜是画面添的。讲「耳朵、眼睛、手、嘴」那段问答时可以用图，但**不要说「画上和书上写的一样」**。
3. **《两只小狮子》那只“刻苦”的小狮子画得像在玩球**，看不出「练习滚扑撕咬」；讲时说「一只在翻滚扑腾，一只躺着晒太阳」即可。
4. **《三个小伙伴》《好天气和坏天气》画面只对上一半**：前者袋鼠抱的是树苗、小象没浇水；后者只画了一页雨伞。见各行 ⚠。

**配图覆盖情况**：全书 14 篇**篇篇有图**（《骆驼和羊》2 幅，《小红帽》三篇共 5 幅，其余各 1 幅，共 17 幅）。首版缺的《勿贪多》《自己去吧》《一次比一次有进步》《三个小伙伴》《好天气和坏天气》五篇已补齐；《雨来了》首版的两张单页换成一张跨页全图。

| 插-01 | 勿贪多 | 单页（原画面在上半页，下半页空白已裁去）。一只透明的大玻璃瓶，瓶身贴着写有「糖」字的标签，瓶里散着几颗花纸包的糖；**一只小手攥成拳头卡在瓶口里**，拳头里露出好几颗糖，瓶口两边画着表示用力晃动的小短线。左边天上飞着一只淡蓝色的鸟，瓶旁一朵紫红小花。**咬合点（本篇最强）**：「把手伸进瓶子里，满满地抓了一大把糖。可是他的手被瓶口卡住了，怎么也出不来」——**拳头比瓶口大**，学生看图就能说出手为什么拿不出来、怎样才拿得出来，正是妈妈那句「如果一次不拿这么多，手就容易拿出来了」。⚠ 画面只有一只手，小明本人和妈妈都没画；飞鸟是画面添的 | |
| 插-02 | 自己去吧 | 跨页（中缝保留）。左页：水边土坡上站着一只灰色的鸭妈妈，扭头望着水面；右页：水里一只黄色小鸭正在游，身后溅起水花。右上方天空里，一只大鹰展翅飞，前面一只小鹰也张开翅膀在飞。**咬合点**：「小鸭说：“妈妈，您带我去游泳好吗？”妈妈说：“小溪的水不深，自己去游吧。”过了几天，小鸭学会了游泳」＋「过了几天，小鹰学会了飞翔」——**妈妈在岸上看、孩子自己在水里游；大鹰小鹰各飞各的**，两段都在一张图上，学生能自己说出「妈妈没有带，孩子自己学会了」。⚠ 原文小鹰要去的是「山那边」，画面没有画山；画的是**已经学会之后**的样子 | |
| 插-03 | 一次比一次有进步 | 单页。右边地上横躺着**一个又大又圆的绿冬瓜**（后面还有一个），冬瓜上停着一只黑色的小燕子，低头看着；左边一棵茄子秧，枝上**挂着好几根细长的紫茄子**。背景是淡蓝、淡黄的天。**咬合点（本篇最强）**：「菜园里，冬瓜躺在地上，茄子挂在枝上」＋「冬瓜大，茄子小」＋「冬瓜是绿的，茄子是紫的」——**躺着／挂着、大／小、绿／紫三组不同，图上全看得出**，学生可以跟着小燕子一次一次找。⚠ 第三次发现的「冬瓜的皮上有细毛，茄子的柄上有小刺」**画面上看不出**，正好留给学生「再去仔细看看」时说出图上找不到、要靠亲眼观察；燕子妈妈和屋檐没画 | |
| 插-04 | 丁一小写字 | 单页，画面在下半部。一张长桌前坐着两个孩子：左边女孩（扎马尾、黄上衣）挺直身子、低头握笔写字，笑眯眯的，身旁一盏台灯；右边男孩（浅绿上衣）一手挠着头，一手拿着笔伸向女孩那边，侧眼看着她。桌上各摊着一张写了字的纸，各有一只文具盒。身后是木栏和一个书架。**咬合点**：「姐姐拿起丁一小丢掉的纸和笔，坐得端端正正，一笔一笔认真地写」——一个坐得端正、一个挠头的对比一眼可见。角色：挠头的男孩＝**丁一小**，写字的女孩＝**姐姐**（依动作推定，原文没写两人样子）。⚠ 男孩伸手的方向像是去拿姐姐那边的东西，可对上「他把姐姐的笔拿来写」，但**画面看不准拿的是纸还是笔**，不要追问 | |
| 插-05 | 乌鸦兄弟 | 单页，画面在下半部。一棵大树，灰白色的树冠上落着雪片，几道黑线表示大风斜着刮过，左下方有落叶被卷着飞。树杈上一个草窝，**两只黑乌鸦紧紧挤在一起**，缩着身子，嘴边画着发抖的小弯线。**咬合点**：「乌鸦兄弟俩都蜷缩在破窝里，哆嗦地叫着：“好冷啊！好冷啊！”」＋「西北风呼呼地刮着，大雪纷纷地飘落」——风、雪、缩成一团、发抖都可对。⚠ 窝上的**洞画面里看不清**，不要让学生在图上找洞；结尾「窝被吹到地上」没画 | |
| 插-06 | 骆驼和羊（吃树叶） | 单页，画面在下半部。一道黄色木栅栏围墙，墙里伸出茂盛的枝叶。一头骆驼站在墙外，**一抬头就叼到了墙头的叶子**；它前面一只白色小羊用后腿站起来，两只前蹄扒在墙上，伸长脖子往上够，却差得远。**咬合点（本篇最强）**：「骆驼一抬头就吃到了树叶。羊抬起前腿，扒在墙上，脖子伸得老长，可还是吃不着」——几乎逐字画出来了，**一高一矮的差别学生一眼能说出** | |
| 插-07 | 骆驼和羊（钻小门） | 单页，画面在上半部。围墙上一个又窄又矮的拱形小门（门边一扇铁栅门），骆驼**跪着前腿、低着头**，只把脑袋探进门洞，身子进不去；门里的空地上，小羊正低头吃草，身旁长着各种花草。**咬合点（本篇最强）**：「羊大模大样地走进门去吃园子里的草。骆驼跪下前腿，低下头，往门里钻，怎么也钻不进去」——**与 `插-06` 并排看正好倒过来**：上一张骆驼得意，这一张羊得意，全篇「各有长处、各有短处」的道理就在两张图里 | |
| 插-08 | 两只小狮子 | 单页，画面在上半部。草原上，一轮红太阳，远处是木栅栏和山坡。前面一只小狮子仰面靠在石头上，两手枕在脑后，翘着腿，懒洋洋地眯着眼；后面一只小狮子躺在草地上，四脚朝天抱着一只紫色的球翻滚，身下扬起一团尘土。左边一棵大树。**咬合点**：「一只小狮子整天练习滚扑撕咬，非常刻苦。另一只却懒洋洋地晒太阳，什么也不干」——一动一静的对比可对，晒太阳的那只最好认。⚠ 动的那只**看起来像在玩球**，不太像「刻苦练习」；原文和懒狮子说话的是「一棵小树」，画面左边的是**一棵粗大的树**，狮子妈妈也没画 | |
| 插-09 | 三个小伙伴 | 单页。草地上，一只小象（灰色、粉脸蛋）站着，抬起两只前脚；它前面一只带棕色条纹的小野猪低着头，**用嘴拱着地面**；右边一只袋鼠抱着一棵**带根的小树苗**。**咬合点**：「小野猪说：“不要紧，不要紧，我有硬硬的嘴巴。”不一会儿，小野猪就用硬嘴巴拱出了一个树坑」——三个小伙伴同框、小野猪拱土可对，学生能说出每个小伙伴靠身上哪一样「本领」帮忙。⚠ 原文袋鼠是「用皮口袋运来了一大堆肥料」，画面里袋鼠**抱的是树苗**，肚子上的口袋也看不清；小象**没有在用鼻子吸水浇树**。讲小象、袋鼠的本领时按原文说，**不要拿这张图核** | |
| 插-10 | 好天气和坏天气 | 跨页（中缝保留）。一整排淡蓝色的雨点背景上，散着**十把各式各样的雨伞**：红底白点的撑开伞、绿色收拢的长柄伞、黄色和红色、蓝色的折叠伞、一把撑开的大蓝伞、一把蓝绿花边伞……都没有人拿着，像摆出来卖的样子。**咬合点**：「小儿子是做雨伞的」＋「我最盼望下雨的好天气……有了天天下雨的好天气，我的伞就好卖了」——满页雨伞加雨点，**正是小儿子盼的「好天气」**。⚠ 全篇只有这一幅，**老奶奶、大儿子和晒果脯都没画**；讲时可以反问「这张图是谁的好天气」，再引出大儿子 | |
| 插-11 | 雨来了 | 跨页（中缝保留）。灰黑的乌云下着雨，绿草地上从左到右是三个小家伙：一只背着**紫色螺旋壳**的小蜗牛，伸着触角、举着小手笑；一朵长着笑脸的**黄色蘑菇**，张开两只细胳膊；一只**蓝色硬壳带花斑**的小甲虫，抬头看着。**咬合点（本篇最强）**：「小蜗牛，说不怕，我把房子背来啦！」「小蘑菇，说不怕，我已备好伞一把。」「小甲虫，说不怕，我有一件防雨褂！」——**三个小家伙的顺序正好和诗里三节一样**，背上的壳＝「房子」、蘑菇的伞形帽子＝「伞」、甲虫的硬壳＝「防雨褂」，学生能在图上一一指出来 | |
| 插-12 | 书本里的蚂蚁 | 满版。深蓝色背景上闪着星光和几只彩色蝴蝶，一个小姑娘（扎马尾、粉色裙子、白色荷叶领）张大嘴惊喜地看着桌上摊开的一本旧书，一只手按着书页；书页上爬着**一只黑蚂蚁**。书边放着一朵白色小花。她的裙子半透明，隐约印着一些字。**咬合点**：「这时候，小姑娘突然看到了住在书里的黑蚂蚁，问：“你是一个字吗？”」——小姑娘、旧书、书页上的蚂蚁、那朵花都在。⚠ 原文是「**红色**的小花」，画面的花是**白色**的，不要追问花的颜色；书页上**没有画字**，看不出「密密麻麻的小字」 | |
| 插-13 | 小红帽（一）（出门） | 单页，画面在上半部。小路上，小红帽（红兜帽、红斗篷、红裙、白围裙、红白条纹袜）双手提着一只小篮子，笑着站着；脚边两只小兔子，远处一座小房子。**咬合点**：「奶奶送给她一顶红绒缝制的小帽子。小姑娘戴上这顶帽子非常好看」＋「这儿有一块蛋糕和一瓶葡萄酒，给你奶奶送去吧」——红帽子、手里的篮子可对。⚠ 原文狼问的是「你那围裙下边装的什么来着？」，画面是**提着篮子**；远处的房子是她家还是奶奶家**看不出来**，不要问 | |
| 插-14 | 小红帽（一）（遇见狼） | 满版。树林里，小红帽（背对画面、手提篮子）抬手跟一只**又高又大的灰狼**打招呼；狼立着身子，黄眼睛斜着、嘴角咧着笑，抬起一只前爪。**咬合点**：「小红帽一走进森林，就碰见一只狼。可她却不知道这是一种多么凶残的动物，因此并不怕它」＋「“你好啊，小红帽。”狼说。“你好啊，狼先生。”」——小红帽抬手打招呼、一点不怕；狼的笑一看就不怀好意，**学生能从狼的表情读出“小红帽不知道的事”** | |
| 插-15 | 小红帽（二）（床上的狼） | 满版。紫色帐子被**一只小手**从右边撩开，床上是那只狼：戴着奶奶的粉色碎花软帽和一副圆框眼镜，咧着嘴露出一排尖牙，两只长着尖爪的大爪子搭在红色被子上。**咬合点（本篇最强）**：「她随即走到床前，撩开帐子」＋「奶奶，你的眼睛怎么这么大啊？」「奶奶，你的手怎么这么大啊？」「可是奶奶，你的嘴怎么大得可怕啊？」——撩帐子的手、大眼睛、大爪子、满嘴尖牙都画了，**问答一句句能在图上找到**。⚠ 原文「软帽拉得低低的，盖住了面孔」，画面上**脸全露着**；眼镜是画面添的；耳朵被帽子挡住，看不出「大」 | |
| 插-16 | 小红帽（三）（得救） | 满版。林间草地上，那只狼仰面躺着，舌头耷拉出来，**肚皮上有一道缝起来的线**；猎人（格子鸭舌帽、灰胡子、格子外套）拄着一杆猎枪站在狼旁边。后面，小红帽和奶奶（灰发、绿上衣、白围裙）手拉着手，开心地蹦着。地上散着几块石头。**咬合点**：「狼一醒过来就想逃走，可石头沉甸甸的，它刚一站起来，马上又倒了下去，摔死了」＋「三个人都很开心」——死狼、猎人、团聚的祖孙都在。⚠ 原文没写把狼肚子**缝起来**，缝线是画面添的；猎人的表情是平静的，不太像「开心」 | |
| 插-17 | 小红帽（三）（蛋糕和葡萄酒） | 单页，画面在下半部。红白格子桌布上，一只柳条篮里插着一瓶葡萄酒、搭着一块蓝格布；篮边一束野花（黄、紫）；右边一个**已经切开的**奶油蛋糕，旁边一块切下的蛋糕放在盘里，还有一杯茶、一把叉子、一把刀。画面里没有人。**咬合点**：「奶奶吃着小红帽送来的蛋糕，喝着葡萄酒，精神好了起来」——蛋糕被切开吃了、葡萄酒、还有小红帽路上采的花，**学生能从这一桌东西说出故事的结局**。用户补图编号（13-2）把它排在《小红帽（三）》末尾，结尾归属已确认。⚠ 画面没有人，讲时以「故事最后，奶奶……」引出即可 | |
