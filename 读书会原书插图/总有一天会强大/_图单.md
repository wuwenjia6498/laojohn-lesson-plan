## 角色识别口径（选图前必读）

- **公太**＝红色短袖T恤套黑白条纹长袖、橄榄色工装短裤、头发竖立。锚定：插-03 镜前涂发蜡（「我对着镜子，把头发往上拉了拉」，此景只有公太一人）、插-08 游标尺压在竖起的头发上（「游标尺碰到了我立起来的头发」）。体检当天（第一、二章同一天）各图沿用这身打扮。
- **希来里**＝高个、青绿色长袖衬衫、深色长裤、头发顺直。锚定：插-05 搂肩（「希来里顺势搂住了我的肩膀」）、插-09 楼梯上比胜利手势（「希来里在楼梯上面比出胜利的手势」）。
- **筑井**＝女生、双马尾/侧马尾、黄色开衫。锚定：插-07 圆形特写里用黑色勺形挡眼板遮眼（「用饭勺形状的黑色挡眼板遮着右眼」）、插-12 托腮（「胳膊肘撑在窗台上，托着腮」）。
- **第三、四章（赛马场那天）两人换了衣服**，原文没有任何衣着描写，只能靠发型推断，**插-17、插-18 的角色归属未锁定**，见各条。
- ⚠ **凡涉及「比个子」，一律不要拿画面当证据**：插-04、插-13、插-18 都有近大远小的透视，画面里的身高关系与原文对不上或看不出。

| 插-17 | 第三章 · 叔叔开车·听跑马场入场曲 | 单页。上方一台车载音响屏幕，下方飘着几个音符；一辆**黄色小汽车**正面，驾驶座上棕色卷发、粉色衬衫、系着安全带的男子握方向盘微笑；他身旁中间位置一个**头发竖立的矮个男孩**探着身子、张嘴看前方；右后侧一个**头发顺直、白衬衫的男孩**咧嘴笑。**咬合点**：「只见一辆赭黄色的小汽车停在路边」「车子遇到红灯停下来时，希来里的叔叔打开了车里的音响。车里响起了激昂的音乐」——黄车、音响、音乐可对；驾驶者＝希来里叔叔。⚠ **两个孩子的归属未定**：按发型，竖发矮个者像公太、顺发者像希来里；但原文写的是「刚出发一小会儿，希来里就向前一探身子」——画面探身的却是竖发者，与原文对不上。**选用前须再核，不要用这幅图讲「谁探身问叔叔」** |  |
| 插-18 | 第三章 · 终点前看7号伊势螺旋桨 | 单页。上半幅：一匹深灰近黑的马飞奔向左，马鞍下白色号码布写「**7**」，骑手戴绿色头盔、穿蓝黄相间的骑手服；其后一匹棕马紧随，骑手戴粉色头盔。下半幅：白色栏杆、绿色灌木与铁栏前，两个男孩侧脸张大嘴看着赛道——前下方一个头发顺直、穿浅色带领衬衫；后方一个头发竖立、白绿色上衣，头部在画面中更高更大。**咬合点**：「它马鞍上的白色号码布上写着数字『7』，下面写着『伊势螺旋桨』」（号码可对；原文说马「近乎黑色的深棕色」，画面偏深灰）＋「阵阵尘土飞起，一眨眼的工夫，那匹马步履矫健地径直超越了其他马儿」。⚠ **两个孩子的归属未定**：按发型推，竖发者像公太、顺发者像希来里（与插-19 发型衣着一致），但画面里竖发者反而显得更高——疑为近大远小透视，**绝不能用这幅图比两人个子**；号码布上原文还有马名，画面只见数字 |  |
| 插-19 | 第四章 · 开篇·吃乌冬面与咖喱饭 | 单页。餐馆长桌（暗红色桌面），两只水杯；右侧棕色卷发、粉色衬衫的男子（与插-17 驾驶者同一造型＝叔叔）一手捧蓝白条纹碗、一手拿筷子，咧嘴笑；左侧两个男孩用勺子吃深色碗里的饭——外侧一个头发顺直、白衬衫系深色领带，斜眼看向叔叔；里侧一个头发竖立、绿袖上衣，闭眼吃着；背景墙上贴着写「水」字和箭头的告示，还有几位背对画面的食客。**咬合点**：「叔叔啪的一下掰开筷子，吃了一口天妇罗乌冬面。我和希来里的面前是咖喱饭」「我和希来里拿着勺子的手停在了空中」——叔叔用筷子、两个孩子用勺子可对。⚠ 画面里两个孩子都在吃，**不是「勺子停在空中」那一刻**；两个孩子按发型推为希来里（顺发）与公太（竖发），衣着无原文锚句，用时说「两个孩子」更稳 |  |
