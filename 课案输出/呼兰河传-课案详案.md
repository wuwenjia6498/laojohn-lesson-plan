### 一、文本介绍

【内容简介】

《呼兰河传》是萧红的一部散文化长篇小说，共七章加一段尾声。它和一般小说不一样——**没有一条贯穿到底的故事，也没有一个从头跟到尾的主角**。全书像一册翻开的相簿：前两章写呼兰河这座北方小城的风土与“精神盛举”（大泥坑、火烧云、跳大神、放河灯、娘娘庙大会）；第三、四章写“我”和祖父、写后园、写“荒凉”的院子；第五、六、七章各以院里的一个人物为中心——小团圆媳妇、有二伯、冯歪嘴子。尾声里，祖父死了，小主人逃荒离乡。作者说，写下这些并不是因为它们是“优美的故事”，只是因为它们充满了自己幼年的记忆，忘却不了。

要读懂这本书，需要换一副眼光：它的“主角”其实是整座呼兰河城，是城里那些“生老病死都一声不响”的普通人。读它的乐趣与分量，就在那些反复出现的物象里——那个年年陷马、却从没人肯填平的大泥坑，那片说变就变的火烧云，那句一再响起的“我家是荒凉的”。

【作者介绍】

萧红（1911—1942），中国现代作家，原名张迺莹，黑龙江呼兰人。《呼兰河传》是她创作后期的代表作，以自己的童年回忆为线索，用散文式的笔法，描绘了上世纪二三十年代家乡的生活图画与风土人情，后世称她为“文学洛神”。这部书的正文末尾清楚地署着：“一九四〇年十二月二十日香港完稿”。

（【教师补充：萧红的生卒年、籍贯属文学史常识，备课时请照实核对后再向学生介绍；不确定的信息宁可不讲。】）

### 二、教学目标

【知识技能】了解《呼兰河传》是一部散文化、无连贯情节、无单一主角的长篇小说，能说清它“小城风土—我与祖父—三个院中人物”三大板块的整体结构；厘清“我”家、老胡家、老王家三户人家的人物关系，不把两位“婆婆/祖母”、三处“王/胡”混为一谈；能抓住大泥坑、火烧云、“我家是荒凉的”等反复出现的物象，读出作者写在字面之下的悲悯与批判。

【过程方法】综合运用提问、联结、推断、比较、整合、转化、监控等阅读策略，对这部群像缀连的作品做“梳理—细读—思辨”的三步深读；借助气泡图、人物关系图、鱼骨图、六面体讨论图、阅读单等可视化工具，把分散在各章的人与事合并成可看见的图谱，并据此独立解释文本、评价书中人物与看客。

【情感价值】在后园“一切都活了”的明亮与院落“荒凉”的对照里，体会作者对故乡又爱又痛的复杂感情；在小团圆媳妇、有二伯、冯歪嘴子的命运里，对“围观而不援手”的看客心理有所警醒，对被侮辱、被损害的普通人生出真切的悲悯，懂得“忘却不了、就记下来”这一份郑重。

### 三、教学流程

## 第1课时 · 导读课

**本节三维目标**

【知识技能】知道自己在三年级《火烧云》、五年级《祖父的园子》里读到的两个片段，都出自《呼兰河传》这同一本书；了解作者萧红与这本书“没有主角、没有连贯故事”的特点；能借已学过的与当堂朗读的样篇，画出一张“呼兰河小城第一印象”气泡图，建立起阅读全书的框架。

【过程方法】重点显性训练**联结**与**提问**两项策略——把课文里学过的火烧云、祖父的园子，联结到它们所在的整本书；在听读、比较、拼图的过程中，提出并记下自己最想弄清的一个问题，带着这个问题走进一周的自读。

【情感价值】对“课文里那么美的火烧云、那么自由的园子，原来只是这本书的一角”生出探究的兴趣，愿意花一周走进整本书，看看它还藏着一个怎样的呼兰河。

### 一、课程导入·同一座城的两副面孔（15 分钟）

师：亲爱的同学们大家好。今天我们要开始读一本新书。我先读两小段话给你们听——你们一边听，一边想：这两段，是不是有点耳熟。

师：（读课文原句）第一段——“这地方的火烧云变化极多，一会儿红堂堂的了，一会儿金洞洞的了，一会儿半紫半黄的，一会儿半灰半百合色……还有些说也说不出来的，见也未曾见过的，诸多种的颜色。”

师：（再读一段）第二段——“一切都活了。……倭瓜愿意爬上架就爬上架，愿意爬上房就爬上房。黄瓜愿意开一个黄花，就开一个黄花，愿意结一个黄瓜，就结一个黄瓜。……玉米愿意长多高就长多高，它若愿意长上天去，也没有人管。”

师：这两段，你们是不是都学过，一篇是三年级的《火烧云》，一篇是五年级的《祖父的园子》。谁还记得，当年读这两篇，心里是什么感觉？

学生互动分享

参考：（让学生说读时的感受即可——绚烂、明亮、自由、温暖、无拘无束……肯定学生真实的阅读体验，老师口头把“美”“自由”这几个词复述、归拢一下。）

师：（过渡·自然揭同书）是啊——一个把满天晚霞写得那么绚烂，一个把小小园子写得那么自由。这两篇，都出自**同一本书、同一个人的笔下**，本来就写在同一座城里。（稍停顿）可就是这同一支笔、同一座城，还写下了下面这样两段。你们再听——

师：（读大泥坑·完整两句）先是城里一条街上的一个大泥坑——

> “一年之中抬车抬马，在这泥坑子上不知抬了多少次，可没有一个人说把泥坑子用土填起来不就好了吗？没有一个。……说拆墙的有，说种树的有，若说用土把泥坑来填平的，一个人也没有。”

师：（读扎彩铺·先铺一句背景再引原文）再是城里一家专给死人扎纸房子、纸人纸马的铺子，扎得又阔气又体面，来看热闹的人——

> “看热闹的人，人人说好，个个称赞。穷人们看了这个竟觉得活着还没有死了好。”

师：（六年级思辨引导·点反差抛悬念）你们听出来了吗——同一个作家、同一座城，笔下却是两副截然相反的面孔：一面，是绚烂的火烧云、自由的园子，美得让人移不开眼；另一面，是一个几十年陷马陷车、却没有一个人肯去填的坑，是一群看着别人扎阴宅、竟觉得“活着还不如死了”的人。（稍停顿）这就奇怪了——那个坑，添上几锹土就好了，为什么偏偏**没有一个人**去填？一座城，怎么会同时长着这么美、又这么让人心里发沉的两副样子？萧红，为什么两样都要写下来？（稍停顿）这几个问题，你们先搁在心里，这一周到书里去找答案。

师：这座又有火烧云、又有大泥坑的小城，叫**呼兰河**。这本书，你们认出那两篇课文的时候，多半已经想起来了——《呼兰河传》，作者萧红。你们其实**早就来过**这座城，只不过课本当年挑给你们的，是它最美、最亮的那两扇窗。

师：（埋“美与痛”钩子·收口）而整本《呼兰河传》，远不止那两扇窗——它还有大泥坑那样的荒唐，有扎彩铺那样的苍凉，还有更多你们没见过的人和事，有的热闹，有的古怪，有的……很沉，很痛。这一节课，我们就先去看看：**你们以为很美的呼兰河，究竟还藏着哪些你不知道的样子。**

### 二、认识作者与这本书·你熟悉的萧红，和你不认识的呼兰河（15 分钟）

师：（介绍作者·与“回忆”扣住）先说说萧红这个人。她是中国现代的一位女作家，家乡就在呼兰河边。这本《呼兰河传》，写的正是她自己**小时候的家乡**——你们学过的那片火烧云、那个园子、那位慈爱的祖父，都是她真实的童年记忆。她写这本书的时候，已经离开家乡很远、很久了。

师：（当堂朗读·亮出书的结尾一句，点明“回忆”的分量）这本书最后，她写下这样一句话——

> “以上我所写的并没有什么优美的故事，只因他们充满我幼年的记忆，忘却不了，难以忘却，就记在这里了。”

师：（推断·抛问）请你琢磨这句话。她说自己写的“并没有什么优美的故事”，可她又说“忘却不了，难以忘却，就记在这里了”。（稍停顿）一个人，会把什么样的事情，明明不算“优美”、却怎么也忘不掉，非要记下来不可？先不忙回答，把这个问题存在心里——读完全书，你会有自己的答案。

学生互动分享

参考：（不求统一答案，接住多种猜想——有人猜是很难过、很心疼的事；有人猜是让她愧疚或后悔的事；有人猜是童年里最温暖、舍不得的事。都先接住，告诉学生这几种“忘不掉”，书里可能都有。此处只埋问题，不给结论。）

师：（介绍体例·建立阅读框架）读之前，老师帮你把这本书的“地图”先画一下，免得你读的时候迷路。这本书一共**七章，加一段尾声**。老师用一句话帮你把它分成三大块——

（老师逐块讲，请学生在自己的本子上跟着记这张“地图”）

- **第一块（第一、二章）：写城。** 写呼兰河这座小城的样子——街道、大泥坑、火烧云，还有跳大神、放河灯、看野台子戏这些热闹。这一块里，“我”几乎不出现。
- **第二块（第三、四章）：写“我”和祖父。** 写“我”家的后园、慈爱的祖父，也写“我家是荒凉的”那座院子和院里的房客。
- **第三块（第五、六、七章）：写三个人。** 每一章专门写院子里的一个人——小团圆媳妇、有二伯、冯歪嘴子。最后是尾声。

师：（点出张力·把课文接到整本书上）你们发现没有——你们学过的《火烧云》，正在**第一块**（写城）里；《祖父的园子》，正在**第二块**（写我和祖父）里。这两块，确实有不少明亮、温暖的东西。可到了**第三块**，笔调就整个变了：那三个人——小团圆媳妇、有二伯、冯歪嘴子——他们的故事，一个比一个让人难受。（稍停顿）所以你们看，这张地图上，**第三块**才是这本书最难、也最要紧的地方——那三个人，正是这一周要你们自己去认识的呼兰河。

师：（提醒读法·防混淆）记住这张地图，你读的时候就知道自己走到哪一块了。老师还要**特别提醒你两个容易读混的地方**，先记下来：第一，书里有两位年长的女性，一位是“我”的**祖母**（她有洁癖，第三章里病死了）；另一位是老胡家小团圆媳妇的**婆婆**（打骂小团圆媳妇的那个人）。这是**完全不同的两个人**，千万别当成一个。第二，书里有“老胡家”“老王家”，还有一个姓王的老厨子——读到“王”“胡”的时候，留个心，看清是哪一家。

### 三、把印象拼成一张画像·气泡图（20 分钟）

师：（承接·从零散到整体）刚才老师一口气给你们读了四段——两段美的：火烧云、祖父的园子；两段沉的：那个没人填的大泥坑、那家扎彩铺。（稍停顿）这四段，就像四块碎片，各是一副样子。这一节，我们把它们**拼到一起**，看看拼出来的呼兰河，到底是座什么城。拼图用的这张图，叫**气泡图**。

师：（介绍工具·气泡图怎么用）气泡图很简单：中间画一个大圆圈，写上我们要谈的对象——“呼兰河小城”；四周再画几个小气泡，每个气泡里写一个你对这座城的**印象词**，最好再在旁边记一句“我是从哪一段听出来的”。

### 四、阅读方法引导·布置阅读任务（10 分钟）

师：（给读法·针对本书难点）这本书没有一个从头到尾的主角，也没有一条连贯的故事，人物又多，读起来容易“散”。老师给你三个上手的办法——

师：（一条一条给，不贪多）**第一，按章读，读完一章停一下**，用一句话跟自己说“这一章主要写了什么/写了谁”。**第二，边读边圈人**，遇到一个人物，就在书边上写下他是谁、哪一家的，尤其把“我”家、老胡家、老王家分清。**第三，留意那些反复出现的东西**——大泥坑、火烧云、跳大神、“我家是荒凉的”这句话——它们一再出现，往往就是作者最想让我们看见的地方，读到了就做个记号。

师：（布置阅读计划）这一周，请你按下面的计划读完全书，并填好这张自读检测表——**刚才你想好的那个最想弄清的问题，就写在表的最后一行**。下次上课，我们就带着你圈好的、记好的这本书，一起把呼兰河这座城看清楚。

## 第2课时 · 阅读交流课1

**本节三维目标**

【知识技能】能整体说清《呼兰河传》“小城风土—我与祖父—三个院中人物”三大板块的结构；能借人物关系图厘清“我”家、老胡家、老王家三户人家的成员与关系，准确区分“我”的祖母与小团圆媳妇的婆婆、老胡家与老王家。

## 第3课时 · 阅读交流课2

**本节三维目标**

【知识技能】能通过细读，说出《呼兰河传》语言的两副面孔——写后园、火烧云时的明亮自由，写“荒凉”与看客时的沉痛；能借鱼骨图，把小团圆媳妇之死背后分散在第五章各处的多重原因梳理清楚，并为每个原因找到书中依据；初步理解本书“以美写痛、借反复咏叹与看客描写批判国民性”的文学价值。

【过程方法】重点显性训练**推断**策略——从“我家是荒凉的”这类反复句、从烫澡时看客的反应里，推断作者写在字面之下、没有明说的意思；并借后园的“自由”与院落的“荒凉”两相比较，读出这本书以乐景写哀的匠心。

【情感价值】在明与暗的对照里体会作者对故乡爱与痛交织的情感；面对小团圆媳妇的遭遇，对“看热闹而不援手”的冷漠有真切的痛感与警醒。

### 一、承接·从“我家是荒凉的”读起（10 分钟）

师：亲爱的同学们大家好。上一节我们把人理清了。这一节，我们钻进文字里去细读。

师：（承接现场产出·从一句反复句切入）这本书里有一句反复出现的话，第一节课老师就请你们留意过——“我家是荒凉的”，或者“我家的院子是很荒凉的”。这一周读下来，你一定又和它碰了好几次。它在第四章、第六章一次次出现。（稍停顿）一个作家，为什么要把同一句话反反复复地写？

学生互动分享

参考：（引导学生推断，而非老师直接给——反复地说，往往是因为这种感觉很深、压在心上，说一次不够；也可能是想让读者也一遍遍地感到那种空、那种冷。接住学生的合理推断，点明：这种一再重复的句子，在这本书里是一个记号，作者用它给全书定了一个“荒凉”的底色。）

师：（过渡·引出“两副面孔”）可奇怪的是，就是在这样一本“荒凉”的书里，却藏着全书最明亮、最快活的一段文字。这一节，我们先读它的**亮**，再读它的**痛**。

### 二、细读语言·萧红的暖笔与冷笔（20 分钟）

师：（细读·样篇一·后园·以旧带新）先读第三章的后园。这一段你们其实**最熟不过**了——它就是你们五年级学的《祖父的园子》的原文。当年在语文课上，我们读到的是它的“自由”；今天，我们把它放回整本书里，读出课文里没来得及说的另一层意思。请一位平时朗读功底不错的同学，把这一段读给大家听。

（邀请一位同学朗读）

> “一切都活了。都有无限的本领，要做什么，就做什么。要怎么样，就怎么样。都是自由的。倭瓜愿意爬上架就爬上架，愿意爬上房就爬上房。黄瓜愿意开一个黄花，就开一个黄花，愿意结一个黄瓜，就结一个黄瓜。若都不愿意，就是一个黄瓜也不结，一朵花也不开，也没有人问它。玉米愿意长多高就长多高，它若愿意长上天去，也没有人管。”

师：（推断·抓住“自由”）这一段里，哪个词反反复复地出现？

学生互动分享

参考：“愿意”“自由”“没有人问它/没有人管”。作者写的其实是倭瓜、黄瓜、玉米，可他把它们写得像**想干嘛就干嘛、没有人管束**的活物。这一段写的是后园，也是写“我”跟着祖父在后园里的那段童年——**自由自在，没有人管**。

师：（比较·把“自由”接到“荒凉”上，读出匠心）请你把这段的“自由”，和我们刚才说的“我家是荒凉的”放在一起想一想。（稍停顿）同一座院子，后园里“一切都活了、都是自由的”，院子却“是荒凉的”。你觉得，作者把这一明一暗放在同一本书里，是想让我们感到什么？

学生互动分享

参考：（鼓励多元推断——有人说，越是写后园的自由和快乐，越显得院子和城里的日子荒凉、可怜，是拿“亮”来反衬“暗”；有人说，那点自由和温暖只在有祖父的后园里有，出了后园就是荒凉。都接住。点明：这种“以乐景写哀”“明暗对照”，正是这本书写得高明的地方。）

师：（补一笔·火烧云的暖笔）再看天上的火烧云——这一段你们三年级就学过，最熟了：“红堂堂”“金洞洞”“半紫半黄”，还有“说也说不出来的，见也未曾见过的”颜色。萧红写景，就是有这样的本事，普通一片晚霞，被她写得能让“三岁的孩子也会呀呀地往西天空里指”。

师：（对照·严冬的冷笔）可别以为萧红只会写这种暖——她的笔，能暖，也能冷。你们再听这本书的开头，她是怎么写严冬的：

> “严冬一封锁了大地的时候，则大地满地裂着口。从南到北，从东到西，几尺长的，一丈长的，还有好几丈长的，它们毫无方向地，便随时随地，只要严冬一到，大地就裂开口了。／严寒把大地冻裂了。”

师：（品·一暖一冷见功力）同样一支笔——写火烧云，暖得让人想抬头去看；写严冬，冷得像连大地都给冻得裂开了一道道口子。（稍停顿）能把暖写到那么暖，又能把冷写到那么冷，这就是萧红文字的功力，也是这本书最值得细读的地方之一。（稍停顿）记住这一暖一冷——因为接下来我们要读的，是这本书里最冷、也最让人难受的一段。

### 三、鱼骨图·是谁害死了小团圆媳妇（25 分钟）

师：（过渡·亮出核心问题）第五章，写的是小团圆媳妇。她刚被接到老胡家时，是个什么样的姑娘？

学生互动分享

参考：十二岁（因为长得高，谎称十四岁），“黑乎乎的，笑呵呵的”，又高又壮，一顿能吃三碗饭，见人也不害羞。（点明：注意，她一开始是个健康、开朗的姑娘。）

师：（细读·样篇·当众烫澡）可就是这样一个姑娘，被“治病”治死了。我们读其中最揪心的一段——众人以“给她治病”为名，当众把她按进滚开水里烫澡。请听——

> “小团圆媳妇还活着的时候，她像要逃命似的。前一刻她还求救于人的时候，并没有一个人上前去帮忙她，把她从热水里解救出来。／现在她是什么也不知道了，什么也不要求了。可是一些人，偏要去救她。”

师：（推断·抓住这段的荒唐）请你细读这两句。她**还活着、还在求救**的时候，“没有一个人”去帮她；等她**什么也不知道了**，“一些人偏要去救她”。（稍停顿）这前后，荒唐在哪儿？作者不动声色地写下这两句，他其实想让我们看见什么？

学生互动分享

参考：（引导学生自己推断——需要救的时候没人救，等救不了了大家反而来“救”；这些人要的不是救她，而是**看热闹、图个自己心里过得去**。作者没有骂一个字，却让我们看清了这群“看客”的冷漠与残忍。这就是“推断”——读出作者写在字面底下、没有明说的意思。）

师：（引出工具·从“一个凶手”到“多方合力”）那么，回到我们这节课要弄清的问题：**到底是谁，害死了小团圆媳妇？** 是她婆婆一个人吗？好像不全是。害死她的，其实是好几股力量一起使的劲。要把这几股力量一样一样看清楚，我们用一件新工具——**鱼骨图**。

师：（先教方法·因是首次出现，简短讲清）鱼骨图长得像一条鱼的骨头：**鱼头**，写我们要追究的那个“结果”——这里就是“小团圆媳妇之死”；从鱼头拖出一条**主骨**，主骨上斜插出几根**大刺**，每一根大刺写一股“害死她的力量/原因”；每根大刺下面，再写上**书里的依据**——是哪一段、哪件事让你这么说。它专门用来看清一件事**是由多个原因合起来造成的**。

师：（填图·分组）请你分组，回到第五章，一根一根地填这些“大刺”。想一想：从她进门，到她死去，一共有哪些人、哪些做法，在往死里逼她？

师：（分享+反馈）哪个组先来？把你们填的“大刺”一根一根说给大家，每说一根，必须说清“书里哪件事让你填它”。

学生互动分享（请 2 组分享；每组念出自己填的“大刺”，其他组把漏掉的补到自己的鱼骨图上，相同的合并、遗漏的老师追问补上。反馈时紧扣“每一根刺都要有书中依据”，训练“观点—证据”的读法。）

参考（鱼骨图·教师参考版，汇总后对照。所有依据均来自第五章）：

|---|---|

| 跳大神、试偏方 | 打出病后，家里请大神、试各种偏方“治病” |

### 四、小结·预告思辨课（5 分钟）

师：（小结）这一节，我们读了这本书的两副面孔——后园的明亮自由，和小团圆媳妇之死的沉痛；也用鱼骨图弄清了，害死她的是“多方合力”。

师：（预告·此为跨周接缝，可布置“想”的准备任务）下一节是这本书的**思辨&应用课**。我们要专门讨论这本书里一个反复出现、也最让人不舒服的东西——**“看客”**：这座城里的人，总爱围着别人的苦难看热闹，大泥坑边看，烫澡时看，后面还等着看冯歪嘴子的笑话。（稍停顿）这一周你回去，请围绕一个问题好好想一想，也可以再翻翻书找证据——**这些“看热闹”的人，到底算不算坏人？** 把你的想法和你找到的书里的例子，准备好，下节课我们摆到桌面上来议。

本课完。

## 第4课时 · 思辨&应用课

**本节三维目标**

【知识技能】能围绕“看客”这一贯穿全书的主题，从联系、描述、比较、争论、应用、分析六个角度展开思考，并为自己的判断找到书中依据；能理解冯歪嘴子“要生根”与有二伯“假上吊”两种面对苦难的方式，体会作者对普通人的复杂态度；能说出这部“没有优美故事”的书为什么值得被郑重地“记下来”。

【过程方法】重点显性训练**联结**与**转化**两项策略——把书里的“看客”联结到自己身边、今天生活里的“围观”；并把整本书的阅读体验，转化为一张“为一个被忘却的人写的记忆卡”。

【情感价值】对围观他人苦难的冷漠有清醒的警觉，学会做一个“愿意伸手、而不只是看热闹”的人；对书中被侮辱、被损害的普通人生出真切的悲悯，理解“忘却不了、就记下来”这份郑重的意义。

### 一、深度阅读发现·大白兔为什么“要回家”（15 分钟）

师：亲爱的同学们大家好。今天是这本书的最后一节课。我们从一个奇怪的、也很凄凉的细节说起。

师：（引出开放疑点·从白兔传说切入）小团圆媳妇死了以后，书里写了一个传说——

> “据说，那团圆媳妇的灵魂，也来到了东大桥下。说她变了一只很大的白兔，隔三差五地就到桥下来哭。有人问她哭什么？她说她要回家。”

师：（抛开放问·不急着定论）作者完全可以让这个故事到“她死了”就结束。可他偏偏又写了这么一段——她变成一只大白兔，在桥下哭着“要回家”。（稍停顿）你觉得，作者为什么要写这一段？这只哭着“要回家”的白兔，让你心里是什么滋味？

学生互动分享

参考：（先让学生自由说，接住多种体会——她被接来做童养媳，其实一直想回自己的家；活着受尽折磨，只有死后、只有在传说里，才敢说出“我要回家”这个最小的愿望；作者用这个凄凉的传说，让我们记住这个连名字都没留下的姑娘。这里不追求统一答案，重在让学生带着这份“滋味”进入今天的讨论。）

师：（补读·把“回家”接到全书的“家”上）她死了，还哭着“要回家”。其实这本书写到最后，“家”是一个很重的字。请再听这本书快结尾时的一句——

> “呼兰河这小城里边，以前住着我的祖父，现在埋着我的祖父。”

师：（体会·一句轻分享）你听——祖父永远留在了这座城里；小主人呢，逃荒离开了家；小团圆媳妇，死了还在哭着“要回家”。（稍停顿）同样一座呼兰河城，有人留下、有人离开、有人回不去。你听到这里，心里最放不下的是谁？说一个名字，一句话就好。

学生自由分享（不展开，收一收学生心里的这份“滋味”，自然过渡到下面对“看客”的讨论。）

### 二、六面体讨论图·“看客”（25 分钟）

师：（点出全书贯穿的主题）你们发现没有，这本书里有一种人，从头到尾都在——**看热闹的人**。大泥坑陷了车马，他们围着看；小团圆媳妇被滚水烫，他们围着看；到了第七章，冯歪嘴子的妻子死了，他们还等着看他“完了”的笑话。萧红管这种人，我们今天给他起个名字，叫**“看客”**。这节课，我们就专门把“看客”这个话题，讨论透。

师：（引出工具·先教方法，六面体首次出现）我们用一件能把一个话题讨论得又全又深的工具——**六面体讨论图**。它像一个正方体的六个面，让我们围着“看客”这一个话题，从**六个不同的角度**去想，不至于只想到一个点上。这六个面是——

〔六面体讨论图·空白表，发给学生分组填〕

| 面 | 这一面要想的问题 | 我们组的想法（含书中依据） |
|---|---|---|
| 联系 | 书里的“看客”，让你联想到今天生活里、网络上的什么现象？ |  |
| 描述 | 书里的“看客”具体是什么样子的？举一两个书中的场面。 |  |
| 比较 | “看客”和书里真正对别人好的人（比如祖父）比，差在哪儿？ |  |
| 争论 | 这些“看热闹”的人，到底算不算坏人？说出你的理由。 |  |
| 应用 | 如果当时你在场，你会怎么做？今天遇到“围观”，你该怎么做？ |  |
| 分析 | 作者为什么要反复写“看客”？他想借他们说什么？ |  |

师：（分组讨论·给足时间）时间有限，我们**深议两面、快扫余面**：“争论”和“分析”这两面，每组**都要认真讨论、写满**；其余四面（联系、描述、比较、应用），每组**各挑一面**写一写就好，不必六面都填满。讨论时记住我们上节课练过的规矩——**你的判断，要能回到书里找到例子**。

学生互动分享（分组讨论后，按面分享：先请几组说“描述”和“比较”（相对具体），再重点请各组碰“争论”这一面——“看客算不算坏人”。老师主持，不急于统一，把不同判断都亮出来、都要求给依据。）

参考（六面体讨论图·教师参考版，供分享后收束对照，非标准答案）：

| 面 | 参考方向（师生讨论后对照） |
|---|---|
| 联系 | 今天在街上、网上围观别人出事、起哄、看笑话而不帮忙的现象 |
| 描述 | 大泥坑边看陷车、烫澡时围观、等着看冯歪嘴子“完了”的热闹 |
| 比较 | 祖父对小团圆媳妇、冯歪嘴子都有真心的善意与帮助；看客只图热闹、不伸手 |
| 争论 | 开放——有人说他们并非蓄意害人、只是麻木随大流；有人说“围观而不援手”本身就是一种伤害。均需依据 |
| 应用 | 开放——当时会不会上前拦一句、递一把手；今天遇到围观该不该转发、该不该伸手 |
| 分析 | 作者反复写看客，是想让我们看见一种“人人都不觉得自己有错”的冷漠，这正是他最想批判的 |

师：（争论面·收口追问，训练“转化”策略的前一步）关于“看客算不算坏人”，老师不给标准答案。但请你记住讨论里最有分量的一种声音——他们**大多不是要故意害人**，他们只是“随大流”“看个热闹”。（稍停顿）可正是这种“没有一个人觉得自己有错”的热闹，把一个大活人看死了。所以真正可怕的，也许不是某一个坏人，而是**一群普通人凑在一起的冷漠**。

师：（回收开场·把三个“没有一个人”串成一条线）讲到这儿，老师要带你们回到**第一节课的开头**——还记得那个几十年没人填的大泥坑吗？作者写下这么一句：“可没有一个人说把泥坑子用土填起来”。（稍停顿）后来到了第五章，小团圆媳妇被滚水烫、拼命求救的时候，作者又写了一句几乎一样的话：“并没有一个人上前去帮忙她”。（稍停顿）而今天我们讨论的这些看客——从头到尾，也**没有一个人**觉得自己做错了什么。（稍停顿）你们发现没有：同一座呼兰河城，一次又一次地出现同一句话——“**没有一个人**”。没有一个人肯填坑，没有一个人肯伸手，没有一个人觉得自己有错。（稍停顿）当年那个填不平的坑，和后来那些伸不出手的人，其实是**同一种城、同一种冷**。萧红反反复复写这句“没有一个人”，写的就是这座城最深、也最痛的那个地方——这，也就是第一节课那个“为什么没人填坑”的谜，真正的答案。

师：（补一笔·两种活法的比较，接住书中另一条线）不过，这座城里也不是只有看客。同样是苦命人——有二伯被逼得**假装上吊、假装跳井**闹给人看；冯歪嘴子的妻子死了，众人都等着看他绝望，他却——

> “他觉得在这世界上，他一定要生根的。要长得牢牢的。”

师：（抛问·不展开成新讨论，只作提升）一个“闹给人看”，一个“默默要生根”。（稍停顿）你更愿意像谁那样活？这个问题，你放在心里，不用现在回答。

### 三、联系生活·阅读成果·为一个“被忘却的人”写一张记忆卡（15 分钟）

师：（引出任务·回到全书的落点）我们回到萧红在书的最后说的那句话——她说，这些人和事“并没有什么优美的故事”，可她“忘却不了，难以忘却，就记在这里了”。（稍停顿）这本书，其实就是萧红为呼兰河那一群普通人，做的一次“记下来”。今天这节课的最后，轮到我们也来做一次“记下来”。

师：（布置成果任务·转化策略）请你从这本书里，挑一个**你不想让他被忘记的人**——可以是小团圆媳妇、有二伯、冯歪嘴子，也可以是那个一边漏粉一边唱歌的漏粉人，或者任何一个打动你的小人物。为他（她）写一张**“记忆卡”**。

〔记忆卡·阅读单，学生独立完成〕

| 记忆卡 |  |
|---|---|
| 我要记住的人 |  |
| 他（她）是谁·哪一家的 |  |
| 书里最让我忘不掉的一个画面 |  |
| 我想为他（她）说的一句话 |  |

师：（提示·扣住书中依据，不悬空抒情）“最让我忘不掉的一个画面”，请你尽量写你**书里真读到的**那一幕，不要编。最后那句“想为他说的话”，才是你自己的。

师：（分享+反馈）请几位同学，把你的记忆卡念给大家听。

学生互动分享（请 3—4 位同学分享；老师不替学生升华，只肯定那些“画面来自书里、话是自己真心”的记忆卡，让“为普通人留一份记忆”这件事，自然地落在每个学生心里。）

### 四、全课总结（5 分钟）

师：（回顾四节·梳理走过的路）这四节课，我们从一座“没有主角的城”走进《呼兰河传》——第一节我们用气泡图画下了对这座城的第一印象；第二节用人物关系图把三户人家理清；第三节用鱼骨图弄明白了是“多方合力”害死了小团圆媳妇；今天，又用六面体把“看客”这个话题讨论透，还为一个不该被忘记的人写下了记忆卡。

师：（回扣·请回学生自己的问题）还记得吗——四节课前，你在自读表的最后一行，写下过一个自己**最想弄清的问题**。（稍停顿）现在请你把它翻出来看一看：读完整本书、上完这四节课，你自己的那个问题，有答案了吗？（稍停顿）有答案的，那是你自己读出来的；还没有答案的，也别急——它就是你合上这本书以后，还可以继续去想的。

师：（收束·不煽情，点到为止）萧红说这本书“并没有什么优美的故事”。读完你会明白，她写的不是优美，是**真实**——一座城的美与荒，一群人的暖与冷，一些被侮辱、被损害、却本不该被忘记的普通人。（稍停顿）把你这四节课的所有图、所有单，都夹进这本书里，作为你读过呼兰河的记号。

师：下一期我们读……【教师补充：此处填上你们下一期实际要读的书名，用一句话勾起学生的期待。】
