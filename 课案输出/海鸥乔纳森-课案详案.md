### 一、文本介绍

【内容简介】 海鸥乔纳森·利文斯顿生活在海边的一个鸥群里。在这个鸥群中，飞行只是一件手段——从岸上飞出去觅食，再飞回来；可是对乔纳森来说，重要的不是吃而是飞。他整日独自练习慢速飞行、高速俯冲，一次次失控坠海，也一次次爬起来重来，终于突破了海鸥的速度纪录，还成了世界上第一只做特技动作的海鸥。可等他兴冲冲飞回海滩，等着他的却是一场全体大会：长者当众判他“太轻率，太不负责任”，把他放逐到远崖。全书由此分成三部——第一部写他在尘世的痴迷、失败、突破与被逐；第二部写他被两只发光的海鸥接到一个“更高的地方”，在那里拜长者江为师，学会以思想的速度飞行，也听江说破一句话：“天堂不是空间，也不是时间。天堂就是尽善尽美。”；第三部写他自愿回到那个赶走他的尘世，在远崖收下弗莱契等同样被放逐的年轻海鸥，又带他们飞回鸥群公开授课，经历鸥群从排斥、围观到分裂的全过程，最后把学生交给弗莱契，自己化为透明消失，全书以弗莱契对新学员说的那句“咱们从水平飞行开始”收束。

【文本特点提示】 这是一部篇幅极短的寓言小说，情节的分量不在事件多，而在几处对话与几次转折。全书没有固定页码，定位一律按“第一部 上 / 下”“第二部 上 / 下”“第三部 上 / 下”六节。书末另附一篇“附录”，那是另一本书里谈论本书的段落，不属于本书正文，教学中一律不用。本书另有通行译名《天地一沙鸥》，作者名另有译法，本课统一用《海鸥乔纳森》与“理查德·巴赫”。

【作者介绍】 理查德·巴赫（Richard Bach），美国作家，本人也是一名飞行员——书里那些俯冲、收翅、失速、翻滚的写法，来自他自己在空中的经验。本书中译本由夏杪翻译。据本书出版方所撰的介绍页，这本书在1970年出版之前曾遭数次退稿，出版之后曾连续38周位居《纽约时报》畅销书排行榜第一名。（以上出版与销售情况来自出版方的介绍文字，不是书中正文，课上引用时须说明来源。）

### 二、教学目标（书级·三维）

【知识技能】了解《海鸥乔纳森》“尘世—更高的世界—返回尘世”三部递进的结构，能按“部/节”定位关键情节；梳理乔纳森与鸥群关系的完整变化线索，从被放逐到主动返回、再到把群体交出去；分辨书中两个极易混淆的“长者”——原鸥群判他放逐的海鸥长者，与第二个世界教他飞行与爱的长者江；识别全书反复出现的三样东西——反复推进的速度数字、两次出现的“咱们从水平飞行开始”、多次被他人喊出而本人明确拒绝的“鸥神之子”。

【过程方法】综合运用预测、提问、联结、推断、比较、转化、监控七项阅读策略；借助预测阅读单、“我的问题”阅读单、故事地图、人物关系图、六面体讨论图与思辨阅读单等工具，对这部极短却极密的寓言小说做梳理、对照、细读与思辨；练习从人物的一句话里推断书中没有直说的意思，任何判断都回到具体的部与节找依据。

【情感价值】体会“一个人把一件事做到远超群体的要求，为什么反而会被群体判为不负责任”这一处张力；感受乔纳森唯一一次屈服（发誓做一只平凡的海鸥）与随后立刻背弃这个誓言的分量；理解全书对“自由”的说法——自由不是想干什么就干什么，而是认识并发挥自己的潜能；同时留意乔纳森临别的叮嘱：不要把他奉为神明。

### 三、教学流程

## 第一课时 · 导读课

### 本课三维教学目标

【知识技能】知道全书分三部、共六节，无固定页码，一律按“部/节”定位；知道乔纳森是一只把飞行当作目的而不是觅食手段的海鸥，知道他因此被鸥群大会判为“不负责任”并放逐远崖；听教师朗读三段原文后，能就“这个判决公不公平”“乔纳森后来会怎么样”作出有依据的预测。

【过程方法】重点显性训练预测与提问两个策略：能从书名、开场判决和三段原文里提取线索，作出说得出依据的预测，并把预测写进阅读单留待读后验证；能就文本提出自己想问的问题，并初步分一分哪些读下去就有答案、哪些要想一想才知道。

【情感价值】对“一只海鸥因为飞得太好而被开除”这件反常的事产生兴趣与不平，愿意在一周内读完全书，并带着一个尚未回答的问题去读。

### 一、导入·一只被开除的海鸥（15 分钟）

师：亲爱的同学们大家好。今天我们要打开的这本书很薄，薄到你们中间读得快的同学，一个下午就能翻完。但是这本薄书里有一个判决，我想请你们用整整四节课的时间来想一想：它到底公不公平。

师：先说这个判决。故事发生在海边的一个海鸥群里，清晨渔船一出海，近千只海鸥就飞过去争食。有一天，这个鸥群开了一次全体大会，把其中一只海鸥叫到中间站着，当众宣布把他赶出去，从此放逐到远崖，不许再回来。（稍停顿）我想先请你们猜一猜：一只海鸥要犯什么错，才会被整个族群这样开除？

学生互动分享

参考：同学们通常会往这几个方向猜——偷了别人的鱼、跟同伴打架伤了谁、偷懒不干活、把危险引到族群里、背叛了大家。这些猜测都很合理，因为在我们熟悉的规矩里，被开除总是因为“做了坏事”。

师：很遗憾，一条也没猜中。这只海鸥叫乔纳森·利文斯顿。他没偷、没抢、没伤过任何一只海鸥。他被赶出去的原因是——他把飞行练得太好了。他从五千英尺的高空俯冲，闭着眼睛以时速二百一十四英里从正在吃早餐的鸥群中间穿了过去，没有伤到一只鸟；当天他又学会了翻斤斗、横滚、定点翻滚、倒转，成了世界上第一只做特技动作的海鸥。他兴冲冲飞回海滩，鸥群正等着他。长者叫他“站到中间去”——他以为这是表彰。

师：我读一段原文给大家听。这是长者当众宣布判决时说的话。请你们特别留意长者用的那个词。

> ……海鸥乔纳森·利文斯顿，总有一天，你会懂得不负责任是不行的。生命是莫测的，是不可知的。我们来到这个世界，就是为了吃，为了活下去，尽可能多活些日子。

师：听清那个词了吗？“不负责任”。（稍停顿）一只鸟练飞练到破了纪录，罪名是“不负责任”。在这个鸥群里有一条老规矩：海鸥从来不对全体会议反驳。可是乔纳森这一次开口了。

> 海鸥从来不对全体会议反驳，但是乔纳森却大声抗议了。“不负责任？同胞们！”他嚷道，“一只海鸥能发现生活的意义，能找到更崇高的生活目的，你们还能说他不负责任吗？一千年来，我们总是眼睛盯着烂鱼头，可是现在我们有了生活的目的——学习，进行发明创造，取得自由！给我最后一次机会，让我告诉你们我学到了什么……”

师：他没有得到这个机会。大会的结果是，鸥群齐声喊“开除他”，然后一同转过身去，不再理睬他。

师：现在我把那个问题正式交给你们。一只海鸥，因为把飞行当成了目的而不是找饭吃的手段，被判为“不负责任”——这个判决，你觉得公平吗？先在心里给自己一个答案，不着急说出来。这四节课我们会一直带着它；到最后一节课，我们要把这场大会重新开一次，由你们来重审这个判决。

学生自由分享（只听两三位同学的第一反应，教师不评判、不展开）

参考：这一步只收第一反应，不作结论。有同学会立刻说不公平——他又没害谁；也会有同学替鸥群说话——大家都得活下去，冬天要来了，你不觅食，最后谁来管你。这两种声音都要原样留住，它们正是最后一节课重审大会上两方的雏形。

师：还有一件事，跟这本书的作者有关。他叫理查德·巴赫，本人就是一名飞行员——所以书里那些俯冲、收翅、失速、翻滚，不是坐在桌前想出来的。另外，这本书的出版方在介绍页里写了这么一段经历：1970年这本书出版之前，曾经被好几家出版社退稿；出版之后，它连续38周排在《纽约时报》畅销书排行榜第一名。这段话我要说明来源——它来自出版方写的介绍，不是书里的正文，我们知道有这么回事就行。

师：不过你们可以顺着想一句：一本被退过好几次稿的书，后来成了最多人读的书。这件事，和书里那只被赶出去的海鸥，是不是有点像。

### 二、抢先看·这只海鸥到底“怪”在哪（20 分钟）

师：判决我们已经听过了。接下来我读三段书里的原文，请你一边听一边想一件事：在鸥群眼里，乔纳森到底“怪”在哪儿？听的时候把你觉得关键的词记在心里。

师：第一段在第一部上，就在开篇不远处。作者一上来先交代了整个鸥群是怎么看待飞行的。

> 大多数海鸥只求学会最简单的飞行本领——如何从岸上飞出去觅食，再飞回来。对他们来说，重要的不是飞行，而是觅食。但对这只海鸥来说，重要的不是吃而是飞。乔纳森喜爱飞行胜于一切。

师：这段话很短，但它是全书第一次把分歧摆出来。我请你们回答两个问题。第一个：对大多数海鸥来说，飞行是什么？

学生互动分享

参考：飞行是手段、是工具、是为了吃饭才不得不学的本事。学会“飞出去、再飞回来”就够了，多一分都不必学。

师：第二个：对乔纳森来说，飞行又是什么？

学生互动分享

参考：飞行本身就是他要的东西，是目的。所以他会为了练飞而饿肚子——同样一件事，在他这里的分量完全不一样。

师：请你们记住“手段”和“目的”这一对词。这本书从头到尾，其实都在这一对词上打转。

师：第二段发生在他的家里。乔纳森练飞练得瘦下去，母亲责问他为什么不好好吃；接着父亲来劝他。这段话，是整个鸥群的价值观说得最集中的一次。

> “你瞧，乔纳森，”他父亲温和地说，“冬天快到了，船只就要少了，海面上的鱼也要钻到海底去了。你要是一定要学习，那就学学怎么觅食吧。飞行当然好，可你总不能拿滑翔当饭吃啊。别忘了，你飞行的目的就是为了吃。”

师：先请你们注意，父亲说这话的语气是“温和地说”。他不是在骂他。我想问一句：父亲说得有没有道理？

学生互动分享

参考：非常有道理。冬天要来了、鱼会往深处走、船会变少，这些都是实情。父亲的出发点是让孩子活下去。这一问要让学生自己说出“他说得对”——这本书的难处正在这里：反对乔纳森的一方，并不是坏人，也不是胡说。

师：乔纳森是怎么回应的呢？书里写他顺从地点了点头，跟着鸥群争食了几天，实在受不了，把好不容易弄到的一条鲤鱼丢给了别的海鸥，又独自飞出去了。他当时心里想的是：

> “这样太没意思了，”他心里想，一边故意把好不容易弄到的一条鲤鱼丢给一只追逐他的饥饿的老海鸥。“我可以把所有这些时间都用来学飞行。要学的东西太多啦！”

师：第三段更短，是他回答母亲的一句话。母亲说他瘦得皮包骨头，他说：

> 我倒不在乎瘦得皮包骨头，妈妈。我只是想知道我在空中能够做什么，不能够做什么。

师：三段听完了。现在请你们做一件事——提问。读到这里，你心里冒出了什么问题？可以是问乔纳森的，可以是问鸥群的，也可以是问作者的。每人至少想出一个，写在本子上。

（给学生 2 分钟写，随后请四五位同学说）

学生互动分享

参考（教师把学生的问题分一分，不急着给答案）：一类问题是“读下去就会有答案”的，比如他后来还回得去吗、他一个人在远崖靠什么活、有没有别的海鸥像他一样；另一类是“要想一想、讨论才知道”的，比如他为什么非要飞不可、鸥群这样做是不是也有他们的道理、作者写海鸥其实想说的是谁。第二类问题当场答不出来很正常——好问题本身就是收获，我们把它留到后面几节课。

师（总结）：这一环节我们做了两件事：一件是听出了“手段”和“目的”这一对分歧，另一件是各自提出了自己的问题。这两件事，会一直跟着我们读完这本书。

### 三、预测阅读单·写下你的“我猜”（15 分钟）

师：在你们自己回去读之前，我们要把刚才心里的猜测落到纸上。这张表叫预测阅读单，有三列——“我的预测”“我的依据”“读完是否被证实”。最后一列今天先空着，第四节课我们回来逐条对答案。

师：为什么一定要写下来？因为预测这个策略，光猜不验，等于没用过。只有回头对一对，你才知道自己是靠线索猜对的，还是碰巧蒙对的。

| 我的预测                          | 我的依据（书里的哪句话、哪个情节让我这么猜）                | 读完是否被证实（第四节课填） |
| ----------------------------- | ------------------------------------- | -------------- |
| 例：“乔纳森最后还会回到那个鸥群，而且不是灰溜溜地回去。” | 他被赶走时说“给我最后一次机会，让我告诉你们我学到了什么”——他一直想说。 |                |
|                               |                                       |                |
|                               |                                       |                |
|                               |                                       |                |

师：我给三个方向，你们至少写两条，每条都要写依据。第一个方向：乔纳森被放逐到远崖以后，一个人会做什么？第二个方向：这本书为什么要分成三部？三部之间可能是什么关系？第三个方向：还会不会出现第二只“乔纳森”这样的海鸥？如果有，他会怎么样？

（给学生 6 分钟独立填写，3 分钟同桌互看、互相补充依据）

学生互动分享

参考（教师走动收口）：这一步的重点不在预测本身，而在“依据”那一栏有没有真东西。写“我猜他会回去”不算完成，写“我猜他会回去，因为他被赶走时最后一句话是想告诉大家他学到了什么，这句话没说完”才算。预测被推翻不丢人，推翻得有理由才厉害。

师：写完把这张表夹进书里。它是我们四节课里唯一一张要“跨越四节课”的单子。

### 四、认识这本书·七天阅读计划（10 分钟）

师：最后十分钟，我要告诉你们怎么读这本书，还有三件读的时候要顺手做的事。

师：先说这本书的样子。全书分三部，每部又切成上、下两节，一共六节，各节没有标题、只有序号。这里有个麻烦：这本书没有固定的页码。我想先问问你们——一本没有页码的书，我们上课要说到某个地方，该怎么说才能让别人一下就翻到？

学生互动分享

参考：让学生自己想办法。多半会有同学想到用“第几部”，再有同学补上“还得说上还是下”。这时教师顺势定下全班的说法就行——一律说“第一部 上”“第二部 下”，不说第几页；说得出在哪一部、哪一节，就算说清楚了。这个约定是学生自己定的，后面三节课他们会用得更自觉。

师：还有一件要提醒的事：书的最末尾有一篇“附录”，那不是这本书的正文，也不是作者写的后记，是另一本书里谈到这本书的一段文字，我们这几节课不读它、也不讨论它。

师：每一部具体讲了什么，我今天不说——下一节课由你们来说给我听。

师：下面这张七天计划表，右边一列我先空着两处。请你们看着六节的顺序，自己认领——哪一天读哪一部，写进你自己的表里。这本书很短，你要是想两天读完前两部，也可以自己调，只要七天后读完、三张记录齐了就行。（给 2 分钟，学生自己填写并与同桌对一对进度安排）

| 时间    | 阅读任务         | 读的时候顺手做                            |
| ----- | ------------ | ---------------------------------- |
| 第 1 天 | 第一部 上        | 圈出所有出现“时速多少英里”的地方                  |
| 第 2 天 | 第一部 下        | 标出大会判决与乔纳森抗议的段落                    |
| 第 3 天 | 第二部 上        | 标出江说“天堂就是尽善尽美”的那一段                |
| 第 4 天 | 第二部 下        | 留意视角忽然换到另一只年轻海鸥身上的地方              |
| 第 5 天 | 第三部 上        | 圈出乔纳森收下的学生的名字                      |
| 第 6 天 | 第三部 下        | 留意乔纳森消失前叮嘱弗莱契的话                    |
| 第 7 天 | 回读自己标过的地方，整理三张追踪记录 | 把三个贯穿任务补齐（附录不读）                    |

师：接下来是三个贯穿七天的任务，请准备一支笔和几张便签。

第一个任务，“我的问题”阅读单。刚才你们已经提过一轮问题了，读的时候继续往里写。这次我给三个方向，每个方向至少写一条：一是情节走向，接下来会怎样、为什么这样走；二是人物动机，谁为什么这么做、换作是我会不会这样；三是作者写法，哪里前后呼应、作者为什么要这么安排。为什么定这三个方向？因为后面两节交流课，正好顺着“情节—人物—写法”往下聊，你现在记的问题，到时候就是我们讨论的题目。

| 提问方向                | 我的问题（每个方向至少 1 条·越多越好） | 出处（第几部、上还是下） |
| ------------------- | -------------------- | ------------ |
| ① 情节走向（接下来会怎样·为什么这样走） |                      |              |
| ② 人物动机（谁为什么这么做）     |                      |              |
| ③ 作者写法（呼应·对照·为什么这么安排） |                      |              |

第二个任务，速度追踪。这本书有个很特别的地方：它一路用具体的时速给乔纳森的进展做标记。今天我们已经听到一个数字了——二百一十四英里。请你每读到一个新的时速，就记一笔：数字是多少，当时正发生什么事。

第三个任务，只记一句话。书里有一句“咱们从水平飞行开始”，它一共出现两次，出现在完全不同的两个地方。请你把这两处都标出来，先别急着想为什么——第三节课我们专门讲它。

师（总结）：最后给一个读法上的提醒。这本书篇幅很短，但有些段落读起来会有点绕，尤其是江和乔纳森的那几段对话。碰到读不懂的地方，不要硬着头皮往下翻，标一个问号、退回去再读一遍，或者干脆记到“我的问题”单子上带到课堂来。读到不懂的地方能停下来，这不是读得慢，这是高年级要养成的本事，它叫监控——自己看住自己有没有真的读懂。七天后，我们带着读完的书、三张记录，回到课堂上来。

本课完。

## 第二课时 · 阅读交流课 1

### 本课三维教学目标

【知识技能】用一句话说清三部各讲了什么，并说明三部之间是怎样一层层推进的；按顺序摆出乔纳森在全书中的关键节点，从独自练飞、撞海屈服、悟出短翅、被判放逐，到远崖独居、被接往更高的世界、决意返回、带队回群、把学生交出去；知道年轻海鸥弗莱契·林德被放逐的缘由，并能说出他与乔纳森被逐后的第一反应有何不同。

【过程方法】重点显性训练比较与提问两个策略：用故事地图把乔纳森与弗莱契两条“被逐—历练—回来”的路并排摆出来，找出两人在被逐缘由、被逐后第一反应、谁在此时出现、后来成了什么角色四个维度上的异同；带着上一节课自己写的“我的问题”，在梳理中找出哪些已经有了答案。

【情感价值】感受乔纳森唯一一次屈服与随后立刻背弃誓言的落差；体会一个人被群体推出去之后，可以走向怨恨，也可以走向学习——这两条路在书里各有一只海鸥走过。

> 本节为第 2 节阅读交流课，与第 3 节同日连排、中间没有自读时间——本节课尾不布置任何回家再读的任务，只承接本节的现场产出、预告下一节。

### 一、读前回顾·分享读完的第一感受（10 分钟）

师：同学们，这一周大家把《海鸥乔纳森》读完了。正式梳理之前，我想先听一听你们合上书那一刻的第一感受。不用长，一句话就好。

师：请你用一个词，或者一句话，告诉别的同学：这是一本什么样的书。可以是“奇怪”、可以是“越读越不像在写海鸥”、可以是“结尾有点没看懂”，都行。

学生自由分享

参考：同学们说的词多半会集中在几类——“奇怪／不太像动物故事”（后两部越来越不像在写鸟）、“痛快”（他破纪录、他回去授课、梅纳德一下子飞起来）、“难过／不公平”（大会那一段、鸥群围攻那一段）、“没读懂”（江那几段话、乔纳森最后为什么变透明消失）。最后一类尤其要请同学说出来，那正是我们两节交流课要处理的东西。

师：我先接住“没读懂”这一类。我想请刚才说没读懂的同学具体说说，是哪一段让你卡住了？

学生互动分享

参考：常见的卡点有三处——江说“天堂就是尽善尽美”到底什么意思；乔纳森最后为什么会变透明、他算不算死了；结尾弗莱契那句“一只海鸥是关于自由的无限观念”，连书里的年轻海鸥都听不懂。这三处正好是下一节课的正题。这里教师只登记、不解答。

师：好，把你们卡住的地方先记着，下一节课我们逐段拆。这一节我们做一件更基础、也更要紧的事——先把这本书读全、读清。请把你们的速度追踪记录和“我的问题”单子摆到桌面上，这节课我们用第一张单子和“我的问题”里①情节走向那一行。

### 二、三部的骨架·一部一句话（20 分钟）

师：这本书作者已经替我们分好了三大块。读长篇也好、读短篇也好，第一步都不是抠细节，是先把骨架立起来。请看这张表，右边一列空着——请你用一句话，不超过二十个字，概括这一部讲了什么。

| 部  | 节     | 这一部讲的“一件事”（请填） |
| -- | ----- | -------------- |
| 第一部 | 上 / 下 |                |
| 第二部 | 上 / 下 |                |
| 第三部 | 上 / 下 |                |

师：我给一分钟想，然后请三组同学，每组认领一部。

学生互动分享

参考（教师听完各组分享后收口）：

第一部：乔纳森在自己的鸥群里痴迷练飞、突破速度，最后被大会判为不负责任、放逐远崖。

第二部：他被两只发光的海鸥接到一个海鸥人人练飞的世界，拜长者江为师，学会以思想的速度飞行，然后决意回到尘世当导师。

第三部：他在远崖收下弗莱契等被放逐的年轻海鸥，带他们飞回鸥群公开授课，最后把学生交给弗莱契，自己消失。

师：三句话摆在一起，你们发现了什么？我想请你们看一看这三部之间是什么关系——是三件不相干的事凑在一起，还是一层一层递进的？

学生互动分享

参考：是递进的，而且递进的方式很清楚：第一部他被推出去，第二部他往上走，第三部他自己走回来。更值得注意的是最后一步——第三部他回的地方，正是第一部把他赶走的地方。一个人被赶出去以后又自己走回去，这是这本书结构上最要紧的一个弯。

师：现在请把你们的速度追踪记录拿出来。第一部是这本书里数字最密的一部分，我们就用你们记的这些数字，给第一部再分一次段——请你把第一部里出现过的时速按先后念出来，并且说清楚每一个数字是在什么时候出现的。

学生互动分享

参考（教师把学生念的数字按先后收拢，数字与情形均据书中第一部）：七十英里是失控的临界，一到这个速度就翻滚坠海；九十英里是他领悟“高速时翅膀要静止不动”之后创下的第一个纪录，但改变姿势时又在半空中爆炸、重重撞进海面；一百四十英里是他在夜里悟出“收拢双翅、只用翼梢”等于短翅之后达到的，而且这一次他能控制；到第一部下，他从五千英尺俯冲，以二百一十四英里穿过正在吃早餐的鸥群。

师：请你看着这一串数字回答我：它们只是在说他越飞越快吗？还是也在说别的什么？

学生互动分享

参考：这串数字其实是第一部的一条暗线——每一个新数字后面都跟着一次代价或一次领悟：九十英里跟着一次撞海和一句认命的誓言，一百四十英里跟着誓言被推翻，二百一十四英里跟着的就是那场判他放逐的大会。所以第一部不是“他越练越好”这么简单，是“他每上一个台阶，和鸥群的距离就远一步”。这串数字请你们先收好——第三部我们还会碰到它，到时候你会发现有人对这些数字说了一句很不客气的话。

师：还有一处值得留意。第二部的末尾，作者忽然不写乔纳森了，镜头切到另一只年轻海鸥身上。哪位同学记得那是谁、他当时正在干什么？

学生互动分享

参考：是弗莱契·林德。他因为绕着海鸥长者做了一个桶式翻滚而被原鸥群放逐，正满怀怨恨飞向远崖，发誓要做“一个真正的叛逆”。这时一个柔和的声音进入他脑海，要他不要怨恨、宽恕鸥群、回去帮助他们提高认识。

师：请注意，这里出现了两个“长者”，很容易混。第二部里教乔纳森的那位长者叫江，是第二个世界的老师；把乔纳森和弗莱契先后判出去的，是原鸥群的海鸥长者，是另一位。以后我们说“长者”，一定要说清楚是哪一位——这一点下一节课我们还要专门用一张图来理。

### 三、故事地图·两只海鸥的“被逐—历练—回来”（25 分钟）

师：刚才有同学说，弗莱契被赶出去的样子跟乔纳森不太一样。这句话说得很准，我们这一环节就把它做实。

师：我们用一张故事地图。这本书里的两只主角海鸥，走的其实是同一个形状的路——先被赶出家门，中间经历一段，最后回来，而且回来时的身份都变了。这个形状可以写成三段：被逐、历练、回来。我们把这三段做成三列，把两只海鸥做成两行，一格一格填进去。

师：这张地图有四个要填的维度，我先说清楚：第一，被逐的缘由是什么；第二，被逐之后他第一反应是什么；第三，这时候是谁出现在他身边；第四，最后他成了什么角色。

| 角色    | 被逐的缘由 | 被逐后的第一反应 | 这时谁出现了 | 最后他成了什么角色 |
| ----- | ----- | -------- | ------ | --------- |
| 乔纳森   |       |          |        |           |
| 弗莱契   |       |          |        |           |

师：分四个小组，每组认领一个维度，两只海鸥都要填。填的时候有一条硬要求：每一格都要能说出出处在哪一部、哪一节。（给小组 8 分钟查书填写）

（教师巡场。学生最容易卡住的是乔纳森“被逐后的第一反应”这一格——他在远崖并没有喊叫抗议，而是继续学习，容易被学生写成“很伤心”。提醒他们回第一部下去找那句写他痛苦来源的话。）

学生互动分享（按维度逐组汇报，每组说完由其他组补充出处）

参考（教师整合，各组对照自己单子上的填法）：

| 角色  | 被逐的缘由                              | 被逐后的第一反应                                             | 这时谁出现了                                       | 最后他成了什么角色                                |
| --- | ---------------------------------- | ---------------------------------------------------- | -------------------------------------------- | ---------------------------------------- |
| 乔纳森 | 高速穿越正在吃早餐的鸥群，被长者判“太轻率，太不负责任”（第一部 下） | 继续学习——学会高速疾降捕深水鱼、空中睡觉、夜航百英里、穿雾冲上晴空。痛苦的不是孤独，而是同类不肯相信（第一部 下） | 两只羽翼发光的海鸥，说要带他到更高的地方去，并告诉他“一个阶段学完了”（第一部 下） | 先是学生，后来成了远崖的老师，再后来把学生交出去（第二、三部）        |
| 弗莱契 | 绕着海鸥长者做桶式翻滚（第二部 下）                 | 满怀怨恨飞向远崖，发誓要做“一个真正的叛逆”、要让他们后悔（第二部 下）                 | 乔纳森——一个柔和的声音进入他脑海，要他不要怨恨、宽恕鸥群（第二部 下）      | 先是首徒，最后接手全班，对新学员说“咱们从水平飞行开始”（第三部 下） |

师：表填好了，现在是这一环节最要紧的一问。比较这个策略，最容易停在“看出两边像”上；真正有用的是下一步——这些相同和不同，让你对这本书有了什么新的理解？我先问相同的部分：两只海鸥被赶出去的缘由，本质上是不是一回事？

学生互动分享

参考：本质上是一回事。两人都不是因为伤害了谁，而是因为在飞行上做了鸥群规矩不允许的事——一个是飞得太快、太不像话，一个是绕着长者翻了个跟头。判他们的还是同一位长者。也就是说，这个鸥群赶走的从来不是坏鸟，是不一样的鸟。

师：再看不同的部分。同样是被赶出去，一个继续学习，一个发誓报复。这个不同重要在哪里？

学生互动分享

参考：这个不同，其实是全书最关键的一处分岔。被推出去以后往哪儿走，是两条完全不同的路：一条是怨恨，一条是继续学。书里写弗莱契走的第一步本来是怨恨那条，是乔纳森在半空中把他拉了回来——乔纳森对他说的第一句话，不是“来跟我学飞”，而是“不要怨恨他们”。这就解释了一件事：乔纳森为什么非要回尘世不可。他不是回去证明自己对，他是回去接住下一个被推出去的鸟。

师（总结）：这张故事地图我们没有为画而画。它替我们看清了三件事：这本书的两只主角走的是同一个形状的路；这个鸥群赶走的是“不一样”而不是“坏”；被赶出去以后往哪儿走，有两条路，而全书的转折就发生在这个岔口上。请把这张地图夹进书里，下一节我们还要用它。

### 四、本节收束·把疑问摆出来（5 分钟）

师：这节课我们立了骨架、画了地图。现在我请你们看着自己的这张表，把还没解决的疑问说出来。特别是你“我的问题”单子上①情节走向那一行，有哪些已经有答案了，哪些还悬着？

学生互动分享（教师只登记疑问，不展开）

参考（教师只归类、不解答，每类一句带过）：一类是关于第二个世界的——那到底是什么地方，江说“这个世界也不是天堂”是什么意思；一类是关于人的——乔纳森的八个学生都是些什么鸟，为什么全是弃儿；还有一类是关于结尾的——乔纳森为什么变透明消失，最后那句“咱们从水平飞行开始”为什么要再说一遍。

师（预告）：这三类疑问其实是一个问题的三个面：这本书里，一个人是怎么把自己学到的东西交给另一个人的。下一节课我们就沿着这条线走，先细读三段“老师的话”，再用一张人物关系图把书里的人摆到位置上。请把今天的故事地图、速度追踪记录留在桌上，“我的问题”单子上②人物动机、③作者写法那两行也别收起来——下一节课直接接着这两行讨论，不用另外准备什么。

本课完。

## 第三课时 · 阅读交流课 2

### 本课三维教学目标

【知识技能】读懂书中三段关键对话的言外之意——江说“天堂就是尽善尽美”、乔纳森对弗莱契说的第一句话、乔纳森对断翅的梅纳德说“我是说你自由了”；分清全书人物之间的两类关系，把人推出去的关系与把人接住的关系；说清“咱们从水平飞行开始”两次出现的位置与差别，以及“鸥神之子”这个称呼是谁在喊、乔纳森本人是什么态度。

【过程方法】重点显性训练推断与比较两个策略：从人物说出口的话，推断书里没有直接写出来的意思，每一处推断都要说出凭的是哪一句；用人物关系图把散在三部里的人物摆到位置上，比较两位长者对待学习的不同方式，比较同一句话在两个位置上的不同分量。

【情感价值】体会“我是说你自由了”这一句为什么比“你能飞”更有分量；理解乔纳森临别为什么特意叮嘱不要把他奉为神明；感受结尾弗莱契从讲大道理退回到“咱们从水平飞行开始”的那一刻。

---

### 一、读前接续·把卡住的地方摆回桌上（5 分钟）

师：上一节课临下课，你们提了三类疑问：第二个世界到底是什么地方、八个学生为什么全是弃儿、结尾那句话为什么要说两遍。这节课我们逐个处理。

师：处理的办法是回到原文里去。这本书篇幅很短，好些分量重的意思，作者不是用一段情节写出来的，是用一句话说出来的——所以这节课我们不再往前赶情节，而是停下来，把三段对话逐句拆开看。

师：还有一样东西先摆到手边。第一节课你们写的“我的问题”单子，上一节只用了①情节走向那一行；这一节请把②人物动机、③作者写法两行摊开——今天细读三段对话，问的正是“谁为什么这么做”；最后比“咱们从水平飞行开始”为什么要说两遍，问的正是作者写法。讲到哪一行，就把你自己写的那条问题拿出来对一对。

师：拆的时候我们用同一个动作，叫推断。推断不是猜：书里没有直接说的意思，你要从它直接说了的那句话里推出来。所以每一次我都会追问你同一句话——你凭哪一句推的？

---

### 二、细读三段“老师的话”（25 分钟）

师：第一段在第二部上。乔纳森到了那个新世界，一开始以为自己到了天堂。他去问即将离开的长者江。请听——

> “江，这个世界根本不是天堂，对不对？”
> 长者在月光下微微一笑。“你又学到了一点，乔纳森，”他说。
> “那么，离开了这里，又会怎么样呢？我们要到哪儿去？难道没有天堂这么个地方吗？”
> “对，乔纳森，没有这么个地方。天堂不是空间，也不是时间。天堂就是尽善尽美。”他沉默了片刻。“你飞得很快，对不对？”

师：先解决一个字面问题：江说天堂不是什么？

学生互动分享

参考：不是空间，也不是时间。也就是说，天堂不是一个“地方”，也不是某个“以后”。所以乔纳森追问“我们要到哪儿去”这个问法，本身就问错了——他还在把天堂当成一个可以飞过去的地点。

师：那么“天堂就是尽善尽美”是什么意思？这一句作者没有解释，请你们推。提示：江的下一句话是“你飞得很快，对不对”。他为什么忽然问速度？

学生互动分享

参考（根据文本作出的合理推断）：因为江要用速度来打这个比方。他后来说得很清楚——达到尽善尽美的速度，也就开始到达了天堂；而尽善尽美的速度不是一千英里、也不是一百万英里、也不是光速，因为任何数字都是有限的，而尽善尽美是无限的。合起来推：天堂不是飞到某个地方去，是把一件事做到没有局限的那个状态。

师：你们凭哪一句推出来的？

学生互动分享

参考：凭“任何数字都是有限的，而尽善尽美是无限的”这一句。这是全书回答得最直接的一处。请注意这句话对第一部的杀伤力——乔纳森前面辛辛苦苦追的九十英里、一百四十英里、二百一十四英里，全是有限的数字。到了第二部，作者等于告诉他：你追的方向对，但你数错了单位。

师：第二段在第二部下。刚被放逐的弗莱契满心怨恨，一个声音进入他脑海。这是乔纳森对弗莱契说的第一句话——

> “不要怨恨他们，海鸥弗莱契。别的海鸥把你赶了出来，吃亏的是他们自己。总有一天他们会后悔的，总有一天他们会懂得你现在已经懂得的道理。宽恕他们吧，帮助他们提高认识。”

师：上一节课我们已经注意到，这第一句话不是“来跟我学飞”。现在我要问得更细一点：乔纳森为什么把“宽恕”排在“学飞”前面？

学生互动分享

参考（根据文本作出的合理推断）：因为一只满心想报复的鸟，学飞是为了让别人后悔，那个方向从一开始就是错的。乔纳森自己走过这条路——他被赶走后没有走向怨恨，所以他知道岔口在哪儿。接下来那一段也印证了这个判断：他没有先教动作，而是先问弗莱契愿不愿意为了飞行去宽恕、去学习、有朝一日回到他们中间帮助他们；弗莱契答“我愿意”之后，他才说“咱们从水平飞行开始吧”。顺序是不能颠倒的。

师：第三段在第三部上。乔纳森带着学生回到鸥群一个月后，一只左翅动不了的海鸥科克·梅纳德爬到他脚边求助。请听乔纳森是怎么回答的——

> “海鸥梅纳德，就在此时、此地，你有自由恢复你的本性，恢复你真正的本性。任何力量都阻挡不了你。这是伟大海鸥的法律，也是真正的法律。”
> “你是说我能飞啦？”
> “我是说你自由了。”
> 瞧，多么简单！多么快！海鸥梅纳德展开了双翅。毫不费力，一下子就飞入黑色的夜空。整个鸥群都被他的叫声从梦中惊醒。只听得他从五百英尺的高空拼命叫喊。“我能飞啦！听着！我能飞啦！”

师：这段里有一处特别值得停一停。梅纳德问的是“你是说我能飞啦”，乔纳森没有顺着答“是”，而是换了一个说法：“我是说你自由了。”我想请你们推一推：这两句话差在哪儿？

学生互动分享

参考（根据文本作出的合理推断）：“你能飞”说的是一个本事，是被别人认证的；“你自由了”说的是他本来就有、只是自己不信的东西。乔纳森不是治好了他的翅膀，也没有教他任何动作——他只是不肯用“我准许你飞”的说法。这一句改口，把力量还给了梅纳德自己。

师：这个推断能回到书里找到旁证吗？

学生互动分享

参考：能。第三部上，近千只海鸥聚来听讲时，有海鸥说他是“特殊的、天才的、神圣的”，乔纳森的回答是——瞧弗莱契、还有罗维尔、查理士·罗兰德、朱迪·李，难道他们也是特殊的、天才的、神圣的？不，不比你们强，也不比我强；唯一的不同，仅有的唯一不同，是他们已经开始认识到自己的潜能，并且已经开始发挥。这段话跟“我是说你自由了”是同一个意思的两种说法：他一直在拒绝把自己说成一个例外。

师（总结）：三段话拆完了。我们做的都是同一件事——从人物说出口的一句话，推出他没有说的那层意思，而且每一次都能说出凭的是哪一句。没有线索的叫瞎猜，有线索的才叫读懂了。

### 三、人物关系图·两张网（20 分钟）

师：现在我们来处理“八个学生为什么全是弃儿”这个疑问。要处理它，先得把这本书里的人摆清楚。这本书的人物不多，但关系有两种，很容易混在一起。

师：请先把上一节的故事地图摊在旁边。那张地图上“被逐的缘由”和“这时谁出现了”两列，其实已经替我们起了个头——一列写的是把人推出去，一列写的是把人接住。这一节我们做的，就是把这两件事从两只海鸥扩到全书的人身上。

师：我们做一张人物关系图。这张图不按谁跟谁是亲戚来画，按“谁对谁做了什么”来画。请在自己的单子上画两组连线：一组是把人推出去的，一组是把人接住的。每一条线都要写清楚从谁指向谁、发生了什么事、在哪一部哪一节。

| 关系类型  | 从谁指向谁 | 发生了什么 | 出处（部/节） |
| ----- | ----- | ----- | ------- |
| 把人推出去 |       |       |         |
| 把人推出去 |       |       |         |
| 把人接住  |       |       |         |
| 把人接住  |       |       |         |
| 把人接住  |       |       |         |

师：我提醒一个最容易画错的地方：书里有两位长者，别把他们连成一个人。分组填，每组至少画三条线。（给小组 7 分钟）

学生互动分享（各组报线。教师不逐条追问出处，只挑有争议的两条追问“凭哪一段这么连”——通常争议出在“父母算不算把他推出去的人”和“苏利万既劝阻又送别，该归哪一组”）

参考（教师整合，学生补自己的单子）：

把人推出去的那一组——原鸥群的海鸥长者判乔纳森“太轻率，太不负责任”，放逐远崖（第一部 下）；同一位长者，后来又因弗莱契绕着他做桶式翻滚而把弗莱契放逐（第二部 下）；这位长者还下过令，跟弃儿说话或者看一眼的，同样被放逐（第三部 上）。此外，乔纳森的父母虽然不是把他推出去的人，但站在鸥群那一边劝他把力气用在觅食上（第一部 上）。

把人接住的那一组——两只羽翼发光的海鸥来接乔纳森，告诉他一个阶段学完了（第一部 下）；江收乔纳森为学生，教他以思想的速度飞行，并说下一课是理解仁慈和爱（第二部 上、下）；苏利万做他的同伴与陪练，后来虽然劝阻他回去，最后还是送别（第二部）；乔纳森接住弗莱契，此后在远崖又收下另外六名弃儿学生（第三部 上）；还乡以后，越界求学的特兰斯·罗维尔被判弃儿，成了第八个学生，断翅的科克·梅纳德也是在这时被他一句话送上天的（第三部 上）。这些学生里书中点到名字的，有亨利·卡尔文、马丁·威廉、查理士·罗兰德、朱迪·李等（第三部 上）。最后弗莱契接住新学员（第三部 下）。

师：图摆出来了，现在回答那个疑问：八个学生为什么全是弃儿？

学生互动分享

参考（根据文本作出的合理推断）：因为在这个鸥群里，被推出去的正是那些想学的。第一张网推出去的，恰好是第二张网接住的。所以这两张网不是各画各的，它们是同一批鸟：乔纳森自己就是先被第一张网推出去，后来成了第二张网上的一个结。罗维尔那件事最能说明问题——他是鸥群里第一个越界来求学的，一求学就立刻被判成弃儿，然后成了第八个学生。想学，就会被推出来；被推出来，就会被接住。

师：还有一条线值得单独看。你们注意到没有，江—乔纳森—弗莱契—新学员，这四步是接在一起的。请你们说说，这条线上每一步在做同一件什么事？

学生互动分享

参考：每一步都是“被教过的那一个，回过头去教下一个”。而且书里点破过这件事——苏利万劝阻乔纳森回尘世的时候，也提到过若当年江不回去教他，乔纳森未必有今天。所以乔纳森决定回去，不是他一个人心血来潮，是他在重复江对他做过的事。

师（总结）：这一张图我们从“谁对谁做了什么”入手，最后看清的是全书的结构：一边不停地往外推，一边不停地往回接，接的人恰好是被推出来的人，而且接过的人后来都会去接下一个。请把这张图夹进书里，最后一节课我们还要用它。

### 四、“咱们从水平飞行开始”·两次出现（10 分钟）

师：最后十分钟，我们兑现第一节课布置的第三个任务。请翻出你标的那两处——“咱们从水平飞行开始”。谁来说说，这两次分别出现在哪儿？

学生互动分享

参考：第一次在第二部下，乔纳森对刚刚答应宽恕鸥群的弗莱契说“咱们从水平飞行开始吧……”；第二次在第三部下，也就是全书最后，弗莱契对着一群听不懂大道理、一脸茫然的新学员，叹了口气，改口说“咱们从水平飞行开始”。两处措辞略有不同，前一句带“吧”和省略号。

师：请你们比一比：同一句话，第一次是谁对谁说，第二次是谁对谁说？

学生互动分享

参考：第一次是老师对学生说，第二次是当年那个学生，站到了老师的位置上，对新的学生说。这本书用同一句话把开头和结尾扣在了一起。

师：那么第二次说这句话之前发生了什么？弗莱契本来想说的是什么？

学生互动分享

参考：他本来讲的是“一只海鸥是关于自由的无限观念，是鸥神的表象”这样的大道理，年轻的海鸥们不解地望着他，心里想这听起来可不像是翻斤斗的规则。他讲不通，才叹气改口从水平飞行讲起。也就是在这一刻，他忽然明白了一件事——他的朋友确实不比自己更神圣。

师：这句“不比自己更神圣”，正好接上乔纳森消失前的叮嘱。我读那一段——

> 转眼间，乔纳森的身体已在空中摆动，全身闪亮，开始变成透明。“别让他们瞎造我的谣言，别让他们把我奉为神明，成不成，弗莱契？我是海鸥，我喜欢飞行，或许……”

师（总结）：这一节课我们做了三件事：细读三段对话、画了两张网、比了同一句话的两次出现。它们合起来回答了上一节留下的那个问题——这本书讲的是一个人怎么把自己学到的东西交给另一个人；而这件事能成，前提恰恰是被教的那个人最后发现，教他的人并不比自己更神圣。顺带说一句你们读的时候多半注意到了：书里好几次出现“鸥神之子”这个称呼，可每一次都是别人在喊——弗莱契转述鸥群的话、鸥群在弗莱契撞崖醒来时高呼、也有海鸥在听讲时这么叫他，而同一夜还有一半的海鸥在喊“魔鬼”。这个称呼从来不是作者给他的身份，是鸥群给的；乔纳森本人明确拒绝，临走还专门叮嘱了那一句。

师（预告）：下一节是最后一节。我们要做两件事：把“自由”这个词从几个方向挖一遍；然后把第一节课那场大会重新开一次，由你们来重审那个判决。请把预测阅读单、故事地图、人物关系图都带来——那两张图上的每一格，到时候都是你发言用得上的证据。

本课完。

## 第四课时 · 思辨&应用课

### 本课三维教学目标

【知识技能】把全书对“自由”的说法整理清楚——自由不是想干什么就干什么，书里说的是认识并发挥自己的潜能，以及“只有通向自由的法律才是唯一的真正法律”；能从三部里各找出至少一处支持自己判断的证据，并按部与节说清出处；回到第一课时的预测阅读单逐条验证。

【过程方法】重点显性训练转化与监控两个策略：把整本书读来的理解，转化成一场重审大会上站得住的发言；同时回到读前写下的预测逐条对答案，看清自己当初凭的是线索还是印象。教学中同时用到联结，把书里的处境接到自己的一段真实经历上。

【情感价值】在一个没有标准答案的两难里练习亮出立场、讲清理由；由乔纳森唯一一次屈服那一段，回看自己是否也有过为了让大家高兴而把想做的事放下的时刻；理解一个判决可以被重新审视，而重审要靠证据，不靠嗓门。

师：同学们，最后一节课的第一件事，是把第一节课那张预测阅读单拿出来，填上最后一列。对的画勾，错的画问号，猜对一半的画三角。给你们两分钟。

（学生独立填写）

学生互动分享（请三位同学各读一条自己的预测和验证结果）

参考：这一步不比谁猜得准，只看一件事——你当初写的依据，现在回头看还站得住吗。有的同学猜对了结果，但依据是“感觉他是主角，主角总会回去”，这种就叫蒙对；有的同学猜错了，但依据抓的是“他最后一句话没说完”，这种错得比蒙对更有价值。能看出自己当初是靠线索还是靠印象，这个本事叫监控。

师：收起单子。下面进入今天的正题：这本书从头到尾在说一个词——自由。

### 二、六面体讨论图·把“自由”挖一遍（20 分钟）

师：我们先花几分钟认识一件新工具，叫六面体讨论图。它的用处是这样的：当我们要讨论一个很大的词，比如“自由”“公平”“友谊”，很容易讨论着讨论着就变成一人一句感想，谁也接不上谁。六面体的办法是把这个词摆在中间，从固定的几个方向各问一遍——描述、比较、争论、分析、联系、应用。每个方向问一遍，讨论就不会打转。今天时间有限，我们用其中四面，剩下两面留给你们自己往下想。

师：第一面我来示范，叫“描述”，问的是：在这本书里，自由具体长什么样子？不要说抽象的话，要举出书里的一个画面。谁来试一个？

学生互动分享

参考：最容易举的一个画面是梅纳德——一只左翅动不了、爬到乔纳森脚边求助的海鸥，听完“我是说你自由了”这一句，当场展开双翅飞入夜空，从五百英尺高处喊“我能飞啦”。这就是这本书里“自由”最具体的一个样子。

师：这就叫描述面：不解释词义，只给画面。剩下三面交给你们。分六个小组，每两组认领同一面，用十分钟讨论并填写，然后每组一分钟汇报——同一面的两组正好互相补。填的时候有一条硬要求：凡是引用书里的内容，都要说得出在哪一部、哪一节。

| 讨论的方向          | 我们组的讨论结果（要写出书中依据·注明部/节） |
| ---------------- | ------------------------ |
| 描述：书里的“自由”是什么样子的（教师已示范） |                          |
| 比较：乔纳森要的自由，和鸥群要的“活下去”，差在哪儿 |                          |
| 争论：如果自由要付出被开除的代价，还值得吗 |                          |
| 分析：为什么书里说，最难的事是让一只鸟相信自己是自由的 |                          |

（教师巡场。提示“分析”组回到第三部下乔纳森那段自问；提示“比较”组回到第一部上父亲的话与第三部上乔纳森讲法律的那段。）

学生分组汇报

参考（教师逐面收口，只补书里的依据，不替学生下结论）：

比较这一面：鸥群那一边说得最清楚的是长者判词里那一句——我们来到这个世界，就是为了吃，为了活下去，尽可能多活些日子（第一部 下）；乔纳森这一边说得最清楚的是他抗议时那一句——现在我们有了生活的目的，学习，进行发明创造，取得自由（第一部 下）。两边的差别不在勇敢不勇敢，在于把“活多久”当成目的，还是把“学到什么”当成目的。

争论这一面：代价在书里是实打实写着的——被判放逐、独居远崖、返群后被下令封锁、最后还被鸥群围攻要啄死。乔纳森自己也说过一句很无奈的话：这就是被误解的代价，他们要么叫你魔鬼，要么称你上帝（第三部 上）。这一面本来就不该有统一答案，值不值，请各组亮各组的判断——待会儿开大会时，这一面的结论正好派上用场。

分析这一面：书里有一处乔纳森自己的纳闷——世界上最难办的事怎么倒是使一只鸟儿确信他自己是自由的，而且可以亲自加以证明，只要他肯略微花费点时间练习练习（第三部 下）。顺着这句可以推：难的不是飞，是相信“我本来就可以”。梅纳德那只翅膀其实一直是好的。

师（总结）：几个方向问下来，我们对这个词的把握就不只是一句“自由很重要”了。请注意其中最容易被读丢的一层：这本书说的自由，不是想干什么就干什么，是认识并发挥自己的潜能——乔纳森当众否认自己特殊时说得很清楚，唯一的不同，仅有的唯一不同，是他们已经开始认识到自己的潜能，并且已经开始发挥。而且他从头到尾没有说过不要法律，他的说法是：只有通向自由的法律才是唯一的真正法律（第三部 上）。带着这两句，我们去开大会。

### 三、阅读成果·重开鸥群大会，重审那个判决（25 分钟）

师：还记得第一节课我答应过你们的事吗？我们要把那场大会重新开一次。

师：议题只有一个：当年鸥群判乔纳森“太轻率，太不负责任”，这个判决要不要改。全班分三方——辩护方，你们是乔纳森的学生，主张改判；判决方，你们代表原鸥群与长者，主张维持原判；其余同学是陪审的鸥群，先不表态，听完两边再决定。

师：有两条硬规矩。第一，每一方的发言里至少要用上两处书里的证据，而且要说清在哪一部、哪一节——光说“他是好鸟”不算数。第二，陪审方听完要投票，投完还要说一句你被哪一条证据说服了。

师：证据到哪儿找？把前两节的故事地图和人物关系图摊开——地图上“被逐的缘由”“最后他成了什么角色”两列，关系图上“把人推出去”“把人接住”两组线，本身就是现成的证据单，每一格都注了在哪一部哪一节。

师：动笔之前，先各自把立场想清楚。这张表填两行就够，重点在最后一栏。

| 我要主张的 | 书中相关片段（注明部/节） | 我的判断 | 我的理由 |
| ----- | ------------- | ---- | ---- |
|       |               |      |      |
|       |               |      |      |

（学生填表 4 分钟，随后按三方就座、分组准备 4 分钟，每方推两位代表）

师：提醒两边一件事，免得辩得太浅。辩护方不要只说“他很努力”，第三部里有实打实的结果可用。判决方也不要只讲吃饭——书里有一个更难反驳的角度，我提示一句：那天他是闭着眼睛从正在吃早餐的鸥群中间穿过去的。

师：还有一个问题，两边迟早都要正面碰上：他后来自己选择回到这个鸥群。辩护方会说这证明他从没想过背弃族群；判决方会说，正因为他后来回来了，才说明当年赶他走这件事本身有代价、有后果。这一条谁用得更好，谁就更贴着书。

（辩护方陈述 2 分钟，判决方陈述 2 分钟，双方自由回应 2 分钟）

学生分组汇报

参考（教师作为大会主席，只梳理不裁决）：

辩护方最可能用到的证据——他高速穿过正在吃早餐的鸥群，没有伤到任何一只海鸥（第一部 下）；他独居远崖期间学会的本事全是实用的，高速疾降捕深水鱼、夜航百英里、穿雾冲上晴空（第一部 下）；他回来以后，断翅的梅纳德飞起来了（第三部 上）、罗维尔越界求学成了第八个学生（第三部 上）；他从没有要求过特权，反而当众否认自己特殊（第三部 上）。

判决方最可能用到的证据——冬天要来、船会变少、鱼会下沉，这是父亲说过的实情（第一部 上）；长者说“生命是莫测的，是不可知的”，鸥群的规矩是拿命换来的（第一部 下）；他确实闭着眼睛以极高的速度从正在吃早餐的鸥群中间穿过，事后没有伤亡是运气好，规矩要防的正是万一。此外，他回去以后鸥群真的分裂了，一半喊“鸥神之子”、一半喊“魔鬼”，还发生了围攻（第三部 下）——判决方可以据此说，当年的顾虑不是空穴来风。

（陪审方投票，请三四位同学说出自己被哪一条说服）

师：这里我不作最终裁决，只做一件事——把两边用到的证据数一数，指出哪一方的判断更贴着书。要留意的是，书里其实给了一个比“该不该”更细的说法。围攻的第二天，弗莱契质问怎么能去热爱一群想啄死自己的暴徒，乔纳森的回答是：你爱的当然不是那个，你当然不爱仇恨与邪恶；你应该通过练习去认识真正的海鸥，要看到每只海鸥的美德，并帮助他们去认识自己的美德（第三部 下）。也就是说，他面对的从来不是“这群鸥好不好”，而是“能不能看见他们身上还没被自己认出来的东西”。

师（收口追问·转化）：最后一问。你们今天做出的这个新判决，和原书是怎么接上的？换句话说，书里有没有替你们的判决留下线索？

学生互动分享

参考：接得上的地方不少。全书结尾，弗莱契在给新学员上课，这说明这个鸥群里终究有鸟愿意学；第三部上写返群一个月后，就有海鸥越界来求学、有近千只海鸥聚来听讲。但也要看到另一半：直到最后，鸥群仍然一半喊“鸥神之子”、一半喊“魔鬼”。所以这场重审不管改判还是维持，书都没有替我们盖章——作者把它留给了读者。

### 四、联系生活·那一夜他也想做一只平凡的海鸥（10 分钟）

师：大会开完了，最后十分钟，我想把这本书从海上挪到你们身上，但不问大问题。

师：先回到第一部上的一个晚上。乔纳森那次以时速九十英里失控、在半空中爆炸、重重撞进海面，夜里他在月光下的海面上醒来，心里响起一个声音劝他认命。他屈服了，发誓今后要做一只平凡的海鸥。书里在这句后面加了一句话——这样会使大家都高兴。

师：（稍停顿）我想问的是：你有没有过这样一刻，为了让大家高兴、为了不显得自己奇怪，把一件自己很想做的事放下了？当时你是怎么权衡的？后来呢，那件事你捡回来了没有？

学生自由分享（请三四位同学说，教师不评价、不追问隐私）

参考：这一问不要求答案漂亮，只要求具体。可以说的方向很多——因为同学都不看所以不再看某一类书、因为怕被说奇怪而不再做某件事、因为大家都选甲所以自己也改选了甲。说完之后回到书上看一眼：乔纳森那个誓言，在同一个夜里就被他自己背弃了——书里写“刚刚发过的誓已经忘掉了，已被那阵疾风吹得无影无踪了”。请注意作者的态度：他没有责怪乔纳森发那个誓，只是让他很快又飞了起来。

师（总结）：同学们，这四节课我们从一个判决开始，最后又回到这个判决。中间我们读了三段老师的话、画了两张网、把“自由”挖了几遍。临了我想请你们记住乔纳森消失前那句叮嘱：别把我奉为神明。这句话在这本书里的分量，不比“我能飞啦”轻——因为一旦把他当成神，你就有了不去练的理由：他是神，我不是。而书里给的说法始终是另一种：唯一的不同，仅有的唯一不同，是他们已经开始认识到自己的潜能，并且已经开始发挥。至于怎么开始，弗莱契在全书最后一句已经替我们说了——咱们从水平飞行开始。

全课完。
