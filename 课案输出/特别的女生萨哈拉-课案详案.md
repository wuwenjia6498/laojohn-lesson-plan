### 一、文本介绍

【内容简介】 萨哈拉·琼斯在上五年级——这是她第二次上五年级。三年级那年爸爸离开了家，从此没有消息，她把写给爸爸的信一直带在身上。有一天信从课桌里散落出来，被老师收走，交给了教导主任史丁先生，史丁先生把这些信塞进了装着她档案的大文件柜。此后她被安排到教学楼大厅接受“特殊教育”，同学背地里叫她“特别的萨哈拉”。妈妈到学校要求停止特殊教育，宁可让女儿留级，学校同意了。学校里没有一个人知道，这个不写作业、不开口读书的女孩，其实一直在偷偷写东西——她把写好的纸一页页从本子上撕下来，藏在公共图书馆 940 区书架底层一本书的后面，取名《我的痛苦人生和精彩历险》。第二个五年级开学，班上来了一位新老师波迪小姐：她在教室里插花、装台灯，立下三条以“一定要”开头的规矩，给每人发一本日记本，说欠她两美元。她讲寓言，讲乔治·华盛顿，讲一个自己编的长故事；她在萨哈拉只写了“我是作家”四个字的日记本上回批“我相信你！”，在萨哈拉四天没写日记时用红笔写下“作家需要写作”；她上门家访，对萨哈拉的妈妈说自己从不看学生的档案，说这孩子“将来能成为一名作家”。这一学年里，萨哈拉抠走过同学的一枚贴纸，失去过一个刚认识的朋友，又把贴纸还了回去；她终于在全班面前读完了自己写的《我的名字》，也在一只旧储物柜里拿回了写着自己名字的档案。全书结尾，她把写给爸爸的信一封封从窗口放走，重新拿出笔记本动笔——这一次她写的不再是“我的痛苦人生”。爸爸没有回来，德里也没有忽然变成好学生，这本书没有给出那样的结局。

【作者介绍】 本书作者是美国作家爱斯米·科德尔，译者陈水平。本课使用的版本为湖南少年儿童出版社·博集天卷 2019 年 5 月版，ISBN 9787556244423，电子版。该版是流式电子书，**没有固定页码**，所以这四节课我们说位置一律说“第几章”，不说“第几页”。这个版本的正文与版权页都没有收录作者简介，所以关于作者本人，我们能告诉大家的只有这些，不多编一句。书前另有一篇中文版前言，题目叫《秘密行程里的绿荫》，前言的作者在文中把这本书归到“灰姑娘的故事”这一类里，说它“是推荐给中国的孩子们的”，也是推荐给中国的小学和中学老师们的。需要说明的是，这篇前言末尾只印了撰稿人的头衔，没有印姓名，所以我们并不知道它是谁写的——这一点向学生说清楚即可，不要替它补一个名字。

### 二、教学目标（书级·三维）

【知识技能】知道全书共十三章、另有中文版前言一篇，采用第一人称叙述，叙述者就是主人公萨哈拉·琼斯，讲的是她“第二个五年级”这一学年；能按第一至四章、第五至十章、第十一至十三章把全书分成三段，说出各段的主要事件；能说出萨哈拉、波迪小姐、德里·赛克斯、瑞秋、巴黎、露兹、萨哈拉的妈妈、史丁先生等人物的身份与彼此关系；对“档案”“日记本”“贴纸”“写给爸爸的信”这几样反复出现的东西，能各举出一到两处它们出现的章节。

【过程方法】综合运用预测、提问、推断、整合、监控、转化六项阅读策略；能借助流程图把散落在十三章里的“写作”事件串成一条先后相继的线，看清萨哈拉是一步一步走到当众朗读的；能借助树形图按“谁在说”把书中关于萨哈拉的各种说法归类；能在讨论中把自己的判断回扣到具体章节的原文上，而不是只凭印象；遇到读不懂的段落（如德里那些错字连篇的日记）时，能主动停下来想办法把它读懂，并说出自己用的是什么办法。

【情感价值】体会一个被贴上标签的孩子，是怎样一点一点被人看见、又怎样自己开口说出“我是作家”的；理解“名字是别人给我的，但同时也是我自己的选择”这句话的分量；在“老师该不该先看学生档案”这类没有标准答案的问题上，愿意先听清对方凭的是什么，再讲自己的理由。

### 三、教学流程

## 第1课时 · 导读课

### 本课三维教学目标

【知识技能】知道《特别的女生萨哈拉》的作者、译者、版本与体例——全书十三章、第一人称、按章节定位；认识萨哈拉、波迪小姐、德里、瑞秋、巴黎、史丁先生几个主要人物的名字与身份；听教师朗读第一章与第五章的三处片段，知道萨哈拉把自己写的东西藏在公共图书馆 940 区，也知道“特别的萨哈拉”这个外号是怎么来的。

【过程方法】重点显性训练预测与提问两个策略：能从今天读到的三段原文里提取线索，对“她写的东西后来会不会被人读到”作出预测并写下依据；能在读前列出自己真正想问的问题，留待后面几节课分类处理。同时用一个环节把“读不懂时怎么办”显性化，为读德里的日记做准备。

【情感价值】对“一个被全班当成笨学生的女孩，其实偷偷写了一本书”这个反差产生好奇与不平，愿意用一周时间读完全书。

### 一、导入·藏在图书馆书架底层的一本书（15 分钟）

师：亲爱的同学们大家好。请把这本《特别的女生萨哈拉》摆在桌上，暂时不用翻开——今天这节课，我们从听开始。

师：我先读一段话给大家听，这段话就出自这本书。请大家只管听，听完我要问一个问题——但不是问“这是谁写的”，书名已经告诉大家一半了。

（教师朗读，定位：第一章）

> 但我总是自己一个人偷偷地写，不管写了什么，我都会把它们从本子上撕下来，然后藏在公共图书馆940区书架底层书后面的一个活页夹里。那个区域杂乱地堆放着一些有关其他地区的书，将来总有一天，会有人发现那里，将我写的东西像文物一样从尘土中刨出来。那一天，人们会认识萨哈拉·琼斯，一位秘密作家；那一天，他们会读到《我的痛苦人生和精彩历险》，他们的生活从此也会变得更加有趣；那一天，他们会承认我是一名作家，会庆幸我写下了自己的故事。

师：（稍停顿）我把这段话里的几件事拎出来，大家跟着我数一数。第一，这个人在写东西，而且是“自己一个人偷偷地写”。第二，写完不留在本子上，要一页页撕下来。第三，撕下来也不扔，藏进公共图书馆 940 区书架的最底层、一本书的后面，塞在一个活页夹里。第四，她给自己写的东西起了名字，叫《我的痛苦人生和精彩历险》。第五，她想着将来有一天，会有人把它像文物一样从尘土里刨出来。

师：说这段话的人，就是书名上的萨哈拉——萨哈拉·琼斯。这个大家一听就知道了。（稍停顿）我要问的是另一件事：光凭这段话，你猜她多大？她过着什么样的日子？在学校里是个什么样的学生？说的时候讲一句你是从哪儿猜的。

学生互动分享

参考：不求标准答案，只求学生把猜测挂在原文的某个细节上。学生常见的猜测有：应该不小了，因为她说话很像大人，还知道“文物”“活页夹”这些词；她大概过得不太好，因为她给自己写的东西起名叫“我的痛苦人生”；她在学校里可能是个成绩很好、很爱读书的学生，因为她读了那么多书才写得出这样的话；她一定很孤单，因为她只能“自己一个人偷偷地写”，还得藏起来。教师把这些猜测都接住，先不评判。

师：好，我把书里写的告诉大家，请你们和自己刚才的猜测对一对。（稍停顿）她是个小学五年级的女生。而且我还要补一句：她今年上的这个五年级，是她第二次上——她留级了。

师：（稍停顿）我知道有同学愣了一下。一个留了级的五年级女生，写了一本自己的书，藏在图书馆里，等着将来有人把它刨出来。这两件事，听起来像不像是同一个人身上的事？

学生自由分享

参考：多数学生会说不像。留级通常意味着“成绩不好”“书读不好”，而写书是件很难的事，还得读很多书才写得出来。也会有学生说像——正因为她在学校里过得不好，才更想在另一个地方证明自己。两种说法都留着，教师不下结论，只说：这本书从第一章起，就是在写这两件事怎么会长在同一个人身上。

师：还有一件事。在学校里，同学们背地里给她起了一个外号——他们叫她“特别的萨哈拉”。（稍停顿）请大家看一眼自己手上这本书的封面：这个外号，正是书名上的那几个字。

师：那么“特别”这两个字，在他们嘴里是夸奖吗？我们不猜，我们看她自己是怎么说的。这一段我来读，请大家听她说“听到”这个词，一共说了几次。

（教师朗读，定位：第一章）

> 班上的同学在经过我去洗手间时，都冲我发出“嘘嘘”声，并偷偷地叫我“特别的萨哈拉”。我知道“特别”这两个字的意思，可不是像王子或公主或电影明星那种光彩照人的特别。我假装没听到他们的嘲讽，但我其实听到了。不仅仅是耳朵听到了，我的双颊也听到了，所以它们变红了；我的双眼也听到了，所以它们直直地盯着墙壁，盯着我的膝盖，盯着我的鞋子；我的指甲也听到了，所以我拼命地啃着它们。嘲讽的声音穿过我的衣服，撕裂了我的皮肤，透过我的骨头，在我空洞的身体里回荡。

师：（稍停顿）她说“我假装没听到”，可是紧接着，她一连说了三个“听到了”——双颊听到了，双眼听到了，指甲也听到了。这三样东西，本来都是不会听的。

师：我想问一句：她明明可以只写“我很难过”三个字，为什么要绕这么大一个圈子，让脸、让眼睛、让指甲去“听”？

学生互动分享

参考：可以谈到的有：这样写，难过就变成看得见的了——脸红、眼睛不敢看人、啃指甲，都是别人从外面能看到的动作，读者跟着就看见了她当时的样子；她说的是“假装没听到”，所以嘴上不能承认听到了，只好让身体承认；一个人如果说“我很难过”，那是说给别人听的，而这些动作是她自己也管不住的，更真。教师收口：这本书是萨哈拉自己讲自己的故事，从第一章起就是这种写法——她很少直接说心情，她说身体做了什么。这一点请大家读的时候留意。

师：写这本书的人，是美国作家爱斯米·科德尔，翻译的是陈水平。这就是我们接下来四节课要一起读的书。

### 二、她写的东西，会有人读到吗（20 分钟）

师：刚才那两段，一段是萨哈拉藏起来的书，一段是同学给她的外号。现在我再给大家读第三段，这一段发生的时间要往后一点，是新学年开学以后。班上来了一位新老师，姓波迪，大家叫她波迪小姐。她做的第一件事里，有一件是给每个人发了一本日记本，要求每天写日记。

师：那么第一节日记课上，萨哈拉写了什么呢？请大家听。

（教师朗读，定位：第五章）

> 下课铃声响了，我一个字都没来得及写，我看着自己的日记本，上面一片空白，日记本也在瞪着我。
>
> “把你们的日记本传上来。”波迪小姐命令道。同学们转过头收了后面同学的本子，再把自己的放在上面，交给前面的同学往前传。我一下子就慌了，只好拿起笔，写了一句：
>
> 我是作家。
>
> 然后我的本子被传了上去，掺杂在一堆日记本里。很快，我就分不清哪本是我的了。一想到波迪小姐会看到我写的东西，我的脸就像煮熟的大虾一样又红又烫。感觉自己像个傻瓜，我怎么会这么写呀？
>
> 不管怎么说，她是老师，还是会看我的日记，还会给我写评语：
>
> 我是作家。
>
> 我相信你！

师：（稍停顿）请注意这一段里的时间。一整节日记课，她一个字都没写出来；本子要传上去了，她才慌慌张张写了四个字——我是作家。

师：写完她后悔了。她说自己“像个傻瓜”，还说“我怎么会这么写呀”。（稍停顿）我想请大家想一想：她写完为什么马上就后悔？她后悔的到底是哪一点？

学生互动分享

参考：可以谈到的有：她后悔的不是这句话不真，而是这句话被人看见了——前面那段说得清清楚楚，她写东西是“自己一个人偷偷地写”，藏进图书馆才安心，现在这四个字要被老师读到；她怕的是被笑话，一个留了级、在大厅里接受特殊教育的学生说自己是作家，在她自己听来都像个笑话，所以脸“像煮熟的大虾”；也可以谈到，她其实是脱口而出的，慌的时候人反而会写出心里最当真的那句话。教师追问一句：“你是从哪句话看出她是慌了才写的？”把答案摁回“我一下子就慌了，只好拿起笔”。

师：那么老师看了以后，给她的评语是什么？只有四个字——我相信你。（稍停顿）我们这本书的书名叫《特别的女生萨哈拉》。今天到这里，我们已经知道了三件事：她偷偷写东西，藏在图书馆 940 区；同学叫她“特别的萨哈拉”，那是嘲笑；她的日记本上写了“我是作家”，老师回了一句“我相信你”。

师：现在，请大家做今天这节课最要紧的一件事——预测。我要问的问题是：这个把自己写的东西藏在图书馆书架底层的女孩，往后会不会让别人读到她写的东西？如果会，你猜会是怎么让人读到的？如果不会，你也说说为什么。

师：请把预测写在这张单子上。有一条硬要求：依据栏里只能填今天读过的这三段里的话，不能填“我猜是个好结局”，也不能填“书名听起来像会成功”。

（学生填写预测阅读单）

| 我的预测 | 我的依据（今天读的哪一段、哪一句） | 读完全书后是否被证实 |
| --- | --- | --- |
|  |  |  |
|  |  |  |
|  |  |  |

学生互动分享

参考：预测本身不分对错，看的是依据站不站得住。倾向“会被人读到”的依据可能是：她把东西藏在公共图书馆而不是自己家的抽屉里，公共图书馆是谁都能进的地方，她嘴上说藏，心里其实盼着被人发现；她自己写着“将来总有一天，会有人发现那里”，这就是她的愿望；她已经在日记本上写下“我是作家”，虽然写完就后悔，但毕竟写了，而且老师回了“我相信你”。倾向“不会”的依据可能是：她连写四个字都要脸红半天，让全班读到几乎不可能；她说“我总是自己一个人偷偷地写”，“总是”这个词说明这是长期的习惯，不容易改。教师收口时逐个追问：“你是根据哪条线索猜的？”并说明这张单子要留到第 2 课时回收，一条一条验证——预测只猜不验，等于没用这个策略。

师：还有一个问题我先不回答，但请大家读的时候盯着它：她写的那本《我的痛苦人生和精彩历险》，到最后还在不在图书馆 940 区？

### 三、认识这本书·体例与几个容易叫岔的名字（10 分钟）

师：接下来我们花十分钟，把这本书的样子看清楚，后面读起来能省不少力气。

师：这本书正文一共十三章，前面另有一篇中文版前言。它没有分卷、也没有分部，从第一章一直排到第十三章，每一章都有标题。我念一遍，大家跟着目录看——第一章《我和德里》，第二章《真正的梦想》，第三章《图书馆女孩》，第四章《每天都有新鲜事》，第五章《新老师来了》，第六章《狮子的故事》，第七章《挨揍的乔治》，第八章《房子是怎样建起来的》，第九章《波迪小姐来家访》，第十章《孤儿》，第十一章《老师和苹果》，第十二章《名字的由来》，第十三章《我的自传》。

师：还有一件要紧的事：这本书讲故事的人，就是萨哈拉本人。整本书从头到尾是“我”在说——“我”看到、“我”想、“我”不敢说。所以你读到的每一件事，都是从她的眼睛里看出去的。这一点请记住，后面我们会用到。

师：另外，我们用的是电子版，它没有固定页码。所以这四节课，我们说位置一律说“第几章”，大家做标注的时候也请写章号。

师：这本书还有一个小麻烦：它里面的名字特别容易叫岔。我给大家发一张对照小条，上面是我们这几节课统一的叫法。请大家现在翻一翻书，在书里找到一个就打一个勾；如果你在书里看到某个名字，小条上没有，请写到背面。给三分钟。

师：先说一句，省得大家白找：小条上的波迪小姐和露兹，要往后面才出场——波迪小姐第五章才到班上，露兹要到第八章才有正面的事。今天找不到很正常，先在小条上留着，读到了再补打勾。

第二，那位新老师有好几个叫法：她的正式名字是波迪尔女士，她自己说也可以叫她帕萨伊小姐；学生一般叫她波迪小姐；德里起哄的时候叫她“破迪”。都是同一个人，不要当成好几位老师。

### 四、阅读方法·给这本书的两个读法（10 分钟）

师：这本书读起来会有两个坎，我先跟大家交个底。不过在我给办法之前，我想先问问大家自己的办法：你平时读书，遇到一段怎么也读不进去、读完了不知道在说什么的文字，你一般怎么办？

学生互动分享

参考：这一问是把“理解监控”显性化——先让学生说自己的办法，教师再补，而不是直接把方法灌下去。学生可能说：往回再读一遍；读慢一点，或者小声读出来；先跳过去往下读，看看后面能不能补上；把不认识的词圈出来；问同学、问家长。教师追问一句：“你上一次用这个办法，最后把它读懂了吗？”把方法落到有没有用上，而不是停在“我知道该回读”。

师：好，现在说这本书特有的两个坎。第一个坎在德里身上。德里·赛克斯是萨哈拉的同班同学，也是留级生。他写日记的时候错字连篇，几乎不用标点。（稍停顿）我先说清楚：这不是印错了，也不是翻译的问题，是作者故意这么写的——她要让你看见德里写字的样子。

师：所以读到德里的日记，你八成会卡住。卡住的时候请别跳过去，用这个办法试试：小声把它念出来，按声音去猜他想写的是哪个词。念出来往往就懂了。我们第 3 课时会专门拿他的一段日记来做这件事。

师：第二个坎是“故事里的故事”。波迪小姐这位老师上课爱讲故事——她讲过伊索的寓言，讲过乔治·华盛顿，第十一章还讲了一个很长的故事，是关于一位老师和一个苹果的。这个长故事是她自己编的，她在书里明说了是她编的。

师：这就容易混。（稍停顿）所以请大家读的时候多做一个动作：一看到有人开始讲故事，就在旁边记一笔——这是谁讲的故事，讲给谁听的。这样你就不会把故事里的人当成班上的人。

师：（稍停顿）这两个读法，一个对付读不懂的字，一个对付分不清的故事。大家读的时候试一试，后面几节课我会问你们用得怎么样。

## 第2课时 · 阅读交流课 1

### 本课三维教学目标

【知识技能】能说出全书按第一至四章、第五至十章、第十一至十三章分成的三段各自讲了什么；能准确复述家访、名字故事分享课、取回档案这几件事的实际经过；能说出书中反复出现的三样东西——档案、日记本、写给爸爸的信，各出现在哪几章。

【过程方法】重点显性训练整合策略：能把散落在十三章里的“写作”相关事件合并成一条先后相继的流程，看出萨哈拉不是忽然就敢当众朗读的；能在梳理中区分“她做了什么”和“这件事被谁看见了”，为后面理解主题作准备。

【情感价值】在把八个节点排成一条线之后，体会“被人看见”这件事对萨哈拉来说是一步一步、来之不易的，而不是一夜之间发生的转变。

### 一、回收预测单·她的东西，后来谁读到了（10 分钟）

师：亲爱的同学们大家好。上节课我们只读了三段，萨哈拉的书还藏在图书馆 940 区的书架底层。大家当时写了预测单，现在请拿出来，我们一条一条验证。

师：先说最要紧的那一条：后来有没有人读到她写的东西？

学生互动分享

参考：有。而且不止一次。第九章家访当晚，她重新动笔写下《我居住的地方》，主动把本子递给瑞秋看；第十二章的名字故事分享课上，波迪小姐点名，她走上讲台，当众读完了自己写的《我的名字》，全班给出反馈并欢呼。另外从第五章起，她的日记本一直是波迪小姐在读——只是那还不算她主动给人看。

师：那我想请几位同学说说：你上节课写的依据，读完之后回头看，站得住吗？有没有人猜对了结果，但依据其实猜错了？

学生互动分享

参考：这一问比“猜没猜对”更有价值。常见的是：有同学的依据是“书名就叫《特别的女生萨哈拉》，主角肯定成功”——结果对了，但这是从书外推的，不是从故事里推的；有同学的依据是“她把东西藏在公共图书馆，说明她心里盼着被发现”，这条依据在后文里真的兑现了，她最后确实是自己走上讲台读出来的；还有同学预测“会被人偶然翻出来”，结果并没有——书里没有人去 940 区把那个活页夹刨出来，是她自己开的口。教师收口：预测的价值不在猜中，在于依据能不能被后文接住。

师：我上节课留了一个不回答的问题：她那本《我的痛苦人生和精彩历险》，到最后还在不在图书馆？谁读到了？

学生互动分享

参考：书里没有写有人去 940 区把那个活页夹刨出来。第十三章写的是她重新拿出笔记本动笔，而且写的东西变了——她不再写“我的痛苦人生”，改写一位老师带着学生进行“神奇的冒险之旅”的故事。不过第十三章还有一处请大家留意：晚饭时她告诉妈妈自己在写自传，妈妈问能不能看，她说的是请妈妈去图书馆找——她把人指向了图书馆，而不是把本子递过去。至于那个活页夹后来到底怎么样了，书里再没有正面交代。教师提醒：书里没写的事，我们不替它补一个结局，这一点后面几节课都一样。

### 三、流程图·萨哈拉的“写”，一步一步走到了哪里（25 分钟）

师：刚才我们排的是“这一学年发生了什么”。现在换一件事做。我们只挑一条线出来看——萨哈拉“写东西”这件事。

## 第3课时 · 阅读交流课 2

### 本课三维教学目标

【知识技能】能复述“作家需要写作”这句批语出现的前因后果；能说出家访那一晚波迪小姐对妈妈讲的三句要紧的话——她讨厌档案、她只看萨哈拉本人、她将来能成为一名作家；能准确复述贴纸事件的经过——萨哈拉抠走了露兹本子上哪一枚贴纸、巴黎为此做了什么、这枚贴纸最后是怎么回到露兹手里的；能准确说出德里在书中的处境与他在第十一、十二章的变化，并知道书中对他的早年传闻是转述而非确定事实。

【过程方法】重点显性训练推断策略：能从人物的一句话、一个动作里，推断出书里没有直接写出来的心思，并指出自己凭的是哪一句；在读德里那段错字连篇的日记时，能主动用出声慢读的办法把它读懂，并说出自己用了什么办法。

【情感价值】体会这本书写老师的方式——她几乎没有说过一句鼓励式的漂亮话，她做的是把人当人看；理解“被看见”和“被评价”是两件不同的事。

### 一、细读·五个字的批语（15 分钟）

师：亲爱的同学们大家好。上节课我们排出了八步，其中第五步是往回退的一步——她连续四天一个字没写。今天我们就从这一步开始，看看当时到底发生了什么。这一段在第八章，我来读。

（教师朗读，定位：第八章）

> 本来我想写：那些只学了两年英语的女孩子为什么可以得到两千万张贴纸，而我却一个也没有？但我很快就猜到她会怎样回答我。有一次我连续四天都没写日记，她就用红笔在我的日记本上写：
>
> 作家需要写作。
>
> 为什么她就不能像其他老师那样，直接叫我“做作业”呢？为什么她不用对付德里那套来对我，把我叫到大厅里，说“你可以做得更好”，说“老师对你很失望”，或者说要叫我妈妈来，说要让我留级呢？她没有，她比那更严格。“作家需要写作”，就这么一句话，我感觉她好像在质问我：你不是说你是作家吗？那你怎么不写？看来你什么也不是嘛。

师：（稍停顿）请大家先注意萨哈拉自己的一句判断——她说“她比那更严格”。她比什么更严格？比“你可以做得更好”“老师对你很失望”“要叫你妈妈来”“要让你留级”这些话更严格。

师：这几句话，是我们平时听得最多的老师的话。可萨哈拉说，波迪小姐那五个字比这些都严格。我想请大家想一想：一句“作家需要写作”，为什么会比“要让你留级”还严格？

学生互动分享

参考：这一问要求学生推断，可以谈到的有：那几句常听的话，说的都是“你没做到别人的要求”，是别人在管她；而“作家需要写作”这句，用的是她自己说过的那个身份——她在第一篇日记上写“我是作家”，波迪小姐是拿她自己的话来问她，躲不掉；那几句话她可以不当回事，因为她本来就不认为自己是好学生，可这一句她没法不当回事，因为她心里最当真的就是这个；还可以谈到，别的老师是要她“做作业”，波迪小姐是要她“写作”——一个是任务，一个是她的梦想，梦想被人拿在手里，才会疼。教师追问一句：“你是凭哪一句推出来的？”把答案摁回“我感觉她好像在质问我：你不是说你是作家吗”。

师：再看这一段的最后一句。她替波迪小姐补出来的话是——“看来你什么也不是嘛”。（稍停顿）我要问：这句话是波迪小姐说的吗？

学生互动分享

参考：不是。波迪小姐在本子上只写了五个字“作家需要写作”，后面那一长串质问，是萨哈拉自己在心里替她补出来的。教师收口：这一处很要紧。全书是萨哈拉在讲自己的故事，所以我们读到的很多“别人的想法”，其实是她猜的。往后读的时候请留意，哪些是书里真的写了的，哪些是她自己补的。

师：那我再追一句：为什么她替老师补出来的，是这样一句很难听的话？

学生互动分享

参考：可以谈到的有：因为她自己心里就是这么想自己的——她被叫作“特别的萨哈拉”，被安排在大厅里，被留级，这些都在告诉她“你什么也不是”，所以她替别人补话的时候，补的也是这一句；也可以谈到，一个真正被这样对待久了的孩子，会先替别人把最坏的话说出来，这样别人真说出来的时候就不那么疼了。教师提醒：这是根据文本作出的推断，书里没有明写，说的时候要讲清凭的是哪一句。

学生互动分享

参考：几乎没有。她写过“我相信你！”，但那是写在日记本上的四个字，不是当面说的；她说“她将来能成为一名作家”，是在厨房对妈妈说的，并不知道萨哈拉在听；她当面说得最多的一次是“文字，你的天赋”，说完紧接着就是“出去玩吧”。教师收口：这本书写这位老师，用的几乎全是动作——发本子、调座位、写批语、上门、挡人、变出一枚贴纸、藏一个信封。她的话很少，而且常常不是说给当事人听的。

师：（稍停顿）我要从这八件里单挑一件出来追问。上节课有同学在问题清单上画了圈——萨哈拉明明知道拿别人的东西不对，为什么还是把那枚贴纸抠走了？我们现在把这件事说完整。谁来说说：这枚贴纸从露兹的本子上到了萨哈拉手里，后来又是怎么回到露兹手里的？

学生互动分享

参考：第八章日记本发错，萨哈拉拿到了露兹的本子，把上面一张金色的、后面拖着一条彩虹尾巴的星星贴纸抠下来据为己有；巴黎目击了，在日记里写下暗示，后来替萨哈拉背了嫌疑，事后与萨哈拉绝交。第十章波迪小姐单独留下萨哈拉，从袖子里摸出的正是这枚贴纸——她一直知道。萨哈拉随后把贴纸交给巴黎，巴黎跑去还给了露兹。至于她当初为什么要抠，第八章她自己写过一句心里话：“那些只学了两年英语的女孩子为什么可以得到两千万张贴纸，而我却一个也没有？”

师：好，那我要问的就是这一问：波迪小姐早就知道贴纸是她拿的。可她既没有当众说破，也没有罚她，只是把贴纸变出来还给了她。（稍停顿）为什么这样做，反而让萨哈拉自己去把贴纸还了回去？

学生互动分享

参考：可以谈到的有：如果当众说破，全班就都知道“特别的萨哈拉”还拿了别人的东西，那正好坐实了她档案里那些“表现不好的证据”，她只会更想躲起来；老师什么也不说，等于把这件事原样留给她自己处理，她就躲不过去了；也可以谈到，波迪小姐是把贴纸交回到她手上的——东西在谁手里，还不还就是谁说了算，这跟“没收”正好相反，而这本书开头，她的信正是被没收的；还可以谈到，第八章巴黎已经替她背了嫌疑、还跟她绝交了，她要还的其实不止一枚贴纸。教师提醒：说的时候要指出你凭的是哪一处。教师收口：这一问也把上节课那个画了圈的问题接住了——从头到尾，书里没有让任何一个大人来处置这件事。

### 三、读德里·从“我想有个月月友”读起（20 分钟）

师：这节课的最后一件事，我们读德里。导读课那天我说过，读到德里的日记你八成会卡住，现在就试一次。这一段在第十一章末尾，是德里写在日记本上、和波迪小姐笔谈的话。请大家看着这两行，先自己读一遍。

> 好吧，我承认，我是个瓜儿！我想有个月月友。

（学生自己读一遍）

师：读第一遍的时候，卡在哪儿了？举手告诉我。

学生互动分享

参考：多数学生会卡在“瓜儿”和“月月友”上。少数学生第一眼就看懂了，多半是因为读出声了。教师顺势追问：“看懂的同学，你是怎么弄懂的？”把办法从学生嘴里说出来。

师：那我们用导读课说的办法试一次——小声念出来，按声音去猜他想写的是哪个词。请大家现在念一遍。

（学生小声出声读）

学生互动分享

参考：念出来就容易了——“瓜儿”是“傻瓜”，“月月友”是“朋友”。教师收口这一步：这就是遇到读不懂的字时的一个具体办法，不是跳过去，也不是硬猜，而是换一种方式再读一遍。请大家记住自己刚才是怎么弄懂的，下次读别的书卡住时还能用。

师：（稍停顿）字认出来了，我们再看内容。德里在这两行里说了两件事：一件是承认自己是个傻瓜，一件是他想有个朋友。

师：这本书里的德里，前面是什么样子的？请大家说说你记得的。

学生互动分享

参考：他和萨哈拉一样是留级生，长期接受特殊教育；他在课上顶撞波迪小姐，叫她“破迪”，踢过讲台，波迪小姐当众把他的桌子踢翻过；他的母亲闯进教室，当着全班用日记本抽打他的头；特殊教育老师说他“得了冲动控制障碍”；他识字和拼写都困难。教师要补充一句提醒：书里第一章提到他一年级踢伤过老师的小腿，但紧接着写了一句“反正人们是这么说的，谁知道是真是假”——这是别人传的话，不是书里确定的事实，我们说的时候不能当成他真做过。

师：那么问题来了。这样一个在全班面前又踢又骂的男孩，写下的却是“我想有个朋友”。（稍停顿）作者为什么不把他的错字改对？如果这两行写成“好吧，我承认，我是个傻瓜！我想有个朋友”，有什么不一样？

学生互动分享

参考：这一问要求推断，可以谈到的有：改对了，你就只读到他说的意思，读不到他写字的样子——错字本身就在告诉你，他写这两行有多吃力；也可以谈到，正因为写得这么费劲还是写了，才看得出他有多想说这句话；还可以谈到，全班都以为他是个不好惹的坏学生，只有这个本子上的两行字露了底——而这个本子只有波迪小姐会看。教师提醒：说的时候要指出你凭的是哪一处。

师：德里后来变了吗？请大家翻到第十二章，找一找。

学生互动分享

参考：第十二章名字故事分享课上，萨哈拉读完之后，是德里说出了那句寓意“不要以貌取人”，波迪小姐当场叫了他的名字表扬他，他笑了，像老师一样咧着嘴；下课后在走廊上，他对萨哈拉说“我不是孤儿”，又说“而且，你也不是”。教师收口：请注意，书里并没有写他从此变成了好学生，也没有写他的功课好起来了——他做的是在课上说出了一句话，在走廊上对萨哈拉说了两句话。这本书对他的交代就到这里，我们不替他补一个更圆满的结局。

### 四、小结·布置思辨准备（5 分钟）

师：（总结）今天我们做了三件事：看那五个字的批语为什么比留级还重，把波迪小姐这一学年做的八件事排了一遍、顺带把贴纸那件事说清楚了，又用出声慢读的办法把德里的两行日记读懂了。

师：下一次课我们要讨论这本书里最值得讨论的一件事。它就是这本书从第一章反复写到第十三章的那样东西——档案。

师：请大家回去做三件事。第一，重读第一章、第九章、第十二章、第十三章这四章里所有提到档案的地方，一边读一边留意：书里的档案是谁写的、装了什么、放在哪儿。

师：第二，请你一边读一边想一个问题，下节课我们要正面讨论它：一位老师，该不该在开学前先看学生的档案？波迪小姐说她不看，她说“我只看萨哈拉本人”。你觉得她做得对吗？

师：第三，请你在书上把支持你这一边的地方标出来，至少标三处，写清第几章。下节课要用，没有依据的意见不能上场说。

师：（稍停顿）我提醒一句，这个问题不是一边对、一边错。等你标到第三处的时候，可能会发现另一边也有道理——那很正常，说明你读到了。

本课完。

## 第4课时 · 思辨&应用课

### 本课三维教学目标

【知识技能】能准确说出萨哈拉的档案里装着什么——她写的“老师也有秘密吗”那一页、妈妈请求停止特殊教育的信、以及全部写给爸爸的信；能说出她拿到档案后做了什么，以及全书结尾她改写的新故事是什么内容；知道全书没有交代爸爸的下落，结局不是“差生变优等生”那种逆袭。

【过程方法】重点显性训练转化策略，并把阅读能力推到五维中的评价鉴赏与转化运用两阶：能围绕一个没有标准答案的问题组织自己的立场，从指定章节里找出至少三条文本证据；能借助树形图按“谁在说”把书中关于萨哈拉的说法归类；能把书中的处境接到自己的一段具体经历上，写出一份“档案”与一页“自传”的对照。

【情感价值】理解“别人怎么记录我”和“我怎么讲述我自己”是两件不同的事；体会“名字是别人给我的，但同时也是我自己的选择”这句话，愿意为自己的判断讲出理由。

### 一、深度阅读发现·那个文件夹里装着什么（10 分钟）

师：亲爱的同学们大家好。上节课布置大家重读四章，把提到档案的地方都找出来。我们先把事情说准，因为等会儿要讨论，事实说错就白讨论了。

师：先问一头一尾两件：这份档案最早是怎么来的？到了第十二章，她又是怎么把它拿回去的？请一起说。

学生互动分享

参考：来历在第一章——萨哈拉写给爸爸的信从课桌里散落出来，被老师收走交给了教导主任史丁先生，妈妈在办公室里读到了这些信；史丁先生把这些信塞进了装着萨哈拉档案的大文件柜。她自己形容那个柜子：“那个文件柜里装满了我所有表现不好的证据，它一直在那儿候着，准备随时听命，打开柜门来证明我是个大笨蛋。”拿回去在第十二章——波迪小姐给了她一个写着“萨哈拉收”的信封，她按纸条的指引走到一只旧储物柜前；柜子里有一盆小小的仙人掌，上面开着一朵漂亮的小红花，在它后面，有一个棕色的文件夹，上面写着她的名字，那就是她的档案。

师：好，那么最要紧的一件来了：她回家拆开档案，里面到底装着什么？

学生互动分享

参考：第十三章写明了三样：她自己写的“老师也有秘密吗”那一页；妈妈写的、请求停止特殊教育的信；还有全部写给爸爸的信。她把这些信一封封从窗口放飞了。教师顺势指出：请注意这三样东西的性质——第一样是她写的，第二样是妈妈写的，第三样也是她写的。她档案里装的，大半是她自己和妈妈写下的东西，可这个柜子却被她说成“装满了我所有表现不好的证据”。

师：（稍停顿）这就有意思了。同样是这些纸，放在她自己手里，是写给爸爸的信；锁进那个文件柜，就成了“证明我是个大笨蛋”的证据。（稍停顿）今天这节课，我们就从这里开始讨论。

### 二、思辨讨论·一位老师，该不该在开学前先看学生的档案（20 分钟）

师：上节课我留的那个问题，现在正式讨论。波迪小姐说：“我讨厌所谓的档案。我总是到了期末才看学生的档案。”她还说：“我只看萨哈拉本人。”

师：我先说清楚这个问题为什么值得讨论，它不是一边对、一边错。（稍停顿）不看档案，好处是明摆着的：萨哈拉的档案里写着留级、特殊教育、表现不好，波迪小姐要是先看了，很可能一开学就把她当成一个“需要特别帮助”的笨学生，那句“她将来能成为一名作家”就说不出来了。可是不看档案，代价也是明摆着的：班上还有一个德里。德里识字和拼写都很困难，特殊教育老师说他得了冲动控制障碍，他的家里还有那样一位母亲——这些事如果老师一开始就知道，也许能早一点帮上他。

师：所以两边都要付代价。请大家填这张单子，把自己的判断和依据写下来。硬要求还是那一条：每一条理由后面必须有一处书里的依据，写清第几章。没有依据的理由不能上场说。

| 我的判断（该看 / 不该看） | 我的理由 | 书中依据（第几章·哪件事或哪句话） |
| --- | --- | --- |
|  |  |  |
|  |  |  |
|  |  |  |
| 我认为对方最有道理的一条是 |  |  |

（学生填写，教师巡视，重点检查依据栏有没有空着，提醒不要只写“我觉得”）

学生互动分享

参考：请正反两边轮着说，一次说一条理由加一条依据。双方可能用到的如下，教师心里有数即可，不要提前抛给学生——

主张“不该看”的可用：第九章波迪小姐自己给的理由——“如果有人老是对你说长道短，评头论足，你就会明白”，她是把学生当成一个会被议论伤到的人；同一章她还说“要是档案都是错的，那并不能节约时间”，而萨哈拉的档案确实是偏的，里面装的是被没收的私人信件，不是她的能力；正因为她没看，她才会在家访时说出“我只看萨哈拉本人”“她将来能成为一名作家”；第五章她在只写了四个字的日记本上回批“我相信你！”——一个看过档案的老师，未必写得出这四个字。

主张“该看”的可用：第十章特殊教育老师来带走德里时，用的正是“您没看他的档案吗”这句话，说明档案里确实记着德里的情况；德里的识字与拼写困难是真实存在的，第十一章末他那两行日记错字连篇，早知道也许能早一点给他帮助；第七章德里的母亲闯进教室、当众用日记本抽打他的头，这类家里的情况，老师提前知道会更有准备；另外波迪小姐自己也没有完全不看——她说的是“我总是到了期末才看”，可见她并不认为档案毫无用处，只是把看的时间往后挪。

师：（在双方各说过两轮之后）我插一个问题，两边都要答。波迪小姐说的是“我总是到了期末才看学生的档案”——她不是不看，是晚看。（稍停顿）为什么是期末？把看档案的时间从开学挪到期末，到底挪掉了什么？

学生互动分享

参考：这一问是本环节最要紧的一问。可以谈到的有：挪掉的是“先入为主”——开学看，档案会变成她认识这个学生的起点，她后面看到的一切都会往上面靠；期末看，她已经用一学年的时间自己看清了这个孩子，档案就只是一份参考，甚至能看出档案哪里写错了。也可以谈到：她说“如果一个孩子不老实、反应慢、不读书，时间会告诉我的”，她信的是时间，不是纸。教师收口：这一问答完，两边其实就说清了各自建立在什么上——一边是“别让纸先替我下结论”，一边是“有些困难早知道才帮得上”。

师：（总结）这个问题我不判谁赢，因为它本来就没有标准答案。我只请每位同学在单子背面写一句话：如果你明年当了老师，你会在什么时候看学生的档案，为什么。

### 三、树形图·关于萨哈拉，都有谁说过话（10 分钟）

师：刚才我们讨论的是档案。可关于萨哈拉这个人，说过话的不只有档案。今天我们用一个新工具，把这些说法归一归类。

师：这个工具叫树形图。它的样子是自上而下分层的：最上面是一个总的题目，往下分出几根大枝，每根大枝是一类；每根大枝底下再挂具体的内容。它和我们上节课用的流程图不一样——流程图是排先后，树形图是分类别。

师：我们今天这棵树，最上面写的是“关于萨哈拉，都有谁说过话”。往下的大枝，就按“说话的人是谁”来分，一共五根：学校的档案、同学、妈妈、波迪小姐、萨哈拉自己。

师：头两根枝我已经替大家填好了——这两根我们前面几节课反复读过，不用再翻。剩下三根是空的，请你填上这个人说过的具体的话或做过的判断，注明第几章。三根枝，每根填两到三条就够。

| 妈妈 |  |
| 波迪小姐 |  |

（学生填写，教师巡视）

学生互动分享

参考：请几位同学念自己填的，教师口头把大家说的归拢，请学生把漏掉的补进自己的单子。空着的三根枝可填——

妈妈：第一章，妈妈到学校要求停止特殊教育，宁可让她留级；同一章妈妈在办公室外说“长点脑子，好吗？做好自己的事吧，证明给他们看是他们错了”；第四章，妈妈一边削土豆一边说“你读那么多书有什么用？还不是留级”，也说“你明明这么聪明”。

波迪小姐：第五章，在只写了四个字的日记本上回批“我相信你！”；第八章，用红笔写下“作家需要写作”；第九章，对妈妈说“我只看萨哈拉本人”“她将来能成为一名作家”，还说“我从不让任何一个孩子留级”；第十章，戴上那副眼镜看过之后说“文字，你的天赋”。

萨哈拉自己：第二章，对瑞秋说“我要成为一名作家”；第五章，日记上写“我是作家”；第十一章，在门口对波迪小姐说“我觉得每个人心中都还有一个秘密的自己”；第十三章，对妈妈说“我的自传。因为我的生活非常有趣”。

师：现在请大家看着这五根枝，回答我一个问题：这五个人说的，是同一个萨哈拉吗？

学生互动分享

参考：不是。档案那一栏几乎全是“表现不好的证据”；同学那一栏是嘲笑，只有德里最后那一句是例外；妈妈那一栏是拧着的——她既说“你读那么多书有什么用”，又说“你明明这么聪明”，还为了她去学校要求停止特殊教育；波迪小姐那一栏说的全是“将来”“天赋”“我相信你”；萨哈拉自己那一栏，从第二章到第十三章，说的其实一直是同一句话——我是写东西的人。教师收口：同一个孩子，五根枝上写着五个不一样的她。

师：那我要追一句：这五根枝里，哪一根最后作数了？

学生互动分享

参考：可以谈到的有：最后作数的是她自己那一根——第十二章她当众读完《我的名字》，第十三章她告诉妈妈自己在写自传，这都是她自己说的那句话变成了真的。也可以谈到：波迪小姐那一根很重要，但她做的事情，与其说是给了萨哈拉一个新说法，不如说是让萨哈拉自己那根枝长了出来——她说的是“我相信你”，不是“我认为你应该”。教师收口：请注意第十二章萨哈拉自己的那句话——“名字是别人给我的，但同时也是我自己的选择。而这些选择，让我变得与众不同。”她没有说那个外号是错的，她说的是她把它拿过来了。

### 四、阅读成果·我的档案，和我的自传第一页（15 分钟）

师：这本书的结尾，萨哈拉做了两件事。第一件，她拆开自己的档案，把里面写给爸爸的信一封封从窗口放走了。第二件，她拿出笔记本重新动笔。这一段我读给大家听。

（教师朗读，定位：第十三章）

> 然后，我拿出笔记本，写啊写，写啊写。我不再写“我的痛苦人生”，我写的是一位老师带领她的学生们，进行了一场“神奇的冒险之旅”。我写她的故事，她的秘密。我写我的朋友，写那些爱打小报告的人，写勇敢的人，写懦弱的人。第一次，我明白了故事不一定要完全真实，它应该是所有我希望能够成真的、有趣的事情。我唰唰地写着，文字像车轮一样驶过本子。

师：（稍停顿）请注意这一整本书里最要紧的一个对照：一边是档案——别人写的、锁在柜子里的、记着你“表现不好”的那些纸；一边是自传——你自己写的、你说了算的那些纸。萨哈拉这一学年，就是从第一边走到了第二边。

师：现在请大家也写这两样东西，写在一张纸的左右两边。左边一栏，请你想一想：如果学校的柜子里有一份关于你的档案，上面可能记着什么？只能写别人看得见、能记下来的事——比如某次考试、某次被叫到办公室、某次值日、某个评语。右边一栏，请你写你的自传第一页：写档案里记不到的那个你。五六句就行，不用写成一篇完整的文章。

| 如果有一份关于我的档案，上面可能记着 | 我的自传第一页，我要写 |
| --- | --- |
|  |  |

（学生写作，约六分钟；教师巡视，只看不评，也不要求学生把两栏都写满）

学生互动分享

参考：请四五位愿意分享的同学读一读，不勉强人人上台，只想读右边一栏也可以。学生左边常写：某次考试的分数、某次上课说话被记名、某次作业没交、某个“很内向”“不爱发言”一类的评语。右边常写：自己在家里养的东西、自己偷偷练了很久的一件事、自己心里想当的那种人、一件只有一两个人知道的事。教师接住之后回扣文本：注意萨哈拉的那两样纸里，写着的其实是同样几件事——同一件事，被别人记下来叫“表现不好的证据”，被自己写出来就成了故事。教师不作抒情性的升华，也不要求学生的自传写得“积极向上”。

师：我再问一句，问的是心里的事，不必回答，只请你自己想一想：有没有一个说法，被别人安在你身上，而你心里知道自己不是那样？（稍停顿）萨哈拉的那个说法是“特别的萨哈拉”。她没有去争辩，她做的是——把自己写的东西读出来。

### 五、全课总结（5 分钟）

师：（总结）这四节课，我们从图书馆 940 区书架底层的一个活页夹开始，把十三章排成了三段，把她“写东西”这条线排成了八步，看了五个字的批语、一场家访、两行错字连篇的日记，讨论了一位老师该不该先看学生的档案，最后各自写了一页自己的自传。

师：这本书的开头，萨哈拉说她假装没听到同学的嘲讽，可她的双颊、双眼、指甲都听到了。它的结尾，是她站在全班面前把自己写的东西读完，然后回家把档案拆开，重新动笔。（稍停顿）中间隔了十三章，也隔了一整个学年。

师：这本书没有给她一个特别圆满的结局。爸爸没有回来，书里从头到尾也没有说他去了哪儿；德里也没有变成一个好学生，他只是在课上说了一句话，在走廊上对萨哈拉说了两句话。（稍停顿）作者留下的，是萨哈拉重新拿起了笔。

师：最后我把第十二章里她自己写的那句话读给大家，作为这四节课的收尾。

（教师朗读，定位：第十二章）

> 名字是别人给我的，但同时也是我自己的选择。而这些选择，让我变得与众不同。

全课完。
