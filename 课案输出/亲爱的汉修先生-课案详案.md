### 一、文本介绍

【内容简介】

《亲爱的汉修先生》是美国作家贝芙莉·克莱瑞的儿童成长小说，1984 年获纽伯瑞儿童文学奖金奖。它的样子很特别——整本书就是一个叫鲍雷伊的男孩写下的信和日记：从二年级起给崇拜的作家汉修先生写信，被作家反问、又被妈妈督促，就此一笔一笔写起了自己。透过这些信和日记，我们看见一个父母离婚、转学后没朋友、午餐总被偷的男孩，怎样在孤独里慢慢长大，最后被一位真正的作家称作“作家”。

写给汉修的“真信”要署名、会寄出，写给“假汉修先生”的日记不署名、不寄出，署名还随他的心情与成长而变——这是本书的写法看点，也是要提醒孩子重点留意的地方。

【作者介绍】

贝芙莉·克莱瑞，1916 年出生于美国俄勒冈州，是美国二十世纪最著名的儿童文学作家之一。她的母亲是个爱书人，曾做过小学教师，后来自己开设了一家图书馆，克莱瑞可以说是在书籍的陪伴下长大的；后来她对文学产生了浓厚兴趣，逐步走向创作上的成功。2003年获得美国国会颁发的美国国家荣誉艺术奖章。她的书为她赢得了许多著名的奖项，其中《亲爱的汉修先生》获得了纽伯瑞儿童文学奖金奖及美国文学最杰出贡献奖；“永远的雷梦拉”系列中的三部作品分别获得纽伯瑞儿童文学奖银奖和美国国家图书奖，还曾被改编为电视剧和电影，深受孩子们的喜爱。

### 二、教学目标

【知识技能】了解《亲爱的汉修先生》是一部由书信和日记组成的儿童成长小说；能理清全书主要发生在鲍雷伊六年级这一年的时间线，说清他从二年级到六年级、从崇拜作家到被真作家称为“作家”的成长脉络；认识书信体与日记体两种文体形式，进而读懂本书“信与日记双线并写”的妙处——最疼的心里话藏在只给自己看的日记里，写给汉修的信则收着分寸，两条线合起来、没有旁白却更贴人心；能从鲍雷伊的信和日记里提取家庭、学校、烦恼等关键信息，理清他身边的人物关系。

【过程方法】综合运用预测、提问、联结、筛选重要信息、推断、比较、转化等阅读策略；借助预测阅读单、人物关系图、对比图、成长阶梯图、思辨阅读单等可视化工具，对这部书信体小说做梳理、对照、细读与思辨；练习从鲍雷伊写下的字句里推断他没有直说的心情，任何判断都回到信和日记里找依据。

【情感价值】在鲍雷伊的孤独与成长里，体会一个普通孩子怎样面对父母离婚、转学、被冷落这些真实的难处，仍一点点找到自己；懂得“写自己真实的经历、做真实的自己”这件事的分量；在结尾父子告别处，感受体谅与成全，学着不急于替书里的人下结论。

### 三、教学流程

## 第 1 课时 · 导读课

**本节三维目标**

【知识技能】知道《亲爱的汉修先生》是一本由一个男孩写的信和日记组成的书，认识它书信体＋日记体交替的样子，能分辨“写给作家的信”（有抬头署名、要寄出）与“写给‘假’汉修先生的日记”（不署名、不寄出）的不同；能从他的信和日记里，提取出鲍雷伊是个怎样的男孩、他想做什么。

【过程方法】重点显性训练预测与提问两项策略——从一封信里的线索预测故事会怎么发展，再记下自己最想问的问题，建立“读前预设—读中验证”的回路。

【情感价值】对这个想当作家、却被作家反将一军的普通男孩生出好奇——一个自称“全班最中等”的孩子，最后真能被人叫作“作家”吗？愿意花一周走进这本书，读完这些信和日记，去解开课上留下的悬念。

### 一、导入·一个男孩的“作家梦”（15 分钟）

师：亲爱的同学们大家好。今天先不急着讲书，老师想先跟大家聊一件生活里的事——

师：假如你心里有个特别崇拜、特别喜欢的人：一位大作家，一个天天追的主播，一个大明星。（稍停顿）你鼓起勇气给他发了条消息、写了封信，问了他一个你憋了好久的问题。结果呢——他不但没回答你的问题，反倒“啪”地甩给你十个问题，要你先一个一个回答他！你说，这时候你是什么滋味？

学生自由分享

师：（听几位后·接住“气/懵/没想到”这类反应）有人说会气，有人说会懵——本来是我求你，怎么反过来考起我来了？（稍停顿）老师手上这本书里，就有一个跟你们差不多大的男孩，真真切切碰上了这么一档子事。他叫鲍雷伊，特别崇拜一位作家，叫汉修先生，从二年级起就开始给他写信。到了六年级，他为了写一份“作家专题报告”，一口气问了汉修先生十个问题。我念几个，你听听他最关心的是什么：

师：（朗读·节自第一章·九月二十日的信）

> 1.您写过几本书？
> 2.汉修是您的本名还是笔名？
> 3.您为什么要写给儿童看的书？
> 4.您的灵感从哪里来？
> 5.您有没有小孩？
> 6.您最喜欢您写的哪一本书？
> 7.您喜欢写书吗？
> 8.您下一本书的书名是什么？
> 9.您最喜欢什么动物？
> 10.请您告诉我写书的秘诀，对我来说这件事真的很重要，我真的很想知道，因为这样我才能成为很有名的作家，才能写出跟您的书一样好的书。

师：（追问·让学生从十个问题里读出这男孩的心事）前面几个还是随便问问，可到了第十个，他把真心话说出来了。你听出来了吗——这十个问题里，藏着他一个什么样的心愿？

学生互动分享

参考：他想当作家，想写出跟偶像一样好的书，所以特地来讨一个“写书的秘诀”。

师：（抛悬念·为预测热身）好，那你再猜猜：这位大作家，会怎么回他？会不会痛痛快快把“秘诀”告诉他？

学生互动分享

师：（揭示反转·呼应开头）结果呀——就跟老师开头说的那件事一模一样！汉修先生不但没给他什么秘诀，反倒反过来甩给鲍雷伊十个问题，要他先回答！（稍停顿）鲍雷伊当时也跟你们刚才说的一样，气坏了。可偏偏就是这十个问题——加上妈妈在旁边一直催着他回答——逼着他一笔一笔，慢慢开始写起了真实的自己。一个普通男孩，最后真的被一位作家当面叫作了“作家”。他是怎么做到的？我们这四节课，就来读读雷伊六年级时候发生的故事。

### 二、先睹为快·当堂精读一则日记、一封信（30 分钟）

师：（点书名＋这本书最特别的地方）这本书，就叫——《亲爱的汉修先生》。它有一个地方特别不一样：从头到尾，没有一句是作者在旁边讲故事，全都是鲍雷伊自己亲手写的信和日记。下面老师带大家先睹为快，读两段他真正写下的东西——一则日记、一封信，既看看这个男孩，也看看这本书长什么样。

师：（先理时间线·帮孩子建立框架）不过在读之前，老师先花一分钟，帮你把这本书的时间捋一捋——不然容易看糊涂。这本书说的，其实主要就是发生在鲍雷伊六年级上学期到次年春季（次年 3 月）这大半个学年的事情；

| 什么时候        | 发生了什么                                                                |
| ----------- | -------------------------------------------------------------------- |
| 二年级～五年级     | 鲍雷伊零零星星写过几封信，崇拜大作家汉修先生                                               |
| 六年级·刚开学     | 为了交一份“作家专题报告”，写信一口气问了汉修十个问题                                          |
| 六年级·秋冬到次年3月 | 汉修不给答案，反问他十个问题，还建议他写日记；他就开始写“假汉修先生”的日记。打这儿起一直到书末，全是他6年级大半个学年里写下的信和日记 |

师：（点一句·让框架落住）所以你读的时候记住：前头几封是他二年级到五年级的，翻过头几页，往后就都是六年级的事了——这大半年里，一封信一则日记地写下来。

师：（引入第一段·日记）好，先读一则他的日记，是他写的头一则。你一边听，一边琢磨两件事：第一，从哪儿看得出这是“日记”、不是信？第二，他这则日记，是为一件什么烦心事写的？

师：（朗读·第二章·十二月二十二日星期五的首则日记，节读）

> 十二月二十二日星期五
> 
> 亲爱的“假”汉修先生：
> 这是日记。我会好好儿保存它，不会把它寄出去。
> 如果我在上学途中就把午餐吃掉，到了下午就会很饿。所以今天早上我没有那么做，结果午餐的时候，我发现妈妈帮我装进袋子里的两个炸香菇丸不见了。……整个上午我都在注意，谁离开过座位到教室后面大家放午餐的地方去过……
> 对了！我想到一个办法。有些作家会用笔名。圣诞节过后，我可以在我的午餐袋上写个假名字。这样就可以瞒天过海，就像许多书上说的。
> 我想我不必在日记的最后签名了吧。我会在真正要寄出去的信上签名。P31-32

师：（问一组·认识“日记”文体）第一个问题：从哪儿看出这是日记、不是写给别人的信？

学生互动分享

参考：他自己就说了——“这是日记，不会把它寄出去”；开头称呼是“亲爱的‘假’汉修先生”，是他假想的一个收信人；末尾也没有签名，他还专门说“日记不必签名，只有要寄出去的信才签名”。所以：日记不寄出、写给自己、不署名。

师：（追问·情节钩子）第二个问题：他这则日记，在为一件什么事发愁？

学生互动分享

参考：他的午餐被偷了——两个炸香菇丸不见了；他正琢磨着，圣诞节过后在午餐袋上写个假名字来骗小偷。

师：（收口·先示范再放手·落地提问策略）读到这儿，你心里是不是也冒出了一些问题？老师先带个头——就刚才这则日记，老师自己就有好几个特别想知道答案的问题，我们把这些问题整理到“问题墙”上，你们看：

| 老师想问的问题                  | 为什么想问                             |
| ------------------------ | --------------------------------- |
| 鲍雷伊能见到汉修先生本人吗？           | 他从二年级就给汉修先生写信、这么崇拜他，真想知道他们能不能见上一面 |
| 那个“亲爱的‘假’汉修先生”，到底是谁呀？    | 明明是写给自己的日记，怎么开头还称呼一个“假”的人         |
| 鲍雷伊想出写假名字防偷午餐，这个办法最后有用吗？ | 日记里只说了这个想法，很好奇这方法到底能不能拦住偷午餐的人     |

师：（把话头交给学生）看，提问就是这么提——把你最好奇、最想知道答案的地方写下来。现在轮到你了：想问鲍雷伊的、想问作者的、想问故事怎么发展的，都行，写在你自己的便签上。（请两三位说说自己写的）——写好了，也贴到问题墙上，跟老师的种子问题挂在一块儿。

师：（点明约定·为下节课埋线）这些问题先挂在那儿，别急着要答案——答案全藏在这本书里。等你这一周读完，下节课我们就把墙上的问题一张张取下来对：看看哪些你自己读着读着就解开了。所以读的时候，心里可以随时惦记着墙上这几个问题。

师：（引入第二段·信，与日记对照）刚才那是日记。再读一封他寄出去的“真信”，对着看，特别有意思。这封信，是全书的第一封——鲍雷伊二年级的时候写给汉修先生的。请一位同学来读，其他同学听：它跟刚才那则日记，开头和落款有什么不一样？

师：（邀请一位同学朗读·第一章·五月十二日的第一封信）

> 亲爱的汉修先生：
> 我们老师给我们读了您写的狗的故事，很有趣。我们都很喜欢这本书。
> 您的明友鲍雷伊（男孩）敬上
> 五月十二日 P1

师：（问一组·对照文体）跟刚才那则日记比，这封信的开头和落款，哪儿不一样？

学生互动分享

参考：开头称呼是“亲爱的汉修先生”（真人，不是“假”的）；末尾签了名——“您的明友鲍雷伊”，还落了日期。对照起来就清楚了：日记不署名、不寄出，信要署名、是要寄给作家的。

师：（点一个好玩的细节·“明友”）这封信里还藏着个好玩的地方——他把“朋友”的“朋”，写成了“明白”的“明”。（稍停顿）这不是印错，是书里特意留着没改的：一个二年级的小孩，给自己崇拜的作家写信，会写错别字，特别真、特别可爱。

师：（点署名会变·埋署名线，不作情绪推断）还有一处请你记住：这封信的落款，是“您的明友鲍雷伊”。你往后读会发现——他高兴、生气、和好，署名回回都不一样。这条“署名的变化”，是这本书特别好玩的一条线，我们后面几节课会专门来看。

师：（小结）你看，就读这一记一信，我们已经摸到这本书的门道了：他的**日记**写给自己、不寄、不签名；他的**信**寄给别人、要署名——而且这署名，还会随着他的心情变。（稍停顿）至于他日记开头那个“亲爱的‘假’汉修先生”到底是怎么回事，这个谜留着你自己思考，下节课我们专门来讲解。

### 三、预测阅读单·猜猜他6年级这段时间发生的事（10 分钟）

师：（引子·读一句“最中等”）刚才我们读了他的一则日记和一封信。其实他被逼着回答那十个问题的时候，还老老实实写下过这样一句话——

师：（朗读·节自第一章·十一月二十日的信）

> 我只是个很普通的男生。……我想您可以说我是全班最中等的人。P12结尾部分

师：（抛预测·三个具体的悬念）一个连自己都觉得“最中等”、成绩不拔尖、朋友也不多的普通男孩，接下来这段时间，会怎么样呢？老师这儿有三件事，特别想请你先猜一猜——都是这本书里悬着的悬念：

师：（发预测阅读单，讲清怎么填）这是一张“预测阅读单”。先自己猜一猜，再简单说一句“你为什么这么猜”就行——不用长，一句话；第三列先空着，等你读完这本书再回来填，看你猜得对不对。

预测阅读单（每人一张，填在自己的单子上）：

| 我的猜测                        | 我为什么这么猜 | 读完后：对不对 / 不一样在哪 |
| --------------------------- | ------- | --------------- |
| 鲍雷伊的午餐老被偷，你猜他最后抓到小偷了吗？      |         |                 |
| 走丢的“土匪”（那只狗），你猜它还能回到鲍雷伊身边吗？ |         |                 |
| 鲍雷伊想当作家，你猜他最后成功了吗？          |         |                 |

师：先自己写前两列，第三列空着，读完这本书再来填。写好了，我请几位同学说说你猜的是什么、为什么这么猜。

学生互动分享

参考（不给标准答案，重在“说得出为什么”）：比如午餐这条，有的同学猜“能抓到，他那么聪明肯定有办法”，有的猜“抓不到，小偷太狡猾”；土匪那条，有的猜“回得来，狗都认得回家的路”，有的猜“回不来，雪那么大”。怎么猜都行——关键是你说得出“我为什么这么猜”。

师：（收口追问·预测策略的关键一步）老师追问一句：你是看到书里哪句话、哪件事，才这么猜的？（请一两位同学说说）记住，预测最要紧的不是猜得准，是留一个“回头验证”的钩子——所以第三列一定要等你读完了回来填。到下节课，我们还会把这张单子拿出来，一条一条对。

### 四、读法小结·布置七天阅读计划（5 分钟）

师：读这本书，老师送大家两句话。第一，盯住每封信的署名——刚才那封信的落款是“您的明友鲍雷伊”，你往后读会发现，他高兴、生气、和好，署名回回不一样，这里头藏着他的心情——署名一变，多半是他这个人也在跟着变；所以每读到一个特别的落款，就把它抄到便签上。第二，随手记问题——就像刚才那样，一冒出疑问，就写在便签上，回头贴到我们的“问题墙”；读完这本书，问题墙上的便签越多，说明大家读得越用心，下节课我们一起解起来也越热闹。

师：（布置阅读计划）好，接下来一周，请大家把这本书读完。全书八章不算厚，我们排一张阅读计划，跟着走就不慌。

## 第 3 课时 · 阅读交流课2

**本节三维目标**

【知识技能】能细读书中一则日记与一封信，读出鲍雷伊把最疼、最难开口的心里话写进了“日记”、写给汉修的“信”却收着些；能用对比图，从“说什么事、什么口气、把什么藏起来又把什么倒出来”几个方面，比出“信”与“日记”这两副笔墨的不同；初步体会这本书用信和日记双线来写、没有旁白却更贴人心的好处。

### 四、作品写法·两条线一起写，好在哪（10 分钟）

师：我们退一步想个大问题：克莱瑞写这个故事，为什么不像别的书那样，找个人在旁边替鲍雷伊讲“他怎样怎样、他很难过”，偏偏要用鲍雷伊自己的信和日记，一封一则地写？这样写，好在哪？先别急，想一想，说说看。

学生互动分享

参考（不必统一，鼓励多说）：用鲍雷伊自己的信和日记来写，我们就像直接读到了他心里的话——他生气、他难过、他偷偷的高兴，都是他亲口“写”给我们看的，特别真、特别近。而且信是一条线、日记是另一条线，两条线一起读下去，我们既看见他对外说的、又看见他心里想的，比别人来讲他，看得更全、更贴。

师：（追问一·让好处落到一处具体对比上）说得挺好，可别停在“觉得真”。我举个例子你就懂了：鲍雷伊被妈妈逼着回答汉修那十个问题时，气冲冲写过一封信，落款直接签的是“讨厌您的鲍雷伊”，末尾还赌气搬出爸爸“叫您干脆去撞树算了”。（稍停顿）假如换个写法，改成别人在旁边淡淡讲一句“鲍雷伊那天很生气”——哪一种，让你更能撞上他正在气头上的样子？为什么？

学生互动分享

参考：读他自己写的更能感到。别人说一句“他很生气”，那只是个结论、干巴巴的；可鲍雷伊亲手把赌气的话写下来、又把气撒进落款“讨厌您的鲍雷伊”，我们是隔着这封信，直接撞上了他正在气头上的样子。他不是被别人转述的，是自己开口说给我们听的。

师：（追问二·把两条线合起来·收口到双线叙事）好，现在把这节课的发现合起来看：一边，是他写给汉修的“信”——收着的、报喜的、有分寸的；另一边，是他只给自己看的“日记”——把“也许全是我的错”这种最疼的话都倒出来的。这本书从头到尾没有一个旁人来讲他，可我们为什么反而觉得，比谁来讲都更懂他、更心疼他？

学生互动分享

参考（说到方向即可）：因为这两条线一起，等于让我们同时听见了鲍雷伊“嘴上说的”和“心里想的”——信里他对外是这副样子，日记里他对自己是那副样子。要是换成一个旁人来讲，我们顶多听他说“这孩子很难过”；可现在，是鲍雷伊自己，把面上的和心里的、明的和暗的，一封一则全摊在我们眼前。所以没有旁白，反而更贴他的心。

师：（总结·点到为止）这就是这本书最巧的地方——它不是别人在讲鲍雷伊的故事，是鲍雷伊自己，用一条“信”的线、一条“日记”的线，把这一年最外头和最里头的自己，一起写给了我们看。

### 五、小结·布置思辨准备（5 分钟）

师：（总结）今天我们做了三件事：细读了一则日记和一封信，练了从字句里“推断”他没直说的心情；用对比图，把“信”和“日记”这两副笔墨比清楚了——最疼的话，他都藏在只给自己看的日记里；还一起想通了，这本书用信和日记两条线一起写、没有旁白，为什么反而更让我们心疼他、懂他。

师：（布置任务·跨周接缝，可留“想”的作业）下一节是这本书的最后一节，思辨&应用课。这几天请你做一件事——不用重读，只要把你便签上抄下的那些署名，按先后顺序在一张纸上抄成小小的一列：从二年级的“您的明友”，一直排到最后的“您的朋友、作家鲍雷伊”。抄的时候边看边想：这条“署名的变化”，是不是也在讲他怎么长大的？把这张抄好的署名单带来，我们下节课就用它接着聊。

## 第 4 课时 · 思辨&应用课

**本节三维目标**

【知识技能】能借成长阶梯图，把鲍雷伊这一年的八个成长转折点（想得到秘诀→被迫回答十问→开始写日记→午餐被偷→爸爸电话→放弃虚构故事→写出《卡车上的一天》→成为“作家”）排成一级级台阶，说清他“从崇拜作家到自称作家”是怎么一步步走过来的；能就书中几处没有标准答案的难题，说出自己的判断，并从信和日记里找出依据。

【过程方法】重点显性训练联结与转化两项策略——把书里的处境联结到自己的生活和感受，再把读到的东西转化成一封写给鲍雷伊的回信；练习“观点—证据”的实证读法，判断都回文本找依据。

【情感价值】在几道思辨题里，练习不急着下结论、先听证据再说话；在给鲍雷伊写回信中，把这一年的陪伴与体会，郑重地还给这个男孩。

- 第一道（汉修是不是好老师）：说他是好老师，有据——他没有把“秘诀”直接喂给鲍雷伊，反倒甩回十个问题，逼着鲍雷伊头一回好好想想自己、写下自己；他建议鲍雷伊写日记，这一写就写出了本事，到最后一封信鲍雷伊还专门说“当初您建议我写日记，我到现在还在写”；他后来点破一句“一个主角在故事里应该解决一个难题”，鲍雷伊靠这句才明白该怎么写。可也有人不服气——他一个字秘诀都不肯给，把鲍雷伊气到写“讨厌您的”那封信；从头到尾没露过面、回信又短；真正当面夸鲍雷伊、鼓励他的，其实是另一位作家贝乔，不是汉修。哪种都行——关键是你指得回书里第几章、哪件事。
- 第二道（汉修教会的，还是他自己长的）：说是汉修教的，有据——写日记是汉修建议的，“主角要解决难题”是汉修点破的，连“先别写虚构、去写真实的”也是被汉修一步步逼出来的。说是鲍雷伊自己长的，也有据——蝴蝶树林那一幕，是他自己一个人撞见、自己心里冒出“想把它写下来”的；放弃虚构、改写《卡车上的一天》是他自己拿的主意；贝乔夸的那句“你写得像你自己，你没有想要模仿别人”，夸的正是他自己身上长出来的东西。这题妙就妙在两边都对——好的老师，往往是点一下，剩下的让你自己长。
- 第三道（送土匪，成全还是遗憾）：说是成全——鲍雷伊说“你比我更需要它”“我没有使它快乐的秘诀”，他看明白了爸爸一个人跑长途更需要这只狗，这是他懂事、体谅爸爸；说是遗憾——一个孩子把自己最喜欢的狗亲手让出去，成全的背后，其实藏着很深的失落。两种都从书里读到了，就很好。

师：（转化·收口追问）我最后追问一句：你的判断，是从书里哪一句话、哪件事来的？（请两三位同学指出依据）——记住，思辨不是“我觉得”，是“我从书里第几章哪件事，看出我这样想”。能说到这一步，你就真的在思辨了。

### 三、联系生活·把烦心事从正面想一想（5 分钟）

师：（先回到书里那一幕）我们先回到书里一个地方。鲍雷伊午餐老被偷，越想越气，有天干脆去乱踢别人的午餐袋，正好被校工法兰德林先生逮住。法兰德林没骂他，只点了他一句——“你要从正面去想。”（稍停顿）鲍雷伊后来真就把这句话听进去了：他不再光顾着抱怨、光顾着抓小偷，而是动手给自己的午餐盒做了一个防盗警报器。你看，一件烦了他好久的糟心事，就这么被他自己动手扭了过来。

师：（抛问·接一个具体的经历，不是泛泛问感受）那我想问问你：你有没有过这样的时候——碰上一件烦心事，本来一肚子气、一肚子委屈，后来你没光生气，而是自己想了个办法、动手把它扭过来了一点？是件什么事？你当时是怎么“从正面去想”、又怎么动手的？说给大家听听。

学生自由分享

参考（鼓励真实、不评判，接住就好）：有的同学总丢橡皮、丢笔，后来自己想办法在文具上写了名字、编了号；有的跟同桌闹别扭，后来自己主动开口说和；有的怕黑、怕一个人睡，后来想了个小办法慢慢不怕了。说得出“那件烦心事、我后来怎么想的、动手做了什么”就好，不必说得多完整。

师：（收口·把话轻轻还回书，不拔高）谢谢大家愿意说。你看，鲍雷伊和你们是一样的——烦心事人人都有，可法兰德林那句“从正面去想”提醒我们：与其在原地生闷气，不如换个方向、自己动手试一试。鲍雷伊就是从那个午餐盒警报器开始，一点一点变得不再只会抱怨的。

### 四、应用·给鲍雷伊写一封回信（15 分钟）

师：这本书有个特别的地方——从头到尾，我们只读到鲍雷伊写出去的信，汉修先生的回信，一次都没有正面出现过，全是鲍雷伊转述的。（稍停顿）今天，我们来补上一封“回信”。

师：（布置任务·读后迁移，说清怎么写）请你选鲍雷伊的一封信或一则日记，以“汉修先生”，或者以“一个刚读完这本书的读者”的身份，给鲍雷伊写一封回信。你可以回应他的烦恼，可以说说你从他身上看到了什么，也可以像朋友那样，跟他说几句心里话。这封信写给谁看，你自己定；写多写少不要紧，写得像你自己就好。

师：（练习法·当堂写）我们现在就写，10 分钟。写完，请几位同学念给大家听。

（学生当堂写作，教师巡视）

师：好，请三四位同学，念念你写给鲍雷伊的回信。

### 五、全课总结·预告下期（5 分钟）

师：（总结）这四节课，我们从二年级鲍雷伊那封写错了字的信读起：第一节猜、第二节理、第三节细读他的信和日记、看清了他藏在两副笔墨里的心，今天，我们把他这一年的八个转折点排成了一条成长的台阶，聊了三道最难的题——包括汉修到底是不是个好老师，还给他回了一封信。（稍停顿）一个父母离婚、转学后没朋友、午餐老被偷的男孩，就是这样，一封信一则日记地，长成了他自己。

师：（回收问题墙·首尾呼应）对了，还记得第一节课起我们墙角那面“问题墙”吗？当初你们一张张贴上去的问题，如今整本书读完了，回头看看，是不是大都自己有了答案？（请一两位说说）剩下那一两个还想不通的，就留着——有些问题，等你再长大一点，或者读到别的书，自然会懂。

师：（预告下期）下一期我们要读……【教师补充：此处填上你们下一期实际要读的书名，一句话勾起学生的期待】。请你把这四节课用过的预测阅读单、人物关系图、对比图、成长阶梯图、思辨阅读单，还有你写给鲍雷伊的回信，都夹进这本《亲爱的汉修先生》里，作为你这一期的阅读笔记，好好留着。
