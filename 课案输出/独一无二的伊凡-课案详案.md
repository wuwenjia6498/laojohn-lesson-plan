### 一、文本介绍

【内容简介】

《独一无二的伊凡》是一部儿童小说，灵感来自一只名叫伊凡的真实大猩猩追寻自由的经历，2013 年荣获纽伯瑞儿童文学奖金奖。它最特别的地方，是**从头到尾由大猩猩伊凡“我”来讲**——我们透过一只大猩猩的眼睛去看人类的世界；全书由 **153 个极短章节**加一篇《作者的话》组成，多数章节只有几百字，以一个意象或一件事为题，如《嗨》《名字》《承诺》《生气》《家》。

故事大致分三段：伊凡在“八号出口的巅峰商城”玻璃笼子里的生活，以及挚友老母象史黛拉、流浪狗鲍勃、画画知音小女孩茱莉亚；象宝宝露比被卖来、史黛拉临终托伊凡照顾露比后死去；伊凡兑现承诺，用手指画拼出“家”（HOME）救露比，最终和露比一起被送到动物园，学着做一只真正的银背大猩猩。全书围绕**囚禁与自由、家与归属、友谊与承诺、成为自己**等主题展开。

【作者介绍】

凯瑟琳·阿普尔盖特（Katherine Applegate，又译“艾波盖特”，1956— ），美国当代儿童文学作家，擅长以儿童或动物的视角讲述成长、友情、勇气与生命的故事，文字细腻温暖、充满人文关怀，始终关注人与自然、人与动物的关系。2012 年，她根据真实故事创作《独一无二的伊凡》，该作荣获 2013 年纽伯瑞儿童文学金奖，后于 2020 年被改编为同名电影。

**特别说明（教师备课注意）**：① 伊凡的本名是“泥巴”，“伊凡”是人类给的名字，讲“名字”这条线时要分清；② “影子”是伊凡死去的双胞胎妹妹，“假影子”是他抱着睡的大猩猩玩偶，两者勿混；③ 强波只出现在史黛拉讲的故事里，引用时须说明“这是史黛拉讲的故事”；④ 全书对“人类”是辩证呈现的（既有用尖爪棍的“坏人类”，也有救露比的村民、茱莉亚、乔治、抗议者），勿简化成“人类都是坏的”。

### 二、教学目标

**本书三维教学目标**
【知识技能】了解作者与本书获奖背景；认识第一人称大猩猩叙述、153 个极短章节的独特体例；读懂全书三段式情节，理清伊凡与史黛拉、露比、鲍勃、茱莉亚等人物的关系，把握囚禁与自由、承诺与家、成为自己等核心内容。
【过程方法】综合运用预测、图像化、筛选重要信息、整合、比较、推断、联结等阅读策略；借助气泡图、思维导图、对比图、阶梯图，梳理情节、分析人物、辨析主题、迁移表达。
【情感价值】体会伊凡对自由、家与承诺的追寻；思考人类对待动物的责任，理解“人类”善恶两面的复杂；学会珍视承诺、尊重生命。

### 三、教学流程

## 第一课时 · 导读课

**本节三维目标**
【知识技能】认识作者与本书；了解第一人称大猩猩叙述和“极短章节”的体例；从开篇片段初步认识伊凡。
【过程方法】重点训练预测与图像化两项策略；学习用气泡图发散人物印象。
【情感价值】对“广告牌上愤怒的伊凡与真正的伊凡到底哪个是真的”产生好奇与代入，激发通读全书的兴趣。

### 一、广告牌上的大猩猩·哪个才是真的他（10 分钟）

师：亲爱的同学们大家好，很高兴又和大家一起读书。上课之前，老师先请大家看一样东西——在美国一家大商场的门口，立着一块巨大的广告牌，上面画着一只大猩猩：呲着牙，瞪着眼睛，胸口挺得老高，愤怒得好像下一秒就要从广告牌里扑出来。大家盯着它看一看——光凭这块广告牌，你觉得这是一只怎样的大猩猩？要是在动物园隔着栏杆碰上它，你心里会怎么想？

学生自由分享

参考：学生多半会说凶猛、可怕、危险、脾气很坏、会伤人、不敢靠近……不必纠正，学生越往“凶”的方向说，越好，为下面的反转蓄势。

师：大家说的都是“凶猛”“可怕”。可奇怪的事情来了——这块广告牌上画的，正是我们今天要读的这本书的主角，一只真的大猩猩，他的名字叫伊凡。（举起书给大家看）可是，对着这块把自己画得张牙舞爪的广告牌，伊凡本人却轻轻说了这样一句话——

（教师读出，语气平静）

> 那只动物应该就是我吧，可是，画家画错了。
> 我从来不生气。

师：你们听——广告牌上那只快要扑出来的、愤怒的大猩猩，和这个说“我从来不生气”的伊凡，简直像两只完全不一样的大猩猩。可他们偏偏是同一只。（稍停顿）那老师就想不明白了：广告牌上的他，和真正的他，到底哪一个，才是真的伊凡？他明明说自己从不生气，人们又为什么，偏要把他画成一只发怒的野兽？

师：这些问题，老师先不回答，答案就藏在这本书里，等你们自己去把它读出来。而且这本书还有一个很特别的地方——它不是别人站在旁边讲伊凡，是伊凡“自己”开口，从头到尾，都是他在跟我们说话。他会怎么讲自己呢？我们一起翻开书。

### 二、认识这一本书·谁在讲这个故事（10 分钟）

师：拿到一本新书，我们先别急着往下读，先认识认识“这一本书”本身。这本《独一无二的伊凡》是美国作家凯瑟琳·阿普尔盖特写的，2013 年得了一个很重要的儿童文学奖——纽伯瑞金奖。（说明：纽伯瑞金奖是公开的获奖记录，不是书里写的，老师这样介绍即可。）

师：还有一件事，大家一定要知道——广告牌上那只伊凡，不只是作家凭空编出来的。真的有过一只叫伊凡的大猩猩：他被人单独关在一家大商场的玻璃笼子里，整整二十七年——二十七年有多长？比你们现在的年纪还长两三倍；这么多年里，每天都有人隔着玻璃看他、对他指指点点，可他身边连一个大猩猩同类都没有，孤零零一个。（稍停顿）后来，是很多人一起把他救了出来，其中有一群特别让人意外——是一大群跟你们差不多大的孩子，他们在一篇杂志报道里看到了这只大猩猩的照片和遭遇，一封信、一封信地写出去替他说话，最后真的把他救了出来，送去了宽敞的动物园，和别的大猩猩住在一起。（说明：这段真事，作家把它写在了书末尾的《作者的话》里，是这本书的灵感来源；它是“关于这本书”的说明，不是伊凡在故事里讲的事，大家读到书的最后就会看到。）

师：不过要分清一件事——这本书是一部小说，书里的伊凡和它的朋友们，是作家想象出来的。现在请大家翻开书，快速翻一翻，看看它和你以前读过的小说，长得有什么不一样？

学生互动分享

参考：章节特别多、特别短，一个章节可能就一页、甚至几行；每个章节的题目都很短，像《嗨》《名字》《承诺》；从头到尾好像都是“我”在说话……

师：（总结）大家观察得很仔细。这本书有两个很特别的地方。第一，它一共有 153 个非常短的章节，短到有的只有几行字，每一章用一个词、一件小事做题目。读这样的书有个好处——我们可以一小段一小段地读，读起来不累。第二，也是最特别的，这本书是“我”在讲故事，而这个“我”不是人，是**大猩猩伊凡自己**。也就是说，接下来我们是钻进一只大猩猩的脑袋里，用它的眼睛去看人类的世界。这在小说里可不多见。

师：老师还要先提醒大家一件事，免得读的时候糊涂。大猩猩伊凡，其实还有一个“本名”。人类叫他“伊凡”，可他的爸爸妈妈，因为他小时候爱用泥巴画画，给他取名叫“泥巴”。所以读到“泥巴”的时候，别以为是另一个角色，那还是伊凡。这个“名字”，后面藏着很重要的秘密，大家边读边留意。

### 三、初读精彩片段·走近伊凡（15 分钟）

师：认识完这本书，我们来听听伊凡自己怎么开口的。老师给大家读全书最开头的两小章——《嗨》和《名字》，请大家闭上眼睛听，一边听一边在脑子里“放电影”：你仿佛看见了一只什么样的大猩猩？他说话是什么语气？

（教师朗读全书开篇《嗨》《名字》两章）

> 我是伊凡，我是一只大猩猩。
> 事情不像表面看起来那么简单。

> 人们叫我“高速公路大猩猩”“八号出口的大猿”“独一无二的伊凡”“大力士银背”。
> 这些都是我的名字，可是都不等于我。我是伊凡，就是伊凡而已。
> 人类浪费字。他们随意抛掷字，就像丢香蕉皮似的，任凭它腐烂。

师：听完这一段，我们来用“图像化”的方法说一说——就是把文字变成脑子里的画面。刚才这段文字，在你脑海里是什么画面？你“看见”的伊凡，是凶猛的，还是别的样子？

学生互动分享

参考：（根据文本作合理想象，答案多元）我看见一只很大、很安静的大猩猩，隔着玻璃看着外面；他看起来不吓人，反而有点孤单；他好像懂很多事，只是不爱说……

师：你是从哪个词、哪句话“看见”这个画面的？

学生互动分享

参考：从“事情不像表面看起来那么简单”，感觉他心里有很多话；从“这些都是我的名字，可是都不等于我”，感觉他很清楚自己是谁，不服人类乱给他起的名号。

师：（总结）大家抓得很准。伊凡一开口就告诉我们两件事：一，人类给了他一大堆名字，可他说“都不等于我”；二，他觉得人类“浪费字”。你看，一只不会说人话的大猩猩，反而最在意“名字”和“字”到底算不算数。这就是这本书一直在问的问题——**别人怎么叫你、怎么看你，就等于你是谁吗？** 记住这个问题，我们往下读。

### 四、气泡图·我眼中的伊凡（15 分钟）

师：刚才我们只听了开头两小章，就已经对伊凡有了一点点印象。现在老师请大家把这些“印象”整理出来。我们用一个很简单的工具，叫“气泡图”。它的样子是：中间画一个大气泡，写上我们要研究的对象——“伊凡”；再从中间向四周拉出几个小气泡，每个小气泡里写一个词，写下你觉得伊凡是“什么样的”。这张气泡图就在你们自己的学习单上，请大家动手填。

师：填的时候有一个要求——不能凭空写，每写一个词，要能说出“我是从哪句话感觉到的”。还可以顺便像刚才那样，在脑子里给这个词配上一个画面——比如写“孤单”，就想象伊凡孤零零坐在玻璃后面的样子。现在请大家先自己填三到四个小气泡。

学生互动分享（学生在各自学习单上填写气泡图）

参考（示例填法，供参考，学生答案可不同）：

| 中心气泡 | 向四周发散的小气泡（特征词） | 我的依据（从哪句话感觉到的） |
|---|---|---|
| 伊凡 | 孤单 | 隔着玻璃、只有他一个大猩猩 |
| 伊凡 | 有想法／聪明 | “事情不像表面看起来那么简单” |
| 伊凡 | 在乎自己是谁 | “这些都是我的名字，可是都不等于我” |
| 伊凡 | 安静、不爱吵 | 他觉得人类“浪费字” |
| 伊凡 |  |  |

师：（请两三位同学展示自己的气泡图）请你读一读你写的词，再说说你的依据。

学生分享

师：（点评追问）老师发现大家写的词，有的是“孤单”“安静”，有的是“聪明”“有主见”。这很有意思——同一只伊凡，我们从几行字里就读出了这么多面。（稍停顿）大家还记得上课一开始，老师给你们看的那块广告牌吗？上面那只伊凡，是愤怒的、张牙舞爪、吓人的；可你们气泡图上写的伊凡，好像没有一个人写“凶”“可怕”。同样一只伊凡，广告牌上的他，和你们从他自己的话里读出来的他，差得这么远——那到底哪个才是真的？这个“对不上”，就是我们读整本书要去解开的谜。（总结）大家先把气泡图收好，读完全书我们再回来看看，你今天写的这些词，哪些对了，哪些要改。

### 五、预测·提问与阅读规划（10 分钟）

师：认识了伊凡，我们来做两件读书前必做的事——先**预测**，就是大胆地猜一猜。老师给大家三条已经知道的线索：第一，伊凡被关在商城的玻璃笼子里很多年；第二，后来来了一只象宝宝，叫露比；第三，伊凡最后用一幅画救了露比。请你猜一猜：伊凡会怎么用一幅画救露比？这本书会是一个悲伤的结局，还是一个温暖的结局？把你的猜测写在预测单上。

学生互动分享

参考（预测无对错，重在有依据）：伊凡可能把画贴到大家都能看见的地方，让人类来帮忙；结局可能是温暖的，因为伊凡这么在乎露比……

| 我的预测 | 我猜的依据是…… | 读完是否被证实 |
|---|---|---|
| 例：伊凡会把画给那个爱画画的小女孩看 | 小女孩是他的知音，会懂他 |  |
|  |  |  |
|  |  |  |

师：（总结）大家的猜测都很有道理，究竟对不对，答案就在书里。这一栏“读完是否被证实”先空着，等你读完全书再回来打勾——这是我们读书人的好习惯，猜了就要回头验证。

师：猜完了，再做第二件事——**提问**。带着问题读书，比闷头读收获大得多。请你现在就写下一个你最想问的问题：可以问伊凡，也可以问作者，比如“伊凡自己会想逃走吗”“他画画到底是为了什么”。写在读书笔记的第一页，带着这个问题去读，留意书里有没有替你解答。下节课，我们请几位同学亮出自己的问题，看看你找到答案了没有。

师：下面布置我们的阅读任务。这本书虽然章节多，但每章都很短，读起来很快。请大家在**这一周之内读完整本书**。读的时候做两件事：一是把你“最喜欢”和“最看不懂”的章节，用小纸条夹在书里；二是特别留意——伊凡“画画”这件事，在书里出现了好几次，他都画了些什么？下一次上课，我们一起把这本书好好聊一聊。

本课完。

## 第二课时 · 阅读交流课1

**本节三维目标**
【知识技能】梳理全书三段式情节脉络；认识伊凡身边的主要人物及其与伊凡的关系；读懂“承诺”这一全书情节枢纽。
【过程方法】重点训练筛选重要信息与整合两项策略；学习用思维导图归并全书情节板块。
【情感价值】体会史黛拉与伊凡的友谊、以及临终托付的分量，初步感受“承诺”的重量。

### 一、阅读回顾·唤醒整本书（10 分钟）

师：亲爱的同学们，这一周大家把《独一无二的伊凡》读完了，辛苦了。我们先不急着分析，先一起回忆一下这本书。老师问几个“读过就知道”的小问题，大家抢答。第一，伊凡住在什么地方？第二，伊凡最好的朋友，那只老母象叫什么名字？第三，那只每天睡在伊凡肚子上的流浪狗叫什么？第四，后来被卖来的象宝宝叫什么？

学生互动分享

参考：伊凡住在“八号出口的巅峰商城和电子游乐场”的玻璃笼子里；老母象叫史黛拉；流浪狗叫鲍勃；象宝宝叫露比。

师：上节课，大家在笔记第一页各写了一个最想问的问题。现在请两三位同学亮出你的问题，再说说——读完全书，你找到答案了吗？

学生互动分享

参考：如问“伊凡为什么不逃走”，读完可能明白：他从小被人类养大、早已回不去野外，而且他把心思都放在了守护露比上；如问“露比会不会得救”，读完知道露比最后被送到动物园、和象群团聚了。（有的问题读完仍没有确定答案，如“伊凡到底算不算自由”，这类问题留到思辨课再讨论。）

师：（总结）看来大家都认真读了，也带着问题在读。上节课老师还请大家留意“伊凡画画”这条线，也请大家夹了纸条。这节课我们就把整本书好好地梳理一遍，先把故事读全、读清楚。

### 二、思维导图·梳理三段情节（20 分钟）

师：这本书有 153 个短章节，事情很多，怎么才能不乱？老师教大家一个办法——用“思维导图”把它归成几大块。做法是：中间写上书名《独一无二的伊凡》，再从中间拉出**三条主枝**，代表故事的三大段；每条主枝下面，再挂上这一段里发生的几件大事。这张思维导图在你们的学习单上，我们一起来填。

师：先看第一大段，大概从开头到史黛拉讲“强波”的故事。这一段主要讲什么？请大家从书里筛选出“最重要”的几件事，不重要的先放一放。

学生互动分享

参考：伊凡介绍自己和巅峰商城的生活；他是会画画的“艺术家”，画能卖钱；认识挚友史黛拉、流浪狗鲍勃、画画知音小女孩茱莉亚；史黛拉讲了银背大猩猩强波守护落难男孩的故事（这是史黛拉讲的故事，要注明）。

师：很好。第二大段，从象宝宝露比被卖来，到史黛拉去世。这一段最重要的事是什么？

学生互动分享

参考：象宝宝露比被卖到商城；史黛拉忍着脚伤帮露比、护着她；史黛拉脚伤恶化，麦克拖延不请兽医；史黛拉临终前，让伊凡承诺照顾露比、送她去一个安全的地方；史黛拉去世了。

师：第三大段，从伊凡下决心，到故事结尾。谁来说说？

学生互动分享

参考：伊凡回忆起自己的身世；他看见麦克用尖爪棍逼露比表演；他决定用手指画拼出一个大大的“家”（HOME）贴到广告牌上救露比；引来记者和抗议的人群；动物园把露比和伊凡接走；伊凡在动物园学着做一只真正的银背大猩猩，最后望见露比安全地和象群在一起。

师：（把三段汇拢，请学生补到自己的思维导图上）请大家把刚才我们一起理出来的大事，补到自己学习单的三条主枝下面。填好的思维导图，大概是这样的骨架——

| 中心 | 三大情节板块（主枝） | 每板块下的关键事件（分枝，可自己补充） |
|---|---|---|
| 独一无二的伊凡 | 一、商城生活与旧友 | 伊凡自述与卖画；结识史黛拉、鲍勃、茱莉亚；史黛拉讲强波的故事 |
| 独一无二的伊凡 | 二、露比到来与史黛拉之死 | 露比被卖来；史黛拉护露比；麦克拖延治病；史黛拉托付承诺后去世 |
| 独一无二的伊凡 | 三、承诺、救露比与去动物园 | 伊凡忆身世；决心画“家”救露比；广告牌引发抗议；伊凡与露比去动物园 |

师：（总结）你看，153 个短章节，被我们归成了三大块。这就是“整合”的力量——把很多零碎的信息合起来，故事的大骨架一下子就清楚了。以后读长书，都可以用这个办法。

师：（回收预测单）对了，上节课大家在“预测单”上猜过两件事——伊凡会怎么用一幅画救露比、结局是温暖还是悲伤。现在整本书读完、故事也理清楚了，请大家翻出预测单，给最后那一栏“读完是否被证实”打个勾：你当时猜对了吗？

学生互动分享

参考：伊凡是用手指画拼出一个“家”（HOME）、贴到广告牌上救的露比，和有人猜的“把画给爱画画的人看”有点接近；结局是温暖的——露比得救、去了动物园。（猜得不完全一样也没关系，重要的是我们回来验证了，这就是读书人的好习惯。）

### 三、认识主要人物·谁围绕着伊凡（15 分钟）

师：故事读清楚了，我们来看看人物。这本书虽然是伊凡一个人讲，可他身边围着一群很重要的角色。老师说一个名字，请你用一句话说说“他是谁、和伊凡什么关系”。先说史黛拉。

学生互动分享

参考：史黛拉是隔壁的老母象，伊凡最亲的朋友之一；她年轻时在马戏团表演，腿被铁链拴伤留下毛病；她记性极好、会讲故事；最后因为脚伤没及时医治而去世。

师：鲍勃呢？

学生互动分享

参考：鲍勃是流浪狗，出生不久就被人从卡车上丢下，后来住在商城，每晚睡在伊凡肚子上；他自称“野兽，不驯服也不屈服”，不让人类碰；结尾却选择跟茱莉亚一家生活。

师：露比、茱莉亚、乔治，还有麦克，谁来说？

学生互动分享

参考：露比是象宝宝，中途被麦克买来，爱提问爱听笑话，史黛拉临终把她托付给伊凡；茱莉亚是清洁工乔治的女儿，10 岁，爱画画，是伊凡的知音，最后读懂了伊凡的画、还打电话给记者；乔治是夜间清洁工、茱莉亚的爸爸；麦克是商城老板。

师：（点评追问）说到麦克，老师想问一个不太好回答的问题：麦克是不是一个纯粹的“坏人”？

学生互动分享

参考（引导辩证看待，不脸谱化）：他确实不好——史黛拉病了他拖着不请兽医，还用尖爪棍逼露比，最后开除了乔治；可是他也养大了小时候的伊凡，临别的时候还拿出旧照片、说“我会想念你”。所以他不是简单的“坏人”，他也有难处和真情。

师：（总结）很好。读小说不能把人物简单地分成“好人”和“坏人”。麦克身上，就既有让人生气的一面，也有让人心软的一面。把人物看得复杂一点，我们才算真正读懂了他。

### 四、聚焦“承诺”·全书的枢纽（15 分钟）

师：整本书里，有一个瞬间是最重要的转折——如果没有这个瞬间，后面救露比的事就不会发生。那就是史黛拉临终前，请伊凡许下的那个“承诺”。我们来细读这一段。

（教师朗读《承诺》一章相关段落）

> “伊凡，我想要你答应我一件事。”史黛拉说。
> “什么事都行。”我说。
> ……
> 我开口了，我被自己说的话吓一跳，“你想要我照顾露比。”
> 史黛拉点点头，这个小动作让她痛得缩了一下，“希望她可以过得……跟我不一样。她需要一个安全的地方，伊凡。不要……”
> “不要在这里。”我说。
> ……
> “我答应你，史黛拉。”我说，“我以银背大猩猩的誓言向你承诺。”

师：请大家在这段话里，筛选出你觉得**最重要的一句**——如果整段话只能留一句，你留哪句？为什么？

学生互动分享

参考：可能留“她需要一个安全的地方”，因为这是史黛拉最放心不下的事；也可能留“我以银背大猩猩的誓言向你承诺”，因为这是伊凡最郑重的保证，后面所有的事都是为了兑现它。（说出理由即可，不强求统一。）

师：（点评追问）老师注意到史黛拉说的是“希望她可以过得跟我不一样”。史黛拉自己，是怎样的一生？她为什么这么希望露比“跟她不一样”？

学生互动分享

参考：史黛拉自己一辈子被囚禁——年轻时在马戏团、腿被拴伤，后来又被关在商城，最后病死在笼子里。她不希望露比重复她这样的命运，所以要伊凡送露比去一个自由、安全的地方。

师：（总结）大家读得很深。这个“承诺”，是史黛拉用自己一生的遗憾换来的嘱托，也是伊凡后面所有勇敢行动的起点。（稍停顿）下一节课，我们就要紧接着这个承诺往下看——伊凡是怎么从一只“不抱希望”的大猩猩，变成一个敢为别人拼命的“保护者”的。请大家把书带好、把你夹的纸条留着，还有你心里的疑问，我们下节课接着深读。

本课完。

## 第三课时 · 阅读交流课2

**本节三维目标**
【知识技能】细读“生气”与“善恶两面”两处关键内容，读懂伊凡“愤怒”的真正含义；对照商城与动物园两处空间，理解“囚禁与自由”的主题。
【过程方法】重点训练比较与推断两项策略；学习用对比图对同一对象作多维度对照，练习“观点—证据”的读法。
【情感价值】感受伊凡从沉默到“为保护而愤怒”的转变；理解人类并非只有一面，学会不简单地评判。

### 一、承接导入·带着承诺读下去（5 分钟）

师：亲爱的同学们，上节课我们停在史黛拉临终的那个“承诺”上。谁还记得——史黛拉到底让伊凡答应了什么？

学生互动分享

参考：史黛拉让伊凡答应照顾露比，让露比过上跟她不一样的生活、送露比去一个安全的地方；伊凡以“银背大猩猩的誓言”答应了。

师：（归纳）对，就是这个承诺。这节课我们就顺着它，深入到几个最关键的段落里，看看伊凡是怎么一步步兑现它的。大家读这本书的时候，有同学夹了“看不懂”的纸条，这节课我们专挑难的、深的地方一起啃。

### 二、细读·伊凡为什么“第一次生气”（15 分钟）

师：这本书里有一个很震撼的场面——伊凡第一次真正地愤怒了。在看这个场面之前，老师先给大家读一小段伊凡早先说过的话，请大家记住它，等会儿有大用。

（教师朗读《我的长相》相关段落）

> 生气是珍贵的。银背大猩猩用生气来维持秩序或警告同伴远离危险。……我生气是为了保护你们，那是我的天职。

师：记住这句——在伊凡心里，银背大猩猩“生气”，不是脾气坏，而是为了保护家人。好，记着这句话，我们再来看那个震撼的场面。先读露比反抗麦克这一段。

（教师朗读《坏人》相关段落）

> 露比突然转头，摇晃她的鼻子朝麦克甩过去。
> 她发出的响声，使碎木屑四散飞扬，也震动了我的玻璃窗。
> 那是我所听过最美丽的怒吼了。
> 露比的鼻子打中了麦克。

师：再看伊凡自己“生气”的这一段。

（教师朗读《生气》相关段落）

> 砰。砰。砰。
> 我撞墙，尖叫，咆哮。我捶胸、捶胸、捶胸。
> 鲍勃躲在假影子底下，用脚掌覆盖住耳朵。
> 我，终于，生气了。
> 我有要保护的对象。

师：书里没有直接告诉我们伊凡生气的全部原因，需要我们**推断**。请结合前面读过的内容想一想：伊凡明明说过自己“从来不生气”，为什么这一次会这么愤怒地捶胸、撞墙？他这份愤怒，是冲着谁、为了谁？

学生互动分享

参考（根据文本作合理推断）：他生气，是因为他画了画想救露比，可茱莉亚一开始读不懂；更深一层，是因为他有了“要保护的对象”——露比。他讲过，爸爸那样的银背大猩猩，会用生气来保护家人。所以他这次生气，其实是他终于像一个真正的银背大猩猩那样，为了保护弱小者而愤怒。

师：（点评追问）你是从哪一句推出来的？

学生互动分享

参考：从最后一句“我有要保护的对象”，还有前面伊凡也说过，银背大猩猩生气是为了保护家人、那是它的天职，两处一对照就明白了。

师：（总结）很好，这就是“推断”——书里没明说，但线索都在，我们把线索连起来，就读出了藏在文字背后的意思。伊凡的这次愤怒，不是失控，而是他重新变回了一只“会保护家人”的银背大猩猩。这是他内心的一次大转变。

### 三、对比图·笼子与动物园（20 分钟）

师：这本书的书名叫“独一无二的伊凡”，可它讲的其实是**两个“家”**——一个是商城的玻璃笼子，一个是最后的动物园。这两个地方到底哪里不一样？我们用一个新工具来比一比，叫“对比图”。做法是：左边一列写“商城的笼子”，右边一列写“动物园”，中间列出几个我们要比较的“角度”，一行一行地对照。这张对比图也在你们的学习单上，我们一起填。

师：老师先给出几个比较的角度：空间大小、是不是孤独、干不干净、还有那面“墙”的含义。我们一个一个来。先说空间和“孤独”——商城的笼子里，伊凡是一个人；动物园呢？

学生互动分享

参考：商城笼子小，伊凡独自一个大猩猩，很孤独；动物园地方大、有露天场地，而且伊凡在那里找到了大猩猩家族、和金雅妮相处，不再孤独。

师：再说那面“墙”。这本书里，“玻璃墙”是伊凡反复琢磨的东西。我们先听伊凡自己在商城里怎么说这面墙。

（教师朗读《消失》相关段落）

> 玻璃窗的意思是：你是你，我们是我们，永远不会改变。
> 人类离开时会留下他们的指纹，沾了黏黏的糖果渍和湿答答的汗水。每天晚上，有个看起来很疲倦的男人会来把它们擦掉。
> 有时候，我把鼻子贴在玻璃上。我的鼻印就像你们的指纹，自始至终独一无二。
> 男人擦完玻璃后，那上面的我就消失了。

师：听出来了吗——对商城里的伊凡来说，这面玻璃墙的意思是“你是你，我们是我们，永远不会改变”。那伊凡对“墙”是不是一直这么看？他后来还说过别的吗？

学生互动分享

参考：不一样。在商城，玻璃墙的意思是“你是你，我们是我们，永远不会改变”；电视里看到动物园时，他觉得那面墙好像在说“你们属于这里，我们属于那里”；到了动物园山顶，他又说这里“毕竟，还是一个笼子”。

师：（把大家的对照汇拢，请学生补到自己的对比图上）我们把比出来的填进去，参考的样子是这样——

| 比较的角度 | 商城的玻璃笼子 | 动物园 |
|---|---|---|
| 空间大小 | 小小的玻璃笼子 | 大，有露天场地和小山 |
| 是否孤独 | 独自一个大猩猩，很孤独 | 有大猩猩家族、有金雅妮，不再孤独 |
| 干净程度 | 旧、脏 | 干净的新笼子 |
| “墙”的含义 | “你是你，我们是我们，永远不会改变” | 也有墙，但伊凡说它“毕竟还是一个笼子” |
| 你的发现 |  （留给学生写） |  |

师：（点评追问）填完这张对比图，老师问一个更难的问题：动物园明明大得多、也不孤独了，可伊凡为什么还要说它“毕竟还是一个笼子”？这句话是什么意思？

学生互动分享

参考（开放，引导深入）：因为动物园再好，也还是有墙、有人来参观，伊凡还是没有完全回到野外的自由；作者好像想说，动物园是“比商城好很多”的地方，是安全的家，但它并不是“完美的自由”。（这个层次很微妙，学生能说到“没有完全自由”即可。）

师：（总结）这就是这本书了不起的地方——它没有把动物园写成一个“完美的天堂”。动物园是伊凡和露比“需要的地方”，是安全的家；但作者也诚实地告诉我们，它“毕竟还是一个笼子”。真正的好书，往往不给我们简单的答案。

### 四、主题探讨·人类到底是好是坏（15 分钟）

师：这本书里，人类做了很多坏事——杀害动物、用尖爪棍、把动物关起来赚钱。可奇怪的是，救动物的，也是人类。我们来读露比讲的一段话。

（教师朗读《露比的故事》相关段落）

> “坏人类杀死我的家族，坏人类把我抓到这里来。可是，那一天，在那个洞里，是人类救了我。”露比的头倚靠着史黛拉的肩膀，“那些人类是好人。”

师：请大家回到整本书里，找一找证据：书里有哪些“坏人类”，又有哪些“好人类”？我们做一次“观点—证据”的读法，任何判断都要能从书里找到根据。

学生互动分享

参考：“坏人类”：杀害露比家族、把她抓走卖掉的人；用尖爪棍逼露比、拖延给史黛拉治病的麦克。“好人类”：在水洞边合力救起露比的村民；给伊凡蜡笔、读懂他的画的茱莉亚；帮忙贴海报的乔治；聚集起来要求“放露比自由”的抗议者；来接他们去动物园的玛雅。

师：（点评追问）那么，如果有人读完这本书说“这本书就是想告诉我们，人类都是坏的”，你同意吗？请用刚才找到的证据反驳或补充。

学生互动分享

参考（引导辩证）：不同意。书里既有坏人类，也有很多好人类；露比自己都说“那一天，是人类救了我”。作者想说的不是“人类都是坏的”，而是“人类很复杂，不能一概而论”——就像史黛拉说的，“灵长类啊，是无法预测的动物”。

师：（总结）大家读得很有分寸。这本书没有让我们简单地去恨“人类”，而是让我们看到：同样是人，有人伤害动物，也有人拼尽全力去救。

### 五、原文齐读·“终于在外面了”（5 分钟）

师：这节课，我们比了商城的笼子和动物园，也辩了人类的好与坏。最后，老师想请一位同学，为大家读一段全书最动人的文字——伊凡被送到动物园，第一次走出笼门、踩到真正的土地那一刻。请其他同学闭上眼睛听。

（邀请一位平时朗读功底不错的同学朗读《终于在外面了》一章）

> 天。
> 草。
> 树。
> 蚂蚁。
> 树枝。
> 鸟。
> 土。
> 云。
> 风。
> 花。
> 岩石。
> 雨。
> 我的。
> 我的。
> 我的。

师：（总结）短短几个字，一行一个，可我们仿佛看见伊凡一样一样地把这个久违的世界看进眼里。老师想问：为什么最后他要连说三次“我的”？

学生互动分享

参考：因为这天、这草、这树、这土，是伊凡失去了很多年、如今终于重新拥有的；说“我的”，是他重新有了属于自己的天地，也是自由回来的声音。

师：（总结）说得真好。（稍停顿）下一节课，我们要把伊凡这一路的转变整个儿看一遍，还要一起讨论几个“没有标准答案”的问题，请大家把心里的想法都带来。

本课完。

## 第四课时 · 思辨&应用课

**本节三维目标**
【知识技能】纵观全书，梳理伊凡从“被动囚禁、不抱希望”到“成为真正的银背大猩猩”的转变历程；就书中开放议题形成有依据的个人判断。
【过程方法】重点训练转化与联结两项策略；学习用阶梯图呈现人物的阶段性成长，并把书中议题迁移到真实生活与创意表达。
【情感价值】理解“成为自己”“守住承诺”“追寻自由与家”的意义；把对生命与自由的思考落到自己的表达里。

### 一、阶梯图·伊凡的转变（20 分钟）

师：亲爱的同学们，这是我们读《独一无二的伊凡》的最后一节课。开始之前，先请大家翻出第一节课画的那张“气泡图”——当时我们只听了开头两小章，就给伊凡写了几个词，像“孤单”“安静”“聪明”。还记得老师当时留下的那个问题吗：广告牌上，人类把伊凡画成一只愤怒的大猩猩，可我们读到的伊凡一点都不愤怒，这中间“对不上”。现在整本书读完了，你当时写的那些词，哪些还对、哪些要改？那个“愤怒之谜”，你解开了吗？

学生互动分享

参考：多数词还对——伊凡确实孤单、安静、聪明、在乎自己是谁；但“从不生气”这一条要改了：读到《生气》才知道，伊凡也会为了保护露比而愤怒地捶胸，广告牌上那只“愤怒的大猩猩”，其实藏着他“要保护家人”的另一面。

师：（承上）大家看，同一只伊凡，读之前和读之后，我们眼里的他已经不一样了。这正说明——伊凡这一路，是在变的。今天我们就用一个新工具，把他的转变画成一道“阶梯”，叫“阶梯图”。伊凡从一只关在玻璃笼子里、什么都不敢想的大猩猩，变成了一个敢为别人拼命、最后走向“我的家”的银背大猩猩。他不是一下子变的，而是一级一级“走上来”的。

师：先讲讲什么是阶梯图。它就像一段台阶，从最低的一级往上走，每一级代表人物的一个成长阶段，越往上，人物变得越勇敢、越像真正的自己。我们把伊凡的转变分成五级台阶，一起来填。这张阶梯图在你们的学习单上。

师：最低的第一级——故事刚开始，伊凡是什么状态？他对未来抱希望吗？他都画些什么？

学生互动分享

参考：他说“我已经学会，不要有太多希望”；他只画笼子里看得见的东西，比如香蕉，不画想象的东西。

师：第一级我们一起填好了。剩下的第二到第五级，这次老师不带着一级一级问了，请大家先自己动手——把伊凡后面几个大的转变，一级一级填到阶梯图上。给一个提示：往上排的时候，想想这几件大事该放在哪一级——史黛拉临终的“承诺”、伊凡第一次讲出自己的身世、他第一次真正“生气”、最后去动物园学做真正的银背大猩猩。

学生互动分享（学生先在自己的阶梯图上，独立填第二到第五级）

师：（抽一两级请学生说，不必四级都过）谁来说说你的第二级填了什么？再请一位说说你的第五级？

学生互动分享

参考：第二级——史黛拉临终，伊凡以银背大猩猩的誓言承诺照顾露比；第三级——为了安慰露比，他第一次讲出自己被封存的身世，还开始画“现实里还不存在的东西”，画想象中的家；第四级——他第一次真正生气、捶胸，说“我有要保护的对象”，下决心用画救露比；第五级——他在动物园学着做一只真正的银背大猩猩，在山顶重新用泥土作画，望见露比安全，走向“我的家族、我的生活、我的家”。

师：（出示参考骨架，请学生对照补全、订正自己的阶梯图）参考的样子是这样——

| 台阶 | 伊凡所处的阶段 | 关键事件（章节定位） |
|---|---|---|
| 第一级（起点） | 被动囚禁、不抱希望，只画笼里的东西 | 《想象》《艺术家》 |
| 第二级 | 以银背大猩猩的誓言，承诺照顾露比 | 《承诺》 |
| 第三级 | 讲出封存的身世；开始画“想象中的家” | 《很久以前》《广告》 |
| 第四级 | 第一次为保护而愤怒，决心用画救露比 | 《生气》 |
| 第五级 | 学做真正的银背，望见露比安全，走向“我的家” | 《山顶》《安全了》《银背大猩猩》 |

师：（顺便点一句）还记得第一节课，老师请大家留意“伊凡画画”这条线吗？它就藏在这道阶梯里——第一级他只画笼子里看得见的香蕉，第三级开始画“想象中的家”，最后一级在山顶用泥土重新作画。画的东西一直在变，其实是伊凡这个人在变。

师：（点评追问）看着这道从下往上的阶梯，老师问一句：伊凡的这道阶梯，是从哪一级开始“往上走”的？换句话说，是什么事，让一只“不抱希望”的大猩猩，重新有了力气？

学生互动分享

参考（开放）：是从“承诺”那一级开始的——史黛拉的托付，让伊凡有了“要保护的对象”，他才一步步找回了自己。也可以说，是“爱”和“责任”让他重新站了起来。

师：（总结）大家看，这就是“成长”的样子——它常常不是因为自己变强了，而是因为心里装下了别人。伊凡是为了守住一个承诺，才慢慢变回了真正的自己。

### 二、思辨讨论·两个没有标准答案的问题（15 分钟）

师：接下来，我们讨论两个“没有标准答案”的问题。规则是：你可以有自己的判断，但要从书里找到证据、讲清理由。请大家在思辨单上填写。

师：第一个问题——**故事结尾，伊凡真的“自由”了吗？** 他到了动物园，有了家族、望见露比安全；可他自己也说，动物园“毕竟还是一个笼子”。你觉得他自由了吗？

师：第二个问题——**史黛拉让伊凡“承诺”照顾露比，这个沉重的托付，对伊凡到底是“负担”还是“礼物”？**

学生互动分享（学生填思辨单，再分组讨论、分享）

参考（开放，鼓励多元，各自都要有证据）：

| 思辨问题 | 书中相关片段（章节） | 我的判断 | 我的理由 |
|---|---|---|---|
| 伊凡自由了吗 | 《终于在外面了》《山顶》 | 例：算比以前自由，但不是完全自由 | 他能看到天、草、树，说“我的、我的、我的”；可他也说动物园“还是一个笼子” |
| 承诺是负担还是礼物 | 《承诺》《生气》《银背大猩猩》 | 例：是礼物 | 正是这个承诺让他重新有了勇气、找回了自己 |
|  |  |  |  |

师：（点评追问）老师听到有的同学说“自由了”，有的说“没完全自由”，这很好。老师追问一句：如果伊凡能选，你觉得他会更想要“完全的野外自由”，还是“动物园里安全的家”？

学生互动分享

参考（无定论）：可能他更想要安全的家，因为野外对他已经太陌生、也回不去了；也可能他心里始终向往野外。（能自圆其说即可。）

师：（总结）这两个问题，老师也没有标准答案。这正是这本书留给我们的礼物——它让我们学会，面对复杂的事，先找证据、再下判断，还允许别人有不一样的答案。

### 三、联系生活·“独一无二”与“家”（10 分钟）

师：读完伊凡的故事，我们把它和自己的生活连一连。伊凡说，人类给他的一大堆名字“都不等于我”，他花了整本书，才活成了“真正的自己”——其实我们每个人也一样，别人怎么称呼你、怎么看你，都不等于真正的你。

师：今天，我们单挑伊凡故事里一个最重要的词，跟自己好好连一连——“家”。伊凡为露比拼的那幅画，最重要的就是一个字。我们先听听他自己怎么说这个字。

（教师朗读《一个字》相关段落）

> “因为这样我就有一个字了。一个非常重要的字。”我伸出手指蘸颜料。
> “什么字？”鲍勃问。
> “家。”
> 鲍勃闭上眼睛。“它没有那么重要。”他轻轻地说。

师：伊凡把“家”看成“一个非常重要的字”，鲍勃却说“它没有那么重要”。那对你来说，“家”意味着什么？是一个地方，还是别的什么？

学生自由分享

参考（联结个人经验，回扣文本，不强求统一、不煽情）：对“家”的理解，可能是一个有家人的地方、是让自己安心的地方；就像露比的“家”是象群，伊凡的“家”是大猩猩家族——不只是一个笼子换成另一个笼子，而是有归属、能做自己的地方。

师：（点评追问）你说的这个理解，和书里伊凡对“家”的追寻，有没有接得上的地方？

学生互动分享

参考：接得上——伊凡找的“家”不只是一个笼子换成另一个笼子，而是有同类、有归属、能做自己的地方。

师：（总结）很好。一本好书就是这样，它讲的是一只大猩猩，可读着读着，我们会照见自己。

### 四、阅读成果·创意表达（15 分钟）

师：动手之前，先快速一问——这几天读这本书的时候，大家夹过“最喜欢”的章节，谁愿意用一句话说说，你最喜欢哪一章？

学生互动分享

师：好，带着你最喜欢那一章的感觉，我们来做这本书的收尾任务。伊凡是用“画”来表达心里最重要的东西的——他为露比画了一个“家”。现在轮到你了，从下面两个任务里**任选一个**，动手完成。

师：任务一，“给伊凡的一段话”——故事结尾，伊凡在动物园望见了安全的露比。请你替伊凡，对已经去世的史黛拉说几句话，告诉她承诺兑现了、现在的日子怎么样。任务二，“一幅画加一句话”——如果让你像伊凡那样，为一个你想保护的人或动物画一幅画、再配上一个“最重要的字”，你会画什么、写哪个字？把它写下来、简单说明理由。

学生互动分享（学生动笔，完成后分享）

参考（尊重个性表达，回扣文本即可）：如替伊凡对史黛拉说话，可写“史黛拉，露比现在和象群在一起，很安全，就像我答应你的那样。我也找到了我的家……”；如画画加字，学生可自由发挥，只要“想保护谁、为什么画这个字”讲得通即可。

师：（请几位同学分享作品，教师点评）

学生分享

师：分享得都很好。这本书我们就要读完了。最后，老师和大家一起，读一读伊凡故事的结尾——他在动物园的山顶，望见了墙那边安全的露比，对已经去世的史黛拉，轻轻说了这样几句话。

（全班齐读结尾《安全了》《银背大猩猩》片段）

> “她在这里，史黛拉。”我小声地说，“露比安全了，就像我承诺你的。”
> 我呼唤露比，可是我的话被风卷走了，我知道她永远听不到我了。
>
> 我点点头，然后转身走向我的家族、我的生活、我的家。
> “大力士银背大猩猩。”我小声地说。

师：（总结）同学们，《独一无二的伊凡》我们就读到这里。伊凡用一幅画、一个“家”字，兑现了对朋友的承诺，也活成了真正的自己。希望大家记住：每个人都是独一无二的，别人怎么叫你、怎么看你，都不等于真正的你——真正的你是什么样，要靠你自己，一级一级，走出来。这本书，下课以后也可以再翻一翻，你一定会有新的发现。

全课完。
