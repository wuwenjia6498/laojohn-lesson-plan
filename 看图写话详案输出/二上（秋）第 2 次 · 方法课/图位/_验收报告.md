# 生图验收报告

- 源详案：`二上（秋）第 2 次 · 方法课.md`
- 生图模型：`gemini-3-pro-image-preview` · 验收模型：`gpt-4o` · 尺寸：4:3 2K

**汇总：1 图，1 过，0 需人工复核。**

## 备-01（备选图） — ✅ 过 · 生图 1 次
- [x] 画面能支撑句式「她在（怎么做）＋ 她脸上（什么样）」所述场景
- [x] 画面与「院子里，一个小女孩双手把一只小猫从纸箱里往上抱，小猫两只前爪扒住箱沿往后缩。」一致
- [x] 满足验收条款：能一眼指出“她在怎么做”（蹲着、上身前倾、双手托抱）与“她脸上什么样”（抿嘴、皱眉）
两处即可，不逐要素核；小猫两只前爪扒住箱沿、身体后缩＝可推想的意外处。
须人工确认：东亚面孔黑发、短袖、树叶翠绿无黄叶、非背影。
⚠ **嘴形必须人工放大看（第 1 版栽在这里）**：第 1 版把“抿着嘴”画成了**噘嘴**——嘴唇向前撅成
一个圆、腮帮鼓起，读作嘟嘴撒娇或生气，与正文 `参考：`“她抿着嘴／她使劲呢”读反方向。
**判据＝嘴唇是压成一条横线（对），还是撅成一个圆（错）**。这是“规定结果不规定姿态”的又一例：
`抿着嘴` 是结果词，模型会用噘嘴速记顶替。
⚠ **改嘴那一轮把猫的姿态丢了（第 2 版）**：只改了嘴与眉、没重述猫的动作，重生后小猫变成
四脚站在箱底、安静被扶着，“她在使劲”失去依据。**第 3 版把两件一起写死才同时成立**——
这是“碰巧画对又没在本轮提示词里重述的东西一定丢”的又一例，改任何一处前先通读整段提示词。
**本图定稿＝第 3 版**（嘴抿平 ＋ 小猫被提离箱底、后腿悬空、身体后仰挣扎）。
两项已知偏差、按轻验收纪律**不再重生**：① **两条眉毛三版都是一高一低**，没做到“左右对称下压”
（模型倾向把不对称当作更有表情）——正文只要学生说得出“眉毛皱起来了”，不受影响；
② **第 3 版背景多了一道矮砖墙**，与主-01 的小院近似（图生图带主-01 作画风参考的副作用），
而本图的用途是“另一个院子里的事”。**正文师话已用一句话交代**（“这一张跟小虎没关系，是另一个
院子里的事”），不构成误读；日后若重出本图，提示词可加“背景不要出现砖墙，用树木与灌木”。
- 其它问题：眉毛一高一低，未做到左右对称下压，但不影响整体表达。；背景出现矮砖墙，与提示词要求的『另一个院子』不完全一致。
