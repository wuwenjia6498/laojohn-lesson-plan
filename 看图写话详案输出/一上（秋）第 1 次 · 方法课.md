# 学会看图——图上有什么
###### 一上（秋）· 第 1 次 · 方法课 · 看图写话详案

## 教案提纲表

**一、本课定位**

| 课次·课型 | 一上（秋）第 1 次　│　方法课（纯口头）　│　两节连排 2×45 分钟 |
| --- | --- |
| 学期主题 | 一上·敢说敢写——说清楚，写完整一句话 |
| 能力线 | 观察线：图上有什么（本课） → 三素句 → 四要素 → 细节四问 → 按方位看 |

**二、本课要点**

| 教学内容 | 看图说清三样——**谁、在哪里、做什么**；把一句话说完整、说通顺。配套三件：有顺序地看（先看正在做事的→旁边大的→地上小的）、一句话接着往下说成一小段、把“看到的”和“我猜的”分开说。 |
| --- | --- |
| 学习目标 | 能当众说完整一句，进而**连说 2～3 句小片段**（口头，本课不动笔）。 |
| 教学准备 | **图**：男孩玩纸飞机（主-01 主图·有顺序看与口头示范）＋追纸飞机（练-01 练笔图·人人独立说）＋备-01～04 练说图；**卡**：三素句结构条小卡，人手一张。 |

**三、与校内的关系**

| 对应教材 | 统编 一上·园地一 口语交际《我说你做》 |
| --- | --- |
| 校内学情起点 | 说话时声音洪亮、吐字清楚，别人说话时认真听；能看图说清“谁做什么”；辅：园地六“有顺序地观察图片”。 |
| 本课提升点 | 同步（对齐校内）：先说清楚、说完整，不提前动笔。 |
| 教学边界 | 时间四要素、三段式、细节四问——纯口头课，动笔从一上第 5 次《三素句起步》开始。 |

## 第1课时 · 从“照片里的故事”学习三素句表达

**本课目标**：降低当众开口的恐惧，让每个孩子敢说、说出“谁／在哪儿／在做什么”。

（注：本课先说够、最后才归纳“三样”——先记格式容易变成填格子，结论要让学生自己发现。）

### 环节一 · 你带来的照片：讲讲照片里的事（15 分钟）

〔课前准备〕上课前一天，可请家长和孩子一起选一张日常生活照片（吃饭、玩耍、出游都行）带来；没带的孩子发**备-02 或备-03**替代（不发备-01——那张老师马上要当示范图讲，发了等于让他复述示范），谁都不落下。到环节四全班看这几张图时，请他改说一张自己没说过的。

师：小朋友们，今天这节课，我们不看书，也不写字。我们来看一些照片。你会发现，看图说话其实你早就会了。

师：我们先来看一张照片，看看照片上有什么。老师先说一张。

〔出示备-01〕

【图位:备-01】

师：你们看——这张照片里，有**谁**呀？

参考：一个小女孩。

〔应答·答成妈妈或小猫〕这张图上小女孩、妈妈、小猫都在，孩子答“妈妈”“小猫”都很常见——

师：你也找到了一个“谁”，观察得真好。这张图上有好几个“谁”呢——小女孩、妈妈，还有一只小猫。今天我们**先说站在小凳上的那个小女孩**，一会儿再说别人。

参考：小女孩。

〔应答完〕

师：对，一个小女孩。那她在**哪里**呢？

参考：在厨房里。

〔应答·学生答不到点上〕学生若答“在她家”——

师：对，是在她家。那再看看，是她家的哪一间屋子呢？你看看她身边有什么。

参考：有水池、有青菜。

师：所以是——厨房。我们把话说得再准一点：“在厨房里”。你再说一遍试试。

〔应答完〕

师：第三样，她**在做什么**？

参考：在洗菜／在帮妈妈洗菜。

（教师总结）

师：你们看，老师问了三个问题——**谁？在哪里？做什么？** 把这三个答案连起来，就是一句完整的话：“一个小女孩在厨房里帮妈妈洗菜。”这就叫“说清楚一句话”。

引导句式：**谁 + 在哪里 + 做什么。**

〔同桌先互说一遍·人人出声〕

师：现在请你拿出自己带来的那张照片，转过身，说给你的同桌听——就用刚才这三样：谁、在哪里、做什么。**你们两个人的照片不一样，所以听的那个要认真听，他说的你可没见过。** 两个人都要说到，谁先说都行。

- 教师在行间走一圈听，听到说全三样的当场点名表扬一句，暂不纠错。**这是全课唯一一次能一次听遍全班的时刻，教师顺便记下哪些孩子已经能独立说齐三样——下一环节派任务要用。**

〔小提醒·像园地一玩“我说你做”那样，说得让人听清〕

师：课本上有个游戏叫“我说你做”，一个人说、大家照着做。说的那个人得**声音洪亮、把话说清楚**，听的人得**认真听**，不然就做错了。今天我们说照片也一样。**说清楚、让同桌听得清**，先愿意开口，说错了没关系。

### 环节二 · 轮到你说：每人对同桌讲一遍（10 分钟）

师：现在轮到你们了。请带了照片的小朋友举起你的照片，老师帮你一起看。

〔轮流说照片〕

- 请带了照片的孩子上来（或在座位上举起照片），老师用“谁？在哪儿？在做什么？”三问帮他说清。**每个孩子只要能说出这三样，就大声表扬。**
- **本环节只请 4 人**（每人约 2 分钟）——人人开口已由环节一同桌互说保证，这里重在示范与鼓励，不必人人上台。

师：（对说得吞吞吐吐的孩子）没关系，我们一件一件来。先说第一件。照片上有谁？

〔应答·只说了一个词〕学生若只答“妈妈”——

师：很好，找到“谁”了，是妈妈。那妈妈在哪里呀？

参考：在公园／在家里。

师：妈妈在做什么呢？

参考：在推我／在拍照。

师：现在把三样连起来，跟老师说一遍：“妈妈在公园里推我荡秋千。”你自己再说一遍。

〔应答完〕

〔应答·跑题说别的〕学生若说起照片以外的事（如“这个碗我家也有”）——

师：你观察得真细，还看到了碗。不过今天我们的任务是说清楚**这张照片上正在发生什么**。你再看看，照片里的人在做什么？

〔应答完〕

- 说不完整没关系，老师补一句、再请他跟说一遍——**本环节首要目标是敢开口，不是说得漂亮。**
- **换一个任务**：环节一巡听时记下的、已经能独立说齐三样的孩子，这一环节请他做另一件事——

师：（对这几个孩子）这次老师不问你了，你自己从头到尾说一遍试试——谁、在哪里、做什么，一口气说完，中间不用等老师。

- 派任务只说“换一件事做”，**不说“你已经会了”“你比别人快”**——避免当众分级。（帮同桌检查的任务放在下一环节，此处不叠加。）

### 环节三 · 一句话三样：谁、在哪里、做什么（5 分钟）

师：刚才每张照片，老师都问了哪三个问题？我们一起说——

参考：谁？在哪里？做什么？

师：这三个问题，就是我们看图说话的**三样**。

〔三素句结构条〕（课前印好并发到每人桌上，每人一张小卡，接下来几次课随身留用）

```
┌─────────────────────────────┐
│   说清一句话 · 三素句          │
│   谁  →  在哪里  →  做什么       │
└─────────────────────────────┘
```

（教师总结）

师：看到一张图，先找“谁”，再找“在哪里”，最后找“做什么”。三样都说到，句子就完整了。这张小卡请你收好，接下来好几次课我们都要用它。

### 环节四 · 换三张图：再把三样说一遍（15 分钟）

〔轮流练说·备选图〕

（注：三张图各练一个难点——两个人的图练“谁”说全，动物图练“不是人也可当主角”，群像图练“主角怎么选”，不是同一道题做三遍。）

**备-02·两个小朋友在公园里玩大皮球**

〔出示备-02〕

【图位:备-02】

师：第一样——这张图上有**谁**？

参考：两个小朋友。

师：注意听，刚才这位小朋友说的是“两个”小朋友，不是“一个”。图上有几个人，我们就要说清几个人。谁能把这三样连起来说一句？

参考：两个小朋友在公园里玩一个大皮球。

**备-03·小猫在窗台上晒太阳**

〔出示备-03〕

【图位:备-03】

师：这一张有点不一样。第一样——**谁**？

参考：一只小猫。

师：小猫不是人，也可以当我们句子里的“谁”吗？

参考：可以。

师：当然可以。图上正在做事的那一个，就是我们的“谁”，是人是小动物都行。那它在哪里、在做什么？

参考：一只小猫在窗台上晒太阳／在窗台上睡觉。

**备-04·一群小朋友在教室里读书**

〔出示备-04〕

【图位:备-04】

师：这张图上人可多了。这时候“谁”该说谁呢？

参考：小朋友们／一个小男孩。

师：两种都对。你可以说一大群人——“小朋友们在教室里读书”；也可以挑出你最想说的那一个——“一个小男孩在教室里读书”。**你想说谁，谁就是主角。**

师：那你挑的那一个，他在做什么？跟旁边的小朋友一样吗？

参考：他也在读书／他低着头看书，旁边那个抬起头了。

师：挑好了一个，就把他做的事说清楚。别人做什么，今天先不管。

- 每图请 2～3 人。鼓励说出**不同的说法**，谁说得跟别人不一样，就表扬谁。
- **换一个任务**：上一环节已能一口气说完的孩子，这一环节再加一件事——

师：（对这几个孩子）这三张图，你连着说三句，中间不停。说完了，再听你同桌说一遍，帮他数数三样齐不齐、少了哪一样。（注：连着说三句只是“一句接一句”，**不提示“先……后来……”这类顺序词**——把两幅图按先后顺序讲成一件事是一上第 3 次《会讲：把图讲成小故事》的训练点。）

- 也可以在三素句后面多加一点点（如“读得很认真”），但不强求、不点评“细节”概念（留到二上《细节四问》再学）。

（教师总结）

师：今天我们学会了看图说话的三样——谁、在哪里、做什么。下节课，我们要把说出来的话，说得更清楚一点，还要试着一口气多说几句。

**（本课完）**

## 第2课时 · 把你说的，讲给大家听

**本课目标**：对一张主图做**有顺序的观察**，把三素句说完整、说通顺，并能连着说 2～3 句小片段；再换一张新图（追纸飞机）人人独立说一遍（仍为口头，本课不成篇书写）。

### 环节一 · 按顺序看图：从做事的人看到地上的小东西（15 分钟）

〔出示主-01·男孩玩纸飞机图〕

【图位:主-01】

师：小朋友，看这张图之前，老师教你一个“有顺序看”的好方法——**先看正在做事的，再看旁边大的，最后看地上小的。**

〔先按顺序扫一遍图·再说三素句〕

（注：先扫图、后说句，两件事分开——一上来就三问，学生会直接跳到答案，观察顺序就练不到。）

师：我们先不着急说话，先按顺序看一遍。第一步，先找**正在做事的那个**，再看看他正在做什么。图上谁在动？

参考：一个小男孩。

〔应答·学生抢着说出整句〕孩子多半会直接喊出“一个小男孩在草地上玩纸飞机！”——

师：你一下子就把整句话说出来了，很厉害。不过我们这一次先玩“慢镜头”：一样一样地看，看完再说。你先只告诉我，正在做事的是谁？

〔应答完〕

师：好，那再看看他的手，还有他前面。有什么？

参考：纸飞机！／他的手伸出来了。

师：对，他两只手向前伸着，纸飞机刚从他手里飞出去，就飞在他前面。人和他在做的事，这就算看清了。

师：第二步，眼睛往**旁边**移一移。旁边有什么大东西？

参考：一棵大树。

师：第三步，最后看**小的**。低下头看看地上，草地上有什么？

参考：小黄花。

师：我们一起数一数，草地上一共有几朵小黄花？

参考：3 朵。

师：你们看，就这三步看下来：先看正在做事的，再看旁边大的，最后看地上小的。这张图上的东西，我们是不是一样都没漏掉？**这就叫有顺序地看。** 以后拿到一张图，都先这样扫一遍。

〔再按三素句三问，说成一句话〕

师：看清楚了，现在来说。第一样——**谁**？

参考：一个小男孩。

师：第二样——他**在哪里**？

参考：在草地上。

师：你从哪里看出来的？

参考：有草／有大树，还有小黄花。

师：说得好，你不是猜的，你是**看出来的**。草地、大树、小黄花都看到了，所以是在草地上。

师：第三样——他**在做什么**？

参考：他在玩纸飞机／他刚把纸飞机放出去。

师：再看仔细一点，他脸上是什么样子？

参考：他在笑／他很开心。

（教师总结）

师：把这三样连起来说：“一个小男孩在草地上开心地玩纸飞机。”是不是就说清楚了？

### 环节二 · 一句变几句：接着往下说（15 分钟）

师：刚才我们说的是一句话。现在我们来玩“句子长大”。先说一句，再多说一两句，让它变成一个小片段。

〔第一拍·先请学生说〕

师：还是这张图，谁能不光说一句，再多说一两句？想到什么说什么，说错了没关系。

- 先请 2～3 人自由多说两句，**老师先不示范、不纠正**，只把他们说的记在心里，一会儿要用。

（注：这一拍必须在示范之前——先示范，学生就只会复述老师的句子。）

〔第二拍·教师示范这条梯子〕

（教师口头说明，学生看手上的结构条小卡，在卡片下方一栏对照）

引导句式：
```
先说说天气、周围什么样   （开个头）
       ↓
谁 + 在哪里 + 做什么。   （第1句，说清楚）
       ↓ 再多说一两句 ↓
他看起来怎么样？  你猜他心里想什么？   （口头拓展，可以说“我猜……”）
```

师：听老师说一遍，你数数老师说了几句。

【教师示范例文】

> 草地绿绿的，还开着小黄花。（第1句：先说周围什么样，给句子开个头）
> 一个小男孩在草地上玩纸飞机。（第2句：这三样，把事情说清楚）
> 他笑得很开心。（第3句：他看起来怎么样，把样子说出来）
> 我猜，他一定希望纸飞机能飞得高高的。（第4句：我猜的，不是看到的）

师：听出来了吗？前面三句都是我**看到的**，最后一句是我**猜的**。看到的和猜的，我们要分开说。猜的要说“我猜”“可能”。

〔应答·把猜的说成看到的〕学生若说“他妈妈在家里等他”——

师：这个想法很有意思。我们一起看看图——图上有妈妈吗？

参考：没有。

师：图上没有妈妈，所以这一句不是你看到的，是你**想到的**。想到的要怎么说？

参考：我猜……

师：对，你再说一遍：“我猜，他妈妈在家里等他。”这样一说，我们就知道哪句是图上有的、哪句是你想的了。

〔应答完〕

〔第三拍·请刚才那位同学再说一次〕

师：（请第一拍说过的孩子）你刚才说得已经很好了。现在照着老师这个梯子，再说一次试试。

师：（听完后）你自己听听看。跟你刚才那一次比，这次哪里不一样了？

参考：多说了天气／多说了他很开心／最后加了“我猜”。

师：对，这句是你自己说长的，老师没替你说。

〔学生练说〕

- 再请 3～4 人各说一小段（看到的 1～2 句 ＋“我猜”1 句），老师帮补顺。
- 说不出“我猜”那句的孩子，可以只说前两句，达标即表扬。
- **换一个任务**：刚才已经能独立说出一小段的孩子，请他再做一件事——

师：（对这几个孩子）你这一小段说得很完整了。再看一眼第1课时的那张图（备-02），把它也说成一小段——两幅图连着说，中间不停。

### 环节三 · 两人一组：人人说清一张图（15 分钟）

师：这两节课，每个人都要开口说一次。这一次我们**两个人一组说**，一个说、一个听。听的那个要听清他这三样说齐了没有。

〔换图速看·只问不判（1~2 分钟）〕

师：不过我们要换一张新图。刚才那张是纸飞机刚飞出去，这一张是**下一刻**——看，发生了什么？

【图位:练-01】

师：谁在动？

参考：还是那个小男孩。

师：他在干什么？

参考：在追纸飞机／纸飞机飞走了，他跑着去追。

师：他在哪里？

参考：还在草地上／大树旁边的草地上。

师：好，三样都在图上找得到。这一张就是你们一会儿要说的图。不用现在说完整，留着一个一个说。（这里只带着看，不判过关）

〔第一步·先扫图，再说话（2 分钟）〕

师：说之前，先用刚才学的方法，把这张新图自己看一遍——**先看正在做事的，再看旁边，最后看地上小的东西**。看完了再开口。

- 学生各自默看一遍（这一次由学生**独立**扫图，老师不带）。教师提醒一句：“不着急说，先看全了。”

〔轻检查·看看是不是真扫到最后一步〕

师：看完了的小朋友先别说话。用手指一指，你**最后**看到的那个最小的东西在哪儿。

- 教师环视一圈即可判定：手指向草地上那几朵小黄花的，说明四步走完了；一眼就抬头等着说话的，请他再看一遍地上。（约 30 秒，不点名、不评判。）

〔第二步·同桌互说互补（4 分钟）〕

- **人人开口**：同桌两人轮流说**这张新图**，每人完整说一遍三素句；听的一方负责数“三样齐了吗”，少哪样就帮补哪样。**两人说的是同一张图，听的人正好当检查员**——他也刚看过，一听就知道漏了哪一样。**开口面靠同桌形态保证，不靠逐个上台。**

师：（示范怎么帮同桌补）比如他说“小男孩在追”。听的小朋友，你说说少了哪一样？

参考：少了“在哪里”／没说在草地上。

师：那你帮他补上。

参考：小男孩在草地上追纸飞机。

师：（对被补的孩子）好，你再完整说一遍，这次三样都在了。

师：现在开始，两个人都要说到。老师会走过来听。

- **换一个任务**：两人都说齐、老师听过的，请他再挑第1课时那三张图（备-02／备-03／备-04）里的一张说一段——同桌还没看过那张，正好当新听众。

〔第三步·抽查与点评 ＋ 全课收尾（8 分钟）〕

- 教师巡听后**抽 3 人**当众说一遍，逐个做过关判定与点评（每人约 70 秒，含点评）。
- 未被抽到的孩子，其“人人开口”已在同桌互说环节完成，不必再逐个上台。
- **“小老师”上台示范默认不做**——这一步还要留出三级评价、本课总结与课后布置的时间；只有当抽查明显提前结束时才加。

〔评价·三级〕

  - 基础：能说出与图有关的词语、愿意开口。
  - 良好：能用三素句说一两句完整的话。
  - 优秀：能连着说 2～3 句通顺的小片段，且把“看到的”和“我猜的”分开。
  （不打分、只口头鼓励。）

〔过关判定·怎么算说清楚了〕

| 判定 | 例句 | 说明 |
| --- | --- | --- |
| 不算过关 | “小男孩。” | 只有“谁”，没说做什么 |
| 不算过关 | “小男孩追纸飞机。” | 缺“在哪里”，三样不齐 |
| 算过关 | “一个小男孩在草地上追纸飞机。” | 三样齐、话完整 |
| 加分 | “一个小男孩在草地上笑着追纸飞机，我猜他想接住它。” | 加了样子，还分开了“我猜” |

“不算过关”不是批评：老师补上缺的那一件、请他**跟说一遍**，仍算当堂过关。

**换任务的孩子**（自己连说三样、三图连说、两幅图连说、说完新图再挑一张备选图说）以“加分”行为为达标线；其余孩子以“算过关”为达标线。

〔点评·怎么夸〕（先复述他的原话，再说好在哪，不说空泛的“你真棒”）

师：你说“一个小男孩在草地上追纸飞机”，三样你一口气都说到了，没让同桌提醒。

师：你说“他**笑着**追”。你多说了“笑着”两个字，我们一下就看见他的样子了。

师：你说“我猜他想接住它”，这句画上是没有的，是你**想出来的**，而且你说了“我猜”，说得很清楚。

师：（本课完 · 教师总结）这两节课，我们学会了看图的“三样”——谁、在哪里、做什么，还会有顺序地看、连着说一小段。**记住：看到的说清楚，猜的说“我猜”。** 下一次，我们还要看新的图，每个人至少说两幅，说给同桌听，请他帮你数一数三样齐不齐。（预告一上第 2 次 会看练习课，不展开）

〔课后·好句本〕

师：回家以后，请你找一张家里的照片，用这两节课学的三样，说给爸爸妈妈听一遍。说完，请你准备一个小本子，把你说得最好的那一句**请家长帮你记在上面**，你也可以在旁边画一画——这是我们的“好句本”，以后说图、写话都用得上。不用写、不用交，**说给家里人听一遍、记下一句**就算完成。（本课还没学写字，抄写等到一上第 5 次《三素句起步》动笔时再说。）

**（本课完）**

## 附：本课支架与说写格式小提醒

- **本课支架层级**：只发**基础层**（三素句结构条）；进阶层、创意层本课不发（加细节留到二上《细节四问》、想象成篇留更后）。
- **三素句结构条**（每人一张小卡，接下来几次课随身）：谁 → 在哪里 → 做什么。
- **撤架信号**：学生不看小卡也能说出完整三素句 → 撤卡，只用口头三问；到一上第 7 次《四要素：加上时间》再换新卡。**本课不做当堂撤架**——小卡今天才发下去，扣卡太早；**当堂撤架动作排在一上第 2 次“会看”练习课**（那时请学生把小卡扣过去、凭记忆说一遍再翻开对照）。
- **看到／猜到分开**：想象一律说“我猜”“可能”，不与画面事实混说。
- **课内分层（本课只发基础层，故靠“不同任务／不同图”实现）**：首轮说不齐的孩子由老师／同桌补一样、请他跟说一遍；已达标的孩子另派任务——自己连说三样不用逐问、听同桌说并帮他检查、两幅图连着说、说完练-01 再挑一张备选图（备-02／备-03／备-04）说。达标线见第2课时环节三过关判定。
- **本课不涉书面格式**（空两格／标点／田字格留到一上第 5 次《三素句起步》动笔时讲）——纯口头课次，免“写”不免“说”“评”，评价与过关判定完整保留。
