# 生图验收报告

- 源详案：`一上（秋）第 1 次 · 方法课.md`（期1《会看图上有什么》，原名 `一期-会看图上有什么-看图写话详案.md`）
- 生图模型：`gemini-3-pro-image-preview` · 验收模型：`gpt-4o` · 尺寸：4:3 2K

**汇总：2 图，2 过，0 需人工复核。**

## 例-01（例库图） — ✅ 过 · 生图 1 次
- [x] 画面能支撑句式「谁 + 在哪里 + 做什么」所述场景
- [x] 画面与「一个小女孩在厨房里帮妈妈洗菜。」一致
- [x] 满足验收条款：画面能支撑“小女孩 / 在厨房里 / 洗菜”；**妈妈须可见（在旁）**——正文参考答案含“帮妈妈洗菜”，妈妈缺席则该答案落空；**须有可见的水池（水槽＋水龙头）与青菜**——正文用“你看看她身边有什么”追问地点线索，参考答案为“有水池、有青菜”，缺则该追问落空；**小女孩须看得见脸、不是背影**；**另须有一只小猫**（正文备了“孩子答成妈妈或小猫”的应答话术，猫缺席则该话术落空）；**窗外无黄叶红叶落叶**（初秋口径）；**小女孩须站在小凳上**——正文用“先说站在小凳上的那个小女孩”把主角与妈妈区分开，缺小凳则该指认落空。妈妈的具体动作不作要求（真图中妈妈同在洗菜，正文已按此改为“图上有好几个『谁』、今天先说小女孩”，不再用“谁在做事”作筛选条件）。

## 例-04（例库图） — ✅ 过 · 生图 1 次
- [x] 画面能支撑句式「谁 + 在哪里 + 做什么」所述场景
- [x] 画面与「一群小朋友在教室里读书。」一致
- [x] 满足验收条款：能说出“小朋友们 / 在教室里 / 读书”即可；**须能从人群里指认出单独一个孩子**（正文要练“一群人里怎么选主角”，人脸全部模糊或背影即不合格）；**画面无英文字样**；**画面中不得有任何一个孩子被书本或画框裁切成看不见头部**（曾出图前排孩子只见手与书、无头，低龄学生会当场追问）。
