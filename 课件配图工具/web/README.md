# 课件配图工具 · 本地单机版

跑在自己电脑上，浏览器开 `http://127.0.0.1:8848`。

```bash
pip install -r 课件配图工具/web/requirements.txt
PYTHONUTF8=1 python 课件配图工具/web/server/main.py
```

密钥读 `课件配图工具/.env`（与 CLI 同一份），右上角会显示当前通道与模型；
缺密钥时那里变红并说明原因，不会静默进假数据。

## 它和命令行是同一套东西

数据全部落在既有文件布局上，**没有另建数据库**：

| 存什么 | 落在哪 |
|---|---|
| 项目（风格卡 + 角色件 + 画面清单） | `课件项目/<项目>.json` |
| 定妆件 / 页目图 | `课件产出/<项目>/<通道>/角色·页目/` |
| 验收记录 | `课件产出/<项目>/<通道>/_验收记录.json` |
| 拆解中间产物 | `拆解底稿/` |

所以 **CLI 跑的项目 Web 能打开，Web 建的项目 CLI 能接着跑**。这是有意的：
命令行仍是排查问题最快的路子，产品化不该把它废掉。

服务端不含任何判据，拆解/生图/验收/导出全部 importlib 载入 `scripts/` 下那四个脚本；
规则库唯一源是 `拆解规则.md`，网页上只读展示。

## 两道闸门：定妆硬、页目软

- **定妆未验收 → 拒绝批量生成页目**（HTTP 409）。定妆图是后面每一页的人物基准，
  它错了这一批全得重来，这道门挡住的是成批的浪费。
- **页目验收不拦生成，拦导出**。生成随时可跑、可改可重出；但往外交付要有人签字。
- 验收一律要填姓名 —— 没有名字的验收等于没验收。

清单里的勾验框是给人自己对账用的，**机器不看**：比喻拆没拆、必现细节准不准、
画面对不对，程序判不了。

## 新建项目要传两份

**课件 pptx** 决定哪页要图、什么画幅（`extract_deck.py` 按面积占比量出来的，是事实）；
**教学详案** 决定画什么。少了 pptx 就只能让模型猜页码 —— 实测手抄清单错位 1–3 页。

详案带页标回注（`〖PPT 第6页 · …〗`）时会自动按页切段喂给模型，`来源` 字段就是照着抄；
没有页标则整篇喂，退化但不报错。

## 已知边界

- 单进程、任务状态在内存：**服务重启后正在跑的任务会丢**，重新发起即可（图已生成的不会重复扣费）。
- 没有登录、没有多用户。**同办公室共用看下一节**；异地给人用才需要对象存储 + 数据库 + 账号，那不是本版范围。
- 生图 30–60 秒一张，一律后台跑 + 轮询，界面显示逐条日志。


## 给同办公室的同事用（局域网）

同事不需要仓库、不需要装 Python、不需要密钥——他只开浏览器。
服务跑在**你的电脑**上，双击 `课件配图工具/启动配图工具-局域网.bat`（等价于加 `--lan` 参数），
启动时会把网址打印出来，把那个 `http://192.168.x.x:8848` 发给他。

**不加 `--lan` 就只听 127.0.0.1**（命令行直接跑就是这个）。安全默认不反过来：
这个服务没有任何登录，开放就意味着同网段任何人都能上传、生图（花你 `.env` 里那把密钥的钱）、
下载已有产出。办公室内网可以接受，不要把 8848 端口映射到公网。

四件事得知道：

- **头一次跑 Windows 会弹防火墙，勾“专用网络”并允许。**勾错了或点了取消，
  服务照跑、你本机照常打开，只有同事连不上，而且不报任何错——这是最容易卡住的一步。
  补放行（管理员 PowerShell）：
  `New-NetFirewallRule -DisplayName "课件配图工具" -Direction Inbound -LocalPort 8848 -Protocol TCP -Action Allow -Profile Private`
- **启动时打印的 IP 可能不止一个**，哪个能开用哪个。代理软件（Clash 等）的虚拟网卡
  会冒充成一个看上去正常的地址（`198.18.x.x`），已在代码里排掉。
- **IP 会变**。路由器 DHCP 重新分配后就不是原来那个了，同事突然打不开先看这里。
  固定下来要么在路由器绑 MAC，要么给本机设静态 IP。
- **任务状态在内存，别随手关窗口。**同事正跑到一半的批量生图会静默消失，
  他那边只看到界面一直转圈。已出的图不会丢、重新发起不重复扣费。
  反过来，你们两边同时用是不冲突的：每个任务各占一个后台线程，不排队。
