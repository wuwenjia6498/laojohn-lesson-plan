# 《猜猜他是谁》课件画面打样清单

> 三上·第一单元·校内同步写作（写人）
> 用途：逆向打样——对照已完成的课件成品图，检验本清单的结构与规则是否足以生成等效画面。
> 生成通道：Gemini 网页端手动执行（打样阶段）。每条 prompt 包可直接复制投喂，参考图按"挂载"栏手动上传。

---

## 一、风格基调卡（全课件一次）

| 项目 | 设定 |
|---|---|
| 画风档 | 水彩儿童插画：柔和水彩质感、干净留白、轮廓线细而松、色彩明快不艳 |
| 色板 | 环境色呼应品牌暖橙黄调（#F5A623 附近的暖光氛围）；人物服装用蓝色系（浅蓝毛衣、蓝白校服）与暖色环境形成对比 |
| 人物年龄设定 | 8—9 岁小学三年级学生，圆脸、头身比约 1:4.5，神态自然不夸张 |
| 场景基调 | 明亮的教室与校园：木色课桌、大窗、暖阳光 |
| 概念母题 | **剪影**——"猜猜他是谁"= 身份隐藏。封面、书封、装饰位统一用深蓝色（#3D4A6B 附近）人物剪影，剪影发型与主角色定妆保持一致 |
| 通用禁区 | 画面内不出现任何文字（中文渲染不可靠，文字信息一律由 PPT 版式承担） |

**通用风格前缀**（每条 prompt 开头拼接）：

```
儿童水彩插画风格，柔和笔触，明快干净的配色，暖黄色调光线，
主体人物为8到9岁的中国小学生，头身比约1比4.5，
背景适度留白，画面中不出现任何文字。
```

## 二、主角色定妆（先于所有页面图生成，须验收通过）

**主角色：推眼镜男孩**（本课唯一跨页复用角色，对应成品 P4 / P6，剪影母题同源）

| 定妆图 | Prompt 包 | 画幅 |
|---|---|---|
| 定妆 A · 正面标准像 | 〔风格前缀〕+ 一个8岁的中国男孩，短而蓬松的深棕色头发，戴一副圆框黑边眼镜，穿浅蓝色圆领毛衣、内搭白色衬衫领；正面半身像，微笑时眼睛眯成两条弯弯的缝，右手抬起用食指轻推眼镜；纯浅色背景 | 1:1 |
| 定妆 B · 动态姿势 | 〔风格前缀〕+ 同一个男孩（挂定妆 A 为参考图），坐在木色课桌前，桌上摊着一张作文稿纸和一支红色铅笔，他侧头微笑推眼镜，背景是有大窗和暖阳光的教室 | 1:1 |

**验收要点**：发型、镜框、毛衣三要素清晰稳定（后续所有复用页靠这三样认人）；笑起来"眼睛眯成一条缝"必须成立——这是课案文本里的原句特征。

**剪影转制**：定妆 A 验收后，同一发型轮廓转深蓝色纯剪影（胸像一张、全身背书包行走一张），供封面与装饰位使用。可用 Gemini 局部编辑（形状/风格类改动可靠）或直接矢量描摹。

## 四、生成与验收顺序

1. **定妆 A → 验收** →（剪影转制）→ **定妆 B / P4 风格锚 → 验收**
2. 剪影族：P1 / P5 / P8 / P9（转制为主，生成量小）
3. 主角色族：P6 → P13 → P19 → P20（每张挂定妆 A + 风格锚，逐张目检"是不是同一个孩子"）
4. 内容角色：P16（对照文案细节逐条勾验——五条必现细节缺一即返工）
5. 道具：P21
6. 另处理位：P3（人工素材）

**打样建议的最小验证集**：定妆 A、P6（跨页一致性）、P16（文案细节锁定）、P1 剪影转制——四张跑通，清单结构即视为成立。

## 五、已应用的既有经验规则（备忘）

- 数量控制不靠禁止式表述，用"画面中恰好 N 个"正向写死（P13、P20）
- 头身比不靠文字控制，靠定妆图参考传递
- 形状/风格类改动可用局部编辑（剪影转制），数量类改动不用局部编辑
- 画面内一律无文字，文字信息全部由版式层承担（P5、P19 稿纸用波浪线示意）
- 淡化、裁切、透明度等排版级处理在排版端完成，不进生成 prompt（P9）
