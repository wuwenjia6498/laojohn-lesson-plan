## 课程信息

- **主题**：雨后菜地
- **阶段**：第二期 · 三段式——讲清一个小故事
- **年级**：一年级
- **课时**：两节连排，每节 45 分钟
- **本期一课一得**：给三素句加上「时间」，凑齐四要素（时间·地点·人物·事件），用三段式写清一个小故事。
- **不越阶**：本期不讲细节四方向（动作 / 表情 / 语言 / 心理，留第三期）；不讲多图串联。

## 教学目标

- 能看着图，用「谁——在哪里——做什么」说出三素句，再加上「什么时候」，说成完整的四素句。
- 学会当「图画小侦探」，从天空、水珠、菜苗等线索里推断出「这是什么时候」，并用圈画四步法在图上做记号。
- 能照三段式（写时间→写看到的→写心情）把一张图写成一小段话，做到开头空两格、标点不顶格、生字用拼音。

## 教学重难点

- **重点**：把「时间」找出来、加进句子，凑齐四要素。
- **难点**：从图里的线索（水珠、水洼、彩虹）推断「雨刚停」，并把环境与动作连起来写成第二段。

# 第 3 课｜让句子更完整——加上「时间」（45 分钟）

## 一、三素句复习 & 练习（15 分钟）

**师**：小朋友们，上一期我们学过一个方法，看一张图就能说出一句完整的话。这句话里有三个重点——「谁」「在哪里」「做什么」。我们给它取了个名字，叫「三素句」。今天老师先考考大家，看你们还记不记得。

【图位:例-01 — 见生图工单】

**师**：先看这张图，谁来说说看，这里有「谁」？他「在哪里」？又「在做什么」？

**引导句式**：（   ）在（   ）里，（   ）。

**参考**：小朋友在公园里放风筝。

**师**：说得真完整！我们把三个重点都说清楚了。再请一位小朋友，能不能换一种说法，把它说得更好听一点？

**参考**：一个小男孩在草地上，开开心心地放风筝。

**师**：你们听，加上「开开心心」，这句话就更具体了，对不对？我们再看一张。

【图位:例-02 — 见生图工单】

**师**：这张图里有「谁」？「在哪里」？「做什么」？同桌两个先互相说一说，等会儿请人来分享。

学生互动分享

**参考**：奶奶在厨房里做饭。 / 一位奶奶在厨房里，正在炒香喷喷的青菜。

**师**：（若时间充裕、想让更多小朋友开口，可再轮换出示例-05、例-06，每张请 2~3 人，鼓励说得各不相同。）

**（教师总结）**：看，只要找到「谁、在哪里、做什么」这三个重点，我们就能说出一句完整的话。可是——光有这三个，故事还差一点点。差什么呢？我们接着往下看。

## 二、学习四要素写话——给句子加上「时间」（20 分钟）

**师**：刚才的句子已经很好了，但是老师有个问题：这件事情，是「什么时候」发生的呢？是早上、中午，还是下过雨以后？我们的句子里好像还没有说。今天，我们就给句子再加一个重点——「时间」。加上它，句子就从三个重点变成了四个重点。

**师**：这四个重点合起来有个名字，叫「四要素」。我们一起读一遍。

**板书（四要素）**：

```
四要素 = 什么时候（时间）· 在哪里（地点）· 谁（人物）· 做什么（事件）
说的时候这样排：什么时候 → 谁 → 在哪里 → 做什么
```

**师**：可是图上又没有写字，我们怎么知道「什么时候」呢？这就要用上一个方法——当一个「图画小侦探」，从图里找「线索」。来，我们先练两张。

【图位:例-03 — 见生图工单】

**师**：小侦探们，看看这张图。你从哪里看出来这是「什么时候」？看看天空、看看小朋友穿的衣服。

学生自由分享

**参考**：天是亮亮的、太阳刚升起来，小朋友背着书包——是早上，要去上学。

**师**：太厉害了！你们没看到字，却从「太阳、书包」这些线索里，把时间猜出来了。再看一张，这张的线索藏在天空里。

【图位:例-04 — 见生图工单】

**师**：这张又是什么时候呢？提示你们看看天的颜色。

**参考**：天边红红的、太阳要落山了——是傍晚。

【图位:例-07 — 见生图工单】（可选 · 中午一档）

**师**：再加一张，这张的太阳跑到头顶上了，是什么时候？

**参考**：太阳当头、影子很短，小朋友在吃午饭——是中午。

**（教师总结）**：你们发现了吗？想知道「什么时候」，就去图里找线索——看天空（早上亮、中午太阳当头、傍晚红）、看景物（有没有雪、有没有水珠）、看人穿什么、在做什么。这些线索，就是帮我们看出时间的好帮手。

**师**：现在，老师把今天真正要研究的那张图请出来。这张图里的时间线索特别多，看你们能不能把它们都找出来。

【图位:锚-01 — 见生图工单】

**师**：先别急着说时间。我们先用刚才的方法，找出「谁、在哪里、做什么」。谁来试试？

**参考**：小女孩在菜园里看青菜。

**师**：很好！「谁」是小女孩，「在哪里」是菜园，「做什么」是看青菜。那——这是「什么时候」呢？这张图里藏了好多线索，我们一个一个找。你看到菜叶上有什么？地上有什么？天上有什么？

学生自由分享

**参考**：菜叶上挂着亮晶晶的水珠；地上有一个小水洼；天上有一道彩虹，太阳刚从云里钻出来——一定是刚刚下过雨！

**师**：找到啦！亮晶晶的水珠、小水洼、那道彩虹，还有刚钻出云的太阳，都在悄悄告诉我们——「雨刚停」。所以这张图的「什么时候」，就是「下过一场雨以后」。我们把四个重点连起来说一遍。

**引导句式**：（什么时候），（谁）在（哪里）（做什么）。

**参考**：下过一场雨，小女孩在菜园里看青菜。

## 三、看图写话方法总结——圈画四步法（10 分钟）

**师**：当小侦探的时候，我们光用眼睛看还不够，还要拿起笔，在图上做记号，把四个重点一个一个圈出来，这样写的时候就不会漏掉。这个方法叫「圈画四步法」。

**板书（圈画四步法）**：

```
第一步：圈「谁」    —— 圈出主角（小女孩）
第二步：圈「在哪里」—— 圈出地点（菜园、菜地）
第三步：圈「做什么」—— 圈出动作（蹲下看、碰水珠）
第四步：圈「什么时候」—— 最后圈，圈出时间线索（水珠、水洼、彩虹、刚出来的太阳）
```

**圈画建议做法**：为了不圈乱，可以约定——「谁」用圆圈〇，「在哪里」用方框▢，「做什么」用波浪线～，「什么时候」用三角△。颜色不同更清楚。**「什么时候」放在最后圈**，因为它藏得最深，要先把人、地点、动作找全，再回头找出时间。

**师**：（教师在锚图上示范圈画一遍：圈出小女孩→框出菜园→画出蹲看的动作→最后用三角点出水珠、水洼、彩虹。）看，老师这样一圈，四个重点就都找全了。下一节课，就轮到你们自己当小侦探，亲手圈一圈、写一写。

**（本课完）**

# 第 4 课｜三段式写话，我来讲清一个小故事（45 分钟）

## 一、看一看圈一圈（10 分钟）

【图位:锚-01 — 见生图工单】

**师**：上节课我们学会了「圈画四步法」。现在，请每个小朋友拿出笔，看着这张雨后菜地的图，自己当小侦探，把四个重点一个一个圈出来。记住顺序——先圈「谁」，再圈「在哪里」，然后圈「做什么」，最后圈「什么时候」。

**圈画清单（学生独立完成，教师巡视）**：

- 〇 圈「谁」：小女孩。
- ▢ 框「在哪里」：菜园、一排排青菜。
- ～ 画「做什么」：小女孩蹲下来，碰一碰菜叶上的水珠；脚边放着小篮子。
- △ 点「什么时候」：菜叶上的水珠、地上的小水洼、天上的彩虹、刚钻出云的太阳——下过雨了。

**师**：（巡视提醒）找到时间线索的小朋友，悄悄举手告诉老师，你是从哪里看出来「下过雨」的？

## 二、说一说（5 分钟）

**师**：圈完了，我们先说后写。请你看着自己圈的记号，把四个重点连成一句完整的话，说给同桌听。

**引导句式**：（什么时候），（谁）在（哪里）（做什么）。

学生互动分享

**参考**：下过一场雨，小女孩在菜园里看青菜。

**师**：（请 2~3 人站起来说）说得越完整越好，别忘了把「下过一场雨」放在最前面。

## 三、写一写·三段式要领（25 分钟）

**师**：会说了，我们就把它写下来。今天写话有个好办法，叫「三段式」——分成三段，一段管一件事，这样写得清清楚楚。

**板书（三段式）**：

```
题目：写在第一行正中间（在干什么，就写什么）
第一段：什么时候，谁在哪里做什么。（只用两个标点：一个逗号、一个句号）
第二段：把看到的写具体——周围有什么（环境）+ 主角在做什么（动作）。
第三段：写心情、感受，可以加一点点合理的想象。
```

**师**：老师先写一篇给你们看，看看老师是怎么照着图、照着三段式写出来的。

### 【教师下水例文 · 示范】

> **题目：雨后的菜园**
>
> 　　下过一场雨，小女孩在菜园里看青菜。〔第一段：时间——「下过一场雨」，把四要素说全〕
>
> 　　青菜的叶子上挂着亮晶晶的水珠，地上有一个小水洼。小女孩蹲下来，轻轻碰了碰叶子上的水珠。〔第二段：细节——环境（水珠、小水洼）＋ 动作（蹲下、轻轻碰）〕
>
> 　　天上还有一道弯弯的彩虹。小女孩看着看着，开心地笑了。她心里想：雨后的菜园真好看呀！〔第三段：心情——「彩虹」来自图，「开心地笑了」写出了心情；「她心里想……」是图上看不见的心里话，属于合理想象，单独写出来〕

**师**：你们看，老师写的每一样东西——水珠、小水洼、彩虹——都是图上真的有的，老师没有乱编。只有「小女孩心里在想什么」是老师想象出来的，因为图上看不到心里话，那是我们替小女孩想出来的。

**师**：写之前，老师再给大家几张「词语卡」，遇到不会说的地方，就到卡片里挑一个词用上。

**词语支架卡（一年级，五类）**：

| 类别 | 可以用的词 |
|---|---|
| 时间 | 雨停了、下过一场雨、雨后 |
| 地点 | 菜园里、菜地里 |
| 环境（雨后景物） | 亮晶晶的水珠、小水洼、弯弯的彩虹、嫩绿的青菜 |
| 动作 | 蹲下来、看一看、轻轻碰、提着小篮子 |
| 情感 | 真开心、好高兴、笑了起来 |

**填空模板（写不出来的小朋友可以先照着填）**：

```
题目：__________

　　__________，__________在__________看青菜。
　　（填——什么时候 / 谁 / 在哪里）

　　青菜上挂着__________，地上有__________。小女孩蹲下来，__________水珠。
　　（填——环境 / 环境 / 动作）

　　天上有__________，小女孩__________。
　　（填——环境 / 心情）
```

**写话格式小提醒**（写之前一起读一遍）：

- 题目写在第一行正中间。
- 每一段开头**空两格**。
- 标点符号**不顶格**（不写在一行最前面），句子结束要打句号。
- 遇到不会写的字，先用**拼音**代替，不空着。

**师**：好，现在请大家照着自己圈好的图，先在心里说一遍，再一段一段写下来。写不出的地方就翻词语卡、看填空模板。老师来回看，谁需要帮忙就举手。（学生写作，教师巡视；提醒空两格、标点不顶格、生字注音。）

【图位:格-01 — 见生图工单】（田字格书写示范，回插时插入）

## 四、分享点评（5 分钟）

**师**：写完的小朋友，先自己小声读一遍，听听通不通顺，有没有漏掉「什么时候」。然后我们请两位小朋友上来读一读。

学生互动分享

**师**：（点评看三点）①四个重点全不全，尤其有没有写出「什么时候」；②第二段有没有把看到的水珠、水洼写具体；③有没有写出小女孩的心情。

**（教师总结）**：今天我们又学会了一个方法——给句子加上「时间」，凑齐了四要素，还学会用三段式把一张图写成一小段话。下次再看到一张图，别忘了先当小侦探，把「什么时候、在哪里、谁、做什么」都找出来，再一段一段写清楚。

**（本课完）**
