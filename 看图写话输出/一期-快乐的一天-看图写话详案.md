# 《快乐的一天》看图写话详案（一期 · 看图说话起步）

> ⚠ 待生图回插：本详案依赖文末「生图工单」里的图位规格。回插前请按每个图位的「必须可见元素清单」逐项验收；缺项就重做图或回改详案，确保「真图＝规格＝正文」三者一致。
> 「照片故事」环节用**教师/家长自备的真实生活照片**（每生不同），不进生图工单、不 AI 生成。

---

## 课程信息

- **期数 / 模块**：第一期 · M1 看图写实（句到段）· 起步档
- **训练重点（一课一得）**：三素句「谁—在哪里—做什么」，从口头表达过渡到规范书面表达
- **课标依据**：留心观察周围事物，写自己想说的话
- **题材**：人物活动（日常玩耍 / 生活小事）
- **适用年级**：一、二年级（支架强度分档，见各环节）
- **课时**：两节连排，每节 45 分钟
- **不可越阶**：本期不讲「时间 / 四要素」、不讲三段式分段、不讲细节四方向——只把一句话说清、写规范；口头可加一点「怎么样 / 什么心情」的轻想象，不进书面分段

# 第 1 课｜从照片和图画里，学说三素句（45 分钟）

**教学目标**：激发兴趣、降低写话恐惧；会用「谁＋在哪里＋做什么」口头说清一幅图，并能顺着画面多说一两句。

## 一、讲出你的照片故事（25 分钟）

【图位：照片故事 — 教师/家长自备真实生活照片，不生图】

师：这节课我们不看书，也先不写字。我们来看几张照片——都是小朋友自己生活里的照片。你会发现，看图说话呀，你早就会了。

> 课前准备：请家长和孩子一起选一张孩子喜欢的、有故事的日常照片（玩耍、过生日、和家人在一起都行），课前发给老师；课上轮流出示。没带照片的孩子，可用老师准备的几张趣味照片。

师：（出示一张照片）你看到了谁？他在哪儿？他在做什么？

**分层追问示范**——同一张照片，老师不是问一句「谁 / 在哪里 / 做什么」就停，而是顺着孩子的回答一层一层往下带（一年级问到第 1 层，二年级加第 2–3 层，学有余力到第 4 层；每张照片挑合适的层次问，不必都问全）。下面用两类常见的生活照片举例，老师用手头类似的照片即可：

照片示例一（一个小男孩蹲在地上，把一朵小花递给身边的人）：
- ①谁 / 在哪里 / 做什么：一个小男孩蹲在地上，把花递给别人。
- ②抠一处细节：他的表情怎么样？——他笑得很灿烂，又有一点点害羞。
- ③轻推心情：你觉得他现在心里高兴吗？为什么又有点不好意思呢？
- ④引一点想象：他可能把花送给谁呀？是在什么情况下送的？（请学生顺着画面编一小段：也许他和妈妈一起去公园，找到一朵小花，很开心地送给妈妈。）

照片示例二（一个小男孩坐在椅子上，怀里抱着一只小狗，闭着眼睛）：
- ①谁 / 在哪里 / 做什么：一个小男孩坐在椅子上，抱着一只小狗。
- ②抠一处细节：男孩的眼睛是睁着还是闭着？小狗呢？——男孩闭着眼睛好像睡着了，小狗却睁着眼睛。
- ③轻推心情 / 关系：屋里是不是很安静？他们俩看上去关系怎么样？——很放松、很亲密。
- ④引一点想象：他们可能刚一起做完什么，才这么舒服地靠在一起？

> 一年级：只问第 1 层，老师把孩子说的关键词板书出来（谁 / 在哪儿 / 做什么），帮他把话说完整。
> 二年级：加第 2–3 层，鼓励一口气说完整一句，再试着多说一两句。
> 学有余力：到第 4 层，顺着画面编一小段合理的想象。

师：（请几位同学说自己带来的照片）谁愿意来讲讲你照片里的故事？先告诉大家照片里有谁、在哪儿、在做什么，再说说他是什么表情、什么心情。

引导句式：
- 我和妈妈在草地上野餐，我们吃得很开心。
- 我和好朋友在沙滩上堆城堡，堆得又高又大。
- 我和小狗在公园的草地上玩飞盘，它跑得可快了。

（教师总结）每张照片里，都藏着三个重点：谁？在哪里？做什么？把这三点说清楚，再加一点他是什么样、什么心情，就把照片讲得又清楚又生动了。

## 二、看图说话一点也不难：三素句结构分享（20 分钟）

师：其实看图说话一点也不难，就像刚才讲照片一样——每一幅图上都有三个重点：谁？在哪里？做什么？找到这三点、说清楚，就完成了最基本的看图说话。

板书 / 投屏（三素句结构）：

```
谁？   →   在哪里？   →   做什么？
```

师：我们来当一回「图画小侦探」，看图找这三点。这里有好几幅图，我们一幅一幅来，比比谁说得不一样。

【图位：例-01 ~ 例-07 — 见生图工单】

师：（依次出示下面各图）这幅图里有谁？在哪里？在做什么？谁来说？

各图练说要点（每幅请 2~3 位同学说，鼓励用不同的词、把「做什么」说得更清楚一点）：
- 例-01：一个小女孩在沙滩上堆城堡。
- 例-02：一个小男孩在花园里浇花。
- 例-03：一个小女孩在公园里荡秋千。
- 例-04：一个小男孩在草地上踢足球。
- 例-05：一群小朋友在操场上玩老鹰捉小鸡。（多角色，挑一个主角说清楚，如「一个孩子当老鹰去追大家」）
- 例-06：一群小动物在森林里开音乐会。（趣味练说，说说是哪些小动物、它们在做什么）
- 例-07：一只小猫在水边，看着自己在水里的影子。（可以想一想：它看到了什么？）

> 一年级：可只说「谁＋做什么」，老师帮着补上「在哪里」。
> 二年级：三点都说全，试着再加一句他怎么样（如「他踢得满头大汗」「小动物们玩得真开心」）。
> 多角色的图（例-05 ~ 例-07）不用把每个都说到，挑一个主角说清楚就好。

（教师总结）看到一幅图，只要找到「谁、在哪里、做什么」，把这三点连起来，就能说出一句完整的话。下节课，我们一边说，一边把它写下来。

（本课完）

# 第 2 课｜把你说的，写下来（45 分钟）

**教学目标**：巩固三素句；掌握规范写话格式（空格、标点、拼音）；完成从口头到规范书面的过渡。

## 一、看图口头练三素句（15 分钟）

【图位：锚-01 — 见生图工单】

师：（出示锚-01）我们先来当小侦探，看清楚这幅图：图上有谁？他在哪里？在做什么？

板书 / 投屏：

```
谁？        在哪里？        做什么？
一个小男孩    在草地上        放风筝
```

师：我们一句一句来，从最简单的说起，一点一点把话说长。

口头句式（多轮练说）：
- 基础句：一个小男孩在放风筝。
- 三素句：一个小男孩在草地上放风筝。
- 感情拓展句：他一边放风筝，一边开心地笑，好像在和风筝比谁飞得高。

**说一段小片段 · 教师逐句示范**——先请学生自由多说两句，老师再照下面这条「梯子」示范怎么把一句话说成一小段（括号里是给老师看的说明，不用念给学生）：

1. （先说环境天气）今天天气真好，蓝天上飘着几朵白云。
2. （再说三素句核心）一个小男孩在公园的草地上放风筝。
3. （说他怎么样）他一只手牵着风筝线，仰着头，看着高高的风筝。
4. （最后加心情）风筝飞得高高的，他笑得真开心。

师：你看，还是这一幅图，我们从一句话，慢慢说成了四句话的一小段。现在请你也照着这样，先说一句完整的，再试着多说一两句。

参考：一个小男孩在公园的草地上放风筝，他仰着头，笑得很开心。

> 一年级：板书三素句结构条不擦，孩子照着填着说，说清一句即可。
> 二年级：试着照上面的「梯子」说一段 3~4 句的小话（先说后写做准备）。

## 二、规范讲述：写话注意事项（10 分钟）

师：接下来，我们要把刚才说的话写下来。写话有几条小提醒，请记牢。

板书 / 投屏（写话小提醒）：

```
* 开头空两格
* 一句话没说完写逗号，说完了写句号（或问号、感叹号）
* 标点符号不顶格写
* 不会写的字用拼音，不写错别字
```

【图位：格-01（田字格）— 固定资产，见生图工单】

师：（出示田字格）我们先看老师怎么在田字格里写，注意每个字、每个标点的位置。

> 实操：学生在田字格里抄写一句三素句示范句，写完同桌互评是否符合写话格式，不规范的当堂订正。

## 三、说一说，写一写（20 分钟）

师：现在轮到你了。还是这幅图（出示锚-01），先说一说，再写下来。记住：先说后写。

【图位：锚-01 — 见生图工单】

步骤：
1. 看图说话：用「谁＋在哪里＋做什么」说一句完整的话（先口头说给同桌听），二年级可照上节的「梯子」多说一两句。
2. 田字格写下：把你说的这句话，按写话小提醒写在田字格里。
3. 朗读分享：请 2~3 位同学读一读自己写的句子。

教师点评重点：
- 三素句是否完整（谁、在哪里、做什么有没有说全）；
- 是否规范书写（空两格、标点、拼音）；
- 是否清楚、有趣。

> 一年级：写一句完整的三素句即可，可给关键词卡（小男孩 / 草地 / 放风筝）。
> 二年级：在三素句后面再加一句「他怎么样」，把话说得更完整。

师：（出示下方下水例文，示范抄写）我们来看老师写的一小段，请按原样规范地抄一遍，巩固写话格式。

【教师下水例文 · 示范】（锚于锚-01，只用清单内画面）

> 一个小男孩在公园的草地上放风筝。他一只手牵着风筝线，仰着头，看着天上的风筝。风筝飞得高高的，他笑得真开心。

（教师总结）这节课，我们学会了看一幅图，找到「谁、在哪里、做什么」，先说清楚、再规范地写下来。下一次，我们会试着说得更多、写得更长。

（本课完）

## 照片故事（不生图）

教师 / 家长自备的真实生活照片（孩子日常玩耍、过节、和家人在一起等），每生不同，课前收集、课上轮流出示。**不进生图工单、不 AI 生成**——真实照片是「降低写话恐惧、联系自己生活」的有意设计。第1课「分层追问示范」里举的两张示例照片（递花、抱小狗）也是这类真实生活照片，老师用手头类似的照片即可，不必照搬。
