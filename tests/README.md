# tests · tone_gate 回归夹具

本目录的 `.md` **是机检回归夹具，不是详案产物**。

- **用途**：给 `tone_gate.py` 提供可复现的回归基线。新增/修改机检项后，跑一遍夹具确认新规则真的命中、旧规则没被改坏（2026-07-29 一次改动曾误删 `variation-pools.md` 的一个节标题、导致「禁止逐字复用」解析静默归零，就是靠比对基线当场抓出来的）。
- **不参与任何下游流程**：不进台账重建（SKILL 第 7 步只扫 `写作课详案输出\`）、不进批次横审（`batch_ngram_scan.py` 默认 `--dir 写作课详案输出`，`glob` 非递归，扫不到这里）、不出 docx、不打包。
- **指纹块已剥除**，不会被误当成一篇存量稿计入反同质化统计。
- **绝不要把夹具复制进 `写作课详案输出\`**，也不要拿它当写作参考——夹具往往是**故意保留缺陷的改前原稿**。

跑法：

```
PYTHONUTF8=1 python tone_gate.py tests\<夹具文件>.md --profile writing
```
