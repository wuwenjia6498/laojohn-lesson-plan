# 《续写故事》· 写作课教学设计
三年级上册·第三单元 校内同步写作

[授课提示：本课所用“前三幅图”为便于教学设计、依看图续写常见题材自拟的示例场景（星期天，朵朵在院子里发现一只被丢弃的小奶狗，妈妈起初不同意收养）。请老师改用教材本单元实际提供的三幅图，并据实际图画内容，相应调整推测方向、构思示范与教师示范文——教学步骤与技法讲法不变。]

## 核心素养教学目标

【语言运用】能承接前面三幅图的内容，把故事的经过和结局续写完整、写通顺；学会在开头用一两句话照应前文，让续写接得自然。

【思维能力】借助图中人物的表情、动作和对话等信息，合理推想故事的发展，做到既不脱离前文、又能想出不止一种可能。

【审美创造】在续写中加入人物的动作、语言和心里的想法，把最要紧的一幕写得生动，感受“同一个开头能长出不同故事”的乐趣。

【文化自信】愿意把自己想出的结局讲给同学听、投进班级的故事征集，在互相分享中体会想象和表达带来的快乐。

## 第1课时 · 写作指导课

### 一、创设情境，明确任务（约8分钟）

[出示前三幅图，先不讲解，让学生自己看两眼。]

师：老师这儿有一个故事，可奇怪了——它只画了三张图，画到第三张，故事就断在半空中，后面到底怎么样，谁也不知道。我看了半天，心里一直痒痒的：接下来会发生什么呢？我想请你们来帮我把它想明白、写下来。

师：先看，别忙着往下想。就看这三张图，你先看出点什么？你猜，这个断了尾巴的故事，讲的可能是件什么事？谁来说一两句。

学生互动分享

参考：（学生就图自由猜，老师不急着对答案，笑着接住）有的说好像是捡到了一只小动物，有的说是谁和妈妈在商量什么事……老师回应：“都有可能。到底是件什么事，咱们等会儿一张一张看过去，就清楚了。”

师：不光是写给老师看。我们班要办一个“同一个开头，你的结局”故事征集——同一组图，每个人往下续一个自己的结局，写完投进这个“结局收集箱”（出示一个纸箱）。等大家都投完，找个晨读的时间，我们抽出来读一读：同样是这三张图，你的小狗留下了没有？他的呢？看看一个开头，能长出多少个不一样的故事。

师：所以今天我们做的这件事，不是“完成一篇作文”，是要给这个断了尾巴的故事，接上一个既接得住前面、又是你自己想出来的结尾。

师：想接得好，得先把前面三张图看明白。我们一张一张来看。

[过渡到逐图观察。真实受众是全班同学，产出物是投进收集箱、会被大家读到的续写结局。]

### 二、观察体验，读懂图意（约10分钟）

师：先看第一张。（出示图一）图上是谁？在什么地方？她在干什么？

参考：星期天，一个小女孩（我们就叫她朵朵）在自家院子里玩，忽然发现墙角有一个鼓鼓的、还在动的小纸箱，她好奇地凑过去看。

师：再看第二张。（出示图二）纸箱里是什么？朵朵这时候什么表情？

参考：朵朵小心地打开纸箱，里面蜷着一只毛茸茸的小奶狗，正抬起头看她，尾巴轻轻摇。朵朵又惊又喜，眼睛都亮了。

师：看第三张。（出示图三）这时候谁来了？她的表情和前面一样吗？故事好像要有变化了。

参考：妈妈走了过来，眉头皱着，好像不太愿意养这只小狗。朵朵着急了，紧紧抱着小狗，仰着头看妈妈。

师：现在请你把这三张图连起来，在心里默默讲一遍：星期天，朵朵在院子里发现了一只被丢下的小奶狗，她很想留下它，可是妈妈皱起了眉头。故事就停在这儿了。来，把这三张图连着说一说——

学生互动分享

师：（教师总结）好，前面的事我们看懂了。故事最要紧的地方，其实藏在第三张图里——妈妈皱眉了，朵朵抱着小狗仰头看她。这一刻，两个人心里都有话。接下来会怎么样呢？现在四人一组，轮流说一说：你觉得后面会发生什么？妈妈会同意吗？小狗最后留下了没有？一人说一种，看看你们组能想出几种不一样的往下走的路。

[组织形态：四人小组轮流说，每人说一种可能的发展，不重复；老师走到两三组当第一位听众。]

学生互动分享

师：（教师总结）我听到好多种了——有的说朵朵一保证自己照顾，妈妈就心软了；有的说他们贴了寻狗启事，找它原来的主人；还有的说小狗生病了，一家人赶紧送它去看病。这些都可以，故事本来就允许有不同的走法。但你们发现没有：不管往哪儿走，都得从“妈妈皱着眉、朵朵抱着小狗”这儿接下去，不能凭空跳到别的事上。这正是我们这节课要练的本事。

### 三、学写法：接住前文，往下合理地想（约12分钟）

师：动笔之前，我们先来做个小判断。等会儿有两段接下去的话摆在你们面前，你们的活儿就是当裁判——看清楚哪一段是真接住了这三张图，哪一段跑偏了。

师：第一段——“第二天早上，朵朵背起书包去上学。今天有一节体育课，同学们在操场上玩得可开心了，跳绳、踢毽子，笑声一片。”

师：第二段——“朵朵抱着小奶狗，仰头看着妈妈，心里怦怦直跳。她多怕妈妈说出一个‘不’字。小奶狗好像也知道自己的处境，往她怀里蹭了蹭。”

师：这两段，哪一段是顺着我们这三张图接下去的？哪一段跑到别处去了？

学生互动分享

参考：第二段接得上。它紧接着第三张图——朵朵还抱着小狗、还在看妈妈，故事从这一刻往下走。第一段虽然写得通顺，可是它把小狗、把妈妈全丢下了，跳到“上学、体育课”上去了，跟前面三张图断开了，这就叫“脱离了前文”。

师：对，你们分得很清。这就点出了我们今天写“续写”最关键的两条规矩。第一条，接得上——续写不是另起一个新故事，得从前面图里停下的那一刻，顺着往下接。所以开头一两句，最好回一下头，照应前面：像刚才第二段，一上来还是“朵朵抱着小狗看妈妈”，读的人一下就知道，哦，接上了。

师：第二条，想得合理——往下怎么发展，不能瞎编，得看着图里的线索来。图里给了我们什么线索呢？妈妈皱着眉，说明她心里犹豫，那朵朵就得想办法打动她；小狗往怀里蹭、尾巴摇，说明它乖、惹人疼，这可能就是打动妈妈的地方。顺着这些线索想出来的发展，才既接得住前文，又让人信。

师：等你把最要紧的那一幕想好了，还有一招能让故事一下子活起来——把那一刻，用人物的动作、表情、说的话、心里想的，写具体。不是光秃秃一句“妈妈同意了”，而是写出妈妈是怎么从皱眉到点头的：她蹲下身、摸了摸小狗、叹了口气、嘴角却往上翘……这样读的人才像亲眼看见一样。

师：其实我们平时读故事，也常常一边读一边猜“后面会怎样”。续写，就是把你猜到的、又觉得最合理最有意思的那一种，接着写下来。今天就练这三样：接住前文、合理往下想、把关键一幕写具体。

### 四、借助构思表，理清续写思路（约9分钟）

师：直接动笔写整段，容易写着写着就跑偏。我们先用一张表，把要写的东西理一理：每格填几个关键的词，不写句子。

[发下“续写构思表”（空白版），每人一张。]

| 项目 | 关键词 |
|---|---|
| 前面发生了什么（用几个词回顾三张图） |  |
| 接下来会怎样（顺着图往下想） |  |
| 最要紧的那一刻（重点写） |  |
| 那一刻的动作 / 表情 / 说的话 / 心里想的 |  |
| 结局怎样 |  |

师：老师先做个样子，把老师想的填进老师这张表里，你们看着老师怎么填。（老师一边说一边在自己的一张表上填）“前面发生了什么”——朵朵捡到小狗、妈妈不同意，我就填“捡小狗、妈妈皱眉”。“接下来会怎样”——我想让朵朵求妈妈、妈妈慢慢心软，就填“朵朵保证自己照顾、妈妈心软”。“最要紧的那一刻”——就是妈妈松口、点头的那一下，填“妈妈从皱眉到点头”。“那一刻的动作、说的话、心里想的”，我填“朵朵怕、朵朵保证的话、妈妈摸小狗、叹气又笑”。“结局”填“留下小狗，多了个小伙伴”。你看，几个词，一条路就清楚了。

师：轮到你们了。你不用跟老师想的一样——你可以让他们找到失主，也可以让小狗留下，怎么想都行，只要接得住前面、想得合理。现在动笔填你自己的表，还是只填关键词，填不出的格子先空着，一会儿咱们一起补。

学生动笔写作

师：（巡视一圈后）好，谁来把你填的往下说一说？说说你打算怎么接、最要紧的是哪一刻。其他同学当小裁判，一边听一边想一件事：他接得住前面三张图吗？

[组织形态：举手抽说，请 2–3 位同学说自己的续写思路；其余同学带着“他接不接得住前文”这个任务听，听完请一两人说说判断。]

学生互动分享

参考：（教师随学生发言点评，只点“接不接得住、合不合理”两处，不改内容）比如学生说“小狗其实是只会魔法的狗，带朵朵飞走了”，老师可回应：“这个想法很大胆，不过它把前面‘妈妈不同意’这条线丢开了，飞走了就接不上啦——要不要想想，怎么让它还留在这个院子里、这个家里？”

师：（教师总结）几位同学的路都不一样，可都是从“妈妈皱眉、朵朵抱狗”这儿接下去的，都对。表填好的同学，把空着的格子也补一补。补齐了，你这个故事的骨架就搭起来了。

### 五、出示示范文，发现写法（约6分钟）

师：你们的表都填好了，各有各的想法。现在老师把老师那张表，写成了一段完整的续写，请大家看看，老师是怎么把几个关键词，变成一段能读的故事的。

> 【教师示范文】
> 朵朵抱着小奶狗，仰头看着妈妈，心里怦怦直跳。她多怕妈妈说出一个“不”字。
> 小奶狗好像也知道自己的处境，把湿乎乎的鼻子往朵朵怀里蹭，“呜呜”地哼了两声。朵朵赶紧说：“妈妈，你看它多可怜，被人丢在墙角，缩成小小的一团。我保证，喂它、给它洗澡、带它散步，全都我自己来，绝不让你操心。”
> 妈妈皱着的眉头，慢慢松开了一点。她蹲下身，伸手摸了摸小狗的头。小狗立刻舔了舔她的手指，尾巴摇得像个小风扇。朵朵大气也不敢出，眼睛一眨不眨地盯着妈妈的脸，心里一遍一遍默念着，盼她点头。
> 妈妈叹了口气，嘴角却往上翘：“那……先养几天，要是找不到它原来的主人，再说吧。”
> “太好了！”朵朵一下子笑开了，抱着小狗在院子里转了个圈。小狗被她逗得汪汪叫，那声音，比院子里任何一朵花都好听。
> 从那天起，院子里就多了一个毛茸茸的小伙伴。

师：先看整体，问三个问题。第一，老师这段开头第一句写的什么？

参考：写的是“朵朵抱着小奶狗，仰头看着妈妈”——正好接住第三张图，一上来就照应了前文，读的人立刻知道故事从哪儿接下去的。

师：第二，从“妈妈不同意”到“妈妈答应先养几天”，中间是不是一下子跳过去的？

参考：不是。中间有朵朵的保证、有小狗往怀里蹭、舔妈妈的手，是这些让妈妈一点点心软的。发展是顺着图里的线索、一步一步来的，所以让人信。

师：第三，故事的结局清楚吗？

参考：清楚。结局是“先养几天”“院子里多了个小伙伴”，故事有了个落脚点，没有断在半空。

师：这三样——照应前文、合理发展、有结局，就是我们说的“接得上、想得合理、写完整”。再看一个更要紧的：老师这段里，有几句话让你一下子就“看见”了当时的样子。我们把它们找出来。

[出示“示范文旁批对照”表，逐句点。]

| 示范文里的句子 | 这一句写了什么 |
|---|---|
| 心里怦怦直跳，多怕妈妈说出一个“不”字 | 心里想的（担心） |
| 把湿乎乎的鼻子往朵朵怀里蹭 | 动作 ＋ 摸上去的感觉 |
| “妈妈，你看它多可怜……绝不让你操心” | 说的话（人物语言） |
| 皱着的眉头，慢慢松开了一点 | 表情的变化 |
| 尾巴摇得像个小风扇 | 一个简单的比喻 |

师：（教师总结）你看，老师没有写“朵朵很紧张”“妈妈同意了”这样干巴巴的话，而是写她“怦怦直跳”“怕说出一个不字”，写妈妈“眉头慢慢松开”“嘴角往上翘”。就是这些动作、表情、心里的想法，把最要紧的那一刻撑了起来。等会儿你写自己那一幕的时候，也这样——别一句话带过，把它放慢，写具体。

师：不过记住，你要写的是你自己想的那个结局，不用跟老师一样。老师这段只是给你看看“关键词怎么长成一段故事”。好，先休息一下，回来我们就动笔，把你的故事接完。

本课完。

## 第2课时 · 当堂写作与评改课

### 一、接住前文，写下开头几句（约5分钟）

师：休息好了，我们接着上节课往下走。把你的续写构思表拿出来，放在面前——上节课你已经把骨架搭好了，这节课就把它变成一个完整的故事。

师：先别想整篇怎么写，我们只写开头。看你表上“前面发生了什么”那一格。开头第一句，就用一句话把前面接住——像老师那样，写“×××还抱着小狗看着妈妈”，或者“雨停了，朵朵手里的小狗还在……”，把读的人一下拉回到第三张图那一刻。来，先把这一句写下来。

学生动笔写作

师：写好了照应的第一句，紧接着看你表上“最要紧的那一刻”那一格。现在在心里，把你编的那一幕慢慢放一遍：那一刻，人物先做了什么动作？脸上什么表情？说了句什么话？心里又在想什么？想到一样就赶紧写一句，别停下来琢磨字词，碰上写不出的字，先空着或标个小记号，别卡在那儿，回头再补上。

学生动笔写作

师：（巡视）好，现在每个人手里都有了开头的几句——一句接住了前文，几句写起了最要紧那一幕。这就是你这篇续写最扎实的开头。别停，顺着这一刻往下写：妈妈后来怎么反应，小狗怎么样，一直写到你想好的那个结局。

### 二、自由写作，续完故事（约18分钟）

师：接下来大约十三分钟，安安静静把你的故事写完。字数多少不用去数，你要做的，就是把想好的那个结局，一句一句接到底。老师在下面走，谁需要就举手。

学生动笔写作

[教师巡视，按学情分类介入，只作正向引导，不纠错别字、不改格式、不打断顺畅书写。]

[接不下去型（写完开头几句就停住）：把学生领回已写的开头，提示顺着关键那一幕往下推。介入语：“你开头这几句写得挺好——朵朵已经抱着小狗、开口求妈妈了。那妈妈听了会先做什么？摇头还是先看看小狗？你就接着写妈妈的反应，一句一句往下走。”]

[内容空泛型（只写“妈妈同意了”一类结论、没有过程）：引导落到具体的动作和话上。介入语：“‘妈妈同意了’——她是怎么同意的呀？是先叹了口气，还是先摸了摸小狗？她答应的时候说了句什么？把这几下写出来，我们才看得见。”]

[书写顺畅型：不打断，为其留出书写空间。可轻声一句“写得好，接着写，别停”。]

[草草收尾型（写了三两句就搁笔说“写完了”、篇幅明显偏短）：先肯定，再追问推着往下写。介入语：“这个结局有意思。不过就这么一句有点可惜——朵朵抱着小狗转圈的时候，是什么样子？小狗又是什么反应？把这一下再写一两句，故事就圆满了。”]

### 三、交流评议，修改收束（约22分钟）

[即时反馈环节（约10分钟）：结局分享，请 4–5 位同学念自己的续写，重点听“接得顺、想得妙”两处。人均约 2–2.5 分钟（念约 300 字续写 ＋ 老师即时点评一两句）倒推，10 分钟正好装下 4–5 人，宁可少请一人也念到位、评到位。本环节三个子环节约 10＋4＋8＝22 分钟，恰好装满，子环节转场从容进行。]

师：好，笔先放下。同样三张图，我们班这会儿一定长出了一大片不一样的故事。请几位同学来念念你的结局，我们听两件事：一是接得顺不顺——接得住前面的图吗；二是想得妙不妙——是不是既合理、又有点出乎意料。哪一位先来？

学生互动分享

师：（就学生所念，具体点评，每人一两句）比如——你这一句“妈妈嘴上说‘就养几天’，手却已经去给小狗倒水了”，这一笔真好！嘴上和手上不一样，把妈妈那点松动写活了，这叫接得住、又想得巧。（再点一位）你让他们最后找到了小狗的主人，把它还了回去，结局跟大多数人都不一样，可它照样接得住前面，还多了一份不舍，这份“想得不一样”特别好。

师：（教师总结）你们发现没有，念出来的这几个结局，没有哪两个是一模一样的，可它们都从“妈妈皱眉、朵朵抱狗”那一刻接下去，都合情合理。这就是续写最好玩的地方——同一个开头，藏着好多个不同的、又都说得通的故事。

[第二层反馈（约4分钟）：同桌互读，把对方续写里“最想接着看下去的一句”读出来，被读到的作者起立念一遍。口头进行，不在稿上画记号。]

师：刚才只请了几位同学，其实每个人的故事都值得被听见。现在同桌两个交换稿子读一读，读完从对方的故事里挑一句——你觉得最想接着往下看的那一句，读给他听。被同桌读到那一句的同学，请你站起来，把这句再大声念一遍，让全班都听听。

学生互动分享

[延迟纠错（约8分钟）：对照三档标准自改 ＋ 同桌互改。修改符号自然带过、不专门教。]

师：听了别人的，也被人夸了一句，现在回到自己的稿子上，我们来改一改。改的时候心里装着三条尺子——

参考：能续写出后面的情节、故事基本完整、跟前文接得上，这是过关；跟前文接得自然、发展合理、写出了简单的对话或动作，这是良好；接得流畅、想得又合理又新鲜、最要紧的那一幕写得具体、人物立得起来，这就很出色了。

师：对着这三条，先自己读一遍，用修改符号理一理：多出来的字圈掉、漏掉的字补上、写错的字改正；再看看开头有没有接住前文、最要紧那一幕是不是还能再写具体一点。改完自己的，同桌再互相帮着看一眼：他接得上前面吗？哪一处再补一句会更好？

学生动笔写作

师：（教师总结）改好的同学，把稿子的题目和你的名字写上，工工整整投进我们的“结局收集箱”。等这一箱都投满了，找个晨读的时间，我们抽出来读——读读同样这三张图，在我们班一共长出了多少个不一样的结局。你今天接住的这个故事，就是其中一个。

本课完。

全课完。

## 附：习作讲评指导环节（单次课可选用 / 系列课作下次课开场）

> 说明：本环节是七环节正课之外、老师可灵活取用的一块深度讲评框架，既可在本次课后老师批读后集中讲评一次，也可作下一次习作课的开场（约 15–20 分钟）先讲评上次、再进新课，不计入 45＋45 分钟、也不要求学生回家再写。
>
> 真实性提示：生成时并不知道本班学生真实写出什么，下文凡出现全角 ＿＿＿ 处，务必换成本班学生续写里的真实句子，切勿照搬、更不可虚构一段“学生作品”当范例。

### 选稿（课前准备）

老师课后从全班续写里挑 2–3 篇代表作，投屏时不具名，各用一句话对着本课技法点点明它好在哪、欠在哪：

- 一篇较好：开头照应了前文、发展合理，最要紧的一幕还写出了动作和心里的想法。（如：＿＿＿，占位：这一篇里最能体现“接得住＋写具体”的一两句。）
- 一篇中等：接得上、故事也完整，但最要紧那一幕一句话带过了，没写具体。（如：＿＿＿，占位：该篇那句“一句话带过”的关键情节。）
- 一篇有典型问题：写着写着脱离了前文，跳到别的事上去了，或结局来得太突然。（如：＿＿＿，占位：该篇脱离前文/结局突兀的那处。）

### 讲评流程（每篇约3–5分钟，围绕本课技法点）

师：这次续写，我们就盯着这节课练的两条来评——接得住前文、往下想得合理，再看最要紧的一幕写没写具体。别的先不挑。

师：先看第一篇。这位同学开头这一句“＿＿＿”（占位：念该篇照应前文的开头句），一下就把我们接回了前面的图；到最要紧的地方，他写“＿＿＿”（占位：念该篇写得具体的动作/心理句），你们听，动作、心里想的都有了，这一幕就立起来了。这就是我们要的样子。

（教师总结）好在哪？好在既接住了前面，又把关键那一刻写慢、写细了。

师：再看第二篇。这一篇故事很完整，接得也顺，就是有一处可惜——他写“＿＿＿”（占位：念该篇一句话带过的关键情节），最要紧的一下，一句话就过去了。如果把这里放慢，添上人物的动作、说的一句话，是不是更让人看见？

师：最后看第三篇，我不点名，我们一起来帮个忙。这位同学前面接得挺好，可写到后来（读到脱离前文那一处：＿＿＿，占位），故事好像跑到别的地方去了。大家想想：怎么改一改，能把它拉回到我们这三张图的故事里来？

学生互动分享

（教师总结）续写最容易在这儿松手——写着写着，把前面的图忘了。记住：不管往哪儿写，线得始终连着前面那一刻。

### 收尾（点回技法）

师：今天讲评的这几篇，好就好在用上了这节课的本事——接住前文、合理往下想、把最要紧的一幕写具体。写得还不够的地方，也都在这几条上。所以这不是谁比谁强，是同一套方法，我们再练一遍。下次再遇到“看图往下写”“接着往下编”的题目，还是这三招，你一定能接得更稳、想得更妙。

本环节完。
