# 四年级上册·第三单元 习作《写观察日记》· 写作课详案

> 老约翰深度阅读 · 校内同步习作课
> 本课为先导课,默认上在校内讲解《写观察日记》之前。

## 二、任务背景

本任务为部编版小学语文四年级上册第三单元习作,文体为连续观察日记,要求学生选一种事物连续观察,用日记形式整理记录,把变化与心情都写出来。本课为培训班先导课,上在学校讲解本单元习作之前;课前一周已由培训班布置“选一种事物开始观察并随手做记录”的前置任务,学生带“观察记录卡”或手账本到课。师话保留对漏做、做得不全、中间断档的兜底,绝不预设学校已讲过单元课文。

## 三、三维教学目标

【知识技能】掌握观察日记的基本格式(日期、星期、天气、空两格);能围绕“变化”这一个意思,选一处“昨天 vs 今天”的对比写出新发现;能用“渐渐地、慢慢地、越来越……、由……变成……”等表示变化的词语;能初步使用删除号、增补号、改正号在习作上自改互改。

【过程方法】经历“现场观察—翻看记录—填连续观察记录表—对照下水文学技法—独立成篇—互读反馈—对照评分标准修改”的完整流程;学会“先填表(关键词)再连段(写完整)”的写作策略;学会一种轻量的连续观察记录方法,带回家继续用。

【情感价值】愿意把日子里的小变化记下来,体会“长在变化里的有意思”;体会观察的乐趣与坚持记录的小成就感;在“班级自然观察家手账墙”的真实任务中,感受到自己的发现真的被人看见。

## 第1课时 · 写作指导课(作前·作中)

### 一、真实情境抛任务(8 分钟)

【PPT换页-P01】

师:同学们,先看看老师手里这个——(举起一只玻璃罐,里面是已经发了芽的绿豆,旁边再放一只刚泡了水的小碗)看到没有?这是老师上周一开始泡的绿豆,今天已经第八天了;旁边这碗,是今天早上才泡进去的。它们都是同一种豆子,中间隔的是什么?

参考:七天的时间;七天里发生的变化。

师:对,是七天里“发生的事”。今天我们要做的,不是写一篇作文交给老师批分数。今天我们要做一件正经事——我们要在咱们培训班的这面墙上,(教师指向教室外或后墙的展示位)挂出一面新的墙,叫“班级自然观察家手账墙”。从今天开始,每周更新一期。咱们这一节课写的观察日记,就是这面墙的“首期作品”。

师:谁会看这面墙呢?咱们班的所有同学;每周接送的爸爸妈妈、爷爷奶奶;下周来上课的同学,会一进门就看到——“哦,上一期他们观察的是绿豆、银杏叶、家里的小猫,这一周我也想试试。”老师可以负责打印、负责贴,但内容必须是你的——是你亲眼看到、亲手记下来的东西。

师:所以,这节课你不是在写作业,你是在做一期“手账墙”的首发作者。你的目标是:让路过的人看着你的日记,能在脑子里看见你观察的那个小生命这几天发生了什么变化。

[PPT 呈现实体载体效果图:一面墙、若干已贴/待贴的观察日记小卡片,中央标题“自然观察家手账墙 · 第1期”]

师:这件事能不能做成,关键就一条——你写的“变化”,别人得看得见。比如你只写“绿豆长大了”,大家心里没画面;但如果你写“昨天豆子上只裂了一条小缝,今天那条缝里钻出了一根白白嫩嫩的小芽,跟米粒一样大”,大家脑子里马上就有了画面。今天老师就教你怎么写出这种“看得见的变化”。

师:不过在开写之前,老师要先确认一下:上周老师布置大家“选一个东西开始观察,每天随手记一记”,有没有人是认真做了的?举手老师看看。

(教师快速点视;允许一部分同学举手,一部分同学没举手。)

师:举手的同学,把你的观察记录卡或者本子放在桌子右上角,待会儿就是咱们写作的“原料”;没举手的同学也别担心,老师今天带了“现场观察”的环节,等下大家一起观察今天这罐绿豆,你就能跟着补一笔——首期手账,没有人会被落下。

(教师总结)这节课不写作业,做一件真事——把自己观察了一周(或者今天开始)的发现,做成“手账墙”的首发作品。一个目标:让别人看见你的变化。

(此处落实“真实情境”——实体载体(手账墙)+ 具体读者(同学、家长、下期学员)+ 可见的成败标准(让别人看见变化)。)

### 二、全感官唤醒(10 分钟)

【PPT换页-P02】

师:好,现在请大家把笔放下,手伸过来。老师给每张桌子发一只小透明杯——里面是老师从上周一开始泡的绿豆,今天第八天,已经长出芽来了。每组一杯,大家轮流仔细看一看。

[教师课前准备:① 每组一只透明小杯,内有已发芽的绿豆(芽长约 2–3 cm)。② 讲台上展示“第0天”的小碗(刚泡水的豆子)。③ 备一张老师自己的“观察记录卡草稿”(纸质,可投影或传看)。]

师:咱们先做一件事——闭上眼,在心里数五个数,然后睁开,把你眼睛里第一眼看到的东西,小声跟同桌说出来。不能说“很漂亮”“很有趣”这种空话,只能说“我看到了什么样子”。来,闭眼……一、二、三、四、五,睁眼,跟同桌说。

学生互动分享(同桌之间,30 秒)

师:好,谁来跟大家分享一下,你看到了什么?不要修饰,就照你眼睛看到的说。

参考(预设可能的学生回答,教师据情况追问):

“我看到豆子裂开了”——师追问:裂在哪里?裂得宽不宽?

“我看到豆子里冒出一根白色的东西”——师追问:那根白白的东西有多长?有没有米粒那么粗?是直的还是弯的?

“豆子皮皱皱的”——师追问:像不像泡久了的指头?

师:看,我们刚才不是在“看”,我们是在“细看”。一边看一边问自己“它到底是什么样子”——这就是观察。

师:接下来再加一个动作。请大家轻轻把杯子端起来,凑近鼻子闻一闻——什么气味?跟你平时吃饭时闻到的味道一样吗?再用一根手指头,轻轻碰一下杯子里的水,什么感觉?温的、凉的、滑的?

[教师边引导边走动,在每组停留 5–10 秒,提示学生“看、闻、摸”三个动作都要落到一句具体的话;对没参加前置观察的学生,明确告知“今天就是你的‘第一天’,这罐豆芽今天的样子,就是你的素材”。]

学生互动分享(自由发言 3–4 人)

师:谢谢你们。我们刚才用眼睛、鼻子、手指头——三种身体的感官,把今天这罐绿豆“今天”的样子,记进了脑子里。这一刻,你脑子里应该不是“豆芽长出来了”这一句空话,而是它具体的样子、气味、手感。

(教师总结)观察的第一步,不是动笔,是把感官打开,先把“具体的东西”吸进脑子里。今天大家吸进去的这些,等会儿都是要写进日记里的。手上有上一周记录卡的同学,也请你翻一翻——你前几天看到的那只小生命,这一刻在你脑子里“长什么样”?把它再“看”一遍。

(此处落实“全感官唤醒”——具身介入(看/闻/摸)+ 现场实物 + 现场素材回流,弥补未做前置观察的学生。)

### 三、一招技法(10 分钟)

【PPT换页-P03】

师:刚才我们把今天的样子看清楚了。可是观察日记不是只写“今天”,它最有意思的地方是——它能让人看到“一直在变”。这就引出今天我们要学的一招:写“变化”。

师:老师先讲一句心里话——很多同学写观察日记,容易写成什么样?写成这样——

[PPT 出示一段反例]
“今天我看了我的绿豆,绿豆长大了一些。我很开心。”

[PPT 出示对照下水句]
“今天,我发现昨天那条小缝里,钻出了一根白白嫩嫩的小芽,只有米粒那么大,像一个怯生生伸出来的小舌头。我兴奋极了!”

师:这两句都说“豆子长出芽了”,但读起来感觉完全不一样,你们觉得差在哪里?

学生互动分享

参考:第二句具体,第一句空;第二句把“小芽”写出了样子;第二句有“昨天”作对比;第二句用了“米粒”“舌头”这样的比方。

师:你们都说到了关键。老师把它收成一句话——

[PPT 出示]
写“变化”,抓一处“对比”:挑一处“昨天 vs 今天”的小不同,写出它具体的样子。

师:三步走——

[PPT 出示]
第一步:今天和昨天比一比,挑一处“不一样”。
第二步:用“渐渐地、慢慢地、越来越……、由……变成……”这类词把“在变”说出来。
第三步:把那一处不一样,写到一个具体的小细节(米粒一样大、五分硬币那么宽、笔尖那么粗……)。

师:为什么强调“一处”?因为一篇观察日记不需要把所有变化都写。一天写一处,写得让人看得见,就成了。挑哪一处呢?挑你今天最惊讶、最高兴、最忍不住凑近看的那一处。

师:老师再给大家提一个伙伴。咱们读书会读过《森林报(春)》的同学,想想——里面那位林务官,每周给森林写一份“新闻”,写谁来了、谁走了、谁变了样,他从来不说“森林春天到了”,他写的是“今天看见冰面上裂了一条缝,缝里冒出第一只小甲虫”。没读过《森林报》的同学也不要紧,老师就告诉你这一点:好的观察记录,都是写“今天看见了什么不一样”,不是写“今天又来了”。今天我们也来给自己观察的小生命写一份“新闻”。

(教师总结)记住:一天写一处“对比”,一处对比要有具体细节,有变化词。这是今天写好观察日记的命根子。

(此处落实主技法点“写变化”——抓一处“对比”+ 变化词 + 具体细节;读书会书目轻引一处,带未读兜底。)

### 四、构思支架落地(9 分钟)

【PPT换页-P04】

师:听是听懂了,可是真要写起来,脑子里多半还是一团。所以老师给你们带了一张表,叫《连续观察记录表》。先填表,再写字。表填完了,字就有方向了。

师:这张表长这样——

[PPT 出示空白表格]

| 日期 | 我看到的样子 | 跟前一天不一样的地方 | 我的心情或想法 |
|---|---|---|---|
|  |  |  |  |
|  |  |  |  |
|  |  |  |  |
|  |  |  |  |

师:四列,三到四行。注意,这张表只填“关键词”,不填整句话——咱们待会儿真的写日记的时候,关键词才好“长”成句子。

师:老师先当众填一张。老师上周开始观察的就是这罐绿豆,我把我的真实记录给大家看。

[PPT 出示教师示范填好的表]

| 日期 | 我看到的样子 | 跟前一天不一样的地方 | 我的心情或想法 |
|---|---|---|---|
| 9月1日(第1天) | 干瘪的小绿豆,圆鼓鼓 | (第一天,无对比)豆子比昨天泡前胀大了一点 | 这能发芽吗?有点怀疑 |
| 9月3日(第3天) | 豆皮裂开一条缝,白芽米粒大 | 昨天还没裂;今天裂开 + 冒白芽 | 兴奋!忍不住凑近看 |
| 9月5日(第5天) | 白芽五分硬币长,弯成钩 | 由“米粒”变成“钩”;颜色更白 | 像小问号,真可爱 |
| 9月8日(第8天) | 芽顶上长出两片小叶,绿色 | 由白色钩变成绿叶;高过杯沿 | 觉得自己也“长大”了 |

师:看到没有?老师只填了关键词,不写整句话。“昨天还没裂,今天裂开”——这就是一处对比;“由米粒变成钩”——这是变化词的样子;“凑近看”——这是心情。我没贪多,一天只圈一处最让我惊讶的小变化。

师:现在轮到你们。请大家拿出老师之前发的《连续观察记录表》(或者翻到练习本对应页),开始填——

[分三类学情给出落地路径:]
[前置观察做得齐的同学]:打开自己的观察记录卡,挑出 3–4 个变化最明显的日子,填进表里;每行只写关键词,不写整句话。
[前置只记了一两天的同学]:把记下的那一两天放最前面,把今天这罐绿豆的“现场观察”补成“今天”这一行;后面留一两个空格,意思是“我接下来还要继续观察”。
[完全没观察的同学]:从“今天”开始;第一行就是“今天 9 月××日,我第一次仔细看了××”,把你刚才看到的绿豆样子写进去;后面三行写“我打算明天、后天、再过一天去看,我猜它会变成××”——也是合格的观察记录,是观察的“开头”。

学生动笔填表(约 4 分钟)

[巡视分层指导(教师按学情轻声提示,不打断学生填写)]
[对填空白处长时间未动笔的同学]:挑你印象最深的那一天,不用按时间顺序。
[对只填了“我看到的样子”未填“对比一栏”的同学]:今天这一处,跟昨天那一处比,哪里不一样了?写在第三列。
[对填了整句话的同学]:这一格,挑两三个词就行,完整的句子留给真正写日记的时候。

学生互动分享(请 2–3 名同学,分别简短说出自己表格中某一行的“对比一栏”内容)

参考(教师对每一位发言简短反馈,聚焦“对比”是否找到):

“昨天豆子还没冒芽,今天冒出来了”——师:好,对比立住了,接下来这一处可以再补一点“具体的样子”,比如冒出来多长。

“昨天叶子是嫩黄色的,今天叶子绿了”——师:这是颜色的对比,非常具体,可以直接进日记。

“我今天才开始看,没有昨天可以比”——师:那你的“对比”可以是“我以为它会××,结果它是××”——你的预期和现实,也是一种对比。

(教师总结)咱们手上现在不止有一张表,我们手上有的是——3–4 天的关键词、几处具体的“对比”、几行心情。这些就是接下来写日记的全部原料,够了,够写一份让别人看见变化的手账。

(此处落实“构思支架落地”——只填关键词,不填整句;给每类学情明确的填写路径;引出→填写→分享+反馈完整环节。)

### 五、下水文做样(8 分钟)

【PPT换页-P05】

师:你们刚才填的是老师那张表的同款空白表。现在老师把刚才那张填好的表,拿来“变”成一篇真正的观察日记给大家看。

师:为什么要看?因为很多同学填表是一回事,从表“长”成段落又是一回事。老师就用大家面前这罐绿豆做例子,让你们亲眼看见——一张表里的关键词,是怎么连成一段话的。

[PPT 出示下水文,教师朗读一遍,语速放慢,带感情。下水文与上一环节示范填表用的是同一只绿豆,形成闭环]

> 【教师下水文 · 示范】
>
> 9月3日 星期三 晴
>
>  今天,我又跑去看我的绿豆。
>
>  昨天那颗豆子还圆鼓鼓的,像谁不小心把它泡胖了;今天我一打开盖子,差点叫出声——它变了!短短一夜,它由圆滚滚的一整颗,渐渐裂开了口子。豆皮上那条缝小小的,跟一根头发那么细。我赶紧凑近看,这一看不要紧,缝里居然钻出来一根白白嫩嫩的小芽,只有米粒那么大,弯弯地探着头,像一个怯生生伸出来的小舌头。
>
>  我屏住呼吸,不敢碰它。我小声跟它说:“你慢慢长,别急。”
>
>  这一夜,它怎么就憋出这么大一件事呢?我心里又惊讶又高兴,忍不住跑去告诉妈妈。妈妈笑着说,你以后每天去看它,它每天都会给你一点新东西。我相信她——我已经迫不及待想知道明天它会变成什么样了。

师:好,日记读完了。现在请大家回头对照——

[PPT 同屏对照:左边是老师“第3天”那一行的表格关键词,右边是这一段日记。]

师:请你们告诉老师,这段日记里——

- 哪一句话,是从老师表里“裂开一条缝”这个关键词长出来的?
- 哪一句话,是从“白芽米粒大”长出来的?
- 哪一句话,是从“凑近看”长出来的?
- 哪一句话,是从“兴奋”长出来的?

学生互动分享

参考:“豆皮上那条缝小小的,跟一根头发那么细”对应“裂开一条缝”;“只有米粒那么大,弯弯地探着头”对应“白芽米粒大”;“我赶紧凑近看……我屏住呼吸,不敢碰它”对应“凑近看”;“心里又惊讶又高兴,忍不住跑去告诉妈妈”对应“兴奋”。

师:对了。你们看,关键词就像菜的食材,长成日记就像把菜炒出来——食材本来就在表里,我只是把它们“展开”了,加了一点点比方(“跟头发那么细”“像怯生生伸出来的小舌头”),用上了变化词(“由圆滚滚的一整颗,渐渐裂开了口子”),加了一点点心情(“屏住呼吸”“惊讶又高兴”)。今天那一招的三样东西——对比、变化词、具体细节,在这一段里全都用上了。

师:还有两件小事大家要看清楚——

- 第一行:9月3日 星期三 晴。这是观察日记雷打不动的格式,顶格写,后面什么都不带。
- 每一段开头:空两格。包括第一段。

师:这是“格式”。今天你们写的时候,这两条要在自己的稿纸上对位摆好。

(教师总结)这一段下水文,跟老师那张表是“同一只绿豆”——表里有什么,日记里就长出什么。一会儿你们写自己日记的时候,就照这个走:看一眼自己表里的关键词,把它“长”成具体的句子。不用模仿老师写绿豆,你写你的银杏叶、你的小蝌蚪、你家的猫,都行。

师:好,这节课就上到这。课间休息 10 分钟,回来咱们就把这只小生命的“它”的故事,亲手写下来,贴上手账墙。不留课后任务,今天的故事今天讲完。

【PPT换页-P06】

本课完。

## 第2课时 · 当堂写作与评改课

### 一、自由倾吐(22 分钟)

【PPT换页-P07】

师:同学们,休息好了。带着刚才填好的那张表和你的观察记录卡,我们现在动笔。

师:今天写多少?——选 2 到 3 天的观察,各写一篇日记。不用写整整一周。每篇日记的格式都是这样——

[PPT 出示格式提示]

> ×月×日 星期× 天气
>
>  (空两格)今天……

师:每一篇,开头那一句话用“今天……”或者你自己的开头句都行。重要的是,落到本节课的那一招——挑一处“对比”,写出今天的新发现。

师:接下来 20 分钟,大家自己写。老师不打断、不纠错字、不改格式,你只管放心写、放手写。写卡了,招手叫老师;写得起劲了,别停。

师:开始。20 分钟。

学生动笔写作

[巡视指导(教师按学情分层、轻声提示,全程不出声打断学生思路。建议第一圈在动笔约 8 分钟时、第二圈在约 13 分钟时各巡视一遍)]

[卡壳型——动笔后 1–2 分钟仍未写出第一句话]
师(轻声):看你表里第一行,挑“我看到的样子”那一列里最具体的一个词,从这个词写起;比如你写了“米粒大”,就从“米粒大”写起。

[写空型——只写“长大了”“变绿了”,景物没出来]
师(轻声):这一句别只说“长大了”,你看那个字“大”,它大成什么样?跟昨天比大了多少?把你刚才在表里圈的那处对比补上。

[写嗨型——已经写完一篇、还有时间]
师(轻声):很好,你今天观察日记的“底气”已经够了。下一篇换成另一天,继续按这一招走;不用着急。

[篇幅短型——半段就停]
师(轻声):心情那一栏你还没用上——把“心里怎么想”补到日记最后一两句;读者会因此觉得这是“你的”日记,不是别人的。

师(全班,18 分钟时轻声提醒一次):还有 2 分钟。不用赶,但写到结尾的同学,记得回头勾一勾“变化”那一处对比。

师(20 分钟整,温声):笔放下,稿纸不收。

(此处落实“自由倾吐”——零打断纠错,巡视只做三件事:为卡壳的学生提供具体素材提示、引导写空的学生落到具体景物、为写得顺畅的学生留出空间不打断;护个性化选材,写小猫、写银杏叶、写厨房里的发面馒头,都一律放行。)

### 二、即时反馈 + 延迟纠错 + 自然收尾(23 分钟)

[即时反馈:“手账墙小评委”游戏,约 9 分钟]

【PPT换页-P08】

师:咱们玩一个反馈游戏,叫“手账墙小评委”。规则很简单——每个同学挑出自己一组日记里最得意的“一句”,只挑一句,站起来念给大家听。念完之后,全班同学不评点子好不好,只做一件事——

[PPT 出示规则]

> 念句子的人念完,全班齐声说:“我仿佛看见了——”然后请一位同学接着说一句:“我仿佛看见了一根米粒大的小芽。”

师:也就是说,你这一句要让听到的人,脑子里马上跳出一个画面。跳出来了,这句就立住了;跳不出来,就没立住。咱们一起验证。

(教师明确目标人数:本节课点到 6–8 位同学,优先邀请平时不爱举手、刚才动笔时全程认真的孩子)

师:谁先来?

学生互动分享(请 6–8 名同学,每人念一句)

[每位念完,老师对事且具体地点一句,如以下示例。每句话只夸一个具体的点,不空夸。]
师:“豆皮上那条缝小小的,跟一根头发那么细。”——你这句把“缝”比成“头发那么细”,老师脑子里马上有了画面——一根真正的细缝。这就是今天那一招“具体的细节”。
师:“我家的小猫今天和昨天不一样了,它的眼睛半睁着,好像懒得理我。”——你抓住了一处对比——昨天的眼睛跟今天的眼睛。“好像懒得理我”这一句又带出了心情。猫就这么一句立起来了。
师:“银杏叶的边边变成了金色。”——边边——你抓的是叶子最先变色的那一处,不是整片叶子。这是观察的细心眼。

(教师总结)刚才点了 7 位同学。还有没点到的同学,我们再做第二层:请每位同学跟同桌交换日记,用铅笔在你最喜欢的同桌的一句下面画一颗小星。画完,被画星的那位同学,可以再把这句话小声念给同桌听一次。

学生互动分享(同桌互动,约 2 分钟)

(教师总结)好,大家都被看见了。手账墙的“首发原料”已经够亮了。接下来我们做最后一件事——把它打磨干净,真的能贴上墙。

[延迟纠错:认识三个修改符号,自改 + 互改,约 11 分钟]

【PPT换页-P09】

师:写文章有一个很有趣的事——好的作品不是一气呵成的,是“改”出来的。我们今天就学三个改作文的小符号,以后会跟你们一直走下去。

[PPT 出示三个修改符号,教师在黑板上当堂示范]

| 符号名称 | 用法 | 示范 |
|---|---|---|
| 删除号 | 划掉多余的字、词、句 | 把要删的字词圈起来,从圈里画一条斜线穿过去 |
| 增补号 | 在两个字之间加上漏掉的字 | 在缺漏处下方画“∧”,写上要补的字 |
| 改正号 | 把写错的字改成对的字 | 在错字旁画圈,圈外写正确的字 |

师:老师先在自己的黑板示范上随手出三处错——

[教师在黑板预设一段稿,内含一个多余的词、一个漏字、一个错别字]

> 今天我又跑去看我的的绿豆。豆皮裂了一条小小缝,我赶紧凑进看。

师:大家帮老师挑挑——哪里多了?哪里少了?哪里错了?

学生互动分享

参考:“我的的”——多了一个“的”,用删除号把多出来的“的”圈起来、画斜线穿过去删掉;“小小缝”——“小”和“缝”中间漏了一个“的”,用增补号在中间下方画∧补“的”;“凑进看”——“进”应为“近”,用改正号在“进”上画圈,旁边写“近”。

师:好,符号会用了。现在请大家做两件事——

[PPT 出示自改流程]

> 第一步 · 自己读三遍:第一遍改错别字和不通顺的句子;第二遍看每篇日记是否都写出了“今天的变化”(那一处“对比”);第三遍看格式——日期、星期、天气有没有顶格,段落开头有没有空两格。
>
> 第二步 · 同桌互读:把日记交换,同桌帮你看一遍——他读完后说一句“我看见了××的变化”,如果他说不出来,这一篇就还要补“对比”;如果他能说出来,就请他在那一句旁边画一颗星。
>
> 第三步 · 对照评分标准:挑出自己写得最好的一篇,自己给自己打一档(基础过关 / 良好达标 / 优秀进阶),并写一句话“我为什么觉得自己达到了这一档”。

【PPT换页-P10】

师:对照下面这张表打档——

| 档次 | 评价标准 |
|---|---|
| 基础过关 | 格式基本正确,能写出观察对象的变化,内容真实。 |
| 良好达标 | 日记格式正确,能把变化过程写清楚,有简单的感受。 |
| 优秀进阶 | 格式规范,变化写得很清楚具体,描写细致,真情实感自然流露,能让人感受到观察的乐趣。 |

学生动笔修改(三步走自改 + 互改,约 8–9 分钟)

[巡视分层指导(教师此刻才统一介入错字与格式问题)]
[对自改速度较快、提前完成三步的同学]:挑一篇你最得意的,拿到讲台对老师小声念一次,可以请它做“首张钉墙作品”。
[对修改符号使用混淆的同学]:对照黑板那三栏再看一眼——划掉、补上、改对,各自只做一件事。
[对仍未能写出“对比”的同学]:回到表里那一列“跟前一天不一样的地方”,把那一格里的关键词,补成一句话写进日记。

(教师总结)同学们,刚才大家自己挑出了自己的档,这就是写作真正在长进的时刻——你能看出自己哪里行、哪里还能再走一步。

[自然收尾:首期手账墙开张,约 3 分钟]

【PPT换页-P11】

师:好,最后老师做一件事——请每位同学把自己最满意的一篇日记,从练习本上工整地誊抄到老师发的“手账卡”上(或者把这一页用尺子整齐地撕下来),老师下课收齐,周末把咱们这“首期自然观察家手账墙”贴好。下周一早,你们一进门,就能看见自己的字、自己的发现,在墙上等着你。

[实体载体落地步骤:① 每人一张手账卡;② 教师本周内打印/装订/上墙;③ 下周更新时旧的不撤,新的叠贴;④ 家长接送时可观看。]

师:还有一件事——今天回家后,请把你的观察记录卡和这张手账卡的复印件,带回家给家里人念一念。你可以问问爷爷奶奶或者爸爸妈妈:他们小时候有没有这样仔细看过一棵植物、一只小动物?他们看到的“变化”是什么样的?他们的故事,可能就是你下一期手账的素材。

师:观察这件事,不是观察一次就完的。你今天发现一根米粒大的小芽,明天它会长成五分硬币那么大,后天它会长成绿叶子,大后天它可能就能下锅了。这就是观察最有意思的地方——它每天都给你一点新东西。希望大家以后,看见什么有趣的小生命,都能愿意停下来,蹲下来,看一会儿,记一笔。

(教师总结)今天我们一起做了一件正经事——把一周里的小变化,变成了手账墙的首期作品。一招“写变化”,一张连续观察记录表,一组观察日记。下课后,把手账卡交上来,我们等下周的“开张”。
