## 二、任务背景

本任务为部编版小学语文三年级上册第六单元习作,单元从写人写事转向“写景”,要求学生从校园、公园、村庄、小区等身边环境中,选一处自己觉得美的地方,围绕“这儿真美”这一意思,按一定顺序把景物特点写清楚。本课为培训班先导课,上在学校讲解本单元之前,不预设学生已学过本单元课文。

## 三、三维教学目标

【知识技能】能从身边选一处美景,围绕“这儿真美”这句“中心句”,挑两到三种最能代表“美”的景物入文;能把“美”写具体——用看得见的颜色形状、听得见的声音、摸得到的感觉来写,挑一两处打个比方;能按“远→近”或“上→下”任一种顺序写下来;开头空两格,标点占一格;会用删除号、增补号、改正号三种修改符号改明显的错别字和漏字。

【过程方法】先做“30 秒小解说员”游戏调动看、听、闻、摸四种感官说出现场;再用一张空白的“五感观察表”把脑子里的画面收成关键词;看老师把这张表变成一段话,发现“美”是怎么被写具体的;最后选取扣住“美”的两到三个关键词,按一种顺序连成段。

【情感价值】愿意把自己心里那个“觉得很美的地方”分享给别人;愿意让没去过的小朋友凭着自己写的这一段话,在脑子里“看见”它。

## 第1课时 · 写作指导课(作前·作中)

### 一、创设情境,明确任务(8 分钟)

师:同学们,上课之前老师先问大家一句——你心里有没有一个地方,你觉得它特别美?可能是学校操场边那一排树,可能是奶奶家屋后那条河,也可能就是楼下小区那块小小的花圃。先在心里悄悄想一个地方,记住它,等一下要用。

学生自由分享(口头说“我心里那个地方”是哪儿,1–2 句即可,请 2–3 人分享)

师:好,先记住它。今天这节课,老师不是让大家随便写一篇作文。老师想跟大家一起做一件事——咱们要在教室后面那面墙上,挂一面“美景明信片墙”。

师:这面墙上,每个人都有属于自己的那一格。你在你的一格里写一段话,把你心里那个地方“种”在墙上。等老师挂上去,班里的同学,还有来接你下课的爸爸妈妈,只要走过这面墙,光看你写的那段话,就能在脑子里“看见”那个地方。能“看见”——这一格就算成功了;看不见,光是“风景很美”“我很喜欢”——这一格就失去了意义。

师:所以,今天我们不是写作文。我们是要做一张明信片,贴在墙上。你的读者,是真的会来的人,不是只有老师一个人打分。明白了吗?

参考:明白了 / 嗯 / 那我得写得让人看见

师:好。把你心里那个地方再悄悄想一遍。今天下课之前,你要把它种到墙上去。

### 二、观察体验,调动感官(10 分钟｜可压缩点:照片只精用 3 张,时间紧时第 2 张可跳过;“30秒小解说员”保底 1 人,时间宽裕再加第 2 人)

师:那咱们这就开始热身。老师手里有一摞照片,六张,都是身边那种最普通的小角落——校园老槐树下、公园荷塘的一角、奶奶家屋顶上的瓦、小巷面馆门口飘出的热气、小区秋天的银杏路、村口小河边那一堆石头。咱们一张一张看,看的时候有一个规矩——不许说“很美”“很漂亮”这种话。老师问什么,你答什么。

[出示第 1 张图——校园老槐树下]

师:第一个问题——你“看”到了什么?

学生互动分享(请 3–4 人,各说一个不同的看到:槐树叶、地上的光斑、石凳、有人坐着写作业、风一吹影子在动……)

师:再问——你“听”到了什么?闭上眼睛想一想,如果你现在就站在这儿,会听到什么?

学生互动分享(请 2–3 人:风吹叶子声、蝉叫、远处篮球落地声、上课铃……)

师:还有,“闻”到了什么?

学生互动分享(请 1–2 人:草味、夏天的味道、有点甜甜的花香……)

[出示第 2 张图——公园荷塘一角],节奏放快,只问 1 个感官(如“你看到了什么?”请 1–2 人)。

[出示第 3 张图——村口小河边那一堆石头]

师:这张换个问法——如果你现在蹲下来,伸手摸一摸这堆石头,你的手会“摸”到什么?

学生互动分享(请 1–2 人:凉凉的、滑滑的、太阳晒过的地方有点热、缝里有青苔湿湿的……)

师:对,“摸”到的也算。看、听、闻、摸——四样,都能让人“到现场”。

[以上三张图节奏要快,合计 5 分钟内;第 1 张图问看/听/闻、第 3 张图专问“摸”,四种感官都露过一次脸即可。]

师:很好,那我们再升级一下来玩个游戏,这个游戏叫“30 秒小解说员”。老师再随机翻一张图,被点到的同学走到前面,假装自己现在就站在这儿。30 秒,说一段话,只说一件事——“我现在站在这里,我看见……,我听见……,我还闻到了……”。注意,不许说“很美”,用看到的、听到的、闻到的,让别人觉得美。

学生互动分享(请 1 位同学上台,30 秒;时间宽裕再加 1 位。老师全程不打断、不纠错,听完只点评一句——“哎,那一句‘荷花的清香飘过来了’,这一下我也站到那儿了。”)

[异常处理·学生上台憋不出话]:老师不要等,立刻给一个“封闭二选一”台阶,让孩子只需点头或说一个词——
师:“别急。你现在站在这棵树底下,风吹到你脸上,是凉凉的,还是热乎乎的?”(孩子答“凉凉的”)→“好,那就一句:‘风吹过来,凉凉的。’你看,这就说出来了。”
[若仍说不出]:师顺势接“没关系,你先看着这张图,听同学说”,把他先放回座位,不强留台上,避免冷场。

(教师总结)看见、听见、闻到、摸到——这四样东西,今天就是你的“笔”。等一下写“这儿真美”的时候,光说“美”是不算数的,要让读你那段话的人,跟咱们刚才一样,在脑子里“听见”“闻到”“看见”。

### 三、习得写法:围绕一个意思写(10 分钟)

师:咱们读书会读过《大森林里的小木屋》的同学,想一想——罗兰一家住在大森林里,她写春天的时候,写溪水化开“哗啦哗啦”地流;写夏天,写萤火虫在屋外亮成一片;写冬天,写雪压在屋顶上“咯吱咯吱”响。每一个季节,她都只挑这个季节最让她记得的几样东西写。没读过这本书的同学也没关系,听老师说说就行——罗兰这个写法,就是今天老师想教你的“一招”。

师:这一招,有一句话能说清,叫——“围绕一个意思写”。听起来有点拗口,老师把它翻译成大白话。

[黑板正中竖写四个大字:这儿真美]

师:“这儿真美”——这四个字,今天就是一块大磁铁。你接下来要写的所有景物,都得是被这块磁铁“吸”过来的。吸得过来的写,吸不过来的——再好玩、再热闹,也不写。

[出示对比 A]

师:咱们看一段话——“周末我和小宇去公园,我俩打了一会儿羽毛球,他赢了我两次,我赢了他一次,后来我们去小卖部买了一根烤肠,烤肠真香。”——这一段,贴到“美景明信片墙”上,行不行?

参考:不行。它在写“我们玩得开心”,不是在写“这儿美”。

师:对了。打羽毛球的输赢、烤肠的味道——跟“这儿真美”有关系吗?

参考:没关系。

师:这块磁铁吸不过去,它就不能写进来。

[出示对比 B]

师:再看这段——“公园真美。滑梯下的草地软绵绵的,踩上去像踩在棉花上;荷花池一片粉,荷叶举着小水珠;池边的柳树梳着自己长长的头发。”——这段呢?

参考:可以,每一句都在说“美在哪儿”。

师:对。三样景物——草地、荷花、柳树——每一样,都被“这儿真美”这块磁铁吸过来了。羽毛球、烤肠,吸不过来,所以不写。这就叫“围绕一个意思写”。

师:磁铁有了,还差一个小帮手,叫“顺序”。你不能东一句西一句,从滑梯跳到柳树,又跳回滑梯。今天老师只教你两种最简单的顺序,你写的时候选一种就够了:

第一种,从远到近。先写你站在门口看到的远的,再写你走进去看到的近的。
第二种,从上到下。先写你抬头看到的(天、树梢),再写低头看到的(花、地、水)。

师:就这两种顺序,你写的时候选一种就行,中间不要跳跃。

### 四、借助观察表,理清思路(9 分钟)

师:好,现在我们手里有了磁铁——“这儿真美”;有了顺序——“远到近”或“上到下”。但还差一样:你得知道你那个地方到底“美在哪几样东西”上。老师给你一张表,叫“五感观察表”。先看。

[黑板/PPT 出示空白表]

| 项目                | 关键词       |
| ----------------- | --------- |
| 这儿是哪里             |           |
| 中心句(例:××真美)       |           |
| 远(或上)看到什么         |           |
| 近(或下)看到什么         |           |
| 看到 / 听到 / 闻到 / 摸到 |           |
| 我选哪种顺序            | 远→近 / 上→下 |

师:这张表不是让你写句子,只是让你填关键词,三五个字也行,写进一格里就够了。先看老师怎么填。老师今天选的地方是——咱们小区门口那条银杏路。

[当众填一张示范]

| 项目                | 关键词                   |
| ----------------- | --------------------- |
| 这儿是哪里             | 小区门口那条银杏路             |
| 中心句(例:××真美)       | 银杏路真美                 |
| 远(或上)看到什么         | 一整条金灿灿的“金色隧道”         |
| 近(或下)看到什么         | 地上铺满扇子形状的叶片           |
| 看到 / 听到 / 闻到 / 摸到 | 风吹叶子哗哗响、有点干草味、踩上去咯吱咯吱 |
| 我选哪种顺序            | 远→近                   |

师:你看,关键词,三五个字。老师没写句子,等会儿动笔了再连起来。

师:轮到你了。把你最开始心里想的那个地方,填到这张表上。先别管句子顺不顺,先填关键词。填不出的那一格可以画一个杠。3 分钟。

[“词语补给站”(仅备查,不要求照抄)]

师:有的同学会卡在“风吹叶子,除了‘呼呼’想不到别的词”。老师在屏幕角落放一个“词语小仓库”,你实在想不出的时候,瞄一眼,挑一个最像你那个地方的——但最好,是它提醒你想起你自己看到的那个词。

> 声音:哗啦啦、沙沙、咯吱咯吱、叮咚
> 颜色:金灿灿、绿油油、雪白雪白、红扑扑
> 摸到:凉凉的、滑滑的、毛茸茸、软绵绵
> 气味:甜丝丝、清清爽爽、干草味、泥土味

师:记住,这个仓库只是个“拐杖”。能自己想到的,就别用它;用它的时候,一格挑一个就够,不要整列抄下来——抄一整列,你那个地方就不见了。

学生动笔填表

[巡视分层指导(教师按学情轻声提示,不打断学生填写)]
[对填不出“远处看到什么”的同学]:想一想,你站在那儿,第一眼远远看过去,是一片什么颜色?(仍无从下笔就给二选一台阶:“是偏绿的,还是偏灰的?”)
[对每一格都想写一整句的同学]:别写整句,三五个字、词语就行,等下再连成一句。
[对没填“看到 / 听到 / 闻到 / 摸到”的同学]:那个地方有声音吗?有味道吗?没有也可以画杠,不勉强。(若孩子盯着“词语补给站”整列抄):只挑一个最像你那儿的,其他划掉;或者想想你自己听到的是什么。

师:好,3 分钟到。同桌之间换一下表,看看对方写的是什么。一个人挑出对方那张表里你最想“亲眼去看看”的一格,跟他说:“你这一条写出来,我肯定能看见。”

学生互动分享(同桌互看 1 分钟,各夸 1 条)

(教师总结)这张表,就是等下写作的地基。一会儿动笔,不用从零开始,从这张表里挑出两到三条最像“那块磁铁能吸的”,连成段就好。

师:动笔之前,还差最后 30 秒,定一件事——顺序。看你表格最后一行,你选的是“远→近”还是“上→下”?选好的同学,手指头点着你的表,小声把顺序念一遍给自己听:“我先写远的＿＿＿,再写近的＿＿＿。”(老师快速点 1 位同学说出来作示范,如“我先写远远一片绿,再写近处的小亭子”。)

师:就这样,顺序心里有数了,等下写就不会东一句西一句。

### 五、教师出示样稿(8 分钟｜可压缩点:时间紧时“写具体”追问保底问第 1 个“哪一句让你看见”,把秘密点透;“出现几次”“几样景物”两问可并入教师一句话总结)

师:你的表填好了,老师的表也填好了。下面老师给你看,老师把这张表,变成了一段什么样的话。注意,这不是范文,是老师亲自动笔写给你看的。看老师是怎么把表里那几个关键词,被“银杏路真美”这块磁铁,一个一个吸过来的。

> 【教师示范文】
>
> 我们小区门口那条银杏路,真美。
>
> 站在路口远远看过去,整条路像一条金色的隧道。两排银杏树在头顶上手牵着手,叶子被太阳一照,闪着金灿灿的光。风一吹,叶子哗哗地响,一片一片往下飘——空中飘的、地上铺的,全是小扇子。
>
> 走近一些,这些小扇子就铺到脚边了。低头一看,地砖完全看不见了,踩上去咯吱咯吱响,像踩在很厚的金色地毯上。蹲下来捡一片,叶柄还带着一点点干草的味儿。我顺手把它夹进书里——这条银杏路真美,我想把它一片一片,带回家。

师:老师先问两个问题。第一,“银杏路真美”这一句,在老师这段话里一共出现了几次?

参考:两次。开头一次,结尾一次。

师:对。开头出现一次,结尾又呼应了一次——这样能让磁铁的吸力变得最强。

师:第二个问题——老师从头到尾,一共写了哪几样景物?

参考:金色隧道(远)、银杏树和飘下来的叶子(中)、脚下的落叶和干草味(近)。

师:对,就三样,都被“银杏路真美”这块磁铁吸过来了。路上谁走过、我跟谁说了话,都没写,因为吸不过来。还有,你看老师走的顺序——远(整条路)→近(脚下的叶子),从头到尾就这一条路,没有跳来跳去。

师:好,现在老师问最要紧的第三个问题——这段话里,哪一句让你一下子就“看见”了那条银杏路?挑一句出来。

学生互动分享(请 2–3 人各挑一句,如“叶子被太阳一照,闪着金灿灿的光”“踩上去咯吱咯吱响,像踩在很厚的金色地毯上”“风一吹,叶子哗哗地响”)

师:你们挑的这几句,藏着一个秘密。老师从头到尾,“美”字没多写,你们却觉得美——因为老师没写“很美”,老师写的是“金灿灿”,那是看到的颜色;写的是“咯吱咯吱”“哗哗”,那是踩到、听到的声音;写“像一条金色的隧道”“像踩在金色地毯上”,那是打了个比方,把你没去过的地方,换成了你见过的东西。

师:这其实就是咱们上课一开始玩的那四样——看、听、闻、摸。把“美”拆开,换成看得见的颜色、听得见的声音、摸得到的感觉,再挑一两处打个比方,“美”就活过来了。光写“美”“漂亮”,反而谁也看不见。

师:所以等下你下笔,不用模仿老师写银杏。老师写的是银杏路,你写你的地方。但有几件事,老师做了,你也做——开头出现一次“××真美”,结尾再呼应一次;选一种顺序写;还有最要紧的一件,别只写“美”,把它换成看得见、听得见、摸得到的样子,挑一两处打个比方。

师:课间休息回来,我们就开写。把这张五感表收好,放在桌上左手边;把你心里那个地方再想一遍;带着“这儿真美”这块磁铁,十分钟后见。

本课完。

## 第2课时 · 当堂写作与评改课

### 一、自由写作(25 分钟)

师:回来了。把刚才那张五感表拿出来,放在左手边;稿纸放在面前。

师:老师只交代三句话。

第一句:开头空两格,从“××真美”那一句写起——把你那个地方的名字填进去。

第二句:遇到不会写的字,先用拼音写在那儿,千万不要停下来翻字典、问老师,先把这一段写完。

第三句:你写的时候,老师不打断任何人,老师只在旁边走一走;如果你抬头看老师,老师只看你的稿纸,不说话,等你写完再说。

师:开始。20 分钟。

学生动笔写作

[巡视指导(教师按学情分层、轻声提示,全程不出声打断学生思路。建议第一圈在动笔约 8 分钟时、第二圈在约 13 分钟时各巡视一遍)]

[无从下笔型——握笔不动、盯着稿纸发呆]
师(轻声):看一眼你五感表第三栏,远处那一句。从那一句先写下来,先不管好不好。

[写空型——“很美”“很漂亮”反复出现,景物没出来]
师(轻声):“很美”老师听到了,把那个让你觉得“很美”的东西写一样出来,是花?是树?是水?写一样,具体的。

[书写顺畅型——写得正起劲,头都没抬]
师(从旁边走过,不停,不说话,一秒钟看一眼就走开)

[提前完成型——10 分钟左右说“我写完了”]
师(轻声):好,你回到你的五感表,看看还有哪一格里的关键词没用进去,挑一条最想说的,再补一段下来。补在原来的后面,不删前面的。

[篇幅过短型——18 分钟时只写了两三行]
师(轻声):你写到的那一句很好。从那一句的后面接着写——那个景物,它周围还有什么?还剩 2 分钟,写一句是一句。

师(全班,18 分钟时轻声提醒一次):还有 2 分钟。不用赶,写到结尾的同学,记得再把“××真美”这句话请出来,和开头呼应一下。

师(20 分钟整,温声):笔放下,稿纸不收。

### 二、交流评议,修改收束(20 分钟)

[本环节是“当堂的、轻的”一层:即时反馈(解说员擂台)+ 自我修改(修改符号)+ 同桌互评 + 老师轻点评 + 自然收尾,当堂闭环即可,不在课上逐篇深批。逐篇、围绕技法的深度讲评,见本详案末尾附加的“习作讲评指导环节”(课后或下次课开场用)。学生书写速度有快有慢,擂台宁可少请几人也不赶;有学生没写完不要紧,评、改的是“已经写出来的部分”,不为追求人人写完整篇而打断节奏。]

师:现在咱们开一个“小小解说员擂台”。规矩很简单——你来念你刚才写的那段话,只念中间最得意的两到三句,不念开头也不念结尾;听的同学,听完只说一句话:“我仿佛看见了……”。把这句话的空填出来就好。

师:谁先来?

学生互动分享(每位约 1 分钟,请 4–5 位同学,优先点平时不爱举手的孩子。擂台约 5 分钟,后面还有符号教学和改稿环节;时间宽裕可多请 1–2 人,宁可多几个孩子被“看见”,不赶场)

[异常处理·听的同学填不出“我仿佛看见……”]:老师替他锁定一个词,把空缩到最小——
师:“他刚才说了‘金灿灿’三个字。听到这个词,你眼前是什么颜色?”(孩子答“金色”)→“对,你就看见那片金色了。这就是‘看见’。”

[老师轻点评:每位同学念完,老师都具体地夸一句,只夸一个具体的点,不空洞、不排名。以下为夸法示范,实际换成学生当场念出的句子]
师:“叶子打着旋儿往下落,像一片小金鱼。”——好,这一下,我也“看见”那片叶子在转了。
师:“奶奶家屋顶上的瓦,一片压一片,像鱼鳞。”——你这个“像鱼鳞”,一下子就让人看见了。
师:“巷口的面馆,雾气一团一团飘出来,把招牌都遮住一半。”——好,我闻到了。这是用“看到的”写“闻到的”,真不简单。

(教师总结)你们听刚才念的——好的句子都不是“很美”“非常漂亮”这种话,都是看到的、听到的、闻到的具体的东西。这就是今天老师说的那块磁铁,把“美”吸出来了。

师:接下来,咱们改一改。老师今天教你三个“修改小符号”,这三个符号最常用,记一辈子都好用。

[黑板/PPT 示范三个符号,每个老师当众画一遍]

1. 删除号:把要删的字、词圈起来,从里面画一条斜线穿过去。把多写的字、重复的字删除掉。
2. 增补号:在要补字的地方,从下往上写一个尖尖朝上的“∨”,把要补的字写在符号上面那个空里。把漏掉的字补进去。
3. 改正号:把错字圈起来,在旁边的空白处写上对的字。

师:这三个修改符号,现阶段已经够用了。

师:对照三条标准,自己改自己的稿。

| 档位   | 自检的话                                                |
| ---- | --------------------------------------------------- |
| 基础过关 | 我写出了那个地方,有几样景物,句子能让人读得通。                            |
| 良好达标 | 我从头到尾都在围着“××真美”那句话写,我用了一种顺序(远到近 或 上到下),写了景物的颜色、形状。  |
| 优秀进阶 | 我的顺序很清楚,我写了 2–3 样最能代表“美”的景物,我用上了一些好词或者比喻,让人读了想去看一眼。 |

师:从下往上看,看自己今天到了哪一档。然后用刚才那三个符号:多的字圈掉,漏的字补上,错的字改正。3 分钟,改不完不要紧,先改你最想改的那一两处。

学生动笔修改

师:好,同桌之间换一下稿子。看完只做一件事——用波浪线,在同桌那篇里画出一个写“颜色、声音、气味或者摸到的感觉”的词。比如“金灿灿”“哗啦啦”“凉凉的”,挑一个画出来。1 分钟。

师:如果你找了一圈,一个这样的词都没找到——别空着,你帮他想一个:他写的那个地方,你觉得会有什么声音、什么颜色?在旁边轻轻补上一个,再把稿子还给他。

学生互动分享(同桌互画/互补,1 分钟)

师:谁的稿子上被同桌画了波浪线?把那个词,连着那一句念出来给全班听。

学生自由分享(请 2 人各念出被同桌画了波浪线的那个词,连着所在的那一句。)

师:你听,每一句都是看得见、听得见、摸得着的。这就是今天咱们一起做成的事。

师:还记得我们上课时说的那件事吗?咱们要做一面“美景明信片墙”。今天写的这一段,就是你贴在墙上的那一张明信片。下课之后,老师把每位同学的稿子收上去,工工整整誊到卡片上,贴到教室后面那面墙上。班里的同学下了课会去看,接你下课的爸爸妈妈也会站在那里看一会儿。

师:你那个地方——可能是奶奶家屋顶,可能是小区那条小路,可能是上学路上你天天经过却从来没认真看过的那个拐角——从今天起,因为你写了这一段,别人也能“看见”它了。

师:走出这间教室之前,老师只多说一句:回家的路上,放慢一点,看一眼窗外。如果你今天看见的那个地方,跟你早上看到的,有一点点不一样了——那就是这堂课真正成功的时候。

师:下课。

本课完。

## 附:习作讲评指导环节(可选 · 单次课课后用 / 系列课作下次课开场用)

> 说明:本环节不计入两节连排的 45+45,是给授课老师的一块可灵活取用的深度讲评指导。本课第 2 课时已完成“当堂的轻反馈”(解说员擂台 + 自我修改 + 同桌互评 + 老师轻点评 + 自然收尾);本环节做的是第 2 课时容不下的“逐篇、围绕技法的深度讲评”。单次课可在课后通读习作后,另找时间集中讲评一次;系列课建议放在下一次写作课开场,约 15–20 分钟,先讲评这次的《这儿真美》,再进新课。本环节评的是学生当堂已写完的稿,不需要学生回家再写。
>
> 真实性提示:下面师话里凡 ＿＿＿ 处都是占位,务必换成本班学生作品里真实写出的句子;不要照搬本详案的示范文,更不要编一段“学生作品”充数。

### 一、选稿(课前准备)

老师课后通读全班习作,挑出 2–3 篇代表作,覆盖不同层次:

- 一篇较好的:围绕“××真美”写、顺序清楚、把景物写具体(用了颜色/声音/触感的词,或打了比方);
- 一篇中等的:中心和顺序都在,但多数句子还停在“很美”“很绿”,没有展开;
- 一篇有典型问题的:或跑题(写成了玩耍、吃东西),或东一句西一句没顺序,或通篇只有“美”“漂亮”。

(把选中的几篇誊清或拍图投屏;不具名,或先征得学生同意。)

### 二、讲评走法(每篇约 3–5 分钟,围绕本课技法点)

讲评只对准这节课教的三件事——围绕“××真美”这一个意思、按一种顺序、把“美”写具体(换成看得见听得见摸得到的样子),不漫无边际地挑全部毛病。每篇按“先肯定一处、再点一处可改”走。

师:先看第一篇。大家听老师念这一句——＿＿＿(占位:念该生最出彩的一两句)。这一句好在哪儿?好在他没有写“很美”,他写的是＿＿＿(占位:点出他用的具体词,如某个颜色、某个声音,或某个比方)——一下子就让人“看见”了。

(教师总结)这就是咱们上节课说的:把“美”换成看得见、听得见、摸得到的东西。

师:再看第二篇。这一篇围绕“美”写、顺序也清楚,就差一步——好些地方还停在“很美”“很绿”。咱们一起帮他改一句:他写“＿＿＿很美”(占位),这个东西是什么颜色?什么形状?(请全班补一两个具体的词)你看,换成“＿＿＿”(占位:填刚补出的具体说法),这就比“很美”活了。

(教师总结)改稿不是从头重写,是挑一两句“只写了美”的,把它换成具体的样子。

师:第三篇,老师想跟大家讨论一个问题——＿＿＿(占位:针对该篇的典型问题提问,如:这一段写得很热闹,可它写的是“这儿美”,还是“我们玩得开心”?)。

学生互动分享(引学生发现问题、说出怎么调整,扣回“这块磁铁只吸跟‘美’有关的”)

### 三、收尾(回扣技法、留迁移)

师:今天讲评的这几篇,好就好在用上了咱们《这儿真美》学的那几招——围绕一个意思、按一种顺序、把“美”写具体。下次你再写一个地方,记住:别只写“美”,把它换成看得见、听得见、摸得到的样子。

[给老师的提示]
- 讲评全程对事不对人:夸具体的句子,不排名、不比“谁写得好谁写得差”。
- 时间紧时讲两篇也可以(一篇“写具体的好例”+ 一篇“只写了美的待改”),保证学生听到“怎么把美写活”这一条。
- 若用于系列课开场,讲评完直接接新课导入,不必再回头布置《这儿真美》的修改任务。

本环节完。
