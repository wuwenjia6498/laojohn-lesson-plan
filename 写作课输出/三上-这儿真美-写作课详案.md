# 《这儿真美》· 写作课教学设计
三年级上册·第六单元 校内同步写作

## 一、教案提纲表

| 项目 | 内容 |
| --- | --- |
| 基本信息 | 课题：三年级上册·第六单元《这儿真美》（写景·校内同步）<br>课时：2 节 × 45 分钟，同次连排 |
| 核心技法 | 主线：围绕一个意思写（只写跟“美”有关的景物，不沾边的不写）<br>顺序：按一种空间顺序（远→近 / 上→下）<br>落地：用五感把美写具体（分步聚焦：颜色形状→细节→声音） |
| 工具与任务 | 构思工具：写作构思表（填关键词，3 分钟）<br>贯穿任务：美景明信片墙（引入真实读者） |
| 评价反馈 | 即时反馈：小解说员分享（“我仿佛看见了……”）<br>自检互评：三档标准自改；同桌互找“感官词”<br>课后延伸：习作讲评环节（备选，逐篇深批） |

## 二、核心素养教学目标

【语言运用】能围绕中心句“这儿真美”挑出 3–4 处最能代表“美”的景物入文，并按“从远到近”或“从上到下”一种顺序写下来，做到有条理；能调动看、听、闻、摸“五感”的词，把笼统的“美”换成具体可感的画面，试着打个比方；掌握开头空两格、标点占一格的写法。

【思维能力】借助“写作构思表”，经历从实地观察到提炼、归类关键词的过程，练习信息提取与整合；通过分步聚焦写景物的练习，建立由浅入深把细节写开的方法，改掉只写“很美”、篇幅过短的毛病。

【审美创造】唤起对校园、公园、小区这些日常环境的观察兴趣，学会在平常的身边角落主动发现美；借“美景明信片”的创意改写，体会用文字把美重新写出来、表现出来的乐趣。

【文化自信】通过“美景明信片墙”的真实展示与互评，乐意把自己眼里的身边景致分享给别人，在真实的读者反馈和交流中获得大方表达的成就感和语言自信。

## 第1课时 · 写作指导课

### 一、创设情境，明确任务（6 分钟）

师：同学们，上课之前老师先问大家一句——你心里有没有一个地方，你觉得它特别美？可能是学校操场边那一排树，可能是奶奶家屋后那条河，也可能就是楼下小区那块小小的花圃。先在心里悄悄想一个地方，记住它，等一下要用。

学生自由分享（口头说“我心里那个地方”是哪儿，1–2 句即可，请 2–3 人分享）

师：好，先记住它。今天这节课，老师不是让大家随便写一篇作文，而是想和大家一起做一件事——把教室后面那面墙，变成一面“美景明信片墙”。

师：这面墙上，每个人都有自己的一格。你今天写一段话，把你心里那个地方写下来；等老师把它抄成一张卡片、放进你那一格，班里的同学、来接你下课的爸爸妈妈，走过这面墙，光读你写的那段话，脑子里就能“看见”那个地方——能让人“看见”，你这一格才算成功；要是只写“风景很美”“我很喜欢”，谁也看不见，这一格就白做了。

师：所以今天我们不是在写作文，是在做一张要贴出去、给人看的明信片。你的读者，是真会站在墙前读它的人，不只是老师一个人打分。明白了吗？

参考：明白了 / 嗯 / 那我得写得让人看见

师：好。把你心里那个地方再想一遍。今天下课之前，你要把它写成一段话，写得能让人“看见”。

### 二、观察体验，调动感官（8 分钟｜可压缩：照片精用 3 张、紧时跳第 2 张；“30秒小解说员”保底 1 人、宽裕再加 1 人）

师：那咱们这就开始热身。老师手里有一摞照片，六张，都是身边那种最普通的小角落——校园老槐树下、公园荷塘的一角、奶奶家屋顶上的瓦、小巷面馆门口飘出的热气、小区秋天的银杏路、村口小河边那一堆石头。咱们一张一张看，看的时候有一个规矩——不许说“很美”“很漂亮”这种话。老师问什么，你答什么。

[出示第 1 张图：校园老槐树下]

师：第一个问题——你“看”到了什么？

学生互动分享（请 3–4 人，各说一个不同的看到：槐树叶、地上的光斑、石凳、有人坐着写作业、风一吹影子在动……）

师：再问——你“听”到了什么？想一想，如果你现在就站在这儿，会听到什么？

学生互动分享（请 2–3 人：风吹叶子声、蝉叫、远处篮球落地声、上课铃……）

师：还有，“闻”到了什么？

学生互动分享（请 1–2 人：草味、夏天的味道、有点甜甜的花香……）

[出示第 2 张图：公园荷塘一角]，节奏放快，只问 1 个感官（如“你看到了什么？”请 1–2 人）。

[出示第 3 张图：村口小河边那一堆石头]

师：这张换个问法——如果你现在蹲下来，伸手摸一摸这堆石头，你的手会“摸”到什么？

学生互动分享（请 1–2 人：凉凉的、滑滑的、太阳晒过的地方有点热、缝里有青苔湿湿的……）

师：对，“摸”到的也算。看、听、闻、摸——四样，都能让人“到现场”。

[以上三张图节奏要快，合计 5 分钟内；第 1 张图问看/听/闻、第 3 张图专问“摸”，四种感官都露过一次脸即可。]

师：很好。接下来请一位同学来当一回“小解说员”。老师再随机翻一张图，被点到的同学走到前面，假装自己现在就站在这儿。说一段话（大约 30 秒），只说一件事——“我现在站在这里，我看见……，我听见……，我还闻到了……”。注意，不许说“很美”，用看到的、听到的、闻到的，让别人觉得美。

学生互动分享（请 1 位同学上台，30 秒；时间宽裕再加 1 位。老师全程不打断、不纠错，听完只点评一句——“哎，那一句‘荷花的清香飘过来了’，这一下我也站到那儿了。”）

[异常处理：学生上台憋不出话]：老师不要等，立刻给一个“封闭二选一”台阶，让孩子只需点头或说一个词——
师：“别急。你现在站在这棵树底下，风吹到你脸上，是凉凉的，还是热乎乎的？”（孩子答“凉凉的”）→“好，那就一句：‘风吹过来，凉凉的。’你看，这就说出来了。”
[若仍说不出]：师顺势接“没关系，你先看着这张图，听同学说”，把他先放回座位，不强留台上，避免冷场。

（教师总结）看见、听见、闻到、摸到——等一下写“这儿真美”的时候，就靠这四样。光说“美”是不算数的，要让读你那段话的人，跟咱们刚才一样，在脑子里“听见”“闻到”“看见”。

[五感观察表（参考）：老师贴在黑板一角，这就是刚才说的“看、听、闻、摸”，写景多用前四样，味觉偶尔用得上]

| 感官 | 观察内容    | 细节描述                 |
| -- | ------- | -------------------- |
| 视觉 | 看到了什么？   | 颜色、形状、大小、光泽、明暗对比等。   |
| 听觉 | 听到了什么声音？ | 声音的强度、节奏、频率、来源，是否连续等。 |
| 触觉 | 感觉到了什么？  | 温度、粗糙度、柔软度、硬度、湿润程度等。  |
| 嗅觉 | 闻到了什么气味？ | 气味的浓淡、种类，是否有变化等。     |
| 味觉 | 品尝到了什么味道？ | 味道的酸、甜、苦、辣、咸、鲜等，余味或口感。 |

### 三、学写法：围绕一个意思写（11 分钟）

师：今天我们学一个写景的方法，叫“围绕一个意思写”。课本里这个单元的《美丽的小兴安岭》就用了它——作者写小兴安岭，一个季节一个季节地写，每个季节都只挑这个季节最有代表性的几样景物，别的不硬塞。

师：那咱们这一篇，要围绕的是哪“一个意思”呢？看黑板。

[黑板正中竖写四个大字：这儿真美]

师：“这儿真美”——这四个字，就是我们这篇要围绕的中心意思。接下来写的每一样景物，都得跟“美”有关；跟“美”没关系的，再好玩、再热闹也不写。

师：动笔之前，咱们先来判断两段话——老师出两段，你们看看，它能不能贴上“美景明信片墙”？

[出示对比 A]

师：咱们看一段话——“周末我和小宇去公园，我俩打了一会儿羽毛球，他赢了我两次，我赢了他一次，后来我们去小卖部买了一根烤肠，烤肠真香。”——这一段，贴到“美景明信片墙”上，行不行？

学生互动分享（先让学生举手表态：能贴 / 不能贴）

参考：不行。它在写“我们玩得开心”，不是在写“这儿美”。

师：对了。打羽毛球的输赢、烤肠的味道——跟“这儿真美”有关系吗？

参考：没关系。

师：这一段跟“美”没关系，就不能写进来。

[出示对比 B]

师：再看这段——“公园真美。滑梯下的草地软绵绵的，踩上去像踩在棉花上；荷花池一片粉，荷叶举着小水珠；池边的柳树梳着自己长长的头发。”——这段呢？

学生互动分享（让学生判断：能贴，并说说凭哪一句判断的）

参考：可以，每一句都在说“美在哪儿”。

师：对。三样景物——草地、荷花、柳树——每一样，都跟“这儿真美”有关。羽毛球、烤肠，跟“美”没关系，所以不写。这就叫“围绕一个意思写”。

师：不光《美丽的小兴安岭》，这个单元的《海滨小城》也是这样——写一处地方，都是只围绕一个意思，把最贴这个意思的几样景物挑出来写，别的不塞。（想给学生读一两句课文原文佐证也行，但引原文要确凿；拿不准就像这样概括着说写法，不要硬背原句。）大作家、课本、咱们今天，用的都是这个写法。

师：中心意思定下了，还差一样，叫“顺序”。你不能东一句西一句，从滑梯跳到柳树，又跳回滑梯。今天老师只教你两种最简单的顺序，你写的时候选一种就够了：

第一种，从远到近。先写你站在门口看到的远的，再写你走进去看到的近的。
第二种，从上到下。先写你抬头看到的（天、树梢），再写低头看到的（花、地、水）。

师：就这两种顺序，你写的时候选一种就行，中间不要跳跃。

### 四、借助构思表，理清思路（11 分钟）

师：好，现在我们定下了中心意思——“这儿真美”；也有了顺序——“远到近”或“上到下”。但还差一样：你得把你那个地方“美在哪几样东西”上想清楚。还记得刚才黑板角上那张“五感观察表”吗？照着它的五感，老师再给你一张“写作构思表”，帮你把地点、要写的景物和顺序，都收成几个关键词。先看。

[黑板/PPT 出示空白表]

| 项目                | 关键词       |
| ----------------- | --------- |
| 这儿是哪里             |           |
| 中心句（例：××真美）       |           |
| 远（或上）看到什么         |           |
| 近（或下）看到什么         |           |
| 看到 / 听到 / 闻到 / 摸到 |           |
| 我选哪种顺序            | 远→近 / 上→下 |

师：这张表不是让你写句子，只是让你填关键词，三五个字也行，写进一格里就够了。先看老师怎么填。老师今天选的地方是——咱们小区门口那条银杏路。

[当众填一张示范]

| 项目                | 关键词                   |
| ----------------- | --------------------- |
| 这儿是哪里             | 小区门口那条银杏路             |
| 中心句（例：××真美）       | 银杏路真美                 |
| 远（或上）看到什么         | 一整条金灿灿的“金色隧道”         |
| 近（或下）看到什么         | 地上铺满扇子形状的叶片           |
| 看到 / 听到 / 闻到 / 摸到 | 风吹叶子哗啦啦响、有点干草味、踩上去咯吱咯吱 |
| 我选哪种顺序            | 远→近                   |

师：你看，关键词，三五个字。老师没写句子，等会儿动笔了再连起来。

师：轮到你了。把你最开始心里想的那个地方，填到这张表上。先别管句子顺不顺，先填关键词。填不出的那一格可以画一个杠。3 分钟。

[“词语补给站”（仅备查，不要求照抄）]

师：有的同学会一时想不出词，比如“风吹叶子，除了‘呼呼’想不到别的词”。老师在屏幕角落放一个“词语小仓库”，你实在想不出的时候，瞄一眼，挑一个最像你那个地方的——但最好，是它提醒你想起你自己看到的那个词。

> 声音：哗啦啦、沙沙、咯吱咯吱、叮咚
> 颜色：金灿灿、绿油油、雪白雪白、红扑扑
> 摸到：凉凉的、滑滑的、毛茸茸、软绵绵
> 气味：甜丝丝、清清爽爽、干草味、泥土味

师：记住，这个仓库只是个参考。能自己想到的，就别用它；用它的时候，一格挑一个最适合的就够，不要整列抄下来。

[“选材菜单”（想不出“这儿是哪里”时瞄一眼，挑一个你真去过的地方）]

师：要是“写哪儿”一时想不起来，老师再放一张“选材菜单”，都是身边最普通的地方——

> 校园：操场边的树、花坛、读书角、放学走的小路
> 家附近：小区花园、楼下大树、奶奶家屋后、阳台上的花
> 远一点：公园一角、村口小河、上学路上那个拐角

师：这也只是个参考——最好是它提醒你想起你自己常去的那个地方，别照着挑一个没去过的。

学生动笔填表

[巡视分层指导（教师按学情轻声提示，不打断学生填写）]
[对填不出“远处看到什么”的同学]：想一想，你站在那儿，第一眼远远看过去，是一片什么颜色？（仍无从下笔就给二选一台阶：“是偏绿的，还是偏灰的？”）
[对每一格都想写一整句的同学]：别写整句，三五个字、词语就行，等下再连成一句。
[对没填“看到 / 听到 / 闻到 / 摸到”的同学]：那个地方有声音吗？有味道吗？没有也可以画杠，不勉强。（若孩子盯着“词语补给站”整列抄）：只挑一个最像你那儿的，其他划掉；或者想想你自己听到的是什么。

师：好，3 分钟到。先请一两位同学，照着自己的构思表说一说——你要写哪个地方？最想写的是哪几样景物？不用说成完整的话，把表上的关键词连起来说出来就行。

学生互动分享（请 1–2 位同学照构思表口头说：地点 + 要写的几样景物；老师听完点评一句作示范，如“你挑的这三样都跟‘美’有关，等下照着写就好”）

（教师总结）这张表，等下动笔就照着它写。不用从零开始，从表里挑出三到四条最跟“美”有关的，连成段。

师：动笔之前，再确定一件事——顺序。看你表格最后一行，你选的是“远→近”还是“上→下”？选好的同学，小声把顺序念一遍给自己听：“我先写远的＿＿＿，再写近的＿＿＿。”（老师快速点 1 位同学说出来作示范，如“我先写远远一片绿，再写近处的小亭子”。）

师：就这样，顺序心里有数了，等下写就不会东一句西一句。

### 五、教师出示样稿（9 分钟｜可压缩：紧时只保“哪一句让你看见”一问、点透写具体；“出现几次”“哪几处”并入一句总结）

师：你的表填好了，老师的表也填好了。看老师是怎么把表里那几个关键词，一个一个都围绕“银杏路真美”写进去的。

> 【教师示范文】
>
> 我们小区门口那条银杏路，真美。
>
> 站在路口远远望过去，整条路像一条金色的隧道。两排银杏树在头顶上手牵着手，把天都遮住了，只漏下一点点细碎的光，整条路黄澄澄、亮堂堂的，像谁在地上铺了一条长长的金毯子。
>
> 再往里走几步，抬头看那些树梢。一片片叶子像小小的扇子，被太阳一照，边上闪着金灿灿的光。风一吹，满树的叶子哗啦啦地响，像在悄悄地拍手。
>
> 这一拍手，叶子就一片一片打着旋儿落下来了。空中飘的、半空里转的、慢慢往下沉的，全是金黄的“小扇子”，落到我的头发上、肩膀上，痒痒的，凉凉的。
>
> 走到树底下，脚边早就铺满了厚厚的一层。低头一看，地砖一点儿也看不见了，踩上去咯吱咯吱响，软软的。我蹲下来捡起一片，叶柄上还带着一点点干草的味儿，挑了几片最黄最大的，小心地夹进书里带回家。
>
> 走在这条银杏路上，真美啊！


师：老师先问两个问题。第一，“银杏路真美”这一句，在老师这段话里一共出现了几次？

参考：两次。开头一次，结尾一次。

师：对。开头出现一次，结尾又呼应了一次——这样能让“银杏路真美”这个中心意思最突出。

师：第二个问题——老师从头到尾，按从远到近，写了银杏路的哪几处？

参考：远处整条金色的隧道、走近后头顶树梢上的叶子、半空里打着旋儿飘落的叶子、脚下厚厚的一层落叶。

师：对，从远到近，四处画面，样样都在写“银杏路的美”。路上谁走过、我跟谁说了话，都没写，因为跟“美”没关系。你看老师走的顺序——远（整条路）→近（脚下的落叶），从头到尾就这一条路，一路从远走到近，没有跳来跳去。

师：好，现在老师问最要紧的第三个问题——这段话里，哪一句让你一下子就“看见”了那条银杏路？挑一句出来。

学生互动分享（请 2–3 人各挑一句，如“被太阳一照，边上闪着金灿灿的光”“踩上去咯吱咯吱响，软软的”“满树的叶子哗啦啦地响，像在悄悄地拍手”）

师：你们挑的这几句，藏着一个秘密。老师从头到尾，“美”字没多写，你们却觉得美——因为老师没写“很美”，老师写的是“金灿灿”，那是看到的颜色；写的是“咯吱咯吱”“哗啦啦”，那是踩到、听到的声音；写“像一条金色的隧道”“像小小的扇子”，那是打了个比方，把你没去过的地方，换成了你见过的东西。

师：老师把这个秘密摆成一张“旁批表”，每句用了什么，一眼就看明白——

| 示范文里的句子 | 这一句用了什么 |
| --- | --- |
| 整条路像一条金色的隧道 | 打比方（把没去过的换成见过的） |
| 黄澄澄、亮堂堂、金灿灿 | 看得见的颜色 |
| 满树的叶子哗啦啦地响 | 听得见的声音 |
| 踩上去咯吱咯吱响、软软的 | 摸得到、听得到的感觉 |
| 一片片叶子像小小的扇子 | 打比方 |

师：这其实就是咱们上课一开始说的那四样——看、听、闻、摸。把“美”拆开，换成看得见的颜色、听得见的声音、摸得到的感觉，再挑一两处打个比方，“美”就活过来了。光写“美”“漂亮”，反而谁也看不见。

师：所以等下你下笔，不用模仿老师写银杏。老师写的是银杏路，你写你的地方。但有几件事，老师做了，你也做——开头出现一次“××真美”，结尾再呼应一次；选一种顺序写；还有最要紧的一件，别只写“美”，把它换成看得见、听得见、摸得到的样子，挑一两处打个比方。

师：老师从远到近写了四处，你今天写三处就行；每一处，把它写得能让人“看见”，就很好了。

师：课间休息回来，我们先一起把方法练一遍，再正式动笔写。把这张写作构思表收好；把你心里那个地方再想一遍；记着“这儿真美”这个中心意思，十分钟后见。

本课完。

## 第2课时 · 当堂写作与评改课

### 一、聚焦一处，写下第一组句子（约 5 分钟）

师：回来了。把刚才那张写作构思表拿出来。这节课不忙写整篇——先快写热身：第一句最省事，开头空两格，写一句“××真美”（把你那地方的名字填进去），点出今天要写哪儿。

学生动笔写作（写中心句“××真美”）

师：有了这句开头，再挑一样最想写的景物，圈出来，跟着老师这三步把它写具体，一步写一句。

[黑板/PPT 一侧竖排三步，孩子话]
看清：它是什么颜色、什么形状？
凑近：再细看一点，它身上有什么细节？
加感觉：它有什么声音？有没有气味？摸上去什么感觉？

师：老师先按这三步说一样给你们听——就说咱们看过的那棵老槐树。

[老师边说边在三步下各写一句]
看清：院子里那棵老槐树，叶子绿得发亮。
凑近：一片片叶子像小扇子，边上带着浅浅的锯齿。
加感觉：风一吹，叶子沙沙地响，凑近还有一股淡淡的草木香。

师：看，“××真美”一句开头，再顺着“看清—凑近—加感觉”把一样景物写具体，开头就有了。咱们再一起说一个——谁来，先说说你挑的是哪一样？

学生互动分享（请 1 人说挑的一样景物，如“池塘里的荷花”；老师顺势引“看清，它什么颜色、什么样子？”带全班补一句，再引“凑近细看，有什么细节？有香味、有声音吗？”，当堂把三句连起来）

师：会了。正式写之前，先各自来一次——看你那张写作构思表，挑你最想写的第一样景物，照“看清—凑近—加感觉”这三步，30 秒，给它写下一两句。

学生动笔写作（各自就自己构思表的第一样景物，照这三步写一两句，约 30 秒）

### 二、自由写作（约 22 分钟）

师：好，停一下。开头那句“××真美”和第一样景物你都写出来了。接着往下，再从构思表里挑两样景物，照“看清—凑近—加感觉”那三步写具体；一样写好了接着写下一样，遇到不会写的字先空着、别停下来。

师：开始，一共 20 分钟。老师头一圈就来看你，景物写得开不开。

学生动笔写作

[巡视指导（教师按学情分层、轻声提示，全程不出声打断学生思路。建议第一圈在动笔约 3–4 分钟时巡视一遍——重点看“第一样景物有没有写开、写具体”，第二圈在约 13 分钟时再巡一遍）]

[无从下笔型：握笔不动、盯着稿纸发呆]
师（轻声）：看一眼你写作构思表第三栏，远处那一句。从那一句先写下来，先不管好不好。

[写空型：“很美”“很漂亮”反复出现，景物没出来]
师（轻声）：“很美”老师听到了，把那个让你觉得“很美”的东西写一样出来，是花？是树？是水？写一样，具体的。

[书写顺畅型：写得正起劲，头都没抬]
师（从旁边走过，不停，不说话，一秒钟看一眼就走开）

[提前完成型：12 分钟左右说“我写完了”]
师（轻声）：好，你回到你的写作构思表，看看还有哪几格的关键词还没用进去，挑一两条最想说的，照那三步接着补下去。补在原来的后面，不删前面的。

[篇幅过短型：18 分钟时只写了两三行]
师（轻声）：你写到的那一句很好。想想刚才那三步——它什么样子？有没有声音？像什么？照着接一句是一句。还剩 2 分钟，写一句是一句。

师（全班，18 分钟时轻声提醒一次）：还有 2 分钟。不用赶，写到结尾的同学，记得再把“××真美”这句话请出来，和开头呼应一下。

师（20 分钟整，温声）：笔放下，稿纸不收。

### 三、交流评议，修改收束（约 18 分钟）

[本环节是“当堂的、轻的”一层：即时反馈（小解说员分享）+ 自我修改（修改符号）+ 同桌互评 + 老师轻点评 + 自然收尾，当堂闭环即可，不在课上逐篇深批。逐篇、围绕技法的深度讲评，见本详案末尾附加的“习作讲评指导环节”（课后或下次课开场用）。学生书写速度有快有慢，这一轮宁可少请几人也不赶；有学生没写完不要紧，评、改的是“已经写出来的部分”，不为追求人人写完整篇而打断节奏。]

师：现在请几位同学来当小解说员。你来念你刚才写的那段话，只念中间最得意的两到三句，不念开头也不念结尾；听的同学，听完只说一句话：“我仿佛看见了……”。把这句话的空填出来就好。

师：来，把你写的那几句念给大家。

学生互动分享（每位约 1 分钟，请 4 位左右同学，覆盖面广些、别集中在几个常发言的孩子。这一轮约 5 分钟，后面还有符号教学和改稿环节；宁可少请几个也不拖堂——逐篇被“看见”留到课后的“习作讲评指导环节”）

[异常处理：听的同学填不出“我仿佛看见……”]：老师替他锁定一个词，把空缩到最小——
师：“他刚才说了‘金灿灿’三个字。听到这个词，你眼前是什么颜色？”（孩子答“金色”）→“对，你就看见那片金色了。这就是‘看见’。”

[老师轻点评：每位同学念完，老师都具体地夸一句，只夸一个具体的点，不空洞、不排名。以下为夸法示范，实际换成学生当场念出的句子]
师：“叶子打着旋儿往下落，像一片小金鱼。”——好，这一下，我也“看见”那片叶子在转了。
师：“奶奶家屋顶上的瓦，一片压一片，像鱼鳞。”——你这个“像鱼鳞”，把那片瓦顶写到眼前了。
师：“巷口的面馆，雾气一团一团飘出来，把招牌都遮住一半。”——好，我闻到了。这是用“看到的”写“闻到的”，真不简单。

（教师总结）你们听刚才念的——好的句子都不是“很美”“非常漂亮”这种话，都是看到的、听到的、闻到的具体的东西。这就是今天老师说的：把“美”换成看得见、听得见、摸得到的样子，写出来了。

师：接下来，我们来改作文。对照三条标准，自己改自己的稿。

| 档位   | 自检的话                                                |
| ---- | --------------------------------------------------- |
| 基础过关 | 我写出了那个地方，有几样景物，句子能让人读得通。                            |
| 良好达标 | 我从头到尾都在围着“××真美”那句话写，我用了一种顺序（远到近 或 上到下），写了景物的颜色、形状。  |
| 优秀进阶 | 我的顺序很清楚，我写了 3–4 样最能代表“美”的景物，我用上了一些好词或者比喻，让人读了想去看一眼。 |

师：从下往上看，看自己今天到了哪一档。然后用修改符号把稿子理一遍：多的字圈掉，漏的字补上，错的字改正。4 分钟，改不完不要紧，先改你最想改的那一两处。

学生动笔修改

师：好，同桌之间换一下稿子。看完只做一件事——用波浪线，在同桌那篇里画出一个写“颜色、声音、气味或者摸到的感觉”的词。比如“金灿灿”“哗啦啦”“凉凉的”，挑一个画出来。1 分钟。

师：如果你找了一圈，一个这样的词都没找到，你就帮他想一个：他写的那个地方，你觉得会有什么声音、什么颜色？在旁边补上一个。

学生互动分享（同桌互画/互补，1 分钟）

师：谁的稿子上被同桌画了波浪线？把那个词，连着那一句念出来给全班听。

学生自由分享（请 2 人各念出被同桌画了波浪线的那个词，连着所在的那一句。）

师：你听，每一句都是看得见、听得见、摸得着的。

师：还记得我们上课时说的那件事吗？咱们要做一面“美景明信片墙”。今天写的这一段，就是你贴在墙上的那一张明信片。下课之后，老师把每位同学的稿子收上去，抄到卡片上，贴到教室后面那面墙上。班里的同学会过来看，接你下课的爸爸妈妈，也会在墙前停下来，读一读你写的那段话。

师：你那个地方——可能是奶奶家屋顶，可能是小区那条小路，可能是上学路上你天天经过却从来没认真看过的那个拐角——因为你写了这一段，别人也能“看见”它了。

师：最后，老师再说一句。回家的路上，放慢一点，多看一看。要是哪个你天天路过的地方，今天让你觉得跟平常不太一样了，那就用今天学的方法，把它写下来。

师：下课。

本课完。

全课完。

## 附：习作讲评指导环节（可选 · 单次课课后用 / 系列课作下次课开场用）

> 说明：本环节不计入两节连排的 45+45，是给授课老师的一块可灵活取用的讲评指导环节。此环节可在课后通读习作后，另找时间集中讲评一次；或在下一次写作课开场用约 15 分钟，先讲评再进新课。老师根据自己情况灵活安排。
>
> 真实性提示：下面师话里凡 ＿＿＿ 处都是占位，务必换成本班学生作品里真实写出的句子。

### 选稿（课前准备）

老师课后通读全班习作，挑出 2–3 篇代表作，覆盖不同层次：

- 一篇较好的：围绕“××真美”写、顺序清楚、把景物写具体（用了颜色/声音/触感的词，或打了比方）；
- 一篇中等的：中心和顺序都在，但多数句子还停在“很美”“很绿”，没有展开；
- 一篇有典型问题的：或跑题（写成了玩耍、吃东西），或东一句西一句没顺序，或通篇只有“美”“漂亮”。

（把选中的几篇誊清或拍图投屏；不具名，或先征得学生同意。）

### 讲评流程（每篇约 3–5 分钟，围绕本课技法点）

讲评只对准这节课教的三件事——围绕“××真美”这一个意思、按一种顺序、把“美”写具体（换成看得见听得见摸得到的样子），不漫无边际地挑全部毛病。按“先肯定、再点可修改处”建议。

师：先看第一篇。大家听老师念这一句——＿＿＿（占位：念该生最出彩的一两句）。这一句好在哪儿？好在他没有写“很美”，他写的是＿＿＿（占位：点出他用的具体词，如某个颜色、某个声音，或某个比方）——读着眼前就有了画面。

（教师总结）这就是咱们上节课说的：把“美”换成看得见、听得见、摸得到的东西。

师：再看第二篇。这一篇围绕“美”写、顺序也清楚，就差一步——好些地方还停在“很美”“很绿”。咱们一起帮他改一句：他写“＿＿＿很美”（占位），这个东西是什么颜色？什么形状？（请全班补一两个具体的词）你看，换成“＿＿＿”（占位：填刚补出的具体说法），这就比“很美”活了。

（教师总结）改稿不是从头重写，是挑一两句“只写了美”的，把它换成具体的样子。

师：第三篇，老师想跟大家讨论一个问题——＿＿＿（占位：针对该篇的典型问题提问，如：这一段写得很热闹，可它写的是“这儿美”，还是“我们玩得开心”？）。

学生互动分享（引学生发现问题、说出怎么调整，扣回“只写跟‘美’有关的内容”）

### 收尾（点回技法、引向今后的写作）

师：今天讲评的这几篇，是为了我们学会那几招——围绕一个意思、按一种顺序、把“美”写具体。下次你再写一个地方，就别停在“美”“漂亮”，把它写具体。


本环节完。
