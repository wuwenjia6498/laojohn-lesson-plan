# 选择题命题硬规则 + 引擎适配写法 + 交付前自检

本文件管"每道题怎么写才合格、整份 .md 怎么写才能被 docx 引擎正确排版"。`dimension-rubric.md` 管"出哪些维度、各几道、用什么题型"；本文件管"写出来的题对不对、卷子排得出不出"。**两份都要遵守。**

---

## 一、单项选择题的硬规则

1. **四个选项 A/B/C/D，唯一正确答案**。不设多选、不设"以上都对/都不对"这类偷懒选项。
2. **干扰项必须是"书里站得住的近似项"**——取自同书的其他人物、其他事件、相邻情节、易混细节。绝不编造书中不存在的人/事/物当干扰项（编造干扰项 = 真实性红线违规）。
3. **题干自足**：不依赖"根据上题""如图"等；每题独立可答。
4. **一题一考点**，不把两个问题塞进一道题。
5. **难度与年级相称**：低段题干短、考点具象（人物/事件/规则）；高段才上推断、评价、迁移等抽象考点（与年级题量表的维度分布天然对应）。

## 一·补：干扰项要有"迷惑性"（本 SKILL 头号质量红线）

> 最易翻车的不是答错事实，而是**干扰项太直白、错项一眼看穿、难度偏低**。合格的题应让学生**经思考、回到书里甄别**才能选对，而不是靠排除明显荒谬项秒选。下面是把干扰项做"难"的硬要求与技法。

**六条技法（每道题至少用上其中 2–3 条）：**

1. **同书真元素·张冠李戴**：干扰项用书里**真实存在**的人/事/物/原话，但**安错对象、错环节、错卷章、错因果**。例：问甲做了什么，拿乙真做过的事去当干扰；把往事线人物的事安到主线人物头上。不熟书者必中招。
2. **"半对"项**：陈述本身**部分属实**，但以偏概全 / 不完整 / 不是题干所问的那一面 / 只对了一半。它最具迷惑性，因为"看着像对的"。
3. **似是而非的解读（评价·转化维专用）**：**严禁**放"价值观一眼即错"的废项（如"命运注定、努力无用""讨好上级才有出路""谁有钱谁横"）——这种学生闭着眼都能排除。改用**看似有理、实则偏离文本依据**的解读：方向沾边但夸大、缩小、张冠李戴或停留在表层。
4. **四项等长等具体等口吻**：长度、句式、具体程度、语气一致；**不让正确项因为"最长 / 最全面 / 最像标准答案"而被认出**。正确项别堆"既…也…、最…、全面"等"答案腔"，干扰项别露"都、全、只有、必定、毫无"等一票否决的极端词。
5. **贴着真实误读设套**：先想"这道题学生最可能怎么记错/混淆"（相似情节混淆、书外信息当书内、近义概念错位、把结果当原因），把那个误读**做成最像的那个干扰项**。
6. **干扰项之间也要拉开**：四项不要三个明显错+一个对；让两三个选项都"乍看可选"，逼学生逐项回书核对。

**反例 → 改进（务必照此标准自检每题）**

- ✗ 太直白（错项一眼排除）：
  > 零蛋最过人的本领是？ A.心算极快(对) B.力气最大 C.个子最高 D.认字最多
  > —— B/C/D 与"瘦小、不识字"的常识/印象直接冲突，秒排。
- ✓ 有迷惑性（干扰项都"沾边"、需回书）：
  > 下列对零蛋的描述，**符合书中事实**的是？ A.他身板单薄却挖洞最快、心算极快(对) B.他力气是 D 组最大的，所以挖得最快 C.他识字不多，但算术是斯坦利教会的 D.他因为最瘦弱，挖洞总是最慢一个
  > —— 每项都把"瘦小/挖洞/识字/心算"等真元素重新组合错位，必须回书才能分辨。

**自检动作**：每写完一题，逐个干扰项问自己——"这个错项，**不读书光靠常识/排除法**能不能删掉？"凡能秒删的，按上面技法改写，直到三个干扰项都需要回书才能否定。

## 一·补二、选项长度必须均衡——"正确项不许总是最长那个"（并列头号质量红线）

> 真实复盘发现的最严重作弊路径：**正确项总是四项里最长、修饰最多、写得"最全"的那个**，学生不读书、只用"挑最长 / 最周全的选"就能稳中。成因：写作者为了把正确项写得"无可挑剔"，给它堆满限定与列举（"既…也…""并且…""最…全面"、多重顿号清单），又把干扰项写成短词组——长度本身泄了底。这条必须当成与"干扰项迷惑性"并列的红线来卡。

**硬要求：**

1. **正确项不得系统性最长。** 全卷写完，逐题数四个选项的字数，记下正确项在四项中的长度排名（最长记 1）。**统计"正确项＝最长项"的题数 ÷ 总题数，必须 ≤ 1/3（理想接近随机的 1/4）。** 超标就回去改：把偏长的正确项压短，或把对应干扰项扩写到等长。
2. **单题内四项长度拉齐**：最长项与最短项字数**不超过约 1.5 倍**；不允许"正确项一长串、干扰项三个短词"。
3. **正确项禁堆"答案腔"**：不靠"既…也…""而且/并…""最…/全面/层层/彻底"这类多重列举与绝对化把它写成"显然最周全"的一项。**正确性要藏在一个关键事实差异里，而不是靠信息量取胜**——一句干净、与干扰项等重的陈述，凭"是否符合书中事实"取胜，而非凭"说得最多最满"。
4. **干扰项要同样写足**：每个干扰项都写到与正确项等长、等具体、同口吻（呼应§一·补技法4）。宁可把三个干扰项都加细节，也不要让正确项"鹤立鸡群"。

**反例 → 改进**

- ✗ 长度泄底：
  > A. 挖洞 B. 挖洞、运土 C. 既挖洞也心算极快、还背着零蛋上山，最见善良(对) D. 挖得慢
  > —— 正确项明显最长最全，"挑最长"即中。
- ✓ 等长改写：四项都写成一句具体动作（"背昏倒的零蛋摸黑爬上大拇指山" / "教零蛋认字换对方帮挖洞" / "推断出金管是凯特的口红管" / "把金管交给 X 光"），长度相当，靠"哪件事最能体现善良"区分，必须懂情节。

## 一·补三、"没读过书也能选对"＝全卷红线（评价·转化两维重灾区）

> 第3类翻车：**正确项是唯一"听上去最有道理 / 最正能量 / 最通顺"的那个**，一个没读过本书、只有同年级常识与语感的学生，凭"哪个说得对"就能稳定选对。这不是在测阅读理解，是在测常识。§一·补管"干扰项别一眼看穿"，本条管另一面——**正确项别一眼看穿**。

**总判别动作（每题必做）**：遮住书，只看题干与四项，问自己——
> "我能不能凭'哪个最有道理 / 最正面 / 最顺口'，**不依赖任何书内具体事实**就选出来？"

**能 → 这道题不合格，重写。** 合格题的判别信息，必须是**非读者无从知道的书内具体事实**（具体情节、某人物在某处境下的具体选择、书中具体因果、具体细节），而不是普世价值或语感。

**评价·转化两维专项收紧（这两维最容易写成"常识单选"）：**

1. **禁"普世美德单选"式迁移题。** 凡四个选项里只有一个是正面价值观、其余三个是"明显歪理"（靠运气 / 宿命 / 拍马讨好 / 唯钱是图 / 恃强凌弱 / 回避退缩），一律重写——这种题不读书也能选。判据：把书名遮掉，这道题是否变成一道"思想品德常识题"？是，则不合格。
2. **迁移题要锚定书中具体情节/人物抉择。** 与其问"这给我们的启示最贴近哪种做法"（答案必是那条放之四海皆准的美德），不如把选项贴着"书里**谁**在**什么具体处境**下**怎么做**"，让选对依赖记得书中事实。
3. **"为观点找证据"型，四个证据都要"沾主题边"。** 给本书一个观点、四个书内情节里选最能支撑的——**四个选项必须都像能支撑（都涉及主题相关的人和事）**，不许放"泅水登岸""搭船回国"这类中性背景事件当陪衬，否则又退化成排除法。
4. **评价题干扰项用"偏离文本依据的解读"，不用"价值观一眼即错"。** 干扰项是"方向沾边但夸大 / 缩小 / 张冠李戴 / 停在表层"的评价（呼应§一·补技法3），而不是"把荒诞手法读成正面赞美"这种谁都能排除的废项。

**反例 → 改进**

- ✗ 常识单选（不读书也选得出）：
  > 《洞》的启示最贴近？ A.守信担当能化解遗憾(对) B.运气够好就能闯关 C.祖辈的债该后代还 D.坚持到底必有重赏
  > —— A 是唯一正能量项，五年级学生闭着眼也选 A。
- ✓ 锚定情节（须懂书）：把四项都改成"斯坦利在书中做过/可能做的具体选择"，或改"为观点找证据"且四个情节都与"守信—解咒"主题相关，逼学生回到情节甄别哪一处真正对应。

## 二、真实性红线（项目级铁律，本 SKILL 不豁免）

> 越是名著越容易凭记忆记错——一律以《书籍档案》为唯一事实源。

- **题干、选项、解析涉及的情节 / 人物 / 章节 / 数字，只能来自该书《书籍档案》**，禁止凭模型记忆补写或"圆"细节。档案没写的，不出这道题。
- **伪摘录禁令**：不输出带引号的"原文题干"——除非该句出自档案「关键片段·可引用原文」或「备用引文」（这些已逐字核对）。需要呈现情节时用**概述**，不要伪造成"原文"。
- **无页码就不写页码**：若档案声明本书"无页码、定位用章节号"（如《洞》），则题干/解析一律用章节号定位，出现"第X页"即为编造。
- **区分"书内"与"书外"信息**：档案里「作者&背景」「获奖信息」「拓展资源」是外部核实信息、**不是书中正文**，不得作为"书里写道"来命题（可作个别"关于这本书"的常识题，但不能冒充情节）。
- 拿不准某个细节档案有没有写——**回档案查，查不到就换一道能查到的题**，不要赌记忆。

## 三、docx 引擎适配写法（复用 `md_to_laojohn_docx.py`，引擎零改动）

测评卷 .md 必须按下列写法，否则会被引擎误渲染（已逐条核对引擎源码）：

1. **H1 不带《》**：写 `# 洞 阅读测评卷`，**不要**写 `# 《洞》阅读测评卷`。
   - 原因：引擎见到 H1 里的《》会判定为课案、自动注入"教学设计"封面页（标签写死"教学设计"，不适用测评卷）。不带《》→ 无封面页、直接是洁净试卷，仍保留页眉品牌条（老约翰深度阅读 / 阅读·思辨·表达）+ 页脚页码。
2. **题号、答案序号用全角 `1．`（或 `1、`）**，**禁用** `1.` / `1)`。
   - 原因：引擎 `LIST_RE` 会把 `1.`/`1)` 当列表标记**剥掉**，题号会消失。全角 `．`/`、` 不被命中，安全。
3. **选项每项独占一行、字母前缀**：`A. 偷了球鞋`（半角 `A.` 安全，字母前缀不被 `LIST_RE` 命中）。每个选项一行。
4. **禁用 markdown 无序列表 `- ` / `* `**（会被压平成普通段落、丢标记）。
5. **禁用 `**` `*` `__` 行内强调**（项目 §4 铁律；引擎虽能转加粗，但正文一律不用）。
6. **通篇全角弯引号** `""` `''`，严禁 ASCII 直引号（项目铁律；引擎有安全网但源文件就要对）。
7. **答案逐题内联**：每道题的四个选项之后，紧跟一行 `答案：X　【维度】解析…`（不另设卷末"参考答案"汇总区）。五个维度用 `###` 分组（不分页、连续流排）；**全卷不用 `##`**（无需分页，整卷连续）。
8. **不写姓名/班级/得分行、标题不带"卷"**：这些题最终**录入到测试系统**、不是纸质考卷，所以不做"姓名＿＿ 班级＿＿ 得分＿＿"的卷头、标题用"阅读测评"而非"测评卷"。
9. **题与题之间空一行**：源 .md 里每题之间留一个空行（便于阅读与复制录入）；docx 端由引擎对题号行（`^\d+．`）自动加段前距，无需手动处理。

### 标准骨架（照此写）

```
# 洞 阅读测评
五年级（L5）· 整本书阅读测评 · 共20题

### 一、提取信息（4题）

1．斯坦利被法官判定做了什么，因而被送进翠湖营？
A. 偷了克莱德·利文斯顿的运动鞋
B. 在学校打架
C. 弄坏了同学的笔记本
D. 偷了一袋葵花子
答案：A　【提取信息】鞋从天桥掉下砸中斯坦利，他拿着鞋被捕，法官判他"蹲监狱或去翠湖营"，他选了翠湖营（第2、6章）。

2．……
（……连续编到 20，每题之间空一行，每题选项后都紧跟一行"答案：…"）

### 二、整体感知（4题）
……
```

> 答案行写法：`答案：+ 正确字母 + 全角空格　+ 【维度】+ 一句话解析（含章节定位）`。`答案：` 与 `【提取信息】` 等都不会被引擎特殊渲染（引擎只认 `参考：` 和 【知识技能】等课案标签），原样显示即可。

## 四、交付前自检清单（逐条过，借鉴 review-rubric「先摘后算」精神）

**A. 合规（客观可核，不过则改）**
- [ ] 维度题量 = 年级题量表对应列（把五维实际题数数出来，写成 `4/4/5/4/3` 与表核对）。
- [ ] 全卷连续编号、无跳号无重号；**总数：L1–L2 = 15、L3–L6 = 20**。
- [ ] 每题恰好 4 个选项、有且仅有 1 个正确答案。
- [ ] 每题选项后都紧跟一行 `答案：X　【维度】解析`（含正确字母 + 维度标签 + 一句话解析）。
- [ ] 解析定位用章节号（无页码档案不得出现"第X页"）。
- [ ] H1 不带《》、标题不带"卷"；无姓名/班级/得分行；题间空一行；题号全角；选项无 `-`/`*`/`1.`；通篇弯引号、无 `**`；维度用 `###`、全卷不用 `##`。

**B. 质量（需判断，存疑则自查或上报）**
- [ ] **干扰项"秒删"排查（头号质量项）**：**逐题逐项**问"不读书、光靠常识或排除法能不能删掉这个错项？"——凡有能秒删的废项，按§一·补六技法改写，直到每题三个干扰项都需回书才能否定。**全卷不得有"一眼看穿"的题。**
- [ ] **"没读过书也能选对"排查（§一·补三，并列头号红线）**：**逐题**遮住书、只看题干四项，问"能否凭'哪个最有道理/最正面/最顺口'、不靠任何书内具体事实就选对？"——能则重写。**尤其评价·转化两维不得为"普世美德单选"**（四项里只有一个正面价值观、其余是明显歪理）。
- [ ] **选项长度均衡排查（§一·补二，并列头号红线）**：逐题数四项字数、记正确项长度排名；**全卷"正确项＝最长项"的占比必须 ≤ 1/3**（写出实际比值，如 5/20）。超标或某题四项长短悬殊（>1.5 倍）即返工。正确项无"既…也…/最…全面"答案腔堆叠。
- [ ] **干扰项真实性抽查**：随机抽 3 题，逐个干扰项回档案核——是否都是"书里有、但此处不对"的近似项（张冠李戴/半对/似是而非），有没有编造项。
- [ ] **评价·转化无"价值观废项"**：这两维的干扰项没有"一眼即错"的反价值观选项（命运注定、讨好上级、谁有钱谁横等），都是"看似有理实则偏离文本"的解读。
- [ ] **答案唯一性抽查**：抽 3 题，确认其余三项确实都错（没有"第二个也说得通"的争议项）；正确项没有靠"最长/最全面/答案腔"露馅。
- [ ] **正确答案位置分散**：A/B/C/D 不严重偏向某一个字母。
- [ ] **维度归类自检（§见 dimension-rubric §三 ①/②判别）**：每道"整体感知"题确认**确需跨章节综合归纳**（主线/结构/整体印象/贯穿变化），不是书中某处直书的单一事实——单一事实属"提取信息"，归错维度即改。
- [ ] **高阶维度真高阶**：评价鉴赏/转化运用的题确实在考评判/迁移，不是换皮的提取题。
