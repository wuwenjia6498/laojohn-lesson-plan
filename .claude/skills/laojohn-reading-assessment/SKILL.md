# 老约翰 · 整本书阅读测评卷生成器

为一本书出一份整本书阅读理解**单项选择题**（**L1–L2 共 15 题、L3–L6 共 20 题**）：参照国际阅读素养评价体系（PIRLS）的**五个维度**命题，结合中国语文新课标按**年级**调配五维题量比例，每题附正确答案 + 维度标注 + 一句话解析。输出 **Markdown（内容源头）+ Word docx（交付/打印）**。

> ⚠ 本项目位于移动硬盘，盘符随挂载变动。执行前用 `(Get-Location).Path` 确认实际项目根目录，下文 `<项目根目录>` 代表该路径，**禁止硬编码盘符**。
> 跑 docx 引擎：用 `python`（非 `python3`）、命令加 `PYTHONUTF8=1`（避免中文乱码）。详见根 `CLAUDE.md` §1。本 skill 不跑 Playwright。

## 这是什么、不是什么（定位）

- **是**：检测学生**对整本书阅读理解水平**的**测评题库**（单项选择题）。事实源头是**书籍档案**，与课案详案平行、**不依赖详案**（测评只考对书的理解，不需要教学设计）。
- **这些题最终录入测试系统、不是纸质考卷**：所以不写"姓名/班级/得分"卷头、标题用"阅读测评"不用"测评卷"、题与题之间空一行便于复制录入。
- **不是**：`laojohn-reading-sheet`（课堂动手填的学习单/作业纸）、不是 `laojohn-reading-guide`（给学生/家长看的导读卡）、不是课案、不是 PPT。**别混用**。

## 事实源头与依赖（单一事实源，见 CLAUDE.md §2/§3）

- **唯一事实源 = 该书《书籍档案》**：`<项目根目录>\书籍档案\<书名>书籍档案.md`。题干/选项/解析的情节、人物、章节、数字只来自它，**不翻原书、不凭记忆**（真实性红线，见 `references/question-writing-rules.md`）。
- 复用（不复制副本）：
  - docx 排版引擎 `.claude\skills\laojohn-lesson-plan\assets\md_to_laojohn_docx.py`（跨技能共用，零改动）。
  - 五维与学段阶梯出处 `.claude\skills\laojohn-lesson-plan\references\grade-structure.md`「五维阅读能力」节。
  - 引号/格式铁律 `.claude\skills\laojohn-lesson-plan\assets\课案Markdown约定规范.md`。

## 工作流

### 1. 读档案，定年级
打开 `<项目根目录>\书籍档案\<书名>书籍档案.md`，从「海报/指南元数据(机器读取区)」机读块读 `等级`（L1–L6）。**用户手动指定年级时以用户为准。**通读档案的事件序列、人物、关键片段、重复事物、对照组、变化线索、主题词——这些是命题素材库。

### 2. 定五维题量
按 `references/dimension-rubric.md`「年级 × 五维题量表」查出本年级五维各出几道。**总数硬规定：L1–L2（一、二年级）= 15 题，L3–L6（三至六年级）= 20 题。**

### 3. 逐维命题
按 `dimension-rubric.md` 的每维**命题原型 + 档案取材指引**逐维出题；按 `references/question-writing-rules.md` 的**硬规则**写好每道题的四选项与正确答案。**两份 reference 动手前都要读。**
- 干扰项必须是"书里站得住的近似项"，瞄准学生易错处。
- 评价鉴赏/转化运用按 reference 给的 MCQ 通法做成选择题（选最贴合文本依据的评价 / 给观点找文内最佳证据 / 新情境迁移判断）。

### 4. 组卷写 .md
全卷**连续编号**（L1–L2 为 1–15、L3–L6 为 1–20），按维度①→⑤分 `###` 段，**题与题之间空一行**。**答案逐题内联**：每题四个选项后紧跟一行 `答案：X　【维度】一句话解析（含章节定位）`。严格遵守 `question-writing-rules.md`§三的**引擎适配写法**（H1 不带《》且不带"卷"、不写姓名/班级/得分行、题号全角 `1．`、选项 `A.` 独占行、维度用 `###`、全卷不用 `##`、通篇弯引号、无 `-`/`*`/`**`）。

### 5. 转 docx
```bash
PYTHONUTF8=1 python "<项目根目录>\.claude\skills\laojohn-lesson-plan\assets\md_to_laojohn_docx.py" "<项目根目录>\测评输出\<书名>_阅读测评.md" "<项目根目录>\测评输出\<书名>_阅读测评.docx"
```
预期：无 ASCII 引号告警；无封面页；题目连续流排、答案另起一页；题号完整。

### 6. 自检 + 交付
- 逐条过 `question-writing-rules.md`§四**交付前自检清单**（A 合规 / B 质量 / C 跑引擎验证）。维度题量要数出来写成 `4/4/5/4/3` 与表核对；干扰项与答案唯一性各抽 3 题回档案核。
- 交付 .md + .docx，并说明：**.md 是内容源头**，要改哪道题就改它再重跑引擎；.docx 可单独微调但不回写 .md。
