# 家长宣传短视频（laojohn-promo-video）

⚠ 项目在移动硬盘，路径以 `<项目根目录>` 表示，执行前 `(Get-Location).Path` 确认盘符（CLAUDE.md §1）。python 一律 `PYTHONUTF8=1 python`。

## 画面思路（2026-09-27 改版）

旧版＝静态照片推拉＋整段文字卡＋TTS 旁白，用户判「像翻 PPT、没人出镜、字多看不清、开头不抓人」。
现版借 B 站 BV17q416fEBH 的角色讲解思路：
- **A-roll**：AI 虚拟老师（讲解员）近景口播，每段一个 H3 片段，声音与口型由模型一次生成。
- **B-roll 盖画不盖声**：课堂照片整屏替换画面、kw/line 大字卡叠在讲解员上方，声音始终是讲解员——全片只有一副嗓子。
- 开头 3 秒就是讲解员近景说痛点；全屏出血，角标常驻左上，字幕在下三分之一。
- **现行＝第五版（2026-09-27 同日四轮对比后定）**：讲解员在书桌、书架、阅读角扶手椅之间换位，段内可切两镜（侧 45° → 特写），动作卡在具体的词上，台词口播腔。**本课海报、课件首页以穿插方式剪进来**，承载真实信息。
- **片头首页图（可选，2026-09-28）**：`meta.opening {header[], title, subtitle, illus}` 配了就在第一段前插 1.5 秒首页图（简洁版：米色底＋商标＋标头＋毛笔标题＋短橙线＋副题＋课件插图，不加装饰碎片，缓推、无声）。**标头取详案首页那一行原文**（写作课如「四年级上册·第五单元 校内同步写作（记事习作）」，按行拆成列表），不自拟，另存 `<课次>-首页.png`；`render_promo.py … --opening-only` 只出图审稿。样片不带。成片会把首页图作为封面内嵌进 mp4（没有首页图就用 `-封面.jpg`）；不嵌的话，文件管理器缩略图取片长约 10% 处那一帧，会随机落在某张穿插画面上。
- 试过弃用的：投屏墙（「不符合真实场景」）、悬浮纸片卡／全息卡（「什么信息都没有，很奇怪」）。博主 skill 里仍有用的原则见 `references\staging-rules.md`（参考，不是硬规则）。

## 链路

| 步 | 谁做 | 产出 |
|---|---|---|
| 0 定妆（一次） | `build_presenter.py init / voice / confirm` | `品牌资产\宣传片讲解员\<名>\`（人像、场景、音色参考、档案.json） |
| 1 写脚本 | **AI（本会话）**按下方规则写台词、每段 `shots` 与穿插 | `宣传短视频输出\<线>\<课次>\<课次>-宣传片脚本.json` |
| 2 机检＋钉图 | `check_script.py <线> <课次> --pin` | 穿插素材 md5 写回脚本 |
| 闸门 A | 用户看过脚本 → `check_script.py … --by <人>` | `meta.audit` |
| 3 提示词 | `h3_prompt.py <线> <课次>` | `storyboard.json`、`_prompts\sNN.txt`（Ref2VA 六段式） |
| 闸门 P | 用户过目 → `h3_prompt.py … --by <人>` | `storyboard.approved`（**此后开始花钱**） |

| 闸门 B | `render_promo.py … --sample 2`，用户手机上看亮度/口型/音色 | `-宣传片-样片.mp4` |
| 5 成片 | `gen_clips.py …`（补齐余段）→ `render_promo.py … [--bgm 曲子]` | `-宣传片.mp4`、`-封面.jpg` |

`<线>` 取 `写作课` / `读书会` / `看图写话`；`<课次>` 写作课沿用 `<年级册>-第N单元-<题目>`，读书会用书名（不带书名号），看图写话用课次目录名。

## 脚本规则（写 json 前必读）

**事实只从源里提炼，不创作**（CLAUDE.md §4 真实性红线照旧）：
- 写作课：海报 json（副题、三卡、cta）、`-家长用_data.json`（oneline、好坏对照、para）、详案提纲表。
- 读书会：书籍档案 `## 海报/指南元数据` 机读块、课程海报 json（summary/gains）、课案。
- 看图写话：详案、picture-materials 家长页。期号是内部编号，**禁入片**。
- 通用口径：`写作课相关宣传文件\同步写作课销售材料\…销售沟通要点.md` 第四节。

**讲解员是 AI 人像**：只以「老约翰」课程的口吻说课，**不自称具体老师、不讲「我班上有个孩子」类亲历**（没有这个人就没有这段经历，机检拦）。对家长说话称「您／孩子」；不用术语、不出现 L1–L6；好坏对照句用详案里老师写的示范句，不说成某个孩子写的，**例句原话里不加语气词**；不许诺提分、不报价、无广告法绝对化用语。全文弯引号，禁直引号与「」。

**口播腔**（2026-09-27 用户定）：像对家长聊天——可以反问、可以带少量「呢/啦/呀/吧」，短句；每段一个意思，10 秒 45～50 字（机检 >50 字 FAIL）。

**结构**：5～7 段，台词共 200～280 字（H3 约 4.5 字/秒 ≈ 60 秒）。hook（首段固定，近景直接说痛点）→ pain → method → compare → class → spirit → cta 或 close（末段二选一：cta 念扫码引导；close 温情收尾、不念扫码，片尾卡配 `end.style: closing`）。一句＝一条字幕 ≤28 字。

**每段镜头 `shots[]`**（段内 1～2 镜）：`{station, framing, move, from_line, beats[]}`。
- `station` 取档案 `stations`（讲解员C：`desk` 书桌坐讲 / `bookshelf` 书架前站讲 / `armchair` 阅读角扶手椅）。
- `framing` 只许 `close-up` / `medium close-up` / `three-quarter`（侧 45° 近景）——中远景脸会糊。
- `move` 取 push/handheld/track/pull/still；`from_line` 本镜从第几句起（首镜 0、逐镜递增）。
- `beats`：`{word: 台词里的词, do: 档案 actions 的键}`＝「说到这个词时做这个动作」（机检核词在台词里）。
- **相邻段换区域或换景别**（机检 WARN）。
- 画面里不出屏幕、不出悬浮图形（`h3_prompt.RULES` 已写死否定）。

**穿插 `broll[]`**：`{at: 第几句(0 起), src, dur ≤3.5, motion?, focus?, fit?, card?}`。
- 照片：`repo:<相对项目根>` / `assets:<相对素材库根>`，整屏替换画面；`focus:[x,y]` 定裁切重心，`motion` 取 in/out/up/down/left/right/none。选照片看 `_assets\图库索引.md`。**真实课堂照片全片 2～3 张**——家长信的是真课堂。
- **本课海报、课件首页**：放在台词说到课名或课的核心内容处，承载真实信息。海报是竖长图，按照片处理（`motion: down` 从标题摇到插画）；课件首页是横版，加 `fit: "contain"`——完整居中、底铺模糊，不裁字。课件取**终稿**（仓内那份可能没配图，桌面/共享盘的配图版用 laojohn-ppt `tools\shot_assets.py` 导第 1 页 PNG），放 `<课次>\_screen\`（不入库）。
- **讲到课案具体情节（例子、步骤、课堂活动）时，优先穿插课件对应页面和课件插图**（2026-09-28 用户定）。课件页按 laojohn-ppt `tools\shot_assets.py` 的 `pptx_to_png_batch(..., size=(3840,2160))` 导出到 `_screen\`。横版页进竖屏按页面类型选 `layout`：
  - `split`（字多的页，首选）：上半屏讲解员（原画面 y=270 起取 960 高，口型不断）、下半屏课件页或 `crop` 出的局部，字幕自动下移。**不算讲解员离场**。
  - `pan`（横排步骤页）：`crop` 裁出那一条放大到 730 高，镜头按 `pan:[起,止]`（裁出条内的横向位置 0~1）停 30%→移 50%→停 20%，让镜头落在「最关键」那一框上。
  - `full` + `fit:"contain"`：只给大字少字的页（课件首页）。
  - 课件插图（`课件配图工具\课件产出\<课次>\gpt-image\抠图\抠-PNN.png`，透明底）用 `fit:"cutout"`，铺课件同款米色底。该目录不入库，换机器须先拷过去或重出，否则 md5 核对会停。
  - `crop` 一律按原图比例 `[x0,y0,x1,y1]`。同段多条穿插时间重叠，前一条自动让给后一条。整屏穿插超过全片一半，机检报 WARN。
- 字卡：`card:kw`（≤10 字大字）、`card:line`（≤22 字例句纸条，`{b}…{/b}` 强调），叠在讲解员胸前。**每段最多 1 张**，不再有整段文字卡。
- **防闪（渲染器自动）**：换画面的穿插（整屏、横摇、分屏）之间、段首段尾，讲解员全屏不足 1 秒就自动吸附（提前到 0／前一条接上／延到段尾），渲染时打印「防闪：…」。用户对「老师闪一下」很敏感，写脚本时也尽量让穿插首尾相接。
- 时间微调：`offset` 覆盖「句首后几秒开始」（缺省首句 0.6、其余 0.25，可为负）；相邻穿插重叠时前一条自动让给后一条；分屏可贴到段尾。
- **讲解员手里的道具是空白的**（本子、纸等，模型写不出真内容）：不重生，用 split 把整段盖住，`top_y` 上移取景让道具落在上半屏之外（先抽帧量道具上沿，四上五 s4 取 60）。
- 素材库根配在 `scripts\promo.config.json`（gitignored）或环境变量 `PROMO_ASSETS_ROOT`。

**meta 必填**：`presenter`（档案名）、`capsule`、`title`、`cover_seg`、`end.subtitle`。`ai_label` 可空（2026-09-28 用户定画面不放 AI 角标）：空则角标只剩年级胶囊，机检报 WARN 提醒——按《人工智能生成合成内容标识办法》，发布时应在平台勾选 AI 生成声明。`end.hold` 片尾秒数（缺省 3.2）。可选 `grade: {gamma, brightness, saturation}`——讲解员画面偏暗时后期提亮。
`end.style: "closing"` + `end.illus`（本课海报插画，钉 md5）＝片尾呼应首页：米色底、毛笔标题、副题、插画、商标，**不放二维码与行动句**；不写 style 则是旧版二维码片尾。

## 硬约束

- **共享件薄壳、禁复制**：`ffmpeg_path.py`、`build_timeline.wrap` 真源在 `laojohn-lesson-video\scripts\`；AiHubMix 密钥回退与多模态判读走 `课件配图工具\scripts\imgclient.py`（`videoclient` importlib 载入）。改真源须回归各自主线。
- **花钱前三道闸**：定妆（`confirmed_by`）、闸门 A（脚本）、闸门 P（提示词哈希）。缺一 `gen_clips.py` 拒绝提交。闸门守「人看过」，不要求机检全绿。
- **ASR 核对不可跳**：片段抽音轨经 whisper 转写，与台词相似度 <0.85 判「念错」自动重生一次，仍不过就停；转写接口失败记「未知」，片段保留、不当「不通过」，成片前人耳听。
- **素材 md5 对不上就停**：素材库文件名是 Windows 去重编号，重扫会变；绝不静默换图。讲解员素材同样钉 md5。
- **零漂移**：视频逐段编码后 concat 复制，音频按「帧数×1600 样本」PCM 精确截齐再拼、最后一次编 AAC。
- 字体：Noto Sans SC（OFL）+ 马善政毛笔体（OFL，取自 writing-poster assets），可商用；BGM 须有商用授权：曲子与 `授权记录.md` 放 `品牌资产\背景音乐\`（已有 Pixabay 两首钢琴，选曲口径＝舒缓钢琴、无人声、不抢讲解员）。选定的曲子写进脚本 `meta.bgm`（`repo:品牌资产/背景音乐/…`），渲染自动带上（`--no-bgm` 出无音乐版）；`--bgm <曲子>` 临时试曲。自动量曲子响度拉到 `--bgm-level`（缺省 -24 dBFS），去掉曲头静音，说话时侧链压到人声下约 19 dB，首尾淡入淡出。
- 入库：脚本 json、`storyboard.json`、`_prompts\`、`_clips\*.json`、讲解员档案四件；不入库：片段 mp4、画面层、成片、封面、`_试音\`。
