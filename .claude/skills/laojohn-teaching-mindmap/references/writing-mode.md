# 写作课模式（teaching-mindmap · 写作详案适配）

本 skill 默认梳理「整本书阅读读书会详案」。当输入是 **写作课（习作课）详案**（由 `laojohn-writing-lesson` 产出）时，切本模式：**渲染引擎、JSON 结构、五分支放射骨架照旧复用**，只把各分支的萃取口径换成写作课的（教学目标四维、两节连排、写作技法）。引擎（`render_pdf.py` + `template.html`）课型无关、不改。

## 0. 怎么判型（自动）
读到详案头部命中任一即判写作课：H1 形如 `# 《题目》· 写作课教学设计`；书级头部 `## 一、教案提纲表` + `## 二、核心素养教学目标`（四维标签 `【语言运用】`/`【思维能力】`/`【审美创造】`/`【文化自信】`）；课时 `## 第1课时 · 写作指导课` / `## 第2课时 · 当堂写作与评改课`。判不准走默认读书会模式。

## 1. title 与分支名差异
- `title`：`<题目> · 教学思维导图`（习作题目**不带《》**，区别于读书会的 `《书名》教学思维导图`）。
- 五分支顺序不变，但**第④支改名**：读书会「阅读策略学习」→ 写作课 **「写作技法学习」**。其余四支名不变（教学目标 / 教学流程 / 重点教学环节 / 可视化工具的运用）。

## 2. 各分支写作课萃取口径

**① 教学目标（4 条·核心素养四维，非三维）**
取详案「## 二、核心素养教学目标」段，四条分别以 `语言运用：`/`思维能力：`/`审美创造：`/`文化自信：` 起头（全角冒号），各概括成一句。纯提取、不改立意；缺某维填「…：待补」。（读书会是三维三条；写作课固定四维四条。）

**② 教学流程（3 层：分支 → 两课时 → 环节要点）**
写作课固定两节连排：二级节点 `第1课时：写作指导课`、`第2课时：当堂写作与评改课`。各挂 3–5 个三级环节要点，**直接来自该课时 `### 一、xxx` 小节标题**，压成短语、去时长括号（如「创设情境·明确任务」「借构思表·理清思路」「自由写作」）。`## 附:习作讲评指导环节` 是备选块，可省或标「（备选）」。

**③ 重点教学环节（2 层·3–5 条）**
挑最核心活动平铺，每条 `环节名：一句说明。`（全角冒号、句号收尾）。写作课优先选：审题辨析（切题/跑题对照）、构思表填写（教师示范+学生速填）、示范文赏析与旁批、当堂自由写作、交流评议·自改互评。

**④ 写作技法学习（2 层·3–5 条）**
扫详案「核心技法」提纲行 + 「### 学写法…」环节 + 正文技法点，去重归纳。每条 `技法名：一句怎么教/怎么用。`（全角冒号、句号）。如：围绕中心意思写、一种空间顺序、五感写具体、打比方、分步聚焦（一句扩三句）。**详案没讲的技法不补**。

**⑤ 可视化工具的运用（2 层·按详案实际）**
扫「工具与任务」提纲行 + 详案里的表/支架。每条 `工具名：一句用途。`。写作课常见：五感观察表、写作构思表、旁批表、三档自改标准表、写作支架。课案没出现的不补。

## 3. 不变量
- 萃取总纪律（归纳重组允许、无中生有禁止、不联网不靠记忆、缺失标待补）与读书会一致。
- JSON 结构、层级深度、文字长度建议见 `data_schema.md`（写作课①支为 4 条、④支名为「写作技法学习」，其余同）。
- 渲染命令、输出三件套（PDF→JSON→HTML）同主 SKILL「第二步」。输出 JSON 落写作物料目录、作内容源头。
