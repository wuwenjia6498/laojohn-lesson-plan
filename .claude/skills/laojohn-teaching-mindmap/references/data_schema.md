# 教学思维导图数据结构(data.json)

萃取后产出的 JSON 喂给 `scripts/render_pdf.py`。结构如下。

## 顶层字段

| 字段 | 必填 | 说明 |
|---|---|---|
| `title` | 是 | 图的标题,固定格式「《书名》教学思维导图」。同时用作中心节点文字。 |
| `header_left` | 是 | 页眉左侧,固定填 `老约翰深度阅读` |
| `header_right` | 是 | 页眉右侧,固定填 `阅读 · 思辨 · 表达` |
| `branches` | 是 | 五个一级分支的数组,顺序固定 |

## branches(一级分支)

固定五个,`name` 依次为:`教学目标`、`教学流程`、`重点教学环节`、`阅读策略学习`、`可视化工具的运用`。顺序不可调,对齐《荒岛机器人》样张。

每个分支:

```json
{ "name": "教学目标", "children": [ ...二级节点... ] }
```

## 二级节点(children 的元素)

两种形态:

**A. 纯叶节点**(教学目标 / 重点教学环节 / 阅读策略学习 / 可视化工具 四支都用这种)
```json
{ "label": "奇人画廊表：把多位奇人放进同一张表，多维度横向梳理人物异同。" }
```

**B. 带三级子节点**(只有「教学流程」分支用,即每个课时一个二级节点,各带一组环节要点)
```json
{
  "label": "第一课时：导读课",
  "children": [
    { "label": "情境导入·话题激趣" },
    { "label": "走进作者·走进作品" }
  ]
}
```

三级节点只能是纯叶(`{ "label": "..." }`),不再嵌套。

## 层级深度约定

- 教学目标、重点教学环节、阅读策略学习、可视化工具的运用:**两层**(分支 → 叶)。
- 教学流程:**三层**(分支 → 课时 → 环节要点)。课时数按课案实际,通常 4 个。

渲染器据此画 2 段或 3 段连线(模板用 `c2.children ? 'l2' : 'leaf'` 自动判断,无需配置)。不要给其他分支加三级,也不要给教学流程去掉三级。

## 文字长度建议

- 一级分支名:4–7 字(已固定)。
- 教学流程的课时节点:`第X课时：课型`,环节要点为短语(不带句号),如「奇人画廊·横向梳理」。
- 教学目标 / 重点环节 / 策略 / 工具的叶:`概念词：一句说明。`(全角冒号),说明控制在一行内(约 20–35 字),以句号收尾。
- 教学目标三条偏长可接受(三维目标信息量大),但仍尽量压在一行半内。
