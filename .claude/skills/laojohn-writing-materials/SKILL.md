# 老约翰 · 同步习作配套物料

把一份写作课详案按侧抽成 `data.json`，注入对应合订模板，每侧渲出 **1 份 HTML 源件 + 1 份多页 A4 合订 PDF**。

**学生合订（4 页，`template_student.html` + `render_student.py`）**：

| 页 | 物料 | 内容 |
|----|------|------|
| P1 | 写作学习单 · 构思表 | 任务导语 + 构思表（学生填关键词）+ 「这一课在练」能力点 |
| P2 | 写作学习单 · 格子稿纸 | 起笔提示 + 18 列格子稿纸（字数刻度+老师批改栏）+ 修改符号表 |
| P3 | 范文页 | 教师下水文（技法句高亮）+ 侧边旁批 + 一句话记住 |
| P4 | 课后练笔 | 换场景任务卡 + 三步提示 + 小稿纸 + 自查 + 家长签字 |

**教师合订（2 页，`template_teacher.html` + `render_teacher.py`）**：

| 页 | 物料 | 内容 |
|----|------|------|
| P1 | 教师速览页 | 上课前 3 分钟扫一遍：一句话目标 + 两节课时间轴（分钟逐字取自详案）+ 易错点 + 下水文 + 物料清单 |
| P2 | 怎么讲活 | 防念稿三色旁注：逐环节 必守(绿)/可放开(黄)/为什么(蓝) + 最不能照着念的 N 处 |

**家长合订（2 页，`template_parent.html` + `render_parent.py`）**：

| 页 | 物料 | 内容 |
|----|------|------|
| P1 | 习作成长反馈 | **结构件**：信息条 + 孩子作品区（留白）+ 能力勾选项（数据层唯一供给）+ 评语/关注/寄语线（留白待老师手填真作真评） |
| P2 | 家长一页纸 | 大白话讲本课能力：一句话说清 + 好/一般写法对照 + 亲子小游戏 + 帮忙避坑两条 |

## 工作流

1. **读详案**：`<项目根目录>\写作课详案输出\<年级册>-<题目>-写作课详案.md`。执行前用 `(Get-Location).Path` 确认盘符，禁止硬编码。
2. **抽取/派生字段**：学生侧按 `references/data_schema.md`、教师侧按 `references/data_schema_teacher.md`、家长侧按 `references/data_schema_parent.md` 的字段契约与「详案锚点速查」逐项填。可直接抽取的（构思表行、示范文、旁批表、环节分钟数）逐字取；派生的（导语、课后练笔任务卡、易错点、三色旁注、家长对照例/亲子任务）必须能回溯到详案技法点/环节动作——学生侧对学生说话，教师侧对教研同行说话，家长侧全大白话不带术语。
3. **写 data.json**：存 `<项目根目录>\写作配套输出\<年级册>-<题目>\<年级册>-<题目>-<侧名>合订_data.json`（侧名=学生/教师/家长）。写完**核验弯引号**：内容里的引用词语须是“”（Write 工具可能打直成 ASCII `"`，发现即修）；禁「」。
4. **渲染**（用 `python` 勿用 `python3`——Store 占位别名 exit 49；三侧入口同一 CLI 形态）：
   ```
   PYTHONUTF8=1 python .claude/skills/laojohn-writing-materials/scripts/render_<student|teacher|parent>.py \
       "写作配套输出/<年级册>-<题目>/<年级册>-<题目>-<侧名>合订_data.json" \
       "写作配套输出/<年级册>-<题目>"
   ```
   自检内置（`_shared.py`）：sheet 溢出 + pypdf 页数（学生 4 页 / 教师 2 页 / 家长 2 页）；学生侧另查格子数。
5. **核验**：页数达标、无溢出告警；截图或打开 PDF 目检版式。超页时先压数据层文本（导语/任务卡/旁注写短），不动模板骨架。

## 红线

- **真实性**：示范文从详案 `> 【教师示范文】` **一字不改照抄**；**绝不虚构学生作文/学生作品/学生评语**；旁批只写详案讲过的技法；课后练笔的场景候选优先取详案「选材菜单」。教师侧：时间轴分钟数逐字取自详案不自行调配；三色旁注/易错点每条须指向详案里真实存在的环节动作，禁写详案没有的教学步骤。家长侧：成长反馈页只出结构与能力勾选项，作品/评语/关注点全留白待老师手填真作真评；对照例是教学示意句，不冒充学生作品或课文。
- **引号纪律**：data.json 字符串内引用词语用弯引号“”，禁「」、禁英文直引号。
- **对外称呼**：如需提能力阶，写「第一阶～第四阶」，不写 L1–L4。
- **固定骨架禁改**：品牌页眉 logo、设计令牌色值、格子稿纸 JS 版式、修改符号表、各模块标题（清单见 data_schema.md 末节）。改文案只改 data.json，不动模板。
- 详案缺某锚点（如无选材菜单）时按技法点自行派生，**不得**为凑内容编造详案里没有的事实性表述。

## 输出目录与命名

`<项目根目录>\写作配套输出\<年级册>-<题目>\`：
- `<年级册>-<题目>-<侧名>合订_data.json`（源，进 git；侧名=学生/教师/家长）
- `<年级册>-<题目>-<侧名>合订.html/.pdf`（渲染产物，已 gitignore，勿 `git add -f`）

## 文件说明

| 文件 | 作用 |
|------|------|
| `assets/template_student.html` | 学生合订四页模板（数据驱动，`/*__DATA__*/ null` 占位） |
| `assets/template_teacher.html` | 教师合订两页模板（速览页 + 怎么讲活三色旁注） |
| `assets/template_parent.html` | 家长合订两页模板（成长反馈结构件 + 家长一页纸） |
| `scripts/_shared.py` | 渲染共享件：logo/数据注入、safe_pdf 防锁旁路、溢出与页数自检（各入口共用，勿复制逻辑） |
| `scripts/render_student.py` | 学生合订入口（附加格子稿纸自检） |
| `scripts/render_teacher.py` | 教师合订入口 |
| `scripts/render_parent.py` | 家长合订入口 |
| `references/data_schema.md` | 学生合订字段契约 + 详案锚点映射（抽学生侧前必读） |
| `references/data_schema_teacher.md` | 教师合订字段契约 + 详案锚点映射（抽教师侧前必读） |
| `references/data_schema_parent.md` | 家长合订字段契约 + 详案锚点映射（抽家长侧前必读） |

新增侧/新模板时：从桌面模板取骨架须把手工仿制 CSS logo 换成 `__LOGO_SRC__` 真图注入（单一源 `品牌资产\logo.png`），渲染一律走 `_shared.py`，勿复制管线逻辑。
