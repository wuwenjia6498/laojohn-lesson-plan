# 老约翰 · 同步习作配套物料

把一份写作课详案按侧抽成 `data.json`，注入对应模板，每侧渲出 **1 份 HTML 源件 + 1 份多页 A4 打印件 PDF**。

**学生用（4 页，`template_student.html` + `render_student.py`）**：

| 页 | 物料 | 内容 |
|----|------|------|
| P1 | 写作学习单 · 构思表 | 任务导语 + 构思表（学生填关键词）+ 「这一课在练」能力点。**详案里「先列整篇提纲、再细化中间」两步走的课**（如五上四《二十年后的家乡》）可另出一张提纲表，与构思表同页——写 `worksheet.outline_rows` 即触发，构思表要多列则给 `plan_cols`，两者都不写时渲染结果与此前一字不变（2026-09-07 增，契约见 `data_schema.md`） |
| P2 | 写作学习单 · 格子稿纸 | 姓名栏 + 起笔提示 + 16 列格子稿纸（老师批改栏内带字数刻度；2026-09-07 起不再放修改符号表） |
| P3 | 写作稿纸 · 续页（备用） | 姓名栏 + 纯格子（无起笔提示、无说明行，故行数更多）；写不下时接着用，写不满就空着 |
| P4 | 范文页 | 教师示范文（技法句高亮）+ 侧边旁批 + 一句话记住 |

**教师用（2 页，`template_teacher.html` + `render_teacher.py`）**：

| 页 | 物料 | 内容 |
|----|------|------|
| P1 | 教师速览页 | 上课前扫一遍：一句话目标 + 两节课时间轴（分钟逐字取自详案）+ 易错点 + 示范文 + 物料清单（学生侧已无课后练笔，勿再列） |
| P2 | 怎么讲活 | 三色旁注：逐环节 必守(绿)/可放开(黄)/为什么(蓝) + 最容易讲僵的 N 处 |

**家长件（1 页，`template_parent.html` + `render_parent.py`）**：

| 页 | 物料 | 内容 |
|----|------|------|
| P1 | 家长一页纸 | 大白话讲本课能力：一句话说清 + 好/一般写法对照 + 亲子小游戏 + 帮忙避坑两条 |

**已撤销的两页，勿加回**（2026-08-03 定）：学生侧「课后练笔」页、家长侧「习作成长反馈」页。对应 `homework`/`feedback` 字段一并作废。

## 工作流

1. **读详案**：`<项目根目录>\写作课详案输出\<年级册>-第N单元-<题目>-写作课详案.md`。执行前用 `(Get-Location).Path` 确认盘符，禁止硬编码。
2. **抽取/派生字段**：学生侧按 `references/data_schema.md`、教师侧按 `references/data_schema_teacher.md`、家长侧按 `references/data_schema_parent.md` 的字段契约与「详案锚点速查」逐项填。可直接抽取的（构思表行、示范文、旁批表、环节分钟数）逐字取；派生的（导语、易错点、三色旁注、家长对照例/亲子任务）必须能回溯到详案技法点/环节动作——学生侧对学生说话，教师侧对教研同行说话（第三人称：教师／学生），家长侧浅白不带术语（浅白≠口语）。**动笔写派生文案前先读 `references/prose-exemplars-materials.md`**（三侧各一组人工润色定稿样本，约 2 分钟，不可跳），照样本的语体写；**不读** `../laojohn-writing-lesson/references/style-criteria.md` 对照表（2026-09-15 与详案线同步换靶，理由见红线节「派生文案语体」）。
3. **写 data.json**：存 `<项目根目录>\写作配套输出\<年级册>-第N单元-<题目>\<年级册>-第N单元-<题目>-<侧名>用_data.json`（侧名=学生/教师/家长）。写完**核验弯引号**：内容里的引用词语须是“”（Write 工具可能打直成 ASCII `"`，发现即修）；禁「」。
   - **机检 D · 确定性润色门（每侧每份必跑 · 2026-09-15 立）**：先 `PYTHONUTF8=1 python .claude/skills/laojohn-writing-materials/scripts/polish_materials.py <该侧_data.json> --dry-run` 看 diff 与命中统计，无误改再去掉 `--dry-run` 落盘——它按详案线同一张 `polish_rules.py` 做机械可判的词句替换（你们→大家／念→读／引出式破折号→冒号／这儿→这里／挑→选／别→不要／教师侧 老师→教师等），示范文、旁批引句、构思表行名、时间轴分钟数、对照示意句等逐字取自详案的字段一律不碰；落盘后自动验保护字段逐字相等、方向指标（口语词／破折号）不反向，任一不过整份回滚，并出 `<课次目录>/_润色报告-<文件>.md`。**报告末节「残余候选」是给人判的**：口语词残余、剩余破折号、内部黑话命中（定起点／零打断／领步／分档收束这类详案外没人懂的方法名）逐条过一遍，判断类五项（升华式收尾／“不是…而是…”／“越…越…”三连／名词化生造术语／跨课同构）机器不判、人写完横向比一眼。同课次详案存在时脚本自动掩蔽其术语表串与环节标题（时间轴环节名须与详案标题一致）。
4. **渲染**（用 `python` 勿用 `python3`——Store 占位别名 exit 49；三侧入口同一 CLI 形态）：
   ```
   PYTHONUTF8=1 python .claude/skills/laojohn-writing-materials/scripts/render_<student|teacher|parent>.py \
       "写作配套输出/<年级册>-第N单元-<题目>/<年级册>-第N单元-<题目>-<侧名>用_data.json" \
       "写作配套输出/<年级册>-第N单元-<题目>"
   ```
   自检内置（`_shared.py`）：sheet 溢出 + pypdf 页数（学生 4 页 / 教师 2 页 / 家长 1 页）；学生侧另查两页格子数（续页格数应不少于 P2）。
5. **核验**：页数达标、无溢出告警；截图或打开 PDF 目检版式。超页时先压数据层文本（导语/任务卡/旁注写短），不动模板骨架。

## 红线

- **真实性**：示范文从详案 `> 【教师示范文】` **一字不改照抄**；**绝不虚构学生作文/学生作品/学生评语**；旁批只写详案讲过的技法。教师侧：时间轴分钟数逐字取自详案不自行调配；三色旁注/易错点每条须指向详案里真实存在的环节动作，禁写详案没有的教学步骤。家长侧：对照例是教学示意句，不冒充学生作品或课文。
- **教师侧不配发逐字稿**：教师速览页+怎么讲活两页就是老师手上的全部纸面材料，文案不得预设老师手边有逐字稿——禁写「配合逐字稿」「照着念/别照念」「稿子上第 X 步」这类指代，旁注从教学动作本身说起。
- **引号纪律**：data.json 字符串内引用词语用弯引号“”，禁「」、禁英文直引号。
- **禁 emoji / 生僻符号字符（模板与 data.json 同禁 · 2026-08-17 立）**：🏠 ✍ ✏ ✕ ↔ 这类字符不在微软雅黑字表内，Chromium 打印时会走系统回退字体（SimSun / Segoe UI Symbol / Segoe UI Emoji），**为每个字形现造一个 Type3 字体**——WPS/福昕/Acrobat 一律拒编这类字体，用户改不动 PDF。装饰图标一律用**纯 CSS 图形**（`content:""` + `width/height/background`，模板里 `.sech::before`、`.legend .dot` 是现成样板）；确需符号则换雅黑覆盖内的等价字符（`✕`→`×`）。`.mark .sym` 的字体栈中间那档 `"Microsoft YaHei"` 是同一道防线（Courier New 缺的字兜到雅黑而非系统回退），**勿删**。渲染时 `_shared.check_type3` 会逐份机检并报出具体字符，看到 `!! 第 N 页含 Type3 字体` 就是回归了、改源头别改 PDF。
- **派生文案语体（2026-09-15 与详案线同步换靶，三层与详案线一一对应）**：三侧文案写成**印在纸上给人读的规范书面文案**——由另一位老师照读不别扭、家长拿到手不觉得是聊天记录。句子说全，口语词换通行词（不要／要／和／选／读／那里／第一句／即可／不必），引出下文用冒号不用破折号，教师侧第三人称（教师／学生）、不写详案内部方法名，家长侧浅白**不等于口语**（不带术语，但口语词与引出式破折号照改）。**三层执行位**：① 生成侧输入只有本条定调 + `references/prose-exemplars-materials.md`（2026-09-01 用户认可的三侧定稿样本），**不读 style-criteria 对照表**——0901「通读对照表自查」口径已废：对照表诱发逐句对表、且 agent 逐处裁量落不实（详案线 0911 实测一篇 18 处「你们」只动 3 处；配套侧 0915 抽《故事新编》三侧，口语词与引出式破折号成片）；② 已定案的词句替换由工作流第 3 步机检 D `scripts/polish_materials.py` 机械落地，规则表与详案线**同一张** `polish_rules.py`（单一源，禁在本 skill 另存副本；新词条与排除项去那边加，两家同时受益）；③ 判断类靠润色报告「残余候选」＋人工五项自查（升华式金句尾改实效句／“不是…而是…”改“光…不够，要…”／“越…越…”三连拆开／名词化生造术语与教研黑话还原成动作句／跨课同构横向比一眼换写法）。示范文、对照示意句、旁批引句是引用件，反向豁免、原样不改。
- **对外称呼**：如需提能力阶，写「第一阶～第四阶」，不写 L1–L4。
- **固定骨架禁改**：品牌页眉 logo、设计令牌色值、格子稿纸 JS 版式、稿纸页姓名栏、各模块标题（清单见 data_schema.md 末节）。改文案只改 data.json，不动模板。
- 详案缺某锚点（如无选材菜单）时按技法点自行派生，**不得**为凑内容编造详案里没有的事实性表述。

## 文件说明

| 文件 | 作用 |
|------|------|
| `assets/template_student.html` | 学生用四页模板（构思表 / 稿纸 / 备用续页 / 范文页；数据驱动，`/*__DATA__*/ null` 占位） |
| `assets/template_teacher.html` | 教师用两页模板（速览页 + 怎么讲活三色旁注） |
| `assets/template_parent.html` | 家长一页纸单页模板 |
| `scripts/_shared.py` | 渲染共享件：logo/数据注入、safe_pdf 防锁旁路、溢出与页数自检、Type3 字体机检（各入口共用，勿复制逻辑） |
| `scripts/render_student.py` | 学生用入口（附加格子稿纸自检） |
| `scripts/render_teacher.py` | 教师用入口 |
| `scripts/render_parent.py` | 家长用入口 |
| `scripts/polish_materials.py` | 机检 D 确定性润色门：三侧 json 派生文案跑详案线 `polish_rules.py`（单一源，import 不复制）＋保护字段／方向指标验收＋残余候选报告；`--all` 扫全部课次。**单向依赖** `../laojohn-writing-lesson/assets/polish_rules.py`、`polish_writing.term_strings` 与仓根 `tone_gate.py`，改那三件须回归本脚本 `--all --dry-run` |
| `references/data_schema.md` | 学生用字段契约 + 详案锚点映射（抽学生侧前必读） |
| `references/data_schema_teacher.md` | 教师用字段契约 + 详案锚点映射（抽教师侧前必读） |
| `references/data_schema_parent.md` | 家长用字段契约 + 详案锚点映射（抽家长侧前必读） |
| `references/prose-exemplars-materials.md` | 三侧文案语体样本（生成时唯一的行文参照，取自 0901 用户认可的《推荐一个好地方》三侧定稿；只借语体不借内容） |
