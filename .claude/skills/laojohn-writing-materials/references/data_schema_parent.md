# 家长合订 data.json 字段契约

模板：`assets/template_parent.html`（2 页 A4：习作成长反馈 / 家长一页纸）。
本文件是「详案锚点 → 家长合订字段」的唯一映射源。富文本只认 `{b}…{/b}`；引号纪律同前两侧（弯引号“”，禁「」、禁英文直引号、禁原始 HTML）。

## 铁律（本侧最重）

**成长反馈页是结构件**：孩子作品节选、老师评语、下次关注、给孩子的一句话**全部留白**，由老师拿到打印件后手填**真实作品与真实点评**——数据层只提供「能力勾选项」，**绝不虚构学生作文、学生表现、教师评语**。给老师的填写提示（要具体到那一句、宁少勿虚、不代笔不美化）已固化在模板骨架里。

## 字段总表

```jsonc
{
  "meta": {
    "kicker": "三年级上册 · 第六单元 · 习作",   // 同前两侧
    "topic": "这儿真美"                        // 信息条「本次习作」自动加《》
  },

  "feedback": {                                // ── 第1页：习作成长反馈（仅此一个字段，其余全是留白骨架）
    "abilities": [                             // 「这次，在这里迈了一步」勾选项 2–4 条
      "…{b}能力名{/b}——大白话描述。例：＿＿＿＿＿＿＿＿＿＿＿"
      //  ← 提纲表「核心技法」+「学习目标」拆成单条能力，家长听得懂的话；
      //    需要老师举例的条目留「例：＿×11+」横线；纯判断类条目不留
    ]
  },

  "onepager": {                                // ── 第2页：家长一页纸
    "oneline": "…",                            // 一句话说清 ← 核心技法的大白话版（不带术语）
    "para": "…{b}…{/b}…",                      // 展开段：本年级此文体常见问题 + 这节课教的本事（3–4 句）
    "compare": {                               // 一眼看懂差别：好 vs 一般对照例
      "bad":  { "quote": "“…”", "note": "…" }, // 反例引句 + 一句点评（quote 含弯引号；【派生】写"此文体
      "good": { "quote": "“…{b}…{/b}…”", "note": "…" } // 通病句"，好例按本课技法现写，{b}标技法落点；
    },                                         //   两句都不是学生作品、不是详案原文，是教学示意句
    "task": {                                  // 亲子小游戏（贴合本课能力点设计，口头为主不动笔）
      "title": "…",                            // 游戏名（弯引号包game名，禁「」）
      "steps": [ "…{b}…{/b}…" ],               // 3 步；序号 1./2./3. 由模板加
      "tip": "…"                               // 一句给家长的松绑话
    },
    "dont": [ "…{b}…{/b}…" ]                   // 「帮忙时，请避开这两件」2 条；①② 序号由模板加
  }
}
```

## 详案锚点速查

| 详案锚点 | 供给字段 |
|----------|----------|
| 提纲表「核心技法」+「学习目标」行 | `feedback.abilities`（拆条）、`onepager.oneline/para` |
| 三档自检表 / 评价标准 | `feedback.abilities` 的勾选判据 |
| 详案讲技法的正反对照（如"只有美/漂亮"病句示例） | `onepager.compare`（有现成对照例优先用；没有则按技法点派生教学示意句） |
| 本课方法三步（如"看清→凑近→加感觉"）| `onepager.task.steps` 的追问设计 |
| 详案评改环节"夸具体那一句"的导向 | `onepager.dont` 的家长版转述 |

## 派生纪律

- `compare` 两句是**教学示意句**（不冒充学生作品、不冒充课文），反例写此学段此文体的典型通病，好例必须用本课教的技法且与 `abilities` 呼应。
- `task` 必须练本课能力点本身（换对象、口头化），不得引入详案没教的技法。
- 面向家长的话全部大白话：不出现 L1–L6（要提能力阶就写「第一阶～第四阶」）、不出现教研术语（"支架/图式/习得"等）。

## 模板里的固定骨架（不在 data.json 里，禁改）

页眉 logo 与用途标签（习作成长反馈·请家长收阅／家长一页纸·陪孩子把课堂延伸到家里）、两页 h1（孩子这一篇，写得怎么样／这节课，孩子学了什么）、信息条（姓名/日期/本次习作）、作品区留白提示语、「老师想对你说（具体到那一句）」、下次关注/给孩子的一句话/指导老师签名、给老师的填写提示、区块标题（这次写的（节选）/这次，在这里迈了一步/一句话说清/一眼看懂差别/帮忙时，请避开这两件）、对照两栏栏头（课上要改掉的写法/课上要学的写法）、🏠 图标与 ★ 勾选星。
