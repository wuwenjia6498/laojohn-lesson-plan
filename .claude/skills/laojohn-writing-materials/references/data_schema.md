# 学生用 data.json 字段契约

模板：`assets/template_student.html`（4 页 A4：学习单构思表页 / 学习单格子稿纸页 / 稿纸续页 / 范文页）。**课后练笔页已于 2026-08-03 撤销**，`homework` 字段随之作废，勿再写、勿加回。
本文件是「详案锚点 → data.json 字段」的唯一映射源。所有字段都是**必填**（标了「可选」的除外）。

## 富文本标记（只认这两对，其余原样转义）

| 标记 | 渲成 | 用在 |
|------|------|------|
| `{hl}…{/hl}` | 荧光下划高亮 | 仅 `essay.paragraphs`（标技法句） |
| `{b}…{/b}` | 加粗（各区块有各自的强调色） | `worksheet.skills`、`essay.notes[].a`、`essay.method`、`essay.footer` |

JSON 字符串内禁塞原始 HTML；引用词语一律弯引号“”，禁「」、禁英文直引号。

## 字段总表

```jsonc
{
  "meta": {
    "kicker": "三年级上册 · 第六单元 · 习作",   // 年级册 + 单元 + 「习作」；自拟主题可省单元
    "topic": "这儿真美"                        // 习作题目，不带书名号；进各页标题 "· <topic>"
  },

  "worksheet": {                               // ── 第1、2页：写作学习单
    "lead": "…",                               // 第1页导语：本课任务一句话+怎么用这张单（对学生说）
    "plan_rows": [                             // 构思表行 ← 详案「借助构思表」环节 | 项目 | 关键词 | 表，逐字取行名
      { "label": "这儿是哪里" },
      { "label": "中心句", "note": "例：××真美" },        // note 可选：行名下的小字提示
      { "label": "我选哪种顺序", "note": "圈一个",
        "prefill": "远 → 近　／　上 → 下" }               // prefill 可选：格内印好供圈选的候选项
    ],
    "skills": "…",                             // 「这一课在练」← 提纲表「核心技法」行改写成学生话，{b}标能力点名
    "page2_lead": "…",                         // 第2页导语（稿纸页）。⚠ 稿纸页已无修改符号表（2026-09-07），导语里不写「写完读一遍，用（下面的）符号改一改」这类句子，读稿修改的指令归详案与课堂
    "draftnote": "…",                          // 起笔提示 ← 详案「当堂写作」环节的起笔引导压缩成一行
    "marks": [                                 // ⚠ 已废弃（2026-09-07 稿纸页删修改符号表，模板忽略此字段，存量可留可删）。原义：修改符号表覆盖，缺省四条（○/∨/——/／）；
      { "sym": "——", "desc": "删除号：…" }      //   详案明确教了修改符号的课（如首次引入课）必须覆盖，
    ]                                          //   逐条对应详案教的符号，禁与课堂教法冲突
  },

  "essay": {                                   // ── 第4页：范文页（P3 为备用稿纸续页，无对应字段）
    "lead": "…",                               // 导语：读范文的方法（对着右边批注看）
    "title": "…",                              // 示范文标题
    "paragraphs": [ "…", "…" ],                // ← 详案 > 【教师示范文】 blockquote，一字不改逐段照抄；
                                               //   技法句加 {hl}…{/hl}，高亮处须与 notes 一一呼应
    "notes": [                                 // 旁批卡（5–6 条）← 详案 | 示范文里的句子 | 这一句用了什么 | 表；
      { "q": "整条路像金色的隧道",             //   可从示范文讲解师话补 1–2 条（如开头结尾呼应、顺序），不得凭空造
        "a": "{b}打比方{/b}：把没见过的，换成见过的东西。" }
    ],
    "method": "…",                             // 「一句话记住」← 详案技法小结压缩，{b}标关键动作
    "footer": "…"                              // 「读范文是为了」：点破"学做法、别照抄题材"
  }
}
```

## 详案锚点速查（laojohn-writing-lesson 详案的结构约定）

| 详案锚点 | 供给字段 |
|----------|----------|
| 提纲表 `课题·课时` 行 | `meta.kicker`（年级册）、`meta.topic` |
| 提纲表 `核心技法` 行 | `worksheet.skills` |
| `### 四、借助构思表…` 环节内 `\| 项目 \| 关键词 \|` 表 | `worksheet.plan_rows`（行名逐字取） |
| 第2课时起笔引导（`### 一、聚焦一处…`） | `worksheet.draftnote` |
| `> 【教师示范文】` blockquote | `essay.title` + `essay.paragraphs`（一字不改） |
| `\| 示范文里的句子 \| 这一句用了什么 \|` 表 | `essay.notes` |
| 示范文讲解环节师话小结 | `essay.method`、可补的 1–2 条 notes |

## 模板里的固定骨架（不在 data.json 里，禁改）

品牌页眉 logo、构思表表头（想清楚这一步/写下你的关键词）、模块标题（理思路·构思表/写下来·格子稿纸/一句话记住/看老师用了什么办法）、「—— 教师示范文」落款、「老师批改」栏（字数刻度挂在栏内左缘）、格子稿纸 JS（16 列、动态行数、字数刻度；2026-09-07 由 18 列改 16 列，同日删去稿纸页底部修改符号表）、稿纸页姓名栏（姓名／班级／日期三栏）、稿纸续页 P3（备用整页格子，data.json 无对应字段）。

**姓名栏的两条硬约束**（2026-08-18 立，为作文批改工具加）：① **必须与 h1 同行**（挂在 `.titlewrap > .titlerow` 内）——独立成行会吃掉一整行格子（实测少一行），四上课次格数本就不多，减不起；② 独立成行时**必须同步计入 `buildGrid()` 的 `used` 选择器列表**，否则可用高度算多、页面溢出。现挂在 `.titlewrap` 内，高度已随其一并计入，`buildGrid` 无需单列。批改工具按这一行归属作业，勿移动、勿改三栏顺序；两页稿纸都要有（散页会分开，续页丢了姓名就归不了属）。

**稿纸续页 P3**（2026-08-18 立）：备用整页格子，不带起笔提示、无说明行（2026-09-07 删「上一页写满了…」一句），故比 P2 多 7–8 行（实测 P2 306–360 格、续页 450 格）。两页由 `buildGridOn()` 同一函数渲染，续页的字数刻度按 `startCount`（＝P2 格数）接着往下标、不从 100 重来。**调用该函数时 `usedSels` 必须列全本页挤占高度的元素**，漏一个就会算多行、页面溢出（末尾收敛环只是兜底，每减一行都要整页重排）。学生用因此为 4 页，`render_student.py` 的 `EXPECTED_PAGES` 与 `grid_checks`（增查续页、并核验续页格数不少于 P2）已同步。
