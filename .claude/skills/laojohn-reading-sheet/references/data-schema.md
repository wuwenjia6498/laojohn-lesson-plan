# manifest.json 字段说明

```json
{
  "book": "书名(纯书名)",
  "sheets": [
    { "file": "<阅读单名>-空", "template": "table|venn|ladder|logic|voyage", "data": { ... } }
  ]
}
```

- `file`：输出名(不含扩展)，约定 `-空`(学生填) 或无后缀单版(如派发表/纯主观单)。**`-示范`(教师参考)已停产**：引擎渲染时自动跳过，新写就别加了。
- `template`：模板键 → `templates/template_<键>.html`。
- `packet`(可选，sheet 级，非 data)：`"none"` 把该单子排除出「全套」册(其余历史值 both/blank 等同默认收、demo 等同排除)。
- `data`：注入模板的字段。**`logo` 不用写**，引擎统一注入。
- 所有 `data` 通用字段：`title`(标题)、`variant`(左上版本角标)、`subtitle`(副标题，可选)、`note`/`footer`(底部说明，可选)。
  - **角标恒久规则（引擎中央 gate，manifest 照常写即可）**：阅读单只出学生能填的版本，学生拿到的单子**不再盖"空白版/派发版"角标**——引擎渲染前会把 `variant` 里纯"空白版""派发版"整条隐藏；复合标签(如"空白版 · 换你来：xxx""派发版（含示例…）")只剥掉这两个前缀词、**保留后半信息**(剥后非空才上屏)。所以 manifest 里照写 `"variant": "空白版"` 不会再上屏，无需手动留空。
- **`sheets` 数组顺序 = 教学先后次序**：引擎按此序合「全套」册，新增单子要按课时位置插、别追加到末尾。

> 中文引号统一用规范弯引号 “”（嵌套用 ‘’），禁 ASCII 直引号，也不要用直角引号「」/『』(渲染引擎会把残留的「」/『』自动归一成 “”/‘’，但 data 里就该直接写 “”)。学生填的格=空字符串 `""`；预填的锚点=文本。
>
> **下文各模板里"示范版填…"的注释为历史说明**：示范版已停产，只看"空白版/学生填"那一半即可——学生要填的格给 `""`，仅表头/维度/锚点等脚手架预填真实内容。

## table —— 万能表格单

```json
"data": {
  "title": "《书名》阅读单 · 预测阅读单",
  "subtitle": "（可选副标题）",
  "variant": "空白版",
  "label_first_col": true,
  "row_min_h": 132,
  "columns": [ {"name": "列名(可含\\n换行)", "width": 38}, ... ],
  "rows": [ ["", "", ""], ... ],
  "note": "（可选底部说明）"
}
```
- `columns[].width`：百分比数字，各列之和≈100。
- `label_first_col`：true 时首列作"行标签"(深一档表头 + 浅底)，用于"维度/问题"固定、其余待填的表。
- `highlight_col`：可选整数列索引(0 起)。把该列整列高亮成绿色(表头深绿 + 单元格浅绿加粗)，用于把"相同点/结论/落点"这类**重点列**视觉提出来。典型场景：详案本想用维恩图、但内容是多维度对照(圆圈装不下)只能退化成表时，用它高亮"相同点"列补回"共同区"的视觉落点(如洞「两次上山对照」)。
- `row_min_h`：每行最小高度(px)。**书写空间的总开关**，见 generation-rules.md。
- `rows`：二维数组，元素为单元格文本；`""`=空白待填。示范版填真实内容。单元格文本支持 `\n` 硬换行（如思辨单“我的判断”列的 □ 选项逐行排，避免选项在窄格里被从词中间折断）。

## venn —— 维恩图(双长椭圆)

```json
"data": {
  "title": "《书名》卷四 · A ↔ B",
  "subtitle": "三个对比维度：① x　② y　③ z\n（第二行可写填法说明）",
  "variant": "空白版",
  "row_marks": true,         // 可选：三区行首挂 ①②③ 维度序号(同一 y 齐平)
  "left_label": "A", "center_label": "共同", "right_label": "B",
  "left":  ["", "", ""],     // 左区独有，每元素=一个「维度」；""=空白书写线，文本=填好
  "center":["", "", ""],     // 交叠区共同
  "right": ["", "", ""]      // 右区独有
}
```
- **图形是两枚竖向长椭圆(非正圆)**，占满 A4 竖版可用高度。两椭圆等大，所以左/右独有区在任一高度上宽度恒定，书写线随椭圆边缘平移、始终满宽——这是书写空间的来源，别改回固定 x。
- **一个数组元素 = 一个对比维度**，不是一行字：引擎给左/右每个维度 **3 条**书写线、交叠区每个维度 **2 条**（`GAP_LINE`/`GAP_ROW`/`L_SIDE`/`L_CENTER` 在模板顶部）。行数 = 三区数组长度的最大值，短的数组自动少排几个维度、位置仍与其它区对齐。
- `row_marks`：三区维度序号 ①②③ 一一对应时打开(**要求三区维度同序同数**)，序号挂在维度块上沿、三区同高。副标题里把维度写成「① x ② y ③ z」与之呼应。`subtitle` 支持 `\n` 换行。
- 交叠区是透镜形、上下两端窄(约 100–200px)，**共同点只写短句**；长句放左/右区(每行约 234px、可写 3 行)。
- 示范文本过长时引擎按各行实际可写宽度断行、余量并入末行。
- **模板 `template_venn.html` 与 `scripts/render_pptx.py` 的 `render_venn()` 各画一遍同一张图，几何常量必须同步改。**

## ladder —— 阶梯图(N 阶)

```json
"data": {
  "title": "X 的四阶变化",
  "subtitle": "每阶用书里的事实写一句话",
  "variant": "空白版",
  "footer": "（可选底部一句）",
  "steps": [
    {"header": "第一阶 · 卷一·第二章", "items": ["", ""]},  // items 每元素一行；""=书写线
    ...                                                      // 默认 4 阶(坐标已为 4 阶调好)
  ]
}
```
- 空白版 `items` 给两个 `""`(两条长书写线)；示范版给 1 个文本(自动断行+底线)。
- **阶数自适应**：`steps` 给几阶就画几阶(2–6+)，坐标/配色自动在版面内均分，无需改模板(格列佛 4 阶、洞 6 阶共用同一模板)。

## logic —— 讽刺逻辑图(三层)

```json
"data": {
  "title": "《书名》· 讽刺逻辑图",
  "subtitle": "从下往上读：① 表层 → ② 中层 → ③ 内核",
  "variant": "空白版 · 换你来：xxx",
  "footer": "（可选）",
  "layers": [          // 自上而下：③ → ② → ①
    {"label": "③ 内核：…", "text": ""},   // text=""→大空白格；有值→填好
    {"label": "② 中层：…", "text": ""},
    {"label": "① 表层：…(支架，常给好)", "text": ""}
  ]
}
```

## voyage —— 思维导图(中心 + 分支卡)

```json
"data": {
  "title_main": "《书名》", "title_sub": "四次远航",
  "variant": "空白版",
  "footer": "（可选）",
  "branches": [
    {"header": "一 · 小人国（卷一）", "fields": [
      {"label": "去到哪里", "lines": 1},                 // 空白：lines=横线条数
      {"label": "主要事件", "lines": 3},
      {"label": "怎么离开", "value": "文本或文本数组"}     // 示范：value=单串或多串(多行)
    ]},
    ...
  ]
}
```
- 字段空白用 `"lines": N`(画 N 条横线)；填好用 `"value"`(字符串或字符串数组，数组每项一行)。

## story_mountain —— 故事山形图（情节起伏，N 节点）

```json
"data": {
  "title": "《书名》· 故事山形图",
  "subtitle": "用书里的事实，在每个阶段写一句话",
  "variant": "空白版",
  "footer": "（可选底部一句）",
  "steps": [
    {"header": "起始", "items": ["", ""]},   // items 每元素一行；""=书写线
    {"header": "上升", "items": ["", ""]},
    {"header": "高潮", "items": ["", ""]},
    {"header": "下降", "items": ["", ""]},
    {"header": "结局", "items": ["", ""]}
  ]
}
```
- 平滑山形曲线，节点沿坡分布；**节点数自适应**(3–7，坐标/配色自动均分，无需改模板)。
- 空白版 `items` 给两个 `""`(框内两条书写线)；示范版给 1 个文本(自动断行，≤4 行)。
- 典型 5 阶：起始 / 上升 / 高潮 / 下降 / 结局；可按详案改 header。
- **单峰定位**：曲线让"峰顶"单独最高(上坡→峰→下坡)。峰顶节点优先认 `header` 含「高潮/climax」，否则取偏后约 60% 处；可加 `"peak": <索引>`(0 起)强制指定。6 阶(如起始/上升①/上升②/高潮/下降/结局)务必让高潮 header 带「高潮」二字，否则两个上升会并列在顶。

## fishbone —— 鱼骨图 / 因果图（多事件汇向一个结果）

> **纸是竖版 A4**（与其余单子同叠打印），但内容按横版 1123×794 排、整页逆时针旋转 90° 铺满页面——学生把纸顺时针转 90° 即为正常视图。这是全套唯一「竖纸横排」的模板；改几何只动 `#canvas` 内坐标，旋转层不必动。

```json
"data": {
  "title": "《书名》· 鱼骨图",
  "subtitle": "每根支骨写一件影响他的事",
  "variant": "空白版",
  "tail_label": "出生",        // 鱼尾=起点
  "head_label": "成为鹿王子",   // 鱼头=结果（≤6 字为宜，过长会挤）
  "ribs": [
    {"header": "童年", "text": ""},          // 上下交替自动排；text=""→书写线(6 根支骨时每框 5 行)，有值→填好(6 骨时≤14 字/行,6 行)
    {"header": "童年", "text": ""},
    {"header": "青年", "text": "", "side": "up"}  // 可选 side:"up"/"down" 强制某骨在上/下
  ]
}
```
- 支骨**沿主干等距、上下交替**(默认偶数在上)；支骨数自适应(建议 4–8)。**框宽随同侧间距自适应**(支骨越少框越宽，上限 300px)，故支骨少时书写空间更大。
- `header` 短词(时段/类别)，`text` 写具体事件。

## timeline —— 横排时间轴（N 个时间点/站点）· **横向 A4**

> 全套唯一**横向纸**的模板：`#page` 自报 1123×794，引擎自动按横向出 PDF（fishbone 内容也横排，但走竖纸旋转、纸仍是竖版）。

```json
"data": {
  "title": "《书名》· 时间轴",
  "subtitle": "每一站写下发生了什么",
  "variant": "空白版",
  "footer": "（可选）",
  "nodes": [
    {"header": "第1站", "lines": 6},          // 空白：lines=下方书写线条数(默认 6)
    {"header": "325星球", "value": "国王"},    // 示范：value=单串或数组(下方居中显示)
    {"header": "地球", "value": ["飞行员", "蛇、狐狸"]}
  ]
}
```
- 横轴 + N 节点等距；**节点数自适应**，但 **≤7 较佳**(更多会拥挤，宜改 `table`)。
- `header` 是轴上方彩色时段标签；空白版在轴下画书写线，示范版居中填字。

## bubble —— 气泡 / 放射图（中心 + N 发散气泡）

```json
"data": {
  "title": "《书名》· 气泡图",
  "subtitle": "把每一次…写进气泡里",
  "variant": "空白版",
  "center": "魔法帽",              // 中心节点文字（或 {"label": "魔法帽"}）
  "color": "#7FA86A",              // 可选，气泡/中心主色，默认绿
  "bubbles": ["", "", "", "", "", ""]  // 每个气泡一格；""=空白，文本=填好(≤4 行自动断行)
}
```
- 气泡绕中心**均匀放射**，数量自适应(建议 5–8)；`bubbles` 元素可为字符串或 `{"text": "…"}`。

## deduce —— 推断卡链（线索 → 追问 → 裁决）

```json
"data": {
  "title": "《书名》阅读单 · 物证推断表",
  "subtitle": "先写下这一章留下的那样东西，再一步步推下去。",
  "variant": "空白版",
  "columns": 3,          // 可选，网格列数，默认=卡数（3 张横排最稳）
  "steps": [             // 各卡共用的推理步骤；卡内可用同名字段覆盖
    {"label": "这一章留下的“物证”", "lines": 3},
    {"label": "如果奇事只是做梦、是假的，这件物证还会存在吗", "lines": 3},
    {"label": "所以我判断", "verdict": true, "options": ["真", "假"]}   // verdict=末步裁决勾选行
  ],
  "cards": [             // 2–4 张；header 支持 \n 换行（章号/章名分两行）
    {"header": "第十章\n月亮圆了"},
    {"header": "第十一章\n买东西过圣诞节"},
    {"header": "第十二章\n西风", "color": "#5B7FA6"}
  ],
  "tail": {              // 可选，底部「合起来看」收口条；不给则不画
    "label": "把三样物证放在一起看——它们有一个共同点，你发现了吗？",
    "lines": 3
  },
  "footer": "（可选底部一句）"
}
```
- **两种版式，默认自动选**：各卡共用同一组 `steps`（卡内不写自己的 `steps`）→ `matrix`，**步骤说明只在左侧竖排一次**，右侧每列一条线索只留格子；某卡自带 `steps` → `cards`，每张卡各印一遍步骤文字。可用 `"layout": "matrix" | "cards"` 显式覆盖。
  **共用步骤时别用 cards**——三张卡把同一句问句印三遍，纸面一半是重复的（初版踩过，已改默认）。
- **步骤间自动画 ↓ 箭头**（matrix 版画在左侧步骤列上），把“推断”这个动作画成方向——这是它区别于普通表格的全部价值。
- `verdict: true` 的步骤不画书写线，改出 `□ 真　□ 假` 勾选行，放在末步。
- 3 卡 × (3+3 行 + 裁决) + 收口 3 行正好一页 A4；再加行会溢出第二页。
- 详案里那句“把它们放在一起看，共同点是什么”的收口追问，**写进 `tail` 而不是页脚**——页脚是提示，`tail` 才有落笔处。

## stance —— 立场表 / 正反对峙单

```json
"data": {
  "title": "《书名》阅读单 · 立场表",
  "subtitle": "不光说“我觉得”，还得说清“我凭什么这么觉得”。",
  "variant": "空白版",
  "claim": "人一长大，就一定会忘掉那些小时候“懂得”的东西。",   // 要辩的那句话（顶部横幅）
  "claim_question": "你同意，还是不同意？",                    // 可选，横幅内小字追问
  "fields": [                                                 // 两栏共用的字段；side 内可用同名字段覆盖
    {"label": "我的理由", "lines": 3},
    {"label": "书里的证据（章 / 情节）", "lines": 4}
  ],
  "sides": [                                                  // 固定 2 栏；label 照抄详案的正反措辞
    {"label": "同意（会忘）"},
    {"label": "不同意（不一定全忘）", "color": "#5B7FA6"}      // color 可选
  ],
  "verdict": {                                                // 可选，底部落立场；不给则不画
    "label": "填完、听完两边，我的立场是：",
    "options": ["同意", "不同意"],                            // 不给则取两栏 label
    "lines": 2
  },
  "vs_label": "VS",                                           // 可选，中间圆标字样
  "footer": "（可选底部一句：找证据的提示）"
}
```
- **两种版式，默认自动选**：两栏共用同一组 `fields`（栏内不写自己的 `fields`）→ `matrix`，**字段标签只在中间比较轴上排一次**，左右两栏只留格子；某栏自带 `fields` → `columns`，两栏各印一遍标签。可用 `"layout": "matrix" | "columns"` 显式覆盖。
  **共用字段时别用 columns**——同一组标签在左右各印一遍，纸面一半是重复的（与 `deduce` 同一个坑）。
- `verdict.options` 给 `[]` 可去掉勾选项，只留书写线——用于「你的发现」这类开放追问（不是二选一）。
- **两栏都留给学生写**：自己那边写满，听同学分享时另一边有地方记——这正是「两边都能成立、关键看证据」的落点。
- `claim` 只抄详案里那句原话，**别自己改写命题**；两栏 label 也照抄详案的正反措辞。
- 字段 3+4 行 + 落立场 2 行正好一页 A4；再加行会溢出第二页。

## lanes —— 双泳道故事线（共同起点 → 并排走 N 段 → 结局分岔）

```json
"data": {
  "title": "《书名》阅读单 · 故事地图（三段式对照）",
  "subtitle": "两个人从同一扇窗口出发，走过同样三段——最后走到哪里去了？",
  "variant": "空白版",
  "start_label": "达林家的窗口",          // 可选，左上共同起点 chip；不给则不画起点与主干线
  "stages": [                            // 阶段 2–4；name=段名，sub=章节范围(可选)
    {"name": "离家远行", "sub": "第一至四章"},
    {"name": "永无乡历险", "sub": "第五至十五章"},
    {"name": "回家与长大", "sub": "第十六至十七章"}
  ],
  "lanes": [                             // 泳道 2–3，一条一个角色
    {"label": "温迪", "end_label": "温迪最后……"},
    {"label": "彼得", "end_label": "彼得最后……", "cells": ["", "", ""]}  // cells=示范预填(串或数组)，留空=书写线
  ],
  "lines": 5,        // 可选，每格书写线条数；不给=按格高自动铺满（推荐不给）
  "end_lines": 2,    // 可选，结局框内书写线条数，默认 2
  "footer": "（可选底部一句）"
}
```
- **书写线条数默认自动**：按格高算容量（56px 硬下限），再把实际间距均分铺满整格——所以**别手写 `lines`**，写小了格子下半截会空一片。
- **末端分岔**：两条泳道的结局框自动向外错开（上道上移、下道下移），虚线箭头岔开引到框上——「同起点、不同结局」是这个模板的表达重点。
- 结局框**留白**：它是学生读完才填的结论，不要预填（预填就把答案剥了）。
- 单角色的情节起伏不用这个，走 `story_mountain`。

## facets —— N 面卡片墙（一个话题拆成若干「面」）

```json
"data": {
  "title": "《书名》· 六面体讨论图 · 看客",
  "subtitle": "围着“看客”这一个话题，从六个角度想一想",
  "variant": "空白版",
  "columns": 2,        // 可选，网格列数，默认 2
  "lines": 3,          // 可选，每卡书写线条数默认值（单卡可用同名字段覆盖）
  "facets": [
    {"label": "联系", "question": "这一面要想的问题…"},
    {"label": "争论", "question": "…", "required": true},          // required=面名右侧加「必写」徽标
    {"label": "分析", "question": "…", "required_label": "重点"},  // 可选：改徽标字样
    {"label": "应用", "question": "…", "value": "示范预填(串或数组)"}
  ],
  "footer": "（可选底部一句）"
}
```
- **6 面 × 2 列 × 3 条书写线正好一页 A4**。书写线固定 56px（过书写间距硬规则）；**改成 4 行会溢出成第二页**——要更多书写空间就减面数或分两张。
- 网格同行卡片等高，因此各卡 `lines` 不同也不会错位（矮的那张多出留白）。
- 卡片彩条按序取 6 色调色板，可用 `color` 单卡覆盖。

## relation —— 人物关系图（N 户/组围栏 + 组内人物槽 + 底部共同节点）

```json
"data": {
  "title": "《书名》· 人物关系图 · 三户人家一张图",
  "subtitle": "把同一户的人写进同一个圈里",
  "variant": "空白版",
  "relation_label": "组内关系（谁是谁的什么人）",   // 可选，各组书写线上方的小标签，默认「组内关系」
  "relation_lines": 3,                             // 可选，每组书写线条数，默认 3（组内可用同名字段单独覆盖）
  "bottom_label": "这三户人家，同住在同一座城、同一个大院子里",  // 可选，底部共同节点；不给则不画
  "groups": [
    {"header": "“我”家", "slots": 8},                       // 空白：slots=空人物槽个数
    {"header": "老胡家", "slots": 8, "relation_lines": 4},
    {"header": "老王家", "members": ["赶车的父亲", ""]}       // members=预填人名(空串=空槽)；slots 取二者较大值
  ],
  "footer": "（可选底部一句）"
}
```
- **组数 2–4 自适应**：列宽自动均分；列宽 ≥200px 时人物槽排 2 列，否则 1 列。槽的大小随槽数自动缩放（槽多则矮，最小 ry 18）。
- `members` 只在**有档案/详案依据**时预填（如某户成员固定），一般空白版全给 `slots` 留空。
- 组内关系写在围栏下方的横线上（行距 62px，满足书写间距硬规则）。

## profile —— 人物名片 / 档案（图框 + 字段，可多卡）

```json
"data": {
  "title": "《书名》· 人物名片",
  "subtitle": "给 TA 做一张名片",
  "variant": "空白版",
  "banner": "人物名片",        // 可选装饰小标题
  "cards": [
    {
      "box": {"label": "画像 / 贴图", "w": 130, "h": 150},  // 可选：左侧图/画框(省略=纯字段)
      "fields": [
        {"label": "姓名", "lines": 1},
        {"label": "印象最深刻的一件事", "lines": 2},
        {"label": "性格", "value": "勇敢、好奇"}            // value=示范预填(串或数组)
      ]
    }
  ]
}
```
- **名片式**(魔法师)：多张 `cards`，每张小 `box`(w≈130,h≈150) + 4 字段。
- **档案式**(长袜子)：单张 `card`，`box` 大(w≈300,h≈520，整列画人物) + 多字段。
- 字段空白 `lines`、填好 `value`(同 voyage)。
