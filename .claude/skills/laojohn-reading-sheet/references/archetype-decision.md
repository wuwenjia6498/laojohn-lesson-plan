# 详案 → 模板 决策树

从详案识别出一张"学生要动手填的阅读单"后，按下面判断归到哪个模板。**先判结构、再选模板**，不是看工具名字。

## 第零刀：先看是不是"书写 / 绘画版式页"（不是信息图表）

有些阅读单不是"梳理信息的图表"，而是让学生**自由书写或画画**的版式页——直接归"版式原语"，**别硬套表格/图形**：

| 详案动作（让学生做的事） | 模板 |
|---|---|
| 「写一首诗 / 写一段 / 续写 / 自由表达」——整页自由书写 | `writing` |
| 「画出… / 画下… / 绘制人物·场景」——整页绘画 | `draw` |
| 「左边写情节、右边画」「画小漫画 / 连环画」——多格图文并排 | `comic` |
| 「做人物名片 / 建人物档案 / 角色卡」——图框/画框 + 字段清单 | `profile` |

> 版式页**默认只出单版**（学生自己写/画，无"标准答案"）；`profile` 若详案给了参考信息可出示范版。

## 第一刀：是"表格"还是"图形"

- 详案里这张是一个 **Markdown 表格的填空页**(有表头行 + 待填空行)，或本质是"列项填写/分栏对照" → **`table`**。这是大多数情况，也是兜底。
- 是一个**特定图形结构**(圆圈交叠/台阶/分层金字塔/中心发散) → 进第二刀。

## 第二刀：图形归哪类

| 详案信号(出现这些词或结构) | 模板 | 结构要点 |
|---|---|---|
| 「维恩图」「两个圆圈交叠」「相同 / 不同」「A ↔ B 对比异同」 | `venn` | 双圈：左独有 / 交集共同 / 右独有 |
| 「阶梯图」「一阶一阶」「逐级升高」「态度 / 梦想 / 成长进阶」 | `ladder` | N 阶台阶(默认 4，自适应)，每阶 header + 书写线 |
| 「讽刺逻辑图」「三层」「表层 → 中层 → 内核」「荒诞事→影射→批评」 | `logic` | 自下而上三层框，上行箭头 |
| 「思维导图」「以…为中心向外并列挂分支」「N 次远航 / N 次冒险 / 几个板块」 | `voyage` | 顶部中心盒 + 连接线 + N 张分支卡，每卡多字段 |
| 「故事山 / 山形图」「情节曲线 / 起伏」「起始→上升→高潮→下降→结局」 | `story_mountain` | 平滑山形弧线，N 节点沿坡(默认 5，自适应)，每节点框 + 书写线 |
| 「鱼骨图 / 因果图」「多件事影响一个结果 / 人物」 | `fishbone` | 横向主干，斜支骨上下交替；头=结果、尾=起点；每骨一事件框 |
| 「时间轴 / 时间线」「依次经历」「N 个星球 / 站点 / 时期」(横向排开) | `timeline` | 横轴 + N 节点(≤7 较佳，自适应)，时段标签 chip + 下方书写块 |
| 「气泡图」「中心一物向外发散」「逐一列举每一次…」 | `bubble` | 中心圆 + 放射气泡(默认 6，自适应)，气泡内填写 |

## 第三刀：归不进图形 4 类 → 退化成 `table`

可视化工具表(见 lesson-plan `references/visualization-tools.md`)里还有不少类型，**多数能退化成带标签的表格**，用 `table` 兜底即可，不必为每种开模板：

| 工具 | 退化成 table 的列设计 |
|---|---|
| 对比图 / 多维对照表(≥3 维度) | 行=对象、列=维度(首列行标签)。**注**：双对象异同才用 `venn`；多维对照仍走 table |
| 树形图 / 分类 | 列：类别 / 子项 / 说明 |
| 故事地图 · 英雄之旅(离家/冒险/回家) | 行=角色，列：离家 / 冒险 / 回家的变化 |
| 环形故事地图(地点绕圈) | 行=各地点，列：地点 / 发生了什么(暂无环形专用模板，可上报候选) |
| 多级括号思维导图(左根多级树) | 行=末级节点，按层级缩进；或上报候选 |
| 六面体讨论图 | 行=联系/描述/比较/争论/应用/分析，列：我的讨论 |
| KWL / 预测 / 自问自答 | 多列填空表 |

> 退化只是**让学生有得填**的务实兜底，不是最佳呈现。**已专门开模板、不要再退化成表格的**：故事山形图→`story_mountain`、鱼骨图→`fishbone`、横排时间轴→`timeline`、气泡/放射图→`bubble`(见第二刀)。仍未覆盖、图形价值高且会反复用到的(如环形故事地图、多级括号导图)，值得按 SKILL.md「如何加第 N 种模板」专门开——但这是主动决策，不是每次都开。

## 第四刀：这张到底做不做成阅读单

只做**学生动手填**的。下列**不做**：
- 原文齐读页、纯老师讲解/示范页、要点小结页(除非详案明确让学生填)。
- 老师展示用的"已填好的展示图"——除非它同时要学生自己填一份(那就出空白版)。

## 拿不准时
- 图形/表格二选一拿不准 → 选 `table`(更稳，学生总有得填)。
- 工具完全不认识、也不像任何已知结构 → **不硬塞**，记下来在交付时上报"需新模板/手工处理"。
