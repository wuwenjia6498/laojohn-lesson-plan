# 老约翰 · 同步习作单元海报

把一份写作课详案变成一张**面向家长的单元招生海报**（对外物料，不是教学物料）。版式对齐用户给的《学会写日记》样张：
logo → 毛笔大标题 → 一句副题 → 深棕胶囊「X年级X册｜第N单元同步习作」→ 中央插画 → 三张牛皮纸卡（**家长三问**：写作难点／这一课怎么教／孩子能学会什么）→ 橙色报名条＋二维码 → 地址电话。

产物落 `<项目根目录>\写作课海报输出\<年级册>-第N单元-<题目>\`：
`<课次>-习作海报.json`（内容源，入库）· `<课次>-插画.jpg`（AI 插画，入库）· `<课次>-插画-提示词.txt`（追溯）· `<课次>-习作海报.html/.jpg`（渲染产物，不入库）。

> 路径与环境：执行前 `(Get-Location).Path` 确认盘符，禁止硬编码；一律 `PYTHONUTF8=1 python`（勿用 `python3`）。
> 写作课配套**独立于读书会重设计**（2026-07 用户定），本 skill 不是 course-poster 的写作模式，只借用它同一条 JPG 渲染引擎。

## 工作流（两段式 + 生图）

```bash
# 1. 机械抽取 → 骨架 json（A 类填实，C 类留【…待 AI 提炼…】占位，_sources 放证据）
PYTHONUTF8=1 python .claude/skills/laojohn-writing-poster/scripts/extract_fields.py "写作课详案输出/<课次>-写作课详案.md"

# 2. 你（AI）读 json 的 _sources，按 references/data_schema.md 填实 C 类 7 处（含 illustration.subject）

# 3. 生图 + 判读（需 AIHUBMIX 密钥；已有正式图会跳过；--style 169 或 json 里 illustration.style 指定手绘风格编号，不给走通用前缀）
PYTHONUTF8=1 python .claude/skills/laojohn-writing-poster/scripts/gen_illustration.py "写作课海报输出/<课次>/<课次>-习作海报.json"

# 4. 渲染（机检不过会拒绝；logo/二维码/校区信息自动取 品牌资产\）
PYTHONUTF8=1 python .claude/skills/laojohn-writing-poster/scripts/render_writing_poster.py "写作课海报输出/<课次>/<课次>-习作海报.json"
```

第 1 步对已有 json 重跑只刷新 A 类与 `_sources`，不会冲掉已填的 C 类。

## 字段三分类（质量核心，契约唯一源 `references/data_schema.md`）

- **A 类**：脚本从详案固定结构抽（H1 题目、副标题文体、提纲表、两课时 H2 与 `###` 环节）。照抄不改写。
- **C 类**：`title` / `subtitle` / 三卡各自的 `head`＋`lines` / `cta.outcome` / `illustration.subject`。**全 skill 唯一让 AI 写字的地方**，受下面红线约束。
- **配置类**：`品牌资产\logo.png`、`qrcode.png`、`校区信息.json`（地址／电话／提示句／行动句；空则隐藏）。渲染时读，不进 json。

## C 类红线

1. **提炼 ≠ 创作**：每一句都要能指出详案哪一段（`_sources` 里已摘好），不新增详案没有的说法、不加课程线级的营销语（「不背范文」「63 篇全覆盖」这类属课程海报，不进单元海报）。
2. **三卡＝家长三问，栏目名 63 张固定**（写作难点→这一课怎么教→孩子能学会什么）：卡① 写孩子最常见的一个真实问题，卡② 写本课最核心的一招，卡③ 写学完具体多会了一件什么事。**「2 节课／当堂写作与评改／构思表」这类交付方式不上卡片**，只进底部橙条（2026-09-20 母版定）。
3. **字数上限是版式硬约束**（副题 ≤18 字、卡片 `head` ≤7 字、`lines` 每行 ≤10 字、`outcome` ≤14）：超了回去压字，不改版式。
4. **同课次配套 json 有现成句就优先复用**（家长用 `oneline`、学生用 `skills` 的加粗点、教师用 `warns[0]`），保证海报与配套口径一致；无配套才从详案派生。
5. `title` 默认就是题目，改写只许「学会／写好 + 题目」式，**避开全角 `＿＿`**（毛笔体缺字）。
6. 弯引号“”，禁 ASCII 直引号、禁 emoji、禁「待补充」——渲染脚本机检拦，拦住就是没填好。
7. 语感：平实、克制，写给家长看（「总写成流水账？」「一天只写一件事」），不用感叹号、不用营销腔。

## 插画（`references/illustration-prompt.md` 是唯一源）

只写 `illustration.subject`：**画面＝这一课的情境**（示范文最关键的那一刻／教材题面／学写法正例），可有人物、禁文字；不是文具静物（2026-09-20 用户否掉「本子加笔」）。**风格按单元自选编号**（`illustration.style`，来自用户级手绘风格库 001–274，静物友好清单见该文件；不填走通用水彩前缀），用过的参考图自动拷进 `assets/handdraw/refs/` 入库。判读四问自动跑；**判读失败＝未知不＝不通过**，候选留 `<课次>-插画.候选.jpg`，人工看过手动改名转正。人工外部出图直接放到 `<课次>-插画.jpg`。图服从文字，绝不用图改文案。

## 交付话术（必说）

- 这张是**对外招生件**：文字全部来自详案，请再通读一遍海报文字是否与课上真会讲的一致。
- 底部地址／电话来自 `品牌资产\校区信息.json`，空则不显示；各校区改这份配置重渲，不要 P 图。
- 插画是 AI 生成、已过「无文字／无人物」判读；不满意改 `illustration.subject` 加 `--force` 重生，或换自己的图放到 `<课次>-插画.jpg`。
- logo 源图只有 292px 宽，2 倍截图下略软；换 ≥600px 的 `品牌资产\logo.png` 重渲即清晰。

## 常见问题

- **机检报「残留占位」**：C 类没填完，回到 json 把 `【…待 AI 提炼…】` 全部换掉。
- **标题字回退成楷体**：`title` 含毛笔体没有的字（生僻字／`＿＿`），改写标题。
- **卡片标题折行 / 三卡行数不齐**：`head` 超 7 字或某行 `lines` 超 10 字，回去压字。
- **插画与背景有接缝**：模板已加径向蒙版；仍明显就是图的底色偏离奶油色，重生（前缀已写死 `#FFF6E3`）。
- **批量**：对 `写作课详案输出\` 逐份跑第 1 步即可回归解析；C 类与生图仍逐课次做，先过一份样张再批量。
