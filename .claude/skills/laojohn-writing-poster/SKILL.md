# 老约翰 · 同步习作单元海报

把一份写作课详案变成一张**面向家长的单元招生海报**（对外物料，不是教学物料）。版式对齐用户给的《学会写日记》样张：
logo → 毛笔大标题 → 一句副题 → 深棕胶囊「X年级X册｜第N单元同步习作」→ 中央插画（下缘被卡片叠压 140px，连成一块）→ 三条要点条（竖排堆叠，均为「左标题｜竖线｜右正文」横排；无阴影纯色平铺、三条同一底色，第三条「成长收获」靠橙色左缘条与橙调栏目名区分，价值升华层）→ 橙色报名条＋二维码 → 地址电话。

产物落 `<项目根目录>\写作课海报输出\<年级册>-第N单元-<题目>\`：
`<课次>-习作海报.json`（内容源，入库）· `<课次>-插画.jpg`（AI 插画，入库）· `<课次>-插画-提示词.txt`（追溯）· `<课次>-习作海报.html/.jpg`（渲染产物，不入库）。

> 路径与环境：执行前 `(Get-Location).Path` 确认盘符，禁止硬编码；一律 `PYTHONUTF8=1 python`（勿用 `python3`）。
> 写作课配套**独立于读书会重设计**（2026-07 用户定），本 skill 不是 course-poster 的写作模式，只借用它同一条 JPG 渲染引擎。

## 工作流（文案两段式 + 插画先推敲后生图）

```bash
# 1. 机械抽取 → 骨架 json（A 类填实，C 类留【…待 AI 提炼…】占位，_sources 放证据）
PYTHONUTF8=1 python .claude/skills/laojohn-writing-poster/scripts/extract_fields.py "写作课详案输出/<课次>-写作课详案.md"

# 2a. 你（AI）读 json 的 _sources，按 references/data_schema.md 填实 C 类 6 处文案（title/subtitle/三卡/cta.outcome）

# 2b. 插画立意推敲（⚠ 先于写 subject，不可跳）：照 references/illustration-prompt.md「出图前的立意推敲」
#     过一遍立意三问 → 在对话里给用户 2–3 个画面方向（各带立意·画风编号·风险）并推荐一个 →
#     用户拍板后才写 illustration.subject，并把三问结论、方向、选定与作废理由回填 illustration._brief

# 3. 生图 + 判读（需 AIHUBMIX 密钥；已有正式图会跳过；--style 169 或 json 里 illustration.style 指定手绘风格编号，不给走通用前缀）
PYTHONUTF8=1 python .claude/skills/laojohn-writing-poster/scripts/gen_illustration.py "写作课海报输出/<课次>/<课次>-习作海报.json"

# 4. 渲染（机检不过会拒绝；logo/二维码/校区信息自动取 品牌资产\）
PYTHONUTF8=1 python .claude/skills/laojohn-writing-poster/scripts/render_writing_poster.py "写作课海报输出/<课次>/<课次>-习作海报.json"
```

第 1 步对已有 json 重跑只刷新 A 类与 `_sources`，不会冲掉已填的 C 类。
⚠ **重跑只拷回 `title/subtitle/cards/cta/illustration` 五个顶层键**，所以立意留痕 `illustration._brief` 必须嵌在 `illustration` 下、别放顶层。

## 字段三分类（质量核心，契约唯一源 `references/data_schema.md`）

- **A 类**：脚本从详案固定结构抽（H1 题目、副标题文体、提纲表、两课时 H2 与 `###` 环节）。照抄不改写。
- **C 类**：`title` / `subtitle` / 三卡各自的 `head`＋`lines` / `cta.outcome` / `illustration.subject`。**全 skill 唯一让 AI 写字的地方**，受下面红线约束。⚠ 其中 `illustration.subject` **不许直接开写**——先走第 2b 步立意推敲、用户拍板方向之后才落笔。
- **配置类**：`品牌资产\logo.png`、`qrcode.png`、`校区信息.json`（地址／电话／提示句／行动句；空则隐藏）。渲染时读，不进 json。

## C 类红线

1. **提炼 ≠ 创作**：每一句都要能指出详案哪一段（`_sources` 里已摘好），不新增详案没有的说法、不加课程线级的营销语（「不背范文」「63 篇全覆盖」这类属课程海报，不进单元海报）。
2. **三卡＝递进三层，栏目名 63 张固定**（写作难点 · 教法→能力收获→成长收获，2026-09-21 母版改）：卡① 行文顺序固定为「孩子真实写作现象 → 点出背后问题 → 引出课程怎么解决」，中间要有过渡（如「问题出在…。这堂课教孩子…」），不许说完问题直接跳到教学手段；卡② 写学完多出来的那项能力（「不再…」这类平实陈述起句，**禁「告别…」**）；卡③ 写这一课在能力之上长在孩子身上的东西。**「2 节课／当堂写作与评改／构思表」这类交付方式不上卡片**，只进底部橙条。
2b. **文案三条硬线（2026-09-28 用户据人工定稿三上五／五上五总结）**：① 语句完整——禁半截句（「不少孩子写观察，」须补全宾语）、禁模糊指代（「那一条」「这一类」须补出中心名词）；② 逻辑连贯——见上条卡①行文顺序；③ 清除口号腔——禁「告别XX」式指令短句，禁抽象造词（「中心却散了」「天天见，也能看出新鲜」「跃然纸上」「不可被复制的…」），一律改成平实陈述：孩子实际会遇到什么、学会后实际会做到什么，家长一读就懂。例：「材料不少，中心却散了」→「材料不少，中心抓不住」；「告别几件事平均着写」→「不再几件事例平均用力」。
3. **字数上限是版式硬约束**（副题 ≤18 字、三条 `head` 各 ≤10 字、`outcome` ≤14；`lines` 以语句完整为先，卡①两段合计约 ≤110 字、卡②③ ≤70 字，卡片随字数长高）：`lines` 是**整段**数组（1–2 段，浏览器自动折行，不要手工断行）；超了回去压字，不改版式。
4. **同课次配套 json 有现成句就优先复用**（家长用 `oneline`、学生用 `skills` 的加粗点、教师用 `warns[0]`），保证海报与配套口径一致；无配套才从详案派生。
5. `title` 默认就是题目，改写只许「学会／写好 + 题目」式，**避开全角 `＿＿`**（毛笔体缺字）。
6. 弯引号“”，禁 ASCII 直引号、禁 emoji、禁「待补充」——渲染脚本机检拦，拦住就是没填好。
7. 语感：书面、连贯的整句，写给家长看（「不少孩子把整日琐事悉数记录，事事浅尝辄止。」），不用感叹号、不用营销腔、不写碎行短语。**卡③「成长收获」是唯一放宽口**（2026-09-21 用户定）：允许价值判断式表述（「这份真切，是成长里无可替代的宝藏」），不必逐句反查详案；**卡①卡② 仍句句来自详案，红线 1 不豁免**。

## 插画（`references/illustration-prompt.md` 是唯一源）

⚠ **先推敲、再落笔、后生图（2026-09-22 定，硬线）**：拿到题目不许直接写 `illustration.subject`。先解一遍题意——题目里的关键词是实指还是比喻／抽象、这一课的能力点是什么、遮住题目只看图家长会说这是在教什么；再给用户 **2–3 个画面方向**，每个写清「立意 ＋ 画风编号 ＋ 风险」并推荐一个，**用户拍板后**才写 subject。**比喻类题目禁止把喻体画成实体主体**——喻体只许降格成视觉语言（构图、色彩、排布），要画的是比喻所指的那个内容。三问、四条硬线与一票否决见 `illustration-prompt.md`「出图前的立意推敲」节；推敲结论回填 `illustration._brief`。

只写 `illustration.subject`：**双轨（2026-09-22 改）——默认按单元习作题目立意、想象尺度放开**（拟人、超现实、巨型实物、书里长出的世界都可以），详案里有一处画面感极强的情境时才取详案（示范文最关键的那一刻／教材题面／学写法正例）。**先定画风编号、再按这个画风写画面**。可有人物、禁文字；仍不许画与课无关的文具静物（0920 否掉「本子加笔」）；高年级走意象化、不走娃娃脸卡通。**画面主体要落在上 2/3**——卡片区上提 140px 压住插画下缘（2026-09-21 版式改），底部那条会被遮住，关键物件别安排在画面最下方。出图后**按具体画面调 `illustration.zoom`**（缺省 1，实测 1.05–1.2：留白多的图调大、满幅到边的图调小），图够大、卡片压上去才成立。**风格按单元自选编号**（`illustration.style`，来自用户级手绘风格库 001–274，**已验证编号清单见该文件**，先挑号再写画面；不填走通用水彩前缀），用过的参考图自动拷进 `课件配图工具/手绘风格库/refs/` 入库（这套风格库 2026-09-24 起与课件配图工具共用）。判读四问自动跑；**判读失败＝未知不＝不通过**，候选留 `<课次>-插画.候选.jpg`，人工看过手动改名转正。人工外部出图直接放到 `<课次>-插画.jpg`。图服从文字，绝不用图改文案。

## 交付话术（必说）

- 这张是**对外招生件**：文字全部来自详案，请再通读一遍海报文字是否与课上真会讲的一致。
- 底部地址／电话来自 `品牌资产\校区信息.json`，空则不显示；各校区改这份配置重渲，不要 P 图。
- 二维码**缺省是「二维码位置」虚线占位框**（2026-09-25 用户定，各校区自行换码）；要印真码渲染时加 `--qr 品牌资产/qrcode.png`（或校区自己的码）。
- 插画是 AI 生成、已过「无文字／无人物」判读；不满意改 `illustration.subject` 加 `--force` 重生，或换自己的图放到 `<课次>-插画.jpg`。
- 插画方向是**你拍板的**：立意三问、当时给过的 2–3 个方向、选定理由与作废理由都存在 json 的 `illustration._brief` 里；要换方向先看一眼这一块，别重复否掉过的路子。
- logo 已换成 1200×414 **透明底** png（2026-09-21，原 292×110 白底图放大发虚）。模板因此**去掉了 `mix-blend-mode:multiply`**——日后若换回白底图必须加回来，否则奶油背景上会出现白方块。

## 常见问题

- **换了插画后四周出现灰色方框、或画面发闷**：json 里还留着按旧图调的 `illustration.punch`（<1 会压低亮度和饱和度，奶油底被压成灰米色）。**换图时要把 `punch`／`zoom`／`theme_hue` 这些按旧图调的参数一并复核**，不合新图就删掉（2026-09-23 三上一实测：残留 `punch 0.78` 显出方框）。

- **插画画的是题目里的那个词、不是题目要说的那件事**（如《生活万花筒》画成一只万花筒）：立意错了，回工序 2b 重走三问换方向，**不是改画风**——画风救不了立意。
- **机检报「残留占位」**：C 类没填完，回到 json 把 `【…待 AI 提炼…】` 全部换掉。
- **标题字回退成楷体**：`title` 含毛笔体没有的字（生僻字／`＿＿`），改写标题。
- **标题字号变小 / 三条竖线没对齐**：三条左栏统一 380px，标题 36px 封顶、超 10 字自动缩（可用宽 374px），缩太多就回去压字。竖线不齐只会是左栏定宽被改。
- **插画与背景有接缝**：模板已加径向蒙版；仍明显就是图的底色偏离奶油色，重生（前缀已写死 `#FFF6E3`）。
- **插画四周显出一块偏黄／偏白的方形**（纸底和页面奶油差一档，gpt-image 常见米黄纸底）：**渲染侧已自动处理**（`_match_paper`：取插画上方两角当纸色，够亮、暖色、离奶油不远就把接近纸色的像素挪到 `#FFF6E3`，人物和暖光不动，原图不改），渲染时会打印「纸底 … 已挪到 #FFF6E3」。不要再手动给插画调色。
- **插画上缘一条发白的带**：模型把四周画成了纯白纸边，渐隐到奶油底上就成一条带。**渲染侧已自动兜底**（`creamify_illu`：外环近白就把全图白点重映射到 `#FFF6E3`，只吃高光、原图不动），渲染时会打印「检出白纸边…」。要关掉用 `--no-creamify` 或 json 里 `illustration.creamify: false`；**别再靠调大 `zoom` 裁白边**，那会白白裁掉画面。
- **插画关键物件被卡片盖住**：卡片叠压插画下缘 140px 是有意的（不是溢出），**改 `illustration.subject` 把主体挪到画面中上部重生，不要去改模板的重叠量**——那是 63 张统一的版式。
- **四张摆一起底色差不多**：自动取色取的是面积最大的高饱和色，这批插画都是暖调水彩，四张自动落点全在 24–35°。要拉开就顶层手填 `theme_hue`（实测：童话菜园 85 绿、教室场景 205 蓝，明显比自动贴合）。
- **换了 `theme_hue` 后插画周围显出一块**：主底奶油是写死的，`theme_hue` 只染光晕与卡片。若整页底色也想换，插画生图背景色（`#FFF6E3`）必须同步改并重生插画——现行不这么做。
- **插画四周羽化太多、边上的景物虚掉一大圈**（满幅场景图常见）：json 里 `illustration.feather` 填 `"light"`，只收最外一圈窄边（2026-09-24 加，六上四实测）；`false` 是整个关掉羽化，只给纯色块平涂图用。缺省不变，存量海报不受影响。
- **插画太淡或太浓**：调 `illustration.punch`（滤镜，不动原图）。**淡了往上 1.2–1.3**（1.45 起暗部发闷），**浓了往下 0.78–0.88**（0.68 起褪色发灰）。别为浓淡重生图。
- **插画左右出现硬边方块**：`zoom` 调太大，画面裁到页边、水彩淡出边被切掉。降到 1.2 以内。
- **批量**：对 `写作课详案输出\` 逐份跑第 1 步即可回归解析；C 类与生图仍逐课次做，先过一份样张再批量。
