# 中央插画 · 主体描述与生图口径（唯一源）

海报中央那张图是**每单元 AI 生图**（2026-09-20 用户定），风格前缀与负面词写死在 `scripts/gen_illustration.py`，
AI 只写 `illustration.subject` 这一段「画面主体」，**且不许拿到题目就动笔**——先走下面「出图前的立意推敲」。**规格是事实源，图服从文字**：判读不过就改提示词重生，绝不反过来改 json 文案迁就图。

## 出图前的立意推敲（先于写 subject · 2026-09-22 定）

拿到题目不许直接写画面。先过三问，再给方向，用户拍板后才落笔。

| 问 | 怎么答 | 答不上来会出什么事 |
|---|---|---|
| ① 题目里的关键词是实指还是比喻／抽象？ | 把那个词单拎出来问「这一课教的是它本身吗」。答「不是」＝比喻或抽象词 | 把喻体当主体画出来 |
| ② 这一课的能力点是什么？ | 照 `_sources.outline.核心技法` 压成一句 | 画面与课脱钩，换个单元照样能用 |
| ③ 遮住题目只看图，家长会说这是在教什么？ | 替家长答出一句话 | 画面认得出题目、认不出课 |

**⚠ 四条硬线**

1. **比喻／抽象题目：禁止把喻体画成实体主体。** 要画的是比喻所指的那个内容；喻体只许降格成**视觉语言**——构图（散开、汇聚、层层套叠）、色彩、排布（弧线、环形），不作为实体道具出现。已知比喻／抽象题目：《生活万花筒》《我的心儿怦怦跳》《多彩的活动》《二十年后的家乡》《＿＿让生活更美好》《笔尖流出的故事》《变形记》。
   **正面范例（四上五《生活万花筒》，2026-09-23 采用）**：中央一个抱着本子、咬着铅笔仰头想的孩子；四周一圈彩色玻璃碎片组成放射状的框，每一块碎片里是一个生活片段（赛跑冲线、领奖、拍蚊子、扶摔倒的同学、一家人吃饭……）。用户评价「既有万花筒的意思，又不是实际万花筒」。成立靠三点：①**中央有一个主角**当视觉锚点，碎片围着他；②片段被**统一的碎片框收住**，不是各自散开的独立小图；③全图**一种画风、一个暖色调**。比喻题给方向卡时可先按这个思路想：喻体变成「框住内容的结构」，本体（生活里的事）装进结构里。
2. **画面主体要对得上本课能力点**（问②）：把画面那句话念出来，指得出它对应「核心技法」里的哪半句；指不出就换方向。
3. **画面要与三卡文案呼应**：逐卡对一遍卡①（写作难点·教法）／卡②（能力收获）／卡③（成长收获），**至少有一卡能被这张画面指认**；三卡一条都对不上＝方向作废。
4. **一票否决＝遮题测试**（问③）：答案落在「一件物品／一个玩具／一处风景」上即作废，**不必再调画风**——画风救不了立意。

**方向卡格式**（2–3 个，每个四行，末尾推荐一个并说明理由）

    方向 X · <一句话画面>
    立意：这张图要让家长看出什么（对应哪一卡、哪半句技法）
    画风：#编号 · 风格名（为什么这个画风担得起这个画面）
    元素：这张图总共几件东西（人＋X＋Y）——多场景方案天然碎，嫌碎就回单一主体（例外：有中心主角＋统一碎片框收住的多场景，见硬线 1 正面范例）
    风险：最可能画坏的那一处

⚠ **给方向是 AI 的活，挑方向是用户的活**（同 `laojohn-detail-review` 的 A 块／B 块口径）：**不许只给一个方向让用户点头**；至少 2 个，且方向之间**立意要真的不同**——只换画风不算换方向。

**推敲留痕**：写进 `illustration._brief`（`题型`／`能力点`／`遮题测试`／`方向[]`｛名·立意·画风·风险｝／`选定`＋`理由`／`作废[]`｛名·为什么｝／`拍板`）。⚠ **必须嵌在 `illustration` 下**——`extract_fields.py` 重跑只拷回 `title/subtitle/cards/cta/illustration` 五个顶层键。`_` 开头 ⇒ 渲染忽略、机检跳过。**作废那条必须写**，下次换图先看它，别重复否掉过的路子。

**作废台账**（否掉一个方向就补一行）
- 四上五《生活万花筒》· 孩子举巨型万花筒、筒口喷出彩色色块（#258）—— 把喻体画成了实体主体；遮题测试答「一个玩具」；三卡一条都对不上。**0922 首版实测，这一条就是本节的由来。**
- 四上五《生活万花筒》· 四处生活小场景沿弧线散开（#128）—— 立意对了（遮题测试过关），**败在呈现**：四块写实小图＋彩纸＋弧线，用户判「太碎、不清爽，而且也太写实」。⚠ **教训：立意过关不等于方向过关**——方向卡里除了立意，还要问一句「这个画面画出来元素有几件」。多场景方案天然碎，嫌碎就得回到单一主体。**0923 补**：这一版败在「四块互不相干的写实小图＋一条弧线、没有中心」，不是「多场景」本身——同一课最后采用的正是多场景（见硬线 1 正面范例），区别在有中心主角、有统一的碎片框、画风统一。
- 四上五《生活万花筒》· 0923 又试了「一条线几个结」「时间被按了暂停」「书包里的小镇」「电梯里数顶灯」四个方向，都没过（用户嫌不够有创意，或画面效果不到位），最后改用 ChatGPT 网页版直接出的图。各方向的否决理由见该课 json 的 `illustration._brief.作废`。

## subject 怎么写（40–180 字，多场景散开构图取上限）· 双轨：默认按**单元习作题目**立意，详案有强画面才取详案

⚠ **2026-09-22 换口径**。此前（0920 晚）锁死「画面必须取详案情境」，跑了 6 张后发现：详案情境大半是「教室里」「书桌前」，
张张雷同且平淡（五上五换了四轮画风仍不满意、三上三「怎么调画风都很普通」），而最出画面的三上四恰恰是题材自带想象空间。
**根子不在画风，在画面来源被锁死。** 现行两轨，**判据一句话：哪个画出来好看用哪个**。

**轨一（默认）· 题目立意**：把**单元习作题目**当主题自由构思，不必是详案里发生过的事。
**想象尺度放开**（2026-09-22 用户定）：拟人、超现实、夸张比例、童话式构图都可以——会说话的物件、从书页里长出来的立体世界、
比人还高的巨型实物、飘着的纸飞机。已验证两例：
- 五上五《介绍一种事物》＝草地上一个比人还高的三阶魔方像小屋，男孩站木梯上拉软尺丈量它，顶上停两只鸟；
- 三上三《续写故事》＝摊开的大书里翻卷出山丘树林，一条路伸向亮着灯的小木屋，系围巾的兔子与提灯笼的刺猬结伴走在路上，男孩坐书脊上用长铅笔把前面的路画出来。

**轨二 · 详案情境**（详案里有一处画面感极强、一眼就成图时才走）：按序取
① 示范文或范例里最关键的那一刻（六上五＝妈妈手机夹在肩上、两手扎头发、眼睛还瞟着锅）；② 教材题面／创设情境；③ 学写法环节的正例。

**一条护栏：放开的是画面创意，不是把画风做低幼。** 三上三上这类中低年级可以走童话拟人；
五上六上走**意象化／超现实**（巨型实物、光影、干净构图），人物按高年级画——同样大胆，但家长一眼看得出是高年级的课。
五上五实测：#061 几何童话出的是娃娃脸卡通（好看但显幼），换 #258 后人物成了穿校服的少年，才对。

**仍然不变的硬约束**：
- 画面要认得出是这个题目——0920 否掉的「日记本＋钢笔＋橡皮」那类**与课无关的文具静物**仍然禁止，放开不等于随便画；
- **禁文字**：黑板、屏幕、纸面一律留白（在 subject 里点明「纸面没有字」「黑板留白」）；
- **别在 subject 里提天空**：写「天空干净没有云」会让模型真画一块蓝天矩形，海报上就是一块突兀的蓝（五上五实测）；要空就写「身后不画天空，背景整片留空」；
- **主体落在画面上 2/3**：下缘 140px 会被卡片压住，关键物件别安排在最下方（底部草地之类只留窄窄一条）；
- ⚠ **人物位置要写死「头顶离画面上缘多少」，光写「近景半身」不够**：写「左下角」模型就把人画进被遮的那 140px 里（四上五实测，头和肩全没了）。现行写法＝「头和肩膀在画面左侧中部，头顶离上缘约四分之一，胸口以下不画」——被压住的只有衣摆；**全身站姿一律不写**（首版实测被切在小腿）；
- 写法＝一句话说清**谁在哪里做什么**＋2–4 件带情绪的细节物件；人物写「小学生／同学／老师」不写名字；
- **人物年龄要正面描述体型，光写「五年级男孩」模型一律画小**：高年级写「十一二岁、个子抽条、手长腿长、脸型清瘦不是幼童圆脸」（五上五实测两轮才对）；
- **鞋、帽这类小件不写就会缺**（漏写鞋出过赤脚站梯子）；要童话感就把人物本身写成绘本角色（尖顶小帽＋条纹围巾＋背带裤），光换画风不够（三上三实测）；
- 不写风格词、不写背景色（前缀已固定），不写「可爱」「温馨」这类空词；
- 真要纯静物时在 json 加 `"no_people": true`，判读才会把人物当硬失败。

## 风格编号（可选，接入用户级 skill handdraw-style-prompter）

`illustration.style` 填三位编号（或 CLI `--style 169`），提示词改为「画风特征（放最前）+ 画面内容 + 固定约束 + 参考图说明」，
并把该编号的参考图作为风格参考传给生图（参考图只给画风、不给内容）。不填编号沿用通用水彩前缀。

⚠ **2026-09-23 修正三处（风格与示例图差距大的根因）**：
- 风格库旧参考图是把拼图一律按 4×4 等分切出来的，**045–048、124–139、201–216 等整批切错了格**（如旧 `046.webp` 实为半只熊加 047 的灰猫，旧 `128.webp` 上半截是 124 的花丛），而且每张都带编号和风格名文字。已在用户级风格库重切（按实测版式、去文字），`refs/` 同名文件已同步。**0923 之前用 #046、#128 出的图都是拿错图生的**。
- 旧提示词对所有编号强加「柔和水彩淡彩上色」，平涂、清线类画风都被拉成水彩；现只在特征缺「色板」一项时加一句不指定媒介的上色要求。
- 风格名和作者名（英文）不再写进提示词，只进回执；特征改写为「线条｜上色｜色板｜人物｜质感｜背景」六项可见描述（目前已改 19 个海报候选编号，其余仍是旧的抽象描述）。
- `258_grid.webp` 本身是重复拼贴、带 promptsref.com 水印，用它出图要留意判读的 has_text。

⚠ **顺序：立意 → 画风 → 画面。** 三问定了立意之后、写 subject 之前挑编号——按选定的那个方向从 `assets/handdraw/styles.json`（274 条）里挑编号——
优先 B 组「国际绘本／叙事型手绘」与 D／E 组当代插画，特征里带「想象／奇幻／绘本／叙事／水彩／明快」的优先——
**再按这个画风所长写 subject**（担得起想象的就写想象场景，擅长光影的就写光线）。先写画面再硬套编号，出来就是「怎么调都很普通」。**方向卡里的「画风」一行就是这一步的产物**，挑号连同方向一起交给用户拍板。

**外部出图口（2026-09-23 立）**：用户在 ChatGPT 网页版（gpt-image）等外部平台直接出的图可以用，四上五即是。放到 `<课次>-插画.jpg`（PNG 先转 JPG）；`<课次>-插画-提示词.txt` 注明外部来源、提示词未知；`illustration.provider` 记 `external`、`judge.verdict` 记 `manual`（没过本工具判读，人工看过无文字）；竖图用 `illustration.scale` 完整显示（四上五 4:5 竖图用 0.72），别用 `zoom`——它只改高度，会把竖图上下裁掉。**`gen_illustration.py` 现在默认就走 gpt-image（AiHubMix，同系模型）并过判读，不必再去网页手动拷；要换回用 `--provider gemini|doubao`**；外部口仍留给网页端对话式改图。

## 出图后的局部修改：用图像编辑，不重出（2026-09-23 立）

画面大体对、只差一处时，**把现有插画当输入交给 gpt-image 做图像编辑**，不要改 subject 重出——重出会把已经对的地方一起丢掉。
提示词固定写法：先写「只改 X，其余全部保持不变」，再逐项点名不许动的东西（构图、姿势、道具、配色、画风），最后说 X 改成什么样、「纸面没有字」。
一次只改一两处；改前把现图另存 `*.<说明>.候选.jpg`（不入库），改完在 `illustration._brief.出图` 记一笔。调用：

    make_client("gpt-image").generate(提示词, ratio="4:3", images=[现插画路径])   # 课件配图工具/scripts/imgclient.py

已验证的三类：
- **外轮廓方形、显死板**（满幅到边的场景图）：「只改画面外轮廓……四周改成不规则的水彩晕染边缘，边缘的叶子一簇簇散开、越往外越淡，露出奶油色纸底；整幅画不碰四条边，四个角全是空白」。六上一一次成功，画面还会顺带往里收一点，被卡片压住的脚也露出来了。**别用调大羽化代替**——那只会把四角糊成一片。
- **人物显小、不像该年级**：画风特征自带「圆脸、头身 1:4」时（#105 这类），光在 subject 写年级没用。编辑时正面写体型：「头相对身体再小一些、头身比拉长；脸更长更瘦、下巴清楚、脸颊没有婴儿肥；没被放大的那只眼睛偏细长；手指修长」。三上五用了两轮才像九岁；**第二轮容易把表情改淡、脖子改细**，第三轮要把「表情＋脖子与头的比例」一起点名补回来。改完同步把体型写进 subject，下次重出不再画小。
- **单处细节**（头发画法、衣服一块、表情）：同上格式，只点那一处。

纸底颜色不用编辑：渲染时自动检查、自动挪到页面奶油色（见 SKILL.md 常见问题）。

## 生图与判读

```
PYTHONUTF8=1 python .claude/skills/laojohn-writing-poster/scripts/gen_illustration.py "<课次>-习作海报.json" [--style 169] [--force] [--ratio 4:3] [--no-judge]
```

- 画幅默认 4:3（模板插画区 1114×720 裁切，`object-fit: cover` + 边缘径向蒙版，与奶油背景融合）。
- 判读四问：`has_text` 为真 = 硬失败（`no_people` 为真时 `has_person` 也算），自动加负面词重生 1 次；`bg_cream` / `subject_ok` 为假只警告，人工看图定。
- **判读请求失败或回包不是 JSON = 未知，不是不通过**（照 `课件配图工具/scripts/verify_rules.py` 的 `judge_failed` 闸门）：候选留在 `<课次>-插画.候选.jpg`，人工看过后手动改名成 `<课次>-插画.jpg` 即转正。
- 人工外部出图：直接把图放到 `<课次>-插画.jpg` 即可，脚本见文件存在就跳过。
- 密钥：环境变量 `AIHUBMIX_API_KEY`，或 `课件配图工具\.env`，或 picture-writing 的 `imggen.config.json`（均 gitignored）；本 skill 不碰密钥。
- 插画入库（重渲不出来的输入资产，比照 `图位\` 口径）；候选图不入库。
