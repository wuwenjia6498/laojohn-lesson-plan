# 单元海报 data.json 字段契约（唯一源）

文件：`<项目根目录>\写作课海报输出\<年级册>-第N单元-<题目>\<课次>-习作海报.json`。
`_` 开头的键是证据块与回执，渲染忽略、机检跳过。引用词语一律弯引号“”，禁 ASCII 直引号、禁 emoji、禁「待补充」。

## A 类 · `extract_fields.py` 机械抽（照抄不改写，AI 不动）

| 字段 | 详案锚点 | 缺失 |
|---|---|---|
| `course.id` / `grade_vol` / `unit` / `topic` | 文件名 `<年级册>-第N单元-<题目>-写作课详案.md`（fullmatch 正则，题目可含 `＿＿`/`“”`）；`topic` 以 H1 `# 《…》· 写作课教学设计` 为准 | topic 硬门槛报错 |
| `course.grade_label`「三年级上册」 | `grade_vol` 映射 | — |
| `course.genre`「应用文·日记」 | 副标题 `X年级X册·第N单元 校内同步写作（文体）` 括号；缺则提纲表「课题·课时」行第 2 段去「·校内同步」 | 留空（不上海报） |
| `capsule`「三年级上册｜第二单元同步习作」 | `grade_label` + `unit` 拼接 | — |
| `cards[*].kind` / `label` | 三卡固定栏目名（63 张统一）：`pain`＝写作难点 · 教法 / `gain`＝能力收获 / `spirit`＝成长收获 | 恒定，AI 不改 |
| `cta.fit`「适合小学三年级」/ `cta.sessions`「2 节课」 | 年级映射 / 常量（提纲表末段「2课时连排」全线恒定） | — |
| `_sources.outline` | 提纲表「学习目标」「核心技法」「教材要求」原文 | 留空 |
| `_sources.lesson1_sections` / `lesson2_sections` | `### 一、…（约 N 分钟）` 环节名与分钟 | 留空 |
| `_sources.warn_sentences` | 第 1 课时「学写法」环节 `师：` 行里含「流水账／不是／不要／别／而是／这就是」的句子，≤4 条 | 留空 |
| `_sources.compare.bad/good` | 同环节 `师：第一段：…` / `师：第二段：…` 审题辨析对比段 | 留空 |
| `_sources.companion` | 同课次 `写作配套输出\<课次>\` 的家长用 `onepager.oneline`、学生用 `worksheet.skills` 的 `{b}` 词（`skills_b`）、教师用 `overview.warns[0]` | 无配套则空 |

已有 json 再跑 `extract_fields.py`：只刷新 `course` / `capsule` / `_sources`，C 类保留。

## C 类 · AI 填（唯一写字处；只许压缩改写详案已有内容，逐条反查依据）

| 字段 | 上海报位置 | 从哪里压缩 | 上限 / 规则 |
|---|---|---|---|
| `title` | 毛笔大标题 | 默认已填 `topic`，可直接用；改写只许「学会／写好 + 题目」式或与「学习目标」同义 | ≤8 字；**避开全角 `＿＿`**（毛笔体缺字），如《＿＿让生活更美好》→「让生活更美好」 |
| `subtitle` | 副题 | `companion.oneline` 优先，无则「学习目标」行 | **≤18 字**（56px 单行硬上限约 19 字），一句话说清这一课最核心的写作突破 |
| `cards[0].head` / `lines` | 卡① 写作难点 · 教法 | 第一段自 `warn_sentences`／`compare.bad`（孩子最常见的那个真实问题），第二段先点背后问题、再引出本课这一招（「问题出在…。这堂课教孩子…」，禁直接跳到教学手段） | head ≤10 字、写孩子遇到的实际情况（如「日记写成了流水账」）；lines 两段、合计约 ≤110 字 |
| `cards[1].head` / `lines` | 卡② 能力收获 | 「核心技法」与 `companion.skills_text`：这一招做到后文章是什么样 | 一段为宜，平实陈述起句（如「不再只用“开心”“难过”这样的词」，**禁「告别…」**）；head 如「写出当时的心情」 |
| `cards[2].head` / `lines` | 卡③ 成长收获（与前两条同结构、异外观） | 这类写作在能力之上长在孩子身上的东西 | 同上（head ≤10 字、lines ≤70 字）。**唯一允许价值判断式表述、不逐句反查详案的卡**（2026-09-21 用户定） |
| `cta.outcome` | 「完成孩子的第一篇完整日记」 | 「学习目标」行末句（「写成一篇日记」） | ≤14 字，「完成…」式 |
| `illustration.subject` | 生图画面 | **先走 `illustration-prompt.md`「出图前的立意推敲」拿到用户拍板的方向**，再按该方向写；轨一题目立意（默认）／轨二详案强画面 | 40–180 字，谁在哪里做什么＋2–4 件细节物件；人物一律近景半身、点名服装颜色、别提天空、禁文字，写法见 `illustration-prompt.md` |
| `illustration.no_people` | 可选 | 题面本身是物件时置 true，判读才把人物当硬失败 | 布尔，默认不写 |
| `theme_hue`（顶层，可空） | 页面光晕与牛皮纸卡的色相 | 缺省由 `render_writing_poster.py` 从插画自动取色；**自动取的是面积最大的高饱和色**，常落在皮肤／木头／砖墙上，与人眼认的主题色不符时手填 | 0–360 数字，如菜园 `85`、教室 `205`。**主底奶油 `#FFF6E3` 不随它变**（插画生图背景写死同色，一换就露色块） |
| `illustration.zoom` | 插画缩放（可空） | 按具体画面定：主体小、四周留白多的图调大，满幅到边的图调小 | 数字，缺省 1（＝容器高 920px）。**实测区间 1.05–1.2**；再大会把画面裁到页边、水彩淡出边被切出硬边（三上四 1.25 实测） |
| `illustration.scale` | 插画整体缩小（可空，2026-09-23 加） | 近景大头、满幅场景图嫌大时用：整张图按比例缩到页宽的这个比例，不裁切 | 0–1 之间的数字，缺省不生效（存量海报不变）；三上五用 0.8。⚠ 与 `zoom` 不同：`zoom` 只改插画区高度、宽度始终铺满，缩它只会把图上下裁掉、人物并不变小 |
| `illustration.space_above` | 插画上方额外留白（可空，2026-09-23 加） | 版面嫌紧、标题区和插画挤在一起时用 | 像素数，加在原有 14px 间距上；缺省不生效；三上五用 70 |
| `illustration.feather` | 关掉插画边缘羽化（可空，2026-09-23 加） | 纯色块平涂图（如 #046）用：羽化会让贴边的人物半透明地虚掉一截 | 填 `false` 生效：模板不做羽化，渲染脚本按外环底色把插画底抠成透明（PNG），不会显出矩形方框；缺省照旧羽化。水彩、铅笔类图别关 |
| `illustration.punch` | 插画浓度（可空） | 整体偏淡（铅笔淡彩）或偏浓压不住文字的图 | 数字，缺省 1（不处理）。**大于 1 加深、小于 1 调浅**：三上三淡彩 1.3（1.45 起暗部发闷）、三上一浓彩 0.78（0.68 起褪色发灰）。只是 CSS 滤镜，原图不动、随时回退 |
| `illustration.focus` | 取景位置（可空） | 放大后主体偏出可视区时才用 | `object-position` 值，如 `"center 38%"`；缺省 `center` |
| `illustration.style` | 手绘风格编号（可空） | 人选：从手绘风格库画廊挑 001–274 的编号（静物友好清单见 `illustration-prompt.md`） | 三位数字串如 `"169"`；空则走通用水彩前缀。**不设全线默认，按单元自选**（2026-09-20 用户定） |
| `illustration._brief` | 不上海报 | 第 2b 步立意推敲的结论（三问答案／2–3 个方向／选定＋理由／作废＋为什么） | 对象。`_` 开头 ⇒ 渲染忽略、机检跳过（`_common.py` 的 `_walk` 任意层级跳过 `_` 键）。**必须嵌在 `illustration` 下**——`extract_fields.py` 重跑只拷回 `title/subtitle/cards/cta/illustration` 五个顶层键，顶层新键会被静默冲掉。字段见 `illustration-prompt.md` |

**三卡＝递进三层，但分两层排**（2026-09-21 母版改，原「家长三问」作废）：孩子卡在哪儿＋这节课怎么教（合并一卡） → 学完多出哪项能力 → 这类写作长在孩子身上的东西。前两卡回答家长「我家孩子是不是这样、老师到底怎么教、学完有什么变化」，**底色 `--tone-a`、无阴影**；卡③ 回答「为什么值得学」，是价值升华层，**与前两条同结构（左标题｜竖线｜右正文横排）、同底色，区别只在左缘橙条 + 橙调栏目名 + 标题不挂深棕竖条**（依次试过「白底」「三档递进」「两档略深」，均被判不协调／多余，最终定为三条同色、只靠细节区分）。**「2 节课／当堂写作与评改／构思表」这类交付方式一律不上卡片**，只在底部橙条出现。

三条 `head` ≤10 字：左栏统一定宽 380px（三条竖线才对齐），标题按字数自动缩保证单行（36px 封顶、可用宽 374px）。`lines` 是**整段**数组（24px 字号，右栏宽约 604px，浏览器自动折行）——**不要手工断行**，卡①合计约 ≤110 字、卡②③ ≤70 字（卡片随字数长高）。

缺失处理：`subtitle` 空则隐藏；某卡 head 与 lines 皆空 → 整卡隐藏、其余卡等分；`cta.outcome` 空则只显示「2 节课」。
**对外物料禁写「待补充」，宁可留空不编。**

## 配置类 · `render_writing_poster.py` 渲染时读，不落进 json

- `品牌资产\logo.png`、`品牌资产\qrcode.png`（单一源，`--logo/--qr` 可覆盖）。
- `品牌资产\校区信息.json`：`address` / `phone` / `note` / `cta`；值空则该行隐藏，四项全空整块隐藏。json 内若已有 `campus` 键则优先（单张海报人工覆盖口）。
- 插画：同目录 `<课次>-插画.jpg`（`--illustration` 可覆盖）；缺则留奶油空区并 stderr 提示。
