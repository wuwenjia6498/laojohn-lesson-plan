# 写作课模式（course-poster · 习作课招生图变体）

本 skill 默认把读书会课案做成课程招生海报。当输入是 **写作课（习作课）详案**（由 `laojohn-writing-lesson` 产出）时，切本模式产出 **习作课招生图**：**渲染脚本、模板、版式照旧复用**，只换数据口径——信息卡换课程信息、四栏标题换写作说法、不取书目/书籍档案。

## 0. 怎么判型（自动）
H1 `# 《题目》· 写作课教学设计`、书级 `## 一、教案提纲表`+`## 二、核心素养教学目标`（四维标签）、课时 `## 第1课时 · 写作指导课`。判不准走默认读书会模式。

## 1. 萃取方式（不跑 extract_fields.py）
`scripts/extract_fields.py` 的 A 类正则针对读书会标题/作者、B 类读书籍档案——**写作课无书籍档案、无书目字段，故不跑该脚手架**，直接**手工萃取写作详案**写 JSON。C 类（summary/gains）提炼红线同主 SKILL（只压缩改写详案已写出的，不新增事实、不营销腔）。

## 2. 数据差异（模板已加可选字段承载，读书会不传即原样）

```json
{
  "title": "这儿真美",                         // 习作题目，不带《》（也用于找封面，无则占位）
  "level": "三上",                             // 等级标改填年级简写（读书会是 Lx）
  "info_rows": [                               // 信息卡：每行 [标签,值]，覆盖默认书目字段
    ["题目", "这儿真美"], ["年级", "三年级上册"],
    ["单元", "第六单元"], ["类型", "写景·校内同步"],
    ["课时", "2 节 × 45 分钟"], ["主题", "把身边的美写具体"]
  ],
  "labels": {                                  // 四栏标题覆盖（不传则用读书会原文）
    "summary": "这门课写什么：",
    "gains": "写作收获：",
    "strategies": "写作技法学习&运用：",
    "vistools": "思维工具学习&运用："
  },
  "summary": "招生向习作介绍，80–100 字（写这次写什么、写给谁看、在哪展示）。",
  "gains": ["收获一：…。", "收获二：…。"],        // 2–3 条，家长视角能带走什么
  "strategies": "围绕中心意思写、按一种顺序、五感写具体、打比方……",  // 该课写作技法
  "vistools": "五感观察表、写作构思表、旁批表、自改标准表。",         // 写作支架/工具
  "award": ""                                  // 写作课无奖，留空、模板自动隐藏
}
```

- **不写** `author/publisher/word_count/page_count/book_type/theme`（写了也会被 info_rows 覆盖；写作课本就没有这些书目字段）。
- `info_rows` / `labels` 值只来自写作详案（提纲表/目标/标题），缺则留空字符串。
- **封面**：写作课无书封；`find_cover` 找不到会用占位封面。如要配图，往 `<项目根目录>\书籍封面\<题目>.png` 放一张主题图（与读书会共用目录、按题目命名），重渲染即嵌入。

## 3. 渲染与输出
```bash
python scripts/render_poster.py "<项目根目录>\习作招生图输出\<题目>_招生图.json" "<项目根目录>\习作招生图输出\<题目>_招生图" --covers "<项目根目录>\书籍封面" --qr "<项目根目录>\品牌资产\qrcode.png"
```
（Windows 先 `set PLAYWRIGHT_BROWSERS_PATH=...`，见根 CLAUDE.md §1。）**输出目录 `<项目根目录>\习作招生图输出\`**，命名 `<题目>_招生图.{json,jpg,html}`。JSON 是内容源头，三件套 JPG→JSON→HTML 交付；缺失信息栏留空等人工回填、不编造。
