# 老约翰课案 → 课程招生海报

把一份课程详案(教案详案 `.md`)转成一张竖版课程海报,版式对齐老约翰品牌样张,输出 **JPG(传播交付)** 与 **HTML(可编辑源文件)**。

## 这张海报是给谁看的(定位)

面向**潜在报名的家长**,是**招生物料**,不是教学物料。因此:
- 丢弃课案里所有教学性内容(师生对白、活动设计、PPT 换页标记、课时安排等)。
- 只保留两件事:**这是一本什么书** + **这门课带孩子读到什么、练到什么**。

## 交付物形态:这是一份「待补全初稿」

**关键认知**:本 skill 产出的 JPG 是**待人工补全的初稿**,不是即发成品。海报上凡是没有明确信息的字段(出版社、字数、页数、类型、主题、获奖):

- **信息栏(出版社/字数/页数/类型/主题)缺失 → 该栏保留、值留空白**(不写"待补充/请回填"、不画占位框)。
- **获奖区缺失 → 整块自动隐藏**,下方内容上移,不留空洞。

由人工在 data.json 里补实后,重新渲染才得到对外发布的成品。绝不允许为了「让初稿好看」而去课案正文里猜这些字段、或凭记忆/联网编造。**留空白等人工,胜过编造。**

## 整体流程

两段式:**萃取(你来做)→ 渲染(脚本来做)**。

1. 跑萃取脚手架,得到一份「半成品 JSON」(A 类字段已填、B 类占位、C 类待填)。
2. **你**按红线把 C 类两栏(内容简介 / 阅读收获)填实到 JSON。
3. 跑渲染脚本,得到 JPG + HTML。

```bash
# 第 1 步:机械抽取,生成骨架 JSON(直接落在固定输出目录)
# --profile 传入书籍档案，自动填充出版社/字数/页数/类型/主题/获奖
python3 scripts/extract_fields.py "<项目根目录>\课案输出\书名-课案详案.md" "<项目根目录>\课程海报输出\书名_海报.json" --profile "<项目根目录>\书籍档案\书名书籍档案.md"

# (第 2 步:你编辑 data.json,填实 summary 与 gains)

# 第 3 步:渲染(--covers 封面目录；--qr 二维码路径，均指向项目级品牌资产)
python3 scripts/render_poster.py "<项目根目录>\课程海报输出\书名_海报.json" "<项目根目录>\课程海报输出\书名_海报" --covers "<项目根目录>\书籍封面" --qr "<项目根目录>\品牌资产\qrcode.png"
```

## 字段三分类(本 skill 的质量核心)

海报固定版式,**每一栏永远存在**,填实值或留空白(获奖块例外:缺失则整块隐藏)。字段分三类,处理方式截然不同:

### A 类|直接抽(来自课案明确字段,照抄不改写)

| 海报栏 | 课案来源 | 缺失处理 |
|---|---|---|
| 书名 | 一级标题 `# 《X》…` | **硬门槛**,缺失则报错停,不可占位 |
| 等级标 | 第二行 `Lx · …` 的 L 数字 | 占位 `L?` |
| 作者 | 「作者简介」段首人名 | 占位 |
| 阅读策略 | 提纲「阅读策略」行 | 占位 |
| 可视化思维工具 | 提纲「可视化教学工具」行 | 占位 |

脚本已自动完成 A 类抽取。**作者只抽名字,国籍前缀(如 [美])课案有就带、没有不补**。

### B 类|优先从书籍档案取，档案无则留空

| 海报栏 | 来源（优先级由高到低） | 仍缺时 |
|---|---|---|
| 出版社 / 字数 / 页数 / 类型 / 主题 | `书籍档案.md` 里 `## 海报/指南元数据` 块 | 留空白（栏位保留、值空白），等人工回填 |
| 获奖信息 | `书籍档案.md` 里 `## 海报/指南元数据` 块的获奖列表 | 默认留空，模板自动隐藏整块；有奖人工填入 |
| 封面图 | `<项目根目录>\书籍封面\` 按书名匹配 | 用占位封面 |

`extract_fields.py` 通过 `--profile <书籍档案.md>` 读取元数据块；档案里填「（待补充）」的字段视同缺失，对应栏留空白。

**重要**:即使书籍档案没有传入，也**绝不从课案正文口语里猜**这些字段——这条反编造红线不变。

### C 类|AI 提炼(全 skill 唯一允许 AI 生成措辞处,受最严约束)

| 海报栏 | 提炼自 | 字数 |
|---|---|---|
| 内容简介 `summary` | 课案「内容简介」段 | 80–100 字 |
| 阅读收获 `gains` | 「情感价值」+「知识技能」目标 | 每条 20–35 字,共 2–3 条 |

脚本把这两栏留成 `【…待 AI 提炼…】` 占位,**必须由你填实**。

---

## C 类提炼的纪律(红线,务必遵守)

这是全 skill 唯一让 AI 写字的地方,约束如下:

1. **提炼 ≠ 创作**。只能压缩、改写课案**已写出**的内容,**不得新增任何课案没有的事实**——不加情节、不加评价、不加书外的奖项/销量/推荐语。
2. **逐条自检**:每写一条,反问「这句的依据在课案哪一段?」答不出就删掉重写。
3. **内容简介**:从课案「内容简介」段压缩成故事梗概。**剔除非故事信息**——如「教育部统编推荐」「某课文出自此书」「语文推荐丛书」等,这些是出版背书不是故事,不进海报简介。若课案原文已是梗概,优先精简原文而非另起重写。
4. **阅读收获**:从「情感价值/知识技能」目标提炼成 2–3 条「家长视角能带走什么」。把「让学生体会……」改写成读者向说法。每条形如「概念词:一句说明。」。
5. **语感**:克制、平实,不用营销腔(「不可错过」「必读神作」「强烈推荐」)。

### C 类范例(俗世奇人课案 → 提炼)

```json
"summary": "本书是冯骥才创作的短篇小说集，写的是清末民初天津卫码头上一群「俗世奇人」。苏七块、刷子李、泥人张、酒婆、蓝眼，三十六位三教九流的小人物，各有一手绝活、一条死规矩，各篇独立成章，合成一幅市井群像。",
"gains": [
  "匠人精神：体会手艺人「靠绝活吃饭、靠死规矩立信」的诚信与坚守。",
  "文学赏析：读懂短篇小说集「合而成卷」的体例，品味津味儿白话语言。"
]
```
简介剔除了课案里的「教育部统编推荐」「五下课文《刷子李》出自此书」(非故事信息);收获两条均能在课案「情感价值/知识技能」目标里找到依据。冒号统一用全角「：」。

## 获奖区怎么处理

获奖信息课案里**几乎从不会有**,所以本 skill **不抽取、不判断有无奖、不编造**。获奖字段**默认留空(`award` 为 `""`),模板自动隐藏整个获奖块**:

- **无奖(默认)**:`award` 留空,获奖块自动隐藏、下方内容零空隙上移,不留空洞、不画占位框。
- **有奖**:人工在 data.json 里把 `award` 字段填成真实奖项(可写成数组,多条多行),重渲染即显示。

你(AI)端默认把 `award` 置空,**不要替用户决定有没有奖、更不要编一个奖填进去**。

## 封面匹配

渲染脚本通过 `--covers` 参数接收封面目录路径，按 `data.json` 的 `title` 去该目录找 `<书名>.jpg`（匹配时自动去书名号、空格、标点容错）。

**封面图统一维护在项目级共用目录（与 laojohn-reading-guide 共用）：**

```
<项目根目录>\书籍封面\<书名>.jpg
```

- 支持扩展名：`.jpg` / `.jpeg` / `.png` / `.webp`
- 匹配到：嵌入该封面。
- 匹配不到：用 `assets/covers/_placeholder.jpg` 占位封面，并在 stderr 提示。**交付时务必把「封面未匹配、已用占位」明确告诉用户**，请其按上面路径规则放图后重渲染。

封面库由用户长期维护：往 `<项目根目录>\书籍封面\` 放图、按书名命名，所有需要封面的 SKILL 都会从这里取用。

## 渲染与交付

### 固定输出目录

> ⚠ 本项目位于移动硬盘，盘符可能随挂载变动。执行前请通过 Cursor 工作区路径或 `(Get-Location).Path` 确认实际项目根目录，下方 `<项目根目录>` 代表该路径。

**所有产物统一保存到：**

```
<项目根目录>\课程海报输出\
```

文件命名规则：`<书名>_海报`（如 `俗世奇人_海报.jpg`、`俗世奇人_海报.html`、`俗世奇人_海报.json`）。

---

```bash
# 数据与产物都落在固定输出目录(JSON 是内容源头,务必一并保存)
# --covers 指向项目级共用封面目录；--qr 指向项目级共用二维码
python3 scripts/render_poster.py "<项目根目录>\课程海报输出\书名_海报.json" "<项目根目录>\课程海报输出\书名_海报" --covers "<项目根目录>\书籍封面" --qr "<项目根目录>\品牌资产\qrcode.png"
```

脚本会:
- 把 JSON、封面、二维码内联进 `assets/template.html`,生成**自包含 HTML**(可独立打开)。
- 用 Chromium 截**整页 JPG**(宽 1242px,高度随内容自适应,2x 高清)。
- 纵向流式布局:删任何块/改任何字,版式自动收拢,无需调坐标。

用 `present_files` 交付三件套,顺序 **JPG → data.json → HTML**。并向用户说明:
- 这张 JPG 是**待补全初稿**,缺失的信息栏(出版社、字数、页数、类型、主题等)显示为空白(栏位保留、值空白),需人工在 data.json 补实;获奖区默认留空隐藏,有奖则填 `award`。
- **改字/补占位/删获奖**:编辑 `data.json` 对应字段,重跑渲染命令即可。data.json 是内容源头,不要只改 HTML(改动不回写 JSON)。
- 全角冒号「：」;若封面是占位图,请补真实书封到 `covers/`。

## 常见问题

- **某栏文字太长撑破版面**:C 类写啰嗦了,回去压短(简介 80–100 字、收获每条 20–35 字),不要改版式。
- **课案缺某类信息**:如实告诉用户哪栏会留空,请其回填,**不要联网/凭记忆填满**。
- **想换书重做**:换课案重跑 `extract_fields.py`,模板和脚本不动。
- **二维码/logo 资产**:正式二维码放 `assets/qrcode.png`;缺失时脚本用占位二维码并提示。
