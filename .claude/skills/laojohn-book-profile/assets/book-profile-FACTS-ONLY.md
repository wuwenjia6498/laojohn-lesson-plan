# 《书籍档案·纯事实版》填写模板

> **用途**:这是生成详案的**内容来源**。本模板**只填客观事实(原料)**,把"用什么工具、阅读单怎么设计、配什么思辨问题、三维目标怎么写"等**全部留给 AI 在生成教案时依据书的内容自行设计**。事实填得越准越全,AI 的设计才越有依凭——原料错了,设计得再好也是废的。
>
> **默认前提**:填写本档案时手头应有这本书的电子版/全文。这是唯一可信的原文来源——逐字原文从它取;定位以章节为主、有稳定页码再附(电子版常是流式/无固定页码,属正常)。没有电子版、只有简介时,情节梗概可填,但**逐字原文栏一律写"无原文,仅概述",绝不凭记忆补**(这是生成 SKILL 在缺料时会拦下要料的情况,不要在档案里用回忆糊弄过去)。
>
> **填写铁律**:所有内容必须来自这本书本身。**不确定、书里没有的,标"(待核实)"或"未涵盖",绝不凭记忆编造。** 情节、人物、章节、页码、原文尤其如此。
>
> **颗粒度提醒**:够用即可,**不要为了"填满"而把记忆当事实补进去**。一条确证的真实片段,胜过五条模糊的回忆。宁可某栏写"未涵盖",也不要凑。
>
> 标 [必填] 的字段缺失会导致无法生成对应环节;**未标的可留空**。

## 一、基本信息
- 书名《》[必填]
- 等级 L_ [必填]
- 建议课时数(可选;留空则按等级默认。一般 L1–L2≈2~3、L3–L4≈4、L5–L6≈4~5,以实际教学安排为准)
- 依据版本(出版社 / ISBN / 或电子版格式如 epub)[必填;有稳定页码则以此版本为准,流式/无页码版注明"无固定页码,按章节定位"]
- 作者 / 译者 / 字数
- 获奖信息(照抄,注明出处)
- 封面/封底/腰封上的宣传语原文(若有,**照抄原文**,注明出处。注:名家推荐语属营销物料、非书内容,不必单独收录,如某句宣传语恰好出自正文另说)

## 二、作者&背景(有则填,无则留空)
> **本节为「书外信息」**:作者简介、写作缘起、背景考据等多半来自封底/前言/译序或外部资料,**不是本书正文**。
> **每条须标来源**,格式 `【书外·来源：xxx】`(如 `【书外·来源：本书前言,杨昊成撰】`、`【书外·来源：作者官网,2026-06 核查】`);书内确有的(如书中印的"作者简介"页)也注明"书内·第X页/位置"。
> **铁律**:本节任何文字**绝不进入第四节「可引用原文」栏、绝不被下游冠以"书里写道/书中原文"**——下游只认第四节关键片段为可逐字引用的书内原文。
- 作者简介
- 写作缘起 / 后记要点(若书中有后记)
- 译后记要点(若书中有译后记)

## 三、内容结构 [必填]
- 章节结构:章节数 + 可否分段(如三段式)及划分依据;逐章标题+页码为可选(长篇可只给分段区间与代表章节)
- **全书事件序列** [必填]:按书中先后顺序,列出推动故事的主要事件节点(每点一句客观陈述 + 章节定位,页码有则附)。这是情节梳理、事件链一类环节的基础,比逐章标题更要紧。只记"发生了什么",不评价、不归因。
  - 示例(手斧男孩):出发探亲(母亲临行送手斧)→ 飞行中驾驶员心脏病猝死 → 布莱恩独自挣扎、飞机坠落湖中 → 搭避难所 → 取火 → 摘浆果(第6章)→ 遭遇豪猪/熊/狼 → 造弓箭、首次猎食禽鸟(第15章)→ 暴风雨掀乱营地、坠机机尾浮现 → 打捞求生包、触发应急发报机 → 获救回家。
- 主要人物的**客观信息** [必填]:只写书中明确呈现的——身份、年龄、与他人的关系、所处处境/境遇。**不写性格判断、不贴标签、不下成长结论**(如"勇敢""坚韧""由幼稚走向成熟"等一律不写,这些是 AI 设计时要从事实里推出的东西)。

## 四、关键片段 [必填]
> **数量下限按等级分档**:L1–L2 至少 3 条;L3–L4 至少 5 条;L5–L6 至少 6 条。**细读课要对比的章节、思辨课要联结的片段,都必须在此出现**——这一节备不足,后续环节就会无米下锅、被迫占位。
>
> 每条三栏。**定位以"章节"为主**(章节序号/章节名),有稳定页码再附;流式或无页码版本只标章节即可,不必强求页码。"内容概述"是客观情节;**"可引用原文"必须是电子版里的逐字原文(逐字红线只认"真不真",不卡"在第几页"),没把握逐字一致就写"无原文,仅概述",绝不写"大概是…""类似…"这类凭印象的句子**——那是伪摘录的温床,比留空更糟。**绝不能因标不出页码就放弃输出真实原文。** 不要写"用途/适合干什么"。

- **片段1**
  - 定位(章节优先,页码有则附):
  - 内容概述:
  - 可引用原文(逐字,无把握则写"无原文,仅概述"):
- **片段2**
  - 定位:
  - 内容概述:
  - 可引用原文:
- **片段3**
  - 定位:
  - 内容概述:
  - 可引用原文:
- (L3 以上按下限继续补 片段4、片段5、片段6……)

**备用引文池(可选,逐字核对,供设计取用)**
> 除上面达标的关键片段外,再把书中其它"值得引用、且已逐字核对一致"的句子收进来,**同守逐字红线**(无把握逐字一致就不收,绝不凭印象补)。下游设计常需档案之外的原文,档案没有就只能占位;这里多备一些,能显著减少占位、提升详案质量。**原则:宁可多备,由下游取舍。**
- (定位：章节＋特征句) 原文："……"
- (定位：____) 原文："……"

## 五、重复出现的事物/场景(小说类,有则填)
- 事物/场景名 + 各次出现的章节 + 每次的客观情形(只记录"出现了什么",含义解读留给 AI)

## 六、可作横向对照的内容(有则填)
> 供"两两对比"类设计(如维恩图、对照表)取材。列出可对照的两项 + 可对照的维度线索,**只列维度、不下结论**——是否做成维恩图、结论怎么写,由 AI 设计时定。每一项涉及的原文,应已在第四节"关键片段"备齐。
- 对照组:____ ↔ ____;可对照维度:____ / ____ / ____
  - 示例(手斧男孩):第6章"第一次摘浆果" ↔ 第15章"第一个吃肉日";可对照维度:获取动机、难度、口感、食用结果。

## 七、贯穿全书的变化线索(有则填)
> 供"纵向追踪"类设计(如成长阶梯、时间轴、心情曲线)取材。挑一条全书最清晰的变化主线(如主角在某方面的前后转变),按先后列出几个**带定位的客观状态节点**——只写"这个节点书里写了什么",**不写"他成熟了/变勇敢了"这类结论**,变化的意义由 AI 推断。
- 变化主线(一句话点出是"哪方面"的变化,如:对食物的态度 / 面对危险的反应):
- 状态节点(按先后,每点带章节定位、页码有则附):
  - 节点①(定位):书中客观情形——
  - 节点②(定位):
  - 节点③(定位):
  - (按需增减)
  - 示例(手斧男孩·对处境的反应):坠落初期(P003前后)自怨自艾、被动等救 → 第6章勉强摘浆果充饥 → 第15章主动造具猎食 → P113"我真的和以前不一样了"感官敏锐 → P205获救后面对母亲秘密"什么都没说"。(各节点只记客观情形,不评成长)

## 八、本书涉及的主题词(只列,不展开;3–6 个为宜)
- 如:勇气 / 成长 / 人与自然 / 面对现实……(供 AI 设计思辨方向参考,但具体问题由 AI 设计。太多会让思辨方向发散,挑最核心的几个。)

- 相关电影 / 文章 / 同系列书等

## ⛔ 本模板**不填**以下内容(交由 AI 生成教案时依据上述事实自行设计):
- 可视化工具的**具体选择与填法**(AI 从候选池自行挑选并设计:阅读单/表格、思维导图、人物关系图、故事山形图、时间轴/阶梯图、维恩图、鱼骨图/因果图、六面体讨论图、对比表 等)
- **阅读单**的主题、维度、参考填充
- **思辨问题**的具体题目与参考方向
- **三维教学目标**(知识技能/过程方法/情感价值观)的具体措辞
- 各环节的设计与话术

> 事实与设计的分工:本模板只负责"书里**有什么**"(情节、事件序列、人物、章节、页码、原文、可对照维度、变化线索、主题词);"**怎么教**"(挑哪种工具、阅读单怎么设计、出什么思辨题、目标怎么写)全部由 AI 在生成阶段依据这些事实完成。两者边界不可混:事实栏只记客观、不下结论,不替 AI 做教学判断。

## 档案使用提醒(事实层注意事项)
> 把"**本书事实里下游极易用错的点**"显式列出,交棒给 lesson-plan 及所有消费档案的物料避坑。这是你通读全书时发现的"坑",下游看不到原书、只能靠这一节避开。
> **只记事实层陷阱,不做教学判断**(不写"建议怎么教")。**无可提醒则写"无特别提醒",不留空、不删本节**。
> 常见类型(按本书实际挑填,不必每类都有):
- **版本/页码陷阱**:如无页码版——"本档案无页码,任何下游产物中出现'第X页'均属编造"。
- **同一引文多版本**:同一句话/歌谣在书中有几处字句不同,须按章逐字取用、勿混用版本。
- **一词多义 / 一名多指**:同一词在书中指代不同事物(如某名既是物名又是商品名),引用须区分。
- **人物称谓 / 身份边界**:书中未明确点破的关系或身份,下游不得直接断言(标为开放讨论点)。
- **书内/书外边界复述**:再次点明"可引用原文"只能取自第四节关键片段;第一、二、九节里的外部信息不得当书内原文引用。
