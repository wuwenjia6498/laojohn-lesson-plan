# 《书籍档案·非虚构版》填写模板

> **用途**:科普 / 知识类 / 说明性非虚构书的建档模板(何时用见 SKILL「非虚构类建档适配」)。与纯事实版同一套口径:**只填客观事实(原料)**,工具、阅读单、思辨题、三维目标全部留给下游 lesson-plan 依据事实自行设计。
>
> **与纯事实版的关系**:机读块、一/二/四/八/九/十节与档案使用提醒节**结构不变**(节号也不变——下游冷审按「档案第四节」核引文,改节号会断);只把叙事专用的三/五/六/七节换成非虚构字段。人物传记 / 纪实(有贯穿人物与时间线)**不用本模板**,仍走纯事实版。
>
> **填写铁律**:所有内容必须来自这本书本身。**书里的科学说法、数据、结论照书记,不得用模型知识纠正、补充或"更新"**——觉得书里说法可疑,只在档案使用提醒节标"(待核实)",正文照书。不确定、书里没有的,标"(待核实)"或"未涵盖",绝不凭记忆编造。
>
> 标 [必填] 的字段缺失会导致无法生成对应环节;**未标的可留空**。

## 五、核心概念·关键事实与数据·说明方法实例
> 取代纯事实版的"重复出现的事物/场景"。三小类都只记书里有什么,不解释、不评价。

**(一)核心概念与术语** [必填]
- 概念名 + 出处 + 书中怎么说:**书中给了定义的逐字引**;只是用到、没有定义的写"书中未定义"。不用模型知识补定义。

**(二)关键事实与数据** [必填]
> 数字、单位、比例、专有名称一律照书原样(含"约""左右"这类限定词,不得删也不得加);同一事实书中前后说法不一的,两处都记。下游测评卷与课堂提问最易在这里出错。
- 事实/数据 —— 出处(章·小节)

**(三)说明方法 / 文本特征实例**(有则填)
> 供交流课"分析说明方法"取材。列书中**可指认**的设问、举例子、列数字、作比较、打比方、分类别、引用等,每类给 1–2 个实例(逐字短句 + 定位)。**只列"这里用了什么",不写"作用是…"**。
- 方法名:实例原文 —— 出处

## 六、可作横向对照的内容(有则填)
> 供"两两对比"类设计(维恩图、对照表)取材。非虚构的对照多在**例证与例证之间**(两种生物、两种做法)或**书中观点与日常常识之间**(书中明说"一般认为…其实…"处)。列对照的两项 + 维度线索,**只列维度、不下结论**;涉及的原文应已在第四节备齐。
- 对照组:____ ↔ ____;可对照维度:____ / ____ / ____

## 七、作者观点句与开放问题(有则填)
> 取代纯事实版的"贯穿全书的变化线索",是下游思辨课与探究任务的主要取材面。
- **作者观点句**:作者明确表态、可以赞成也可以质疑的句子(逐字 + 定位)。只摘录,不评对错。
- **书中承认未解的问题**:书里写"至今不清楚""有一种说法认为""科学家还在研究"的地方(逐字 + 定位)。**原书的不确定措辞必须原样保留**,下游不得讲成定论。
- **贯穿全书的观点线索**(有则填):若作者在多章反复回到同一个看法(如"成长不等于变大"),按先后列出各处(定位 + 客观复述),只记"书里在哪儿又说了",不总结升华。

## 十、原书插图(有则填;该书无插图则整节删除)
> **本节只作指针,画面事实一律以图单为准,不在此复制图单内容**。产出方式同纯事实版(见 SKILL「有插图的书:建档时同步读图」)。
> 非虚构书的图多是示意图、对比图、图表,图上文字与数字要与正文核对:图文数字不一致时如实记进图单、正文为准,标「不得让学生按图读数」。
- **图源目录**:`读书会原书插图\<书名>\`;**图单**:同目录 `_图单.md`
- **数量与分布**:共 N 幅(`插-01`–`插-NN`,全书连号);按章分布,写明哪些章节未配图

## 档案使用提醒(事实层注意事项)
> 把本书事实里下游极易用错的点显式列出。**只记事实层陷阱,不做教学判断**。**无可提醒则写"无特别提醒",不留空、不删本节**。
> 非虚构书常见类型(按本书实际挑填):
- **版本/页码陷阱**:无页码版——"本档案无页码,任何下游产物中出现'第X页'均属编造"。
- **照书不纠错**:书中科学说法照书讲;若与现行认知可能不符,列在这里并标"(待核实)",下游不得自行改写或补充"其实现在科学家认为…"。
- **不确定措辞须保留**:列出书中"有一种说法""至今不清楚"的位置,下游不得讲成定论。
- **作者本国语境**:作者以本国情况举的例子(地名、习俗、制度)照书记,不本土化改写。
- **作者第一人称经历**:书中"我""我家"的经历属书内原文,可引用;但不得延伸出书中没写的作者生平。
- **数据易混**:前后相近的数字、单位、比例,在此点明各属哪个对象。
- **书内/书外边界复述**:"可引用原文"只能取自第四节关键片段与备用引文池。
