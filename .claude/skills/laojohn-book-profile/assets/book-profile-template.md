# 《书籍档案·完整版》填写模板

> 这是生成详案的**内容来源 + 教学设计来源**。与"纯事实版"的区别:纯事实版只给事实、设计交给 AI;**本版承载填写者(资深老师/你)的教学判断**——用什么工具、阅读单设哪些维度、思辨题问什么,由人定好,AI 照此落地,不自行发挥。
>
> 本版的价值在"人的设计判断",所以两类内容都要硬:
> - **事实层**(情节/事件序列/章节/原文/人物)的真实性要求与纯事实版完全一致——这是设计的地基,不因"有人工设计"而放松。逐字原文必须来自电子版,无把握逐字一致就写"无原文,仅概述",绝不凭记忆编造。定位以章节为主、页码有则附(逐字红线只认"真不真",不卡页码)。
> - **设计层**每一项决策都要**附文本依据**——选这个工具/维度/思辨题,是因为书里哪段内容支撑它。**只填"设计意图 + 依据 + 参考方向",不要画成品表格**(渲染成带格子的阅读单是 SKILL 落地阶段的事,档案里画死反而会和它打架)。
>
> 标 [必填] 的缺失会导致无法生成对应环节。

## 一、基本信息
- 书名《》[必填]
- 等级 L_ [必填]
- 依据版本(出版社 / ISBN / 或电子版格式如 epub)[必填;有稳定页码则以此为准,流式/无页码版注明"无固定页码,按章节定位"]
- 作者 / 译者 / 字数
- 获奖信息(照抄,注明出处)
- 封面/封底/腰封宣传语原文(若有,照抄+注明出处。名家推荐语属营销物料、非书内容,不必收录)

## 二、作者&背景(有则填,无则留空)
> **本节为「书外信息」**:作者简介、写作缘起、背景考据等多半来自封底/前言/译序或外部资料,**不是本书正文**。
> **每条须标来源**,格式 `【书外·来源：xxx】`(如 `【书外·来源：本书前言,杨昊成撰】`、`【书外·来源：作者官网,2026-06 核查】`);书内确有的(如书中印的"作者简介"页)也注明"书内·第X页/位置"。
> **铁律**:本节任何文字**绝不进入第四节「可引用原文」栏、绝不被下游冠以"书里写道/书中原文"**——下游只认第四节关键片段为可逐字引用的书内原文。
- 作者简介(用于导读课)
- 写作缘起 / 后记要点(若书中有后记)
- 译后记要点(若书中有译后记)

## 三、内容结构 [必填]
- 章节结构:章节数 + 可否分段(如三段式)及划分依据;逐章标题+页码为可选(长篇可只给分段区间与代表章节)
- **全书事件序列** [必填]:按书中先后顺序列出推动故事的主要事件节点(每点一句客观陈述 + 章节定位,页码有则附)。这是情节梳理、事件链类环节的基础。只记"发生了什么",不评价、不归因。
  - **合集/短篇集(低段书籍常态)**:改为「分篇梗概」——每篇一个粗体小标题 + 一句概述,篇内用 → 串本篇事件、篇间无因果,篇目多时按辑/版次分块,并标出「建议课堂精读篇」(其余泛读);**寓言集**每则加一栏「寓意」(原文点明才逐字引、没点明不编)。详见 SKILL「合集类书籍的建档适配」。
- 主要人物的**客观信息** [必填]:身份、年龄、与他人关系、所处处境。**不写性格判断/成长结论**(那是教学环节里要引导学生推出的)。(**合集**:按篇分组,或用表格 `| 篇目 | 角色 | 客观信息 |`,声明角色不跨篇复现。)

## 四、关键片段 [必填,下限按等级:L1–L2≥3 / L3–L4≥5 / L5–L6≥6]
> 细读要对比的章节、思辨要联结的片段,都必须在此出现。**定位以章节为主**,有稳定页码再附,流式/无页码版只标章节即可。原文栏必须逐字(只认"真不真"、不卡页码),无把握则写"无原文,仅概述",绝不写"大概是…";**不得因标不出页码而放弃真实原文**。**合集**:定位用「篇名 + 场景」,篇目多时只为「建议课堂精读篇」按下限备足逐字原文、其余泛读。
- **片段1** — 定位(章节优先,页码有则附): / 内容概述: / 可引用原文(逐字,无则写明):
- **片段2** — 定位: / 内容概述: / 可引用原文:
- **片段3** — 定位: / 内容概述: / 可引用原文:
- (按等级下限续补)

**备用引文池(可选,逐字核对,供设计取用)**
> 除上面达标的关键片段外,再把书中其它"值得引用、且已逐字核对一致"的句子收进来,**同守逐字红线**(无把握逐字一致就不收,绝不凭印象补)。下游设计常需档案之外的原文,档案没有就只能占位;这里多备一些,能显著减少占位、提升详案质量。**原则:宁可多备,由下游取舍。**

## 十三、原书插图(有则填;该书无插图则整节删除)

- **图源目录**:`读书会原书插图\<书名>\`;**图单**:同目录 `_图单.md`(图片本体已 gitignore,图单与 `_清洗记录.json` 入库)

## 档案使用提醒(事实层注意事项)
> 把"**本书事实里下游极易用错的点**"显式列出,交棒给 lesson-plan 及所有消费档案的物料避坑。这是你通读全书时发现的"坑",下游看不到原书、只能靠这一节避开。
> **只记事实层陷阱,不做教学判断**(不写"建议怎么教")。**无可提醒则写"无特别提醒",不留空、不删本节**。
> 常见类型(按本书实际挑填,不必每类都有):
- **版本/页码陷阱**:如无页码版——"本档案无页码,任何下游产物中出现'第X页'均属编造"。
- **同一引文多版本**:同一句话/歌谣在书中有几处字句不同,须按章逐字取用、勿混用版本。
- **一词多义 / 一名多指**:同一词在书中指代不同事物(如某名既是物名又是商品名),引用须区分。
- **人物称谓 / 身份边界**:书中未明确点破的关系或身份,下游不得直接断言(标为开放讨论点)。
- **书内/书外边界复述**:再次点明"可引用原文"只能取自第四节关键片段;第一、二、十二节里的外部信息不得当书内原文引用。
