# 老约翰深度阅读 · 书籍档案生成器

本技能把一本书的电子版,按固定模板抽取成一份《书籍档案》.md。这份档案是**下游生成课案详案的唯一事实来源**——生成详案时不会再翻原书,只依赖这份档案。因此本技能的全部价值,在于**把事实挖准、挖全,绝不掺入编造**。

## 这份档案是干嘛用的(动笔前必须理解)

- 你产出的档案,会交给另一个技能(laojohn-lesson-plan)生成给小学生上课用的**逐字稿教案**。
- 教案里凡引用"书中原文",都直接取自本档案"可引用原文"栏,会被老师**原样念给学生听**。所以这一栏的每个字都要经得起核对。
- 教案的情节梳理、人物分析、对比细读、成长追踪,全部以本档案的事实字段为依据。**档案错一处,详案就跟着错一处,且下游无从发现**(它看不到原书)。
- 正因如此:本技能最高优先级不是"填得全",而是"填得真"。

## 工作流程(按顺序)

1. **确认输入(硬闸)**:必须拿到 (a) 这本书的电子版/PDF/足量全文文本,(b) 书名与等级(L1–L6),(c) 用哪份模板(见第2步)。
   - **若只给了书名、没有电子版/全文**:**必须停下来索取原文**。**禁止以"我读过/了解这本书""资料足够"为由凭记忆建档**——模型对童书的记忆往往似是而非(页码、人名、逐字原文尤其易错),且这种错误下游无从察觉,危害比叙事书出名与否无关。没有原文就没有可信事实来源,不开写。
2. **选定模板**:
   - 默认用 **`book-profile-FACTS-ONLY.md`**(纯事实版):只填事实,可视化工具/阅读单/思辨题/三维目标留空,交由下游详案技能依据事实自行设计。**绝大多数情况用这份。**
   - 仅当用户明确要"连教学设计一起预置好"时,才用 `book-profile-template.md`(完整版):事实层同纯事实版,另需逐项填写设计层、且每项附文本依据。
3. **适用范围核查**:本套模板**仅适用于叙事类文本**(小说/绘本/故事/带叙事的传记)。若该书是说明性科普(如问答条目式)、诗歌赏析、无主线轶事汇编等非叙事非虚构,**先告知用户当前模板未必适配,确认后再决定是否继续**,不要硬套字段。
   - **若该书是多篇彼此独立的短篇/寓言/故事合集(无贯穿主线)**:仍适用本模板,但须按下文「合集类书籍的建档适配」改写事件序列/变化线索/人物/横向对照等字段——**低段(L1/L2)书籍多属此类**,别照单一长篇的字段硬填。
> **档案开头的「海报/指南元数据」节 = 所有下游物料读取基本信息的唯一固定位置(务必填全)**。书目卡 / 招生海报 / 阅读指南 / 思维导图 / 反馈话术都从这里取基本信息;其中 book-card、course-poster 的脚本按固定键名正则解析。字段已扩为全量:**书名 / 作者 / 译者 / 出版社 / 出版年 / ISBN / 字数 / 页数 / 等级 / 类型 / 主题 / 获奖**。规则:字段名与顺序固定、缺失填"(待补充)"**不删行**、只填脚本能直接解析的**纯值**(不带括号注解、不写"约/左右";流式无页码版"页数"填"(待补充)"或"无固定页码");作者带国籍前缀(如"[英] 乔纳森·斯威夫特");获奖区一行一项、无则留一行"(待补充)"。**「类型」须落到具体文学类型**(成长小说/幻想小说/动物小说/寓言小说/讽刺小说/短篇小说集/长篇童话…,可带篇幅/体裁修饰如"长篇""书信体")——**禁写空泛的"儿童小说""长篇儿童小说""儿童文学"**:本套书全是童书,"儿童"不构成类型信息(2026-07-22 用户拍板;"儿童成长小说"这类"儿童"仅作修饰、核心类型具体的写法可保留)。它与"基本信息"节有意重复,各司其职——基本信息节可写说明文字,本区只放纯值。**凡此处缺失的字段,绝不从课案正文猜、不凭记忆补**,留"(待补充)"等人工回填。

4. **逐章通读电子版全文,再逐字段填写**:严格按模板字段填,遵守下方"真实性红线"。
   - **【全文通读·刚性红线】必须把电子版从头到尾、逐章读完,严禁只读章前【导读】/目录/前后记等"框架",严禁只挑几章"代表性"章节选择性翻阅,更严禁靠对名著的既有印象补足未读部分。** 事件序列、关键片段、人物、变化线索、事实陷阱都必须建立在"整本读过"的基础上——中段章节(往往是全书主体)里藏着大量下游细读/思辨要用的场景与逐字原文,只读框架必然导致事件序列空泛、关键片段全挤在开头结尾、且漏掉只有通读才会发现的事实陷阱(如同一角色的别称/全名在中段才出现)。**长篇(如数十章的名著)也不豁免**:篇幅大只意味着分多次读完,不意味着可以跳读;宁可多花时间,也不得在未通读的情况下开写或交付。
   - **【若该书配有插图】通读时须同步逐张目视真图,边读文边对图**,并当场产出图单——详见下文「有插图的书:建档时同步读图」。**不要读完全文再回头补图**:图文咬合点只在两者同时在眼前时才浮现,补图流程结构上产不出。
5. **自检后交付**:对照下方自检清单逐项核对,产出 `<书名>书籍档案.md`(无连字符,书名不带书名号——下游 course-poster / reading-guide 等按此路径查档案,带横杠或书名号会查不到),告知用户"可将此档案连同电子版一起交给 laojohn-lesson-plan 生成详案"。

## 真实性红线(违反即作废,与详案技能同一套口径)

- **必须逐章通读全文,不得以框架/选读代替通读(刚性红线)。** 见工作流第 4 步:整本书从头读到尾是建档前提,只读【导读】/目录/选读几章即开写,等于用残缺事实建档,下游无从察觉。**这条与"不得凭记忆编造"同级,不因书长、书有名而豁免。**
- **事实只能来自电子版,不得编造。** 情节、人物、章节、页码、原文、事件序列、变化线索——一律以电子版为准。拿不准的标"(待核实)",不要编一个看起来合理的填进去。
- **"可引用原文"栏 = 逐字红线。** 只有能在电子版里逐字核对一致的句子,才填进此栏(逐字红线只认"真不真",**不卡"在第几页"**;定位以章节为主,有稳定页码再附,流式/无页码版只标章节即可,**绝不能因标不出页码就放弃真实原文**)。**没把握逐字一致,一律写"无原文,仅概述",绝不凭印象或记忆补写**——哪怕这本书你"好像读过"。**对热门/经典书尤其警惕**:越是名作,模型越容易"自信地记错",这种记忆不因书出名而可信。"我好像记得"≠可用来源。
- **够用即可,宁缺毋造。** 一条确证的真实信息,胜过五条模糊的回忆。某字段书里没有,就写"未涵盖",不要为填满而凑。
- **书内/书外边界(防下游伪摘录的关键)。** 作者背景、获奖、拓展资源、外部考据等**非本书正文**的信息,一律在条目/段首标 `【书外·来源：xxx】`;这些内容**绝不进入「可引用原文」栏、绝不被冠以"书里写道/书中原文"**。下游 lesson-plan 只认第四节关键片段(及备用引文池)为可逐字引用的书内原文——边界没标清,下游就会把书外信息误当原文念给学生。
- **不越界做教学设计。** 纯事实版里留空的设计字段(工具/阅读单/思辨题/三维目标),保持留空,不要"顺手"替下游设计——你这一步只负责事实。

## 字段填写要点(配合模板看)

- **事件序列**:按书中先后,列推动故事的主要事件 + 章节定位(页码有则附),只记"发生了什么",不评价、不归因。(合集/无主线的书改「分篇梗概」,见「合集类书籍的建档适配」)
- **关键片段**:按等级备足下限(L1–L2≥3 / L3–L4≥5 / L5–L6≥6);定位以章节为主、页码有则附;原文栏守逐字红线。**下游细读要对比的章节、思辨要联结的片段,都得在这里出现**,宁可多备。**达标后再开「备用引文池」**(模板第四节末尾):把书中其它已逐字核对一致、值得引用的句子也收进来——下游设计常需档案外原文而档案没有就只能占位,引文池备足能显著减少占位,原则"宁可多备由下游取舍"。
  - **「可引用原文」栏取「成段」、不取孤零单句**:每条片段的原文取「这句话所在的那一整段／那一轮完整对话」逐字照录,而**不是**只摘中间一句;只有独立成句已自足的点睛句(如某书结尾的一句宣言)才留单句。原因是下游怎么用它决定粒度——`laojohn-ppt` 的「原文齐读」页要把原文成段打上屏、老师原样念给学生,单句撑不起一页;细读/横向对照要抓的往往是「一段里的转折」(只摘结论句会丢掉前面的铺垫与心理挣扎)。取用以「一个完整意群／一轮对话」为界、不必整章照搬;成段处标注「(逐字,成段)」。**逐字红线不因取长而豁免、反而更严**:成段原文须**保留原书弯引号原样照录**(对话轮用书里的引号),**不要为避免嵌套把内层引号改写**——那是逐字失真;书内传说里人物转述的台词,按原书用的引号照录并注明出自谁之口。**备用引文池**则可保留零散单句,供下游点缀取用。
- **横向对照**:列可两两对比的对象 + 维度线索,只列维度不下结论;涉及的原文应已在关键片段备齐。
- **变化线索**:挑一条全书最清晰的变化主线,按先后列带定位的客观状态节点,不写"成熟了/勇敢了"这类结论(那是下游要引导学生推出的)。(合集在全书层面标「不适用」,降为单篇候选,见「合集类书籍的建档适配」)
- **人物**:只填客观信息(身份/年龄/关系/处境),不贴性格标签、不下成长结论。
- **档案使用提醒节**(模板末尾固定节):把你通读全书时发现的"下游极易用错的事实陷阱"显式列出(无页码版的"第X页"禁令、同一引文多版本、一词多义、人物称谓/身份边界、书内外边界复述等),只记事实层陷阱、不做教学判断。下游看不到原书,这一节是你向它交棒避坑的唯一渠道;无可提醒则写"无特别提醒",不留空、不删节。

## 合集类书籍的建档适配(短篇集/寓言集/童话集/系列短篇——低段书籍的常见形态)

模板的两个字段——`全书事件序列`(一条推动故事的主线)与`贯穿全书变化线索`(一个主角的转变主线)——**默认单一叙事长篇**。但很多书没有这条主线,而是**多篇彼此独立的短篇/寓言/故事**:这在**低段(L1/L2)是常态**(童话集、寓言集、儿童故事集、系列短篇、桥梁书系列几乎都是),高段也有(《快乐王子》童话集、《俗世奇人》短篇小说集)。**判据:全书没有一条贯穿始终的情节主线与固定主角、拆成若干篇后每篇仍独立成立**——命中即按本节适配。

**不新建模板,而是在同一份模板里改写受影响字段的语义**(两份成熟先例可对照:`读书会书籍档案\快乐王子书籍档案.md`、`读书会书籍档案\俗世奇人书籍档案.md`)。六个固定动作:

1. **机读块「类型」**落到具体合集体裁:短篇童话合集 / 寓言集 / 儿童故事集 / 系列短篇——禁空泛"儿童文学"(同上一节既定规则)。
2. **档案顶部加一句「结构性事实」声明**(放在机读块之后、正文之前的醒目处):本书是合集、共 N 篇、篇间无单一主线、无贯穿人物。
3. **三、全书事件序列 → 改「分篇梗概」**:每篇一个粗体小标题 + 一句客观概述;篇内可用 → 串本篇自己的事件链,并注明篇与篇之间无先后因果;篇目多时按辑/版次分块。
4. **主要人物 → 按篇分组,或用表格** `| 篇目 | 角色 | 客观信息 |`,并声明角色不跨篇复现。
5. **六、横向对照 → 改「篇际对照」**(篇 A ↔ 篇 B 的可对照维度),这是合集最有教学价值的取材面;**七、变化线索 → 标「不适用」**,降级为"单篇故事山 / 单篇反转"候选,不在全书层面套成长阶梯/时间轴。
6. **四、关键片段定位一律用「篇名 + 场景」**(不用全书章节序号);逐字红线、成段取用、无页码禁写页码一条不豁免。**档案使用提醒节把「不得当长篇梳理」列头号陷阱**:下游任何产物不得对本书做"全书情节主线梳理 / 全书成长曲线 / 人物关系总图",这些只能落到单篇。

**低段合集另有两处必做**(高段合集同样适用,只是低段几乎必然踩到):

- **选篇标记(篇目多时必做)**:短篇集常十几到几十篇(稻草人十余篇、克雷洛夫数十则),深度阅读课 2–4 节精读不完。在档案里标出**「建议课堂精读篇」**(判据:篇幅短 / 主题贴近儿童 / 语言浅 / 与教材单元关联),精读篇按等级下限**备足逐字关键片段**;其余篇进「分篇梗概」作**泛读**即可、不逐篇备原文。标记放第三节分篇梗概处或档案使用提醒节(《俗世奇人》档案的"选篇范围"提醒即此)。
- **寓言的「寓意」栏**:寓言集(克雷洛夫/伊索一类)每则 = 小故事 + 大道理。分篇梗概里每则**加一栏「寓意」**;**寓意原文点明的才逐字引,原文没点明就只客观概述、不替它编一句道理**——与「可引用原文」同属真实性红线。

其余红线(逐篇通读全文、无原文写占位、书内外边界)**一条不变**:合集篇目虽多但每篇短,通读仍是硬红线——篇篇独立,跳读必漏。

## 有插图的书:建档时同步读图(2026-08-06 立)

**触发条件**:该书配有插图、且用户能提供图(扫描/翻拍/电子书内嵌导出均可)。低段绘本与童话集几乎必然命中。没有图就跳过本节,不必因此索要图。

**为什么放在建档、而不是详案阶段**:插图链路原先归 lesson-plan 侧,图单是详案写完后补的。代价见《神笔马良》——图单把 `插-09` 判成「众人围案逼画」,实为**画中的蛇活了扑向皇帝、众人惊逃**,详案参考答案据此写出「一群人围着案子逼他画的那幅」,**书里根本没有这幅画**,老师照着找必然讲错。根因是画面描述**事后据画面孤立判读**得来——没有原文在旁边对照,判读就是猜。

**真正的收益不是「档案里多记一栏」,而是图文咬合点只在边读文边看图时才浮现**。这类点是详案里最好用的材料:它让学生**自己看图读出结论**,而不是老师讲给他听。两个实测样例——
- 《孤独的小螃蟹》`插-01`:画面里橙红蟹与青蓝蟹并置、钳子明显差一号,与原文「她的颜色那么青,青得像蓝天。她的钳子也很小,只有小螃蟹的一半儿大」逐字可验。
- 《恐龙鲁鲁》`插-12`:一幅跨页把原文「这蛋壳,是鲁鲁的摇篮／小船／雨伞／太阳帽」四种用途**同框画出**,是天然的对读材料。

事后补图的流程结构上产不出这些:详案已成型,图只能去迁就写好的环节。

**四个固定动作**:

1. **先归位再读**:图复制进 `读书会原书插图\<书名>\`(书名不带书名号),改名 `插-01.jpg` 起两位编号、**全书连号**(跨篇连续排,不按篇重起)、**半角**连字符。建 `_清洗记录.json` 记原文件名→新编号映射。**图片本体、`_图单.md`、`_清洗记录.json` 一并入库**(CLAUDE.md §8,2026-08-20 起原书插图入库;旧口径「图片被 .gitignore 挡下」已作废,照旧口径做会漏提交、另一台机器缺图)。
   - 用户只管把图(文件名随意)放进 `读书会原书插图\<书名>\`,去重、去水印黑边(`读书会原书插图\_tools\dewatermark_autocrop.py`)、改名、写图单都由 agent 做。书封不放这里,留在 `读书会书籍封面\`。
   - ⚠ **原文件名的编号不等于正文顺序**,连号前须按画面内容重排。《孤独的小螃蟹》实测两处需对调(「睡在洞里」在「梦中火车」之前;「变大瞬间」在「青蛙爬满全身」之前——后者画中已是变大后的体型)。**照原文件名数字顺序排必错位**。
   - ⚠ **同幅判定不能只信感知哈希**:该批 24 个文件里,一对重版 dHash 距离 10(测得出),另一对因**裁切放大**改变了构图、距离 114(测不出),是并排目视认出的。裁切版通常丢信息(该例丢了枯树/猫头鹰/火车/月亮),**不作正片**,移入 `_备选\` 不占连号。
2. **边读文边对图,当场写 `_图单.md`**(体例照 `读书会原书插图\神笔马良\_图单.md`):四列＝编号｜原书出处(**篇名 + 章节/小节名,禁页码**)｜画面描述｜用在哪里。
   - **画面描述只写真图目视所见的客观特征**(颜色/数量/大小比例/动作/位置),**禁止从文字推**。
   - 描述里另标**可对上的原文**——这是本节的主要产物,供详案挑图时直接取用。
   - **第四列建档阶段一律留空**(详案未写,填不了),详案定稿后回填「**已用** · 第N课时 X(用途)」或「素材库(本次未选用,老师可自取)」。
3. **角色归属必须锚定原文句,锁不住就写「未定」**。这条比描述本身更要紧——下游详案的参考答案会直接建立在角色判断上。
   - 判据:能引出一句原文把该角色的**可视特征**(颜色/体型/衣着/随身物)钉死,才可断言;否则写「归属未定」并列出候选,注明「选用前须再核」。
   - 实测教训:《孤独的小螃蟹》`插-10` 曾一度矛盾——车头那只橙色圆背物被误认作蜗牛,于是成了「青绿色螃蟹在开车」,与全篇颜色分工冲突;**放大**后可见长眼柄与蟹钳,是螃蟹,矛盾才解除。**孤立看图必错,颜色/身份一律回原文锚句核;拿不准就放大,不要将就。**
4. **档案里只加指针节,不搬图单内容**。在「九、拓展资源」之后、「档案使用提醒」之前加 `## 十、原书插图`,只写:图源目录与图单路径、总幅数与按篇分布(含**未配图的章节**)、**候选咬合点清单**、以及「选图前必读图单的判读警示」。
   - 理由:图单已是成熟载体(四列表、`--check-only` 三方核验、入库),复制进档案必然双写漂移;但档案里若没有任何信号,下游 lesson-plan 根本不知道「这本书有图可用」——指针节只补信号、不搬内容。
   - 新增 `## 十、` 不影响 `scripts/profile_meta.py`(它只正则定位 `## 海报/指南元数据`),book-card / course-poster 两条脚本线安全。

**画面与原文不一致时,如实记进图单、不要替它圆场**。这是低幼绘本的常态(画家与文字各自发挥),实测《恐龙鲁鲁》12 幅里有 4 处:铃铛原文挂尾巴上、画面挂脖子上;某节画面里没有原文点名的小鸡;原文四位抬蛋糕、画面只见三只;原文四只棉鞋、画面只画一只。**凡此类须在图单标明「师话按画面说」,并明确写「不得让学生数数」**——数量类观察一旦与原文对不上,课堂上必然当场翻车。反过来,**数量能对上的要标出来**(如《恐龙鲁鲁》「老鼠七兄弟」画面正好七只),那是低年级能自己数清的验证点。
