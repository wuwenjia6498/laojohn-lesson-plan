# 老约翰 · 课程交付打包（成品归集）

把一本书的成品从十几个分散的输出目录里**复制归集**进一个干净的交付文件夹，方便整本发给老师/家长。本技能**只搬运、不生成**——所有内容早已由上游各 skill 产出。

## 产出结构与命名（固定 · 2026-10-26 用户定稿，样例 L3《稻草人》）

```
读书会整套文件打包输出\3上《稻草人》\            ← <年级><上/下>《书名》
├── 教师用\
│   ├── 《稻草人》教学逐页讲稿\                  ← 讲稿 docx：《稻草人》导读课-逐页讲稿.docx …
│   ├── 《稻草人》导读课.pptx / 阅读交流课1.pptx …
│   ├── 《稻草人》教学思维导图.pdf
│   └── 《稻草人》课案详案.docx                   （有配图版则另收《稻草人》课案详案-配图.docx）
├── 宣传推广、日常服务类\
│   └── 《稻草人》海报.jpg / 课程反馈话术.docx / 书目卡.jpg
├── 学生用\
│   └── 《稻草人》（学生用资料）.pdf / .pptx、抢先看.pdf、阅读指南.pdf
└── 《稻草人》阅读测评.docx                       ← 只有测评卷放根目录
```

- **命名一律「《书名》+物料名」**，无连字符/下划线隔开书名；源文件名里的 `书名-`、`书名_`、`《书名》_` 前缀由脚本换掉。
- **「阅读单」在交付包里一律改称「学生用资料」**（`（学生用资料）` 带全角括号）；`教学导图` 改称 `教学思维导图`。
- **年级**取书籍档案机读块「等级：Lx」；**上/下册**不知道就一律写「上」（用户后期手改），知道时加 `--term 下`。年级读不到时用 `--grade` 指定。
- 只收成品：散张阅读单、md/json/html 源默认不收（`--with-sources` 才收，同样改名）；PPT 中间稿不收。

## 执行

先用 `(Get-Location).Path` 确认实际盘符（移动硬盘盘符会变，禁止硬编码），再在**项目根目录**下跑：

```bash
# 本机用 python（不是 python3）；脚本里有 ✓ 等字符，务必带 PYTHONUTF8=1
PYTHONUTF8=1 python ".claude/skills/laojohn-course-package/assets/package_course.py" <书名>
```

常用参数：

```bash
# 先演练看清单、不实际复制（推荐第一步先 dry-run 核对哪些缺料）
PYTHONUTF8=1 python ".claude/.../package_course.py" 洞 --dry-run

# 连可编辑源文件(md/json/html)一起打包
PYTHONUTF8=1 python ".claude/.../package_course.py" 洞 --with-sources

# 直接打包到桌面/指定路径（覆盖默认 读书会整套文件打包输出\<年级册《书名》>）
PYTHONUTF8=1 python ".claude/.../package_course.py" 洞 --dest "C:/Users/xx/Desktop/洞"
```

- 书名**不带书名号**（脚本会自动去掉 `《》`）；源目录里的各种命名（详案 `<书名>-`、其余多为 `<书名>_`、反馈话术 `《书名》_`）脚本都能认，复制时统一改成上节口径。
- **复制不移动**：各原始输出目录是单一事实源，归集后原目录原封不动。
- 目标已存在则**覆盖同名文件**（重跑即刷新；不会删掉目标里你手动加的别的文件）。

## 工作流

1. **确认书名**与盘符（`(Get-Location).Path`）。
2. **先 `--dry-run`**：看清单，确认各分类都命中、没有因命名不符而漏收。
3. 决定是否 `--with-sources`（默认否，交付包更干净）。
4. **正式复制**，把脚本汇总（每类复制了几个文件 + 缺料清单）转述给用户。
5. **缺料不阻断**：某物料还没生成（如海报没做）→ 该分类标「缺」，照常打包其余，并在汇总里提示用户「先去生成 XX 再重跑打包即可补进」。

## 边界（不做）

- **不生成任何内容**：缺哪份物料就去对应 skill 生成（详案→laojohn-lesson-plan、下游配套→各物料 skill 或 laojohn-pipeline 一键跑），再回来重跑打包。
- 不改、不删、不移动原始输出目录里的文件（只读取并复制出去）。
