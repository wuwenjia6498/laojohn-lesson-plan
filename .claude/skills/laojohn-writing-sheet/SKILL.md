# 老约翰写作课详案 → 学生写作学习单

把一份**写作课(习作课)详案**(`.md`)里**学生要动手填的支架表**，批量做成可打印的 A4 学习单——**只出学生能填的空白版**，输出 PDF(打印) + HTML(可再编辑)。

> ⚠ 本项目位于移动硬盘，盘符随挂载变动。执行前用 `(Get-Location).Path` 确认实际项目根目录，下文 `<项目根目录>` 代表该路径，**禁止硬编码盘符**。
> 跑渲染脚本：用 `python`(非 `python3`)、命令加 `PYTHONUTF8=1`、并设 `PLAYWRIGHT_BROWSERS_PATH=C:/Users/<你>/AppData/Local/ms-playwright`。详见根 `CLAUDE.md` §1。

## 这是什么、不是什么（定位）

- **是**：写作课学生在课堂上**动手填**的支架单——写作构思表、人物特点卡、写作支架（动笔前三步）、阅读/习作计划表、自读检测表、自改标准表（学生对照自查）……即写作详案里那些**学生要填**的表。
- **不是**：`laojohn-reading-sheet`（整本书**阅读单**，吃读书会详案）、不是 PPT、不是教学导图。本 skill 吃**写作课详案**（由 `laojohn-writing-lesson` 产出）。
- **不做学生版的**：示范文旁批表、五感观察表/词语库等**老师展示/参考**用的表（贴黑板或上投屏，不发给学生填）——这些归 PPT 的双栏对照/填空表格，不进学习单。

## 架构（一句话）：复用阅读单引擎 + 写作扫描规则

```
读写作详案 → 识别学生要填的支架表 → 归类到模板 → 写 manifest.json → 复用 reading-sheet 的 render.py 批量出 PDF/HTML
```

- **引擎与模板：单一共享源，复用 `laojohn-reading-sheet`**——不另起渲染引擎、不复制模板（守 CLAUDE.md §3 禁副本）。写作学生单的支架表绝大多数是表格形，直接用 reading-sheet 的 `table` 模板；人物卡用 `profile`、自由书写页用 `writing`。
- **本 skill 只新增「写作详案怎么扫、怎么映射、落哪个目录」的规则**（下文）；字段 schema 与硬规则**指向 reading-sheet 的单一源**，不复述：
  - 每模板 JSON 字段 → `../laojohn-reading-sheet/references/data-schema.md`
  - 格子多大/书写空间/留白/真实性红线 + 自检清单 → `../laojohn-reading-sheet/references/generation-rules.md`（**动手前先读**）

## 写作详案 → 学生单的模板映射

| 写作详案里的内容 | 学生填？ | 模板 | 处理要点 |
|---|---|---|---|
| 写作构思表（地点/中心句/远近/五感/顺序…的关键词表） | ✅ | `table`（`label_first_col`） | 项目列做行标签预填、关键词列留空；末行若详案给了选项提示（如「远→近 / 上→下」）作锚点保留 |
| 人物特点卡（外貌/招牌动作/性格/爱好/品质 + 关键词，写人课） | ✅ | `profile` 或 `table` | 字段名预填、值留空；要圈「最突出一项」时用 table 加一列 |
| 写作支架（动笔前三步：定「奇」/选一桩事/用招式 之类） | ✅ | `table`（`label_first_col`） | 步骤列预填、填写列留空 |
| 阅读/习作计划表（日期/篇目/完成情况，贴扉页） | ✅ | `table` | 日期/篇目锚点预填、完成列留空；本身是派发表→无后缀单版 |
| 自读检测表（篇名/奇在哪/标签/疑问，逐篇填） | ✅ | `table` | 列名预填、内容留空，给 4–6 行 |
| 自改标准表（基础/良好/优秀三档自检话） | ✅（对照自查） | `table`（`label_first_col`） | 三档话作为对照内容**预填**（这是给学生读着自查的标尺，不是留空填的），不挖空 |
| 示范文旁批表 / 五感观察表 / 词语库 | ❌ | — | 老师展示/参考用，归 PPT，不做学生单 |

> 归不进 `profile`/`writing`/`draw` 专用类的，一律 `table` 兜底。实在无法用现有模板表达的，**先记下、交付时显式上报「需新模板/手工」**，绝不瞎画、绝不漏报。

## 工作流

### 1. 扫描写作详案，列「学生单清单」
通读写作详案两节（写作指导课 + 当堂写作与评改课），逐环节找出**学生要动手填**的支架表。登记每张：`单名 / 所在课时·环节 / 候选模板 / 数据从详案哪一段取`。**只收学生动手填的**；老师展示/参考用的表（旁批表、五感观察表、词语库）不做。

### 2. 归类到模板 + 写 manifest.json
- 按上表归类，多数 `table`。字段照 `../laojohn-reading-sheet/references/data-schema.md` 写，**强制套** `../laojohn-reading-sheet/references/generation-rules.md` 的硬规则（最易踩三条：空白格够大 `row_min_h`≥90/130、书写重的列给宽、真实性红线——预填锚点只来自**写作详案**，不凭记忆、不伪造带引号「原文」）。
- **只出学生版**（`-空` 或本就是派发物的无后缀单版），不写 `-示范`（引擎也会自动跳过）。
- **`sheets` 顺序 = 教学先后次序**（构思表/支架在作前、检测/自改在作中作后），引擎按此序合「全套」册。
- manifest 落输出目录，是内容源头。

### 3. 渲染（复用 reading-sheet 引擎，传写作合册名）
```bash
PYTHONUTF8=1 python <项目根目录>\.claude\skills\laojohn-reading-sheet\scripts\render.py \
    <manifest.json> "<项目根目录>\写作学习单输出\<题目>" --bundle-label 写作学习单
# 自检视觉加 --png；关全套合册加 --no-bundle
```
逐张出 `<单名>-空.pdf` + `.html`，logo 自动注入，A4 竖版高度自适应；默认再合一份 `<题目>-写作学习单-全套.pdf`（按教学顺序合订）。
（可编辑 PPTX：`render_pptx.py` 可复用，但其合册名暂仍按「阅读单」命名——写作 PPTX 命名参数化为待办；当前以 PDF/HTML 为主交付，需 PPTX 时先与用户确认。）

### 4. 自检 + 交付
- 对照 `../laojohn-reading-sheet/references/generation-rules.md` 末尾自检清单逐条过（格子大小、书写空间、留白、真实性、品牌统一）。
- 交付：「全套」PDF + 整批单张 PDF + `manifest.json`（**内容源头**，改字改它再重渲，别手改 HTML/PDF）。
- 「需新模板/手工」的单独上报。

## 固定输出目录

```
<项目根目录>\写作学习单输出\<题目>\
```
- `<题目>` = 习作题目纯文字、不带《》（如 `这儿真美`、`猜猜他是谁`）。一篇习作的所有学生单 + manifest 落此子目录。
- 命名：`<单名>-空.pdf/.html`（或派发单的无后缀单版）、`<题目>-manifest.json`；合册 `<题目>-写作学习单-全套.pdf`。

## 依赖与单一事实源

- **渲染引擎 + 模板：`laojohn-reading-sheet`（`scripts/render.py`、`scripts/render_pptx.py`、`templates/`）= 单一共享源**，本 skill 跨技能调用、不复制（如 writing-lesson 复用 lesson-plan 的 docx 引擎一样）。**改 reading-sheet 引擎/模板路径或契约前，须想到本 skill 受影响**（无副本，会静默失效）。render.py 的 `--templates-dir`/`--bundle-label` 是为本类复用预留的课型无关参数。
- **logo**：根 `品牌资产\logo.png`（引擎注入，禁在 data 里另存副本）。
- **数据事实源**：该篇**写作课详案**（表结构、行项、锚点）。**不凭记忆、不伪造原文**。
- 字段 schema、硬规则、扩展机制（加第 N 种模板）一律以 reading-sheet 的 references 为准，本文件不重复。
