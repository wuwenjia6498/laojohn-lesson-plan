# 老约翰「本期深度阅读书目」书目卡

把书籍档案 + 课程详案转成一张**「本期深度阅读书目」**书目卡，输出 **JPG**（传播用）与 **HTML**（可编辑源文件）。

---

## 这张卡是给谁看的（定位）

面向**读书会成员/家长**，是**书目介绍物料**，不是招生物料。内容极简：
- 这是一本什么书（基本信息表格 + 书封）
- 一段简短的故事梗概（内容简介）

**不包含**：获奖信息、阅读收获、阅读策略、可视化工具等课程内容。

---

## 字段三分类

| 类别 | 字段 | 来源 | 缺失处理 |
|---|---|---|---|
| **A 类**（课案机械抽取） | title（书名）、level（阅读阶段） | 课案一级标题、L\d+ | title 缺失→报错停 |
| **B 类**（书籍档案优先） | author、publisher、word_count、page_count | 书籍档案 `## 海报/指南元数据` 及 `## 一、基本信息` | 留空白（栏位保留、值空白，不写"待补充/请回填"、不画占位框），等人工回填 |
| **C 类**（AI 提炼，唯一允许生成处） | summary（内容简介） | 课案「内容简介」段 | 脚本留占位，**必须由你填实** |

**B 类反编造红线**：即使书籍档案某字段为空，也**绝不从课案正文猜、不凭记忆补**。**留空白**（不写"待补充/请回填"），告知用户。

---

## 整体流程

```bash
# 第 1 步：机械抽取，生成骨架 JSON
python3 scripts/extract_fields.py "<课案路径>" "<输出目录>\<书名>_书目卡.json" --profile "<书籍档案路径>"

# （第 2 步：你填实 summary 字段）

# 第 3 步：渲染
python3 scripts/render_card.py "<输出目录>\<书名>_书目卡.json" "<输出目录>\<书名>_书目卡" --covers "<项目根目录>\书籍封面" --logo "<项目根目录>\品牌资产\logo.png"
```

> ⚠ 本项目在移动硬盘，盘符可能变动。执行前通过 Cursor 工作区路径或 `(Get-Location).Path` 确认 `<项目根目录>`。

---

## C 类提炼纪律（红线）

这是全 skill 唯一让 AI 写字的地方：

1. **提炼 ≠ 创作**。只能压缩、改写课案**已写出**的内容，不得新增任何课案没有的事实。
2. **字数**：100–200 字，一段话，不分点。确保有足够信息量，人物群像/情节丰富的书可酌情写到 200 字。
3. **剔除非故事信息**：如「教育部推荐」「五年级下册课文选文」等出版背书，不进简介。
4. **逐句自检**：每写一句，问「这句依据在课案哪段？」答不出就删。
5. **语感**：平实，无营销腔（「必读」「神作」「强烈推荐」一律不用）。

### 提炼范例（俗世奇人）

```json
"summary": "天津卫码头，水咸土碱、风习强悍，孕育出一群各有绝活、各守死规矩的「俗世奇人」——刷子李衣上不沾一点白，泥人张袖底单手捏出活人像，苏七块先收七块银元再治骨伤……冯骥才将三十六个独立故事合成一册，绘出清末民初最鲜活的市井群像。"
```

## 封面匹配规则

渲染脚本通过 `--covers` 参数接收封面目录，按 `title` 匹配 `<书名>.jpg`（自动去书名号/空格/标点容错）。

- **封面统一维护在**：`<项目根目录>\书籍封面\<书名>.jpg`
- 匹配不到：卡片上封面区域为空白占位，stderr 提示用户补图后重渲染。

---

## 交付

用 `present_files` 交付两件套，顺序 **JPG → HTML**，并告知用户：
- 出版社/字数/页数等缺失字段会显示为空白（栏位保留、值空白），需人工在 data.json 补实后重渲染。
- **改字/补占位**：编辑 `data.json`，重跑 `render_card.py` 即可。
- data.json 是内容源头，不要只改 HTML。

---

## 常见问题

- **简介太长撑破版面**：压到 80–100 字，不要改模板。
- **课案缺某类信息**：如实告诉用户哪栏留空，请补填，不要猜。
- **换书重做**：换课案/档案重跑 `extract_fields.py`，模板和脚本不动。
