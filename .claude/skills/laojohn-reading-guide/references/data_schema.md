# data.json 字段说明

阅读指南的全部内容由一个 JSON 描述。结构固定,渲染脚本据此填进模板。

## 顶层结构

```json
{
  "header_left": "老约翰深度阅读",
  "header_right": "阅读·思辨·表达",
  "title": "《书名》阅读指南",
  "cover_image": null,
  "info": { ... },
  "sections": [ ... ]
}
```

| 字段 | 说明 |
| --- | --- |
| `header_left` | 页眉左侧,**固定**「老约翰深度阅读」 |
| `header_right` | 页眉右侧,**固定**「阅读·思辨·表达」(中间用间隔号·) |
| `title` | 居中大标题,格式固定为 `《书名》阅读指南` |
| `cover_image` | 书封图。`null` = 渲染占位框;填图片路径或 base64 data URI = 渲染该图 |
| `info` | 信息表,见下 |
| `sections` | 四个栏目,**顺序固定**,见下 |

## info(信息表)

```json
"info": {
  "书名": "《俗世奇人》",
  "字数": "",
  "作者": "冯骥才",
  "页数": "184",
  "出版社": "",
  "累计阅读": ""
}
```

- 六个键**固定**,渲染成 3 行 ×(键|值|键|值)的表:书名/字数、作者/页数、出版社/累计阅读。
- **课案有的填值,没有的留空字符串 `""`**(渲染成空白格)。绝不联网或臆造。
- 「累计阅读」固定留空。

## sections(四个栏目)

数组,**顺序固定**为:内容简介 → 阅读要点 → 阅读建议 → 拓展阅读建议。

每个栏目两种 `type`:

**paragraph(用于内容简介)**
```json
{ "label": "内容简介", "type": "paragraph", "content": "一整段文字。" }
```

**list(用于其余三栏)**
```json
{ "label": "阅读要点", "type": "list", "items": ["1、……", "2、……", "3、……"] }
```

- `label` 是左侧标签块文字。若要分两行显示(如「拓展阅读建议」样张里排成「拓展/阅读/建议」),模板会按字数自动折行,无需手动换行;如需强制换行可在 label 里写 `\n`。
- `items` 每条建议为一个字符串,自带序号(`1、` `2、`)。
- 阅读要点 vs 阅读建议:**内容必须分工不重复**(见 SKILL.md 红线)。
