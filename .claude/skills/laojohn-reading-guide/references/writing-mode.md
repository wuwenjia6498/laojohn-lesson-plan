# 写作课模式（reading-guide · 写作学习指南变体）

本 skill 默认把读书会课案做成《书名》阅读指南。当输入是 **写作课（习作课）详案**（由 `laojohn-writing-lesson` 产出）时，切本模式产出 **写作学习指南**：**渲染引擎、模板、版式照旧复用**，只换数据口径——信息表换课程信息、栏目换写作维度、不取书目/书封。

## 0. 怎么判型（自动）
H1 `# 《题目》· 写作课教学设计`、书级 `## 一、教案提纲表`+`## 二、核心素养教学目标`（四维标签）、课时 `## 第1课时 · 写作指导课`。判不准走默认读书会模式。

## 1. 给谁看 / 改写口径
面向**要上这次习作课的学生和家长**：这次要写什么、要做到哪几点、怎么准备和动手、写完还能怎么延伸。仍是「降维改写」成温暖平实的孩子话，丢弃教学性细节（师生对白、环节时长、参考答案）。

## 2. 数据差异（其余字段同主 SKILL/data_schema）

- **title**：`<题目> · 写作学习指南`（习作题目**不带《》**）。
- **cover_image**：写作课无书封，置 `null`；**`cover_placeholder` 设为 `""`**（空占位框，不显示「书封待放」）。
- **info → 改用 `info_rows`**（模板新增的可选字段：每行 `[k1,v1,k2,v2]`，覆盖默认书目六格）。写作课填课程信息，3 行例：
  ```json
  "info_rows": [
    ["题目", "这儿真美", "年级", "三年级上册"],
    ["单元", "第六单元", "类型", "写景·校内同步"],
    ["课时", "2 节 × 45 分钟", "主题", "把身边的美写具体"]
  ]
  ```
  字段值只来自写作详案（提纲表/标题），缺则留空字符串。**不写 `info`**（写了也会被 info_rows 覆盖）。
- **sections（四栏，顺序固定，label 换写作说法）**：
  1. `这次写什么`（paragraph）：习作主题介绍，4–5 句温暖叙述，说清写什么、写给谁看（如真实读者/展示场景）。取详案提纲「核心技法/贯穿任务」+ 情境环节。
  2. `写作要点`（list 2–3 条·**内容/技法层**：这次要做到什么）：取「核心素养目标 / 核心技法」，改写成「① 概念词：一句说明。」如 围绕一个意思选景物 / 按一种顺序 / 五感写具体。
  3. `怎么学好`（list 2–3 条·**方法/行为层**：怎么准备和动手）：取「工具与任务 / 评价反馈 / 作前准备」，改写成给孩子的动作。如 先到身边那个地方用五感看一看、填构思表理思路、写完读给家人听看能不能「看见」。
  4. `范例与延伸`（list 2 条为佳）：取详案的范例/拓展方向，改写成可执行推荐。如 读完把今天的方法用到另一处身边的景、回看课文里的写景段。详案没提就放占位「待补：可由老师补充…」，不臆造。

> **红线同主 SKILL**：`写作要点`(技法/内容层) 与 `怎么学好`(方法/行为层) 必须分工不重复，自查两栏不许讲同一件事。

## 3. 渲染与输出
渲染命令同主 SKILL「第二步」（复用 `scripts/render_pdf.py` / `render_win.py`）。**输出目录 `<项目根目录>\写作学习指南输出\`**，命名 `<题目>_写作学习指南.{json,pdf,html}`（题目纯文字不带《》）。JSON 是内容源头，三件套 PDF→JSON→HTML 交付。
