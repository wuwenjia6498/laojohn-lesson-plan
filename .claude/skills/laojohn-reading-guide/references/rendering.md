# 渲染与版式说明

## 渲染管线

`scripts/render_pdf.py` 做三件事:
1. 读 `data.json`,把内容注入 `assets/template.html` 的 `/*__DATA__*/ null` 占位,生成自包含 HTML。
2. Playwright + Chromium 无头打开该 HTML,等版式渲染完(`body[data-rendered='1']`)。
3. 按竖向 A4 宽度(794px)导出 PDF;页面高度取 `max(A4高1123px, 实际内容高)`,内容超长自动增高、不截断。

中文字体走系统 Noto Sans CJK SC,已嵌入 PDF,无乱码。

## 版式结构(从上到下)

1. **页眉**:左「老约翰深度阅读」、右「阅读·思辨·表达」,下方一条细分隔线。
2. **居中大标题**:`《书名》阅读指南`。
3. **顶部区**:左书封(200px 宽,占位时为虚线框)+ 右信息表(3 行键值)。
4. **四个栏目**:每个 = 左标签块(96px)+ 右正文,标签与正文等高、左右拼接成一体色块。

## 调整建议

- **某栏文字过长撑破版面**:首选回到萃取压短文字。版面是自适应高度,撑长不会截断,但过长不美观。
- **书封比例**:模板按图片原宽缩放到 200px 宽、高度自适应;占位框固定 268px 高。竖版书封最自然。
- **标签文字折行**:标签块定宽 96px,四字标签(拓展阅读建议→「拓展阅读/建议」)会自动折行居中。

- [ ] 信息表:课案有的已填、没有的留空(无臆造)
- [ ] 内容简介:面向孩子、温暖平实,无教学术语
- [ ] 阅读要点 vs 阅读建议:**确实分工、无重复**
