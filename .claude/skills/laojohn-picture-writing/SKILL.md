# 老约翰 · 看图写话课详案生成器（图位规格驱动 · 低年级）

把「一个主题/课次」变成一次老约翰风格的看图写话课逐字稿（两节连排 × 45 分钟）。**核心机制：AI 不等真图，而是先为每个用图位『定义画面』，产出结构化《图位规格书》，再据规格中的「必须可见元素清单」写出图文自洽的详案。** 用户事后拿规格去任意生图工具出图、按清单逐项验收回插。这样既全自动出详案、写作不被卡断，又不丢真实性纪律。

## 图位规格门禁（最高优先级，先于一切正文）

看图写话的一切观察、圈画、例文都锚定「图上有什么」；这个"图"在写作时尚未存在，由 AI 用规格规定。五道门禁：

1. **无规格不写正文**：正文里任何依赖画面的句子，其依赖元素必须先出现在某个图位规格书的「必须可见元素清单」里；不得随手「（如图）」却没有对应规格。
2. **正文不越清单**：例文与圈画指令只能引用清单内元素；清单外内容只能作"合理想象"落在想象环节、明示为想象，不得伪装成画面事实。
3. **训练点反向约束画面**：每个图位声明训练点，并据此**主动要求画面包含可教元素**（如细节课必须要求画面含可圈画的细节），防止设计一张干净但教学贫乏的图。
4. **回插终检（交付后由用户触发）**：真图按规格清单逐项验收，缺项→重做图或回改详案。该提示固定写在**文末「生图工单」区开头**，**不写详案头部**——第一页只留教学内容。
5. **两道选图硬门（2026-07-26 定，细则唯一源＝`references/image-spec.md` §一~§三）**：① **图随方法点定规格**——出图前按 §一对照表逐条核验，表里没有本课方法点就先补一行；四问类图**必须有「意外点」，一票否决**（没有意外点，四问里的心理这一问只能瞎编）。② **一课三图位**——主图（`主-0N`）＋练笔图（`练-0N`）＋备选图（`备-0N`）必须交齐，**纯口头课不豁免**；**教师示范例文写主图、学生当堂写作用练笔图**（同族异时），写作前配 1~2 分钟〔换图速看〕；缺的图写「待出图」列入待办，不得留空冒充已有。

> 本门禁对应 laojohn 生态既有的「无档案不虚构」铁律：真实性核查从「正文 vs 真图」前移为「正文 vs 规格清单」，回插时补一道「真图 vs 规格清单」终检。

## 图的四种角色（编号前缀即角色）

**主图 `主-0N`**（第1课时全程＋示范例文所锚，完整规格）／**练笔图 `练-0N`**（学生当堂写作，完整规格＋`同族关系:`）／**备选图 `备-0N`**（练说与分层，轻规格）／**格式图 `格-0N`**（固定资产不写规格）。角色×规格详略对照表与同族关系定义见 `references/image-spec.md`；**旧前缀 `锚-／例-` 仅作存量兼容，新稿不再使用**（见 `references/terminology.md`）。把严格核查的成本花在主图与练笔图这两张上（学生真正要圈、要写的就是它们），整套系统才跑得动。

## 课程框架（24 方法主线 · 四学期 64 课次，唯一源＝course-map.md 与 ability-ladder.md）

全体系接入同步习作六阶总轴，看图写话占第一、二阶（一二年级）。**排期口径＝四学期 × 每学期 16 次 = 64 课次**（`course-map.md` §四），24 个方法为主线、五条能力线归类（§二），方法 meta 见 §五内部编号表。**期号纪律：期N 只是方法的内部编号，仅供 references 间检索与冷审核对，禁入任何对外产物**——详案正文/首页/docx/生图工单/预告话术一律用「学期＋课次＋方法名」。

- **五课型**（方法/练习/回顾/综合/展示）＋**衔接课**，两节结构见 `course-map.md` §三；**每次课统一两节连排 90 分钟**（详案一律按 45+45 产出，纯口头课次机构可现场压缩至约 60 分钟执行、不另出 60 分钟版）。
- **年级档＝课次属性，不进正文**：年级由排期学期唯一确定，产出量/标点/识字/说写比据此写死进详案，**正文不写 `〔L1〕〔L2〕` 括注**；二年级插班生走独立衔接课。
- **课内分层三手柄**（不同支架/不同任务/不同图，见 `scaffold-cards.md` §一；支架手柄越阶敏感）与**评价三级**（基础/良好/优秀配对照例句，`lesson-structure.md` §10.2）是两套——支架层跨课次递进，评价级课次内**每次课都能拿满三档**。

### 衔接课（二年级入班衔接包 · 独立生成入口 · 生成规则唯一源在本节）

面向二年级中途入班学员（定位与客群见 `course-map.md` §三）：入学测评＋4 节衔接课（①三素句＋四要素合并 ②三段式 ③细节四问 ④单图综合演练），修完并入主轨。能力记录位见 `ability-ladder.md` 附「衔接包」表。**生成规则（与主轨课次的关键差别，违反即返工）**：

1. **按二年级单档独立设计，不复用一年级课次改档**。衔接课 ①② 对应的主轨方法是一年级课，其环节节奏、支架强度、产出量均按一年级定；直接「改成二年级档」会保留一年级节奏，对已在校内写过话的插班生偏慢、偏幼。须**重新设计环节骨架与支架强度**，只沿用训练点。
2. **压缩靠合并、不靠删环节**：说—写—评三段仍须齐全，先说后写不豁免。
3. **学情前提写进提纲表**：衔接课学员已有校内写话经历，起点是「写过但写不好」不是「没写过」；导入不做「降低动笔恐惧」，直接切入方法。
4. **题目取自 `references/topic-registry.md`，并与主轨近期已用题交叉查重**（与将并入的学期主轨交叉查重）。
5. **课型标注**：提纲表「课次·课型」行写「衔接课（二年级入班衔接包 第N节）」——不占 64 课次主轨、无内部编号，能力线行不打「（本课）」标记。
6. **一年级中途插班不设衔接包**，直接入轨，前置缺口在练习课内以课内分层手柄①② 补齐。

## 工作流程（必须按顺序）

0. **确认输入**：课次/年级（方法名亦可）＋主题——主题**按课次从 `references/topic-registry.md` 取，禁自拟**；总表中该课次缺行的，**先补行、再生成**。缺课次则查 `course-map.md` §四，按主题+年级+方法匹配最贴近课次，头部标注推定依据。
1. **规划课次与图位**：由课次经 `course-map.md` §五定位方法内部编号，读 `ability-ladder.md` 命中方法记录 + 同步锚点命中的 `curriculum-archive.md` 记录 → 列出全课**图位清单**（每图位标角色与所属环节；**必须按三图位配齐**，并先按 `image-spec.md` §一对照表确认本课方法点对图的要求）。
   - 图位清单按 `topic-registry.md` 该课次的三行（主／练／备）建，题材与出场角色照表取；图规格按 `image-spec.md` §一 对照表中本课方法点那一行逐条过门。
   - **骨架分 A/B 两层，读法按状态**（`ability-ladder.md` 索引表「详录状态」列）：`◐`＝A 约束层（不可越阶/支架/例文要求）已定、B 实施层（环节＋分钟）待录——**这是常态，本课就是要产出 B 层**，按 A 层约束自行设计环节；`★`＝俱全，B 层照读；`★（引旧五期）`＝B 层按记录指引翻旧五期详录。
   - ⚠ **A 层缺失不得跳过**：命中方法没有 A 层记录时，先按 `ability-ladder.md`「三条推导规则」补出 A 层再往下走——A 层是防越阶的前置约束，事后补＝追认，冷审的「不可越阶逐条核」会空转。
2. **写《图位规格书》**（先于正文）：按 `image-spec.md` schema 为每图出规格。主图与练笔图完整规格（练笔图另填 `同族关系:`，四问类主图清单另加 `□ 意外点＝…`），备选图轻规格，格式图只登记。**训练点反向约束画面**（门禁 3）。
3. **据规格清单写正文**：把「必须可见元素清单」当环节取材池，正文不越清单。**分头对源**：圈画与例文回主图清单；当堂写作的任务提示、兜底填空条、过关判定与评价例句回练笔图清单。
4. **写配图示范例文**：按 `model-essay.md`，标 `【教师示范例文】`；细节全部来自**主图**规格清单；想象部分单独成段、明示。例文之后、动笔之前放〔换图速看〕（1~2 分钟、只问不写，作写作环节子步骤，不单列环节、不改各环节标称分钟）。
5. **自检**：对照 `checklist.md`，重点跑「例文 vs 规格清单」越清单核查；语言类机检先跑 `PYTHONUTF8=1 python tone_gate.py <详案.md> --profile picture` 全绿，人工只留判断项。
6. **产出装配**：文末工单区开头写回插提示（不放头部，门禁 4）＋两块核验表（方法点图规格核验表/三图位交付清单，格式见 `image-spec.md` 文末）；**正文每个图位出现处必须放机读占位标记 `【图位:编号】`**，文末汇总全部规格书成「生图工单」区（主图→练笔图→备选图→格式图）。
   - ⚠ **占位标记是硬契约**：`insert_images_docx.py` 只按 `【图位:编号】` 定位回插，叙述式「（出示备-01）」脚本认不到、回插插 0 张；叙述说明可保留但必须**紧跟**一个占位标记，同一行连列多个合法。
   - ⚠ **占位标记要独占一段**：标记会被换成真图，和师话同段会把句子挤成上下两截、版式不可控。师话一段，占位标记另起一段。
   - **装配后立即机检**：`PYTHONUTF8=1 python scripts/imgspec_parser.py <详案.md>`，「正文引用但工单缺规格」与「工单有但正文未引用」须均为「无」方可交付。
7. **通读复盘（冷启动·独立执行·交付前必做）**：第5步查合规，本步查 checklist 查不出的**质量问题**（装载量/师话密度/图有没有真用起来/训练点教了有没有练）。**必须换人冷审、不在本生成会话自审**——执行形态、审稿人协议与五维一律以 `laojohn-detail-review/SKILL.md` 及其加载的 `references/review-rubric.md` 为准（总纪律见根 CLAUDE.md §4「交付双道工序」）。首选派 fresh（非 fork）子 agent 执行 detail-review，或告知用户在新会话跑。生成方记住三点：换人冷审不自审；复盘补全时真实性红线不豁免（画面回图位清单、教材回 curriculum-archive、课次回 course-map）；**冷审若要改图位规格，须回验真图**。
8. **回录 B 实施层（详案定稿后必做）**：把定稿的 `## 第N课时 · <名>` 与各 `### 环节N · <名>（M 分钟）` **照抄**回 `ability-ladder.md` 该方法〔B 实施层〕节，索引表状态 `◐`→`★`。**只抄不设计**（B 层的价值就在被真实详案验证过）；可附一两条「关键设计（勿丢）」；原 `★（引旧五期）` 回录后改 `★` 并注明旧详录仅作历史来源。
9. **(可选)导出 Word**：复用 `laojohn-lesson-plan` docx 引擎；图位占位转图框，用户回插。
10. **(可选)自动生图闭环**：详案+工单就绪后可自动跑「生图→验收→回插 docx」，**opt-in**；脚本用法、后端选择、密钥、`--verify-only`/`--only --edit` 开关、验收红线，全见 `references/imggen-pipeline.md`。**人工终检不可省**：主图与练笔图务必人工再扫一眼（同一角色/意外点机器判不了）；生成图服从规格，绝不可反过来用图改写正文/规格（CLAUDE.md §5 例外口）。

## 核心约束（违反即返工）

- **规格是画面事实唯一来源**：观察/圈画/例文只能引用规格清单；清单外走"合理想象"且明示。
- **训练点驱动画面**：每个图位声明训练点，并据此要求画面含可教元素。
- **示范例文红线**：标 `【教师示范例文】`，不冒充学生/名家；例文不得出现规格清单外的"事实性"物件。**例文写在主图上、学生当堂写作用练笔图**（两者同图＝把「集体说过的抄一遍」当成写作，返工）；写作前必配 1~2 分钟〔换图速看〕（只问不写、作子步骤不单列环节）。
- **一课一得**：训练点锁定本课 ≤ 1 项（指**新授**方法；综合课/回顾课复用已教方法不算越例），不越阶叠加——排期靠前的课不得预教靠后方法（判据＝`course-map.md` §四课次先后）。
- **官方锚点不虚构**：涉教材/课标的表述只能来自 `curriculum-archive.md` 对应记录；「无官方对应」课次如实写明，不反向编造。机构自研教法（圈画四步法、分档支架卡）注明「借鉴/机构设计」，不冒充官方要求。
- **语言风格（适龄亲切 · 去重型游戏化）**：一二年级师话亲切、多示范、多肯定，但**方法叫法直说、不裹形象比喻**——要素叫"重点/要素"（非"小秘密"）、把句子写好说"写完整/写具体"（非"句子胖起来"）、支架叫"词语卡"（非"魔法卡片"）、加细节说"加细节/写生动"（非"加料/变身"）；不"站好队/破案啦"游戏旁白，不反复情绪安抚（个别学生当堂卡住临场安抚一句除外）。**"小侦探"禁用（2026-07-20 用户拍板，推翻此前保留）**：看图说话是直接说出画面上明摆着的东西，不是找隐藏线索，套"侦探/破案/找线索"属硬加包装——**检索"侦探"应为零**。**"段子"禁用（2026-07-23 用户拍板）**：现今几乎只作"笑话"讲，一律改说"这段话"——**检索"段子"应为零**。**保留**的低龄亲切："心里话"（心理想象）、画面生动描写与拟声词、固定话术骨架。**判据**＝方法叫法与环节称呼平实直说，只有画面描写可生动。
- **逐字稿语言肌理（去模型腔）**：并列教学点不套同一句式模具、对仗式总结每课限一句、"抛词——解释"破折号限密、`参考：` 含粗糙口语档且链条接得上；机构自造简写换教研通用词（`references/terminology.md` 分语境执行）；软规则与**反向约束**（不注水/不统一句长/不动学生话轮粗糙感/不改示范例文/不引新对仗/每处独立判断）成对、缺一半即走向反面。规则正文与判据唯一源＝`lesson-structure.md` §13，数字判据见 `checklist.md`「话术与产出」组。
- **先说后写**：写话环节一律先口头说—再规范写；写话格式小提醒（空两格/标点不顶格/生字拼音）每课呈现。
- **教室无黑板/白板、也别指望墙面（全仓恒久约束）**：详案禁写「板书/黑板/白板」；常驻支架一律做成**每人一张小卡（随身留用）**，教师口头归拢。**不要写「教室墙面张贴」**（机构教室多为借用，墙面不可控，2026-07-20 收紧）。
- **时长 5 的倍数、两节各 45 分钟、说/写/评三段齐全。**
- **固定话术骨架**：`师：` `参考：` `引导句式：` `（教师总结）` `（本课完）`、田字格示范、圈画建议做法。
- **回插提示常驻**：固定写在文末「生图工单」区开头（门禁 4），不放详案头部。

## 详案骨架（速记 · 细则唯一源＝lesson-structure.md §16）

```
# <总标题>（课程主题式，无台账字眼）
###### <学期>· 第 N 次 · <课型> · 看图写话详案   ← 期次副标，台账信息只放这一行
## 教案提纲表（三区：一、本课定位 3 行／二、本课要点 3 行／三、与校内的关系 4 行）
## 第1课时 · <一句话>　　## 第2课时 · <一句话>
## 附：本课支架与说写格式小提醒（唯一进 docx 的可见附录）
## 附：生图工单　## 附：真实性自检（两区整体包 <!-- -->，只留 md 源不进 docx）
```

四条硬耦合（违反即坏版式/断链，展开见 `lesson-structure.md` §16）：① 课时标题必须 `## 第N课时 · 小标题`——docx 引擎按「`##` 以『第』开头」判定分页；② 课时后章节一律 `## 附：…`，不用「三、四、五」编号；③ 生图工单/真实性自检两区包注释（`<!--`/`-->` 各占独立行，区内不得出现 `-->`），「支架小提醒」不得误包；④ 导出 docx 后必跑 `style_front_page.py`（picture 档 `zones3`，靠期次副标行判型；改脚本须回归两线）。提纲表三区行名与取值规则见 §16.2；不设独立教学目标节（目标由提纲表＋各课时「本课目标」承载，四维标签检索应为零）。

## 输出形态

保存到：`<项目根目录>\看图写话详案输出\`；命名 `<年级册>（<季>）第 N 次 · <课型>.md`（如 `二上（秋）第 1 次 · 方法课.md`，**不带主题、不带「看图写话详案」尾缀**），课次/课型取自 `course-map.md` §四，上学期＝秋、下学期＝春。**标题体例＝三行，规则唯一源＝`references/title-naming.md`**（H1 主题式总标题／`###### ` 期次副标／`## 第N课时 · <一句话>`）；**脚本耦合：期次副标行不可省、尾缀「 · 看图写话详案」不可改**——文件名口径由它承载（映射见 title-naming §七）、`style_front_page.py` 靠它判型，H1 反而自由。详案文末附「生图工单」；导出 .docx 同名同目录；自动生图产物落点见 `references/imggen-pipeline.md`。
