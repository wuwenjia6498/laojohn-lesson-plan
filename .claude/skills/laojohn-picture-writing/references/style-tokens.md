# 画风令牌（style-tokens）· 全期画风的唯一事实源

本文件定义看图写话所有生成图的**统一画风**。写图位规格时**不要再在每张 `生图提示词` 里各写各的风格形容词**（「低龄儿童绘本插画风」「暖色调」这类），`生图提示词` 只写画面内容（谁、在哪里、做什么、要素、季节），画风由本文件的令牌在组装提示词时**自动注入**。

> **运行时事实源共三处**（2026-07-27 厚涂改造起由「两处」改为「三处」）：
> 1. `scripts/imgspec_parser.py` 顶部 `MAIN_STYLE_TOKEN` 常量；
> 2. 同文件 `ALT_STYLE_TOKEN` 常量；
> 3. `scripts/generate_images.py` 的 `_STYLE_REF_INSTR`（图生图参考图指令里的质感描述句）。
>
> 第三处是**图生图回弹防线**：练笔图与备选图**全部**走图生图，随参考图附的指令里又硬编码了一遍媒介描述——只改前两处不改它，每一张跟随图都会被参考图指令拽回旧媒介。本文件是给人读的同一份文字，**与三处代码必须一字一致，改一处必须同步全部**。别在第四个地方再写一遍风格。
>
> **令牌仍是两档、图位是三个**：主图与**练笔图**同走 clean 档（A），备选图走 atmos 档（B）。练笔图是学生当堂写作所锚，要能数细节、回溯任务提示，可读性与主图同级。

---

## 为什么要收成全局令牌（2026-07-21 抽查两期成品图后定）

抽查发现配图整体停在「即梦/MJ 默认儿童插画档」——塑料光泽、糖果饱和度、每个物体一圈同粗黑描边、没有环境光。根因不是提示词写得不够多，而是**风格控制分散在每张图各写各的**，既漂移又只能漂到模型的默认档。

改法与本 SKILL 既有的实测经验（见 `image-spec.md`「画风不靠形容词、靠参考图」）是**同一条链路的升级、不是推翻**：

```
                                  ┌──▶ 练笔图（clean 档令牌，同族异时·锁角色）
主图（clean 档令牌，定调）──图生图参考──┤
                                  └──▶ 备选图（atmos 档令牌，跟随）
```

`generate_images.py` 里练笔图与备选图一律带本课主图作参考图（img2img）。所以真正要提升的只有**主图这一张的质感**：主图高级，全课跟着高级。令牌负责把主图从默认档拉起来，参考图负责把这套质感复制到其余各图。

**分两档的理由**：主图要给一年级学生数要素、圈画面，太氤氲的水彩、太暗的光影、太满的肌理会让「图上有什么」变难认——**可读性优先于美观是硬红线**。**练笔图同理入 clean 档**：学生当堂写作对着它数细节、教师照它判过关。备选图只服务「练说句式」、不进例文、不承担逐要素核查，所以允许氛围浓一点。

## 厚涂平面档改造：已终止（2026-07-28）

**当前生效的就是下面 A / B 两档的水彩淡彩叠彩铅档**——厚涂平面档改造已整体回滚，`style_anchor` 置空、锚图链路停用（代码保留未删，换生图通道后可重启评估）。下一节起的「厚涂改造判断依据」是历史留痕，**不代表现行口径**。

**终止原因：人物上色档位无解，两条路互斥。** 背景层面的改造是**成功**的——大色域、浊色、纸底颗粒、满幅出血，锚图一带就跟上；**人物层面不成立**：模型对人脸的先验强于参考图，单参考图迁不动（换成「锚图里有一个平涂的男孩」之后连跑三次，人物仍是渐变皮肤）；双参考图（A 供画风 + B 供内容）能把平涂迁到人身上，**但保不住 B 的内容**（手势、花数、年龄、构图每次重掷，且指令写得越硬偏离越大）。**要画风就丢内容，要内容就丢画风**，两个条件在现有通道上互斥。

**成本**：主-01 一张走了十余轮（四轮令牌措辞迭代 + 母图 v1~v4 + 锚图两版 + 双参考图两次 + 单参考图三次）。按此推算，后续 23 张的预期成本不可接受——**画风不是教学功能项，不值得再投**。

**保留的净收益（本轮改造的真实产出，全部不回滚）**：

| 保留项 | 位置 | 为什么与画风无关 |
|---|---|---|
| `trim_border` 白边裁切 + 4:3 强制 | `generate_images.py` | 工程解，任何画风都会出白边 |
| 多画轨（`_NO_EXTRA_PROPS` + `extras`） | 同上 | 模型自作主张加道具与画风无关（红毛线球） |
| **姿态专项**（含手部五指单独报告） | 同上 | 抓出过首发漏判的「手收在膝前」与「食指指点」，旧画风下同样会发生 |
| 计数轨两步法 + **只报不拦** | 同上 | 见 image-spec.md；轨本身不可靠，但只报不拦这条原则要留 |
| 网络重试（指数退避 3 次） | 同上 | 与画风无关 |
| **近景教学层分层写法** | `imgspec_parser.py` `build_prompt` | 让画面有主次虚实，旧画风下同样有益（若发现要素反而变糊再单独议） |
| **年龄几何量写法** | 图位规格书写法（`image-spec.md`） | 头身比／脸宽高比／眼睛水平中线位置／脖子短——年龄偏大是旧画风也有的老毛病 |
| `--edit` 分级适用 + 单诉求单发 | `image-spec.md` | 实测结论：它是整图重绘、会主动制造违规 |

**全过程实验实录保留在 `image-spec.md`**（三处画风事实源、脱敏、双参考图用途划分、只报不拦原则、「先看失败的维度是否与产物用途相关」等），供**今后换生图通道后重启评估**时参考——重启时先回读那几条，不要从零重来。

## 2026-07-27 厚涂改造的判断依据（决策留痕，勿删；**改造已于 2026-07-28 终止，见上一节**）

抽查 一上（秋）第1次 六张成品图（主-01 / 练-01 / 备-01~04），对照厚涂绘本内页（《大狼和小狼》《雨天》一类），确认旧令牌下配图仍停在「教辅配图档」。根因四条，**其中三条在代码、不在详案**：

1. **薄媒介 vs 厚媒介**。旧令牌「水彩淡彩叠加彩色铅笔」是两个薄媒介，模型的先验解法必然是「线稿打底 + 柔和上色」，负面词「不要描一圈黑色轮廓」压不过正面词「彩色铅笔」——实测六张图全部出现细棕勾线。目标绘本用厚媒介（油画棒 / 厚水粉），形体靠色块边缘定形，根本不需要线。故令牌整体换为厚涂档。
2. **画风事实源实际是三处，旧文档只登记了两处**。`_STYLE_REF_INSTR` 里硬编码的媒介描述漏改会让所有跟随图退回旧媒介——已在文件头改为三处口径。
3. **陈列柜效应主要来自 build_prompt 的硬编码句**。旧句「画面必须同时清晰包含以下全部元素」把所有要素设为等权、等清晰、互不遮挡，虚实、遮挡、大小对比这些绘本语言全被禁掉——这是「教科书样」的**主要**贡献项，比画风段本身影响更大。已改为「近景教学层」句式：可读性护栏从全画面收缩到近景教学层，画面其余部分释放给色域与氛围；`must_see` 内容与机器验收链路完全不动。
4. **重试循环劣化画风**。`process_strict` 缺项重生的追加句会把模型推向逐项摊平，重试越多越像教辅——已改为「补画进近景教学层、其余仍按色域与氛围处理」。

**核心取舍**：绘本语言（大色域、虚实、遮挡）与教学硬约束（3 朵花要数得清、要素要圈得住）本质冲突，不能全要。解法是**把可读性护栏从全画面收缩到「近景教学层」**，教学硬约束一条不丢，机器验收链路不动。

**同日第二轮修订（母图 备-03 v1 实测后）**：首版厚涂令牌出图漂到「油画写生档」而非目标绘本档，三条召唤词被证实——① 「粗纹纸纹透出」「像真实画在纸上再扫描进书里的原作」在召唤纸边，白边反而更重，否定句「满幅出血」压不住，改为正面描述「已经裁切好的绘本内页、颜色覆盖到图像最外一圈边缘」；② 「颜料有明显厚度与堆叠」「笔触短促、有方向性」在模型先验里指向 alla prima 油画写生（笔触塑造体积：猫毛刷出圆柱感、窗框做木纹转折），媒介改「油画棒与蜡质色粉笔」＋明写「物体是平的色块、不做体积感、接近剪贴画」；③ 删「配色低饱和」时没补替代表述导致饱和度失控，补回「低饱和、以浊色为主（掺灰的绿、掺土的黄、掺灰的蓝），仅跳色允许高饱和」。教训：**正面描述目标画法，别用否定句去压强召唤词；删旧约束时必须补等价替代**。

**同日第三轮修订（母图 备-03 v2 实测后，画风档位定稿）**：v2 平面化、浊色、蜡质颗粒、剪贴式剪影均已咬住，档位定稿；收尾两件事——
- **白边改走工程解，令牌不再承担此责任**：两轮措辞（否定句、正面句）都压不净白边，定案为 `generate_images.py` 的 `trim_border()` 落盘后自动裁边（四边逐行扫白带 + 中心裁回 4:3，阈值 `_TRIM_LUMA`/`_TRIM_STD`，四边裁量超任一边 15% 判异常不裁）。**后续调令牌时不要再往里加满幅出血相关措辞**——现存出血句保留（能减少裁量），但白边达标与否以裁边后为准。
**第四轮＝最后一次措辞迭代，风格控制主责移交锚图（母图 备-03 v3 实测后定案）**：v3 修好了舒适感，却回弹三处——猫身一圈等粗红棕描边（勾线回来了）、浊色被冲掉（饱和度上去）、整体漂向商业萌系档。祸源是「讨喜」「剪影形状」这类词在往模型默认萌系档拉。三轮修订每次都按下葫芦起了瓢，**结论：文字撑不住风格**，与 `image-spec.md` 既有结论「画风不靠形容词、靠参考图」一致。

本轮只做最后一次微调（删「讨喜」、「剪影形状」改「外形」避免被理解成描轮廓、追加「不沿角色轮廓描一圈线／外缘不得有连续封闭轮廓线」、造型规则前重申色彩优先级），随即**转入阶段二：全期风格锚图**。

- **风格控制主责已从令牌转移到锚图**：链路 `全期风格锚图（一张，人工定稿）→ 每课主图 → 本课练笔图/备选图`。代码已就位（`generate_images.py` 的 `style_anchor` 配置项、`anchor_ref()`、`_ANCHOR_REF_INSTR`、`main()` 主图分支），**默认留空＝不启用，行为与阶段一完全一致**；人工定稿一张锚图后填 `imggen.config.json` 的 `style_anchor` 即启用。
- **两个图生图语境不可混用**：`_ANCHOR_REF_INSTR`＝跟随全期锚图，只锁画风与媒介，明确声明「参考图与本图内容无关，不要沿用其中的角色、场景或构图」；`_STYLE_REF_INSTR`＝跟随本课主图，锁画风 + 锁角色（同族异时要同一个人），保持不变。
- **令牌今后只做兜底，不再为解决画风漂移而反复加措辞**。真图与目标档有差距，先换/重出锚图，不要回来改词——四轮实测已证明加词只会换一个方向漂。

- **新增主体角色造型规则（平面化的代价补偿）**：v2 的猫显得病恹恹（眼睛下垂细缝、嘴角向下、身体摊平），因为「不做体积感」把塑造舒适感的手段一并收走了。解法是**靠形状与五官补、不是退回体积塑造**：主体剪影要饱满讨喜（睡卧团成一团）、五官明确传达情绪（眼弯嘴平、可加腮红）、主体下方一块单色投影托底。毛糙边同时加了限定：只适用于画面内部色块交界，不适用于图像最外边缘。

## A. 主图档（clean 档 · 优先可读性 · 练笔图同用此档）

> 常量名 `MAIN_STYLE_TOKEN`

```
画风：柔和的水彩淡彩叠加彩色铅笔质感的手绘插画，看得见纸张纹理与自然笔触，不要矢量扁平风、不要塑料光泽、不要均匀渐变；线条轻盈、粗细有变化，不要每个物体都描一圈同样粗细的黑色轮廓；配色低饱和、以柔和的暖色系为主，只保留一处克制的强调色，不要糖果色、荧光色、不要整体高饱和拉满；光线是柔和的自然方向光，带轻微的环境光与柔和投影，画面有空气感、有主次虚实。同时保证可读：主角与每一个要素都清晰、边缘可辨，构图干净、留白充足，孩子要能一眼看清、数得出、圈得住，氛围一律服从可读。
```

## B. 备选图档（atmos 档 · 可偏氛围）

> 常量名 `ALT_STYLE_TOKEN`

```
画风：柔和的水彩淡彩叠加彩色铅笔质感的手绘插画，看得见纸张纹理与自然笔触，不要矢量扁平风、不要塑料光泽、不要均匀渐变；线条轻盈、粗细有变化，不要每个物体都描一圈同样粗细的黑色轮廓；配色低饱和、以柔和的暖色系为主，只保留一处克制的强调色，不要糖果色、荧光色、不要整体高饱和拉满；光线是柔和的自然方向光，带轻微的环境光与柔和投影，光影可以更丰富、氛围可以更浓一些，但仍要看起来与本课主图出自同一位插画师、同一套绘本。
```

两档的媒介 / 定形方式 / 色域规则 / 光线基调**必须逐字同源**——备选图要靠图生图跟随主图，基调不同源会打架。两档的差别只在最后一句：主图收在「可读」，备选图放到「氛围」。

## `色域` 字段（每图变量 · 可选）

令牌只管**通用**色域规则（2~3 块大色域、一处跳色 ≤8%）；具体某张图「哪块颜色占哪里、跳色落在谁身上」是每图变量，由图位规格书的可选字段 `色域:` 承载。`build_prompt` 在 `生图提示词` 之后、`风格/比例` 之前拼入 `本图色域：…`；**字段缺省时不拼、不给默认值**，令牌里的通用规则仍然成立。

写法示例（写进图位规格书）：

```
色域: 黄绿色草地占画面下方约 65%，浅暖米白天空占上方约 30%，深绿与砖褐的树占右侧约 20%；
      跳色＝男孩上衣的橘红，不超过画面 8%；3 朵小黄花为明黄，落在偏冷的草绿上靠冷暖对比跳出来
```

## 负面清单（令牌里已含，图生图指令也复述一遍）

不要矢量扁平风 / 不要塑料光泽 / 不要均匀渐变 / 不要每个物体都描一圈同样粗细的黑色轮廓 / 不要糖果色与荧光色 / 不要整体高饱和拉满；图生图指令另加：不要多重生硬高光。

> ⚠ 2026-07-28：厚涂档时期加的三条（不要退回细勾线加淡彩的薄涂画法 / 不要用笔触塑造体积 / 不要出现纸张白边或毛边）**已随改造终止一并撤销**——前两条与现行水彩淡彩档直接冲突，白边那条已由 `trim_border` 工程解承担。
>
> ⚠ 2026-07-29 再证一次：**「平铺色块」「两级明暗」这类正面措辞同样禁用**（不只是负面清单里那三条）。角色定妆图妆-05 画风偏实时下了这条指令回拉，**一次就把整张图推出 A 档**——粗细均匀黑描边的矢量动画风，纸纹与水彩笔触全失。这与上面终止的厚涂平面档改造**是同一件事**：往「平面／两级」方向推，模型的先验落点就是矢量卡通。**画风偏差只能靠参考图带，不能靠措辞纠**；详见 `image-spec.md` 实测经验区同日两条（跨物种参考图链失效 / 平铺色块禁令）。

这份清单同时写进 `generate_images.py` 的 `_STYLE_REF_INSTR`——模型在图生图时最容易「回弹」到默认卡通档，那一路要再钉一次。

## 调令牌的注意事项

- **只改这三处**（本文件 + `imgspec_parser.py` 两常量 + `generate_images.py` `_STYLE_REF_INSTR` 的质感句），且同步。第三处漏改＝所有图生图跟随图退回旧媒介。
- **往可读方向收是安全的，往氛围方向放要看真图**：任何措辞若可能让近景教学层要素变模糊、变暗、难辨认、难圈画，就往「清晰、边缘可辨」方向收回来。
- **机器验收判不出画风好坏**（也判不出季节、遮脸、背影，见 `image-spec.md`）。令牌措辞是否奏效，只能拿一期真实详案跑一次 `generate_images.py`、人工看图定。
- **改令牌后不要批量重生已有图**——旧图已人工核准，回验一律 `--verify-only`；迁移到新画风是独立决策、单独排期。
- **换档位这件事，先读「厚涂平面档改造：已终止」那一节再动手**。一次整档改造实测走了十余轮仍未成，且失败点不在措辞而在模型对人脸的先验；**若只是想让画面好看一点，改措辞的边际收益极低**。真要换档，前提是换生图通道，并按那一节列的顺序重启评估。
