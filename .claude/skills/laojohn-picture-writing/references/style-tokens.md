# 画风令牌（style-tokens）· 全期画风的唯一事实源

本文件定义看图写话所有生成图的**统一画风**。写图位规格时**不要再在每张 `生图提示词` 里各写各的风格形容词**（「低龄儿童绘本插画风」「暖色调」这类），`生图提示词` 只写画面内容（谁、在哪里、做什么、要素、季节），画风由本文件的令牌在组装提示词时**自动注入**。

> **运行时事实源是 `scripts/imgspec_parser.py` 顶部的 `ANCHOR_STYLE_TOKEN` / `LIBRARY_STYLE_TOKEN` 两个常量**；本文件是给人读的同一份文字。**两处必须一字一致，改一处必须同步另一处。** 别在第三个地方再写一遍风格。

---

## 为什么要收成全局令牌（2026-07-21 抽查两期成品图后定）

抽查发现配图整体停在「即梦/MJ 默认儿童插画档」——塑料光泽、糖果饱和度、每个物体一圈同粗黑描边、没有环境光。根因不是提示词写得不够多，而是**风格控制分散在每张图各写各的**，既漂移又只能漂到模型的默认档。

改法与本 SKILL 既有的实测经验（见 `image-spec.md`「画风不靠形容词、靠参考图」）是**同一条链路的升级、不是推翻**：

```
锚图（clean 档令牌，定调）  ──图生图参考──▶  例库图（atmos 档令牌，跟随）
```

`generate_images.py` 里例库图一律带本期锚图作参考图（img2img）。所以真正要提升的只有**锚图这一张的质感**：锚图高级，全期跟着高级。令牌负责把锚图从默认档拉起来，参考图负责把这套质感复制到其余各图。

**分两档的理由**：锚图要给一年级学生数要素、圈画面，太氤氲的水彩、太暗的光影、太满的肌理会让「图上有什么」变难认——**可读性优先于美观是硬红线**。例库图只服务「练说句式」、不进例文、不承担逐要素核查，所以允许氛围浓一点。

---

## A. 锚图档（clean 档 · 优先可读性）

> 常量名 `ANCHOR_STYLE_TOKEN`

```
画风：柔和的水彩淡彩叠加彩色铅笔质感的手绘插画，看得见纸张纹理与自然笔触，不要矢量扁平风、不要塑料光泽、不要均匀渐变；线条轻盈、粗细有变化，不要每个物体都描一圈同样粗细的黑色轮廓；配色低饱和、以柔和的暖色系为主，只保留一处克制的强调色，不要糖果色、荧光色、不要整体高饱和拉满；光线是柔和的自然方向光，带轻微的环境光与柔和投影，画面有空气感、有主次虚实。同时保证可读：主角与每一个要素都清晰、边缘可辨，构图干净、留白充足，孩子要能一眼看清、数得出、圈得住，氛围一律服从可读。
```

## B. 例库图档（atmos 档 · 可偏氛围）

> 常量名 `LIBRARY_STYLE_TOKEN`

```
画风：柔和的水彩淡彩叠加彩色铅笔质感的手绘插画，看得见纸张纹理与自然笔触，不要矢量扁平风、不要塑料光泽、不要均匀渐变；线条轻盈、粗细有变化，不要每个物体都描一圈同样粗细的黑色轮廓；配色低饱和、以柔和的暖色系为主，只保留一处克制的强调色，不要糖果色、荧光色、不要整体高饱和拉满；光线是柔和的自然方向光，带轻微的环境光与柔和投影，光影可以更丰富、氛围可以更浓一些，但仍要看起来与本期锚图出自同一位插画师、同一套绘本。
```

两档的媒介 / 描边 / 配色 / 光线基调**必须同源**——例库图要靠图生图跟随锚图，基调不同源会打架。两档的差别只在最后一句：锚图收在「可读」，例库图放到「氛围」。

---

## 负面清单（令牌里已含，图生图指令也复述一遍）

不要塑料光泽 / 不要均匀矢量渐变 / 不要全图均质黑描边 / 不要糖果色或高饱和拉满 / 不要多重生硬高光。

这份清单同时写进 `generate_images.py` 的 `_STYLE_REF_INSTR`——模型在图生图时容易「回弹」到默认卡通，那一路要再钉一次。

---

## 调令牌的注意事项

- **只改这两处**（本文件 + `imgspec_parser.py` 常量），且同步。
- **往 clean 方向收是安全的，往氛围方向放要看真图**：任何措辞若可能让锚图要素变模糊、变暗、难辨认、难圈画，就往「清晰、留白、边缘可辨」方向收回来。
- **机器验收判不出画风好坏**（也判不出季节、遮脸、背影，见 `image-spec.md`）。令牌措辞是否奏效，只能拿一期真实详案跑一次 `generate_images.py`、人工看图定。
