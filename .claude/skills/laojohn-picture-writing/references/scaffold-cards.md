# 词语支架卡与填空模板（scaffold-cards）

低龄写话的脚手架库：**词语支架卡**（按类给词、降启动门槛）+ **填空模板**（一年级用、把段落骨架挖空让学生填）。`ability-ladder.md` 各骨架「支架强度」段引本文件。这是技能自有的通用支架格式，供新生成 20 期时按题材填充。下文以一个「春日公园」题材为例演示类目与挖空格式。

## 支架强度总则（一/二年级分档）

- **一年级**：给词语支架卡 + 填空模板（把句段挖空，学生只填词/短语）。
- **二年级**：只给词语支架卡，不给填空模板，鼓励独立成句。
- 词语卡是**启发用、可选用**，不是必须全用、更不是标准答案；鼓励学生说出卡外的词。
- ⚠ 叫「词语卡」，不叫「魔法卡片」。

## 一、词语支架卡（五类）

按表达需要给词，五类对应四要素 + 情感。**每期据题材替换具体词条**，类目固定。

| 类别 | 作用 | 示例（「春日公园」题材） |
|---|---|---|
| 时间词语 | 起笔点时间 | 春天、星期天、不知不觉、天快黑了 |
| 地点/场景词语 | 点地点 | 公园、草地、大树下、春天的公园里 |
| 环境描写词语 | 写第二段环境 | 小草绿绿的、软软的、白色的小花、枝繁叶茂、空气中飘着花香 |
| 动作词语 | 写主角动作 | 躺在草地上、读故事、听得入迷 |
| 情感词语 | 写第三段心情 | 心情舒畅、开开心心 |

**按模块的卡变体**：
- M1 进阶（三段式）：五类齐全（如上）。
- M1 综合（细节四方向）：在动作类基础上增「表情词」「拟声词」两小类，配合细节四方向。
- M2 轻想象：增「对话起句」（它说：『……』）、「心情词」（供心里话）。
- M3 多图：增「关联词」（先……接着……后来……最后……）「对话起句」。
- M5 期18：好词按 时间/环境/动作/心情 分类积累（叠词、拟声词单列）。
- M6 综合表达：增「过渡句」（图上……我也……我觉得……）。

## 二、填空模板（一年级专用）

把三段式骨架挖空，学生填词/短语即成段。**据题材替换括号内提示**，结构不变。范式（三段式·以「春日公园」题材演示）：

```
【第一段】
一个（时间），（谁）和（谁）来到（地点），准备（做什么）。

【第二段】
（地点）真美呀。阳光（怎么样），草地上（怎么样），树上（怎么样），空气里（怎么样）。
它们坐在（哪里），（做什么）。
（谁）（怎么样地）（动作），（谁）（怎么样地）（动作），它们（怎么样）。

【第三段】
它们（做了多久/什么），不知不觉（时间变化）。它们（收尾动作）回家了。今天真是（评价/心情）的一天！
```

**按模块的填空变体**：
- M1 起步（三素句）：不给整段填空，给单句模板「（谁）在（哪里）（做什么）。」
- M2 轻想象：给「它说：『___』」「它心想：『___』」「之前……此刻……后来……」。
- M3 多图：四格各一句的「起因—经过—经过—结果」四栏。
- M4 创意：缺图那段给「引导问题清单」（谁出现了？做了什么？有没有说话？心里怎么想？）替代填空。
- M6：给「图上……我也……我觉得……」过渡梯子。

## 三、使用纪律

- 填空模板里的提示词/示例**不得包含锚图规格清单外的「画面事实」**——填空骨架是语言脚手架，不是替学生编造画面。涉及画面的空（环境/动作）须能从该期锚图清单填得出。
- 用完即撤：二年级不发填空模板；一年级填完后按规范格式正确抄写一遍，巩固写话格式。
