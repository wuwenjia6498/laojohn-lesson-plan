# 三层支架卡 · 分层写话支架（scaffold-cards）

> **性质与来源**：机构教学法设计,三层支架命名（要素填空/细节拓展/问题启发）源自姚颖 2026-07,句式迁移法同源。**非官方要求**。解决「写下来」这一端;「看懂图」那端见 `picture-reading.md`。
> **核心原则**：支架是**脚手架不是模板**——帮学生起步,不规定成品长相。学生能自己写就撤支架;支架用久了要拆,避免八股同质化(承接项目同质化防线)。
> **调用场景**：详案「作中指导」环节必读。按课内三层(基础/提高/拔尖)对应发不同支架,不是全班同一张。

---

## 一、三层支架总览

学生写话能力分层,支架随之分层。三层对应课内基础/提高/拔尖三层教学,也对应从「写完整」到「写具体」到「写出个性」的进阶(姚颖 2026)。

| 层级 | 支架名 | 解决什么 | 产出目标 | 对应课内层 |
|---|---|---|---|---|
| 基础层 | 要素填空支架 | 把句子写**完整** | 谁+在哪+做什么,一句通顺 | 基础(过关) |
| 进阶层 | 细节拓展支架 | 把句子写**具体** | 加动作/表情/环境细节 | 提高(达标) |
| 创意层 | 问题启发支架 | 写出**个性与想象** | 加起因后续/心里话/独特视角 | 拔尖(进阶) |

> 三层不是三个班,是同一堂课里给不同程度学生的不同支架;也可同一学生分阶段从基础走到创意。

### 硬要求：详案必须声明本课支架层级与撤架路径

每份详案在「作中指导」或等价环节须**显式写明**两句话，缺一即返工（见 `checklist.md` 教学厚度组）：

1. **本课支架发到哪一层**（只发基础层也合法，但要写明「本课只发基础层，进阶/创意层不发」及理由）；
2. **哪些该撤、撤的信号是什么**（引各层「撤架信号」即可）。

> **`〔L1〕〔L2〕` 不等于课内三层**：前者是**年级双档**（一年级/二年级两个不同学段的教法差异），后者是**同一堂课内**不同程度学生的支架分层。两者不可互相顶替——只写了 `〔L1〕〔L2〕` 括注**不算**做了分层设计。真正的分层至少要有一处**不同任务、不同图或不同支架**，而不是同一件事换个说法。

### 三档发放的触发条件（写法示例）

分层不是理念、是当堂可判定的动作。旧稿的成熟写法是**按学情给出触发条件**，详案照此写：

| 档 | 发什么 | 触发条件（写进详案的原话） |
|---|---|---|
| 词语支架卡 | 分类词库（时间/地点/环境/动作/情感各若干） | 全班通发，贴墙或每人一张 |
| 填空版 | 整段挖空模板 | 「如一年级学生较多，可提供写作模板供学生填写」 |
| 自由写 | 不发 | 已能不看支架说/写完整的学生，直接撤 |

## 二、要素填空支架（基础层）

**做什么**：提供带空格的句式,学生把从图上圈到的要素填进去,保证句子完整。

**卡片形制**（示例·三素句）:
```
看图填一填：
（　谁　）在（　哪里　）（　做什么　）。
例：小狗 在 草地上 睡觉。
```
四要素版加时间:
```
（什么时候），（谁）在（哪里）（做什么）。
```

**使用要点**：
- 填空来自 `picture-reading` 第1步圈的形象、第3步的关系,不是凭空。
- 空格数=当前训练点要素数,不多给。三素句就三空,别塞时间。
- 学生填完读一遍通不通顺,不通顺调语序——这是"写完整"的达标线。

**撤架信号**：学生不看空格也能说出完整句 → 撤填空,只给要素词卡。

## 三、细节拓展支架（进阶层）

**做什么**：在完整句基础上,标注图中关键信息(人物表情、环境元素),提示学生把句子**写具体**。

**卡片形制**（示例·把句子写具体）:
```
先写完整：小狗在草地上睡觉。
再加细节，选1~2项加进去：
  □ 什么样的？（小狗→懒洋洋的小狗）
  □ 怎么做的？（睡觉→舒服地睡觉）
  □ 周围有什么？（草地上→开满小花的草地上）
升格后：懒洋洋的小狗在开满小花的草地上舒服地睡觉。
```

**使用要点**：
- 细节项直接对应 `picture-reading` 第2步圈出的形象细节和环境细节。
- 一次加 1~2 项即可,不要求全加——避免句子臃肿、避免"好词堆砌"同质化。
- 加的细节必须图上有(或合理),不虚构画面没有的东西(承接不虚构原则)。

**撤架信号**：学生主动加细节 → 撤提示项,只提醒"能不能更具体"。

## 四、问题启发支架（创意层）

**做什么**：用问题链启发,让学生写出画面外的想象、心里话、独特视角,写出个性。

**卡片形制**（示例）:
```
故事更有意思，想一想：
  · 这之前发生了什么？（起因）
  · 接下来会怎么样？（后续）
  · 他心里在想什么？（心里话）
  · 如果你是他，你会怎么做？（视角）
挑1~2个问题，把想到的写下来。
```

**使用要点**：
- 问题对应 `picture-reading` 第4步"想画外"。
- 想象内容写话时**单独成段或明示**(我猜/他可能在想),不与画面事实混（承接 image-spec 规则）。
- 鼓励不同学生写出不同版本——这正是期12「同图多解」的落点(该期官方依据已核准)。

**撤架信号**：学生自发联想 → 完全撤架,放手写。

## 五、句式库（句式迁移支架 · 横切三层）

**做什么**：提供可迁移的句式模板,学生换内容套用,快速积累"会写的句型"。源自句式迁移法(姚颖 2026)。句式库不独立成层,而是三层通用的"零件库"。

### 基础句式（配基础层）
- 谁 + 在哪里 + 做什么
- 什么时候 + 谁 + 在哪里 + 做什么
- （官方锚:一下园地六「谁怎么样地在什么地方干什么」）

### 铺陈句式（配进阶层）
- 有的……有的……有的……（写一群/多个对象,论文示范句式）
- 一边……一边……（写同时的动作）
- ……的……（形容词+名词,把对象写具体）

### 连接句式（配多图/叙事）
- 先……接着……然后……最后……（多图顺序,官方锚:一下园地五、二上园地三顺序词）
- 因为……所以……（写理由,官方锚:二下园地七想养小动物）
- 没想到……（写转折,对应期16）

### 想象句式（配创意层）
- 他心里想：“……”（心里话,官方锚:一下园地八心情词、二上园地七）
- 好像……（比喻联想,对应期20）

> **用法**：句式库是"给学生选的菜单",不是"必须用的清单"。一节课点 1~2 个句式练透,不铺开。句式迁移的目的是降低起步难度,熟练后要脱离句式自由表达,避免全班句子一个模子(同质化防线)。

## 六、三层支架与课型的配合

- **方法课**：教新方法时,先示范基础层支架,再演示如何升格到进阶层。创意层作为"挑战任务"给学有余力者。
- **练习课**：三层支架同时提供,学生按自己程度取用;评改升格节重点是帮基础层学生够到进阶层。
- **综合课**：撤大部分支架,只留句式库备查,检验学生能否独立完成。

> 支架的终点是**不用支架**。每个能力点,从满支架→半支架→无支架,是一个期次内或跨期次的撤架过程。详案设计时须标明本课支架发到哪一层、哪些该撤。
