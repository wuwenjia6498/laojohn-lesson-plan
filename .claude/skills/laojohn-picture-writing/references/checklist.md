# 交付前自检清单（checklist）

逐项核验，未过即返工。**带 ★ 的为本技能特有红线，优先核。**

## ★ 图位规格门禁类
- [ ] ★ 每个用图位是否都先有《图位规格书》？正文无「裸引用图」（出现“如图”却无对应规格）？
- [ ] ★ **例文 vs 规格清单 越清单核查**：把下水例文逐句拆开，每个具体画面细节都能在锚图规格的「必须可见元素清单」中定位？定位不到的 → 删除，或移入“合理想象”段并明示。
- [ ] ★ 圈画指令/观察问题是否都指向规格清单内真实声明的元素？没有“圈出规格里没有的东西”。
- [ ] ★ 每个图位是否声明了「承担训练点」，且画面据此包含可教元素（如「细节四问」课含可圈画细节）？未做到 → 该图“干净但教学贫乏”，返工补元素要求。
- [ ] ★ 推断不唯一处（季节/关系/时段）是否用多解口吻，未替学生强行定论？
- [ ] ★ **画面季节/时令与开课学期一致**：图中人物衣着与景物须匹配本课实际开课时间（如一上（秋）第 1 次＝初秋九月 → 短袖/薄长袖，不出现毛衣、围巾、厚外套、满树黄叶、雪）。季节口径写进工单区、对全图统一声明。
- [ ] ★ **画面人物完整性**：每个出现的孩子**头部完整可见**，不被书本/家具/画框边缘遮挡或裁切成“无头”——低龄学生会当场追问、干扰教学。
- [ ] ★ **画面人物族裔＝中国/东亚儿童**：每个孩子须**黑发、黑眼、东亚面孔、黄种人肤色**（模型默认画成西方浅发白人，须在提示词与清单/验收里正面写死，连“黑色短发”颜色词也要写）。**机器验收判不出族裔/发色，锚图务必人工再看一眼。**
- [ ] ★ 文末「生图工单」区开头是否写入「⚠ 回插前逐项验收」提示？工单本身是否汇总齐全？（**提示写在工单区、不占第一页**——老师翻开第一页该看见教学内容，不是生产流程说明；同理「提升点类型」「真实性口径」等给生成方看的字段一律下沉文末自检）
- [ ] ★ **两附录区已包注释**：「附：生图工单」「附：真实性自检」两区是否各自整体包进 `<!-- ... -->`（`<!--`/`-->` 独立成行、区内无 `-->` 字样）？「附：本课支架与说写格式小提醒」是否**未被误包**（它是唯一进 docx 的附录）？正文是否无「详录见文末真实性自检」这类指向注释区的悬空转引？

## 阶段与一课一得
- [ ] 训练点锁定本课 1 项，未提前引入更高阶技法（如「四要素」课误讲心理描写）？**详案正文/首页/预告无「期N」「模块」旧口径字样**（期号仅内部用，对外一律「学期＋课次＋方法名」）。
- [ ] 一二年级（L1–L2 学段）避免术语，但**方法叫法与环节称呼都平实直说**——检索「胖句子/加料/变身/魔法卡片/小秘密/**侦探**/**段子**」应为零（“小侦探/破案/找线索”式包装 2026-07-20 起一并禁用；“段子”现今几乎只作“笑话”讲、2026-07-23 起禁用，改说“这段话”）；保留的低龄亲切仅限「心里话」、画面生动描写与拟声词（详见 SKILL「语言风格」条）？

## 结构与时长
- [ ] 两节连排、各 45 分钟、环节时长均为 5 的倍数且每节合计 45？
- [ ] 说/写/评三段齐全？先说后写？**（M0 纯口头课免「写」，见 `lesson-structure.md` §1 豁免条款；但「说」「评」不得免，且须有口头过关判定与人人开口机制——豁免只免书面、不免评价。）**
- [ ] 写话格式小提醒（空两格/标点不顶格/生字拼音）本课已呈现？**（M0 豁免；M0 讲书写格式属越阶。）**

## ★ 教学厚度（治「合规但空」——一上第 1 次（会看）首稿曾整环节零师话、三张图零追问）
- [ ] **师话密度**：每个 ≥5 分钟的环节是否**至少有 1 句 `师：`**？占时最长的环节是不是师话最少的那个？（逐字稿的价值在于老师能照着上，环节只写 bullet 指令＝把最难的现场应对留白了）
- [ ] **图位不闲置**：每个用图位在正文是否**至少有 1 条追问或 1 条 `参考：`**？只有「依次出示例-0X」这类指令的图＝图片墙，返工。
- [ ] **每图追问点不重复**：多图练说时，各图是否用了**不同的追问点**（如两人图练「谁」怎么说全、动物图练「不是人也能说三素句」、群像图练「怎么选主角」）？全图同问＝浪费规格。
- [ ] **错答应答**：`参考：` 是否**至少 2 处**给出学生说偏/说不全时的教师应答话术（如只说人不说地点、把「在哪里」答成「在她家」、答非所问），而非清一色理想答案？
- [ ] **训练点教了要练**：提纲表「教学内容」行列出的**每一个**训练点，正文是否都有对应的**学生练习动作**？（只在师话里说了方法、后续没让学生用过 = 教而未练，返工）
- [ ] **分层是设计不是标签**：课内分层是否**至少 1 处**落成三手柄之一——不同支架／不同任务／不同图（见 `scaffold-cards.md` §一「分层是设计，不是标签」）？「程度好的可以说得更具体一点」这类无当堂动作的写法＝标签，不算。
- [ ] **分层不写年级指向**：分层任务是否写成了学情条件而非年级？检索「二年级孩子」「一年级孩子换」应为零——同一份详案只服务一个年级，写年级会让人误以为教室里坐着两个学段（二年级插班生走独立衔接课，见 `SKILL.md`「衔接课」节）。
- [ ] **详案正文无年级档括注**：检索「〔L1〕」「〔L2〕」应为**零**。年级档是课次属性（由排期学期唯一确定，见 `course-map.md` §五），不进正文；提纲表「课次·课型」行只写学段学期，不写「L1 档／L2 档」标注。
- [ ] **支架声明**：本课支架**发到哪一层、哪些该撤**是否已显式写明？**声明只发基础层的课次，其分层必须落在「不同任务／不同图」上**——发了本课训练点之外的层＝越阶（如一上「会看」课发细节拓展支架＝提前上二上「细节四问」），见 `scaffold-cards.md` §一越阶闸门。
- [ ] **评价可判定**：评价三级（基础/良好/优秀）是否配了「不算过关/算过关/加分」对照例句（§10.2）？**每一处分层任务是否交代了达标线落在哪一档**（如「换任务的孩子以『加分』为达标线」），而不是派了任务却不说怎么算完成？点评环节是否给了**至少 2 条可照读的夸奖句**（§10.1），而非只写维度名？
- [ ] **课后延伸**：是否有一条轻量课后动作（家校说图/积累本，§11）？
- [ ] **决策批注（双向查）**：非显然的教学决策（顺序、取舍、为何不讲某点）是否用 `（注：…）` 写明理由（§12）？反向查超量：`（注：` 计数 **≤3/课时**、每条一句话；全文检索"原配""拆出""规格核查"应零（修订留痕与生成侧自检不入正文，§12）。

## 话术与产出
- [ ] 固定话术骨架在位（师：/参考：/引导句式：/（教师总结）/（本课完））？
- [ ] **并列教学点无句式模具**：教多个并列点（四问/四要素等）的段落，各点引出句**两两不同构**、无“第N问：X”式逐条清单推进；性质相近的点有合并带过的转折过渡（做法见 `lesson-structure.md` §13.1，示例禁逐字复用）？
- [ ] **对仗式总结句 ≤1 句/课**：全课“前半否定/后半肯定”式工整对句逐句摘出，除与提示卡呼应的核心口诀一句（多处复现算一句）外应为**零**，其余总结已是不对仗大白话（§13.2）？
- [ ] **破折号限密**：师生对话区检索“——”逐处归类，“抛词——解释”式**约一半已改句号短句**，留下的均属真转折/语气留白/枚举三类（§13.3；表格、`（注：…）`、生图工单等书面区豁免；按判断执行，计数只作筛查线索）？
- [ ] **`参考：`含粗糙口语档且链条接上**：`参考：` 中**至少 2 处**为本年级粗糙短口语口吻（口吻基准＝〔应答·…〕段学生话），且凡粗糙答案不完整、后续教学依赖完整信息处，教师话轮紧跟追问/补全；另保留部分完整答案作理想参照（§13.4；与「★ 教学厚度」组“错答应答”条分工：那条查**有没有**错答应答话术，本条查**答案口吻与链条**，两条不互删）？
- [ ] **术语已换教研通用词**：`贴图/说话句/心里话/圈图` 等机构自造简写按 `terminology.md` 换成通用词（`说话句/心里话` 分语境：书面标注用「语言/心理描写」、口头问学生用「他会说什么/心里想什么」，两者并存正确）；发现表外新自造词已就地改并考虑是否入表（§13.5）？
- [ ] **软规则已落地（补主语/序号/自造表述）**：缺主语像系统提示的指令句已补（「一个一个来」→「我们一个个来」）、圈画流程「第一圈/第二圈」已改「首先/接下来」（清点用数字如「四问都到齐了」保留）、读不懂的自造短语（如「多看见一点」）已换通用说法或补解释（§13.6–§13.8）？
- [ ] **改写后防改过头四查（缺一即返工，与上面的补足规则互相制衡；「四查」与教学术语「细节四问」无关，勿混）**：①通读教师话轮，句子长短**仍有起伏**（全部被拉长/句长趋齐＝失败，回退一部分）；②学生话轮〔应答·…〕**仍保持不完整、不精确**（被润色/补足＝失败）；③**未出现原稿没有的对仗句、四字词堆叠**（顺手写出的「既…又…」删掉）；④随机挑三段读出声，**像一个真人站在二年级教室里说话**。（每处独立判断、禁全文批量替换；每处增字不超原句一倍；下水例文不适用口语规则。§13.9）？
- [ ] ★ **正文占位标记与工单双向零缺口**：每个图位在正文出现处都写了 `【图位:编号】`（叙述式的「出示例-01」不算，脚本按此标记定位回插，缺了回插即插 0 张）；反之工单每个规格都被正文引用过。**机检**：`PYTHONUTF8=1 python scripts/imgspec_parser.py <详案.md>`，「正文引用但工单缺规格」与「工单有但正文未引用」两行须均为「无」。同一行连列多个占位（如例-02/03/04）合法。
- [ ] ★ **占位标记独占一段**：`【图位:编号】` 所在段落不与师话/指令同段（回插脚本会把标记换成图；标记与正文同段时脚本虽已保住文字，但图会被挤到下一段、版式不可控）。写法：先写师话一段，占位标记另起一段。
- [ ] **教室无黑板/白板、不写墙面张贴**：检索「黑板/板书/白板/**墙面张贴**」应为零。结构条、句式条等常驻支架一律做成**每人一张小卡**（卡在学生手上，教师口头归拢）——借用/共用教室墙面不可控，张贴不能普遍实现。
- [ ] **标题体例合规（`title-naming.md`）**：H1 总标题无「第N次/详案/方法课」字样、无《》（抽象术语已加 `——副题`）；紧跟一行 `###### <学期>· 第 N 次 · <课型> · 看图写话详案`（课型用现行五类名、含「回顾课」，与文件名逐字对应，**尾缀不可改、此行不可省**——`style_front_page.py` 靠它判型）；两个课时标题为 `## 第N课时 · …`（**全角间隔号**、非竖线），第1课时点新方法、第2课时收束到「写下来/改」（纯口头课收束到「讲」），两句式不重复？
- [ ] 命名与输出目录合规？
