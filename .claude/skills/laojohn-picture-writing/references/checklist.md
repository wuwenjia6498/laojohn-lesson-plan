# 交付前自检清单（checklist）

逐项核验，未过即返工。**带 ★ 的为本技能特有红线，优先核。**

## ★ 图位规格门禁类
- [ ] ★ 每个用图位是否都先有《图位规格书》？正文无「裸引用图」（出现“如图”却无对应规格）？
- [ ] ★ **例文 vs 规格清单 越清单核查**：把下水例文逐句拆开，每个具体画面细节都能在锚图规格的「必须可见元素清单」中定位？定位不到的 → 删除，或移入“合理想象”段并明示。
- [ ] ★ 圈画指令/观察问题是否都指向规格清单内真实声明的元素？没有“圈出规格里没有的东西”。
- [ ] ★ 每个图位是否声明了「承担训练点」，且画面据此包含可教元素（如三期含可圈画细节）？未做到 → 该图“干净但教学贫乏”，返工补元素要求。
- [ ] ★ 推断不唯一处（季节/关系/时段）是否用多解口吻，未替学生强行定论？
- [ ] ★ 详案头部是否写入「⚠ 待生图回插 + 按清单验收」提示？文末是否有「生图工单」汇总？

## 模块/阶段与一课一得
- [ ] 训练点锁定本期所在**模块/难度档** 1 项，未提前引入更高阶技法（如 M1 起步误讲时间/三段式、M1 进阶误讲心理描写）？
- [ ] **前置依赖守住**：M4 四格创意（缺图补全/同图多解）确认排在 M3 多图叙事之后，未把四格创意前移？
- [ ] **课标依据可追溯**：本期 meta 的 `课标依据` 与 `competency-matrix.md` 一致、能挂靠到具体课标条目？
- [ ] **标点专项（M5）**：若为标点/叠词专项期，是否只练四种基础标点/积累词语、未越阶引高阶标点或堆砌辞藻？

## 语言风格（适龄亲切 · 去重型游戏化，见 SKILL「语言风格」条）
- [ ] **方法叫法平实直说**：要素＝「重点/要素」非“小秘密”；把句子写好＝「写完整/写具体」非“句子胖起来/像吃饱了”；支架＝「词语卡」非“魔法卡片”；三期加细节＝「加细节/写生动」非“加料/变身”？
- [ ] **无游戏旁白与啰嗦安抚**：无“站好队/破案啦”这类游戏旁白；不反复情绪安抚（“别怕/别着急/没关系”式，个别学生当堂卡住的临场安抚除外）；师话精简不啰嗦？
- [ ] **保留项仍在、未误删**：环节亲切称呼（“小侦探”）、“心里话”、画面生动描写与拟声词（“太阳钻出云”等）、固定话术骨架原样？

## 结构与时长
- [ ] **课型与时长匹配**：默认两节连排、各 45 分钟、环节 5 的倍数且每节合计 45；**仅 M5 用词与标点专项可单节/微课**（按期卡 `课型`），不把专项硬套两节连排？
- [ ] 说/写/评三段齐全？先说后写？
- [ ] 写话格式小提醒（空两格/标点不顶格/生字拼音）本课已呈现？

## 下水例文
- [ ] 标 `【教师下水例文 · 示范】`，未冒充学生/名家？
- [ ] 分段批注与本期写法对应（如 M1 进阶三段式：时间/细节/心情；M3 多图：起因/经过/经过/结果）？

## 话术与产出
- [ ] 固定话术骨架在位（师：/参考：/引导句式：/（教师总结）/（本课完））？
- [ ] 正文图位占位标记规范（【图位:编号 — 见生图工单】）？命名与输出目录合规？

## ★ 回插终检（交付后由用户在生图回插时执行，SKILL 在头部提示）

**两种路径，验收红线一致——每张真图都须过「必须可见元素清单」：**

手工生图回插：
- [ ] ★ 每张生成的真图按对应规格「必须可见元素清单」逐项验收，无缺项？
- [ ] ★ 缺项时已重做图或回改详案，确保「真图 = 规格 = 正文」三者一致？

自动生图闭环（跑 `scripts/` 生图+验收+回插，见 SKILL「自动生图闭环」节）：
- [ ] ★ `图位\_验收报告.md` 中**锚图**全部「✅ 过」？标「⚠ 需人工」的锚图已人工重生或回改？
- [ ] ★ **人工最终抽查**锚图（自动验收对"只有一个小孩""季节=春"等隐性约束判定偏弱，不可全托给视觉模型）？
- [ ] ★ 例库图缺项告警已扫一遍（不拦交付，但明显不符的换图）？
- [ ] ★ 未把生成图当事实——没有反向用图去改写正文/规格的情节·数字（生成图服从规格，非反之）？
