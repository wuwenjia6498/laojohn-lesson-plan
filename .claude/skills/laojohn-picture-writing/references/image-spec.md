# 图位规格书 schema（image-spec）

每个用图位先出规格、再写正文。规格一物两用：上半段是可直接喂生图工具的**提示词**，下半段是用户拿回图后的**验收勾选表**。三种角色详略不同。

> 注：本文件「必须可见元素清单」是**生产/验收**视角（图必须画出什么）；引导学生**读图圈画**的五要素/找变化是**教学**视角,见 `picture-reading.md`,勿混。

---


## 通用画面约束（全期全图适用，写进工单区开头统一声明）

以下两条与训练点无关、但错了就毁课，**每期工单区开头都要写一遍**，并在各图提示词里落实：

1. **季节/时令须与该期实际开课时间一致**。图里的衣着与景物是学生眼中的"现在"，与开课季节对不上会当场违和。按 `course-map.md` 该期的「建议学期」推开课时间，再定衣着与景物：
   - 一上（秋）第 1～2 期 ＝ **初秋九月** → 短袖或薄长袖；**不出现毛衣、厚外套、围巾、帽子**；户外草木仍绿、可有少量微黄，不画满树黄叶/落叶堆/雪。
   - 一下（春）→ 春装、新绿；二上（秋）→ 同初秋口径；涉及冬季期次才可上厚衣。
   - 若某期训练点本身要教"从衣着看季节"（如四要素·时间），则季节由训练点定，但仍须在规格里写死是哪一季，不许含糊。
2. **人物完整性**：画面中每个出现的人（尤其孩子）**头部完整可见**，不被书本、家具、画框边缘遮挡或裁切成"无头"。低龄学生会当场追问"他的头呢"，整节课的注意力就散了。群像图尤其要写死这一条。

> 两条都属**验收硬项**：锚图写进「必须可见元素清单」，例库图写进「验收」字段——否则视觉验收模型不会主动检查（曾出图：教室群像里前排孩子只见手与书、无头；秋季第一课人物却穿毛衣戴围巾）。

**写提示词的实测经验（2026-07-20 五图重生一轮得出）：**

- **"初秋/秋天"必被画成深秋红黄落叶。** 只写季节名没用，要**正面写景物状态 + 反面列禁止项**：「窗外树木一律翠绿茂盛，**严禁出现黄叶、红叶、枫叶、飘落的树叶**」。同理"不穿毛衣"要连"不穿外套/不戴围巾"一起写死。
- **"书本不要遮住脸"这类否定式约束，模型执行率低**；改成**正面规定姿态**更可靠：与其写「书本拿在胸前偏下、不遮脸」，不如写「**书本平摊放在课桌桌面上**，孩子低头看书，整张脸完整露出」。**能用姿态/构图规定的，就不要用禁令**。
- **重生会丢掉上一版里"没写进规格但正文用到"的元素**（例-01 重生后小猫消失，而正文备了"孩子答成妈妈或小猫"的应答话术）。**凡正文话术依赖的画面元素，必须写进该图的清单/验收字段**，否则一次重生就落空。
- **模型爱在背景里加英文招牌**（曾出 "HAPPY KITCHEN"、墙上 "September" 月份牌）。中文低年级用图**一律写死"不出现任何英文单词、字母或文字招牌"**，否则学生会追问"那是什么字"。此条已进上面的通用约束。
- **颜色词别用带歧义的复合词**：写「草地为鲜嫩的**黄绿**到翠绿」，模型会抓住"黄"字画出一整片柠檬黄草坪。改成「新鲜的青绿色草坪（**严禁明黄、柠檬黄、枯黄**）」才稳。凡颜色要求，正面给一个明确色名 + 反面列出不要的邻近色。
- **画风不靠形容词、靠参考图（★ 全期统一画风的唯一可靠办法）**：纯文字描述控不住画风——同一句「低龄儿童绘本插画风」，在锚图题材上出柔和手绘，在群像题材上就出粗描边矢量卡通；写「水彩淡彩」得到水彩晕染，改「数字彩绘·线条清晰·边缘利落」又得到扁平卡通，把形容词全删只留锚图原句也没变。**正解：例库图一律带本期锚图作参考图生成（图生图）**，`generate_images.py` 已内置——自动定位本期锚图 png，随提示词一起传给模型并附「只改画面内容、严格沿用参考图画风」的指令，日志显示「（沿用锚图画风）」。由此：**锚图定调 → 例库图跟随**，五张图线条、上色、人物画法、留白自动同源。锚图本身不带参考图（它就是基准）。
- **"脸完整可见"要连"不许背影"一起写**：只写"头部完整可见"，模型会给一个后脑勺——头确实完整，脸却没了。写法：「侧身或半侧身面向观者、能清楚看到脸（**严禁只画背影/后脑勺**）」。
- **机器验收判不出这几类**（季节、遮脸、背影、画面英文、构图关系都曾判过），故 `--verify-only` 通过 ≠ 可交付，**锚图与群像图必须人工再看一眼**。实测一轮五图：机器 5/5 全过，人工看出 2 图不合格。

## A. 锚图 · 完整规格（圈画/四要素/例文所锚）

```imgspec
编号: 锚-01
角色: 锚图
环节: 第4课 写一写·三段式（例文与圈画均锚此图）
承担训练点: 四要素圈画 + 三段式例文取材；须含可圈画的「时间线索」与「主角动作」

生图提示词（可直接复制喂工具）:
  一个阳光明媚的春天，公园草地上一只小狗舒服地躺着，一只小黄鸟站在小狗的前腿上读一本打开的书；
  大树下，绿草地开着白色小花，枝叶繁茂；暖色调、横构图、低龄儿童绘本插画风，画面干净、主角清晰。

必须可见元素清单（验收用，缺一即不合格，正文/例文只能引用本清单）:
  □ 一只小狗（躺姿，靠近观者）
  □ 一只小黄鸟（站姿，立于小狗前腿/身上，作读书状）
  □ 一本打开的书
  □ 一棵大树
  □ 绿草地
  □ 白色小花（地面，可圈画的环境细节）
  □ 季节线索 = 春（枝繁叶茂 / 花开，供推断时间用）

允许但不强制（仅作点缀，不得写进例文为事实）: 蝴蝶、远处长椅、云

风格/比例: 低龄绘本插画、暖色、横版 4:3
```

> 正文里第二段「环境描写」只能写到草地、白花、大树、春；动作只能写小狗躺、小黄鸟读——全部落在清单内。对话、心里话属想象，单独成段并明示。

## B. 例库图 · 轻规格（练说用，不进例文，可替换）

```imgspec
编号: 例-03
角色: 例库图
环节: 第3课 三素句练习（教师轮流出示，学生练说）
支持句式: 谁 + 在哪里 + 做什么
一句话画面: 一群小动物在森林里开音乐会。
生图提示词: 森林空地上，几只小动物（如小熊、小兔、小狐狸）拿着乐器演奏，欢快、低龄绘本插画风。
验收: 画面能支撑“一群小动物 / 在森林里 / 开音乐会”即可，不要求具体到某只动物。
```

> 例库图不做逐细节核查——它只服务“能否说出某个句式的句子”，不承担例文对应责任。一节课的多张练习图各出一条轻规格即可，不必逐张建完整清单。

## 组图（第四/五期四格锚图）

四格作为**一个锚图组**，编号 `锚-01-1 … 锚-01-4`，每格出一份完整规格，并额外标注**格间变化**（本格相对上一格新增/改变了什么），供“起因—经过—结果”教学与一图一段例文使用。**「格间变化」字段设计依据见 `picture-reading.md` 多图找变化三维度（人物活动/地点时间/色彩亮度）——出规格时须确保每格之间至少有一处可圈画的变化,供教学找变化用。**第五期「缺图补全」中被缺的那一格，规格标 `状态: 留白（不生图，由学生想象补出）`，但仍须写出“前后格已定的约束”，确保学生补的内容能接得上。

## 文末「生图工单」汇总格式

详案正文用占位标记 `【图位:锚-01 — 见生图工单】`；文末集中列出全部 imgspec 块，按 锚图→例库图→格式图 排序，方便用户整段复制喂工具、逐图验收。
