# 图位规格书 schema（image-spec）

每个用图位先出规格、再写正文。规格一物两用：上半段是可直接喂生图工具的**提示词**，下半段是用户拿回图后的**验收勾选表**。三种角色详略不同。

> 注：本文件「必须可见元素清单」是**生产/验收**视角（图必须画出什么）；引导学生**读图圈画**的五要素/找变化是**教学**视角,见 `picture-reading.md`,勿混。

---


## 通用画面约束（全课次全图适用，写进工单区开头统一声明）

以下三条与训练点无关、但错了就毁课，**每期工单区开头都要写一遍**，并在各图提示词里落实：

1. **季节/时令须与本课实际开课时间一致**。图里的衣着与景物是学生眼中的"现在"，与开课季节对不上会当场违和。按 `course-map.md` §四该课次所在学期与次序推开课时间，再定衣着与景物：
   - 一上（秋）开学初的头几次课 ＝ **初秋九月** → 短袖或薄长袖；**不出现毛衣、厚外套、围巾、帽子**；户外草木仍绿、可有少量微黄，不画满树黄叶/落叶堆/雪。
   - 一下（春）→ 春装、新绿；二上（秋）→ 同初秋口径；涉及冬季课次才可上厚衣。
   - 若本课训练点本身要教"从衣着看季节"（如四要素·时间），则季节由训练点定，但仍须在规格里写死是哪一季，不许含糊。
2. **人物完整性**：画面中每个出现的人（尤其孩子）**头部完整可见**，不被书本、家具、画框边缘遮挡或裁切成"无头"。低龄学生会当场追问"他的头呢"，整节课的注意力就散了。群像图尤其要写死这一条。
3. **人物族裔＝中国／东亚儿童**（★ 2026-07-23 期6 练习课得出）：画面中的孩子一律**黑色头发、黑色眼睛、东亚面孔、黄种人肤色**，**不要金发/棕发/浅色头发、不要蓝眼绿眼、不要欧美白人或其他族裔长相**。这是中国低年级课堂用图，学生要在画中人身上认出"和我一样的小朋友"；**模型默认会把儿童画成西方浅发白人，必须在每张有人物的图里正面写死**（连"黑色短发"这种颜色词也要写进发型描述，只写"短发"会出浅棕发）。

> 三条都属**验收硬项**：主图写进「必须可见元素清单」，备选图写进「验收」字段——否则视觉验收模型不会主动检查（曾出图：教室群像里前排孩子只见手与书、无头；秋季第一课人物却穿毛衣戴围巾；放风筝男孩画成金发西方小孩）。

**写提示词的实测经验（2026-07-20 五图重生一轮得出）：**

- **"初秋/秋天"必被画成深秋红黄落叶。** 只写季节名没用，要**正面写景物状态 + 反面列禁止项**：「窗外树木一律翠绿茂盛，**严禁出现黄叶、红叶、枫叶、飘落的树叶**」。同理"不穿毛衣"要连"不穿外套/不戴围巾"一起写死。
- **"书本不要遮住脸"这类否定式约束，模型执行率低**；改成**正面规定姿态**更可靠：与其写「书本拿在胸前偏下、不遮脸」，不如写「**书本平摊放在课桌桌面上**，孩子低头看书，整张脸完整露出」。**能用姿态/构图规定的，就不要用禁令**。
- **上一条更进一步：规定错对象比用禁令更隐蔽（★ 2026-07-22 期1 例-01 得出）**。只规定**结果**、不规定**达成结果的姿态**，模型会用别扭的方式硬凑。实录：例-01 规格写「小女孩侧身或半侧身**面向观者**、能清楚看到脸」——可她正在洗菜、身体正对着水池，模型只能让她**把头大幅扭向观者**，出图脖子拧得很怪。**根因是约束加在了"脸的朝向"上，而该约束的是"身体的朝向"**：改写成「**她的身体侧对着水池站**（不是正对水池），所以脸本来就朝着画面前方、脖子保持自然不扭转」，一次就对。同源案例：「脸上沾着水珠」（结果）→ 画成汗，改规定水的来路与形态才对。**下笔前自问：我写的这一条，模型能不能在"不改变他正在做的动作"的前提下满足？不能，就说明约束加错了对象。**
- **重生会丢掉上一版里"没写进规格但正文用到"的元素**（例-01 重生后小猫消失，而正文备了"孩子答成妈妈或小猫"的应答话术）。**凡正文话术依赖的画面元素，必须写进该图的清单/验收字段**，否则一次重生就落空。
- **上一条不只管"画面里有什么物件"，人物形态·动作姿态·光影同样适用（★ 2026-07-21 期6 主图四版迭代得出）**：碰巧生成对、却没写进规格的东西，下一次重生一定丢。期6 锚-01 迭代实录——v2 的小狗甩头（耳朵外张＋甩动弧线）与圆脸小男孩画得很好但规格没写，v3 修水珠时双双丢失（狗变成正面站立不动、男孩变成板寸皱眉的成人脸）；直到 v4 把两代各自做对的地方**逐条写死**（男孩：圆脸有肉／柔软蓬松短发·不要板寸光头／眉眼舒展弯月牙·不要皱眉挤五官；小狗：头猛甩向一侧·两耳外张·头周围带甩动弧线·不要正面站着不动）才一次收敛。**每轮重生前，先把这一版看着好的地方补进规格再动手**，否则会在"修好 A 丢掉 B、修好 B 丢掉 A"之间空转。
- **"脸上沾着水珠"会被画成汗**（同期实录）：一颗颗独立挂在额头脸颊的圆水滴，配上大笑表情，学生读作出汗。改成**规定水的形态与来路**——"水珠正打在他脸上溅开成小水花、脸颊被溅出湿亮的一片水光，脸旁还有正在飞来的水珠拖着飞溅水痕"，并禁掉"一颗颗独立挂着的圆水滴"，才读得出水是被甩到的。凡"沾/带/有某物"这类静态描述，若该物的**来路**正是教学点，就要把来路画进去（飞行轨迹、溅开的瞬间）。
- **模型爱在背景里加英文招牌**（曾出 "HAPPY KITCHEN"、墙上 "September" 月份牌）。中文低年级用图**一律写死"不出现任何英文单词、字母或文字招牌"**，否则学生会追问"那是什么字"。此条已进上面的通用约束。
- **颜色词别用带歧义的复合词**：写「草地为鲜嫩的**黄绿**到翠绿」，模型会抓住"黄"字画出一整片柠檬黄草坪。改成「新鲜的青绿色草坪（**严禁明黄、柠檬黄、枯黄**）」才稳。凡颜色要求，正面给一个明确色名 + 反面列出不要的邻近色。
- **画风不靠形容词、靠参考图（★ 全期统一画风的唯一可靠办法）**：纯文字描述控不住画风——同一句「低龄儿童绘本插画风」，在主图题材上出柔和手绘，在群像题材上就出粗描边矢量卡通；写「水彩淡彩」得到水彩晕染，改「数字彩绘·线条清晰·边缘利落」又得到扁平卡通，把形容词全删只留主图原句也没变。**正解：备选图一律带本课主图作参考图生成（图生图）**，`generate_images.py` 已内置——自动定位本课主图 png，随提示词一起传给模型并附「只改画面内容、严格沿用参考图画风」的指令，日志显示「（沿用主图画风）」。由此：**主图定调 → 备选图跟随**，五张图线条、上色、人物画法、留白自动同源。主图本身不带参考图（它就是基准）。
- **"脸完整可见"要连"不许背影"一起写**：只写"头部完整可见"，模型会给一个后脑勺——头确实完整，脸却没了。写法：「侧身或半侧身面向观者、能清楚看到脸（**严禁只画背影/后脑勺**）」。**但人物正在做的事若让他背对/侧对观者（洗菜、面朝黑板、伏案写字），别停在这句上**——按上面「规定错对象」那条，改去规定**身体怎么站**，让脸自然朝前，否则会拧出一个扭脖子的姿势。
- **数量约束要锁总数 + 锁位置 + 禁别处出现**（★ 2026-07-22 期1 锚-01）：只写「他身侧开着 3 朵小黄花」，出图是左侧一丛 4 朵＋脚边 1 朵、共 5 朵分两处，而正文第2课要当堂数「一共几朵」。写法：「**整幅画面里一共只有 3 朵小黄花，全部长在男孩身侧的同一小片草地上，彼此分开、互不重叠**；**画面其他任何地方都不许再出现黄色的花**」。凡"可数"的教学元素（几朵花、几个人、几只动物），三件都要写。
- **物件的"种类/形状"是教学锚点时，要正面写清＋列出会混的近亲禁掉**（★ 2026-07-23 期6 练习课 例-01）：只写「踢足球／一只足球」，模型出了**橄榄球**（椭圆美式足球），而正文让学生看这张图写"踢球"的动作。同类：写"球"可能出各种球，写"帽子"可能出各种帽。写法＝正例定死＋负例排除：「**一只普通的圆形黑白相间的足球（白底黑色五边形、圆球形）**，**严禁画成椭圆的橄榄球/美式足球**」。凡该物件的**具体样子**会进圈画/例文/追问，就不能只给品类名，要把形状、配色写死并禁掉最容易混的那一两种。
- **人物年龄要圆脸低龄正面写＋排除大孩子**（同期例-01）：备选图只写"约七八岁"仍被画成十来岁少年——年龄和族裔一样，是模型爱漂移的维度。凡有人物的图（含备选图），把主图那套「圆圆的脸蛋、脸颊有肉、身形小、头身比偏小，不要画成十来岁的少年或成年人脸」也写进去，别只留一个岁数。
- **改"单一属性"时优先图生图编辑、别从零重生**（★ 2026-07-23 期6 锚-01 得出）：一张已经满意的图只需改一处（如把人物族裔从西方改成东亚），**从零 regen 会顺带丢掉上一版画对却难描述的东西**——期6 锚-01 全图 regen 后族裔对了，却把原来"右上方斜射的暖金色晨光＋地面清晰投影"丢成了平光白背景。更稳的办法：**拿那张好图做 img2img 编辑**，提示词写"以这张图为基准，只把 X 改成 Y，其余（尤其光影/构图/某物件）全部原样保留"（`generate_images.py` 的 `_gen_gemini(style_ref=<好图>)` 走的就是图生图通道，但其内置 `_STYLE_REF_INSTR` 是"换内容锁画风"、方向相反，这类"锁一切改一处"的编辑要另写编辑指令、不要套用那段）。光影这类"画对了难用词复现"的氛围，尤其值得用编辑而非重生来保。
- **机器验收判不出这几类**（季节、遮脸、背影、画面英文、构图关系、**数量**、**人物族裔/发色**、**物件种类形状**、**年龄**、**光影氛围**都曾判过），故 `--verify-only` 通过 ≠ 可交付，**主图与群像图必须人工再看一眼**。实测：期1 主图 5 朵花冒充 3 朵、期6 练习课放风筝男孩画成金发西方小孩＋踢的是橄榄球，机器均判「过」，全靠人工挑出。

## 画风令牌（全线统一，勿逐图另写形容词）

**画风不再在每张 `生图提示词` 里各写各的**，改由 `style-tokens.md`（人读文档）／`scripts/imgspec_parser.py` 的 `ANCHOR_STYLE_TOKEN`、`LIBRARY_STYLE_TOKEN` 两个常量（运行时事实源）统一注入：`build_prompt()` 按角色自动在提示词末尾追加对应令牌，主图走 clean 档（优先可读、要素一眼可数可圈）、备选图走 atmos 档（可偏氛围）。

写规格时 `生图提示词` **只写画面内容**——谁、在哪里、做什么、有哪些要素、什么季节；**不要再写「低龄儿童绘本插画风」「暖色调」「画面干净」这类风格形容词**，否则会与全局令牌打架，也会让旧的低级措辞回潮。`风格/比例` 字段可以保留，它写的是比例信息（横版 4:3 等），不是画风。

> 这是上面「画风不靠形容词、靠参考图」那一条的升级、不是推翻：**主图令牌定调 → 备选图图生图跟随**。要调画风，改令牌那两处（且两处同步），别回到逐图写形容词。

## A. 主图 · 完整规格（圈画/四要素/例文所锚）

```imgspec
编号: 锚-01
角色: 主图
环节: 第4课 写一写·三段式（例文与圈画均锚此图）
承担训练点: 四要素圈画 + 三段式例文取材；须含可圈画的「时间线索」与「主角动作」

生图提示词（只写画面内容；画风由令牌统一注入，勿写风格形容词）:
  一个阳光明媚的春天，公园草地上一只小狗舒服地躺着，一只小黄鸟站在小狗的前腿上读一本打开的书；
  大树下，绿草地开着白色小花，枝叶繁茂；横构图。

必须可见元素清单（验收用，缺一即不合格，正文/例文只能引用本清单）:
  □ 一只小狗（躺姿，靠近观者）
  □ 一只小黄鸟（站姿，立于小狗前腿/身上，作读书状）
  □ 一本打开的书
  □ 一棵大树
  □ 绿草地
  □ 白色小花（地面，可圈画的环境细节）
  □ 季节线索 = 春（枝繁叶茂 / 花开，供推断时间用）

允许但不强制（仅作点缀，不得写进例文为事实）: 蝴蝶、远处长椅、云

风格/比例: 横版 4:3（本字段只写比例/构图方向，画风交给令牌）
```

> 正文里第二段「环境描写」只能写到草地、白花、大树、春；动作只能写小狗躺、小黄鸟读——全部落在清单内。对话、心里话属想象，单独成段并明示。

## B. 备选图 · 轻规格（练说用，不进例文，可替换）

```imgspec
编号: 例-03
角色: 备选图
环节: 第3课 三素句练习（教师轮流出示，学生练说）
支持句式: 谁 + 在哪里 + 做什么
一句话画面: 一群小动物在森林里开音乐会。
生图提示词: 森林空地上，几只小动物（如小熊、小兔、小狐狸）拿着乐器演奏，气氛欢快。
验收: 画面能支撑“一群小动物 / 在森林里 / 开音乐会”即可，不要求具体到某只动物。
```

> 备选图不做逐细节核查——它只服务“能否说出某个句式的句子”，不承担例文对应责任。一节课的多张练习图各出一条轻规格即可，不必逐张建完整清单。

## 组图（第四/五期四格主图）

四格作为**一个主图组**，编号 `锚-01-1 … 锚-01-4`，每格出一份完整规格，并额外标注**格间变化**（本格相对上一格新增/改变了什么），供“起因—经过—结果”教学与一图一段例文使用。**「格间变化」字段设计依据见 `picture-reading.md` 多图找变化三维度（人物活动/地点时间/色彩亮度）——出规格时须确保每格之间至少有一处可圈画的变化,供教学找变化用。**第五期「缺图补全」中被缺的那一格，规格标 `状态: 留白（不生图，由学生想象补出）`，但仍须写出“前后格已定的约束”，确保学生补的内容能接得上。

## 文末「生图工单」汇总格式

详案正文用占位标记 `【图位:锚-01 — 见生图工单】`；文末集中列出全部 imgspec 块，按 主图→备选图→格式图 排序，方便用户整段复制喂工具、逐图验收。

**工单区整体包 HTML 注释（2026-07-22 定）**：从 `## 附：生图工单` 标题行起、到最后一个 imgspec 块结束，整区包进 `<!-- ... -->`——`<!--` 与 `-->` 各占独立行，区内容不得出现 `-->` 字样。docx 引擎整块跳过，生图提示词不进老师拿到的 docx；imgspec_parser 全文正则抓 ```imgspec 围栏，注释对它透明。格式：

```
<!--
## 附：生图工单

> ⚠ 回插前逐项验收：…
（全图适用口径 + 各图位 imgspec 块）
-->
```
