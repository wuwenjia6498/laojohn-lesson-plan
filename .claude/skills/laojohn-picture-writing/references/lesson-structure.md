# 看图写话课型骨架与写法要领（lesson-structure）

本文件是看图写话**课型层与教学方法的唯一源**：全部课次共用的课堂结构、各能力点的写法要领（三素句/四要素/圈画法/三段式/细节四方向/多图叙事/创意写话）、取名法、写话格式、评价维度都集中在这里，`ability-ladder.md` 的各方法骨架只引环节名、不复述这些细则。这些是通用看图写话教法，供技能新生成各课次详案时统一调用。

> 语言风格按 SKILL「语言风格」条（去重型游戏化）：方法叫法与环节称呼平实直说（**“小侦探”等比喻性称呼 2026-07-20 起禁用**），保留心里话/拟声词/画面描写/固定话术骨架。本文件已用新口径写定。

## 1. 课型与时长

- **默认课型＝两节连排**，每节 45 分钟；环节时长均为 5 的倍数、每节合计 45。
- **说—写—评三段齐全、先说后写**：任何写话环节都先口头说、再规范写、最后分享评。
- **课型变体（仅纯口头课次）**：一上第 1~4 次（会看/会讲及其练习）为纯口头课，可按机构实情缩至 60 分钟；其余课次一律两节连排 90 分钟（`course-map.md` §三课次形制）。
- **纯口头课次豁免条款**：纯口头课（一上第 1~4 次）只做口头表达、无书面产出，故**免「写」这一段与 §9 写话格式小提醒**（此时讲书写格式属越阶）。但**「说」「评」两段不得免**——必须有独立的评价环节、人人开口机制，以及 §10 的**口头过关判定样例**。豁免只免书面，不免评价；详案不得以「本课纯口头」一句带过评价设计。
- 固定话术骨架（全课次通用）：`师：`（师话）/ `参考：`（参考答案）/ `引导句式：` / `（教师总结）` / 每课末 `（本课完）`。

## 2. 起步档：三素句的口头教学法（分层追问 + 扩句成段）

起步档（三素句）核心是口头说清一幅图，方法在「怎么问、怎么把一句说长一点」。以下两条通用——照片故事、例库图练说、第2课口头练均用。**全程口头**，不写、不引入「时间/四要素/三段式」术语（守起步档 `不可越阶`）。

### 2.1 分层追问链（观察 → 想象 → 心情）

同一幅图/照片，追问不是只问一句「谁/在哪里/做什么」就停，而是按学生反应逐层往下带；**每幅图的追问点不必相同、鼓励说不同**：

1. **字面三素**：谁？在哪里？在做什么？（人人可答，先把话说完整）
2. **抠一处可见细节**：就画面挑一个看得见的点追问——「他脚下是什么？」「他的表情怎样？」「手里拿着什么？」（把「做什么」说清楚一点）。
3. **轻推心情/关系**：据表情、动作、处境问「你觉得他现在什么心情？」「这两个好朋友关系怎么样？」（从看得见推到看不见，但仍由画面引出）。
4. **顺势引一点想象**：借一个画面线索往外想一点——「他可能把花送给谁？在什么情况下？」（明示是「想一想」，不是画上画的）。

- **分层按学情，不按年级**：说不齐三素的学生停在第 1 层，老师口头把缺的那一样补上、请他跟说一遍即可；答得顺的加第 2–3 层；学有余力再到第 4 层。（这是「不同任务」手柄，见 `scaffold-cards.md` §一；不发第二张支架卡，故不越阶。）
- 第 3、4 层的想象/心情只作**口头**延伸，落在「感情拓展句」，不进书面三段式（那是进阶档）。

### 2.2 从一句到一段：扩句成段逐句示范

起步档第2课「说 3–4 句小片段」不是让学生凭空多说，而是**教师先示范、逐句点明每句在做什么**，让学生看见「一句怎么长成一段」。示范把一句三素句扩成小片段，逐句批注：

1. 先说一句**环境/天气的合理想象**（如「天空乌云密布，大雨哗啦啦地下着」——观察＋合理想象）；
2. 再说**三素句核心**（谁在哪里做什么——把主体事情说清）；
3. 接一句「**它/他怎么样**」（神态、样子——把画面说具体）；
4. 收一句**心情感受**（如「它们玩得真开心」——加感受）。

- **先学生说、教师再示范、学生再说一次**（三拍，缺一不可）：
  1. 先请学生自由多说两句（**不先给示范**，否则学生只会复述老师的句子）；
  2. 教师据此示范这条扩句梯子，逐句点明每句在做什么；
  3. **同一个学生照梯子再说一次**，教师追问「跟你刚才那次比，哪里不一样了？」——让学生自己听见进步。
- 第 3 拍是低龄学生建立信心的关键，**不可省**：进步必须是学生自己说出来的，不是老师夸出来的。详案里这三拍要写全，不能只写第 1、2 拍就转下一环节。
- 批注是给老师看的教法提示，不必逐字念给学生。
- 仍是口头扩句，**不分段、不写题目**（分段成篇是进阶档三段式）。

### 2.3 同图三级句子爬梯（升格，区别于 §2.2 的加长）

同一幅图连说三次、一次比一次高一档，让学生看见「同一张图可以说得不一样好」：

1. **基础句**（只说出主体）：「两只小猫在跑。」
2. **三素句**（谁+在哪里+做什么，把话说完整）：「两只小猫在雨里跑。」
3. **感情拓展句**（加一点样子或心情）：「两只小猫举着一块红围巾遮雨，在雨里开心地跑。」

- 与 §2.2 的区别：§2.2 是**把一句加长成一小段**（横向铺开），本条是**同一句话反复升格**（纵向拔高）。起步档两条都用得上，一课选一条主打即可，不必都上。
- 三级只作**口头**对照；停在第 2 级即算过关，第 3 级是加分项（见 §10.2 过关判定）。
- **这三级是「同一句话的升格梯子」，与支架三层、评价三级都不是一回事**——它是教师示范用的话术梯度，既不是分层机制（那是 `scaffold-cards.md` §一的三手柄），也不是判定档名（那是 §10 的基础/良好/优秀）。三者勿混。

## 3. 四要素与圈画四步法

- **四要素＝时间·地点·人物·事件**。三素句（谁/在哪里/做什么）＋「时间」＝四要素。
- **怎么判断「时间」**（低龄最难，故最后圈）：
  1. 看景物：嫩芽=春、荷花=夏、落叶=秋、枝枯=冬。
  2. 看衣着：棉袄=冬、短袖=夏。
  3. 看天空/太阳：阳光灿烂=上午或中午、夕阳西斜=傍晚、月亮=晚上。
  4. 看屋内灯：开灯多为晚上或室内暗。
- **怎么判断「地点」**：看景物特征（绿色田野=乡村/郊外/公园；高楼街道=城市），与生活场景关联（教室/医院/超市…）。
- **怎么判断「人物」**：多角色时分主次——主角优先、多写；次要少写。
- **圈画四步法**：先圈「谁」→ 再圈「在哪里」→ 然后圈「做什么」→ 最后圈「什么时候」。建议做法：把图打印出来，用铅笔逐步圈。

## 4. 三段式写话要领

配田字格例文边写边讲：
1. **题目**：写在第一行正中间。一般「在干什么就写什么」（如《雨后菜地》）。
2. **第一段**：什么时候，谁在哪里干什么。**只用两个标点**——写完时间马上写逗号，整句末尾写句号。
3. **第二段**（最重要，抓图片细节）：从两方面入手——
   - 环境描写：观察图中景象，用五感写（看到什么、想象的声音/气味），能力强的可写想象中的感觉。
   - 主角动作：直接写谁在干什么。
4. **第三段**：心情、感受、领悟的道理、适当想象。

## 5. 细节四方向（二上「细节四方向」起用）

- 四方向＝**动作 / 表情 / 语言 / 心理（心里话）**。
- 教法：先出「平淡句 vs 生动句」对比句直观感受，再以一原句逐步**加细节**——加动作→加表情→加语言→加心理（平实说「加细节/写生动」，不叫「加料/变身」）。
- 想象类细节（语言/心理）须从画面合理引出，不得编造画面没有的物件。

## 6. 多图叙事要领（叙事线多图课次：两图串联/四图故事/对话推进/转折/多图综合）

把多幅图连成一件事：
1. **起因—经过—结果 三步**：起因（图1）＝事情由来与困难；经过（图2–3）＝怎么做、加对话与心理；结果（图4）＝结局与心情/想象。
2. **五问理线**（看图先想清）：主角是谁？想做什么？遇到什么困难？谁来帮、怎么帮？最后怎样、心情如何？
3. **三要点**：① 一图一段、整篇≥四段；② 细节写具体（神态、动作）；③ 合理想象（把故事写完整，或写出道理）。
4. **目标感**：写得「像看一场电影」——有画面、动作、声音、心情。
5. **互读互评**：同桌互换读，评是否讲清各图、最喜欢哪段、可加什么动作或对话。

## 7. 创意写话要领（想象线课次：补对话/心里话/缺图补全/同图多解）

- **缺图补全三步法**：看前图找「起因」→ 看后图猜「结果」→ 想中间补「经过」（谁出现、做了什么、有没有对话/动作/表情/心理）；补出的中间段要上接下连。
- **同图多解**：同一组图，每人可写完全不同的版本——写清动作、加一点对话、写出心里话、说出感受或想法（如「把它当成了什么」）。
- **个性表达**：分享点评重点放在**对情节的不同想象**，肯定「同画面多版本」，不评「标准答案」。

## 8. 取名两法（给主角取名，便于表达）

1. 参考同学/朋友的名字稍作改动（如 张宇轩、李小多）。
2. 取一个有趣、有特点的名字（如 丁咚、小年糕）。

## 9. 写话格式小提醒（每课必呈现）

「写话小提醒」（每人一张小卡或投屏，**不写板书**——教室无黑板白板）：
- 开头空两格；
- 一句话没结束写逗号，结束写句号（或问号、感叹号）；
- 标点符号不顶格写；
- 不会写的字用拼音，不写错别字。

田字格实操后互评是否规范，不规范当堂订正。

## 10. 分享点评维度

- **基础（各期通用）**：是否说清楚「什么时候，谁、在哪儿、做了什么」；是否先说后写、书写规范。
- **六维点评（二上「细节四方向」起用）**：①内容完整 ②细节描写 ③想象合理 ④结构清晰 ⑤语言通顺 ⑥书写规范。
- **想象/综合类课次**：重点点评**对情节的不同想象**与个性表达，肯定「同画面多版本」，不评「标准答案」。

### 10.1 点评示范话术（详案必须给具体样例，不许只写维度名）

维度名（「细节描写」「想象合理」）只告诉老师**看什么**，没告诉老师**怎么说**。详案的分享点评环节须给**至少 2 条可照读的夸奖句**，句式统一为「**复述学生原句 + 点明它好在哪**」：

- 「你说『小兔一边弹吉他一边点头打拍子』，这句**动作**写得让人看得见。」
- 「你加了一句『快看，我也会打鼓！』，有了**说话**，整个画面一下子热闹起来了。」
- 「你说『它心里像蜜一样甜』，这是它**心里的话**，画上看不见，是你想出来的，很好。」

要点：**先引原句、再说好在哪**；不说空泛的「很棒/真棒/你真聪明」。低龄学生要听见「我哪一句好」才能复制。

### 10.2 过关判定样例（评价三级必须配对照例句）

**评价三级＝基础／良好／优秀**，对应下表的 不算过关／算过关／加分。只写「能说完整一句话」，新手老师无法当场判定。**每一档都要配「算过关 / 不算过关」的对照例句**：

| 判定 | 例句 | 说明 |
|---|---|---|
| 不算过关 | 「小女孩。」 | 只有「谁」，没说做什么 |
| 不算过关 | 「小女孩洗菜。」 | 缺「在哪里」，三素句不齐 |
| 算过关 | 「一个小女孩在厨房里洗菜。」 | 三素齐、话完整 |
| 加分 | 「一个小女孩在厨房里帮妈妈洗菜，她笑得很开心。」 | 加了样子/心情 |

「不算过关」不等于批评：老师补齐缺的那一件、请学生**跟说一遍**即可，仍算当堂过关（见 §2.2 第 3 拍）。

**分层任务的达标线**：课内派了不同任务的学生（如「不用逐问、自己一口气说完」「两幅图连着说」），其达标线**上移到「加分」行为**，不另立档名。评价三级每次课都能拿满，不因本课只发基础层支架而砍掉优秀档（见 `scaffold-cards.md` §一）。

## 11. 课后延伸与积累

每课须有**一条轻量课后动作**，不留书面作业负担、但让能力走出课堂：

- **家校协同说图**：回家给家人说一张图/一张照片（纯口头与起步课次口头即可；进阶课次可说完再写一句）。这条同时为下一次课的「自带照片/自带素材」蓄水。
- **精彩句子积累本**：课上点评出的好句子，学生抄进积累本，下次写话可以用。老师每次课从积累本里挑 1–2 句开课时读一读。
- 课后动作写在详案末尾，一句话交代清楚做什么、要不要交、怎么反馈。**不设打分、不设家长批改**。

## 12. 教学决策理据批注（体例）

详案中凡作出**非显然的教学决策**（环节顺序、内容取舍、为什么先教这个后教那个、为什么某个点不讲），须紧跟一条 `（注：…）` 写明理由，供教研与后续迭代复用。范例：

> （注：此环节之所以最后才圈「时间」，是因为对低年级学生来说时间相对抽象、容易造成识别困难，所以从具体的三要素开始，逐步识图、圈画。）

- 批注是**写给老师和教研看的**，不念给学生。
- 只在决策点写，不逐环节堆注；**硬上限：每课时 ≤3 条，每条一句话**——只给结论性理由，不写论证过程、不写算式推导。
- **修订过程留痕一律不入稿**（"原配 X 分钟装不下""本环节从 XX 拆出"这类给审稿人看的话，改完即弃）；**生成侧自检**（规格核查、时间算式）也不进正文，归文末"真实性自检"（该节整体包 `<!-- -->`，只留 md 源、不渲进 docx，见 SKILL.md 骨架条）。正文里的注只回答一个问题：老师照做时为什么这么排。
- 「本课不讲 X」这类越阶克制的判断，也用本体例交代理由，避免后来者误以为是漏掉了。
