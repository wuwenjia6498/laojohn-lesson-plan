# 示范例文规范（model-essay）

本文件是看图写话**示范例文的唯一规范源**：例文怎么标、怎么批注、各类方法写到什么程度、真实性红线如何守。`ability-ladder.md` 各骨架的「例文要求」只引本规范、不复述。这是技能自有的通用例文规范，供新生成各课次详案时统一调用。

## 1. 通用红线

- **标注**：例文统一标 `【教师示范例文】`，**不冒充学生、不冒充名家**。
- **口头示范同属例文，不得规避标注**：教师在课堂上说的示范片段（哪怕只有三两句、哪怕本课「不写整篇」）**就是示范例文**，同样要标 `【教师示范例文】` 并逐句批注。不得以「本课不写例文」为由把示范片段裸放在师话里躲开本规范——起步档的 3–4 句口头片段正是最容易被规避的一处。
- **例文是教师范本，不是学生产出目标**：例文的用途是**给老师照着讲、照着读**，示范「这句在做什么」。呈现时不得说成「你们要写成这样」。学生的达标线看 `lesson-structure.md` §10.2 过关判定，通常远低于例文水平。
- **真实性（图位规格门禁延伸）**：例文里每个具体画面细节都必须能在本课主图《图位规格书》「必须可见元素清单」里定位到；**定位不到的删除，或移入「合理想象」段并明示**（如对话、心里话、前因后果）。不得出现清单外的「事实性」物件。
- **例文写在主图上、学生当堂写作用练笔图（2026-07-26 三图位定案，硬线）**：示范作用靠「示范方法怎么用」成立，不靠同图；两者同图时学生写的就是「把刚才集体说过的抄下来」。故越清单核查**分头做**——**例文逐句回溯主图清单**，**学生任务提示、兜底填空条与过关判定例句逐句回溯练笔图清单**（详见 `image-spec.md` §三）。教师若要在换图后再口头示范一两句，那几句同属例文、须回溯练笔图清单。
- **越清单核查**：交付前把例文逐句拆开，逐一对清单核对（见 `checklist.md`）。
- **弯引号（按全仓口径，勿用直角引号）**：一律用**全角双引号 `“”`**、内层用**全角单引号 `‘’`**，**不用 ASCII 直引号，也不用直角引号 `「」`／`『』`**——全仓详案（读书会/写作课/看图写话）统一为 `“”`，见 `CLAUDE.md` §4「中文弯引号铁律」；此前本条曾误写为「」并已扩散进期1 详案，2026-07-20 更正。交付前跑根 `check_quotes.py` 校验、`fix_quotes_md.py` 批修。
  > 生成侧注意：Write 工具会把全角弯引号规范成 ASCII 直引号（**不要因此改用「」规避**），正确做法是写完立刻跑 `fix_quotes_md.py` 转回。

## 2. 分段批注规范（按方法类型）

例文每段末或括号内做**写法批注**，让老师看见「这段在示范什么」。

- **三段式（一下）**：三段分别批注「时间」「细节（环境+动作）」「心情」。批注范式：
  - 第一段批注：时间写完逗号；写完时间写事件，一句话讲述，写完句号。
  - 第二段批注：重点抓图片细节，主要是环境描写和动作描写。
  - 第三段批注：心情感受。
- **细节四问（二上）**：分段/分句批注所用的那几问（动作/表情/语言/心理），至少含两种。
  - **批注感官归类判据（2026-07-26 两稿独立命中后固化）**：拟声词与声音细节属「**听得见的**」，按两看两想归【两想】侧（照着画面想出来的声音）——批注**不得把拟声词标成「看得见的」**（判据唯一源见 `lesson-structure.md` §5）。
- **多图叙事（两图串联/四图故事/对话推进/转折/多图综合）**：四段一图一段，分段批注「起因/经过/经过/结果」，含至少一处对话与一处心理；每段细节只引对应格清单。
- **缺图补全（二下）**：四段，**明示哪一段是想象补全**，且与前后格自洽。
- **同图多解（二下）**：给 1–2 个**不同想象走向**的例文片段，示范同图多解，避免学生以为只有标准答案。
- **单图轻想象（补对话/心里话，一下）**：写实部分贴清单；补出的声音/对话/心里话/前因后果**单独成句或成段、明示为想象**。
- **真实表达（看图+我的生活，二下）**：画面细节贴清单；联系自身的经历/感受**明示为「我」的真实表达**（非画面事实）。

## 3. 篇幅与难度档（按方法/课次段）

| 方法/课次段 | 例文形态 | 长度参考 |
|---|---|---|
| 三素句起步（一上） | 不写整篇；若干三素句示范句 + 一段 3–4 句口头片段 | 句级 |
| 三段式（一下） | 一篇三段式 | 三段、每段数句 |
| 细节四问（二上） | 一篇含细节四问 ≥2 种 | ≥4 句 / 小段 |
| 补对话/心里话（一下轻想象） | 一段（写实+想象明示） | 小段 |
| 多图叙事（二上/二下） | 四段式（一图一段） | 四段 |
| 缺图补全/同图多解（二下创意） | 四段式（缺图补全明示想象段 / 同图多解给多版本片段） | 四段 / 片段 |
| 语言线专项（标点/叠词拟声/好词入话） | **不出整篇**，只给对比示范句（造句，非伪原文） | 句级对比 |
| 看图+我的生活（二下真实表达） | 一篇（画面+自身衔接） | 三至四段 |

> **学生可及度警示**：上表长度是**教师范本**的长度，不是学生的产出目标。旧稿曾出现约 400 字、含「灵机一动」这类书面语的一年级例文——作教师朗读范本可以，一旦当成学生目标就会打击信心。写例文时自问一句：**「这一档的学生，照着能说/写出其中一两句吗？」** 答不出就降档，或明确标注「本篇仅供教师朗读，学生达标线见过关判定」。

## 4. 例文取材纪律（与门禁一致）

- 例文是「据规格清单写」的产物，与「看真图写」逻辑一致，只是清单来源是规格书。
- **想象内容**（对话/心里话/前因后果/同图多解）一律单独成段或明示括注，不与画面事实混淆。
- 取名可用（取名两法见 `lesson-structure.md`），但取名不构成「画面事实」。
- 语言线专项（标点/叠词拟声/好词入话）的对比示范句是造句练习、不锚定具体主图，故不涉图位真实性核查。

## 5. 风格

- 适龄亲切、画面感强，保留拟声词与生动描写（属「写具体」手段）。
- 方法叫法平实（不「胖起来/加料/变身」）；人工 docx 例文里若有旧叫法，迁用时按新口径改写。
