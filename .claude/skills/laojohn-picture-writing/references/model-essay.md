# 下水例文规范（model-essay）

本文件是看图写话**下水例文的唯一规范源**：例文怎么标、怎么批注、各模块写到什么程度、真实性红线如何守。`ability-ladder.md` 各骨架的「例文要求」只引本规范、不复述。这是技能自有的通用例文规范，供新生成 20 期时统一调用。

## 1. 通用红线

- **标注**：例文统一标 `【教师下水例文 · 示范】`，**不冒充学生、不冒充名家**。
- **真实性（图位规格门禁延伸）**：例文里每个具体画面细节都必须能在该期锚图《图位规格书》「必须可见元素清单」里定位到；**定位不到的删除，或移入「合理想象」段并明示**（如对话、心里话、前因后果）。不得出现清单外的「事实性」物件。
- **越清单核查**：交付前把例文逐句拆开，逐一对清单核对（见 `checklist.md`）。
- **弯引号**：例文一律用全角引号（对话/心里话用 `「」`，引文用 `『』`），不用 ASCII 直引号；交付前跑根 `check_quotes.py` 校验、`fix_quotes_md.py` 批修。

## 2. 分段批注规范（按模块）

例文每段末或括号内做**写法批注**，让老师看见「这段在示范什么」。

- **M1 进阶（三段式）**：三段分别批注「时间」「细节（环境+动作）」「心情」。批注范式：
  - 第一段批注：时间写完逗号；写完时间写事件，一句话讲述，写完句号。
  - 第二段批注：重点抓图片细节，主要是环境描写和动作描写。
  - 第三段批注：心情感受。
- **M1 综合（细节四方向）**：分段/分句批注所用的细节方向（动作/表情/语言/心理），至少含两种。
- **M3 多图叙事**：四段一图一段，分段批注「起因/经过/经过/结果」，含至少一处对话与一处心理；每段细节只引对应格清单。
- **M4 缺图补全**：四段，**明示哪一段是想象补全**，且与前后格自洽。
- **M4 同图多解**：给 1–2 个**不同想象走向**的例文片段，示范同图多解，避免学生以为只有标准答案。
- **M2 单图轻想象**：写实部分贴清单；补出的声音/对话/心里话/前因后果**单独成句或成段、明示为想象**。
- **M6 综合表达**：画面细节贴清单；联系自身的经历/感受**明示为「我」的真实表达**（非画面事实）。

## 3. 篇幅与难度档

| 模块/档 | 例文形态 | 长度参考 |
|---|---|---|
| M1 起步（三素句） | 不写整篇；若干三素句示范句 + 一段 3–4 句口头片段 | 句级 |
| M1 进阶（三段式） | 一篇三段式 | 三段、每段数句 |
| M1 综合（细节） | 一篇含细节四方向 ≥2 种 | ≥4 句 / 小段 |
| M2 轻想象 | 一段（写实+想象明示） | 小段 |
| M3 多图 | 四段式（一图一段） | 四段 |
| M4 创意 | 四段式（缺图补全明示想象段 / 同图多解给多版本片段） | 四段 / 片段 |
| M5 标点·叠词 | **不出整篇**，只给对比示范句（造句，非伪原文） | 句级对比 |
| M6 综合表达 | 一篇（画面+自身衔接） | 三至四段 |

## 4. 例文取材纪律（与门禁一致）

- 例文是「据规格清单写」的产物，与「看真图写」逻辑一致，只是清单来源是规格书。
- **想象内容**（对话/心里话/前因后果/同图多解）一律单独成段或明示括注，不与画面事实混淆。
- 取名可用（取名两法见 `lesson-structure.md`），但取名不构成「画面事实」。
- M5 的对比示范句是造句练习、不锚定具体锚图，故不涉图位真实性核查。

## 5. 风格

- 适龄亲切、画面感强，保留拟声词与生动描写（属「写具体」手段）。
- 方法叫法平实（不「胖起来/加料/变身」）；人工 docx 例文里若有旧叫法，迁用时按新口径改写。
