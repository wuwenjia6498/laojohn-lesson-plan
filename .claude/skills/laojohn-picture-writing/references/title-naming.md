# 看图写话详案 · 标题与环节命名规则（唯一源）

规定每份看图写话详案的**总标题、期次副标、课时小标题、环节名**格式。目标：标题像面向师生的课程名（简洁、点题、有温度），而非内部台账编号；台账所需的期次信息用一行小字副标保留。

> 2026-07-25 用户拍板启用，取代旧 H1 体例 `# <年级册>（<季>）第 N 次《方法名》· 看图写话详案`。
> 课时标题的**分隔符仍是 `·`**（2026-07-26 用户拍板：一度改过全角竖线 `｜`，已改回）——本规则改的是课时**小标题的句式**（§四三种句式＋两条铁律），不是分隔符。

---

## 一、三行标题结构（固定）

```
# 〔总标题〕
###### 〔期次副标〕
…（正文）…
## 第1课时 · 〔课时句〕
## 第2课时 · 〔课时句〕
```

- 第 1 行：一级标题 `#`，放**总标题**（课程主题式，见 §二）。
- 第 2 行：六级标题 `######`，放**期次副标**（台账信息，见 §三）。
- 课时小标题：二级标题 `##`，格式 `第N课时 · 〔一句话〕`（见 §四）。

## 二、总标题规则

**句式**：一个能力/主题短语，不含「第N次」「详案」「方法课」等台账字眼，**不带《》**。

**是否带副题——有规则地混**：

- **主题词本身够清楚 → 不带副题。** 例：`多图故事`、`创意写话`、`看图写话起步`、`比喻拟人`
- **主题词偏抽象、单看不知道学什么 → 加破折号副题点出目标。** 格式 `主题词——〔达成什么/怎么做〕`
  例：`细节四问——把一段话写生动`、`三段式写话——讲清一个小故事`

**判断「够不够清楚」的标准**：一个没上过这套课的家长/老师，只看主题词能不能猜到「这节大概学什么」。能猜到（多图故事＝把多张图写成故事）→ 不带；猜不到（「细节四问」是机构自造术语）→ 带副题。

**破折号用中文双破折号 `——`**，副题不加书名号、不加句号。

## 三、期次副标规则

```
〔学期〕· 第 N 次 · 〔课型〕· 看图写话详案
```

例：`二上（秋）· 第 1 次 · 方法课 · 看图写话详案`／`一下（春）· 第 9 次 · 回顾课 · 看图写话详案`

- 学期写法沿用课程地图：`一上（秋）/ 一下（春）/ 二上（秋）/ 二下（春）`。
- 课型用课程地图统一叫法：`方法课 / 练习课 / 回顾课 / 综合课 / 展示课`（**注意：原「复现课」已更名「回顾课」**）。
- 结尾统一 `看图写话详案`。
- 用六级标题 `######`，渲染时显示为小字副标、不与主标题抢视觉。

## 四、课时小标题规则

**格式**：`## 第N课时 · 〔一句话〕`

- 序号用「第N课时」；**分隔符用全角间隔号 `·`（前后各一个半角空格），与 writing-lesson 同款**——2026-07-26 用户拍板改回，不用竖线 `｜`。

**三种句式**（按课时性质选用）：

1. **从…到…**（点能力跃迁）——多用于第1课时。例：`从“看一眼”到“看仔细”`、`从“说完整”到“说生动”`、`从“照片里的故事”学习三素句表达`
2. **动作＋产出**（做什么·得到什么）——通用。例：`加一点细节，句子更精彩`、`补出缺图，写出完整故事`
3. **学生第一人称/口语收束**——多用于第2课时收尾。例：`讲出你自己的故事`、`把你说的，写下来`

**隐藏铁律（务必遵守）**：

- **第1课时**＝学方法、由说到练：优先用句式①或②，点出本课**新方法**是什么。
- **第2课时**＝把方法写下来＋评改：**必须收束到「写下来／写出来／写好再改／我来讲」**，呼应正文第2课时「当堂写作＋评改升格」。**纯口头课次**（一上第 1~4 次）无书面产出，收束到「讲／说给大家听」即可。
- 两个课时句**避免同一句式重复**，读起来要有「学→用」的推进感。

**标点**：句中引号一律中文弯引号 `“”`（师话区禁 `「」`）；需副题用 `——`；行末不加句号。

## 五、完整示例

###### 二上（秋）· 第 1 次 · 方法课 · 看图写话详案

## 六、环节命名规则（2026-07-26 用户给《详案标题与环节命名规则》§六，入库）

**格式**：`### 环节N · 〔环节名〕（M 分钟）`

- 三级标题 `###`；保留「**环节一/二/三/四**」中文序号前缀（详案是备课文档，教师按环节推进，序号必须明确）。
- 序号后用全角间隔号 `·` 接环节名，末尾括注本环节时长 `（10 分钟）`。

**环节名句式**：口语的**动宾短语或名词短语＋冒号点睛**，面向学生/课堂，**不用教研黑话与文白词**。

- 结构：`〔这一环节讲什么/做什么〕：〔一句话说清目的或学生动作〕`。例：`细节四问：一句话变成一段话`、`图上的细节：一处一处圈出来`、`写完再改：改过比写对更重要`。
- **「句式统一」＝结构统一，不是词性统一**（2026-07-26 用户反馈后收紧的判据）：八个名共用同一套「〔主题〕：〔做什么〕」骨架即可；冒号前那半截**不要求全是动宾、也不要求全是名词短语**，按哪种说法自然就用哪种。
- **★ 反模式化（硬规则）**：**禁止每个环节名都用同一种词形开头**——尤其是 `听一听／圈一圈／写一写／改一改／读一读` 这类 **X一X 复叠动词**排成一串，八条读下来像口令操。判据：把八个名的冒号前半截抽出来竖排，**若同一构词法出现三次以上，就换掉多数**。冒号前半截**也不得重复**（两个环节都叫「说一说」＝没说清区别）。

**必须避开的教研黑话/文白词**（出现即换成口语）：

| 禁用词 | 换成 |
|---|---|
| 升格 | 改一改／改得更好／改过更重要 |
| 引路（例文引路） | 带路／先看老师写一段／例文示范 |
| 引入、导入 | 先看／听一听／从…说起 |
| 感知（对比感知） | 听一听／比一比 |
| 巡视指导（作环节名时） | 写一写／当堂写 |
| 落位、承载、锚定等 | 一律不进环节名（内部机制词，只可留在批注/附录） |

**每个环节名自带一句「做什么」**，不要光秃动作。
- 反例 `当堂写作`（秃）→ 正例 `写一写：把这张图写成一段`。
- 反例 `读一读·怎么算写生动了`（一名塞两件事＋设问）→ `读一读：怎样算写生动了`（一个环节一件主事）。

**标点**：环节名内引号用中文 `“”`；冒号用中文 `：`；序号与名之间用全角 `·`；名内不加句号、不再出现第二个 `·`。

**参考（方法课两课时的八环节，2026-07-26 已按此改定二上第 1 次）**：

```
第1课时
### 环节一 · 两种说法：哪一句让你看见画面（10 分钟）
### 环节二 · 细节四问：一句话变成一段话（15 分钟）
### 环节三 · 图上的细节：一处一处圈出来（10 分钟）
### 环节四 · 连成一段：说给同桌听（10 分钟）

第2课时
### 环节一 · 老师写的一段：动笔前先听一遍（10 分钟）
### 环节二 · 当堂动笔：把这张图写成一段（15 分钟）
### 环节三 · 写完再改：改过比写对更重要（10 分钟）
### 环节四 · 读给大家听：怎样算写生动了（10 分钟）
```

> 旧版参考示例（`听一听／学四问／圈一圈／连起来｜看一看／写一写／改一改／读一读`）已作废——它八条全是复叠动词开头，正是上面「反模式化」要禁的那种口令操，照抄即返工。

（第2课时天然有「看范文→写→改→读」的推进感，可顺势体现，但**不必为了工整去凑动词序列**；核心要求是口语、去黑话、结构统一、每名自带「做什么」、不模式化。**纯口头课次**可少于四环节，按实际环节数写、不硬凑。）

## 七、★ 脚本耦合（改标题前必读）

- **文件名不跟着改**：仍是 `<年级册>（<季>）第 N 次 · <课型>.md`（见 SKILL「输出形态」）。**文件名口径由「期次副标」这一行承载**，两者逐字对应；H1 总标题与文件名不再同口径。
- **`style_front_page.py`（picture 档）靠期次副标判型**：`detect` 正则认 `^###### …· 看图写话详案$`，首页副题也取这一行（去掉尾缀）。**期次副标行不可省、「· 看图写话详案」尾缀不可改**，否则版式化脚本直接判不出型退出。
- **能力线本课方法名的标黑**改为**按 `（本课）` 标记**定位（不再依赖 H1 的《》）——提纲表「能力线」行必须保留 `（本课）` 标记。
- **共享 docx 引擎**（`md_to_laojohn_docx.py`）已支持「H1 紧跟的 `###### ` 行＝文档副标题」（与主标题同段、软回车分行）；该分支课型无关，改动须回归两条线。
