# 看图写话 20 期能力坐标总图（competency-matrix）

本表是 20 期的**全局坐标图与目录**：纵向＝课标第一学段「写话」四个能力维度落成的 **6 个模块**，横向＝**难度三档**（起步／进阶／综合），辅以**题材**横铺。每期在「模块 × 难度」里占一个坐标，**坐标互不重复**——这是防同质化（不重演「换张图换个题材、能力没递进」）的硬约束。

> 关系：本文件是「看哪 20 期、为什么是这 20 期、彼此不重叠」的总览；`ability-ladder.md` 是「每期/每模块具体怎么教」的执行台账（6 模块模板 + 20 期卡）。改期目录先改这里，再到 ability-ladder 落期卡。

## 课程定位（沿用「看图写话训练营」产品简介）

- **形态**：「看图写话训练营」，面向**小学一、二年级**；默认每期两节课、一周一次，或短期训练营；适用语文拓展课、专项训练营、课后服务、寒暑假托管。
- **进阶主线**：会看图 → 会说话 → 能写句 → 会写段 → 写得生动 → 写出创意（即本表 M1→M3→M4 主干；M2 轻想象 / M5 标点专项 / M6 综合表达为在此基础上补齐的课标维度）。
- **卖点**：螺旋递进、方法可迁移、素材童趣有温度且难易适中、任务明确成果可见、**紧贴学校语文教学重点助力写话得分**。


## 课标依据（第一学段 1–2 年级 · 写话）

2022 课标第一学段写话要求（本表逐模块挂靠）：
1. 对写话有兴趣，留心周围事物，写自己想说的话 → **M1 写实观察 / M6 综合表达**
2. 写想象中的事物 → **M2 单图轻想象 / M4 四格创意综合**
3. 在写话中乐于运用阅读和生活中学到的词语 → **M5 用词与标点专项**
4. 根据表达的需要，学习使用逗号、句号、问号、感叹号 → **M5 用词与标点专项**
5.（衔接的口头表达）能较完整地讲述小故事 → **M3 多图叙事**

部编节奏参照：一上口头为主、一下写句子起步、二年级系统化主题写话（记实类/想象类）。

## 分期总原则

- **纵轴 = 6 模块**（按课标四维落地，不是机械 5 阶 ×4）。
- **横轴 = 难度三档** 起步 / 进阶 / 综合；同模块内多期靠难度递进 + 题材轮换双重区分，**杜绝同期同质**。
- **期号 = 稳定目录 ID**（按模块顺序排，1–20），非死板教学顺序；教学顺序见文末。
- **20 期全部由技能新生成**（图位规格驱动 + AI 生图，去游戏化、弯引号、风格统一），不依赖原 5 份人工 docx；理由＝一套设计更成体系、期间衔接更自然。原稿的**教学方法**已沉淀进 ability-ladder 模块骨架与 lesson-structure/model-essay/scaffold-cards（通用教法），生成时调用。**`看图写话输出/二期-雨后菜地…`（季节景物·M1 进阶）是唯一已产的一期**。
- **缺图补全/同图多解（M4）须排在多图叙事（M3）之后**——它们是四格操作、以多图叙事为前置；轻想象（M2，单图补声音/心里话）才前移。

## 推荐教学顺序

M1（期 1→6）→ **期 17 标点会说话**（三段式学完即可插）→ M2（期 7→9）→ M3（期 10→13）→ **期 18 叠词拟声词**（多图叙事前后）→ M4（期 14→16）→ M6（期 19→20）。

- **标点专项（M5）是可穿插单元**，不锁死位置：建议期 17 在三段式（期3）之后任意时机插入、期 18 在多图阶段前后插入。
- 一二年级跨用：同一期靠 ability-ladder「支架强度」段区分（一年级给填空模板、二年级只给词语卡），不另立年级专属套。

## 能力进阶来源

能力阶梯沿用通用看图写话教法（三素句→四要素三段式→细节→多图叙事→创意），**不绑定任何具体 docx**；各能力点的写法要领集中在 `lesson-structure.md`，由技能新生成各期时统一调用。其中 M2（单图轻想象）、M5（标点专项）、M6（综合表达）是据课标补齐的维度，使 20 期覆盖更完整。
