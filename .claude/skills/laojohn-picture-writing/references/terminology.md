# 看图写话 · 术语对照表（机构自造简写 → 教研通用词）

**用途**：收录本课程稿件里出现过的「机构自造简写」与对应的「语文教研通用词」。这类问题是**术语问题、不是语感问题**，须全课程统一，故单列一表，不散落在各课稿里。语感层面的软规则（补主语、去对仗、序号改衔接词、去自造表述等）与其反向约束，见 `lesson-structure.md` §13，不重复于此。

**维护规则（两条）**：
1. **发现新的机构自造词，往这张表加**——不改主文档、不改 §13，只增本表一行。
2. **只收通用术语**（所有课次都可能用到、且属机构自造简写的词）。单课特有的用词问题（如某课把「西瓜汁」简写成「瓜汁」）在该课稿件里直接改掉，**不入本表**——一次性条目会把表撑大、稀释通用规则。

**置信度**：高。术语替换不随课次变化，逐字执行即可。

## 分语境处理（`说话句`／`心里话` 类）

`说话句`／`心里话` 在**面向学生的口语**里说「心里想的什么」是自然的，硬换成「心理描写」反而不像跟二年级说话。规则是：

- **教师讲解、总结、书面标注处** → 用标准术语（「语言描写」「心理描写」）；
- **直接问学生时** → 用儿童能懂的说法（「他会说什么」「心里想什么」）。

提示卡上写「语言／心理」、口头问「他会说什么、心里想什么」——**两者并存是对的，不是不一致**。

> 注：`心里话`（指心理想象）作为师话里对儿童的口语说法仍**保留**（见 SKILL「语言风格」条与 `lesson-structure.md` 头部口径）；本表约束的是把它当作**书面术语标注/讲解**时应写「心理描写」。两者不冲突：口头对孩子说「心里想的」是保留项，书面标注写「心理描写」是本表要求。
