# 小试 · PS 缩头定妆图能不能把场景图比例带下来（2026-07-30 · 非交付物料）

**验什么**：定妆图头部偏大。PS 把头缩小另存 → 用它作参考图出场景图 → 看孩子比例是否更自然、角色是否还认得出、模型会不会照抄畸形。

**理论依据（已验，不必重验）**：`references/image-spec.md`「比例·收口结论」① —— **参考图会同时传递画风、角色身份与身体比例，三者靠措辞解耦不了**。本轮验的是这条能不能**反向利用**：改参考图的比例，让它把新比例带给场景图。

**与 0729 负面清单的关系（重要，别被旧条目拦住）**：`docs/handoff/小试结论_头身比收口-0729 .md` §五 否决过「PS 缩小定妆图头部再作参考」，理由是「要达 4.0 需头缩至 51%，产出畸形参考图」。**那个 51% 是为了凑四头身算的**；0730 已拍板不设数值关卡、≈2.8 头身人工接受。本轮目标是**目视改善**（缩到 72~86%），与 51% 不是一个量级。旧条目里**唯一仍然成立的部分**是「参考图畸形会被模型照抄」——它现在是本单的失败判据，不是禁止理由。

## 一、妆-01 现状实测（原件 `assets/角色册/妆-01_小虎.png`，2400×1792）

| 线 | y | 测法 |
|---|---|---|
| 发顶 | **121** | 全宽扫，首个出现连续 ≥6px 暗像素（V<95）的行 |
| 下巴 | **~716** | 肤色跨度扫描的轮廓合拢点：y=704 跨度 141px → y=712 为 98px → y=720 归零（该行 RGB(158,87,67)＝下巴阴影线） |
| 鞋底 | **1664** | 鞋区 x 960–1440 深色描边（V<150）终止行。⚠ y=1678 起出现的"纯白"是**背景纸纹高光、不是鞋**，别拿它当鞋底 |

导出量：头高 h = **595px**、身体段 b = **948px**、全身高 H = **1543px** → 占比 **38.6%**、**2.59 头身**。与已知「第一批定妆图 ≈39%／约 2.5 头身」吻合。

已验传递关系：定妆图 38.6% → 场景图 **37.4~39.0%**（近 1:1 带过去）；零参考图时场景图落 **30.9~31.7%**。

## 二、缩多少

缩头时**身体不动、头顶下移**，全身高同时变短，故解 `595k /(595k + 948) = 目标占比`：

| 缩放系数 | 新头高 | 头顶新 y | 预期占比 | 预期头身比 | 判断 |
|---|---|---|---|---|---|
| 86% | 512px | 204 | ≈35% | ≈2.9 | 最保守，畸形风险最低，改善幅度小 |
| **78%** ← 建议起点 | **464px** | **252** | **≈33%** | **≈3.0** | 温和且看得出差别 |
| 72% | 428px | 288 | ≈31% | ≈3.2 | 落到零参考图那档的自然感，畸形风险开始上升 |

**先只做 78% 这一档**——一次动一个变量。方向对了再决定要不要推到 72%。

## 三、PS 操作要点

- **以下巴为锚点等比缩放，头顶下移**（不是以头顶为锚点）。这样脖子、肩、身体、双臂、双手一律不动，**接缝只出现在头发外沿与背景之间**，而背景是纯米白纸纹，最容易补干净。
- **必须等比**（拖角点时按住 Shift）。脸宽高比 ≈1:1 是角色硬项（§八 三可量项），压扁即角色走形。
- 头缩小后头发外沿会露出原被遮住的背景 → 内容识别填充或仿制图章补纸纹。
- **另存为新文件，绝不覆写母版**。母版是人工定稿基准，量几何量、比色值都要回它。建议另存到 `_临时_角色定妆/` 或桌面，命名如 `妆-01_小虎_头78.png`。
  ⚠ **不要放进 `assets/角色册/` 目录**——那里的 `妆-\d+_名.png` 会被 `generate_images._load_char_registry()` 当成新角色注册。

## 四、做完先自查（别急着烧图）

- [ ] 1. 三线法复量，占比落在目标档（78% → 33%±1）
- [ ] 2. 脸宽高比仍 ≈1:1，五官没被压扁
- [ ] 3. **脖子**：头缩小后是否显得过粗／过长 ← **本方案最可能的畸形点，也是模型最可能照抄的地方**
- [ ] 4. 头发外沿补的背景无接缝痕迹、无残留的原轮廓
- [ ] 5. 辨识锚（左手腕深蓝布绳）、主色（正红 T 恤／藏青短裤／白球鞋）零改动

第 3 项若明显别扭，**换 86% 档重做，不要硬上**——参考图畸形会被模型照抄。

## 六、判据

**主判＝并排目视**（0730 已定：比例不设数值关卡）：

| 看什么 | 通过 | 失败 |
|---|---|---|
| 比例观感 | 实验组比对照组自然，且与三张已核准存量主图（一上第1次、二上第1/2次）同档 | 无差别，或反而怪 |
| 角色一致性 | 脸型、发型、正红 T 恤、藏青短裤、白球鞋、左手腕布绳全中 | 任一项丢 → 缩放伤了角色锚 |
| **畸形照抄**（重点） | 脖子长短粗细正常、头身接缝无变形、脸未压扁 | 出现异常长脖／粗脖／头身错位 → 方案作废，回 0729 否决结论 |

**次判**（诊断用、不作关卡）：三线法量实验组产出的场景图占比，看是否真落到 33~35% —— 这是「参考图比例可反向利用」这条机制成不成立的**直接证据**。
