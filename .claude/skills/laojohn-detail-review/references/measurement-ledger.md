# 分层改制 · 测量台账（跨三条详案线共用 · 2026-08-04 起）

> **这份文件是什么。** 2026-08-04 把措辞层约束从生成侧后移到冷审 Pass B（判据不变、只改执行时机，见两条详案线的 `references/generation-brief.md`）。改制是否合适**只能靠数据判**，所以每跑一次 Pass B 就往下表追加一行。
>
> **为什么要落盘、不靠记忆**：测量方法一度只写在项目记忆里，而记忆是「相关时才召回」——指望它在下次写课案时自己冒出来，等于指望恰好想起来。这跟这条线反复撞到的那条规律是同一个：**没牙齿的规则不会被执行**。故 `SKILL.md` 第 1.5 步职权 4 把「写计量行 ＋ 追加本表」定为 Pass B 的必做项。
>
> **谁来写**：跑 Pass B 的那个 agent，在出报告的同时追加一行。**不要等人转述。**
