# 老约翰 · 详案独立复盘（冷启动审稿）

把一份**已成稿**的详案 `.md` 当作「别人交来的稿子」从头审到尾，找出 checklist（合规检查）查不出的**质量、节奏、衔接、可信度**问题，并出一份让用户不必回翻源文件就能判断的复盘报告。支持三类详案（整本书阅读 / 写作课 / 看图写话），自动判型。

## 这个技能为什么单独存在（先读懂，否则等于没拆）

成稿复盘最大的失效模式是**「生成者自审」**：刚把详案写出来的那个 agent，脑子里全是"我为什么这么排"的设计记忆，紧接着复盘时会不自觉地为自己的设计辩护，`默认有问题`这条立刻空转，审稿沦为走过场。

**本技能的全部价值，建立在「运行它的 agent 不带生成上下文」之上。** 两种正确的触发形态（都属**形态A**——无生成上下文的冷启动）：

- **形态A · 强隔离（首选）**：由 `laojohn-lesson-plan` / `laojohn-writing-lesson` 生成完详案后，**派一个全新的（fresh，非 fork）子 agent** 来运行本技能——子 agent 冷启动、一片空白，眼里只有这份 .md，没有任何生成记忆。这是结构上最干净的「换人审稿」。
- **形态A · 手动（等效）**：用户在**一个新会话**里直接调用本技能、对着一份 .md 跑。同样无生成上下文，与派子 agent 等效。

> **形态B（降级兜底 · 效果最弱）：如果你正运行本技能、却恰好就是刚才写出这份稿子的那个 agent（同一会话顺接，没换人也没另起）。** 此时**必须显式封存**前面的全部生成过程：从现在起，你不是作者，你不知道这稿是怎么来的，你手里只有一份陌生人交来的待审 .md。仍按下面流程一字不差地走。（形态命名与两份 review-rubric 顶部协议一致：A=冷启动、B=同会话降级。）

## 输入

- **必需**：一份详案 `.md` 的路径（整本书阅读「课案详案」、习作「写作课详案」或低年级「看图写话详案」）。
- **可选**：用户指明文档类型；未指明则按下面规则自动判型。

> ⚠ 本项目位于移动硬盘，盘符可能随挂载变动，执行前用 `(Get-Location).Path` 确认实际项目根目录，下方 `<项目根目录>` 代表该路径，禁止硬编码盘符。

## 工作流程（必须按顺序）

### 1. 判型 → 决定加载哪份 rubric（单一事实源，不复制内容）

按以下顺序判断这份 .md 是哪类详案，**复盘的五个维度内容以对应 skill 的 `review-rubric.md` 为唯一权威**——本技能不重抄五维，只负责把正确的 rubric 加载进来、按它执行：

| 信号 | 判为 | 加载的 rubric（唯一源） | 事实核对源 |
|---|---|---|---|
| 文件名 `*-课案详案.md`；正文有 `## 第N课时 · 课型`、`阅读策略`、`可视化工具`、`思辨` | **整本书阅读详案** | `.claude/skills/laojohn-lesson-plan/references/review-rubric.md` | 书籍档案 `读书会书籍档案\<书名>书籍档案.md` |
| 文件名 `*-写作课详案.md`；正文有「两节连排 / 45 分钟 / 全感官唤醒 / 构思支架 / 【教师示范文】」 | **校内同步习作（写作课）详案** | `.claude/skills/laojohn-writing-lesson/references/review-rubric.md` | 习作档案 `laojohn-writing-lesson/references/archive/`（按册检索 index.md） |
| 文件名为课次口径 `<年级册>（季）第 N 次 · <课型>.md`（位于 `看图写话详案输出\`；旧稿或为 `*-看图写话详案.md`）；正文有 `【图位:编号】` 占位、文末有「生图工单」与 ` ```imgspec ` 块 | **低年级看图写话详案** | `.claude/skills/laojohn-picture-writing/references/review-rubric.md` | **三处并用**（详见该 rubric「事实核对源」节）：① 文末生图工单各图「必须可见元素清单」＝画面事实唯一源；② `laojohn-picture-writing/references/curriculum-archive.md`＝教材锚点唯一源；③ `course-map.md`（§四 64 课次表＋§五 24 方法内部编号表）／`ability-ladder.md`＝课次与不可越阶；已回插时另核真图 `看图写话详案输出\<详案stem>\图位\*.png` |

- 三类信号都不明显或冲突时，**停下问用户**这是哪类详案，不要猜。
- 看图写话的辨识度最高、优先按它判：**只要正文出现 `【图位:` 占位或文末有 `imgspec` 块，就是看图写话详案**，另两类都不含这两个标记。
- 判型只为选对 rubric 与事实核对源，不影响后续动作的严格度。

### 2. 立「审稿人协议」五条（缺一则走过场）

打开第 1 步选定的 `review-rubric.md`，**先把它顶部「审稿人协议」五条原样立住**，再开审——五条的权威文字以 rubric 为准，本技能不复述。助记一句：身份重置、默认有问题、先摘后算、量化下限（B 块不得为空）、真实性红线不豁免；缺一条，复盘即走过场。

### 3. 按 rubric 的五维冷审，逐维「先摘后算」

严格按选定 rubric 的五个维度逐维核查（五维的具体名称与查项以 rubric 为准——阅读详案与写作详案各五维不同，本技能不复述）。每维：

- **先摘**：把详案里相关那句/那段原样摘出来摊开（如各环节时长并排、工具"让学生做的动作"逐句写出、②激出素材与⑤支架字段并排）。
- **后算**：做该维 rubric 标注的「强制计算/写出动作」——节奏维写出 `T÷N=每X分钟`、`净书写=N分钟`、`反馈÷人数`、`连续高强度 X+Y=共N分钟`；策略维写出功能去重清单、重点策略频次清点。**这些算式/清单必须真的出现在报告里，否则该维视为未做、退回补算。**
- **再判断**：基于摘录与算式，而非整体印象。
- **真实性核对**：凡涉及原文/情节/页码/人物/示范文数据，回**第 1 步的事实核对源**逐一核对；档案/源缺失则保持占位，**绝不凭记忆补成具体内容**。

### 4. 分流处理（关键 · 决定改不改、问不问）

- **无争议项（客观错、没有第二种对法）→ 直接改掉这份 .md，不要问。** 改完在报告 A 块列一句「已改」。⚠ 何为「客观错」**随第 1 步判型而变**，别把一类详案的规则套到另一类上：
  - **两类通用**：环节时长合计不等于标称总长（阅读课每节 60 分钟 / 写作课每节 45 分钟）、环节漏标时长、衔接断裂（上节布置下节凭空消失）、残留 `【PPT换页-PXX】` 换页点。
  - **仅阅读（读书会）详案的时长粒度**：时长不是 5 的倍数按客观错处理。**写作课不适用**——其 checklist 只要求「合计=45、标题带时长」，存量写作详案普遍用 6/8/13/19 等精细配时，勿按读书会口径重排（2026-07 两份独立冷审同时撞出此误标，据此拆分）。
  - **仅写作课详案**：第 1 节尾误布置课后任务（两节连排、无课后时间）、收尾踩了明令禁止的对比/卖点话术。
  - **仅看图写话详案**：环节时长非 5 的倍数或每节合计≠45；**课次/方法映射与 `course-map.md` 不符**（课尾预告说错下一课次内容）；**正文/首页出现「期N」「模块X」对外旧口径字样**（2026-07-22 终稿0722 起期号仅内部用，对外一律「学期＋课次＋方法名」；所指方法回 `course-map.md` §五内部编号表核对后改写——旧 5 期制「三期＝细节四方向」与内部编号「细节四方向＝期6」极易混淆，勿按字面照搬）；**正文越图位清单**（把「必须可见元素清单」以外的东西当成"看到的"事实说出来，教师口头示范片段是高发处）；占位标记 `【图位:编号】` 与文末工单双向缺口；占位标记与师话写在同一段（应独占一段）。
    - ⚠ **例外：改「图位规格」不算无争议项，不得随手直改。** 规格是**已生成真图的验收依据**，改规格会让「真图＝规格＝正文」三者失配。要么归入 B 块请用户定夺；要么改完**立即打开对应真图确认仍达标**，并在报告里写明「已回验真图 X，仍满足」。没回验就改规格＝制造隐性不一致。
  - **仅阅读（读书会）详案**：第 2 节（交流1）课尾误布置「回去重读」类课后阅读任务（第 2↔3 节同日连排，见 grade-structure.md）。**注意：阅读详案导读课（第 1 节）尾布置「7 天读完全书」等阅读任务是必须动作、不是错误**——第 1↔2 节之间隔着周中自读，勿照写作课规则误删。
- **涉及教学判断项（怎么改取决于老师意图、有取舍）→ 拎出来问用户，绝不自作主张。** 如：可视化工具换不换、思辨/全感官环节换不换形式、构思支架要不要简化、示范文出示时机调不调、某环节压缩还是保留、三维目标某维补不补。这类只给诊断 + 备选改法，进报告 B 块，**等用户拍板**。
- 拿不准属于哪边 → **归到「问用户」**。宁可多问，不可擅改教学设计。
- 改 .md 时遵守该 skill 的 Markdown 约定（`师：`/`参考：`/弯引号/不碰 `##`/`###`/表格分隔行）；**真实性红线在改写时同样不豁免**。

### 5. 出报告（三件套 · 让用户不必开 .md 就能判断）

**完全按选定 rubric 末尾的「报告格式」输出**（A. 已自动修正 / B. 待你定夺两块，字段与范例以 rubric 为准，本技能不复述）。三条不可省的硬要求：**每条都要带「现状摘录」**——没有摘录的复盘等于没做，摘录逼你真回正文定位，堵住"经通读无明显问题"式空话；**B 块不得为空**；涉及节奏/策略的条目**必须带支撑算式或清单**。收尾按 rubric：A 块已改、B 块待用户拍板后由生成方一并落定重出稿，其余通读无问题的维度一句带过、不凑数。

## 范围与边界

- **只审稿 + 直改无争议项**。不生成/重写详案（那是 `laojohn-lesson-plan` / `laojohn-writing-lesson` / `laojohn-picture-writing` 的职责）、不出 .docx、不碰 PPT/海报/导图/阅读单等下游配套。
- **对看图写话详案另加两条**：不调用生图脚本、不跑回插（`generate_images.py` / `insert_images_docx.py` 归生成方）；改动涉及图位规格时按上面的例外条处置。审稿只动详案正文 .md。
- **不替用户做教学判断**：B 块只诊断 + 备选，决策权留给用户。
- **真实性红线全程不豁免**：碰原文/情节/页码/人物/示范文客观数据一律占位，不造「官方」条款，示范文身份标注不松。「现在只是复盘」不是放松理由。
- B 块拍板后的「按报告动手改」由生成方（原 skill 的「生成后的优化」段）执行，不在本技能内大改骨架。
