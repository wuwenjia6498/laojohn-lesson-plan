# 老约翰 · 写作课整套文件打包（成品归集）

把一节写作课的成品从各输出目录里**复制归集**进一个干净的交付文件夹，方便整套发给老师/家长。本技能**只搬运、不生成**——所有内容早已由上游各 skill 产出。

## 产出结构（固定 · 单层平铺）

```
写作课整套文件打包输出\<年级册>-第N单元-<题目>\      ← 单层平铺，无子文件夹（2026-08-26 改）
├── <年级册>-第N单元-<题目>-写作课详案.docx   ← 写作课详案输出\
├── <年级册>-第N单元-<题目>-课件PPT.pptx      ← 写作课件PPT输出\<课次>\*.pptx（外部平台生成、本仓做完动画的成品）
├── <年级册>-第N单元-<题目>-学生用.pdf        ← 写作配套输出\<课次>\*.pdf
├── <年级册>-第N单元-<题目>-教师用.pdf
└── <年级册>-第N单元-<题目>-家长用.pdf
```

## 收哪些文件（默认：仅对外成品）

| 分类 | 子目录 | 默认收的成品 |
|------|--------|------------|
| 写作课详案 | （根目录） | `.docx` |
| 投屏PPT | （根目录） | `.pptx` |
| 配套物料 | （根目录） | 三侧配套 `.pdf`；`.html` / `_data.json` 是源，默认不收 |

- **默认过滤掉中间稿与可编辑源**（md/json/html），交付包保持干净；`--with-sources` 时一并打包。
- **PPT 中间稿（写作课件中间稿输出\）不收**——它是生成 PPT 的中间产物、非交付件。

## 执行

先用 `(Get-Location).Path` 确认实际盘符（移动硬盘盘符会变，禁止硬编码），再在**项目根目录**下跑：

```bash
# 本机用 python（不是 python3）；脚本里有 ✓ 等字符，务必带 PYTHONUTF8=1
PYTHONUTF8=1 python ".claude/skills/laojohn-writing-package/assets/package_writing.py" <年级册>-第N单元-<题目>
```

常用参数：

```bash
# 先演练看清单、不实际复制（推荐第一步先 dry-run 核对哪些缺料）
PYTHONUTF8=1 python ".claude/.../package_writing.py" 三上-第六单元-这儿真美 --dry-run

# 连可编辑源文件(md/json/html)一起打包
PYTHONUTF8=1 python ".claude/.../package_writing.py" 三上-第六单元-这儿真美 --with-sources

# 直接打包到桌面/指定路径（覆盖默认 写作课整套文件打包输出\<年级册>-第N单元-<题目>）
PYTHONUTF8=1 python ".claude/.../package_writing.py" 三上-第六单元-这儿真美 --dest "C:/Users/xx/Desktop/这儿真美"
```

- 课次标识用 **`<年级册>-第N单元-<题目>`**（如 `三上-第六单元-这儿真美`），与 `写作课详案输出\`、`写作配套输出\`、`写作课件*输出\` 的目录/文件命名口径一致；PPT 文件名同此口径（如 `三上-第六单元-这儿真美-课件PPT.pptx`；**2026-08-26 起，旧的「文件名内纯题目、不带年级单元」已作废**）。**写作课线已无逐页讲稿**（2026-08-03 停产）。
- **复制不移动**：各原始输出目录是单一事实源，归集后原目录原封不动。
- 目标已存在则**覆盖同名文件**（重跑即刷新；不会删掉目标里你手动加的别的文件）。

## 工作流

1. **确认课次标识**与盘符（`(Get-Location).Path`）。
2. **先 `--dry-run`**：看清单，确认各分类都命中、没有因命名不符而漏收。
3. 决定是否 `--with-sources`（默认否，交付包更干净）。
4. **正式复制**，把脚本汇总（每类复制了几个文件 + 缺料清单）转述给用户。
5. **缺料不阻断**：某物料还没生成（如配套没做）→ 该分类标「缺」，照常打包其余，并在汇总里提示用户「先去生成 XX 再重跑打包即可补进」。

## 边界（不做）

- **不生成任何内容**：缺哪份物料就去对应 skill 生成（详案→laojohn-writing-lesson、PPT→外部平台出件后由 laojohn-ppt 做后处理、配套→laojohn-writing-materials），再回来重跑打包。
- 不改、不删、不移动原始输出目录里的文件（只读取并复制出去）。
- 读书会书目的打包不归本技能，走 laojohn-course-package（`读书会整套文件打包输出\<书名>\`）。
