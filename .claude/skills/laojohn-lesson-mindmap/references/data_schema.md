# 思维导图数据结构(data.json)

萃取后产出的 JSON 喂给 `scripts/render_pdf.py`。结构如下。

## 顶层字段

| 字段 | 必填 | 说明 |
|---|---|---|
| `title` | 是 | 图的标题,固定格式「《书名》精彩抢先看」。同时用作中心节点文字。 |
| `header_left` | 是 | 页眉左侧,固定填 `老约翰深度阅读` |
| `header_right` | 是 | 页眉右侧,固定填 `阅读 · 思辨 · 表达` |
| `branches` | 是 | 五个一级分支的数组,顺序固定 |

## branches(一级分支)

固定五个,`name` 依次为:`书籍信息`、`书籍概述`、`书籍主题`、`书籍特色`、`阅读收获`。

每个分支:

```json
{ "name": "书籍主题", "children": [ ...二级节点... ] }
```

## 二级节点(children 的元素)

两种形态:

**A. 纯叶节点**(信息/主题/特色/收获分支都用这种)
```json
{ "label": "绝活与规矩:手艺人靠真本事吃饭,靠死规矩立信。" }
```

**B. 带三级子节点**(只有「书籍概述」分支用,即「背景设置」「主要内容」两个节点各带一组三级)
```json
{
  "label": "主要内容",
  "children": [
    { "label": "共三十六篇短篇,各篇独立、互不相关" },
    { "label": "苏七块:看病先码七块银元的正骨医生" }
  ]
}
```

三级节点只能是纯叶(`{ "label": "..." }`),不再嵌套。

## 层级深度约定

- 书籍信息、书籍主题、书籍特色、阅读收获:**两层**(分支 → 叶)。
- 书籍概述:**三层**(分支 → 背景设置/主要内容 → 叶)。

这与样张一致,渲染器据此画 2 段或 3 段连线。不要给其他分支加三级,也不要给概述分支去掉三级。

## 文字长度建议

- 一级分支名:4 字左右。
- 概述的三级、信息分支的叶:短句,不带句号。
- 主题/特色/收获的叶:`概念词：一句说明。`(全角冒号) 说明控制在一行内(约 20–30 字),以句号收尾。叶节点不自动折行;若用户指定的文字超长、贴出右边距,在 label 里加一个换行符(JSON 写作反斜杠 n)手动断成两行。
