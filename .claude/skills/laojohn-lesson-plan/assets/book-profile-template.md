# 《书籍档案》填写模板

> 这是生成详案的**内容来源**。工具不会凭记忆补全这些信息——请按本书如实填写。
> 标 [必填] 的缺失会导致无法生成对应环节。

## 基本信息
- 书名《》[必填]
- 等级 L_ [必填]
- 作者 / 译者 / 出版社 / 页数 / 字数
- 获奖、推荐信息
- 宣传语(一句话主题)

## 作者&背景
- 作者简介(用于导读课)
- 写作缘起 / 后记要点 [思辨课必填,若该书有后记]
- 译后记要点 [思辨课必填,若该书有译后记]

## 内容结构 [必填]
- 章节结构:章节数 + 分段(如三段式)区间与划分依据;**逐章标题+页码为可选**(长篇书可只给分段区间与代表章节,不必逐章罗列)
- 主要人物及特征

## 关键片段(每条:章节 + 页码 + 用途)[必填,至少3条]
- 适合导读"抢先看"的悬念片段
- 适合精读/朗读的片段
- 适合推断作者意图的片段

## 重复出现的事物/场景(用于阅读交流2,小说类)
- 事物/场景名 + 各次出现的章节与含义变化

## 可视化工具选择
- 本书适合(择用,详见 `references/visualization-tools.md`):阅读单/表格、思维导图、人物关系图(家庭树)、故事山形图、时间轴/阶梯图、维恩图(异同对比)、鱼骨图/因果图、六面体讨论图、对比表 等
- 说明:按本书内容选 1–2 种/课;所选工具须能在课中真正"引出→填写→分享反馈"地落地,不挂名

## 阅读单设计 [必填]
- 阅读单主题 + 维度 + 参考填充

## 思辨问题(L3–L6)[必填]
- 3–5个开放性问题 + 每题"参考"方向

## 主题与价值观
- 教学目标三维度(知识技能 / 过程方法 / 情感价值观)

## 拓展资源(可选)
- 相关电影 / 文章 / 链接
