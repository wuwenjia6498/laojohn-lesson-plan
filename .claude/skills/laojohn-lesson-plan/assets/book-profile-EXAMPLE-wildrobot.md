- 译者:汤锐、陈方歌
- 出版社:接力出版社

- 字数:—

- 宣传语:一个没有感情的机器人,荒岛教会了她一切。

## 作者&背景
- 作者简介:彼得·布朗是美国著名图画书作家和插画家,出版作品有《我的老师是怪兽!》《老虎先生来撒野》《胡萝卜怪》《奇异花园》等。六次被评为《纽约时报》畅销书作家,赢得包括凯迪克大奖银奖、金风筝插画奖、《出版人周刊》年度图画书奖、亚马逊年度图书奖、E·B怀特朗读奖等多项大奖。
- 写作缘起(后记要点):作者一直着迷于机器人,也着迷于自然世界;他在农田、河流和森林的探险中长大,熟悉野生动物的行为。当思考人工智能时会涌现许多哲学问题——我们希望机器人能像人那样思考和有感觉吗?能信任机器人去做外科手术、照顾孩子、维护治安吗?在机器人包揽所有工作的世界里,人类如何消磨时间?这些问题成为他创作萝丝、写下第一本小说的灵感。他发现动物的本能与计算机程序有相似之处。
- 译后记要点(译者汤锐《情感、野性与母爱——人工智能的一种可能性》):本书既是儿童科幻小说也是冒险小说,且极富文学质感;核心启发之一是关于人工智能的展望以及人类自身生存处境的自省。人类开发AI初心是突破自身生理局限(力量、速度、精确度、记忆力、数据处理),但随着AI发展进化,它将如何影响人类生活,引发不确定性的思考与担忧。彼得·布朗在萝丝身上倾注了对AI前景的乐观想象——萝丝与岛上动物的关系不是弱肉强食,而是众生平等、自由博爱、合作共赢;而"锐酷"们的出现则是变数,指向AI发展截然不同的方向,表达世界的多元性。

## 内容结构
- 总章节:共 80 章,每章简短;章节标题简短,便于据标题预测和回顾。
- 分段(三段式)及划分依据:
  - **求生**:第1章(大海)— 第20章(鸟言兽语),共20章。萝丝从流落荒岛到学会鸟言兽语等生存技能,终于能在荒岛生存。
  - **共生**:第21章(自我介绍)— 第66章(庆祝会),共46章。萝丝从与动物相识到一起举行盛大狂欢,故事达到高潮。
  - **离开**:第67章(日出)— 第80章(天空),共14章。开始与结束都跟"天空"有关;飞船出现,经过战斗,最终带走萝丝,从天空消失。
- 主要人物及特征:
  - 萝丝(7134号罗森姆型机器人):流落荒岛的"野生机器人",会学习、观察,后成为小野鹅的妈妈,拥有思想和情感。
  - 布莱特比尔:萝丝收养的小野鹅"儿子"。
  - 熊妈妈与两只小熊;老鹅;荒岛上的各种动物。
  - 锐酷(RECO)机器人:前来追捕萝丝的其他机器人。

## 关键片段(章节 + 页码 + 用途)
1. 第五十章《按钮》大跨页插图及前后文字 —— 用途:导读课精读/朗读示范,体会插图与文字配合带来的紧张情绪(萝丝被按下按钮关闭又重启)。
2. 第四十七章《游行》P137 插图(熊妈妈背着受伤的萝丝,动物们跟随)—— 用途:交流课1插图回顾,标志动物们开始接纳萝丝为荒岛一员。
3. 第十三章《灾后》P028 —— 用途:交流课2细读推断,说明"本能"——动物是生存的行家,机器人并非万能(原文划线句:"很显然,这些动物是生存的行家。很显然,机器人并不是。")。
4. 第二十八章《老鹅》& 第三十四章《妈妈》—— 用途:交流课2细读,关于"学习"——动物有与生俱来的智慧,机器人有强学习能力,可相互取长补短。
5. 第四十八章《新脚》P141 —— 用途:交流课2细读,关于"合作"——动物各有所长且善于合作,机器人尚做不到;唯有合作才是共存之道。

## 重复出现的事物/场景(用于阅读交流2)
- **重复事物:火**
  - 第一次:萝丝生火,使动物们免于严寒,避免许多死亡。
  - 第二次:动物不慎,取暖之火引发火灾,造成极大伤亡。
  - 第三次:狂欢夜篝火,带来空前和谐,却引来路过船只注意,招来锐酷机器人,最终导致萝丝离岛。
  - 引申思考:火在人类历史上的划时代作用(恩格斯语);AI是否如火,既是划时代大事,也有危险性和不确定性,需合理使用。
- **重复场景:机器人墓地(第五章)、机器人尸体(第四十五章)**
  - 引申思考:机器人是否只是用过即弃的无生命工具?若机器人有情感,从伦理上是否正当?可联结电影《人工智能》。

## 阅读单设计
- **阅读单1:萝丝的荒岛历险记**(交流课1)——左列"萝丝能在荒岛生存、与荒岛动物们共生的原因",右列"我的依据是……"。参考填充:
  - 学习能力 → 从螃蟹学会爬岩石顶;从小棍虫学会伪装;从负鼠学会"表演";从老鹅学会当妈妈。
  - 观察能力 → 观察周围一切,学会鸟言兽语,能听懂动物语言,是融入荒岛的关键。
  - 机器人特性1(程序设定的规定动作)→ 让自己保持最佳工作状态。
  - 机器人特性2(强大信息存储与处理能力)→ 指导小鹅学飞,成为鹅群领袖。
  - 机器人特性3(远超人的速度/视觉/听力/体力)→ 救小熊;无休无眠工作,效率极高。
  - 拥有思想和情感 → 像妈妈一样照顾爱护小鹅;对动物友好。
- **阅读单2:作者的观点 vs 我的观点**(思辨课)——表头:人工智能 / 作者的观点 / 书中相关片段 / 我是否认同 / 我的观点;四行维度:对人工智能的展望、人工智能与人类的冲突、人工智能与人类的融合、人工智能发展的不确定性。

## 思辨问题(L3–L6,开放性 + 参考方向)
1. 与荒岛其他野生动物相比,萝丝不足的地方在哪里?(参考:本能——机器人并非万能,各有局限;动物自带生存本能。)
2. 作者反复写"火"想说什么?AI的出现是否与人类用火有相同之处?(参考:既划时代又有危险与不确定,需合理使用。)
3. 机器人墓地/尸体的重复场景引发什么思考?如果你的机器人朋友"死"了你会怎么处理?(参考:用过即弃是否正当;若有情感,伦理上的考量。)
4. 我们希望机器人像人一样思考和有感觉吗?(参考:希望——可做朋友解孤单;不希望——人机难辨令人不安。)
5. 在机器人包揽所有工作的世界,人类将如何消磨时间?(参考:鼓励想象,无固定答案。)

## 主题与价值观(三维教学目标)
- 知识与技能:通过情节梳理,了解并概括人工智能机器人的特点。
- 过程与方法:细读部分章节,借助情节推断作者写作意图;细读后记、译后记等非正文内容,学习多角度阅读和深度理解一本书的方法。
- 情感态度价值观:思考AI与人类、自然、道德、情感的关系,激发对人工智能的兴趣与理性认识。
