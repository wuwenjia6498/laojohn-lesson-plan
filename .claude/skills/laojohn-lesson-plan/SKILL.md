# 老约翰深度阅读 · 整本书课案详案生成器

本技能把一本指定童书 + 一份"书籍档案"转化为符合老约翰深度阅读读书会规范的逐字稿课案详案。

## 文件加载策略(先读这里,避免上下文浪费)

生成一本书时**不要全量读所有文件**。按下表取用:

| 层级 | 文件 | 何时读 |
|------|------|--------|
| **每次必读** | 本 SKILL.md、`grade-structure.md`、`style-and-format.md`、`lesson-templates.md`、`checklist.md` | 生成任何一本都读 |
| **生成方不读·复盘方读** | `review-rubric.md` | 第8步"通读复盘"的五维与协议**唯一源**,但复盘已独立为冷启动执行(派 fresh 子 agent / 用户新会话调 `laojohn-detail-review`),**由那个冷审 agent 读、本生成会话不读**;改其五维即改冷审依据 |
| **按需读** | `reading-strategies.md` | 该书要落地阅读策略时(基本都需要),读一次;含10策略"引→练→追问"卡片、学段侧重、策略↔能力↔工具对照 |
| **按需读** | `visualization-tools.md` | 该书要落地可视化工具时(基本都需要),读一次 |
| **按需读** | `examples/` 下范例 | **只取"等级+题材"最相近的 1–2 本**,绝不全量(12本纯正文合计约14万字,全吞会挤占生成空间) |
| **按需读** | `examples-usage.md` | 取范例前读一次,遵守"防串味"规则 |
| **按需读** | `assets/课案Markdown约定规范.md` | 需导出 .docx 时读一次,确保 Markdown 标记符合引擎要求 |
| **基本不读** | `source-docs/`(官方原文、样本证据、课标) | 仅在需要追溯依据或排查规则来源时查;**正常生成流程不读** |

> 规则已沉淀进上面几个"必读/按需"文件,生成时读它们即可,无需回查 source-docs 的原始证据。
>
> **体量参考**(便于预估上下文):必读核心层约2.5万字;单本范例纯正文约1万多字(L1最短约6千,L5最长约1.8万);典型一次生成 = 必读 + 可视化与策略(约1.2万)+ 1–2本范例 ≈ 5–7万字。

## 范围

本技能**只产出逐字稿详案**一项。不生成 PPT、思维导图、独立阅读单册、书目海报、反馈话术等其他配套。

## 工作流程(必须按顺序)

1. **确认输入(硬闸 · 缺料必须停下要,不得自行开写)**:检查用户是否提供了 (a) 书名与等级(L1–L6),(b) 一份《书籍档案》或等价材料(书籍目录 + 全文/足量原文片段)。
   - **若缺少《书籍档案》且无目录+原文**:**必须停下来向用户索取**一份已填好的《书籍档案》,或等价材料(目录 + 全文/足量原文片段)。**禁止以"我了解/读过这本书""资料已足够""凭已知信息即可"为由继续生成。** 模型对童书的记忆不可作为情节、章节、人物、原文的来源——这是本技能最高优先级的约束。(档案如何产出与本技能无关:手工填写、或由上游建档技能生成均可,本技能只负责"读已填好的档案、据以生成详案"。)
   - 用户坚持"先出个初稿"时:可以生成**结构骨架**(课型框架、环节标题、策略/工具安排、话术模板),但**所有依赖具体内容的位置一律留占位**(见核心约束的"伪摘录禁令"),不得用编造内容填满。
   - **审核档案**:核对等级是否与官方书目一致;检查必填项是否齐全;若页码标注为"约/参考"或版本不明,生成时改为"(页码以实际版本为准)"——**此机制仅用于"有真实来源但页码存疑"的情况,绝不可用作编造整段情节/原文的兜底**。
   - **两种档案形态要分清(靠档案自身特征判断,不依赖任何模板文件)**:① **设计层已填好的档案**(可视化工具/阅读单/思辨题/三维目标都给了,且多附文本依据)→ 设计层按档案给的来,不自行发挥。② **设计层留空的档案**(只给事实、设计字段空着或注明留待设计)→ **阅读单、可视化工具、思辨问题、三维目标由你依据书的事实自行设计,不要因这些字段"缺失"而停下索取**。
     - **注意档案的"事实层"可能包含这些字段**:除情节/人物/章节/页码/原文外,还有「全书事件序列」「可作横向对照的内容(+维度线索)」「贯穿全书的变化线索(状态节点)」「主题词」等。这些都是**事实**,必须读取并据以生成(事件链取事件序列、维恩图取对照组、成长阶梯/时间轴取变化线索、思辨方向参考主题词),**不属于"可自行设计"的范围**。
     - 无论哪种形态,**事实层始终只能来自档案,不得编造**;能自行设计的仅限"教学设计",绝不包括"书的事实"。档案中凡标注"无原文,仅概述"的片段,引用处一律走占位,不得补写伪原文。
2. **确定课型结构**:依据等级查 `references/grade-structure.md` 决定课时数与每节课型。
   - **2b 判定文本类型(设计重心的依据)**:据《书籍档案》`类型`字段按**三选一互斥**规则判定本书属于 **故事、小说类 / 非虚构文本 / 经典文学名著** 之一(**用户定调优先**——用户明确指定或否掉判定时从用户;无定调才走缺省判定顺序:先判非虚构 → 再判经典名著[名著优先,既是小说又是名著归名著] → 否则故事小说类)。判定规则与「三类文本 × 课型设计重点对照表」见 `references/lesson-templates.md` 开头新节。此判定仅作内部设计驱动,不新增对外输出字段。
3. **生成书级头部(仅在第1节最前面附一次)**:教案提纲七项表格 + 文本介绍 + 书级三维教学目标。后续各节不再重复。
4. **逐节生成**:对每个课型,读取 `references/lesson-templates.md` 中对应模板,用《书籍档案》内容填充。**每节按“课型 × 已判定文本类型”从开头对照表取该格设计重点,再落到具体环节**——避免张冠李戴(勿给科普书套“预测故事/人物塑造”,勿给普通当代小说套“作者时代背景/文学价值”)。每节须包含:
   - **该节的三维教学目标**(知识技能/过程方法/情感价值观,可只突出当节侧重的1-2维但需成条);
   - 各环节标题带时长,合计 60 分钟;
   - 该节用到的**阅读策略**与**教学方式**要真正落地:**策略不靠旁注贴标签,而要写成让学生真正做这个动作的环节(提问/阅读单/任务)**;重点策略按 `references/reading-strategies.md` 的"引→练→追问"卡片走。**策略按本书内容从该等级"可选池"中选 3–7 项、本课重点显性训练 1–2 项,不机械照搬全级清单**(可选池见 grade-structure.md 实证修正框,学段侧重与卡片见 reading-strategies.md)。
   - **可视化思维工具必须真正落地**:每种工具都以 Markdown 空白表格或节点清单呈现(A档:不画图、不出图形代码),并有"引出→填写→分享+反馈"的完整环节,且提纲所列工具与正文一一对应,不得只在提纲挂名。具体用法见 `references/visualization-tools.md`。
5. **保证衔接**:每节结尾为下一节布置任务/埋伏笔,下一节开头接住上一节任务。四节须在同一次生成流程中保持连贯。**注意同日连排约束**:第2、3节同日连排、中间无自读,第2节课尾不得布置课后阅读类任务;"再读原文"类作业只能挂跨周接缝(第1↔2、第3↔4节)——推导与正反例以 grade-structure.md「同日连排约束」框为**唯一源**。
6. **套用话术与格式**:全程遵守 `references/style-and-format.md` 的语气、句式、排版约束。
7. **自检(交付前必做,不得省略或笼统带过)**:对照 `references/checklist.md` **逐项**核验后再交付。
8. **通读复盘(冷启动·独立执行 · 交付前必做,与第7步分工不同)**:第7步查“规则有没有违反”(合规);本步查 checklist 查不出的**质量问题**。**这一步必须「换人审稿」,绝不能「自己再看一遍」**——生成者顺接自审会为自己的设计辩护、`默认有问题`空转,等于走过场。因此**不在本生成会话里自审**,而是冷启动独立执行,二选一:
   - **首选(形态A · 强隔离)**:第7步 checklist 过后**停手**,派一个**全新的(fresh,非 fork)子 agent** 来复盘,任务给:“读并遵循 `.claude/skills/laojohn-detail-review/SKILL.md`,待审稿件 = `<读书会详案输出/…-课案详案.md 的绝对路径>`”。子 agent 跑完把报告交回,你原样转述给用户(A 块已改、B 块待定夺)。
   - **等效(形态A · 手动)**:不便派子 agent 时,告知用户在**新会话**里调用 `laojohn-detail-review` 对这份 .md 跑独立复盘(同样不带生成上下文,与派子 agent 同属形态A)。

   (**形态B** 专指"同一会话顺接、显式封存生成过程后自审"的降级兜底,效果最弱,仅在无法另起时使用——命名口径与 `laojohn-detail-review/SKILL.md` 一致。)形态细则(含形态B的封存办法)、审稿人协议五条、五维查项、分流与报告格式,**一律以 `laojohn-detail-review/SKILL.md` 及其加载的 `references/review-rubric.md` 为准,此处不复述**。生成方只需记住两点:本步换人冷审、不自己复盘;真实性红线在复盘补全时同样不豁免——碰原文/情节/页码/人物一律占位,禁止凭记忆补成伪原文。
9. **(可选)导出 Word**:若用户要 .docx,把通过自检的 Markdown 存成 `.md`,运行 `python assets/md_to_laojohn_docx.py 详案.md`,即得官方样式 docx(详见"输出形态")。

## 核心约束(违反即返工)

- **页码与片段必须来自《书籍档案》或用户提供的原文**,不得虚构。引用书中原文片段时,标注章节与页码,单段摘录控制在合理篇幅,避免大段照抄。
- **伪摘录禁令(违反即返工)**:**没有真实原文来源时,严禁输出任何带引号的"书中原文",也严禁使用"节选自第X章""——节选自……"等让人误以为是真实摘录的标注。** 缺原文处一律写占位:`(教师朗读【待补:第X章 / 某情节段落,以实际书籍为准】)`,把"缺料"显式暴露出来,不得用模型仿写的句子冒充原文。同理,章节归属、人物设定、情节细节若无来源,不得编造填入——宁可留占位,不可造假象。
  - **设计中临时需要档案之外的原文时,同样占位,不得凭记忆补。** 生成过程中常会发现某环节想引一段档案未提供的原文——此时唯一可信来源是用户提供的全文/电子版;若未提供,**一律占位**,绝不用模型记忆填充。**对热门/经典书尤其警惕**:模型记得这类书的细节往往似是而非(页码、人名、逐字原文易错),这种自信的记忆是伪摘录高发区,可信度不因书出名而提高。档案之外但我好像记得≠可用来源。
- **讲解自洽红线(违反即返工)**:伪摘录红线管"书的事实层";本条管**老师临场生成、非逐字取自档案的话术**(比喻、换算、对照、举例等)。判断基准一句:**这句话单独拎出来,常识上站得住、逻辑上不自相矛盾、和要说明的点对得上吗?** 拿不准就退回平实陈述。**涉及数字的比喻,锚点必须取自《书籍档案》已核实真值,不凭记忆现编尺寸。**(错型与回读做法见 `references/checklist.md`「讲解自洽」组。)
- **课时数严格匹配等级**(见 grade-structure.md)。
- **每节课各环节时长合计 = 60 分钟**,且**每个环节时长一律取 5 的倍数**(5/10/15/20…,无一例外:开场白、布置任务、PPT 过渡等短环节同样按 5 分钟计,不写 3、7、13 这类"假精确"数字)。两条并列约束:先按教学轻重把 60 分钟分到各环节,再调成 5 的倍数,保证调完合计仍正好 60(都是 5 的倍数,数学上必能凑齐,不要机械四舍五入致总和偏离 60)。
- **环节时间要按真实教学动作可行、宁可深讲不赶(违反即返工)**:合计 60、取 5 的倍数只是底线;更要保证**每个环节标称的分钟,真装得下它串起来的全部教学动作**(讲解＋朗读＋学生读＋抛问＋学生回答＋追问＋小结/填表),并把真实课堂摩擦(学生答偏要重引、过渡、安顿)算进去。一个环节塞不下时,**宁可把一两件事充分展开、其余降格为快速一例或后移到别处,也不要五六件事都匆匆带过**——尤其导读课读法示范,深讲一篇即可,不必一口气精读多篇。(复盘时按 review-rubric 维一“逐环节耗时累加”核查。)
- **导读课不预设已读红线(违反即返工)**:导读课(第 1 课时)是整本书阅读的第一课,学生此时**尚未读这本书**。导读课的一切活动必须**自含**——要分析/比较/推断的文本,只能是教师当堂朗读、或学生当堂阅读的样篇;**严禁设计任何“需学生已读过该篇/全书”才能完成的环节**(如比较两篇、评价全书人物、揭某篇谜底)。需课后阅读才能做的任务,只能留作课后、挂在跨周接缝。(交流课/思辨课排在跨周自读之后,可依赖已读;此红线只约束导读课。复盘时按 review-rubric 维三“导读课红线”核查。)
- **保留固定话术骨架**:"师:""学生互动分享""参考:……""(教师总结)"。**不再埋 PPT 换页点**:详案不写 `【PPT换页-PXX】` 等换页标记——分页权已交给下游 `laojohn-ppt-draft`,由它按"教学节拍"自行切页(详案只需用 `## 第N课时 · 课型` 划课时、`### 一、xx` 划环节,工具据此分页)。
- 思辨问题须开放、可多角度作答,并给出"参考"而非唯一答案。
- **写作技法:默认不主动讲,按需解锁(违反即返工)**。基线"用而不教"——写作只作读后迁移/应用活动出现;仅当用户**明确要求**读写结合/讲写法时解锁,且只挂在已有读后写作任务"动笔前"、真实性红线不豁免。三条边界的完整口径以根 `CLAUDE.md` §6「写作技法解锁口」为**唯一源**,此处不复述;需系统化独立教写作走 `laojohn-writing-lesson`。

## 输出形态

### 固定输出目录

> ⚠ 本项目位于移动硬盘，盘符可能随挂载变动。执行前请用 `(Get-Location).Path` 确认实际项目根目录（见 CLAUDE.md §1），下方 `<项目根目录>` 代表该路径。

**所有产物统一保存到：**

```
<项目根目录>\读书会详案输出\
```

文件命名规则：`<书名>-课案详案.md`（如 `俗世奇人-课案详案.md`）；导出 .docx 时同名同目录：`<书名>-课案详案.docx`。

---

默认输出 Markdown 详案。**生成 Markdown 时必须遵守 `assets/课案Markdown约定规范.md` 的标记格式**,这样产出的 .md 才能被排版引擎正确转换。要点:
- 文档主标题用 `#`,每个课时标题用 `## 第X课时 · 课型`,课时内环节用 `### 一、…`;
- 师话以 `师：` 开头;参考以 `参考：` 开头;学生互动写整行 `学生互动分享` / `学生自由分享`;
- 三维目标条用 `【知识技能】…` / `【过程方法】…` / `【情感价值】…`;
- **不写 PPT 换页点**(`【PPT换页-PXX】` 已废弃,分页交由 `laojohn-ppt-draft` 按教学节拍处理);原文/宣传语用 `> ` 引用块(占位仍用 `(教师朗读【待补：…以实际版本为准】)`,不加 `>`);
- 可视化工具/阅读单用标准 Markdown 表格(`|` 分隔,空格留空,单元格内换行用 `<br>`);
- 每课时末写 `本课完。`,全文末写 `全课完。`。
- **引号**：一律中文弯引号、**严禁** ASCII 直引号；**导出 .docx 前务必对 .md 全文检索 `"` 与 `'`（Markdown 语法/代码除外），命中即改为弯引号**——引擎安全网对跨行、奇数个、弯直混排会判错方向，不可托底。码位与细则以 `assets/课案Markdown约定规范.md` §7 为**唯一源**。

**需要 Word(.docx)时,不要手写 docx,改用本 skill 自带的固定排版引擎:**
1. 先把详案保存为 `.md` 文件(如 `手斧男孩-课案详案.md`);
2. 运行 `python assets/md_to_laojohn_docx.py 详案.md [输出.docx]`(不给输出名则自动同名 .docx);
3. 引擎自动套用老约翰官方样式——宋体12pt/行距1.5、层级靠加粗与居中、米色表头(F5E6C6)的 Table Grid 表格、橙色(#E99743)的 PPT 页标〖PPT 第N页…〗(由 laojohn-ppt-draft 在出 PPT 后反向回注进详案、非详案生成时所埋;另对已废弃的旧换页点 ED7D31 仍作向后兼容渲染)、左右两端对齐的页眉+下分隔线、居中页码、每课时另起一页。无需任何手动排版。
4. 引擎首次运行会自动检测并安装依赖 `python-docx`,无需手动准备环境。

> 引擎只负责"排版",不改动任何文字内容;真实性约束(伪摘录禁令、占位规则)在生成 .md 阶段就已落实,引擎原样保留。

## 生成后的优化(改写阶段:多数不必重载本 skill)

> **复盘与优化的分工**:上面第8步的「冷启动独立复盘」(由 fresh 子 agent 或新会话的 `laojohn-detail-review` 执行)负责**找问题、出诊断报告**(无争议项已直改、教学判断项只诊断不替决);本节负责**按报告动手改**。完整链路:生成 .md → 冷启动独立复盘出报告 → 用户对“待定夺”项拍板 → 按下面规则执行修改 → 重出 docx。


课案一旦产出为 .md 源稿,用户常会按自己的想法继续优化。**判断标准:改的是"文字"还是"骨架"。**

- **改文字 → 不必触发本 skill。** 措辞润色、调整某道思辨题的角度、改师话口气、改阅读单填法/提示语、增删个别问题等局部编辑,只需提供两样东西:① 该课案的 .md 源稿(作为上下文直接在其上编辑);② `assets/课案Markdown约定规范.md`(确保不碰坏 `师：`、`参考：`、表格 `|---|` 分隔行、`##`/`###`、以及 ppt-draft 出 PPT 后回注的 `〖PPT第N页…〗` 页标等标记,否则转 docx 会样式错乱;`【PPT换页-PXX】` 已废弃,遇到残留应删除而非保护)。改完对 .md 全文检索 ASCII 直引号 `"`/`'`,命中即改为弯引号,再跑 `python assets/md_to_laojohn_docx.py 课案.md` 重新出 docx。

- **改骨架 → 回到本 skill 的对应部分。** 增减课时、更换可视化工具种类、改变分级假设(如"按 L5 重做")、补全占位原文/扩写情节等结构性改动,需重新动用 skill 的结构与工具知识(读相关 reference)。

- **唯一全程不豁免的约束:真实性红线。** 无论是否重载 skill,只要优化涉及补原文、扩情节,都禁止凭记忆编造、禁止伪摘录;无原文确证时一律保持 `(教师朗读【待补：…以实际版本为准】)` 占位。"现在只是改写"不是放松此约束的理由。
