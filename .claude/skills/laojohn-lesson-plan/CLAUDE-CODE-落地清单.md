# Claude Code 落地清单

本清单是这个 skill 的总路线图与决策备忘。分两部分:**不变的决策**(定了就长期有效)与**待办路线**(做完即失效)。

---

## 一、不变的决策(回看时先读这里)

1. **一个 SKILL,不拆**。按课型拆模板文件控长度,按年级拆参数写进 `grade-structure.md`;不拆成多个 SKILL(否则衔接断、维护翻倍)。
2. **SKILL 只产出逐字稿详案**这一项内容。不做 PPT、思维导图、海报、话术等二次创作。
   - 例外仅是"换格式呈现":详案以 Markdown 为源稿,可经自带引擎转成官方样式 docx;这不是新增内容产物,只是排版。
3. **产出链路 = md 源稿 → 引擎 → docx**。
   - AI 按 `assets/课案Markdown约定规范.md` 生成合规 .md;
   - 需要 Word 时运行 `python assets/md_to_laojohn_docx.py 课案.md`,自动套老约翰官方样式(宋体12pt/行距1.5、米色表头、橙色PPT锚点、页眉页脚、每课时分页),引擎首次运行自动装 python-docx;
   - 引擎只排版、不改字;真实性约束在生成 .md 阶段已落实。
4. **工具天花板 = 书籍档案天花板**。课案质量上限取决于档案质量,不取决于 SKILL 写得多花哨。最重要的把关动作是填好档案,不是改 SKILL。
5. **范例只供风格结构参考,内容必来自当前书的档案**。范例渐进加载,**只取"等级+题材"最近的 1–2 本,绝不全量**(12本纯正文约14万字,全塞反而挤占生成空间)。
6. **档案按需生成,不预先囤库存**。用户要做哪本,才补哪本的档案;不存在"先把N本档案补齐再开张"。
   - 已支持纯事实档案(`FACTS-ONLY` 模板):事实层不可编造,设计层(阅读单/工具/思辨题/三维目标)由 AI 自行设计;
   - 已验证可"从成品详案反向抽取档案"(手斧男孩即如此),所以补档案是可即时、半自动完成的动作。
7. **真实性红线,任何阶段不豁免**。无原文确证一律占位 `(教师朗读【待补:…以实际版本为准】)`;禁止凭记忆编情节、禁止伪摘录。生成阶段如此,后续改写阶段同样如此。

## 二、生成后的优化流程(改写阶段)

课案产出为 .md 后,用户常按自己想法继续优化。判断标准:**改的是"文字"还是"骨架"。**(SKILL.md「生成后的优化」节有同款规则,此处为路线层面的提示。)

- **改文字 → 不必重载 SKILL**。措辞、某道思辨题角度、师话口气、阅读单填法等局部编辑,只需:① 该课案 .md 源稿;② `assets/课案Markdown约定规范.md`(守住 `师：`/`参考：`/表格 `|---|` 分隔行/`##`·`###` 等标记;换页点 `【PPT换页-PXX】` 已废弃,勿新增)。改完跑引擎重出 docx。
- **改骨架 → 回到 SKILL 对应部分**。加减课时、换可视化工具种类、改分级假设、补占位原文/扩情节,需重新动用结构与工具知识(读相关 reference)。
- 在同一段连续对话里,用户一句"这个工具不合适,换个更扎根文本的"即可让 AI 自行回查 `visualization-tools.md`,无需逐条报要求;新开会话或要钉死边界时,再显式给出 md + 规范 + 明确要求。

## 四、SKILL 替代不了、必须人/老师把关的三件事

1. **页码与版本**:SKILL 一律占位,须拿指定版本核对填入。
2. **档案质量**:档案错,SKILL 会把错误放大成一万字。填档案是关键把关点(对应决策 4)。
3. **教学法火候 + 分级口气**:导入吸引力、提问梯度、深浅是否合该年级——教研判断,非格式判断,标尺在老师手里。

## 五、是否上传电子书的决策规则(给填档案的人看)

要不要给某本书上传电子版,**不取决于书的长短**,取决于两条轴:**① AI 对这本书记忆的可信度;② 档案"可引用原文"栏的缺口大小**。书长只影响"传的上下文成本",不决定"该不该传"。

| 情形 | 建议 | 理由 |
|---|---|---|
| 热门/经典书 + 档案原文充足 | **可不传** | 档案供原文、模型记忆供结构,缺原文处占位即可 |
| 热门/经典书 + 档案原文薄 | **传,或先把档案原文补厚** | 短篇集补档案通常比传全本划算 |
| 冷门/小众/新书 + 没电子书 | **必须把档案做扎实**,严格"没原文就占位、绝不编造" | 模型对冷门书记忆残缺甚至张冠李戴,不可信 |
| 冷门/小众/新书 + 有电子书 | **强烈建议传** | 记忆不可信,电子书是设计时唯一能查证的真源 |

**一句话总线**:传电子书的收益,与"AI 对这本书记忆的可信度"成反比、与"档案原文完整度缺口"成正比。越冷门、档案缺口越大,越该传;越热门、档案越全,越可不传。

**两个要点**:① 传也要**版本对得上**(同一出版社/印次),否则引出的原文页码仍错,只能标"以实际版本为准";② 不传时,务必在指令里加兜底——"凡档案未提供原文处一律占位 `【待补:…以实际版本为准】`,不编造",这条 SKILL 的伪摘录禁令已强制,但显式重申更稳。

**短篇集特例(如《俗世奇人》)**:篇幅短、靠"选几篇讲透",细读很少需要跨段连续原文。与其传十几万字全本,不如**在档案"可引用原文"栏给每篇一两句最标志性的真句子**——既省上下文,又消除编造风险。

## 六、现成文件清单(本目录)

**主文件**
- `SKILL.md` — 主调度(加载策略/范围/工作流/核心约束/输出形态/生成后优化)

**references/(生成期知识)**
- `grade-structure.md` — 六年级分级参数表
- `lesson-templates.md` — 四课型生成模板
- `style-and-format.md` — 话术+格式+分级口气规则
- `visualization-tools.md` — 5 个官方可视化工具范例 + "别让工具挂名"原则(A档纯文字骨架)
- `checklist.md` — 交付前自检
- `examples-usage.md` — 范例库加载与防串味规则(含 L5–L6 范例特别说明)
- `reading-strategies.md` — 10 策略"引→练→追问"卡片、学段侧重、策略↔能力↔工具对照
- `review-rubric.md` — 成稿质量复盘五维与审稿人协议(冷审唯一源,生成方不读)
- `examples/L1..L6/` — 每级 2 本风格结构范例(共 12 本)
- `source-docs/` — 官方原文、样本证据、课标、可视化工具官方案例图(基本不读,仅追溯依据时查)

**assets/(模板与工具)**
- `book-profile-template.md` — 书籍档案完整模板(含设计字段)
- `book-profile-EXAMPLE-wildrobot.md` — 荒岛机器人填好的样例(示范颗粒度)
- `book-profile-FACTS-ONLY.md` — 纯事实档案模板(测试 AI 设计能力)
- `课案Markdown约定规范.md` — 生成 .md 的标记规范(改写/转 docx 都依赖)
- `md_to_laojohn_docx.py` — 固定排版引擎(md → 官方样式 docx,自带依赖自检与注释跳过)
