# 各课型生成模板

每节课 60 分钟,环节顺序固定,时长据样本给出参考分配。具体内容从《书籍档案》填充。

## 导读课(所有等级第1节)

教学目标:激发兴趣、预测想象、为深入阅读做准备。

| 环节 | 参考时长 | 内容来源 |
|------|---------|---------|
| 课程导入&话题激趣 | 10–20 min | 由书名/封面/主题引出;可联结学生生活经验或上一本书 |
| 精彩片段共读 / 抢先看 | 5–25 min | 选《书籍档案》中"关键片段+页码";绘本走精读、小说走剧透式设问 |
| 自由阅读 / 预测想象 | 20 min | 附自读检测表(小说)或预测阅读单(绘本) |
| 阅读建议&计划布置 | 5–15 min | 作者介绍、章节特点、分段任务、7天阅读计划 |

收尾:`本课完。`

## 阅读交流课(L1–L2 第2节 / L3–L6 第2、3节)

L1–L2(单节):阅读感受分享 → 插图回顾故事 → 故事探索分析(共鸣点、问题解决原因)→ 创意写作 → 课堂总结。

L3–L6 阅读交流1:分享感受 → 情节梳理(如三段式划分)→ 内容梳理讨论 + 阅读单 → 总结概括 + 资料补充阅读。

L3–L6 阅读交流2:细读关键片段做推断(片段+作者观点)→ 细读"重复"事物/场景、推断作者意图 → 布置思辨任务(后记/译后记/拓展)。

## 思辨&应用课(L3–L6 第4节)

来源:书的后记、译后记、宣传语、外部资料。课型骨架:
- 趣味表达:就后记问题分享观点。
- 思辨应用:作者观点 vs 我的观点(表格阅读单)。
- 主题分享:我知道的/想分享的/想了解的。
- 课堂总结:`全课完。`

> 具体任务类型(情境模拟/创编/续编/人物采访/辩论/实践等)见 `style-and-format.md` 的"思辨&应用课型任务"一节,此处不重复。
