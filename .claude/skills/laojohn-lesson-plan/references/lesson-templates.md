# 各课型生成模板

每节课 60 分钟。下列各课型给出的是**环节菜单**而非定死的流水线:除标注“必选”的环节外,其余环节**依据具体书目按需选用全部或部分**,顺序也可按这本书的最佳教学逻辑调整。**这样设计是为了避免不同书目生成出雷同套路**——同一课型在不同书上应呈现不同的环节组合与侧重,而非千篇一律。具体内容一律从《书籍档案》填充。

> 环节时长不再逐项定死:按“选了哪几个环节 + 这本书的轻重”把 60 分钟自行分配,允许浮动。绘本(L1–L2)环节少、单环节可长;小说(L3–L6)环节多、节奏紧。

## 三类文本 · 课型设计重点对照(按书择重的第一层依据)

这是“按书取舍、组合求异”的**第一层依据**:同一课型面对不同文本,设计重心不同。**先据文本类型定该课型的设计重心,再在对应课型的环节菜单里选具体环节**——避免把科普书套成“预测故事/人物塑造”、把普通当代小说套成“作者时代背景/文学价值”。

**文本类型判定(三选一·互斥·就近命中即止):**
1. **先判非虚构** —— 科普 / 知识类 / 人物传记纪实 / 说明性文本 → **非虚构文本**(不论是否有名,其设计线是“信息·说明方法·探究实践”,比文学赏析更适用)。
2. **再判经典名著** —— 文学类中公认的经典 / 名著(有稳定传播与译介史、常列“经典名著”书目,如《格列佛游记》《汤姆索亚历险记》《纳尼亚传奇》)→ **经典文学名著**。**此步即“名著优先”**:一本书既是小说又是名著时归**名著**列。
3. **否则** —— 当代 / 普通儿童小说、童话、故事集、桥梁书 → **故事、小说类**。

> 判定依据 = 《书籍档案》`类型`字段(自由文本,如“游记体讽刺小说”)+ 体裁常识。文本类型判定属“体裁归类”、不属“书的事实层”(情节/页码/人物),据档案 `类型` 字段与体裁常识判断即可,不违反“事实不凭记忆”红线;档案 `类型` 缺失或模糊时可据书名/主题/内容判断体裁大类。

| 课型 | 故事、小说类 | 非虚构文本 | 经典文学名著 |
|------|------|------|------|
| 导读课 | 激发阅读兴趣,预测故事,认识人物,学习阅读策略 | 激活背景知识,提出探究问题,认识文本结构,明确探究任务 | 了解作者与时代背景,认识作品价值,建立阅读框架 |
| 交流课1 | 梳理故事内容,分析人物与情节,理解故事结构 | 提取关键信息,梳理知识结构,理解核心概念 | 梳理作品内容,分析人物形象,理解作品整体结构 |
| 交流课2 | 分析关键情节、人物塑造、主题表达,学会用文本证据支持观点 | 理解科学原理或事实依据,分析说明方法,建立知识联系 | 分析艺术特色、语言风格、主题思想,理解经典的文学价值 |
| 思辨&应用课 | 评价人物与事件,联系生活,迁移阅读体验 | 运用知识解决问题,开展探究实践,设计项目成果 | 探讨经典价值,联系现实,进行跨文本阅读与文化思考 |

> **L1–L2(仅导读课 + 单节阅读交流课)的折叠规则**:矩阵四列课型对应 L3–L6 的四节;L1–L2 取「导读课」列 +「交流课1」列为单节交流课主线(按低龄浅化),矩阵「思辨&应用课」列的“联系生活/迁移阅读体验”落在交流课收尾的「阅读成果」环节。

## 导读课(所有等级第1节)

教学目标:激发兴趣、预测想象、为深入阅读做准备。

> 按文本类型择重(见开头对照表):故事小说走“激发兴趣+预测故事+认识人物”;非虚构走“激活背景知识+提出探究问题+认识文本结构+明确探究任务”;经典名著走“作者与时代背景+作品价值+建立阅读框架”。

环节菜单(★必选,其余按书选用):

- **★ 激发兴趣 / 课程导入**:由书名、封面、主题、作者或一个悬念问题引出;可联结学生生活经验或上一本书。
- **精彩片段共读 / 抢先看**:选《书籍档案》中“关键片段+页码”;绘本走精读细赏,小说走剧透式设问、只亮钩子不揭底。
- **预测故事**:就封面/书名/已读片段预测走向,附预测阅读单(绘本)或自读检测表(小说)。
- **认识一本书**:作者其人其事、书籍背景、章节体例、目录与版式特点——帮学生“看懂这是一本怎样的书”。
- **阅读方法引导**:针对这本书的难点给一两个上手的读法(如做批注、画关系图、追线索、查注释),不贪多。
- **★ 布置阅读任务**:分段任务、阅读计划(如7天计划)、自读记录表。

> 选用建议:不必每本书都铺满六个环节。情节性强的书侧重“精彩片段+预测”;信息量大/体例特殊的书侧重“认识一本书+阅读方法”;据书取舍,组合求异。

收尾:`本课完。`

## 阅读交流课

### L1–L2(单节 · 第2节)

> 按文本类型择重(见开头对照表 + 折叠规则):此单节交流课以「导读课」列 +「交流课1」列为主线,按低龄浅化——故事小说走“梳理内容+人物与情节”,非虚构走“提取关键信息+核心概念”,经典名著走“梳理内容+人物形象”;「思辨&应用课」列的“联系生活/迁移体验”落在收尾的「阅读成果」环节。

环节菜单:阅读回顾 → 分享阅读发现 → 理解故事 → 阅读成果。

- **阅读回顾**:借插图/关键画面带学生重走故事线,唤醒记忆。
- **分享阅读发现**:学生自由说“我注意到的/我喜欢的/我不懂的”。
- **理解故事**:聚焦共鸣点、人物心情、问题是怎么解决的——把故事读懂读透。
- **阅读成果**:创意写作 / 续画 / 复述 / 角色扮演等任选其一,落一个看得见的产出,再课堂总结。

### L3–L6 交流课1(第2节)

定位:**先把书读全、读清**——梳理与初步分析为主。

> 按文本类型择重(见开头对照表):故事小说走“梳理故事内容+分析人物与情节+理解故事结构”;非虚构走“提取关键信息+梳理知识结构+理解核心概念”;经典名著走“梳理作品内容+分析人物形象+理解作品整体结构”。

环节菜单(按书选用):

- **内容梳理**:情节脉络、时间线、章节大意(如三段式划分、事件链)。
- **人物**:主要人物关系、性格、成长变化。
- **情节或文本结构分析**:转折、悬念、线索、叙事结构(如双线、倒叙、书信体)——据这本书实际有的结构特点选讲。
- **内容探讨**:就梳理出的内容展开一两个讨论点,引向理解。
- **阅读方法应用**:用导读课给的读法(批注/关系图/阅读单)真正动手一次。

> “人物”“情节或文本结构分析”按书择重:人物群像突出的书讲人物,结构精巧的书讲结构,不必都讲。

### L3–L6 交流课2(第3节)

定位:**在读全的基础上读深**——细读、探究、找证据。

> 按文本类型择重(见开头对照表):故事小说走“分析关键情节+人物塑造+主题表达,用文本证据支持观点”;非虚构走“理解科学原理或事实依据+分析说明方法+建立知识联系”;经典名著走“分析艺术特色、语言风格、主题思想,理解经典的文学价值”。

环节菜单(按书选用):

- **细读文本**:挑关键片段逐句品,做推断(片段 + 作者言外之意)。
- **重点情节或内容探讨**:就最值得深挖的情节/母题(如反复出现的事物、象征)追问作者意图。
- **作品写法**:这本书在写法上的独到处(讽刺、伏笔、视角、语言风格)——只点书中确有的,不硬塞。
- **主题探究**:从内容走向主题,提炼这本书想说什么。
- **阅读证据论证**:任何判断都回文本找依据,练“观点—证据”的实证读法,可用阅读单承载(章/页 | 我的依据)。

## 思辨&应用课(L3–L6 第4节)

定位:深度阅读发现 → 思辨讨论 → 联系生活 → 阅读成果。

> 按文本类型择重(见开头对照表):故事小说走“评价人物与事件+联系生活+迁移阅读体验”;非虚构走“运用知识解决问题+开展探究实践+设计项目成果”;经典名著走“探讨经典价值+联系现实+跨文本阅读与文化思考”。

来源:**文本自身的两难抉择与开放问题**为主;后记、译后记可作引子,外部资料酌情补充。**不以封底名家荐语/宣传语作为思辨对照对象**——荐语属营销物料、非书内容,思辨须回到文本。

环节菜单:

- **深度阅读发现 / 趣味表达**:就一个开放问题(可由后记引出)分享初步想法,亮出尚未定论的疑点。
- **思辨讨论**:**两难思辨阅读单**——给出文本中“没有标准答案”的抉择/问题,引导“从读过的章节找证据 → 亮出我的判断 → 讲清理由”(表格:思辨问题 | 书中相关片段(章/页) | 我的判断 | 我的理由)。
- **联系生活 / 主题分享**:我知道的 / 想分享的 / 想了解的,把书中议题接到学生的真实生活。
- **阅读成果**:落一个任务驱动的产出,再课堂总结。

> 具体任务类型(情境模拟/创编/续编/人物采访/辩论/实践等)见 `style-and-format.md` 的“思辨&应用课型任务”一节,此处不重复。

收尾:`全课完。`
