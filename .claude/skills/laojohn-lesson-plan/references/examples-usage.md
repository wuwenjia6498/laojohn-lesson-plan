# 范例库使用规则(references/examples/)

存放已完成的可信详案,按等级分目录:`L1/ … L6/`,文件名带题材标签。
现已入库 L1–L6 各2本(共12本,跨题材);后续精修成品可回灌充实。

## 加载规则(防上下文爆炸)

- **绝不全量加载。**
- 生成某本书时,**按"等级 + 题材"只取最相近的 1–2 本**范例入上下文。
  - 例:生成 L4 儿童小说 → 取 L4/ 下的儿童小说范例 1–2 本;没有同题材则取相邻等级同题材。

## 防"串味/抄错"规则(关键)

范例**仅供风格、结构、话术参考**。严格遵守:

- **所有人物、情节、章节、页码、片段,必须来自当前书的《书籍档案》,不得从范例搬运。**
- 不得把范例的情节骨架(如荒岛"求生—共生—离开")硬套到新书;新书用新书自己的分段。
- 不得模仿范例时编造新书并不存在的片段。
- 范例可能含笔误,**不模仿其错误**;以风格神韵为准,不逐字复制。

## L5–L6 范例的特别说明

L5–L6 已各有2本入库,但**经典名著/科幻外的题材(文言、人物传记)仍偏少**。遇到这些题材时,L5–L6 详案宜作**初稿**,经高年级教研老师精修后回灌本目录。新范例的筛选标准见 `L5-L6-example-criteria.md`(仅筛选时读)。
