# 阅读策略的运用

来源:官方《整本书阅读策略和可视化思维工具运用》文件(10策略定义、学段侧重、五维能力)+ L1–L6 共12本成品详案的落地措辞。
配套:工具落地见 `visualization-tools.md`;策略的分级可选池与学段侧重见 `grade-structure.md`。

## ★核心问题:别让策略"贴标签"

可视化工具最大的毛病是"挂名"(提纲列了、正文不用);阅读策略最大的毛病是**"贴标签"**——在某个环节旁边写一句"——此处训练'推断'策略",但环节本身的话术和任务**并没有真正让学生做推断的动作**。这和工具挂名是同一类问题。

**12本成品详案的实证**:真正落地的策略,是**直接写成环节里的提问/任务**的,而不是靠旁注。例如:
- L4《我家没有英雄》——`比较:莫里斯的家人和祖先,和伊波利特的家人,有相同点和不同点吗?`(这一问本身就是"比较"的动作)
- L4《我家没有英雄》——`联结:当你发现好朋友家有很多英雄,而你家一个也没有时,你的心情、感受是怎样的?`(把"联结个人经验"做成了一道题)
- L3《大森林里的小木屋》——`结合已知信息,推断一下为什么作者要主要描写冬天?`(这一问就是"推断")

**硬规则(违反即返工):**
1. **提纲里列的每一个策略,正文必须有一个让学生真正做这个动作的环节**(一道提问、一张阅读单、一个任务),不能只用旁注挂名。
2. 显性标注(`——此处训练X策略`)是**锦上添花**,不是落地证据;有标注、但环节没让学生做这个动作,等于没落地。
3. 一节课**重点显性训练 1–2 个策略**即可(按学段侧重选,见下),其余策略自然融入,不必每个都标。

## 10 种阅读策略 · 运用卡片

每张卡片三行:**触发话术**(老师怎么把策略引出来)→ **学生动作**(学生实际要做什么、做在哪)→ **收口追问**(怎么让"用了策略"变得可见、可评)。
卡片里的话术是**句式示范**,具体内容必须换成当前书的事实(来自《书籍档案》),不得照搬例句里的书名/情节。

### 1. 预测
- **触发话术**:"看到书名/这张封面/这个章节标题,你猜接下来会发生什么?为什么这么猜?"
- **学生动作**:基于标题、封面、关键词、已读情节,写下/说出对人物、事件、结局的预判,并给出依据。常配"我的预测 | 我的依据 | 读完是否被证实"阅读单。
- **收口追问**:"你是根据哪条线索猜的?"读后回看:"和你猜的一样吗?哪里不一样?"——**预测必须留一个"回头验证"的接口**,只猜不验等于没用这个策略。

### 2. 联结
- **触发话术**:"这让你想到了什么?(你自己的经历 / 别的书 / 别的事)""如果是你,你会怎么样?"
- **学生动作**:把文本和三类已知建立联系——联结自身经验、联结其他文本、联结文本前后内容,并说出联系点。
- **收口追问**:"这个联系帮你更懂这本书的哪一点?"——联结不能停在"我也有过"的共鸣,要回扣到对**文本的理解**上。

### 3. 提问
- **触发话术**:"读到这里,你心里冒出了什么问题?""有什么是你想问问作者/人物的?"
- **学生动作**:在读前、读中、读后提出基于文本或由文本引发的问题,记录下来(可用"我的问题"清单/便签)。
- **收口追问**:把学生的问题分一分——"哪些读下去就能找到答案?哪些要想一想/讨论才知道?"**好问题本身就是成果**,不必当场都有答案。

### 4. 图像化
- **触发话术**:"闭上眼睛,这段文字在你脑海里是什么画面?""如果把这一段拍成电影,镜头里有什么?"
- **学生动作**:把抽象文字转成具体画面——口头描述脑海中的"思维电影",或简笔勾勒场景/人物(重在"在脑中成像",不是比谁画得好)。
- **收口追问**:"文字里哪个词让你看见了这个画面?"——把"想象"拉回到**具体的文本语言**上。

### 5. 筛选重要信息(成品详案常称"确认重要信息")
- **触发话术**:"这一段里,哪句话最关键?哪些是可以先放一放的?""如果只能划三句,你划哪三句?"
- **学生动作**:依据文本结构,对信息分主次,圈画/摘录重要内容(科普文尤其要抓结构里的关键句)。
- **收口追问**:"你为什么觉得这句重要?"——重点是讲出**判断重要与否的理由**,而非划得多。

### 6. 整合
- **触发话术**:"把刚才几处信息合起来看,你能得出什么结论?""这几件事放在一起,说明了什么?"
- **学生动作**:把分散在多处的信息(多个章节、多个细节)与自己的认识合起来加工,提炼出一个新结论/整体印象。常配多列阅读单或"勾勒完整图景"任务。
- **收口追问**:"你的结论是从哪几条信息合出来的?"——整合要看得见"由多到一"的归并过程。

### 7. 推断
- **触发话术**:"书里没直接说,但你能从哪句话推出来?""结合已知,你觉得他为什么这么做?"
- **学生动作**:利用文本明示的线索,对没有直接写出的内容(人物动机、原因、言外之意)作合理补充与假设。
- **收口追问**:"你凭哪条线索推的?"(这是最关键的一问)——**推断必须能回指到文本证据**,否则就是凭空猜。成品详案里"参考"常标"(根据文本信息作出合理推断)"。

### 8. 比较
- **触发话术**:"把 A 和 B 放在一起看,它们有什么相同、什么不同?"
- **学生动作**:对内容或形式上有关联的两个(或多个)对象——角色、事件、章节、文本——找出异同。**这是维恩图/对比图最直接的落地策略**(见 visualization-tools.md)。
- **收口追问**:"这些异同,让你对……有了什么新的理解?"——比较不为比而比,要落到加深理解。

### 9. 监控(成品详案常称"理解监控")
- **触发话术**:"读到哪里你有点卡住、读不懂?""你打算怎么把它读懂?(回读?查?问?)"
- **学生动作**:意识到自己理解出了问题,主动停下来回读、放慢、标注、提问;也包括对自己阅读计划/重点的自我评估。
- **收口追问**:"你用什么办法把它弄懂的?"——把"读不懂时怎么办"显性化,这本身就是高阶能力。**高年级重点策略**。

### 10. 转化(也称综合分析/运用)
- **触发话术**:"学了这个,你能用它来做什么/解决什么?""如果换个情境/续写一段,你会怎么写?"
- **学生动作**:把文本的新信息与已有知识结合,形成新观点或新创造;联系现实、迁移运用(续编、创编、情境模拟、专题写作等)。
- **收口追问**:"你这个新想法/作品,和原书是怎么接上的?"——转化要既有"新",又看得出**从文本生长出来**。**思辨&应用课的主力策略**。

## 学段侧重(决定本课重点显性训练哪几项)

各学段"重点显性训练哪几项"的侧重表,**唯一源在 `grade-structure.md`「各等级阅读策略」节末的学段侧重框**(与那里的"可选池"配套:可选池定"这级能用哪些",侧重定"这级重点练哪些"),此处不复制以免漂移。

> 用法:**先按 grade-structure.md 的可选池(不超过该级天花板)定"这本书用哪几个策略",再按该文件的学段侧重决定"本课重点显性训练的 1–2 个"**。重点训练的策略,要按上面的卡片走完"引→练→追问";其余策略自然融入即可。

## 策略 → 五维能力(写三维目标时定阶)

五维能力阶梯(① 提取信息 → ② 解释推断 → ③ 整体感知 → ④ 评价鉴赏 → ⑤ 转化运用)的定义与"读了什么/懂了什么/想了什么"对应关系**以 `grade-structure.md`「五维阅读能力」节为唯一源**;此处只给"哪个策略落在哪一阶"的对照——写"知识技能/过程方法"维度目标时,据策略对应的能力阶定高低:

| 策略 | 主要指向的能力维度 |
|------|------------------|
| 筛选重要信息、预测(读前) | ① 提取信息 |
| 推断、联结、图像化 | ② 解释推断 |
| 整合、比较 | ③ 整体感知(概括分析) |
| 监控、(对人物/写法的)评判 | ④ 评价鉴赏 |
| 转化 | ⑤ 转化运用 |

> 据此:低年级目标多落在①②,中年级推进到②③,高年级须触及④⑤(与 grade-structure.md 五维阶梯一致)。

## 策略 → 适配可视化工具(选了策略,顺手带出工具)

策略和工具是一条链:**选定要练的策略 → 这一栏告诉你哪个工具最能把它"做出来"**。工具的完整用法、范例、落地依据见 `visualization-tools.md`。

| 策略 | 最顺手的工具 |
|------|------------|
| 预测 | 预测阅读单("我的预测 \| 依据 \| 是否证实") |
| 联结 | 阅读单(联结栏);亦可在讨论中口头落地 |
| 提问 | "我的问题"清单 / 便签 |
| 图像化 | 气泡图(把画面/特征发散)、口头描述 |
| 筛选重要信息 | 各类阅读单、圈画;科普文配结构表 |
| 整合 | 多列阅读单、思维导图(归并脉络) |
| 推断 | 阅读单("线索 \| 我的推断")、鱼骨图(由因推果) |
| 比较 | **维恩图(两项)/ 对比图(多项)** |
| 监控 | 阅读计划表、"读不懂—我的办法"记录 |
| 转化 | 两难思辨阅读单、续编/创编/情境任务 |

> 注意:工具只是策略的载体,**先有"要练哪个策略"的判断,再选工具**,不要为了用某个工具而硬塞一个策略。一节课重点策略 1–2 个、落地工具 1–2 种,对应即可,不堆砌。

## 生成时的执行清单(策略部分)

- 选策略:按 grade-structure 可选池 + grade-structure 学段侧重,为整本书选 3–7 个、为本课定 1–2 个重点。
- 写落地:每个列入提纲的策略,正文都有让学生真正做这个动作的环节(提问/阅读单/任务),不靠旁注挂名。
- 重点策略走完"引→练→追问"三步(尤其"追问"那一步:推断问"凭哪条线索"、比较问"异同说明什么"、转化问"和原书怎么接上")。
- 写三维目标:据"策略→五维能力"表定阶,低年级①②、中年级②③、高年级④⑤。
- 配工具:据"策略→工具"表带出 1–2 种工具,与 visualization-tools.md 的落地四步衔接。
- 自检:对照 checklist.md(策略落地项)。
