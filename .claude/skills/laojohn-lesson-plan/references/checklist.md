# 交付前自检清单

逐项打勾,全部通过才交付。

> **两类条目 · 分工声明(防误删重叠)**:本清单含 ① **合规项**(格式/标记/收尾/真实性等,可机械核对)与 ② **质量预检项**(逐环节装载量双向核查、全课时动作量累加、全篇密度对标、导入钩子两面查、创意环节三查、讲解自洽回读等,需估算与判断)。质量预检是**生成方的第一道粗查**;冷审(`laojohn-detail-review` 按 review-rubric)会以更严口径**再查一遍同类问题**——两道**有意重叠**,是纵深防御、不是冗余,自查过≠冷审可省,也不得以"rubric 已有"为由删本清单条目(反之亦然)。口径分工:**判据数字(体量区间/环节与轮次上限/师话轮次对标)以本文件为唯一源**(rubric 对应条已指回本文件取数);**查法、维度与算式要求的详述以 review-rubric 为准**。

## 结构
- [ ] 课时数与等级匹配(L1/L2=2节,L3–L6=4节,等级默认钉死——见 grade-structure.md 官方表与周次节奏;档案"建议课时数"字段仅作提醒信号,与等级默认不符时停下问用户,不自行增减课时)
- [ ] 课型序列正确
- [ ] 每节课各环节时长合计 = 60 分钟
- [ ] **每个环节时长都是 5 的倍数**(5/10/15/20…),无 3、7、13、17 这类非 5 倍数的"假精确"数字(短环节如开场白/布置任务也按 5 分钟计)
- [ ] **逐环节装载量双向核查**:每个环节把它串起来的动作逐项估时累加,对照标称分钟——装不下(挤)与明显装不满(松,如两轮快问快答占10分钟、一段资料+一轮讨论占15分钟)都要改;松出的时间回补主体实做环节,不拿虚胖时长凑60
- [ ] **全课时动作量累加核查(防"每环节都勉强满、合起来一节讲不完")**:上一条只查单环节松紧,查不出"每个环节单看都勉强能装、5个环节累加却超60分钟"这种**整节超载**(照着讲赶不完)。对**每一节**把全部环节的真实耗时加总:①数这一节的师生问答**轮次总数**(每轮"抛问→学生答→追问→再答→小结"真实约3–5分钟)、朗读段数、动手填表次数;②按真实耗时(含课堂摩擦:学生答偏要重引、过渡、组织)累加。判据:**一节通常≤4–5个环节、师生问答块通常≤5–6轮**;明显超出即"照讲讲不完",必须砍——**优先砍重复问答轮次(每环节收敛到"1核心问+1追问")、合并次要信息点,绝不砍原文精读或参考深度**。补厚(防偏薄见下条)与可讲完是一对张力:**厚度放进"参考"(老师备课看),课堂"动作量"必须能在标称时间讲完,不靠堆问答轮次充厚度**
- [ ] **无学生动作环节排查**:除布置任务/收束类外,每个≥5分钟的环节至少有一处学生动作(分享/填写/朗读);连续两段教师独白之间无学生动作、或老师直接灌方法/结论的,改为"先问学生、老师再归纳"
- [ ] **全篇密度/体量对标(防系统性偏薄)**:上一条双向核查只查单环节松紧,查不出"每环节都勉强能过、合起来却偏薄"(每环节师话少一点点、参考薄一点点,累积成全篇偏薄)。交付前粗量全稿字符数,对照同批**同学段**成品区间(L3–L4 约1.4万–1.6万、L5–L6 约1.7万＋,**仅作信号、非达标线**;字符数受Markdown标记/表格影响不精确,只用于"明显偏低→往下查");明显低于下限即逐项查三杠杆——① **师话密度**:每个≥15分钟环节的 `师：` 是否普遍只"引→答→参考→收"约4轮就过(应写成一句多动作、每环节6–10轮;全篇师话轮次可对标同批同学段成品,如 L3《亲爱的汉修先生》约81轮、《俗世奇人》约76轮);② **参考/单子填实**:`参考：` 是否多为单行、表格是否多空格(应①②③列举式、单子给示例填法);③ **原文精读用满**:档案「关键片段/备用引文池」是否大半没用上。**补厚一律取自档案、逐字核对、零虚构,不灌抽象、不靠加环节凑字数**(唯字数论会诱导灌水,违反简洁与真实性红线)
- [ ] 第1节最前面有"教案提纲七项表格 + 文本介绍 + 书级三维目标",且仅出现一次
- [ ] 每一节都有该节的三维教学目标(成条)
- [ ] 提纲列的每个阅读策略,正文都有让学生**真正做这个动作**的环节(提问/阅读单/任务),不是只靠旁注贴标签
- [ ] 教学方式在环节处适当体现
- [ ] **已判定文本类型**(故事小说/非虚构/经典名著;用户有定调以定调为准,无定调才按名著优先·三选一互斥缺省判),各课型设计重点与开头「三类文本对照表」对应类型一致,未张冠李戴(科普书未套“预测故事/人物塑造”,当代普通小说未套“作者时代背景/文学价值”)
- [ ] **导入钩子"既抓人又切题"(两面都查)**(见 style-and-format「导入钩子」红线):① **切题**——钩子对准本书主线/主题,未拿抓眼球的次要情节(某单一事件)做开场钩子而使阅读期待跑偏,抓人的次要情节线留作正文情节梳理;② **抓人**——导入有一个具体、先声夺人的钩子(真实背景/反常设定/震撼数字/核心悬念/独特叙述声音等),**不是"解释一个主题词/概念"式的温吞暖场**(如"'X'是什么意思");生成前已盘点本书钩子素材库(优先从档案「作者的话/拓展资源/主题词/变化线索」找)、选了最强且切题的一个开场;③ **开场话术不抄示范句**——导入起手措辞为本书自拟,未逐字照抄 style-and-format「正确的开场姿势」的示例句(示例是形态举例、不是模板)
- [ ] **思辨/创编/应用等"创意·互动"环节不平庸(与导入钩子同源·两面查)**(见 style-and-format「思辨&应用课型任务」+ lesson-templates「思辨讨论/联系生活」):凡要学生"创造·思辨·联系"的环节(思辨题、创编/续编/辩论/情境/采访/专题写作任务、联系生活),都不能只套一个类型壳/抛一个泛问了事。逐个查——① **扣内核**:对准全书核心价值冲突/主题,非枝节;② **有空间**:逼学生调用对整本书的理解、且答得出高下(非复述、非填空、非脱书自由发挥);③ **已盘点素材**:生成前已从档案「主题词/横向对照/变化线索/事件序列」挖过素材、择最强且切题者,而非凭空想一个再硬套书。反面靶子:思辨题伪开放("你喜欢主角吗")/伪两难(一边明显对)、成果任务套壳换书名("续写个结局""如果是你会怎么做")、联系生活问"你有什么感受"

## 内容真实性
- [ ] 所有页码、章节标题来自《书籍档案》或用户提供原文,无虚构
- [ ] 所有人物、情节与档案一致
- [ ] 原文摘录有章节/页码标注,篇幅合理,未大段照搬
- [ ] **无《书籍档案》/原文时未擅自开写**(应已停下索取,或仅出结构骨架+占位)
- [ ] **无伪摘录**:凡带引号的"原文"均有真实来源;无来源处用"(教师朗读【待补:…】)"占位,未用仿写句冒充原文
- [ ] 章节归属、人物设定、情节细节均有来源,未凭记忆编造;存疑处标"(以实际版本为准)"而非编造内容
- [ ] **事件序列、变化线索如实取自档案**:事件链的事件、成长阶梯/时间轴的状态节点,均来自档案"全书事件序列""贯穿全书的变化线索",未自行增删事件或调换先后顺序
- [ ] **档案中标"无原文,仅概述"的片段,正文只作概述、未补写伪原文**(此类片段是补全冲动的高发区,引用处一律占位)

## 讲解自洽(话术层真实性)
> 管的是老师临场生成(而非取自档案)的话术——比喻、换算、对照句、动作/外形描写、举例、即兴推理。这层不受伪摘录红线约束,但同样要为常识与内部逻辑负责。正文写完后,把这类话术**单独拎出来回读**(别混在通读里顺带看),逐句对照:
- [ ] **每句临场话术都站得住**:单独拎出来看,常识上正确、逻辑上不自相矛盾、和它要说明的点真的对得上;拿不准的已退回平实陈述
- [ ] **常见错型已排查(举例,非穷举)**:换算/参照失真(六英寸≈一手掌,非小拇指)、对照塌成重复(两边其实是同一件事)、措辞自相矛盾("四肢直立")、时间/卷次张冠李戴、例子年代或常识错位、面向小学生却用超纲概念——这些及**任何同类问题**均已查
- [ ] **数字比喻锚点取自真值**:打比方依据的尺寸/数字来自《书籍档案》已核实事实,非凭记忆现编(同红线)
- [ ] **兜底回读**:除上面列举的,我有没有别的"自己造出来、却站不住"的讲解(比喻/换算/对照/举例/推理)?已通读确认无遗漏

## 话术格式
- [ ] 教师发言以"师:"开头,开场为固定句
- [ ] 学生互动处有"参考:"
- [ ] **全文不含 `【PPT换页-PXX】` 等换页点**(已废弃,分页交 laojohn-ppt-draft 按教学节拍处理)
- [ ] 每节结尾"本课完。",末节"全课完。"
- [ ] 含教案提纲七项表格、文本介绍、教学目标三维度
- [ ] **引号全用全角弯引号** `“”`/`‘’`:全文检索 ASCII 直引号 `"`(U+0022)与 `'`(U+0027)无残留(Markdown 语法/代码除外),弯直引号无混用——不靠 docx 引擎安全网兜底
- [ ] **无 HTML 样式/高亮标签**:全文检索 `<\w+>` 无残留(仅放行表格换行 `<br>` 与注释 `<!-- -->`)——`<mark>`/`<b>`/`<u>`/`<span>` 等引擎不解析、会原样印进 docx;行内强调只用 `**`,伏笔用文字直说
- [ ] **未预设学生手上没有书**(学生上课前已人手一本,恒久约束):全文检索"说出书名/告诉大家书名/这是一本什么书/猜猜书名/把书发给大家"无残留;导读课开场承认书已在手(如"这本《X》,大家手上都拿到了"),悬念不建立在"学生看不到书名/封面/作者"上,而落在书名给不了的信息(人物处境、原文出自谁之口、未解之问);要学生先别翻书时直接说"请先别翻开"(见 style-and-format.md「学生上课前已人手一本书」)
- [ ] **无黑板/板书依赖**(教室无黑板白板,恒久约束):全文检索 `黑板`/`板书`/`白板` 无残留;可视化图的汇总走"学生学习单 + 老师口头归拢、学生补自己单子",未写"老师在黑板上画/记一张集体大图";预制框架走"老师口述、学生跟记";回指不写"老师画的那张图"(见 style-and-format.md「课堂无黑板/白板」)

## 分级适配
- [ ] 阅读策略在该等级"可选池"内(不超天花板),且本课重点 1–2 项按 reading-strategies.md 走完"引→练→追问"(尤其"追问"那一步)
- [ ] 重点策略与三维目标的能力阶相称(低年级①②、中年级②③、高年级④⑤)
- [ ] 思辨问题开放且配参考(L3–L6)
- [ ] 低龄(L1/L2)语言更口语、活动更具象;高龄(L5/L6)含批判/象征/跨文本
- [ ] **师话的比喻与口吻不低于学段(L5/L6 专查)**:通读教师引语,凡打比方处逐一判喻体的心理年龄——无"迷路/收拾行李/拼图/长得像一条鱼"这类生活化可爱喻体,无"老师帮你……免得你……"的保护性口吻,无"归归类、理理清/碰一碰/想干嘛就干嘛"这类叠词与儿化口语;比喻取自文学与阅读本身(结构/线索/底色/暖笔冷笔)或直接把话说清。**高发位置=过渡句**——引入工具、宣布本环节要做什么、承接上一节课这三处最易漏(内容分析成熟不代表过渡句不低龄)。改喻体须连全文回指与 `〖PPT 第N页〗` 页标一起改(见 style-and-format.md「不分级的通用底线」比喻与口吻条)
- [ ] **写作技法只在该讲时才讲**:用户没明确要求"读写结合/讲写法"则全文无写作技法点拨;若已解锁,技法只挂在读后写作应用任务"动笔前",未上溯到导读/交流课文本分析、未改动课时结构(详见 SKILL.md「核心约束」写作技法条 / CLAUDE.md §6)
