# 交付前自检清单

逐项打勾,全部通过才交付。

## 结构
- [ ] 课时数与等级匹配(L1/L2=2节,L3–L6=4节)
- [ ] 课型序列正确
- [ ] 每节课各环节时长合计 = 60 分钟
- [ ] 第1节最前面有"教案提纲七项表格 + 文本介绍 + 书级三维目标",且仅出现一次
- [ ] 每一节都有该节的三维教学目标(成条)
- [ ] 各节用到的阅读策略/教学方式有适当显性标注

## 内容真实性
- [ ] 所有页码、章节标题来自《书籍档案》或用户提供原文,无虚构
- [ ] 所有人物、情节与档案一致
- [ ] 原文摘录有章节/页码标注,篇幅合理,未大段照搬
- [ ] **无《书籍档案》/原文时未擅自开写**(应已停下索取,或仅出结构骨架+占位)
- [ ] **无伪摘录**:凡带引号的"原文"均有真实来源;无来源处用"(教师朗读【待补:…】)"占位,未用仿写句冒充原文
- [ ] 章节归属、人物设定、情节细节均有来源,未凭记忆编造;存疑处标"(以实际版本为准)"而非编造内容

## 话术格式
- [ ] 教师发言以"师:"开头,开场为固定句
- [ ] 学生互动处有"参考:"
- [ ] PPT换页锚点连续不跳号
- [ ] 每节结尾"本课完。",末节"全课完。"
- [ ] 含教案提纲七项表格、文本介绍、教学目标三维度

## 分级适配
- [ ] 阅读策略与等级匹配
- [ ] 思辨问题开放且配参考(L3–L6)
- [ ] 低龄(L1/L2)语言更口语、活动更具象;高龄(L5/L6)含批判/象征/跨文本

## 阅读单与表格
- [ ] 至少含一张阅读单(表格 + 参考)
- [ ] 导读课附阅读记录/计划表

## 可视化思维工具落地(见 visualization-tools.md)
- [ ] 提纲"可视化教学工具"列的每一种,正文都有对应运用环节(无"挂名"工具)
- [ ] 正文用到的工具都已在提纲列出(提纲↔正文一一对应)
- [ ] 每个工具以 Markdown 表格/清单呈现(不含图形文件或绘图代码),环节具备"引出→填写→分享+反馈"闭环,未填完即过
- [ ] 陌生/复杂工具(六面体/鱼骨/维恩等)先有"介绍方法"小环节
- [ ] 每节落地工具控制在 1–2 种,未堆砌
