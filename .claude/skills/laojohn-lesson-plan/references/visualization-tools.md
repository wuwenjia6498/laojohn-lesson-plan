# 可视化思维工具的运用

来源:官方《整本书阅读策略和可视化思维工具运用》文件 + 落地最实的两本成品(L3《大森林里的小木屋》家庭树、L4《我家没有英雄》六面体讨论图)。

## ★输出边界(A 档:纯文字骨架)

本系统**只产出逐字稿详案中的"可视化工具文字骨架",不生成任何图形文件、不画图、不输出 Mermaid/SVG/绘图代码**。每个工具在详案里以下列文字形态之一呈现:
- **Markdown 空白表格**(阅读单、六面体六问表、对比表等);
- **节点/要点清单 + 一句结构说明**(如家庭树:列出成员 + "画出 X 与 Y 的关系");
- **课堂话术**,由老师在课上引导学生自己动手画/填。

"画图"是**课堂里老师和学生的动作**,写进话术即可;详案本身不附成品图。需要精美可打印的图形版式时,归属 PPT/设计物料线,不在本系统范围。

> **⚠ "不画图"包含"不用代码块画 ASCII 图"(硬规则):** 维恩图/思维导图/阶梯图/讽刺逻辑图/鱼骨图等工具,**一律用 Markdown 空白表格或"节点清单 + 一句结构说明"承载,禁止在 ```代码块``` 里用制表符 `┌─│├└`、树状 `├─└`、箭头台阶等 ASCII 字符画示意图**——这类 ASCII 画图在 docx 里渲染成等宽乱码、错位难读,且违背本档"不出图形代码"。
> - **空白版**(给学生填)= 一张空单元格的 Markdown 表(行/列取自该工具的结构维度,如维恩图=对象列×维度行、阶梯图=阶梯×卷章×状态);
> - **参考版** = 同结构的 Markdown 表填上答案(答案只来自《书籍档案》);
> - 空白版与参考版**用同一套表头/行列**,便于学生对照。工具的"圈叠/台阶/树枝"形态用一句话文字说明即可(如"两个交叠的圈,左圈填甲、右圈填乙、交集填共同点"),不靠 ASCII 还原图形。

## ★核心问题:别让工具"挂名"

**12本成品详案的实证教训**:多数详案在"教案提纲"列了 3–5 种可视化工具,但课堂正文里**根本没用到**(尤其 L5《纳尼亚》《作业机器的秘密》、L6《汤姆·索亚》《记忆传授人》——提纲列了树状图/气泡图/时间轴/计划表,正文一个都没落地,全靠"阅读单"统包)。真正把工具写进流程的只有 L3 家庭树、L4 六面体、L4《十万个为什么》流程图/思维导图。

**硬规则(违反即返工):**
1. **提纲里写的每一种可视化工具,正文必须有对应的运用环节**——有"这一步用 X 图"的师生话术、有 **Markdown 空白表格或节点清单**(供学生填)、有填写→分享→反馈的闭环。
2. 反之,**正文用到的工具,必须在提纲列出**。提纲与正文一一对应,不多不少。
3. 宁可少列。一节课落地 1 种工具、用透,胜过提纲堆 5 种、全程不碰。

## 官方运用原则

- **选用标准**(满足其一即可):① 梳理文本信息;② 理解文本核心价值;③ 直观、有趣味;④ 引导思考、分享与讨论。
- **闭环铁律**:工具"**填写后需要反馈、分享、交流**"。高质量的分享交流才带来深度阅读——所以每个工具环节都要有"填→展示/分享→师生点评/追问"三步,不能填完就过。

## 工具 → 用途 → 选用理由(官方 + 实证)

> **怎么读这张表:** 选工具看的是**"本书内容里有没有这个工具对应的结构需求"**,不是看年级。
> - **「选用理由」栏** = 这个工具的内在逻辑(比较类 / 因果类 / 时间类 / 分层类…)+ 题材举例。题材用"如…"举例,**只是常见场景,不是限定**——任何具备该结构需求的书都可用。
> - **年级深浅不在此表判断**:同一个工具低年级浅用、高年级深用(如维恩图低年级比两个角色、高年级跨文本比象征),"本课该把工具用到多深"由 `grade-structure.md` 的策略分级 / 五维能力阶梯决定,本表不写"高/低年级"以免锁死。
> - **「落地依据」栏**分两档:【有范例】照下方案例库结构仿照;【需自建】无现成范例、但同样可选,需自建完整四步。

| 工具 | 主要用途 | 选用理由(何时选它·题材仅为举例) | 落地依据 |
|------|----------|----------|----------|
| 各类表格 / 阅读单 | 梳理信息、记录观点、对照分析 | **最通用的承载式工具**:任何需要"列项填写/分栏对照"的场景都可用,各级各题材 | 【有范例】最通用,12本均用;各类阅读单写法见 style-and-format.md |
| 思维导图 | 发散梳理主题/人物/事件脉络 | **发散/归纳类**:一个中心词需要向外铺开多个并列分支(主题、人物、情节线)时选;信息量大的书更受益,简单中心发散低年级亦可 | 【有范例】中心发散·并列分支见案例⑦(L6《汤姆·索亚》5次冒险);L4《十万个为什么》亦用 |
| 流程图 | 呈现先后顺序、步骤、情节链 | **顺序/步骤类**:内容是"一步接一步"的过程、步骤、情节链时选;如科普的操作流程、故事的事件链 | 【需自建】结构简单(箭头串步骤/环节),自己搭四步即可;参考 L4《十万个为什么》 |
| 时间轴 / 时间线 | 梳理时间脉络、发展阶段 | **时间/阶段类**:内容沿时间或阶段推进时选;如历史、航海、传记、成长线、长篇主线 | 【有范例】三种排版见下:竖排分期挂群像(③ 航海大发现)、横排串单线事件(③b 鲁滨逊)、横排每段挂人物(⑧ 小王子) |
| 人物关系图 / 家庭树 | 厘清人物及其关系 | **关系网类**:人物多、关系交错、需厘清谁和谁什么关系时选;如群像小说、经典名著、家族故事 | 【有范例】落地范例见下(L3《大森林里的小木屋》家庭树) |
| 维恩图 | 异同对比、跨文本比较 | **比较类(两项·圈圈式)**:用两个交叠的圈对照两个对象的相同点/不同点时选;如两个角色、两件事、两个文本。**只比两项、且重"共同点/不同点"时用维恩图;要比三项以上或多个维度逐栏对照,用下方的对比图。** 低年级比具象、高年级比抽象/象征,深浅由分级定 | 【有范例】官方案例①(L4《手斧男孩》) |
| 故事地图(故事弧/英雄之旅表·路线图) | 用情节框架或行进路线梳理脉络 | **情节框架类**:故事有清晰的"出发—经历—回归"等结构、或主角不断移动、或多角色可平行对照时选;如成长故事、冒险/旅行小说 | 【有范例】两种形态见下:表格分栏式(④b《柳林风声》英雄之旅表)、环形/路线节点式(⑥ 提姆的旅程) |
| 故事山形图 | 梳理情节起伏:起始→上升→高潮→下降→结局 | **情节曲线类**:想呈现一条主线情节的起伏与高潮时选;如有明显矛盾发展与转折的故事/小说 | 【有范例】官方案例④(《白海豹》) |
| 对比图(多维对照表) | 多项/多维度并列对照 | **比较类(多项·表格式)**:要同时比 3 个以上对象,或对一组对象按多个维度逐栏对照时选(行=对象、列=维度);如多个角色横向对比、几种方案权衡。比两项异同更轻便的场景用维恩图 | 【需自建】无填好范例;选用须自建四步。结构可参照下方维恩图的"对比维度"思路,改用多列表格承载 |
| 气泡图 | 围绕中心词发散特征/联想 | **描述/发散类**:聚焦一个对象(人物、事物、概念),把它的特征、联想、关键词向四周铺开时选;如"这个角色是什么样的"。**低年级友好**,是描述与图像化策略的好载体 | 【需自建】无填好范例;选用须自建四步。结构可参照下方思维导图(中心发散),但只发散"特征词"、不必再往下分层 |
| 树形图 | 自上而下分类、分层 | **归类/层级类**:内容本身有上下层级或可归类(总—分、类别—子项)时选;如知识分类、人物阵营划分、主题下的子主题 | 【需自建】无填好范例;选用须自建四步。结构可参照下方思维导图,但强调"层级归属"而非自由发散 |
| 六面体讨论图 | 围绕一主题从6面(联系/描述/比较/争论/应用/分析)深入 | **单主题多角度深挖类**:围绕一个核心主题(如"英雄""友谊")需从多个侧面充分讨论时选;常用于思辨&应用课 | 【有范例】落地范例B(L4《我家没有英雄》) |
| 阶梯图 / 阶梯式时间轴 | 分阶段呈现人物成长/梦想进阶 | **递进/进阶类**:人物的成长、梦想、能力呈阶段性递进、一级比一级高时选;如成长主题、人物分析 | 【有范例】官方案例②(《吹小号的天鹅》梦想阶梯) |
| 鱼骨图 / 因果(关系)图 | 呈现因果关系、多因一果 | **因果类(多因一果)**:一个结果由多个原因/影响共同促成时选;如某事件成因、某人物受多方影响、社会/财商议题的成因 | 【有范例】官方案例⑤(《小鹿斑比》);L3《小狗钱钱》因果图亦用 |

> **★阅读计划表不计入可视化教学工具(恒久规则):** 阅读计划表/阅读计划单是**阅读规划与进度记录工具**,不是可视化思维工具——它不承载"梳理/对照/因果/递进"这类思维结构。因此:
> - **绝不写进提纲"四、可视化教学工具"栏**,也绝不进入下游 vistools(海报/导图/阅读单的"可视化思维工具"列)。
> - 导读课仍可照常布置一周阅读计划(作为收尾的阅读规划环节),但它归"阅读安排",不算工具落地——本表"提纲列的工具正文须落地"的一一对应**不把计划表算在内**。

## 官方工具案例库(从《阅读策略》文件图示提取 · 供 AI 仿照结构)

以下 10 个案例是官方文件/成品课件里**真正填好的范例**(原藏于文档与课件图片,已提取)。生成时按"同工具、同结构、换本书内容"仿照——结构照搬,文字内容必须来自当前书的《书籍档案》,不得搬运这些范例的具体内容。原图存于 `source-docs/可视化工具官方案例图/`。

**① 维恩图 — L4《手斧男孩》(对比阅读,分析主人公成长)**
引导问题:"通过这两章的对比阅读,你有什么发现?"
- 左圈【吃浆果】:为了充饥的无奈之举;找到浆果随着吃就行;浆果很甜,只为果腹;吃多了之后半夜肚子疼。
- 右圈【吃肉】:为了换口味;要想吃到禽鸟肉没那么容易;肉很美味、味道无与伦比;禽鸟的肉吃下去很舒服。
- 交集:填饱了肚子。
- 右侧延伸"不同点"维度:吃的动机 / 获取难度 / 美味程度 / 吃的结果。
结构骨架:`一个引导问题 → 左圈A特征(3–4条)/ 右圈B特征(3–4条)/ 交集共同点 → 提炼对比维度`。

**② 阶梯图 / 阶梯式时间轴 — 《吹小号的天鹅》(分析人物路易斯的梦想进阶)**
引导问题:"路易斯的梦想阶梯可以怎么画?从阶梯图你看出路易斯是一只什么样的天鹅?"
五阶递进(每阶填该阶段目标/成就):
第一阶段 学会读写、与人交流 → 第二阶段 学吹小号、挣钱还债 → 第三阶段 挣钱还债、吹出美妙的音乐 → 第四阶段 吹奏美妙的音乐(爱情/自由/梦想)→ 第五阶段 实现梦想。
结论指向:不断突破自身局限、追求梦想的天鹅。
结构骨架:`3–5 级递增台阶,每级写该阶段的目标或突破 → 看整条阶梯回答"这是个怎样的人物"`。

**③ 时间轴(竖排·按时期分支)/ 思维导图 — L5《航海大发现》(梳理时间线+人物事件)**
中心【航海大发现】向右按时代分支,每支挂代表人物、留空格待学生补事件:
- 1000年以前:希腊 / 罗马 / 斯堪的纳维亚人
- 13世纪后半叶:马可·波罗
- 15世纪:葡萄牙亨利王子 / 哥伦布 / 卡波特父子
- 16世纪:亚美利哥·韦斯普奇 / 巴尔博亚 / 麦哲伦 / 科尔多瓦 / 科尔特斯 / 皮萨罗 / 德索托 / 科罗纳多
- 17世纪:斯考特和哈得尔 / 亨利·哈德逊 / 英国人 / 荷兰人
用途:明晰发展脉络,思考航海大发现的关键要素。
适用:**时间节点本身不连续、需按"时期"归类、每期挂多个人物**的题材(历史/航海/群像)。
结构骨架:`中心主题 → 按时间分期 → 每期挂关键人物 → 每人留空格填事件/贡献`。

**③b 时间轴(横排·线性分段) — 《鲁滨逊漂流记》(梳理六次航海历程)**
一条从左到右的箭头横轴,等距切成 6 个连续节段,每段一个标题 + 下方一个空框待学生填:
- 第1次航海:1651年9月1日违背父母意愿,乘伙伴父亲的船离家去伦敦,途中遇风暴在雅茅斯登陆。
- 第2次航海:去非洲经商,认识第一位船长朋友并发了财,把财物寄存在船长朋友的妻子处。
- 第3次航海:再去非洲途中被土耳其海盗俘虏成奴隶,两年后逃离;被葡萄牙船长搭救到巴西,成了有钱的种植园主。
- 第4次航海:1659年9月1日带种植园主们去非洲贩卖黑奴,遇风暴,唯一幸存的鲁滨逊流落荒岛,在此生活28年。
- 第5次航海:1686年12月19日离开荒岛,经长途航行于1687年6月11日回到阔别35年的英格兰。
- 第6次航海:1694年跟侄子船长再次出海去东印度,路上重返荒岛看望岛民。
用途:呈现单一主角**一条主线、先后相继**的经历。
适用:**时间/事件本身就是一条连续链(单主角的旅程、传记、长篇情节主线)**的题材;与③的区别在于③是"分期挂群像",③b 是"线性串单线"。
结构骨架:`一条横向箭头 → 等分为若干连续节段 → 每段一个阶段标题 + 一个空框填该段发生了什么`。

**④ 故事山形图 — 《白海豹》(《丛林故事》,梳理情节起伏)**
一条山形曲线上 5 个空框:起始 → 上升 → 高潮(顶点)→ 下降 → 结局,学生填各阶段情节。
配套思辨问题(均标注"筛选重要信息、整合、反思评价"策略,各带参考答案):
- 问题1:能成功找到新栖息地,柯迪克做对了什么?
- 问题2:柯迪克在说服族群迁徙过程中遇到的最大障碍是什么?你如何评价他克服障碍的方法?
- 问题3:如果柯迪克不能找到新栖息地,他还有哪些选择?他的冒险和探索有意义吗?
结构骨架:`山形5框填情节 → 配3个由浅入深的思辨问题(各标策略、各给参考)`。

**④b 故事地图(故事弧 / 英雄之旅表) — 《柳林风声》(梳理鼹鼠与蟾蜍的"英雄之旅")**
先点明故事模式:**离家 → 游历(冒险)→ 归家**;再做成三列表格,按主要角色分行填写。官方原范例(供仿照结构,内容须换成当前书):

| 角色 | 离家原因 | 冒险经历 | 回家的变化 |
|---|---|---|---|
| 鼹鼠 | 干活干得"烦死人了!",想出去轻松一下;感受到春天的召唤 | 结识了河鼠、獾、蟾蜍;和河鼠河中划船、独自去野林探险、找小胖胖体验父爱友爱、和朋友一起为蟾蜍夺回蟾宫…… | 感受到家的温暖;体验到原先没体验过的乐趣;收获了友谊 |
| 蟾蜍 | 不想被约束,被汽车吸引 | 因偷车、胡乱驾驶被捕入狱;扮洗衣妇逃走;被警察追赶、火车司机搭救;被船妇扔进河里……(一路狼狈,吃尽苦头) | 感受到平常忽略的日常生活的珍贵;多次历险也让他对自己的所作所为有所反思 |

用途:用一个**情节框架(故事弧)**把全书梳理成可对照的结构,顺带为后续"人物变化/主题"分析铺垫。
适用:**有清晰\"出发—经历—回归\"结构、或多角色可平行对照的故事/小说**。与故事山形图的区别:山形图重"情节起伏曲线(一条线)",故事地图重"用固定框架分栏归类(可多角色并列)"。
结构骨架:`先点明故事模式(离家→冒险→归家等)→ 按模式设列、按角色设行 → 各格填该角色在该阶段的情节 → 借表分析人物变化/主题`。


**⑤ 鱼骨图 — 《小鹿斑比》(梳理重要人物对主角的影响)**
鱼头=【成为鹿王子】,鱼尾=【出生】,主干按 童年→青年→中年 分段,各骨支填一个"重要人物/事件对斑比的影响":教导斑比独自生活 / 阻止斑比掉入猎人的圈套 / 教斑比救助其他小动物 / 赞赏和鼓励斑比 / 提醒他生活要谨慎 / 斑比受伤后照顾他……
结尾提示:"同理,我们还可以用同样的方法来分析其他的人物。"
结构骨架:`鱼尾=起点、鱼头=终点结果 → 主干按成长阶段分段 → 各支填影响事件`。

**⑥ 故事地图(环形·路线节点式) — 提姆系列(梳理主角行经的地点与路线)**
区别于④b《柳林风声》的"表格分栏式"故事地图,这是另一种形态:**把主角走过的所有地点画成一圈(或一条路线),从"家"出发,按行进顺序串起每个站点**,行经处可加标注。官方原范例(供仿照结构,内容须换成当前书):
- 从【家】出发,沿环路依次经过:小车站 → 森林 → 农庄 → 牧场 → 森林 → 农庄 → 小河 → 森林 → 小农庄 → 邮局 → 大庄园 → 森林 → 地下室 → 草地 → 火车站,回到起点附近。
- 路线旁可加**特殊标注**:如"采石坑""森林"两站标注【提姆单独】,提示这两段是主角单独行动。
用途:把"主角走了哪些地方、按什么顺序、哪几段是独自经历"一眼看清,为分析行程、人物处境作铺垫。
适用:**主角不断移动、地点构成主线**的书(冒险、旅行、求生类,如《手斧男孩》《鲁滨逊漂流记》)。与时间轴的区别:时间轴重"时间先后",路线图重"空间地点的串联"。
结构骨架:`定起点(家)→ 按行进顺序把地点串成环/线 → 每站一个节点 → 特殊行程(单独/折返/关键事件)加标注 → 借图分析行程与人物`。

**⑦ 思维导图(中心发散·并列分支) — L6《汤姆·索亚历险记》(以5次冒险为主线梳理情节)**
真正"一个中心词 → 向外并列挂多个分支"的思维导图(区别于③那种按时间分期的);每个分支是一条情节线,**可在分支末尾标注对应章节/页码**。官方原范例:
- 中心:【《汤姆·索亚历险记》情节梳理】,向右并列挂5个分支:
  - 第一次历险:黑夜坟场目睹凶杀案【第9章】
  - 第二次冒险:三个海盗小岛探险【第13–18章】
  - 第三次冒险:潜入鬼屋,寻找宝藏【第26–27章】
  - 第四次冒险:汤姆和蓓姬被困山洞【第32章】
  - 第五次冒险:汤姆和哈克山洞寻获宝藏【第34章】
用途:用一条主线(此处=5次冒险)把全书情节归并成并列的几支,脉络清晰。
适用:**情节可归纳成若干并列板块/线索**的书;分支可挂事件、人物、主题等。**章节页码须来自《书籍档案》,不得虚标**。
结构骨架:`中心主题 → 并列挂 3–6 个分支(每支一条线索/板块)→ 每支可标章节页码 → 留空或填要点`。

**⑧ 时间轴(横排·每段挂人物) — 《小王子》(按星球顺序梳理所遇人物)**
③b《鲁滨逊》是"横排串单线事件";这张是横排的另一种用法:**横轴按顺序分段,每段下方挂"该段遇到的人物/角色"**(把③的"分期挂人物"做成了横排)。官方原范例:
- 横轴七段(按小王子游历顺序):325星球 → 326星球 → 327星球 → 328星球 → 329星球 → 330星球 → 地球。
- 每段下方挂该星球上的人物:国王 / 爱慕虚荣的人 / 酒鬼 / 商人 / 点灯人 / 地理学家 / (地球:飞行员、商人、扳道工、狐狸、玫瑰花、蛇)。
用途:把"主角依次到了哪、各自遇到谁"排成一条线,便于对照各站人物、提炼主题。
适用:**主角按顺序游历多地、每地遇到不同角色**的书(游历体、星际/国度漫游类)。
结构骨架:`一条横向箭头 → 按顺序分段(每段一个地点/阶段)→ 每段下方挂该段的人物/角色 → 借此对照分析`。


## 落地范例 A:人物关系图 / 家庭树 — L3《大森林里的小木屋》(阅读交流课)

嵌在"阅读交流课2"的一个 15 分钟环节,走完整的"引出→填写→分享→反馈"闭环:
1. **引出**:师先用提问把信息聚起来——"书中还出现了哪些亲人呢?"(给参考:爷爷、奶奶、姨妈、舅舅、表兄……)。
2. **填画**:"咱们用'家庭树'来画出人物关系图谱。重点画出劳拉的家庭成员,其他家族成员也可以画上去。"给出参考图,**让孩子自由发挥**,画出关系即可。
3. **分享 + 反馈**:请学生展示自己画的关系图,师借图追问、点评,把工具落到"分析人物形象"这一教学目标上,而非为画而画。

**可复制骨架**:`师:(提问聚拢相关信息)→ 师:我们用【X图】把它画/填出来,重点是…… →(给空白图/参考图)→ 学生填画 → 学生分享 + 师点评追问 → 回扣本环节的策略/目标`。

## 落地范例 B:六面体讨论图 — L4《我家没有英雄》(思辨&应用课)

1. **先教方法(5分钟)**:专门用一个短环节讲"什么是六面体讨论"——围绕一个主题从六面展开,讨论得更全面深入。给出六行空表:联系 / 描述 / 比较 / 争论(反驳)/ 应用 / 分析。
2. **再用工具(35分钟)**:用六面体图讨论本书核心主题"英雄",逐面填写、分组讨论、分享。

**要点**:**首次出现/结构较绕的工具,要先花一个小环节讲清"是什么、怎么用",再进入主体讨论**(已多次用过的常规工具不必);工具直接挂靠在本课的思辨主题上。

## 生成时的执行清单

- 选工具:按"本书内容的结构需求 + 本节教学目标 + 上表'选用理由'"挑 **1–2 种/节**,不堆砌;**先判断书里有没有该工具对应的结构(比较/因果/时间/关系…),再选**,不按年级硬套。用到多深由 grade-structure 的分级定。
- 写流程:每种工具都要有①引出 ②**Markdown 空白表格 / 节点清单 + 一句结构说明**(不画图、不出图形代码)③填写 ④**分享+反馈**四步。
- 陌生/复杂工具先教方法:判据不是"工具名听起来难",而是**该工具在本年级/本期是否首次出现**——首次出现、或结构较绕(如六面体、鱼骨图)的,先加一个 3–5 分钟"这是什么、怎么用"的小环节(见落地范例 B);已多次用过的常规工具(如表格、维恩图)直接进入运用即可,不必每次重教。
- 写提纲:提纲的"可视化教学工具"行 = 正文实际出现的工具,逐一对应。
- 自检:对照 checklist.md 中"可视化工具落地"项。
