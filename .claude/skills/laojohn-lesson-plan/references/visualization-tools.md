# 可视化思维工具的运用

来源:官方《整本书阅读策略和可视化思维工具运用》文件 + 落地最实的两本成品(L3《大森林里的小木屋》家庭树、L4《我家没有英雄》六面体讨论图)。

## ★输出边界(A 档:纯文字骨架)

本系统**只产出逐字稿详案中的"可视化工具文字骨架",不生成任何图形文件、不画图、不输出 Mermaid/SVG/绘图代码**。每个工具在详案里以下列文字形态之一呈现:
- **Markdown 空白表格**(阅读单、六面体六问表、对比表等);
- **节点/要点清单 + 一句结构说明**(如家庭树:列出成员 + "画出 X 与 Y 的关系");
- **课堂话术**,由老师在课上引导学生自己动手画/填。

"画图"是**课堂里老师和学生的动作**,写进话术即可;详案本身不附成品图。需要精美可打印的图形版式时,归属 PPT/设计物料线(见 OPEN-QUESTIONS.md 项D),不在本系统范围。

## ★核心问题:别让工具"挂名"

**12本成品详案的实证教训**:多数详案在"教案提纲"列了 3–5 种可视化工具,但课堂正文里**根本没用到**(尤其 L5《纳尼亚》《作业机器的秘密》、L6《汤姆·索亚》《记忆传授人》——提纲列了树状图/气泡图/时间轴/计划表,正文一个都没落地,全靠"阅读单"统包)。真正把工具写进流程的只有 L3 家庭树、L4 六面体、L4《十万个为什么》流程图/思维导图。

**硬规则(违反即返工):**
1. **提纲里写的每一种可视化工具,正文必须有对应的运用环节**——有"这一步用 X 图"的师生话术、有 **Markdown 空白表格或节点清单**(供学生填)、有填写→分享→反馈的闭环。
2. 反之,**正文用到的工具,必须在提纲列出**。提纲与正文一一对应,不多不少。
3. 宁可少列。一节课落地 1 种工具、用透,胜过提纲堆 5 种、全程不碰。

## 官方运用原则

- **选用标准**(满足其一即可):① 梳理文本信息;② 理解文本核心价值;③ 直观、有趣味;④ 引导思考、分享与讨论。
- **闭环铁律**:工具"**填写后需要反馈、分享、交流**"。高质量的分享交流才带来深度阅读——所以每个工具环节都要有"填→展示/分享→师生点评/追问"三步,不能填完就过。

## 工具 → 用途 → 适配题材(官方 + 实证)

| 工具 | 主要用途 | 典型适配 | 实证出处 |
|------|----------|----------|----------|
| 各类表格 / 阅读单 | 梳理信息、记录观点、对照分析 | 通用,各级各题材 | 12本均用,最通用 |
| 思维导图 | 发散梳理主题/人物/事件脉络 | 中高年级、信息量大的书 | L4《十万个为什么》;官方 L5《航海大发现》梳理时间线与人物事件 |
| 流程图 | 呈现先后顺序、步骤、情节链 | 低中年级、过程性内容、科普 | L4《十万个为什么》;L1–L2 多本(需落地) |
| 时间轴 / 时间线 | 梳理时间脉络、发展阶段 | 历史/航海/传记/长篇 | 官方 L5《航海大发现》;L6《记忆传授人》(提纲有,需落地) |
| 人物关系图 / 家庭树 | 厘清人物及其关系 | 人物多的小说、经典名著 | **L3《大森林里的小木屋》(落地范例,见下)** |
| 维恩图 | 异同对比、跨文本比较 | 中高年级、比较类任务 | **官方案例:L4《手斧男孩》**(见下) |
| 故事地图 / 故事山形图 | 梳理情节结构、起承转合高潮 | 故事/小说类 | **官方案例:《白海豹》故事山形图**(见下) |
| 对比图 / 气泡图 / 树形图 | 多维对照、概念分层、人物特质发散 | 高年级、思辨类 | L5/L6 提纲常列(**多未落地,务必补流程**) |
| 六面体讨论图 | 围绕一主题从6面(联系/描述/比较/争论/应用/分析)深入 | 思辨&应用课、主题讨论 | **L4《我家没有英雄》(落地范例,见下)** |
| 阶梯图 / 阶梯式时间轴 | 分阶段呈现人物成长/梦想进阶 | 成长主题、人物分析 | **官方案例:《吹小号的天鹅》梦想阶梯**(见下) |
| 鱼骨图 / 因果(关系)图 | 呈现因果关系、多因一果 | 议题分析、财商、社会主题、人物影响 | L3《小狗钱钱》因果图;**官方案例:《小鹿斑比》鱼骨图**(见下) |
| 计划表 | 制定/记录阅读计划 | 导读课收尾通用 | 多本导读课 |

## 官方工具案例库(从《阅读策略》文件图示提取 · 供 AI 仿照结构)

以下5个案例是官方文件里**真正填好的范例**(原藏于文档图片,已提取)。生成时按"同工具、同结构、换本书内容"仿照——结构照搬,文字内容必须来自当前书的《书籍档案》,不得搬运这些范例的具体内容。原图存于 `source-docs/可视化工具官方案例图/`。

**① 维恩图 — L4《手斧男孩》(对比阅读,分析主人公成长)**
引导问题:"通过这两章的对比阅读,你有什么发现?"
- 左圈【吃浆果】:为了充饥的无奈之举;找到浆果随着吃就行;浆果很甜,只为果腹;吃多了之后半夜肚子疼。
- 右圈【吃肉】:为了换口味;要想吃到禽鸟肉没那么容易;肉很美味、味道无与伦比;禽鸟的肉吃下去很舒服。
- 交集:填饱了肚子。
- 右侧延伸"不同点"维度:吃的动机 / 获取难度 / 美味程度 / 吃的结果。
结构骨架:`一个引导问题 → 左圈A特征(3–4条)/ 右圈B特征(3–4条)/ 交集共同点 → 提炼对比维度`。

**② 阶梯图 / 阶梯式时间轴 — 《吹小号的天鹅》(分析人物路易斯的梦想进阶)**
引导问题:"路易斯的梦想阶梯可以怎么画?从阶梯图你看出路易斯是一只什么样的天鹅?"
五阶递进(每阶填该阶段目标/成就):
第一阶段 学会读写、与人交流 → 第二阶段 学吹小号、挣钱还债 → 第三阶段 挣钱还债、吹出美妙的音乐 → 第四阶段 吹奏美妙的音乐(爱情/自由/梦想)→ 第五阶段 实现梦想。
结论指向:不断突破自身局限、追求梦想的天鹅。
结构骨架:`3–5 级递增台阶,每级写该阶段的目标或突破 → 看整条阶梯回答"这是个怎样的人物"`。

**③ 思维导图 / 时间轴 — L5《航海大发现》(梳理时间线+人物事件)**
中心【航海大发现】向右按时代分支,每支挂代表人物、留空格待学生补事件:
- 1000年以前:希腊 / 罗马 / 斯堪的纳维亚人
- 13世纪后半叶:马可·波罗
- 15世纪:葡萄牙亨利王子 / 哥伦布 / 卡波特父子
- 16世纪:亚美利哥·韦斯普奇 / 巴尔博亚 / 麦哲伦 / 科尔多瓦 / 科尔特斯 / 皮萨罗 / 德索托 / 科罗纳多
- 17世纪:斯考特和哈得尔 / 亨利·哈德逊 / 英国人 / 荷兰人
用途:明晰发展脉络,思考航海大发现的关键要素。
结构骨架:`中心主题 → 按时间分期 → 每期挂关键人物 → 每人留空格填事件/贡献`。

**④ 故事山形图 — 《白海豹》(《丛林故事》,梳理情节起伏)**
一条山形曲线上 5 个空框:起始 → 上升 → 高潮(顶点)→ 下降 → 结局,学生填各阶段情节。
配套思辨问题(均标注"筛选重要信息、整合、反思评价"策略,各带参考答案):
- 问题1:能成功找到新栖息地,柯迪克做对了什么?
- 问题2:柯迪克在说服族群迁徙过程中遇到的最大障碍是什么?你如何评价他克服障碍的方法?
- 问题3:如果柯迪克不能找到新栖息地,他还有哪些选择?他的冒险和探索有意义吗?
结构骨架:`山形5框填情节 → 配3个由浅入深的思辨问题(各标策略、各给参考)`。

**⑤ 鱼骨图 — 《小鹿斑比》(梳理重要人物对主角的影响)**
鱼头=【成为鹿王子】,鱼尾=【出生】,主干按 童年→青年→中年 分段,各骨支填一个"重要人物/事件对斑比的影响":教导斑比独自生活 / 阻止斑比掉入猎人的圈套 / 教斑比救助其他小动物 / 赞赏和鼓励斑比 / 提醒他生活要谨慎 / 斑比受伤后照顾他……
结尾提示:"同理,我们还可以用同样的方法来分析其他的人物。"
结构骨架:`鱼尾=起点、鱼头=终点结果 → 主干按成长阶段分段 → 各支填影响事件`。



嵌在"阅读交流课2"的一个 15 分钟环节,完整三步闭环:
1. **引出**:师先用提问把信息聚起来——"书中还出现了哪些亲人呢?"(给参考:爷爷、奶奶、姨妈、舅舅、表兄……)。
2. **填画**:"咱们用'家庭树'来画出人物关系图谱。重点画出劳拉的家庭成员,其他家族成员也可以画上去。"给出参考图,**让孩子自由发挥**,画出关系即可。
3. (随后)**分享/分析**:借图分析人物形象,工具服务于"分析人物"这一教学目标,而非为画而画。

**可复制骨架**:`师:(提问聚拢相关信息)→ 师:我们用【X图】把它画/填出来,重点是…… →(给空白图/参考图)→ 学生填画 → 学生分享 + 师点评追问 → 回扣本环节的策略/目标`。

## 落地范例 B:六面体讨论图 — L4《我家没有英雄》(思辨&应用课)

1. **先教方法(5分钟)**:专门用一个短环节讲"什么是六面体讨论"——围绕一个主题从六面展开,讨论得更全面深入。给出六行空表:联系 / 描述 / 比较 / 争论(反驳)/ 应用 / 分析。
2. **再用工具(35分钟)**:用六面体图讨论本书核心主题"英雄",逐面填写、分组讨论、分享。

**要点**:**陌生工具要先花一个小环节讲清"是什么、怎么用",再进入主体讨论**;工具直接挂靠在本课的思辨主题上。

## 生成时的执行清单

- 选工具:按"本书内容 + 本节教学目标 + 上表适配"挑 **1–2 种/节**,不堆砌。
- 写流程:每种工具都要有①引出 ②**Markdown 空白表格 / 节点清单 + 一句结构说明**(不画图、不出图形代码)③填写 ④**分享+反馈**四步。
- 陌生/复杂工具(六面体、鱼骨、维恩):先加一个"介绍方法"的小环节。
- 写提纲:提纲的"可视化教学工具"行 = 正文实际出现的工具,逐一对应。
- 自检:对照 checklist.md 中"可视化工具落地"项。
