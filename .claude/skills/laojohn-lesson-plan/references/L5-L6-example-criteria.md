# L5–L6 范例筛选标准

从已完成的五六年级存货中手工挑选可信范例。**范例标准严于"合格课案"标准**——
范例会被 SKILL 模仿并放大到后续所有同级生成,毛病会被复制。
判断时用"我愿不愿意让 SKILL 把这本的所有特征都学走",而非"这本能不能上课"。

## 五条硬标准(一条不过即不选)

1. **分级深度到位**(最核心):真正体现 L5–L6 应有的高阶思维——文学鉴赏、象征意义分析、
   批判性评估文本、跨文本联结、研究性/跨学科阅读;而非把中年级"理解情节"换本书重写。
2. **结构完整规范**:四节齐全、课型正确、衔接连贯;含教案提纲表、逐节三维目标、阅读单。
3. **页码片段真实可查**:章节、页码与指定版本一致,无"约/参考"虚标。
4. **文字干净**:无错别字、无病句(范例笔误会被当成"老约翰风格"学走)。
5. **题材有代表性**:尽量覆盖不同题材各取样本——经典名著、文言/人物传记、人文百科等;
   题材太单一会导致 SKILL 遇到没见过的题材时失准。

## 流程建议

- **请带过五六年级的教研老师一起把关**,尤其第1条"深度合不合该年级"是教研判断,非格式判断。
- 每个年级哪怕只挑到 1–2 本过关,L5–L6 即从"零范例外推"变为"有真实样本兜底"。
- 选出后放入 `references/examples/L5/`、`L6/`,配齐《书籍档案》。
