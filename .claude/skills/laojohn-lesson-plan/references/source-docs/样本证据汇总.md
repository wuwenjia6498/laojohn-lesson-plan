## 课时结构(实证,与官方《方案设计解析》一致)
- L1-L2:2课时(导读课 + 交流课)。
- L3-L6:4课时(导读课 + 阅读交流课1 + 阅读交流课2 + 思辨&应用课)。
- 每节60分钟。注:L3 两本(大森林/小狗钱钱)提纲虽写"交流课1/2",实为4课时型,与官方L3-L6一致。

## 单节时间切分(实证)
- L1-L2 导读课:导入15min前后 / 共读25min / 课上自读15min / 总结5min(青蛙);或 导入5+预备10/共读25/自读15/总结5(狮子)。
- L4-L6 导读课:导入10-20min / 介绍作家作品5-20min / 先睹为快(课上初读)35min / 制定计划+小结5-10min。
- 交流课:导入10min / 主体(交流讨论·完成阅读单·分析人物)25-45min / 小结5min。
- 思辨&应用课:导入10min / 创意主体(情境模拟·创编/续编·人物采访·辩论·实践)35-45min / 小结5min。

## 阅读策略:实证 ≠ 官方"逐级累加表"  ★重要
官方分级表给的是"该年级应掌握策略全集";成品详案里每本只列**本书实际训练的子集**,按内容定制:
- L1《汉字的故事》竟用了"转化"(理论高阶策略)——说明不按年级硬卡。
- L4《十万个为什么》仅3种(预测/提问/整合);L4《我家没有英雄》列满10种。
- L5/L6 多本雷同:确认重要信息/预测/整合/联结/自我提问/理解监控(±图像化)。
- 用词差异:成品用"确认重要信息/自我提问/理解监控",官方表用"筛选重要信息/提问/监控"——同义不同名。
结论:策略分级表用作"能力天花板/可选池",不作每本必现的硬清单。

## 口气分级(实证,详见 style-and-format.md)
- 教师引语标签:L1-L2 多为"师:…学生互动分享";L4起出现"师(总结):";L5-L6 答案/背景用"明确:""参考资料:"。
- 导入方式:L1-L2 看封面/猜词/联系生活;L3-L4 作者传奇经历或生活话题;L5-L6 观影/概念思辨(乌托邦)/文言互文(桃花源记)。
- 句长与停顿:L1-L2 短句多、含"(稍停顿)"、可"拼音代替";L5-L6 长导语、跨文化、跨学科、长"参考资料"块。
- 题材差异(同级内):非虚构(汉字/十万个为什么)导入用"提问→猜测→投票/圈画重要信息",story类用"预测情节/角色"。
