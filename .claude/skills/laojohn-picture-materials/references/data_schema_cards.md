# 支架小卡 data.json 字段契约

模板：`assets/template_cards.html`（1 页 A4，2 列 × N 行卡片，沿虚线裁开）。
本文件是「看图写话详案锚点 → data.json 字段」的唯一映射源。字段除标「可选」外都必填。

## 富文本

本物料**不解析** `{b}`/`{hl}` 等标记，所有字段纯文本、按内容原样转义。
引用词语一律弯引号 `""`/`''`，禁 `「」`、禁英文直引号。

## 字段总表

```jsonc
{
  "meta": {
    "kicker": "二上（秋）· 第 1 次 · 方法课",   // 详案 H1 / 提纲表「课次·课型」行
    "topic": "细节四方向"                      // 方法名（详案 H1 《…》内），不带书名号
  },
  "head": "…",        // 页眉主行：本课支架层级 + 卡名 + 发放口径（进阶层支架 · 细节四方向提示卡（每人一张，整期随身））
  "note": "…",        // 页眉小字：怎么用 + 「本页 8 张，沿虚线裁开」
  "per_page": 8,      // 可选，默认 8；一张 A4 铺几张卡（偶数，成对裁切）

  "card": {           // 本课要发的支架卡（单一卡型；多卡型时分别各出一份 data.json）
    "type": "quad",   // "chips"=三素句/要素结构条(箭头串联) | "quad"=四方向等 2×2 提示盒
    "title": "加细节 · 四方向",
    "sub": "先写完整一句，再选两个方向加细节",   // 可选，卡副标题

    // type=chips 时：
    "chips": ["谁", "在哪里", "做什么"],         // 箭头串联的要素词
    "hint": "看到一张图：先找「谁」…",           // 可选，chips 卡底部提示句

    // type=quad 时：
    "boxes": [                                  // 2×2 四个方向盒（各 main + 可选 small 追问）
      { "main": "动作", "small": "他在怎么做？" },
      { "main": "表情", "small": "他脸上什么样？" },
      { "main": "语言（想）", "small": "他会说什么？" },
      { "main": "心理（想）", "small": "他心里想什么？" }
    ]
  }
}
```

> chips 卡不要 `boxes`，quad 卡不要 `chips`/`hint`——模板按 `type` 分派，多余字段忽略。

## 详案锚点速查

| 详案锚点 | 供给字段 |
|----------|----------|
| H1 `# <年级册>（<季>）第 N 次《方法名》· 看图写话详案` / 提纲表「课次·课型」「教什么」 | `meta.kicker`、`meta.topic` |
| `## 附：本课支架与说写格式小提醒` 声明的**支架层级**（基础层/进阶层/创意层） | `head`（层级 + 卡名） |
| 正文内联 ASCII 支架卡（`〔发…提示卡〕` 后的 ` ``` ` 框）+ 附录卡复述 | `card`（卡型、标题、要素/方向逐字取；卡上"先写完整一句，再选两个方向加细节"= `sub`） |
| 支架卡发放纪律（每人一张随身、整期留用） | `note` |

三素句结构条（chips）取自一上等基础层课的「谁 → 在哪里 → 做什么」卡；细节四方向（quad）取自二上进阶层「动作/表情/语言/心理」卡。**卡上文字只取详案实际写的那张卡**，不自造方向/要素。

## 模板固定骨架（不在 data.json 里，勿改）

品牌页眉 logo（`品牌资产\logo.png` 注入）、左上「支架小卡 · 每人一张随身 · 沿虚线裁开」标签、卡片 2 列裁切网格、chips 箭头 `→`、quad 2×2 盒版式、令牌配色。
