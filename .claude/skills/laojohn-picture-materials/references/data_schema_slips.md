# 兜底纸条 data.json 字段契约

模板：`assets/template_slips.html`（1 页 A4，竖排 N 条填空纸条，沿虚线横裁）。
本文件是「看图写话详案锚点 → data.json 字段」的唯一映射源。

## 填空线写法

`lines[].template` 里用**全角下划线 `＿`（连续 ≥2 个）**标一处填空线（渲成可写下划线）；
其余文字原样。引用词语弯引号 `""`/`''`，禁 `「」`、禁英文直引号。

## 字段总表

```jsonc
{
  "meta": {
    "kicker": "二上（秋）· 第 1 次 · 方法课",
    "topic": "细节四问"
  },
  "head": "…",        // 页眉主行：这条纸条挂在哪（第 2 课时·当堂写作兜底（给小狗洗澡图））
  "note": "…",        // 页眉小字：发放纪律（不全班发、只给写不动的孩子、能独立起句即撤不连用两次）+「本页 7 条，沿虚线裁开」
  "tag": "给小狗洗澡图 · 填空续写",   // 每条左上的红标（图名 + 用途）
  "repeat": 7,        // 可选，默认 7；一张 A4 重复几条同款纸条

  "lines": [          // 一条纸条里的填空行（顺序＝详案纸条 fenced 块逐行）
    { "label": "开头",   "template": "一个晴朗的上午，＿＿＿在院子里给小狗洗澡。" },
    { "label": "加动作", "template": "他一边＿＿＿，一边＿＿＿。" },
    { "label": "加表情", "template": "小狗一抖，水珠甩了他一脸，他＿＿＿。" }
  ]
}
```

## 详案锚点速查

| 详案锚点 | 供给字段 |
|----------|----------|
| H1 / 提纲表「课次·课型」 | `meta.kicker`、`meta.topic` |
| 第 2 课时「当堂写作」环节里「给写不动的孩子」递的纸条 ` ``` ` fenced 块 | `lines`（`label:` = 冒号前的词逐字，`template:` = 冒号后的句逐字，`＿＿＿` 保留为填空线） |
| 环节里 `〔发…小纸条〕` 巡视话术 + 附录「撤架信号」中"开头句纸条…能独立起句即撤，不连用两次" | `head`、`note`、`tag` |

> 纯口头课（免"写"）无当堂写作 → **不出本物料**。

## 模板固定骨架（勿改）

品牌页眉、左上「兜底纸条 · 只发写不动的孩子 · 沿虚线裁开」标签、纸条虚线裁切框、红色 `.slip-tag`、填空下划线、令牌配色。
