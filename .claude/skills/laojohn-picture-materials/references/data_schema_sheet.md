# 看图写话稿纸 data.json 字段契约

模板：`assets/template_sheet.html`（1 页 A4：本课图框 + 格子稿纸（18 列动态行）+ 写话格式小提醒）。
本文件是「看图写话详案锚点 → data.json 字段」的唯一映射源。

## 富文本

本物料纯文本，无 `{b}` 标记。引用词语弯引号 `""`/`''`，禁 `「」`、禁英文直引号。

## 字段总表

```jsonc
{
  "meta": {
    "kicker": "二上（秋）· 第 1 次 · 方法课",
    "topic": "细节四方向"
  },
  "sheet": {
    "anchor_img": "看图写话详案输出/二上（秋）第 1 次 · 方法课/图位/锚-01.png",
                       // 可选：本课锚图路径（相对项目根/CWD 或绝对）。渲染时内联为缩略图；
                       // 缺失或渲染入口 --anchor 覆盖为空 → 留"老师另发/贴图"占位框。
    "lead": "…",       // 标题下导语：本次写话要求一句话（不少于 4 句、至少两个方向）
    "draftnote": "…",  // 格子上方一行起笔提示（取名 + 先完整一句再选两个方向加细节）
    "format_tips": [   // 底部「写话格式小提醒」← 详案〔写话小提醒〕逐条
      "开头空两格",
      "一句话没结束写逗号，结束写句号",
      "说话句用冒号、引号",
      "标点符号不顶格写",
      "不会写的字用拼音，不写错别字"
    ]
  }
}
```

## 详案锚点速查

| 详案锚点 | 供给字段 |
|----------|----------|
| H1 / 提纲表「课次·课型」「学生带走」 | `meta`、`sheet.lead`（写话要求＝"学生带走"行的量化标准） |
| 第 2 课时「当堂写作」环节起笔要求（取名 / 先完整一句 / 选两个方向） | `sheet.draftnote` |
| `〔写话小提醒〕` fenced/列表块（每课呈现的格式提醒） | `sheet.format_tips`（逐条） |
| `看图写话详案输出\<详案stem>\图位\锚-01.png`（详案生图产物） | `sheet.anchor_img` |

> 纯口头课（免"写"）无当堂写作 → **不出本物料**。

## 模板固定骨架（勿改逻辑）

品牌页眉、标题区、姓名/日期条、本课图框（`__ANCHOR_SRC__` 由渲染入口注入，缺则占位）、
**格子稿纸 `buildGrid`（18 列、按可用高度动态定行数、100/200 字刻度）＝复用 writing-materials 单一源骨架**、老师批改栏、写话格式提醒条、令牌配色。
