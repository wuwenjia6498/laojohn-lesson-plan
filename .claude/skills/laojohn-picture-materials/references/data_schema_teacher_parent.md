# 教师家长页 data.json 字段契约

模板：`assets/template_teacher_parent.html`（2 页 A4：P1 教师速览 / P2 家长一页纸）。
本文件是「看图写话详案锚点 → data.json 字段」的唯一映射源。

## 富文本

只认 `{b}…{/b}`（加粗，各区块有各自强调色），其余原样转义。
表格类字段（`pass_table`、`eval_levels`、时间轴）纯文本、不加标记。
引用词语弯引号 `""`/`''`，禁 `「」`、禁英文直引号。

## 字段总表

```jsonc
{
  "meta": {
    "kicker": "二上（秋）· 第 1 次 · 方法课",
    "topic": "细节四问",
    "genre": "看图写话 · 方法课"          // 课型副标题
  },

  "teacher": {                             // ── P1 教师速览
    "goal": "…",                           // 一句话目标 ← 提纲表「教学内容」+「学习目标」，{b}标能力点
    "pass_title": "怎么算写生动了（过关判定）",  // 可选，默认「怎么算过关了（过关判定）」；取详案〔过关判定〕小标题措辞
                                           //   （写话课=「怎么算写生动了」；纯口头课=「怎么算说清楚了」）
    "lessons": [                           // 两节课时间轴（分钟逐字取详案环节标题）
      { "title": "第1课时 · …",
        "steps": [ { "min": "10′", "name": "…" } ] },
      { "title": "第2课时 · …",
        "steps": [ { "min": "10′", "name": "…" } ] }
    ],
    "pass_table": [                        // 过关判定 ← 详案〔过关判定〕表逐行
      { "verdict": "不算过关", "example": "…", "note": "…" },
      { "verdict": "算过关",   "example": "…", "note": "…" },
      { "verdict": "加分",     "example": "…", "note": "…" }
    ],                                     // verdict 值须是 不算过关/算过关/加分（决定判定色）
    "eval_levels": [                       // 评价三级 ← 详案〔评价·三级〕逐条（顺序=基础/良好/优秀）
      { "level": "基础", "desc": "…" },
      { "level": "良好", "desc": "…" },
      { "level": "优秀", "desc": "…" }
    ],
    "essay": {                             // 教师示范例文 ← 详案【教师示范例文】blockquote
      "title": "…（教师示范例文）",
      "paragraphs": [ "…", "…" ]           // 逐句照抄，去掉行末（批注）；正文含弯引号原样保留
    },
    "materials": [ "…", "…" ]              // 物料清单 ← 本课要发/用的卡·纸条·主图打印·稿纸·换任务图
  },

  "parent": {                              // ── P2 家长一页纸（派生，不虚构学生作品）
    "oneline": "…",                        // 一句话说清这节课学什么
    "para": "…",                           // 展开：方法（几问/看得见 vs 想出来），{b}标关键词
    "compare": {                           // 好坏对照 ← 过关判定的"不算过关"vs"算过关"改写成家长话
      "bad":  { "head": "只写完整的一句", "quote": "…", "note": "…" },
      "good": { "head": "加了细节的一段", "quote": "…", "note": "…（{b}标能力{/b}）" }
    },
    "task": {                              // 好句本·亲子任务 ← 详案〔课后·好句本〕改成家长可操作步骤
      "title": "好句本 · 亲子五分钟",
      "steps": [ "…", "…", "…" ],          // 家长第二人称步骤（读给你听 / 挑一句抄标哪一问 / 你当读者）
      "tip": "…"                           // 一句叮嘱（当读者不当裁判）
    },
    "dont": [ "…", "…" ]                    // 避开两件（别代笔改成大人话 / 别逼四问都用）
  }
}
```

## 详案锚点速查

| 详案锚点 | 供给字段 |
|----------|----------|
| H1 / 提纲表「课次·课型」「教学内容」「学习目标」 | `meta`、`teacher.goal` |
| `## 第N课时 · <小标题>` + `### 环节…（N 分钟）` | `teacher.lessons`（title / steps，分钟逐字） |
| 〔过关判定·怎么算写生动了〕表 | `teacher.pass_table` |
| 〔评价·三级〕 | `teacher.eval_levels` |
| 【教师示范例文】blockquote | `teacher.essay`（逐句照抄，去批注） |
| 本课支架/图/纸条发放（提纲表「教学准备」+ 附录三手柄） | `teacher.materials` |
| 教「哪四问、看得见 vs 想出来」的师话小结 | `parent.oneline`、`parent.para` |
| 过关判定"不算过关" vs "算过关"例句 | `parent.compare`（改写成家长话，例句可引详案过关判定例句） |
| 〔课后·好句本〕环节 | `parent.task` |
| 评价三级达标线 / 撤架纪律 / 分层达标 | `parent.dont`（"用好两问"是达标线，别贪多） |

> **真实性**：`teacher.essay`、`pass_table` 例句、时间轴分钟逐字取详案；`parent` 各项派生自详案方法与判定，**不编造孩子写的具体句子**（家长页只讲能力与怎么陪）。

## 模板固定骨架（勿改）

品牌页眉、两页标题区、时间轴 `.min` 分钟胶囊、过关判定表（判定色按 verdict）、评价三级三色卡、示范文框、物料清单勾选、家长页 一句话/好坏对照/🏠亲子任务/避开两件版式、令牌配色。
