# laojohn-ppt — 中间稿 → 投屏 PPT 编译器

把一份"课件中间稿 markdown"编译为投屏专用 `.pptx`（16:9，微软雅黑 + 宋体，零依赖）。
本技能只做"渲染"，不做内容生成；上游中间稿由 `laojohn-ppt-draft` 或人工撰写产生。

## 何时使用

- 用户说"把中间稿做成 PPT""根据中间稿生成投屏 PPT""把这份 md 烘焙成 pptx"
- 用户上传一份带 `## P\d+ | 页型:xx` 分页的 md 并希望产出 pptx
- 上游 Skill `laojohn-ppt-draft` 已输出中间稿，需要继续编译

## 中间稿契约（重要）

每一份中间稿对应 **一节课** 的 PPT（导读课 / 阅读交流课1 / 阅读交流课2 / 思辨应用课 之一）。

### 1) 元信息块（文件顶部，可选）

```
书名：俗世奇人
课时：导读课
作者：冯骥才 著
年级：L5 · 五年级
```

### 2) 分页头

```
## P14 | 页型:原文齐读
```

`P14` 是详案里"【PPT换页-P14】"的全局编号，**仅用于回溯**：
- 中间稿里的 P 编号不必从 1 开始，也不必连续，跨课时无需重排
- PPT 内显示的页码是 PPT 内顺序（1 / Total），与 P 编号解耦

页型枚举（**6 种，多一个都不行**）：
`封面` / `环节标题` / `引导问题` / `原文齐读` / `要点小结` / `填空表格`

### 自动注入的封面 / END 页（v6）

每节课 PPT 会自动包含：

- **起始页（封面）**：若中间稿首页不是 `封面`，build_ppt 会自动注入一页。
  布局与导读课起始页完全一致（横幅 + ▷ 三角 + LOGO + 居中书名 + 副标题 + 左下作者），副标题取自元信息里的"课时"。
  若中间稿已写 `封面` 页，则使用中间稿内容，不重复注入。
- **结束页（END）**：每份 PPT 末尾自动追加一页。
  青绿渐变底 + 居中超大 "END" + 老约翰 LOGO + 右下"下一次再见 ▶"。
  样式固定，中间稿无需声明。

**页码计数**：仅对中间内容页计数（封面、END 不参与）。例如 12 张 slide 的 PPT，页码显示 1/10 ~ 10/10。

### 3) 字段集合（共 7 个，缺省即省略）

| 字段 | 类型 | 说明 |
|---|---|---|
| 眉标 | 单行 | 页内小节/篇目（如"苏七块"），**不写课型** |
| 标题 | 单行 | 页面主标题 |
| 副标题 | 单行 | 仅"填空表格"用 |
| 正文 | 多行 | 段落文本；原文齐读放节选原文 |
| 要点 | 列表 | 以 `- ` 开头，每行一条 |
| 表格 | GFM 表格 | 仅"填空表格"用，标准 `\| col \| col \|` 格式 |
| 配图建议 | 单行 | `篇目·场景｜书内页码｜建议元素：x、y` 或填"无" |

### 4) 完整示例

```
## P03 | 页型:引导问题
眉标：猜书名
标题：书名叫《俗世奇人》——请关注"俗"和"奇"这两个字
要点：
- 这本书可能写的是哪些人
- "俗"是什么意思
- "奇"又奇在哪里
配图建议：苏七块·封面人物｜书内P12｜建议元素：长衫大夫、手部特写
```

完整示例文件见 `examples/mini-test.md`。

## 调用方式

```bash
cd .claude/skills/laojohn-ppt/scripts
python build_ppt.py --input <中间稿.md> --output <输出.pptx>
```

可选参数：
- `--course "导读课"` 覆盖元信息里的课时
- `--book "俗世奇人"` 覆盖书名
- `--logo <path>` 自定义 LOGO（默认取 `../assets/logo/logo-red.png`）
- `--banner <path>` 自定义封面横幅（默认取 `../assets/decorations/cover-banner.jpg`）

执行后终端会输出"配图占位清单"——把这份清单交给老师即可知道哪些页需要手动贴图。

## 视觉规范（已内建）

- 16:9 / 微软雅黑（标题）+ 宋体（正文）/ Calibri（数字英文）
- 左上：深灰蓝 `#44546A` 色条 + 课时铭牌（仅内页）
- 右上：LOGO（封面 9.4%，内页 11.6%）
- 右下：页码 `N / Total`（封面、END 不显示页码）
- 配图占位框：虚线 + 浅灰底 + 📷 + 配图建议文字（**不会**强行画图，老师手动贴图）
- 原文齐读：浅米色 `#F5F1EA` 书页底，正文 1.8 倍行距 + 首行缩进 2 字
- **END 页**：青绿渐变 `#6FB4AF → #3A7F7A`（135°）+ 居中白色 "END" 200pt + 底部 LOGO + 右下"下一次再见 ▶"

## 不做的事

- 不生成内容，不改写文案
- 不内嵌字体（保证 .pptx 体积小、跨平台兼容）
- 不自动配图（始终给老师占位框）
- 不导出 PDF（让 PowerPoint/WPS 自行导出）

## 故障排查

| 现象 | 原因 | 处理 |
|---|---|---|
| 报错"页型未识别" | 中间稿写了非 6 类页型 | 检查 `## P\d+ \| 页型:xx` 是否在枚举内 |
| 中文字体回退 | 系统未装微软雅黑/宋体 | Windows 默认有；Mac 会回退到苹方/宋体-简，可接受 |
| 配图框文字溢出 | 配图建议过长 | 在中间稿里精简，控制在 30 字内 |
| 表格挤压 | 行数过多 | 拆成两页填空表格 |
