# laojohn-ppt — 中间稿 → 投屏 PPT 编译器

把一份"课件中间稿 markdown"编译为投屏专用 `.pptx`（16:9，微软雅黑 + 宋体，零依赖）。
本技能只做"渲染"，不做内容生成；上游中间稿由 `laojohn-ppt-draft` 或人工撰写产生。

## 何时使用

- 用户说"把中间稿做成 PPT""根据中间稿生成投屏 PPT""把这份 md 烘焙成 pptx"
- 用户上传一份带 `## P\d+ | 页型:xx` 分页的 md 并希望产出 pptx
- 上游 Skill `laojohn-ppt-draft` 已输出中间稿，需要继续编译

## 中间稿契约（重要）

每一份中间稿对应 **一节课** 的 PPT（导读课 / 阅读交流课1 / 阅读交流课2 / 思辨应用课 之一）。

### 1) 元信息块（文件顶部，可选）

```
书名：俗世奇人
课时：导读课
作者：冯骥才 著
年级：L5 · 五年级
```

### 2) 分页头

```
## P14 | 页型:原文齐读
```

`P14` 是 `laojohn-ppt-draft` **自排的中间稿内部编号**（详案已无换页点可沿用），**仅作引用 ID**：
- 中间稿里的 P 编号每节课都从 P01 起（每课时独立，不跨课时延续）：**P01 固定为封面页、正文内容页从 P02 起**，与详案页标 `〖PPT 第N页〗`、课件实际翻页一致
- **PPT 不在页面上标注页码**（右下角不印 `N/Total`）；页号以课件系统实际翻页为准（封面=第1页、正文从第2页起）

页型枚举（**6 种，多一个都不行**）：
`封面` / `环节标题` / `引导问题` / `原文齐读` / `要点小结` / `填空表格`

### 自动注入的封面 / END 页（v6）

每节课 PPT 会自动包含：

- **起始页（封面）**：若中间稿首页不是 `封面`，build_ppt 会自动注入一页。
  布局与导读课起始页完全一致（横幅 + ▷ 三角 + LOGO + 居中书名 + 副标题 + 左下作者），副标题取自元信息里的"课时"。
  若中间稿已写 `封面` 页，则使用中间稿内容，不重复注入。
- **结束页（THE END）**：每份 PPT 末尾自动追加一页。
  青绿渐变底 + 居中超大 "THE END" + 老约翰 LOGO + 右下"下一次再见 ▶"。
  样式固定，中间稿无需声明。

**页码**：PPT 页面上**不标注页码**（右下角不印 `N/Total`）。页号以课件系统实际翻页为准——封面=第1页、正文从第2页起，与详案页标 `〖PPT 第N页〗`、逐页讲稿 `## 第N页` 一致。

### 3) 字段集合（共 7 个，缺省即省略）

| 字段 | 类型 | 说明 |
|---|---|---|
| 眉标 | 单行 | 页内小节/篇目（如"苏七块"），**不写课型** |
| 标题 | 单行 | 页面主标题 |
| 副标题 | 单行 | 仅"填空表格"用 |
| 正文 | 多行 | 段落文本；原文齐读放节选原文 |
| 要点 | 列表 | 以 `- ` 开头，每行一条；**某条要点下紧跟一行 `参考：答案`**（缩进 2 空格）→ 该答案渲成红字、问题之后点击淡入（见下「要点参考答案上屏」） |
| 表格 | GFM 表格 | 仅"填空表格"用，标准 `\| col \| col \|` 格式；**空格答案用 `{{答案}}` 标记**（见下「填空表格答案逐格点击」） |
| 配图建议 | 单行（可多条） | `篇目·场景｜书内页码｜建议元素：x、y` 或填"无"；引导问题页写 ≥2 条 → 自动排 2×2 四图网格 |

> **四图网格**：引导问题页带 **2–4 条** `配图建议：` 时，标题下整幅排成 2×2 占位网格（每幅一格、逐格各配一图），此模式自动**不画问号水印、不渲染要点**（题面由各格配图建议的「篇目·场景」段承载）。用于"给学生看 N 幅画面，自己感受"这类页。单条配图建议行为不变。

### 填空表格答案逐格点击（答案 `{{}}` 标记）

填空表格是给学生填的；答案过去只在详案里、PPT 端无法呈现。现在中间稿可把答案填进表格单元格、用 `{{答案}}` 包裹，渲染器据此：

- **底表留空**：每个 `{{X}}` 在底表渲成空白占位 `＿＿`，单元格其余提示文字照常显示；
- **答案叠层**：对每个含 `{{}}` 的单元格，叠一个「不透明底色矩形 + 完整答案文本框」盖在该格上，初始隐藏；
- **逐格点击**：按阅读顺序（行优先、列内左→右）一格一击淡入填出，复用 `add_click_reveal`。

两类空格：整格留白 → 整格答案包 `{{1—28章}}`；行内挖空 → 只包答案片段 `【第{{3}}章】`（提示留在框里）。一个单元格含多个 `{{}}` 仍算一格、一次点击整格揭示。

`--no-anim` 或系统不支持动画时，所有答案叠层直出（=答案静态全显，非损坏）。**无 `{{}}` 标记的表格行为不变**（纯空白表）。技术原因：OOXML 表格是单 graphicFrame、无法对单元格做动画目标，故答案必须用独立叠层形状才能逐格点击。

### 要点参考答案上屏（`参考：` · 红字逐段点击）

引导问题 / 要点小结两类页型，**某条要点(问题)下若紧跟一行 `参考：答案`**，渲染器（`add_qa_textbox`）会把该页要点改成"问题 + 红色参考答案"交错版式：

- **问题**（圈号 ①②③、正文色）在上，**参考答案**（缩进、红字 `#C0392B`）紧跟其下；
- **逐段点击**：先出问题，点一次再淡入红色答案，每段各一击（复用 `add_click_reveal` 段落级揭示）；
- `--no-anim` 或系统不支持动画时全部静态显示（问题黑、答案红），不影响线上系统；
- **某条要点没有 `参考：` 也兼容**——只出问题、无红字答案。

整页**任一条要点带 `参考：`** 即切换此版式（要点小结此时不再用红方块编号，改圈号问答）；**全页无 `参考：` 时行为完全不变**（引导问题=圈号要点、要点小结=红方块编号）。答案来源、压短、真实性红线见 ppt-draft `references/field-extraction.md` §5。

### 4) 完整示例

```
## P03 | 页型:引导问题
眉标：猜书名
标题：书名叫《俗世奇人》——请关注"俗"和"奇"这两个字
要点：
- 这本书可能写的是哪些人
- "俗"是什么意思
- "奇"又奇在哪里
配图建议：苏七块·封面人物｜书内P12｜建议元素：长衫大夫、手部特写
```

完整示例文件见 `examples/mini-test.md`。

## 调用方式

### 固定输出目录

> ⚠ 本项目位于移动硬盘，盘符可能随挂载变动。执行前请通过 Cursor 工作区路径或 `(Get-Location).Path` 确认实际项目根目录，下方 `<项目根目录>` 代表该路径。

**所有投屏课件 PPT 统一保存到：**

```
<项目根目录>\课件PPT输出\<书名>\
```

例：`<项目根目录>\课件PPT输出\俗世奇人\俗世奇人-导读课.pptx`

---

```bash
cd .claude/skills/laojohn-ppt/scripts
python build_ppt.py --input "<项目根目录>\课件中间稿输出\<书名>\<书名>-<课型>-中间稿.md" --output "<项目根目录>\课件PPT输出\<书名>\<书名>-<课型>.pptx"
```

可选参数：
- `--course "导读课"` 覆盖元信息里的课时
- `--book "俗世奇人"` 覆盖书名
- `--logo <path>` 自定义 LOGO（默认取 `../assets/logo/logo-red.png`）
- `--banner <path>` 自定义封面横幅（默认取 `../assets/decorations/cover-banner.jpg`）
- `--no-anim` 关闭逐条点击动画（**默认开启**，见下方「逐条点击呈现」）

执行后终端会输出"配图占位清单"——把这份清单交给老师即可知道哪些页需要手动贴图。

## 视觉规范（已内建）

- 16:9 / 微软雅黑（标题）+ 宋体（正文）/ Calibri（数字英文）
- 左上：深灰蓝 `#44546A` 色条 + 课时铭牌（仅内页）
- 右上：LOGO（封面 9.4%，内页 11.6%）
- 右下：**不标注页码**（已取消 `N / Total` 角标）
- 配图占位框：虚线 + 浅灰底 + 📷 + 配图建议文字（**不会**强行画图，老师手动贴图）
- 原文齐读：浅米色 `#F5F1EA` 书页底，正文 1.8 倍行距 + 首行缩进 2 字
- **END 页**：青绿渐变 `#6FB4AF → #3A7F7A`（135°）+ 居中白色 "THE END" 120pt + 底部 LOGO + 右下"下一次再见 ▶"

### 自动差异化渲染（v6.1）

为避免大量同类页面视觉同质化，渲染器内建三套差异化策略，**中间稿无需声明**：

- **关键词高亮**：标题里被 `""`（U+201C/U+201D 中文弯引号）、`「」`、`"…"`（ASCII 直引号）任一包围的词，自动渲染为红色加粗
  - 例：`关注"俗"和"奇"两个字` → "俗" "奇" 两字红色加粗
- **环节标题自适应**：
  - 多环节课时（≥ 2 张环节标题页）：左上 200pt 巨型 02 序号 + 红色短分隔 + 大白字左对齐标题
  - 单环节课时（仅 1 张环节标题页）：自动隐藏序号，改为**居中大标题** + 居中红色短分隔 + 居中副本
  - 因此**单环节课时的中间稿标题不要带"一、"前缀**（上游 `laojohn-ppt-draft` v1.2 已约束）
- **引导问题序号水印**：同一 PPT 内多张 `引导问题` 页自动渲染 `Q1 / Q2 / Q3…` 半透明水印（240pt 中文红 12% 透明），避免"问号墙"

### 逐条点击呈现（v7 · 默认开启）

为降低"整页内容一次性铺满"的认知压力、让老师按讲课节奏推进，渲染器给三类页型注入 **PowerPoint 原生「点击淡入」动画**（OpenXML `<p:timing>` mainSeq），**中间稿无需声明**：

| 页型 | 逐条单元 | 机制 |
|---|---|---|
| **要点小结** | 每条要点（红方块 + 数字 + 文字 3 形状成组）；**带 `参考：` 时**改"问题段 + 红字答案段"逐段 | 一次鼠标点击同出一条 / 一段 |
| **引导问题** | `要点` 里的每条追问；**带 `参考：` 时**追加红字答案段 | 单文本框按段落构建（`bldP byParagraph`），点一次出一段 |
| **填空表格** | 每个 `{{}}` 答案格（不透明矩形 + 答案文本框成组） | 底表留空，一次点击淡入填出一格 |

> **要点带参考答案**（`参考：`）时，引导问题/要点小结都改走 `add_qa_textbox`：问题(圈号·正文色)与红色参考答案交错成段，**先出问题、点击后出红字答案**，每段各一击（见上「要点参考答案上屏」）。

规则与边界：

- **只对要点小结、引导问题追问、参考答案段、填空表格答案格生效**；封面 / 环节标题 / 原文齐读 / END **不加动画**（一次性直出）。填空表格**无 `{{}}` 标记时**（纯空白表）也不加动画。
- **标题、眉标、引文(正文)、问号水印、表头与提示文字首屏即在**，不参与点击——逐条出的只有"要点 / 追问 / 参考答案 / 答案格"本身。
- **要点/追问/问答段仅 ≥2 段才启用**；单段直接静态显示。填空表格只要有 `{{}}` 答案格即逐格点击。
- 动画类型固定为**淡入（fade, 0.5s）+ 点击推进**（非自动计时），克制不抢内容。
- **交付前提**：老约翰用的线上课件系统已确认能播放 PPT 原生动画。若换到**会把幻灯片拍平成图片/PDF 的系统**，动画会被丢弃；多数此类系统退化为"该页全部内容直出"（非损坏），如遇异常用 `--no-anim` 关闭、回退翻页式逐进。
- 实现：`helpers.add_click_reveal(slide, groups)` 注入时间树；`add_numbered_bullets` 返回每条的形状分组。每个 `<p:cTn>` id 全树唯一，文件可被 python-pptx 重新打开、无修复弹窗。

## 不做的事

- 不生成内容，不改写文案
- 不内嵌字体（保证 .pptx 体积小、跨平台兼容）
- 不自动配图（始终给老师占位框）
- 不导出 PDF（让 PowerPoint/WPS 自行导出）

## 故障排查

| 现象 | 原因 | 处理 |
|---|---|---|
| 报错"页型未识别" | 中间稿写了非 6 类页型 | 检查 `## P\d+ \| 页型:xx` 是否在枚举内 |
| 中文字体回退 | 系统未装微软雅黑/宋体 | Windows 默认有；Mac 会回退到苹方/宋体-简，可接受 |
| 配图框文字溢出 | 配图建议过长 | 在中间稿里精简，控制在 30 字内 |
| 表格挤压 | 行数过多 | 拆成两页填空表格 |
