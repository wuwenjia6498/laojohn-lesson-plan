## 基础视觉规范

- 16:9 / 微软雅黑（标题）+ 宋体（正文）/ Calibri（数字英文）
- 左上：深灰蓝 `#44546A` 色条 + 课时铭牌（仅内页）
- 右上：LOGO（封面 9.4%，内页 11.6%）

- 原文齐读：浅米色 `#F5F1EA` 书页底，正文 1.8 倍行距 + 首行缩进 2 字
- **END 页**：青绿渐变 `#6FB4AF → #3A7F7A`（135°）+ 居中白色 "THE END" 120pt + 底部 LOGO + 右下"下一次再见 ▶"

## 自动差异化渲染（v6.1）

为避免同类页面视觉同质化，渲染器内建三套策略，**中间稿无需声明**：

- **关键词高亮**：标题里被 `""`（中文弯引号）、`「」`、ASCII 直引号任一包围的词，自动渲染为红色加粗（例：`关注"俗"和"奇"两个字` → "俗""奇"红色加粗）。
- **环节标题自适应**：多环节课时（≥2 张环节标题页）＝左上 200pt 巨型序号 + 红色短分隔 + 大白字左对齐；单环节课时＝自动隐藏序号、改居中大标题 + 居中红色短分隔。因此**单环节课时的中间稿标题不要带"一、"前缀**（上游 ppt-draft v1.2 已约束）。
- **引导问题页不加 `Q1/Q2` 序号水印**（历史曾渲染半透明大字水印，现已移除；仅保留标题左侧红色竖条）。

## 逐条点击呈现（v7 · 默认开启）

渲染器给三类页型注入 **PowerPoint 原生「点击淡入」动画**（OpenXML `<p:timing>` mainSeq），**中间稿无需声明**：

| 页型 | 逐条单元 | 机制 |
|---|---|---|
| **要点小结** | 每条要点（红方块+数字+文字 3 形状成组）；**带 `参考：` 时**改"问题段+红字答案段"逐段 | 一次点击同出一条/一段 |
| **引导问题** | `要点` 里的每条追问；**带 `参考：` 时**追加红字答案段 | 单文本框按段落构建（`bldP byParagraph`），点一次出一段 |
| **填空表格** | 每个 `{{}}` 答案格（不透明矩形+答案文本框成组） | 底表留空，一次点击淡入填出一格 |

带 `参考：` 时引导问题/要点小结都改走 `add_qa_textbox`（问答交错，先问题后点击出红字答案，见 `page-contract.md` §8）。

规则与边界：

- **只对要点小结、引导问题追问、参考答案段、填空表格答案格生效**；封面/环节标题/原文齐读/END **不加动画**。填空表格无 `{{}}` 时也不加。
- **标题、眉标、引文(正文)、表头与提示文字首屏即在**，不参与点击。
- **要点/追问/问答段仅 ≥2 段才启用**；单段直接静态显示。填空表格只要有 `{{}}` 答案格即逐格点击。
- 动画类型固定为**淡入（fade, 0.5s）+ 点击推进**（非自动计时），克制不抢内容。
- **交付前提**：老约翰线上课件系统已确认能播 PPT 原生动画。若换到会把幻灯片拍平成图片/PDF 的系统，动画被丢弃、多数退化为整页直出（非损坏）；如遇异常用 `--no-anim` 关闭。
- 实现：`helpers.add_click_reveal(slide, groups)` 注入时间树；`add_numbered_bullets` 返回每条形状分组。每个 `<p:cTn>` id 全树唯一，文件可被 python-pptx 重新打开、无修复弹窗。

## 故障排查

| 现象 | 原因 | 处理 |
|---|---|---|
| 报错"页型未识别"/"无渲染器" | 中间稿页型不在该 profile 枚举内 | 检查 `## P\d+ \| 页型:xx` 与元信息 `文体：` 是否匹配 |
| 中文字体回退 | 系统未装微软雅黑/宋体 | Windows 默认有；Mac 回退苹方/宋体-简，可接受 |
| 配图框文字溢出 | 配图建议过长 | 中间稿里精简，控制在 30 字内 |
| 表格挤压 | 行数过多 | 拆成两页填空表格 |
