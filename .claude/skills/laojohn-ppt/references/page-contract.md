# 中间稿契约（页型 · 字段 · 答案上屏机制）

> 2026-07-27 由 SKILL.md 下沉，本文件为中间稿输入契约细则唯一源。profile 分层架构见 `architecture.md`；写作页型**字段写法**的唯一源仍是 `laojohn-ppt-draft/references/writing-mode.md` §2/§2.5/§2.6/§2.7（本文件不与之双写，只收录渲染端行为）。

每一份中间稿对应 **一节课** 的 PPT（导读课 / 阅读交流课1 / 阅读交流课2 / 思辨应用课 之一；写作课为 写作指导课 / 当堂写作与评改课）。

## 1) 元信息块（文件顶部，可选）

```
书名：俗世奇人
课时：导读课
作者：冯骥才 著
年级：L5 · 五年级
```

写作课中间稿另有 `文体：写作`（profile 触发开关，见 architecture.md）。

## 2) 分页头

```
## P14 | 页型:原文齐读
```

`P14` 是 `laojohn-ppt-draft` **自排的中间稿内部编号**，**仅作引用 ID**：
- P 编号每节课从 P01 起（每课时独立，不跨课时延续）：**P01 固定为封面页、正文内容页从 P02 起**，与详案页标 `〖PPT 第N页〗`、课件实际翻页一致。
- **PPT 不在页面上标注页码**（右下角不印 `N/Total`）；页号以课件系统实际翻页为准（封面=第1页、正文从第2页起）。

页型枚举（**按 profile 裁决**）：
- **读书会 profile（缺省）6 种**：`封面` / `环节标题` / `引导问题` / `原文齐读` / `要点小结` / `填空表格`
- **写作课 profile（元信息 `文体：写作` 触发）**：共用 封面/环节标题/填空表格，另有写作专属 `情境任务`/`写法讲解`/`活动指令`/`示范文`/`双栏对照`/`写作任务`/`实景观察`（v8）——`双栏对照` 块模式用 `左标题/左正文/右标题/右正文` + 可选 `要点`、行模式用 `表格`；`写作任务` 用 `要点` + 可选 `计时/字数`。
- 某页型在某 profile 下是否有效由 `RENDERERS_<profile>` 字典裁决；写错 profile（如读书会稿写 `写作任务`）会因查不到 renderer 报错。

## 3) 写作专属页型（v8）：`实景观察`

给学生看真实场景照片、问"看/听/闻/摸到什么"的观察页（图在上、绿色说明条压图底沿、问答文字在图外下方、绿线收尾）。字段用重复的 `场景：` 行，**按场景数自动切版面**——1 景=图占右侧+问答在左，2 景=两卡并排：

```
## P04 | 页型:实景观察
眉标：调动感官
标题：校园老槐树下——你"看""听""闻"到了什么？
场景：图=imgs/tree.jpg｜名=校园老槐树下｜问=你"看"到了什么？｜答=槐树叶、地上的光斑、石凳……
```

`场景：` 四段（`图=`路径 · `名=`场景名 · `问=`问题 · `答=`答案）；`答` 为红字、点击后淡入。图路径相对中间稿 .md 目录；缺图自动退占位框、不报错。

## 4) v8 视觉版式选择器（讲解/情境类页型可选，不声明＝默认，向后兼容）

- **标题粉底色块＝写作内页默认标题款（v8.1）** — 写作 profile 的内页标题（凡走 `_heading` 的）**默认**外扩浅粉圆角块托住标题（无描边/无阴影/无下短线），不用声明。`标题样式：强调`/`默认` 是同款别名（向后兼容）。
- **`标题样式：竖条`** — 标题左侧红竖条（密集讲解页可选，不画色块）。
- **`标题样式：纯文字`/`无`** — opt-out：不画色块、回到纯文字标题 + 标题下红短线。
- **`要点样式：卡片`** / **`卡片强调`** — 每条要点一张浅底圆角卡横排 + 序号圆章（3 条稳、4 条缩）；`卡片强调` 末条红底突出。
- **`要点样式：节点`** — 双层菱形序号节点 + 折线引导 + 文字（3–4 条竖排；序号菱形，不放语义图标）。
- **`要点样式：步骤`** — 方块序号 + 竖连接线（照步骤做的动手环节）。
- **`要点样式：图文`** — 左真图（`配图建议：图=<路径>`）+ 右要点竖排。
- 未声明＝竖排（有序 bar、无序 dot）。**某条要点带 `参考：` 答案时，版式选择器让位于问答交错**（教学正确性优先，卡片/菱形不承载红答案）。

**真图通道**：`配图建议：图=<路径>｜说明…` 的 `图=` 段会被抽出作真实图片（`图文` 版式、`实景观察` 页共用）；无 `图=` 时行为不变（虚线占位框）。图片路径相对中间稿 .md 目录解析。

**适用范围**：写作 profile 用；`render_teach`/`render_task_intro` 认，`render_activity` 不认。

## 5) 自动注入的封面 / END 页（v6）

- **起始页（封面）**：中间稿首页不是 `封面` 时 build_ppt 自动注入一页（横幅 + ▷ 三角 + LOGO + 居中书名 + 副标题 + 左下作者，副标题取元信息「课时」）；已写 `封面` 页则用中间稿内容、不重复注入。
- **结束页（THE END）**：每份 PPT 末尾自动追加（青绿渐变底 + 居中超大 "THE END" + LOGO + 右下"下一次再见 ▶"），样式固定、中间稿无需声明。

## 6) 字段集合（共 7 个，缺省即省略）

| 字段 | 类型 | 说明 |
|---|---|---|
| 眉标 | 单行 | 页内小节/篇目（如"苏七块"），**不写课型** |
| 标题 | 单行 | 页面主标题 |
| 副标题 | 单行 | 仅"填空表格"用 |
| 正文 | 多行 | 段落文本；原文齐读放节选原文 |
| 要点 | 列表 | 以 `- ` 开头，每行一条；**某条要点下紧跟一行 `参考：答案`**（缩进 2 空格）→ 该答案渲成红字、问题之后点击淡入（见 §8） |
| 表格 | GFM 表格 | 仅"填空表格"用；**空格答案用 `{{答案}}` 标记**（见 §7） |
| 配图建议 | 单行（可多条） | `篇目·场景｜书内页码｜建议元素：x、y` 或填"无"；引导问题页写 ≥2 条 → 自动排 2×2 四图网格 |

> **四图网格**：引导问题页带 **2–4 条** `配图建议：` 时，标题下整幅排成 2×2 占位网格（每幅一格、逐格各配一图），此模式自动**不画问号水印、不渲染要点**（题面由各格配图建议的「篇目·场景」段承载）。单条配图建议行为不变。

## 7) 填空表格答案逐格点击（`{{}}` 标记）

填空表格是给学生填的；中间稿可把答案填进单元格、用 `{{答案}}` 包裹，渲染器据此：

- **底表留空**：每个 `{{X}}` 在底表渲成空白占位 `＿＿`，单元格其余提示文字照常显示；
- **答案叠层**：对每个含 `{{}}` 的单元格，叠「不透明底色矩形 + 完整答案文本框」盖在该格上，初始隐藏；
- **逐格点击**：按阅读顺序（行优先、列内左→右）一格一击淡入填出，复用 `add_click_reveal`。

两类空格：整格留白 → 整格答案包 `{{1—28章}}`；行内挖空 → 只包答案片段 `【第{{3}}章】`（提示留在框里）。一个单元格含多个 `{{}}` 仍算一格、一次点击整格揭示。

`--no-anim` 或系统不支持动画时，所有答案叠层直出（=答案静态全显，非损坏）。**无 `{{}}` 标记的表格行为不变**（纯空白表）。技术原因：OOXML 表格是单 graphicFrame、无法对单元格做动画目标，故答案必须用独立叠层形状才能逐格点击。

## 8) 要点参考答案上屏（`参考：` · 红字逐段点击）

引导问题 / 要点小结两类页型，**某条要点(问题)下若紧跟一行 `参考：答案`**，渲染器（`add_qa_textbox`）把该页要点改成"问题 + 红色参考答案"交错版式：

- **问题**（圈号 ①②③、正文色）在上，**参考答案**（缩进、红字 `#C0392B`）紧跟其下；
- **逐段点击**：先出问题，点一次再淡入红色答案，每段各一击；
- `--no-anim` 或系统不支持动画时全部静态显示（问题黑、答案红）；
- 某条要点没有 `参考：` 也兼容——只出问题、无红字答案。

整页**任一条要点带 `参考：`** 即切换此版式（要点小结此时不再用红方块编号，改圈号问答）；**全页无 `参考：` 时行为完全不变**。答案来源、压短、真实性红线见 ppt-draft `references/field-extraction.md` §5。

## 9) 完整示例

```
## P03 | 页型:引导问题
眉标：猜书名
标题：书名叫《俗世奇人》——请关注"俗"和"奇"这两个字
要点：
- 这本书可能写的是哪些人
- "俗"是什么意思
- "奇"又奇在哪里
配图建议：苏七块·封面人物｜书内P12｜建议元素：长衫大夫、手部特写
```
