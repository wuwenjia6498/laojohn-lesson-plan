# 语域审读附件（register-audit.md · 仅审读遍使用）

> **使用时机**：课件内容与版式排完之后、`ready_for_verification` 之前的独立一步。**起草阶段不要打开本文件**——起草只按 framework.md §七（一页纸）执行，词表提前进入生成遍会挤占内容提炼的注意力。
> 审读时把本文件 + 课件文字发给窗口，不看版式、只看文字。判断的**唯一标准**始终是 framework.md §7.1 那一句：写进正式教案、由另一位老师照读会不会别扭；本文件的信号与词表都只是找问题的工具，表里没有的词同样按该标准判断。

## 一、审读流程
1. **排版阶段**：按框架把课案排成页面，此时以内容和版式为主，语域先按 framework §7.2 正面样本的语感写。
2. **语域审读**（必做，单独一步）：内容排完后，**不看版式、只看文字**，逐页做三件事：
   - 把每一句按 framework §7.1 的标准默读一遍；
   - 按第三节的九类信号逐类扫一遍；
   - 检查本页标题结构（引导句 + 冒号/逗号 + 红字关键词，无破折号）与术语一致性。
   发现问题当场改写；改写后再默读一遍，确认没有变成成人腔。
3. **机械自检**：跑本文件第七节的 grep 清单兜底，只能抓已知词，不能替代第 2 步。
4. 审读到此结束。**不修改本文件**：错题本由母版维护者统一更新，使用课件的窗口不自行追加条目。

## 二、豁免层（与 framework §7.1 一致，审读时先分层再动笔）
- 三类文字**不改语体**：① 示范文（教师下水文）；② 供学生判断的学生例段；③ 预设的学生答语与情境人物的话（对话气泡、答案条里"朋友说""学生说"的内容）。前两类只改错别字与标点，正文引用它们的句子时原样引用；第三类保留说话人口吻，只修语病与事实错误——把孩子的答语改成书面腔，比留着口语更糟。
- 讲者备注已确认不产出；打磨带备注的历史课件时，备注按教师面文字**从严**：指称授课者一律写"教师"（页面上"听老师读""看老师改"仍自称"老师"），不用"——"拼接，指令用短句。

## 三、口语化的识别信号
遇到以下任何一类，都视为需要改写，无论具体是哪个词：
1. **儿化与方言词**：哪儿、这会儿、劲儿、待会儿、老（总是）、搁、整……
2. **口头语气词与口头衔接**：呀、呢、吧、啦、嘛、"话说""你看""反正"……
3. **口语惯用语、俗语式表达**：多着呢、抢戏、帮个忙、不糙、一下子、来来来、赶紧……
4. **叠词昵称与随意称谓**：包包、狗狗、小家伙、宝贝；指同学说"别人""那个人"（→ 同学、同伴、作者）。
5. **泛指词代替具体名词**：东西、玩意儿、那个、这样（→ 物品、细节、这一处）。
6. **口语量词与单位**：一样东西、一个人、五十八块（→ 一件物品、一位同学、五十八元）。
7. **口语化的指令与评价**：就行、都行、别写、试试、看看、照着用就行（→ 即可、都可以、不必写、试一试、可以直接借鉴）。
8. **口语动词**：念（→ 读）、干（→ 做）、摆（→ 放）、瞄（→ 看）、蹦出（→ 说出）。
9. **叙述腔的口头修辞**："这一下就不一样了""一切都变了"这类空泛点题句（→ 说清具体变化）。

## 四、去 AI 痕迹
- **破折号"——"只用于示范文与学生例段**。标题、要点、说明句里一律不用"——"拼接前后半句，改用冒号、逗号或直接成句：
  - ✗ 今天的任务——办一场心爱之物展览会　✓ 今天的任务：办一场心爱之物展览会
  - ✗ 摸一摸手边那样东西——找买来那天没有的痕迹　✓ 摸一摸手边的物品，找一找买来时没有的痕迹
- 不用"／""&"当连接词；"·"只用于眉标环节分隔与关键词并列。参考答案的并列用分号或顿号。
- 加粗/标红的 `<span>` 前后**不留半角空格**，标点紧跟中文字。
- 程度副词（非常、特别、真的、其实）一句最多一个；不用排比式三连短句做页脚总结，页脚一句话说清一个结论。
- 比喻式、拟人式修辞不用于说明句："变化自己就说了话""心情自己流露出来"改"变化自然就显现出来""情感自然流露"；核心比喻若是本课线索，全篇至多出现一两次。
- 自造词全篇高频重复（"独一份""藏进"出现十几次）：换常规词（独有的、放进、融入）或明显降频。
- "不是 X，而是 Y"的对举句每页来一次即是套路：保留必要的一两处，其余直接说 Y。
- 标题党短句（"先猜三个数""把'急'的秘密找出来""把'变化'的秘密摆出来"）改说明性标题（"猜一猜：桌上这只旧包""把写出'急'的方法找出来"）；标题结构统一为"引导句 + 冒号／逗号 + 关键词"。
- 术语全篇唯一：本课线索词一经确定（如"三个小妙招""专属痕迹""难忘往事"）不再换写法。

## 五、标点与格式
- 全篇中文标点（，。；：？！""''《》）；不出现半角逗号、引号、括号。引号内引号用''；书名、篇名用《》。
- 数字：正文用汉字（两个问题、三四句话），计时徽标、页码、步骤编号可用阿拉伯数字。计时徽标统一写"⏱ 写作时间约 N 分钟"。
- 序号同一页内不混用①②③与"一、二、三"。
- 待补内容用统一占位"插入：配套学生作文纸截图"，占位文字本身不润色、不删除。
