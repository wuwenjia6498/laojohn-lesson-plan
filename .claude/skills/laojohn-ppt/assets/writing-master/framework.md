## 0. 技术实现（照抄即可）

- **格式**：单个 Design Component `课名-写作课.dc.html`，1920×1080，用 `deck-stage.js` 幻灯壳。
- **依赖文件**（与 .dc.html 同目录）：`deck-stage.js`、`image-slot.js`、`logo.png`。跨项目复制时一并带上。
- **骨架**：
  ```
  <x-import component-from-global-scope="image-slot" from="./image-slot.js" hint-size="1px,1px" style="display:none;"></x-import>
  <x-import component-from-global-scope="deck-stage" from="./deck-stage.js" width="1920" height="1080" hint-size="100%,100%">
    <section data-label="封面" data-screen-label="01">...</section>
    ...
  </x-import>
  ```
- **每张幻灯** = 一个 `<section data-label data-screen-label>`，内含 `<div style="position:absolute;inset:0;...">` 绝对定位画布。**画布不写整块白色背景**（不要 `background:#ffffff`）——导出 PPTX 后那是每页最底层一个满版白色矩形，选中、拖动元素时老挡手，删掉更干净。**不生成讲者备注**：不写 `data-speaker-notes` 属性，也不写 `#speaker-notes` JSON。
- **样式全部内联**（inline style），不用 class/stylesheet。**字体统一用「微软雅黑」**：`font-family:'Microsoft YaHei','微软雅黑',sans-serif`（含封面大字、THE END 等所有文字）。原因：导出 PPTX 后在 WPS/PowerPoint 里若引用 Noto 等未安装字体，会被替换并「伪造粗体」→ 粗字出现重影；微软雅黑为 Windows/WPS 自带，字重正常、无重影。封面大标题与副标题用 `font-style:italic` 斜体、但不加字距（见下"封面首页规则"）。
- **配图**：用 `<image-slot id="唯一id" shape="rect|rounded|circle" radius="18" placeholder="配图：说明">`，外层包 `data-om-raster="true"`。用户拖入图片即填充。
  > **本仓直出例外（2026-09-26）**：image-slot 是给网页端 Design 留的拖图占位；本仓直出时图已备好，一律直接写 `<img>`（`writing_deck_kit.fig()`），版式规则见 §四之二。下文版式库里「另一侧 image-slot」等说法，直出时都读作放真图。

### 封面首页规则（务必遵守 · 全部原生形状，禁止转图片）
封面渐变块、白圆圈、标题、副标题**一律不加 `data-om-raster`**——PowerPoint/WPS 原生支持整块四角圆角 + 三色线性渐变 + 半透明椭圆，转图片反而会把标题一起烤进图里，导出后出现"图里一个标题 + 文字层一个标题"的重影，且底下多出一张无圆圈的渐变图。标准写法：
```html
<div style="position:absolute;top:120px;left:90px;width:1740px;height:600px;border-radius:16px;overflow:hidden;background:linear-gradient(105deg,#EE7B2E 0%,#F0A63C 42%,#57B0A6 100%);">
  <div style="position:absolute;top:30px;left:220px;width:360px;height:360px;border-radius:50%;background:rgba(255,255,255,0.10);"></div>
  <div style="position:absolute;top:320px;left:520px;width:430px;height:430px;border-radius:50%;background:rgba(255,255,255,0.08);"></div>
</div>
<div style="position:absolute;left:400px;top:280px;width:1120px;font-weight:700;font-style:italic;font-size:118px;line-height:1.25;color:#fff;">课名</div>
<div style="position:absolute;left:404px;top:470px;width:1120px;font-size:40px;font-style:italic;line-height:1.4;color:#fff;">年级 · 单元 · 校内同步写作（体裁）</div>
```
配套硬规则（全篇通用，防 WPS 文字重叠）：
- 圆圈用 `top` 定位、**不要靠负值溢出裁切**（导出后 `overflow:hidden` 不生效，圆圈会跑出色块）。
- **不写 `letter-spacing`**；**不用 `font-weight:900`，最粗到 700**。WPS 以雅黑 Bold 顶替 900，实际字宽大于排版宽 → 溢出圆角框、压住相邻文字。
- 封面/尾页/分隔页大字一律给显式 `line-height` 与 `width`。
- 封面主标题与副标题**用 `font-style:italic` 斜体**（本模板固定风格）；斜体本身不导致重影，重影来自转图片，务必保持原生文字。

### 导出 PPTX 防变形（务必遵守）
PowerPoint 只支持"四角统一圆角"。凡是**上圆下方/局部圆角的色块**，都要把背景与文字分离：
```html
<div style="position:relative; ...文字样式...">
  <div data-om-raster="true" style="position:absolute;inset:0;background:#3D4A63;border-radius:18px 18px 0 0;"></div>
  <span style="position:relative;">文字</span>
</div>
```
即：圆角/渐变/三角箭头等靠 `data-om-raster="true"` 的绝对定位层烘焙成图片，文字用 `position:relative` 浮在上层保持可编辑。封面/尾页渐变、卡片表头、表格首末行、气泡尖角、播放三角都这样处理。

### 色块内文字必须包一层中性 div（防"文字自带底色"）
**症状**：导出 PPTX 后，在 PowerPoint/WPS 里把色块上的文字拖出来，文字自身带着一层同色底（文字高亮），不是纯文字。
**原因**：文字若**直接**写在带 `background:#xxx` 的 div 里（如 `<div style="background:#FCE7EA;...">标题文字</div>`），导出器会把它理解为"带背景色的文字"，除生成色块形状外，还给文本框的文字附加同色高亮。
**写法规则**：凡是带纯色背景的 div（粉胶囊标题、浅蓝条、暖米框、词语胶囊、表格单元格、计时徽标、数字块、三档自检行等），文字一律**不直接**作为其子节点，而是再包一层无样式的 `<div>`：
```html
<!-- 错误：文字直接在色块里 → 导出后文字带底色 -->
<div style="display:inline-block;background:#FCE7EA;border-radius:20px;padding:20px 44px;font-size:46px;font-weight:700;">标题：<span style="color:#C0392B;">关键词</span></div>
<!-- 正确：文字包一层中性 div → 色块与纯文字各自独立 -->
<div style="display:inline-block;background:#FCE7EA;border-radius:20px;padding:20px 44px;font-size:46px;font-weight:700;"><div>标题：<span style="color:#C0392B;">关键词</span></div></div>
```
中性 div 不写任何样式，版面完全不变；导出后色块是独立形状、文字是无填充的纯文本框。气泡/卡片这类"背景在外层、文字本就在子 div 里"的结构天然满足，不用改。

### 带文字的色块表头禁止 raster（实测 · 优先级高于上一条）
**症状**：导出 PPTX 后，表格深蓝表头、卡片表头的白字出现重影——图片里烤了一遍文字，上面又叠了一层可编辑文字，每次都要手动删掉一层。
**原因**：把表头圆角背景做成 `data-om-raster="true"` 的绝对定位层时，栅格化截的是该区域的像素，浮在上层的文字被一并烤进图片，导出器随后又输出一份文本框。
**写法规则**：凡是「色块 + 文字」的表头，**一律不用 raster**，直接写纯色背景（不写圆角），文字仍按上一条包一层无样式 `<div>`；圆角交给外层容器的 `border-radius` + `overflow:hidden`（HTML 里照常显示，PPT 里是直角，可接受）。
```html
<!-- 错误：表头背景用 raster → 导出后表头文字重影 -->
<div style="display:grid;grid-template-columns:1fr 620px;color:#fff;position:relative;"><div data-om-raster="true" style="position:absolute;inset:0;background:#3D4A63;border-radius:14px 14px 0 0;"></div><div style="padding:20px 32px;position:relative;">示范文里的句子</div></div>
<!-- 正确：纯色背景 + 中性 div -->
<div style="display:grid;grid-template-columns:1fr 620px;background:#3D4A63;color:#fff;font-size:31px;font-weight:700;">
  <div style="padding:20px 32px;"><div>示范文里的句子</div></div>
  <div style="padding:20px 32px;"><div>这一句用了什么写法</div></div>
</div>
```
`data-om-raster` 此后只用于**不含文字**的图形：封面/尾页三角、气泡尖角、播放三角、image-slot 外层。封面渐变与标题仍按「封面首页规则」全部原生形状。

### 导出 PPTX 的正确参数（deck-stage 幻灯壳）
- `resetTransformSelector: "deck-stage"`（必填，否则捕获到缩放态坐标，整页错位挤压）。
- 每页 `selector: "deck-stage > [data-deck-active]"`，`showJs: "document.querySelector('deck-stage').goTo(N)"`（N 从 0 起）。不要用 `section[data-screen-label=...]` 之类选择器，匹配不到。

## 四之二、配图版式（本仓增补 · 六上五 v1–v8 定稿，2026-09-25/26）

> 来源：六上五外部件添图调了 8 版、用户逐条拍板，再经仓内直出试点验证。括号里是出处页，便于追溯；定稿过程见记忆 ppt-illustration-style-reference-0925。起草 dc.html 时按下面顺序判断。

1. **除本条列出的页外，内容页默认都配图**（六上五 v8 定稿 30 页里 21 页有图；收束页、修改页这类收尾页同样配，如 P27 伏案改稿、P28 帅旗与兵棋）。**哪些页不放图**：课时分隔页、尾页一律不放；封面照常放人物，可出血到右下、压在渐变块上。表格页、三栏已排满的页不放主图。**整篇示范文页要配图**（画示范文里的人物与场景），把末尾几段收窄、人物立在卡片右下角（v8 P18，用户纠正过：别当满页不放）。版式照 v8 P18（用户定：比拆 L 形合理）：范文用一整块底色卡，不另写卡内标题行（页题已有篇名）；末尾两三段加 `margin-right` 收窄，人物放在卡内右下、脚落卡片底边，图的顶端不得压到上面通栏段落的文字；**标色图例放卡外最后一排**，写全意思（如 详写的一条：一个动作一个动作写），不要塞进卡内右侧，混在范文底色里显乱。**判断题页的配图不能画出答案**，只画两边共有的情境（P09 只画发烧量体温，不画喂粥）。教材图位放教材扫描图，不换成 AI 图；同页可再配一张较小的人物（教材图靠左、人物立在右下页边，如 P05）。这里的主图指占版面一成以上的人物大图；第 4 条卡片角上的小插画不算主图，但表格页连小插画也不放。
2. **以图为主重排，不在排好的版面里找空地塞小图**（v1 被否的做法）：正文压到左侧约 60%，人物占右侧 35–45%，常出血到右边或下边；图放右上时，其下的底框恢复通栏（P25）。两卡并排挤不下图时，改成两卡上下叠放、图占右栏（P23、P26）；两栏排满的页把各行压矮，腾出右下角放大图（P27）。
3. **人物要有依托**：人物下沿落在浅色底带的底边或页面底边，底带放在正文区之下；人物四周什么都不挨就会飘。**底带用 v8 定稿的三色，页与页交替：暖黄 `#FFF6E5`、浅绿 `#EEF5E6`、浅桃 `#FDEFE6`**；别用近白的 `#F7F5F2`，铺了跟没铺一样，页面照样单调（直出试点 v1–v4 犯过）。底带按页判断：要给人物落脚、或**页面显得单调时就铺**（v8 P28：一条暖黄底带横贯下部，帅旗兵棋立在底带上，正文压左栏——用户点名这样比不铺好）；物件图放在白底上且不单调时可以不铺。**页脚一句总结收窄**，让出人物那一栏。
4. **卡片里的小插画收进卡片**：贴在卡片右下角、略探出卡边，与卡内文字同属一张卡；不要孤零零放在卡片外面（P07 甜、寻两卡）。
5. **大色块概念标签换成标签胶囊加插图**（P14）。
6. **页题下的说明句单独留一行**，正文整体下移，不要挤在标题与正文之间（P09、P11）。
7. **素材**：**先用已有的、用户认可过的图，不重复生成**——课件配图工具产出目录下的 `抠图/`、`页目/`、`ppt配图缓存/` 里有的就直接用（六上五 P28 帅旗图 v8 已认可，直出时又花钱重出一张，被用户点名）。缺图要新出时，人物一律用透明底 PNG，由 `gen_cutouts.py` 从源头直出（清单写在项目 JSON 的抠图件里）；**禁止拿带水彩底晕的人物页目图后期抠图**，抠不干净，用户三次点名。这条禁令只管人物页目图，不是说已抠好、已认可的道具图要重做。`<img>` 只写 height、宽度自适应，保持原比例；用前按透明通道裁掉四周空白。
8. **页面要饱满**：下半页空着时，加底带或放大人物，不留大片空白（P11、P17 加底带是用户点名）。
9. **稿纸页（终稿固定加的一页）**：自由写作说明页之后紧跟一页稿纸页（三套外部终稿都有，六上五直出 P25）。构成：眉标 自由写作 与 logo；居中一张稿纸图（约 1400×753px，细描边圆角），是学生用配套第 2 页从页题 写作稿纸 起的上部；右下红色计时徽标 ⏱ 写作时间约 N 分钟（N 取详案自由写作计时）。没有标题胶囊、没有吉祥物、没有页脚，整页不加动画。说明页上的计时徽标照旧保留（三套终稿两页都有）。**稿纸图每次出件都用 `laojohn-ppt/tools/grab_worksheet.py` 从 `写作配套输出/<课次>/<课次>-学生用.html` 现截**，不要复用旧截图：配套一改，旧图就过期。

## 五、字体与字号
- 字体统一：**微软雅黑** `'Microsoft YaHei','微软雅黑',sans-serif`（全篇包括封面/尾页大字；不再用衷线体，保证 WPS 导出无伪粗体重影）。
- 封面主标题 ~118px（`font-weight:700` + `font-style:italic`，不加字距）；尾页 THE END ~170px。
- 眉标 32px（24pt）/ 主标题 42.7px（32pt，胶囊）或 52px（无胶囊）/ 要点 36–39px / 正文 28–34px / 页脚一句总结 34.7px（26pt）。
- px→pt 换算：1920×1080 画布导出 PPTX 后 `pt = px × 0.75`。
- 1920×1080 下正文不小于 28px。

## 六、复用要点（口诀）
1. **眉标 + 主标题** 是每页识别度最高的固定组合，务必保留；一份课件内标题模式统一。
2. 标题写法："引导句 + 关键词"，关键词标红（如"今天的任务：做一本《人物图鉴》"）。引导句与关键词之间用冒号或逗号衔接，**不用破折号"——"拼接**（见 §七）。
3. 一条全课线索反复标红（写人=特别的地方/写景=看听闻摸），并在示范文—旁批表间用**同色**呼应。
4. 图片先用 `image-slot` 占位；示范文与例段亲切、给孩子做样子，其余页面文字用规范教学语言（§七）。
5. 一份课件配色克制：深蓝 + 红 + 粉胶囊为主，浅蓝/暖米点缀；渐变只用于封面/尾页/分隔页。
6. 所有圆角/渐变/异形务必按"§0 导出防变形"处理，保证 PPTX 可编辑不走样；**封面按"§0 封面首页规则"全用原生形状，一处都不转图片**。
7. 全篇禁用 `letter-spacing` 与 `font-weight:900`，避免 WPS 文字溢出重叠。
8. **色块内文字必须再包一层无样式 `<div>`**（见 §0"色块内文字"），否则导出后文字自带同色高亮底色，拖动时不是纯文字。
9. **带文字的色块表头一律不用 `data-om-raster`**（见 §0"带文字的色块表头禁止 raster"），否则导出后表头文字重影，需手动删除一层。

## 七、文字表达（起草阶段只带本节 · 审读用 register-audit.md）

> 生成与审读**分开做**：排版起草时只执行本节这一页——一句判断标准、一组正面语感、三条结构习惯；
> 口语化信号、AI 痕迹、标点细则、错题本与自检清单全部在 `register-audit.md`，**只在排完之后的语域审读遍打开**。
> 这样内容提炼阶段的注意力留给"详案里哪一处是本页核心"，文字问题留给专门的一遍去修。

### 7.1 总原则与判断标准
- 课件正文是**教师面向学生的规范课堂语言**：句子完整、用词书面、指令明确；可以亲切，但不口语、不随意、不啰嗦。
- **唯一判断标准**：这句话如果印在教材上、写进正式教案，由另一位老师在课堂上照读，会不会别扭？会，就改。
- 改写原则：**保留原意和亲切感，只换表达方式**；不把学生听得懂的话改成成人腔（"请同学们认真观察物品表面的磨损特征"是过度书面化，同样不合格）。目标是"规范而自然"，不是"文绉绉"。
- 三类文字**不套用**本节：① 示范文（教师下水文）；② 供学生判断的学生例段；③ 预设的学生答语与情境人物的话（对话气泡、答案条里"朋友说""学生说"的内容）。前两类保留生活化语气，只改错别字与标点，正文引用它们的句子时原样引用；第三类保留说话人口吻，只修语病与事实错误——把孩子的答语改成书面腔，比留着口语更糟。
- 讲者备注**已确认不产出**（技术上见 §0"不生成讲者备注"）。此条仅在打磨带备注的历史课件时使用：备注是给教师看的文字，尺度**比页面更严**——指称授课者一律写"教师"（页面上学生可见的"听老师读""看老师改"仍按师话自称"老师"），同样不用"——"拼接，指令用短句。

### 7.2 正面样本（全篇语感以此为准）
以下取自已润色的《我的心爱之物》（五上·第一单元），亲切、清楚、可照读：
> 摸一摸手边的物品，找一找买来时没有的痕迹。
> 和同桌说一说：这些痕迹里，哪一处是只属于你这一件物品的。
> 磨掉的漆、翘边的贴纸、磕掉的那一块，都不是买来就有的，而是它陪伴你一天天生活时慢慢留下的专属印记。
> 只挑属于它的印记与痕迹：磨白的边、掉漆的角、缺损的一块、修补过的地方。
> 写一件因为它才发生的事：它坏过一次你是怎么处理的，你带着它经历过什么。
> 在两三件之间拿不定主意？问一问自己：哪一件搬家时会第一个装进箱子。

对照（同一内容的口语版，不合格）：
> 摸一摸手边那样东西——找买来那天没有的痕迹。
> 在两三样之间定不下来？问自己——哪一样搬家会第一个装进箱子。

### 7.3 起草时即遵守的三条结构习惯（返工成本高，随写随守）
1. **标题结构**："引导句 + 冒号／逗号 + 红字关键词"，不用破折号"——"拼接（"——"只出现在示范文与学生例段内）。
2. **术语唯一**：本课线索词一经确定（如"专属痕迹""三个小妙招"）全篇不换写法；数量、单位、步骤数前后一致。
3. **标点干净**：全篇中文标点，标红／加粗 `<span>` 前后不留半角空格。

### 7.4 语域审读（单独一步，必做）
内容与版式排完后，把 `register-audit.md` + 课件文字另起一步做语域审读并跑机械自检。
审读遍不修改 `register-audit.md`（错题本由母版维护者统一更新）。做完这一步才 `ready_for_verification`。

## 八、本仓直出的动画与核对（本仓增补 · 2026-09-26 六上五直出试点）

> 本仓出件不经网页端导出，走 `laojohn-ppt/tools/html_to_pptx.py`，后接写作课后处理链的审查闸门与动画注入（命令见 `laojohn-ppt/SKILL.md`）。下面几条是起草 dc.html 时就要写对的。

1. **点击分组写在 HTML 里**：给元素加 `data-anim="N"`，N 按详案师话顺序编号，子元素随最近的带标记祖先成组；没有任何标记的页整页不加动画。整篇出示、留在屏幕上自主阅读的页（如全篇示范文、同时投屏的两段对照）不标。
2. **动画不许由下往上跳**：每一击的最高处不得高于上一击（容差 0.45 英寸，即 1920 画布上约 43px；画布 96px 合 1 英寸）。两栏页做不到先左栏后右栏，要改成上下排，或让两栏同一高度并列、各自一击（P19 改上下排；P27 保持 v8 的左右两栏逐行对齐，左栏整栏一击、右栏整栏一击，两栏同顶就不回跳——用户看过上下排版本，嫌乱；P07 两卡静置、只让卡内答案逐击出现）。能用同顶并列解决的，优先保留左右两栏，别为了动画把版式拆乱。
3. **页脚一句总结**：详案里一开头就讲的指令或交代，不加动画、常驻；是讨论后的结论，放最后一击。吉祥物、手指图标、装饰性人物插图不加动画；卡片内的小插画随卡片同一击。
4. **成表成篇的内容逐字照详案**：示范文、旁批表、中心选材表、评价标准表不压缩、不改写；审查闸门的表格提示应为 0 条。页面上的其他文字可以提炼，但术语与详案一致。
