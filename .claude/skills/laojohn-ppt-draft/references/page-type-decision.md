# 6 页型判定决策树

> **前置：先分页，再判型。** 详案已不含 `【PPT换页】` 换页点——分页由 `pagination-engine.md` 的"教学节拍切分"完成。本文件处理的是：**对切分出的每个"节拍块"判定页型**。

每个节拍块（一个师抛问 / 一段引文 / 一张表 / 一处归纳 / 一句环节过渡……），按下表 **从上到下** 依次匹配，**先匹中先用**。

## 决策表（按优先级排）

| 序 | 页型 | 触发信号（出现任一即可） | 典型来源 |
|---|---|---|---|
| 1 | **填空表格** | 文本块含标准 GFM 表格（至少 2 行、含 `\|---\|` 分隔行）；或详案 `### 可视化工具` 环节里以表/散文描述的维恩图 / 阶梯图 / 时间线 / 山形图 / 讽刺逻辑图 / 对照表等"动手填写"工具——统一搬成 GFM 表，**空格按详案答案用 `{{}}` 标记**（见 field-extraction §6） | 苏七块 vs 刷子李两列对照、奇人画廊表、主线大事记、各类可视化工具表 |
| 2 | **原文齐读** | 文本块以 `> ` 引用块为主体，或含 `(教师朗读【待补：…以实际版本为准】)` 占位，或出现"——节选自《…》P\d+" 字样 | 序言节选、章节原文片段 |
| 3 | **环节标题** | 节拍块是 `### 一、xx`、`### 二、xx` 三级标题**之后第一个**块；或以"接下来我们一起…""下面进入…"等过渡语开场，无实质问答 | 各环节的开场过渡页 |
| 4 | **封面** | 每课时**首个**节拍块；或在长段切换处出现 `### x、走近作者`、`### x、走进 xx 篇` 等"独立人物/章节亮相"的开场页（极少，仅当详案明确以"作者·冯骥才""主角·xxx"作分隔题面时） | 课时首页；中段人物登场页 |
| 5 | **引导问题** | 文本块含 `学生互动分享` / `学生自由分享` 行，且师话以问句结尾（"…？" "你觉得…？"） | 师抛问 → 学生答 → 参考 的环节核心页 |
| 6 | **要点小结** | 文本块以 `明确：` 开头，或含"**总结**" "**小结**" 等显式归纳；师话多为陈述句、列点说明 | 知识点小结、章节归纳、收尾要点 |

## 判定示例

### 示例 1：引导问题

详案片段（一个节拍块）：

```
师：先做一个小游戏——"猜书名"。书名叫《俗世奇人》。请同学们关注其中两个字："俗"和"奇"。请你猜猜看，这本书会写什么样的人？

学生互动分享

参考：
- "俗"是普通、市井，"奇"是不一般……
```

判定：含 `学生互动分享` + 问句 → **引导问题**。

### 示例 2：原文齐读

详案片段（一个节拍块）：

```
师：那为什么这样一个有真本事的人，要立下"先拿七块钱才看病"的死规矩呢？

> 别以为我这人心地不善，只是我立的这规矩不能改。
> ——节选自《俗世奇人·苏七块》P17–20
```

判定：主体是 `> ` 引用块 + "——节选自" → **原文齐读**。

### 示例 3：环节标题

详案片段：

```
### 三、先睹为快·初读两篇(30 分钟)

师：接下来我们一起读两篇，品一品什么叫"俗世奇人"。第一篇——《苏七块》。
```

判定：紧跟三级标题后的第一个节拍块 + 过渡语 → **环节标题**。

**二次过滤**（v1.2 — 满足下表 **全部** 条件才算 `环节标题`，否则改判 `要点小结`）：

- [ ] 下面挂 ≥ 2 个其他页型页面（引导问题/原文齐读/要点小结/填空表格）
- [ ] 对应详案三级标题写明教学时长（≥ 10 分钟）
- [ ] 文本块本身只有过渡语，**不含**完整的师抛问/明确归纳
- [ ] 不与上一张 `环节标题` 页相邻（同一课时禁止两连环节）

不满足任何一条 → 改判 `要点小结`（短过渡文本压成 2–4 条本节回顾要点）。
单课时最多 4 个环节标题；超出说明环节拆得太碎。

### 示例 4：要点小结

详案片段：

```
明确：本书共收录**三十六**篇短篇小说(18 篇旧作 + 18 篇新作)，每一篇都讲一个奇人故事，**各不相关**。也就是说，这是一本"短篇小说集"……
```

判定：`明确：` 开头 + 列点归纳 → **要点小结**。

### 示例 5：填空表格（含答案标记）

详案片段（表里留白，答案在周边 `参考：`里）：

```
| 项目 | 苏七块 | 刷子李 |
| --- | --- | --- |
| 他的"本事"是什么？ |  |  |
| 他的"死规矩"是什么？ |  |  |

参考：苏七块正骨手到病除、立下"先付七块银元才看病"的死规矩；刷子李刷墙不沾一个白点，立"身上白点白刷不要钱"的规矩。
```

判定：GFM 表格 → **填空表格**。照搬表框，并把详案答案抽进单元格、用 `{{}}` 包裹（见 field-extraction §6）：

```
表格：
| 项目 | 苏七块 | 刷子李 |
| --- | --- | --- |
| 他的"本事"是什么？ | {{正骨，手到病除}} | {{刷墙不沾白点}} |
| 他的"死规矩"是什么？ | {{先付七块银元才看病}} | {{身上白点白刷不要钱}} |
```

> laojohn-ppt 渲染：底表显示 `＿＿` 空格、答案逐格点击淡入。详案没给答案的格留空、不写 `{{}}`。
> 可视化工具（时间线/阶梯图/维恩图/山形图等）同样统一搬成 GFM 表走填空表格——把详案描述的"该填什么"作答案标记，不再导入真实阅读单渲染图。

### 示例 6：封面

只有**每课时首页**与极少数的"人物亮相分隔页"。后者判据：节拍块短、仅一句引语或人物名 + 一句话点题，且**前后页型差异巨大**（如从"引导问题"切到"作者·冯骥才"独立亮相）。

判定保守：**默认只把课时首页当封面**；中段非必要不出封面。

## 歧义处理

| 现象 | 处置 |
|---|---|
| 节拍块同时有 `明确：` 和 `学生互动分享` | 看主体：以问答为主→引导问题；以归纳为主→要点小结 |
| 节拍块既有引用块又有问答 | 引用块仅 1–2 行作背景 → 引导问题；引用块占主体 → 原文齐读 |
| 节拍块过短（只有 1 句师话） | 多半是环节过渡（环节标题），或并入相邻同类块（见 pagination-engine "碎并"） |
| 节拍块含多组问答/多段引文 | 这是**胖块**，应在分页阶段拆成多页（见 pagination-engine "胖拆"）；单页引导问题要点控制 2–4 条 |
| 一张工具表，答案散在周边师话/参考里 | 仍出**填空表格**，把答案抽进单元格用 `{{}}` 标记（详案没给的格留空不补）|
| 同一张工具表超 6 行 | 拆成两页填空表格（见 SKILL.md 故障排查），不要硬塞一页 |
| 完全没有信号词（裸文本） | 默认按 **环节标题** 处理 |

## 写作 profile 页型重定向（仅 `文体：写作` 时生效）

写作课详案切本模式后，上面 6 页型决策树里的 **引导问题 / 要点小结不再产出**——凡被判为这两类的节拍块，按老师的**教学动作**改判到写作专属讲解页型（详见 `writing-mode.md §2`）。判定顺序（先匹先用）：

| 序 | 页型 | 触发信号（老师在做什么） | 典型来源 |
|---|---|---|---|
| A | **情境任务** | 老师**宣布/设定**：发布真实写作任务、设定情境、课尾情境寄语——"今天的任务——做一面…墙""这节课要用到它""这张卡片会贴到墙上，爸爸妈妈会读它"。连贯陈述、**非并列列点**、非问答。 | 环节①创设情境、⑦收尾寄语 |
| B0 | **实景观察**（v8） | 老师**给学生看真实场景图、再逐感官追问**："出示一张/几张实景图，请学生观察说五感""看图说话——你看到/听到/闻到了什么"。**判据＝有真实场景图 + 逐感官追问**（有 `配图建议` 实景 + "看/听/闻/摸到什么"）。 | 环节②看图观察·感官导入 |
| B | **活动指令** | 老师**让学生照着做**（**纯口头/动手、无图**）：`学生互动分享`/`学生自由分享` + 操作动词"当一回…""说一说写一写""走到前面""换稿""画波浪线""念出来"。要点=可操作的步骤。 | 环节②感官活动、⑦即时反馈/互评 |
| C | **写法讲解** | 老师**讲道理/给要点**：技法名、`（教师总结）`、"今天这一招""围绕…写""还差一样""做到这几件事""写话小提醒"；或真正抛给学生的**开放问句**（读样稿"…出现几次？""从远到近写了哪几处？"）。要点=讲解要点/问句答案。 | 环节③技法、④读样稿、⑥起步支架 |

**歧义处置：**
- 一个节拍块既像"宣布任务"又像"给要点"：看主体——整段连贯叙述 → 情境任务；已是并列几条要点 → 写法讲解。
- 一个节拍块既有 `学生互动分享` 又是讲写法：以"学生这一步要**动手做**还是**听讲**"定——动手做（说、写、画、念）→ 活动指令；听老师讲要点 → 写法讲解。
- **感官观察类分岔（B0 vs B）**：有真实场景图可看 → **实景观察**（给学生看图、逐感官追问）；纯口头/动手、无图（如"当一回小解说员"站着说）→ **活动指令**。
- 连贯陈述**不拆编号**（含列举问号），走情境任务正文整段（见 `writing-mode.md §2.6`）。

**视觉版式选择器决策（v8 · 可选）**：路由定页型后，可给讲解/情境类页加视觉选择器（字段写法见 `writing-mode.md §2.5`）。**标题色块（v8.1）已是大部分内页的默认标题款，不必再写 `标题样式：强调`**；只有个别页想换口味/素净时才写 `标题样式：竖条` 或 `纯文字`。要点版式仍按语义克制点缀：照步骤做的流程 → `要点样式：步骤`；并列要点想醒目 → `要点样式：卡片`/`节点`；要点配真图 → `要点样式：图文`——**一节课只挑 1–2 页点缀、勿页页换**；**带 `参考：` 答案的页不叠加 `要点样式`**（版式让位问答揭示）。

> 其余写作专属映射（教师示范文→**示范文**（整篇一页、字号自适应，不再拆成多张原文齐读）、审题辨析/评改/旁批→双栏对照、静默写作→写作任务、构思表/五感表/评价量表→填空表格）不经本决策树，按 `writing-mode.md §2` 的内容形态直接判。
