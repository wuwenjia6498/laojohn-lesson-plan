# 6 页型判定决策树

> **前置：先分页，再判型。** 详案已不含 `【PPT换页】` 换页点——分页由 `pagination-engine.md` 的"教学节拍切分"完成。本文件处理的是：**对切分出的每个"节拍块"判定页型**。

每个节拍块（一个师抛问 / 一段引文 / 一张表 / 一处归纳 / 一句环节过渡……），按下表 **从上到下** 依次匹配，**先匹中先用**。

## 决策表（按优先级排）

| 序 | 页型 | 触发信号（出现任一即可） | 典型来源 |
|---|---|---|---|
| 1 | **填空表格** | 文本块中含标准 GFM 表格（至少 2 行、含 `\|---\|` 分隔行） | 阅读单、维恩图、奇人画廊表 |
| 2 | **原文齐读** | 文本块以 `> ` 引用块为主体，或含 `(教师朗读【待补：…以实际版本为准】)` 占位，或出现"——节选自《…》P\d+" 字样 | 序言节选、章节原文片段 |
| 3 | **环节标题** | 节拍块是 `### 一、xx`、`### 二、xx` 三级标题**之后第一个**块；或以"接下来我们一起…""下面进入…"等过渡语开场，无实质问答 | 各环节的开场过渡页 |
| 4 | **封面** | 每课时**首个**节拍块；或在长段切换处出现 `### x、走近作者`、`### x、走进 xx 篇` 等"独立人物/章节亮相"的开场页（极少，仅当详案明确以"作者·冯骥才""主角·xxx"作分隔题面时） | 课时首页；中段人物登场页 |
| 5 | **引导问题** | 文本块含 `学生互动分享` / `学生自由分享` 行，且师话以问句结尾（"…？" "你觉得…？"） | 师抛问 → 学生答 → 参考 的环节核心页 |
| 6 | **要点小结** | 文本块以 `明确：` 开头，或含"**总结**" "**小结**" 等显式归纳；师话多为陈述句、列点说明 | 知识点小结、章节归纳、收尾要点 |

## 判定示例

### 示例 1：引导问题

详案片段（一个节拍块）：

```
师：先做一个小游戏——"猜书名"。书名叫《俗世奇人》。请同学们关注其中两个字："俗"和"奇"。请你猜猜看，这本书会写什么样的人？

学生互动分享

参考：
- "俗"是普通、市井，"奇"是不一般……
```

判定：含 `学生互动分享` + 问句 → **引导问题**。

### 示例 2：原文齐读

详案片段（一个节拍块）：

```
师：那为什么这样一个有真本事的人，要立下"先拿七块钱才看病"的死规矩呢？

> 别以为我这人心地不善，只是我立的这规矩不能改。
> ——节选自《俗世奇人·苏七块》P17–20
```

判定：主体是 `> ` 引用块 + "——节选自" → **原文齐读**。

### 示例 3：环节标题

详案片段：

```
### 三、先睹为快·初读两篇(30 分钟)

师：接下来我们一起读两篇，品一品什么叫"俗世奇人"。第一篇——《苏七块》。
```

判定：紧跟三级标题后的第一个节拍块 + 过渡语 → **环节标题**。

**二次过滤**（v1.2 — 满足下表 **全部** 条件才算 `环节标题`，否则改判 `要点小结`）：

- [ ] 下面挂 ≥ 2 个其他页型页面（引导问题/原文齐读/要点小结/填空表格）
- [ ] 对应详案三级标题写明教学时长（≥ 10 分钟）
- [ ] 文本块本身只有过渡语，**不含**完整的师抛问/明确归纳
- [ ] 不与上一张 `环节标题` 页相邻（同一课时禁止两连环节）

不满足任何一条 → 改判 `要点小结`（短过渡文本压成 2–4 条本节回顾要点）。
单课时最多 4 个环节标题；超出说明环节拆得太碎。

### 示例 4：要点小结

详案片段：

```
明确：本书共收录**三十六**篇短篇小说(18 篇旧作 + 18 篇新作)，每一篇都讲一个奇人故事，**各不相关**。也就是说，这是一本"短篇小说集"……
```

判定：`明确：` 开头 + 列点归纳 → **要点小结**。

### 示例 5：填空表格

详案片段：

```
| 项目 | 苏七块 | 刷子李 |
| --- | --- | --- |
| 他的"本事"是什么？ |  |  |
| 他的"死规矩"是什么？ |  |  |
```

判定：GFM 表格 → **填空表格**。

### 示例 6：封面

只有**每课时首页**与极少数的"人物亮相分隔页"。后者判据：节拍块短、仅一句引语或人物名 + 一句话点题，且**前后页型差异巨大**（如从"引导问题"切到"作者·冯骥才"独立亮相）。

判定保守：**默认只把课时首页当封面**；中段非必要不出封面。

## 歧义处理

| 现象 | 处置 |
|---|---|
| 节拍块同时有 `明确：` 和 `学生互动分享` | 看主体：以问答为主→引导问题；以归纳为主→要点小结 |
| 节拍块既有引用块又有问答 | 引用块仅 1–2 行作背景 → 引导问题；引用块占主体 → 原文齐读 |
| 节拍块过短（只有 1 句师话） | 多半是环节过渡（环节标题），或并入相邻同类块（见 pagination-engine "碎并"） |
| 节拍块含多组问答/多段引文 | 这是**胖块**，应在分页阶段拆成多页（见 pagination-engine "胖拆"）；单页引导问题要点控制 2–4 条 |
| 完全没有信号词（裸文本） | 默认按 **环节标题** 处理 |
