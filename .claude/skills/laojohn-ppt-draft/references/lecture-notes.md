# 逐页讲稿生成规则

> **为什么有这份讲稿**：老师用的是**线上课件系统**，PPT 备注栏不可用——师话/口播无法塞进 PPT 备注。于是把详案里的师话路由到一份独立的"逐页讲稿"文档：课件翻到第几页，老师就看讲稿对应第几页。

每个课时**同时产出两份**：`<书名>-<课型>-中间稿.md`（投屏可见内容）+ `<书名>-<课型>-逐页讲稿.md`（老师手边备讲稿）。两者**页序严格 1:1**。

## 输出位置与命名

```
<项目根目录>\读书会课件讲稿输出\<书名>\<书名>-<课型>-逐页讲稿.md
```

（中间稿在 `读书会课件中间稿输出\<书名>\`，讲稿在 `读书会课件讲稿输出\<书名>\`，两目录平行；写作课同构，走 `写作课件中间稿输出\` / `写作课件讲稿输出\`，子目录为 `<年级册>-<题目>`。）

## 文件头（固定）

```
# 《书名》课型 · 逐页讲稿（线上课件系统配套）

> 用法：本讲稿是老师手边的备讲稿（打印或存在自己电脑上），与线上课件系统逐页对应——课件翻到第几页，就看讲稿对应的第几页。
> 口播=可直接念的师话；兜底参考=学生答不出时老师收口用，不出现在课件上；节奏=本页用时与组织方式；回溯=对应原详案锚点。
> 对应课件：`<书名>-<课型>.pptx`。
```

顶部固定三行，**简洁为要、不堆页码注解**。**页号口径**（不写进讲稿、仅作约定）：`## 第N页` 用课件实际页码——**封面 = 第1页、正文内容页从第2页起**，与中间稿 P 编号、详案页标 `〖PPT 第N页〗`、课件系统翻页一致。

## 每页条目（四件套）

与中间稿一一对应，每页一条：

```
## 第N页 · [页型] 标题
**回溯**：详案 <环节·片段>｜**节奏**：<用时与组织方式>
**口播**：<可直接念出口的师话>
**兜底参考**：<学生答不出时老师收口用的话>
```

### 四个字段来源

| 字段 | 来源 | 约束 |
|---|---|---|
| **回溯** | 本页节拍块归属的 `### 环节标题` + 片段提示（如"二、关键片段·片段一·第1章"） | 锚到环节+片段，**不用 P 编号**（详案已无换页点） |
| **节奏** | 详案环节时长 + 组织方式（同桌说/请人分享/齐读/闭眼想象/写下来） | 一句话，给个用时（"约 5 分钟"） |
| **口播** | 详案 `师：` 师话，**提炼成可直接念的口语** | 去掉旁注；保留亲切语气；引文照念屏上文字 |
| **兜底参考** | 详案 `参考：` 后的内容 | 学生答不出时收口；**不上课件**，只在讲稿 |

### 哪些字段可省

- **环节标题页 / 原文齐读页**：通常只有 `**回溯**`+`**节奏**`+`**口播**`，无 `**兜底参考**`（不抛问）。
- **引导问题页 / 要点小结页**：四件套齐全（抛问页才有兜底参考）。
- **填空表格页**：`**口播**` 写"怎么填表"的指令，`**兜底参考**` 可放示例填法。

## 特殊页

- **封面页**：讲稿写一条 `## 第1页 · [封面]`，只给 `**口播**`（开场白：书名 + 一句话亮点/获奖），无回溯/节奏/兜底。**封面占第1页**，故正文首个内容页是 `## 第2页`。
- **END 页**：可省（推荐不写）；若写则用 `## END 页`（一句结束语口播，如"今天就到这里，下一次再见"），不计入页号。

## 真实性约束（与详案一脉相承）

- **口播不得编造原文**：详案是 `(教师朗读【待补：…以实际版本为准】)` 占位的，讲稿口播照搬"（朗读屏上文字）"指令，**不补伪原文**；
- 口播只能提炼/重组详案已有的师话，**不凭记忆新增情节、人名、页码**；
- 兜底参考同理，只能来自详案 `参考：`，不自行发挥成"标准答案"。

## 自检

- [ ] 讲稿页数（含封面、不含 END）= 中间稿内容页数 + 1（封面）
- [ ] **封面 = `## 第1页`、正文从 `## 第2页` 起**；每页 `## 第N页` 序号 == 中间稿同页 P 编号 == 详案页标 `〖PPT 第N页〗`（三者同号），页型、标题一致
- [ ] 抛问页（引导问题/要点小结）有 `**兜底参考**`，非抛问页可省
- [ ] 回溯锚到"环节·片段"，无 `【PPT换页】`/P 编号残留
- [ ] 口播无伪原文（占位照搬）、无凭记忆新增的事实
- [ ] 文件头 `课件共 N 个内容页` 的 N 填对、对应 pptx 名填对
