# 详案页标回注规则（备课交叉对照）

> **为什么有这一步**：详案已无换页点、与 PPT 解耦。但老师备课时希望"对着详案，就能看出现在讲到 PPT 第几页"。本步在产出中间稿 + 逐页讲稿**之后**，把"PPT 页切换位置"**反向内联回注**进详案——在每个成页的详案文本块正前方插一个醒目页标。

这是**输出侧的备课标注**，不是输入侧的分页指令——与已废弃的 `【PPT换页-Pxx】` 换页点本质不同。

## 页标格式（独占一行）

```
〖PPT 第2页 · 环节标题 · 话题激趣〗
```

- 全角 `〖〗` 分隔（**绝不用** `【】`，避免与废弃换页点混淆）；
- 内容：`PPT 第N页` + ` · ` + 页型 + ` · ` + 眉标（取自中间稿该页眉标，作一眼对应的提示）；
- **`第N页` 用"课件实际页码"（物理张序）**：**封面 = 第1页，正文从第2页起**——与老师在课件系统里翻页看到的页码一致（封面是第一张、正文紧随其后）。
  - **封面 / END 自身不标**（无详案取材源）；正文首个内容页 = 第2页，依次 +1。
  - laojohn-ppt **不在 PPT 页面上标注页码**（右下角不印 `N/Total`），所以页标对齐的就是"课件系统实际翻页显示"——封面第1页、正文第2页起，与中间稿 P 编号、逐页讲稿 `## 第N页` 全部同号。
- **独占一行**，插在该页取材的详案文本块**正前方**（不插进引用块、表格内部、句子中间）。

## 写作课线适配（2026-08-03 起 · 外部 PPT）

写作课 PPT 改由外部平台生成后，上面「每课时一份 PPT、每课时独立编号」的前提不成立，本线按以下口径回注（读书会线不变）：

- **页码取外部 pptx 的物理页序，全课连续**（两节合一时就是 1–N 一条到底，不按课时重编）；
- 页标第二段本线**没有页型概念，改放 pptx 眉标**，第三段放该页标题 —— `〖PPT 第3页 · 创设情境 · 先玩个游戏——猜猜他是谁〗`；
- **不标的页**：封面、END（无详案取材源）。**课时分隔页要标**（外部件常有「01 写作指导课」这类页），锚在详案 `## 第N课时` 标题前，第二段写 `课时分隔`；
- 眉标自带 ` · ` 时**要压掉**，否则页标会撑成四段、读着像格式错乱（实测 `附 · 习作讲评` 就会）；
- 锚定按下表，表里没有的页型按「翻页发生在开始讲这段时」定位——锚在该页取材的**那句师话前**，而不是等到表格/引文才标；
- 自检项相应改为：页标数 == pptx 页数 − 封面 − END；页码连续且顺序与 pptx 一致；
- **本线没有逐页讲稿**（2026-08-03 停产），所以下面「推导法」第 2 步那种「读讲稿的 `**回溯**` 字段定位取材段」在本线不适用——直接对着 pptx 每页的屏上文字，去详案里找对应的那段师话；
- 机械活走 `scripts/pageback_annotate.py`（`--from-pptx` 出骨架 → 人工填 anchor → 回注，幂等；锚点不唯一/不存在/留空/页序倒挂一律报错退出且不改详案）。人工填好的映射表存 `写作课件中间稿输出\<课次>\<题目>-页标映射.json` 复用。

**自由写作页固定占两页（2026-09-11 用户立 · 仅写作课线）**：教师每次都会在「自由写作」那页之后自插一页学生配套写作稿纸的截图，让学生直观看到自己要写在什么纸上。故**写页码时自由写作一律按两页算**，其后各页顺延；外部件送来时那一页可能还没插，也照两页写、不按当下 pptx 页数回退。

**区间页标引擎不认，一律写单号＋括注**：docx 引擎的 `PAGETAG_RE` 只匹配 `第\d+页`，`〖PPT 第23-24页 · …〗` 会掉出页标样式、被当普通段落印成黑字。两页合一处（自由写作＋稿纸页、正文页＋计时页）写成 `〖PPT 第23页 · 自由写作 · 完整写下你的故事新编：三个要求（第24页出示学生写作稿纸）〗`——括注放在第三段末尾，不另起段。

由此本线自检项「页标数 == pptx 页数 − 封面 − END」**要减去这类合并页**，不再是严格相等。

## 锚定位置（按页型，插在取材块正前方一行）

| 中间稿页型 | 详案锚定位置 |
|---|---|
| 环节标题 | 对应 `### 一、xx` 三级标题**前** |
| 引导问题 | 该页提炼自的 `师：…？` 抛问句**前** |
| 原文齐读 | 对应 `> 引文` 引用块 / `(教师朗读【待补…】)` 占位**前** |
| 要点小结 | 对应 `明确：` / "总结" / 归纳句**前** |
| 填空表格 | 对应 GFM 表格**前** |
| 封面 / END | **不标**（自动注入页，无详案取材源） |

## 推导法（依据中间稿 + 讲稿回溯）

1. 取该课时的中间稿，**按页序逐页**遍历内容页；封面 = 第1页（不标）、END 不标，**正文内容页按出现顺序编为 第2页、第3页……**（即课件实际页码）；
2. 读该页在逐页讲稿里的 `**回溯**` 字段（如 `详案 三、先睹为快·片段一·卷一第一章`）——它已指明本页取材的环节 + 片段；
3. 据回溯提示在详案中定位取材段落，在其**正前方**插入对应页标；
4. **一页一标、顺序与中间稿严格一致**。一个详案段落被拆成多页时，多个页标按页序**堆叠**在该段正前方（如示范页与方法页同源）。

## 幂等（可重复回注）

- 回注前**先删除**详案中所有既有 `〖PPT …〗` 独立行，再重插——保证重跑不叠加、不残留旧标。
- 因此重新生成中间稿（分页可能变）后再回注，页标会刷新到与新分页一致。

## 与生成流程的关系（不再耦合）

- 页标是**生成之后**才回注的，不参与分页决策；
- 若把含页标的详案**重新喂给 ppt-draft**，输入契约要求**忽略** `〖PPT …〗`、按节拍重新分页（见 SKILL 输入契约）；
- 详案与 PPT 仍解耦：页标只是给老师看的"备课对照锚"。

## 自检

- [ ] 每课时 `〖PPT 第N页〗` 数量 == 该课时中间稿内容页数（不含封面/END）
- [ ] `第N页` 每课时**从第 2 页起**（封面占第1页）、连续、顺序与中间稿一致
- [ ] 页标都在独立行，未插进引用块/表格/句中，详案标题·引文·表格结构无损
- [ ] 页型与中间稿对应页一致
- [ ] 回注前已清除旧 `〖PPT …〗`（幂等）
