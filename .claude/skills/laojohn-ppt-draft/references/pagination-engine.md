# 教学节拍分页引擎

> 详案已**不含** `【PPT换页】` 换页点。分页权在本工具——按"教学节拍"把详案切成一页一页。本文件定义**怎么切**；切出每块后到 `page-type-decision.md` 判页型、到 `field-extraction.md` 填字段。

## 为什么按节拍切（背景）

旧流程靠详案预埋的换页点定死分页，一个换页点块常塞下多个教学动作（如《洞》详案"二、关键片段"一个环节里塞了三段朗读 + 三组追问），工具被迫一块一页，成品页面信息过载、又把"该独立呈现的节拍"挤没了。

新流程：**一个教学节拍 = 一张投屏页**。碎的并、胖的拆，让每页只承载一个清晰的教学动作。

## 切分三步

### 第 1 步：按课时切文件

扫 `## 第N课时 · 课型`，每个课时 → 一份独立中间稿（+ 一份逐页讲稿）。课时边界即文件边界。

### 第 2 步：按环节定归属

课时内扫 `### 一、xx`、`### 二、xx` 三级标题。每个三级标题是一个**环节**，环节名是该段所有页的眉标来源（见 field-extraction §1）。

### 第 3 步：环节内切节拍

在每个环节内部，按下表把内容识别成一个个"教学节拍"，**每个节拍 = 一个候选页**：

| 教学节拍（详案信号） | → 候选页型 | 拆/并提示 |
|---|---|---|
| 环节开场的过渡句（`### 环节`后第一句师话，只点题不抛问） | 环节标题 | 每环节至多 1 张；纯过渡才算，详见 page-type-decision 二次过滤 |
| 一处师抛问（`师：…？` + `学生互动分享`） | 引导问题 | **一问一页**；详案一个段落里若有"三连问/分几步问"，按教学逻辑可合为一页要点（≤4 条）或拆成数页 |
| 一段引文 / 朗读片段（`> ` 引用块、`(教师朗读…)` 占位、"——节选自"） | 原文齐读 | **每段引文单独成页**；长引文（>约 50 字）绝不并入追问页 |
| 一处归纳（`明确：`、"总结"、列点小结） | 要点小结 | 把列举项拆成 2–5 条要点 |
| 一处「动手填写 / 可视化工具」活动（GFM 表，或 `### 可视化工具` 环节里描述的维恩/阶梯/时间线/山形/逻辑/远航图） | **填空表格** | 一张工具一页；统一搬成 GFM 表，空格按详案答案用 `{{}}` 标记（超 6 行拆两页）。判定见 page-type-decision 序 1 |
| 以前被换页点"吞掉"的独立节拍：微辩论 A/B/C 立场、示范推断步骤、想象/图像化指令、闭眼定格等 | 各自独立页（多为引导问题/要点小结） | **本次固化的重点**：这些以前被并进大页或丢弃，现在各做成一张干净页 |

## 碎并规则（碎的并）

相邻节拍**同属一个教学动作、且各自内容很薄**时，合并成一页：

- 一句过渡 + 紧接的一个小抛问，且抛问无需独立停留 → 并成一张引导问题页；
- 连续两条一句话归纳 → 并成一张要点小结页（2 条要点）；
- 判据：合并后单页不超载（标题 ≤25 字、要点 ≤5 条、正文 ≤4 行）。超了就别并。

## 胖拆规则（胖的拆）

一个详案段落含**多个并列教学动作**时，必须拆成多页：

- **多段朗读片段**：N 段引文 → N 张原文齐读页（每段一页），各自后面若带追问再各出一张引导问题页；
- **多组问答**：一段里"先问 A，再问 B，又问 C"且每问都要学生停下来作答 → 拆成多张引导问题页；
- **引文 + 追问**：长引文单独成原文齐读页，追问另起一张引导问题页（短引文可走"引文+追问"同页，见 field-extraction §正文，渲染器已支持引文在上、要点在下共存）。

### 标定样例（《洞》导读课"二、关键片段·抢先看"环节）

详案该环节一段里有三段朗读（第1章开篇 / 第4章规矩 / 第12章营火）各带追问。**正确切法 = 8 页**：

```
环节标题(抢先看) → 原文齐读(片段一) → 引导问题(追问一)
                 → 原文齐读(片段二) → 引导问题(追问二)
                 → 原文齐读(片段三) → 引导问题(追问三)
                 → 要点小结(三片段收束)
```

旧换页点流程这里只有 3 页（一片段一页、追问被挤进同页），新引擎拆开后每个朗读、每个追问都有独立干净页。

## P 编号

详案已无换页点可沿用。**P 编号由本工具自排**，规则统一如下：

- **每节课中间稿首页固定为封面页 `## P01 | 页型:封面`**（标题=书名、副标题=课时；正文留空即可，渲染器回退到作者元信息）；**正文内容页从 P02 起**连续编。
- 每节课**独立**（都从 P01=封面 起，不跨课时延续）。
- 这样 **中间稿 P 编号 = 课件实际页码（封面=第1页、正文从第2页起）= 详案页标 `〖PPT 第N页〗` = 逐页讲稿 `## 第N页` = 老师在课件系统看到的翻页页码**，全部一致。
- laojohn-ppt **不在 PPT 页面上标注页码**（右下角不印 `N/Total`），故无第二套口径，页号只看课件系统实际翻页。

## 回溯记录

每页要能回溯到"来自详案哪一段"，便于改稿。因换页点已删，**回溯锚定到 `### 环节标题` + 片段提示**，不再用 P 编号：

- 写进逐页讲稿的 `**回溯**` 字段（见 lecture-notes.md），如：`详案 二、关键片段·片段一·第1章` ；
- 中间稿本身不写回溯（中间稿只放投屏可见内容），回溯只活在讲稿里。

## 分页数量参考（防过碎/过简）

- 单课时典型 14–22 个内容页（《洞》四课时均落在此区间）；
- 单环节至多 1 张环节标题页；单课时至多 4 个环节标题（超出说明环节拆太碎）；
- 同一课时禁止两张相邻环节标题页（中间无实质内容则其一改判要点小结）。
- **整课不许一张环节标题都没有**（2026-10-06 立）：详案这一课时有两个以上 `### 一、xx` 环节，中间稿就要给每个环节配一张环节标题页，渲染成 01/02 分节页。人工优化版里，汉修交流课2 原稿一张分节页都没有，老师手动补了两张——学生靠分节页知道「换了一件事」。只有一个环节的课时照旧可以只用一张不带「一、」的环节标题页。
- **收尾页**：详案结尾有「下节预告」「回去想一想」的，最后一张内容页写成 `要点小结`，眉标「下节预告」，把本课回顾和下节要准备的事都写进去（人工版呼兰交流课2 补的就是这一页）。

## 自检（分页阶段）

- [ ] 每段引文都独立成原文齐读页，长引文未被并入追问页
- [ ] 以前会被丢弃的节拍（微辩论分立场、示范步骤等）已各自成页
- [ ] 没有"一页塞多段朗读/多组问答"的胖页
- [ ] 没有"一句话过渡也单独占一页"的过碎页（应并入相邻或归环节标题）
- [ ] 页数落在课时参考区间，环节标题数量合规
