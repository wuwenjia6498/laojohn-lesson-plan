# 写作课模式（writing-mode）

本 Skill 默认处理「整本书阅读读书会详案」。当输入是 **校内同步习作课（写作课）详案**（由 `laojohn-writing-lesson` 产出）时，切入本模式：**骨架、节拍引擎、讲稿四件套照旧复用**，按本文件覆盖写作课专有差异。写作课 profile **有自己的一套专属页型**，见 §2。

> 渲染端对应：`laojohn-ppt` 按中间稿元信息 `文体：写作` 选 `RENDERERS_WRITING`（写作 profile）。
>
> **写作 profile 页型 = 封面 / 环节标题 / 原文齐读（共用公共版式）+ 写作专属「情境任务 / 写法讲解 / 活动指令 / 双栏对照 / 写作任务」+ 填空表格。** 核心原则：写作课的主体是**老师讲写法、布置任务、给操作指令、做示范**——是陈述、讲解、指令，**不是**读书会那种抛给学生的开放思辨题。因此写作课**不再把内容映射到「引导问题」「要点小结」**（它们的 Q1/Q2/Q3 大水印、红方块 1/2/3 是读书会"思辨追问"的视觉隐喻，套到写作讲解语境会把连贯的一句话切成割裂编号、逻辑生硬）。真正抛给学生的开放问句（如读样稿两问）用「写法讲解」承载（问句作标题、`参考：`答案红字揭示）。

---

## 0. 怎么判型（自动）

读到详案头部命中以下任一特征即判为写作课，切本模式：

- H1 形如 `# 《题目》· 写作课教学设计`，紧邻一行副标题 `三年级上册·第X单元 校内同步写作`；
- 书级头部为 `## 一、教案提纲表` + `## 二、核心素养教学目标`（核心素养四维标签 `【语言运用】`/`【思维能力】`/`【审美创造】`/`【文化自信】`）；
- 课时标题为 `## 第1课时 · 写作指导课` / `## 第2课时 · 当堂写作与评改课`。

判不准就按读书会模式走（向后兼容默认路径）。

## 1. 元信息块差异（覆盖 SKILL §输出契约 2）

写作课无「书」「书作者」，元信息这样填：

```
书名：这儿真美            ← 习作题目（不带《》）
课时：写作指导课          ← 写作课型（写作指导课 / 当堂写作与评改课）
年级：三年级上册·第六单元   ← 年级 + 册 + 单元
文体：写作                ← 必填！触发 laojohn-ppt 选写作 profile（封面不加书名号、用写作页型）
```

- **`作者` 行省略**（写作课无书作者）。`文体：写作` 必填——它是 laojohn-ppt 选写作 profile 的唯一开关。
- 封面副标题（`副标题：`）写「年级册·单元 + 校内同步写作」，标题写习作题目本身。

## 2. 写作专有内容 → 页型映射

写作 profile 按**老师的教学动作类型**把内容映射到专属页型（不再复用「引导问题/要点小结」）：

| 详案内容（教学动作） | 落到的页型 | 处理要点 |
|---|---|---|
| **设定情境 / 发布写作任务 / 课尾情境寄语**（环节①"今天的任务——做一面…墙"、"这节课要用到它"；⑦末"这张卡片会贴到墙上，爸爸妈妈会读它"） | **情境任务** | 老师宣布/设定的话，**正文=整段陈述**（连贯话不拆编号，见 §2.6）；零星提点可放 `要点`（渲染成底部圆点）。不出编号方块、不出 Q 水印。 |
| **讲写法 / 归纳技法要点**（环节③"今天这一招——围绕一个意思写"、"还差一样——顺序"、"做到这几件事"；②"看听闻摸让别人到现场"；⑥起步"一句扩三句"的三个台阶）；含真正抛给学生的**开放问句**（读样稿"银杏路真美出现几次？") | **写法讲解** | `标题`=技法名/问句；`要点`=要点几条（克制描边序号）；可选 `正文`=中心句/引文小字。有 `参考：` 答案则挂到对应要点、渲染成红字点击揭示。 |
| **组织学生动手做**（环节②感官活动"当一回小解说员"；说一说写一写步骤；⑦即时反馈游戏、同桌互评"画波浪线/念出来"） | **活动指令** | `标题`=活动名；`要点`=操作步骤几条（渲染成步骤条：方块序号+竖连接线）；有情境实景场景时给 `配图建议`（右侧占位）。 |
| `> 【教师示范文】` 整篇范文 | **示范文 ×1** | **整篇塞进一页、不拆页**：正文=整篇范文（保留自然段之间的空行），渲染端按实际字数**自适应缩放字号**（字多则字号往下缩，下限 13pt）；眉标=「教师示范文」。让学生一眼看到整篇范文的谋篇结构。范文是教师创作、非原著节选，**不写「——节选自《》」出处行**、不套「齐读原著」话术。 |
| 审题辨析（切题/跑题 A/B 对照判断） | **双栏对照（块模式）** | 左右各一大段：用 `左标题/左正文`、`右标题/右正文`（见 §2.5）；底部 `要点` 列「判断依据」。一屏双看。 |
| 评改对照（改前 vs 改后一个句/段的修改演示） | **双栏对照（块模式）** | 左=改前、右=改后；`左标题：改前`/`右标题：改后`；底部 `要点` 说「改了哪处、为什么更好」。 |
| 示范文旁批表（`句子｜用了什么手法` 多行成对） | **双栏对照（行模式）** | 用 `表格`（2 列：句子↔批注），纯展示**不挖空**（不写 `{{}}`）。渲染端检测到表格即走行模式。**右列手法名做分类上色**：加 `图例` + 单元格 `[码:片段]`，与示范文同码同色（见 §2.5 示范文块「分类上色」）。 |
| 当堂自由写作时段（17–30 min 静默写作，`学生动笔写作`） | **写作任务** | 静默写作时投屏定格：`标题`=任务、`要点`=写作要求几条、`计时`=时长、`字数`=字数指引（详案没给字数就**不写该行**，渲染端隐藏字数 chip，真实性红线不豁免）。 |
| 写作构思表（详案给「空白版」+「教师示范版」两张） | **填空表格** | 搬空白版做底表，把示范版对应格作 `{{答案}}` 逐格点击叠层（同读书会填空机制；详案没给的格留空）。 |
| 五感观察表 / 三档评价量表 | **填空表格** | 纯展示表，不挖空。**类别列（感官/维度）做分类上色**：加 `图例` + 单元格 `[码:片段]`，与示范文同码同色（见 §2.5 示范文块「分类上色」）。 |
| 纯环节过渡（只点题、无实质讲解/指令） | **环节标题** | 每环节至多 1 张。 |

> **判「情境任务 / 写法讲解 / 活动指令」三者的快速口径**（详见 `page-type-decision.md` 写作重定向小节）：老师**宣布/设定**（"今天的任务""要用到它""贴到墙上"）→ 情境任务；老师**讲道理/给要点**（技法名、"这一招""还差一样""做到这几件事"、`（教师总结）`）→ 写法讲解；老师**让学生照着做**（`学生互动分享`/`学生自由分享` + "当一回""说一说写一写""换稿""画出来""念出来"）→ 活动指令。

## 2.5 新页型字段写法

### 情境任务（`## PXX | 页型:情境任务`）
```
## P03 | 页型:情境任务
眉标：创设情境
标题：今天的任务——做一面「美景明信片墙」
正文：每个人在墙上都有自己的一格，写一段话，让人光读你的字，脑子里就能「看见」那个地方。读者是真站在墙前的人——同学、来接你的爸爸妈妈，不只老师一个人；只写「风景很美」「我很喜欢」，谁也看不见，这一格就白做了。
要点：
- 先在心里悄悄想一个「特别美」的地方，记住它
```
- `正文`（必填）=老师宣布/设定的话，首行缩进。两种形态：
  - **连贯口令/寄语**（如"先想一个特别美的地方…"、课尾寄语）→ 正文=**整段陈述**、**不拆编号**（见 §2.6），占大区大字。
  - **发布任务**（任务有几个并列要素，如「做一面明信片墙」）→ 正文=**一句总起**（"今天我们要做一面美景明信片墙——每人一格"），并列要素放 `要点`。
- `要点`（可省）=任务的**并列要素**（写让人看见的话/真实读者/反面提醒），用 `- ` 渲染成**圆点主体列表**。⚠ 要点是本就并列的几件事，**不是**把一句连贯口令切碎（连贯口令仍整段进正文）。
- 不写 `副标题`、`表格`。

### 写法讲解（`## PXX | 页型:写法讲解`）
```
## P10 | 页型:写法讲解
眉标：学写法
标题：还差一样——「顺序」，选一种就够
要点：
- 从远到近：先写门口看到的远的，再写走进去看到的近的
- 从上到下：先写抬头看到的，再写低头看到的
- 选一种就行，中间不要跳来跳去
```
- `标题`=技法名/一句话要旨，或真正抛给学生的开放问句（读样稿两问）。
- `要点`（必填）=讲解要点 2–5 条。**按有无先后次序选列表标记**：
  - **并列/无次序**（如"看得见的颜色/听得见的声音/…"、几个平行选项）→ 用 `- ` 列表，渲染成**圆点符号**（不硬套 1/2/3）。
  - **有先后次序/递进**（如"第一步…第二步…"、一句扩三句）→ 用 `1. ` 有序列表，渲染成**克制描边序号**（白底深灰蓝边，非红方块）。
- `正文`（可选）=中心句/引文小字，置于要点上方。
- `参考：` 答案行照旧挂到上一条要点，渲染成红字点击揭示（承载"问题→红答"）。
- 不写 `副标题`、`表格`。

### 活动指令（`## PXX | 页型:活动指令`）
```
## P05 | 页型:活动指令
眉标：调动感官
标题：当一回「小解说员」——站在那儿，说说你看见、听见、闻到了什么
要点：
- 走到前面，假装自己现在就站在那儿
- 说一段话，大约 30 秒
- 「我现在站在这里，我看见……我听见……我还闻到了……」
- 不许说「很美」，用看到、听到、闻到的，让别人觉得美
配图建议：校园老槐树下｜情境照片｜建议元素：老槐树、地上光斑、石凳
```
- `标题`=活动名。
- `要点`（必填）=操作步骤 2–5 条（动词起头），渲染成**步骤条**（深灰蓝方块序号 + 竖连接线）。
- `配图建议`（可选）=仅当有明确实景场景时给一条，渲染成右侧占位；否则填「无」。
- 不写 `副标题`、`表格`。

### 示范文（`## PXX | 页型:示范文`）
```
## P14 | 页型:示范文
眉标：教师示范文
标题：看老师怎么把关键词写进「银杏路真美」
图例：中心=中心句｜色=看得见的颜色｜感=听到·摸到的感觉｜喻=打比方
正文：我们小区门口那条[中心:银杏路，真美]。

站在路口远远望过去，[喻:整条路像一条金色的隧道]。……整条路[色:黄澄澄、亮堂堂]的，[喻:像谁在地上铺了一条长长的金毯子]。

风一吹，[感:满树的叶子哗啦啦地响]，[喻:像在悄悄地拍手]。

走在这条[中心:银杏路上，真美啊]！
```
- `正文`（必填）=**整篇范文**，自然段之间用空行分段；渲染端整篇一页、字号按字数自适应、宋体。
- **分句上色（强烈建议给）**：`图例` 声明 `码=图例名`（用 `｜` 分隔，颜色按顺序取 红→橙→蓝→绿…），正文里用 `[码:片段]` 把该片段标成对应色；渲染端顶部画颜色图例、正文分句上色，让「哪句写颜色/声音/比喻、哪句是中心句」在文字上**直接跳出来**——把 P19 旁批表的"美的秘密"提前显性化到范文本身。
  - 常用四类（写景）：`中心`（中心句「××真美」）/ `色`（看得见的颜色）/ `感`（听到·摸到的感觉）/ `喻`（打比方）。写人/记事可换类别（如 `外`外貌 / `动`动作 / `语`语言），码与图例名自定、颜色自动分配。
  - 标注**只圈"能明确归类的关键片段"**，不必逐字圈满；每个图例类别在正文里至少出现一次（否则图例项没意义）。真实性红线不豁免：标注不改动范文一个字，只是给片段套色。
  - `图例` 省略时=纯灰底整篇（向后兼容），但**示范文默认应做分句上色**。
  - **⚑ 跨页颜色统一（同一课的示范文 + 五感表 + 旁批表必守）**：颜色由码在**本页 `图例` 里的声明顺序**决定（第1个=红、第2=橙、第3=蓝、第4=绿、第5=紫…），不是码名本身。所以要让三页同一手法同色，**三页的 `图例` 必须同码、同序**——直接把示范文这行 `图例` 原样复制到五感表（填空表格）、旁批表（双栏对照行模式）即可（用不到的码留着不用不影响其余颜色，缺的码只能往末尾补，绝不插在中间打乱顺序）。例：写景一课统一用 `图例：中心=中心句｜色=看得见的颜色｜感=听到·摸到的感觉｜喻=打比方｜嗅=闻到的气味`，则三页里"颜色词=橙、声音/触感=蓝、比喻=绿"处处一致，学生形成稳定的"某色=某类手法/感官"认知。表格页只用图例做**单元格配色**、不画顶部图例行（图例行仅示范文有）。
- 不写出处行、不拆多页。眉标固定「教师示范文」。
- 不写 `要点`、`副标题`、`表格`。

### 双栏对照（`## PXX | 页型:双栏对照`）

两种模式，由内容自动判（渲染端：有 `表格` 走行模式，否则走块模式）：

**块模式**（审题辨析、评改对照——左右各一大段）：
```
## P09 | 页型:双栏对照
眉标：判断切题
标题：这两段话，哪个能贴「美景明信片墙」？
左标题：A
左正文：周末我和小宇去公园。我们先玩了滑梯……（一整段，可多行）
右标题：B
右正文：公园真美。滑梯下的草地绿油油的……（一整段，可多行）
要点：
- B 写的三样景物都扣着「美」——草地、柳树、花坛
- A 写的是玩耍的过程，没有围绕「这儿真美」
```
- `左标题/右标题` 是栏头小标签（如 `A`/`B`、`改前`/`改后`），可省（省则无栏头 tab）。
- `左正文/右正文` 各一段、各自可多行；渲染端按长度自动缩字、左右取同一字号、不出血。
- `要点`（可省）= 底部「判断依据/对比点」条。
- **块模式点击逐步揭示**（渲染端自动，关动画/线上系统不支持时全静态直出）：先出左栏正文卡（让学生先读内容思考）→ 亮左栏标签（揭"能贴/不能贴"判断）→ 右栏正文卡 → 右栏标签 → 底部要点**逐条**。教学逻辑＝先看内容、再揭结论、后讲原因。

**行模式**（示范文逐句批注——句子↔批注成对）：用标准 `表格`（2 列、纯展示不挖空），不用左右栏字段。

### 写作任务（`## PXX | 页型:写作任务`）
```
## P04 | 页型:写作任务
眉标：自由写作
标题：开始写——写你的地方，让人「看见」
要点：
- 开头空两格，写一句「××真美」
- 从构思表挑一样景物，照「看清—凑近—加感觉」三步写具体
计时：约 22 分钟
字数：150–250 字
```
- `计时`/`字数` 渲染成右侧两枚显要 chip（计时红、字数深灰蓝）；**详案没给就不写该行**（渲染端隐藏对应 chip，不编造）。
- 定格页全程静态可见，不做逐条点击动画。

## 2.6 连贯话语不强拆编号（治"逻辑割裂"的核心规则）

**情境任务**页、以及**活动指令**里老师一口气说完的一段话，是**连贯陈述**，要作 `正文` 整段呈现，**绝不拆成 ①②③ 编号要点**。典型反例（旧版把连贯话切碎，逻辑割裂）：

> ❌ 旧：`要点：\n- 操场边那排树？奶奶家屋后那条河？楼下那块小花圃？\n- 在心里悄悄想一个，记住它\n- 等一下，这节课要用到它`
>
> ✅ 新（情境任务正文整段）：`正文：先想一个你觉得「特别美」的地方——操场边那排树？奶奶家屋后那条河？楼下那块小花圃？在心里悄悄想一个，记住它，等一下这节课要用到它。`

判据：一段话若是老师**顺着说下来的一件事/一个情境/一句叮嘱**（哪怕中间带列举问号），就是连贯陈述 → 正文整段。只有当详案本身把内容组织成**并列的几条/几个步骤**（技法要点、操作步骤、写作要求）时，才用 `要点` 列点——且分别落到写法讲解（要点）/活动指令（步骤）/写作任务（要求），不落情境任务。

## 3. 零碎差异（覆盖各 reference 的读书会缺省）

- **技法归纳信号**：写作课用 `（教师总结）`/`(教师总结)` 而非 `明确：`——识别为**写法讲解**的要点归纳信号（写作课不出「要点小结」页型）。
- **眉标**：写作课无「篇目名」概念，一律退到所属 `### 环节名`（仍禁写课型，见 §5）。
- **配图建议**：写作课无书内插图，**默认填「无」**；仅情境导入有明确实景场景（如「美景明信片墙」「校园老槐树」照片）时给情境图建议，其余「无」。`image-suggestion.md` 的「书内篇目·页码」模型不适用。
- **封面**：标题=习作题目（不加《》，靠 `文体：写作` 让写作 profile 跳过书名号强包）、副标题=年级册·单元 + 校内同步写作、不填作者元信息。

## 4. 不进投屏的部分

- **书级头部**：`## 一、教案提纲表`、`## 二、核心素养教学目标` 属备课内容，不出投屏页。中间稿从 `## 第1课时` 起（首页仍是封面页）。
- **`## 附:习作讲评指导环节`**：附加块，默认不出投屏页（用户明确要求时再单议）。

## 5. 眉标禁课型（写作课补充）

`_smoke_check.py` 的眉标课型 denylist 已含 `写作指导课`、`当堂写作与评改课`。眉标用环节名（「创设情境」「学写法」「教师出示样稿」「判断切题」「自由写作」等），不得出现这两个课型字样。
