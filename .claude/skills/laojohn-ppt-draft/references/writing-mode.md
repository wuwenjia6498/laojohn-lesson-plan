# 写作课模式（writing-mode）

本 Skill 默认处理「整本书阅读读书会详案」。当输入是 **校内同步习作课（写作课）详案**（由 `laojohn-writing-lesson` 产出）时，切入本模式：**骨架、节拍引擎、6 页型、7 字段、讲稿四件套全部照旧复用**，只按本文件覆盖几处写作课专有差异。不新增页型。

---

## 0. 怎么判型（自动）

读到详案头部命中以下任一特征即判为写作课，切本模式：

- H1 形如 `# 《题目》· 写作课教学设计`，紧邻一行副标题 `三年级上册·第X单元 校内同步写作`；
- 书级头部为 `## 一、教案提纲表` + `## 二、核心素养教学目标`（核心素养四维标签 `【语言运用】`/`【思维能力】`/`【审美创造】`/`【文化自信】`）；
- 课时标题为 `## 第1课时 · 写作指导课` / `## 第2课时 · 当堂写作与评改课`。

判不准就按读书会模式走（向后兼容默认路径）。

---

## 1. 元信息块差异（覆盖 SKILL §输出契约 2）

写作课无「书」「书作者」，元信息这样填：

```
书名：这儿真美            ← 习作题目（不带《》）
课时：写作指导课          ← 写作课型（写作指导课 / 当堂写作与评改课）
年级：三年级上册·第六单元   ← 年级 + 册 + 单元
文体：写作                ← 必填！触发 laojohn-ppt 封面不加书名号、左下不残留分隔点
```

- **`作者` 行省略**（写作课无书作者）。`文体：写作` 必填——它是 laojohn-ppt 渲染器识别写作课的唯一开关。
- 封面副标题（`副标题：`）写「年级册·单元 + 校内同步写作」，标题写习作题目本身。

---

## 2. 写作专有内容 → 现有页型映射（无新页型）

| 详案内容 | 落到的页型 | 处理要点 |
|---|---|---|
| `> 【教师示范文】` 整篇范文 | **原文齐读 ×2–3** | 按自然段拆成 2–3 页（单页 ≤ ~5 行/~300 字，避免溢出）；**不写「——节选自《》」出处行**；眉标 = 「教师示范文」。范文是教师创作、**非原著节选**，所以无出处、不套「齐读原著」话术。 |
| 当堂自由写作时段（17–30 min 静默写作，`学生动笔写作`） | **要点小结** | 出一张「写作任务页」：标题 = 习作题目/任务，要点 = 写作要求 + 字数 + 计时几条。静默写作时投屏定格此页，给学生持续可看的任务锚点。 |
| 示范文旁批表（`句子｜用了什么手法`） | **填空表格** | 纯展示表，**不挖空**（不写 `{{}}`）。 |
| 五感观察表 / 三档评价量表 | **填空表格** | 纯展示表，不挖空。 |
| 写作构思表（详案给「空白版」+「教师示范版」两张） | **填空表格** | 搬**空白版**做底表框架；把示范版对应格的值作 `{{答案}}` 逐格点击叠层（同读书会填空表机制，详案没给的格留空、真实性红线不豁免）。 |
| 审题辨析（③ 环节开场，切题/跑题 A/B 对照判断） | **引导问题** | ③ 环节内的固定半步，不单列环节；眉标归父环节名。 |
| 全感官唤醒（看/听/摸/演热身） | **环节标题** 或 **引导问题** | 有 `师：…？` + `学生互动分享` 走引导问题；纯过渡走环节标题。 |

---

## 3. 零碎差异（覆盖各 reference 的读书会缺省）

- **要点小结信号**：写作课用 `（教师总结）`/`(教师总结)` 而非 `明确：`——把它与「技法要点归纳」一并识别为要点小结信号（`page-type-decision.md` 的「总结/小结」弱匹配在此为主信号）。
- **眉标**：写作课无「篇目名」概念，一律退到所属 `### 环节名`（仍禁写课型，详见 §4）。
- **配图建议**：写作课无书内插图，**默认填「无」**；仅情境导入环节有明确实景场景（如「美景明信片墙」「校园老槐树」照片）时，可给情境图建议，其余一律「无」。`image-suggestion.md` 的「书内篇目·页码」模型不适用。
- **封面**：标题 = 习作题目（**不加《》**，靠 `文体：写作` 让渲染器跳过书名号强包）、副标题 = 年级册·单元 + 校内同步写作、不填作者元信息。

---

## 4. 不进投屏的部分

- **书级头部**：`## 一、教案提纲表`、`## 二、核心素养教学目标` 与读书会的文本介绍/教学目标同属备课内容，**不出投屏页**。中间稿从 `## 第1课时` 起（首页仍是封面页）。
- **`## 附:习作讲评指导环节`**：课后/下次开场用的附加块，**默认不出投屏页**（用户明确要求时再单议）。

---

## 5. 眉标禁课型（写作课补充）

`_smoke_check.py` 的眉标课型 denylist 已含 `写作指导课`、`当堂写作与评改课`。眉标用环节名（「创设情境」「学写法」「教师出示样稿」等），不得出现这两个课型字样。
