# 配图建议生成规则

中间稿不会真的画图——它只在该字段写一行"配图建议"，下游 `laojohn-ppt` 会渲染为虚线占位框 + 📷 + 说明文字，老师手动贴图。

## 配图策略：宜配则配（默认主动配，不默认留白）

- **凡适合配图的页型就主动给一条建议，不要图省事填"无"。** 配图是降低备课门槛、提升投屏观感的手段——能配就配：
  - **引导问题**：默认配（除纯思辨/元认知页，见下）；
  - **要点小结**：只要有具体画面/场景/人物可指（如作者肖像、某卷场景、概念示意），就配。
- **"无"只用于两种情形**：① 规则明令不配的页型（封面 / 环节标题 / 原文齐读 / 填空表格）；② 确实没有可视锚点的抽象页——纯思辨、自我提问、监控/反思类引导问题，硬配场景图反而牵强。
- **配图建议只是"灵感来源"，最终由老师人工审核**：实际效果不佳、找不到合适图、或页面已满时，老师可直接删去该建议（删掉后渲染端不画占位框）。所以**宁可多给、由人删减，不可因怕多余而漏给**。

## 四图网格：一页多图（"给你们看 N 幅画面"）

当某个**引导问题**页本质是"同时给学生看若干幅画面、各自感受"（详案里出现"看四幅画面""三个场景对比""下面几张图"等多画面并置的师话），不要把多幅压成一条合并配图，也不要拆成多页——**在同一页写多条 `配图建议：`（每幅一条，2–4 条）**，`laojohn-ppt` 会自动排成 2×2 占位网格，每幅一格、逐格各配一图。

- **触发条件**：同一引导问题页出现 **≥2 条** `配图建议：`，即进入网格模式。
- **此模式下 `要点` 不必填**：每格的题面（场景名）由各条配图建议的「篇目·场景」段承载，无需再单独写 `要点`；写了也不会渲染（被网格取代）。
- **每条仍是标准三段式**、各自 ≤30 汉字；条目顺序即网格从左到右、从上到下的铺排顺序。
- 标题照常写这一组画面共同的引导问题（如"这四个国度，你最想先去哪一个？"）。

例（格列佛导读课 P03 · 四国奇遇）：

```
## P03 | 页型:引导问题
眉标：四幅奇画
标题：这四个国度，你最想先去哪一个？
配图建议：小人国·沙滩捆缚｜卷一·第1章｜建议元素：巨人、小人、细绳
配图建议：大人国·掌心玩偶｜卷二·第1章｜建议元素：巨手、小格列佛
配图建议：飞岛·黄瓜榨阳光｜卷三｜建议元素：飞岛、研究者
配图建议：慧骃国·马讲道理｜卷四｜建议元素：慧骃马、野胡
```

> 普通单图页**仍只写一条** `配图建议：`，行为不变；只有 ≥2 条才触发网格。

## 格式（固定三段，以 `｜` 分隔）

```
篇目·场景 ｜ 书内页码 ｜ 建议元素：A、B、C
```

例：

```
配图建议：苏七块·正骨场景｜书内P17–20｜建议元素：正骨大夫、银元、病患
配图建议：天津卫码头·开篇氛围｜书前彩页｜建议元素：码头、人物群像、市井烟火
配图建议：俗世奇人·目录页｜书内目录｜建议元素：篇目排版
```

## 字段细则

### 第一段：篇目·场景

- **篇目**：当前页讨论的具体篇目名（"苏七块" "刷子李" "泥人张"）；
- 若是整本/作者级页（封面、走近作者），写"书名·xxx"或"作者·xxx"；
- **场景**：用 4–8 汉字描述要画的画面（如"正骨场景" "码头氛围" "封面人物"）。

### 第二段：书内页码

- 优先用真实页码区间（"书内P17–20" "书内P12"）；
- 不确定时用泛指（"书前彩页" "书内目录" "书中插页"）；
- **不要写"网络搜图"或外部来源**——老师可能用书内插图、可能自配，配图建议只指向"灵感来源"。

### 第三段：建议元素

- 关键词列 2–4 个，以中文顿号 `、` 分隔；
- 用具体名词（"正骨大夫" "银元" "黑长衫"），避免抽象词（"氛围感" "意境"）；
- 总长度（含前缀"建议元素："）≤ 14 汉字。

## 全字段总长

整行 ≤ **30 汉字**（投屏占位框宽度有限，超长会溢出）。

## 何时填"无"

仅下列情形配图建议字段填 **"无"**（小写"无"）——其余一律按"宜配则配"主动给建议：

1. **原文齐读页**——满屏书页底 + 引文，再加占位框会显得拥挤；
2. **填空表格页**——表格本身已占满主区，无配图空间；
3. **封面页**——封面横幅已是装饰主体，无需占位；
4. **环节标题页**——满屏深灰蓝实心卡片，渲染器不画占位框，写图也不会出现；
5. **纯思辨 / 元认知类引导问题**——如自我提问、监控自查、抽象追问，没有可视锚点，硬配场景图反而牵强；
6. **要点小结内容已满**——5 条要点排满左半屏、且无强相关画面时，右半屏可留白（有合适画面仍优先配）。

写成：

```
配图建议：无
```

`laojohn-ppt` 渲染器会识别"无 / 无配图 / 无（页面已满）/ —" 等几种写法，全部跳过绘制。

## 推荐风格表（按页型）

| 页型 | 是否建议配图 | 推荐元素 |
|---|---|---|
| 封面 | 否（填"无"） | — |
| 环节标题 | 否（填"无"） | —（满屏深灰蓝实心卡片，不放图） |
| 引导问题 | 是（默认配，纯思辨/监控页除外） | 篇目场景图 / 人物特写 |
| 原文齐读 | 否（填"无"） | — |
| 要点小结 | 有具体画面则配 | 作者肖像 / 某卷场景 / 目录页 / 概念示意图 |
| 填空表格 | 否（填"无"） | — |

## 反例

❌ **错（无具体来源）**：
```
配图建议：可以配一张天津卫的图
```

❌ **错（带外部来源）**：
```
配图建议：网上搜"天津卫民国老照片"
```

❌ **错（过长溢出）**：
```
配图建议：苏七块在小诊所里给病人正骨的场景｜书内第十七到二十页｜建议元素：苏七块大夫、病人、银元、桌椅、药柜、徒弟
```

✅ **对**：
```
配图建议：苏七块·正骨场景｜书内P17–20｜建议元素：正骨大夫、银元、病患
```
