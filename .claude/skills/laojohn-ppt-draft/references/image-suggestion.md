# 配图建议生成规则

**现行口径＝新样式**（中间稿元信息写了 `主题色：`，见 SKILL.md 元信息节）：配图建议既是给老师看的说明，也是配图脚本 `课件配图工具/scripts/reading_deck.py` 取图／生图的唯一输入。脚本把图做出来、人工验收后回填 `图=`，`laojohn-ppt` 再按图排版（抠图贴右下出血、场景图放右栏）。没回填图的页，引擎按无图版式出，**不再画虚线占位框**。

> 旧样式（元信息不写 `主题色`）的存量稿照旧：一行三段式说明、渲染成虚线占位框、老师手贴。新稿一律写新样式。

## 一、哪些页配图（每张内容页都配）

用户人工优化版的实测结果：除去不放图的页，几乎每页都有一张大图。所以口径从「宜配则配」改成**「每页都配，只有下列页不配」**：

| 页型 | 配不配 | 说明 |
|---|---|---|
| 封面 | **配**，写 `形=抠图` | 本书主人公半身或全身，引擎贴在横幅右下、出血 |
| 环节标题 | 不配，填「无」 | 整页主题色底 |
| 填空表格 | 不配，填「无」 | 表格占满主区 |
| 引导问题 | 配 | 纯元认知页（「你读书时会怎么提问」这类）也配：画本页讨论的人物或物件 |
| 要点小结 | 配 | `要点样式：时间轴` 的页不配（时间轴横贯全宽） |
| 原文齐读 | 配 | 引文约 150 字以上的写「无」：放了图字号会降到 20pt 以下，引擎本来就会弃图，写了只是白花生图费 |

## 二、格式

```
配图建议：<篇目·场景>｜<章节>｜建议元素：A、B｜形=抠图|场景｜画面=<生图描述>[｜插=插-NN][｜击=N]
```

| 段 | 必填 | 写法 |
|---|---|---|
| 篇目·场景 | 是 | 4–8 字说清画什么（「鲍雷伊·伏案写信」） |
| 章节 | 是 | 写**章节**（「第二章」「第五章·烫澡」）。**禁写页码**——档案里没有页码，按真实性红线不许编（CLAUDE.md §4） |
| 建议元素 | 是 | 2–4 个具体名词，顿号分隔 |
| `形=` | 是 | `抠图`＝单个人物或物件、透明底，贴右下出血；`场景`＝有环境的完整画面，放右栏圆角 |
| `画面=` | 是 | 给生图用的画面描述，约 40–80 字，见第三节。不受 30 字上限约束 |
| `插=` | 选 | 两种取值：① `插-NN`：本书 `读书会原书插图/<书名>/` 下有对得上的扫描件时写（按 `_图单.md` 的画面描述挑，避开图单标了「画文不一致」且与本页提问冲突的图）；② `封面`：取 `读书会书籍封面/<书名>`，用在讲整本书的页（读法叮嘱、阅读计划、走近作者、全书回顾）。**两者都优先于 AI 生图**；写了 `插=` 的页 `画面=` 可省 |
| `击=N` | 选 | 图对应第 N 项（或会露出第 N 个答案）时，让图跟第 N 击一起出现；不写＝翻页即在 |
| `图=` | 不手写 | 由配图脚本验收后回填 |

例：

```
配图建议：鲍雷伊·伏案写信｜第一章｜建议元素：男孩、信纸、铅笔｜形=抠图｜画面=一个十一二岁的美国男孩坐在书桌前，低头认真写信，一手按住信纸，一手握铅笔，表情专注、嘴微闭
配图建议：后园·倭瓜爬架｜第三章｜建议元素：倭瓜、黄瓜架、蝴蝶｜形=场景｜画面=夏天的北方农家后园，倭瓜藤爬上木架和房顶，黄瓜开着小黄花，几只蝴蝶飞过，阳光明亮
```

## 三、`画面=` 怎么写（生图口径）

吸收写作课线配图的教训（记忆 ppt-illustration-style-reference-0925），六条：

1. **画内容，不画活动**。画本页讲的那个人、那件事、那个物件；不画「学生讨论」「老师讲课」「孩子托腮思考」这类挪到哪页都能用的陪衬图。判据：这张图挪到别的页也说得通，就是没画对。
2. **不露答案**。问题页的图不能画出参考答案的内容；会露答案的图写 `击=` 跟答案那一击出现，或者换成问题本身的画面。
3. **写清表情和姿态**。默认表情要压住：「专注」「认真听」「淡淡微笑」「嘴闭着或微张」；只有本页情绪就是兴奋、惊喜、难过时才写开。
4. **人物要写外貌锚点**：年龄、国别、发型、衣着，一本书四课统一（配图脚本会给主要人物出定妆图，`画面=` 里只写本页的动作和情境，不要和定妆冲突）。
5. **画风不写进 `画面=`**。画风由本书项目的手绘风格编号统一控制，`画面=` 里不写「水彩」「素描」「卡通」。
6. **避开会被拒的题材**：孩子＋床＋嘴里含东西、暴力血腥的直接画面一律改写（如「烫澡」画成「围观的人群和冒热气的大缸」，不画人在缸里）。「旗子」写明「纯色三角旗，无图案」。

7. **只画物件的抠图要写「画面中没有任何人」**。抠图工具的固定尾句是「只画人物和必要道具」，不写这句模型会自己添一个孩子进来（汉修试点 P14 信纸页就多画了一个男孩）。
8. **非主角人物写清年龄和外貌，不许跟主角撞脸**。只写「一位男作家」，会画成和主角一样的少年（汉修试点 P07）；要写「五六十岁、头发花白」这种锚点。

**情节和细节只来自书籍档案**。档案没写的外貌、场景细节可以按时代和地域合理补，但不许和档案冲突；图服从文字，绝不可拿图改写情节或数字。

## 三点五、取图顺序与 AI 图的画风（2026-10-06 用户定）

**取图顺序**：原书插图（`插=插-NN`）→ 书封（`插=封面`）→ AI 生图。

- 原书插图放在 `读书会原书插图/<书名>/`，**必须配 `_图单.md`**（逐张写原书出处、画面描述、画文不一致警告），挑图靠图单，不靠文件名。用户新放进来的图，先逐张目视、对照书籍档案补图单，再拿来配页。
- 书封只放在 `读书会书籍封面/<书名>`，**不复制进原书插图目录**（CLAUDE.md §3：挪走会让书目卡、海报、阅读指南静默丢封面）。

**AI 图的画风**，一本书定一次，写进项目 JSON 的风格卡，四课统一：

| 情形 | 怎么定 |
|---|---|
| 本书**有**原书插图 | 先逐张看插图，从手绘风格库（`课件配图工具/手绘风格库/styles.json`）选最接近的编号填进 `手绘编号`；必要时再在风格卡写 `风格参考图: 读书会原书插图/<书名>/插-NN.jpg`，挂这张扫描件、只取画风（顶替编号自带的参考图）。**挂扫描件前先试出 2–3 页**：这个模型容易把参考图里的人物衣着、道具照搬过来，照搬了就撤掉 `风格参考图`、只留编号 |
| 本书**没有**原书插图 | 按书的年代、地域、气质选 2–3 个候选编号（附一句理由）交用户挑，拍板后再统一出图 |

两种情形都要先出主角定妆图，各页挂载定妆图保证长相一致。

## 四、四图网格（一页多图）

详案里「看四幅画面」「三个场景对比」这类多画面并置的页，在同一页写 2–4 条 `配图建议：`，每幅一条，按从左到右、从上到下排。每条都写完整的六段。此模式不渲染 `要点`。

```
## P03 | 页型:引导问题
眉标：四幅奇画
标题：这四个国度，你最想先去哪一个？
配图建议：小人国·沙滩捆缚｜卷一·第一章｜建议元素：巨人、小人、细绳｜形=场景｜画面=…
配图建议：大人国·掌心玩偶｜卷二·第一章｜建议元素：巨手、小格列佛｜形=场景｜画面=…
```

## 五、何时填「无」

只有四种情形：环节标题页、填空表格页、`要点样式：时间轴` 的要点小结页、引文约 150 字以上的原文齐读页。写成 `配图建议：无`。

## 反例

❌ 写页码：`配图建议：苏七块·正骨｜书内P17–20｜…`（档案没有页码）
❌ 陪衬图：`画面=几个孩子围坐讨论这本书`
❌ 露答案：问「他最后成功了吗」，`画面=` 画鲍雷伊捧着获奖证书
❌ 写画风：`画面=水彩风格的……`
✅ `配图建议：苏七块·正骨｜〈苏七块〉｜建议元素：正骨大夫、银元、病患｜形=抠图｜画面=民国天津一位穿黑长衫的中年大夫，双手托着病人的胳膊正在正骨，神情专注`
