# laojohn-ppt-draft — 详案 → PPT 中间稿提炼器

把一份"课案详案 markdown"(由 `laojohn-lesson-plan` 产出，或人工撰写) 按**教学节拍**自动分页，提炼为符合 `laojohn-ppt` 契约的产物——**每个课时一份「中间稿（.md）」+ 一份「逐页讲稿（.md 与 .docx）」**。详案不需要预埋换页点，本技能自带分页引擎。

本技能的中间稿与讲稿文本由 Prompt 直接产出（LLM 读完本 SKILL.md + references 后撰写）；仅末端的「讲稿 .md → .docx」转换走脚本 `scripts/lecture_notes_to_docx.py`。另带 `_smoke_check.py` 作回归校验。

> **⚠ 写作课线例外（2026-08-03 起）**：写作课 PPT 已改由**外部平台生成**，本仓不再烘焙（详见 CLAUDE.md §3 与 `laojohn-ppt/SKILL.md`）。因此在写作课线上——
> - **逐页讲稿已停产**。`写作课件讲稿输出\` 目录已撤，存量讲稿已删，打包脚本的讲稿档也已撤。**不要再为写作课产讲稿**，用户不要。
> - **中间稿降级为「外部平台的生成依据」**（草稿），仍可产出，但不再定页序、也不再有讲稿与之 1:1。
> - 本 skill 在写作课线上只剩两件事：`scripts/pptx_outline.py`（从外部 pptx 抽页序骨架，供校正动画分组、备课查页时看每页屏上有什么）与 `scripts/pageback_annotate.py`（详案页标回注）。
>
> 读书会线**完全不受影响**，仍是「中间稿 → 讲稿 1:1 → laojohn-ppt 烘焙」，讲稿照旧生成。

## 何时使用

- 用户说"把详案做成 PPT 中间稿""提炼幻灯片骨架""详案抽成投屏稿"
- 上一步刚由 `laojohn-lesson-plan` 产出详案，准备走 `laojohn-ppt` 烘焙
- 用户上传一份按 `## 第N课时` / `### 环节` 组织的详案 .md
- **不要在用户只想要 pptx 时跳过本步骤**：必须先经此 Skill 产出中间稿，再交 `laojohn-ppt`

## 输入契约（硬闸 · 缺料停下要）

> **本 Skill 自带分页引擎**：详案**不再需要**（也不应再有）`【PPT换页】` 换页点。分页权在本工具——按"教学节拍"切页（见 `references/pagination-engine.md`）。若输入详案仍残留换页点，**忽略它们**、照样按节拍切。
>
> 详案若含 `〖PPT …〗` 页标（本 Skill"详案页标回注"步的产物，备课对照用），**同样视为注释、一律忽略**、按节拍重新分页——它是输出侧标注，不参与分页决策。

输入是一份按课时/环节组织的详案 .md。具体要求：

1. 文档主标题用 `#`；
2. 每个课时用 `## 第N课时 · 课型`（如 `## 第二课时 · 阅读交流课1`）划分；
3. 课时内环节用 `### 一、xx`、`### 二、xx` 划分；
4. 师话以 `师：` 开头；参考以 `参考：` 开头；引文用 `> ` 引用块；表格用标准 GFM 表格。

**若缺课时划分（`## 第N课时`）或环节划分（`### 一、xx`）→ 停下要补全，分页引擎依赖这两级结构定边界与归属。**

### 写作课模式（自动判型）

本 Skill 默认处理「整本书阅读读书会详案」。**若输入是校内同步习作课（写作课）详案**（由 `laojohn-writing-lesson` 产出，特征：H1 形如 `# 《题目》· 写作课教学设计`、书级头部为 `## 一、教案提纲表`+核心素养四维、课时为 `## 第1课时 · 写作指导课`）→ **切「写作课模式」，全程加载 `references/writing-mode.md`**。骨架/节拍引擎/7 字段/讲稿照旧复用，但**页型体系按写作 profile 走**：写作课**不产出「引导问题/要点小结」**（读书会思辨隐喻，套写作讲解会把连贯话切碎），改按老师的教学动作映射到写作专属页型——情境任务 / 写法讲解 / 活动指令 / 双栏对照 / 写作任务，另加示范文拆页、元信息含 `文体：写作`、配图默认「无」等差异。判不准就按读书会模式走。

### 固定输出目录

> ⚠ 路径与本机环境约定见根 `CLAUDE.md` §1：执行前用 `(Get-Location).Path` 确认实际项目根目录，下文 `<项目根目录>` 代表该路径，禁止硬编码盘符。


例：`<项目根目录>\读书会课件中间稿输出\俗世奇人\俗世奇人-导读课-中间稿.md`、`<项目根目录>\写作课件中间稿输出\三上-第六单元-这儿真美\这儿真美-写作指导课-中间稿.md`

### 1) 文件粒度

**一节课产出：中间稿（.md）+ 逐页讲稿（.md 与 .docx 同时出）。** 4 课时课程 → 4 份中间稿 + 4 份讲稿 md + 4 份讲稿 docx。

- 中间稿（投屏可见内容）：`读书会课件中间稿输出\<书名>\<书名>-<课型>-中间稿.md`（写作课在 `写作课件中间稿输出\<年级册>-第N单元-<题目>\`）
- 逐页讲稿（老师手边备讲稿，承接师话）：`读书会课件讲稿输出\<书名>\<书名>-<课型>-逐页讲稿.md` **与同名 `.docx`**。**仅读书会线**——写作课线讲稿已于 2026-08-03 停产，无对应目录

讲稿与中间稿**页序严格 1:1**。讲稿格式见 `references/lecture-notes.md`——因线上课件系统的 PPT 备注栏不可用，师话只能走这份独立讲稿。**讲稿 .md 写完后，必须用 `scripts/lecture_notes_to_docx.py` 转出同名 .docx**（讲稿专用干净版式，便于老师打印批注；md 仍是事实源、docx 是其渲染产物，改讲稿改 md 后须重转 docx）。

### 2) 元信息块（每个文件顶部，必填）

```
书名：俗世奇人
课时：导读课
作者：冯骥才 著
年级：L5 · 五年级
```

四项缺一不可。从详案的提纲、文本介绍中提取。

> **写作课模式例外**：写作课无书作者，`作者` 行省略、改加 `文体：写作` 行（触发 laojohn-ppt 封面不加书名号）；`书名` 填习作题目（不带《》）、`年级` 填年级册·单元。详见 `references/writing-mode.md` §1。

### 3) 分页头

```
## P02 | 页型:环节标题
```

`P02` 是**本工具自排**的连续编号，仅作中间稿内部引用 ID 与"中间稿↔讲稿"对位用；每个文件内从 P01 起连续、**每节课独立重排、不跨课时延续**；PPT 实际页码由 laojohn-ppt 按 slide 顺序独立计算（v6 页码解耦），与此处 P 编号无关。渲染端契约细则见 `laojohn-ppt/references/page-contract.md`。

### 4) 页型枚举（按 profile，不得自创）

- **读书会（缺省）6 种**：`封面` / `环节标题` / `引导问题` / `原文齐读` / `要点小结` / `填空表格`。
- **写作课（`文体：写作` 触发）不产出** `引导问题` / `要点小结`：共用 封面/环节标题/填空表格，另有 7 种写作专属页型（情境任务/写法讲解/活动指令/实景观察/示范文/双栏对照/写作任务）——完整枚举与渲染端行为见 `laojohn-ppt/references/page-contract.md`；何时用、字段写法见 `references/writing-mode.md` §2/§2.5/§2.6（v8 实景观察与视觉版式选择器亦在其中，按内容语义克制使用）。

判定规则见 `references/page-type-decision.md`。可视化工具/动手填写节拍统一走 `填空表格`（答案用 `{{}}` 标记、逐格点击），不再导入真实阅读单渲染图。

### 5) 字段集合（7 个，缺省即省略）

7 字段（眉标/标题/副标题/正文/要点/表格/配图建议）的集合定义与渲染端行为见 `laojohn-ppt/references/page-contract.md` §6；**生成端萃取口径唯一源＝`references/field-extraction.md`**（配图建议另见 `references/image-suggestion.md`）。三条生成端要点先记住：

- 眉标不写课型；标题 ≤ 25 汉字（投屏阅读距离 5 米）；**写全名、写完整句**，不用「他」承接上一页（field-extraction §2）；
- 某条要点下紧跟 `参考：答案`（缩进 2 空格）→ 逐段点击上屏，**口径从宽**：示例型参考也算，仅"详案没写参考或参考仅组织性文字/判定口径"才豁免；答案**写全**（判断加依据），**只上答案本身**——「说得出…就算数／都算对／押哪边都行，关键…」这类作答提示与判定口径一律不上屏（需要时进讲稿）（正反例见 field-extraction §5）；
- 填空表格空格答案用 `{{答案}}` 标记（整格留白整格包、行内挖空只包答案片段，见 field-extraction §6）。

### 6) 页面示例

页面写法示例见 `laojohn-ppt/references/page-contract.md` §9；完整一节课正例见 `examples/独一无二的伊凡-导读课-中间稿.md`。

## 工作流程（必须按顺序）

1. **审核输入 + 判型**：确认详案有 `## 第N课时 · 课型` + `### 一、xx` 两级结构。缺则停下要。（残留换页点忽略即可。）**若是写作课详案**（见上「写作课模式」判型特征）→ 切写作课模式、加载 `references/writing-mode.md`，后续 2–8 步均叠加其差异规则。
2. **抽元信息**：从详案提纲表与文本介绍提取 `书名 / 课时 / 作者 / 年级`，**另写一行 `主题色：`**（读书会新样式开关，2026-10-06 立）：
   - 从 `蓝 / 橙 / 灰蓝 / 绿` 里按本书气质选一色，**一本书四课统一**；这本书已有别的课时中间稿时照它，不另选。
   - 选色理由写一句交给用户（如「呼兰河传·橙：北方小城的暖色与荒凉」）；用户另指定的照用户。
   - 不写这一行＝旧样式（虚线配图占位、红字答案），只用于重烘存量书，新稿一律写。
3. **按课时拆分**：扫描 `## 第N课时 · 课型`，每个课时生成一份中间稿 + 一份讲稿。
4. **节拍分页**：在该课时段内，按 `references/pagination-engine.md` 把详案切成"教学节拍块"——碎的并、胖的拆、每段引文独立成页。对每块：
   - **判页型**（查 `page-type-decision.md`）；「动手填写/可视化工具」节拍统一出 `填空表格`（把工具搬成 GFM 表）；
   - **填字段**（查 `field-extraction.md`，遵守"7 字段缺省即省略"原则）；填空表格的空格答案从详案抽出、用 `{{}}` 标记（§6，真实性红线不豁免：详案没给就留空）；
   - **写配图建议**（查 `image-suggestion.md`，新样式口径：除环节标题、填空表格、时间轴页外**每页都配**，封面配主人公抠图；每条带 `形=` 与 `画面=` 两段，供配图脚本生图；章节不写页码）。**多画面并置**（详案"给你们看 N 幅画面/N 个场景对比"）→ 在同一引导问题页写 2–4 条 `配图建议：`，触发 2×2 网格、勿压成一条合并图、勿拆成多页。
   - **并列项选要点样式**（新样式可选，见 field-extraction §5b）：二选一 `药丸`、3–4 个并列 `卡片`、有先后 `流程`、回顾 `时间轴`、两组对照 `对比`；带参考答案的页不选。
   - **写作课防塌缩**（见 `writing-mode.md` §2「分页密度铁律」）：详案为同一环节铺开的多个平行素材要逐一落页——**多张实景图各自成景**（≤2景/页、不得只取第一张）、**词语补给站与选材菜单各自独立成页**（不合并、词/地点照详案列全）、**感官热身规则单独成页**。投屏薄多因分页挖漏详案，非详案薄。
5. **产出逐页讲稿**：与中间稿页序 1:1，按 `references/lecture-notes.md` 把详案师话提炼成口播/兜底参考/节奏/回溯四件套。
5b. **讲稿转 docx**：每份讲稿 .md 写完后，对其跑
    `PYTHONUTF8=1 python <skill>/scripts/lecture_notes_to_docx.py "<讲稿.md>"`
    （默认输出同名 .docx）。md 是事实源、docx 是渲染产物；后续若改讲稿务必重转。
6. **回标详案页标（必做 · 2026-07-18 用户拍板）**：按 `references/detail-pageback-annotation.md`，依据中间稿页序 + 讲稿回溯，把 `〖PPT 第N页 · 页型 · 眉标〗` 页标**就地内联回注**进详案（备课交叉对照用）。`第N页`=课件实际页码（**封面=第1页、正文从第2页起**，对齐课件系统翻页显示；封面/END 不标）。回注幂等（先清旧标再重插）。**PPT 链每次产出/重产中间稿后都要执行，不等用户点名**；回注改动了详案 .md，**必须随后重渲详案 .docx**：读书会详案跑 `laojohn-lesson-plan/assets/md_to_laojohn_docx.py` 一步即可；**写作课详案是两步——共享引擎（带 `--header-left/--header-right`）＋ `laojohn-lesson-plan/assets/style_front_page.py`**，漏第二步会静默把首页打回朴素版式（命令见 `laojohn-ppt/SKILL.md` 第 3 步）。docx 被 Word/WPS 占用报 PermissionError 时，请用户关闭文档后重跑。
7. **自检**：跑下方"产出前自检清单"。
8. **交付**：依次产出 N 份中间稿 + N 份讲稿（.md + .docx 各 N，N = 课时数），另交回注页标后的详案（.md + 重渲的 .docx）。

## 核心约束（违反即返工）

- **眉标禁写课型**：课型只能在封面副标题。眉标用"猜书名""苏七块""走近作者"等小节/篇目名。
- **不保留师话与备注**：中间稿只放"投屏可见的内容"。师话留在详案里，中间稿不写 `备注：` 字段（这条与笔者之前手写的中间稿不同，**新契约不保留**）。
- **页型枚举封闭**：读书会 6 种、写作课额外 7 种（`情境任务`/`写法讲解`/`活动指令`/`实景观察`/`双栏对照`/`写作任务`/`示范文`，见上「写作课页型」），不得自创第三套。如遇详案出现枚举外的新形态（如视频、互动游戏），就近归类（多数归"环节标题"或"引导问题"）。
- **填空表格答案只来自详案**：把详案空格答案抽进单元格、用 `{{答案}}` 标记（整格留白整格包、行内挖空只包答案片段如 `【第{{3}}章】`）。**正向义务别漏**：详案给了 `参考：` 定论答案的梳理表（对照表/维恩图/阶梯图/情节归并表等）**必须**包 `{{}}`，不得只搬空框；**豁免**：预测阅读单、纯思辨判断单（我的判断/我的理由）、开放体验单这类详案本无定论的，保持空白不硬凑。**真实性红线不豁免**：情节·人物·章节·数字回详案/档案核对，详案没给的格就留空、不写 `{{}}`、绝不凭记忆补。详见 `field-extraction.md` §6。
- **原文真实性**：原文齐读页若详案里是 `(教师朗读【待补：…以实际版本为准】)` 占位，中间稿照搬该占位，**不得凭记忆补原文**——延续详案的伪摘录禁令。
- **标题精炼**：投屏阅读距离 5 米，标题 ≤ 25 汉字。若详案里师话过长，需提炼核心问句/陈述句。
- **P 编号工具自排**：详案无换页点可沿用，由本工具编号，**每节课都从 P01 起**（不跨课时延续）；仅作内部引用 ID。
- **分页按教学节拍**：不许"一页塞多段朗读/多组问答"（胖块必拆），也不许"一句过渡独占一页"（碎块并入）；每段引文独立成原文齐读页，长引文不并入追问页。详见 `references/pagination-engine.md`。
- **环节序号一致性（v1.2）**：单环节课时不写"一、"；多环节课时按 1→N 递增，不跳号、不嵌套、单课时上限 4 个；禁止两个相邻的 `环节标题` 页。详见 `references/field-extraction.md` §2 与 `page-type-decision.md` 环节标题二次过滤。

## 产出前自检清单

逐项核验（或直接跑 `python _smoke_check.py <文件>` 自动校验）：

- [ ] 每个 .md 顶部有元信息块（4 行 + 新样式的 `主题色：`）
- [ ] 每页分页头格式 `## PXX | 页型:xx`，页型在 6 种枚举内
- [ ] 眉标不出现"导读课""阅读交流课1"等课型字样
- [ ] **眉标与同页标题不共享核心主词**（眉标整体不得为标题子串；环节标题页除外，见 field-extraction §5）
- [ ] **副标题读得通顺、非电报体**：整句陈述型字段（副标题、环节标题/情境任务正文）主谓齐备、助词不省，`+` 号未用作连词，当众读一遍不需脑补省字（见 field-extraction §3「克制电报体」）
- [ ] 引导问题/要点小结的 `要点：` 用 `- ` 列表格式，**不要** 用 `/` 分隔
- [ ] **参考答案上屏（口径从宽·逐问回详案对）**：详案在某条要点处写了 `参考：` 且含可引用内容的——**示例型（"比如…"）也算**——已在该条下补 `参考：答案`（缩进 2 空格、写全一两句、只来自详案）；仅"详案没写参考、或参考通篇只有组织性文字/判定口径（无答案内容）"才留白。**逐条扫一遍 `参考：` 行，凡「就算数／都算对／就好／关键说清」一类判定口径都已删除**；交付前逐张问题页回详案数一遍 `参考：`，宁可多挂勿漏挂（见 field-extraction §5 正反例）
- [ ] 原文齐读的占位文本与详案完全一致（不私自补全）
- [ ] 表格页是标准 GFM 格式，列数与详案一致
- [ ] **留白填写表已写 `列宽：`**：按预估填写量分（篇名/日期窄、写一件事/一句理由宽），个数等于列数（见 field-extraction「列宽」）
- [ ] **填空表格答案已用 `{{}}` 标记**：逐张填空表格回详案对过——详案给了 `参考：` 定论的（对照/维恩/阶梯/归并表）都已包 `{{}}`、没漏；纯开放单（预测单/思辨判断单）保持空白；答案来自详案（行内挖空只包答案片段、不连提示一起包），未凭记忆补
- [ ] **元信息写了 `主题色：`**，与本书其他课时中间稿一致
- [ ] **配图建议（新样式）**：除环节标题、填空表格、时间轴页外每页都有；每条六段式 `篇目·场景｜章节｜建议元素：…｜形=抠图|场景｜画面=…`，章节不写页码；`画面=` 画内容不画活动、不露答案、写清表情（见 image-suggestion.md §三）
- [ ] **写全名、写完整句**：标题、要点、答案没有压成电报体，人名不省（「汉修先生」不作「汉修」），不用「他」承接上一页
- [ ] **上屏原文都带页码**：原文齐读页出处行与问题页里引的原句，凡详案/档案标了页码的都已照搬（出处行"·篇名 P61"）；详案没标的不写不占位，已列进交付报告「缺页码清单」；没有一处页码是详案/档案之外来的
- [ ] **多环节课时每个环节都有环节标题页**；有下节预告的，末页是「下节预告」要点小结
- [ ] **多画面页用四图网格**：详案"看 N 幅画面/N 场景对比"的引导问题页，已写 2–4 条 `配图建议：`（未压成一条合并图、未拆成多页）；此类页可不写要点
- [ ] P 编号连续不跳号、不重复（工具自排，不再要求与详案锚点对应）
- [ ] **分页合规**：无"一页多段朗读/多组问答"胖页，无"一句过渡独占一页"碎页，每段引文独立成页（见 pagination-engine 自检）
- [ ] **每课时同时产出中间稿 + 逐页讲稿**，两者页序 1:1（讲稿自检见 lecture-notes.md）
- [ ] **每份讲稿 .md 都已转出同名 .docx**（跑 `scripts/lecture_notes_to_docx.py`；md 改后须重转）
- [ ] **详案页标已回注（必做）**：各课时 `〖PPT 第N页〗` 数量 = 该课时中间稿内容页数（封面/END 不标、每课时从第2页起连续），锚在取材块正前方独立行（自检见 detail-pageback-annotation.md）；回注后详案 .docx 已用 lesson-plan 的 docx 引擎重渲
- [ ] 输出文件数 = 中间稿 N + 讲稿 .md N + 讲稿 .docx N（N = 详案课时数）
- [ ] 文件命名 `<书名>-<课型>-中间稿.md` / `<书名>-<课型>-逐页讲稿.md` / `<书名>-<课型>-逐页讲稿.docx`
- [ ] 同一课时内不存在两个相邻的 `环节标题` 页（v1.2）
- [ ] 单环节课时的环节标题**不带**"一、"前缀；多环节课时序号 1→N 无跳号无嵌套（v1.2）

## 调用示例

```
用户：把刚生成的《俗世奇人》详案做成 PPT 中间稿。
助手：（读 SKILL.md + references → 按教学节拍分页 → 每课时产出「中间稿.md」+「逐页讲稿.md」→ 共 4+4 份 → 提示下一步用 laojohn-ppt 编译）
```

```bash
cd .claude/skills/laojohn-ppt/scripts
python build_ppt.py --input "<项目根目录>\读书会课件中间稿输出\俗世奇人\俗世奇人-导读课-中间稿.md" --output "<项目根目录>\读书会课件PPT输出\俗世奇人\俗世奇人-导读课.pptx"
```

## 不做的事

- 不生成内容、不改写文案、不补原文（师话只能提炼重组，不凭记忆新增事实）
- 不直接产出 .pptx（那是 `laojohn-ppt` 的事）
- **中间稿不写师话**（中间稿是"投屏稿"，只放投屏可见内容）——师话改路由到**逐页讲稿**（因线上课件系统备注栏不可用）
- 不自己生图：只写配图建议（新样式带 `形=`／`画面=` 两段），图由 `课件配图工具/scripts/reading_deck.py` 生成、验收后回填 `图=`
