# laojohn-ppt-draft — 详案 → PPT 中间稿提炼器

把一份"课案详案 markdown"(由 `laojohn-lesson-plan` 产出，或人工撰写) 提炼为 **多份** 符合 `laojohn-ppt` v5 契约的"中间稿 markdown"——**每个课时一份**。

本技能是纯 Prompt Skill，无脚本依赖。LLM 读完本 SKILL.md + references 后，直接产出中间稿文本。

## 何时使用

- 用户说"把详案做成 PPT 中间稿""提炼幻灯片骨架""详案抽成投屏稿"
- 上一步刚由 `laojohn-lesson-plan` 产出详案，准备走 `laojohn-ppt` 烘焙
- 用户上传一份带 `【PPT换页-P\d+】` 锚点的详案 .md
- **不要在用户只想要 pptx 时跳过本步骤**：必须先经此 Skill 产出中间稿，再交 `laojohn-ppt`

## 输入契约（硬闸 · 缺料停下要）

输入必须是一份 **带 `【PPT换页-P\d+】` 锚点** 的详案 .md。具体要求：

1. 文档主标题用 `#`；
2. 每个课时用 `## 第N课时 · 课型`（如 `## 第二课时 · 阅读交流课1`）划分；
3. 课时内环节用 `### 一、xx`、`### 二、xx` 划分；
4. PPT 锚点格式：`【PPT换页-PXX】`，P 编号全局连续（不按课时重置）；
5. 师话以 `师：` 开头；引文用 `> ` 引用块；表格用标准 GFM 表格。

**若缺锚点 / 缺课时划分 → 停下要补全，不得自行猜测拆页。**

## 输出契约

### 1) 文件粒度

**一节课一个 .md 文件。** 4 课时课程 → 4 个中间稿文件。

文件命名：`<书名>-<课型>-中间稿.md`（如 `俗世奇人-导读课-中间稿.md`、`俗世奇人-阅读交流课1-中间稿.md`）。

### 2) 元信息块（每个文件顶部，必填）

```
书名：俗世奇人
课时：导读课
作者：冯骥才 著
年级：L5 · 五年级
```

四项缺一不可。从详案的提纲、文本介绍中提取。

### 3) 分页头

```
## P02 | 页型:环节标题
```

- `P02` 沿用详案里 `【PPT换页-P02】` 的 **全局** 编号，不重置；
- 每个文件内只包含本课时段的 P 编号（如导读课 P01–P18，交流课1 接 P19–P30）。

### 4) 页型枚举（6 种，不得自创）

`封面` / `环节标题` / `引导问题` / `原文齐读` / `要点小结` / `填空表格`

判定规则见 `references/page-type-decision.md`。

### 5) 字段集合（7 个，缺省即省略）

| 字段 | 类型 | 说明 |
|---|---|---|
| 眉标 | 单行 | 页内小节/篇目名（如"猜书名""苏七块"）；**不写课型** |
| 标题 | 单行 | 页面主标题，≤ 25 汉字 |
| 副标题 | 单行 | 仅"填空表格"用 |
| 正文 | 多行 | 段落文本；原文齐读放节选原文 |
| 要点 | 列表 | 以 `- ` 开头，每行一条；2–5 条 |
| 表格 | GFM 表格 | 仅"填空表格"用，标准 `\| col \| col \|` 格式 |
| 配图建议 | 单行 | `篇目·场景｜书内页码｜建议元素：x、y` 或填"无" |

萃取规则见 `references/field-extraction.md`；配图建议规则见 `references/image-suggestion.md`。

### 6) 完整页面示例

```
## P03 | 页型:引导问题
眉标：猜书名
标题：书名叫《俗世奇人》——请关注"俗"和"奇"这两个字
要点：
- 这本书可能写的是哪些人
- "俗"是什么意思
- "奇"又奇在哪里
配图建议：苏七块·封面人物｜书内P12｜建议元素：长衫大夫、手部特写
```

完整一节课示例见 `examples/俗世奇人-导读课-中间稿.md`。

## 工作流程（必须按顺序）

1. **审核输入**：确认详案带 `【PPT换页-P\d+】` 锚点 + `## 第N课时` 课时划分。缺则停下要。
2. **抽元信息**：从详案提纲表与文本介绍提取 `书名 / 课时 / 作者 / 年级`。
3. **按课时拆分**：扫描 `## 第N课时 · 课型`，每个课时生成一个独立文件。
4. **逐页提炼**：在该课时段内，按 `【PPT换页-PXX】` 切块——**两个相邻锚点之间的文本块** 对应一张 PPT。对每块：
   - **判页型**（查 `page-type-decision.md`）；
   - **填字段**（查 `field-extraction.md`，遵守"7 字段缺省即省略"原则）；
   - **写配图建议**（查 `image-suggestion.md`）。
5. **自检**：跑下方"产出前自检清单"。
6. **交付**：依次产出 N 份中间稿 .md（N = 课时数）。

## 核心约束（违反即返工）

- **眉标禁写课型**：课型只能在封面副标题。眉标用"猜书名""苏七块""走近作者"等小节/篇目名。
- **不保留师话与备注**：中间稿只放"投屏可见的内容"。师话留在详案里，中间稿不写 `备注：` 字段（这条与笔者之前手写的中间稿不同，**新契约不保留**）。
- **页型枚举封闭**：只允许 6 种，多一种都不行。如遇详案出现新形态（如视频、互动游戏），就近归类（多数归"环节标题"或"引导问题"）。
- **原文真实性**：原文齐读页若详案里是 `(教师朗读【待补：…以实际版本为准】)` 占位，中间稿照搬该占位，**不得凭记忆补原文**——延续详案的伪摘录禁令。
- **标题精炼**：投屏阅读距离 5 米，标题 ≤ 25 汉字。若详案里师话过长，需提炼核心问句/陈述句。
- **P 编号不重置**：跨课时沿用详案全局编号。

## 产出前自检清单

逐项核验（或直接跑 `python _smoke_check.py <文件>` 自动校验）：

- [ ] 每个 .md 顶部有 4 行元信息块
- [ ] 每页分页头格式 `## PXX | 页型:xx`，页型在 6 种枚举内
- [ ] 眉标不出现"导读课""阅读交流课1"等课型字样
- [ ] **眉标与同页标题不共享核心主词**（眉标整体不得为标题子串；环节标题页除外，见 field-extraction §5）
- [ ] 引导问题/要点小结的 `要点：` 用 `- ` 列表格式，**不要** 用 `/` 分隔
- [ ] 原文齐读的占位文本与详案完全一致（不私自补全）
- [ ] 表格页是标准 GFM 格式，列数与详案一致
- [ ] 配图建议格式 `xxx·xxx｜xxx｜建议元素：x、y` 或填"无"，控制 30 字内
- [ ] P 编号与详案锚点一一对应，不缺不重
- [ ] 输出文件数 = 详案课时数
- [ ] 文件命名 `<书名>-<课型>-中间稿.md`

## 调用示例

```
用户：把刚生成的《俗世奇人》详案做成 PPT 中间稿。
助手：（读 SKILL.md + references → 产出 4 份中间稿 .md → 提示下一步用 laojohn-ppt 编译）
```

下游衔接：拿到中间稿后，用户运行：

```bash
cd .claude/skills/laojohn-ppt/scripts
python build_ppt.py --input 俗世奇人-导读课-中间稿.md --output 俗世奇人-导读课.pptx
```

## 不做的事

- 不生成内容、不改写文案、不补原文
- 不直接产出 .pptx（那是 `laojohn-ppt` 的事）
- 不写师话备注（中间稿是"投屏稿"，不是"讲师稿"）
- 不自动配图（始终给老师占位文本）
