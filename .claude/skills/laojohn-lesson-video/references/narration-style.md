# 备课视频旁白 · 写法判据（唯一源）

本文件是 `write_narration.py` 生成旁白、`audit_narration.py` 机检、以及人工审稿三处**共同的判据**。
改这里就是同时改了三处；不要在 prompt 里另存一份口径。

---

## 一、这支片子是什么（决定一切的前提）

看片人是**加盟商老师，上课前一晚打开它**。他手里已经有详案、PPT、教师速览三份纸。
他缺的不是「课上说什么」——逐字稿写得清清楚楚；他缺的是**有人带他走一遍，告诉他哪里是关键、
为什么这么排、学生会在哪儿卡住**。

所以：

> **旁白不是念给学生听的课，是讲给老师听的备课。**

一句话判据：**把画面遮住只听声音，听起来应该像一位老教研在带新老师过教案，
不应该像一节课的录音。**

---

## 二、每页四块骨架

固定顺序 `locate → do → why? → risk?`。`locate`/`do` 必有，`why`/`risk` 按素材有无决定。

> **页与页的衔接由 `locate` 承担**：它的第一句要接住上一页的产出，再说这一页干什么。
> `LOCATE_OPENERS` 六条只换**怎么接**，不换**接不接**。
> （0921 晚：bridge 删干净之后用户反馈「前后衔接不上」——查下来是旧池六条里
> 只有一条真在接上一页，其余各说各的。**过渡本来就该在 locate，不该靠翻页提示顶着。**）
>
> ⚠ **`bridge`（翻页提示）已于 0921 废除**，新稿写出来机检判 FAIL。
> 张祖庆视角审片时取数：**26 页里 25 页的 bridge 是同一句「……了，再翻页」**，
> 占全片 8%、四百五十多字，零信息量——老师看着自己的课件，
> 不需要人告诉他什么时候翻页。**与其页页提醒他翻页，不如把那八分之一的时间全给卡点。**
> 批次接缝改用上一批末页的最后一块原文，接缝要的本来也只是「上一页讲到哪儿了」。

| 块 | 讲什么 | 素材来源（分镜单字段） | 长度 |
|---|---|---|---|
| `locate` | **接住上一页 + 这一页拿来干什么**（解决什么问题、为后面哪一步铺路） | `kicker`、`title`、`step`、`source.stage`、**上一页的眉标** | 1–2 句，25–55 字（接住前一步只要半句） |
| `do` | **哪一步做错这一页就废了，以及怎么判断做对了** | `source.teacher_lines`（**只取关键那一步，不复述流程**）、`source.interaction`、`source.materials` | 2–3 句，**不超过全页一半** |
| `why` | 为什么这么设计／哪里必须守住／哪里可以放开 | `delivery.why` / `delivery.keep` / `delivery.free` | 1–2 句 |
| `risk` | 学生容易卡在哪、卡住了怎么办 | `warns`、`nono`、**`source.refs`（`参考：`）、`source.materials` 里的 `〔应答·…〕`** | 1–3 句，**有素材就必须写** |
| `end` | **结束语**（只在片尾页，且必须是最后一块） | 本课技法 | 1–2 句，25–50 字 |

各块的话头（**只示意语气落在哪个区间，一字都不要搬**）：

> ⚠ **凡是写进这份判据的例句，都会被逐字抄。** 同一个根因 0921 犯了三次：
> 片尾抄出「巡视时」（那时根本没学生可巡）、locate 抄出「屏幕上是…」、
> do 抄出「这一页只有一件事不能错」（六上四 29 页里 15 页一字不差）。
> 所以例句一律**不写起头句式**，只写内容；起头由 `write_narration.py` 的三个轮换池指定。

- `locate`：「这一页要解决的是：让学生自己发现，特点抓准了别人才猜得中。」
  ⚠ **不准描述画面**：「屏幕上是…」「封面上印着…」「屏幕上写着『…』」这类一律不写——老师正看着屏幕，把标题念一遍没有任何信息量。locate 回答的是「干什么」不是「长什么样」。
  ⚠ **不要报点击次数**（「一共四次点击」这类）——老师自己点课件时自然就看到了，说出来只是占时间，而且页页都报一遍特别吗嗦。
- `do`：「两段都得读，只读一段学生就没得比。读完别急着评价——你一评价，后面的发现就不是他们自己的了。」
  ⚠ **不要复述流程**。「你先……然后……最后……」这种详案上一字不差地印着，
  老师不需要你念给他听。do 只讲**那一步**：做错了这一页就白上，以及怎么看出做对了。
- `why`：「这一步必须守住的是——两段都要读，只读一段学生就没得比了。」
- `risk`：「学生这时候最容易把线索说成评价，比如说他人很好。遇到这种，追问一句你从哪儿看出来的。」

  **卡点素材有四个来源，前两个一直没被用起来**：
  - `warns` / `nono`（教师用配套的易错点）——整课只有六七条，摊到二十几页远远不够
  - **`参考：`（详案里学生可能给出的答案）**——它是一张卡点地图：
    学生会往哪几个方向答，哪个方向是偏的，哪个是老师收不上来的
  - **`〔应答·……〕`（详案里的答偏预案）**——这就是现成的「答偏了怎么办」，
    而那正是新手最怕的时刻
  - `source.stage` 里带判断的舞台指令

  ⚠ **有素材就必须写 risk**。这一层是整支片子唯一的增量——
  详案和课件老师都有，只有「学生会卡在哪」他没处看。
  实测过一版：risk 只占 3%、二十四页里三页有，那支片子八成是在陪老师读详案。
- `end`：说完技法之后给老师一个**落点**——下一步该动手做什么（上课前把哪样东西再过一遍、
  哪一处提前想好怎么接）。说完片子就结束。

  ⚠ **结束语不是客套话**：不祝愿、不道别、不说「期待」「祝教学顺利」「各位老师」，
  也不夸这堂课好。它仍受语言红线里「客套话」那一组约束。
  0921 用户指出片子**没有结束语**——讲完卡点就戛然而止。根因是早先为了删掉
  「期待下次课」那类客套，把收束一并禁掉了；**「不说空洞客套」和「不给收束」是两回事**。

## 三、三条硬线

### 1. 不念师话

`师：` 段落是**证据**，不是台词。模型读它是为了知道这一页课堂上在发生什么，
产出的应该是**对老师说的第二人称指令**。

> 详案：`师：同学们，刚才大家的脑海里都浮现出了一个清晰的人物形象。动笔之前，还要先弄清一件事……`
> 旁白：`你先让学生在脑子里把人定下来，再转到今天要写什么——这个转场不能省，省了学生会以为随便写谁都行。`

**唯一例外**：`delivery.keep` 点名必须守住的那句关键提问，可以引用，但必须包成
`这句话建议照着问：“……”`，让老师听得出这是引语、不是旁白自己在说。

机检判的是**比例与最长连续段**，不是「出现过相同的十几字」：
单段连续逐字相同 ≥ 26 字即 FAIL（整句抄了）；全页与详案逐字相同的字占比
≥ 30% 判 FAIL、≥ 20% 判 WARN。引语块豁免。

> 为什么不按片段命中判：**技法名、学生任务指令、情境设定本来就必须
> 与详案一字不差**（仓内对技法名有硬要求）。首版按 12 字命中判，一口气误报
> 7 处，条条都是该一致的术语（如「只抓一两处最特别的地方」）。

### 2. 人称是「你」

对老师说话。不出现「同学们」开头的直呼，不出现「我们来看」这类课堂用语——引语内除外。

### 3. 三色旁注是骨干，不是补充

`keep`／`free`／`why`／`warns`／`nono` 是这支片子**唯一的增量**——
详案和 PPT 老师手里都有，只有这层东西他没处看。

推论：**一页如果既没有 keep/why、又没有 warns，它的旁白就该短**（压到 90–120 字），
把时间让给有货的重点页。宁可某页只说两句，也不要为了凑字数把师话复述一遍。

**这一条现在有机检**（`check_increment`，0921 加），三个数字都报 WARN：

| 指标 | 下限 | 它在问什么 |
|---|---|---|
| `why`+`risk` 字数占全片 | **30%** | 这支片到底给了不与他手里没有的东西吗 |
| 带 `risk` 的页占比 | **30%** | 卡点是撑开的还是只在几页里扒了一下 |
| 全课上游卡点素材条数 | **8** | 不够就**不是写稿的错**——这一课撑不起一支片 |

第三项最要紧，因为它在**写稿之前**就能算出来。
0921 两课次实测：三上一只有 **3 条**（早期课次，`参考：` 与〔应答〕体例还没定型），
六上四有 **23 条**（17 条 `参考：` + 3 条〔应答〕 + 3 条易错点与禁忌）。
差了七倍多——**素材薄的课次不是把旁白写得更用力就能补上的，得回头去补详案的 `参考：` 与应答预案**。

### 4. 凡是「按条件该做的事」，都得程序逐页点名

这是本链 0921 一天内反复踩出来的一条总规律：

> **写成通则的约束，模型会漏；程序逐页算好再点名的约束，模型才执行。**

三个实例，每一个都是先写通则、没治住，改成逐页点名才治住：

| 约束 | 写成通则的结果 | 逐页点名的实现 |
|---|---|---|
| 起手式别重复 | 23/23 页同一个调 | `LOCATE_/DO_/RISK_OPENERS` 三池按页号取模 |
| 有素材就写 `risk` | 24 页里只 3 页写了 | 逐页列出「这一页手里有 N 条卡点素材」 |
| 有必守就写 `why` | prompt 写了硬线，29 页仍 11 页漏 | `_required_blocks_note()` 逐页算出该写哪几块 |

所以新增任何「满足 X 就要 Y」的判据时，**不要只往判据文档和 prompt 里加一句话**，
要同时问：这个 X 能不能在 `build_shotlist` 阶段就数出来？能，就逐页写进 prompt。

---

### 5. 起手式必须轮换

**整片最忌每页一个调。** 首版实测：23 页里 23 页的 locate 以「这一页是」开头、
20 页接「屏幕上是」、11 页以「一共四次点击」收——**逐页看毫无毛病，
连着听十几分钟像复读机**。这是听觉上最要命的一项，而单页审稿永远发现不了。

靠提示词说「别重复」治不住，所以改成**程序按页序指定角度**：
`write_narration.py` 的 `LOCATE_OPENERS` 是轮换池，每页在 prompt 里被点名用哪一种起手。
改轮换池就改这里。

`audit_narration.py` 的「起手式重复」项负责让它藏不住：同一块里≥45% 的页
前六字相同即报 WARN。why 与 risk 同理。

⚠ **只给 locate 配轮换池是不够的**。locate 治住之后，0921 六上四实测立刻出现：
**do 块 27/29 页以「这一页」开头、risk 块 13/29 页以「学生可」开头**。
现在 `LOCATE_OPENERS`、`DO_OPENERS`、`RISK_OPENERS` 三个池子按页号取模同时生效。

## 四、语言红线（对外件不豁免）

沿用仓内既有两条，另加三条本链专属。

**沿用：**
- 禁市井网络口语（「搞定」「一波」「直接起飞」「拿捏」），禁过度学术术语
  （「支架式学习」「元认知监控」「具身认知」）。中间那档才对：「先……再……」
  「这一步的目的是……」「这里不用展开」。
- 禁 AI 腔：破折号拼接长句、三句排比收尾、「不仅……更是……」、空泛点题句
  （「让每个孩子都爱上写作」这类）。

**本链专属：**
- **禁把 `参考：` 里的学生答案当标准答案宣读。** 那是学生可能说出的话，讲成
  「学生会回答 A、B、C」会让老师误以为必须收到这几个答案，收不到就慌。
  要讲也只能讲成「学生大概会往这几个方向说」。
- **禁出现具体学生姓名**，禁出现「我们机构」「总部」这类内部称谓。
- **禁替总部承诺**师训安排、班型人数、排课频次、课时费、效果数据。
  仓内对这些的现行口径是「还在定」——旁白里一个字都不要提。

**引号只用弯引号 `“”` / `‘’`**（0921 用户定）。禁 ASCII 直引号，**也禁直角引号 `「」`／`『』`**——
旁白稿的正文最终要以字幕的形式印在屏幕上，直角引号在字幕带里显得生硬。
（判据文档、SKILL 这些**给人看的文件**照旧用 `「」` 做行文强调，本条只管旁白正文。）

**引号一律不许落在字幕行首**——开引号、闭引号都不行。
字幕折行是渲染时才发生的，看 srt 文件看不出来，所以这条由 `build_timeline.wrap()`
在折行时保证：切点会绕开整个引号块，不把成对引号拆到两行上。

⚠ **别用引号包裹旁白自己的话**。引号是留给「让老师照着说的原话」和「学生可能说出的答案」的。
0921 五上四 s10 实测：`『对照写是为了展现变化…』` 整句是旁白自己在讲解，套上引号纯属多余，
转成弯引号之后还和内层的 `“街道变得更干净了”` 撞成同形嵌套，念出来分不清层次。

## 五、字数预算

基准语速 **5.29 字/秒**（火山渊博小叔 speed=1.0 实测）。**各通道差得很远**——AiHubMix 的 OpenAI 音色只有 3.5，差了一半；换通道后以 `_配音清单.json` 的 `rate_cps_measured` 为准重算。
全片目标 **5000–5400 字 ≈ 18–19.5 分钟**（含停顿）。实测语速在 5.04–5.29 之间浮动，
同通道同音色、不同文本也有 4% 的差，所以每次都以配音清单回写的实测值为准。

| 页型 `kind` | 每页基准 |
|---|---|
| `cover` 片头 | 60 |
| `lesson_split` 课时分隔 | 130 |
| `teach` 常规教学页 | 175 |
| `model` 技法／示范文／对照／旁批（重点） | 230 |
| `write` 写作流程页 | 195 |
| `review` 评改交流页 | 205 |
| `appendix` 讲评附录 | 150 |
| `outro` 片尾 | 250 |

`build_shotlist.py` 在基准上按信息量微调（keep／why／warns／nono／`参考：`／〔应答〕
**每多一条 +12，上限 +60**），**只在总量溢出 4300–6800 时才归一化**。
生成时以分镜单里的 `budget_chars` 为准，允许 ±15%。

⚠ **总量不以师话字数为锚**（0921 改）。旧版把全片归一化到「师话字数 × 0.93」，
而张祖庆视角报出的病灯恰恰是「旁白总字数是详案师话的 94%」——
**拿师话字数当锚，等于从预算层就把「陪老师读一遍详案」写死了**。
片长该由增量素材的多少决定。`--target-chars` 的 CLI 默认值必须是 `None`，
给硬默认会永久盖住这条逻辑且完全静默。

**硬闸值**（`audit_narration.py` 判 FAIL）：单页 90–340 字；全片 4300–6800 字；单句 ≤45 字。

**超长压缩阶梯**（按序，前三级自动）：
1. 从 `warns` 最少的页开始砍 `why`——保 `keep` 与 `risk`，「必须守住」和「学生会卡」
   才是老师真正需要的
2. 合并相邻同环节的 `teach` 页（省掉一组 locate），画面仍逐页推进
3. 常规页的 `locate` 压到 15 字以内，重点页保留
4. 语速提到 1.05–1.10（**上限 1.10**，再高听感变机器）
5. 讲评附录独立成番外片——最后手段，它改变交付形态

**过短**（<15 分钟）反向来：给 `model` 页加 `why`，每个环节首页加一句
「这个环节整体 X 分钟，节奏是先……再……」。

## 六、分批生成与接缝

**按环节分批，一批 3–6 页**，不要整篇一次生成：

- 一次吐 26 页会撞 `max_tokens` 截断（`imgclient.chat` 有截断检测，但截了还得重跑）
- 同一环节内的页要共享上下文，后一页才接得住前一页

每批 prompt 必带三样：
1. 本批 shots 的完整切片
2. **整课的** `overview.goal` / `course_warns` / `course_nono` / 环节分钟表
   （页级 warns 归属只是提示，全表才是事实源——挂不上页的那几条就在这里）
3. 上一批最后一页**最后一块**的原文（接缝）

**失败语义**：任何一批返回 `_error`，已成功的批次照常落盘，失败批次的 `blocks` 置 null
并 exit 1，允许 `--only s11,s12` 重跑。**绝不写一段空旁白蒙混过去。**
