# 范文规则(教师下水文)

每个写作题目**必须配范文**。本文件规定范文的身份、篇幅、位置与红线。

## 一、身份红线(最高优先级,违反即返工)

- 范文一律由生成流程**现场创作**,身份只能是一种:**教师下水文(教师创作的示范例文)**。文首固定标注:`【教师下水文 · 示范】`。
- **严禁**把范文伪装成“某学生作品”“上届学生佳作”;**严禁**冒充名家名篇、教材选文,或编造“选自《XX》”“作者:XXX”等来源。无确证出处 = 不得标注出处,这是本体系反伪造红线在写作课的形态。
- 若用户提供了真实学生作品/真实例文,可用,但须按用户给的来源如实标注,不加工冒充。
- 不建固定范文库:范文必须与本节技法点咬合,逐课现写才能咬得上;库存范文易与教学两张皮。

## 二、事实层红线

下水文是创作,但**创作里引用的事实不归创作管**:
- 涉及客观知识、数据的题目(《国宝大熊猫》《介绍一种事物》《中国的世界文化遗产》等),下水文中的数字、史实只能来自档案、教材资料袋或用户提供的资料;无来源处写占位:`（此处数据以教材资料袋/权威资料为准）`,不得编一个像样的数字。
- 写人记事类下水文写虚构的“我”与日常事件,属正常示范创作,不受此限——但不得虚构可被当真的具体人名、校名。下水文中如需人名,用“小宇”“小林”类通名。

## 三、分级篇幅与形态

| 级 | 形态 | 参考篇幅 |
|---|---|---|
| L1 | 一两句下水句(常含目标句式) | 1–3 句 |
| L2 | 一小段下水段 | 3–6 句 |
| L3 | 一段(围绕一个意思的完整段) | 100–150 字 |
| L4 | 关键段或近成篇 | 200–300 字 |
| L5 | 成篇 | 350–450 字 |
| L6 | 成篇 | 450–550 字 |

篇幅是参考区间,以“够示范本节技法、不淹没学生”为准;宁短勿长,下水文不是炫技场。

## 四、出示位置(防套作)

- **L3 及以上:后置。** 下水文在学生完成自己的构思(支架填写)**之后**、动笔之前出示。先有学生自己的材料,再看老师怎么写,防止全班套写下水文。
- **L1–L2:可前置。** 写话阶段仿写本身就是教学目标,例句/下水句可在动笔前出示并带读。
- 出示后必须有 1–2 个指向性问题,让学生自己发现下水文如何落实本节技法(如:“老师这段里,哪几句是围绕‘爱笑’这一个意思写的?”)。
- 作后评改环节回指下水文:评价标准里的“优秀进阶”档可用下水文作参照,但明确告知“写出你自己的,不用像老师的”。

## 五、咬合检验

下水文写完自问一句:**本节技法点的每一个要素,在这篇下水文里都能被学生一眼指出来吗?** 指不出来 = 范文与教学两张皮,重写下水文(而不是改技法点)。

注意"每一个要素"——若本节技法是个多件套(如观察日记的"对比 + 变化词 + 具体细节"三件套、写人的"外貌 + 一件事 + 性格"等),下水文要把**每一件**都示范到,不能只演示主干、漏掉其余。反例:绿豆观察日记的下水文只写了"对比"和"具体细节",却没出现"渐渐地/由……变成……"这类变化词,等于本课三招只示范了两招——学生在范文里找不到第三招的样子。补法:就地把缺的要素嵌进已有句子(如"它由圆滚滚的一整颗,渐渐裂开了口子"一句即补上变化词),不必另起一段。配套地,讲解环节(关键词对照、教师小结)最好逐一点出每个要素落在哪句,使要素"可被指认"落到实处。

## 六、可信度自检(下水文写完通读一遍,逐条问)

下水文最容易出的不是格式错(机器能查),而是**"读着假"**——逻辑、设定、风格、知情边界上的破绽,只有人读才发现。写完通读一遍,逐条问:

1. **逻辑成立吗?** 每句的因果/推论站得住吗?(反例:"那边四季如春"推不出"你穿得惯短袖吗";"九个月、九年"两个数字并列费解)
2. **符合人物设定吗?** 虚构人物的来历、地理流向、身份关系前后自洽吗?(反例:给一个从宁波搬走的学生写信,却向他科普"宁波冬天冷"——他在宁波长大,这话假)
3. **知情边界对吗?** 每个细节,说话人凭他的身份**真能知道**吗?(反例:老师未必知道某个学生最爱吃什么水果——这是家长、同学才掌握的私人偏好;老师该惦记的是"在新学校习不习惯"这类校园情境里天然会有的关心)
4. **调子克制不表演吗?** 写真实情感时忌拟人升华、金句式雕琢、层层铺陈的抒情;用具体的事和平实的话承载情感,惦记藏在话里,不挂在嘴上。(反例:"满嘴红的、数数吃了几颗""位置还是那个位置,只是换了一个人在用心地画"——刻意煽情,像在表演想念)
5. **素材间事实一致吗?** 下水文与示范填表、PPT 反例/对照句若共用同一例子,共享事实必须前后一致:日期与星期对得上、"第 N 天"与日历步长对得上、数字/人名/称呼不矛盾、修改符号等画法描述在符号表与示范参考里说法统一。

任一条不过 = 就地改顺(改下水文,不是改技法点)。这五问全部是引号/星号机器自检覆盖不到的盲区,是"讲解自洽"红线在写作课的完整形态。
