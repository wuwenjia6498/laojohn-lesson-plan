# 示范文规则(教师示范文 · 现行条文)

> 来历、实测反例与留痕全部下沉到 `history/model-essay-history.md`(生成不读);本文件只留判据与判法。checklist D 组、workflow-engine ④、review-rubric 维三只列查项与做法;判据改动以本文件为准,改本文件须同步三处的复述句。

## 〇、一屏卡(生成时先读这一屏,其余按需翻)

**动笔前八条**
1. 身份只能是 `【教师示范文】`,现场创作,不冒充学生/名家/教材,不编出处(§一)。
2. 客观数据、史实只来自档案/资料袋/用户资料,无来源写占位(§二)。
3. 篇幅对齐本级整篇区间,单点示范克制在句段级(§三)。
4. 本课技法的每个要素都在文里可被一眼指认——**不少也不多**,不顺手教第四招;多出来的那条**先判是不是真工具**,是就补进核心技法行、不是才降为提醒或删(§五 1、3)。
5. 每处特点独一份:换一个人/一件东西这句就不成立(**只管细节层**,不管事例与抽象主题词的绑定);夸张是变形不是计数;样板不低于 ③ 例句;一篇内锚点不复用(§四之四)。
6. 笔法:多用短句和动词、形容词克制、描写生动、情感真挚、收尾适当点题抒发情感或感悟,但不过度升华;**以本级优等学生写得出的句子为上限**,成年人的笔法整篇 ≤2 处(§四之三)。
7. 有可被指认的「把句子写具体」的样子,深度按级不越档(§四之二)。

8. 起笔与落点不与 ③ 反例段同型;题材域按避让卡避重(§五 5、本节末引块)。
9. 「我」＝与学生同龄、过学生当下的日子;成人当下生活(下班／职场／房贷／育儿)不作主素材,教师童年事是例外不是默认(§二)。

**写完后三道**
- 咬合五问(§五)→ 可信度八问(§六,第 8 问＝AI 味五查:标题/开头指示语/结尾落点/时间线断层/省主语)→ 跑机检 E(`assets/essay_audit.py`:篇幅段数实数、引文逐字、旁批表逐格、锚点复用)。
- 旁批表双标准:技法要素全覆盖 + 全篇最见功夫两句必入表(§五 4)。
- L3+ 后置出示,指向性问题分结构层与句子层,投屏与标题不预告答案(§四、workflow ④)。

> **题材域避重**:动笔前看第 1.5 步避让卡的「示范文题材」项(卡从台账该列与 `variation-pools.md` 池 4 算出,不整读两文件),同年级连续两篇题材域不同,想象类换设定域;定稿后写进指纹块。

## 一、身份红线(最高优先级,违反即返工)

- 示范文由生成流程**现场创作**,身份只有一种:教师示范文,文首固定标注 `【教师示范文】`。
- **严禁**伪装成学生作品/上届佳作,**严禁**冒充名家名篇、教材选文,或编造“选自《XX》”“作者:XXX”。无确证出处 = 不标出处。
- 用户提供的真实学生作品/例文可用,按用户给的来源如实标注。
- 不建固定示范文库:逐课现写才能与本节技法咬合。

## 二、事实层红线

- 涉客观知识、数据的题目,示范文中的数字、史实只能来自档案、教材资料袋或用户资料;无来源写 `（此处数据以教材资料袋/权威资料为准）`,不得编一个像样的数字。
- 写人记事类写虚构的“我”与日常事件不受此限,但不得虚构可被当真的具体人名、校名;人名用“小宇”“小林”类通名。
- **「我」的默认设定＝与学生同龄(2026-09-14 立)**:身份标注只有一种(§一,不松),但文里的**「我」默认就是一个本级学生**,过的是学生当下的日子——家、学校、小区、同学、父母祖辈、常去的地方、当下的器物。出示时明说这是老师写的、写的是你们这个岁数(话术见 `workflow-engine.md` ④)。
- **素材域红线:成人当下生活不得作整篇主素材**。下班上班加班、职场同事、房贷装修、育儿、成年社交,以及成年人才有的感慨(“住了三年才算住进来”),一律不作示范文的主线素材。**理由不是它假,是学生照着它找自己的素材时只能编**——这正是示范文最不该诱导的事。零星出现按 §四之三 4 的「成年人的笔 ≤2 处」计。
- **教师童年事＝例外出口,非推荐款**:只在同龄「我」确实写不了的题目上用(罕见),用时避开年代物(粮票、河边洗碗、跳皮筋)并守 §六第 2 问的过去锚。默认不走这条路——年代感太强,孩子读来陌生(2026-09-14 用户拍板)。

## 三、分级篇幅与形态(两套口径,各管各的)

**A. 整篇示范文**(构思后、动笔前出示的完整参照):

| 级 | 整篇篇幅 |
|---|---|
| L1–L2 | 50–150 字 |
| L3 | 300 字左右 |
| L4 | 400 字左右 |
| L5 | 450–500 字 |
| L6 | 500–600 字+ |

**B. 单点示范 / 局部练笔示范**(作中只演一个技法点的句/段,不成篇):

| 级 | 形态 / 篇幅 |
|---|---|
| L1 | 示范句 1–3 句 |
| L2 | 示范段 3–6 句 |
| L3 | 一段 约 120–180 字 |
| L4 | 一段 约 180–250 字 |
| L5 | 一两段 约 250–350 字 |
| L6 | 两段 约 300–400 字 |

- L1–L2 以单点示范句/段为主,不另写成篇示范文;L3+ 两者都要(B 配一次局部练笔只攻一个点,A 在动笔前出示)。
- “宁短勿长”约束的是不超过本级上限:整篇对齐区间即可、不必再砍;单点不得逼近整篇。

## 四、出示位置(防套作)

- L3 及以上**后置**:学生填完支架之后、动笔之前出示;L1–L2 可前置带读。
- 出示后必有 1–2 个指向性问题,让学生自己发现技法怎么落实;作后评改回指示范文(**「写出你自己的,不用像老师的」这句 2026-09-22 起停写**——用户判为废话,回指示范文照旧,只是不再加这句叮嘱)。
- **投屏与标题不预告答案**:指向性问题的答案不得已在三处之一:① 此前已投屏且未收起的件(投屏标题、教师当众填的那张表、旁批表、示范卡);② 同一环节内此前的师话;③ 问句本身(自带答案的是非问)。答案已给的改成转化问(卡上关键词到文里长成几段、多出来的是什么)。口径与 `review-rubric.md` 跨维九「答案已给」一致;做法见 `workflow-engine.md` ④。
- **本单元课文佐证:匹配则引**——先判配不配,不配不引不硬上;只点篇名 + 概括写法,一句带引号“原文”都不输出;篇名与写法要点只从 `unit-texts.md` 取;卡位、边界、`UNIT-TEXT-DECISION` 留痕见 `workflow-engine.md` ③。课文是补充,教师示范文仍是主样。

## 四之二、示范“怎么写具体”,不止“结构对”

- 文里要有该级可被一眼指认的基础描写手法:把抽象的“美/好/热闹”换成可感的颜色、形状、声音(拟声词)、气味、触感,以及最基础的一个比喻。
- 指向性问题分两层:结构层(验主技法)+ 句子层(“这一句为什么让你一下‘看见’了?”),讲解逐句点出。
- 深度按级不越档(technique-levels.md):L1–L2 仿一句;L3 颜色/形状词 + 拟声词 + 一个简单比喻;L4+ 可到神态、动作、语言。不新立技法点、不单独计入技法数。

## 四之三、笔法锚点(自写风格示例 · 对齐笔法,严禁复用内容)

生成前读一遍下面两段,对齐的是**写法**,不是内容(非名篇、非课文、不进详案;L1–L2 不设档)。

**L3–L4 档 · 白描动作特写**:

> 弟弟蹲在门口系鞋带。两根带子在他手里绕了三圈,一拉,散了。他把带子抻直,重新交叉、压住、穿过去,手指头都用上了劲。这回成了个疙瘩。他盯着那个疙瘩看了两秒,干脆把鞋一脱,拎在手里,光着袜子跑了。

**L5–L6 档 · 克制的情感流露**:

> 爷爷的自行车还停在楼道里。车把上缠的胶布卷了边,后座那块木板是他自己钉的,边角磨得发亮。我路过的时候按了一下车铃。铃还响,还是从前那个声音。我站了一会儿,把车挪正了些,上楼了。

硬规则:
1. 示例的题材、任何一句、任何比喻严禁出现在示范文里(机检 E ④ 查)。
2. 四条笔法:短句多动词多、一个动作拆几步写;形容词只在必要处点一两个(五感词按技法正常用);情感不直接命名,让动作和物件替它说;**收尾两选一**——① 不升华,停在最后一个动作上、留余味;或 ② 适当点题抒发情感或感悟,但不过度升华。两种都是正确写法,按题目与本课技法选;**「不升华」不等于「不准点题」**(见 `lesson-structure.md` §三 红线第 10 条)。
3. L3–L4 向白描档对齐;L5–L6 兼取两档,情感类重点对齐克制档。
4. **够得着**:以本级优等学生写得出的句子为上限,逐句问「这句换本班写得最好的那个学生,写得出吗」;写不出的是成年人的笔(散文腔修辞、成人生活细节、超龄词汇),整篇 ≤2 处。**够得着分两层**:本条管句子层(这句本班最好的学生写得出吗),素材层(这件事本班学生遇得上吗)见 §二「我」的默认设定。够不着时不把示范文写差,备选是再给一篇够得着的——只能是附录讲评块挑出的本班真作(＿＿＿ 占位),不得虚构学生作品。
5. 与 §六 的关系:本节是动笔前定调,§六是写完验收,两道都过;与技法咬合冲突时咬合优先。

## 四之四、例子的特征必须独一份(管全篇所有教师自拟例子)

适用范围:①开场例句、③A/B 两段与三档说法、④示范文每一处特点、⑤构思支架教师示范填——凡教师自拟给学生当样子看的例子。

1. **独一份**:把这个特征安到另一个人/另一件东西身上,成不成立?成立就换。合格的是具体锚点,不是形容词:

| ✗ 通用款 | ✓ 具体锚点 |
|---|---|
| 嗓门大／不爱笑／走路快／很严厉／做事认真 | 十个指头上洗不掉的颜色／外套上两个从来没瘪过的口袋 |
| 什么都要当场试一试／讲到要紧处压低声音 | 笔一到手就别在头发上／袖子挽到胳膊肘一年到头没放下来 |

   通用款会让课自相矛盾:老师示范一个谁都能安上的例子,转头要求学生「换成别人也成立的话写了白写」。状物、写景同理(「很漂亮的杯子」vs「杯盖上磕掉一块漆」)。
   > **适用域**:本条管的是**例子的特征／细节选得够不够具体独特**(细节层),判掉的是形容词式通用款。它**不管「事例与抽象主题词的因果绑定」**(选材层)——写《诚信让生活更美好》这类题,事例换个词「也成立」是这类题材的常态、不是毛病,拿本条去判会误杀合格素材。抽象题材里「独一份」落在**事里那个具体画面**(那个关口、那个动作、那一句),不落在「换掉主题词还成不成立」。选材层的分型判据见 `workflow-engine.md` 环节③「筛选类判据须覆盖本题全部合法话题」。
2. **夸张 ≠ 计数**:漫画式放大是物理上不可能、心理上极准的变形;「问了八遍我们数过」是计数,没放大也没笑点。放大之后紧跟一笔按回真事(「跟到水池边去看,水是清的」),把「放大只放大真事」演给学生看。
3. **样板不得低于例句**:④ 整篇示范文的有趣度与独一份程度不得低于 ③ 的小片段;判法＝并排读,问「哪一段更让人想笑、更认得出人」。
4. **一篇之内锚点不复用**:①开场例句／③A、B 段与三档说法／④示范文两处特点／⑤构思卡示范填,锚点互不重复。

## 五、咬合检验(写完自问)

1. 本节技法点的每一个要素,都能被学生在文里一眼指出来吗?多件套(如「对比 + 变化词 + 具体细节」)要每一件都示范到,缺的就地嵌进已有句子。
2. 有没有可被一眼指认的「把句子写具体/写活」的样子?
3. **要领数上限**:旁批表的行与 ④ 讲解点名的每条「写法/要领/做法」,逐条到提纲表「核心技法」行找对应短语;**找不到的先判是不是真工具**——问一句「这条删掉,学生写这一篇会不会真少一件工具」:是 → **补进核心技法行**(本课确实要教它,只是提纲表漏写);不是 → 降为一句提醒或删。前两问管「不少」,本条管「不多」。**三个出口不可只取后两个**——2026-09-15 四篇评估实测,被判超标的条目多数是真工具(「其余的时候让他的手替他说」「用一个动作替感动说话」),机械按「提醒或删」处理会删掉本课最见功夫那句的生成规则。
4. **旁批表双标准**:① 技法要素全覆盖;② 先不看表,自己挑出示范文最见功夫的两句,再核它们在不在表里——不在就补进去;结构上的呼应(开头挂上、结尾摘下)算一处。
5. **起笔与落点不与 ③ 反例段同型**:第一句的起法、结尾的落点,与被判掉的那段并排读一遍。**判的是「③ 判词实际判掉的那个点」上同不同型,不是形态像不像**——先把 ③ 的判词原话抄出来,问「学生照这堂课念下去,会不会得出『这么起笔／这么收尾＝跑偏』」;会,就改示范文。**两种情形明确不算同型**:① 该特征是 ③ 的正例段与反例段**逐字共用**的(控制变量设计,课堂已把它标为中性);② 该特征**写在本课提纲表「核心技法」行里**(示范文不演它反而违反 §五 1)。命中 ① 或 ② 时不改示范文,改法照立条先例走:把 ③ 的判词落点收准到真正判掉的那一点,并在师话里加一句显式点破(「不是说不许……,老师这一篇也……,差别在于……」)。⚠ **两个口子都是可核对的客观事实、不是判断题**——① 把两段首句原样抄出来逐字比,「差不多」不算;② 到核心技法行找对应短语,找得到才算。唯一的滥用路径是「为豁免而反向往核心技法行补一个短语」,由 §五 3 的「先判是不是真工具」堵住。

答案推荐落成「示范文旁批对照」(逐句标手法落点);详案里只放表本身,不写面向下游的提示。任一条不过 = 重写示范文,不改技法点。

## 六、可信度八问(写完通读一遍逐条问,机器查不到的盲区)

1. **逻辑成立吗?** 每句因果/推论站得住。
2. **符合人物设定吗?** 来历、地理、身份关系自洽;教师第一人称另查**时间锚**——童年事用过去锚(上三年级那年/那年暑假),不混「这个暑假/这学期」等现在锚,收到当下用「前些日子/如今」过桥。
3. **知情边界对吗?** 每个细节,说话人凭身份真能知道。
4. **调子克制不表演吗?** 文辞适宜,不过分使用(排比、拟人升华、金句雕琢、层层铺陈抒情等);抒情适当;让情感藏在事和平实的话里。
5. **素材间事实一致吗?** 与示范填表、反例/对照句共用例子时,日期星期、第 N 天、数字人名称呼、符号画法说法统一。
6. **(想象/续写/看图类专问)没越过「已给信息」的边界吗?** 关键情节只从已给的图/开头长出来;渲染情绪用图内已有细节,不引入图外新事实。查法:逐个关键事实与题目/图组比对。
7. **有没有自犯本课反例的病?** 把 ③ 反例段被判掉的写法列两三条(结论句/说明书式功能罗列/平均用力/换一件也成立),逐条回示范文找同款句,「来历/交代/外形」段最高发;命中即改示范文。冷审端对应 review-rubric 维三「示范文细读三问」①。

8. **AI 味五查(2026-09-22 由四上五《生活万花筒》用户逐条意见立 · 前七问全过也照样命中)**:
   - ① **标题不写事件概括式的直白题**(「电梯停在了半路」「一次难忘的比赛」),起一个与结尾或主线呼应的题目(改后「漫长的十一分钟」,结尾正是「最漫长的十一分钟」)。
   - ② **开头不用「那天／有一次／记得有一回」**——这类指示语要顺承前文才成立,而作文是从头写起的,读者没有「那天」可指;换具体时间锚(上个星期五放学／昨天晚上)。同一改动要同步构思表示范填的「时间」格。
   - ③ **结尾的情绪落点与题面对得上**:《捉蚊趣事》就该落在「趣」上,落到「胳膊还痒着,可是这一晚我睡得很踏实」那是成年人的安宁感。判据＝**把题目盖住读结尾,读出来的是不是这个题目要的那一种情绪**。与第 4 问同向但分工不同:那条管「升华过不过」,本条管「落点对不对路」。
   - ④ **时间线与因果不许断层**:每一处状态变化都要交代(按下紧急呼叫 →「等了几秒钟,喇叭里传出一个人的声音」,不能直接「按钮里传出一个声音」——按钮里怎么会有声音);两处数字必须对得上(说「五分钟就到」、实际十一分钟、八个灯「数到第三遍」不可能耗掉五分钟 → 要么改数字、要么补等待描写);**同一事实在师话里复述时不许生出歧义**(「最后一共等了十一分钟」会读成等救援等了十一分钟,改「从电梯停住到被扶出来前后一共十一分钟」)。
   - ⑤ **示范文与 `〔材料〕` 里的第一人称叙述不省主语**:「要是一直不开怎么办」「五分钟就到」「这回可别再飞了」→「电梯要是一直不开,怎么办」「我们五分钟就到」「这只蚊子可千万别再飞走了」。学生照着它学写句子,红线第 7 条① 的省主语禁令在这两处同样适用;反向刹车只豁免 `参考：` 学生话轮的口语粗糙,不豁免示范文与自拟材料。

任一条不过 = 就地改顺(改示范文,不是改技法点)。第 6 问仅想象/续写/看图类需过,其余每篇必过;第 8 问每篇必过(它捞的是「前七问全过、读着仍有 AI 味」的那一层)。

## 七、示范文一动的连改位(改稿时查)
