# 范文规则(教师示范文)

每个写作题目**必须配范文**。本文件规定范文的身份、篇幅、位置与红线。

> **题材域避重(反同质化)**:动笔写示范文前,先查 `variation-ledger.md` 台账「示范文题材」列 + `variation-pools.md` 池 4——同年级连续两篇示范文题材域不同(别每篇都取「老师小时候……」同一个素材库),想象类换设定域;定稿后把本篇题材域+具体素材写进文件尾指纹块。题材域只管素材来源分散,本文件的身份/事实红线一条不松。

## 一、身份红线(最高优先级,违反即返工)

- 范文一律由生成流程**现场创作**,身份只能是一种:**教师示范文(教师创作的示范例文)**。文首固定标注:`【教师示范文】`。
- **严禁**把范文伪装成“某学生作品”“上届学生佳作”;**严禁**冒充名家名篇、教材选文,或编造“选自《XX》”“作者:XXX”等来源。无确证出处 = 不得标注出处,这是本体系反伪造红线在写作课的形态。
- 若用户提供了真实学生作品/真实例文,可用,但须按用户给的来源如实标注,不加工冒充。
- 不建固定范文库:范文必须与本节技法点咬合,逐课现写才能咬得上;库存范文易与教学两张皮。

## 二、事实层红线

示范文是创作,但**创作里引用的事实不归创作管**:
- 涉及客观知识、数据的题目(《国宝大熊猫》《介绍一种事物》《中国的世界文化遗产》等),示范文中的数字、史实只能来自档案、教材资料袋或用户提供的资料;无来源处写占位:`（此处数据以教材资料袋/权威资料为准）`,不得编一个像样的数字。
- 写人记事类示范文写虚构的“我”与日常事件,属正常示范创作,不受此限——但不得虚构可被当真的具体人名、校名。示范文中如需人名,用“小宇”“小林”类通名。

## 三、分级篇幅与形态

示范文按用途分**两套口径**,篇幅各管各的——别再用一个长度套两件事:

**A. 整篇示范文**——学生构思(支架填写)后、动笔前出示的完整参照,篇幅对齐本年级整篇习作字数要求:

| 级 | 整篇篇幅 |
|---|---|
| L1–L2 | 50–150 字 |
| L3 | 300 字左右 |
| L4 | 400 字左右 |
| L5 | 450–500 字 |
| L6 | 500–600 字+ |

**B. 单点示范 / 局部练笔示范**——作中指导时只演**一个**技法点的句/段,配学生即时小练笔;不成篇:

| 级 | 形态 / 篇幅 |
|---|---|
| L1 | 示范句 1–3 句 |
| L2 | 示范段 3–6 句 |
| L3 | 一段 约 120–180 字 |
| L4 | 一段 约 180–250 字 |
| L5 | 一两段 约 250–350 字 |
| L6 | 两段 约 300–400 字 |

**两套口径按年级分工,不必每级都凑齐两栏:**

- **L1–L2 以单点示范句/段为主**:写话阶段整篇本就只有 50–150 字、与单点示范基本重合,**不单独要求另写一篇成篇范文**——一两句/一小段示范句即承担「整篇」职能。
- **L3+ 两者都要**:作中指导用 B(单点示范带一次局部练笔,只攻一个技法点),学生动笔前再出 A(整篇示范文)作完整参照,让学生看见「本年级一篇完整习作该有的样子」。

篇幅是参考区间,以“够示范本节技法、不淹没学生”为准。**“宁短勿长”约束的是不超过本级上限**:整篇示范文对齐字数要求即是该级应有的完整篇幅、不必再砍短;单点示范则克制在 B 表区间、**不得逼近整篇**(否则就不是「单点」了)。示范文不是炫技场。

## 四、出示位置(防套作)

- **L3 及以上:后置。** 示范文在学生完成自己的构思(支架填写)**之后**、动笔之前出示。先有学生自己的材料,再看老师怎么写,防止全班套写示范文。
- **L1–L2:可前置。** 写话阶段仿写本身就是教学目标,例句/示范句可在动笔前出示并带读。
- 出示后必须有 1–2 个指向性问题,让学生自己发现示范文如何落实本节技法(如:“老师这段里,哪几句是围绕‘爱笑’这一个意思写的?”)。
- 作后评改环节回指示范文:评价标准里的“优秀进阶”档可用示范文作参照,但明确告知“写出你自己的,不用像老师的”。
- **课文/名篇片段可作补充范例(读写打通,推荐)**:教师示范文之外,讲技法时可引一段确凿课文/名篇佐证该技法(如写景引《海滨小城》《富饶的西沙群岛》某段)。**真实性不豁免**:确凿原文方可逐字引用并注明篇名;拿不准逐字原文时只概括其写法、不输出带引号的“原文”(伪摘录禁令照旧)。课文范例是补充,教师示范文(情境①产物)仍是主样、非每篇必引课文。

## 四之二、示范文要示范“怎么写具体”,不止“结构对”

技法点多落在**结构层**(围绕一个意思、按顺序、起因经过结果……),但学生最常卡在**句子层**——“结构会搭、句子写不活”,只会写“很美/很热闹”、罗列景物却立不起画面。所以**示范文不能只示范结构,还要让学生在文里看见“怎么把一句话写得让人‘看见’”**:

- 示范文里要有**该级可被一眼指认的基础描写手法**——把抽象的“美/好/热闹”换成**可感的具体东西**:看得见的颜色、形状,听得见的声音(拟声词),闻得到、摸得到的感觉,以及最基础的一个比喻。
- 出示后的指向性问题要**分两层**:结构层(中心句几次/几样景物/什么顺序——验主技法)+ 句子层(“这一句为什么让你一下‘看见’了?”——引学生发现把“美”换成了具体可感的东西)。讲解时把这样的句子逐句点出来。
- **深度按级走,不越档**(遵从 technique-levels.md):L1–L2 仿一句;L3 颜色/形状词 + 拟声词 + 一个简单比喻;L4+ 可到神态、动作、语言。**这是“主技法 + 五感支架经范文示范落地”的呈现,不是新立技法点,不单独计入技法数。** 这一手专治第2节“动笔时只会写‘很美’”的门槛。

## 四之三、笔法锚点(自写风格示例 · 对齐笔法,严禁复用内容)

示范文的「读着不假」,一半靠第六节六问的事后验收,一半靠下笔时有个具体的「好的样子」可对齐。下面两段是**为对齐笔法而自写的风格示例**(非名家原文、非课文、不进详案),生成示范文前读一遍,对齐的是它们的**写法**,不是它们的内容。(L1–L2 暂不投产,不设锚点档。)

**L3–L4 档 · 白描动作特写**(看一个动作怎么全靠动词立起来):

> 弟弟蹲在门口系鞋带。两根带子在他手里绕了三圈,一拉,散了。他把带子抻直,重新交叉、压住、穿过去,手指头都用上了劲。这回成了个疙瘩。他盯着那个疙瘩看了两秒,干脆把鞋一脱,拎在手里,光着袜子跑了。

**L5–L6 档 · 克制的情感流露**(情感一个字不点破,全在物件与动作里):

> 爷爷的自行车还停在楼道里。车把上缠的胶布卷了边,后座那块木板是他自己钉的,边角磨得发亮。我路过的时候按了一下车铃。铃还响,还是从前那个声音。我站了一会儿,把车挪正了些,上楼了。

硬规则:

- **对齐笔法,不对齐内容**:示例中的题材(系鞋带/自行车)、任何一句、任何比喻,严禁出现在任何示范文里;交付前对照本节示例全文比对(checklist D 组有对应查项)。
- 锚定的四条笔法:① 短句多、动词多,一个动作拆成几步写;② 形容词只在必要处点一两个(五感词按技法正常用,不算堆叠);③ 情感不直接命名(「难过」「想念」不出现在情感落点处),让动作和物件替它说;④ 收尾不升华,停在最后一个动作上即可。
- 两档各管各的:L3–L4 示范文向白描档对齐(在此之上按技法正常加进颜色/拟声/简单比喻);L5–L6 兼取两档,情感类任务重点对齐克制档。
- 本节示例只写给生成器看,不作为课文/名篇引进详案(它们不是名篇,也不得冒充);「笔法锚点」是内部叫法,不进产物。
- 与第六节六问的关系:六问是写完后的验收,本节是动笔前的定调,两道都过;与技法咬合冲突时,咬合优先(示范文首先要把本课技法演全,笔法是「怎么写得不假」的底色)。

## 四之四、例子的特征必须独一份(2026-08-17 立 · 管全篇所有教师自拟例子)

> **适用范围不限于示范文**:①开场例句、③审题辨析的 A/B 两段与三档说法、④示范文的每一处特点、⑤构思支架的教师示范填——凡是**教师自拟、给学生当样子看**的例子,一律受本节四条判据约束。判据的单一源在此,`workflow-engine.md` 环节③、`variation-pools.md` 池 4、`checklist.md` D 组只指向、不复制。

**判据一:独一份(最要命的一条)。** 写下例子的特征后先问一句——**把这个特征安到另一位老师(另一件东西、另一个人)身上,成不成立?** 成立就得换。合格的特征是**具体锚点**,不是形容词:

| ✗ 通用款(换个人照样成立) | ✓ 具体锚点 |
|---|---|
| 嗓门大／不爱笑／走路快／很严厉／做事认真 | 十个指头上洗不掉的颜色／工装外套上两个从来没瘪过的口袋 |
| 什么都要当场试一试／讲到要紧处压低声音 | 笔一到手就别在头发上／袖子挽到胳膊肘一年到头没放下来 |

**这一条之所以要命,是它会让课自相矛盾**:老师亲手示范一个「谁都能安上」的例子,转头又要求学生「凡是换成别人也成立的话,写了也白写」。写人类课次尤其易踩,但状物、写景同理(「很漂亮的杯子」vs「杯盖上磕掉一块漆」)。

**判据二:夸张 ≠ 计数。** 漫画式放大是**物理上不可能、心理上极准**的变形;**精确统计不是夸张,写出来既没放大也没有笑点**。
- ✗「一节课问了八遍‘听懂了没有’,我们数过」「一学期见过他笑三次」——全在现实范围内
- ✓「洗手时从指缝里流下去的水一定是彩色的」「那两个口袋底下通着实验室」「我怀疑那两只袖子是缝上去的」
- 教材档案给的官方示例正是这个机制:「头顶都快碰到天花板了」「声音能穿透三堵墙」(`archive/grade5-vol1.md` 第 154 行)
- **放大之后要收得住**:紧跟一笔把那句变形按回真事(「几个同学特意跟到水池边去看,水是清的」),既保住笑点,又不让假话留在纸上——这一手同时把「放大只放大真事」演给了学生看。

**判据三:样板不得低于例句。** ④ 的整篇示范文是学生要照着写的**样板**,它的有趣度与独一份程度**不得低于** ③ 里那些小片段。实测倒挂过:③ 的正例(笔别在头发上、找笔找到自己头上)明显比 ④ 的整篇(嗓门大＋当场做实验)好笑,学生看完样板反而降级。**判法**:把 ③ 的正例与 ④ 的示范文并排读一遍,问「哪一段更让人想笑、更认得出人」。

**判据四:一篇之内锚点不复用。** ①开场例句／③A、B 段／三档说法／④示范文的两处特点／⑤构思卡示范填,这几处的锚点**互不重复**。实测踩过:开场例句用「袖子挽到胳膊肘」,⑤构思卡的长相格又填「袖子老挽到胳膊肘」,同一个锚点一课用两次。

> **留痕(为什么写得这么细)**:2026-08-17 生成五上《“漫画”老师》,教师自拟例子被用户连否四次——开场例句两次(「只看见一阵风」不好笑、「问了八遍数过」不是夸张)、③正例一次(「讲到要紧处压低声音」是通用款、且样板里没有本课第三条)、④示范文两次(特点一「嗓门大」、特点二「什么都当场试」皆通用款)。**五次返工的根因全部落在上面四条里**;判据不写下来,下一篇照样从形容词出发造例子。

## 五、咬合检验

示范文写完自问两句:
1. **本节技法点(结构层)的每一个要素,在这篇示范文里都能被学生一眼指出来吗?**
2. **这篇示范文里有没有可被学生一眼指认的“把句子写具体/写活”的样子(写具体层)?**

> 这两问的答案,**推荐落成一份「示范文旁批对照」**(逐句标出手法落点,小表格或逐句师话均可):既是写完后的自检,又是课上句子层呈现;它也能作下游 PPT「原文→批注」的旁批素材(见 workflow-engine.md 环节④),但**这层下游用途只生成器知道、不写进详案正文**——详案里只放旁批表本身,不写“此表可作 ppt 素材/供 ppt-draft 出图”这类提示。

任一句答“不能/没有” = 范文与教学两张皮,重写示范文(而不是改技法点)。

注意"每一个要素"——若本节技法是个多件套(如观察日记的"对比 + 变化词 + 具体细节"三件套、写人的"外貌 + 一件事 + 性格"等),示范文要把**每一件**都示范到,不能只演示主干、漏掉其余。反例:绿豆观察日记的示范文只写了"对比"和"具体细节",却没出现"渐渐地/由……变成……"这类变化词,等于本课三招只示范了两招——学生在范文里找不到第三招的样子。补法:就地把缺的要素嵌进已有句子(如"它由圆滚滚的一整颗,渐渐裂开了口子"一句即补上变化词),不必另起一段。配套地,讲解环节(关键词对照、教师小结)最好逐一点出每个要素落在哪句,使要素"可被指认"落到实处。

## 六、可信度自检(示范文写完通读一遍,逐条问)

示范文最容易出的不是格式错(机器能查),而是**"读着假"**——逻辑、设定、风格、知情边界上的破绽,只有人读才发现。写完通读一遍,逐条问:

1. **逻辑成立吗?** 每句的因果/推论站得住吗?(反例:"那边四季如春"推不出"你穿得惯短袖吗";"九个月、九年"两个数字并列费解)
2. **符合人物设定吗?** 虚构人物的来历、地理流向、身份关系前后自洽吗?(反例:给一个从宁波搬走的学生写信,却向他科普"宁波冬天冷"——他在宁波长大,这话假)**教师第一人称示范文另查时间锚**:通篇是谁的人生、处在人生哪个时点,一读便知——写老师童年事,用「上三年级那年/到了四年级/那年暑假」等过去锚,**不得混用「这个暑假/这学期」等现在锚**(2026-07 实测反例:「三年级我吵着要学书法……这个暑假我说要背古诗……这学期的毛笔我又拿起来了」——童年年级与眼下学期混排,教师叙述者读成了在读小学生);童年事收到当下,用「前些日子/如今」自然过桥。
3. **知情边界对吗?** 每个细节,说话人凭他的身份**真能知道**吗?(反例:老师未必知道某个学生最爱吃什么水果——这是家长、同学才掌握的私人偏好;老师该惦记的是"在新学校习不习惯"这类校园情境里天然会有的关心)
4. **调子克制不表演吗?** 写真实情感时忌拟人升华、金句式雕琢、层层铺陈的抒情;用具体的事和平实的话承载情感,惦记藏在话里,不挂在嘴上。(反例:"满嘴红的、数数吃了几颗""位置还是那个位置,只是换了一个人在用心地画"——刻意煽情,像在表演想念)
5. **素材间事实一致吗?** 示范文与示范填表、PPT 反例/对照句若共用同一例子,共享事实必须前后一致:日期与星期对得上、"第 N 天"与日历步长对得上、数字/人名/称呼不矛盾、修改符号等画法描述在符号表与示范参考里说法统一。

6. **(想象/续写/看图类专问)示范文没越过"已给信息"的边界吗?** 想象与续写类的本课红线不是"写具体"(那是通用项),而是**"想得合理 = 不脱离题目/图组已经给定的信息"**——这类文体有两个专属失守点,生成时都要防:① 学生端的"脱线式"发展(如续写里"小狗其实会魔法,带主角飞走了"——把前文设定丢开),这在讲法里作反例点破即可;② **更隐蔽的是示范文自己越界**——老师的示范文里悄悄添了图组/题面没给的关键事实(2026-07 实测反例:三上《续写故事》前三幅图只有"院子、纸箱、小狗",示范文台词却让主角说"被人丢在墙角,还下过雨呢"——雨是图外事实)。本课既然在教"据图合理推想、不凭空添",**示范文更须以身作则**:一切关键情节只从已给的图/开头长出来,要渲染可怜、紧张等,用图内已有的细节(缩成一团、尾巴摇)去写,不引入图外的新事实。查法:把示范文每个关键事实与题目/图组比对,凡"图里没有、题面没给"的设定,删或换成图内细节。

任一条不过 = 就地改顺(改示范文,不是改技法点)。这六问全部是引号/星号机器自检覆盖不到的盲区,是"讲解自洽"红线在写作课的完整形态(第 6 问仅想象/续写/看图类需过,其余文体略过)。
