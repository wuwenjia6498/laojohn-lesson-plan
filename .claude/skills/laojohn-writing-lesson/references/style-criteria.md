## 一、总判据（一票裁决，其余各条都是它的展开）

**这句话如果印在教材上、写进正式教案，由另一位老师在课堂上照读，会不会别扭？会，就改。**

反向刹车：**保留原意和亲切感，只换表达方式**；不把学生听得懂的话改成成人腔（「请同学们认真观察物品表面的磨损特征」是过度书面化，同样不合格）。目标是「规范而自然」，不是「文绉绉」。

## 二、八类改法（1–7 类取自 2026-08-31《猜猜他是谁》真实前后对照；第 8 类 2026-09-01 从 framework §7.2 收编）

### 2. 引出式破折号改冒号（AI 痕迹头号形态）

「破折号引出下文」是模型高频句式，润色版**成批**改为冒号或句号；但**插入语破折号保留**。

| 原稿 | 润色后 |
|---|---|
| 规则很简单——老师来描述一个人 | 规则很简单：老师描述一个人 |
| 第一段——「我的同桌……」 | 第一段：「我的同桌……」 |
| 最关键的一步在这里—— | 最关键的一步在这里： |
| 删除号——写多了或写错的字…… | 删除号：写多了或写错的字…… |
| 这就是今天最要紧的写法——（悬念收束） | 这就是今天最重要的写法。（句号收束，下一段接着讲） |

**保留的**：「因为老师说的这几样——蓝色紧身衣、红披风、会飞、爱救人，还有胸前的大字母——合在一个人身上，就只有他了」（真插入语，两端可摘除）。
判法：把破折号后半截删掉句子仍完整＝插入语，保留；删掉就断头＝引出式，改冒号。

### 3. 省主语祈使补成礼貌完整句

| 原稿 | 润色后 |
|---|---|
| 师：好，说说看——你心里那个人…… | 师：好，请几位同学说一说：你心里的那个人…… |
| 把它记在心里，待会儿就用得上 | 请把它记在心里，接下来就会用到 |
| 好，停笔！ | 好，请停笔。 |
| 先收好你的特点卡 | 请先收好你的特点卡 |
| 你听／你看／注意看 | 大家听／大家看／请注意看 |
| 想想专属于他的那个瞬间 | 想一想专属于他的那个瞬间 |

单字动词一律双音化：**想想→想一想、说说→说一说、看看→看一看、听听→听一听**。

### 8. 空泛点题句说清具体变化（2026-09-01 从 framework §7.2-9「叙述腔的口头修辞」收编）

「这一下就不一样了」「一切都变了」这类句子只宣布“有变化”、不说变化是什么——是叙述腔的口头修辞，在师话里既撑不起讲解、也给不了学生可模仿的东西。改法＝**就地补上具体变化**，不是删掉了事。

| 原稿 | 润色后 |
|---|---|
| 你们听，这一下就不一样了。刚才说的那些磨掉的漆…… | 大家听，这一说就不一样了。刚才说到的磨掉的漆……（后文本就接着具体细节，故只需把“一下”落到“一说”这个动作上） |
| 一切都变了 | 说清哪一处变了、变成了什么样 |

判据：把这句删掉，听课的人少知道了什么？什么都没少＝空泛点题，就地补具体。

## 三、保留边界（润色版实际没动的 · 比任何规则条文都真实）

1. **示范文与学生例段一字不动**（错别字与标点除外）：「他呀，一刻也闲不住」「我同桌有一手画画的本事」「急得直抓头发」「风风火火的劲儿」全部保留——生活化语气是这两类文字的**设计要求**，正文引用它们时原样引用。`参考：` 学生话轮同理。
2. **⚠ 结课抒情句被用户保留**：「以后再翻开，读着你写的这几行字，那个同学的样子就又回来了」（红线 6⑥ 禁用表里的原例句）在润色版里**原样保留**、只改了前半句的「写工整→誊写工整」。**红线 6⑥ 的整段禁在用户实操里从宽**——冷审 Pass B 对 6⑥ 只标注、不激进删（原文提及的 Pass C 已于 0901 撤销），删不删由用户逐处拍板。
3. **⚠「好就好在」收尾骨架被保留**（只把「本事」改成「方法」）——**跨篇同构不在单篇润色的射程内**，仍归池 9 与 `batch_ngram_scan` 横审管，不归本卡。
4. 拟声词、必要的感叹引用（「我知道！我知道！」）保留。
5. **短指令的口径（2026-09-01 拍板）**：收敛语气标点并**加礼貌前缀**——「好，停笔！」→「好，请停笔。」；但**不加长成句**（「请停笔」不改成「请大家停下手中的笔」）。存量已有的裸短指令（「停一停。」）不专项回改、不算违规，下次 Pass B 顺手统一。

### 五类识别判据（编号沿用原卡 ①③④⑤⑥，②号空缺不补）

**第 ① 类 · 生僻口语与地域词（主症）** —— 核心问法：**这话像不像一位语文老师在课堂上说的？**
- **①-a 地域词**（南北方是否通用）：记岔了、合不合身、别搁着、讲头、盼头、不评高低、不糙、上头、里头、这会儿、来劲、啥、捋顺、搭把手、找着、不重样、掂量、各人、那会儿、管它叫。
- **①-b 表达罕见**（意思能懂，课堂与书面都少见）：心里过的那两三处、末了又被丢在那儿不管、不忙想、往哪儿去、留一件事在心上、摆开、上收住、单给、两头、最欠的、判成没成。
- **①-c 口吻失当**（不是老师在这个场合会说的话）：先说一句公道话、那是一句正正经经的话、你比谁都清楚、有本事一路改下去、大概率、仅凭肉眼观察、进行放大描写、做一番辨析。
- **只在 `师：`、`（教师总结）`、`〔…〕`／`[…]` 提示行里查**；豁免见 §三。
- ⚠ **「菜市场」不是地域词，不要改**（08-30 复核撤销：它是普通话通用词、「菜场」才偏江浙沪）。**审稿人的批注里会混有个人方言偏好，判「地域词」先问一句「这是南北不通用，还是只是我不习惯」。**

**第 ③ 类 · 教学用语不严谨（08-30 实测最普遍的一类）**
- **③-a 指代错位**：用「它」指文章却接人的行为动词；并列结构两支不同类。
- **③-b 术语混用（头号病症）**：同一技法一篇内换名字；同一物在「习作／作文／文章／稿子」间跳；同一张表的单位在「栏／格／行」间跳。→ 现由指纹块「本篇术语表」（生成时定名）＋ tone_gate 术语一致性候选承接。
- **③-c 术语不准**：管习作叫「完成这道题」；「轻声默读」（默读即不出声）；把学生编的情节叫「答案」；数目说错。
- **③-d 判据放空**：列举把标准放宽到失效；评价档位用学生无法自评的形容词（真情实感、语言流畅、生动、到位）→ 改成可数、可指认的判据。
- **③-e 中心宾语残缺**：→ 判据与排查法归红线第 7 条第五形态（`lesson-structure.md` §三），此处不重抄。
- **③-f 教学指令虚动词**：适时启发、引导学生体会、带领学生感受、针对性点评、精准指出、用心感受。**判法：后面紧跟具体动作或具体问句的不算**；后面仍是形容词的才算。

**第 ④ 类 · 冗余** —— 判据：**把这一句／这个括注删掉，教学动作有没有损失？** 没有 → 命中。高发位：互动括注里的附加说明、师话纯前导句（「你听听看」「老师问一个问题」）、同义反复、把已说过的话整块再说一遍。

**第 ⑤ 类 · 视角与预设** —— 师话是否预设了学生的身份或处境：「你家养的那只猫」（预设有猫）、「把习作带回家读给你写的这位家人听」（预设同住）。⚠ 只管身份／处境预设；**预设课堂结果**归红线第 9 条（预演式总结）。

**第 ⑥ 类 · 学生话轮反向失当（08-30 新增）** —— `参考：` 行豁免的是**口语粗糙**，不豁免**书面化**：学生答案写得比老师还书面（「热闹宜人／杂草丛生」），同样破坏拟真。判法：**这句话，这个年级的学生开口说得出来吗？**
