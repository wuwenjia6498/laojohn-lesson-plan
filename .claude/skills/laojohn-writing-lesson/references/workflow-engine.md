# 教学工作流引擎(血肉层 · 强制骨架)

> 本文件取代旧「各段生成要点」,是生成详案教学流程的**强制骨架**。底座不变(课时 2 节 × 45、先导定位、分级、真实性红线、引号星号规则照旧),本文件只管“课怎么走才有血肉”。
> 四大价值观是**硬约束不是建议**:每一份详案都必须能在自检时指认出这四样东西各落在哪个环节。做不到 = 返工。

## 〇、四大价值观(贯穿全程,先记住)

1. **真实情境**:写作必须有真实的社交目的,不是“为交作业而写”。
2. **全感官支架**:先动后写——构思前必有感官唤醒(看/听/摸/玩/演),不是直接发表格。
3. **即时高频反馈**:写完一段就能当堂得到具体的闪光点肯定,不靠课后批改。
4. **表达主权 + 延迟纠错**:初稿只护表达流,绝不打断纠错;所有纠错与优化放到独立修改环节。

下面把它们焊进固定七环节。

## 一、固定七环节骨架(替代旧“导入→填表→讲技法→写→评”)

第 1 节(45 分钟):**① 真实情境抛任务 → ② 全感官唤醒 → ③ 一招技法 → ④ 示范文做样 → ⑤ 构思支架落地**
第 2 节(45 分钟):**⑥ 自由倾吐(护表达流)→ ⑦ 即时反馈 + 延迟纠错修改 + 自然收尾**

时长是参考,可依任务浮动,但每节合计必须 = 45 分钟,七环节不得缺项。

**④与⑤的先后按分级走(遵从 model-essay.md 的示范文出示位置)**:
- **L3 及以上**:推荐 ③技法 → ⑤构思支架(学生先填出自己的素材)→ ④示范文(再看老师怎么把素材连成段),即示范文后置。这样学生带着自己的构思看示范文,既防套写、又正好示范“关键词表→成段”的转化。
- **L1–L2**:④示范文(例句/示范句)可前置到⑤之前,仿写即教学目标。
- 无论先后,④和⑤都在第1节、紧邻,且最好共用同一个例子(见环节④)。下文仍按 ③④⑤ 编号叙述,实际生成时按本规则定序。

### 环节① 真实情境抛任务(第1节,约8分钟)——价值观1

开课**第一件事不是讲题目,是抛一个真实任务**。让学生在前 3 分钟就知道:今天写的东西**有人要看、要用、要回应**,不是写完交给老师打分。

- **怎么造情境**:从档案任务里挖出它天然的社交场景,做成“痛点驱动”或“需求驱动”(下列为**范例,非固定模板**;实际以 `variation-pools.md` 池0 的按文体映射为准,并查台账避开近作同款):
  - 写信 → 真的要把信寄出去/送到,解决一件具体的事(替奶奶捎话、约转学的朋友暑假见面)。
  - 写景(《这儿真美》《__即景》)→ 当“大自然解说员/小导游”,带外地朋友云游一处。
  - 写人(《身边那些有特点的人》)→ 做一本“班级人物图鉴”,让别人靠你的描写猜中是谁。
  - 状物(《我的动物朋友》)→ 给走失的它写一张“寻××启事”,别人靠你的描写认出来。
  - 想象(《奇妙的想象》)→ 投稿“奇想博物馆”,最离奇的展出。
  - 说明(《介绍一种事物》)→ 给不懂的人写一张“使用/品尝指南”。
  - 倡议/建议(《我有一个想法》《学写倡议书》)→ 真的提给班级/家庭,看能不能被采纳。
- **真实受众必须点名**:谁会读到、读了会怎样,说清楚。受众越具体,内驱力越强。
- **档案咬合**:情境是包装,不改写作目标。档案要求写什么、练什么技法,一项不少地装进这个情境。
- **师话落点**:“今天我们不是写作文,是要__(做成一件事)”。让任务感压过作业感。
- **优先给情境一个“实体载体”**:比起抽象角色(“当解说员”),落成一个看得见的产出物更有力。**但载体不是默认套同一面展示墙——先按文体从 `variation-pools.md` 池0 选最贴切的真实社交场景(信→寄到人手里、观察日记→连载追踪、倡议→真提给班委…),再决定要不要实体载体、用哪一种(墙/手作册/投稿箱/连载本/朗读会/真实投递/卡片交换…),并查台账避开同年级近作的同款。** 实体载体要有:物理去处(贴哪/收进哪/寄给谁)、具体读者(谁会来看/会回应)、可见的成败标准(因文体而异,见池0第三节,反例别永远用“很美”)。受众越具体、产出物越实在,内驱力越强。
- **不写逐环节括号自注**:旧做法在环节末挂 `(此处落实「真实情境」——…)` 给老师看,属 AI 自检标签,**不写进面向老师的正文**;价值观是否落位,在 checklist G/H 组核验。

### 环节② 全感官唤醒(第1节,约10分钟)——价值观2

构思之前**必有一个“动起来”的环节**,调动至少一种身体感官或具身参与,把素材“激”出来,而不是让学生对着空白表格干想。**具体动作从 `variation-pools.md` 池1 按文体选,并查台账避开同年级最近 2 篇的同款类型**(图组/实物/回忆/演练/游戏)。任选(按文体配):

- **微型游戏**:绰号竞猜、“我说你猜”、词语接龙、角色扮演 30 秒。
- **实物/标本观察**:带一片叶子、一个旧物、一份食物,看摸闻甚至尝。
- **强视觉素材库 + 留白**:出示一组高冲击图片/短视频片段,只给画面不给文字,让学生说出看到了什么(写景、状物、想象尤其需要)。
- **现场情境演练**:把情境①演一小段(模拟打电话、模拟解说)。
- **回忆唤醒**:用强感官提问勾出记忆——“闭眼想想他笑起来的样子/那天的味道/手心的感觉”。

要点:**先有鲜活的感官输入,再进构思**。这一环结束时,学生脑子里应当塞满了具体的画面/声音/气味,而不是抽象的“我要写勇敢”。此环节产出直接喂给环节⑤的支架。

### 环节③ 一招技法(第1节,约10分钟)——底座(一课一得)

讲本节唯一主技法,深度上限 = 档案重难点(见 technique-levels.md)。正面、显性、只讲一个。技法要**长在情境里讲**:不是“今天学描写”,而是“要让别人猜中是谁/认出走失的它,光说‘他很高’不够,得__”。把技法说成达成真实任务的必要手段。

### 环节④ 示范文做样(第1节,约8分钟)——底座

教师示范文示范该技法(规则见 model-essay.md)。示范文**本身就该是情境①的产物**:情境是“寄信”,示范文就是一封真能寄的信;情境是“寻物启事”,示范文就是一张启事。出示后用 1–2 个指向性问题让学生发现技法怎么用。L3+ 后置(学生构思之后),L1–L2 可前置。

**强烈建议:示范文与构思支架用同一个例子,形成闭环。** 教师在⑤当众填的那张支架(如“银杏路”),到④就把这张表“变成”一段示范文,再回头问“表里几样东西被吸进文里了/老师走的什么顺序”。学生于是亲眼看见“关键词表 → 成段”的完整转化,而不是面对两个互不相干的示范例子。这一手能显著降低 L3–L4 学生“填完表却不会连成段”的卡点。

**示范文讲解要带学生看“句子怎么写得让人‘看见’”,不止看“结构对不对”(硬要求)。** 这是降低第2节动笔难度的关键抓手。环节③讲的主技法多是“结构层”(围绕一个意思、按顺序、起因经过结果……),学生往往“结构会搭、句子写不活”——只会写“很美/很热闹”,罗列景物却立不起画面。所以④的指向性问题要分两层:
- **结构层**(沿用):中心句出现几次?写了哪几样?走的什么顺序?——验证主技法到位。
- **句子层**(必须加):“老师这一句为什么让你一下就‘看见’了?”引导学生发现——把抽象的“美/好/热闹”换成了**可感的具体东西**:看得见的颜色、形状,听得见的声音(拟声词),闻得到、摸得到的感觉,以及**最基础的一个比喻**(“整条路像一条金色的隧道”)。讲解时把范文里这样的句子逐一点出来,让“写具体”的样子在范文里可被学生一眼指认(咬合检验见 model-essay.md 第五节)。
- **深度按级走,不越档**(遵从 technique-levels.md 边界):L1–L2 落到“照着说一句、仿一句”;L3 落到“颜色/形状词 + 拟声词 + 一个简单比喻”;L4+ 可到神态、动作、语言等。**这一层是“主技法 + 五感支架经范文示范落地”的呈现,不是新立的第三技法,不破“一课一得”**(见 technique-levels.md §一边界澄清)。
- **可配“词语小仓库”式助攻**:在构思/动笔前给一小张分类词表(声音/颜色/触感/气味各几个词),供想不出词的学生瞄一眼;务必讲清它只作拐杖——一格挑一个最像自己那处的,不整列照抄,**最好是它提醒学生想起自己看到的那个词**。

### 环节⑤ 构思支架落地(第1节,约9分钟)——价值观2 落地 + 底座

把环节②激出的素材,用一张 A 档空白支架收拢、聚焦、选材(支架类型见 technique-levels.md 对照表)。规则同底座:教师先当众示范填一张,再让学生填,有“引出→填写→分享+反馈”完整环节。**支架是为了减负不是增负**:填的是关键词不是句子,三五分钟能填完;填不出宁可缩格子,不要让填表本身变成新的认知负担。第 1 节尾收束:每人手里有“一个真实任务 + 一张填好的支架 + 满脑子感官素材”,预告动笔,不留课后任务。

### 环节⑥ 自由倾吐(第2节,约22分钟)——价值观4(表达主权)

开头一句接住支架即开写。这一环的**唯一铁律:护住表达流,绝不打断纠错**。

- **初稿不纠错**:学生动笔期间,教师**不指出错别字、不纠格式、不改病句、不打断思路**。哪怕看见明显错误,也忍住,留到环节⑦。
- **巡视只做三件事**:① 对无从下笔的,提供具体素材提示(“看你支架第二列,第一件事是什么?就从那句写起”);② 对内容空泛的,引导落到具体细节(“别再说‘他很热心’,写他做了什么”);③ 对书写顺畅的,不打断、留出空间(“写得好,继续”)。巡视话术按学情分类(无从下笔/内容空泛/已顺利完成/篇幅过短),每类给一句具体指导语。
- **护接地气的个性化选材**:学生写“我同桌爱抠橡皮”“我想给游戏角色写信”,只要扣住真实表达,**一律放行**,不因“不够正能量/不够典雅”而否定。先有意思,再有意义。
- **硬格式应用文的例外**(书信/留言条/倡议书):格式框架已在第1节讲清、动笔前摆好(可给一张格子稿/版式提示),动笔时**格式可当场对位**;但错别字、语句、内容的优化**仍然延迟**到环节⑦,不在倾吐期打断。除此之外的文体,格式与一切纠错全部延后。

### 环节⑦ 即时反馈 + 延迟纠错 + 自然收尾(第2节,约23分钟)——价值观3 + 价值观4(延迟纠错)

> **本环节是“当堂的、轻的”一层,不承担深度讲评。** 即时反馈(擂台/解说员/猜)是高频、鼓励、人人被看见的快肯定;延迟纠错是带标准的自改+同桌互改;老师只做**轻点评**(对事且具体地夸一两句、点一个可操作的小改处),**不在当堂逐篇深批**——老师真要做“逐篇、深入、围绕技法的深度讲评”,移到课后或下一次课开场的**附加「习作讲评指导环节」**(见本文件「一之二、习作讲评指导环节」一节)。这样设计是因为学生书写速度差异大、当堂时间紧,硬塞深度讲评必然“写不完、改不深、评不透、节奏断”。**注意:“当次完成、当次评改”的硬约束不破——当堂闭环(即时反馈+自改+互评+轻点评+收尾)仍然完整,深度讲评只是面向系列课/课后的可选深化,不是把评改推走。**
>
> **节奏要留弹性,不把环节排满。** 承认起笔慢、边写边停、书写快慢不一是常态:即时反馈环节宁可少请几篇也别赶场,自改给足时间,收尾从容。环节⑥若有学生确实没写完,⑦的反馈与自改照常进行(评、改的是“已写出的部分”),不为追求“人人写完整篇”而打断节奏。

倾吐完毕,进入**集中的、热闹的反馈与修改环节**。顺序固定:先肯定(即时反馈)→ 再优化(自改+互改)→ 老师轻点评 → 自然收尾。

- **即时高频反馈(先做,撑内驱力)**:设计**当堂、具体、高频**的正向反馈机制,让尽量多的孩子被“看见”一个局部闪光点。形式优先用游戏化的:
  - “猜猜他是谁”升级版(写人):念片段全班猜,猜中=特点立住。
  - “金句墙/亮句采集”:每人挑自己最得意的一句念出来,贴墙/记下,师快评一句好在哪。
  - “解说员擂台”(写景状物):读一段,听众举手说“我仿佛看到了__”。
  - “猜猜写给谁”(书信):念正文不念称呼,猜收信人。
  反馈要**对事且具体**——“你这句‘手指在方向盘上嗒嗒嗒敲’,一下就让人看见急性子了”,不是空泛的“写得不错”。覆盖面要广:宁可多请几个人各亮一句,不要只评一两篇全篇;**明确争取请到 6–8 人,有意点平时不爱举手的孩子**。可叠一个**第二层低门槛反馈**让全员被看见——**这一层从 `variation-pools.md` 池2 轮换,别再永远是“同桌互画喜欢的一句小星星”**(该句已在旧稿三篇逐字复现,是最刺眼的复读零件):互读读出最喜欢的一句、传一句纸条、点亮起立念、自评一句等,查台账避开同年级连续批次的同款。主反馈游戏也按文体从池2 选(写人猜是谁、书信猜写给谁、写景解说员擂台、说明照着做做看、倡议能不能说动我、观察日记连载预告…)。
- **延迟纠错(后做,有抓手)**:此刻才统一处理格式与错字。先教/复习修改符号(L3+:删除号、增补号、改正号,当堂示范),再对照档案评价标准,让学生**带着标准自改 + 同桌互改**。纠错聚焦本节技法点和硬伤,不求一次改到完美。
- **自然收尾**:按 lesson-structure 二之二的“回校衔接(轻处理,优先自然)”——贴本课情境真实收束(寄信/送达/上墙/投稿),把任务闭环,衔接的底气让学生自己体会,不喊机构卖点。

## 一之二、习作讲评指导环节(附加块 · 可选,不计入 45+45)

七环节是两节连排的核心,**当堂闭环已完整**(⑦的即时反馈+自改+互评+轻点评+收尾)。本节是**附加在详案末尾的一块可选模块**,专供老师做⑦容不下的“逐篇、深入、围绕技法”的**深度讲评**:

- **定位与两用**:既可**单次课**用(课后老师批读后,挑时间集中讲评一次),也可**系列课**用(作**下一次课的开场**,约 15–20 分钟,先讲评上次习作、再进新内容)。详案里把这块写成**老师可灵活取用**的指导框架,不替老师决定课时怎么排。
- **它评的是“已当堂完成”的稿,不破“当次完成、当次评改”**:作品仍是当堂写、当堂得到即时反馈与自改互改;深度讲评是**事后的再深化**,不是把评改推到下次去做。也**不构成课后写作任务**(学生不用回家再写),与先导红线/连排约束不冲突。
- **必须是“方法框架 + 占位槽”,严禁捏造学生作品**(真实性红线,见 model-essay.md §一):生成时**不知道**真实学生会写出什么,所以这一节只给**讲评的走法**和**留给老师填真实样本的空位**,绝不凭空编一段“学生作品”当范例(那等于伪造学生作品)。给老师的话术里用“某位同学的这一句______”这类**占位指引**。
- **讲评方法框架(写进详案的内容)**:
  1. **选稿**:从本班作品里挑 2–3 篇代表作——一篇较好、一篇中等、一篇有典型问题(好/中/待改进),覆盖不同层次,不只夸尖子。
  2. **围绕本课技法点讲**:讲评口径**锁定这节课教的那一两个点**(如写景课就看:有没有围绕“××真美”这个中心、顺序清不清、有没有把景物写具体写活),不漫无边际地挑全部毛病。
  3. **一篇一肯定一改处**:每篇先给**1 个具体的闪光点**(指到句子:“这一句‘____’让人一下看见了”),再给**1 个可操作的改进点**(“如果把‘很美’换成你看到的那个颜色,这句就立起来了”),忌“写得不错/再具体些”这类泛泛评语。
  4. **回扣技法、留迁移**:讲评收在“这几篇好就好在用上了我们这节课的______”,让学生把讲评听成“方法的再练一遍”,而不是“谁写得好谁写得差”。
- **与即时反馈/轻点评的分工(写清,避免混淆)**:即时反馈(⑦)= 当堂、高频、人人被看见的快肯定;轻点评(⑦)= 老师当堂顺口夸一两句、点一个小改处;**深度讲评(本节)= 事后、少量代表作、逐篇深入、围绕技法**。三者层层递进,不重复、不互相取代。
- **格式与落位**:本块作为详案的**附加章节**,置于 `全课完。` 之后、文件尾 `VARIATION-FINGERPRINT` 指纹注释之前,用清晰标题标明其“可选、两用”属性(具体写法见 lesson-structure.md §三);仍守弯引号/无星号/机构不拟人三条格式硬规则。
