# 行文风格基准（正样本 · 2026-08-04 立）

> **这份文件为什么存在。** 2026-08-04 用户拿人工逐句改过的《四上-第一单元-推荐一个好地方》当样板，要求其余写作课详案照此调风格；随后指出新生成的四篇「AI 痕迹依然偏重」。复盘规则库发现：`lesson-structure.md` §三语言风格红线七条、`checklist.md` E 组二十余条、本目录各 reference 合计含禁令词的行约 157 行，**而全线只有 2 处「正例」，都是讲教学动作的，一段管行文的正样本都没有**。等于对生成侧说了 157 次「别那样写」，一次没说「要这样写」。
>
> 禁令表管得住**旧病**（抒情腔、导演腔、教研黑话），管不出**新的好文风**——它只划出禁区，不给方向，生成侧在禁区边上随便找个落点都算合规，于是落到了另一个极端：把话压短、压硬、压成方言味的电报体。**本文件补的就是这个方向。**
>
> **定位**：与红线并列的正样本，不是又一条禁令。红线第 7 条（禁电报体与生造词）的判据「读出声像不像真老师顺嘴讲」原先只指了篇名、没给可对照的段落，**本文件即那条判据的落地形态**。改红线第 7 条须同步本文件，反之亦然。

## 二、五类改法（左栏＝生成侧实际写出来的，右栏＝用户改成的）

以下全部取自 2026-08-04 那次人工修订的真实前后对照，不是拟例。

### 1. 补足完整词汇——单音节词与极简断句

| 生成侧原稿 | 用户改后 |
|---|---|
| 先看架子——整篇的骨头就这么几句 | 先看框架——整篇文章的骨架就是这么几句 |
| 理由就从景、吃的、玩的、故事这几方面去找 | 理由就从风景、吃的、玩的、地方传说／故事等这几方面去找 |
| 差的不是那个地方，是说法 | 地方本身没差别，差别全在我们怎么介绍 |
| 参考：它就是记了一天 | 参考：它只是记录当天发生的事情 |

判据：**一个词能不能单独立住**。「景」「架子」「说法」在口语里立不住，读的时候要靠上下文兜，听的人得回想一下——真老师会直接说全。

### 2. 去掉生硬缩略与方言腔

| 生成侧原稿 | 用户改后 |
|---|---|
| 动笔前得先弄准一件事 | 准备动笔之前，我们先要弄清楚一件事 |
| 挑最说得动人的两条就够 | 挑选最吸引人的两条就足够 |
| 记得住的地方，才推荐得动别人 | 只有自己印象深刻的地方，才能把别人说得心生向往 |
| 往后推荐一本书、推荐一部电影，这条路子都走得通 | 今后推荐书籍、影片，同样可以使用 |
| 别把它们搅在一块儿 | 不要混在一起 |

⚠ **不是所有口语都要改**：同一次修订里，「同一个人说，头一回人家没动」「那儿挺好的」「随你摘」用户原样保留。留下的是**说得出口的口语**，改掉的是**写下来才有、说出来别扭的缩略**。2026-08-04 实测：把「头一句/头一回」当禁词去扫，基准篇自己命中 9 次——**这类词做不成词表，只能按上面这条判据逐处看**。

### 3. 自造术语一律换通行说法

| 生成侧原稿 | 用户改后 |
|---|---|
| 理由一 · 那儿真有的东西（构思表行名） | 理由一 · 让你印象深刻的东西 |
| 后面把那儿真有的东西写出来 | 接着写上现场令你印象深刻的细节 |
| 段里有具体的东西 | 段落嵌入实景细节 |

自造短语的典型长相：**四到六字、动宾或偏正压缩、看着精准、第一遍读不懂**。它们几乎全是为了避反同质化配额而生的（机制与豁免见 `variation-pools.md` §「配额与自然表达的裁决序」）。

### 4. 补主语与关联词，把并置短句接成完整句

| 生成侧原稿 | 用户改后 |
|---|---|
| 这就有点奇怪吧。先别忙着答。 | 这就有点奇怪了。大家先别急着回答。 |
| 第一段记的是「我那天干了什么」，从早到晚一件一件排下来 | 按时间从头到尾挨个罗列。别人看完只知道你的行程，却没法判断自己想不想去 |
| 读的人一眼就看见你说了两件事 | 读者一下子就能看清你的两个亮点 |
| 段一开头就把理由亮出来了 | 段落开头一句先把理由亮出来，开门见山，读者一眼就能抓住段落重点，条理特别清晰 |

面向学生的问句与指令句补「你们／我们／大家」；两个并置短句之间，该有的「因为／所以／可是／而」不要省。

### 5. 示范文同样处理，且对照表引用句必须同步

| 生成侧原稿 | 用户改后 |
|---|---|
| 村口那家米糕，天不亮就开始蒸 | 村口那家米糕店，天不亮就开始蒸糕 |
| 做糕的奶奶握着木槌，笃、笃、笃地敲，敲一阵，掀开笼盖 | 做糕的奶奶拿着木槌，笃、笃、笃轻轻敲打米团。敲上一会儿，她掀开蒸笼 |
| 米糕烫手，得两只手来回倒着拿 | 米糕烫得很，我只能双手来回轮换捧着 |

⚠ **示范文一改，环节⑤旁批对照表里逐字引用的那几句必须跟着改**——两处对不上，课上带读时老师念的和屏上写的不是一句话。这是改文风时最容易漏的连带项（骨架屏、对照表、正文三处引同一句的课次尤其）。

## 三、只改行文，不动教学设计

按本文件调风格时，**下列内容一律原样保留，不在改写范围内**：

- `〔应答·…〕` 块、`[教师巡视…]` 四类处理、`[投屏…]`／`[发放…]` 等现场提示
- `〔教师示范·…〕` 与 `【教师示范文】` 的教学落点、装置设计、环节时长
- 评价表档位的**判据本身**（措辞可改，判定口径不可改）
- 文末 `<!-- VARIATION-FINGERPRINT -->` 指纹块（改风格不改指纹；指纹记的是设计不是措辞）
- 表格单元格里刻意的**词语化短填**（示范表「没得比」「圆、黄、硬」这类）——那是给学生看的填法示范，本就该短

2026-08-04 实测：用户的人工修订版把 3 处 `学生互动分享（…）` 改成了普通括号、删掉了 4 处投屏提示与指纹块——**那是交付副本上的顺手删改，不是文风规则**，回写仓库时指纹块须补回。

## 四、反向护栏（防矫枉过正）

与红线第 7 条的反向约束同源，改风格时同查：

1. **增字不注水**：每处改写增字原则上不超原句一倍。「先看架子」→「先看框架」是对的，→「我们先来看一看这篇文章整体的框架结构是怎么样的」是错的。
2. **不统一句长**：改完整段若短句尽失、句长均齐，AI 味不降反升。真实短指令（「笔放下。」「停一停。」「一、二、三！」）保留。
3. **不把口语改成书面语**：目标是「说得出口的完整话」，不是「写得规整的书面语」。判据始终是读出声，不是看着顺眼。
4. **`参考：` 行是学生话轮**，粗糙口语是设计要求，只补到「说得出口」为止，不改成完整规范句。
5. **示范文与书面区不套口语规则**（同 checklist E 组「示范文与书面区未被口语化规则误改」）。
