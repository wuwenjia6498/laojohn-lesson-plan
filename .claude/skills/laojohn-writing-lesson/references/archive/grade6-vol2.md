# 六年级下册 · 习作档案

> 来源:《1-6年级习作要求、教学重难点及教学建议》(用户提供官方指导文件,内容逐字搬运,未做改写)。
> 老约翰分级对应:L6。

## 册级说明

六年级下册因有“难忘小学生活”综合性学习单元，单元习作共五个，加上综合性学习中的习作任务，一并列在下面

## 六年级下册·第一单元 习作《家乡的风俗》

```meta
册: 六年级下册
任务: 第一单元 习作《家乡的风俗》
文体: 民俗·介绍
关键词: 风俗 特点 体验
分级: L6
```

### 一、习作要求（教学目标）

1. 了解并介绍家乡的一种风俗：能通过调查、访问或查阅资料，了解家乡的一种风俗，把这种风俗写清楚。

2. 写清楚风俗的主要特点：能写出风俗的活动内容、形式、流程、寓意等，让读者对这种风俗有一个全面的了解。

3. 融入自己的亲身经历和感受：能在介绍风俗的同时，结合自己参加这种风俗活动的经历，写出自己的感受和体验。

4. 表达对家乡文化的热爱：在写作中自然流露出对家乡风俗和传统文化的认同感与自豪感。

### 二、教学重难点

重点：指导学生把家乡的一种风俗写清楚，既介绍风俗本身，又融入自己的亲身经历。

难点：帮助学生在介绍与叙事之间找到平衡，做到既长知识又有温度，避免写成干巴巴的资料介绍。

### 三、教学建议（核心教学环节）

第一环节：作前准备——查风俗，理资料

1. 确定要写的风俗

引导学生回忆或调查自己家乡有哪些独特的风俗。可以从不同方面想：节日风俗（春节、元宵、清明、端午、中秋、重阳等）、人生礼俗（满月、抓周、婚礼、寿宴等）、地方特色风俗（庙会、社火、舞龙舞狮、赛龙舟、赶集等）、日常生活中的独特习俗（饮食风俗、待客之道等）。选定一种自己最熟悉或最感兴趣的风俗。

2. 课前进行调查和资料搜集

布置学生课前通过访问长辈、实地观察、查阅资料等方式，了解所选风俗的详细信息。可以从以下方面搜集：这种风俗的由来或传说、风俗活动的具体内容和流程（人们穿什么、吃什么、做什么）、风俗有什么寓意或象征意义、自己参加过的经历和感受。

3. 整理资料，分清主次

引导学生把搜集到的信息进行整理。区分哪些是风俗的“客观介绍”（大家都知道的），哪些是自己“独特的经历和感受”。本次习作两者都需要，但自己的亲身经历和感受是让文章有温度的关键。

第二环节：作中指导——写风俗，融经历

1. 明确习作要求

写家乡的一种风俗。把风俗的主要特点写清楚。结合自己的亲身经历和感受来写。语句通顺，内容具体。

2. 指导写作结构

提供参考结构：开头点明要写的风俗是什么，可以用一句俗语、一个传说或一个场景来引入。中间先介绍这种风俗的基本情况（由来、内容、形式、寓意等），再写自己参加这种风俗活动的经历和感受。结尾写出对这种风俗的看法，表达对家乡文化的感情。

3. 指导把风俗写清楚

介绍风俗时，要按一定的顺序来写，如时间顺序（活动从开始到结束的流程）、空间顺序（活动场地的布置和变化）等。把风俗中最有特点的活动或仪式写具体，让没有见过的人也能想象出来。

4. 指导写好亲身经历

在介绍风俗的基础上，选取自己参加这种风俗活动的一次具体经历来写。写出当时自己做了什么、看到了什么、心里怎么想。用第一人称“我”的视角，让读者感受到身临其境。亲身经历可以和风俗介绍穿插着写，也可以单独集中写。

第三环节：作后评改——读风俗，品文化

1. 同桌互读

交换读习作，读完后说说：你了解这种风俗了吗？哪里写得最清楚？作者的个人经历写得生动吗？

2. 自我修改

检查：风俗介绍是否清楚？亲身经历是否具体？有没有融入自己的感受？进行修改。

3. 全班“家乡风俗展”

将全班习作按风俗类型分组展示，可以配上照片、实物或图画。同学们自由阅读，投票评选“最想去体验的风俗”。引导从“风俗介绍清楚、个人经历生动、有真情实感”等方面进行点评。在交流中感受祖国各地风俗文化的丰富多彩。

### 四、评价标准参考

1. 基础过关：能写出一种风俗的基本内容，有简单的个人经历，语句通顺。

2. 良好达标：风俗介绍比较清楚，个人经历比较具体，有自己的感受。

3. 优秀进阶：风俗介绍清晰生动，个人经历具体感人，风俗文化与个人感受融合自然，表达了对家乡文化的热爱。

## 六年级下册·第二单元 习作《写作品梗概》

```meta
册: 六年级下册
任务: 第二单元 习作《写作品梗概》
文体: 梗概
关键词: 梗概 概括 理清脉络
分级: L6
```

### 一、习作要求（教学目标）

1. 理解“梗概”的意思和写法：知道梗概就是用简练的语言把一本书或一篇文章的主要内容概括出来，让没有读过的人也能了解大概。

2. 学习写梗概的基本方法：能抓住作品的“主干”，去掉“枝叶”，用连贯的语言把主要情节串联起来。

3. 保持内容完整、语言连贯：梗概要保留作品的基本情节框架和结局，语言通顺、前后连贯。

4. 培养概括和提炼能力：在写梗概的过程中，进一步锻炼提取主要信息和概括表达的能力。

### 二、教学重难点

重点：指导学生掌握写梗概的方法，抓住主干、删减枝叶。

难点：帮助学生在删繁就简的同时保持情节的完整和连贯，使梗概读起来通顺自然。

### 三、教学建议（核心教学环节）

第一环节：作前指导——学方法，抓主干

1. 认识梗概，明确作用

通过对比一篇长作品和它的梗概，让学生直观感受什么是梗概。讨论：梗概有什么用处？（帮人快速了解内容、推荐书籍、写读书报告等）梗概和读后感有什么不同？（梗概客观概括内容，不写感想和评价）

2. 学习写梗概的方法

结合教材提示，归纳写梗概的方法：第一步，通读全书或全文，把握整体内容。第二步，找出主要人物和主要情节。可以用思维导图或提纲把主要情节的脉络理出来。第三步，删去细节描写、次要情节、人物对话的具体内容，只保留推动情节发展的关键信息。第四步，把保留的关键信息用自己的话重新组织成通顺连贯的文字。

3. 尝试口头缩写练习

选取本单元一篇比较熟悉的文章或一本书中的一段，让学生尝试口头概括主要内容，只保留主干信息。在练习中体会如何“留主干、去枝叶”。

4. 确定写梗概的作品

让学生选定一本自己读过的书或一篇文章来写梗概。提醒选择情节比较清晰、篇幅适中的作品更容易上手。

第二环节：作中指导——留主干，串成篇

1. 明确习作要求

选一本读过的书或一篇文章，写它的梗概。保留主要人物和主要情节。语言简练，内容连贯。字数明显少于原文。

2. 指导写作结构

提供参考结构：开头用一两句话交代作品的名称、作者和主要人物。中间用一段或几段概括主要情节，按事情发展的顺序，把起因、经过和结果串联起来。结尾交代故事的结局。梗概中不写自己的感想和评价。

3. 指导把情节串联起来

在概括每个主要情节时，用恰当的连接词使情节连贯，如“接着”“随后”“然而”“最终”等。注意情节之间的因果关系要清楚，前一件事要能引出后一件事，不能前后脱节。

4. 指导语言简练

提醒学生：梗概的语言要干净利落，不拖泥带水。不说“书中写道”“作者认为”这样的话，直接叙述内容。不引用原文中的长对话，不进行景物和心理描写。把最核心的事实叙述出来即可。

第三环节：作后评改——验完整，查连贯

1. 同桌互读互验

交换读梗概，读完后说说：你能看懂这本书讲的是什么吗？有没有重要的情节被遗漏了？读起来连贯吗？

2. 自我修改

检查：主要情节是否完整？有没有重要的转折点遗漏？语言是否简练？前后是否连贯？进行修改。

3. 全班“好书一分钟速览”

举办一个模拟的“好书一分钟速览”活动，请几位同学在一分钟内口述自己写的梗概。检验梗概是否能在短时间内让听众了解一本书的基本内容。评选“最清晰梗概”“最吸引人的梗概”等。

### 四、评价标准参考

1. 基础过关：能写出作品的主要人物和大致情节，语句通顺。

2. 良好达标：主要情节完整，语言比较简练，梗概基本连贯。

3. 优秀进阶：主干突出，删减得当，情节完整连贯，语言精练流畅，能让人快速了解全书大概。

## 六年级下册·第三单元 习作《让真情自然流露》

```meta
册: 六年级下册
任务: 第三单元 习作《让真情自然流露》
文体: 抒情
关键词: 真情实感 情感变化
分级: L6
```

### 一、习作要求（教学目标）

1. 写一种自己印象最深的感受：能回忆自己生活中印象最深刻的情感体验，选一种感受（如感动、欣喜、愧疚、难过、盼望、后悔等）作为写作的中心。

2. 把感受写具体、写细致：能通过具体的事来表现这种情感，把情感变化的轨迹写清楚，不空洞说“我很感动”。

3. 学习用多种方法表达情感：能综合运用动作、神态、心理、环境烘托等多种手法，把无形的感受变成可感可触的文字。

4. 真情实感，自然流露：真诚地面对自己的内心，写出自己真实的感受，不虚假、不做作。

### 二、教学重难点

重点：指导学生通过具体事例，综合运用多种手法把真情实感写具体。

难点：帮助学生把情感的变化过程写细致、写自然，让读者跟着文字一起感受情绪的变化。

### 三、教学建议（核心教学环节）

第一环节：作前指导——忆真情，说感受

1. 打开情感的闸门

引导学生回顾本单元学过的课文《匆匆》《那个星期天》，说说作者是怎样把内心的感受写得那么动人的。引出话题：生活中有很多让你内心产生强烈感受的时刻，选一种印象最深的感受来写。

2. 确定要写的感受

引导学生从不同的情感中选定一种：喜悦类的（欣喜若狂、兴高采烈、心花怒放等）、感动类的（热泪盈眶、感激涕零等）、愧疚类的（追悔莫及、惭愧不已等）、忧伤类的（肝肠寸断、黯然神伤等）、思念类的（望眼欲穿、归心似箭等）。选定一种自己最有话可说、印象最深的感受。

3. 回忆与这种感受相关的事

这种感受是由什么事引起的？把这件事的来龙去脉想清楚。重点是回忆在这件事中，你的感受是怎样产生、变化和发展的。刚开始是什么感觉？后来怎样？什么时候感受最强烈？最后又是怎样？

4. 口述真情，捕捉细节

在小组内用自己的话讲述这件事和当时的感受。组员听完后说说：你感受到他的真情了吗？哪个细节最打动你？哪里还可以说得更细致？用追问帮助讲述者挖掘更多细节。

第二环节：作中指导——写心事，现真情

1. 明确习作要求

选择一种自己印象最深的感受来写。把事情的经过写清楚。把感受写具体、写细致。综合运用多种方法来表达情感。语句通顺，真情实感。

2. 指导写作结构

提供参考结构：开头直接进入情感氛围，可以写感受最强烈的那个瞬间，也可以交代事情的起因。中间写事情的经过，在叙事中把感受的变化过程写出来，感受最强烈的部分放慢笔墨细写。结尾写情感沉淀后的体会，自然收束。

3. 指导用多种方法表达情感

引导综合运用以下方法：直接写内心感受（“我心里像打翻了五味瓶”）、通过动作表现（“我紧紧地抱住她，久久不愿松开”）、通过神态表现（“泪水在眼眶里打转，我使劲抿着嘴不让它流下来”）、通过语言表现（说话的语气、语速的变化）、通过环境烘托（“天灰蒙蒙的，好像也在为我难过”）、通过联想和内心独白表现。本单元课文是很好的范例，可以回顾借鉴。

4. 指导写出情感的变化

真实的感受往往不是单一的，而是有一个变化过程。引导写出情感的曲线：可能一开始不太在意，后来逐渐被触动；可能一开始欣喜，后来变得失落；可能多种感受交织在一起。把变化写出来，真情就更真实、更动人。

第三环节：作后评改——读心事，感真情

1. 同桌互读

交换读习作，读完后说说：你感受到了他写的是一种什么感受吗？哪里写得最打动你？哪里让你仿佛也跟着一起经历？

2. 自我修改

检查：事情写清楚了吗？感受写具体了吗？是不是用了多种方法来表达？情感的变化写出来了吗？进行修改。

3. 全班“真情分享”

选择愿意分享的同学在全班朗读自己的习作。由于这类习作涉及真实情感，朗读时要营造尊重的氛围，认真倾听。引导从“感情真实、细节具体、方法多样、有变化过程”等方面进行欣赏和点评。老师要肯定每一个敢于袒露真心的孩子。

### 四、评价标准参考

1. 基础过关：能写出一种感受和相关的事情，语句通顺。

2. 良好达标：事情清楚，感受比较具体，能用一些方法表达情感。

3. 优秀进阶：感受具体细腻，情感变化丰富真实，综合运用多种表达方法，真情流露，有强烈的感染力。

## 六年级下册·第四单元 习作《心愿》

```meta
册: 六年级下册
任务: 第四单元 习作《心愿》
文体: 表达心愿
关键词: 心愿 选材 表达方式
分级: L6
```

### 一、习作要求（教学目标）

1. 选一个自己最想实现的心愿来写：能敞开心扉，从对自己、对家人、对社会等不同层面选择一个心愿来写。

2. 写清楚心愿是什么和产生的原因：能写出心愿的内容，以及为什么会有这个心愿，把前因后果写明白。

3. 选择适合的文体来表达：能根据心愿的内容，选择叙述故事、书信、日记、诗歌等自己认为最适合的文体来表达。

4. 表达真情实感：在表达心愿的过程中，自然流露出自己的真实想法和情感。

### 二、教学重难点

重点：指导学生把心愿写清楚，写出为什么有这个心愿。

难点：帮助学生根据心愿的内容选择合适的文体，并能在所选文体中自如地表达。

### 三、教学建议（核心教学环节）

第一环节：作前指导——敞心扉，说心愿

1. 理解“心愿”的含义

引导学生谈谈什么是心愿。心愿是对未来的美好期盼，是心中最想实现的想法。心愿可大可小，可以是近期的，也可以是远大的。每个人在不同阶段都会有不同的心愿。

2. 多角度打开心愿的思路

引导学生从不同层面想心愿：关于自己的（希望自己考上理想的中学、学会一项本领、改掉一个缺点、变得更自信等）、关于家人的（希望爸爸妈妈多陪陪自己、希望爷爷奶奶身体健康、希望家人之间更和睦等）、关于朋友和老师的（希望好朋友永远不分开、希望老师不要太辛苦等）、关于社会和大自然的（希望世界和平、希望环境变好、希望流浪动物有家等）。选定一个自己最想写、最有感触的心愿。

3. 理清心愿的来龙去脉

选定心愿后想一想：这个心愿是从什么时候开始有的？是什么事情触发或让你产生了这个心愿？这个心愿对你来说为什么这么重要？如果实现了会怎样？把心愿的产生、发展和重要性想清楚。

4. 选择适合的文体

引导学生思考用什么文体来写最合适：如果是通过一件事来表达心愿，可以选叙事文；如果是向某人倾诉心愿，可以选书信体；如果是抒发内心的渴望，可以选诗歌或散文。选定文体后按该文体的特点来构思。鼓励有创意的选择。

第二环节：作中指导——选文体，写心愿

1. 明确习作要求

写自己的一个心愿。写清楚心愿是什么、为什么会有这个心愿。选择一种适合的文体来写。语句通顺，感情真实。

2. 指导写作结构

根据不同文体提供参考结构。叙事文参考结构：开头写心愿是什么，用一句话点出。中间写心愿产生的原因和过程，可以写一件具体的事，把自己当时的所见所闻所感写出来。结尾再次表达心愿，写出期盼。书信体参考结构：用书信的格式，正文中向收信人倾诉心愿，说明为什么有这个心愿，希望得到理解或支持。诗歌体：自由表达，用精炼的语言、意象来表达内心的渴望。

3. 指导把原因写具体

这是本次习作的重点。不管是哪种文体，都要把为什么会有这个心愿写清楚。不能只说“因为我想要”，而要通过具体的事情或真实的感受让读者理解这个心愿的来由。把这个心愿在你心中生根发芽的过程写出来。

4. 指导情感表达

心愿是最贴近内心的文字，语言要真诚，感情要自然。不管是倾诉、渴望还是期盼，都要让读者感受到这是你的真心话。不喊口号、不写套话。

第三环节：作后评改——读心愿，感真情

1. 同桌互读

交换读习作，读完后说说：你了解他的心愿了吗？为什么会有这个心愿，清楚吗？你觉得文体选择合适吗？

2. 自我修改

检查：心愿是否写清楚了？原因是否写具体了？文体选择是否恰当？感情是否真实？进行修改。

3. 全班“心愿分享会”

举办一个温馨的“心愿分享会”，请几位同学用自己选择的文体来分享心愿。引导从“心愿清楚、原因具体、文体恰当、感情真挚”等方面进行欣赏和点评。可以用“心愿墙”的方式把全班的心愿展示出来，互相了解、互相鼓励。

### 四、评价标准参考

1. 基础过关：能写出自己的一个心愿，有基本的原因说明，语句通顺。

2. 良好达标：心愿清楚，原因比较具体，文体选择基本恰当，感情比较真实。

3. 优秀进阶：心愿动人，原因具体深刻，文体选择恰当且运用自如，真情实感自然流露，有感染力。

## 六年级下册·第五单元 习作《插上科学的翅膀飞》

```meta
册: 六年级下册
任务: 第五单元 习作《插上科学的翅膀飞》
文体: 想象·科幻
关键词: 科幻 科学 想象
分级: L6
```

### 一、习作要求（教学目标）

1. 编写一个科幻故事：能展开科学幻想，想象未来科技的发展或未知世界的奥秘，编写一个具有科幻色彩的故事。

2. 故事要围绕科技展开：情节的发展要和某种未来的科学技术有关，科技是推动故事情节的重要因素。

3. 把科技的“神奇”之处写具体：能把想象中的科技是什么样的、有什么功能和效果写清楚，让读者感受到科技的力量。

4. 在科幻故事中融入人文思考：能在精彩的故事中，蕴含对人类、社会、环境等的思考，让科幻故事不仅有想象力，也有温度。

### 二、教学重难点

重点：指导学生把科技想象和故事情节有机结合起来，写出一个有趣又合理的科幻故事。

难点：帮助学生在科幻故事中融入思考和情感，让故事既有科技感，又有人文关怀。

### 三、教学建议（核心教学环节）

第一环节：作前指导——想科技，编情节

1. 打开科幻的想象空间

引导学生回顾自己读过的科幻故事、看过的科幻电影，说说其中最吸引自己的是什么。讨论：科幻故事和我们之前写过的童话、想象故事有什么不同？引出科幻故事以科学技术为核心，想象要有一定的科技感。

2. 选定科幻创意

引导学生从不同角度展开科学幻想：未来的发明（会飞的汽车、能治百病的药丸、时间机器等）、未来的世界（人类住在火星上、海底城市、人工智能全面进入生活等）、宇宙探索（发现外星文明、进入平行宇宙等）、科技带来的变化和挑战（机器人和人类的关系、基因改造的伦理问题等）。选定一个自己最感兴趣、最有话可写的科幻创意。

3. 围绕科技构思故事情节

确定科幻创意后构思故事：主角是谁？生活在什么时代或环境中？遇到了什么因科技而产生或能被科技解决的困难？事情是怎样发展的？结果如何？让科技成为推动情节发展的重要因素。

4. 在故事中融入思考

科幻故事往往通过对未来的想象，表达对现实的某种思考。引导学生想一想：你的故事除了好玩之外，还想传达什么？是对环境破坏的担忧，还是对科技双刃剑的思考，还是对勇敢探索精神的赞美？把这一点思考自然地放进故事中。

第二环节：作中指导——写科技，融思考

1. 明确习作要求

编一个科幻故事。围绕某种未来的科学技术来写。把故事写完整，把科技的“神奇”写具体。尝试在故事中融入自己的思考。想象丰富合理，语句通顺。

2. 指导写作结构

提供参考结构：开头交代故事的背景，点出所处的时代环境。中间写故事的情节发展，重点写科技在故事中发挥了什么作用，把最神奇、最关键的部分写具体。结尾写故事的结果和人物的感悟，点出故事中蕴含的思考。

3. 指导把科技写具体

对自己想象出来的科技产品或科技场景，要像介绍真的一样写清楚它的样子、功能和效果。可以适当运用一些科学术语或自创的“科技名词”，让故事更有科技感。但不要堆砌术语，还是要让读者能看懂、觉得有趣。

4. 指导人文思考的自然融入

思考不要生硬地加在结尾，可以通过人物的经历和感受来自然呈现。比如人物在使用某种强大科技时感到敬畏、在见证科技造成的后果时产生反思、在探索未知时表现出人类的勇气和好奇心等。

第三环节：作后评改——读科幻，赏创意

1. 同桌互读

交换读故事，读完后说说：你觉得这个故事有科幻感吗？科技的描写具体吗？有没有感受到故事中的思考？

2. 自我修改

检查：科幻创意是否新奇合理？科技描写是否具体？故事情节是否完整？思考是否自然？进行修改。

3. 全班“科幻故事展”

举办“科幻故事展”，请几位同学朗读自己的科幻故事，或者把习作配上插图进行展示。评选“最有创意的科幻”“最震撼人心的科幻”“最有科技感的科幻”等。引导从“创意新奇、科技具体、情节精彩、有思考深度”等方面进行欣赏和点评。

### 四、评价标准参考

1. 基础过关：能围绕科技编写一个基本完整的故事，语句通顺。

2. 良好达标：科幻创意比较有趣，科技描写比较具体，故事完整。

3. 优秀进阶：科幻创意独特，科技描写具体生动，情节引人入胜，能自然融入对人与科技的思考，有想象力也有深度。

## 六年级下册·第六单元 综合性学习《难忘小学生活》（习作部分）

```meta
册: 六年级下册
任务: 第六单元 综合性学习《难忘小学生活》（习作部分）
文体: 综合性学习
关键词: 成长纪念册 毕业
分级: L6
```

本单元为综合性学习单元，包含两个习作任务。第一个任务是写信，包含在“回忆往事”板块中；第二个任务是写活动策划书，包含在“依依惜别”板块中。因用户前文要求整理四年级上册第六单元“记一次游戏”时是完整的习作任务指导，此处对应六年级下册第六单元的习作任务进行整理。教材中本单元无独立编号的第六单元习作，实际为综合性学习中的两个写作任务。

习作任务一：写信（给老师、同学或母校）

### 一、习作要求（教学目标）

1. 用书信表达惜别之情：能在即将毕业之际，用书信的形式向老师、同学、母校表达自己真挚的情感。

2. 回忆美好往事，表达真情：能在信中回忆小学生活中难忘的人或事，把印象最深的画面写具体，表达感恩、不舍或祝福之情。

3. 书信格式正确：能规范地使用书信格式，称呼、正文、祝福语、署名和日期各部分齐全。

4. 真诚沟通，温暖告别：通过这封信，把平时可能不好意思说出口的话说出来，让小学阶段的师生情、同学情留下美好的文字纪念。

### 二、教学重难点

重点：指导学生用书信的形式回忆美好往事，表达真情实感。

难点：帮助学生在众多回忆中选取最有代表性、最打动人心的内容，书信语言真诚得体。

### 三、教学建议（核心教学环节）

第一环节：作前指导——忆往昔，定内容

1. 营造惜别氛围，打开记忆闸门

播放小学六年来的照片或视频，回顾一起走过的日子。引导学生畅谈：六年中，你最难忘的人是谁？最难忘的事是什么？有什么话一直想对某人说却没有说出口？在即将毕业的时刻，把心里话写下来，是一份珍贵的毕业礼物。

2. 确定收信人和主要内容

引导学生确定这封信写给谁：写给一位老师、一位同学、或者写给母校这个集体。选定后想一想：我最想对他（她）说什么？是感谢、是不舍、是祝福，还是回忆一两个难忘的瞬间？把最想说的内容整理出来。

3. 回忆具体的事例和画面

要把信写得打动人，需要有具体的画面。引导学生回忆一两个具体的场景：老师给你印象最深的一个瞬间、和同学之间最难忘的一件事、在校园里最有意义的一个角落等。把这些画面想在脑海中重现清楚。

4. 想想用什么语气

给不同的人写信，语气不同。给老师写信要尊敬而亲切，给同学写信可以轻松温暖一些。无论什么语气，真诚最重要。

第二环节：作中指导——用书信，写真情

1. 明确习作要求

写一封信给老师、同学或母校。格式正确。回忆难忘的人或事，表达真情实感。语句通顺，感情真挚。

2. 指导书信格式

称呼顶格加冒号；问候语另起一行空两格；正文分段写；祝福语分两行；署名和日期在右下方。虽是再次使用书信格式，仍需强调规范。

3. 指导写作结构

提供参考结构：开头用问候语和引入语，如“马上就要毕业了，我想借这封信对您说说我的心里话”。中间写一两件具体的回忆，在回忆中表达自己的情感。结尾再次表达感谢、祝福或不舍，自然收束。

4. 指导把回忆写具体

写回忆时，要把当时的场景写清楚：是什么时候、在什么地方、发生了什么事、对方说了什么做了什么、自己当时是什么感受。通过具体的画面来传递情感，让读到信的人能想起那个瞬间。

第三环节：作后评改——读信，品真情

1. 同桌互读（如涉及隐私可自读自查）

交换读，读完后说说：感受到作者的真情了吗？哪些回忆写得最打动你？格式正确吗？

2. 自我修改

检查：格式正确吗？回忆是否具体？感情是否真挚？进行修改。

3. 真实的送信活动

鼓励学生把这封信真正地写下来，装入信封，亲手交给收信人。这是小学毕业季最有意义的纪念之一。也可以在毕业典礼上设置“读信”环节，让真情在现场流淌。

### 四、评价标准参考

1. 基础过关：格式正确，能写出想说的话，语句通顺。

2. 良好达标：格式规范，有具体的回忆内容，表达出真情实感。

3. 优秀进阶：格式规范，回忆具体生动，情感真挚动人，书信语言真诚得体，有纪念价值。

习作任务二：写活动策划书（毕业联欢会策划书）

### 一、习作要求（教学目标）

1. 了解策划书的基本格式和作用：知道策划书是用来对一次活动进行整体安排和设计的应用文，掌握其基本写法。

2. 学习全面考虑活动安排：能从活动目的、时间地点、分工安排、活动流程等方面对毕业联欢会进行全面策划。

3. 把活动流程写清楚：能按顺序把活动流程分条列出，语言简洁明了，职责分工明确。

4. 在策划中融入对母校和同学的情感：毕业联欢会的策划要体现惜别之情和对未来的展望，让活动有意义、有温度。

### 二、教学重难点

重点：指导学生掌握策划书的格式，把活动安排写清楚。

难点：帮助学生在策划中体现毕业联欢会的特殊意义，活动安排既有条理又有情感。

### 三、教学建议（核心教学环节）

第一环节：作前指导——明任务，学格式

1. 明确写作任务

在“依依惜别”的氛围中，引出毕业联欢会的话题：如果要举办一场毕业联欢会，我们需要做哪些准备？怎样才能办好？引出写活动策划书的需要。

2. 了解策划书的基本格式

出示一份简明的策划书范例，引导学生了解策划书的主要组成部分：活动名称、活动目的、活动时间、活动地点、活动分工、活动流程、注意事项等。让学生对策划书有一个整体的认知。

3. 讨论毕业联欢会的特殊意义

引导学生讨论：毕业联欢会和平时的联欢会有什么不同？它承载了怎样的情感？在策划时要体现“回忆、感恩、祝福、展望”等元素，让活动不仅是表演，更是一次情感的凝聚。

4. 口头讨论活动安排

在小组内初步讨论毕业联欢会的构想：活动可以有哪些环节？哪些同学负责什么？流程怎样安排？把讨论的结果作为写策划书的素材。

第二环节：作中指导——按格式，写策划

1. 明确习作要求

写一份毕业联欢会活动策划书。格式基本规范。活动安排清楚具体。体现毕业联欢会的特殊意义。语言简洁明了。

2. 指导策划书各部分写法

活动名称：简洁明确，如“XX班毕业联欢会策划书”。活动目的：一两句话写出举办这次活动的意义。活动时间和地点：写清楚具体时间和场地。活动分工：分条列出哪些人负责节目统筹、场地布置、物资采购、主持、音响等。活动流程：这是主体部分，按时间顺序分条列出活动的各个环节，如“1. 主持人开场 2. 校长/老师致辞 3. 节目表演 4. 互动游戏 5. 交换毕业礼物 6. 合唱毕业歌 7. 合影留念”。注意事项：写出需要特别注意的事项，如安全问题、时间控制等。

3. 指导把活动流程写具体

活动流程是策划书的核心。每个环节简要写清楚内容和负责人。可以在节目表演部分留出填写具体节目的空位，因为节目可能还在征集中。流程安排要体现毕业主题，如设置回忆环节、感恩环节、展望环节等。

4. 指导语言简洁清晰

策划书的语言要准确、简洁，让人一看就明白该做什么、怎么做。不需要描写和抒情。职责分工要明确到人，时间节点要清晰。

第三环节：作后评改——评规范，验可行

1. 同桌互读

交换读策划书，读完后说说：这份策划书格式规范吗？活动安排清楚吗？分工明确吗？按照这份策划书能办好活动吗？

2. 自我修改

检查：策划书各部分是否齐全？活动流程是否合理？分工是否明确？语言是否简洁？进行修改。

3. 全班“最佳策划案”评选

展示几份策划书，全班同学从“格式规范、安排合理、体现毕业主题、可行性强”等方面进行评选。如果班级真的要举办毕业联欢会，可以综合大家的策划案，形成最终的正式策划，让这次习作成为一次真实的活动筹备。

### 四、评价标准参考

1. 基础过关：策划书格式基本正确，能写出活动的基本安排，语句通顺。

2. 良好达标：格式规范，活动安排比较具体，分工基本明确。

3. 优秀进阶：格式规范，活动安排具体合理，流程清晰，分工明确，体现毕业联欢会的特殊意义，可行性强。
