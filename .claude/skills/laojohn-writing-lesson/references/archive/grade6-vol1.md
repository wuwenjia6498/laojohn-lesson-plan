> 老约翰分级对应:L6。

## 六年级上册·第一单元 习作《变形记》

```meta
册: 六年级上册
任务: 第一单元 习作《变形记》
文体: 想象·变形
关键词: 变形 视角 经历
分级: L6
```

### 一、习作要求（教学目标）

1. 发挥想象，写一个“变形”后的故事：能想象自己变成另一种事物，如动物、植物、物品、自然现象等，以第一人称“我”的视角来写变形后的经历。

2. 把变形后的经历写清楚：能围绕变形后的身份，写出自己所看、所听、所做、所想，把事情的发展过程写完整。

3. 写出变形后世界的“新”和“奇”：能以变形后独特的视角来观察和感受世界，写出与原来不一样的新奇体验。

4. 在故事中融入自己的思考：能在变形故事中，通过新奇有趣的经历，含蓄地表达自己对生活、社会或自然的某种感悟或思考。

### 二、教学重难点

重点：引导学生展开丰富而合理的想象，以第一人称写好变形后的经历。

难点：帮助学生在新奇有趣的想象中，自然地融入自己的情感和思考，让故事不仅好玩，还有一点余味。

### 三、教学建议（核心教学环节）

第一环节：作前指导——选变形，想经历

1. 回顾课文，激发变形愿望

引导学生回顾本单元学过的课文《草原》《丁香结》等，说说作者是怎样通过独特的视角来感受世界的。引出话题：如果你能变成另一种东西，你最想变成什么？为什么？

2. 选定变形对象，打开想象空间

引导学生从不同类别中选定变形对象：动物（蚂蚁、小鸟、鱼、蝴蝶等）、植物（一棵树、一朵花、一棵小草等）、物品（路灯、书本、雨伞、铅笔等）、自然现象（风、云、雨滴、雪花等）。选定后想一想：变形之后，你是什么样子的？你能做什么？你眼中的世界和原来有什么不同？

3. 构思变形后的经历

引导学生围绕变形后的身份构思一个完整的故事：你变形后去了哪里？经历了什么？遇到了什么人或其他事物？发生了什么有趣、惊险或感人的事？结果怎样？把故事的起因、经过、结果想清楚。故事要有情节的起伏，不要平铺直叙。

4. 用“我”的视角来感受

强调本次习作要用第一人称来写，自己就是那个变形后的事物。要写出“我”在那个形态下独特的感受：作为一只蚂蚁，“我”看一粒米就像一座山；作为一盏路灯，“我”每天晚上看着不同的人经过……用变形后的眼睛和心灵去感受世界。

第二环节：作中指导——用“我”眼，写奇遇

1. 明确习作要求

写自己变成另一种事物的经历。用第一人称来写。把变形后的经历写完整、写具体。写出变形后独特的感受和体验。想象丰富合理，故事有趣。

2. 指导写作结构

提供参考结构：开头写自己是怎么变形的，引出变形后的新身份。中间写变形后的一两件主要经历，把最精彩、最奇特的部分写具体。结尾可以写变形结束后的感悟，或者变形后留在那个世界的感想。

3. 指导写好变形后的独特感受

这是本次习作最出彩的地方。写变形后“我”看到的世界跟人看到的有何不同，如蚂蚁眼中草地像森林、水滴眼中水龙头像瀑布。写出因形体变化带来的新奇体验和感受。把这种“新”和“奇”写细致。

4. 指导在故事中融入思考

在经历中或结尾处，自然地写一点变形后的感悟。比如变成一棵树后感受到被砍伐的疼痛，呼吁保护森林；变成一盏路灯后看到了深夜环卫工人的辛苦，懂得了感恩。思考要通过故事自然流露，不说教。

第三环节：作后评改——读变形，赏新奇

1. 同桌互读

交换读习作，读完后说说：你觉得他变形后的经历新奇吗？哪里写得最有趣或最打动人？

2. 自我修改

检查：变形后的视角是否统一（始终是“我”在看、在听、在想）？经历是否完整具体？有没有写出变形后独特的感受？进行修改。

3. 全班“变形分享会”

请几位同学在全班朗读自己的变形故事。可以让大家闭上眼睛听，看是否能在脑海中浮现变形后的世界。评选“最奇妙的变形”“最动人的变形故事”“最有深度的变形”等。引导从“想象丰富、视角独特、感受新奇、有思考”等方面进行点评。

### 四、评价标准参考

1. 基础过关：能写出自己变成另一种事物的基本经历，用第一人称，故事基本完整。

2. 良好达标：变形后的视角比较统一，经历写得比较具体，有新奇感。

3. 优秀进阶：想象奇妙独特，变形视角运用自如，经历生动具体，写出了新奇的感受和体验，有打动人心的思考。

## 六年级上册·第二单元 习作《多彩的活动》

```meta
册: 六年级上册
任务: 第二单元 习作《多彩的活动》
文体: 记事·场面
关键词: 活动 点面结合 场面
分级: L6
```

### 一、习作要求（教学目标）

1. 选一次印象深刻的活动来写：能从校内外各种活动中，选择一次自己亲身参与的、印象深刻的活动来写。

2. 用“点面结合”的方法写场面：能既写整个活动的宏大场面（面），又写个别人物的具体表现（点），把活动场面写清楚、写生动。

3. 把重点部分写具体：能在整个活动过程中，选取一两个最精彩的环节作为重点来展开写。

4. 写出活动中的体会和感受：在记叙活动的过程中，写出自己的真实感受和参加活动后的收获。

### 二、教学重难点

重点：指导学生运用“点面结合”的方法把活动场面写具体。

难点：帮助学生在写大场面的同时，选取有代表性的“点”进行细致刻画，做到既有整体感又有细节感。

### 三、教学建议（核心教学环节）

第一环节：作前指导——忆活动，定格画面

1. 打开思路，选定活动

引导学生回忆参加过的各种活动：学校的（运动会、文艺汇演、升旗仪式、义卖活动、拔河比赛等）、班级的（班队活动、联欢会、朗诵比赛等）、校外的（参观博物馆、春游秋游、社区志愿服务、研学旅行等）。选定一次自己印象最深、最有话可写的活动。

2. 回顾活动过程，理清顺序

想一想这次活动的过程：活动前是什么场景？活动是怎么开始的？中间有哪些环节？哪个环节最精彩？活动是怎么结束的？用简单的提纲或流程图把整个过程梳理清楚。

3. 定格最精彩的场面

引导学生从整个活动中选定一两个最精彩的场面作为重点来写。把这个场面像拍照一样“定格”在脑海中：你看到了什么？整个场面是怎样的？（这就是“面”）场面中有哪些特别引人注目的人物？他们在做什么？（这就是“点”）把“面”和“点”都想清楚。

4. 运用“点面结合”进行口述练习

在小组内口头描述选定的精彩场面。先说整个场面的气氛和景象，再聚焦到一两个具体人物的动作、神态、语言。组员评价是否既有整体感又有细节。

第二环节：作中指导——写场面，抓点面

1. 明确习作要求

写一次印象深刻的活动。运用“点面结合”的方法写场面。把活动过程写清楚，重点部分写具体。写出自己的感受和体会。语句通顺，描写生动。

2. 指导写作结构

提供参考结构：开头交代活动的时间、地点和名称，用一句话总写这次活动的感受。中间按顺序写活动过程，重点部分用“点面结合”的方法展开。结尾写活动结束后的感受和收获。

3. 指导写好“面”

写“面”要写出场面的整体气氛。可以从这些角度写：视觉上的整体印象（操场上人山人海、红旗飘扬等）、听觉上的整体感受（呐喊声此起彼伏、掌声雷动等）、整体氛围（紧张激烈、欢乐祥和等）。用简洁的语言描绘出大画面。

4. 指导写好“点”

在“面”的基础上，选取一两个有代表性的人物进行特写。可以是一个表现最突出的同学、一个让人感动的瞬间、一个自己最难忘的动作。写清楚这个人的动作、神态、语言，以及周围人对他（她）的反应。点的描写要具体细腻，与大场面形成对比和呼应。

第三环节：作后评改——读场面，验结合

1. 同桌互读

交换读习作，读完后说说：活动的场面写清楚了吗？你感受到“面”和“点”的结合了吗？哪里写得最有画面感？

2. 自我修改

检查：过程顺序清楚吗？“点面结合”的方法运用了吗？重点部分写具体了吗？感受写出来了吗？进行修改。

3. 全班展示

选几篇写不同类型活动的习作在全班展示。可以请作者朗读重点场面部分，让其他同学闭上眼睛想象画面。引导从“顺序清楚、点面结合、场面生动、感受真实”等方面进行点评。

### 四、评价标准参考

1. 基础过关：能写清楚一次活动的过程，有简单的场面描写，语句通顺。

2. 良好达标：过程清楚，能用“点面结合”的方法写场面，重点部分比较具体。

3. 优秀进阶：点面结合自然巧妙，场面描写既有气势又有细节，活动过程生动再现，感受真实深刻。

## 六年级上册·第三单元 习作《____让生活更美好》

```meta
册: 六年级上册
任务: 第三单元 习作《____让生活更美好》
文体: 感受·议论
关键词: 美好 理由 事例
分级: L6
```

### 一、习作要求（教学目标）

1. 把题目补充完整，确定写作话题：能从“运动、旅行、种花、科技、微笑、诚信、梦想、创意”等话题中选择一个，或自己确定一个，把题目补充完整。（2026-09-14 按用户课本页更正话题词：旧版“集邮”换为现行“科技”，八词按课本顺序）

> 教材习作页（2026-09-14 据用户课本页抄录，供详案引用）：题面要求原句“写之前想一想它是怎么影响你的生活的，为什么让你觉得生活更美好。写的时候注意把原因写具体。”页上三个学生气泡：科技（概述：科技发展带来便利，去爷爷奶奶家坐高铁比以前快两个小时，妈妈买菜扫码支付方便快捷）、音乐（听音乐唱歌让我放松开心）、微笑（爸爸妈妈、老师、陌生人的微笑让我感到温暖）。页末另有“共享美好生活”主题班会建议。

2. 写清楚让生活更美好的原因：能写出是什么让生活更美好，通过具体的事例或经历来表现它为什么能让生活变得更美好。

3. 用具体事例来表达观点：不空洞地说“它很好”，而是通过写一两件具体的事，让读者感受到它带来的美好变化。

4. 表达真情实感：在叙事和议论中自然表达自己的真实感受和体会。

### 二、教学重难点

重点：指导学生通过具体事例来说明某种事物或品质为什么让生活更美好。

难点：帮助学生在叙事的基础上进行一定的议论和抒情，把“美好”写具体、写深刻。

### 三、教学建议（核心教学环节）

第一环节：作前指导——补题目，选事例

1. 理解题意，补充题目

引导学生理解“____让生活更美好”这个半命题作文。横线上可以填一种品质、一种爱好、一种习惯、一种情感、一种态度等。从教材提供的参考话题中打开思路，鼓励学生自己想一个与众不同的词。选定后将题目补充完整。

2. 思考“为什么让生活更美好”

想一想：你填的这个事物，是怎样让你的生活变得更美好的？它给你带来了什么变化？可以从以下几个方面思考：它让你的心情变得怎样？它让你学到了什么？它让你的人际关系发生了什么变化？它让你对生活有了什么新的认识？

3. 选取具体的事例

用一个具体的事例来“证明”它确实让生活更美好。这件事可以是自己亲身经历的，也可以是亲眼所见的。把这件事的经过想清楚：时间、地点、人物、起因、经过、结果。在事例中要体现出“美好”在哪里。

4. 口头交流，互相启发

在小组内说说自己选的话题和准备写的事例。组员评价：这个事例能说明“它让生活更美好”吗？

第二环节：作中指导——用事例，写美好

1. 明确习作要求

把题目补充完整。写清楚是什么让生活更美好。用具体的事例来说明。写出自己的真实感受和体会。语句通顺，内容清楚。

2. 指导写作结构

提供参考结构：开头点明话题，用一两句话总写“它”为什么让生活更美好。中间用一两个具体事例来展开说明，把事例写具体，在叙事中体现“美好”。结尾再次点题，抒发自己的感受和体会。

3. 指导把事例写具体

在叙事的过程中，要把最能体现“美好”的那个时刻、那个画面写细致。写清楚当时的情境、人物的言行、自己的内心活动。让读者通过具体的事例感受到“美好”的所在。

4. 指导叙议结合

在写事例的基础上，适当加入自己的议论和抒情。比如在写完一件事后，简单议论这件事让自己懂得了什么；在结尾可以抒发这种事物给自己的生活和成长带来的积极影响。议论要基于事例，不要空发感慨。

第三环节：作后评改——读美好，验说服力

1. 同桌互读

交换读习作，读完后说说：你被说服了吗？感受到“它”让生活更美好了吗？事例有没有说服力？

2. 自我修改

检查：题目是否通顺？事例是否具体？有没有把“美好”写出来？议论和抒情是否自然？进行修改。

3. 全班展示

选几篇写不同话题的习作在全班展示。可以给每篇习作配上相关的图片或音乐。评选“最能打动人的美好”“最有说服力的事例”等。引导从“话题明确、事例具体、感受真实、叙议结合得当”等方面进行点评。老师总结生活中各种美好的事物和品质。

### 四、评价标准参考

1. 基础过关：能把题目补充完整，写出一种事物让生活更美好的简单原因，语句通顺。

2. 良好达标：话题明确，有具体事例，能写出“美好”的基本感受。

3. 优秀进阶：事例典型具体，叙事生动，“美好”的感受真切，叙议结合自然，有感染力和说服力。

## 六年级上册·第四单元 习作《笔尖流出的故事》

```meta
册: 六年级上册
任务: 第四单元 习作《笔尖流出的故事》
文体: 虚构·创作
关键词: 虚构 环境 情节 人物
分级: L6
```

### 一、习作要求（教学目标）

1. 根据环境和人物创编故事：能从教材提供的三组环境和人物中选择一组，或自己创设，展开想象，创编一个故事。

2. 故事要围绕主要人物展开：能以选定的主要人物为中心，写清楚他们之间发生的故事，有起因、经过和结果。

3. 情节要完整、有起伏：能在故事情节中设置一定的冲突、转折或悬念，使故事曲折有趣。

4. 尝试写出人物心理和情感变化：能在叙事过程中，注意描写人物的内心活动，展现人物的情感变化。

### 二、教学重难点

重点：指导学生根据给定或自设的环境和人物，创编一个情节完整的故事。

难点：帮助学生在给定要素的基础上展开合理想象，写出有冲突、有转折、有情感的故事，避免平淡。

### 三、教学建议（核心教学环节）

第一环节：作前指导——选要素，编情节

1. 理解写作任务，选择创作要素

引导学生看教材提供的三组环境和人物，每组都包含一个特定的环境和一组人物。让学生选择自己最感兴趣的一组，也可以参考这种形式自己创设环境和人物。确定故事的基本要素。

2. 围绕要素展开想象，构思故事

围绕选定的环境和人物想故事：这是一个怎样的环境？人物之间是什么关系？他们在这样的环境中会发生什么故事？引导学生构建故事框架：故事的起因是什么？经过是怎样的？有什么冲突或困难？结果怎样？试着构思一个有开头、发展、高潮和结局的完整故事。

3. 设计情节的起伏

一个吸引人的故事需要有起伏。引导学生想一想：故事中会出现什么意外或转折？人物会遇到什么麻烦？他们是怎么应对的？有没有让读者意想不到的地方？在构思中加入一两个“波折”，让故事不平淡。

4. 口头讲述，组内打磨

在小组内讲述自己构思的故事。组员听完后评价：故事完整吗？有没有吸引人的地方？哪里还可以更曲折或更有趣？提出建议。

第二环节：作中指导——写故事，求曲折

1. 明确习作要求

根据选定的环境和人物创编一个故事。故事围绕主要人物展开。情节完整，最好有起伏。尝试写出人物的心理和情感变化。语句通顺，故事吸引人。

2. 指导写作结构

提供参考结构：开头描写环境，引出主要人物，交代故事的背景。中间写故事的发展和高潮，详写人物遇到的冲突或转折，写出人物是怎么应对的。结尾写故事的结果，可以交代人物的变化或故事的结局。

3. 指导写好情节的起伏

在写故事经过时，设置至少一个矛盾或困难，让人物面临选择和挑战。把这个矛盾写具体：困难是什么？人物当时是怎么想的、怎么做的？解决困难的过程不要一笔带过，要展开来写，制造一点悬念。

4. 指导写好人物心理

在关键情节处，穿插人物的内心独白或心理描写。如遇到困难时可以写心里的挣扎，做出决定时可以写内心的坚定，故事结束时可以写心里的感受。心理描写让读者更贴近人物，情感变化也推动情节的发展。

第三环节：作后评改——读故事，评吸引

1. 同桌互读

交换读故事，读完后说说：故事吸引你吗？情节有没有起伏？人物的心理和情感变化写出来了吗？

2. 自我修改

检查：故事是否完整？有没有设计情节的起伏？环境描写是否起到烘托作用？人物心理是否写出来了？进行修改。

3. 全班“故事会”

举办“班级故事会”，请几位同学在全班讲述自己创编的故事。评选“最吸引人的故事”“最出人意料的情节”“最打动人心的人物”等。引导从“情节完整、有起伏、人物鲜明、环境描写恰当”等方面进行欣赏和点评。

### 四、评价标准参考

1. 基础过关：能根据环境和人物创编一个完整的故事，语句通顺。

2. 良好达标：故事完整，围绕人物展开，情节有一定的起伏，有简单的心理描写。

3. 优秀进阶：情节曲折有致，人物形象鲜明，环境描写烘托气氛好，心理描写细腻，故事引人入胜。

## 六年级上册·第五单元 习作《围绕中心意思写》

```meta
册: 六年级上册
任务: 第五单元 习作《围绕中心意思写》
文体: 立意选材
关键词: 中心 选材 围绕
分级: L6
```

### 一、习作要求（教学目标）

1. 选择一个感受最深的汉字来写：能从教材提供的汉字中选择一个，或自己选一个，作为自己要表达的中心意思。

2. 围绕中心意思选择材料：能围绕选定的汉字所代表的意思，选择适合的材料（事例、场景、感受等）来写。

3. 从不同方面或选取不同事例来写：能从几个不同的方面，或用几个不同的事例，来共同表达同一个中心意思。

4. 学习围绕中心组织材料：初步学习用一个核心意思统率全文，所有材料都为中心服务。

### 二、教学重难点

重点：指导学生围绕选定的中心意思来选择和组织材料。

难点：帮助学生在众多可写的内容中，筛选出最能表达中心意思的材料，做到不跑题、不散漫。

### 三、教学建议（核心教学环节）

第一环节：作前指导——选汉字，定中心

1. 理解题意，感受汉字的深意

引导学生看教材提供的一组汉字：甜、乐、泪、暖、悔、望、迷、变、忙、寻、让……每个字都代表一种感受或一种状态。让学生选一个最有感触、最能引发联想的字。说说看到这个字想到了什么。

2. 明确中心意思

选定的汉字就是本次习作要表达的“中心”。想一想：这个字代表了什么意思？你想通过这篇习作表达怎样的感受或想法？比如选“甜”，中心意思可以是“生活中处处有甜”“帮助别人心里很甜”等。把中心意思想明确。

3. 围绕中心选择材料

想一想：哪些事、哪些经历能体现这个中心意思？可以围绕中心从不同方面想，也可以想几个不同的事例。把想到的列出来，然后筛选出最能表达中心、最有话可写的材料。去掉那些和中心意思关系不大的内容。

4. 安排材料的详略

选定材料后，确定哪些材料详写、哪些略写。最能表达中心意思的事例要详写，占主要篇幅；次要材料可以略写或简要带过。

第二环节：作中指导——扣中心，选材料

1. 明确习作要求

选择一个感受最深的汉字来写。围绕这个汉字表达的中心意思，选择合适的材料。从不同方面或选取不同事例来写。所有材料都围绕中心，不跑题。语句通顺，中心明确。

2. 指导写作结构

提供参考结构：开头点出选定的汉字，用一句话写出自己的理解和感受，点明中心意思。中间从不同方面或用不同事例来展开，每个方面或事例写一段，紧紧围绕中心意思来写。结尾再次点题，深化中心意思。

3. 指导围绕中心写具体

在写每个事例或每个方面时，要把和中心意思相关的部分写具体。比如写“甜”的事例，就要写出“甜”在哪里：是嘴里甜还是心里甜？为什么觉得甜？当时的感受是怎样？时刻牢记要表达的“中心”，不写和中心无关的内容。

4. 指导材料的组织和过渡

如果写几个事例，注意事例之间的过渡要自然。可以用“说到甜，还有一件事让我印象更深”“生活中的甜，不光来自成功，也来自挫折后的成长”这样的句子来连接。

第三环节：作后评改——查中心，验集中

1. 同桌互读

交换读习作，读完后说说：这篇习作的中心意思是什么？你读出来了吗？有没有哪段和中心关系不大？

2. 自我修改

检查：中心意思是否明确？所有材料是否围绕中心？有没有跑题或无关的内容？详略安排是否恰当？进行修改。

3. 全班展示

选几篇选不同汉字、有不同中心意思的习作在全班展示。先让听众猜作者的中心意思是什么，看是否能够准确感知。引导从“中心明确、材料集中、详略得当”等方面进行点评。

### 四、评价标准参考

1. 基础过关：能选定一个汉字，围绕它写出基本内容，语句通顺。

2. 良好达标：中心意思比较明确，所选材料能围绕中心，内容比较集中。

3. 优秀进阶：中心意思鲜明突出，材料典型且紧紧围绕中心，详略得当，立意有一定深度。

## 六年级上册·第六单元 习作《学写倡议书》

```meta
册: 六年级上册
任务: 第六单元 习作《学写倡议书》
文体: 应用文·倡议书
关键词: 倡议书 格式 建议
分级: L6
```

### 一、习作要求（教学目标）

1. 了解倡议书的格式和作用：知道倡议书是用来号召大家共同做某件事或不做某件事的应用文，掌握其基本格式。

2. 把倡议的内容写清楚：能把为什么倡议、倡议大家做什么、具体怎么做等内容分条列项写清楚。

3. 语言有号召力、有说服力：能运用恰当的措辞和语气，让倡议书有感染力和号召力，让人愿意响应。

4. 关注身边的问题：能从校园、社区或社会生活中发现问题，通过写倡议书表达自己的关注和思考，培养社会责任感。

### 二、教学重难点

重点：指导学生掌握倡议书的格式，把倡议的内容写清楚、有条理。

难点：帮助学生在倡议书中做到语言有说服力和号召力，既要讲清道理，又要能打动人心。

### 三、教学建议（核心教学环节）

第一环节：作前指导——选话题，理内容

1. 认识倡议书

出示一两则典型的倡议书范例，让学生了解倡议书是什么、在什么情况下使用。引导学生发现倡议书的特点：有明确的倡议对象、有清楚的倡议内容、语言有号召力。

2. 选定倡议话题

引导学生从身边发现问题，确定倡议的话题。可以从以下范围思考：校园里的（节约用水、爱护图书、文明课间、保护花草等）、家庭或社区里的（垃圾分类、节约粮食、关爱老人等）、社会上的（保护环境、文明出行、拒绝浪费等）。选定一个自己最有感触、最有话可说的话题。

3. 理清倡议内容

确定话题后，想一想：为什么提出这个倡议？（把原因和重要性想清楚）倡议大家怎么做？（把具体要求想清楚，最好分条列项）这样做的意义是什么？（把好处和影响想清楚）把这些内容用提纲整理出来。

第二环节：作中指导——依格式，写倡议

1. 明确习作要求

写一份倡议书。格式正确。把倡议的原因、内容和意义写清楚。语言有号召力。书写工整。

2. 指导倡议书格式

逐项指导倡议书的组成部分：标题（居中写“关于……的倡议书”或直接写“倡议书”）、称呼（顶格写倡议的对象，如“同学们”“全体少先队员”等，后面加冒号）、正文（另起一行空两格，写倡议的原因、具体内容和号召大家行动起来）、署名和日期（右下方，先署名后日期）。正文中倡议的具体内容宜分条列出，每条另起一行。

3. 指导正文写作

正文一般分为三部分：第一部分写倡议的原因和目的，要简洁有力，让人明白为什么要响应这个倡议。第二部分写倡议的具体内容，每一条写一个方面的要求，用“一、二、三”或“第一、第二、第三”列出。第三部分写号召性的结束语，如“让我们行动起来，从自己做起，从现在做起”。

4. 指导语言的号召力

倡议书的语言要真诚、有感染力。可以用“我们”拉近与读者的距离，而不是用“你们”来说教。可以用“让我们……”的句式来号召。可以适当运用排比句增强气势，但不要过于夸张。

第三环节：作后评改——评规范，验号召

1. 同桌互读

交换读倡议书，读完后说说：格式正确吗？倡议的内容清楚吗？你有被号召的感觉吗？

2. 自我修改

检查：格式各大部分是否正确？倡议原因是否说清楚？具体内容是否条理分明？语言是否有号召力？进行修改。

3. 全班“优秀倡议书”评选

将全班倡议书张贴在教室“倡议墙”上，组织全班同学阅读，投票评选“最有意义的倡议”“最有号召力的倡议”“格式最规范的倡议”等。对于优秀的倡议，可以鼓励学生真的提交给学校或社区。

### 四、评价标准参考

1. 基础过关：格式基本正确，能写出倡议的基本内容，语句通顺。

2. 良好达标：格式正确，倡议内容清楚，有条理，语言有一定号召力。

3. 优秀进阶：格式规范，倡议内容具体实在、条理清晰，语言有感染力和号召力，能打动人心。

## 六年级上册·第七单元 习作《我的拿手好戏》

```meta
册: 六年级上册
任务: 第七单元 习作《我的拿手好戏》
文体: 记事·详略
关键词: 拿手好戏 详略安排
分级: L6
```

### 一、习作要求（教学目标）

1. 选一项自己最拿手的本领来写：能选择自己最擅长、最引以为傲的一项本领或特长来写。

2. 把拿手好戏练成的过程或展示的情形写清楚：能写清楚这项本领是怎么练成的，或者是怎样展示的，把过程写具体。

3. 详写最精彩的展示：在写展示本领的过程中，能选取最精彩、最得意的部分进行重点描写。

4. 写出自信和自豪的感受：在习作中自然表达出对自己这项本领的自信和自豪之情。

### 二、教学重难点

重点：指导学生把展示拿手好戏的过程写具体，突出最精彩的部分。

难点：帮助学生在写“拿手”的过程中自然流露出自信和自豪，而不是简单地说“我很厉害”。

### 三、教学建议（核心教学环节）

第一环节：作前指导——亮绝活，说过程

1. 打开思路，选定拿手好戏

引导学生理解“拿手好戏”就是自己最擅长、最有自信的本领。可以从不同方面打开思路：文艺类的（弹琴、唱歌、跳舞、画画、书法等）、体育类的（游泳、打球、跳绳、轮滑等）、生活类的（做饭、做手工、修理东西等）、学习类的（口算、背诵、做实验等）、其他类的（变魔术、讲故事、逗人笑等）。选定一项自己最有话可说的。

2. 回忆练成的过程

想一想：这项本领是怎么练成的？是谁教你的，还是自学的？从不会到会经历了什么？有没有遇到过困难？是怎么克服的？这个过程可以略写，但要让读者知道这项本领来之不易。

3. 聚焦最精彩的一次展示

这是本次习作的重点。回忆一次最能体现你这项本领厉害的展示：是在什么场合？有哪些人在场？你表演或展示的时候是怎样的？最精彩的部分是哪个瞬间？当时你心里是怎么想的？观众有什么反应？把这次展示的情形想清楚。

4. 口头“亮绝活”

在小组内口头介绍自己的拿手好戏。按照“是什么本领——怎么练成的——最精彩的一次展示——当时的感受”的顺序来说。组员听后评价：最精彩的地方说清楚了吗？感受到你的自信和自豪了吗？

第二环节：作中指导——写展示，亮精彩

1. 明确习作要求

写自己的拿手好戏。写清楚是怎么练成的或怎么展示的。把最精彩的展示部分写具体。写出自己的感受。语句通顺，内容清楚。

2. 指导写作结构

提供参考结构：开头点出自己的拿手好戏是什么，用一句话亮出自信。接着简单写这项本领是怎么练成的，可略写。中间详写一次最精彩的展示，把当时的情形、自己的动作和观众的反应写具体。结尾写出自己的感受和想法，再次点题。

3. 指导写好展示的精彩瞬间

对于最精彩的展示部分，要像放慢镜头一样写细致。写自己是怎么做的（精准的动作、熟练的操作等），写当时周围的环境和观众的表情、反应（他们的惊叹、掌声、喝彩等），写自己心里的感觉（胸有成竹、心无旁骛、表演结束后的满足等）。把这些交织在一起写，让读者仿佛亲眼看到。

4. 指导写出自信和自豪

自信不是喊出来的，而是通过描写展现出来的。写展示时行云流水的动作、面对挑战时的镇定自若、完成后的淡然一笑，都能体现自信。自豪可以在结尾适当抒发，但要基于前面的具体描写。

第三环节：作后评改——读好戏，赏精彩

1. 同桌互读

交换读习作，读完后说说：你感受到他的拿手好戏有多“拿手”了吗？哪里写得最精彩？有没有写出自信的感觉？

2. 自我修改

检查：本领写清楚了吗？展示过程写具体了吗？最精彩的部分写细致了吗？感受写出来了吗？进行修改。

3. 全班“拿手好戏展示会”

结合习作展示，可以举办一个真正的“拿手好戏展示会”。请几位同学先朗读习作中的精彩展示部分，再进行现场表演。将习作和真实本领结合起来，让习作更加鲜活。引导从“过程清楚、展示精彩、自信自然”等方面进行点评。

### 四、评价标准参考

1. 基础过关：能写出自己的拿手好戏，有基本的展示过程，语句通顺。

2. 良好达标：过程清楚，展示部分写得比较具体，能写出简单的感受。

3. 优秀进阶：展示过程写得精彩生动，细节丰富，自信和自豪之情自然流露，让读者由衷佩服。

### 三、教学建议（核心教学环节）

第一环节：作前指导——选“你”，忆场景

1. 确定倾诉对象

引导学生理解“你”可以是谁：可以是亲人（爸爸、妈妈、爷爷、奶奶、兄弟姐妹等）、老师、同学、朋友，甚至可以是偶遇的陌生人。选定一个在自己生命中扮演过重要角色、让自己由衷想说“有你，真好”的人。

2. 回忆那些“有你，真好”的时刻

想一想：为什么觉得“有你，真好”？他（她）为你做过什么？他（她）的存在给你带来了什么？引导学生回忆几个具体的场景：可能是在你困难时伸出援手，在你伤心时给予安慰，在你迷茫时指引方向，或者只是日常中最平凡的陪伴和关爱。选择两三个最有代表性的场景来写。

3. 把每个场景想具体

选定场景后，把每一个都像放电影一样在脑海中重现：当时的时间、地点、环境是怎样的？“你”做了什么、说了什么？“你”的表情、动作是怎样的？我当时是什么感受？把这些细节想清楚，为写作做准备。

4. 确定“你”的称呼方式

整篇习作都要用第二人称“你”来写，就像在面对面和这个人说话。想好用什么样的语气：是深情感谢的语气，还是温暖回忆的语气。

第二环节：作中指导——用“你”称，写场景

1. 明确习作要求

确定要写的“你”是谁。围绕“有你，真好”这个主题来写。选取几个具体的场景，把场景写具体。用第二人称“你”来写。表达出真挚的感情。

2. 指导写作结构

提供参考结构：开头直接倾诉，说出“有你，真好”这句话，引出“你”是谁。中间用几个自然段写不同的场景，每个场景都体现出“有你，真好”。结尾再次点题，总结“你”对自己的重要性。

3. 指导写好每个场景

每个场景都要写清楚时间、地点、事情的经过。重点写出“你”的言行举止，以及当时自己的内心感受。每个场景写完后，可以有一句简短的点题，如“那一刻，我觉得，有你真好”，但不要每个场景都用同样的句式。

4. 指导情景交融

在场景描写中自然融入情感，不单独大段抒情。比如写到“你”在雨中等我的场景时，通过写“你”淋湿的头发、焦急的眼神这些细节，自然流露出“有你真好”的感动。情感不架空，全都落在具体的画面上。

5. 指导全文用“你”的写法

提醒始终用“你”来称呼写作对象。文中不出现这个人的名字或“他/她”等第三人称。用“你”让人感觉亲近、真诚，仿佛在与对方面对面说话。这是本次习作语言上的一大特点。

第三环节：作后评改——读场景，品真情

1. 同桌互读

交换读习作，读完后说说：你读出来“你”是谁了吗？哪些场景让你感受到“有你，真好”？哪里最打动你？

2. 自我修改

检查：是否全文用“你”来称呼？场景是否具体？情感是否真挚自然？进行修改。

3. 全班展示与分享

请几位同学在全班朗读自己的习作。由于这类习作情感真挚且私密，朗读时要注意尊重作者的情绪，营造安静、温馨的倾听氛围。引导从“场景具体、情感真挚、用‘你’自然、主题鲜明”等方面进行点评。若有学生愿意，可鼓励课后将习作送给那个“你”听。

### 四、评价标准参考

1. 基础过关：能确定“你”是谁，写出相关的场景，用“你”来称呼，语句通顺。

2. 良好达标：场景比较具体，能围绕“有你，真好”主题，情感比较真挚。

3. 优秀进阶：场景描写生动具体，情景交融，情感真挚动人，第二人称运用自然贴切，让读者感同身受。
