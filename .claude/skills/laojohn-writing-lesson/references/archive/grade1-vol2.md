> 老约翰分级对应:L1。

## 册级说明

从这一册开始，语文园地中正式出现“写话”练习。

但一年级下册的写话属于起步阶段，要求是“对写话有兴趣，留心周围事物，写自己想说的话”（课标第一学段目标）。

教学中不强调篇幅和格式，重点是激发表达欲望，能用一两句或几句话把意思说清楚，不会写的字可以用拼音代替。

以下是该册全部写话任务的详细内容：

## 一年级下册·语文园地二 写话《我多想……》

```meta
册: 一年级下册
任务: 语文园地二 写话《我多想……》
文体: 写话起步·愿望
关键词: 愿望 句式仿写 我多想
分级: L1
```

### 一、写话要求（教学目标）

1. 激发表达愿望：以“我多想……”为开头，写下自己的愿望，培养书面表达的兴趣。

2. 学习写清楚理由：不仅写出想做什么，还能尝试写一写为什么这么想，把意思表达得更完整。

3. 模仿句式进行表达：借助例句“我多想去看看，我多想去看看”的句式，学习用重复句式表达强烈愿望。

4. 正确使用标点：初步学习使用逗号和句号。

### 二、教学重难点

重点：引导学生打开思路，大胆说出并写下自己的愿望。

难点：帮助学生从“想做什么”延伸到“为什么这么想”，把句子写完整、写清楚。

### 三、教学建议（核心教学环节）

第一环节：作前指导——聊愿望，打开思路

1. 读例句，发现特点

出示例句“我多想去看看，我多想去看看”，让学生读一读，说说发现了什么。引导学生关注：这句话用了两次“我多想”，表达的心情非常强烈；两个“看看”后面还可以接着说想看什么、为什么想看。

2. 畅谈愿望，激活思维

老师可以先示范：“老师也有一个愿望。我多想去草原骑马，看看一望无际的绿色，感受风吹过脸庞的感觉。”然后请学生想一想：你有什么特别想做的事？特别想去的地方？特别想见的人？特别想实现的愿望？鼓励学生从不同角度说愿望，如：想去的地方（北京、海边、迪士尼）、想做的事（学会游泳、养一只小狗）、想见的人（远方的爸爸妈妈、宇航员）、想实现的梦想（变成小鸟、当老师）。

3. 追问理由，把话说完整

学生说出一个愿望后，老师追问：“你为什么这么想去那里？”“你想在那里做什么？”引导学生在“我多想……”之后，加上理由或具体想做的事，把一句话变成一个完整的意思。比如从“我多想去海边”变成“我多想去海边，看看蓝蓝的大海，在沙滩上捡贝壳”。

第二环节：作中指导——学句式，写下来

1. 回顾句式

让学生再次读例句，感受“我多想……，我多想……”的节奏。告诉学生：也可以用“我多想……，因为……”或者直接写“我多想……，……”的形式，不强求统一，关键是写出自己的真心话。

2. 动笔写话

提出写话要求：以“我多想”开头，写一两句话，写出自己的愿望。遇到不会写的字可以用拼音代替。写话时注意：开头空两格，标点占一格，逗号和句号要写清楚。

3. 个别指导

巡视时重点关注基础较弱的学生，可以先让他口头说一遍，再照着写下来。对能力较强的学生，可以鼓励他把理由写得更具体一些。

第三环节：作后评改——读愿望，共分享

1. 自己读一遍

写完后自己轻声读一读，看句子通不通顺，有没有漏掉的字。

2. 同桌互相读

同桌交换读愿望，读完说说对方的愿望是什么，为什么有这个愿望。如果同桌读不懂，说明句子可能没写清楚，可以修改。

3. 全班分享

选几份有代表性的愿望在全班读，可以是愿望特别有趣的、理由写得特别感人的、句子写得特别通顺的。老师重点表扬能写出真情实感的学生，保护学生的表达热情。

### 四、评价标准参考

1. 基础过关：能以“我多想”开头写出一句话，语句基本通顺。

2. 良好达标：能写出愿望并简单说明理由，标点使用基本正确。

3. 优秀进阶：能写出愿望和较充分的理由，语句通顺，有真情实感。

## 一年级下册·语文园地四 看图写话（无标题）

```meta
册: 一年级下册
任务: 语文园地四 看图写话（无标题）
文体: 看图写话
关键词: 看图 单图
分级: L1
```

### 一、写话要求（教学目标）

1. 学习观察图画：能按一定顺序观察图画，看清楚图上画了谁、在什么地方、在做什么。

2. 把观察到的写下来：用一两句话把图上的内容写清楚，做到语句通顺。

3. 展开合理想象：在观察的基础上，能对人物的对话、心情等进行简单想象，补充画面以外的内容。

4. 初步建立段落意识：知道写几句话时，要围绕一个意思写，句子之间要连贯。

### 二、教学重难点

重点：指导学生有序观察图画，把看到的和想到的写下来。

难点：帮助学生从“看到了什么”过渡到“想到了什么”，把静态画面写成有情节的小故事。

### 三、教学建议（核心教学环节）

第一环节：作前指导——有序观察，合理想象

1. 整体感知图画

出示图画，先让学生用一句话说说：图上大概画了什么？整体把握画面内容，明确图画主题。

2. 有序观察，逐个要素看仔细

引导学生按一定顺序观察，可以从上到下、从左到右，也可以从近到远、从主要人物到次要人物。逐一回答：图上画了谁？（给人物起个名字，方便后面写）他们在什么地方？（从环境细节判断，如草地、教室、公园）他们在做什么？（每个人物的动作、神态是怎样的）

3. 展开想象，让画面“动”起来

在观察的基础上追问：他们可能会说什么？他们心里在想什么？接下来会发生什么？鼓励学生根据自己的生活经验补充画面以外的内容，让写话更有意思。

4. 连起来说一说

请学生把观察到和想象到的内容连起来完整地说一遍，可以同桌互说、小组内说，为写话做铺垫。

第二环节：作中指导——搭框架，写清楚

1. 指导基本写作顺序

给学生一个简单的写话框架：先写“谁在什么地方做什么”，再写“他们是怎么做的、说了什么”，最后写“结果怎样或心情怎样”。不强求写全，但提供思路帮助学生把几句话写连贯。

2. 动笔写话，提出要求

写话要求：不会写的字用拼音代替；一句话说完用句号，句中停顿用逗号；开头空两格，标点占一格。

3. 关注书写习惯

提醒学生保持正确的坐姿和握笔姿势，书写工整。

第三环节：作后评改——读一读，改一改

1. 自我检查读

写完后自己读一遍，检查句子通不通顺，有没有漏字。

2. 同桌互读互评

同桌交换读，读完后互相说一说：我读懂了什么？还有什么地方不清楚？根据同学的意见进行修改。

3. 全班展示与点评

选几篇写话展示，老师从以下角度点评：观察是否有序、句子是否通顺、有没有写出自己的想法。多表扬，少批评，保护写话积极性。

### 四、评价标准参考

1. 基础过关：能写出图上有谁、在做什么，语句基本通顺。

2. 良好达标：能按顺序把观察到和想象到的写下来，句子通顺，标点基本正确。

3. 优秀进阶：观察细致，想象合理，句子连贯，能写出人物的对话或心情。

## 一年级下册·语文园地六 仿写句子（无标题）

```meta
册: 一年级下册
任务: 语文园地六 仿写句子（无标题）
文体: 句式仿写
关键词: 仿句 夏天
分级: L1
```

### 一、写话要求（教学目标）

1. 学习用叠词描写事物：仿照例句“荷叶圆圆的，绿绿的”，学习用叠词写出事物的形状、颜色等特征。

2. 积累语言材料：在仿写中积累叠词表达方式，丰富语言表达。

3. 观察事物特征：能抓住事物的形状、颜色、味道等特征进行描述。

4. 培养规范表达意识：正确使用形容词和“的”字结构。

### 二、教学重难点

重点：引导学生发现叠词的表达效果，学会用叠词描写事物特征。

难点：帮助学生在叠词之外，还能抓住事物多方面的特征，写出有层次的描述。

### 三、教学建议（核心教学环节）

第一环节：作前指导——读例句，发现语言奥秘

1. 朗读例句，感受节奏

出示“荷叶圆圆的，绿绿的”，让学生读一读，说说感觉。引导学生发现：用“圆圆的”写出了荷叶的形状，用“绿绿的”写出了颜色，读起来有节奏感，感觉很可爱。

2. 拓展积累叠词

让学生想一想，还知道哪些这样的叠词？表示形状的：长长的、圆圆的、方方的、弯弯的……表示颜色的：红红的、黄黄的、蓝蓝的、白白的……表示味道的：甜甜的、酸酸的、辣辣的……表示大小、质感的：大大的、小小的、软软的、硬硬的……可以分类板书，形成词汇库。

3. 练习用叠词说话

出示具体事物（如苹果、香蕉、西瓜），让学生试着用叠词描述。从说一个叠词开始，逐步增加到说两个、三个，从简单模仿到灵活运用。

第二环节：作中指导——选事物，动笔写

1. 选择写话对象

让学生从苹果、香蕉、西瓜等常见事物中选一个，也可以选自己喜欢的事物，如家里的玩具、文具、小动物等。

2. 明确写话要求

照样子写一写，写出事物的两三个特征，至少用上一个叠词。可以用“什么，怎样的，怎样的”的句式，也可以灵活表达。不会写的字用拼音代替，注意标点。

3. 分层要求

基础层：能写出一两个叠词描述事物。提高层：能写出多个方面的特征，叠词运用恰当，语言有美感。

第三环节：作后评改——赏读语言，感受美感

1. 读自己的作品

写完后读一读，听听句子是否顺口，叠词用得是否恰当。

2. 小组交流

在小组内读自己的写话，互相听听谁的描写最生动，谁用的叠词最有意思。

3. 全班赏析

展示优秀作品，老师重点引导赏析：哪些叠词用得特别准确？哪些句子写出了事物的特点？还可以引导学生发现，有的同学不仅写了颜色和形状，还写了味道、手感等其他方面。

### 四、评价标准参考

1. 基础过关：能写出一个叠词描述事物特征。

2. 良好达标：能用两个以上叠词写出事物的特征，语句通顺。

3. 优秀进阶：能抓住事物多方面的特征，叠词运用恰当生动，语言有节奏感。

## 一年级下册·语文园地七 话题写话（无标题）

```meta
册: 一年级下册
任务: 语文园地七 话题写话（无标题）
文体: 话题写话
关键词: 想法 一段话
分级: L1
```

### 一、写话要求（教学目标）

1. 先做后写，积累素材：通过亲手做一件事（洗袜子、做手工、打扫房间等），获得真实的写话素材。

2. 按顺序写过程：学习用上“先……再……然后……”等词，把做事的经过写清楚。

3. 尝试写几句连贯的话：围绕一件事，写出连续的几句话，初步培养写话的段落意识。

4. 分享劳动乐趣：通过写话体验劳动的成就感，乐于与他人交流分享。

### 二、教学重难点

重点：指导学生把做事的过程分解成几个步骤，按顺序写下来。

难点：帮助学生把“做了什么”写具体，学习用连贯的句子表达过程。

### 三、教学建议（核心教学环节）

第一环节：作前准备——动手做，真体验

1. 布置写话前体验任务

可提前布置家庭作业，让学生在家做一件力所能及的事，如洗袜子、叠衣服、扫地、做手工等。要求边做边想：先做什么？再做什么？最后做什么？当时心里怎么想？也可以在课堂上组织简单的手工制作活动，如折纸、捏橡皮泥等，获得即时体验。

2. 课堂上回顾交流

请学生说一说自己做了什么，是怎么做的。引导学生用“先……再……然后……最后……”的顺序词来讲述过程，帮助理清步骤。

第二环节：作中指导——按顺序，写过程

1. 示范引路，学习按步骤写

老师可以以“洗袜子”为例，示范如何把过程分解成几个步骤，再连起来写成几句话。先打湿袜子，再打上肥皂，然后用力搓，最后用清水冲干净。每个步骤用一句话写清楚。

2. 明确写话要求

从给定的话题中选一个自己做过的事。用几句话把过程写清楚，可以用上顺序词“先……再……然后……”。不会写的字用拼音代替。标点正确，格式规范。

3. 分层要求

基础层：能写出做事的三个步骤，语句基本通顺。提高层：能把每一步写得较具体，写出自己的心情或感受。

第三环节：作后评改——读过程，学分享

1. 自己读，检查通顺

读一遍自己的写话，看步骤是否完整，顺序有没有混乱。

2. 同桌互读，检验是否清楚

读给同桌听，让同桌说说自己听懂了没有。如果同桌能按写话重新说出做事步骤，说明写得很清楚。

3. 全班交流

展示优秀写话，引导学生从“步骤是否清楚、句子是否通顺、有没有写出感受”等方面进行评价。还可结合劳动教育，让学生谈谈做这件事后的收获和体会。

### 四、评价标准参考

1. 基础过关：能用几句话写出做事的过程，能看出先后顺序。

2. 良好达标：能按顺序把过程写清楚，语句通顺，用上了顺序词。

3. 优秀进阶：能把过程写具体，语句连贯，写出了自己劳动时的感受。

## 一年级下册·语文园地八 看图写话《小熊过桥》

```meta
册: 一年级下册
任务: 语文园地八 看图写话《小熊过桥》
文体: 看图写话
关键词: 看图 故事
分级: L1
```

### 一、写话要求（教学目标）

1. 有序观察多幅图：能按顺序观察几幅连续的图画，看懂故事情节的发展变化。

2. 把事情写完整：能围绕“小动物们遇到困难——小熊帮忙——解决问题”这条线索，把故事写完整。

3. 展开想象，丰富画面：对人物的动作、对话、心理活动进行合理想象，把静止的画面写成有趣的小故事。

4. 感受助人为乐的品质：通过写话体会小熊乐于助人的精神，渗透品德教育。

### 二、教学重难点

重点：引导学生看懂图与图之间的联系，把故事按顺序写完整。

难点：帮助学生把关键情节写具体，尤其是“小熊是怎样帮忙的”这一重点部分。

### 三、教学建议（核心教学环节）

第一环节：作前指导——看图画，编故事

1. 逐图观察，读懂情节

按顺序出示图画，逐图提问：第一幅：图上都有谁？它们怎么了？遇到了什么困难？（小动物们站在河边，桥断了或桥太窄不敢过）第二幅：小熊来了，它在做什么？它会怎么说？（小熊搬来木板搭桥、伸手扶小动物过桥等）第三幅：小动物们顺利过桥了吗？大家心情怎么样？会说什么？

2. 建立图与图之间的联系

引导学生把这组图连起来看，发现故事的发展：发现困难——想办法解决——解决问题。强调这是同一个故事的连续发展，写的时候也要前后连贯。

3. 展开想象，丰富故事

鼓励学生给画面中的人物加上对话、动作和表情。比如：小熊搭桥时可能会说“别怕，我来帮你们”；小动物过桥时可能会说“谢谢你，小熊”；过桥后小动物们可能会拥抱小熊或者一起开心地玩耍。

4. 口头讲述，理清思路

请学生按照图画的顺序，把整个故事完整地讲一遍，可以同桌互讲。老师可提供简单叙事框架：先讲小动物遇到什么困难，再讲小熊怎么帮忙，最后讲结果和心情。

第二环节：作中指导——写故事，写完整

1. 提出写话要求

题目可定为《小熊过桥》或自拟。按图画的顺序来写，一幅图写一两句话。要把故事写完整，让读者能看懂事情的起因、经过和结果。不会写的字用拼音代替。注意开头空两格，标点占一格。

2. 指导写重点部分

引导学生把“小熊怎么帮忙”写具体，这是故事的重点。可以用上“搬、扶、拉、搭”等动作词语，可以写写小熊说的话，还可以写写小动物们当时的心情。

第三环节：作后评改——讲故事，共欣赏

1. 自读自查

自己读一遍，看故事有没有讲完，句子通不通顺。

2. 同桌互讲

互相读给对方听，听完说说对方的故事有没有讲完整，哪里写得最有趣。

3. 全班讲评

请几位同学朗读自己的写话，全班进行点评。引导关注：故事完整吗？小熊帮忙的过程写清楚了吗？哪里让你觉得特别生动？

4. 延伸讨论

交流：你喜欢小熊吗？为什么？你在生活中帮助过别人吗？引导学生把写话与生活联系起来，升华情感。

### 四、评价标准参考

1. 基础过关：能根据图画写出简单的故事，把起因、经过、结果基本写清楚。

2. 良好达标：能把故事按顺序写完整，语句通顺，有简单的对话或想象。

3. 优秀进阶：能把“小熊帮忙”的过程写具体，对话和想象丰富，语言生动，能表达出助人为乐的快乐。
