## 二年级上册·语文园地三 写话《我最喜爱的玩具》

```meta
册: 二年级上册
任务: 语文园地三 写话《我最喜爱的玩具》
文体: 状物写话
关键词: 玩具 喜爱 样子玩法
分级: L2
```

### 一、写话要求（教学目标）

1. 学习从不同方面介绍玩具：能从名称、样子、玩法等方面介绍自己最喜爱的玩具，把话写完整。

2. 抓住玩具的主要特点：能观察并写出玩具的形状、颜色、大小等主要特征，尝试用上学过的叠词或形容词。

3. 表达喜爱之情：在介绍玩具的过程中，自然表达出自己对玩具的喜爱。

4. 继续巩固写话格式：开头空两格，标点占一格，不会写的字用拼音代替。

### 二、教学重难点

重点：指导学生从样子、玩法等方面有序介绍玩具，把话说清楚。

难点：帮助学生抓住玩具最特别的地方来写，避免泛泛而谈。

### 三、教学建议（核心教学环节）

第一环节：作前指导——带玩具，说玩具

1. 提前布置带玩具

课前请学生带来自己最喜爱的一件玩具，可以是毛绒玩具、积木、小汽车、洋娃娃等。提醒学生先仔细观察自己的玩具，想想它哪儿最特别。

2. 创设情境，激发兴趣

可以设计“玩具小超市”“玩具展览会”等情境，让学生在情境中介绍自己的玩具。老师先示范介绍一个玩具，给学生提供说的范例。

3. 指导从不同方面说

引导学生从以下几个方面介绍：叫什么名字？是什么样子的？（形状、颜色、大小、材质）怎么玩？（操作方式、规则）你为什么喜欢它？（谁送的、玩时的感受）可以让学生先同桌互说，互相补充。

4. 指导按一定顺序说

给学生一个说的框架，比如：先说名称，再说样子（从整体到局部，或从上到下），然后说玩法，最后说为什么喜欢。

第二环节：作中指导——搭框架，写清楚

1. 明确写话要求

写自己最喜爱的玩具。写出玩具的样子、玩法和喜欢的原因。用几句话写清楚。标点正确，格式规范。

2. 提供写作框架

出示简单框架供参考：第一部分写玩具叫什么名字。第二部分写它的样子（形状、颜色、大小等）。第三部分写它的玩法。第四部分写为什么喜欢它。鼓励能力强的学生在此基础上写得更丰富。

3. 分层要求

基础层：能写出名称和样子，语句基本通顺。提高层：能从多个方面介绍玩具，写出为什么喜欢，句子连贯。

第三环节：作后评改——读一读，猜一猜

1. 同桌互读猜玩具

同桌交换读，读完后猜一猜对方写的是哪件玩具。如果一猜就中，说明样子写得很清楚；如果猜不出，说明特征没写出来，需要补充修改。

2. 自我修改

根据同桌反馈，对没写清楚的地方进行修改。

3. 全班展示与点评

选几篇优秀写话展示，老师从以下方面点评：样子的描写是否抓住了特点？玩法是否写得清楚？有没有表达出喜爱之情？

### 四、评价标准参考

1. 基础过关：能写出玩具的名称和简单的样子，语句基本通顺。

2. 良好达标：能从样子、玩法等方面介绍玩具，写出为什么喜欢，语句通顺。

3. 优秀进阶：能抓住玩具的特点进行具体描写，语言生动，自然表达出喜爱之情。

## 二年级上册·语文园地四 写话《学写留言条》

```meta
册: 二年级上册
任务: 语文园地四 写话《学写留言条》
文体: 应用文·留言条
关键词: 留言条 格式
分级: L2
```

### 一、写话要求（教学目标）

1. 认识留言条的实用功能：知道留言条是生活中常用的应用文，了解在什么情况下需要写留言条。

2. 掌握留言条的基本格式：知道留言条由称呼、正文、署名和日期四部分组成，各部分位置正确。

3. 学习写简单的留言条：能把事情说清楚，语言简洁明了。

4. 感受语文与生活的联系：通过写留言条，体会语文学习的实用性。

### 二、教学重难点

重点：掌握留言条的格式，能按要求写简单的留言条。

难点：把事情说清楚的同时做到语言简洁，不啰唆。

### 三、教学建议（核心教学环节）

第一环节：作前指导——认识留言条

1. 创设情境，引出需要

老师可设置情境：妈妈不在家，我有事要出门，怎么告诉妈妈？电话打不通怎么办？引出写留言条的需要。

2. 出示范例，认识格式

出示一则标准的留言条范例，引导学生观察留言条由哪几部分组成。称呼写在第一行，顶格写，后面加冒号。正文另起一行，开头空两格，把要说的事情写清楚。署名写在正文右下方。日期写在署名的下面。可以用儿歌帮助学生记住格式：称呼顶格加冒号，正文空两格写清楚，署名右下角，日期署下方。

3. 对比辨析，明确适用场合

出示几个需要不需要写留言条的情境，让学生辨析：去同学家，同学不在家，想约他明天踢球（需要写）。给奶奶打电话祝生日快乐（不需要，电话交流即可）。早上出门发现书包破了，想让妈妈帮忙缝一下（需要写）。引导学生明确：联系不到对方，又有事情需要告知时，就需要写留言条。

第二环节：作中指导——学格式，写留言

1. 提供写话情境

从教材提供的情境中选择一个进行写话练习。情境一：去办公室还书，老师不在。情境二：去小芳家里通知她明天九点到学校参加书法小组活动，但小芳家里没有人。

2. 先口头练习，再说动笔

让学生先口头说一遍留言条的内容，确认事情说清楚了，格式记准确了，再动笔写。

3. 强调格式要点

写前再次强调：称呼顶格。正文开头空两格，把事情说清楚。署名和日期的位置要正确。写完逐项自查：称呼对了吗？事情说清楚了吗？署名和日期写了吗？位置对吗？

第三环节：作后评改——评格式，议应用

1. 自我检查

对照格式要求逐项自查，重点看格式是否正确。

2. 同桌互评

交换读，按照格式要求给对方打分，指出格式上的问题。

3. 全班点评

选几篇具有代表性的留言条进行展示，重点点评格式是否正确，内容是否清楚简洁。

4. 拓展练习

课后可以创设更多需要写留言条的情境让学生练习，如给老师留言、给同学留言、给家长留言等，巩固应用文写作能力。

### 四、评价标准参考

1. 基础过关：格式基本正确，能把要说的事情写出来。

2. 良好达标：格式正确，事情说清楚，语句通顺。

3. 优秀进阶：格式规范，内容清楚简洁，语言得体。

## 二年级上册·语文园地七 写话（看图写话，无标题）

```meta
册: 二年级上册
任务: 语文园地七 写话（看图写话，无标题）
文体: 看图写话
关键词: 看图 想象
分级: L2
```

### 一、写话要求（教学目标）

1. 有序观察单幅图：能按照一定顺序观察单幅图画，看清楚图上有什么。

2. 展开想象，把画面写活：能在观察的基础上，根据人物的动作、表情等展开合理想象，补充事件的前因后果。

3. 把故事写完整：能写清楚谁在什么时间、什么地方、干什么，初步写出事情的起因、经过和结果。

4. 尝试使用修饰词语：能在写话中尝试使用一些学过的词语进行修饰，让句子更生动。

### 二、教学重难点

重点：指导学生把观察到的和想象到的写下来，把故事写完整。

难点：帮助学生在已有画面基础上展开合理想象，把故事写得生动有趣。

### 三、教学建议（核心教学环节）

第一环节：作前指导——看图画，讲故事

1. 整体感知图画

出示单幅图，先让学生说说图上画了什么，用一两句话概括画面内容，对图画有整体印象。

2. 有序观察画面要素

引导学生按一定顺序观察：图上的人物（谁？动作？表情？穿着？）、时间（什么时候？从哪些细节看出来的？）、地点（什么地方？环境是怎样的？）、事件（他们在做什么？），让学生把这些要素一一说清楚。

3. 展开想象，把故事讲完整

在观察的基础上追问：这幅图前面可能发生了什么？接下来又会怎样？人物之间可能在说什么？心里在想什么？鼓励学生以画面为起点，向前后延伸，把一幅图讲成一个有头有尾的小故事。

4. 口头讲述完整故事

让学生在小组内或同桌之间把编的故事完整讲一遍，老师巡视指导，鼓励讲得有条理、有想象力的学生。

第二环节：作中指导——搭框架，写故事

1. 指导写作顺序

建议学生按照时间顺序来写：先写事情的开头（起因），再写画面的内容（经过），最后写事情的结尾（结果）。

2. 提出写话要求

把看到和想到的写下来。故事要写完整，有开头、经过和结尾。可以给人物起名字，写出他们的对话。用上学过的修饰词语让句子更生动。格式正确，标点规范。

3. 分层要求

基础层：能写清楚谁在什么地方做什么。提高层：能写成一个有起因、经过、结果的小故事，有简单的对话。拔尖层：故事完整，想象丰富，语句生动，能恰当使用积累的词语。

第三环节：作后评改——读故事，评完整

1. 自读自查

读一遍自己的故事，看故事有没有讲完，有没有漏掉重要的内容。

2. 小组交流互评

小组内互相读，听完后互相点评：故事完整吗？哪里写得最有趣？有什么建议？

3. 全班展示

选几篇有特色的写话全班展示，引导从“故事是否完整、想象是否合理、语句是否通顺生动”等方面进行点评，老师总结表扬。

### 四、评价标准参考

1. 基础过关：能写出图上的基本内容，语句基本通顺。

2. 良好达标：能写出有起因、经过、结果的小故事，语句通顺。

3. 优秀进阶：故事完整，想象合理丰富，能使用修饰词语让表达生动。
