## 五年级下册·第一单元 习作《那一刻，我长大了》

```meta
册: 五年级下册
任务: 第一单元 习作《那一刻，我长大了》
文体: 记事·成长
关键词: 成长 那一刻 细节
分级: L5
```

### 一、习作要求（教学目标）

1. 选一件成长中印象深刻的事来写：能从自己的成长经历中，选择一件让自己突然觉得自己“长大了”的事。

2. 把“那一刻”的情形写具体：能聚焦到“那一刻”，把当时的所见、所闻、所做、所想写清楚、写具体。

3. 写出当时的真实感受：能写出自己在“那一刻”内心的触动和感悟，把“长大”的感觉写出来。

4. 体会成长的含义：通过回忆和书写，加深对“成长”的理解，懂得长大不仅是身体的变化，更是心灵的成熟。

### 二、教学重难点

重点：指导学生把感到自己长大的“那一刻”的情形写具体，写出真实感受。

难点：帮助学生从平凡的小事中发现“长大”的瞬间，并把内心的触动写细致。

### 三、教学建议（核心教学环节）

第一环节：作前指导——忆成长，找“那一刻”

1. 理解题意，打开思路

引导学生理解“长大”不仅指年龄增长、个子长高，更指内心变得懂事、懂得体谅、学会承担责任等。让学生想一想：有没有哪一个瞬间，你突然觉得自己不再是小孩了？可以是从家人的疲惫中懂得心疼、从独立完成一件事中获得成就感、从面对困难时不再退缩中看到自己的勇敢等。

2. 选定事件，聚焦“那一刻”

让学生从自己的经历中选定一件事。这件事可能跨度较长，但本次习作要把镜头聚焦到让你产生“我长大了”感觉的那个瞬间。想一想：那个瞬间你在哪里？看到了什么？听到了什么？想到了什么？做了什么？

3. 把“那一刻”展开来想

引导学生把“那一刻”像放慢镜头一样展开：当时的环境是怎样的？周围的人在做什么、说什么？你的心里经过了怎样的变化？从一开始的“没长大”到“长大”之间，是什么触动了你？把这个变化过程想清楚。

4. 口头交流“那一刻”

在小组内说一说自己选的事和“那一刻”的情形。组员听后说说是否感受到“长大”的触动，哪里还可以说得更细致。

第二环节：作中指导——聚焦点，写触动

1. 明确习作要求

写一件成长过程中印象深刻的事。把感到自己“长大了”的“那一刻”的情形写具体。写出当时的真实感受。语句通顺，有真情实感。

2. 指导写作结构

提供参考结构：开头简要交代事情的背景。中间重点写“那一刻”的情形，把所见、所闻、所想、所做具体地写出来。结尾写这件事带给自己的变化和感悟，点明“那一刻，我长大了”。

3. 指导把“那一刻”写具体

可以运用动作、神态、心理、环境等多种描写手法。写出人物的一举一动和自己的内心活动，如看到妈妈手上的老茧、爸爸疲惫的背影时心里的触动，以及自己主动端上一杯水、接过重物等行动的转变。用细节表现内心变化。

4. 指导写出真实感受

不喊口号、不说套话。把当时最真实的想法写出来，哪怕只是心里轻轻的一句“妈妈辛苦了”“我能行”，也是珍贵的“长大”的声音。

第三环节：作后评改——读触动，评成长

1. 同桌互读

交换读习作，读完后说说：你感受到他“长大”的那个瞬间了吗？哪里写得最让你触动？

2. 自我修改

检查：“那一刻”的情形是否写具体了？内心的感受有没有写出来？有没有把“长大”的感觉表达清楚？进行修改补充。

3. 全班“成长分享会”

请几位同学分享自己的成长故事。引导从“聚焦一刻、细节具体、感受真实”等方面进行欣赏和点评。在分享中感悟每个人的成长都有属于自己的独特时刻。

### 四、评价标准参考

1. 基础过关：能写出一件事，有感到自己“长大”的那一刻，语句通顺。

2. 良好达标：能聚焦“那一刻”写具体，有环境、动作和简单的心理描写，写出真实感受。

3. 优秀进阶：聚焦精准，细节描写生动，内心变化写得很细腻，成长感悟自然真挚，有打动人心的力量。

## 五年级下册·第二单元 习作《写读后感》

```meta
册: 五年级下册
任务: 第二单元 习作《写读后感》
文体: 读后感
关键词: 读后感 感受 联系实际
分级: L5
```

### 一、习作要求（教学目标）

1. 选择一篇读过的文章或一本书来写感想：能选择自己印象最深、最有感触的阅读材料，写一篇读后感。

2. 简单介绍读的内容：能用简洁的语言概括所读文章或书的主要内容，让没有读过的人也能了解大概。

3. 重点写自己的感想和收获：能从人物形象、故事情节、蕴含的道理等方面，选择感触最深的一两点来写感想，把“感”写具体。

4. 联系自己的阅读积累或生活经验：能把阅读感受和自己的实际联系起来，让感想更充实、更有说服力。

### 二、教学重难点

重点：指导学生把“感想”写具体，避免过多复述内容。

难点：帮助学生找到最有感触的“感点”，并能联系实际展开，避免空泛议论。

### 三、教学建议（核心教学环节）

第一环节：作前指导——忆阅读，定感点

1. 明确读后感的含义

引导学生理解读后感重在“感”。读是基础，感是重点。可以先简单介绍读的内容，但重点要写自己的感想、体会和收获。

2. 选定阅读材料，回顾内容

让学生选定一篇或一本最近读过且印象深刻的作品。想一想：这篇作品主要讲了什么？用几句话能概括出来吗？

3. 寻找“感点”

引导学生从不同角度寻找感触最深的地方：对作品中的人物有什么看法？（喜欢、敬佩、同情还是讨厌？为什么？）对情节有什么感受？（哪个情节最打动你？哪个地方最让你意外？）懂得了什么道理？（读完有什么收获和启发？）联想到什么？（有没有联想到自己读过的其他书、自己的生活经历或社会现象？）选定一两个最有话说的“感点”来重点写。

4. 处理好“读”与“感”的关系

提醒学生：“读”的内容只需要简单介绍，让读者知道你在说哪本书即可，一两段足够。“感”的部分才是主体，要用主要篇幅来写自己的感想。

第二环节：作中指导——重感想，联实际

1. 明确习作要求

选一篇文章或一本书写读后感。简单介绍读的内容。重点写自己的感想和收获。感想可以就一两方面深入写，可以联系实际。语句通顺，感情真实。

2. 指导写作结构

提供参考结构：开头交代读了什么作品，用一句话总写自己的整体感受。接着简要介绍作品的主要内容。然后重点写自己的感想，每个感点写一段，结合书中的内容谈自己的看法，再联系自己的经历或身边的事来充实。结尾总结自己的收获，或向别人推荐这本书。

3. 指导把感想写具体

写感想不要只说“我很感动”“这本书很好看”，要写出：为什么感动？书中哪句话、哪个情节让你感动？你想到了什么？联系自己的实际时，要把相关经历简单写出来，让感想有根有据。

4. 指导联系实际的方法

联系实际可以联系自己的生活经历、学习情况、身边的现象等。比如读了关于坚持的故事，可以写自己在学某样东西时遇到困难想放弃，想到书中人物就坚持了下来。适当的联系能让感想更落地、更有共鸣。

第三环节：作后评改——评感点，验深度

1. 同桌互读

交换读习作，读完后说说：你能清楚地知道他读了什么吗？他的哪点感想最打动你？有没有觉得“感”太少而“读”太多？

2. 自我修改

检查：“读”与“感”的比例是否恰当？感想是否具体？有没有联系实际？读的部分是否过于冗长？进行调整修改。

3. 全班展示交流

选几篇写不同作品、有不同感想的习作展示。引导从“感点清晰、感想具体、联系实际得当”等方面进行点评。可以让其他同样读过该作品的同学分享是否也有同感，或有无不同的感想。

### 四、评价标准参考

1. 基础过关：能简单介绍内容并写出自己的一点感想，语句通顺。

2. 良好达标：内容介绍简洁，感想比较具体，有简单的联系或分析。

3. 优秀进阶：感点明确，感想具体深入，能恰当联系实际，有独特的思考和感悟，有感而发。

## 五年级下册·第三单元 综合性学习《遨游汉字王国》（写研究报告）

```meta
册: 五年级下册
任务: 第三单元 综合性学习《遨游汉字王国》（写研究报告）
文体: 研究报告
关键词: 汉字 调查 研究报告
分级: L5
```

### 一、习作要求（教学目标）

1. 围绕汉字确定研究主题：能从汉字的演变、书法、错别字、姓氏文化、有趣的谐音等中选择一个感兴趣的问题作为研究主题。

2. 学习搜集和整理资料：能通过查阅书籍、网络搜索、调查访问等方式获取相关资料，并对资料进行筛选和整理。

3. 学写简单的研究报告：了解研究报告的基本格式，能把研究的目的、方法、过程和结论写清楚。

4. 感受汉字文化的魅力：在研究过程中加深对汉字的了解，激发对祖国语言文字的热爱之情。

### 二、教学重难点

重点：指导学生掌握研究报告的基本格式，把研究过程和结论写清楚。

难点：帮助学生在众多资料中筛选出有用信息，并用自己的语言进行整合和分析，避免简单照搬资料。

### 三、教学建议（核心教学环节）

第一环节：作前准备——选主题，搜资料

1. 回顾活动，确定主题

结合本单元综合性学习“遨游汉字王国”的活动，引导学生回顾在活动中的收获和感兴趣的问题。研究主题可以参考教材提供的，也可以自己确定。如：“有趣的形声字”“街头错别字调查”“自己姓氏的起源和现状”“汉字字体的演变”“对联中的汉字文化”等。主题宜小不宜大。

2. 学习搜集资料的方法

引导学生通过多种渠道搜集资料：查阅图书、上网搜索、请教老师家长、实地调查拍照等。提醒对搜集到的资料要进行记录，标明来源，以便写报告时引用。

3. 整理和分析资料

指导学生把搜集到的零散资料进行整理，可以按类别分类，可以用表格或思维导图呈现。思考：从这些资料中你发现了什么？有什么结论？有没有什么有趣的现象或规律？

第二环节：作中指导——学格式，写报告

1. 明确习作要求

写一份关于汉字的研究报告。报告要有研究主题、研究目的、研究方法、研究过程、研究结论等部分。语言简洁清楚。格式基本规范。

2. 指导研究报告的基本格式

向学生介绍简单的研究报告通常包含以下几个部分：标题（写清楚研究什么）、问题的提出（为什么想研究这个问题）、研究方法（用了哪些方法来搜集资料）、资料的整理（把搜集到的资料分门别类地简要呈现）、研究结论（通过研究你得出了什么结论或有什么发现）。不强求完全规范，但基本结构要清楚。

3. 指导用自己的话写

研究报告中的资料不能大段照抄原文，要用自己的语言进行概括和转述。如果需要引用原文中的某句话作为例子，要加上引号。引导学生在“结论”部分多写自己的发现和思考，这是研究报告最有价值的部分。

4. 指导语言风格

研究报告的语言以平实、准确为主，不需要过多的修饰和抒情。把事情说清楚，把结论写明白。

第三环节：作后评改——评报告，验规范

1. 同桌互读互评

交换读研究报告，读完后说说：研究的是什么问题，清楚吗？资料整理得怎么样？结论是什么，你认同吗？格式是否基本规范？

2. 自我修改

检查：主题明确吗？资料整理有条理吗？结论和研究问题匹配吗？格式各大部分是否完整？进行补充修改。

3. 全班“汉字研究成果发布会”

举办一个模拟的“研究成果发布会”，请几位同学宣读自己的研究报告。台下同学可以提问，由“研究者”回答。引导从“主题明确、资料丰富、条理清楚、有自己发现”等方面进行点评和欣赏。

### 四、评价标准参考

1. 基础过关：有研究主题，能写清楚基本的研究结果，语言通顺。

2. 良好达标：报告结构基本完整，有资料的整理和分析，有研究结论。

3. 优秀进阶：主题有价值，资料整理有条理，结论有自己的发现和见解，报告格式比较规范，能体现一定的研究意识。

## 五年级下册·第四单元 习作《他____了》

```meta
册: 五年级下册
任务: 第四单元 习作《他____了》
文体: 写人·描写
关键词: 神态 动作 语言 入迷生气
分级: L5
```

### 一、习作要求（教学目标）

1. 把题目补充完整：能从“陶醉、生气、伤心、高兴、激动、烦恼”等反映人物内心状态的词语中选择一个，把题目补充完整。

2. 写清楚事情的前因后果：能写出是什么事情导致人物进入这种状态的，事情的经过和结果怎样。

3. 把人物当时的表现写具体：能通过对人物动作、神态、语言的描写，把人物“____了”的样子写具体，反映出人物的内心世界。

4. 尝试多角度描写人物表现：不仅写人物的动作表情，还能写周围人的反应，侧面烘托人物的状态。

### 二、教学重难点

重点：指导学生把人物“____了”的样子写具体，通过对人物外在表现的描写反映内心。

难点：帮助学生在叙事中聚焦人物状态最强烈的那段时间，把表现写细致、写生动，避免一笔带过。

### 三、教学建议（核心教学环节）

第一环节：作前指导——补题目，选事件

1. 理解题意，补充题目

引导学生理解“他____了”这个题目，“他”可以是身边的人（家人、同学、老师、朋友等），也可以是偶遇的陌生人。横线上补充的是表现人物内心状态的词语。打开思路：除了陶醉、生气、伤心，还可以是感动、幸福、满足、后悔、着急等。

2. 选定人物和状态，回忆事件

让学生确定要写的“他”是谁，他“怎么了”。想一想：是什么事情让他这样的？这件事的前因后果是怎样的？选定一件自己亲眼所见、印象深刻的事。

3. 聚焦状态最强烈的时刻

引导学生回忆：他在那种状态下，和平时有什么不一样？他的脸上是什么表情？眼睛有什么变化？手在做什么？说话的语气和声音是怎样的？周围其他人有什么反应？把这些细节在脑海中重现，为写作做准备。

4. 口头描述，捕捉细节

在小组内口头描述人物“____了”的样子，组员互相补充细节，看看是否通过描述就能感受到人物的内心。

第二环节：作中指导——写表现，现内心

1. 明确习作要求

把题目补充完整。写清楚事情的起因、经过和结果。把人物当时的表现写具体，反映出他的内心。语句通顺，描写生动。

2. 指导写作结构

提供参考结构：开头交代事情的起因，引出人物即将进入某种状态。中间写事情经过，重点把人物“____了”的那段表现写具体，从动作、神态、语言、周围反应等多角度展开。结尾写事情的结果，可以简单写人物恢复平静或状态持续。

3. 指导多角度描写人物表现

动作描写：写出人物在那种状态下的特殊动作，如“陶醉时手指轻轻打着节拍”“生气时拳头紧握、身体微微发抖”。神态描写：细致刻画面部表情，如“眼睛眯成了一条缝”“嘴唇抿得紧紧的”“泪水在眼眶里打转”。语言描写：写出说话的内容、语气、语速，如“说话都结巴了”“声音大得整间屋子都在震”。侧面烘托：写周围人的反应，如“旁边的人都安静了下来”“同学们面面相觑，不敢出声”。

4. 指导让描写为主题服务

所有的描写都要指向同一个目的：让读者感受到人物“____了”的内心状态。描写不在多，而在能突出人物的这一状态。

第三环节：作后评改——读表现，验生动

1. 同桌互读

交换读习作，读完后说说：你感受到那个人“怎么了”吗？哪里写得最传神？还有哪里可以再细致一些？

2. 自我修改

检查：题目是否完整？事情前因后果清楚吗？人物表现是否多角度写具体了？进行修改。

3. 全班展示与点评

选几篇写不同情绪状态的习作在全班展示。可以请作者不公布题目中补充的词语，只读习作，让同学猜“他怎么了”。猜得出来的，说明描写很成功。引导从“表现具体、描写生动、内心可见”等方面进行点评。

### 四、评价标准参考

1. 基础过关：能把题目补充完整，写清楚事情和人物的基本表现，语句通顺。

2. 良好达标：事情清楚，能通过动作、神态等描写把人物当时的表现写出来。

3. 优秀进阶：多角度描写人物表现，细节生动传神，人物的内心状态跃然纸上，让人感同身受。

## 五年级下册·第五单元 习作《形形色色的人》

```meta
册: 五年级下册
任务: 第五单元 习作《形形色色的人》
文体: 写人·事例
关键词: 典型事例 特点鲜明
分级: L5
```

### 一、习作要求（教学目标）

1. 选择一个人来写：能从生活中选择一个给自己留下深刻印象的人，可以是熟悉的，也可以是偶然遇见的。

2. 运用学过的描写人物的方法：能运用外貌、动作、语言、神态、心理等描写手法，以及通过具体事例来表现人物特点。

3. 选取典型事例表现人物特点：能围绕人物的一个主要特点，选取一两件最能体现这个特点的典型事例来写。

4. 初步运用侧面描写：能在正面描写的基础上，尝试用他人的反应来侧面烘托人物特点。

### 二、教学重难点

重点：指导学生综合运用多种人物描写方法，选取典型事例表现人物特点。

难点：帮助学生在众多特点中聚焦一个，并把事例写得典型、描写写得生动。

### 三、教学建议（核心教学环节）

第一环节：作前指导——选人物，定特点

1. 回顾单元课文，学习方法

引导学生回顾本单元学过的课文《人物描写一组》《刷子李》，回顾作者是怎样通过外貌、动作、语言、神态描写来塑造人物的，怎样通过具体事例和侧面描写来突出特点的。

2. 选定人物，聚焦特点

让学生选定一个人。想一想：这个人最大的特点是什么？用一个词或一句话来概括，如“记忆力超群的爷爷”“爱唠叨的妈妈”“幽默的同桌”“小区里最热心的保安”。本次习作只需要围绕这一个主要特点来写。

3. 选取典型事例

引导学生思考：哪些事最能表现这个特点？挑选一两件最有代表性的事。把事例想清楚：时间、地点、人物、经过。如果写两件事，可以一详一略。

4. 设计描写方法

根据所选的事例，想想准备怎样把人物写生动：哪里可以用外貌描写？哪里可以用动作描写？哪里可以写人物的语言？周围的其他人有什么反应可以用来侧面烘托？

第二环节：作中指导——用方法，写特点

1. 明确习作要求

写一个有特点的人。选取典型事例表现人物特点。运用学过的描写人物的方法。语句通顺，描写具体。

2. 指导写作结构

提供参考结构：开头介绍要写的人是谁，用一两句话点出他的主要特点。中间选取一两件典型事例，在叙事中综合运用动作、神态、语言、外貌等描写方法，把人物写活。可以加入他人的反应作为侧面烘托。结尾表达对这个人的评价或自己的感受。

3. 指导综合运用描写方法

提醒学生在写事例的过程中，在关键处插入描写，如写到精彩的地方时放慢笔速，写写人物当时的神态和动作，写写他说了什么，怎么说的。写外貌不必集中在一段，可以分散在文中随文而出。参考《刷子李》中曹小三的心理变化来侧面烘托主角的手法，试着写写旁人看这个人的反应。

4. 指导突出主要特点

所有的事例和描写都要围绕那个主要特点进行。和这个特点无关的事情和描写可以删掉，保证特点突出、不散漫。

第三环节：作后评改——读人物，评生动

1. 同桌互读

交换读习作，读完后说说：这个人最大的特点是什么？事例是否典型？哪里的描写最生动？

2. 自我修改

检查：特点是否鲜明？事例是否围绕特点？是否运用了多种描写方法？进行修改补充。

3. 全班展示

选几篇写不同人物的习作在全班展示。引导从“特点鲜明、事例典型、描写生动、方法多样”等方面进行点评。可以让大家说说是否通过这些描写在脑海中看到了这个人。

### 四、评价标准参考

1. 基础过关：能写出人物的一个特点，有简单的事例和描写，语句通顺。

2. 良好达标：特点比较突出，事例典型，能运用几种描写方法把人物写得较生动。

3. 优秀进阶：特点非常突出，事例典型具体，多种描写方法运用自如，人物形象生动鲜活，能给读者留下深刻印象。

## 五年级下册·第六单元 习作《神奇的探险之旅》

```meta
册: 五年级下册
任务: 第六单元 习作《神奇的探险之旅》
文体: 想象·探险
关键词: 探险 装备 险情
分级: L5
```

### 一、习作要求（教学目标）

1. 展开合理而大胆的想象：能根据自己选择的场景、同伴和装备，展开想象，编写一个探险故事。

2. 把探险过程写完整：能写清楚探险的起因、途中遇到的困境、脱离困境的方法和探险的结果。

3. 把遇到的困境和求生的方法写具体：这是本次习作的重点，能把遇到的最惊险的困境和怎样脱离困境的过程写详细、写精彩。

4. 写出心情的变化：能在故事中写出探险过程中的紧张、害怕、勇敢、坚持等心情变化，让故事有起伏。

### 二、教学重难点

重点：指导学生把遇到的困境和求生的方法写具体，突出“神奇”和“惊险”。

难点：帮助学生在想象中兼顾合理性与趣味性，把脱离困境的过程写得一波三折、合情合理。

### 三、教学建议（核心教学环节）

第一环节：作前指导——定要素，编困境

1. 借助教材提示，确定探险要素

引导学生参考教材提供的选择项，确定自己探险故事的基本要素：和谁去探险？（知识渊博的生物学家、好奇心强的表哥等）、去哪探险？（茫茫大漠、热带雨林、海中荒岛、幽深洞穴、南极冰川等）、带什么装备？（指南针、地图、饮用水、帐篷、药品、瑞士军刀等）。选好后故事就有了基本设定。

2. 构思探险情节，设计困境

引导学生构思故事的基本框架：为什么去探险？路上遇到了什么困境？这是故事最核心的部分，困境要惊险神奇但又不离谱。比如遇到猛兽、遭遇恶劣天气、设备失灵、迷路、断水断粮、落入陷阱等。怎样脱离困境？用智慧、勇气、装备和同伴合作脱险，要写得一波三折，不要太容易。

3. 把困境和脱险过程想具体

选定一个最核心的困境，把它展开想具体：当时的情况有多危急？看到了什么？听到了什么？同伴们各自什么反应？你心里在想什么？怎样一步一步想出了脱困的办法？每一步怎么做的？用了哪些装备？过程怎样？一步一步想清楚，写作就顺了。

4. 口头讲述探险故事

在小组内简要讲述自己的探险故事，组员听后感不感兴趣、困境是否惊险、脱险是否合理，提出建议。

第二环节：作中指导——写困境，写脱险

1. 明确习作要求

编一个惊险刺激的探险故事。把探险的起因、遇到的困境、脱离困境的方法和结果写完整。把困境和脱险的过程写具体。写出心情的变化。想象合理，故事有趣。

2. 指导写作结构

提供参考结构：开头写探险的起因和出发前的准备。中间写探险过程，重点是遇到困境和脱离困境（可以用一个主要困境，也可以安排一详一略两个困境）。结尾写探险的结果和感受。

3. 指导把困境写具体

通过环境描写营造紧张气氛，如“天色突然暗了下来，狂风卷着沙石打在脸上”“四周一片漆黑，只听见水滴在石头上的回声”。通过人物反应强化危急感，写大家的惊呼、紧张的神态、焦急的心理活动。

4. 指导把脱险过程写具体

脱险过程要一步一步写清楚。写怎么想的、怎么做的、大家怎么配合的。用上“突然，我想到……”“于是我们……”“先……再……然后……”等表示顺序和思考过程的语句。脱险可以写利用知识、装备，也可以写意外发现的契机，让过程曲折一些更好看。

第三环节：作后评改——读探险，评惊险

1. 同桌互读

交换读故事，读完后说说：你觉得这次探险神奇惊险吗？困境和脱险写具体了吗？哪里最惊险刺激？

2. 自我修改

检查：困境是否写具体了？脱险过程清楚合理吗？心情变化写出来了吗？进行修改。

3. 全班“探险故事会”

请几位同学在全班讲述自己的探险故事。评选“最惊险刺激的探险”“最机智的脱险”“最神奇的想象”等。引导从“想象奇妙、困境惊险、脱险合理、描写具体”等方面进行点评。

### 四、评价标准参考

1. 基础过关：能编一个探险故事，有困境和脱险，故事基本完整。

2. 良好达标：故事完整，困境和脱险写得比较具体，想象比较合理。

3. 优秀进阶：故事惊险刺激，困境描写扣人心弦，脱险过程一波三折、合情合理，心情描写细腻，让人身临其境。

4. 融入自己的感受和评价：在客观介绍的基础上，写出自己对该文化遗产的感受和审美评价，表达对中华文明的热爱。

### 二、教学重难点

重点：指导学生从几个方面有条理地介绍一处文化遗产，内容清楚。

难点：帮助学生在整合资料时避免照搬，用自己理解后的语言进行转述，并融入个人的感受和评价。

### 三、教学建议（核心教学环节）

2. 确定介绍对象，搜集资料

让学生选定一处遗产后，课前通过多种途径搜集资料。可以从以下方面搜集：地理位置（在哪）、历史背景（什么时候建的、用来做什么）、外观和结构（长什么样、有什么特别的建筑）、文化价值（为什么能成为世界文化遗产）、相关故事或传说、自己的感受等。

3. 整理资料，确定介绍内容

把搜集到的资料进行分类整理，筛选出最重要、最有意思的内容来写。不必面面俱到，可以选择最有特色的几个方面重点介绍。

选择一处中国的世界文化遗产写介绍。从几个方面有条理地介绍。用自己的语言写，不要大段照搬资料。融入自己的感受和评价。语句通顺，内容清楚。

2. 指导写作结构

3. 指导用自己的话写

强调把资料读懂后，用自己的语言表达出来。可以用“资料显示”“据说”“导游介绍说”等方式自然引出信息。要避免生硬地堆砌数据和专业术语，让读者易于理解。

4. 指导融入个人感受

在介绍的过程中或结尾，适时加入自己的感受和评价，如“站在长城上，我真切地感受到了古人的伟大”“莫高窟的壁画美得让人说不出话来”。个人感受让介绍文字有了温度和个性。

1. 同桌互读

交换读习作，读完后说说：对这处文化遗产了解清楚了吗？哪里介绍得最有意思？有没有感受到作者的感情？

2. 自我修改

检查：介绍是否条理清楚？是否用自己的话？有没有个人感受？资料是否准确？进行修改。

3. 全班“文化遗产推介会”

### 四、评价标准参考

1. 基础过关：能介绍一处文化遗产的基本情况，语句通顺。

2. 良好达标：能从几个方面有条理地介绍，内容比较清楚，有自己的语言表达。

3. 优秀进阶：条理清晰，内容具体有特色，语言生动，融入了自己的真情实感和评价，能激发读者对文化遗产的兴趣。

## 五年级下册·第八单元 习作《漫画的启示》

```meta
册: 五年级下册
任务: 第八单元 习作《漫画的启示》
文体: 说理·启示
关键词: 漫画 含义 启示
分级: L5
```

### 一、习作要求（教学目标）

1. 读懂漫画的内容：能仔细观察漫画，看懂画了什么内容，有什么人物或事物，可笑之处在哪里。

2. 理解漫画的含义：能透过漫画的表面，思考作者想讽刺或赞扬什么现象，表达了什么观点。

3. 把漫画的内容和含义写清楚：先用文字把漫画的内容描述出来，再写出自己从中得到的启示或思考。

4. 联系生活谈启示：能把从漫画中得到的启示与生活中的现象或自己的实际联系起来，让启示更深刻、更有说服力。

### 二、教学重难点

重点：指导学生看懂漫画的寓意，把启示写清楚、写深刻。

难点：帮助学生从漫画的夸张和幽默中提炼出严肃的社会主题或生活哲理，并联系实际展开议论。

### 三、教学建议（核心教学环节）

第一环节：作前指导——看漫画，找寓意

1. 认识漫画的特点

引导学生了解漫画是一种用简单而夸张的手法来描绘生活或时事的图画，常常带有讽刺性或幽默性，让人在笑的同时产生思考。

2. 观察漫画，理解内容

让学生认真观察教材提供的漫画或自己选定的漫画。想一想：漫画上画了谁？在做什么？有什么特别可笑或夸张的地方？画面上有没有文字？先用一两句话说清楚漫画的内容。

3. 思考寓意，提炼观点

引导学生思考漫画背后想表达的意思：作者在讽刺什么现象？批评什么行为？或者表扬什么品质？想告诉人们什么道理？让学生试着用一两句话概括漫画的寓意，这就是全文的核心观点。

4. 联系实际，充实启示

围绕提炼出的观点，想一想：生活中有没有类似的现象？自己有没有亲身经历过？从漫画中你得到了什么启发？以后应该怎么做？把这些思考串联起来，就是“启示”的主体。

第二环节：作中指导——写内容，谈启示

1. 明确习作要求

认真观察漫画，写清楚漫画的内容。写出自己从漫画中得到的启示。可以联系生活实际来写。语句通顺，观点明确。

2. 指导写作结构

提供参考结构：开头简要描述漫画的内容，引出自己的观点或总的感受。中间分两部分：先具体写漫画的内容和自己的理解，再写从漫画中得到的启示（可以结合生活中的类似现象和自己的思考来写）。结尾总结启示，发出呼吁或表达自己的决心。

3. 指导把内容写清楚

对漫画的描述要简洁而形象，让没有看过漫画的人也能在脑海中浮现画面。抓住漫画中最夸张、最核心的画面来写，不啰嗦。描述后可以简单分析漫画使用了什么样的手法（如夸张、对比），以达到效果。

4. 指导把启示写深刻

启示部分要有理有据。可以先点明漫画讽刺或说明的问题，再联系生活中的现象具体说，然后谈谈自己对此的认识和应持的正确态度。启示不要停留在“好笑”的层面，要深入下去，写出有思考的感悟。

第三环节：作后评改——评观点，验深度

1. 同桌互读

交换读习作，读完后说说：漫画内容写清楚了吗？他得到的启示是什么？是否深刻？有没有联系生活？

2. 自我修改

检查：内容描述是否清楚？寓意理解是否正确？启示是否深刻、是否联系了实际？进行修改。

3. 全班交流展示

选几篇写不同漫画、有不同启示的习作在全班展示。引导从“内容清楚、寓意准确、启示深刻、联系实际恰当”等方面进行点评。可以展示漫画图片，边看边听习作，检验描述是否到位。

### 四、评价标准参考

1. 基础过关：能写清楚漫画内容，写出自己的一点感受或启示，语句通顺。

2. 良好达标：内容描述清楚，能正确理解寓意，启示比较具体。

3. 优秀进阶：寓意理解深刻准确，启示深入，联系生活恰当，思考有独立见解，能给读者带来启发。
