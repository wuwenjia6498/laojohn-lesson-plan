## 三年级上册·第一单元 习作《猜猜他是谁》

```meta
册: 三年级上册
任务: 第一单元 习作《猜猜他是谁》
文体: 写人
关键词: 同学 特点 外貌性格爱好
分级: L3
```

### 一、习作要求（教学目标）

1. 激发习作兴趣，消除畏难情绪：乐于书面表达，体会习作的乐趣，这是从“写话”到“习作”过渡阶段的首要目标。

2. 学习抓住人物特点：能选择一两点特别的地方，写清楚同学外貌或性格、爱好等方面的特点。

3. 尝试用几句话或一段话写人物：不要求篇幅，关键是围绕一个意思写清楚。

4. 学习基本习作格式：开头空两格，标点占一格，初步学习修改有明显错误的词句。

### 二、教学重难点

重点：引导学生选择人物特别的地方，把特点写清楚。

难点：帮助学生避免面面俱到，只选择一两个最突出的特点来写。

### 三、教学建议（核心教学环节）

第一环节：作前指导——玩游戏，抓特点

1. 游戏导入，激发兴趣

做“猜猜他是谁”的游戏：老师口头描述一个大家都熟悉的书中人物或班里同学，让学生猜。在游戏中让学生感知，只有抓住特点，才能让人一猜就中。

2. 畅谈游戏感受

让学生说说刚才为什么能猜出来，引出“写出人物特点”这个核心。如果猜不出来，讨论是什么原因，强化“特点要突出”的意识。

3. 选定写作对象，指导观察角度

让学生选定一个同学，不着急写，先仔细想想他最与众不同的地方。借助教材提供的图示，引导学生从不同角度思考：外貌（发型、眼睛、身高、体型等）、性格（爱笑、文静、开朗、调皮等）、爱好（爱看书、爱踢球、爱画画等）、品质（乐于助人、关心集体、有礼貌等）。提醒学生只需要选择其中一两个方面来写，不要求面面俱到。

4. 指导精选最有代表性的特点

举例比较：写“头发卷卷的、皮肤白白的”就不如写“特别爱笑，笑起来有两个小酒窝”或“他是我们班的‘小书虫’，下课时总在看书”更传神。引导学生选择那些“一说出来大家就知道是谁”的特点。

第二环节：作中指导——选特点，写清楚

1. 明确习作要求

选择班里的一个同学来写。抓住一两个特别的地方写清楚。整篇习作不要出现这个同学的名字，用“他”或“她”代替。语句通顺，格式正确。

2. 指导围绕一个意思写

提醒学生：写外貌就围绕外貌写，不要把外貌、爱好、性格都各写一句，结果哪个都没写清楚。可以集中笔墨把一两个方面写好。

3. 关注格式和书写

强调开头空两格、标点占一格。不会写的字可以先用拼音代替，但要逐步减少拼音的使用。

第三环节：作后评改——猜一猜，改一改

1. “猜猜他是谁”评改活动

让学生朗读自己的习作，其他同学猜写的是谁。猜出的快慢和准确度，就是评价习作是否抓住特点的最好标准。

2. 引导讨论修改

如果猜不出来，大家一起讨论：他写的这些特点，是不是很多人都符合？哪些地方可以改得更具体、更有特点？师生共同修改一篇有代表性的习作，学习使用简单的修改符号。

3. 自我修改

学生根据猜的结果和讨论收获，修改自己的习作。

4. 建档鼓励

建议为每个学生建立“习作成长档案”，把这第一次习作收藏起来，作为成长的起点。

### 四、评价标准参考

1. 基础过关：能写出一两个特点，语句基本通顺，能让人大致猜出写的是谁。

2. 良好达标：特点比较突出，能把一方面特点写清楚，让人容易猜出来。

3. 优秀进阶：特点非常突出，描写生动有趣，能抓住与众不同的细节，让人一猜就中。

## 三年级上册·第二单元 习作《写日记》

```meta
册: 三年级上册
任务: 第二单元 习作《写日记》
文体: 应用文·日记
关键词: 日记 格式 记录
分级: L3
```

### 一、习作要求（教学目标）

1. 认识日记的格式和作用：了解日记的基本格式（日期、星期、天气、正文），知道日记是用来记录生活中值得记下的事。

2. 学习选择有记录价值的内容：能在一天的生活中，选取有意义的、新鲜的或自己感触较深的事来写。

3. 写清楚一件事：能把一件事的过程写清楚，把意思表达明白。

4. 培养坚持写日记的习惯：通过这次习作，激发写日记的兴趣，为养成习惯打下基础。

### 二、教学重难点

重点：指导学生掌握日记格式，学会从生活中选取有记录价值的内容。

难点：帮助学生把日记写成流水账，学会捕捉一天中最值得写的一件事。

### 三、教学建议（核心教学环节）

第一环节：作前指导——识日记，选素材

1. 认识日记的格式

出示几则日记范例，引导学生发现日记的格式特点：第一行写日期、星期和天气，中间空一格。正文另起一行，开头空两格。讨论：为什么要写这些信息？（方便以后查看，知道这天发生了什么，什么天气）

2. 认识日记的内容

讨论：日记可以写什么？引导学生明白，日记可以写做过的事、看到的人或景、心里的想法和感受、开心的事或难过的事等。日记是写给自己看的，要写真话。

3. 指导选择日记素材

引导学生回顾最近一两天发生的事，说说哪些事可以写进日记。帮助学生打开思路：学校里的事（一堂有趣的课、一次活动、和同学的事等）、家里的事（帮家长做家务、和家人一起做的事等）、上学路上的见闻、自己的心情和想法等。强调选择一件最有话想说的事来写，不要从早到晚什么都写。

4. 口头交流素材

同桌互相说一说自己打算写什么，为什么想写这件事。互相评价素材是否新鲜、有意义。

第二环节：作中指导——定内容，写清楚

1. 明确习作要求

按照日记的格式来写。选择一件值得记录的事，把事情写清楚。写出自己的真实感受。语句通顺，书写工整。

2. 指导把事情写清楚

回顾第一单元学习的方法，把一件事写清楚可以按事情发展的顺序来写，写出时间、地点、人物、经过和结果。提醒学生把经过写具体，写出自己的做法和当时的心情。

3. 格式提醒

第一行：日期、星期、天气。正文开头空两格。标点正确。

第三环节：作后评改——读日记，共分享

1. 自我阅读检查

自己读一遍，检查格式是否正确，事情写清楚没有，语句通不通顺。

2. 小组交流

小组内交换读日记，读完说说对方写的事情清不清楚，哪些地方写得有意思。

3. 全班交流

选择几篇不同内容、不同风格的日记展示，引导学生发现日记内容的多样性。可以包括：写了一件趣事的日记、写了心里感受的日记、写了观察到的事物的日记等。

4. 鼓励坚持写日记

老师总结写日记的好处，鼓励学生准备一个日记本，尝试每周写几篇日记，养成习惯。

### 四、评价标准参考

1. 基础过关：格式正确，能把一件事写下来，语句基本通顺。

2. 良好达标：格式规范，能选择有记录价值的事，把经过写清楚，有简单感受。

3. 优秀进阶：格式规范，内容新鲜有趣，过程清楚具体，有真情实感，语言流畅。

## 三年级上册·第三单元 习作《续写故事》（看图发挥想象）

```meta
册: 三年级上册
任务: 第三单元 习作《续写故事》（看图发挥想象）
文体: 想象·续写
关键词: 续写 看图 接下去
分级: L3
```

### 一、习作要求（教学目标）

1. 看懂图意，合理预测：能看懂图画中的情境，根据画面信息合理推测故事的发展和结局。

2. 把故事续写完整：能根据前三幅图提供的内容，续写出故事的经过和结局。

3. 发挥想象，丰富细节：能在续写中加入人物的语言、动作、心理活动等细节，把故事写得生动。

4. 学习前后照应：初步懂得续写时要与前面的内容相衔接，注意前后照应。

### 二、教学重难点

重点：指导学生根据已有信息合理推想故事情节，把故事续写完整。

难点：帮助学生在续写时注意情节的逻辑性和连贯性，不脱离前文。

### 三、教学建议（核心教学环节）

第一环节：作前指导——读图画，推情节

1. 逐图观察，读懂已知信息

按顺序出示前三幅图，引导学生逐图观察：图上有谁？在做什么？他们的表情怎样？说了什么？让学生把三幅图的内容连起来说一说，理清已知的故事线索。

2. 寻找关键信息，推测故事走向

引导学生从图中寻找推动情节的关键信息。重点观察人物表情和对话，思考图中人物面临什么情况，心情发生了什么变化。让学生根据已有信息推测接下来可能发生什么。

3. 讨论多种可能性

鼓励学生说出自己推测的故事发展和结局，可以有多种不同的合理推测。讨论：哪种推测最合理、最有趣？为什么？

4. 口头续编，理顺思路

学生在小组内把自己续编的故事完整讲一遍，注意与前三幅图的内容衔接自然。

第二环节：作中指导——接前文，写完整

1. 明确习作要求

认真观察前三幅图，想清楚故事会怎样发展。续写出故事的经过和结局。续写内容要与前面的图画相衔接，前后连贯。发挥想象，可以加入人物的语言、动作和心理活动。语句通顺，标点正确。

2. 指导衔接自然

提醒学生在续写开头用一两句话回顾或呼应前面的内容，如“看着眼前的场景，小华心想……”“就在这时……”等，让续写与前文自然衔接。

3. 指导把重点场景写具体

引导学生选取第四幅图中最关键的场景作为重点来写，把人物的动作、对话、心情写具体，不急着收尾。

第三环节：作后评改——评衔接，比想象

1. 同桌互读

交换读续写，读完说说对方的续写跟前面的图是否衔接得上，哪里写得好。

2. 小组比较讨论

小组内几份不同的续写对比读，看看对同一个故事，大家有哪些不同的想象和结局。讨论哪些想象既合理又有创意。

3. 全班展示

选择有代表性、不同风格的续写进行展示，从情节的合理性和想象力两个角度进行点评。

### 四、评价标准参考

1. 基础过关：能续写出后续情节，故事基本完整，与前文有一定衔接。

2. 良好达标：续写内容与前文衔接自然，情节合理，能写出简单的对话或动作。

3. 优秀进阶：衔接流畅自然，情节既合理又富有新意，场景描写具体生动，人物形象鲜明。

## 三年级上册·第四单元 习作《我来编童话》

```meta
册: 三年级上册
任务: 第四单元 习作《我来编童话》
文体: 想象·童话
关键词: 童话 角色 编故事
分级: L3
```

### 一、习作要求（教学目标）

1. 学习编写简单童话：能根据提供的词语或角色，展开想象编写童话故事。

2. 把故事写完整：能写清楚故事的角色、时间、地点和事情，有基本的起因、经过和结果。

3. 发挥想象，创编情节：能在基本框架内发挥想象，创编出有趣的故事情节。

4. 感受童话的魅力：在编写中体会童话的奇思妙想，乐于与同学分享自己的创作。

5. 加题目并修改：写完后给故事加一个题目，注意题目要居中；再试着用学过的修改符号修改自己的习作（教材原话是“学过的”，属已会能力，自然用、不重教）。

### 二、教学重难点

重点：引导学生根据词语或角色展开想象，创编一个完整的小童话。

难点：帮助学生把故事情节写得有趣味、有波折，避免平淡直叙。

### 三、教学建议（核心教学环节）

第一环节：作前指导——搭舞台，编故事

1. 回顾学过的童话

引导学生回忆本单元学过的童话，说说童话有什么特点。童话里的动物、植物会说话、有思想；童话里经常发生神奇的事；童话往往能告诉我们一个道理。

2. 出示角色或词语，激发想象

教材习作页把词语排成三竖列——左列是角色（每格两个）、中列是时间、右列是地点，横着一行即为一组：

| 角色 | 时间 | 地点 |
| ---- | ---- | ---- |
| 西红柿　茄子 | 夏天 | 菜园 |
| 松鼠　孔雀 | 星期天 | 森林 |
| 铅笔　橡皮 | 深夜 | 文具盒 |

教材原话：“看到上面这些词语，你的脑海里浮现出了怎样的画面？你想到了什么样的故事？选择一组，发挥想象，把故事写下来。”横着选一组最省事，也允许从每一竖列各挑一个自行搭配。角色不封顶——教材明说“可以是上面提供的角色，还可以添加你喜欢的其他角色”。引导学生思考：看到这些词语，你脑海中浮现出什么画面？它们之间可能发生什么故事？

3. 围绕要素展开想象

教材“写之前想一想”给了三问，逐问过一遍：①故事里有哪些角色？（可以是习作页提供的角色，还可以添加自己喜欢的其他角色。）②故事发生在什么时间？是在哪里发生的？③他们在那里做什么？他们之间发生了什么事？第三问即起因、经过、结果的入口。鼓励学生大胆想象，不拘泥于现实逻辑。

4. 口头创编，初步成文

让学生选择一组词语，先在小组内口头创编故事。小组成员听完后可以提出建议：哪里很有趣？哪里还可以更神奇？

第二环节：作中指导——写故事，写完整

1. 明确习作要求

选择一组词语或自己确定角色，编一个童话故事。故事要有角色、时间、地点和事情的起因、经过、结果。发挥想象，让故事有趣或神奇。语句通顺，意思清楚。

2. 指导把故事写完整

提供简单框架帮助构思：开头介绍角色、时间和地点。中间写故事经过，遇到了什么事或什么人，做了什么。结尾写结果怎样。鼓励学生在“经过”部分写出一点波折，比如角色遇到困难、出现帮手、发生意外等。

3. 指导写对话

童话中角色经常说话，提醒学生正确使用冒号和引号，这是三年级标点学习的一个重点。

第三环节：作后评改——讲故事，赏童话

1. 同桌互读

互相读给对方听，读完说说：故事完整吗？哪里最有趣？

2. 加题目、修改完善

根据同桌的建议，修改自己故事中不完整、不通顺的地方；给故事加一个题目，写在第一行正中间；再用学过的修改符号（删除号、增补号、改正号）把稿子理一遍——多的圈掉、漏的补上、错的改正。

3. 童话故事会

组织“童话故事会”，请几位同学在全班朗读自己的童话。引导听众从“想象力、完整性、趣味性”等方面进行评价和欣赏。

4. 汇编班级童话集

鼓励将全班同学的童话汇编成册，放在班级图书角，增强成就感。

### 四、评价标准参考

1. 基础过关：能根据词语创编一个简单故事，角色、时间、地点清楚，故事基本完整，写完加了题目。

2. 良好达标：故事完整，有起因经过结果，情节有一定想象力，语句通顺。

3. 优秀进阶：故事完整有趣，想象丰富新奇，情节有波折，对话生动，能给读者带来惊喜。

## 三年级上册·第五单元 习作《我们眼中的缤纷世界》（观察作文）

```meta
册: 三年级上册
任务: 第五单元 习作《我们眼中的缤纷世界》（观察作文）
文体: 观察作文
关键词: 观察 事物 变化
分级: L3
```

### 一、习作要求（教学目标）

1. 学习留心观察周围事物：能运用多种感官（眼看、耳听、手摸、鼻闻等）对事物进行细致观察。

2. 把观察所得写下来：能把观察时印象最深的一两个方面写清楚，写出事物的特点或变化。

3. 尝试用积累的词语表达：能在习作中运用平时积累的描写颜色、形状、声音等的词语。

4. 感受观察的乐趣：通过细致观察发现平常事物的美和趣味，体会“世界上不缺少美，只是缺少发现美的眼睛”。

### 二、教学重难点

重点：指导学生运用多种感官进行观察，把观察到的内容写具体。

难点：帮助学生从观察中抓住事物的特点或变化，而不是流水账式地记录。

### 三、教学建议（核心教学环节）

第一环节：作前指导——细观察，真发现

1. 提前布置观察任务

课前布置学生选择一种事物或一个场景进行观察，可以是动物、植物、水果、文具、一处景物等。要求动用多种感官去观察，做好简单记录。

2. 交流观察发现，激发兴趣

课堂上组织学生交流自己的观察发现。引导学生从不同感官的角度来说：你看到了什么？（颜色、形状、大小、变化）听到了什么？（声音像什么？）闻到了什么？（气味怎样？）摸到了什么？（手感、温度）尝到了什么？（味道，适用于可食用事物）通过交流，让学生感受到同一个事物可以从多个角度来观察。

3. 指导聚焦印象最深的地方

引导学生想一想，在观察中印象最深的画面是什么？哪里让自己觉得最有趣、最美、最特别？强调不必面面俱到，把这一两个印象最深的地方写具体就好。

4. 回顾课文中的观察方法

结合本单元课文《搭船的鸟》《金色的草地》，回顾作者是怎样观察的，是怎样把观察到的写清楚的。学习作家用准确的语言描写事物特点的方法。

第二环节：作中指导——选角度，写具体

1. 明确习作要求

写一种自己观察过的事物或一处场景。写出自己观察到的内容，把印象最深的地方写清楚。可以用上学过的词语。语句通顺，格式正确。

2. 指导把特点写具体

帮助学生从“是什么样”升级到“具体怎么样”。举例子对比：写“菊花很美”不如写“菊花的颜色金灿灿的，花瓣细细长长的，像妈妈的卷发一样舒展开来”。引导学生用比喻、用积累的词语把看到的内容写得让人仿佛亲眼见到。

3. 指导写出变化

如果观察的是一个过程或场景的变化，如日出、花开、蚂蚁搬家等，可以用上“刚开始……过了一会……最后……”等词把变化过程写清楚。

第三环节：作后评改——读作品，共发现

1. 自读修改

自己读一遍，看看观察到的东西写清楚了没有，有没有把印象最深的那个画面写出来。

2. 小组交流

小组内交换读，互相说说：读了对方的习作，你仿佛看到了什么？哪些句子让你印象深刻？

3. 全班展示

选择几篇观察角度独特、描写具体的习作在全班展示，引导大家欣赏作者的眼睛是怎样发现美的。老师总结：只要留心观察，平常的事物也会变得不平常。

### 四、评价标准参考

1. 基础过关：能写出观察到的内容，有基本的形状、颜色等方面的描写。

2. 良好达标：能运用多种感官观察，把观察到的一两个方面写清楚，语句通顺。

3. 优秀进阶：观察细致，能抓住事物独特的特征，描写具体生动，能运用恰当的词语和修辞手法，让人有身临其境之感。

## 三年级上册·第六单元 习作《这儿真美》（写景）

```meta
册: 三年级上册
任务: 第六单元 习作《这儿真美》（写景）
文体: 写景
关键词: 风景 围绕一个意思 身边美景
分级: L3
```

### 一、习作要求（教学目标）

1. 选择身边的美景来写：能从校园、公园、村庄、小区等身边的环境中，选择一处自己觉得美的地方来写。

2. 围绕一个意思写：学习围绕“这儿真美”这个中心意思，把景物的特点写清楚。

3. 按一定顺序写景物：尝试按空间顺序（从远到近、从上到下等）或时间顺序来写景物。

4. 运用积累的词语：能运用学过的描写颜色、形状的词语，把景物写得有画面感。

### 二、教学重难点

重点：指导学生围绕“美”这个中心意思，按一定顺序把景物特点写清楚。

难点：帮助学生避免走马观花式的罗列，学会选取有代表性的景物进行具体描写。

### 三、教学建议（核心教学环节）

第一环节：作前指导——赏美景，定顺序

1. 提前布置观察或回顾

课前让学生有意识地去观察身边的一处美景，或者回忆自己去过的美丽的地方。可以是用眼睛实地观察，也可以是借助照片、回忆来重现场景。

2. 交流美景，打开思路

让学生说说自己身边有哪些美的地方：校园的一角、小区的花园、村口的大树、家乡的小河、公园的湖等。引导学生说清楚这个地方在哪儿，那里有什么，为什么觉得美。

3. 指导围绕“美”选择景物

一个地方的景物可能有很多，引导学生思考：最能体现这儿“美”的是哪些景物？不需要把所有的都写出来，选择几个最有代表性的、最美的来写。

4. 指导按顺序写

让学生想一想可以按什么顺序来介绍：从远到近、从近到远、从上到下、从左到右、从整体到局部等。确定一个顺序后，先口述练习：先说远处的山，再说山下的湖，最后说湖边的树。

5. 回顾课文中的写法

结合本单元课文《富饶的西沙群岛》《海滨小城》《美丽的小兴安岭》，回顾作者是怎样围绕一个意思、按顺序写景物的。

第二环节：作中指导——定顺序，写特点

1. 明确习作要求

写身边的一处美景。围绕“这儿真美”这个意思来写。按一定的顺序写出景物的美。运用学过的词语把景物写生动。语句通顺，标点正确。

2. 指导围绕中心句写

可以在开头或结尾用上“这儿真美”这个中心句，然后围绕它来写。如开头写“我们学校的后花园真美”，下面的内容就围绕“美在哪里”来展开。

3. 指导把景物写具体

对选择写的景物，从颜色、形状、大小等方面进行具体描写，不只用“很美”“很漂亮”这样笼统的词。引导学生用上学过的描写词语，如“五光十色”“葱葱茏茏”“金灿灿”等。

第三环节：作后评改——读美文，共赏美

1. 自读自改

读一遍自己的习作，检查顺序是否清楚，有没有围绕“美”来写。

2. 同桌互读

互相读给对方听，说说：读了你的习作，我觉得这个地方真的很美吗？哪里写得最美？

3. 全班展示

选出几篇写不同地点、不同风格的习作展示，可以配合作者的照片或图画，让全班同学一起“云游”美景。老师重点引导学生欣赏作者有序描写和抓住景物特点的方法。

### 四、评价标准参考

1. 基础过关：能写出身边的一处地方，写出有哪些景物，语句基本通顺。

2. 良好达标：能围绕“美”来写，按一定顺序写景物，能写出景物的颜色、形状等特点。

3. 优秀进阶：顺序清晰，景物特点突出，能运用丰富的词语把景物写得生动优美，让人读后有向往之情。

## 三年级上册·第七单元 习作《我有一个想法》

```meta
册: 三年级上册
任务: 第七单元 习作《我有一个想法》
文体: 表达观点
关键词: 现象 想法 建议
分级: L3
```

### 一、习作要求（教学目标）

1. 学习关注身边的现象和问题：能留心观察生活，发现生活中需要改进的问题或需要关注的现象。

2. 把想法写清楚：能写清楚自己发现的某种现象或问题，并把自己的想法和建议表达清楚。

3. 学习“先写现象，再写想法”的结构：初步学习用“发现问题——提出想法——给出建议”的基本结构来写。

4. 培养社会责任感和主人翁意识：通过对身边事物的关注和思考，增强参与社会生活的意识。

### 二、教学重难点

重点：指导学生把发现的现象和自己的想法的想法写清楚。

难点：帮助学生把想法写得有条理，能把“为什么这样想”说清楚，而不仅仅是“我觉得不好”。

### 三、教学建议（核心教学环节）

第一环节：作前指导——聊现象，说想法

1. 创设情境，引出话题

老师可以先说出自己观察到的一个现象和想法，如“我发现班里有些同学课间总爱在走廊里追逐打闹，我想如果大家都能文明游戏，既安全又开心”。引出话题：生活中，你有没有注意到一些现象或问题，让你产生了一些想法？

2. 引导学生从生活中发现

从不同角度打开思路：在家里（家人爱玩手机、浪费水等）、在学校（操场设施、垃圾分类、图书角管理等）、在小区或社会上（随地吐痰、乱扔垃圾、流浪小动物等）。让学生说说自己注意到的现象。

3. 指导把现象说清楚

当学生说出一个现象后，引导他说得更具体：你是在什么时候、什么地方看到的？这个现象是怎样的？有什么不好的影响或值得关注的地方？

4. 指导把想法说清楚

追问：看到这个现象，你有什么想法？你觉得应该怎么做？你的建议是什么？引导学生不仅说出“这样不好”，还要说出“为什么不好”和“应该怎样”。

5. 口头练习，初步成形

让学生在小组内按照“现象——想法——建议”的顺序说一遍，组员提出建议。

第二环节：作中指导——分层次，写想法

1. 明确习作要求

写一个自己发现的生活中的现象或问题。把现象写清楚，再写自己的想法和建议。语句通顺，能把意思写明白。

2. 指导写作结构

第一部分：写现象。写清楚发现了什么现象，它是什么样的，有什么影响。第二部分：写想法。看到这个现象，自己是怎么想的，为什么觉得需要关注或改进。第三部分：写建议。提出自己的建议或解决办法。

3. 分层要求

基础层：能写出一个现象和简单的想法。提高层：能写清楚现象的表现，写出自己的想法和理由。拔尖层：能分层次写，观点明确，建议合理可行。

第三环节：作后评改——评想法，议行动

1. 同桌互读

交换读，看看对方的想法写清楚了没有，自己是不是也有同感。

2. 小组讨论

小组内读了大家的想法后，选出最有价值的一个想法，在全班分享。讨论：哪个想法最值得大家关注？哪个建议最可行？

3. 全班交流

各组代表分享最有价值的想法。老师引导学生关注：这些想法是不是基于真实的观察？建议是不是切实可行？鼓励学生课后尝试去实践一些好的建议。

### 四、评价标准参考

1. 基础过关：能写出一个生活中的现象和自己的简单想法，语句基本通顺。

2. 良好达标：能把现象写清楚，想法表达明白，有一定的理由。

3. 优秀进阶：现象具体真实，想法有说服力，建议可行，结构层次分明，语言流畅。

## 三年级上册·第八单元 习作《那次玩得真高兴》

```meta
册: 三年级上册
任务: 第八单元 习作《那次玩得真高兴》
文体: 记事
关键词: 玩 高兴 过程
分级: L3
```

### 一、习作要求（教学目标）

1. 选一件玩得高兴的事来写：能从自己的经历中选择一次玩得特别高兴的活动来写。

2. 按顺序写清楚过程：能按事情发展的顺序，把玩的过程一步一步写清楚。

3. 写出高兴的心情：能在叙事中通过动作、神态、语言和心理描写，表现出“高兴”的心情。

4. 学会分享快乐：通过习作把快乐传递给读者，体会分享的乐趣。

### 二、教学重难点

重点：指导学生把玩的过程按顺序写清楚，突出高兴的心情。

难点：帮助学生把“高兴”写具体，不是只说“我很高兴”，而是通过具体的描写让读者感受到高兴。

### 三、教学建议（核心教学环节）

第一环节：作前指导——忆快乐，说过程

1. 创设轻松氛围，唤起回忆

以聊天的方式导入：大家平时最喜欢玩什么？哪一次玩得特别高兴，到现在想起来还想笑？让学生打开记忆的闸门，想一想那些快乐的事情。

2. 多角度打开思路

引导学生从不同范围回忆：和同学一起玩（踢球、游戏、春游等）、和家人一起玩（去游乐园、旅行、过节等）、自己玩（拼积木、骑自行车等）。帮助学生明确要写的是“哪一次”，而不是“经常玩的”。

3. 指导按顺序说过程

请学生说说那次玩的过程：玩之前做了什么准备？刚开始怎么样？接着发生了什么？最精彩、最开心的是哪个时刻？最后是怎么结束的？可以用上“开始……接着……然后……最后……”等表示顺序的词语。

4. 指导把高兴写具体

问学生：当时你高兴成什么样了？有什么动作？说了什么？表情什么样？心里是什么感觉？引导用具体描述代替笼统的“很高兴”，比如“高兴得跳了起来”“笑得肚子疼”“兴奋得晚上都睡不着”等。

第二环节：作中指导——重过程，写心情

1. 明确习作要求

写一次自己玩得真高兴的经历。按顺序写清楚玩的过程。写出当时高兴的心情。语句通顺，把意思表达明白。

2. 指导写好过程

提醒学生把过程分解成几个环节，一个环节写一个自然段或几句话。重点写出最精彩的那个时刻，放大了写。

3. 指导写好心情

在叙述过程中，自然地加入表现心情的句子。可以写在做什么动作时的心情，也可以单独写一两句心理感受。

第三环节：作后评改——读快乐，共分享

1. 自读自查

读一遍自己的习作，看看过程写清楚了没有，高兴的心情写出来没有。

2. 同桌互读“评快乐指数”

同桌交换读，读完给对方的“快乐指数”打分：读完这篇习作，我感受到作者的高兴了吗？哪里让我也跟着开心了？如果不太能感受到，说明心情写得还不够具体。

3. 全班分享

选几篇写得特别有感染力的习作在全班朗读，让全班同学一起感受快乐。老师引导学生关注作者是怎样把快乐写得让读者也感同身受的。

### 四、评价标准参考

1. 基础过关：能写清楚玩的过程，有基本的情节，语句通顺。

2. 良好达标：过程清楚，有简单的顺序，写出了高兴的心情。

3. 优秀进阶：过程具体生动，重点突出，高兴的心情写得有感染力，让读者也能感受到快乐。
