## 三年级下册·第一单元 习作《我的植物朋友》

```meta
册: 三年级下册
任务: 第一单元 习作《我的植物朋友》
文体: 状物·植物
关键词: 植物 观察记录卡
分级: L3
```

### 一、习作要求（教学目标）

1. 选择一种植物进行观察记录：能选择自己感兴趣的一种植物，通过观察或查阅资料，了解它的样子、颜色、气味等特点。

2. 为植物制作观察记录卡：学习用记录卡的形式，有条理地整理观察到的信息，为习作准备素材。

3. 把观察到的内容写清楚：能借助记录卡，把植物的样子、颜色、气味、变化等方面写清楚。

4. 写出自己的感受：在描写植物的过程中，自然表达自己对这位“植物朋友”的喜爱之情。

### 二、教学重难点

重点：指导学生借助观察记录卡，把植物的特点写清楚。

难点：帮助学生把植物写得有特点、有感情，而不是千篇一律的科普说明。

### 三、教学建议（核心教学环节）

第一环节：作前指导——交朋友，做记录

1. 提前布置观察任务

课前让学生选择一种植物作为“朋友”进行观察。可以是家里养的、校园里的、路边的、公园里的等。引导学生运用多种感官去观察：用眼睛看（形状、颜色、大小）、用鼻子闻（气味）、用手摸（叶片的质感）等。可以查阅资料，了解这种植物的名称、习性等。

2. 指导制作观察记录卡

出示观察记录卡的范例，让学生学习记录。记录卡可以包括：名称、样子（根、茎、叶、花、果实等）、颜色、气味、摸上去的感觉、生长变化、其他发现等。提醒学生不用面面俱到，记录自己观察到的最有特点的方面即可。

3. 课堂交流，分享发现

让学生拿着自己的记录卡或照片，在小组内交流自己的植物朋友。说说自己观察到了什么，最感兴趣的是什么，为什么选它做朋友。

4. 指导把记录转化为叙述

引导学生把记录卡上的关键词和短句，转化成通顺的句子。比如记录卡上写“叶子：绿色，手掌形，有毛”，可以转化为“它的叶子是绿色的，像一只只小手掌，摸上去毛茸茸的”。进行口述练习，为动笔做准备。

第二环节：作中指导——借记录，写清楚

1. 明确习作要求

写一种自己观察过的植物。写出植物的样子、颜色、气味等特点。借助观察记录卡，把内容写清楚。写出自己对植物的喜爱之情。语句通顺，书写工整。

2. 指导写作顺序

给学生提供基本的写作顺序：先介绍植物名称和来历（怎么认识的），再写植物的样子（从整体到局部，或按根、茎、叶、花、果实的顺序），然后写植物的变化或独特之处，最后写出自己的感受和喜爱。

3. 指导把特点写具体

提醒学生参照记录卡，把每一个特点都写具体。不说“花很美”，而写“它的花是粉红色的，花瓣一层一层的，像小姑娘的裙子”。鼓励用上比喻、拟人等手法，让描写更生动。

4. 指导表达情感

引导学生思考：为什么把它当成朋友？它给你带来了什么？看到它你会想到什么？在描写中自然融入自己的感受。

第三环节：作后评改——读作品，赏朋友

1. 同桌互读

互相读给对方听，读完说说：你认识这位“植物朋友”了吗？哪里写得最清楚？

2. 对照记录卡修改

学生对照自己的观察记录卡，检查有没有把观察到的重要内容遗漏，有没有写得不清楚的地方，进行修改补充。

3. 全班展示

选出写不同种类植物的习作在全班展示，让同学们认识更多“植物朋友”。引导从“特点是否清楚、描写是否生动、有没有感情”等方面进行欣赏和点评。

4. 延伸活动

可以将全班习作配上图画或照片，做成“班级植物图鉴”，放在图书角供大家阅读。

### 四、评价标准参考

1. 基础过关：能写出植物的名称和基本样子，语句基本通顺。

2. 良好达标：能写清楚植物的样子、颜色等特点，有一定的描写，表达出喜爱之情。

3. 优秀进阶：观察细致，特点突出，描写生动形象，能运用比喻等手法，感情真挚自然。

## 三年级下册·第二单元 习作《看图画，写一写》（放风筝）

```meta
册: 三年级下册
任务: 第二单元 习作《看图画，写一写》（放风筝）
文体: 看图作文
关键词: 放风筝 画面 想象
分级: L3
```

### 一、习作要求（教学目标）

1. 有序观察画面内容：能按一定顺序观察图画，看清楚图上有哪些人、他们在做什么、周围环境怎样。

2. 把看到的和想到的写清楚：能把观察到的画面内容写清楚，并结合自己的生活经验展开合理想象。

3. 把人物动作写具体：学习使用准确的动词描写放风筝的动作，把过程写生动。

4. 写出活动的快乐：在描写中表现出放风筝的乐趣和春天的美好。

### 二、教学重难点

重点：指导学生把画面上的内容写清楚，把放风筝的过程写具体。

难点：帮助学生在静态画面基础上，通过想象把人物的动作、语言和心理活动写得生动有趣。

### 三、教学建议（核心教学环节）

第一环节：作前指导——看图画，说画面

1. 整体感知图画

出示图画，让学生先整体看一看，用一两句话说说画面画了什么。明确画面主题：春天放风筝。

2. 有序观察画面要素

引导学生按一定顺序观察：环境（天气怎样？天空有什么？地上有什么？）、人物（有哪些人？他们分别在做什么？动作怎样？表情如何？）、风筝（有哪些风筝？什么样子的？飞得怎么样？）。让学生把观察到的要素一一说清楚。

3. 展开想象，让画面“活”起来

在观察的基础上追问：画面中的人在说什么？他们在想什么？风筝飞上天的那一刻，他们心情怎样？近处的人物在做什么？远处的人物又在做什么？鼓励学生联系自己放风筝的经历进行想象，把静态的画面想象成动态的过程。

4. 口头完整描述

请学生按照“环境——人物——风筝——感受”的顺序，把画面内容完整地说一遍。可以同桌互说，互相补充。

第二环节：作中指导——分层次，写生动

1. 明确习作要求

认真观察图画，写清楚看到的和想到的。把放风筝的过程写具体，写出人物的动作和心情。语句通顺，表达清楚。

2. 指导写作结构

提供结构参考：开头写时间和环境（春天的景色、天气等）。中间写画面的主要内容，可以按“近处的人——远处的人——天空中的风筝”的顺序来写。结尾写感受或想象画面以外的内容。

3. 指导写好动作

放风筝涉及一系列动作，如“举、跑、放线、拉、拽、看”等。引导学生使用准确的动词，并用上“一手……一手……”“一边……一边……”等句式把动作写连贯。

4. 指导写出心情

不仅写“很开心”，还要写出开心的表现，如“兴奋地大喊”“笑得合不拢嘴”“激动得跳了起来”等。

第三环节：作后评改——读画面，评生动

1. 自读修改

自己读一遍，看看画面内容写清楚了没有，动作和心情写得是否具体。

2. 同桌互评

交换读习作，读完说说对方哪里写得让自己仿佛看到了画面，哪里还可以写得更生动。

3. 全班展示

选几篇写得生动有趣、想象丰富的习作在全班朗读展示。可以请其他同学根据习作内容，用自己的话复述画面，检验写得是否清楚。

### 四、评价标准参考

1. 基础过关：能写出画面上的基本内容，有人物和活动，语句基本通顺。

2. 良好达标：能把画面内容写清楚，有对人物动作和心情的描写，语句通顺。

3. 优秀进阶：画面描写生动具体，动作描写准确传神，想象合理丰富，能让读者产生身临其境之感。

## 三年级下册·第三单元 习作《中华传统节日》

```meta
册: 三年级下册
任务: 第三单元 习作《中华传统节日》
文体: 记事·文化
关键词: 节日 过节经过
分级: L3
```

### 一、习作要求（教学目标）

1. 选择一个传统节日来写：能从春节、元宵、清明、端午、中秋、重阳等中华传统节日中，选择自己最感兴趣或最熟悉的一个来写。

2. 写清楚过节的过程或节日习俗：能把过节的过程或节日中印象深刻的事写清楚，把节日习俗写明白。

3. 按一定顺序写：能按时间顺序或事情发展的顺序来写过节的过程。

4. 表达真情实感：在写过节的过程中，写出自己的心情和感受，表达对传统文化的热爱。

### 二、教学重难点

重点：指导学生把过节的过程或印象深刻的节日习俗写清楚。

难点：帮助学生在写节日的同时，写出自己的真实感受，避免写成简单的节日介绍。

### 三、教学建议（核心教学环节）

第一环节：作前指导——话节日，忆习俗

1. 打开思路，畅谈节日

引导学生回顾传统节日：你知道哪些中华传统节日？分别在哪一天？有什么习俗？可以出示图片或实物（灯笼、粽子、月饼、春联等），唤起学生的记忆。

2. 选定节日，聚焦内容

让学生选定一个自己最想写的节日。引导思考：这个节日你印象最深的是什么？是过节的过程（如包粽子、贴春联、赏月），还是节日中发生的一件事（如和家人一起守岁、看龙舟比赛），还是节日的习俗和传说？帮助学生明确自己要写的内容。

3. 指导按顺序写过程

如果写过节的过程，引导学生按时间顺序来想：节前做了什么准备？节日当天先做了什么，然后做了什么，最后做了什么？如果写节日习俗，可以从几个方面来介绍，如习俗的内容、怎么做的、有什么寓意等。

4. 口头交流，互相启发

在小组内说说自己准备写什么、怎么写。听的同学可以提出建议：哪里还可以写得更具体？有没有遗漏重要的内容？

第二环节：作中指导——定顺序，写清楚

1. 明确习作要求

选一个中华传统节日来写。写清楚过节的过程或节日习俗。按一定的顺序写。写出自己的心情和感受。语句通顺，意思清楚。

2. 指导写作结构

提供参考结构：开头点明是什么节日，这个节日给你的总体感觉。中间具体写过节的过程或习俗，按顺序一步一步写清楚。结尾写自己的感受或对这个节日的感情。

3. 指导写出节日气氛

引导学生用上描写颜色、声音、气味的词语来表现节日特有的气氛。比如春节的红灯笼、鞭炮声、饺子的香味，中秋的明月、月饼的香甜、桂花的清香等。

4. 指导表达情感

在叙述中自然地写出自己的心情，如和家人一起过节时的温暖、参加节日活动的兴奋、对节日传说的喜爱等。

第三环节：作后评改——读节日，传文化

1. 同桌互读

交换读，读完说说：他的习作让你了解这个节日了吗？过节的过程清楚吗？

2. 自我修改

检查过程是否按顺序写清楚了，有没有把自己的感受写出来，进行补充修改。

3. 全班展示与交流

按节日分类展示习作，让写同一个节日的同学互相比较、学习，看看各自写的侧重点有什么不同。引导从“过程清楚、顺序合理、有真情实感”等方面进行点评。可以结合综合性学习“中华传统节日”的成果一起展示。

### 四、评价标准参考

1. 基础过关：能写出一个传统节日和基本的过节过程或习俗，语句通顺。

2. 良好达标：能按顺序把过节过程或习俗写清楚，写出自己的感受。

3. 优秀进阶：过程具体清楚，节日气氛浓厚，描写生动，真情实感自然流露。

## 三年级下册·第四单元 习作《我做了一项小实验》

```meta
册: 三年级下册
任务: 第四单元 习作《我做了一项小实验》
文体: 记事·实验
关键词: 实验 先接着然后最后
分级: L3
```

### 一、习作要求（教学目标）

1. 亲手做一项小实验：能选择一项简单有趣的小实验动手操作，获得真实的体验和写作素材。

2. 按步骤把实验过程写清楚：能按照“先……接着……然后……最后……”的顺序，把实验的过程一步一步写清楚。

3. 写出实验中的心情和发现：能写出自己在实验过程中的心情变化，以及实验中的有趣发现。

4. 初步学习写“做—看—想”：尝试在写过程的同时，写出自己看到了什么、想到了什么。

### 二、教学重难点

重点：指导学生把实验步骤按顺序写清楚。

难点：帮助学生在写实验步骤的基础上，融入自己的观察、思考和心情变化，让习作有过程、有发现、有感受。

### 三、教学建议（核心教学环节）

第一环节：作前准备——做实验，真体验

1. 提前布置做实验

课前布置学生自己动手做一项简单、安全的小实验，如“鸡蛋浮起来了”“纸片托水”“会吸水的蜡烛”“静电实验”等。鼓励学生自己准备材料，亲自动手操作，边做边观察边思考。如果条件不允许，也可在课堂上统一做一个小实验。

2. 指导记录实验信息

让学生在做实验的过程中，用简单的词语记录下关键信息：实验名称、实验材料、实验步骤（用顺序词）、实验结果、我的发现等。为写作积累素材。

3. 课堂上交流分享

让学生带着实验记录或实验材料到课堂，在小组内分享自己做的实验。说清楚：做了什么实验？怎么做的？看到了什么现象？有什么发现？组员可以对不清楚的地方进行提问。

第二环节：作中指导——按步骤，写清楚

1. 明确习作要求

写自己做过的一项小实验。按顺序把实验过程写清楚。写出实验中的心情和发现。语句通顺，表达清楚。

2. 指导写作结构

提供结构参考：开头写实验名称和做实验的原因或心情。中间写实验过程，这是重点，分步写清楚：先准备什么材料，接着怎么做，然后观察到了什么现象，最后结果怎样。结尾写自己的发现、感受或懂得的道理。

3. 指导写好实验步骤

这是本次习作的核心。引导学生用上表示先后顺序的词语，如“第一步……第二步……第三步……”或“先……再……接着……然后……最后……”。每步写一两句话，把操作和观察到的现象结合起来写。

4. 指导写“做、看、想”三结合

在写每一步操作的同时，引导学生写写自己当时看到了什么现象、心里想了什么。如“我小心翼翼地把鸡蛋放入盐水中，眼睛一眨不眨地盯着它。咦，鸡蛋怎么还是没有浮起来？是不是盐放少了？”这样让习作更有趣味，也更有科学探究的味道。

第三环节：作后评改——读步骤，验清楚

1. 同桌互读互验

交换读习作，读完互相检验：按照他写的步骤，能明白这个实验怎么做吗？如果哪里不清楚，提出来。

2. 自我修改

根据同桌反馈，修改不清楚的步骤。检查顺序词使用是否恰当。

3. 全班展示

选几个写了不同实验的习作在全班展示。可以请作者一边读，一边用实验材料演示，检验习作是否把步骤写清楚了。引导从“步骤清楚、顺序清晰、有观察和思考”等方面点评。

### 四、评价标准参考

1. 基础过关：能写出实验的基本步骤，语句基本通顺。

2. 良好达标：能按顺序写清楚实验过程，有简单的观察和感受。

3. 优秀进阶：步骤清楚有序，写出了实验中的有趣发现和自己的所思所想，融入了科学探究的精神。

## 三年级下册·第五单元 习作《奇妙的想象》

```meta
册: 三年级下册
任务: 第五单元 习作《奇妙的想象》
文体: 想象
关键词: 大胆想象 奇妙
分级: L3
```

### 一、习作要求（教学目标）

1. 大胆想象，创编故事：能根据教材提供的题目或自己拟定的题目，展开大胆、新奇的想象，创编一个想象故事。

2. 把故事写完整：能写清楚故事的角色、起因、经过和结果，有基本的故事情节。

3. 写出想象的奇妙之处：能把最奇妙、最大胆的想象写具体，让读者感受到想象的魅力。

4. 感受想象的乐趣：在自由想象中体会创作的快乐，激发想象力和创造力。

### 二、教学重难点

重点：引导学生大胆展开想象，创编一个完整有趣的想象故事。

难点：帮助学生在“大胆”的基础上做到“合理”，即故事内部逻辑自洽，同时把奇妙之处写具体。

### 三、教学建议（核心教学环节）

第一环节：作前指导——开脑洞，选题目

1. 回顾课文，激发想象

引导学生回顾本单元的精读课文《宇宙的另一边》《我变成了一棵树》，说说作者有哪些奇妙大胆的想象，这些想象为什么让人觉得很神奇、很有趣。

2. 介绍题目，打开思路

出示教材提供的想象题目：最好玩的国王、一本有魔法的书、小树的心思、躲在草丛里的星星、手罢工啦、滚来滚去的小土豆、假如人类可以冬眠等。逐个简单讨论：看到这个题目，你想到了什么？引发学生的想象。鼓励学生自己拟一个更奇妙的题目。

3. 选定题目，搭建故事框架

让学生选定一个自己最感兴趣的题目，想一想：故事的主角是谁？他有什么特别的地方？发生了什么奇妙的事情？事情的起因是什么？经过怎样？结果如何？在小组内说一说自己的初步构思。

4. 指导把“奇妙之处”想具体

引导学生思考故事中最奇妙、最与众不同的地方在哪里。比如写《一本有魔法的书》，这本书的魔法是什么？怎么使用？会产生什么效果？把这些问题想清楚，故事才能写得具体有趣。

第二环节：作中指导——搭框架，写奇妙

1. 明确习作要求

选一个题目或自己拟一个题目，写一个想象故事。大胆想象，创造属于自己的奇妙世界。把故事写完整，有起因、经过和结果。把最奇妙的地方写具体。语句通顺，表达清楚。

2. 指导写作结构

提供参考结构：开头交代故事的主角和他所处的奇妙世界或特殊情境。中间写故事的经过，发生了什么奇妙的事，主角经历了什么。结尾写故事的结果，可以出人意料，也可以温馨动人。

3. 指导写好“奇妙感”

在故事的展开过程中，通过具体的描写表现想象的奇妙。可以写奇妙的环境、奇妙的人物能力、奇妙的事件变化等。鼓励学生把想象的内容当作“真的发生过”一样来认真描写，让读者信以为真。

第三环节：作后评改——赏想象，评创意

1. 同桌互读

交换读对方的想象故事，读完后说说：你觉得最奇妙的地方是哪里？故事完整吗？

2. 小组评选

在小组内朗读各自的习作，评选出“最佳创意奖”“最奇妙想象奖”“最有趣故事奖”等，激发学生的创作热情。

3. 全班展示

各组推选代表在全班朗读，引导从“想象是否大胆奇妙、故事是否完整、奇妙之处是否具体”等方面进行欣赏和点评。

4. 汇编想象故事集

将全班习作汇编成册，放在班级图书角，激发持久的创作兴趣。

### 四、评价标准参考

1. 基础过关：能围绕题目写一个简单的想象故事，故事基本完整。

2. 良好达标：想象比较大胆新奇，故事完整，能把奇妙之处写出来。

3. 优秀进阶：想象独特奇妙，故事引人入胜，奇妙之处描写具体生动，情节有创意。

## 三年级下册·第六单元 习作《身边那些有特点的人》

```meta
册: 三年级下册
任务: 第六单元 习作《身边那些有特点的人》
文体: 写人
关键词: 特点 称呼 事例
分级: L3
```

### 一、习作要求（教学目标）

1. 选择身边有特点的人来写：能从家人、老师、同学、邻居等身边人中，选一个在某方面特别有特点的人来写。

2. 用具体事例表现特点：能通过一件或几件具体的事，把人物某方面的特点写清楚，不空洞地说特点。

3. 学习用“特点+事例”的结构：初步学习用“先概括特点，再写具体事例”的方式来写人。

4. 表达对人物的情感：在写人物的过程中，自然表达自己对这个人的感情。

### 二、教学重难点

重点：指导学生通过具体事例来表现人物的特点。

难点：帮助学生在众多特点中聚焦一个最有代表性的特点，并选择最能表现这个特点的事例来写。

### 三、教学建议（核心教学环节）

第一环节：作前指导——找特点，选事例

1. 理解“特点”，打开思路

引导学生理解“有特点的人”是什么意思。可以先举例：“小书虫”“乐天派”“运动健将”“故事大王”“热心肠”“小问号”“幽默王子”等。让学生说说自己身边有没有这样的人，他们有什么与众不同的地方。

2. 选定人物，聚焦特点

让学生选定一个自己最想写的人。想一想：这个人最大的特点是什么？用一个词或一句话来概括。提醒学生：一个人可能有很多特点，这次习作只需要抓住一个最突出的特点来写，不要面面俱到。

3. 用具体事例支撑特点

这是本次习作的关键。引导学生回忆：哪些事最能体现他这个特点？至少想出一两件具体的事。在小组内说一说：你写了谁？他有什么特点？你打算用什么事例来写？组员评议：这个事例能不能很好地表现这个特点？

4. 指导把事例写具体

选择一个最典型的事例，引导学生把这件事展开说清楚：事情发生在什么时候、什么地方？他做了什么、说了什么？当时的表现怎样？通过具体的言行来展现特点。

第二环节：作中指导——抓特点，写事例

1. 明确习作要求

写身边一个有特点的人。用具体的事例来表现人物的特点。把事例写清楚。语句通顺，表达出对人物的感情。

2. 指导写作结构

提供参考结构：开头介绍要写的人是谁，概括他有什么特点（可以用一个词或一句话）。中间写一件或几件具体的事例来表现这个特点，把事例写具体（人物的动作、语言、神态等）。结尾写出自己对这个人的看法或感情。

3. 指导写好人物言行

事例中要通过人物的语言、动作、神态来表现特点。比如写“热心肠”，可以写他主动帮同学值日、扶老人过马路等，写清楚他是怎么说、怎么做的。

4. 避免“贴标签”

提醒学生不要只是反复说“他真是一个热心肠”，而要让人物自己的行动来证明这一点。事例写好了，特点自然就出来了。

第三环节：作后评改——读事例，评特点

1. 同桌互读

交换读，读完说说：他写的人有什么特点？事例能表现这个特点吗？

2. 自我修改

根据同桌反馈，检查事例是否写具体了，有没有需要补充修改的地方。

3. “猜猜他是谁”升级版

在全班展示几篇习作（不读名字），让同学们根据事例猜写的是谁。如果大家能异口同声说出来，说明特点和事例都写得很好。

4. 全班点评

引导从“特点是否鲜明、事例是否具体、人物形象是否生动”等方面进行点评。

### 四、评价标准参考

1. 基础过关：能写出一个人和他的某个特点，有简单的事例，语句通顺。

2. 良好达标：特点鲜明，能用一件事例表现特点，事例写清楚。

3. 优秀进阶：特点非常突出，事例具体生动，人物的言行描写到位，感情真挚。

## 三年级下册·第七单元 习作《国宝大熊猫》

```meta
册: 三年级下册
任务: 第七单元 习作《国宝大熊猫》
文体: 说明性介绍
关键词: 熊猫 信息整合 介绍
分级: L3
```

### 一、习作要求（教学目标）

1. 围绕问题搜集整合信息：能围绕教材提出的关于大熊猫的问题，通过查阅书籍、上网等方式搜集信息。

2. 学习整合信息介绍事物：能把搜集到的信息进行筛选和整合，用自己的话从几个方面介绍大熊猫。

3. 按一定顺序介绍：能把关于大熊猫的信息按一定的顺序组织起来，条理清楚地写下来。

4. 培养整合资料的能力：初步学习如何把碎片化的信息整合成一篇通顺完整的介绍性文字。

### 二、教学重难点

重点：指导学生围绕问题搜集信息，并把信息整合成通顺的文字。

难点：帮助学生避免直接照搬资料，学习用自己的语言来组织和表达信息。

### 三、教学建议（核心教学环节）

第一环节：作前准备——搜信息，做整理

1. 出示问题，明确方向

出示教材中关于大熊猫的问题：大熊猫是猫吗？大熊猫生活在什么地方？大熊猫为什么被视为国宝？大熊猫喜欢吃什么？大熊猫的寿命有多长？大熊猫的外形有什么特点？等等。让学生带着问题去搜集信息。

2. 指导搜集信息的途径

引导学生从以下途径获取信息：课外书、百科全书、网络、纪录片、动物园参观等。提醒注意信息的准确性和可靠性。

3. 指导整理信息

让学生把搜集到的信息用自己喜欢的方式整理出来，可以做成信息卡、思维导图、表格等。每条信息用简单的词语或短句记录，不照抄大段文字。

4. 课堂交流信息

在小组内交流各自搜集到的信息，看看有没有互相补充的地方。对不清楚或不一致的信息，可以进行讨论或课后进一步查证。

第二环节：作中指导——选信息，巧整合

1. 明确习作要求

写一写自己了解的大熊猫。围绕教材提出的问题来写，也可以写自己感兴趣的其他方面。把搜集到的信息用自己的话写下来。按一定的顺序写。语句通顺，意思清楚。

2. 指导写作结构

提供参考结构：开头总体介绍大熊猫，点明它是国宝。中间从几个方面介绍大熊猫，如外形、生活习性、饮食习惯、为什么是国宝等。结尾表达对大熊猫的喜爱或保护大熊猫的呼吁。每个方面写一段或几句话，使习作有条理。

3. 指导“用自己的话写”

这是本次习作的重点和难点。提醒学生不能直接把查到的资料抄下来。要先读懂资料，再用自己的话把意思说出来。可以两人一组练习：一人看资料口述，另一人听，看是否说得清楚明白，是否用自己的话。

4. 指导信息的选择

搜到的信息可能很多，不必都写进去。引导学生选择最有意思、最能反映大熊猫特点的信息来写。

第三环节：作后评改——评清楚，比特色

1. 同桌互读

交换读，读完说说：你从对方的习作中了解了哪些关于大熊猫的新知识？哪里写得很清楚？

2. 核对信息

检查习作中的信息是否准确，有没有自己没弄明白就写上去的内容，进行修改核对。

3. 全班展示

选几篇写得条理清楚、语言生动的习作在全班展示。可以比较不同习作选取的信息和组织的顺序，让学生体会信息整合的多样性。

### 四、评价标准参考

1. 基础过关：能写出关于大熊猫的一两个方面，语句基本通顺。

2. 良好达标：能从几个方面介绍大熊猫，信息比较准确，能用自己的话表达。

3. 优秀进阶：条理清楚，信息丰富准确，语言生动自然，能体现自己的理解和感受。

## 三年级下册·第八单元 习作《这样想象真有趣》

```meta
册: 三年级下册
任务: 第八单元 习作《这样想象真有趣》
文体: 想象·童话
关键词: 动物 反差 有趣
分级: L3
```

### 一、习作要求（教学目标）

1. 反向想象，创编故事：能根据“动物失去原有特征或变得与原来相反”的提示，展开反向想象，创编一个童话故事。

2. 把故事写完整：能写清楚主角的变化、经历的事情和故事的结果。

3. 写出“变化”带来的有趣情节：能把动物“变了”之后发生的奇妙有趣的事情写具体，突出想象的趣味性。

4. 感受反向想象的乐趣：在创编中体会从不同角度想象的独特魅力，进一步激发想象力。

### 二、教学重难点

重点：引导学生根据提示大胆进行反向想象，创编完整的故事。

难点：帮助学生在想象的基础上，把动物“变了”之后的有趣经历写具体、写生动。

### 三、教学建议（核心教学环节）

第一环节：作前指导——反着想，找趣味

1. 游戏导入，体会“反着想”

做一个“反着说”的小游戏：老师说一个动物的特征，学生说相反的特征。如“兔子跑得快”反着说“兔子跑得慢”，“老鹰飞得高”反着说“老鹰飞得低”，“蚂蚁个头小”反着说“蚂蚁个头大”等。让学生在游戏中初步感受反向想象的趣味。

2. 出示教材提示，打开思路

出示教材中的提示：如果母鸡能在天上飞，如果蚂蚁的个头比树还大，如果老鹰变得胆小如鼠，如果蜗牛能健步如飞……让学生选择一个自己最感兴趣的变化，也可以自己想一个其他的反向变化。

3. 围绕“变化”展开想象

选定变化之后，引导学生进一步想象：它变成这样之后，生活会发生什么变化？会发生哪些有趣的事？会遇到什么麻烦或惊喜？让学生顺着“变化”这条线，想出一个故事的大致情节。

4. 口头创编，初步成形

在小组内把自己想到的故事讲一遍，组员听听是否有趣、是否完整，提出建议。

第二环节：作中指导——定变化，写故事

1. 明确习作要求

选一种动物，让它失去原来的特征或变得和原来相反。写一个有趣的童话故事。把故事写完整，写出变化之后发生的趣事。语句通顺，想象有趣。

2. 指导写作结构

提供参考结构：开头交代主角原来是什么样，发生了什么变化。中间写变化之后发生的有趣故事，这是重点部分。结尾写故事的结果，可以回到原来的样子，也可以一直保持变化后的样子。

3. 指导写出“有趣”

故事的趣味来自“变化”带来的反差和意想不到的情节。引导学生把这种反差写出来，比如“蜗牛跑得比兔子还快，兔子在后面气喘吁吁地追”“蚂蚁个头比树还大，走路的时候不小心把房子撞倒了”。把这些因为“变化”而产生的新鲜事写具体。

第三环节：作后评改——读故事，赏趣味

1. 同桌互读

交换读对方的故事，读完说说：哪里最有趣？故事完整吗？

2. 小组分享

在小组内朗读各自的故事，评选出“最有趣的故事”，说一说为什么有趣。

3. 全班展示

各组推选代表在全班朗读，引导从“想象是否有趣、故事是否完整、变化带来的情节是否好玩”等方面进行点评。体会同一只动物，不同的人可以写出完全不同的有趣故事。

### 四、评价标准参考

1. 基础过关：能写出一种动物的反向变化和一个简单的故事，故事基本完整。

2. 良好达标：故事完整有趣，能写出变化之后发生的好玩的事情。

3. 优秀进阶：想象独特，故事引人入胜，把变化带来的趣味情节写得具体生动，充满童趣。
