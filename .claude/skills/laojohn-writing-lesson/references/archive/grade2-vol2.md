## 二年级下册·语文园地二 写话《我的好朋友》

```meta
册: 二年级下册
任务: 语文园地二 写话《我的好朋友》
文体: 写人写话
关键词: 朋友 外貌 一起做
分级: L2
```

### 一、写话要求（教学目标）

1. 从多个方面介绍好朋友：能从姓名、样子、一起做的事等方面介绍自己的好朋友，把话写完整。

2. 抓住人物的主要特点：能观察并写出好朋友外貌上最明显的一两个特点，不要求面面俱到。

3. 表达与朋友的友情：在介绍中自然流露出对好朋友的喜爱和友谊之情。

4. 学习使用连接词：尝试用“我们经常一起”“有时候……有时候……”等词语把句子连接得更连贯。

### 二、教学重难点

重点：指导学生从多个方面介绍好朋友，把内容写清楚。

难点：帮助学生抓住好朋友最突出的特点来写，避免千人一面。

### 三、教学建议（核心教学环节）

第一环节：作前指导——聊朋友，说特点

1. 创设情境，引出话题

可以播放歌曲《找朋友》或谈论班级趣事，引出“好朋友”这个话题。让学生自由说说自己的好朋友是谁。

2. 引导从不同方面说朋友

借助教材提供的提示，引导学生从以下方面介绍：好朋友是谁？长什么样子？（抓住最明显的外貌特点，如脸型、发型、眼睛、戴不戴眼镜等）你们经常一起做什么？（一件事或几件事，可以是有趣的事、难忘的事、互相帮助的事等）鼓励学生说真话，写真朋友。

3. 指导抓住主要特点

老师示范抓特点的方法，比如不说“他有一双眼睛、一个鼻子”，而说“他笑起来眼睛眯成一条缝”“他的头发卷卷的，像个洋娃娃”。引导学生想一想：你的好朋友和别人最大的不同是什么？最让人一眼就能认出他的是什么？

4. 同桌互说，练习表达

同桌之间互相介绍自己的好朋友，听的同学可以猜一猜对方说的特点明不明显。

第二环节：作中指导——按顺序，写清楚

1. 明确写话要求

写自己的好朋友。写出他是谁、长什么样子、你们经常一起做什么。用几句话写清楚。语句通顺，标点正确，格式规范。

2. 提供写作框架

给学生一个基本顺序：先写好朋友是谁，再写他的样子（抓住一两个特点），然后写你们一起做的事，最后可以用一句话表达对好朋友的感情。告知学生这个框架只是参考，可以根据自己的想法灵活调整。

3. 分层要求

基础层：能写出好朋友的名字、简单的样子和一起做的事。提高层：能抓住好朋友的特点写样子，能写出一两件具体的事，语句连贯。

第三环节：作后评改——读一读，猜一猜

1. 游戏“猜猜他是谁”

让学生读自己的写话，不读好朋友的名字，请全班同学猜写的是谁。如果一猜就中，说明特点抓得准；如果猜不出，说明没写出特点。

2. 自我修改

根据猜的结果，修改自己的写话，把特点写得更清楚。

3. 全班展示与交流

选几篇优秀写话展示，引导从“特点是否突出、事情是否写清楚、有没有表达友情”等方面点评。老师强调写真话、表真情就是好作文。

### 四、评价标准参考

1. 基础过关：能写出好朋友是谁、简单的样子和一起做的一件事，语句基本通顺。

2. 良好达标：能抓住好朋友一两个特点写样子，写出一起做的事，语句通顺连贯。

3. 优秀进阶：特点突出，事情写得具体生动，自然表达出对好朋友的友情。

## 二年级下册·语文园地四 写话（看图写话，无标题）

```meta
册: 二年级下册
任务: 语文园地四 写话（看图写话，无标题）
文体: 看图写话
关键词: 看图 经过
分级: L2
```

### 一、写话要求（教学目标）

1. 有序观察多幅图：能按顺序观察多幅连续图画，看懂故事的发生、发展和结局。

2. 把故事写完整：能按照事情发展的顺序，把故事写完整，有起因、经过和结果。

3. 发挥想象补充画面：能根据画面提示展开想象，补充人物对话、心理活动和动作细节。

4. 尝试用时间词连接故事：学习用“有一天、过了几天、最后”等表示时间的词，把多幅图的故事情节连贯起来。

### 二、教学重难点

重点：引导学生看懂多幅图之间的联系，按顺序把故事写完整。

难点：帮助学生通过想象补充画面之间的情节，使故事连贯自然。

### 三、教学建议（核心教学环节）

第一环节：作前指导——看图，编故事

1. 逐图观察，了解每幅图内容

按顺序出示多幅图，逐图提问：图上画了谁？在做什么？表情怎么样？让学生先看懂每幅图各自画了什么。

2. 建立图与图之间的联系

引导学生把这组图连起来看，发现事情的起因、经过和结果。追问：第一幅图和第二幅图之间发生了什么？第二幅图和第三幅图之间又发生了什么？通过“发生了什么”这个问题，帮助学生把图与图之间可能省略的情节补充出来。

3. 展开想象，丰富情节

鼓励学生对画面进行合理想象：人物之间会说什么话？他们心里在想什么？当时周围环境是怎样的？让学生把想象到的内容加入故事，让故事更生动。

4. 口头讲述完整故事

请学生把整个故事连起来讲一遍，可以用上“有一天”“过了几天”“最后”等时间词。可以同桌互讲或小组内讲，老师巡视指导。

第二环节：作中指导——按顺序，写故事

1. 明确写话要求

按图画的顺序写故事。把起因、经过、结果写完整。展开合理想象，把故事写得有趣。语句通顺，正确使用逗号和句号。

2. 指导使用时间词

提供一些连接时间的词语供学生选用，如“有一天”“第二天”“过了一段时间”“最后”“终于”等，帮助学生把多幅图的情节自然连接。

3. 分层要求

基础层：能写出每幅图的内容，故事基本完整。提高层：能把多幅图的情节连贯地写出来，有简单对话。拔尖层：想象丰富，情节生动，能用上时间词自然过渡。

第三环节：作后评改——讲故事，评故事

1. 自读自查

读一遍自己的故事，看有没有把所有图都写到，故事有没有讲完整。

2. 小组互评

小组内交换读，互相评一评：故事讲完整了吗？哪幅图的内容写得最好？哪里的想象最有意思？

3. 全班展示

挑选几篇有特点的故事全班朗读展示，引导学生关注情节的连贯性和想象力。可以对比几篇写同一组图的作品，让学生感受不同的想象力带来的不同趣味。

### 四、评价标准参考

1. 基础过关：能写出每幅图的内容，故事基本完整，语句基本通顺。

2. 良好达标：能把多幅图的情节连贯地写出来，有简单的想象和对话，语句通顺。

3. 优秀进阶：情节连贯自然，想象合理丰富，语言生动，能运用时间词过渡。

## 二年级下册·语文园地六 写话《大自然中的“问号”》

```meta
册: 二年级下册
任务: 语文园地六 写话《大自然中的“问号”》
文体: 写话·好奇提问
关键词: 问号 疑问 大自然
分级: L2
```

### 一、写话要求（教学目标）

1. 学习提出疑问：能留心观察大自然，对身边的事物提出自己感兴趣的问题。

2. 用疑问句表达：学习用“为什么”“怎么”“哪儿”等疑问词写问句，正确使用问号。

3. 整理多个问题成段：能把几个问题放在一起写成一段话，初步体会围绕一个主题组织句子。

4. 激发探索自然的兴趣：通过提问培养对大自然的好奇心和探究欲望。

### 二、教学重难点

重点：指导学生把心中的疑问用通顺的问句表达出来，正确使用问号。

难点：帮助学生打开思路，从不同角度对大自然提问，避免问题单一重复。

### 三、教学建议（核心教学环节）

第一环节：作前指导——打开问号的大门

1. 激发好奇心

老师可以先展示一些有趣的自然现象图片或视频，如彩虹、蚂蚁搬家、含羞草、向日葵等，引导学生说感受。引出话题：大自然就像一个巨大的问号宝库，等待我们去发现。

2. 示范提问，拓展角度

老师先示范提出一些问题，引导学生从不同角度思考：关于天空的——为什么天是蓝的？关于动物的——蚂蚁为什么要搬家？关于植物的——含羞草为什么一碰就合拢？关于天气的——为什么会下雨？关于季节的——树叶为什么秋天会变黄？鼓励学生说出自己心中关于大自然的疑问。

3. 学习用疑问词

板书常用的疑问词：为什么、怎么、什么、哪儿、谁、什么时候等。引导学生用上不同的疑问词来提问，把问题问得更加多样。

4. 口述问题

请学生把自己心中最想问的几个问题说给同桌听，鼓励提出和别人不一样的问题。

第二环节：作中指导——写问题，用问号

1. 明确写话要求

把自己心中关于大自然的疑问写下来。至少写两到三个问题。每个问题后面用问号。问题语句要通顺。

2. 指导组织成段

告诉学生可以把几个问题连起来写，一个问题写一句，每个问题用问号结束。如果能围绕一个方面来提问更好，比如都问关于动物的，或者都问关于天气的，当然问不同方面的也可以。

3. 分层要求

基础层：能写出两三个通顺的问句，使用问号。提高层：能围绕一个主题提出多个不同角度的问句，问句有多样性。

第三环节：作后评改——读问题，共探索

1. 同桌互读

交换读对方写的问题，看看对方对什么感到好奇，自己是不是也有同样的疑问。

2. 全班交流“问号墙”

将学生写的问题贴在黑板或“问号墙”上，全班浏览，选出“最有趣的问号”“最想知道的问号”“最特别的问号”。对提出好问题的学生予以表扬。

3. 延伸探索

引导学生课后尝试通过看书、上网、问家长等方式，去寻找其中一个问题的答案。把写话和综合性学习联系起来，培养探究能力。

### 四、评价标准参考

1. 基础过关：能写出两三个通顺的疑问句，正确使用问号。

2. 良好达标：能提出多个不同方向的问题，问句通顺，问号使用规范。

3. 优秀进阶：问题新颖有趣，能从多角度思考，问句形式多样，能围绕主题组织成段。

## 二年级下册·语文园地七 写话《我想养的小动物》

```meta
册: 二年级下册
任务: 语文园地七 写话《我想养的小动物》
文体: 写话·表达理由
关键词: 小动物 理由
分级: L2
```

### 一、写话要求（教学目标）

1. 写清楚想养什么和原因：能明确写出自己想养什么小动物，并从多个方面写清楚想养它的理由。

2. 分条列举，条理清楚：尝试用分条列举的方式说明理由，初步学习有条理地表达观点。

3. 用“因为……所以……”等句式：学习使用表示因果关系的句式来说理由，增强表达的逻辑性。

4. 培养对小动物的爱心和责任感：在写理由的过程中，渗透关爱动物、负责任养宠物的意识。

### 二、教学重难点

重点：指导学生从多个角度写出想养某种小动物的理由，把理由写充分。

难点：帮助学生把理由写得有条理，能够分条陈述，并用上表示因果关系的句式。

### 三、教学建议（核心教学环节）

第一环节：作前指导——选动物，说理由

1. 情境导入，激发兴趣

可以设置“班级宠物角”或“说服爸爸妈妈让我养宠物”的情境，让学生产生表达动机。让学生说说如果可以选择，最想养什么小动物。

2. 头脑风暴，多角度想理由

引导学生从不同角度思考想养的理由：样子可爱（毛茸茸、胖乎乎、圆溜溜的眼睛等）、有特殊的本领（小猫会抓老鼠、小狗会看家、鹦鹉会说话等）、可以陪伴自己（和自己玩、一起散步、在孤独时陪伴等）、照顾它的乐趣（给它喂食、洗澡、布置小窝等）。让学生在小组内交流自己想到的理由。

3. 指导用因果句式说理由

出示句式“我想养……，因为……”，让学生练习用完整的句子说理由。可以先说一条，再说第二条、第三条，引导学生按条来说。

4. 讨论分条列举的方式

告诉学生：当理由比较多时，可以把理由一条一条分开写，这样别人读起来更清楚。可以每条单独写一句话，也可以在每条前面加上序号或者“第一、第二、第三”。

第二环节：作中指导——分条理，写理由

1. 明确写话要求

写出自己想养什么小动物。写出想养它的理由，至少写两条。理由要写清楚，最好用上“因为……所以……”或“可以……”等句式。可以分条写，让理由看起来更清楚。语句通顺，标点正确。

2. 指导分条写作格式

提供示范：先写一句“我想养的小动物是……”。另起一行写“因为……”，写完一条再另起一行写“还因为……”或“它的……也很吸引我”。告知学生不强求分条，但鼓励尝试。

3. 分层要求

基础层：能写出想养什么和一条简单的理由。提高层：能写出两三条理由，用上因果关系句式。拔尖层：能分条写出多条理由，条理清楚，理由充分。

第三环节：作后评改——读理由，评说服力

1. 同桌互读

交换读理由，读完后说说：你被说服了吗？他的哪条理由最有说服力？

2. 自我修改

根据同桌反馈，想想还可以补充什么理由，修改不完整的句子。

3. 全班展示

选几篇理由充分、条理清楚的写话全班展示。可以设计“最佳说服奖”“最有爱心奖”“理由最充分奖”等，激发学生兴趣。

4. 延伸讨论

引导学生说说如果真的养了小动物，需要做什么？渗透养宠物需要付出爱心和责任，不能三分钟热度。

### 四、评价标准参考

1. 基础过关：能写出想养什么小动物和一条理由，语句基本通顺。

2. 良好达标：能写出两三条理由，理由清楚，语句通顺，能用因果关系句式。

3. 优秀进阶：理由充分多样，能分条有条理地陈述，语言有说服力。

从三年级上册开始，教材进入正式的“习作”板块，内容会更加系统和丰富。
