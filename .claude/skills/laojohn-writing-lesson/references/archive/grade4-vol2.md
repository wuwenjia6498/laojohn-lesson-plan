## 四年级下册·第一单元 习作《我的乐园》

```meta
册: 四年级下册
任务: 第一单元 习作《我的乐园》
文体: 写景·场所
关键词: 乐园 样子 快乐
分级: L4
```

### 一、习作要求（教学目标）

1. 选择一个自己心中的乐园来写：能从自己熟悉的生活场所中，选择一个给自己带来快乐的地方作为“乐园”来写。

2. 写清楚乐园的样子和在乐园中的活动：能写出乐园是什么样子的，自己在乐园里最喜欢做什么，把快乐写具体。

3. 围绕“乐”字来写：能把“为什么这是你的乐园”写清楚，让读者感受到你在这个地方获得的快乐。

4. 学习用“总—分—总”结构：初步学习先总的介绍乐园，再分段写乐园的样子和活动，最后总结感受的写作结构。

### 二、教学重难点

重点：指导学生把乐园的样子和在乐园中的活动写清楚，突出“乐”字。

难点：帮助学生在写景物和活动的同时，融入自己的快乐感受，避免写成单纯的景物介绍。

### 三、教学建议（核心教学环节）

第一环节：作前指导——忆乐园，说快乐

1. 理解“乐园”，打开思路

引导学生理解“乐园”就是让自己感到快乐的地方。讨论：你的乐园在哪里？它可以是校园的一角、家里的院子、村头的小河边、自己的房间、篮球场、图书馆、爷爷的菜地等。只要是给你带来快乐的地方，都可以成为你的乐园。

2. 选定乐园，想样子

让学生选定一个自己最喜欢的地方作为乐园。想一想：这个乐园是什么样子的？有哪些景物或陈设？可以按一定的顺序想一想，比如从远到近、从整体到局部、从外到内等，在脑海中把乐园的样子看清楚。

3. 回忆在乐园中的快乐时光

这是本次习作的核心。追问：你在乐园里最喜欢做什么？是一个人静静地待着，还是和小伙伴一起玩耍？最快乐的一次经历是怎样的？有没有发生过什么有趣的事？让学生把最能体现“乐”的一两件事或一两个活动想清楚。

4. 口头交流，互相启发

在小组内介绍自己的乐园：乐园在哪里？什么样子？你在那里做什么最快乐？组员听完后说说感受到快乐了吗。

第二环节：作中指导——定结构，写快乐

1. 明确习作要求

写自己的乐园。写出乐园的样子和在乐园中的活动。围绕“乐”来写，让读者感受到你的快乐。语句通顺，条理清楚。

2. 指导写作结构

提供参考结构（总—分—总）：开头总的介绍自己的乐园是哪里，用一句话概括它给你带来的感受。中间分段写乐园的样子和在乐园中快乐的活动。结尾总结表达对这个乐园的喜爱之情。

3. 指导写乐园的样子

按一定顺序写景物的位置、形状、颜色等。不用面面俱到，选择最有特点的几处景物来写。描写中融入喜爱的感情，让景物带上快乐的色彩。

4. 指导写快乐的活动

把在乐园中的活动写具体。可以写一次具体的经历，也可以写经常做的一件事。写出自己的动作、心情和感受，让读者能感受到你的快乐。

第三环节：作后评改——读乐园，感快乐

1. 同桌互读

交换读习作，读完说说：你感受到他在乐园中的快乐了吗？哪里写得最有意思？

2. 自我修改

检查：乐园的样子写清楚了吗？快乐的活动写具体了吗？有没有让读者感受到“乐”？进行补充修改。

3. 全班展示

选几篇写不同乐园的习作在全班展示。引导从“样子清楚、活动具体、快乐真实”等方面进行点评。可以配合作者的照片或图画，让展示更生动。

### 四、评价标准参考

1. 基础过关：能写出乐园在哪里，有什么活动，语句通顺。

2. 良好达标：能写清楚乐园的样子和在乐园中的活动，表达出快乐。

3. 优秀进阶：景物描写具体有序，活动生动有趣，快乐之情自然洋溢，结构清晰。

## 四年级下册·第二单元 习作《我的奇思妙想》

```meta
册: 四年级下册
任务: 第二单元 习作《我的奇思妙想》
文体: 想象·发明
关键词: 发明 功能 样子
分级: L4
```

### 一、习作要求（教学目标）

1. 大胆想象，发明创造：能展开奇思妙想，想发明一种神奇的东西，写清楚它是什么、什么样子、有什么功能。

2. 学习从不同方面介绍发明：能从样子、功能、使用方法等方面来介绍自己想发明的东西。

3. 把神奇之处写具体：能把发明最奇妙、最与众不同的功能写清楚，让读者感受到“奇”和“妙”。

4. 感受科技想象的乐趣：在想象中培养创新意识和对科学技术的兴趣。

### 二、教学重难点

重点：指导学生从样子和功能等方面介绍自己想发明的东西，把神奇之处写具体。

难点：帮助学生在“大胆想象”的同时做到有条理地介绍，使说明有层次。

### 三、教学建议（核心教学环节）

第一环节：作前指导——开脑洞，想发明

1. 激发发明欲望

从生活中的不便或需求入手：你有没有遇到过一些麻烦，希望有一样东西能帮你解决？比如书包太重，想要一个会变轻的书包；下雨天鞋子容易湿，想要一双防水的鞋子；想去很多地方玩但时间不够，想要一扇任意门等。让学生畅所欲言。

2. 选定发明对象

让学生确定自己想发明什么。可以是生活用品、学习工具、交通工具、机器人伙伴等。给它取一个酷炫的名字，让它一开始就吸引人。

3. 从不同方面想具体

引导学生从以下几个方面来构思自己的发明：样子（它长什么样？外形、颜色、材质有什么特别之处？）、功能（它有什么神奇的功能？能做什么？这是最重要的部分，至少想出两到三个与众不同的功能）、使用方法（怎么使用它？有没有按钮、语音控制或脑电波控制？）。可以用思维导图来整理这些信息。

4. 口头介绍，互相提问

在小组内介绍自己的发明构想。组员听完后可以提问：“你这个功能是怎么实现的？”“它还有什么更厉害的地方吗？”通过提问帮助构思者想得更深入。

第二环节：作中指导——有条理，写神奇

1. 明确习作要求

写自己想发明的一种神奇的东西。写出它是什么、什么样子、有什么功能。把最神奇的功能写具体。语句通顺，条理清楚。

2. 指导写作结构

提供参考结构：开头引出自己的发明，可以写发明的原因或发明的名称。中间分段介绍：先写样子，再写功能（一个功能写一段），然后可以写使用方法。结尾写这个发明能给人们带来什么好处，表达自己的期待。

3. 指导把功能写具体

这是本次习作的亮点所在。写每一个功能时，不只说“它可以……”，还要写清楚它是怎么做到的、效果怎么样、使用时是什么感受。用上“只要……就能……”“如果……就会……”等句式把神奇的感觉写出来。

4. 指导语言既准确又生动

因为是介绍发明，需要有一定的说明性，但因为是“奇思妙想”，可以融入想象和趣味。在介绍功能时可以用打比方、举例子等方法让读者更容易理解。

第三环节：作后评改——读发明，评奇妙

1. 同桌互读

交换读习作，读完说说：你觉得他的发明神奇吗？哪个功能最吸引你？有没有哪里没写清楚？

2. 自我修改

检查：样子写清楚了吗？功能写得够神奇、够具体吗？进行补充修改。

3. 全班“发明发布会”

举办一个模拟的“奇思妙想发明发布会”，请几位同学上台介绍自己的发明。台下的同学作为“投资人”或“用户”进行提问和点评。评选“最奇妙的发明”“最有用的发明”“最有趣的发明”等。

### 四、评价标准参考

1. 基础过关：能写出想发明什么，样子和功能基本说清楚。

2. 良好达标：能从样子、功能等方面有条理地介绍，功能写得比较具体。

3. 优秀进阶：样子描写生动，功能介绍神奇具体，条理清晰，富有创意，语言有吸引力。

## 四年级下册·第三单元 习作《轻叩诗歌大门》（综合性学习·写诗）

```meta
册: 四年级下册
任务: 第三单元 习作《轻叩诗歌大门》（综合性学习·写诗）
文体: 诗歌
关键词: 写诗 综合性学习
分级: L4
```

### 一、习作要求（教学目标）

1. 初步了解现代诗的特点：通过诵读、欣赏，感受现代诗语言凝练、富有节奏感和想象力的特点。

2. 尝试自己写小诗：能结合自己的生活体验和感受，尝试用诗的形式来表达，写一两首小诗。

3. 不拘形式，自由表达：不强调押韵和格律，鼓励学生自由地、有创意地表达真情实感。

4. 感受诗歌创作的乐趣：在写诗和合编诗集的过程中，体验创作的成就感，进一步走进诗歌的大门。

### 二、教学重难点

重点：激发学生写诗的兴趣，帮助其打破畏难情绪，敢写、愿写。

难点：在自由表达的基础上，引导学生注意语言的精炼和意象的选择，写出一点“诗味”。

### 三、教学建议（核心教学环节）

第一环节：作前指导——读诗歌，找感觉

1. 回顾单元诗歌，感受特点

引导学生回顾本单元学的现代诗，如冰心的《短诗三首》、艾青的《绿》、叶赛宁的《白桦》、戴望舒的《在天晴了的时候》等。讨论：这些诗和我们平时读的文章有什么不同的感觉？诗歌的语言有什么特点？引导学生发现：诗歌通常分行写、语言很凝练、有节奏感、充满想象等。

2. 打开写诗思路

告诉学生，写诗并不神秘，生活中处处有诗。可以从以下角度寻找写诗的素材：写一种景物（花、草、风、雨、星空等）、写一种心情（快乐、忧伤、思念、感动等）、写一个人（妈妈、朋友、老师等）、写一件小事（放风筝、踩水坑、看蚂蚁搬家等）。把心中的感觉用简练的、分行的话语写出来，就是一首诗。

3. 学习“把感觉变成诗句”

给出一个普通的句子，引导学生尝试把它变成有诗味的句子。比如“春天来了，花开了”，可以变为“春天打翻了调色盘，洒了一地”。引导学生用上比喻、拟人、想象，把话说得更有画面感、更有新鲜感。

4. 口头尝试，消除畏难

请学生就一个话题，口头说一两行诗句，老师予以鼓励和简单指点。不强求完美，重在让学生敢于表达。

第二环节：作中指导——写感觉，分好行

1. 明确习作要求

自己动手写一两首小诗。内容不限，可以写景、写事、写人、写心情等。分行写，语言尽量精炼。写出自己的真实感受。有兴趣的同学可以配上插图。

2. 指导诗歌分行

讲解诗歌基本的书写格式：标题居中或顶格，每句诗一行，可以每行字数差不多，也可以长短不一。根据自己的感觉来停顿和换行。

3. 指导锤炼语言

提醒写完后读一读自己的诗，感受一下有没有节奏感。把可有可无的字去掉，让语言更凝练。可以把普通的事物换个想象的说法，让诗句更有诗意。同时强调，初学者不必追求完美，写出真心话就是好诗。

4. 分层要求

基础层：能围绕一个主题写出几句分行的话。提高层：语言比较凝练，有一定的节奏和想象。拔尖层：有独特的意象，富有想象力和真情实感。

第三环节：作后评改——读诗歌，共欣赏

1. 自读和朗读

写完后自己大声读几遍，感受节奏，修改不顺畅的地方。

2. 小组诗歌朗诵会

小组内互相朗读自己的诗。组员说说最喜欢哪一句，为什么。提出建议：哪句话还不够有味道，可以怎么改。

3. 全班展示与合编诗集

各小组推选代表在全班朗诵自己的诗。可以配上背景音乐。全班评选“最佳小诗人奖”“最佳诗句奖”等。将全班诗作汇编成一本班级诗集，可以配上插图、设计封面，作为综合性学习的成果。

### 四、评价标准参考

1. 基础过关：能围绕一个主题写出内容基本相关的分行语句。

2. 良好达标：诗句有一定节奏感，语言比较精炼，有自己的想法。

3. 优秀进阶：有诗意，有独特的想象和意象，语言凝练有感染力，真情流露。

## 四年级下册·第四单元 习作《我的动物朋友》

```meta
册: 四年级下册
任务: 第四单元 习作《我的动物朋友》
文体: 状物·动物
关键词: 动物 情境 介绍
分级: L4
```

### 一、习作要求（教学目标）

1. 在特定情境下介绍动物：能根据不同的情境（寻物启事、托人喂养、送人收养等），选择不同的内容来介绍自己的动物朋友。

2. 抓住动物的特点来写：能从外形、习性、趣事等方面写出动物的主要特点。

3. 根据目的选择内容：学习根据不同的表达目的，有侧重地选择和组织材料，不面面俱到。

4. 表达对动物的喜爱之情：在介绍中自然流露对动物朋友的喜爱和关心。

### 二、教学重难点

重点：指导学生根据情境需要，有侧重地介绍动物的特点。

难点：帮助学生根据不同的目的来筛选和组织材料，培养“读者意识”。

### 三、教学建议（核心教学环节）

第一环节：作前指导——创情境，明目的

1. 创设不同情境，明确写作目的

出示教材提供的三个情境，让学生明白这次习作要有“目的”地写。情境一：小羊走丢了，请帮忙写一个寻羊启事，要写出小羊的外形特点，让人一看就能认出来。情境二：全家要外出，请邻居帮忙喂养小狗，要写清楚小狗的生活习性，方便邻居照顾。情境三：要搬家了，想给小猫找一个新主人，要写出小猫的可爱之处，打动别人愿意收养。让学生体会：同一个动物，因为目的不同，写的重点就不一样。

2. 选择情境，确定写作重点

让学生选定一个情境，或者结合自己的实际情况创设一个情境。确定后想一想：在这个情境下，你最需要告诉别人什么？哪些信息是必须写的？哪些可以不写？比如写寻物启事，外形特点最重要；写托人喂养，生活习性最重要；写送人收养，可爱和趣事最重要。

3. 回忆动物朋友的特点

不管选哪个情境，都需要对自己写的动物有充分的了解。引导学生从以下方面回忆：外形（毛色、体型、眼睛、耳朵等最有特点的地方）、习性（吃什么、喜欢做什么、生活习惯等）、趣事（和它之间发生过什么好玩或感人的事）。

4. 口头练习，按情境来说

在小组内，根据自己选的情境，用口述的方式介绍自己的动物朋友。组员听完后评判：他的介绍符合这个情境的需要吗？重点内容突出了吗？

第二环节：作中指导——依情境，写特点

1. 明确习作要求

根据一个具体的情境，写自己的动物朋友。根据情境的需要，选择合适的内容来写。抓住动物的特点写清楚。语句通顺，表达出对动物的感情。

2. 指导写作结构

提供参考结构：开头说明写这篇介绍的原因（点明情境）。中间根据情境需要有侧重地介绍：寻物启事重点写外形，托人喂养重点写生活习性，送人收养重点写可爱和趣事，外形也可写。结尾根据情境再次发出请求或表达愿望，如“请帮我找找它”“请帮我好好照顾它”“如果你愿意收养它，请一定要好好爱它”。

3. 指导写好外形

写外形要抓住最明显的特征，让人一眼就能认出。按一定顺序写，从整体到局部，或从上到下。语言要简洁准确。

4. 指导写好习性

写习性要写清楚日常的照料方法，如吃什么、吃多少、喜欢做什么、需要注意什么等。用“要”“不要”“记得”等词语把注意事项写明确。

5. 指导写好趣事

写趣事选一两件最能体现动物可爱或有趣的事情来写，把经过写清楚，写出自己的感受。

第三环节：作后评改——评目的，验效果

1. 同桌互读互验

交换读习作，读完后说说：他的介绍能帮人认出这只动物/方便喂养/打动想收养的心吗？目的达到了吗？

2. 自我修改

检查：有没有根据情境把该突出的内容写具体？有没有写不相关的内容可以删去？进行修改。

3. 全班展示与评价

选不同情境的优秀习作展示。引导从“是否符合情境需要、特点是否清楚、是否达到预期效果”等方面点评。让学生体会写作中“读者意识”的重要性。

### 四、评价标准参考

1. 基础过关：能根据情境写出动物的基本情况，语句通顺。

2. 良好达标：能根据情境有侧重地介绍，抓住动物的主要特点写清楚。

3. 优秀进阶：紧密围绕情境需要，特点突出，内容具体，能有效达成写作目的，感情真挚。

## 四年级下册·第五单元 习作《游____》

```meta
册: 四年级下册
任务: 第五单元 习作《游____》
文体: 游记
关键词: 游览顺序 移步换景 印象深
分级: L4
```

### 一、习作要求（教学目标）

1. 学习按游览的顺序写景物：能按照自己游览的先后顺序，把游览的过程写清楚。

2. 用过渡句把景物连接起来：学习使用“走过……来到……”“沿着……就到了……”等过渡句，把不同地点的景物自然衔接。

3. 把印象最深的景物写具体：能在按顺序写的基础上，选择一两处印象最深的景物进行重点描写。

4. 感受祖国山河和身边景物的美：在写作中进一步体会大自然和人文景观的美，培养热爱生活的情感。

### 二、教学重难点

重点：指导学生按照游览顺序写景物，学习使用过渡句。

难点：帮助学生在移步换景的过程中做到详略得当，把重点景物写具体。

### 三、教学建议（核心教学环节）

第一环节：作前指导——忆游览，理路线

1. 确定游览地点，补充题目

引导学生从自己去过的地方中选一个来写：可以是名胜古迹、自然风景区、公园、博物馆、动物园、校园、家乡的小山等。把题目补充完整。

2. 画出游览路线图

这是本次习作的重要支架。让学生回忆游览的路线，画出简单的路线图：从哪儿出发，先到了哪儿，接着到了哪儿，然后到了哪儿，最后从哪儿出来。在路线图上标注经过的主要景点或地点。路线图可以帮助学生理清写作顺序。

3. 确定重点景物

在路线图中的各个地点中，让学生标出哪一两处是自己印象最深、觉得最美的。这一两处就是需要重点写具体的地方。其他地方可以简单写或者一笔带过。

4. 口头“带路”，练习过渡

让学生在小组内，用自己的路线图“带”组员“游览”一遍。练习用过渡句连接不同地点，如“一进大门，首先映入眼帘的是……”“沿着小路继续往前走，就来到了……”“穿过长廊，眼前豁然开朗，原来是……”。通过口述练习，把路线和过渡语理顺。

第二环节：作中指导——按路线，写景物

1. 明确习作要求

把题目补充完整。按照游览的顺序来写。用上过渡句，把景物连接起来。把印象最深的景物写具体。语句通顺，条理清楚。

2. 指导写作结构

提供参考结构：开头交代游览的时间、地点和人物，总写对这个地方的整体印象。中间按游览顺序分段写，一段写一个地点，用过渡句连接。重点段落展开来写，写出景物的颜色、形状、大小等特点和自己的感受。结尾写游览结束的感受和心情。

3. 指导写好过渡句

示范几种常见的过渡句写法：“走完……就来到了……”“绕过……便看到了……”“沿着……一直走，就到了……”“离开……继续前行，不一会儿就……”等。过渡句就像一根线，把散落的珍珠串起来。

4. 指导把重点景物写具体

对于选定的重点景物，从多个角度进行描写：看到的、听到的、闻到的、感受到的。用上比喻、拟人等手法把景物写得生动。写出当时的联想或心情，让景物描写有温度。

第三环节：作后评改——按路线，验清楚

1. 同桌互读

交换读习作，读完后试着画出对方的游览路线图。如果画不出来或画乱了，说明顺序不清楚或过渡不自然。

2. 自我修改

检查：游览顺序清楚吗？过渡句自然吗？重点景物写具体了吗？根据同桌反馈进行修改。

3. 全班展示

选几篇写不同景点的习作在全班展示。可以请作者当“小导游”，按照习作中的路线带全班“云游览”。引导从“顺序清楚、过渡自然、重点突出”等方面进行点评。

### 四、评价标准参考

1. 基础过关：能按游览顺序写出游览的过程，语句通顺。

2. 良好达标：顺序清楚，有简单的过渡，能把一两处景物写具体。

3. 优秀进阶：顺序清晰，过渡自然流畅，重点景物描写生动具体，详略得当，给人身临其境之感。

## 四年级下册·第六单元 习作《我学会了____》

```meta
册: 四年级下册
任务: 第六单元 习作《我学会了____》
文体: 记事·过程
关键词: 学会 过程 心情变化
分级: L4
```

### 一、习作要求（教学目标）

1. 选择一件学会做的事来写：能从自己的成长经历中，选择一件最有成就感、印象最深刻的事来写。

2. 按步骤写出学习的过程：能按照学习的先后顺序，把学做这件事的过程一步一步写清楚。

3. 写出学习过程中的心情变化：能写出从不会到会的过程中，自己遇到了什么困难、怎样克服的、心情发生了怎样的变化。

4. 表达成长的感悟：在学习过程的叙述中，自然地写出学会之后的成就感和从中懂得的道理。

### 二、教学重难点

重点：指导学生按顺序把学做一件事的过程写清楚，写出遇到的困难和克服的方法。

难点：帮助学生在写过程的同时，写出心情的变化和成长的感悟，使习作有过程、有感受、有收获。

### 三、教学建议（核心教学环节）

第一环节：作前指导——忆经历，说过程

1. 打开记忆，选择素材

引导学生从不同方面回忆自己学会做的事：学习方面的（学会了查字典、学会了写毛笔字、学会了做思维导图等）、生活方面的（学会了游泳、学会了骑自行车、学会了包饺子、学会了系鞋带等）、技能方面的（学会了弹一首曲子、学会了下棋、学会了摄影等）。选定一件自己最有成就感的事。

2. 回忆学习过程，理清步骤

这件事你是怎么学会的？是谁教你的，还是自学的？学习的过程是怎样的？让学生按照“第一步做什么——第二步做什么——第三步做什么”的顺序，把学习的主要步骤理清楚。如果中途有困难，也把遇到什么困难、怎么克服的插进去。

3. 回忆心情变化

在学习的过程中，你的心情有什么变化？刚开始学的时候是什么心情？遇到困难时呢？克服困难之后呢？学会之后又是什么心情？引导学生画一条“心情曲线”，直观地展示从紧张、害怕、想放弃，到被鼓励、坚持、成功、喜悦的心理历程。

4. 口头讲述，组内交流

在小组内按照“学了什么——怎么学的（步骤+困难+克服）——学会后怎样”的顺序完整地讲一遍。组员听完后说说过程清楚吗，心情感受有吗。

第二环节：作中指导——按步骤，写起伏

1. 明确习作要求

把题目补充完整。按顺序写清楚学会这件事的过程。写出遇到了什么困难，是怎样克服的。写出学习过程中的心情变化。语句通顺，写出真实的感受。

2. 指导写作结构

提供参考结构：开头交代学了什么，为什么学。中间写学习过程：先做了什么，然后做了什么，遇到了什么困难，怎么克服的（这是重点），最后终于学会了。结尾写学会之后的心情和感悟。

3. 指导写好“困难与克服”

这是习作中最有看头的部分。引导学生把困难写具体：哪里做不好？为什么觉得难？当时想放弃吗？再把克服的过程写具体：谁帮助了你？你是怎么想的？用了什么方法？反复练习了多少次？通过困难的克服来体现“成长”。

4. 指导写好心情变化

在学习过程的叙述中，自然地穿插心情描写。开始可能是兴奋、好奇，中间遇到困难可能是沮丧、着急，克服困难后可能是松了一口气，学会后可能是欣喜若狂。把心情的起伏写出来，习作就有了打动人心的力量。

第三环节：作后评改——读过程，品成长

1. 同桌互读

交换读，读完说说：学会的过程清楚吗？困难写具体了吗？感受到心情变化了吗？

2. 自我修改

检查：步骤是否清楚连贯？困难和克服部分是否具体？心情变化是否写出来了？进行补充修改。

3. 全班“成长分享会”

请几位同学在全班分享自己“学会了”的故事。引导从“过程清楚、困难具体、有心情变化、有成长感悟”等方面进行点评和欣赏。可以在黑板上记录下同学们学会的各种本领，感受成长的多样性。

### 四、评价标准参考

1. 基础过关：能写清楚学会了什么，有基本的学习过程，语句通顺。

2. 良好达标：过程清楚有序，写出了遇到的困难和克服方法，有心情变化。

3. 优秀进阶：过程具体生动，困难与克服写得扣人心弦，心情变化细腻真实，感悟自然深刻。

## 四年级下册·第七单元 习作《我的“自画像”》

```meta
册: 四年级下册
任务: 第七单元 习作《我的“自画像”》
文体: 写人·自我
关键词: 自我介绍 特点
分级: L4
```

### 一、习作要求（教学目标）

1. 从多个方面介绍自己：能从外貌、性格、爱好、优缺点等方面来介绍自己，写出一个真实的“我”。

2. 选择最能体现自己特点的事例：能用具体的事例来表现自己的性格特点或爱好，不空泛地说。

3. 学习用“特点+事例”的结构写自己：将前面学过的写人方法运用到自我介绍中。

4. 客观认识自我，真诚表达：在写作中对自己有一个比较全面的认识，既能写优点，也能不避讳缺点，做到真诚坦率。

### 二、教学重难点

重点：指导学生从多个方面介绍自己，用具体事例表现特点。

难点：帮助学生选准自己最有代表性的特点，并且找到最能体现这个特点的事例。

### 三、教学建议（核心教学环节）

第一环节：作前指导——照镜子，识自我

1. 创设情境，明确目的

创设一个情境：班里要来一位新老师，为了让老师尽快了解每一个同学，请每人写一篇“自画像”交给老师。或者要参加一个笔友活动，需要写一篇自我介绍。让学生带着目的来写，增强表达动机。

2. 从多个方面“画”自己

引导学生从不同方面来认识自己：外貌（你长什么样？有什么让人一眼就记住的特点？）、性格（你是活泼还是安静？是急性子还是慢性子？）、爱好（你最大的爱好是什么？最喜欢做什么？）、优点和不足（你觉得自己最值得骄傲的是什么？最想改掉的小毛病是什么？）等。让学生用几个关键词写下自己各方面的特点，形成对自己的初步认识。

3. 为特点寻找事例

每个特点都需要用具体的事例来证明，这是把“自画像”画得像的关键。选择一个自己最想写的性格特点或爱好，想一想：哪件事最能证明这一点？把这件事的经过想清楚。在小组内说说自己的特点和对应的事例，组员评议：这个事例能体现这个特点吗？

4. 真诚面对自己的不足

写“自画像”不意味着只写优点。引导学生想一想自己有没有什么小缺点、小毛病，也可以写进去，这样画出来的“我”才更真实、更可爱。同样，写缺点也最好有一个小例子。

第二环节：作中指导——选特点，找事例

1. 明确习作要求

从外貌、性格、爱好、优缺点等方面介绍自己。选择最想写的特点用具体事例来表现。可以写优点，也可以写不足。语句通顺，把“我”写真实。

2. 指导写作结构

提供参考结构：开头简单介绍自己是谁，给读者一个总的印象。中间分几个方面来介绍（外貌一段、性格加事例一段、爱好加事例一段、优缺点一段等）。结尾表达自己对新老师（或笔友）的期待，或者对未来自己的期望。分段要清晰。

3. 指导写好外貌

外貌描写要抓住最有特点的地方写，不面面俱到，不写流水账。按一定顺序写，语言简洁。外貌可以单独写一段，也可以融入性格或爱好的段落中。

4. 指导用事例体现特点

每个特点后面用“比如有一次……”之类的话引出具体事例。把事例的时间、地点、经过写清楚，重点是写出自己当时的言行和想法，让读者看了就觉得“哦，他果然是这样的人”。

第三环节：作后评改——猜画像，验“像不像”

1. 同桌互读

交换读“自画像”，读完后说说：你觉得他写的是自己吗？哪个特点写得最像？哪个事例最有说服力？

2. 自我修改

根据同桌反馈，看看哪些特点还没写清楚，哪些事例还不够有力，进行修改补充。

3. “猜猜这是谁”活动

把全班习作收上来，随机抽取几篇朗读（不读姓名和明显的外貌特征），让全班猜是谁写的。被猜中的越快、越准确，说明“自画像”画得越像。这个活动既有趣味性，又是很好的评价方式。

4. 全班点评

引导从“特点鲜明、事例具体、画像真实全面”等方面进行点评，表扬那些写出了真实而独特的自己的习作。

### 四、评价标准参考

1. 基础过关：能从几个方面简单介绍自己，语句通顺。

2. 良好达标：特点比较清楚，有用事例来表现特点，内容比较真实。

3. 优秀进阶：特点鲜明突出，事例具体生动，能多角度展现真实的自我，语言真诚有感染力。

## 四年级下册·第八单元 习作《故事新编》（2026 秋教材调整前 · 已停用）

```meta
册: 四年级下册
任务: 第八单元 习作《故事新编》
文体: 想象·改编
关键词: 旧故事新编 龟兔赛跑
分级: L4
```

### 一、习作要求（教学目标）

1. 选择一个熟悉的故事重新创编：能从自己熟悉的寓言、童话、成语故事、民间故事中，选一个来重新编写。

2. 在原故事基础上大胆创新：可以从改变结局、改变人物特点、改变情节发展、增加新角色等角度进行创新。

3. 把故事写完整写有趣：新编的故事要有完整的起因、经过和结果，情节有趣，想象合理。

4. 感受创编的乐趣：在“老故事”中写出“新意思”，体会创作的成就感和想象的乐趣。

### 二、教学重难点

重点：指导学生找到一个创新的切入点，把故事重新编得有趣合理。

难点：帮助学生在“新编”的过程中保持故事的基本逻辑自洽，既有新意又不荒诞不经。

### 三、教学建议（核心教学环节）

第一环节：作前指导——选故事，找切口

1. 回顾熟悉的故事，打开“故事库”

引导学生回忆学过的和课外读到的各种故事：寓言故事（《守株待兔》《龟兔赛跑》《狐假虎威》等）、童话故事（《小红帽》《三只小猪》《丑小鸭》等）、成语故事（《画龙点睛》《掩耳盗铃》等）、神话传说（《后羿射日》《精卫填海》等）。说说自己最喜欢哪个故事，对哪个故事的情节和结局最熟悉。

2. 选定故事，寻找创新切入点

以《龟兔赛跑》为例，打开创新思路。可以改变结局：兔子没有睡觉，赢了比赛；乌龟和兔子成了好朋友，一起冲过终点。可以改变人物特点：兔子变得非常骄傲自大目中无人；乌龟用上了现代科技，穿上了滑轮鞋。可以改变情节：比赛中途出现了一条河，兔子过不去，乌龟帮它过河。可以增加新角色：裁判是一只狡猾的狐狸，在比赛中搞鬼。让学生从不同角度去想，找到自己的创新点。

3. 围绕创新点构建新情节

选定创新点之后，重新构思故事的情节：起因还是原来的吗？经过发生了什么变化？结局变成了什么样？在小组内口头讲一讲自己的新编故事梗概，看看情节是否完整、是否合理有趣。

第二环节：作中指导——定新意，写新篇

1. 明确习作要求

选一个熟悉的老故事，进行新编。在原故事基础上创新，可以改结局、改人物、改情节或加角色等。把新编的故事写完整、写有趣。语句通顺，想象合理。

2. 指导写作结构

提供参考结构：开头交代原来的故事是怎样的（用一两句话简要回顾），引出“如果……”引出新编。中间写新编的故事经过，重点写与原来不同的地方，把创新的部分写具体。结尾写新故事的结果，可以和原故事结局作一个对比，突出新意。

3. 指导写好“新”的部分

新编故事的魅力在于“新”，所以要把创新的部分作为重点来写。改写结局的，把新的结局写详细；改写情节的，把新情节展开；改变人物的，通过言行体现人物的新特点。新意要贯穿全文，不能只改一点点。

4. 保持故事感

虽然是“新编”，但仍然要写得像一个有趣的故事。有人物的对话、动作和心理活动，有情节的起伏，有吸引人的叙述。让读者愿意读下去。

第三环节：作后评改——读新篇，评创意

1. 同桌互读

交换读对方的新编故事，读完后说说：这个新编故事哪里最有新意？情节合理有趣吗？

2. 小组分享

在小组内朗读各自的故事新编，评选出“最佳创意奖”“最出人意料奖”“最有趣新编奖”等。

3. 全班“故事新编会”

各组推选代表在全班讲述自己的新编故事。可以配上简单的道具或表演。引导从“创新点的巧妙、情节的完整与合理、故事的趣味性”等方面进行欣赏和点评。

4. 与原故事对照阅读

如果有时间，可以将新编故事和原故事放在一起阅读比较，讨论：哪些地方变了？变得好不好？体会创作的空间和乐趣。

### 四、评价标准参考

1. 基础过关：能对一个老故事进行改写或续写，故事基本完整。

2. 良好达标：有新编的创意，能在一个方面有所创新，故事完整通顺。

3. 优秀进阶：新编有巧思，情节既合理又出人意料，故事生动有趣，体现了较强的想象力和创作力。
