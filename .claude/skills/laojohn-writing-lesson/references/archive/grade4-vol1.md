## 四年级上册·第一单元 习作《推荐一个好地方》

```meta
册: 四年级上册
任务: 第一单元 习作《推荐一个好地方》
文体: 推荐·写景
关键词: 地方 推荐理由
分级: L4
```

### 一、习作要求（教学目标）

1. 学习从不同角度推荐：能从景色、美食、好玩的项目、文化内涵等不同角度，向别人推荐一个好地方。

2. 把推荐理由写清楚：能围绕“这是个好地方”这个中心意思，写出两条以上的推荐理由，把每一条理由写具体。

3. 学习用总分结构：初步学习先总体介绍这个地方，再分段写推荐理由的写作结构。

4. 激发分享与交流的兴趣：通过向别人推荐，感受分享的快乐，激发对祖国山河和家乡美景的热爱。

### 二、教学重难点

重点：指导学生从多角度写出推荐理由，把理由写具体。

难点：帮助学生在多条理由之间合理组织材料，做到条理清楚。

### 三、教学建议（核心教学环节）

第一环节：作前指导——选地方，理理由

1. 创设推荐情境，激发兴趣

设置情境：学校广播站要开设“好地方推荐”栏目，向全校同学征集稿件；或者“六一”儿童节要评选“最值得去的好地方”。让学生带着推荐任务来写作，增强表达动机。

2. 确定推荐地点，打开思路

引导学生从不同范围选择地点：身边的（校园一角、小区花园、常去的书店等）、家乡的（一个公园、一座山、一条老街等）、旅游去过的（名胜古迹、主题乐园、博物馆等）。让学生选定一个自己真心觉得好的地方。

3. 多角度思考推荐理由

借助教材提供的提示，引导学生从以下角度梳理推荐理由：这个地方有什么美景？（自然风光、建筑特色等）有什么好吃的？（特色美食、小吃等）有什么好玩的？（游乐设施、体验项目等）有什么文化或故事？（历史传说、名人足迹等）还有什么其他特色？（民风民俗、特产等）让学生在小组内说一说，互相启发。

4. 筛选和整理推荐理由

引导学生从想到的众多理由中，选择两三个最有代表性的、最能吸引人的理由作为重点来写。用一个词语或一句话概括每条理由，做到心中有提纲。

第二环节：作中指导——定结构，写理由

1. 明确习作要求

推荐一个好地方。写出这个地方在哪里，有什么特别之处。写出两条以上的推荐理由，把理由写清楚。语句通顺，条理清楚。

2. 指导总分结构

提供参考结构：开头总体介绍这个地方在哪里，给它一个总的评价，如“这是一个让人流连忘返的好地方”。中间分段写推荐理由，一条理由写一段或一个部分，把这一条理由写具体。结尾再次发出邀请或表达推荐之意。

3. 指导把推荐理由写具体

每条理由不能只说“很美”“很好玩”，要通过具体描写让读者感受到。比如推荐美景，就具体写看到的景色是怎样的；推荐美食，就写食物的样子、味道、吃时的感受。用具体的描写代替空洞的评价。

4. 指导写开头和结尾

开头可以直接说出推荐的地方，也可以设置悬念。结尾可以发出热情的邀请，如“听了我的介绍，你是不是也想去看看呢”，让整篇习作有推荐的感觉。

第三环节：作后评改——评推荐，比吸引力

1. 同桌互读互评

交换读习作，读完说说：你被说动了吗？想去这个地方吗？哪条理由最吸引你？

2. 自我修改

根据同桌反馈，看看哪条理由还不够具体、不够吸引人，进行修改补充。

3. 全班“好地方推荐会”

模拟推荐会，请几位同学在全班朗读自己的习作。全班投票评选“最想去的好地方”。引导从“理由是否具体、是否吸引人、条理是否清楚”等方面进行点评。

4. 汇编推荐集

将全班习作按地区或类型分类，汇编成《班级好地方推荐指南》，放在图书角。

### 四、评价标准参考

1. 基础过关：能写出推荐的地方和基本理由，语句通顺。

2. 良好达标：能从两个以上角度写出推荐理由，理由比较具体，条理较清楚。

3. 优秀进阶：推荐理由具体充分，描写生动有感染力，条理清晰，能让读者产生想去的愿望。

## 四年级上册·第二单元 习作《小小“动物园”》（2026 秋教材修订前 · 已停用）

> **已停用。** 2026 秋教材修订后本单元习作改为《我的家人》（见下一节）。本节仅供旧详案 `四上-第二单元-小小“动物园”-写作课详案.md` 追溯其事实依据，**不得作为新详案的依据**。

```meta
册: 四年级上册
任务: 第二单元 习作《小小“动物园”》
文体: 写人·比喻
关键词: 家人 像什么动物
分级: L4
```

### 一、习作要求（教学目标）

1. 学习用比喻写家人：能抓住家人和某种动物之间的相似之处，把家人比作动物来写。

2. 通过具体表现写出相似点：不能只说“爸爸像熊”，还要通过爸爸的外貌、性格、行为等方面的具体表现，写出他和熊哪里像。

3. 把每个家人写到一个段落：初步学习一人一段的写作方式，使结构清晰。

4. 表达对家人的爱：在充满趣味的比喻中，自然表达对家人的喜爱和家庭生活的温馨。

### 二、教学重难点

重点：指导学生抓住家人与动物的相似点，用具体表现把比喻写生动。

难点：帮助学生在比喻中把握好分寸，既有趣味性，又充满爱意，不伤害家人感情。

### 三、教学建议（核心教学环节）

第一环节：作前指导——找相似，说特点

1. 创设情境，引出比喻

出示几张动物图片（熊、猴子、蜜蜂、孔雀、树懒等），让学生说说这些动物有什么特点。然后话题一转：如果把自己的家想象成一个“动物园”，家人分别像什么动物？引发学生兴趣。

2. 给家人找动物对应

引导学生一个一个地想：爸爸像什么动物？妈妈像什么动物？爷爷、奶奶、兄弟姐妹呢？每个人从外貌、性格、行为、习惯、爱好等方面去寻找相似点。比如爸爸胖胖的、很威严，像大熊；妈妈每天忙忙碌碌，像蜜蜂；爷爷很慈祥、爱吃素，像老山羊等。

3. 指导把相似点想具体

这是本次习作能否写好的关键。找到对应动物之后，追问：为什么说他像这个动物？有什么具体的表现？比如“爸爸像熊”，能举出什么例子？是不是他胖胖的、走路慢悠悠、爱吃肉、发起脾气来很吓人但平时很温和？引导学生把相似点一个一个想出来，这就是写作的素材。

4. 把握情感基调

强调这次习作是把家人写得可爱有趣，是“爱的比喻”，不是取笑。选择的比喻要带有喜爱之情，不要用贬义的动物来形容家人。

第二环节：作中指导——一人一段，写具体

1. 明确习作要求

把自己的家想象成“动物园”，给每个家人写一段。写出家人和某种动物的相似之处。通过具体表现把比喻写生动。语句通顺，表达出对家人的爱。

2. 指导写作结构

提供参考结构：开头总体写“我家是个小小的‘动物园’”，简单介绍有哪些“动物”。中间一人写一段，每段先点出像什么动物，再具体写哪里像（外貌、性格、行为等）。结尾写出在这个“动物园”里的感受，表达对家人的爱。

3. 指导把“像在哪里”写具体

示范对比：不说“爸爸像熊”，而写“爸爸长得高高壮壮的，走起路来慢悠悠的。他最爱的就是吃肉，每次吃饭都要吃一大盘红烧肉。别看爸爸平时很温和，发起脾气来一声吼，整个‘动物园’都安静了”。这样从几个方面写具体，比喻就成立了。

4. 指导过渡和衔接

教学生用简单的方法在段落之间过渡，如“说完了爸爸，再来说说我的妈妈”“动物园里还有一只可爱的小猴子，那就是我的弟弟”。

第三环节：作后评改——读比喻，猜特点

1. 同桌互读

交换读，读完说说：你觉得他写的家人和那种动物像吗？哪里写得最像？

2. 自我修改

检查是否把每个家人的相似点写具体了，有没有只说“像什么”却没说“为什么像”的情况，进行补充修改。

3. 全班展示

选几篇写得生动有趣的习作在全班朗读。可以读完一个家人的段落后，让其他同学猜写的是家里的谁（爸爸、妈妈还是其他人），检验比喻是否贴切。

4. 情感升华

老师总结：虽然我们把家人比作各种各样的动物，但在这个“动物园”里，我们感受到的是满满的爱。引导学生课后把习作读给家人听，共享家庭欢乐。

### 四、评价标准参考

1. 基础过关：能给每个家人找到一个动物的对应，写出基本相似点，语句通顺。

2. 良好达标：能写出家人与动物的具体相似之处，一人一段，结构清晰。

3. 优秀进阶：比喻贴切生动，相似点写得具体有趣，充满家庭温情和爱意。

## 四年级上册·第二单元 习作《我的家人》

```meta
册: 四年级上册
任务: 第二单元 习作《我的家人》
文体: 写人·事例
关键词: 家人 特点 具体事例
分级: L4
```

> **2026 秋教材修订后的现行题目。** 本单元习作由《小小“动物园”》换为《我的家人》，单元课文未变（仍为提问策略单元）。旧题一节保留在本文件上方，仅供旧详案追溯。

### 一、习作要求（教学目标）

（第 1、2 条为教材页原文逐字转述；第 3、4 条依教参教学目标归纳。）

1. 结合具体事例写出家人的特点：可以选择一个家人来写，也可以选择家中的几个人来写，结合具体事例写出家人的特点，注意把印象最深的地方写出来。（教材原文）

2. 与同学和家人分享习作：写好了读给同桌听，看看有没有不通顺的句子。回家读给家人听，请他们评评写得像不像。（教材原文）

3. 从不同角度发现家人的特点：借助教材文段，从外貌、性格、兴趣爱好、做事方式等多个角度去想家人有什么特点。

4. 体验表达的乐趣：在与同学、家人的分享和修改中，修改不通顺的语句，体会表达的乐趣。

### 二、教学重难点

重点：从外貌、性格、兴趣爱好等多个方面发现并写出家人的特点。

难点：通过印象最深、最能反映家人特点的事例，写出家人的特点。

### 三、教学建议（核心教学环节）

第一环节：作前指导——找特点，挑事例

1. 借助教材文段发现特点的多个角度

教材呈现五个学生介绍家人的片段（奶奶脾气特别好、总是笑眯眯的，还特别会做好吃的；爸爸是卡车司机，工作很忙，一有空就给我们讲故事；姥爷已经退休，每天练习书法，一年三百六十五天从不间断；妈妈酷爱运动，跑步、跳绳、打羽毛球都充满热情；妹妹今年四岁，很淘气，也很聪明）。引导学生读一读，说说这几位家人分别是从哪个角度被写出来的，再想想自己的家人有什么特点。

2. 由特点走向事例

这些片段说的多是家人经常做的事和总体印象。追问：能不能想起一件具体的事，让人一听就明白他是这样的人？引导学生回忆家庭生活中印象最深的片段。

3. 挑出最能反映特点的那一件

家人身上的事很多，指导学生比较几件候选的事，挑出印象最深、最能说明这个特点的那一件。这是本次习作的难点所在。

4. 明确可以写一个也可以写几个

写一个家人可以把事例写得更完整；写几个人则每人一段、每人各挑各的事，避免几段写成一个样子。

第二环节：作中指导——把事例写清楚

1. 明确习作要求

结合具体事例写出家人的特点，把印象最深的地方写出来。写一个人或写几个人均可。

2. 指导把事例写清楚

指导学生写这件事时交代清楚是什么时候、他做了什么、说了什么，让读的人自己从事情里看出这个特点。

3. 指导开头与段落安排

写一个人时可先点出他是个什么样的人，再写那件事；写几个人时一人一段，段与段之间可用简单的过渡衔接。

4. 表达对家人的感情

在写事例的过程中自然流露对家人的喜爱、感激或敬佩，感情要真实。

第三环节：作后评改——读一读，评一评

1. 同桌互读

写好了读给同桌听，看看有没有不通顺的句子，当场改过来。

2. 自我修改

检查有没有把最能说明特点的那件事写清楚，有没有只写了特点却没有事例，进行补充修改。

3. 全班分享

选几篇分享，请听的同学说说从哪件事里看出了这位家人的特点。

4. 回家分享

引导学生回家把习作读给家人听，请他们评评写得像不像。

### 四、评价标准参考

（教材页与所核两份教参均未给出星级/等第量表；以下三档依四年级学段目标与本单元重难点**推定**，非教材官方条款。）

1. 基础过关：能写出一位家人的一个特点，并写到一件相关的事，语句通顺。

2. 良好达标：能挑出较能说明特点的事例，把事情的经过写清楚，读的人能从事例中看出这个特点。

3. 优秀进阶：挑的事例是印象最深、别人家写不出的那一件，事情里有家人的动作和话语，特点鲜明，感情真实自然。

## 四年级上册·第三单元 习作《写观察日记》

```meta
册: 四年级上册
任务: 第三单元 习作《写观察日记》
文体: 观察·日记
关键词: 连续观察 变化
分级: L4
```

### 一、习作要求（教学目标）

1. 学习连续观察并做记录：能对一种事物进行连续、细致的观察，并用自己喜欢的方式做好观察记录。

2. 用日记的形式写观察所得：能把连续观察到的内容整理成观察日记，格式正确，内容真实。

3. 写出观察对象的变化：能通过前后对比，把观察对象的变化过程写清楚。

4. 写出观察中的心情和感受：在记录观察发现的同时，写出自己的心情和想法。

### 二、教学重难点

重点：指导学生进行连续观察并做好记录，把观察对象的变化写清楚。

难点：帮助学生在连续的观察日记中避免重复，每天写出新的发现和变化。

### 三、教学建议（核心教学环节）

第一环节：作前准备——选对象，做记录

1. 提前布置观察任务

提前一周左右布置观察任务。引导学生选择适合连续观察的对象：植物的生长（种豆芽、养水仙、观察树叶变色等）、动物的生活（养蚕、观察小蝌蚪、观察家里宠物等）、自然现象（月亮的变化、天气变化等）、生活场景（泡豆子、面包发霉的过程等）。

2. 指导做观察记录

教给学生简单的记录方法：可以用表格记录（日期、观察发现、我的心情），也可以用日记形式简单记录。每天记录一点新发现，重点记录变化。不强求每天写很多，关键是真实记录观察到的变化。

3. 课堂交流观察记录

习作课前，让学生在小组内交流自己这段时间的观察记录，说说选了什么观察对象，发现了哪些变化，最有趣或最让自己惊讶的发现是什么。

第二环节：作中指导——理记录，写变化

1. 明确习作要求

写一组观察日记，记录自己对一种事物的连续观察。格式正确（有日期、星期、天气）。把观察到的变化写清楚。写出自己的心情和感受。语句通顺，内容真实。

2. 指导从记录到成文

引导学生翻看自己的观察记录，选择几天最有代表性、变化最明显的记录来写成日记。不需要把每一天的记录都写成一篇，可以选取关键节点来写，如“第一天、第三天、第五天、第七天”等。

3. 指导写清楚变化

这是本次习作的核心。每一天的日记都要突出“今天有什么新的变化”。可以通过与前一天比较来写，如“今天，我发现绿豆裂开了一条缝，冒出了一个小小的白芽”之类的表述。用上表示变化的词语，如“慢慢地”“渐渐地”“越来越大”“由……变成……”等。

4. 指导写出心情和感受

在写观察发现的同时，引导学生写出自己的心情，如“我兴奋极了”“真神奇啊”“我忍不住凑近了看”。观察日记不仅是记录，也是与自己的对话。

第三环节：作后评改——读日记，验变化

1. 同桌互读

交换读观察日记，读完说说：从他的日记中，你发现了什么变化？变化写清楚了吗？

2. 对照记录修改

学生对照自己的原始观察记录，检查是否把重要的变化遗漏了，有没有写得不准确的地方，进行补充修改。

3. 全班展示

选择几组不同观察对象的观察日记在全班展示，让同学们了解不同事物的变化过程。引导从“变化是否清楚、记录是否真实、有没有写出感受”等方面点评。可以请作者分享观察过程中的趣事。

4. 延伸讨论

讨论：通过这次连续观察和写观察日记，你有什么收获？体会到观察的什么乐趣？鼓励学生把观察的习惯保持下去。

### 四、评价标准参考

1. 基础过关：格式基本正确，能写出观察对象的变化，内容真实。

2. 良好达标：日记格式正确，能把变化过程写清楚，有简单的感受。

3. 优秀进阶：格式规范，变化写得很清楚具体，描写细致，真情实感自然流露，能让人感受到观察的乐趣。

## 四年级上册·第四单元 习作《我和____过一天》

```meta
册: 四年级上册
任务: 第四单元 习作《我和____过一天》
文体: 想象·神话人物
关键词: 神话 人物 一天
分级: L4
```

### 一、习作要求（教学目标）

1. 选择神话或童话人物来写：能从自己熟悉的神话或童话人物中，选择一个来展开想象，写一个故事。

2. 写出“和谁过一天”的经历：能想象自己与所选人物一起度过一天的经过，写出去了哪里、做了什么、发生了什么故事。

3. 写出人物的特点：能在故事中体现所选人物的特点或本领，让人物的行为与其性格本领相符合。

4. 感受想象的快乐：在跨越时空的想象中，体验与神话童话人物互动的乐趣。

### 二、教学重难点

重点：引导学生展开丰富想象，写出与所选人物度过一天的具体经过。

难点：帮助学生在故事中自然地体现人物的特点，使想象既丰富又合理。

### 三、教学建议（核心教学环节）

第一环节：作前指导——选人物，想故事

1. 回顾积累，打开人物库

引导学生回顾学过或读过的神话、童话故事，说说其中有哪些人物：孙悟空、哪吒、葫芦娃、白雪公主、神笔马良、哆啦A梦、嫦娥、后羿、猪八戒等。让学生说说自己喜欢哪些人物，他们有什么特点和本领。

2. 选定人物，展开想象

让学生选定一个自己最想共度一天的人物。想一想：你为什么会选他？他有什么本领或特点？如果有一天他真的来到你身边，你们会一起去哪里？做什么？会发生什么有趣的事？

3. 构思一天的经历

引导学生按时间顺序或地点转换来构思一天的经历：你们是怎么相遇的？上午做了什么？下午去了哪里？晚上怎样告别？可以选择两三个主要场景来写，不需要从早写到晚。

4. 注意体现人物特点

引导学生思考：在故事中，怎样才能让读者感觉“这就是他”？要让人物的行为与他的特点相符。比如孙悟空会七十二变和驾筋斗云，哪吒会踩风火轮，白雪公主很善良会和动物说话等。人物做了符合他特点的事，故事才会让人信服。

第二环节：作中指导——定情节，写具体

1. 明确习作要求

选择一个神话或童话中的人物，把题目补充完整。写一写你们一起度过一天的经过。写出去了哪里、做了什么。体现人物的特点。语句通顺，想象合理。

2. 指导写作结构

提供参考结构：开头写相遇的情景，可以是一次奇妙的相遇（他从书里走出来、从天而降、在梦里见到等）。中间写一两个主要场景，具体写你们一起做的事，把最有趣的场景写详细。结尾写告别和感受，表达对这段奇幻经历的留恋。

3. 指导把重点场景写具体

选定一个最有趣或最难忘的场景作为重点来写。写出当时的环境、人物的动作和对话、自己的心情。把“神奇”的感觉通过具体描写表现出来。

4. 指导写对话

人物之间的对话是写好这个故事的重要手段。对话要符合人物身份和性格。比如孙悟空的语气可以活泼调皮一些，白雪公主的语气温柔亲切一些。

第三环节：作后评改——读故事，评想象

1. 同桌互读

交换读故事，读完说说：你觉得他写的故事有趣吗？人物特点体现出来了吗？

2. 自我修改

检查：人物的行为和他的特点相符吗？重点场景写具体了吗？进行补充修改。

3. 全班“奇幻故事会”

请几位同学在全班朗读自己的故事。引导从“想象力是否丰富、人物特点是否鲜明、经历是否有趣”等方面欣赏和点评。看看同学们都和哪些人物度过了奇妙的一天。

### 四、评价标准参考

1. 基础过关：能写清楚和谁过一天，有什么经历，故事基本完整。

2. 良好达标：故事完整有趣，能在一定程度上体现人物特点，语句通顺。

3. 优秀进阶：想象丰富奇妙，人物特点鲜明突出，重点场景具体生动，故事引人入胜。

## 四年级上册·第五单元 习作《生活万花筒》

```meta
册: 四年级上册
任务: 第五单元 习作《生活万花筒》
文体: 记事
关键词: 一件事 起因经过结果
分级: L4
```

### 一、习作要求（教学目标）

1. 选一件印象深刻的事来写：能从生活中选择一件自己亲身经历的、看到的或听说过的事来写。

2. 按一定顺序把经过写清楚：能按照事情发展的顺序，把事情的起因、经过和结果写清楚。

3. 把重点部分写具体：能在写清楚过程的基础上，把最令人印象深刻的部分写具体。

4. 写出自己的感受和想法：在叙事中自然表达出事情带给自己的感受和启发。

### 二、教学重难点

重点：指导学生按顺序把事情的经过写清楚，把重点部分写具体。

难点：帮助学生从众多事情中筛选出“有写头”的事，并且详略得当地安排材料。

### 三、教学建议（核心教学环节）

第一环节：作前指导——选素材，理过程

1. 理解“万花筒”，打开思路

万花筒的特点是五彩缤纷、变化多端。引导学生理解：生活就像一个万花筒，每天都有各种各样的事情发生。有开心的、烦恼的、有趣的、感动的、后悔的……借助教材提供的参考题目打开思路，如《捉蚊趣事》《一件烦心事》《她收到了礼物》《爷爷戒烟了》《照片里的温暖》《教室里的掌声》《信不信由你》等。

2. 确定写作素材

让学生静心想一想：最近一段时间，哪件事让自己印象最深刻？那是一件什么事？发生在什么时候、什么地方？为什么对这件事印象深刻？选定一件最有话想说的事。

3. 按顺序梳理过程

引导学生按事情的起因、经过、结果来梳理。起因是什么？事情是怎么发生的？经过是怎样的？可以分为哪几个阶段？结果怎样？可以用简单的提纲或流程图把事情的脉络理清楚。

4. 确定重点部分

在梳理完整个过程后，让学生想一想：这件事中，哪个部分是最精彩、最令人印象深刻的？哪个部分是读者最想了解的？这个部分就是需要重点写具体的地方。其他部分可以简略地写。

第二环节：作中指导——按顺序，写重点

1. 明确习作要求

写一件印象深刻的事。按一定的顺序把事情的经过写清楚。把重点部分写具体。写出自己的感受或想法。语句通顺，意思完整。

2. 指导写作结构

提供参考结构：开头交代事情的起因，引起读者兴趣。中间写事情的经过，详写重点部分，略写次要部分。结尾写事情的结果和自己的感受或想法。

3. 指导把重点部分写具体

选取事情中最核心的一个场景或片段，进行细致描写。写出人物的动作、语言、神态和心理活动。写出当时的环境和氛围。用“慢镜头”的方式把这个片段展开来写，让读者有身临其境之感。

4. 指导详略安排

提醒学生：事情的前因后果交代清楚即可，不需要每个环节都详细写。重点笔墨放在最精彩的部分。开头和结尾要简洁。

第三环节：作后评改——读事情，评清楚

1. 同桌互读

交换读习作，读完说说：事情的经过清楚吗？哪里写得最具体、最吸引人？

2. 自我修改

检查：顺序有没有混乱？重点部分够不够具体？感受写出来了吗？进行修改。

3. 全班展示

选几篇写了不同事情、不同风格的习作在全班展示。可以请作者说说为什么选这件事来写。引导从“顺序清楚、重点具体、有真情实感”等方面进行点评。

### 四、评价标准参考

1. 基础过关：能写清楚一件事的起因、经过和结果，语句通顺。

2. 良好达标：顺序清楚，经过写具体，有重点部分，写出简单感受。

3. 优秀进阶：顺序清晰，详略得当，重点部分描写生动具体，感受真实自然。

## 四年级上册·第六单元 习作《中国的世界文化遗产》

```meta
册: 四年级上册
任务: 第六单元 习作《中国的世界文化遗产》
文体: 说明性介绍
关键词: 文化遗产 资料 整理
分级: L4
```

### 一、习作要求（教学目标）

1. 选择一处中国的世界文化遗产来写：能从中选择一处自己感兴趣或有所了解的世界文化遗产。

2. 围绕主题搜集和整理资料：能通过书籍、网络等方式搜集该遗产的相关资料，并进行分类整理。

3. 从几个方面有条理地介绍：能从地理位置、历史背景、建筑特点、文化价值等方面，有条理地把这处文化遗产介绍清楚。

4. 融入自己的感受和评价：在客观介绍的基础上，写出自己对该文化遗产的感受和审美评价，表达对中华文明的热爱。

### 二、教学重难点

重点：指导学生从几个方面有条理地介绍一处文化遗产，内容清楚。

难点：帮助学生在整合资料时避免照搬，用自己理解后的语言进行转述，并融入个人的感受和评价。

### 三、教学建议（核心教学环节）

第一环节：作前准备——选遗产，搜资料

1. 了解中国的世界文化遗产

引导学生回顾已知道的中国世界文化遗产，如长城、故宫、兵马俑、莫高窟、布达拉宫、苏州园林、丽江古城、杭州西湖等。如果学生不了解，可提供资料清单让学生选择一处。

2. 确定介绍对象，搜集资料

让学生选定一处遗产后，课前通过多种途径搜集资料。可以从以下方面搜集：地理位置（在哪）、历史背景（什么时候建的、用来做什么）、外观和结构（长什么样、有什么特别的建筑）、文化价值（为什么能成为世界文化遗产）、相关故事或传说、自己的感受等。

3. 整理资料，确定介绍内容

把搜集到的资料进行分类整理，筛选出最重要、最有意思的内容来写。不必面面俱到，可以选择最有特色的几个方面重点介绍。

第二环节：作中指导——理顺序，融感受

1. 明确习作要求

选择一处中国的世界文化遗产写介绍。从几个方面有条理地介绍。用自己的语言写，不要大段照搬资料。融入自己的感受和评价。语句通顺，内容清楚。

2. 指导写作结构

提供参考结构：开头点明要介绍的文化遗产，用一句话总写它的地位或给你的整体印象。中间分段介绍几个方面，如地理位置与概况、历史背景、建筑或景观特点、文化价值与传说。结尾写自己的感受和评价，或呼吁大家去了解和保护。

3. 指导用自己的话写

强调把资料读懂后，用自己的语言表达出来。可以用“资料显示”“据说”“导游介绍说”等方式自然引出信息。要避免生硬地堆砌数据和专业术语，让读者易于理解。

4. 指导融入个人感受

在介绍的过程中或结尾，适时加入自己的感受和评价，如“站在长城上，我真切地感受到了古人的伟大”“莫高窟的壁画美得让人说不出话来”。个人感受让介绍文字有了温度和个性。

第三环节：作后评改——评清楚，赏文化

1. 同桌互读

交换读习作，读完后说说：对这处文化遗产了解清楚了吗？哪里介绍得最有意思？有没有感受到作者的感情？

2. 自我修改

检查：介绍是否条理清楚？是否用自己的话？有没有个人感受？资料是否准确？进行修改。

3. 全班“文化遗产推介会”

举办一次“中国的世界文化遗产推介会”，请几位同学担任“文化推介官”，用习作向大家介绍。评选“最想去参观的文化遗产”。引导从“条理清楚、内容有特色、语言生动、有个人感受”等方面进行点评。

### 四、评价标准参考

1. 基础过关：能介绍一处文化遗产的基本情况，语句通顺。

2. 良好达标：能从几个方面有条理地介绍，内容比较清楚，有自己的语言表达。

3. 优秀进阶：条理清晰，内容具体有特色，语言生动，融入了自己的真情实感和评价，能激发读者对文化遗产的兴趣。

## 四年级上册·第六单元 习作《记一次游戏》（2026 秋教材换新 · 已删除 · 已停用）

> **已停用。** 2026 秋教材将本单元习作换为《中国的世界文化遗产》（自五年级下册第七单元迁入，见上一节），单元课文同时整组更换为《长城》《颐和园》《秦兵马俑》。《记一次游戏》整题从统编教材删去、无新去处。本节仅供旧详案追溯，**不得再用于生成新详案**。

```meta
册: 四年级上册
任务: 第六单元 习作《记一次游戏》
文体: 记事
关键词: 游戏 过程 感受
分级: L4
```

### 一、习作要求（教学目标）

1. 按顺序把游戏过程写清楚：能按照“游戏前、游戏中、游戏后”的顺序，把游戏的过程完整地记录下来。

2. 写出游戏中的心情和感受：不仅要写看到的、听到的，还要写出自己在游戏过程中的真实感受和想法。

3. 学习捕捉印象深刻的画面：能从整个游戏中选取一两个最精彩、印象最深的场面进行重点描写，避免写成流水账。

4. 尝试用修改符号修改习作：写完后读给同学听，根据建议进行修改，学习使用规范的修改符号。

5. 体会习作分享的快乐：把游戏时的快乐通过文字传递给别人，感受书面表达的交流作用。

### 二、教学重难点

重点：指导学生按一定顺序把游戏过程写清楚，并写出当时的心情。

难点：帮助学生学会从完整的游戏过程中，选取印象最深的场面进行具体描写。

### 三、教学建议（核心教学环节）

第一环节：作前指导——做游戏，聊感受

1. 选择一个游戏，真正地“做”起来

建议课前或当堂组织一个游戏，如“贴鼻子”“击鼓传花”“抢椅子”“两人三足跑”等。让学生带着写作任务去“玩”，有意地观察和体验。强调游戏规则：做游戏前，要把规则讲清楚，让学生明白规则是整个游戏的基础。

2. 游戏后趁热打铁，畅谈感受

按顺序引导回忆：游戏前，大家是什么状态？你在想什么？（期待、紧张、自信）游戏规则是什么？聚焦精彩瞬间：游戏中，你印象最深的是哪个画面？当时你看到了什么？听到了什么？心里怎么想？分享游戏结果：游戏结束了，结果如何？你有什么感受？（胜利的喜悦、失败的遗憾、懂得了什么道理）

3. 结合课文，学习写法

本单元为习作策略单元，课文《牛和鹅》《一只窝囊的大老虎》《陀螺》都涉及通过动作、语言、神态、心理描写来记录事件和心情的方法。指导重点：写动作，不用“很”。不说“他很紧张”，而是写“他的手微微发抖，眼睛死死地盯着前面的椅子”。写心理，说真话。学习《一只窝囊的大老虎》中真实记录内心“窝囊”感觉的方法，鼓励学生写真实的情绪变化。

第二环节：作中指导——搭支架，写清楚

1. 按顺序列出写作提纲

指导学生在动笔前先想清楚按什么顺序写，并在草稿纸上列出简单的提纲：第一部分游戏前（做什么准备？规则是什么？心情如何？），第二部分游戏中（先怎样？接着怎样？最精彩的一幕是什么？），第三部分游戏后（结果怎样？感受和想法是什么？）。

2. 把“经过”写具体

聚焦“那一刻”：引导学生思考，整个游戏中，如果只用一个慢镜头重放，会选哪一个瞬间？把这一瞬间的动作、语言、神态和自己的心理活动放大了写。串联整过程：提醒学生用上“首先……接着……然后……最后……”等表示顺序的词，把游戏经过写连贯。

第三环节：作后评改——读习作，共分享

1. 依据标准，自我修改

写完后，先自己读三遍：第一遍改错别字和不通顺的句子。第二遍看游戏过程是不是按顺序写清楚了。第三遍看是不是写出了自己当时的心情。

2. 同桌互读，分享快乐

猜心情：同桌交换读习作，读完后猜一猜对方在游戏中最开心（或最紧张、最遗憾）的是哪个时刻。如果没读出来，说明心情写得不具体，可以提出修改建议。用符号规范修改：指导学生使用上一单元学过的“改正、增补、删除”等修改符号，在习作上直接批改。

3. 全班交流，佳作赏析

选择有代表性的习作进行全班点评。重点关注：“顺序是不是很清楚？”“哪里让你仿佛看到了当时的场面？”“哪里让你体会到了他的心情？”

### 四、评价标准参考

1. 基础过关：能把游戏过程写下来，语句基本通顺，能看出游戏的先后顺序。

2. 良好达标：能按一定顺序把游戏过程写清楚，写出自己当时的心情，能进行简单的自我修改。

3. 优秀进阶：能抓住一两个印象最深的场面具体描写，能把人物的动作、语言、心理活动写生动，并写出自己独特的感受。

## 四年级上册·第七单元 习作《我的心儿怦怦跳》

> ⚠ **2026 秋教材换新：本单元号已变。** 四上第七、八单元习作位置互换——**七＝《我的心儿怦怦跳》、八＝《写信》**（`换新梳理` p.7）。两题本身与内容均未变，只是所在单元号对调；本节标题与 `meta` 已按新单元号改，正文一字未动。旧详案按旧单元号命名的不回改。

```meta
册: 四年级上册
任务: 第七单元 习作《我的心儿怦怦跳》
文体: 记事·心理
关键词: 心理感受 紧张害怕激动
分级: L4
```

### 一、习作要求（教学目标）

1. 选一件让心儿怦怦跳的事来写：能从自己的经历中，选择一件让自己紧张、害怕、激动或惊喜的事来写。

2. 写清楚事情的经过和当时的心情：能按事情发展顺序把过程写清楚，重点把心儿怦怦跳时的内心感受写具体。

3. 学习写内心感受：能用心理描写的方法，把紧张、害怕、激动等情绪的变化过程写清楚。

4. 体会习作中表达真情实感的重要性：通过这次习作，进一步体会把真实感受写出来才能打动人。

### 二、教学重难点

重点：指导学生把事情的经过写清楚，把内心感受写具体。

难点：帮助学生把紧张、激动等内心感受的变化过程写细致，避免简单地说“我很紧张”。

### 三、教学建议（核心教学环节）

第一环节：作前指导——忆心跳，说感受

1. 创设情境，唤起体验

老师可以先分享一件自己“心儿怦怦跳”的经历，如第一次上台演讲、参加比赛、走夜路、等待考试成绩等。用生动的讲述让学生进入情境，也唤起他们自己的记忆。

2. 多角度打开思路

引导学生从不同经历中寻找素材：紧张害怕的事（第一次独自在家、打针、走夜路、被老师点名回答不会的问题等）、激动兴奋的事（登上领奖台、收到惊喜礼物、见到偶像等）、担心忧虑的事（等待考试结果、家人晚归时的心焦等）。让学生静心回忆：哪一次心儿跳得最厉害？

3. 聚焦心跳时刻，把感受说具体

让学生选定一件事后，聚焦心跳最厉害的那个时刻。追问：当时你在哪里？发生了什么？你的身体有什么反应？（心跳加速、手心出汗、腿发软、脸发烫等）你心里在想什么？（一个又一个念头、自己对自己说的话）周围的其他人或环境是怎样的？引导学生把那一瞬间的心理和生理感受说具体、说细致。

4. 感受“心路历程”

不仅写心跳最厉害的那一刻，还可以写心情的变化过程：刚开始心情怎样？后来发生了什么变化？什么时候心跳得最快？后来又怎样了？这种心情的起伏变化，让感受更真实丰富。

第二环节：作中指导——按顺序，写心情

1. 明确习作要求

写一件让心儿怦怦跳的事。按顺序写清楚事情的经过。重点写出心跳时的内心感受。语句通顺，真情实感。

2. 指导写作结构

提供参考结构：开头用一句话引出这件事，可以设置悬念，如“那次，我的心差点从嗓子眼里跳出来”。中间按事情发展顺序写，分为事情开始、心跳加速、心跳最快的时候、事情结束心情平复。结尾写事后自己的感受或想法。

3. 指导写内心感受的方法

多种方法结合写心理：直接写心里话，如“我不停地对自己说：别紧张，别紧张……”；写身体反应，如“我的手心全是汗，腿也不听使唤地发抖”；通过动作和环境来映衬心情，如“教室里安静极了，我能听见自己的心跳声”。这些方法本单元的课文都有示范，可以引导学生回顾借鉴。

4. 指导写出心情变化

引导学生不只是一个调子写到底，试着写出心情的起伏：可能一开始还好，越接近关键时刻越紧张；可能紧张到极点后突然放松了；也可能一波三折。真实地记录下心情的曲线。

第三环节：作后评改——读心跳，评真情

1. 自读自查

自己读一遍习作，检查事情的经过清楚了没有，心跳时的感受写出来了没有。

2. 同桌互读

交换读习作，读完说说：你感受到他当时心跳的感觉了吗？哪里写得最让你也跟着紧张（或激动）？哪里还可以写得更有感觉一些？

3. 全班展示

选几篇写得特别有真情实感的习作在全班朗读。可以配上紧张的背景音乐，营造氛围。引导从“事情过程清楚、内心感受具体、有没有写出心情变化”等方面进行点评和欣赏。老师总结：把真实感受写出来，文章就有了打动人心的力量。

### 四、评价标准参考

1. 基础过关：能写清楚事情的经过，写出了紧张或激动的感觉。

2. 良好达标：过程清楚，能把心跳时的感受写具体，有一定的心理描写。

3. 优秀进阶：过程清楚，心理描写细致生动，写出了心情的变化起伏，有真情实感，让读者感同身受。

## 四年级上册·第八单元 习作《写信》

> ⚠ **2026 秋教材换新：本单元号已变。** 四上第七、八单元习作位置互换——**七＝《我的心儿怦怦跳》、八＝《写信》**（`换新梳理` p.7）。两题本身与内容均未变，只是所在单元号对调；本节标题与 `meta` 已按新单元号改，正文一字未动。旧详案按旧单元号命名的不回改。

```meta
册: 四年级上册
任务: 第八单元 习作《写信》
文体: 应用文·书信
关键词: 书信 格式
分级: L4
```

### 一、习作要求（教学目标）

1. 掌握书信的基本格式：知道书信由称呼、问候语、正文、祝福语、署名和日期六部分组成，格式正确。

2. 能把想说的内容写清楚：能根据收信对象，确定写信的内容，把想说的事情一件一件写清楚。

3. 学习书信的语言特点：能根据不同的收信对象，使用恰当的语气和措辞，做到语言得体。

4. 感受书信交流的独特价值：在电子邮件和即时通讯普及的时代，体会手写书信的独特情感价值。

### 二、教学重难点

重点：指导学生掌握书信的正确格式，把想说的内容写清楚。

难点：帮助学生在书信中表达真情实感，根据不同对象使用得体的语言。

### 三、教学建议（核心教学环节）

第一环节：作前指导——识书信，明格式

1. 创设情境，引出书信

可以展示一封真实的来信或名人书信，引导学生感受书信的独特魅力。讨论：在手机和微信普及的今天，为什么还要学写信？让学生明白书信可以长久保存、反复阅读，有特殊的纪念意义和情感价值。

2. 认识书信格式

出示一封标准格式的书信范例，引导学生逐项认识书信的六个部分。称呼：第一行顶格写，后面加冒号。问候语：另起一行空两格写，如“您好”“最近好吗”。正文：另起一行空两格写，这是书信的主体。祝福语：正文写完后另起一行空两格写“祝”，再另起一行顶格写祝福内容，如“身体健康”。署名：在右下方写上自己的名字。日期：在署名下方写上日期。

3. 确定收信对象和内容

引导学生确定写信对象：可以是远方的亲人、转学的同学、敬爱的老师、想交的笔友等。想一想：你想对他（她）说什么？可以是分享近况、倾诉心事、表达感谢、提出建议、发出邀请等。在小组内说说自己打算写给谁，写什么。

4. 指导书信语言

讨论：给不同的人写信，语气有什么不同？给长辈写信语气要尊敬，用“您”；给朋友写信语气可以轻松亲切一些。提醒书信语言要真诚自然，就像面对面聊天一样。

第二环节：作中指导——讲格式，写真情

1. 明确习作要求

写一封信给亲友或其他人。格式正确，六部分完整。把想说的内容写清楚。语言得体，表达真情实感。书写工整，卷面整洁。

2. 指导格式书写

逐项指导书写位置：称呼顶格、问候语空两格、正文分段写、祝福语分两行（“祝”空两格，祝福内容顶格）、署名和日期靠右。可以边讲边让学生跟着写格式，确保人人过关。

3. 指导正文内容

提醒正文要分段写。如果写几件事，一件事写一段，这样读起来清晰。把事情写清楚，让对方看得明白。可以加上一两句关心对方的话，体现书信的交流感。

4. 指导祝福语

介绍常用的祝福语：给长辈用“祝您身体健康、万事如意”；给平辈用“祝你学习进步、天天开心”；给老师用“祝您工作顺利、桃李满天下”等。学生可以根据收信对象自己写祝福语。

第三环节：作后评改——查格式，读真心

1. 格式自查

对照书信格式要求逐项自查：称呼顶格了吗？问候语空两格了吗？祝福语两行格式对吗？署名和日期位置对吗？用红笔标出格式错误的地方并改正。

2. 同桌互查

交换检查格式，互相指正格式上的问题。读一读正文，看看对方想说的内容写清楚了没有，有没有打动自己的地方。

3. 全班展示

选几封写给不同对象的信在全班展示，引导从“格式是否正确、内容是否清楚、语言是否得体、情感是否真挚”等方面进行点评。

4. 真实的寄信体验

鼓励学生把信装入信封，写上收信人地址和姓名，贴上邮票，真的寄出去。体会从写信到寄信再到等待回信的完整过程，感受书信往来的美好。

### 四、评价标准参考

1. 基础过关：格式基本正确，能把想说的内容写出来，语句通顺。

2. 良好达标：格式正确，内容清楚，语言比较得体。

3. 优秀进阶：格式规范，内容具体清楚，语言得体自然，真情实感，能体现书信的交流功能。
