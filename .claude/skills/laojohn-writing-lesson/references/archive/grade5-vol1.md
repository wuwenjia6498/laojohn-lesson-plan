## 五年级上册·第一单元 习作《我的心爱之物》

```meta
册: 五年级上册
任务: 第一单元 习作《我的心爱之物》
文体: 状物·情感
关键词: 心爱之物 来历 感情
分级: L5
```

### 一、习作要求（教学目标）

1. 选择一件心爱之物来写：能选出自己最心爱的一件物品，可以是动物、植物、玩具、学习用品、生活用品、工艺品等。

2. 写清楚心爱之物的样子和来历：能写出这件物品是什么样子的，是怎么得到的，把物品的特点写清楚。

3. 围绕“心爱”写出感情：能通过具体的事例或细节，写出这件物品为什么成为自己的心爱之物，表达出自己的喜爱之情。

4. 学习借物抒情：初步学习通过对物品的描写来表达自己的情感，为高年级借物抒情的写作打下基础。

### 二、教学重难点

重点：指导学生写清楚心爱之物的样子、来历和心爱的原因。

难点：帮助学生把“心爱”写具体，通过细节和事例让读者感受到这份感情，避免空洞地说“我很喜欢它”。

### 三、教学建议（核心教学环节）

第一环节：作前指导——选物品，说心爱

1. 创设情境，引出心爱之物

可以让学生把自己心爱的小物品带到课堂上来，或者通过照片展示。也可以老师先展示自己的心爱之物，讲述它背后的故事，引发学生的共鸣和表达欲。

2. 选定心爱之物，多角度思考

引导学生选定自己最想写的一件物品。想一想：它是什么样子的？可以从颜色、形状、大小、材质等方面来想。你是怎么得到它的？是家人送的礼物，还是自己努力换来的，还是有什么特殊的缘分？它为什么是你的心爱之物？和你之间有什么故事？它陪伴了你多久？有什么特殊的意义？

3. 聚焦“心爱”，挖掘故事

物品之所以成为“心爱之物”，往往是因为它背后有故事、有情感。引导学生回忆与这件物品相关的特别经历：它有没有在某个时刻给过你安慰？有没有见证过你的成长？你和它之间有没有发生过难忘的事？这个“故事”是本次习作最动人的部分。

4. 口头交流，互相启发

在小组内介绍自己的心爱之物，说说它的样子、来历和心爱的原因。组员听完后说说哪里最打动自己，有没有还想了解更多的内容。

第二环节：作中指导——写样子，讲故事

1. 明确习作要求

写自己的心爱之物。写出它的样子、来历和心爱的原因。通过具体的事例或细节写出感情。语句通顺，有真情实感。

2. 指导写作结构

提供参考结构：开头点出心爱之物是什么，给一个总的印象。中间分段写物品的样子、物品的来历、心爱的原因（可以写一件事或几个细节）。结尾再次表达对心爱之物的感情，点题。

3. 指导写好样子

按一定顺序写物品的外形、颜色、材质等。抓住物品最特别、最有特点的地方进行描写，不面面俱到。在描写中可以融入自己的感情，让描写带上温度。

4. 指导写好故事和感情

这是习作的核心部分。把与心爱之物相关的故事写具体，写清楚时间、地点、经过。通过细节来表现感情，如每天都要看一看、摸一摸，搬家时第一个想到带上它，坏了自己动手修补等。感情不说出来，而是通过这些细节让读者感受到。

第三环节：作后评改——读心爱，品真情

1. 同桌互读

交换读习作，读完后说说：你感受到他对这件物品的心爱之情了吗？哪里写得最动人？

2. 自我修改

检查：样子写清楚了吗？来历写明白了吗？心爱的感情是否通过细节和故事体现出来了？进行修改补充。

3. 全班“心爱之物展览会”

结合学生带来的实物或照片，举办“心爱之物展览会”。请几位同学朗读自己的习作，大家一边听一边看实物。引导从“样子清楚、故事动人、感情真挚”等方面进行点评。

### 四、评价标准参考

1. 基础过关：能写出心爱之物是什么，基本的样子和来历，语句通顺。

2. 良好达标：能写清楚样子和来历，有简单的故事或细节，表达出喜爱之情。

3. 优秀进阶：描写具体生动，故事动人，情感真挚自然，能通过细节让读者感受到物品对自己的特殊意义。

## 五年级上册·第二单元 习作《“漫画”老师》

```meta
册: 五年级上册
任务: 第二单元 习作《“漫画”老师》
文体: 写人·事例
关键词: 老师 特点 典型事例
分级: L5
```

### 一、习作要求（教学目标）

1. 选择一位老师来“画”像：能选择一位给自己留下深刻印象的老师来写，可以是现任老师，也可以是以前的老师。

2. 抓住老师最突出的特点：能像画漫画一样，抓住老师在外貌、性格、教学风格等方面最突出的一个或几个特点来写。

3. 用具体事例来“画”特点：能选择一两件典型的事例，把老师的特点写具体、写生动。

4. 用夸张的手法增强趣味：能适当运用漫画式的夸张手法，把老师的特点写得有趣可爱，表达对老师的感情。

### 二、教学重难点

重点：指导学生抓住老师最突出的特点，用具体的事例来表现。

难点：帮助学生在“漫画式夸张”和“真情实感”之间找到平衡，写得有趣又不失尊重。

### 三、教学建议（核心教学环节）

第一环节：作前指导——选老师，抓特点

1. 理解“漫画”式写法

引导学生回顾看过的漫画人物，说说漫画有什么特点：抓住人物最突出的特征进行夸张，让人一看就知道是谁，而且觉得很有趣。告诉学生，这次习作要用文字来“画”一幅老师的“漫画像”，也要像画漫画一样，抓住最有特点的地方来写。

2. 选定一位老师

让学生想一想教过自己的老师，哪一位最有特点、最让自己印象深刻。选定后确定写哪一位老师。

3. 多角度寻找特点

引导学生从不同角度想老师的特点：外貌上的特点（发型、眼镜、身高、笑容等）、性格上的特点（幽默风趣、严肃认真、温柔细心、急性子等）、上课风格的特点（声音洪亮、喜欢做实验、讲起故事来滔滔不绝等）、其他方面的特点（爱运动、字写得特别好、有一个特别的爱好等）。让学生用几个关键词写下老师的特点。

4. 为特点寻找典型事例

特点需要用具体的事例来“证明”。选定一两个最想写的特点，想一想哪些事最能体现这些特点。比如写老师幽默，要想起一件让大家哈哈大笑的事；写老师认真，要想起一件他一丝不苟的事。在小组内说给组员听，让大家判断这个事例是否能体现这个特点。

5. 讨论“夸张”的尺度

引导学生理解，这里的“夸张”是为了突出特点，让文字更有趣，但要建立在真实的基础上。不是丑化老师，而是用放大的方式让特点更鲜明，表达的是对老师的喜爱。

第二环节：作中指导——抓特点，写事例

1. 明确习作要求

写一位老师。抓住老师最突出的一两个特点来写。用具体的事例来表现特点。可以适当运用夸张的手法，写得有趣。语句通顺，表达出对老师的感情。

2. 指导写作结构

提供参考结构：开头点出要写的老师是谁，用一两句话概括他的突出特点，就像给漫画配一个标题。中间分段写老师的几个特点，每个特点配上一个具体的事例，把事例写生动。结尾写出对老师的感情或评价。

3. 指导用夸张手法写

在描写外貌和人物言行时，可以适当放大特点。如写老师个子高，可以说“他站在讲台上，头顶都快碰到天花板了”；写老师说话声音大，可以说“他的声音能穿透三堵墙”。这种漫画式的夸张能让习作生动有趣，但要掌握好分寸。

4. 指导写好事例

每个特点后面跟的事例要写具体。写清楚事情发生的时间、地点、经过，特别是老师当时的语言、动作和神态，让读者看了觉得“果然是这位老师才会做的事”。

第三环节：作后评改——读画像，猜老师

1. 同桌互读

交换读习作，读完后说说：你猜出写的是哪位老师了吗？哪个特点写得最像？哪个事例最生动？

2. 自我修改

检查特点是不是抓住了，事例是不是写具体了，夸张是不是恰当有趣。进行修改。

3. “猜猜是哪位老师”活动

在全班匿名朗读几篇习作（不读老师姓名），让同学猜写的是谁。被大家异口同声猜出来的，说明特点抓得准、写得像。这个活动有趣味性，也是很好的评价方式。

4. 全班点评

引导从“特点鲜明、事例典型、语言有趣、感情真挚”等方面进行点评。老师也要有一颗宽容幽默的心，乐于看到学生在习作中用善意的方式写自己。

### 四、评价标准参考

1. 基础过关：能写出老师的一两个特点，有简单的事例，语句通顺。

2. 良好达标：特点比较鲜明，事例比较具体，有一定的趣味性。

3. 优秀进阶：特点突出，事例典型生动，夸张手法运用得当有趣，写出了对老师的真挚感情。

## 五年级上册·第三单元 习作《缩写故事》（2026 秋教材调整前 · 已停用）

> **已停用。** 2026 秋教材调整后本单元习作改为《故事新编》（见下一节），单元课文未变（仍为民间故事单元）。本节仅供旧详案 `五上-第三单元-缩写故事-写作课详案.md` 追溯其事实依据，**不得作为新详案的依据**。

```meta
册: 五年级上册
任务: 第三单元 习作《缩写故事》
文体: 缩写
关键词: 缩写 概括 保留主干
分级: L5
```

### 一、习作要求（教学目标）

1. 理解缩写的意思和方法：知道缩写就是把一个较长的故事压缩成较短的故事，保留主要内容，删减次要内容。

2. 学习缩写的基本方法：能用“摘录主要情节、删减细节描写、概括人物对话”等方法对故事进行缩写。

3. 保持故事完整连贯：缩写后故事的基本情节完整，事情的前因后果清楚，语言通顺连贯。

4. 培养概括和提炼能力：在缩写实践中锻炼提取主要信息和概括表达能力。

### 二、教学重难点

重点：指导学生掌握缩写的基本方法，保留主干、删减枝叶。

难点：帮助学生在删减的同时保持故事的完整和连贯，避免缩写后变成“故事梗概”或“故事碎片”。

### 三、教学建议（核心教学环节）

第一环节：作前指导——学方法，练缩写

1. 认识缩写

通过对比一篇长故事和它的缩写版本，让学生直观感受缩写是什么。讨论：缩写了以后，哪些内容保留了？哪些内容被删掉了？为什么？引导学生发现缩写的规律：保留主要人物、主要情节和故事结局，删掉细节描写、次要情节和人物对话的详细内容。

2. 学习缩写方法

结合教材提示和范例，归纳缩写的常用方法：摘录法：保留原文中最关键、最能推动情节发展的句子。删减法：删掉环境描写、外貌描写、心理描写等细节性的内容。概括法：把人物的具体对话概括成叙述性的语言，如把一段对话概括为“他们说好了明天一起去”。合并法：把几个次要情节合并成一句话简要带过。

3. 小试牛刀，口头练习

选取本单元学过的民间故事中的一段，让学生试着口头缩写。比如把《牛郎织女》中牛郎被哥嫂赶出家门那一段详细叙述，缩写为“牛郎的哥嫂对他很不好，最后只分给他一头老牛，把他赶出了家门”。在练习中体会如何删和留。

4. 确定缩写对象

让学生从本单元学过的民间故事中选择一个来缩写，也可以选择自己课外读过的其他民间故事或神话故事。提醒学生选择篇幅适中、情节比较熟悉的故事来缩写更容易上手。

第二环节：作中指导——留主干，删枝叶

1. 明确习作要求

选择一个民间故事或其他故事进行缩写。保留故事的主要情节和人物，删掉细节。缩写后故事要完整连贯。语言简洁通顺。字数明显少于原文。

2. 指导缩写步骤

第一步：通读原文，理清主要人物和主要情节。第二步：画出必须要保留的“骨架”内容（这些如果删了故事就不完整了）。第三步：标记可以删减的“枝叶”内容（细节描写、对话、修饰语等）。第四步：把保留的内容用自己的话重新连缀成篇。

3. 指导保持完整连贯

提醒学生在缩写时注意：故事的起因、经过和结果都要有，不能只有经过没有结局；人物之间的关系要清楚；删掉的内容不能影响读者对故事的理解；段落之间过渡自然。缩写不等于只写提纲，仍然要是一篇通顺的文章。

4. 指导控制字数

可以给出一个参考字数范围，如把一篇一千字左右的故事缩写成三百字左右。提醒缩写后的故事篇幅明显缩短。

第三环节：作后评改——比原文，验缩写

1. 同桌互读互验

交换读缩写后的故事，然后翻看原文对照：主要情节都保留了吗？有没有重要的内容被误删了？故事还完整连贯吗？

2. 自我修改

根据同桌反馈，检查是否有遗漏的重要情节，是否有删减后读不通顺的地方，进行调整。

3. 全班展示比较

选几组同一篇原文的缩写进行对比展示，看看不同同学保留了哪些内容、删掉了哪些内容。讨论：哪个缩写版本既简洁又完整？引导体会“保留主干、删减枝叶”的原则。

### 四、评价标准参考

1. 基础过关：能把握主要情节进行缩写，故事基本完整。

2. 良好达标：主要情节完整，删减得当，语言比较简洁通顺。

3. 优秀进阶：主干突出，删减合理，故事完整连贯，语言精练流畅，篇幅明显缩短。

## 五年级上册·第三单元 习作《故事新编》

```meta
册: 五年级上册
任务: 第三单元 习作《故事新编》
文体: 想象·改编
关键词: 旧故事新编 龟兔赛跑
分级: L5
```

> **2026 秋教材调整后的现行题目。** 本习作原在**四年级下册第八单元**，2026 秋移入本单元，替代原题《缩写故事》（旧题一节保留在本文件上方，仅供旧详案追溯）。**单元课文未随之改变**，仍为民间故事单元（《猎人海力布》《牛郎织女（一）》《牛郎织女（二）》）。**分级由 L4 升为 L5。** 教材页题面同时更新三处，逐字见「五、教材页题面」——下面「一～四」四节是随题目迁入的官方指导件内容，**不是教材页原文**，两者不可互相替代。

### 一、习作要求（教学目标）

1. 选择一个熟悉的故事重新创编：能从自己熟悉的寓言、童话、成语故事、民间故事中，选一个来重新编写。

2. 在原故事基础上大胆创新：可以从改变结局、改变人物特点、改变情节发展、增加新角色等角度进行创新。

3. 把故事写完整写有趣：新编的故事要有完整的起因、经过和结果，情节有趣，想象合理。

4. 感受创编的乐趣：在“老故事”中写出“新意思”，体会创作的成就感和想象的乐趣。

### 二、教学重难点

重点：指导学生找到一个创新的切入点，把故事重新编得有趣合理。

难点：帮助学生在“新编”的过程中保持故事的基本逻辑自洽，既有新意又不荒诞不经。

### 三、教学建议（核心教学环节）

第一环节：作前指导——选故事，找切口

1. 回顾熟悉的故事，打开“故事库”

引导学生回忆学过的和课外读到的各种故事：寓言故事（《守株待兔》《龟兔赛跑》《狐假虎威》等）、童话故事（《小红帽》《三只小猪》《丑小鸭》等）、成语故事（《画龙点睛》《掩耳盗铃》等）、神话传说（《后羿射日》《精卫填海》等）。说说自己最喜欢哪个故事，对哪个故事的情节和结局最熟悉。

2. 选定故事，寻找创新切入点

以《龟兔赛跑》为例，打开创新思路。可以改变结局：兔子没有睡觉，赢了比赛；乌龟和兔子成了好朋友，一起冲过终点。可以改变人物特点：兔子变得非常骄傲自大目中无人；乌龟用上了现代科技，穿上了滑轮鞋。可以改变情节：比赛中途出现了一条河，兔子过不去，乌龟帮它过河。可以增加新角色：裁判是一只狡猾的狐狸，在比赛中搞鬼。让学生从不同角度去想，找到自己的创新点。

3. 围绕创新点构建新情节

选定创新点之后，重新构思故事的情节：起因还是原来的吗？经过发生了什么变化？结局变成了什么样？在小组内口头讲一讲自己的新编故事梗概，看看情节是否完整、是否合理有趣。

第二环节：作中指导——定新意，写新篇

1. 明确习作要求

选一个熟悉的老故事，进行新编。在原故事基础上创新，可以改结局、改人物、改情节或加角色等。把新编的故事写完整、写有趣。语句通顺，想象合理。

2. 指导写作结构

提供参考结构：开头交代原来的故事是怎样的（用一两句话简要回顾），引出“如果……”引出新编。中间写新编的故事经过，重点写与原来不同的地方，把创新的部分写具体。结尾写新故事的结果，可以和原故事结局作一个对比，突出新意。

3. 指导写好“新”的部分

新编故事的魅力在于“新”，所以要把创新的部分作为重点来写。改写结局的，把新的结局写详细；改写情节的，把新情节展开；改变人物的，通过言行体现人物的新特点。新意要贯穿全文，不能只改一点点。

4. 保持故事感

虽然是“新编”，但仍然要写得像一个有趣的故事。有人物的对话、动作和心理活动，有情节的起伏，有吸引人的叙述。让读者愿意读下去。

第三环节：作后评改——读新篇，评创意

1. 同桌互读

交换读对方的新编故事，读完后说说：这个新编故事哪里最有新意？情节合理有趣吗？

2. 小组分享

在小组内朗读各自的故事新编，评选出“最佳创意奖”“最出人意料奖”“最有趣新编奖”等。

3. 全班“故事新编会”

各组推选代表在全班讲述自己的新编故事。可以配上简单的道具或表演。引导从“创新点的巧妙、情节的完整与合理、故事的趣味性”等方面进行欣赏和点评。

4. 与原故事对照阅读

如果有时间，可以将新编故事和原故事放在一起阅读比较，讨论：哪些地方变了？变得好不好？体会创作的空间和乐趣。

### 四、评价标准参考

1. 基础过关：能对一个老故事进行改写或续写，故事基本完整。

2. 良好达标：有新编的创意，能在一个方面有所创新，故事完整通顺。

3. 优秀进阶：新编有巧思，情节既合理又出人意料，故事生动有趣，体现了较强的想象力和创作力。

## 五年级上册·第四单元 习作《二十年后的家乡》

```meta
册: 五年级上册
任务: 第四单元 习作《二十年后的家乡》
文体: 想象·未来
关键词: 未来 家乡 变化
分级: L5
```

### 一、习作要求（教学目标）

1. 围绕“二十年后”展开想象：能大胆想象二十年后的家乡会发生什么变化，从环境、生活、工作、交通等方面展开想象。

2. 把想象的变化写具体：能选择几个方面的变化，把变化后的景象写具体，写出和现在的不同。

3. 尝试用对比的方法写变化：能用“现在……二十年后……”的对比方式，突出家乡的变化之大。

4. 表达对家乡的热爱和期待：在对未来家乡的畅想中，表达对家乡美好未来的向往和祝愿。

### 二、教学重难点

重点：引导学生从多个方面展开对二十年后家乡的大胆想象。

难点：帮助学生把想象的变化写具体、写生动，避免笼统地说“变得更好了”。

### 三、教学建议（核心教学环节）

第一环节：作前指导——畅想未来，打开思路

1. 立足现在，发现“可变化之处”

引导学生观察自己家乡现在的样子：环境方面（空气、河流、街道等）、建筑方面（房子、道路等）、生活方面（交通方式、购物方式、学校样貌等）、工作方面（人们做什么工作、用什么工具等）。让学生说说现在有哪些地方还不够好，或者有哪些方面可以变得更先进。为想象“二十年后的变化”找到出发点。

2. 大胆想象二十年后

以现在为起点，让学生大胆想象二十年后这些方面会变成什么样。可以从以下角度展开：环境变化（天空更蓝了、河水更清了、到处都是公园等）、科技变化（家家户户有机器人、出行用飞行器、学校上课用虚拟现实等）、生活变化（食物更健康、人们的工作方式改变了、通信方式更新了等）、家乡面貌（老房子变成高楼、小村庄变成特色小镇等）。鼓励大胆新奇的想象。

3. 选定几个方面，深入想具体

让学生从众多想象中选择三四个自己最感兴趣、最有话说的方面来重点写。每一个方面要想具体：变化之后具体是什么样子的？和现在有什么不同？人们在这样的环境中是怎样生活的？

4. 口述“二十年后的家乡”

在小组内描述自己想象中二十年后的家乡，可以按照“现在的样子——二十年后的变化——变化带来的好处”的顺序来说。组员互相评价谁的想象最有意思、最具体。

第二环节：作中指导——列对比，写变化

1. 明确习作要求

大胆想象二十年后家乡的变化。选择几个方面把变化写具体。可以用对比的方法来写。语句通顺，想象合理有趣。

2. 指导写作结构

提供参考结构：开头设置一个“穿越”或“回归”的情境，引出二十年后回到家乡。中间分段写各个方面的变化，一个变化写一段，用对比的方式写出“原来……现在……”。结尾写出对家乡变化的感慨和对未来的美好期待。

3. 指导写好对比

教给学生用对比句式来突出变化：“现在的家乡是……二十年后变成了……”“以前……如今……”“过去……现在……”通过鲜明的前后对比，让读者感受到变化之大、之美。

4. 指导把变化写具体

写一个方面的变化时，不要只说“变得更好了”“变得更先进了”，要通过具体的描绘让读者看到画面。写环境变化，写出具体的景物是什么样的；写科技变化，写出具体的科技产品是怎样运作的。让人读了之后觉得“二十年后真好啊”。

第三环节：作后评改——读未来，赏想象

1. 同桌互读

交换读习作，读完后说说：他的想象中最打动你的是哪个变化？哪里写得最具体？

2. 自我修改

检查：变化写具体了吗？对比清楚了吗？有没有把对家乡的感情写进去？进行修改补充。

3. 全班“未来家乡展”

请几位同学在全班朗读自己的习作，可以配上自己画的“未来家乡示意图”。评选“最令人向往的未来家乡”“最有创意的变化”“最具体的描写”等。讨论：为了实现这些美好变化，我们现在可以做些什么？

### 四、评价标准参考

1. 基础过关：能写出二十年后家乡的几点变化，语句通顺。

2. 良好达标：能从几个方面写出家乡的变化，有一定的想象和对比。

3. 优秀进阶：想象大胆新奇，变化写得具体生动，对比鲜明，充满对家乡的热爱和期待。

## 五年级上册·第五单元 习作《介绍一种事物》（说明文）

```meta
册: 五年级上册
任务: 第五单元 习作《介绍一种事物》（说明文）
文体: 说明文
关键词: 说明方法 列数字举例子打比方
分级: L5
```

### 一、习作要求（教学目标）

1. 选择一种事物来介绍：能从动物、植物、物品、美食、自然现象等中选择一种自己了解并感兴趣的事物来写。

2. 学习用说明方法写清楚：能运用列数字、打比方、举例子、作比较等说明方法，把事物的特点写清楚。

3. 分段从不同方面介绍：能从几个不同的方面（如外形、构造、功能、用途等）有条理地介绍事物。

4. 语言准确、简洁：注意说明文语言的准确性和简洁性，与记叙文的语言有所区别。

### 二、教学重难点

重点：指导学生运用说明方法从多个方面有条理地介绍一种事物。

难点：帮助学生收集和筛选准确的资料，用恰当的说明方法把事物的特点写清楚，语言做到准确简洁。

### 三、教学建议（核心教学环节）

第一环节：作前准备——搜资料，理信息

1. 选定介绍对象

引导学生从教材提供的参考题目中选择，也可以自己确定一个。参考题目包括：恐龙、菊花、灯、扫地机器人、溜溜球的玩法、涮羊肉、怎样泡酸菜、我的文具盒、火星的秘密、热带植物大观园等。选定后确保自己对这个事物有充分的了解，或者有条件去搜集资料。

2. 搜集和整理资料

课前布置学生通过观察、查阅书籍、上网搜索等方式，搜集所选事物的相关信息。信息可以从以下方面收集：外形特点（样子、大小、颜色等）、种类分类、功能用途、工作原理或生长过程、相关的有趣知识等。把搜集到的信息用卡片或思维导图整理出来。

3. 筛选和确定写作内容

搜到的信息可能很多，不需要都写。引导学生从中选择三四条最有价值、最能体现事物特点的信息作为重点来写。在小组内交流各自准备介绍什么事物、从哪几个方面介绍。

第二环节：作中指导——用方法，写清楚

1. 明确习作要求

介绍一种自己了解的事物。从几个方面把事物介绍清楚。运用恰当的说明方法。语言准确、通顺。

2. 指导写作结构

提供参考结构：开头总体介绍要说明的事物是什么，给人一个整体印象。中间分段介绍事物的几个方面，一个方面写一段。每个方面运用恰当的说明方法把特点写清楚。结尾可以简要总结事物的价值或自己对它的看法。

3. 指导运用说明方法

结合本单元学过的说明性文章，复习常用的说明方法并指导运用：列数字：用具体的数字来说明，如“长颈鹿的身高可达六米”。打比方：用比喻来让读者容易理解，如“石拱桥的桥洞像一道彩虹”。作比较：和熟悉的事物比较，如“鲸的一条舌头就有十几头大肥猪那么重”。举例子：用具体的例子来说明，如“很多动物都有冬眠的习性，比如熊、蛇、青蛙等”。提醒说明方法要恰当使用，不要堆砌。

4. 指导说明文的语言

说明文的语言讲究准确、简洁、客观。提醒学生不说“我觉得它很美”这样主观感受的话，而要说“它全身覆盖着色彩鲜艳的羽毛”这样客观的描述。专业术语要解释清楚，让读者能看懂。

第三环节：作后评改——查准确，评清楚

1. 同桌互读互查

交换读习作，读完说说：你了解这种事物了吗？哪里写得最清楚？有没有什么地方看不懂？信息准确吗？

2. 自我修改

检查：说明方法运用恰当吗？信息准确吗？语言是否准确简洁？有没有把几个方面分段写清楚？根据同桌反馈进行修改。

3. 全班“事物博览会”

将全班习作按事物类别分组展示，如动物组、植物组、科技产品组、美食组等。同学们自由阅读，投票评选“最让我长知识的介绍”。引导从“内容清楚、方法恰当、语言准确”等方面进行点评。

### 四、评价标准参考

1. 基础过关：能介绍一种事物的基本特点，语句通顺。

2. 良好达标：能从几个方面有条理地介绍，运用了一两种说明方法，语言比较准确。

3. 优秀进阶：内容具体清楚，说明方法运用恰当多样，语言准确简洁，条理清晰，有知识性。

## 五年级上册·第六单元 习作《我想对您说》

```meta
册: 五年级上册
任务: 第六单元 习作《我想对您说》
文体: 书信·真情
关键词: 心里话 父母 沟通
分级: L5
```

### 一、习作要求（教学目标）

1. 用书信的形式表达心声：能以书信的形式，向爸爸、妈妈或其他自己信任的人，倾诉自己最想说的话。

2. 表达真情实感：能敞开心扉，写出自己真实的心里话，可以是感恩、建议、委屈、心愿等。

3. 用具体事例支撑情感：在表达某种感情或想法时，能用具体的事例来支撑，让情感有依托。

4. 注意书信的语言得体：在表达真实想法时，注意语气恰当，尊重长辈，做到真诚而不失礼。

### 二、教学重难点

重点：引导学生用书信的形式，敞开心扉写出真情实感。

难点：帮助学生在表达真实想法的同时把握好分寸，做到既真诚又得体，书信格式正确。

### 三、教学建议（核心教学环节）

第一环节：作前指导——敞心扉，选话题

1. 创设温馨氛围，引出心里话

老师可以先分享自己在成长中有没有特别想对父母说却一直没有说出口的话，营造真诚、安全的表达氛围。引导学生明白，每个人心里都有一些特别想对某人说的话，有些是感恩的话，有些是心里的小委屈，有些是小小的建议，有些是藏在心底的愿望。把它们写下来，是一种很好的沟通方式。

2. 选定倾诉对象

引导学生确定这封信写给谁。通常是写给爸爸妈妈的，也可以是写给其他亲近信任的人，如爷爷奶奶、老师、好朋友等。选定后想一想：这个人平时对你怎么样？你们之间最难忘的是什么？

3. 确定想说的内容

引导学生从不同角度想自己最想说的话：回忆感动的事（他为你做了什么让你特别感动的事，你想对他说声谢谢）、提出小小的建议（你有没有希望他改掉的某个小习惯，如少抽烟、少看手机、多一些陪伴等）、说出心里的小委屈（有没有被误解的时候，一直没有机会说清楚）、表达自己的心愿（你希望他能支持你做什么，或者你希望你们之间能怎样更好地相处）。选定一两个最想说的话题，不要太散。

4. 为心声寻找事例

如果是要感谢，就要想到一件具体的事；如果是提建议，也要想到一个具体的场景。心里话有具体的事例作支撑，才会更有力量。在小组内可以简单说说自己准备写什么，互相鼓励。

第二环节：作中指导——用书信，说心里话

1. 明确习作要求

写一封信给爸爸、妈妈或其他人。用书信的格式。写出自己最想说的心里话。用具体的事例来表达感情。语气真诚得体。语句通顺，有真情实感。

2. 指导书信格式

复习四年级学过的书信格式：称呼顶格、问候语空两格、正文分段写、祝福语分两行、署名和日期在右下方。写信的对象是长辈时称呼和祝福语要注意礼貌。

3. 指导写作结构

提供参考结构：开头用问候语和简单的引入，如“今天我想借这封信对您说说我的心里话”。中间分段写一两件具体的事，在事中融入自己真实的想法和感受。结尾再次表达情感，写下祝福语、署名和日期。

4. 指导把事例写具体

每说到一件事，就把这件事的时间、地点、经过写清楚。写出对方当时做了什么、说了什么，自己的内心是什么感受。把情感附在具体的事上，不说空话。

5. 指导语气得体

在提建议或说委屈时，不要用指责的语气。可以用“我有一个小小的建议，不知道您觉得怎么样”“我知道您是为我好，但是……”这样的表达方式。真诚不等于可以不顾礼貌，尊重和真诚要兼顾。

第三环节：作后评改——读信，品真心

1. 同桌互读（如果信涉及隐私，可改为自读自查）

如果学生愿意分享，可同桌交换读。读完后说说：你感受到他的真心了吗？哪里最打动你？语气得体吗？

2. 自我修改

检查：格式正确吗？心里话写清楚了吗？有事例吗？语气合适吗？进行修改。这是一封真实的信，写好后可以考虑是否真的交给对方。

3. 全班展示（尊重隐私，自愿原则）

选择愿意分享的同学在全班朗读自己的信。引导全班同学认真倾听，尊重他人的心声。从“格式正确、事例具体、情感真挚、语气得体”等方面进行欣赏和点评。

4. 鼓励真实沟通

老师可以鼓励学生，如果愿意，可以课后把这封信真的交给收信人。有时候文字比口头表达更能把话说清楚、说完整，也许这封信能成为增进亲子或师生感情的桥梁。

### 四、评价标准参考

1. 基础过关：书信格式基本正确，写出了想说的心里话，语句通顺。

2. 良好达标：格式正确，心里话清楚，有具体的事例，语气比较得体。

3. 优秀进阶：格式规范，事例具体感人，情感真挚动人，语气真诚得体，体现了书信沟通的独特价值。

## 五年级上册·第七单元 习作《____即景》（2026 秋教材换新 · 已停用）

```meta
册: 五年级上册
任务: 第七单元 习作《____即景》
文体: 写景·动态
关键词: 即景 变化 顺序
分级: L5
```

### 一、习作要求（教学目标）

1. 观察一种自然现象或自然景观：能选择一种短时间内发生在眼前的自然现象或景观，如日出、日落、下雨、起雾、刮风、彩虹等。

2. 按一定顺序写出景物的变化：能按照时间顺序或空间顺序，把景物在短时间内发生的变化过程写清楚。

3. 写出景物的动态美：能通过细致的观察，捕捉景物在变化过程中的动态之美，把变化写具体。

4. 融入自己的感受：在写景的过程中，自然融入自己观察时的感受和联想，让景物描写有情有味。

### 二、教学重难点

重点：指导学生按顺序观察并写出景物的动态变化过程。

难点：帮助学生在短时间内捕捉到景物的细微变化，并用准确生动的语言表达出来。

### 三、教学建议（核心教学环节）

第一环节：作前指导——细观察，捕变化

1. 理解“即景”，明确写作对象

引导学生理解“即景”的意思：就是眼前的、当下正在发生的景物变化。“即景”写的是短时间内景物在眼前的变化过程，比如太阳慢慢升起、乌云聚集然后下雨、雾渐渐散开等。确定写作对象：可以是教材提示的“雨中即景”“日落即景”“田野即景”“窗外即景”等，也可以自己选择。

2. 提前布置观察任务

课前让学生有意识地观察一种自然现象的变化过程，或者回忆自己印象最深的一次观察。观察时要注意：景物的变化是从什么开始的？中间经过了哪些阶段？最后变成了什么样？每一个阶段景物有什么不同的样子？可以用简单的笔记记录变化的过程。

3. 理清变化顺序

在课堂上引导学生回忆或整理观察到的变化顺序。例如日落即景可以整理为：太阳西斜——靠近地平线——半张脸看不见——完全落下——天空颜色变化。把变化的过程分成几个阶段，每个阶段一个画面，写作的顺序就有了。

4. 聚焦动态，发现美

引导学生关注景物在变化中表现出来的动态美。追问：颜色是怎么一点一点变的？形状是怎样慢慢改变的？声音有什么变化？周围其他景物有什么反应？把动态写出来，“即景”的味道就出来了。

第二环节：作中指导——按顺序，写变化

1. 明确习作要求

把题目补充完整。按照一定的顺序写出景物的变化过程。把景物的动态变化写具体。融入自己的感受。语句通顺，语言优美。

2. 指导写作结构

提供参考结构：开头交代观察的是什么即景，在什么时间、什么地点。中间按变化顺序分段写景物的变化过程，一个阶段写一段。每个阶段写出景物的样子、颜色、声音等方面的变化。结尾写出观察结束后的感受和联想。

3. 指导写好动态变化

这是本次习作的关键。用上表示变化的词语，如“渐渐地”“慢慢地”“忽然”“不一会儿”“紧接着”等来连接变化的各个阶段。用准确的动词写出景物的动态，如“云涌上来了”“雨点落下来了”“雾散开了”“太阳探出了头”。用上色彩变化的描写，如“天空由深蓝变成了橘红，又变成了紫红色”。

4. 指导融入感受

在写景的过程中，自然地写一点自己的反应和感受，如“我不由得屏住了呼吸”“我忍不住惊叹大自然的奇妙”。这些感受让景物描写有了人的温度。

第三环节：作后评改——读变化，赏动态

1. 同桌互读

交换读习作，读完后说说：你能跟着他的描写想象出景物变化的过程吗？哪里写得最有画面感？

2. 自我修改

检查：变化的顺序清楚吗？动态写出来了吗？有没有融入自己的感受？进行修改。

3. 全班展示

选几篇写不同“即景”的习作在全班展示。可以配上同主题的图片或音乐。引导从“顺序清楚、动态生动、语言优美、有感受”等方面进行欣赏和点评。老师总结：大自然的美稍纵即逝，用文字把它定格下来，是一种了不起的本领。

### 四、评价标准参考

1. 基础过关：能按顺序写出景物的大致变化，语句通顺。

2. 良好达标：顺序清楚，能写出景物的动态变化，语言比较生动。

3. 优秀进阶：变化层次分明，动态描写具体生动，语言优美有画面感，融入了自己的真实感受。

## 五年级上册·第八单元 习作《推荐一本书》

```meta
册: 五年级上册
任务: 第八单元 习作《推荐一本书》
文体: 推荐·理由
关键词: 推荐 书 理由
分级: L5
```

### 一、习作要求（教学目标）

1. 选择一本自己读过的好书来推荐：能从自己读过的课外书中，选择一本最想推荐给同学的书。

2. 写清楚书的基本信息：能写出书名、作者、出版社等基本信息，让读者对书有一个基本了解。

3. 写出推荐理由：能从内容、人物、语言、思想等多个角度，写出推荐这本书的具体理由。

4. 激发读者的阅读兴趣：推荐语有吸引力，能让读者读了之后产生去读这本书的欲望。

### 二、教学重难点

重点：指导学生从多个角度写出推荐理由，把理由写具体、有说服力。

难点：帮助学生在介绍书的内容时做到既吸引人又不剧透太多，把握好分寸。

### 三、教学建议（核心教学环节）

第一环节：作前指导——选好书，理理由

1. 选定要推荐的书

引导学生回忆自己读过的课外书中，哪一本是特别想推荐给同学读的。提醒可以是文学名著、科幻小说、历史故事、科普读物、人物传记等各种类型的书。选定后写下书名、作者、出版社等基本信息。

2. 多角度思考推荐理由

引导学生从不同角度来思考这本书为什么值得推荐：内容方面（书讲了什么故事或什么知识？最精彩或最让你印象深刻的是什么？）、人物方面（书中有没有让你特别喜欢或敬佩的人物？为什么？）、语言方面（书的语言有什么特点？是幽默风趣，还是优美动人，还是通俗易懂？）、思想方面（读了这本书你有什么收获或感悟？懂得了什么道理？）。让学生选择两三个最有说服力的推荐理由作为重点来写。

3. 练习写“推荐语”

用一句话或几句话写出最核心的推荐理由，这句话要能打动人、吸引人。比如“这本书让我笑到肚子疼，也让我感动得流眼泪”“如果你想知道恐龙是怎么灭绝的，这本书会给你最有趣的答案”。在小组内分享推荐语，看谁的推荐语最让人想读。

4. 注意“不剧透太多”

在介绍书的内容时，要避免把精彩情节和结局都写出来。引导学生把握介绍的度：写一点最吸引人的内容但留足悬念，如“主人公遇到了一个天大的麻烦，他是怎么解决的呢？你自己去看吧”。

第二环节：作中指导——写理由，引兴趣

1. 明确习作要求

推荐一本自己读过的好书。写清楚书的基本信息。写出具体的推荐理由。语言有吸引力，能激发别人的阅读兴趣。语句通顺，条理清楚。

2. 指导写作结构

提供参考结构：开头点出要推荐的书，用一句有吸引力的话引起读者的兴趣。中间分段写推荐理由，一条理由写一段，把理由写具体。结尾再次发出推荐或邀请，鼓励读者去读这本书。

3. 指导把推荐理由写具体

每一条推荐理由都要有具体的内容来支撑。比如推荐理由是“人物写得很生动”，就要举出书中的某个人物，说说他的特点是什么，为什么让你印象深刻。推荐理由是“语言很幽默”，就要引一小段书中的话作为例子。具体的内容让推荐更有说服力。

4. 指导写好书的内容简介

用精炼的语言介绍书的主要内容，只介绍故事的开头或大概背景，不透露高潮和结局。留足悬念，让读者想自己去读。

第三环节：作后评改——评推荐，验效果

1. 同桌互读

交换读推荐习作，读完后说说：你想去读这本书吗？哪条推荐理由最打动你？有没有什么内容让你觉得不想读了（比如剧透太多）？

2. 自我修改

检查：推荐理由够不够具体、有没有吸引力？书的内容介绍有没有剧透太多？语言够不够有号召力？进行修改。

3. 全班“好书推荐会”

举办“好书推荐会”，请几位同学在全班朗读自己的推荐。全班投票评选“最想读的书”。引导从“推荐理由具体、语言有吸引力、内容简介适度”等方面进行点评。可以将全班推荐书目汇编成班级“好书推荐单”或“阅读地图”，贴在教室里供同学们选书时参考。

### 四、评价标准参考

1. 基础过关：能写出推荐的书名和基本推荐理由，语句通顺。

2. 良好达标：能从一两个方面写出推荐理由，理由比较具体，有一定吸引力。

3. 优秀进阶：推荐理由具体充分，语言有感染力，能巧妙设置悬念，让人产生强烈的阅读欲望。
