## 一、能力进阶轴（四阶，接入全体系六阶）

老约翰写作产品线为一条贯通一至六年级的六阶总轴：第一、二阶为看图写话，第三至第六阶为同步习作，
能力主线从「说清楚·写完整」到「写清楚」「写具体·写生动」再到「写深刻·有章法」。
**「第几阶」指能力阶段，非年级。** 本文件收录第三至第六阶（同步习作）；
表中前两行为看图写话，详见《看图写话课程总地图》。

| 阶（全体系） | 能力名 | 核心能力 | 学段 |
| --- | --- | --- | --- |
| 第一阶 | 说清楚 · 写完整 | 见《看图写话课程总地图》 | 一年级 |
| 第二阶 | 写连贯 · 讲成故事 | 见《看图写话课程总地图》 | 二年级 |
| 第三阶 | 写清楚 | 敢写不畏难；围绕一个意思，把一件事/一个人/一处景写清楚、有条理 | 三年级 |
| 第四阶 | 写具体 | 调动观察与五感，把笼统换成可感的细节；按一定顺序写 | 三下—四年级 |
| 第五阶 | 写生动 | 有细节、有描写、有真情实感；视角、想象、结构开始讲究 | 四下—五年级 |
| 第六阶 | 写深刻·有章法 | 围绕中心谋篇；说理、思辨、应用文；情感与思想的表达 | 六年级 |

## 二、文体六大类

- **写人**：抓特点 → 具体事例 → 多面立体
- **写景状物**：五感写具体 → 顺序与中心 → 即景与情景交融
- **记事**：写清过程 → 写出心情 → 写出波澜与深意
- **想象**：创编完整 → 想象合理有趣 → 科幻/变形/新编
- **应用·说理**：写想法/日记/信 → 建议/倡议/读后感 → 围绕中心说理
- **观察·说明**：观察记录 → 说明一种事物 → 介绍与推荐

## 四、六条能力进阶线

同类任务跨年级抽出，每类构成一条从第三阶到第六阶的能力生长线（衔接看图写话的第一、二阶）——
这是向家长讲「体系」时最有力的一张图。**详案首页「文体线」行即取自本节**：整行照录该文体的箭头链，
当前篇在链上原样出现（docx 首页版式化时自动标红，md 侧不加任何标记）。

| 文体 | 能力生长线 |
| --- | --- |
| 写人 | 猜猜他是谁 → 身边有特点的人 → 小小动物园 / 自画像 → “漫画”老师 → 形形色色的人 |
| 写景状物 | 缤纷世界 → 这儿真美 → 我的乐园 / 动物朋友 / 游____ → 心爱之物 → ____即景 |
| 记事 | 那次玩得真高兴 → 生活万花筒 / 记一次游戏 → 我学会了 / 心儿怦怦跳 → 多彩的活动 / 围绕中心意思写 → 让真情自然流露 |
| 想象 | 续写故事 / 编童话 → 奇妙的想象 / 这样想象真有趣 → 奇思妙想 / 故事新编 → 神奇探险 / 笔尖流出的故事 → 变形记 / 插上科学翅膀 |

> 注：进阶线里的题目多为**简称**（如「缤纷世界」＝《我们眼中的缤纷世界》、「小小动物园」＝《小小“动物园”》），
> 与 §三 全表的完整题目对应；首页「文体线」行照录简称即可，不必回填全称，以免一行过长。
>
> **一处对原件的编辑**：想象线首项原件写作「续写」，此处按 §三 全表题目《续写故事》展开为「续写故事」——

> 其余各项与原件逐字一致。若某篇题目在所属线上仍以简称出现（红标落空），属预期，不得为标红而改写题目。

## 五、教研决策记录

- **能力轴**：本产品线四个能力阶段（写清楚 / 写具体 / 写生动 / 写深刻·有章法）在全体系中为第三至第六阶
  （第一、二阶为看图写话）；「第几阶」指能力阶段，非年级。
- **排课顺序**：按教材年级单元次序排（一学期 8 个任务），与校内进度同步——学校教到哪一单元，课上就练哪一篇。
- **投产范围**：只投产三至六年级 63 任务。一二年级看图写话为独立项目，不在本表。
- **六阶总轴**：看图写话为第一、二阶，同步习作为第三至第六阶，两表合为一条贯通一至六年级的能力主轴。
  全文「阶」的编号统一采用全体系口径（本产品线任务落在第三~六阶）。
