# 写作课课型结构与逐字稿格式

## 一、课型骨架(七环节,血肉层骨架)

写作课走七个环节,把四大价值观焊进流程。详细走法见 `workflow-engine.md`,此处只给骨架与各环节归属的课时。

| # | 环节 | 课时 | 价值观落点 |
|---|---|---|---|
| ① | 真实情境抛任务 | 第1节 | 真实情境 |
| ② | 全感官唤醒 | 第1节 | 全感官支架 |
| ③ | 一招技法 | 第1节 | 一课一得(底座) |
| ④ | 示范文做样 | 第1节 | 底座 |
| ⑤ | 构思支架落地 | 第1节 | 全感官支架落地 |
| ⑥ | 自由倾吐(护表达流) | 第2节 | 表达主权 |
| ⑦ | 即时反馈 + 延迟纠错 + 自然收尾 | 第2节 | 即时反馈 + 延迟纠错 |

七环节与档案「教学建议」的“作前/作中/作后”三段仍一一对应(①②③④⑤ ⊂ 作前+作中,⑥⑦ ⊂ 作中动笔+作后评改),生成时仍**以档案该任务的教学建议为内容蓝本**,只是按七环节重排节奏、注入血肉,不另起炉灶、不偏离档案的写作目标与技法。

> **附加块「习作讲评指导环节」(可选,不在七环节内):** 七环节是两节连排的核心、当堂评改闭环已完整;在此之外,每份详案末尾再**附一块可选的「习作讲评指导环节」**,供老师做⑦容不下的深度讲评(单次课课后用 / 系列课作下次课开场用)。它**不是第 8 环节、不计入 45+45**,走法见 workflow-engine.md「一之二」节,落位与格式见本文件 §三。

## 二、课时安排(固定:同次连排 2 节 × 45 分钟)

每次习作课 = **2 节课同次连排,每节 45 分钟**,中间课间休息。这是培训班的固定排课,不设单节模式、不询问。

| 节次 | 覆盖段落 | 参考切分 |
|---|---|---|
| 第 1 节(45 分钟) | 作前指导 + 作中指导(技法讲解、构思支架、示范文) | 作前约 20 分钟 / 作中约 25 分钟 |
| 第 2 节(45 分钟) | 当堂动笔完成 + 作后评改 | 动笔约 20–25 分钟 / 评改约 20–25 分钟 |

切分可依任务浮动,但**每节各环节时长合计必须 = 45 分钟**,三段总体缺一不可。

**连排约束**:
- 第 1 节课尾**不布置任何课后任务**,只收束构思成果并预告“休息回来就动笔”(口气可留悬念);第 2 节开头一句话接住(“带着你刚才填好的××,我们开写”)。
- 作品**当次完成、当次评改**,不存在“写完下周带来”。L1–L2 写话篇幅小,第 2 节动笔用时短,余量给“读一读、改一改、誊写一遍”或二次创作。
  - **“当次评改”指当堂闭环**:即时反馈(⑦)+ 带标准自改 + 同桌互改 + 老师轻点评 + 自然收尾,这一套必须在第 2 节内完成,不得推走。文末附加的「习作讲评指导环节」是**面向系列课/课后的可选深化**,评的是已当堂完成的稿,**不构成课后写作任务**(学生不回家再写),与本约束及先导红线均不冲突。
- 整篇当堂完成是默认要求;L5–L6 篇幅长确实写不完时,当堂完成核心段并评改核心段,结尾段落回家补完——这是唯一允许的课后延伸,且评改环节须围绕当堂已写部分设计。

## 二之二、先导定位(课外培训班,默认先于校内)

本课默认上在**学校讲解同一习作之前**(抢先打底)。由此三条硬规则:

1. **零预设红线**:不得预设学生已学本单元课文、已被学校指导过此题。师话严禁出现“我们课文里学过”“语文老师讲过的《XX》”类共同经验引用。档案教学建议里若依托单元课文(如“借助教材图示”“回顾本单元《XX》的写法”),改造为**自含材料**:教师当堂出示/朗读,当新材料用,或换成等效的自创情境。
2. **素材自含**:导入与例证只用当堂给得出的东西——游戏、情境、实物、图片、示范文。
3. **回校衔接(轻处理,优先自然)**:这层价值**不必每次由老师明说**——生硬的“别的同学才开始想,你已经写过一遍”读着像招生话术,味儿不对。
   - **优先**自然收尾,把“今天这件事本身的意义”讲透即可(写信课收在“真把信寄出去/送到那个人手里”、写人课收在“路上留心观察、记进心里”);“将来在校写起来更从容”的底气让学生自己体会,不必点破。
   - 确实想点校内衔接,只淡淡一句、落在“今天先认真做了一件事”;**不要**“别的同学才开始想/你比别人早一步”这类对比,也不说“拿给语文老师看”。结尾一律真诚、向着学生和作品,不向着“机构卖点”;作品收进档案、带回家、或按情境真实处理(如寄信),都比空喊衔接实在。

若用户说明该习作学校**已经讲过**(后置情况),转“提升与讲评”取向:作前压缩(快速唤起,不重复审题游戏)、技法上探到档案难点、评改加重并对照学生在校已写稿(有则用)。默认不问、按先导走。

## 三、逐字稿格式(与阅读详案同一套骨架)

全程逐字稿。固定话术骨架与 Markdown 标记沿用老约翰体系:

- 师话以 `师：` 开头;预设答案以 `参考：` 开头;学生环节写整行 `学生互动分享` / `学生自由分享` / `学生动笔写作`;小结用 `（教师总结）`。
- 文档主标题 `#`;课时标题固定两个:`## 第1课时 · 写作指导课（作前·作中）` 与 `## 第2课时 · 当堂写作与评改课`;环节 `### 一、…（X分钟）`。
- **环节标题须专业平实(硬规则,违反返工)**:`### 一、…` 的标题要写成**一线语文教案那样的教学环节名**(动宾或并列短语,如“创设情境,明确任务”“观察体验,调动感官”),**严禁照搬本 skill 内部的七环节工作名**——`真实情境抛任务 / 全感官唤醒 / 一招技法 / 示范文做样 / 构思支架落地 / 自由倾吐 / 即时反馈+延迟纠错+自然收尾` 是写给生成器看的“价值观工作名”,带 AI/教研黑话味,**不是给老师看的标题**。推荐对照(可按本课技法点微调,不必逐字照抄):

  | 内部环节(workflow-engine 的工作名) | 详案里的专业标题(示例) |
  |---|---|
  | ① 真实情境抛任务 | 创设情境,明确任务 |
  | ② 全感官唤醒 | 观察体验,调动感官 |
  | ③ 一招技法 | 习得写法:〈本课主技法〉(如“围绕一个意思写”) |
  | ④ 示范文做样 | 出示示范文,发现写法(或“教师出示样稿”) |
  | ⑤ 构思支架落地 | 借助〈构思工具名〉,理清思路(如“借助观察表,理清思路”) |
  | ⑥ 自由倾吐 | 自由写作(写话课可作“写一写”) |
  | ⑦ 即时反馈+延迟纠错+自然收尾 | 交流评议,修改收束 |

  这条与本节「语言风格红线」一脉相承——标题层同样不要学术黑话;同理,`【知识技能】/【过程方法】/【情感价值】` 标签、`师：/参考：` 等固定话术骨架是体系既定符号,不在此列、保持原样。
- 三维目标条:`【知识技能】…` `【过程方法】…` `【情感价值】…`。
- 构思工具表/评价量表用标准 Markdown 表格(`|` 分隔,空格留空,单元格内换行 `<br>`)。
  - **填写型表格(构思工具表等)必须给“两格都填”的真表头(硬规则)**:首行写成 `| 项目 | 关键词 |` 这类两列均非空的表头,字段(如“这儿是哪里”“中心句”)放到表头下面的数据行去。**切勿把首个字段当首行、右格留空**(写成 `| 这儿是哪里 |  |`)——排版引擎会把“首格有内容、其余格全空”的首行当成**合并标题横幅**渲染、并把第一列强制压到 1.6cm,结果是该字段变成居中横幅、丢掉它本该留给学生填写的空格,且后续标签被挤窄换行。空白版与教师示范版两张表要用**同一套表头与字段行**,保持一一对应。
- 示范文用 `> ` 引用块,文首标 `【教师示范文】`(详见 model-essay.md)。
- 每课时末写 `本课完。`,两节正文末写 `全课完。`。
- **附加块「习作讲评指导环节」的落位**:置于 `全课完。` **之后**、文件尾 `VARIATION-FINGERPRINT` 指纹注释**之前**,作为详案的可选附加章节。用 `## ` 章节标题,标题须标明其“可选、两用”属性,例如:`## 附:习作讲评指导环节(单次课可选用 / 系列课作下次课开场)`。该块内容(选稿/围绕技法/一篇一肯定一改处/占位槽不捏造学生作品)走 workflow-engine.md「一之二」节;块内仍守弯引号、无星号、机构不拟人、固定话术骨架等全部格式硬规则。docx 引擎把它当普通 `##` 章节渲染,无需特殊处理。
- **中文引号规范(硬规则)**:详案正文一律使用全角弯引号——外层 `“”`、内层 `‘’`,**严禁**在中文语境使用半角直引号 `"` `'`,全文不得混用两种引号。半角符号仅允许出现在 Markdown 语法、行内代码、英文文件名/路径处。排版引擎虽有交替式安全网会补转 ASCII 直引号,但对跨行、奇数个、弯直混排会判错方向,**不可托底**;引号必须在 .md 阶段就写对,交付前全文检索 `"` 与 `'` 自查。
- **行内强调禁令(硬规则)**:详案正文**严禁使用 `**`、`*`、`__` 等行内强调标记**——单星/单下划线斜体 `*…*`、`_…_` 引擎不解析、会原样印进 docx;成对 `**` 虽会被引擎转成加粗,但本 skill 一律不用(三维目标等小标题用 `【】`标签与固定话术骨架承载),保证详案检索 `*` 为零。这条覆盖一切位置:师话、参考、示范文、表格单元格、习作要求,无一例外。需要强调时靠话术本身(重复、设问、停顿提示如“——”),或交给 PPT 锚点呈现。注意:本 skill 各规则文件里的加粗是写给生成者看的规则强调,**不是**详案可用的标记,不得模仿进产物。交付前全文检索 `*` 自查,应为零。
  - **填空横线写法(配套约定)**:讲评模块占位、师话里让学生口头补全的横线等,**需要“填空横线”时一律用全角 `＿`(U+FF3F)、不要用 ASCII 下划线 `_`**——连写的 `______` 会被引擎当成成对 `__` 加粗标记、整段剥除,横线在 docx 里凭空消失,且违反上一条 `__` 禁令。横线旁可附 `(占位:…)` 说明老师填什么。交付前全文检索 ASCII `_` 应为零(Markdown 语法/英文路径除外)。
- **机构名不拟人(硬规则)**:“老约翰”是机构名,不是教师名。师话中教师一律自称“老师”,**严禁**出现“老约翰说”“老约翰老师”“我是老约翰”等把机构当作授课人的称呼。机构名只允许出现在文档头部/页眉等品牌信息位,不进入任何教学话术。
- **语体分层(硬规则)**:详案内含两套语体,各守各的口径,不得串味。
  - **师话层**(`师：`、`参考：`、`学生互动分享` 等讲给学生听的内容):**亲切、具体、面向小学生**——可用**贴切的比喻**(“这块磁铁吸得过来的写”)、必要的拟声词(“咯吱咯吱”)把抽象技法讲得好懂,不写成教研论文式术语;但用词仍须**专业平实**,不堆砌市井/网络口语(见下「语言风格红线」),“技法”就叫“技法/方法/要点”,不说“小妙招”。
  - **提示层**(方括号舞台提示 `[…]`、括号旁注如 `(教师巡视时…)`、巡视说明:**写给授课老师看、要被另一位老师照做的内容**;注意逐环节价值观自注 `(此处落实…)` 已整类删除,不属此层):一律用**清楚、专业、可执行的规范指导语**,**严禁**口语化随意词。典型反例及改法:`递话`→`提示/介入`;`喂具体`→`提供具体素材提示/引导落到具体景物`;`让路`→`不打断、为其留出书写空间`。判据一句话:这句是“讲给学生听的”还是“讲给老师做的”——前者可口语,后者须规范。
  - 自检:交付前快速扫一遍所有 `[…]` 与 `(…)`,凡含义含糊或口语随意的指导动词,改为明确动作描述;`（教师总结）` 等固定话术骨架属师话层,不在此列、不得改写。
- **语言风格红线(硬规则 · 专业且平实,规范且易懂)**:全文(师话层与提示层)用词守住“专业平实、规范易懂”这条中线——**既不市井江湖、也不晦涩学术**,像一位有经验的老师在跟同行平实交代这节课怎么上、跟学生把方法讲清楚。三条边界:
  1. **禁市井化与网络口语**:不用“写嗨了”“卡壳了”“命根子”“主菜”“小妙招”“炒菜/食材”这类非正式词;也不把“兜底”作为详案里的字面用词(“兜底”是 skill 内部机制名,如“未读兜底/通用兜底”,**不得原样落进详案产物**)。
  2. **禁晦涩学术词汇**:不用“学习支架”“知识建构”“学情干预”“最近发展区”“多模态”等过度理论化术语(内部档位词如“A 档”本就禁入正文,见 technique-levels.md)。
  3. **改用中性、准确的实操词**,常见对照:

  | 详案里禁用(市井/网络) | 改用(规范业务词) |
  |---|---|
  | 兜底 | 基础辅导预案 / 补充引导 |
  | 卡壳了 / 卡住 | 无从下笔 / 起步困难 |
  | 写嗨了 / 写得起劲 | 书写顺畅 / 已顺利完成 |
  | 命根子 / 主菜 | 关键环节 / 重点内容 / 核心 |
  | 小妙招 | 方法 / 要点 / 步骤指引 |
  | 递素材 / 喂具体 | 提供具体素材提示 / 思路引导 |
  | 让路 | 不打断、留出书写空间 |
  | 学习支架 | 构思引导 / 思路引导 |
  | (抛任务的)情境 | 情境描述 / 真实情境 |

  > 红线针对的是**市井 slang 与学术黑话两个极端**,不是要把师话改成干巴术语:师话层仍可亲切、可打**贴切**比方(磁铁、钩子这类干净比喻保留);提示层则一律用上表右栏的规范实操词。自检见 checklist.md E 组。

> 详细排版语义与 .docx 导出共用 `laojohn-lesson-plan/assets/课案Markdown约定规范.md` 与其排版引擎——两个 skill 的产物走同一条排版流水线。

## 四、书级头部(每份详案最前面附一次)

1. **教案提纲表**(七项,沿用阅读详案表式,字段改为):习作任务 / 年级与分级 / 文体 / 课时安排(固定填“2 节 × 45 分钟,同次连排”) / 本节技法点 / 构思工具(可视化) / 评价方式。(字段名用“构思工具”而非“构思支架”——“支架”属教研术语,见 §三标题专业平实规则;内部概念仍可叫“构思支架”,但提纲表这一对外字段用平实说法。)
2. **任务背景一句话**:本任务在教材中的位置与定位(取自档案,如“三年级上册第一单元,从写话到习作的第一篇”),并注明“本课为先导课,上在校内讲解之前”。
3. **三维教学目标**:依据档案「习作要求(教学目标)」改写成三维条目,不得超出档案要求的能力上限。

## 五、教学流程(血肉层 → 见 workflow-engine.md)

教学流程的具体走法由 **`references/workflow-engine.md`** 规定,那是强制骨架,生成时必读、逐环节照走。它把四大设计价值观(真实情境 / 全感官支架 / 即时反馈 / 表达主权与延迟纠错)焊进固定七环节:

第 1 节:① 真实情境抛任务 → ② 全感官唤醒 → ③ 一招技法 → ④ 示范文做样 → ⑤ 构思支架落地
第 2 节:⑥ 自由倾吐(护表达流、零打断纠错)→ ⑦ 即时反馈 + 延迟纠错修改 + 自然收尾

本节(课型骨架、课时、先导、格式、书级头部)是**底座**,与引擎不冲突;冲突时以底座为准。底座仍要求:每段在师话/技法讲解里显性点出本节训练点(把“今天练的是……”讲给学生听),但**不写“(此处落实……)”这类括号自注标签**——逐环节括号自注已整类删除(见 workflow-engine.md 环节① / checklist.md H 组 / variation-pools.md 表层指纹一节);第 1 节尾不留课后任务;作品当次完成当次评改(教师课后精批属允许的额外动作,但不得表述成“写不完带回家写完”)。
