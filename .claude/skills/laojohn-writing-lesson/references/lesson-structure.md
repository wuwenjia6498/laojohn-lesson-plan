# 写作课课型结构与逐字稿格式

## 一、课型骨架(七环节,血肉层骨架)

写作课走七个环节,把四大价值观焊进流程。详细走法见 `workflow-engine.md`,此处只给骨架与各环节归属的课时。

| # | 环节 | 课时 | 价值观落点 |
|---|---|---|---|
| ① | 真实情境抛任务 | 第1节 | 真实情境 |
| ② | 全感官唤醒 | 第1节 | 全感官支架 |
| ③ | 一招技法(开头含「审题辨析」固定半步,见 workflow-engine 环节③) | 第1节 | 技法克制(底座) |
| ④ | 示范文做样 | 第1节 | 底座 |
| ⑤ | 构思支架落地 | 第1节 | 全感官支架落地 |
| ⑥ | 自由倾吐(护表达流;开场含起步半环——L1–L4「降压起步」／L5–L6「定起点」,见 workflow-engine.md 环节⑥-起步) | 第2节 | 表达主权 |
| ⑦ | 即时反馈 + 延迟纠错 + 自然收尾 | 第2节 | 即时反馈 + 延迟纠错 |

七环节与档案「教学建议」的“作前/作中/作后”三段仍一一对应(①②③④⑤ ⊂ 作前+作中,⑥⑦ ⊂ 作中动笔+作后评改),生成时仍**以档案该任务的教学建议为内容蓝本**,只是按七环节重排节奏、注入血肉,不另起炉灶、不偏离档案的写作目标与技法。

> **附加块「习作讲评指导环节」(可选,不在七环节内):** 七环节是两节连排的核心、当堂评改闭环已完整;在此之外,每份详案末尾再**附一块可选的「习作讲评指导环节」**,供老师做⑦容不下的深度讲评(单次课课后用 / 系列课作下次课开场用)。它**不是第 8 环节、不计入 45+45**,走法见 workflow-engine.md「一之二」节,落位与格式见本文件 §三。

## 二、课时安排(固定:同次连排 2 节 × 45 分钟)

每次习作课 = **2 节课同次连排,每节 45 分钟**,中间课间休息。这是培训班的固定排课,不设单节模式、不询问。

| 节次 | 覆盖段落 | 参考切分 |
|---|---|---|
| 第 1 节(45 分钟) | 作前指导 + 作中指导(技法讲解、构思支架、示范文) | 作前约 20 分钟 / 作中约 25 分钟 |
| 第 2 节(45 分钟) · L1–L4 | 当堂动笔完成 + 作后评改 | 降压起步约 5 分钟 / 自由写作约 17 分钟 / 评改约 23 分钟 |
| 第 2 节(45 分钟) · **L5–L6** | 同上 | **定起点约 3–4 分钟 / 自由写作 25 分钟以上 / 评改约 16–17 分钟** |

切分可依任务浮动,但**每节各环节时长合计必须 = 45 分钟**,三段总体缺一不可。

> **L5–L6 切分要前重后轻(2026-08-30 用户拍板 · 上表第二行已写死基线)**:L5 整篇约 450–500 字、L6 约 500–600 字+,⑥净书写(起步落笔+续写)不足 25 分钟,慢的孩子当堂写不完(阈值见 review-rubric.md 维四)。**自由写作 25 分钟以上是硬下限**,分钟从两处腾:① 起步半环压到 3–4 分钟——它在 L5–L6 已由「降压起步」改判为「定起点」(先判断从哪儿起笔、再落笔写这一处),本就不需要 5 分钟;② 评改压到 16–17 分钟。仍不够时按下条「核心段当堂完成并评改、结尾段回家补完」处理。**不要套用 17 分钟。****唯一例外**:本课篇幅要求明显低于该级常规的任务(如五上《缩写故事》,缩写本就要求压短)按实际字数折算,但须注明理由、不得默认放宽。
>
> **L6 另放行一档**:起步那几分钟**可并入自由写作、不单列 `###`**(见下 §三环节序号条与 workflow-engine.md 环节⑥-起步改判块),此时第 2 节只有两个环节,自由写作标称须把这几分钟含进去(≥ 28 分钟左右)。

**连排约束**:
- 第 1 节课尾**不布置任何课后任务**,只收束构思成果并预告“休息回来就动笔”(口气可留悬念);第 2 节开头一句话接住(“带着你刚才填好的××,我们开写”)。
- 作品**当次完成、当次评改**,不存在“写完下周带来”。L1–L2 写话篇幅小,第 2 节动笔用时短,余量给“读一读、改一改、誊写一遍”或二次创作。
  - **“当次评改”指当堂闭环**:即时反馈(⑦)+ 带标准自改 + 同桌互改 + 老师轻点评 + 自然收尾,这一套必须在第 2 节内完成,不得推走。文末附加的「习作讲评指导环节」是**面向系列课/课后的可选深化**,评的是已当堂完成的稿,**不构成课后写作任务**(学生不回家再写),与本约束及连排约束均不冲突。
- 整篇当堂完成是默认要求;L5–L6 篇幅长确实写不完时,当堂完成核心段并评改核心段,结尾段落回家补完——这是唯一允许的课后延伸,且评改环节须围绕当堂已写部分设计。

## 二之二、课时定位(中性校内同步课)

本课是**校内同步习作课**,默认**中性定位**:不假设学生已学/未学本单元课文,也不假设是否已被学校指导过此题。课文与已学内容可自然引用作范例。由此两条与定位无关、但因课时结构与语气需要而保留的硬规则:

1. **连排内自含(课时结构,非先导)**:本课是单次两节连排(2 × 45),无法布置长周期准备。导入与例证只用当堂给得出的东西——游戏、情境、实物、图片、示范文、课文片段。档案教学建议里若依托校内长周期活动(如“提前一周观察”“课前带实物”“综合性学习成果展”),改造成**单次两节课内自含**的形态(用强视觉素材/课堂微观察/回忆唤醒替代长周期准备),但保留其真实内核;若依托单元课文,**可直接当堂出示/朗读作范例**,不必再绕成“自创情境”。
2. **收尾真诚、不喊机构卖点(语气护栏)**:这与定位无关,是语气底线——
   - **优先**自然收尾,把“今天这件事本身的意义”讲透即可(写信课收在“真把信寄出去/送到那个人手里”、写人课收在“路上留心观察、记进心里”)。
   - **不要**“别的同学才开始想/你比别人早一步”这类对比话术,也不说“拿给语文老师看”;结尾一律真诚、向着学生和作品,不向着“机构卖点”;作品收进档案、带回家、或按情境真实处理(如寄信),都比空喊衔接实在。

若用户说明该习作学校**已经讲过**,可转“提升与讲评”取向(可选,非默认二分):作前压缩(快速唤起,不重复审题游戏)、技法上探到档案难点、评改加重并对照学生在校已写稿(有则用)。默认不问、按中性同步课走。

## 三、逐字稿格式(与阅读详案同一套骨架)

全程逐字稿。固定话术骨架与 Markdown 标记沿用老约翰体系:

- 师话以 `师：` 开头;预设答案以 `参考：` 开头;学生环节写整行 `学生互动分享` / `学生自由分享` / `学生动笔写作`;小结用 `（教师总结）`。
- 文档主标题 `#`:固定写成 `# 《题目》· 写作课教学设计`(题目带书名号、不带年级册;用“教学设计”,不用“详案/教案”);**紧接下一行、中间不空行**写副标题 `<年级册次>·<单元> 校内同步写作（<体裁>）`(如 `三年级上册·第一单元 校内同步写作（写人习作）`;年级册次与单元之间用全角 `·` 紧连,其后空一格接“校内同步写作”;体裁括注可选,无则省)——引擎把 H1 后紧邻的非标记行渲染为居中副标题,中间留空行副标题会失效。课时标题固定两个:`## 第1课时 · 写作指导课` 与 `## 第2课时 · 当堂写作与评改课`;环节 `### 一、…（约 N 分钟）`(时长与标题长度格式见下条)。
  - **环节序号按课时各自从「一」重起(硬规则,不跨课时连续编号)**:第1课时五个环节编「一」到「五」;第2课时**重新从「一」起**——`### 一、〔起步半环平实环节名:L1–L4 如“借助构思表,写下第一组句子”／L5–L6 如“看着构思表,定下从哪儿起笔”〕（约 5 分钟／L5–L6 约 3 分钟）` → `### 二、自由写作（约 N 分钟）` → `### 三、交流评议,修改收束（约 N 分钟）`。读者每进一个新课时,序号都从「一」开始,符合一线教案“每课时各自成篇”的习惯。**唯一例外:L6 可把起步半环并进自由写作、不单列**(2026-08-30 放行),此时第2课时只有两个环节——`### 一、自由写作（约 N 分钟）` → `### 二、交流评议,修改收束（约 N 分钟）`;并入不等于取消,三件套(锚定旧知/判断定起点/落笔)照写在自由写作开头,详见 workflow-engine.md 环节⑥-起步。**L5 仍须单列。**(七个价值观工作环节 ①–⑦ 是另一套贯穿两课时的内部连续编号,只写给生成器看、不进详案;别把它和详案里按课时重起的 `### 一、二、` 混为一谈。)
- **环节时长与环节名长度(硬规则)**:时长一律写作 `（约 N 分钟）`——带「约」字、阿拉伯数字两侧各一个半角空格、中文圆括号;`（8分钟）`、`（8 分钟）`、`（约8分钟）` 三种写法**均不合规**。区间写 `（约 3–5 分钟）`,范围连接号用 `–`(不写 3 到 5、不写 3-5)。**环节名内不得夹带教学预案、压缩方案等长说明**——标题只留「环节名（约 N 分钟）」;`｜可压缩：……` 这类整段说明须移出标题,放到该环节正文第一行作引用块批注 `> **可压缩预案**：…`(说明文字原样搬运,只改位置与前缀,不改写不删减)。完整体例见 `title-naming.md`。
- **环节标题须专业平实(硬规则,违反返工)**:`### 一、…` 的标题要写成**一线语文教案那样的教学环节名**(动宾或并列短语,如“创设情境,明确任务”“观察体验,调动感官”),**严禁照搬本 skill 内部的七环节工作名**——`真实情境抛任务 / 全感官唤醒 / 一招技法 / 示范文做样 / 构思支架落地 / 自由倾吐 / 即时反馈+延迟纠错+自然收尾` 是写给生成器看的“价值观工作名”,带 AI/教研黑话味,**不是给老师看的标题**。推荐对照(可按本课技法点微调,不必逐字照抄):

  | 内部环节(workflow-engine 的工作名) | 详案里的专业标题(示例) |
  |---|---|
  | ① 真实情境抛任务 | 创设情境,明确任务 |
  | ② 全感官唤醒 | 观察体验,调动感官 |
  | ③ 一招技法(开头含「审题辨析」固定半步) | 学写法:〈本课主技法〉(如“围绕一个意思写”) |
  | ④ 示范文做样 | 出示示范文,发现写法 |
  | ⑤ 构思支架落地 | 借助〈构思工具名〉,理清思路(如“借助构思表,理清思路”) |
  | ⑥-起步 衔接落笔(第2节开场半环) | 按平实教案式环节名:**L1–L4「降压起步」**如“借助构思表,写下第一组句子”“先说一句,再落笔”;**L5–L6「定起点」**如“看着构思表,定下从哪儿起笔”“先挑一处,再落笔”。其行为支架方法(盯住一处看清/闭眼回想/限时快写)照用,但**不以游戏化叫法做标题**——亲切具体即可,直说方法本身、不裹比喻。(L6 并入自由写作时无此标题) |
  | ⑥ 自由倾吐 | 自由写作(写话课可作“写一写”) |
  | ⑦ 即时反馈+延迟纠错+自然收尾 | 交流评议,修改收束 |

  **「审题辨析」不单列环节标题**:它是③环节 `### 学写法…` 内部的开场首段(固定半步,见 workflow-engine 环节③),**不单列 `###`、不占课时内的环节序号**;详案里以平实说法(如“判断哪段切题”“审清题目要求”)出现在③的师话开头,无需为它另起一个「一、二、」。

  这条与本节「语言风格红线」一脉相承——标题层同样不要学术黑话;同理,`师：/参考：/（教师总结）` 等固定话术骨架是体系既定符号,不在此列、保持原样。
- 构思工具表/评价量表用标准 Markdown 表格(`|` 分隔,空格留空,单元格内换行 `<br>`)。
  - **填写型表格(构思工具表等)必须给“两格都填”的真表头(硬规则)**:首行写成 `| 项目 | 关键词 |` 这类两列均非空的表头,字段(如“这儿是哪里”“中心句”)放到表头下面的数据行去。**切勿把首个字段当首行、右格留空**(写成 `| 这儿是哪里 |  |`)——排版引擎会把“首格有内容、其余格全空”的首行当成**合并标题横幅**渲染、并把第一列强制压到 1.6cm,结果是该字段变成居中横幅、丢掉它本该留给学生填写的空格,且后续标签被挤窄换行。空白版与教师示范版两张表要用**同一套表头与字段行**,保持一一对应。
- 示范文用 `> ` 引用块,文首标 `【教师示范文】`(详见 model-essay.md)。
- 每课时末写 `本课完。`,两节正文末写 `全课完。`。
- **附加块「习作讲评指导环节」的落位**:置于 `全课完。` **之后**、文件尾 `VARIATION-FINGERPRINT` 指纹注释**之前**,作为详案的可选附加章节。用 `## ` 章节标题,标题须标明其“可选、两用”属性,**固定写成**:`## 附：习作讲评指导环节（可选 · 单次课课后用 / 系列课作下次课开场用）`(全角冒号与括号,措辞全线统一,不得自拟变体;逐字体例的唯一源见 title-naming.md §四)。该块内容(选稿/围绕技法/一篇一肯定一改处/占位槽不捏造学生作品)走 workflow-engine.md「一之二」节;块内仍守弯引号、无星号、机构不拟人、固定话术骨架等全部格式硬规则。docx 引擎把它当普通 `##` 章节渲染,无需特殊处理。
  - **写成「三段式逐字稿」、不写干巴方法清单**:`## 附：…` 头部先用 blockquote 写两句(说明:可灵活取用+两用+不计入45+45 / 真实性占位提示),正文分**三节逐字稿**——`### 选稿（课前准备）`、`### 讲评流程（每篇约 3–5 分钟，围绕本课技法点）`、`### 收尾（点回技法、引向今后的写作）`(全角标点,三节标题与括注全线统一、不得自拟),讲评流程里逐篇用 `师：` 师话 + 全角 `＿＿＿` 占位 + `(教师总结)`/`学生互动分享` 骨架,末尾 `本环节完。`(详细写法见 workflow-engine.md「一之二」,成稿样例见 `写作课详案输出/三上-第六单元-这儿真美-写作课详案.md`、`三上-第一单元-猜猜他是谁-写作课详案.md`)。
  - **附加块不参与教学环节序号**:它不是「环节」,三节小标题用**无序号描述性 `### 标题`**(选稿/讲评流程/收尾),**一律不冠 `### 一、二、三`**(否则会与第2课时重起后的「一、二、三」撞号、读着像又冒出一组一二三)。
- **中文引号规范(硬规则)**:详案正文一律使用全角弯引号——外层 `“”`、内层 `‘’`,**严禁**在中文语境使用半角直引号 `"` `'`,全文不得混用两种引号。半角符号仅允许出现在 Markdown 语法、行内代码、英文文件名/路径处。排版引擎虽有交替式安全网会补转 ASCII 直引号,但对跨行、奇数个、弯直混排会判错方向,**不可托底**;引号必须在 .md 阶段就写对,交付前全文检索 `"` 与 `'` 自查。
- **中文标点全角规范(硬规则)**:详案正文标点一律全角——逗号 `，`、冒号 `：`、问号 `？`、叹号 `！`、分号 `；`、圆括号 `（）`,**严禁**在中文语境使用半角 `,` `:` `?` `!` `;` `(` `)`（句号除外:中文句末用全角 `。`,半角 `.` 因小数/序号/英文歧义大、不强制转;HTML 注释 `<!--`、图片 `![` 等 Markdown 语法里的半角符号靠上下文判定自动豁免）。固定话术骨架 `师：`/`参考：`/`（教师总结）` 的冒号、括号同此。非标点符号保留原样、不在转换之列:数字范围用 `–`(如“3–4 人”)、流程箭头 `→`(如“远→近”)、并列斜杠 `/`(如“看/听/闻”)、乘号 `×`、全角竖线 `｜`;Markdown 语法、行内代码、英文路径处的半角符号亦不动。与上「中文引号规范」一脉,半角标点须在 .md 阶段就写对,交付前全文检索半角 `,:?;()` 应为零(扣除上述豁免)。**适用范围 = 初稿 + 此后每一次局部增改**,改一处就地重扫,不因“只是小修”跳过。

  - **括号家族分工:「做 / 读」判据(硬规则 · 2026-07-26 定,与下面「`参考：`标签纪律」条配套)**:提示层内部再分两类,分界不看内容主题、只看**这段是让老师「做」还是让老师「读」**——
    - **让老师做一个动作 → `[…]` 舞台提示**:出示材料、巡视分层、组织形态、异常处理、学生类型等,独立成段或段末括注(体例见上条)。

- **`参考：`标签纪律与学生话轮拟真(硬规则 · 2026-07-23 增设「拟真」,2026-07-26 补「标签纪律 + 术语归位 + 追问链」)**:`参考：` 曾被当成万能筐,同时装了四种性质完全不同的内容——学生答案、图意/材料描述、教师应答策略、评价档位。老师读稿时分不清哪句该由学生说出口、哪句是给自己看的,由此派生出「学生答得像教研员」的观感(2026-07-26 于《三上·续写故事》定点修改验证)。以下六组一体执行,①②③是新增主干,④是原「拟真」条,⑤是防改过头的反向约束、与前四组同等重要,⑥(2026-07-29 增)管**标签块与上文师话的衔接**——前五组管的都是「内容该挂哪个标签」,没有一条管挂上标签之后师话还接不接得上。

  **① 标签纪律(置信度高:三份三上存量稿均命中,属结构问题、不随课次变化)**——`参考：` 后面只准放**学生可能说出口的话**;另三类各归各标签(括号家族分工见上「`〔…〕` 与 `[…]` 的分工」条):

  | 内容性质 | 标签 | 说明 |
  |---|---|---|
  | 学生可能说出的话 | `参考：` | 写法归②③管 |
  | 图画/材料内容描述(教师用) | `〔图意〕` | 看图类课次用;非看图课次(读材料、听录音、看实物等)用 `〔材料〕` |
  | 教师应答策略、课堂处置 | `〔应答·触发情形〕` | 括号内点明触发条件,正文写教师怎么接 |
  | 评价标准、评分档位 | `〔三档标准·教师掌握〕` | 或按该课实际档位命名 |
  | 教师当场念给学生听的示范字句 | `〔教师示范·…〕` | 括号内点明演的是什么(如 `〔教师示范·当场把“他很急”扩成一小段〕`);与独立成块的 `【教师示范文】` 分工见下 |

  **`〔教师示范·…〕` 与 `【教师示范文】` 是两回事,不得互相并入(2026-07-26 用户拍板)**:前者**占话轮位**——是老师在③里要念出口的**当场演示**(把一句扩成一段、把“难过”写成一段、出示一则日记讲格式),它挤在 `师：`／`参考：` 的序列中间,过去常被误挂在 `参考：` 下,老师照稿上课会当成学生该说的话;后者是**独立成块的示范例文**(环节④,`> ` 引用块 + `【教师示范文】` 标注,整篇成文)。**两者体例各自保留**:话轮位示范用 `〔教师示范·…〕`、不套引用块也不加 `【】`;`model-essay.md` 的身份红线与体例**只管独立成块的那一类、本次不动**——不得因为话轮位示范也是“老师写的”就把它改成 `【教师示范文】` 块,那会把③的教学节奏切断。

  `〔应答·…〕` 的写法与 `laojohn-picture-writing` 线保持一致(那条线已多课验证有效,本线沿用同一格式):括号内写清触发情形——如 `〔应答·学生编出脱离前文的情节〕`、`〔应答·漏说时间〕`、`〔应答·学生只答一个词〕`,正文写教师怎么接,接不上时紧跟 `师：` 行给可照说的话。**图意/材料标签只换标签,原来跟在后面的师话不动。****判断方法**:每写完一处 `参考：` 自问一句——这话是要学生说出口的吗?不是,就换标签。

  **② 教学术语的首现权归教师(硬规则 · 置信度高,2026-07-26 由静态黑名单改为条件规则)**——不是「术语一律不许进 `参考：`」,而是**首现权在教师**:某个教学术语可以出现在 `参考：` 里,**当且仅当**满足下面任一条——

  - **本课内已教过**:该术语在**本课更早的 `师：` 话轮里已经出现过**(位置须真的在前,同一环节内也算);
  - **前序课次已教且有据可查**:能指出出处——同年级更早已成稿的篇目、`references/course-map.md` 的进阶线、或 `references/archive/` 该任务的官方要求。**「学生大概学过」不算据**:凭印象推断即视为未教过,拿不准就让教师先说一遍(同真实性红线精神:不凭记忆补事实)。

  两条都不满足 → 这句话必须挪到 `师：` 话轮,由教师说出。理由:学生不会**凭空**用出教研词汇——让学生一上来就说“这就叫脱离了前文”,既不真实,也让老师误以为课堂该出现这种回答。**结论性术语的第一次亮相,永远由教师完成。**

  **两条护栏(即便已教过、可以复用,也须同时满足)**:
  - **单条 `参考：` 中「单个学生的单次发言」不超过 40 字**(同③):**事实罗列**(按顺序数出四处景物、把三段各是什么逐一说出)与**多人答案集合**(`／` 或 `；` 分隔的七嘴八舌答案)**不受此限**——它们不是一个孩子一口气说的一句话;但两者**仍须满足术语首现权**(②),不得借罗列之名把教研判断塞进学生话轮;
  - **复用形态是零碎不完整的口语,不是工整完句**——学生复用术语时说的是“它跑偏了／没照应前面”“这段跟前面接上了”这类半截话,**不是**“这一段照应了前文、发展合理,所以接得住”式的完整教研判断句。判据:读出声,像不像这个年级的孩子随口带出一个刚学的词。

  **常见术语(降级为示例,非封闭清单)**:照应前文、脱离前文、合理发展、围绕一个意思、中心句、落脚点、面面俱到、流水账、写具体、打比方。清单只帮生成时快速起疑,**判断一律回上面两条准入条件**;清单外的词若同样是教研判断语,同办。

  **③ 学生答案拆追问链(置信度中:看图写话线与写作线各验证一次)**——不得让一处学生回答承担整个教学结论。正确形态是**学生给粗答 → 教师追问 → 学生补 → 教师收拢成术语**;单条 `参考：` 中单个学生的单次发言不超过 40 字(事实罗列与多人答案集合不受此限,口径同②护栏)。已验证样例(《三上·续写故事》环节三“判断两段话”):

  ```
  师：这两段,哪一段是顺着我们这三张图接下去的?
  参考：第二段。
  师：第一段写得也挺通顺,为什么不算接住?
  参考：它没写小狗了／它写到上学去了。
  师：对,小狗和妈妈全丢下了,跳到上学、体育课上去——这就叫“脱离了前文”。
  ```

  关键在**真拆成多轮,不是把原答案截短了事**。极简确认类回答(“在！”“明白了”)不需拆。这一条与下面④是同一件事的两面:粗答→追问的链条,本身就是「拟真」的实现方式。

  **④ 答案拟真(原 2026-07-23 条,保留)**——`参考：` 不得清一色完整、切题、书面化,那不像本年级学生当堂说出的话,老师照稿备课后接不住真实课堂。两半做法,缺一不可:
  - **一部分参考答案写成本年级的粗糙短口语**(不完整、口语碎、贴年级语感;措辞按本课内容自拟,禁跨篇复用同款“粗糙句”),同时**保留一部分完整答案**作理想参照;
  - **链条补全(关键)**:凡粗糙答案不完整、而后续教学依赖完整信息(要拿它进构思表、进示范讲解、进讲评)的,教师话轮必须紧跟一句追问或补全,把缺的信息当堂补齐——只把答案改糙、不补教师追问,教学链条就断在那一步。
  - 判据(正向):把每处 `参考：` 读出声,问“像不像这个年级的孩子当堂说出来的”;再顺读其后教师话轮,问“老师拿这个答案能不能把课接下去”。

  **⑤ 反向约束(防止改过头)**:
  1. **不得为拆链而拖慢课堂节奏**:一处追问链两到三轮即可,不要拆成五六轮;简单问题(“结局清楚吗”)两轮就够。
  2. **不得因②清空学生话轮的内容**:学生仍然要说出实质内容(“朵朵保证自己照顾、小狗往怀里蹭”),只是不说术语。把学生答案一律改成“嗯”“对”是错的。
  3. **不得把 `〔应答·…〕` 写成理想化的师生对答**:它是给老师的处置预案,触发条件要具体、教师话要可照说。
  4. **不得动教师示范文**:示范文须书面规范,口语化与拆链规则**一律不适用**(同理:表格、评价量表、`[…]` 提示段、讲评占位槽等书面区亦不适用)。
  5. **不得引入新的对仗**:改写时顺手写出“既……又……”“接得稳、想得妙”这类工整结构,一律删掉。**例外**=该课刻意设计的核心口诀(如“接得上、想得合理、写完整”)保留——判据是“这句是要学生记住的吗”。
  6. **每处独立判断,禁止全文批量替换标签**:同一段文字在不同语境下可能归属不同标签。

  **⑥ 教师掌握类标签的口语转述义务(硬规则 · 2026-07-29 立)**——`〔…·教师掌握〕` 类内容**不念给学生**,因此它与上文师话的衔接须单独约束。实测漏出:「师：我们先对着标准看看自己写得怎么样,有三条标准:」后面直接接 `〔三档标准·教师掌握〕`——按①–⑤完全合规,可学生听到的是**一句悬空的话**,老师照稿上课会当场卡住。

  1. **师话不得悬空**:师话**不得以冒号或「有三条标准:」这类预告结尾后直接甩给标签块**,冒号之后必须有面向学生的内容。
  2. **预告即转述**:师话若已向学生预告了标签块的内容,须**在师话内用学生听得懂的话讲完**;标签块随之降级为教师判断依据。
  3. **无预告可独立**:上文师话完全没提到该块内容的,标签块可独立存在、不需转述。**判据只看上文师话有没有向学生预告,不看块的内容性质**。
     注意:`〔修改符号说明·教师掌握〕` **不属于**本条。三上第一单元是统编要求「学习使用修改符号」的**首次引入单元**(见 checklist F 组「仅首次引入单元才当众示范教学」),该块上方师话既已预告、本单元又该当众教,就须按第 2 条在师话里讲一遍。
  4. **括注义务**:教师掌握块的标题内须加括注,**含「不必读给学生」(或旧写法「不必念给学生」)字样**(如 `〔三档标准·教师掌握（供教师判断用，不必读给学生）〕`;措辞可随该块微调,机检只认「不必念/读给学生」这五个字,0831 方向 念→读 后两写法并认)。
  5. **术语降级**:转述时**不得沿用评估黑话**(基础过关/良好达标/优秀进阶/达成度),改说学生做得到的动作。
  6. **管辖边界:学生可见的自评表不属本组(2026-07-29 补)**——同是「三档标准」,存量里有两种承载形态,**不是体例分叉、是两件不同的东西,同篇并存也合理**:`〔三档标准·教师掌握〕` 是**教师判档依据**、不念给学生,本组①–⑤ 管的是它;写成**学生可见的第一人称自评表**(表头如「档位｜自检的话」,行文作「我写出了那个地方,有几样景物…」「我走全了三步…」)的,是**学生手上的件、本来就该学生看见**,**不需口语转述、不加「不必念给学生」括注、不受第 1 条悬空约束**(师话以冒号预告后接一张学生看得见的表,预告已被兑现)。**判据看这张表给不给学生看,不看它叫什么名字**。⚠ 不要为了「统一」把学生自评表改成教师掌握块——那是把一个好设计改坏。机检只认 `〔…教师掌握〕` 标签,故学生自评表天然不在扫描范围内,无须额外豁免。

  正例:「师：改之前,我们先看三条:第一,特点抓着没有;第二,有没有围绕这一处写具体;第三,别人读了,能不能认出他是个怎样的人。就对着这三条,看看自己这一页。」→ 其后接 `〔三档标准·教师掌握（供教师判断用，不必念给学生）〕`。

     **适用范围只限师话层**:`【教师示范文】`、表格、`[…]` 提示段、讲评占位槽**保持书面规范**——这与 checklist E 组「示范文与书面区未被口语化规则误改」一条同理,**不得反向误伤**(故①的机检只扫 `师：` 行、不做全文 grep:示范文里写「浮现」可能正是正当的描写示范)。②③⑤ 是判断项、不入机检,归 checklist E 组人工判;**④⑥⑦ 已于 2026-08-31 进机检的 [INFO] 候选清单**(`tone_gate.py --profile writing`:⑦按课时计数并对超配额给结论、④只扫收束位、⑥摘出每个课时与附录的末条师话)。⚠ **候选清单只捞候选、不判决**——⑦的「教学演示位不计配额」例外与⑥的「删掉有没有损失」都要人来判,机器判不了;立此清单是因为**判据清晰的规则一年没人扫过**(2026-08-31 实证:四份详案 92 条病灶里 57% 属「规则已写但没执行」,《漫画的启示》第 1 课时⑦实测 6 处、三份稿⑥全部命中),根因是没有带行号的候选、人工判就得通读全篇。

  7. **禁电报体压缩与生造词(语气松弛、把话说全 · 2026-07-31 用户反馈立)**:病征方向与第 5 条相反——句式过分简洁,单看每句都“对”,连读像电报、像提纲缩写,不像活人说话。五个形态,准绳＝《三上-第一单元-猜猜他是谁》与《五上-第二单元-“漫画”老师》两篇用户逐句改稿:
     - **省主语的问句/指令句**:「怎么一下就猜中了?」→「**你们**怎么一下就猜中的?」——面向学生的问话、指令补上「你们/我们/咱们」。
     - **名词压缩**:「蓝紧身衣」→「蓝色的紧身衣」;「老师说的这几样」→「老师说的这几样东西」——名词短语把「的」与中心词说全,不写提纲式缩略。
     - **电报短语当句子**:「再来一个,更快——」→「那现在再来猜一个,你们应该会猜得更快——」——逗号隔开的孤立短语,说成有主有谓的完整句。
     - **生造压缩表达(务必杜绝;读者第一遍读不懂即失败)**:「脑子里立起了一个人」→「脑海里浮现出了一个清晰的人物形象」;「最像他自己的是哪一下」→「专属于他、一眼就能认出是他的那个瞬间」;「光看光听就认得出的地方」→「不用提名字,单凭动作、说话就能认出他的细节」;「被组员摇头、需要换圈选处的学生」→「说完组员想不起人来、需要回卡上另圈一处的学生」;「往大里写」→「放大着写」(缩略口头禅,且「大」在本课指特征放大、不是立意深广);「这条界一样得守」→「同样有个分寸要守」(把「边界/底线/分寸」硬缩成一个「界」字)。排查法:不在语文教研与日常通行说法里、且无上下文解释的短语,一律换通行说法或就地一句话说破。
     - **中心宾语残缺(2026-08-19 用户反馈补 · 准绳＝《五上-第二单元-“漫画”老师》逐句改稿)**:限定词/数量词/指示词后不接中心名词,句子看着说完了、信息没给全,读的人得自己猜——「专挑你身上最扎眼的一处」→「…最扎眼的一处**特点**」;「你们找出来的这几样,归起来是两条」→「归起来是两条**写法**」;「后面讲了上星期改作业那一回」→补出那一回**发生的是什么事**(「上星期改作业时她满讲台找红笔那件事」);「换成他真做过的那一件」→「…那一件**事**」。排查法:全文搜「一处/一样/一条/一件/那一回/这几样」,凡其后直接跟标点或「,」的逐处判,上下文补得上中心词就补。⚠ **反向刹车(本篇实测)**:课内已建立的教学术语(本篇「那一处」＝人物身上最突出的一处特点)只在**定义句处补全一次**,其后回指不必逐处补——逐处补会把它压成口令并撞池 8 高密度配额(本篇「一处特点」一度 ×7,退到 2 次才达标)。
     判据(与看图写话线 lesson-structure §13.6/§13.8 同款——本条即该两条在写作线的对应物):**读出声,像不像一位真老师顺嘴讲下来**。**正样本＝`prose-style-benchmark.md`(2026-08-04 立,本条判据的落地形态)**:那里有用户逐句修订的真实前后对照与五类改法,**写新篇前先通读基准篇第 1 课时的师话**。此前本条只指了篇名、没给可对照的段落,等于把「像不像真老师」全托给生成侧的自我感觉——2026-08-04 四篇复发即此。**本条与该文件互为单一源,改一处须同步另一处。****与第 5 条「师话精简」不矛盾**:精简砍的是重复叮嘱、情绪安抚、管理碎指令,**不是句子成分**——把一句话说全、说松弛,和不啰嗦是两件事。⚠ **第三方向见 `style-criteria.md`(向规范书面靠·礼貌补全,0901 立)**:与本条同向推长、与第 5 条③反向;只执行任一方向都会走到另一头,裁决位＝review-rubric Pass B「教学语言规范化」项。反向约束(防矫枉过正,同看图写话线 §13.9):① 每处改写增字原则上不超原句一倍,不为补足而注水;② 不统一句长——改完整段若短句尽失、句长均齐,AI 味不降反升,回退一部分;真实短指令(「笔放下。」「在!」)与学生话轮的粗糙口语保留;③ 逐处判断,禁全文批量替换。本条是判断项、不入机检,归 checklist E 组人工判。
  8. **教学指令正向表述:写法只作优劣对比,不判对错(2026-08-24 用户反馈立)**:病征是详案里反复出现「不要写……」「不能写……」「避免写……」式的禁令,**把一种本来可行的写法说成写作错误**。实测存量:《我的心爱之物》把「全篇不写“我很喜欢它”」同时写进核心技法行、成败标准、动笔前写作要点三处(只有⑦的修改指令被用户手工改成了对比口径);而本条最隐蔽的来源是**档案自己**——`archive/` 的重难点原文常以否定式写成(如《二十年后的家乡》难点原话即“避免笼统地说‘变得更好了’”),**照抄进师话即复发**。**后果落在老师不在学生**:详案是给别的老师照着上的,一份份读下来会形成“直接抒情＝写作错误”的认知,课堂上一刀切禁止,学生连“我很喜欢它”都不敢写——而那本是五年级学生表达真情实感的正当句子。
     - **判据:先分两类,再决定能不能说“不对”**——
       - **写法偏好类**(直接抒情 vs 细节描写、概括 vs 具体、朴素 vs 修辞、开门见山 vs 铺垫……):**两种都成立、只有效果差别,一律不判对错**。师话走三步:① **先承认它可行**(“‘我很喜欢它’这句话没写错,意思清清楚楚”);② **出示另一种写法的样例,让学生自己比出差别**(不是老师宣布哪种好);③ **把选择权交回学生**(“两种都能用。你觉得哪一种更像你想说的?也可以先直说一句,再用一段具体的把它撑住”)。**搭配使用要明确说出来**——学生最容易误以为二选一。
       - **题目要求类**(跑题、漏掉题目指定的要素、文体不对):这是客观标准,**照旧可以明确说“这样就不合要求”**。③ 开头的「审题辨析」固定半步判的正是这一类,**不受本条约束**(那半步的 A 段本就是教师自拟的跑题反例)。
     - **五个落点(逐处查,不止 `师：` 话轮)**:提纲表「核心技法」行 / ③技法讲解与命名 / ④示范文点评 / ⑥动笔前的写作要点交代 / ⑦自评互评标准与修改指令。**⑦ 最容易漏**:“把‘我很喜欢它’删掉”是禁令,“试着在它后面补一段具体的,再读读看哪一种更打动你”才是本条要的。
     - **反向刹车(防矫枉过正,三条)**:① **不是“全文不许出现否定词”**——“不用面面俱到”“不必每样都写到”这类**减负性**指令是替学生卸包袱、方向相反,照写不误;② **不是“两种写法一样好”**——对比的目的仍是让学生看见具体描写的力量,**教师可以有明确倾向、可以推荐**,只是把“禁止用”换成“我更推荐这一种,你来选”;③ 真实性、格式对位、示范文身份这类硬要求**不作对比**,该说不行就说不行。
     - **一句话判据:这句话是在告诉学生“怎样写效果更好”,还是在告诉他“这样写是错的”?** 后者、且属写法偏好类的,改写。⚠ **本条要求的三步对比会产生「不是 A,是 B」句式,该句式在第 6 条⑦有配额——⑦ 已于 2026-08-24 为此开例外(教学演示位不计配额),执行本条时不必为躲⑦的配额把对比句改掉。**本条属**生成层**(要动教学设计——出示对照样例、改成败标准的写法,冷审逐句改补不回来),不后移 Pass B;自检见 checklist C 组对应条,冷审见 review-rubric 跨维查项八。


  9. **禁预演式总结:不把还没发生的课堂结果写成既成事实(2026-08-31 立)**:病征是师话与`（教师总结）`里预先宣布全班的表现——「大部分同学第三步“联生活”都想到了具体的事」「刚才这几位,画面都念得让人“看见”了」「你们观察到的这些确实都写出来了」。**这是「读着不像真老师」里最硬的一类**:真老师站在教室里不可能预先知道全班答得怎么样,照着念会出现「稿子说都想到了、眼前根本没人举手」的当场落空;它同时也是**评价环节空转的成因**——总结已经替学生下了结论,后面的追问与补救就没有着落了。
     - **判据是评价性完成体,不是「都」字本身**:预先给出**对学生表现的评价**才算(都想到了/都写出来了/都念得让人看见了/都用上了);**将来时与任务分派不算**(「等一会儿每个人都要在组里念」「现在每个人都有事做」),**纯动作完成也不算**(「每个人都给自己的日记本写下了第一篇」——那是本课必做任务写完了,不是对表现的预判)。
     - **改法两条**:① 改条件式,把结论挂到实际出现的产出上(「谁写到了具体的事,举手让我看看」「凡是把那件真事写进去的,这一步就站住了」);② 指向具体某一位、不概括全班(「刚才这位同学念的那句,画面就出来了」)。两条都比原句更能推动下一步,不是单纯删掉。
     - **已入机检(FAIL 级)**:`tone_gate.py --profile writing`,只扫 `师：`/`（教师总结）` 行。2026-08-31 全线 17 篇实测 4 处命中、零误报;误报最多的宽匹配形态(「每…都＋动词」)已在脚本里收窄并留注释。⚠ **机检是执行层、不是定义处**——判据以本条为准,改判据须同步 `tone_gate.py` 的 `PREEMPTIVE_PATTERNS`。
     - **本条属生成层,不后移 Pass B**:改一处预演式总结要连着改后面的追问与补救动作(条件式改法会改变教学动作),冷审逐句改补不回来。自检见 checklist E 组对应条。⚠ 与红线第 8 条的关系:第 8 条治「把可行的写法说成错的」,本条治「把没发生的说成发生了」,两条不重叠。

  > 红线针对**市井 slang、学术黑话、花哨包装、低幼哄劝、书面抒情、电报压缩、否定式指令、预演式总结**八类:既不市井江湖、也不晦涩学术、也不靠游戏化叫法与形象比喻撑场面、也不靠反复安抚和过度兜底把学生当更低龄、也不在师话里写出只能读不能说的抒情句、也不把话压成电报缩略和生造词。但平实**不等于**干巴术语——师话层仍可亲切、具体、面向小学生(必要拟声词如“咯吱咯吱”保留),只是**直说方法本身、不再裹一层比喻**;提示层一律用上表右栏的规范实操词。自检见 checklist.md E 组。

## 五、教学流程(血肉层 → 见 workflow-engine.md)

教学流程的具体走法由 **`references/workflow-engine.md`** 规定,那是强制骨架,生成时必读、逐环节照走。它把四大设计价值观(真实情境 / 全感官支架 / 即时反馈 / 表达主权与延迟纠错)焊进固定七环节:

第 1 节:① 真实情境抛任务 → ② 全感官唤醒 → ③ 一招技法 → ④ 示范文做样 → ⑤ 构思支架落地
第 2 节:⑥ 自由倾吐(开场起步半环按文体调行为支架——L1–L4「降压起步」写出第一组句子／L5–L6「定起点」先判断从哪儿起笔再落笔写这一处 → 护表达流、零打断纠错续写完篇)→ ⑦ 即时反馈 + 延迟纠错修改 + 自然收尾

本节(课型骨架、课时、定位、格式、书级头部)是**底座**,与引擎不冲突;冲突时以底座为准。底座仍要求:每段在师话/技法讲解里显性点出本节训练点(把“今天练的是……”讲给学生听),但**不写“(此处落实……)”这类括号自注标签**——逐环节括号自注已整类删除(见 workflow-engine.md 环节① / checklist.md G 组 / variation-pools.md 表层指纹一节);第 1 节尾不留课后任务;作品当次完成当次评改(教师课后精批属允许的额外动作,但不得表述成“写不完带回家写完”)。
