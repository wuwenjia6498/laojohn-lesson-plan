# 写作课课型结构与逐字稿格式

> 本文件只写**现行规则条文**。每条的立条日期、用户拍板经过、实测数据与复发记录，见 `history/lesson-structure-history.md`（同节号回查），生成详案时不读。

## 一、课型骨架(七环节,血肉层骨架)

写作课走七个环节,把四大价值观焊进流程。详细走法见 `workflow-engine.md`,此处只给骨架与各环节归属的课时。

| # | 环节 | 课时 | 价值观落点 |
|---|---|---|---|
| ① | 真实情境抛任务 | 第1节 | 真实情境 |
| ② | 全感官唤醒 | 第1节 | 全感官支架 |
| ③ | 一招技法(开头含「审题辨析」固定半步,见 workflow-engine 环节③) | 第1节 | 技法克制(底座) |
| ④ | 示范文做样 | 第1节 | 底座 |
| ⑤ | 构思支架落地 | 第1节 | 全感官支架落地 |
| ⑥ | 自由倾吐(护表达流;开场含起步半环——L1–L4「降压起步」／L5–L6「定起点」,见 workflow-engine.md 环节⑥-起步) | 第2节 | 表达主权 |
| ⑦ | 即时反馈 + 延迟纠错 + 自然收尾 | 第2节 | 即时反馈 + 延迟纠错 |

七环节与档案「教学建议」的作前/作中/作后三段一一对应;生成时仍**以档案该任务的教学建议为内容蓝本**,按七环节重排节奏、注入血肉,不偏离档案的写作目标与技法。

> **附加块「习作讲评指导环节」(可选,不在七环节内):** 每份详案末尾附一块可选的深度讲评模块(单次课课后用 / 系列课作下次课开场用)。它**不是第 8 环节、不计入 45+45**,走法见 workflow-engine.md「一之二」节,落位与格式见本文件 §三。

## 二、课时安排(固定:同次连排 2 节 × 45 分钟)

每次习作课 = **2 节课同次连排,每节 45 分钟**,中间课间休息。培训班固定排课,不设单节模式、不询问。

| 节次 | 覆盖段落 | 参考切分 |
|---|---|---|
| 第 1 节(45 分钟) | 作前指导 + 作中指导(技法讲解、构思支架、示范文) | 作前约 20 分钟 / 作中约 25 分钟 |
| 第 2 节(45 分钟) · L1–L4 | 当堂动笔完成 + 作后评改 | 降压起步约 5 分钟 / 自由写作约 17 分钟 / 评改约 23 分钟 |
| 第 2 节(45 分钟) · **L5–L6** | 同上 | **定起点约 3–4 分钟 / 自由写作 25 分钟以上 / 评改约 16–17 分钟** |

切分可依任务浮动,但**每节各环节时长合计必须 = 45 分钟**,三段总体缺一不可。

- **L5–L6 前重后轻(硬规则)**:L5 整篇约 450–500 字、L6 约 500–600 字+,**自由写作 25 分钟以上是硬下限**(算法见 review-rubric.md 维四);分钟从起步半环(3–4 分钟)与评改(16–17 分钟)两处腾。例外:篇幅要求明显低于该级常规的任务按实际字数折算,须注明理由。**L6 放行**:起步可并入自由写作、不单列 `###`,此时自由写作标称含进这几分钟(≥ 28 分钟左右);L5 仍须单列。

**连排约束**:
- 第 1 节课尾**不布置任何课后任务**,只收束构思成果并预告“休息回来就动笔”;第 2 节开头一句话接住。
- 作品**当次完成、当次评改**——即时反馈 + 带标准自改 + 同桌互改 + 老师轻点评 + 自然收尾这一套在第 2 节内完成。文末附加的「习作讲评指导环节」评的是已当堂完成的稿,不构成课后写作任务。
- 整篇当堂完成是默认;L5–L6 确实写不完时,当堂完成核心段并评改核心段,结尾段回家补完——这是唯一允许的课后延伸。

## 二之二、课时定位(中性校内同步课)

本课默认**中性定位**:不假设学生已学/未学本单元课文,也不假设是否已被学校指导过此题;课文与已学内容可自然引用作范例。两条硬规则:

1. **连排内自含**:导入与例证只用当堂给得出的东西——游戏、情境、实物、图片、示范文、课文片段。档案教学建议若依托长周期活动(提前一周观察、课前带实物),改造成单次两节课内自含的形态,保留其真实内核;若依托单元课文,可直接当堂出示/朗读作范例。
2. **收尾真诚、不喊机构卖点**:自然收尾,把“今天这件事本身的意义”讲透(写信课收在真把信送到那个人手里);**不要**“别的同学才开始想/你比别人早一步”这类对比话术,也不说“拿给语文老师看”。

若用户说明该习作学校**已经讲过**,可转“提升与讲评”取向(作前压缩、技法上探到档案难点、评改加重);默认不问、按中性同步课走。

## 三、逐字稿格式(与阅读详案同一套骨架)

- **固定话术骨架**:师话以 `师：` 开头;预设答案以 `参考：` 开头;学生环节写整行 `学生互动分享` / `学生自由分享` / `学生动笔写作`;小结用 `（教师总结）`。
- **标题**:主标题 `# 《题目》· 写作课教学设计`(题目带书名号、不带年级册;用“教学设计”);**紧接下一行、中间不空行**写副标题 `<年级册次>·<单元> 校内同步写作（<体裁>）`(引擎把 H1 后紧邻的非标记行渲染为居中副标题,留空行即失效)。课时标题固定 `## 第1课时 · 写作指导课` 与 `## 第2课时 · 当堂写作与评改课`。
- **环节序号按课时各自从「一」重起**:第1课时编「一」到「五」;第2课时重新从「一」起——`### 一、〔起步半环平实环节名〕（约 5 分钟／L5–L6 约 3 分钟）` → `### 二、自由写作（约 N 分钟）` → `### 三、交流评议,修改收束（约 N 分钟）`;L6 并入起步时只有两个环节,三件套照写在自由写作开头。工作流的 ①–⑦ 是内部编号,不进详案。
- **时长与标题长度**:时长一律 `（约 N 分钟）`——带「约」、阿拉伯数字两侧各一个半角空格、中文圆括号;区间写 `（约 3–5 分钟）`,连接号用 `–`。**环节名内不得夹带预案、压缩方案等长说明**,这类说明移到该环节正文第一行作引用块 `> **可压缩预案**：…`。完整体例见 `title-naming.md`。
- **环节标题须专业平实(硬规则)**:写成一线语文教案的教学环节名(动宾或并列短语),**严禁照搬七环节工作名**(真实情境抛任务/全感官唤醒/一招技法/示范文做样/构思支架落地/自由倾吐/即时反馈+延迟纠错+自然收尾)。推荐对照(可按本课技法点微调):

  | 内部环节 | 详案里的专业标题(示例) |
  |---|---|
  | ① 真实情境抛任务 | 创设情境,明确任务 |
  | ② 全感官唤醒 | 观察体验,调动感官 |
  | ③ 一招技法 | 学写法:〈本课主技法〉(如“围绕一个意思写”) |
  | ④ 示范文做样 | 出示示范文,发现写法 |
  | ⑤ 构思支架落地 | 借助〈构思工具名〉,理清思路 |
  | ⑥-起步 | L1–L4 如“借助构思表,写下第一组句子”;L5–L6 如“看着构思表,定下从哪儿起笔”(直说方法本身,不用游戏化叫法;L6 并入时无此标题) |
  | ⑥ 自由倾吐 | 自由写作 |
  | ⑦ 即时反馈+延迟纠错+自然收尾 | 交流评议,修改收束 |

  「审题辨析」不单列环节标题——它是③内部的开场首段,以平实说法(“判断哪段切题”“审清题目要求”)出现在③的师话开头。`师：/参考：/（教师总结）` 等固定话术骨架是既定符号,保持原样。
- **表格**:用标准 Markdown 表格,单元格内换行 `<br>`。**填写型表格必须给“两格都填”的真表头**(如 `| 项目 | 关键词 |`),字段放数据行——首行只有首格有内容时引擎会把它当合并标题横幅渲染。空白版与教师示范版用同一套表头与字段行。
- 示范文用 `> ` 引用块,文首标 `【教师示范文】`(详见 model-essay.md)。
- 每课时末写 `本课完。`,两节正文末写 `全课完。`。
- **附加块落位**:置于 `全课完。` 之后、指纹注释之前,标题**固定写成** `## 附：习作讲评指导环节（可选 · 单次课课后用 / 系列课作下次课开场用）`(唯一源 title-naming.md §四)。头部先用 blockquote 写两句(可灵活取用+两用+不计入 45+45 / `＿＿＿` 处换成本班真实习作),正文分**三节逐字稿**:`### 选稿（课前准备）`、`### 讲评流程（每篇约 3–5 分钟，围绕本课技法点）`、`### 收尾（点回技法、引向今后的写作）`——**无序号、不冠「一、二、三」**;逐篇用 `师：` + 全角 `＿＿＿` 占位 + `（教师总结）`/`学生互动分享` 骨架,末尾 `本环节完。`。写法见 workflow-engine.md「一之二」。
- **中文引号规范(硬规则)**:正文一律全角弯引号——外层 `“”`、内层 `‘’`,**严禁**半角直引号 `"` `'`;半角只允许出现在 Markdown 语法、行内代码、英文路径处。引擎安全网对跨行、奇数个、弯直混排会判错方向,**不可托底**,交付前全文检索自查。
- **中文标点全角规范(硬规则)**:逗号、冒号、问号、叹号、分号、圆括号一律全角(半角 `.` 因小数/序号歧义不强制转);数字范围 `–`、箭头 `→`、并列 `/`、乘号 `×`、全角竖线 `｜` 及 Markdown 语法、行内代码、英文路径处的半角符号不动。**适用范围 = 初稿 + 此后每一次局部增改**。
- **行内强调禁令(硬规则)**:正文**严禁 `**`、`*`、`__`**(单星/单下划线会原样印进 docx;成对 `**` 本 skill 也不用,小标题靠 `【】` 与骨架承载),**唯一例外＝`## 教案提纲表` 一节之内**;规则文件里的加粗是写给生成者看的,不得模仿进产物。
  - **填空横线**一律用全角 `＿`(U+FF3F),不用 ASCII `_`(连写 `__` 会被引擎当加粗剥除)。横线旁括注直接写动作指令,**不加「占位:」前缀**(如 `＿＿＿(读该生最传神的一两句)`);正文检索「占位」应为零(tone_gate 全文扫)。
- **机构名不拟人(硬规则)**:教师一律自称“老师”,**严禁**“老约翰说”“老约翰老师”;机构名只出现在文档头部/页眉。
- **语体分层(硬规则)**:两套语体各守各的口径。
  - **师话层**(`师：`、`参考：` 等讲给学生听的):亲切、具体、面向小学生,直说方法本身,必要的拟声词可留;**少用或不用形象比喻**,“技法”就叫“技法/方法/要点”。
  - **提示层**(`[…]` 舞台提示、括号旁注、巡视说明——写给授课老师照做的):一律用清楚、专业、可执行的规范指导语,**严禁**口语随意词:`递话`→`提示/介入`、`喂具体`→`提供具体素材提示`、`让路`→`不打断、为其留出书写空间`。判据:这句是“讲给学生听的”还是“讲给老师做的”。
  - **方括号提示体例**:教师现场提示统一用半角 `[…]`(结构标记,区别于 `【】` 固定话术与 `〖〗` 页标);方括号内「类别/情形 + 说明」之间用全角冒号(`[异常处理：学生上台憋不出话]`),不得用 `——`、`·` 混用;方括号后引出正文冒号亦全角。同一份详案内写法前后一致。**清单里不含「板书」——教室无黑板白板**。
  - **括号家族「做 / 读」分工(硬规则)**:让老师**做一个动作** → `[…]` 舞台提示(出示材料、巡视分层、组织形态、异常处理);让老师**读一段信息** → `〔…〕` 话轮位标签(它占 `师：`／`参考：` 序列上的一格),全集五类:`〔图意〕`／`〔材料〕`／`〔应答·触发情形〕`／`〔三档标准〕`／`〔教师示范·…〕`。判据:这一格不设标签,老师会不会误当成学生该说的话或自己该照念的话?会 → `〔…〕`;只是交代动作 → `[…]`。新增标签按此归家族;四家族 `[…]`/`〔…〕`/`【】`/`〖〗` 互不替代。
  - 自检:交付前扫一遍所有 `[…]` 与 `(…)`,含糊或口语随意的指导动词改为明确动作描述;`（教师总结）` 等骨架不在此列。
- **`参考：`标签纪律与学生话轮拟真(硬规则)**:`参考：` 后面只准放**学生可能说出口的话**;六组一体执行(来历见 history §三)。

  **① 标签纪律**——另三类各归各标签:

  | 内容性质 | 标签 |
  |---|---|
  | 学生可能说出的话 | `参考：`(写法归②③管) |
  | 图画/材料内容描述(教师用) | `〔图意〕`;非看图课次用 `〔材料〕` |
  | 教师应答策略、课堂处置 | `〔应答·触发情形〕`(括号内点明触发条件,正文写教师怎么接) |
  | 评价标准、评分档位 | `〔三档标准〕`(或按该课实际档位命名)。**学生可见**:不挂 `·教师掌握`、不加「不必读给学生」括注、不受⑥约束——学生知道判档依据才好照着改自己的稿 |
  | 教师当场念给学生听的示范字句 | `〔教师示范·…〕`(括号内点明演的是什么) |

  `〔教师示范·…〕`(占话轮位、当场演示)与 `【教师示范文】`(环节④独立成块的例文)是两回事,不得互相并入。每写完一处 `参考：` 自问:这话是要学生说出口的吗?不是,就换标签。

  **② 教学术语的首现权归教师**——术语可进 `参考：`,**当且仅当**:本课更早的 `师：` 话轮已出现过;或前序课次已教且指得出出处(同年级已成稿篇目、course-map 进阶线、archive 官方要求;「学生大概学过」不算据)。两条都不满足 → 挪到 `师：` 由教师说出。**两条护栏**:单条 `参考：` 中「单个学生的单次发言」不超过 40 字(事实罗列与 `／` 分隔的多人答案集合不受此限,但仍须满足首现权);复用形态是零碎口语(“它跑偏了”),不是工整完句(“这一段照应了前文、发展合理,所以接得住”)。

  **③ 学生答案拆追问链**——不得让一处学生回答承担整个教学结论;正确形态是**学生粗答 → 教师追问 → 学生补 → 教师收拢成术语**。样例:

  ```
  师：这两段,哪一段是顺着我们这三张图接下去的?
  参考：第二段。
  师：第一段写得也挺通顺,为什么不算接住?
  参考：它没写小狗了／它写到上学去了。
  师：对,小狗和妈妈全丢下了,跳到上学、体育课上去——这就叫“脱离了前文”。
  ```

  关键在真拆成多轮,不是把原答案截短。极简确认类回答(“在！”“明白了”)不需拆。

  **④ 答案拟真**——`参考：` 不得清一色完整、切题、书面化。两半缺一不可:一部分写成本年级的粗糙短口语(措辞按本课自拟,禁跨篇复用同款),同时保留一部分完整答案;**链条补全**——凡粗糙答案不完整而后续教学依赖完整信息的,教师话轮紧跟追问或补全。判据:读出声像不像这个年级的孩子当堂说的;顺读其后教师话轮,老师拿这个答案能不能把课接下去。

  **⑤ 反向约束(防改过头)**:1. 一处追问链两到三轮即可;2. 不得因②清空学生话轮的内容(学生仍要说出实质内容,只是不说术语);3. `〔应答·…〕` 是给老师的处置预案,触发条件要具体、教师话可照说,不写成理想化对答;4. **不得动教师示范文**(表格、评价量表、`[…]` 提示段、讲评占位槽等书面区同样不套口语规则);5. 不得引入新的对仗(“既……又……”“接得稳、想得妙”一律删),例外＝该课刻意设计的核心口诀;6. 每处独立判断,禁止全文批量替换标签。

  **⑥ 教师掌握类标签的口语转述义务**——`〔…·教师掌握〕` 块不念给学生,故与上文师话的衔接单独约束。**评价档位不在本组**:`〔三档标准〕` 一律学生可见(见上表),本条管的是 `〔修改符号说明·教师掌握〕` 这类仍不念给学生的块。约束如下:1. **师话不得悬空**——不得以冒号或「有三条标准:」这类预告结尾后直接甩给标签块;2. **预告即转述**——师话若已向学生预告了块的内容,须在师话内用学生听得懂的话讲完,标签块降级为教师判断依据;3. **无预告可独立**——上文师话没提到该块内容的,标签块可独立存在;4. **括注义务**——教师掌握块的标题内须含「不必读给学生」(或旧写法「不必念给学生」)字样,如 `〔三档标准·教师掌握（供教师判断用，不必读给学生）〕`,机检只认这五个字;5. **术语降级**——转述时不得沿用评估黑话(基础过关/良好达标/达成度),改说学生做得到的动作;6. **学生可见的自评表不属本组**——写成第一人称自评表(「档位｜自检的话」)的是学生手上的件,不需转述、不加括注、不受悬空约束;判据看这张表给不给学生看。

  正例:「师：改之前,我们先看三条:第一,特点抓着没有;第二,有没有围绕这一处写具体;第三,别人读了,能不能认出他是个怎样的人。就对着这三条,看看自己这一页。」→ 其后接 `〔三档标准·教师掌握（供教师判断用，不必读给学生）〕`。自检见 checklist E 组;冷审见 review-rubric.md 维二。

- **语言风格红线(硬规则 · 专业且平实,规范且易懂)**:全文(师话层与提示层)守住“专业平实、规范易懂”这条中线——既不市井江湖、也不晦涩学术,也不靠游戏化叫法和形象比喻撑场面,也不低幼哄劝、啰嗦重复。**适用范围 = 初稿生成 + 此后所有改写/局部增改**,不因“只是改一句”豁免。

  > **⚑ 执行层分工**(分层判据只有一条:**修这一处,要不要动教学设计?** 要动→生成层;不动→冷审 Pass B;拿不准留生成层)
  > - **生成层**:第 1–4 条(管环节名与方法叫法)、第 5 条④(动作指令有真实功能)、第 8 条整条(正向表述)、第 9 条(预演式总结,tone_gate FAIL 兜底)、第 10 条(过犹不及型演三档)。
  > - **冷审 Pass B**:第 5 条①②③、第 6 条②–⑦(①禁用词已机检)、第 7 条整条;「教学语言规范化」(向规范书面靠,判据单一源＝`style-criteria.md`,与第 7 条同向推长、与第 5 条③反向,裁决位在 review-rubric Pass B)。

  十条边界:
  1. **禁市井化与网络口语**:不用“写嗨了”“卡壳了”“命根子”“主菜”“小妙招”“炒菜/食材”;“兜底”是 skill 内部机制名,不得原样落进详案。
  2. **禁晦涩学术词汇**:不用“学习支架”“知识建构”“学情干预”“最近发展区”“多模态”等(内部档位词“A 档”亦禁入正文)。
  3. **改用中性、准确的实操词**:

  | 详案里禁用(市井/网络) | 改用(规范业务词) |
  |---|---|
  | 兜底 | 基础辅导预案 / 补充引导 |
  | 卡壳了 / 卡住 / 卡着 | 无从下笔 / 起步困难 |
  | 写嗨了 / 写得起劲 | 书写顺畅 / 已顺利完成 |
  | 命根子 / 主菜 | 关键环节 / 重点内容 / 核心 |
  | 小妙招 | 方法 / 要点 / 步骤指引 |
  | 递素材 / 喂具体 | 提供具体素材提示 / 思路引导 |
  | 让路 | 不打断、留出书写空间 |
  | 学习支架 | 构思引导 / 思路引导 |
  | (抛任务的)情境 | 情境描述 / 真实情境 |
  | 磁铁 / 拐杖 / 钩子 / 空壳子(等形象比喻) | 直说方法本身(围绕中心意思写 / 把“急”“美”这类抽象词,落成看得见听得见的样子) |
  | 上墙评审 / 辨一辨 / 30秒大倾泻(等游戏化叫法) | 平实教案式环节名(判断哪段切题 / 借助构思表写第一句) |

  4. **禁游戏化叫法与形象比喻(覆盖所有年级)**:环节标题与师话直说方法本身——“围绕一个意思写”就直接说“写的每样景物都得跟这个中心意思有关、不沾边的不写”。拟声词是“写具体”的手段、不在此列;起步半环那套行为支架(盯住一处看清、闭眼回想、限时快写)方法保留,只把叫法改平实。
  5. **语气适龄,不哄不啰嗦(覆盖所有年级)**:① **不反复情绪安抚**(“别怕/别有压力/没关系”式心理按摩;个别学生当堂卡住时的临场安抚属具体指导);② **不用一二年级写话式的过度兜底**铺给全体(“不会写的字用拼音”);③ **师话精简**——同一意思不反复说,一句能讲清就不写三句;过场/管理指令一句带过(“把特点卡拿出来”);④ **动作指令须有真实功能、不预设学生处境**:不无故让学生“闭上眼睛”“用手比个框”这类摆拍动作,不写“看你左手边那张表”;判据是“这个动作对写出东西有没有用”。
  6. **师话禁书面抒情**:判定基准——**这句话,授课老师能不能一口气自然说出来**。① **禁用词(出现即改)**:真真切切、重新浮现、闪闪发光、愿你们、往后的日子里、被吸引着想、留在了纸上、有了眉目、真切地感受到、回到眼前、在眼前了、写到眼前、就像站在旁边、活过来了、撑了起来、撑起来了、长出了。 **本表是家族/词根口径**(同一个抒情模子换个宿主也算);「立起来/写活了」不进本表(归池 7);新增词一律进本行(顿号分隔、单行、句号收尾——tone_gate 按此体例运行时解析,换行或改分隔符即静默失效)。② 每课时结尾抒情 ≤1 段、≤3 句、≤80 字,不连着两条师话都在抒情。③ 抒情句里的动词须是学生做得到的动作(翻开、读、记住),禁状态性文学动词(浮现、绽放、点亮、镌刻)。④ 不得用三个及以上对仗分句作收束。⑤ 单个**抒情句**超 45 字且中间无停顿点的,拆句或改写(讲方法、给指令、提问、复述答案这类日常师话不受 45 字限制)。⑥ **结课祈愿·抒情段整段禁**——把镜头推到未来、给这节课做有时间纵深的感慨收束(「老师真心希望你们……」「日子一天天记下来,你会发现自己悄悄长大了好多」这一族);判据:把这段删掉,课的完整性有没有损失,没有就删,收尾用一句实在的交代代替;冷审只标注、不激进删,删不删由用户逐处拍板;生成新稿不主动写。⑦ **格言体对举判断句每课时 ≤1 处**(「不是 A,是 B」「不看 X,看 Y」);例外:教学演示位的写法对比不计配额——对举两端均为可照抄的具体写法样例、或承载第 8 条「承认可行/说明可搭配」那一步的;判据:把这句删掉,学生少学到一个可照做的东西吗?少→不计;不少→照计。附录「习作讲评指导环节」单独算 ≤1。**只限师话层**(示范文、表格、`[…]` 提示段、讲评占位槽保持书面规范)。①已机检(只扫 `师：` 行);④⑥⑦ 进 tone_gate [INFO] 候选清单(只捞候选、不判决);②③⑤ 归 checklist E 组人工判。
  7. **禁电报体压缩与生造词(把话说全)**:病征与第 5 条相反——句式过分简洁,连读像电报、像提纲缩写。五个形态:省主语的问句/指令句(「怎么一下就猜中了?」→「**大家**怎么一下就猜中的?」);名词压缩(「蓝紧身衣」→「蓝色的紧身衣」);电报短语当句子(「再来一个,更快——」→「那现在再来猜一个,大家应该会猜得更快——」);生造压缩表达(「脑子里立起了一个人」→「脑海里浮现出了一个清晰的人物形象」;「往大里写」→「放大着写」——不在语文教研与日常通行说法里、且无上下文解释的短语,一律换通行说法);中心宾语残缺(「专挑你身上最扎眼的一处」→「…一处**特点**」;排查法:全文搜「一处/一样/一条/一件/那一回/这几样」,其后直接跟标点的逐处判;**反向刹车**:课内已建立的术语只在定义句处补全一次,回指不逐处补)。判据:**读出声,像不像一位真老师顺嘴讲下来**;正样本＝`prose-style-benchmark.md`。与第 5 条不矛盾:精简砍的是重复叮嘱与管理碎指令,不是句子成分;第三方向见 `style-criteria.md`,裁决位＝review-rubric Pass B。反向约束:增字不超原句一倍;不统一句长(真实短指令与学生话轮的粗糙口语保留);逐处判断,禁批量替换。不入机检,归 checklist E 组人工判。
  8. **教学指令正向表述:写法只作优劣对比,不判对错**:病征是「不要写……」「避免写……」式禁令把可行的写法说成写作错误(最隐蔽的来源是 `archive/` 重难点的否定式原文,照抄进师话即复发)。**判据先分两类**:写法偏好类(直接抒情 vs 细节描写、概括 vs 具体、朴素 vs 修辞……)一律不判对错,师话走三步——① 先承认它可行;② 出示另一种写法的样例,让学生自己比出差别;③ 把选择权交回学生,并明确说出两种可以搭配。题目要求类(跑题、漏要素、文体不对)是客观标准,可以说“不合要求”;③ 开头的审题辨析半步不受本条约束。**五个落点**:提纲表「核心技法」行 / ③ / ④示范文点评 / ⑥动笔前要点 / ⑦自评互评标准与修改指令(⑦最易漏)。**反向刹车**:减负性指令(“不用面面俱到”)照写;教师可以有倾向、可以推荐,只是把“禁止用”换成“我更推荐这一种,你来选”;真实性、格式、示范文身份等硬要求不作对比。**一句话判据:这句话是在告诉学生“怎样写效果更好”,还是“这样写是错的”?** 三步对比产生的「不是 A,是 B」句式在第 6 条⑦有例外。本条属生成层;自检见 checklist C 组,冷审见 review-rubric 跨维查项八。
  9. **禁预演式总结:不把还没发生的课堂结果写成既成事实**:师话与 `（教师总结）` 不得预先宣布全班表现(「大部分同学都想到了具体的事」)——真老师不可能预知全班答得怎么样,照着念会当场落空,也让后面的追问与补救没有着落。**判据是评价性完成体,不是「都」字本身**:将来时与任务分派、纯动作完成不算。**改法两条**:① 改条件式,把结论挂到实际出现的产出上(「谁写到了具体的事,举手让我看看」);② 指向具体某一位、不概括全班。已入 `tone_gate.py` FAIL 级(只扫 `师：`/`（教师总结）` 行;改判据须同步脚本 `PREEMPTIVE_PATTERNS`)。本条属生成层;与第 8 条不重叠(第 8 条治「把可行的说成错的」,本条治「把没发生的说成发生了」)。
  10. **过犹不及型技法须演三档,不给两极二选一**:病征是课堂只出示「完全不做」与「做过头」两个极端,学生就学成二元判断——见到过度形态被判掉,便推出「只要做就是错」,倒向另一个极端。**适用面是一整类技法**:点题、抒情、议论、修辞(比喻排比)、详略——凡「多了不行、没有也不行」的都算。**做法**:凡本课当众判掉了某种写法的**过度形态**,就必须在同一组对比里给出**适度形态作正样**——三档并排:完全不做(可行)／**适度(正样,不可缺)**／做过头(判掉);判掉那一档时要**点明判的是哪几句、不是那个做法本身**。**典型现场**:六上三《＿＿让生活更美好》三版结尾只有「只叙不议」与「喊口号」,而被判掉那版的头一句「洗碗让生活更美好」恰恰是合格的点题句,却跟后面三句口号一块儿被判掉——学生学到的是「出现『美好』二字就是套话」,写成只讲故事、不点明中心。**含蓄叙事≠完全不点题**。**点题与口号的分界在「跟着什么」**:跟着刚讲的这件事就是点题,跟着「每一个家庭／让我们从小事做起」才是口号;三档并排时**适度版与过度版都该含题目词**,比的才是落点、不是有没有那几个字。**反向刹车**:不是每条技法都要凑三档——只对「过犹不及」型适用;切题与否、真实性这类有客观对错的不适用(它们本就只有两档);三档共用一组材料、不另起环节。**与第 8 条的分工**:第 8 条治「把可行的写法说成错的」,本条治「只给两极、没给适度的样子」——即使完全守住了三步对比,只要两端都是极端,本条照样命中。**四个落点**:③ 效果对比／④ 示范文与旁批表／⑦ 三档标准与讲评／提纲表「核心技法」行。本条属生成层;自检见 checklist C 组,冷审见 review-rubric 跨维查项八。

  > 红线针对**市井 slang、学术黑话、花哨包装、低幼哄劝、书面抒情、电报压缩、否定式指令、预演式总结**八类。平实**不等于**干巴术语——师话层仍可亲切、具体、面向小学生,只是直说方法本身、不裹比喻;提示层一律用上表右栏的规范实操词。自检见 checklist.md E 组。

   > 以上 2–4 行事实**只来自 `references/course-map.md`**(取值口径见其 §六),不得手编;题目不在 course-map §三全表内时,「同类习作顺序」「教材要求」留空不编。

5. **学习目标**:**一句话**,说清这一课学生学会写哪一类文章,起句二选一——「通过<本课这一招>,来学习怎么写<某类文章／短文>。」或「掌握<格式或方法>;能<挑什么、做什么>,写成<某类习作>。」写法细项不进本行;不写效果检验句;不写活动载体包装。20–35 字为宜。
6. **核心技法**:两截,用句号断开。前截固定 **「使用“<本课构思工具名>”。」**——工具名取本课环节④那张卡/表在正文里的名字,与正文一致、不自造;没有卡表的篇目点名实际用的那件东西(写作提纲／段意梳理表)。后截平白地说这一招怎么做,两到三个分句,按课堂动作顺序排。「怎么落地」不得单列成行。

> **两行同禁**:反例、备选写法、任务成果包装、与「教材要求」行重复的抽象套话一律不进这两行;选材限定语(“自家独有的小事”)照留,另起一句的选材建议不写;用词不越阶段(三上不出现“写深刻”)。样例:
> - 三上《猜猜他是谁》——学习目标「通过抓住一位同学一两个最特别的地方,来学习怎么写一个人的短文。」核心技法「使用“人物特点卡”。从他身上挑出一两个最特别、最与众不同的特点,然后围绕这点,把他写清楚、写具体。」
> - 三上《写日记》——学习目标「掌握日记格式;能从一天里挑出最值得记的那一件事,写成一篇日记。」核心技法「使用“日记构思表”。把值得记的事情按顺序来写,把时间、地点、人物、经过和结果都写清楚;再写下心里的感受。」
> - 例外口:课型与阶段词相抵的篇目,两行可不含阶段词;工具在正文未冠名的篇目,提纲表可给它一个与正文说法对得上的名字,并在修订记录里注明。
>
> 两行值内**可用**成对 `**…**`(全文 `*` 禁令在提纲表内的唯一放行,为兼容存量稿保留),新稿不再加粗。**不设「工具与任务」「评价反馈」两行、不设区头行与「怎么落地」行,不得以任何名义加回或改名变相保留**——6 行以外不加行、表以外不加区。**不设独立教学目标节**:四维标签(`【语言运用】`等)整节取消,详案检索四维标签应为零。

> **标题体例**:`## 教案提纲表` 用无序号 `##`,其下直接跟表(看图写话线仍是三区版,勿互抄)。副标题 `X年级X册·第X单元 校内同步写作(<文体>习作)` 写在 H1 下一行——docx 首页版式化脚本按此行取副标题。头部只此一节一表,**不单设「任务背景」节**。
>
> **docx 首页版式化(导出后必跑)**:`PYTHONUTF8=1 python ../laojohn-lesson-plan/assets/style_front_page.py <详案.md> <详案.docx>`(看图写话与同步习作共用的单一源,本技能对应 `writing` 档、H1 自动判型;样式常量以脚本为准,改它须回归两条线)。

## 五、教学流程(血肉层 → 见 workflow-engine.md)

教学流程的具体走法由 **`references/workflow-engine.md`** 规定,生成时必读、逐环节照走:第 1 节 ① 真实情境抛任务 → ② 全感官唤醒 → ③ 一招技法 → ④ 示范文做样 → ⑤ 构思支架落地;第 2 节 ⑥ 自由倾吐(起步半环——L1–L4「降压起步」／L5–L6「定起点」→ 护表达流续写完篇)→ ⑦ 即时反馈 + 延迟纠错修改 + 自然收尾。

本节是**底座**,冲突时以底座为准。底座仍要求:每段在师话里显性点出本节训练点,但**不写“(此处落实……)”括号自注**;第 1 节尾不留课后任务;作品当次完成当次评改(教师课后精批属允许的额外动作,不得表述成“写不完带回家写完”)。
