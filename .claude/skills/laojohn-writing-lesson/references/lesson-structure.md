# 写作课课型结构与逐字稿格式

## 一、课型骨架(七环节,血肉层骨架)

写作课走七个环节,把四大价值观焊进流程。详细走法见 `workflow-engine.md`,此处只给骨架与各环节归属的课时。

| # | 环节 | 课时 | 价值观落点 |
|---|---|---|---|
| ① | 真实情境抛任务 | 第1节 | 真实情境 |
| ② | 全感官唤醒 | 第1节 | 全感官支架 |
| ③ | 一招技法(开头含「审题辨析」固定半步,见 workflow-engine 环节③) | 第1节 | 技法克制(底座) |
| ④ | 示范文做样 | 第1节 | 底座 |
| ⑤ | 构思支架落地 | 第1节 | 全感官支架落地 |
| ⑥ | 自由倾吐(护表达流;开场含「降压起步」降压半环,见 workflow-engine.md 环节⑥-起步) | 第2节 | 表达主权 |
| ⑦ | 即时反馈 + 延迟纠错 + 自然收尾 | 第2节 | 即时反馈 + 延迟纠错 |

七环节与档案「教学建议」的“作前/作中/作后”三段仍一一对应(①②③④⑤ ⊂ 作前+作中,⑥⑦ ⊂ 作中动笔+作后评改),生成时仍**以档案该任务的教学建议为内容蓝本**,只是按七环节重排节奏、注入血肉,不另起炉灶、不偏离档案的写作目标与技法。

> **附加块「习作讲评指导环节」(可选,不在七环节内):** 七环节是两节连排的核心、当堂评改闭环已完整;在此之外,每份详案末尾再**附一块可选的「习作讲评指导环节」**,供老师做⑦容不下的深度讲评(单次课课后用 / 系列课作下次课开场用)。它**不是第 8 环节、不计入 45+45**,走法见 workflow-engine.md「一之二」节,落位与格式见本文件 §三。

## 二、课时安排(固定:同次连排 2 节 × 45 分钟)

每次习作课 = **2 节课同次连排,每节 45 分钟**,中间课间休息。这是培训班的固定排课,不设单节模式、不询问。

| 节次 | 覆盖段落 | 参考切分 |
|---|---|---|
| 第 1 节(45 分钟) | 作前指导 + 作中指导(技法讲解、构思支架、示范文) | 作前约 20 分钟 / 作中约 25 分钟 |
| 第 2 节(45 分钟) | 当堂动笔完成 + 作后评改 | 降压起步约 5 分钟 / 自由写作约 17 分钟 / 评改约 23 分钟 |

切分可依任务浮动,但**每节各环节时长合计必须 = 45 分钟**,三段总体缺一不可。

> **L5–L6 切分要前重后轻**:上表「自由写作约 17 分钟」是中低段参考;L5 整篇约 450–500 字、L6 约 500–600 字+,⑥净书写(降压落笔+续写)不足约 25 分钟,慢的孩子当堂写不完(阈值见 review-rubric.md 维四)。高年级应把自由写作上调到约 25 分钟、相应压缩评改,或按下条「核心段当堂完成并评改、结尾段回家补完」处理,不要套用 17 分钟。

**连排约束**:
- 第 1 节课尾**不布置任何课后任务**,只收束构思成果并预告“休息回来就动笔”(口气可留悬念);第 2 节开头一句话接住(“带着你刚才填好的××,我们开写”)。
- 作品**当次完成、当次评改**,不存在“写完下周带来”。L1–L2 写话篇幅小,第 2 节动笔用时短,余量给“读一读、改一改、誊写一遍”或二次创作。
  - **“当次评改”指当堂闭环**:即时反馈(⑦)+ 带标准自改 + 同桌互改 + 老师轻点评 + 自然收尾,这一套必须在第 2 节内完成,不得推走。文末附加的「习作讲评指导环节」是**面向系列课/课后的可选深化**,评的是已当堂完成的稿,**不构成课后写作任务**(学生不回家再写),与本约束及连排约束均不冲突。
- 整篇当堂完成是默认要求;L5–L6 篇幅长确实写不完时,当堂完成核心段并评改核心段,结尾段落回家补完——这是唯一允许的课后延伸,且评改环节须围绕当堂已写部分设计。

## 二之二、课时定位(中性校内同步课)

本课是**校内同步习作课**,默认**中性定位**:不假设学生已学/未学本单元课文,也不假设是否已被学校指导过此题。课文与已学内容可自然引用作范例。由此两条与定位无关、但因课时结构与语气需要而保留的硬规则:

1. **连排内自含(课时结构,非先导)**:本课是单次两节连排(2 × 45),无法布置长周期准备。导入与例证只用当堂给得出的东西——游戏、情境、实物、图片、示范文、课文片段。档案教学建议里若依托校内长周期活动(如“提前一周观察”“课前带实物”“综合性学习成果展”),改造成**单次两节课内自含**的形态(用强视觉素材/课堂微观察/回忆唤醒替代长周期准备),但保留其真实内核;若依托单元课文,**可直接当堂出示/朗读作范例**,不必再绕成“自创情境”。
2. **收尾真诚、不喊机构卖点(语气护栏)**:这与定位无关,是语气底线——
   - **优先**自然收尾,把“今天这件事本身的意义”讲透即可(写信课收在“真把信寄出去/送到那个人手里”、写人课收在“路上留心观察、记进心里”)。
   - **不要**“别的同学才开始想/你比别人早一步”这类对比话术,也不说“拿给语文老师看”;结尾一律真诚、向着学生和作品,不向着“机构卖点”;作品收进档案、带回家、或按情境真实处理(如寄信),都比空喊衔接实在。

若用户说明该习作学校**已经讲过**,可转“提升与讲评”取向(可选,非默认二分):作前压缩(快速唤起,不重复审题游戏)、技法上探到档案难点、评改加重并对照学生在校已写稿(有则用)。默认不问、按中性同步课走。

## 三、逐字稿格式(与阅读详案同一套骨架)

全程逐字稿。固定话术骨架与 Markdown 标记沿用老约翰体系:

- 师话以 `师：` 开头;预设答案以 `参考：` 开头;学生环节写整行 `学生互动分享` / `学生自由分享` / `学生动笔写作`;小结用 `（教师总结）`。
- 文档主标题 `#`:固定写成 `# 《题目》· 写作课教学设计`(题目带书名号、不带年级册;用“教学设计”,不用“详案/教案”);**紧接下一行、中间不空行**写副标题 `<年级·册> 校内同步写作`——引擎把 H1 后紧邻的非标记行渲染为居中副标题,中间留空行副标题会失效。课时标题固定两个:`## 第1课时 · 写作指导课` 与 `## 第2课时 · 当堂写作与评改课`;环节 `### 一、…（X分钟）`。
  - **环节序号按课时各自从「一」重起(硬规则,不跨课时连续编号)**:第1课时五个环节编「一」到「五」;第2课时**重新从「一」起**——`### 一、〔降压起步平实环节名,如“借助构思表,写下第一句”〕（约5分钟）` → `### 二、自由写作（约X分钟）` → `### 三、交流评议,修改收束（约X分钟）`。读者每进一个新课时,序号都从「一」开始,符合一线教案“每课时各自成篇”的习惯。(七个价值观工作环节 ①–⑦ 是另一套贯穿两课时的内部连续编号,只写给生成器看、不进详案;别把它和详案里按课时重起的 `### 一、二、` 混为一谈。)
- **环节标题须专业平实(硬规则,违反返工)**:`### 一、…` 的标题要写成**一线语文教案那样的教学环节名**(动宾或并列短语,如“创设情境,明确任务”“观察体验,调动感官”),**严禁照搬本 skill 内部的七环节工作名**——`真实情境抛任务 / 全感官唤醒 / 一招技法 / 示范文做样 / 构思支架落地 / 自由倾吐 / 即时反馈+延迟纠错+自然收尾` 是写给生成器看的“价值观工作名”,带 AI/教研黑话味,**不是给老师看的标题**。推荐对照(可按本课技法点微调,不必逐字照抄):

  | 内部环节(workflow-engine 的工作名) | 详案里的专业标题(示例) |
  |---|---|
  | ① 真实情境抛任务 | 创设情境,明确任务 |
  | ② 全感官唤醒 | 观察体验,调动感官 |
  | ③ 一招技法(开头含「审题辨析」固定半步) | 学写法:〈本课主技法〉(如“围绕一个意思写”) |
  | ④ 示范文做样 | 出示示范文,发现写法(或“教师出示样稿”) |
  | ⑤ 构思支架落地 | 借助〈构思工具名〉,理清思路(如“借助构思表,理清思路”) |
  | ⑥-起步 降压衔接落笔(第2节开场半环) | 按平实教案式环节名(如“借助构思表,写下第一句”“先说一句,再落笔”);其行为支架方法(盯住一处看清/闭眼回想/限时快写)照用,但**不以游戏化叫法做标题**——亲切具体即可,直说方法本身、不裹比喻 |
  | ⑥ 自由倾吐 | 自由写作(写话课可作“写一写”) |
  | ⑦ 即时反馈+延迟纠错+自然收尾 | 交流评议,修改收束 |

  **「审题辨析」不单列环节标题**:它是③环节 `### 学写法…` 内部的开场首段(固定半步,见 workflow-engine 环节③),**不单列 `###`、不占课时内的环节序号**;详案里以平实说法(如“判断哪段切题”“审清题目要求”)出现在③的师话开头,无需为它另起一个「一、二、」。

  这条与本节「语言风格红线」一脉相承——标题层同样不要学术黑话;同理,`师：/参考：/（教师总结）` 等固定话术骨架是体系既定符号,不在此列、保持原样。
- 构思工具表/评价量表用标准 Markdown 表格(`|` 分隔,空格留空,单元格内换行 `<br>`)。
  - **填写型表格(构思工具表等)必须给“两格都填”的真表头(硬规则)**:首行写成 `| 项目 | 关键词 |` 这类两列均非空的表头,字段(如“这儿是哪里”“中心句”)放到表头下面的数据行去。**切勿把首个字段当首行、右格留空**(写成 `| 这儿是哪里 |  |`)——排版引擎会把“首格有内容、其余格全空”的首行当成**合并标题横幅**渲染、并把第一列强制压到 1.6cm,结果是该字段变成居中横幅、丢掉它本该留给学生填写的空格,且后续标签被挤窄换行。空白版与教师示范版两张表要用**同一套表头与字段行**,保持一一对应。
- 示范文用 `> ` 引用块,文首标 `【教师示范文】`(详见 model-essay.md)。
- 每课时末写 `本课完。`,两节正文末写 `全课完。`。
- **附加块「习作讲评指导环节」的落位**:置于 `全课完。` **之后**、文件尾 `VARIATION-FINGERPRINT` 指纹注释**之前**,作为详案的可选附加章节。用 `## ` 章节标题,标题须标明其“可选、两用”属性,例如:`## 附:习作讲评指导环节(单次课可选用 / 系列课作下次课开场)`。该块内容(选稿/围绕技法/一篇一肯定一改处/占位槽不捏造学生作品)走 workflow-engine.md「一之二」节;块内仍守弯引号、无星号、机构不拟人、固定话术骨架等全部格式硬规则。docx 引擎把它当普通 `##` 章节渲染,无需特殊处理。
  - **写成「三段式逐字稿」、不写干巴方法清单**:`## 附:…` 头部先用 blockquote 写两句(说明:可灵活取用+两用+不计入45+45 / 真实性占位提示),正文分**三节逐字稿**——`### 选稿(课前准备)`、`### 讲评流程(每篇约3–5分钟,围绕本课技法点)`、`### 收尾(点回技法)`,讲评流程里逐篇用 `师：` 师话 + 全角 `＿＿＿` 占位 + `(教师总结)`/`学生互动分享` 骨架,末尾 `本环节完。`(详细写法见 workflow-engine.md「一之二」,成稿样例见 `写作课详案输出/三上-这儿真美-写作课详案.md`、`三上-猜猜他是谁-写作课详案.md`)。
  - **附加块不参与教学环节序号**:它不是「环节」,三节小标题用**无序号描述性 `### 标题`**(选稿/讲评流程/收尾),**一律不冠 `### 一、二、三`**(否则会与第2课时重起后的「一、二、三」撞号、读着像又冒出一组一二三)。
- **中文引号规范(硬规则)**:详案正文一律使用全角弯引号——外层 `“”`、内层 `‘’`,**严禁**在中文语境使用半角直引号 `"` `'`,全文不得混用两种引号。半角符号仅允许出现在 Markdown 语法、行内代码、英文文件名/路径处。排版引擎虽有交替式安全网会补转 ASCII 直引号,但对跨行、奇数个、弯直混排会判错方向,**不可托底**;引号必须在 .md 阶段就写对,交付前全文检索 `"` 与 `'` 自查。
- **中文标点全角规范(硬规则)**:详案正文标点一律全角——逗号 `，`、冒号 `：`、问号 `？`、叹号 `！`、分号 `；`、圆括号 `（）`,**严禁**在中文语境使用半角 `,` `:` `?` `!` `;` `(` `)`（句号除外:中文句末用全角 `。`,半角 `.` 因小数/序号/英文歧义大、不强制转;HTML 注释 `<!--`、图片 `![` 等 Markdown 语法里的半角符号靠上下文判定自动豁免）。固定话术骨架 `师：`/`参考：`/`（教师总结）` 的冒号、括号同此。非标点符号保留原样、不在转换之列:数字范围用 `–`(如“3–4 人”)、流程箭头 `→`(如“远→近”)、并列斜杠 `/`(如“看/听/闻”)、乘号 `×`、全角竖线 `｜`;Markdown 语法、行内代码、英文路径处的半角符号亦不动。与上「中文引号规范」一脉,半角标点须在 .md 阶段就写对,交付前全文检索半角 `,:?;()` 应为零(扣除上述豁免)。**适用范围 = 初稿 + 此后每一次局部增改**,改一处就地重扫,不因“只是小修”跳过。
- **行内强调禁令(硬规则)**:详案正文**严禁使用 `**`、`*`、`__` 等行内强调标记**——单星/单下划线斜体 `*…*`、`_…_` 引擎不解析、会原样印进 docx;成对 `**` 虽会被引擎转成加粗,但本 skill 一律不用(小标题靠 `【】`标签与固定话术骨架承载),保证详案检索 `*` 为零。**唯一例外＝`## 教案提纲表` 一节之内**(2026-07-22 提纲页定稿后收口):两个区头行 `**N、区名 —— 副题**` 是首页版式化脚本的解析锚;「怎么落地」「学习目标」两行值内的成对 `**…**` 是版式化脚本认的强调标记(渲成主色)。`*` 自查应**只命中教案提纲表节内**、正文各课时为零。这条覆盖一切位置:师话、参考、示范文、表格单元格、习作要求,无一例外。需要强调时靠话术本身(重复、设问、停顿提示如“——”),或交给 PPT 锚点呈现。注意:本 skill 各规则文件里的加粗是写给生成者看的规则强调,**不是**详案可用的标记,不得模仿进产物。交付前全文检索 `*` 自查,应为零。
  - **填空横线写法(配套约定)**:讲评模块占位、师话里让学生口头补全的横线等,**需要“填空横线”时一律用全角 `＿`(U+FF3F)、不要用 ASCII 下划线 `_`**——连写的 `______` 会被引擎当成成对 `__` 加粗标记、整段剥除,横线在 docx 里凭空消失,且违反上一条 `__` 禁令。横线旁可附 `(占位:…)` 说明老师填什么。交付前全文检索 ASCII `_` 应为零(Markdown 语法/英文路径除外)。
- **机构名不拟人(硬规则)**:“老约翰”是机构名,不是教师名。师话中教师一律自称“老师”,**严禁**出现“老约翰说”“老约翰老师”“我是老约翰”等把机构当作授课人的称呼。机构名只允许出现在文档头部/页眉等品牌信息位,不进入任何教学话术。
- **语体分层(硬规则)**:详案内含两套语体,各守各的口径,不得串味。
  - **师话层**(`师：`、`参考：`、`学生互动分享` 等讲给学生听的内容):**亲切、具体、面向小学生**——把抽象技法讲得好懂、**直说方法本身**,必要的拟声词(“咯吱咯吱”这类帮“写具体”的)可留;但**少用或不用形象比喻**——磁铁/拐杖/钩子之类的包装一律去掉、平实直说(见下「语言风格红线」第四条),用词专业平实、不写成教研论文式术语,“技法”就叫“技法/方法/要点”,不说“小妙招”。
  - **提示层**(方括号舞台提示 `[…]`、括号旁注如 `(教师巡视时…)`、巡视说明:**写给授课老师看、要被另一位老师照做的内容**;注意逐环节价值观自注 `(此处落实…)` 已整类删除,不属此层):一律用**清楚、专业、可执行的规范指导语**,**严禁**口语化随意词。典型反例及改法:`递话`→`提示/介入`;`喂具体`→`提供具体素材提示/引导落到具体景物`;`让路`→`不打断、为其留出书写空间`。判据一句话:这句是“讲给学生听的”还是“讲给老师做的”——前者可口语,后者须规范。
  - **方括号提示的标注体例(统一格式 · 硬规则)**:教师现场提示(出示材料/板书/巡视分层/异常处理/学生类型等)统一用半角方括号 `[…]` 作标记——它是结构标记、**保留半角 `[]`**,以区别于固定话术标签的 `【】` 与 PPT 页标的 `〖〗`;方括号内若是「类别/情形 + 说明」,二者之间一律用全角冒号 `：`(如 `[异常处理：学生上台憋不出话]`、`[无从下笔型：握笔不动、盯着稿纸发呆]`),**不得用 `——`、`·` 等当分隔符混用**;方括号后若紧接引出正文,冒号亦全角(`]：`)。同一份详案内这类提示的写法须前后一致。
  - 自检:交付前快速扫一遍所有 `[…]` 与 `(…)`,凡含义含糊或口语随意的指导动词,改为明确动作描述;`（教师总结）` 等固定话术骨架属师话层,不在此列、不得改写。
- **`参考：`预设学生答案拟真(硬规则 · 2026-07-23 增设)**:`参考：` 给的预设学生答案不得清一色完整、切题、书面化——那不像本年级学生当堂说出的话,老师照稿备课后接不住真实课堂。两半做法,缺一不可:
  - **一部分参考答案写成本年级的粗糙短口语**(不完整、口语碎、贴年级语感;措辞按本课内容自拟,禁跨篇复用同款“粗糙句”),同时**保留一部分完整答案**作理想参照;
  - **链条补全(关键)**:凡粗糙答案不完整、而后续教学依赖完整信息(要拿它进构思表、进示范讲解、进讲评)的,教师话轮必须紧跟一句追问或补全,把缺的信息当堂补齐——只把答案改糙、不补教师追问,教学链条就断在那一步。
  - 判据(正向):把每处 `参考：` 读出声,问“像不像这个年级的孩子当堂说出来的”;再顺读其后教师话轮,问“老师拿这个答案能不能把课接下去”。自检见 checklist E 组对应条;冷审见 review-rubric.md 维二。
- **语言风格红线(硬规则 · 专业且平实,规范且易懂)**:全文(师话层与提示层)用词守住“专业平实、规范易懂”这条中线——**既不市井江湖、也不晦涩学术,也不靠游戏化叫法和形象比喻撑场面,也不低幼哄劝、啰嗦重复**,像一位有经验的老师在跟同行平实交代这节课怎么上、跟学生把方法讲清楚。**适用范围 = 初稿生成 + 此后所有改写/局部增改**:每次对产物文字的增、删、改(含按用户反馈做的迭代优化、单句润色、插入新环节/新话术)都须就改动处重过本红线与 checklist E 组自检——**不因“只是改一句/只是小修”而豁免**(市井词、学术黑话最常在事后的局部增改里悄悄混入)。五条边界:
  1. **禁市井化与网络口语**:不用“写嗨了”“卡壳了”“命根子”“主菜”“小妙招”“炒菜/食材”这类非正式词;也不把“兜底”作为详案里的字面用词(“兜底”是 skill 内部机制名,如“未读兜底/通用兜底”,**不得原样落进详案产物**)。
  2. **禁晦涩学术词汇**:不用“学习支架”“知识建构”“学情干预”“最近发展区”“多模态”等过度理论化术语(内部档位词如“A 档”本就禁入正文,见 technique-levels.md)。
  3. **改用中性、准确的实操词**,常见对照:

  | 详案里禁用(市井/网络) | 改用(规范业务词) |
  |---|---|
  | 兜底 | 基础辅导预案 / 补充引导 |
  | 卡壳了 / 卡住 / 卡着 | 无从下笔 / 起步困难 |
  | 写嗨了 / 写得起劲 | 书写顺畅 / 已顺利完成 |
  | 命根子 / 主菜 | 关键环节 / 重点内容 / 核心 |
  | 小妙招 | 方法 / 要点 / 步骤指引 |
  | 递素材 / 喂具体 | 提供具体素材提示 / 思路引导 |
  | 让路 | 不打断、留出书写空间 |
  | 学习支架 | 构思引导 / 思路引导 |
  | (抛任务的)情境 | 情境描述 / 真实情境 |
  | 磁铁 / 拐杖 / 钩子 / 空壳子(把抽象词比成“空壳子”再“打开装东西”,等形象比喻) | 直说方法本身(围绕中心意思写 / 把“急”“美”这类抽象词,落成看得见听得见的样子) |
  | 上墙评审 / 辨一辨 / 30秒大倾泻(等游戏化叫法) | 平实教案式环节名(判断哪段切题 / 借助构思表写第一句) |

  4. **禁游戏化叫法与形象比喻(覆盖所有年级)**:环节标题与师话**直说方法本身**——不用“上墙评审/辨一辨/30秒大倾泻”这类游戏化叫法,也不用“磁铁/拐杖/钩子/空壳子”这类形象比喻给方法裹包装(如把抽象词说成“是个空壳子、把壳子打开装进东西”——直说“把‘急’‘美’这类词,写成看得见听得见的样子”即可)。“围绕一个意思写”就直接说“写的每样景物都得跟这个中心意思有关、不沾边的不写”,“词语小仓库”就说“只作参考、不照抄”。这条**覆盖所有年级**(含 L1–L2 写话:亲切、多示范、多肯定即可,不靠游戏化、夸张语气);拟声词(咯吱咯吱)是“写具体”的手段、不在此列。降压起步那套行为支架(盯住一处看清、闭眼回想、限时快写)**方法保留,只把环节名与叫法改平实**。

  5. **语气适龄,不哄不啰嗦(覆盖所有年级)**:面向小学生要亲切,但**信任学生、不把学生当更低龄**——① **不反复情绪安抚**(“别怕/别有压力/不会卡/没关系”式的心理按摩;个别学生当堂卡住时,巡视里临场安抚一句属具体指导、不在此列);② **不用一二年级写话式的过度兜底**铺给全体(如把“不会写的字用拼音”“一句一句喂到底”当三年级以上的常规手段;实在写不出再个别给台阶);③ **师话精简、不啰嗦**——同一意思不反复说、不层层叮嘱,一句能讲清就不写三句;减压点到为止,一句“写三处就行”足够,不堆一串“别有压力、不会卡、很棒了”;**过场/管理指令同样从简**——让学生拿材料、就位这类过场一句带过(“把特点卡拿出来”即可),不逐项叮嘱“平放桌上、笔和纸摆好、坐端正”这类管理碎话。④ **动作指令须有真实功能、不为形式而加,不预设学生处境**:让学生做的动作要对完成任务有实际作用——不无故让学生“闭上眼睛”“用手比个框”“手指点着表”这类对写出东西没用的摆拍动作(降压与构思的支架靠问题、步骤本身驱动,不靠摆拍),也不预设学生的物理处境(如“看你左手边那张表”——你并不知道表在哪边,“看你那张表”即可);判据是“这个动作对写出东西有没有用”,没用就删。降门槛靠把任务拆清楚、脚手架到位,不是靠哄。

  > 红线针对**市井 slang、学术黑话、花哨包装、低幼哄劝**四类:既不市井江湖、也不晦涩学术、也不靠游戏化叫法与形象比喻撑场面、也不靠反复安抚和过度兜底把学生当更低龄。但平实**不等于**干巴术语——师话层仍可亲切、具体、面向小学生(必要拟声词如“咯吱咯吱”保留),只是**直说方法本身、不再裹一层比喻**;提示层一律用上表右栏的规范实操词。自检见 checklist.md E 组。

## 五、教学流程(血肉层 → 见 workflow-engine.md)

教学流程的具体走法由 **`references/workflow-engine.md`** 规定,那是强制骨架,生成时必读、逐环节照走。它把四大设计价值观(真实情境 / 全感官支架 / 即时反馈 / 表达主权与延迟纠错)焊进固定七环节:

第 1 节:① 真实情境抛任务 → ② 全感官唤醒 → ③ 一招技法 → ④ 示范文做样 → ⑤ 构思支架落地
第 2 节:⑥ 自由倾吐(开场「降压起步」按文体调行为支架写出第一组句子 → 护表达流、零打断纠错续写完篇)→ ⑦ 即时反馈 + 延迟纠错修改 + 自然收尾

本节(课型骨架、课时、定位、格式、书级头部)是**底座**,与引擎不冲突;冲突时以底座为准。底座仍要求:每段在师话/技法讲解里显性点出本节训练点(把“今天练的是……”讲给学生听),但**不写“(此处落实……)”这类括号自注标签**——逐环节括号自注已整类删除(见 workflow-engine.md 环节① / checklist.md G 组 / variation-pools.md 表层指纹一节);第 1 节尾不留课后任务;作品当次完成当次评改(教师课后精批属允许的额外动作,但不得表述成“写不完带回家写完”)。
