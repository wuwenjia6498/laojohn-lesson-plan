# 书目 × 习作任务对照档案(book-writing-map)

> 用途:让**写作课**能命中学生在读书会读过的书,做素材级连接(单向:写作课→书目;读书会不查本表)。**人工编辑的教学映射,非官方内容**;书单与习作任务均另有官方来源,本表只负责“谁连谁”。

## 使用规则

1. **单向查询(仅写作课用)**:`laojohn-writing-lesson`(写作课详案)按**习作任务**查:命中则师话可引用对应书目(须带未读兜底),示范文可化用书中素材。读书会详案(`laojohn-lesson-plan`)**不查本表、不生成“写作指认”**,读书会照常进行。
2. **任务向后原则**:连接只指向学生当前或未来的习作任务(书目年级 ≤ 任务年级,跨度一般不超过两个年级)。
3. **宁缺毋滥**:不在本表中的任务 = 写作课全程不提书目。连接点是方向提示,不是台词,话术现场生成。
4. **口袋六类**(与习作文体同一坐标系):写人 / 记事 / 写景状物 / 想象 / 说明说理 / 应用与综合。
5. **真实性**:引用书中内容时只可使用本表连接点级别的概括与自己读到的确凿情节,不得编造书中细节;没把握就不引。

## 未匹配说明

未列出的书目(约70本)为有意不匹配:或主题与任何习作任务咬合不紧(如《小狗钱钱》《给孩子的小岛经济学》),或仅能向后兼容已过去的任务(如六年级读《昆虫记》,而说明文任务在五上)。一年级书单匹配少属正常——写话阶段以句式与看图为主,书目连接价值本就有限。后续书单调整时,按本表口径增删条目即可。
