# 写作课详案自检清单（交付前逐项核验）

> 只留「查什么 + 判据 + 单一源」。各条来历见 `history/checklist-history.md`。**第 5 步自检时读，生成时不读。**

## A. 依据与真实性（任一不过即返工）

- [ ] 习作要求、重难点、官方环节均来自档案该任务记录，未编造“课标说”“官方要求”类条款
- [ ] 自拟主题时文首已标注推定依据（学段目标 + 最相近任务），未伪称“官方指导”
- [ ] 示范文标注 `【教师示范文】`，无伪造学生作品、无冒充名家/教材、无编造出处
- [ ] 示范文中客观数据/史实有来源，无来源处已占位 `（此处数据以…为准）`
- [ ] 全文无任何无来源的带引号“原文摘录”
- [ ] 附加讲评块只给方法框架 + 占位槽，无捏造的“学生作品”

## B. 结构、时长与课时定位

- [ ] 两节齐全，七环节齐备：①情境→②感官→③技法→④示范文→⑤支架；⑥自由倾吐（含起步半环）→⑦反馈+纠错+收尾
- [ ] 第 2 节开场有起步半环（L1–L4 降压起步约 5 分钟／L5–L6 定起点约 3–4 分钟，第一个 `### 一、`；唯一例外 L6 可并入自由写作）：未套「一句扩三句」；行为支架按文体调对（写人快问快答／写景状物聚焦细看／记事慢镜头／想象抒情限时倾泻）；三件套齐全（锚定旧知定位到构思表具体格子 + 策略执行 + 当堂落笔）；L5–L6 方向一次给出且先判断再落笔（判断是可指认的动作、只在已填表上取舍、不出现心理按摩措辞）；起步产出按文体归位、不笼统当成品开头，L5–L6 须交代那一段落在整篇的位置。判据见 `workflow-engine.md` 环节⑥-起步
- [ ] ③ 开头有「审题辨析」半步：教师自拟切题/跑题两段 → 学生判断 → 审题引出主技法；不单列 `###`；反例 A 段在「具体不具体」上不输 B、只错在本课那一条；参考答案含「会有学生选 A」；师话先接住选 A 者、说实质不说长短；指纹「审题辨析形态」的程度描述与正文相符。判据见 `workflow-engine.md` 环节③
- [ ] ① 未提前给出 ③ 的判据、未剧透 ④ 指向性问题的答案：① 只说成败的外部标准，不说写法道理；检查法＝把 ① 与 ③ 的判据并排读，凡因果落点同义即命中
- [ ] 每节各环节时长合计 = 45 分钟，环节标题带时长
- [ ] L5–L6 自由写作标称 ≥ 25 分钟（硬下限；L6 并入起步则 ≥ 28）；篇幅要求明显偏低的任务按实际字数折算并注明理由。见 `lesson-structure.md` §二

- [ ] 环节内纯书写/纯活动时长 < 环节标称总长（留出师话）
- [ ] 师话里的时间断言与环节标称对得上：检索 `师：` 行的「N 分钟／一节课／整节课」逐处核；对学生报的「写完一整篇的时间」= ⑥ 纯书写时间，不拿 45 分钟充数

- [ ] 作品当次完成当次评改，当堂闭环完整（即时反馈+自改+互改+轻点评+收尾）；未表述成“写不完带回家写”

- [ ] 连排自含：导入与例证当堂可得，未依赖课前长周期准备
- [ ] 第 2 节结尾真诚贴题；无“比别人早一步”“拿给语文老师看”等对比话术与机构卖点
- [ ] 提纲表与正文头身一致：「核心技法」主线与做法、「学习目标」产出物逐项与正文对表；改正文必回改提纲表同一格
- [ ] 书级头部＝`## 教案提纲表` 下两列表恰好 6 行、零区头，行序：课题·课时／能力阶段（本课阶后「（本课）」）／同类习作顺序（本课后「（本课）」）／教材要求／学习目标／核心技法。见 `lesson-structure.md` §四

## C. 技法与分级

- [ ] 技法克制：技法点 ≤ 2–3、未满堂灌、第 2 节练笔充足、不超档案重难点深度
- [ ] 技法深度符合该级边界（`technique-levels.md` §二「技法边界」；L1–L2 无术语）
- [ ] 学段口气已分级：对照 `technique-levels.md` §二「口气栏的落地动作」逐核 ③ 技法怎么抵达／⑤ 构思怎么引导／⑦ 评改问什么；`参考：` 行判据口径同受约束（学生不拿字数当判据）。判据＝把本篇降两级用要不要改，改不动即未分级
- [ ] 构思支架至多 1 个，空白表格/节点清单落地，有「引出→填写→分享+反馈」完整环节，与技法点咬合
- [ ] 正文未漏出内部机制名：全文检索「A 档／降压／定起点／兜底／锚点／指纹／台账／零件／池」（作机制义）为零，师话逐句查；提纲表/方括号提示/环节名人工扫（「池」以外的词师话与参考行已由 tone_gate 机检；「池」机器分不出机制义，人工扫）
- [ ] 提纲表所列支架与正文一一对应
- [ ] 口诀/自造类比/学情标签每字可懂，自造词当场一句话点透，否则不用
- [ ] **对学生下的格式性规定没有说死（0921 三篇实证）**：凡师话/技法行/三档标准里出现的可验证规定（「每段段首一句点明方面」「数字要说准」「用两种说明方法」），逐条拿**本篇引用的课文＋教师示范文＋三档标准**三处各验一遍；有一处不成立就把口径放宽（→「开头一两句」／「有把握的就写准，拿不准就写大约」／「多用几种」），并**全篇同步**（五上五实测：归纳句·旁批表·指纹块三处漏改，隔一轮才清净）。同族第二问：**有没有把学生的正常写法设成判断题的错项**——「很大」「很快」这类总说句本身不是错，该判的是「后面有没有跟上把它说清楚」（与红线第 8 条同向）
- [ ] 教学指令正向表述：检索“不要写／不能写／不许写／避免写／别写／不用写”，写法偏好类改三步对比（承认可行→出示另一种样例→选择权交回并说明可搭配），题目要求类可判；五落点＝提纲表核心技法行／③／④／⑥／⑦；档案否定式原话不直接进 `师：`。见 `lesson-structure.md` §三红线第 8 条
- [ ] 过犹不及型技法演了三档：本课若判掉了点题／抒情／议论／修辞／详略的**过度形态**，同一组对比里有没有**适度形态作正样**（三档：完全不做／适度／过头）；判掉那一档时有没有点明判的是哪几句、不是那个做法本身（点题类的分界＝跟着这件事是点题、跟着「每一个家庭」是口号；适度版与过度版都该含题目词）。四落点＝③效果对比／④示范文与旁批表／⑦三档标准与讲评／提纲表技法行。见 `lesson-structure.md` §三红线第 10 条
- [ ] 示范与归纳的要素数一致：含数量词的师话回上文数得上（模糊量词从宽、确数从严）；连用多例特征数只持平或递减；每个示范段只承载一个技法点；旁批表行数与师话点名数一致；教师示范填卡守住填写口令（逐格数字数）；同一数量词全篇指代稳定。见 `workflow-engine.md` 环节③同名条
- [ ] 筛选类判据覆盖本题全部话题：本篇 ③ 若给了筛素材/选材的判据，拿 `archive/` 该任务「习作要求」列出的话题逐类过一遍，有一类过不去即须分型或换判据；正反例、构思表示范填、示范文、三档标准的题材不得全落在同一类。见 `workflow-engine.md` 环节③同名条

## D. 示范文

> 判据唯一源 `model-essay.md`（先读其〇「一屏卡」）；本组只列查什么。

- [ ] 身份 `【教师示范文】`、无伪造/冒充/编出处；客观数据有来源、无来源已占位（A 组已核，此处只复核示范文）
- [ ] **机检 E（每份必跑）**：`PYTHONUTF8=1 python .claude/skills/laojohn-writing-lesson/assets/essay_audit.py <详案.md>`——篇幅段数实数在本级区间；引文逐字审计「疑似改写」＝0（截断可、改写不可）；旁批表引句列每格是示范文子串；笔法锚点题材／整句零复用。师话与旁批表里的可数断言（几段／最长段／一句带过／几处）一律按 ① 实数回填，改法优先改示范文
- [ ] 出示位置正确（L3+ 后置；L1–L2 可前置）；出示后有指向性问题且分结构层＋句子层；作后评改有回指；投屏与标题不预告答案。见 `model-essay.md` §四、§四之二
- [ ] 技法要素可一眼指认，有「写具体」的样子。见 `model-essay.md` §五 1–2
- [ ] **要领数不超（§五 3）**：把旁批表右列每条 ＋ ④ 讲解点名的每条「写法／要领／做法」抄成清单，**逐条**回提纲表「核心技法」行找对应短语，标〔找得到／找不到〕。找不到的**先判是不是真工具**——问「这条删掉，学生写这一篇会不会真少一件工具」：是真工具就**补进核心技法行**，不是就降为一句提醒或删
- [ ] **旁批表双标准（§五 4）**：① 核心技法行拆成要素清单，逐要素回旁批表右列找，缺一即不过；② **先不看表**，自己挑出全篇最见功夫的两句写下来，**再**核它们在不在表里，不在就补（结构呼应算一处）。②的顺序不可倒——先看表再挑句等于没做
- [ ] **起笔落点不与 ③ 反例同型（§五 5）**：把 ③ 反例段首句与示范文首句**并排原样抄出**再判，结尾落点同理。**判的是「③ 判词实际判掉的那个点」，不是首句形态像不像**——先抄出 ③ 的判词原话，问「学生照这堂课念下去，会不会得出『这么起笔＝跑偏』」。两种情形不算同型：① 该特征是 ③ 正例段与反例段**逐字共用**的；② 该特征**写在本课提纲表核心技法行里**。⚠ 用 ② 豁免前先过 §五 3 那一问——「这条删掉，学生写这一篇会不会真少一件工具」，答不上就是为豁免临时补的短语，不作数
- [ ] 例子独一份四判据（管全篇教师自拟例子·**细节层**）：换一个人不成立（不用于判「事例与抽象主题词的绑定」）／夸张≠计数／④ 不低于 ③ 正例／一篇内锚点不复用。见 `model-essay.md` §四之四
- [ ] 示范文的「我」与素材域：「我」是与学生同龄、过当下日子的人；**素材对标问＝本班学生照这篇去找自己的素材，找得到，还是只能编一个？**；机检 E ⑦ 会报成人当下生活词候选（下班／同事／房贷／开会／我女儿…），逐条查是否作了主线素材；④ 出示时有明说身份与岁数的那一句。见 `model-essay.md` §二
- [ ] 笔法锚点五条：短句动词／形容词克制／情感不命名／**收尾两选一**（不升华停在动作上留余味／适当点题抒发但不过度；「不升华」≠「不准点题」）／**够得着**（本级优等学生写得出，成年人的笔 ≤2 处，够不着走讲评本班真作占位不虚构）。见 `model-essay.md` §四之三
- [ ] 可信度七问过（逻辑／人物设定与时间锚／知情边界／调子克制／共用例子事实一致／想象类不越题目与图组边界／不自犯本课反例的病）。见 `model-essay.md` §六
- [ ] 引本单元课文佐证（匹配则引）：先判配不配（不配就不引，文末 `<!-- UNIT-TEXT-DECISION … -->` 记结论）；引则 ③ 两处卡位各一处；篇名/单元/写法要点均在 `unit-texts.md` 查得到；不输出带引号原文；选篇最突出的写法正是本课这一招。见 `workflow-engine.md` 环节③
- [ ] 题材域已按台账与池 4 避重，指纹块「示范文题材」已填
