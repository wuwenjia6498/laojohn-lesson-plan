## B. 结构、时长与课时定位

- [ ] 两节齐全,七环节齐备:第1节 ①真实情境→②全感官→③技法→④示范文→⑤支架;第2节 ⑥自由倾吐(开场含起步半环——L1–L4「降压起步」／L5–L6「定起点」)→⑦即时反馈+延迟纠错+收尾
- [ ] **第2节开场有起步半环**(L1–L4「降压起步」约 5 分钟／**L5–L6「定起点」约 3–4 分钟**;作为该课时第一个 `### 一、`——**唯一例外:L6 可并入自由写作、不单列 `###`**,2026-08-30 放行,并入时三件套仍须逐件写在自由写作开头,L5 不适用此例外):① 未套「一句扩三句」或纯写法复述充数;② 按本课文体调对了行为支架(写人=快问快答采访法(做派类问动作/表情/声音;纯外貌类改问看清/比/像、并配一件体现它的事) / 写景·状物·观察·说明=聚焦细看法 / 记事·叙事=慢镜头回放法 / 想象·抒情·读后感·倡议=限时倾泻法);③ 强制三件套齐全(锚定旧知点名定位到第1节构思表的具体关键词 + 策略执行含代入感教师直接引语与学生配合动作 + 当堂落笔写出第一组句子并顺接自由写作);**③之二 领的颗粒度按学段调(2026-08-17 立)**——行为支架内核不变,但 L3 可一句一句领、**L5–L6 须把几个方向一次给出,由学生自己定先写哪一样、写几句**(台阶低 ≠ 领得细);判据:**这一段读下来,学生是在自己组织还是在填空?** L5 仍在填空即不合格(判据与实测反例见 workflow-engine 环节⑥-起步矩阵下同名条);**③之三 L5–L6 内核改判为「定起点」(2026-08-30 用户拍板)**——这几分钟里学生做的**不是零评判快写**,而是**先判断再落笔**:哪一处最有话说、该写得最厚、整篇从哪一句起笔,**定下来才动笔写这一处**。逐项核:**(a)** 判断是**可指认的一步**(表上圈定/标序,或口头说出「我先写哪一处、为什么」),不是师话里丢一句「你自己定」就算;**(b)** 判断**只在⑤已填好的表上做取舍排序**,未借机重开选材、未变成第二次构思;**(c)** 方向清单与句数量级仍然给出(改判不是撤台阶);**(d)** 环节名与师话里**不出现「降压/减压/别怕/没关系」式的心理按摩**(那是 L1–L4 的口径,在高年级同时违反语言红线第 5 条①)。⚠ **只做到③之二(方向一次给出)、仍按快写降压走的,不算合格**——两条叠加生效;④ 游戏化环节名与教师直接引语未同年级逐字复用;⑤ **起步产出未被笼统当成成品开头**——L1–L4 描写类(写人/写景/状物)起步第一句先快写点题中心句、随后细节问题写两三句具体的,一条链不分阶段(中心句即链首,不另起起手句/过渡);写序=正文序,⑥接着补事/景、叙事类高潮感觉句可直接作 hook、倾泻类素材先选定再展开,均按文体归位,未出现「这几行就是你这篇开头、顺着往下写」式跳过中心句的接法。**L5–L6 另核一句位置交代**:学生定下的那一处常在篇中,衔接师话须点明「这一段落在中间／正好可以当开头」再让他往下补,**漏了这句即命中本项**(与上面踩同一个坑)
- [ ] **第1节③(一招技法)开头有「审题辨析」固定半步**:出切题/跑题两段对照样例(教师自拟、非冒充“某学生作品”或课文原文)→ 学生判断哪段切题 → 老师顺势审题(点明本课写什么/避开什么,咬合档案习作要求)并引出主技法;它是③内部首段、不单列 `###`、不占环节序号;现场呈现名用平实教案式(如“判断哪段切题”、不用上墙评审/辨一辨这类游戏化叫法)、与话术未同年级逐字复用。**⚠ 反例(A 段)不得敷衍(2026-08-17 立)**:A 段须**刻意写得细、可比 B 段更长**,在「具体不具体」这维上不输,错只错在本课那一条上——A 段明显更短更干 = 学生凭「谁写得好」就选对了,这半步白做(判据滑到写得好不好)。**逐项核**:① **实质判据**——A 段在「具体不具体」这维上输不输给 B?输了即返工(**字数各数一遍只作粗筛**:A 明显短于 B 必不合格,但字数够了不等于合格);② 参考答案里有没有「会有学生选 A」的拟真项;③ 师话有没有先接住选 A 的学生再抛判据,且**承认 A 的长处时说的是实质不是长短**(「颜色尺寸都交代了、画面也有」,不是「它写得多／比第二段长」——拿篇幅当课堂比较维度是把判断口径降到低学段);④ 指纹「审题辨析形态」的程度描述回正文量得上(**指得到 ≠ 描述属实**,判据与三处存量正例见 workflow-engine 环节③同名条)
- [ ] **① 不得提前给出 ③ 的判据(2026-08-18 立 · 纯语义、机检抓不到)**:① 真实情境抛任务只许说**成败的外部标准**(什么算做成了/什么算没做成、谁来判、怎么判),**不许说「为什么」**——凡在 ① 里解释「样样写就记不住／平摊着写谁也立不起来」这类**写法道理**,③ 那次两段对照就成了走过场:学生开课头几分钟已经拿到判据,到 ③ 只是复述,本组上一条辛苦经营的「反例不得敷衍」「参考答案要拟真到承认有学生选 A」随之全部失效(选 A 的学生本就该存在,①先交底则连这个拟真反应都不会发生)。**逐项核**:① **定位 ① 全段里所有带因果的句子**(那多半是因为…／…就记不住／之所以…),凡因果落点与 ③ 的判据同义即命中,删掉因果半句、只留成败标准;② 同理**不得提前剧透 ④ 示范文指向性问题的答案**(如 ① 里先说「写老师最要紧的是找一件只有他做得出的事」,④ 再问「换一位老师碰上这件事会怎么办」就没有发现可言);③ 反向不禁——① 用比喻/类比给学生一个**图像层**的概念(如「写的不是照片那样的像,是漫画那样的像」)不算命中,**判据是:这句话是否已经能让学生在 ③ 直接答对**,能即返工、不能则放行。**检查位:定稿前把 ① 全段与 ③ 的两段对照判据并排读一遍**(单看 ① 读不出问题,单看 ③ 也读不出,只有并排才暴露)。⚠ **实测留痕**:2026-08-18 五上《“漫画”老师》,① 成败标准末句「那多半是你把他身上五六样都写了一遍,哪一样都没写足」正是 ③ 两段对照要学生判出来的那条;tone_gate 与 D 组各条均不覆盖此形态,是通读 ①③ 并排才发现的

- [ ] **情境先查官方锚点、兑现必须课内闭环(2026-07-31 立)**:① **先查 `situation-anchors.md` 本任务那一行**——官方情境/官方反馈活动栏有内容的直接用或按右栏改造,**尤其标了「已自含」的不得再自造载体**(池0「不造轮子」的落地检查位;判例:三上《续写故事》官方反馈本是「同桌评衔接、小组比不同结局」,旧稿却自造了「结局收集箱」投稿情境);② **开场承诺的兑现动作必须全部发生在这两节课内**——机构课**没有「下次课把上次的稿子拿出来读」这回事**(下次是新课次),凡写「投进箱子等下次读」「贴出来以后大家看」这类课外兑现,等于开空头支票,须改成当堂做完;③ **承诺的覆盖面要兑得了**——说了「全班都会读到」,就不能只抽 3–4 人念完事;全班环节相应改为各组推优或抽样。**「人人被听见」的可行做法不止一种,按本课情境选最贴的**:小组内轮读(听觉,覆盖最稳)／**排内朝同一方向传稿、人人被邻座读到**(书面,更贴「靠文字认出来」这类情境)／同桌互念两轮／分批全班念(前半批、评改后再一批)／自由结对找一个人念给他听(L4+)。**⚠ 别每篇都取第一个(2026-08-17 补)**:本条 2026-07-31 立时只点名了「小组内轮读」一种做法,实测四上起连续四篇⑦位全部落成四人小组(见 G 组池5 对应条),**推荐做法写成唯一做法就是同质化的来源**
- [ ] **全感官支架**:构思(⑤支架)之前有②全感官唤醒环节(微型游戏/实物观察/强视觉素材/情境演练/感官回忆),先动后写
- [ ] **支架减负**:构思支架填关键词非句子,三五分钟可完,未让填表本身变成新负担
- [ ] **即时反馈**:第2节有当堂、具体、覆盖面广的反馈节点(猜猜他是谁/金句墙/小解说员分享等),反馈对事且具体,非空泛“写得好”,且尽量多孩子被点到
- [ ] **表达主权**:⑥倾吐期巡视只做正向介入(提供具体素材提示、引导落到具体景物、为顺畅者留出空间不打断),无“纠错字、改格式、改病句”动作;护接地气的个性化选材
- [ ] **延迟纠错**:格式与错字优化全部集中在⑦修改环节;硬格式应用文若动笔时对位格式,错字/语句/选材仍延迟到⑦
- [ ] 教师当众示范填了一次构思支架再让学生填;导入素材有贯穿;⑥巡视话术按学情分类(接不下去[写完起步那几句停住]/内容空泛/已顺利完成/草草收尾),且承接起步半环、按「续写」设计而非「从空白起笔」(**L5–L6 第①类问的是顺序不是素材**:「你表上还有哪两处没写?哪一处接在这后面最顺」,不提示「再写一件事」);⑦修改符号自改互改有抓手,且**按档案判定教法**——仅首次引入单元(档案写“学习使用修改符号”,如三上第一单元)才当众示范教学;其余单元自然带过、不重教也不专设“回忆/上台画”复习环节
