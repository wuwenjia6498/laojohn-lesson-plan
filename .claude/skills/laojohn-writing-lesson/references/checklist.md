# 写作课详案自检清单(交付前逐项核验)

## A. 依据与真实性(任一不过即返工)

- [ ] 习作要求、重难点、官方环节均来自档案该任务记录,未编造“课标说”“官方要求”类条款
- [ ] 自拟主题(档案无此任务)时,文首已显式标注推定依据(年级学段目标 + 最相近任务),未伪称“官方指导”
- [ ] 下水文标注 `【教师下水文 · 示范】`,无伪造学生作品、无冒充名家/教材、无编造出处
- [ ] 下水文中客观数据/史实有来源,无来源处已占位 `（此处数据以…为准）`
- [ ] 全文无任何无来源的带引号“原文摘录”式内容

## B. 结构、时长与先导定位

- [ ] 两节齐全,七环节齐备:第1节 ①真实情境→②全感官→③技法→④下水文→⑤支架;第2节 ⑥自由倾吐→⑦即时反馈+延迟纠错+收尾
- [ ] 每节各环节时长合计 = 45 分钟,环节标题带时长
- [ ] 第 1 节课尾未布置课后任务,只收束构思并预告动笔;第 2 节开头接住第 1 节成果
- [ ] 作品当次完成当次评改;若提及教师课后批改,未表述成“写不完带回家写完”(动笔与课堂评改在本次两节内闭环)
- [ ] 先导红线:全文无“课文里学过”“语文老师讲过”类预设;依托单元课文的档案活动已改造为自含材料
- [ ] 第 2 节结尾真诚、贴合本课内容自然收尾;若点校内衔接则只淡淡一句,未出现“比别人早一步/别的同学才开始想”等对比话术,未出现“拿给语文老师看”,未喊机构卖点
- [ ] 书级头部齐全:提纲表(七项,课时安排填“2 节 × 45 分钟,同次连排”)+ 任务背景(含先导课说明)+ 三维教学目标

## C. 技法与分级

- [ ] 技法点 ≤ 1 主 + 1 辅,且未超出档案重难点的深度上限
- [ ] 技法深度与口气符合该级边界(对照 technique-levels.md 表格;L1–L2 无术语)
- [ ] 构思支架至多 1 个,A 档落地(空白表格/节点清单),有“引出→填写→分享+反馈”完整环节,且与技法点咬合
- [ ] **详案正文未漏出内部术语**:全文检索无“A 档”“A 档落地”等只供 skill 内部使用的档位词;若提纲表/正文要说明支架简易度,已改用老师直接看得懂的话(如“空白表格、只填关键词、不画图、3 分钟可填完”)
- [ ] 提纲表所列支架与正文一一对应,无挂名不落地
- [ ] 口诀/自造类比/学情标签每字可懂:无只有老师懂的简写字(如用"让"指代"空两格");自造词当场一句话点透,否则不用(详见 technique-levels.md)

## D. 范文

- [ ] 每个写作题目配了下水文,篇幅符合该级区间
- [ ] 出示位置正确(L3+ 后置于学生构思之后;L1–L2 可前置)
- [ ] 出示后有指向性发现问题;作后评改有回指
- [ ] 咬合检验通过:本节技法点的每个要素(多件套如"对比+变化词+细节"须逐一)都在下水文中可被一眼指出,不只示范主干;讲解环节逐一点出各要素落在哪句
- [ ] 下水文可信度自检通过(逐句通读,对照 model-essay.md 第六节五问):①逻辑成立 ②符合人物设定 ③知情边界对(细节落在说话人身份真能知道的范围内)④调子克制不表演 ⑤共用例子的素材间事实前后一致(日期/星期/天数/数字/人名/画法描述)

## E. 逐字稿与格式

- [ ] 固定话术骨架完整:`师：` `参考：` `学生互动分享` `（教师总结）`
- [ ] 全文无 `【PPT换页-PXX】` 等换页点(全项目已废弃,分页交下游 laojohn-ppt-draft 按教学节拍处理)
- [ ] 全文中文语境只用全角弯引号 `“”` `‘’`,检索 `"` 与 `'` 无残留(Markdown 语法与代码除外),两种引号无混用
- [ ] 全文检索 `*` 为零:无 `**`、`*`、`__` 等行内强调标记(任何位置,包括师话/参考/下水文/表格)
- [ ] 全文无“老约翰说”“老约翰老师”等机构拟人称呼,授课人一律称“老师”;机构名仅在头部品牌位出现
- [ ] 语体分层:师话层保留课堂口语/比喻;方括号舞台提示与括号旁注用规范指导语,无“递话/喂具体/让路”类口语随意词(`（教师总结）`等固定骨架不在此列)
- [ ] 评价标准呈现(档案有则照用,无则按重难点自拟三档)
- [ ] Markdown 标记符合排版约定(`##` 课时 / `###` 环节 / 表格 `|` 分隔 / 下水文 `> ` 引用块),可直接过 docx 引擎
- [ ] 每课时末 `本课完。`,全文末 `全课完。`

## F. 读书会连接(仅当任务在 book-writing-map 中命中时核验)

- [ ] 书目引用不超过一处,且来自对照档案命中条目,书名无误
- [ ] 引用句带未读兜底,未预设全班读过该书
- [ ] 引用的书中内容为确凿情节级概括,无编造细节
- [ ] 素材卡衔接(如有)标注了【如有素材卡】,未命中任务全程未提书目

## G. 四大教学价值观(血肉层,任一缺位即返工)

- [ ] **真实情境**:开课即抛真实社交任务、点明真实受众与用途;情境贯穿到下水文与收尾,非“为交作业而写”
- [ ] **全感官支架**:构思(⑤支架)之前有②全感官唤醒环节(微型游戏/实物观察/强视觉素材/情境演练/感官回忆),先动后写
- [ ] **支架减负**:构思支架填关键词非句子,三五分钟可完,未让填表本身变成新负担
- [ ] **即时反馈**:第2节有当堂、具体、覆盖面广的反馈节点(猜猜他是谁/金句墙/解说员擂台等),反馈对事且具体,非空泛“写得好”,且尽量多孩子被点到
- [ ] **表达主权**:⑥倾吐期巡视只做正向介入(提供具体素材提示、引导落到具体景物、为顺畅者留出空间不打断),无“纠错字、改格式、改病句”动作;护接地气的个性化选材
- [ ] **延迟纠错**:格式与错字优化全部集中在⑦修改环节;硬格式应用文若动笔时对位格式,错字/语句/选材仍延迟到⑦
- [ ] 教师当众示范填了一次构思支架再让学生填;导入素材有贯穿;⑥巡视话术按学情分类(卡壳/写空/早完/篇幅短);⑦教了修改符号(L3+)且自改互改有抓手

## H. 反同质化(96 篇规模 · 任一不过即需改写,对照 variation-pools.md 与 variation-ledger.md)

- [ ] **已查锚点表 + 台账**:生成前读了 `situation-anchors.md` 本任务行,**真实情境/反馈活动优先采用档案官方设计**(非自造一套),并按「先导课改造」改成单次两节自含;读了 `variation-ledger.md` 比对同年级+同文体已用零件
- [ ] **真实场景未偏离档案**:档案有官方情境的已采用并改造(未用自造映射盖掉);档案无明确情境的硬任务(缩写/梗概/研究报告等)才用通用兜底,且取"真实功能目的"非展示墙
- [ ] **真实场景按文体选最贴切**:不是默认套展示墙;实体载体(若用)非同年级最近 3 篇的同款;同文体两篇场景/载体有别
- [ ] **热身动作**非同年级最近 2 篇同款类型(图组/实物/回忆/演练/游戏)
- [ ] **反馈游戏**:主反馈按文体选;第二层反馈**不是「同桌互画喜欢的一句小星星」的逐字复用**(该句已三篇全同,列为禁止连续复用)
- [ ] **开场钩子**类型非同年级连续重复;开场第一句未套「同学们,先看老师手里这个——」等禁止逐字复用句
- [ ] **逐环节括号自注已整类删除**:全文检索无 `(此处落实「真实情境」——…)` 这类写给老师看的价值观自注标签(核验它落在哪环节是本清单 G 组的事,不在面向老师的正文里贴标签)
- [ ] **三维目标句式**:未与同年级邻近批次用同一句法骨架(能…能…会… / 愿意…体会… 不必每篇照搬;按 variation-pools.md 骨架轮换)
- [ ] **成败标准反例**未永远用「很美」;句式未固定成「能X=成功;光说Y=空了」
- [ ] **「禁止逐字复用」清单**全文比对通过,无命中残留
- [ ] **指纹块已写入**:文件尾有 `<!-- VARIATION-FINGERPRINT … -->`,六项如实填写,与正文实际所用一致;定稿后已重建台账
