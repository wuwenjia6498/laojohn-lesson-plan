# 写作课详案自检清单(交付前逐项核验)

## A. 依据与真实性(任一不过即返工)

- [ ] 习作要求、重难点、官方环节均来自档案该任务记录,未编造“课标说”“官方要求”类条款
- [ ] 自拟主题(档案无此任务)时,文首已显式标注推定依据(年级学段目标 + 最相近任务),未伪称“官方指导”
- [ ] 示范文标注 `【教师示范文】`,无伪造学生作品、无冒充名家/教材、无编造出处
- [ ] 示范文中客观数据/史实有来源,无来源处已占位 `（此处数据以…为准）`
- [ ] 全文无任何无来源的带引号“原文摘录”式内容
- [ ] 附加「习作讲评指导环节」(若有)只给方法框架+占位槽,**无凭空捏造的"学生作品"当范例**(同示范文身份红线)

## B. 结构、时长与课时定位

- [ ] 两节齐全,七环节齐备:第1节 ①真实情境→②全感官→③技法→④示范文→⑤支架;第2节 ⑥自由倾吐(开场含「降压起步」半环)→⑦即时反馈+延迟纠错+收尾
- [ ] **第2节开场有「降压起步」环节(作为该课时第一个 `### 一、`,约5分钟)**:① 未套「一句扩三句」或纯写法复述充数;② 按本课文体调对了行为支架(写人=快问快答采访法(做派类问动作/表情/声音;纯外貌类改问看清/比/像、并配一件体现它的事) / 写景·状物·观察·说明=聚焦细看法 / 记事·叙事=慢镜头回放法 / 想象·抒情·读后感·倡议=限时倾泻法);③ 强制三件套齐全(锚定旧知点名定位到第1节构思表的具体关键词 + 策略执行含代入感教师直接引语与学生配合动作 + 当堂落笔写出第一组句子并顺接自由写作);④ 游戏化环节名与教师直接引语未同年级逐字复用;⑤ **降压产出未被笼统当成成品开头**——描写类(写人/写景/状物)降压第一句先快写点题中心句、随后细节问题写两三句具体的,一条链不分阶段(中心句即链首,不另起起手句/过渡);写序=正文序,⑥接着补事/景、叙事类高潮感觉句可直接作 hook、倾泻类素材先选定再展开,均按文体归位,未出现「这几行就是你这篇开头、顺着往下写」式跳过中心句的接法
- [ ] **第1节③(一招技法)开头有「审题辨析」固定半步**:出切题/跑题两段对照样例(教师自拟、非冒充“某学生作品”或课文原文)→ 学生判断哪段切题 → 老师顺势审题(点明本课写什么/避开什么,咬合档案习作要求)并引出主技法;它是③内部首段、不单列 `###`、不占环节序号;现场呈现名用平实教案式(如“判断哪段切题”、不用上墙评审/辨一辨这类游戏化叫法)、与话术未同年级逐字复用
- [ ] 每节各环节时长合计 = 45 分钟,环节标题带时长
- [ ] **环节内「纯书写/纯活动时长」< 环节标称总长(留出师话)**:凡一个环节既有开场交代/收束提示、又让学生写或做,师话里说的「大约写 X 分钟」必须**小于**该环节标称分钟——不得出现「20 分钟的自由写作环节里写 20 分钟」这种把纯书写时间等同于环节总长、挤掉开场与收尾师话的写法(如环节 17 分钟,师话报「写 15 分钟」)
- [ ] **逐环节时长配比双向自检(不只算合计)**:除合计=45 外,逐环节掂量「实际互动/活动量」撑不撑得起标称分钟——全班齐答/齐猜类按秒过估(≈30秒/次)、不按逐个发言;明显**撑不满**(盈余 ≥ 约 2 分,如开场只有两处秒过猜谜却给 8 分钟)的环节压时长,把省下的拨给偏紧的核心环节(②⑥⑦/构思支架);同一份内及同年级同类环节(①创设情境、④⑤构思支架)标称应大致相当,不齐的并排核一遍(详见 review-rubric.md 维度四)
- [ ] **环节序号按课时各自从「一」重起**:第1课时编一~五、第2课时**重新从「一」起**(一、降压起步 / 二、自由写作 / 三、交流评议),不跨课时连续编号(如第2课时编成六、七、八即不合规);文末附加「习作讲评指导环节」不参与环节序号,内部三节用无序号描述性 `### 标题`(选稿/讲评流程/收尾),**未冠 `### 一、二、三`**(避免与第2课时撞号)
- [ ] 第 1 节课尾未布置课后任务,只收束构思并预告动笔;第 2 节开头接住第 1 节成果
- [ ] 作品当次完成当次评改;当堂闭环完整(⑦即时反馈+自改+互改+老师轻点评+收尾),未把评改推走;若提及教师课后批改,未表述成“写不完带回家写完”(动笔与课堂评改在本次两节内闭环)
- [ ] 附加「习作讲评指导环节」已写入:置于 `全课完。` 之后、指纹注释之前,标题标明“可选·两用(单次课课后 / 系列课作下次课开场)”;**写成三段式逐字稿**——头部 blockquote 两句(说明:可灵活取用+两用+不计入45+45 / 真实性占位提示)+ `### 选稿(课前准备)` + `### 讲评流程(每篇约3–5分钟,围绕本课技法点)`(逐篇 `师：`话术走「一篇一肯定一改处」、指到具体句、全角 `＿＿＿` 占位、穿插 `(教师总结)`/`学生互动分享`)+ `### 收尾(点回技法)` + 末尾 `本环节完。`,**非干巴的「1.选稿 2.…」方法清单**;选稿覆盖好/中/待改进2–3篇;不计入 45+45、不构成课后写作任务
- [ ] 连排自含:导入与例证当堂可得,未布置课前长周期准备(提前一周观察/课前带实物等);依托长周期的档案活动已改造为单次两节自含(课文可直接当堂出示作范例,不必绕成自创情境)
- [ ] 第 2 节结尾真诚、贴合本课内容自然收尾;若点校内衔接则只淡淡一句,未出现“比别人早一步/别的同学才开始想”等对比话术,未出现“拿给语文老师看”,未喊机构卖点
- [ ] 书级头部齐全(两件套,不设“任务背景”节):提纲表(四行精简版:基本信息/核心技法/工具与任务/评价反馈,课时安排填“2 节 × 45 分钟,同次连排”;基本信息·课题含校内同步定位)+ 核心素养教学目标(四维:【语言运用】/【思维能力】/【审美创造】/【文化自信】)

## C. 技法与分级

- [ ] 技法克制:技法点 ≤ 2–3 个、未满堂灌、第2节练笔时间充足,且未超出档案重难点的深度上限
- [ ] 技法深度与口气符合该级边界(对照 technique-levels.md 表格;L1–L2 无术语)
- [ ] 构思支架至多 1 个,A 档落地(空白表格/节点清单),有“引出→填写→分享+反馈”完整环节,且与技法点咬合
- [ ] **详案正文未漏出内部术语**:全文检索无“A 档”“A 档落地”等只供 skill 内部使用的档位词;若提纲表/正文要说明支架简易度,已改用老师直接看得懂的话(如“空白表格、只填关键词、不画图、3 分钟可填完”)
- [ ] 提纲表所列支架与正文一一对应,无挂名不落地
- [ ] 口诀/自造类比/学情标签每字可懂:无只有老师懂的简写字(如用"让"指代"空两格");自造词当场一句话点透,否则不用(详见 technique-levels.md)

## D. 范文

- [ ] 示范文篇幅符合该级区间(整篇示范文对齐本年级整篇字数 / 单点示范为句段级,见 model-essay.md §三);L3+ 若用了单点示范带局部练笔,其篇幅克制在 B 表区间、未逼近整篇
- [ ] 出示位置正确(L3+ 后置于学生构思之后;L1–L2 可前置)
- [ ] 出示后有指向性发现问题;作后评改有回指
- [ ] 咬合检验通过:本节技法点的每个要素(多件套如"对比+变化词+细节"须逐一)都在示范文中可被一眼指出,不只示范主干;讲解环节逐一点出各要素落在哪句
- [ ] 示范文示范了"把句子写具体/写活"的基础描写手法(按级:L1–L2仿句 / L3颜色·拟声·简单比喻 / L4+神态动作语言),且出示后的指向性问题分两层(结构层+句子层"为什么让你看见"),讲解逐一点出落在哪句(详见 model-essay.md §四之二)
- [ ] (推荐)句子层已落成「示范文旁批对照」(小表格或逐句师话点出每句手法),非仅泛讲;若引课文/名篇作补充范例,原文确凿可核、拿不准则只概括写法、未伪造逐字"原文"(真实性红线)
- [ ] 示范文可信度自检通过(逐句通读,对照 model-essay.md 第六节五问):①逻辑成立 ②符合人物设定 ③知情边界对(细节落在说话人身份真能知道的范围内)④调子克制不表演 ⑤共用例子的素材间事实前后一致(日期/星期/天数/数字/人名/画法描述)

## E. 逐字稿与格式

- [ ] 固定话术骨架完整:`师：` `参考：` `学生互动分享` `（教师总结）`
- [ ] 全文无 `【PPT换页-PXX】` 等换页点(全项目已废弃,分页交下游 laojohn-ppt-draft 按教学节拍处理)
- [ ] 全文无面向下游 ppt-draft 的提示标签:不出现 `[可视化建议:…供 ppt-draft 出图]`、`[此表…可作 ppt 可视化页素材]` 这类写给生成 PPT 看的元信息(可视化由 ppt-draft 环节自行判断;详案只放给师生用的教学内容,同换页点已废弃之理)
- [ ] 全文中文语境只用全角弯引号 `“”` `‘’`,检索 `"` 与 `'` 无残留(Markdown 语法与代码除外),两种引号无混用
- [ ] 全文中文标点全角:逗号 `，`/冒号 `：`/问号 `？`/叹号 `！`/分号 `；`/圆括号 `（）` 不用半角(检索半角 `,:?!;()` 为零;数字范围 `–`、箭头 `→`、斜杠 `/`、乘号 `×`、全角竖线 `｜` 及 Markdown/代码/英文路径豁免)。骨架 `师：`/`参考：`/`（教师总结）` 同此。**初稿与每次局部增改均适用**(定义见 lesson-structure.md §三「中文标点全角规范」)
- [ ] **方括号教师提示标注体例统一**:现场提示用半角 `[…]`(区别于 `【】`教学目标、`〖〗`页标);方括号内「类别+说明」用全角冒号 `：`(如 `[异常处理：…]`、`[无从下笔型：表现]`),不用 `——`/`·` 当分隔符混用,紧接正文的冒号亦全角 `]：`;同一详案内写法前后一致(定义见 lesson-structure.md §三)
- [ ] 全文检索 `*` 为零:无 `**`、`*`、`__` 等行内强调标记(任何位置,包括师话/参考/示范文/表格)
- [ ] 全文检索 ASCII `_` 为零(Markdown 语法/英文路径除外):填空横线一律用全角 `＿`(U+FF3F),未用 `______`(会被引擎当 `__` 加粗剥除、横线消失)
- [ ] **无 HTML 样式/高亮标签**:全文检索 `<\w+>` 无残留(仅放行表格换行 `<br>` 与注释 `<!-- -->`)——`<mark>`/`<b>`/`<u>`/`<span>` 等引擎不解析、会原样印进 docx;强调用 `【】`标签/话术骨架承载(本 skill 连 `**` 也不用),伏笔用文字直说
- [ ] **无黑板/板书依赖**(教室无黑板白板,恒久约束):全文检索 `黑板`/`板书`/`白板` 无残留;构思表/五感表/评价量表等支架都是学生动手填的单子,老师走"口头归拢 + 请学生补到自己单子上",未写"老师在黑板上画/记一张集体大图";回指不写"老师画的那张图"(与 laojohn-lesson-plan 共用同一课堂物理条件,见其 references/style-and-format.md「课堂无黑板/白板」)
- [ ] 全文无“老约翰说”“老约翰老师”等机构拟人称呼,授课人一律称“老师”;机构名仅在头部品牌位出现
- [ ] 语体分层:师话层保留亲切口吻与贴切比喻(但专业平实、无市井 slang);方括号舞台提示与括号旁注用规范指导语,无“递话/喂具体/让路”类口语随意词(`（教师总结）`等固定骨架不在此列)
- [ ] **语言专业平实(对照 lesson-structure.md §三「语言风格红线」对照表)**:全文无市井/网络口语(“写嗨了/卡壳了/命根子/主菜/小妙招/炒菜”及作为字面词的“兜底”等)、无晦涩学术词(“学习支架/知识建构/最近发展区/多模态”等)、**无游戏化叫法与形象比喻**(磁铁/拐杖/钩子/上墙评审/辨一辨等一律直说方法本身,见红线第四条,覆盖所有年级);提示层与师话层用词均规范易懂,已逐词替换为“思路引导/基础辅导预案/关键环节/重点内容/步骤指引/无从下笔/情境描述”等中性实操词。**本组对初稿与此后每一次局部改写/增改同样适用:改动处就地重扫本组,不因“只是小修”跳过**
- [ ] **语气适龄、不哄不啰嗦(红线第五条)**:师话信任学生、**不反复情绪安抚**(“别怕/别有压力/不会卡/没关系”式;个别学生当堂卡住的临场安抚除外)、**无一二年级写话式过度兜底**(拼音兜底、一句一句喂到底铺给全体);**同一意思不反复说、不层层叮嘱**,减压点到为止(一句“写三处就行”即可,不堆“别有压力、不会卡、很棒了”);**过场/管理指令从简**(拿材料、就位一句带过,不堆“平放桌上、笔摆好、坐端正”这类碎指令);**动作指令须有真实功能、不预设学生处境**(不无故让学生闭眼/比框/点着表;不写“看你左手边”这类对学生处境的预设)
- [ ] **环节标题专业平实**:`### 一、…` 用一线教案式教学环节名(如“创设情境,明确任务”“观察体验,调动感官”“交流评议,修改收束”),**未照搬内部七环节工作名**(真实情境抛任务/全感官唤醒/一招技法/构思支架落地/即时反馈+延迟纠错+自然收尾 等带 AI·教研黑话味的词)。对照 lesson-structure.md §三标题对照表。**这条无例外:第2节「降压起步」也用平实教案式环节名(如“借助构思表,写下第一句”“先说一句,再写下来”),其行为支架方法(盯住一处看清、闭眼回想、限时快写)保留,但不以游戏化叫法做标题**
- [ ] 评价标准呈现(档案有则照用,无则按重难点自拟三档)
- [ ] Markdown 标记符合排版约定(`##` 课时 / `###` 环节 / 表格 `|` 分隔 / 示范文 `> ` 引用块),可直接过 docx 引擎
- [ ] 每课时末 `本课完。`,全文末 `全课完。`

## F. 四大教学价值观(血肉层,任一缺位即返工)

- [ ] **真实情境**:开课即抛真实社交任务、点明真实受众与用途;情境贯穿到示范文与收尾,非“为交作业而写”
- [ ] **全感官支架**:构思(⑤支架)之前有②全感官唤醒环节(微型游戏/实物观察/强视觉素材/情境演练/感官回忆),先动后写
- [ ] **支架减负**:构思支架填关键词非句子,三五分钟可完,未让填表本身变成新负担
- [ ] **即时反馈**:第2节有当堂、具体、覆盖面广的反馈节点(猜猜他是谁/金句墙/小解说员分享等),反馈对事且具体,非空泛“写得好”,且尽量多孩子被点到
- [ ] **表达主权**:⑥倾吐期巡视只做正向介入(提供具体素材提示、引导落到具体景物、为顺畅者留出空间不打断),无“纠错字、改格式、改病句”动作;护接地气的个性化选材
- [ ] **延迟纠错**:格式与错字优化全部集中在⑦修改环节;硬格式应用文若动笔时对位格式,错字/语句/选材仍延迟到⑦
- [ ] 教师当众示范填了一次构思支架再让学生填;导入素材有贯穿;⑥巡视话术按学情分类(接不下去[写完降压开头停住]/内容空泛/已顺利完成/草草收尾),且承接降压、按「续写」设计而非「从空白起笔」;⑦修改符号自改互改有抓手,且**按档案判定教法**——仅首次引入单元(档案写“学习使用修改符号”,如三上第一单元)才当众示范教学;其余单元自然带过、不重教也不专设“回忆/上台画”复习环节
