# 反同质化台账(已用零件登记 · 查重依据)

> **这份文件是「跨篇查重」的落地载体(判断二的 B 方案)。** 生成新详案前,先查这里:本年级/邻近批次已经用过哪些场景、载体、热身、反馈游戏、开场钩子,**撞了就换**(规则见 `variation-pools.md`)。
>
> **台账的真相来源是每份详案文件尾部的「指纹块」,不是生成时的临时意图。** 因此台账**只重建、不盲目追加**:任何时候都可以扫一遍 `写作课输出\` 目录下所有 `.md` 的指纹块,重建出当前真实的占用情况。这样无论详案后来被手动改过、还是被 AI 优化过,只要改稿时同步更新了文件尾的指纹块(这是硬规则),台账重建后永远对得上成稿。

## 一、指纹块格式(写在每份详案 .md 的**文件最末尾**,`全课完。` 之后)

每份详案结尾追加一段 HTML 注释(不渲染、不进 docx 正文、老师看不见,但机器和重建脚本能读):

```
<!-- VARIATION-FINGERPRINT
册级: 四上
题目: 写观察日记
文体: 观察日记
场景原型: 连载追踪(给自己/同伴看的成长记录)
实体载体: 连载档案/成长本(自己留存)
热身动作: 现场观察今天的实物+翻看记录卡

主技法: 连续观察对比写变化(今昔对照+变化词)
示范文题材: 养育·种植过程记录(窗台水培蒜苗)
互动组织: ②同桌互说/⑤四人围圈轮说/⑦传邻座画亮点
-->
```

> 共 **13 个字段**(册级/题目/文体/场景原型/实体载体/热身动作/主反馈游戏/第二层反馈/开场钩子/主技法/示范文题材/互动组织/发令词)。「主技法」记本篇提纲表核心技法的主线一句(供同文体纵向对照定差异轴);「示范文题材」记**题材域 + 具体素材**(域名单见 variation-pools.md 池 4);「互动组织」按环节位紧凑记录本篇各主要互动点的组织形态(形态池见 pools 池 5,篇内 ≥3 次互动须至少两种形态);「开场钩子」自 2026-07 起按「钩子类型·语气姿态」合记(姿态池见 pools 池 3 修饰维度,如「实物道具式·尝试者」);「发令词」自 2026-07 起紧凑记录本篇「转正题/点名发起/催收束」三功能点各用哪一路(池见 pools 池 6,如「①问题直入/②点名个人/③停在句号」),供同年级邻近篇避让。教学讲评用语(池7)因词太细不设字段,靠 checklist E 组 + ngram 横审兜底。冒号全角半角皆可,重建时兼容两种写法。

> **硬规则:改稿必改指纹。** 凡在「生成后的优化」阶段动了上述任何一项(换了载体、换了反馈游戏、改了开场……),**必须同步改这段指纹块**。指纹块就在同一个 .md 里,改正文时顺手改它。指纹块与正文不一致 = 台账会失真 = 下次查重出错。

## 三、查重操作(生成新详案时,工作流第 1.5 步调用)

1. 读本表,筛出**同年级**全部行 + **同文体**全部行(跨年级也算)。
2. 对照即将生成的本篇,逐列比对场景原型/载体/热身/反馈/开场。
3. 命中规则(见 `variation-pools.md` 文首「距离化避让规则」与各池硬规则)即换:
   - 同年级最近 2–3 篇用过的,避开;
   - **强避让范围**(同年级 / 相邻年级同文体 / 同一生产批次同文体)内,场景/载体/反馈必须有别;**弱避让范围**(年级差 ≥2 的同文体)零件类型可复用,具体由头/道具/措辞必须换;
   - 示范文题材域:同年级连续两篇不同域(池 4);
   - 「禁止逐字复用」清单里的句子,全文比对改写(不分距离、全局生效)。
4. **同文体纵向对照(定差异轴)**:读第 1 步筛出的同文体行的「主技法」列——若本篇拟定主技法与已有篇同款,回档案核对本任务重难点,把差异轴显式定在「本档进阶什么」(如写人:三上抓特点写活 → 四上比喻联结 → 五上典型事例),让同文体篇读起来是**进阶**而非换皮;差异轴只体现在技法选择与讲法里,正文不写「相对X年级新增」式元话语。
5. 生成完成、写入指纹块后,**重建本表**(扫目录覆盖重写)。

> 若台账文件丢失或盘符变动:不慌,扫 `写作课输出\` 下所有 .md 的指纹块即可一键重建本表,不依赖任何外部状态。
