# 同步习作详案 · 标题与环节命名规则

本规则规定「校内同步习作·写作课详案」的**总标题、副标、课时标题、环节名**格式，供生成与校对时统一套用，是本 skill 命名体例的**唯一源**（`lesson-structure.md` §三、`checklist.md` 的相关条目与本文件冲突时以本文件为准，并须回改那两处）。

## 〇、口径声明（先读这条）

本规则与看图写话线的同名规则（`laojohn-picture-writing/references/title-naming.md`）**方向不同，不可互相套用**。

- **看图写话详案**面向加盟商与非科班新手老师，标题环节要**去教研腔、口语化**（"听一听""写一写"）。
- **同步习作详案**面向**有教材在手的校内语文老师**，有意对齐统编教材与语文教研的标准话语。此处「创设情境」「学写法」「交流评议」「构思表」**不是黑话，是行业通用语，保留即专业**。把它们改成口语儿童化说法会显得幼化、不够正式。

因此本规则的核心是：**保持现行教研规范语，不做风格改造；只做格式与结构的一致性对齐。**

---

## 一、总标题与副标

**格式（固定两行）**：

```
# 《〔习作题目〕》· 写作课教学设计
〔年级册次〕·〔单元〕 校内同步写作〔（体裁备注，可选）〕
```

示例：

```
# 《猜猜他是谁》· 写作课教学设计
三年级上册·第一单元 校内同步写作（写人习作）
```

```
# 《这儿真美》· 写作课教学设计
三年级上册·第六单元 校内同步写作
```

要点：

- 习作题目用书名号 `《》`，与教材题目**逐字一致**，不得改写或简称。
- 题目与「写作课教学设计」之间用全角间隔号 `·` 加空格分隔（`》· 写作课`）。
- 第二行为副标，**不加 Markdown 标题级别**（纯文本行），不加粗。
- 副标内「年级册次·单元」之间用全角 `·` 紧连（`三年级上册·第一单元`），其后空一格接「校内同步写作」。
- 体裁备注可选，用中文圆括号，仅在有助识别时加（如"写人习作"）；无则省略。
- **不使用**看图写话那套 `######` 小字副标格式；同步习作沿用现行纯文本副标。

**授课提示行（可选）**：若本课示例材料为自拟（如教材图片不便复制），在副标后空一行，用中括号整段说明，格式沿用现状：

```
[授课提示：……请老师改用教材本单元实际提供的三幅图……教学步骤与技法讲法不变。]
```

---

## 二、课时标题

**格式（固定两条，不得改写）**：

```
## 第1课时 · 写作指导课
## 第2课时 · 当堂写作与评改课
```

- 二级标题 `##`；序号用「第N课时」；与课时性质名之间用全角 `·` 加空格。
- 这两个名称**全线统一、不随课文变化**，体现"两节连排 = 指导 + 写评"的固定模型。
- 不采用看图写话的 `｜` 分隔与口语句式。

---

## 三、环节名

**格式**：

```
### 〔中文数字序号〕、〔环节名〕（约 N 分钟）
```

示例：`### 三、学写法：抓住一两个最特别的地方（约 13 分钟）`

### 3.1 序号

- 三级标题 `###`，序号用**中文数字＋顿号**（一、二、三、四、五），**课时内独立编号**（第2课时重新从"一、"起）。
- 不使用「环节一」前缀（那是看图写话的写法），同步习作沿用现行"一、二、三"。

### 3.2 句式

沿用现行教研规范句式，**保持不变**：

- **动作＋目的的四字/短语对举**：`创设情境，明确任务`／`观察体验，读懂图意`／`交流评议，修改收束`
- **冒号点睛式**（用于讲技法的环节）：`学写法：围绕一个意思写`／`学写法：抓住一两个最特别的地方`
- **借助工具式**：`借助构思表，理清思路`／`借助人物特点卡，理清思路`

以上三种句式**允许并存**，这是本文体的规范样态，不必强求单一句式。

### 3.3 两课时的环节骨架（全线统一，务必对齐）

**第1课时·写作指导课（五环节）**：

| 序 | 骨架 | 说明 |
| --- | --- | --- |
| 一 | 创设情境，明确任务 | 起头激趣＋亮出本课要写什么 |
| 二 | 观察体验，〔本课特异语〕 | 特异语随文体变：读懂图意／调动感官／唤醒人物的样子 |
| 三 | 学写法：〔本课核心技法〕 | 冒号后写本课技法，逐课不同 |
| 四 | 借助〔工具名〕，理清思路 | 工具名随课变：构思表／人物特点卡等 |
| 五 | 出示示范文，发现写法 | 全线统一措辞；「教师出示样稿」是已废止的旧变体，不再使用（2026-07-26 存量五份已归一） |

**第2课时·当堂写作与评改课（三环节）**：

| 序 | 骨架 |
| --- | --- |
| 一 | 〔借助工具/接住前文〕，写下第一组句子 |
| 二 | 自由写作〔，本课产出语〕 |
| 三 | 交流评议，修改收束 |

要求：**环节一、五（第1课时）与环节三（第2课时）措辞全线一致**；环节二、三、四的"特异语"随课文内容变化，属正常，不必统一。

### 3.4 时长标注（高频出错项）

**统一格式：`（约 N 分钟）`** —— 带"约"字，数字两侧各一个半角空格，中文圆括号。

- ✅ `（约 8 分钟）`
- ❌ `（8分钟）`、`（8 分钟）`、`（约8分钟）`

区间时长写作 `（约 3–5 分钟）`（用中文数字范围连接号 `–`）。

### 3.5 环节名长度（高频出错项）

**环节名内不得夹带教学预案、压缩方案等长说明。** 标题只保留「环节名（约 N 分钟）」。

反例（须整改）：

```
### 二、观察体验，调动感官（8 分钟｜可压缩：照片精用 3 张、紧时跳第 2 张；“30秒小解说员”保底 1 人、宽裕再加 1 人）
```

改为：

```
### 二、观察体验，调动感官（约 8 分钟）

> **可压缩预案**：照片精用 3 张、紧时跳第 2 张；“30秒小解说员”保底 1 人、宽裕再加 1 人。
```

即：把 `｜可压缩：……` 整段移出标题，作为该环节正文**第一行的引用块批注**（`> **可压缩预案**：…`）。信息不丢，标题清爽，三份齐整。

---

## 四、附录环节（讲评指导）

**格式**：

```
## 附：习作讲评指导环节（可选 · 单次课课后用 / 系列课作下次课开场用）
### 选稿（课前准备）
### 讲评流程（每篇约 3–5 分钟，围绕本课技法点）
### 收尾（点回技法、引向今后的写作）
```

- 附录用二级标题 `##`，以「附：」起头。
- 括注中的用途说明**全线统一**为上述措辞（现有文件中「单次课可选用 / 系列课作下次课开场」等变体须统一）。
- 三个子环节名与括注**全线统一**，包括「每篇约 3–5 分钟」的写法（不写"3 到 5 分钟"、不写"3-5"）。

---

## 五、明确不做的事

- ❌ 不把「创设情境／学写法／交流评议／构思表／技法点」等改成口语说法。
- ❌ 不引入看图写话的 `｜` 分隔符、`第N课时｜口语句` 句式、`######` 小字副标。
- ❌ 不给总标题加「——副题」。
- ❌ 校对既有详案时，不借命名整改之便改动教学内容、时长分配、环节顺序与数量。

本规则的作用面只有三块：**格式对齐 + 超长环节名瘦身 + 附录措辞统一**。

---

## 六、自检清单

- [ ] 总标题为 `# 《题目》· 写作课教学设计`，题目与教材逐字一致。
- [ ] 副标为纯文本行，格式 `年级册次·单元 校内同步写作（体裁）`。
- [ ] 课时标题恰为 `## 第1课时 · 写作指导课` 与 `## 第2课时 · 当堂写作与评改课`。
- [ ] 环节序号为中文数字＋顿号，课时内独立编号；第1课时五环节、第2课时三环节。
- [ ] 环节一、五及第2课时环节三的措辞与其他详案一致。
- [ ] 所有时长为 `（约 N 分钟）`，含"约"、数字两侧半角空格。
- [ ] 无任何环节名夹带"可压缩""预案"等长说明；已移入正文 `>` 批注。
- [ ] 附录标题、三个子环节名及括注措辞全线统一。
