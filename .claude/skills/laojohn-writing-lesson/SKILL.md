# 老约翰 · 校内同步习作课详案生成器

把「课标习作要求档案 + 年级 + 习作主题」变成会讲技法的写作课逐字稿(两节连排 × 45 分钟,默认先于校内讲解)。与 `laojohn-lesson-plan`(整本书阅读详案)**独立并行**:阅读详案吃书籍档案,本技能吃习作档案;阅读课对写作技法是「默认不讲、用户明确要求时才解锁，且只挂在读后写作应用任务上」;本技能不同——写作课正面讲技法是本分,不需用户点名、逐字稿默认就讲。

## 范围

只产出**写作课逐字稿详案**一项(含文末附加的「习作讲评指导环节」一块)。不生成 PPT、思维导图、海报、家长反馈等配套(各归各的 skill)。

## 工作流程(必须按顺序)

1. **确认输入与检索档案**:输入 = 年级(或 L1–L6,L 即年级)+ 习作主题。打开 `references/archive/index.md` 按年级+主题/文体/关键词检索:
   - **命中教材任务** → 读对应册档案文件,以该任务记录(要求/重难点/教学建议/评价标准)为主依据。
   - **模糊命中**(主题相近但措辞不同,如“写秋天的公园”≈三上《这儿真美》)→ 采用最相近任务为依据,并在详案头部注明“依托X年级X册《XX》单元习作要求设计”。
   - **完全未命中(自拟主题)** → 走自拟模式:以**同年级最相近文体的任务 + 该册册级说明**为推定依据,详案头部显式标注:`自拟主题,非教材单元习作;教学要求由X年级学段目标及《最相近任务》习作要求推定`。**严禁**给自拟主题伪造“官方指导”“课标原文”。
   - 用户只给主题不给年级 → 若 index 中该任务唯一对应某册,直接采用;否则才询问年级。
1.5. **查锚点表 + 查反同质化台账(避重 · 不可跳过)**:先读 `references/situation-anchors.md` 本任务那一行,拿到官方真实情境、官方反馈活动、先导课改造建议(这是情境与反馈的第一供给源);再读 `references/variation-ledger.md`,筛出**同年级**与**同文体**已生成的详案,记下它们已用的「场景原型/实体载体/热身动作/反馈游戏/开场钩子」。生成时:档案官方情境优先,通用池(`variation-pools.md`)兜底;据台账避重(同年级最近 2–3 篇用过的零件避开,同文体两篇的场景/载体/反馈必须有别,「禁止逐字复用」清单里的句子全文比对改写)。**这一步决定这套 SKILL 在 96 篇规模下会不会读出『又是那面墙、又是那颗小星星』的复读感——锚点表保证情境贴合教材、不造轮子,台账+零件池+指纹块保证跨篇不撞款。**
2. **定结构**:读 `references/lesson-structure.md`。课时固定为**同次连排 2 节 × 45 分钟**(第 1 节作前+作中,第 2 节当堂写作+评改),不询问课时安排。默认按**先导定位**生成(培训班上在校内讲解之前,零预设、素材自含、结尾回校衔接);用户说明学校已讲过时才转“提升与讲评”取向。
3. **定技法点与口气**:读 `references/technique-levels.md`。主技法点从档案重难点中提取(≤1主+1辅,不越档);确定该级口气;选定至多 1 个构思支架。
4. **按七环节工作流逐段生成**(读 `references/workflow-engine.md`,这是强制骨架):书级头部(提纲表+任务背景+三维目标)在前,正文教学流程严格走七环节——第1节 ①真实情境抛任务 → ②全感官唤醒 → ③一招技法 → ④示范文做样 → ⑤构思支架落地;第2节 ⑥自由倾吐(护表达流、零打断纠错)→ ⑦即时反馈+延迟纠错修改+自然收尾。档案「教学建议」作内容蓝本,但按七环节注入血肉、重排节奏;环节处显性标注训练点。
   - **环节①②⑦及开场、三维目标、评价方式,先查 `references/situation-anchors.md` 本任务那一行拿官方情境/反馈活动,再用 `references/variation-pools.md` 兜底与轮换,不得硬编码套同款**:① 真实情境**优先用锚点表「官方情境」**(教材编者按该任务设计的,如好地方推荐会、猜猜他是谁、发明发布会、寻物启事),按「先导课改造」列改成单次两节自含;档案未给明确情境(缩写/梗概/研究报告等硬任务)才用池0 通用映射兜底——墙只是选项之一,信/连载/投递等按文体优先;② 热身动作按文体优先 + 同年级轮换(池1);⑦ 主反馈游戏**优先用锚点表「官方反馈活动」**(猜猜他是谁、快乐指数、读后画路线图验证、实验演示等),第二层反馈轮换,**那颗「同桌互画小星星」不得再连续复用**(池2);开场钩子类型同年级不连续重复(池3);三维目标句式按骨架轮换、删掉逐环节括号自注(见「表层 AI 指纹」与池内规则)。**档案官方情境优先于通用映射;先选最贴切,只有被邻近批次占用才退到次选——贴切优先于新鲜。**
   - **读书会书目引用**(查 `references/book-writing-map.md`):**默认不引,可引则至多一处**,且需满足:① 引用点能自然预演本课主技法;② 不与示范文撞题材。引时必须带未读兜底(“咱们读书会读过《XX》的同学,想想……;没读过的也没关系,听老师说说”)。示范文化用书中事例须如实提书名、只用确凿情节;未命中则全程不提书目。为引而引比不引更糟。
4.5. **附加「习作讲评指导环节」(每份必附)**:七环节正文写完、`全课完。` 之后,再附一块**可选取用的习作讲评指导模块**(走法见 `workflow-engine.md`「一之二」节,落位/格式见 `lesson-structure.md` §三)。要点:① 定位“可选·两用”——单次课课后用 / 系列课作下次课开场用(约 15–20 分钟);② 它评的是**已当堂完成**的稿,**不破“当次完成当次评改”、不构成课后写作任务**;③ 因生成时不知道真实学生作品,**只给方法框架 + 占位槽,严禁捏造“学生作品”当范例**(真实性红线);④ 讲评口径锁定**本课技法点**,选 2–3 篇代表作(好/中/待改进),一篇一肯定一改处;⑤ 写清即时反馈/轻点评(当堂)与深度讲评(本块)的分工。
5. **自检(交付前必做,不得省略或笼统带过)**:对照 `references/checklist.md` **逐项**核验后再交付。
6. **通读复盘(冷启动·独立执行 · 交付前必做,与第5步分工不同)**:第5步查“规则有没有违反”(合规);本步查 checklist 查不出的**质量问题**。**这一步必须「换人审稿」,绝不能「自己再看一遍」**——生成者顺接自审会为自己的设计辩护、`默认有问题`空转,等于走过场。因此**不在本生成会话里自审**,而是冷启动独立执行,二选一:
   - **首选(形态A · 强隔离)**:第5步 checklist 过后**停手**,派一个**全新的(fresh,非 fork)子 agent** 来复盘,任务给:“读并遵循 `.claude/skills/laojohn-detail-review/SKILL.md`,待审稿件 = `<写作课输出/…-写作课详案.md 的绝对路径>`”。子 agent 跑完把报告交回,你原样转述给用户(A 块已改、B 块待定夺)。
   - **兜底(形态B · 手动)**:不便派子 agent 时,告知用户在**新会话**里调用 `laojohn-detail-review` 对这份 .md 跑独立复盘。

   形态细则(含同会话顺接时的降级封存办法)、审稿人协议五条、五维查项、分流与报告格式,**一律以 `laojohn-detail-review/SKILL.md` 及其加载的 `references/review-rubric.md` 为准,此处不复述**。生成方只需记住两点:本步换人冷审、不自己复盘;真实性红线在复盘补全时同样不豁免——碰示范文客观数据/史实/出处一律占位、不造“官方”条款、示范文身份标注不松。
7. **写指纹块 + 重建台账(反同质化闭环 · 定稿时做)**:详案定稿后,在 .md **文件最末尾**(`全课完。` 之后)追加一段 `<!-- VARIATION-FINGERPRINT … -->` 注释块,如实记录本篇实际用的「场景原型/实体载体/热身动作/主反馈游戏/第二层反馈/开场钩子」(格式见 `references/variation-ledger.md` 第一节)。这段是 HTML 注释,不渲染、不进 docx 正文、老师看不见,但供台账重建读取。随后**重建台账**:扫 `写作课输出\\` 下所有 .md 的指纹块,覆盖重写 `variation-ledger.md` 的登记表(只重建、不盲目追加,保证与成稿一致)。
8. **(可选)导出 Word**:用户要 .docx 时,复用阅读详案的排版引擎:`python ../laojohn-lesson-plan/assets/md_to_laojohn_docx.py 详案.md`(两 skill 产物同一条排版流水线,Markdown 标记须符合其约定规范)。引擎路径以实际安装位置为准。**导出前务必对 .md 全文检索 ASCII 直引号 `"` 与 `'`(Markdown 语法/代码除外),命中即就地改为弯引号 `“”`/`‘’`**——引擎的交替式安全网对跨行、奇数个、弯直混排的引号会判错方向,不可托底。(指纹块是 HTML 注释,docx 引擎会忽略,无需处理。)

## 核心约束(违反即返工)

- **四大教学价值观(硬约束,逐份可指认)**:① 开课抛真实社交任务、点明真实受众,不为交作业而写——**真实场景按文体选最贴切的(信→寄到人手里、观察→连载追踪、倡议→真提给班委…),实体载体(墙/册/箱…)是可选项不是默认,严禁每篇都套同一面展示墙**(详见 `variation-pools.md` 池0);② 构思前必有全感官唤醒(看/听/摸/玩/演),先动后写;③ 第2节有当堂、具体、覆盖面广的即时反馈节点(游戏化优先);④ 初稿零打断纠错、护个性化选材,所有格式与错字优化延迟到独立修改环节(硬格式应用文例外:格式框架可在动笔前讲清、动笔时对位,但错字/语句/选材仍延迟)。详见 `references/workflow-engine.md`。
- **反同质化(硬约束,96 篇规模下逐份可指认)**:真实场景/载体、全感官热身、反馈游戏、开场钩子、三维目标句式一律从 `variation-pools.md` 取并按台账避重;「禁止逐字复用」清单里的句子不得再现;逐环节括号自注 `(此处落实「真实情境」——…)` 整类删除,核验改在 checklist H 组做。详见「反同质化机制」一节。
- **档案是唯一“官方”来源**:习作要求、重难点、官方环节只能来自 `references/archive/`,不得编造课标条款;自拟主题必须标注推定来源。
- **示范文身份红线**:范文一律标注 `【教师示范文】`,严禁伪造成学生作品、冒充名家名篇、编造出处;示范文内的客观数据无来源一律占位(详见 model-essay.md)。
- **一课一得**:技法点 ≤ 1 主 + 1 辅,深度上限 = 档案该任务重难点;L1–L2 不出现技法术语。
- **课时固定两节连排,每节各环节时长合计 = 45 分钟**;三段(作前/作中/作后)缺一不可;第 1 节尾不布置课后任务,作品当次完成当次评改。**当堂评改闭环(⑦即时反馈+自改+互改+老师轻点评+收尾)不破**;文末附加的「习作讲评指导环节」是面向系列课/课后的**可选深度讲评 add-on**,不计入 45+45、不构成课后写作任务、不捏造学生作品(见工作流 4.5)。
- **范文不止讲“结构对”,要讲“句子怎么写得让人看见”**:环节④示范文须示范该级基础描写手法(把抽象的“美/好”换成可感的颜色/声音/触感/简单比喻),指向性问题分结构层+句子层两层。这是“主技法+五感支架经范文落地”、**不另立第三技法、不破一课一得**(见 model-essay.md §四之二、technique-levels.md §一边界澄清),专为降低第2节动笔难度。
- **环节时间按真实教学动作可行、宁可深讲不赶**:每节合计 45 只是底线;更要保证每个环节标称的分钟**装得下其全部教学动作**(讲解＋示范＋学生说/写＋反馈)并算进课堂摩擦;塞不下时**宁可把核心环节(②全感官唤醒、⑥自由倾吐、⑦即时反馈)充分展开,把次要环节压缩或合并,不要每件事都匆匆带过**。(复盘时按 review-rubric 维四“逐环节耗时累加”核查。)
- **先导红线**:默认学生未学本单元课文、未被学校指导过此题——师话不得引用单元课文作共同经验,导入与例证素材必须自含;第 2 节结尾以真诚、贴合本课的方式收尾(回校衔接轻处理、优先自然,不说“比别人早一步”、不喊机构卖点,详见 lesson-structure.md)。
- **构思支架 A 档落地**:空白表格/节点清单 + “引出→填写→分享+反馈”完整环节,不画图、不挂名不落地。(“A 档”是内部术语,定义见 technique-levels.md;**严禁把“A 档”写进面向老师的详案正文**,详案里改用“一张空白表格、只填关键词、不画图”这类老师直接看得懂的话。)
- **保留固定话术骨架**:`师：` `参考：` `学生互动分享` `（教师总结）`。**不再埋 PPT 换页点**:详案不写 `【PPT换页-PXX】` 等换页标记(全项目已废弃)——若后续要做投屏课件,分页权交给下游 `laojohn-ppt-draft` 按教学节拍自行切页。
