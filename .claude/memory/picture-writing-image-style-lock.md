2026-07-20 期1 五图前后重生六轮，得到的核心结论：

**★ 画风统一靠参考图，不靠形容词。** 同一句"低龄儿童绘本插画风"，在锚图题材上出柔和手绘、在群像题材上稳定出粗描边矢量卡通。我依次试过写"水彩淡彩"（→水彩晕染）、改"数字彩绘·线条清晰·边缘利落"（→扁平卡通）、把形容词全删只留锚图原句（→几乎没变），**三轮全废**。正解是改 `generate_images.py`：例库图生成时自动带**本期锚图 png 作参考图**（Gemini 多模态 contents=[Part.from_bytes(锚图), prompt+画风指令]），日志显示"（沿用锚图画风）"，一次就对。**锚图定调 → 例库图跟随**，锚图本身不带参考图。此能力已内置并写进 SKILL/image-spec，后续 23 期直接用。

**其余提示词实测教训**（均已进 `image-spec.md` 通用画面约束）：
- "初秋/秋天"必被画成深秋红黄落叶 → 要正面写景物状态＋反面列禁止项（"树木翠绿，严禁黄叶红叶枫叶落叶"）
- 否定式约束执行率低 → 能用姿态规定就别用禁令（"书本不要遮脸" ✗ → "书本平摊放在课桌桌面上" ✓）
- 模型爱在背景塞英文招牌（HAPPY KITCHEN、墙上 September 月份牌）→ 中文课堂图须写死"不出现任何英文"
- "头部完整可见"会得到一个后脑勺 → 必须连"严禁背影"一起写
- 颜色词忌歧义复合词："鲜嫩的**黄绿**" → 一整片柠檬黄草地；改"新鲜青绿色（严禁明黄枯黄）"
- **重生会丢掉没写进规格但正文话术依赖的元素**（例-01 小猫消失过一次，而正文备了"孩子答成妈妈或小猫"的应答）→ 凡正文用到的元素必须写进清单/验收字段
- **机器验收判不出季节/遮脸/背影/画面英文**：实测机器 5/5 全过、人工看出 2 图不合格。`--verify-only` 通过 ≠ 可交付

**同轮三条详案规范变更（用户提出，已固化，勿改回）**：
1. **头部不放元信息**：回插提示移到文末工单区开头；"给生成方看的字段下沉文末"本就是 SKILL 规定，之前违反了。老师翻开第一页就该是提纲表。
2. **引号统一 `""`，禁用直角引号 `「」`**：全仓 6 份详案都用 `""`，`model-essay.md` 里"用「」"是写歪的、已更正。我为规避 Write 工具吞弯引号而改用「」是错的——正解是写完跑 `fix_quotes_md.py`。（本轮我自己又复发一次，写工单说明时用了「」。）
3. **"小侦探"禁用**：SKILL 原写着"保留小侦探、勿当 bug 改回"，用户推翻——看图说话是直说画面明摆着的东西，不是找线索。连那句"勿改回"一起删了。**教室墙面张贴**同样禁用（借用/共用教室墙面不可控），常驻支架一律只发每人一张小卡。
