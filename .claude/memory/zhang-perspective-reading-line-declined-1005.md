2026-10-05 用户问写作课线用过的 `zhang-zuqing-perspective` 是否适合审读书会详案。评估后用户拍板**暂不接入**。

**不整套扮演的理由**：① skill 里整本书阅读的一手材料几乎为零（演讲录第九讲「整本书共读的应为与可为」只收了目录行），扮演审读书会观点会大量出自模型记忆；② 他的处方与读书会产品规格冲突——批「思维导图、导读单」泛滥（《警惕新繁琐主义》）、反逐字稿、认为整本书阅读能力「不是教出来的」，而读书会规格是每节落地工具＋逐字稿＋策略显性训练；写作线 0918 已证他诊断准、处方默认「删」（见 [[zhang-perspective-audit-checks-0918]]）。

**连「只抽两张清点表」也不做的理由**：写作线跨维九的伪问题清点表、活动产出对账表与课型无关，读书会 rubric 确实没有；但《稻草人》里这两类问题（维恩图答案先念、是非问、提问未回收、跨课时许诺未兑现）三轮冷审都已抓到并改掉，边际收益小；成本是每次冷审多约 60 分钟＋多一条要维护的规则。真正兜住这类问题的是「多轮改稿后二次冷审」（已写进 lesson-plan SKILL）。

**How to apply / 重启条件**：别再从头评估。若后续连写两三本，冷审报告里反复出现「伪问题／活动产出没人接」且现有 Pass A 与二次冷审漏网，再按写作线 rubric 九的体例给读书会 rubric 加跨维查项，并写死读书会专属刹车（导读课预测题与设计好的缺口不算伪问题；工具／阅读单／计划表是规格不报；开放思辨题按 lesson-templates 正向标准判）。相关：[[zhang-zuqing-on-writing-line-0912]]、[[reading-line-return-style-boundary-1005]]。
