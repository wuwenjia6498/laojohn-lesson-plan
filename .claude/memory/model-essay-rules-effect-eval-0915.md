2026-09-14 深夜至 09-15，对示范文规则两波十三条做了一次效力评估。方法：四篇同尺**盲评**（甲＝六上二多彩的活动、乙＝六上四笔尖流出的故事、丙＝六上三走楼梯、丁＝五上一心爱之物，代号给 agent、不告知组别与作者），三位 fresh agent 按查项分工、每位横向量四篇，主 agent 只跑脚本与汇总。报告＝`写作课详案输出/_规则评估-示范文两波规则-四篇同尺-20260915.md`。

## 结论（一句话：素材层做到了，咬合层没做到）

- **0914 素材层那波有效且可证**：A1／B1／B2／G1 四条查项呈干净分野——甲乙全达标（成人物证 0、学生物证各 5 处），丙丁全未达标（丙成人 5 学生 0、丁成人 4 学生 0）。
- **0912「够得着」需与 0914 叠加才生效**：丙是 0912 之后生成的、当时三道关全放行；今天 A1 判得出它，靠的是 5 句全部归入〔成人生活细节〕——**这一类正是素材层规则的句子层投影**。
- **0912 咬合三条零落地**：C1 四篇只有甲落实；**C2 旁批表双标准四篇全未达标**（规则立了三天、实测零达标）；C3 唯一未达标的是规则后的乙（起笔与反例段同型，三次独立判断都指向同型）。
- **无任何判据空转**：12 条查项每一条都在规则前的稿子上报了警。
- **规则没付质量代价**：R1 四篇无一被写平淡，三篇示范文强于本课正例段、一篇持平；与笔法锚点比表现力全部持平或略高。丙丁**不是写坏了，是写的人不对**，修法是换素材域重写而非把句子写钝。

## 三条可操作的发现

1. **落地率差异与 checklist 形态完全对应**：素材层两条在 model-essay／checklist／rubric 三处都是独立条目、判据逐字复述 → 做到了；咬合三条在 checklist D 组**挤在第 59 行同一个勾里**（0912 瘦身时并的）、rubric 只覆盖其中两条 → 全线未落实。**规则写没写 ≠ 自检看不看得见。**
2. **「要领数上限」缺第三个出口**：现行条文是「找不到的降为一句提醒或删」。实测乙与丙被判超标的条目（「让他的手替他说」「用一个动作替感动说话」）追问「删掉学生会不会真少一件工具」，答案都是真工具——正确处置是**补进核心技法行**，条文少了这一条出口。
3. **机检全绿 ≠ 示范文合格**：机检 E 的 ②③④（引文改写／旁批表子串／锚点复用）四篇全 0，而丁在这三项全绿的同时 A1／B1／B2／C4 全部未达标。这三项是合规性机检，与写得好不好无关。**能报出旧稿的是 ① 篇幅（丁超 L5 区间 56 字）与 ⑦ 成人生活词（丙丁各报强信号）——这两项都是新建闸门，补跑到旧稿上都拦得住。**

**Why：** 用户问「优化后两篇有没有达到优化目的」。若只评那两篇，结论只能说「这两篇合规」，说不出规则起没起作用；带上规则前的丙与病症经用户点名的丁做基线，才能把「规则起作用」与「碰巧写对」分开。

## 评估后的修补（2026-09-15 当日已落，用户拍板先做规则层）

两条根因均已改，改的是「自检看不看得见」不是判据本身：
- `checklist.md` D 组第 59 行那一个勾**拆成三条独立勾**（要领数不超／旁批表双标准／起笔落点不与反例同型），各自带可指认的动作与顺序义务（双标准明写「先挑句再核表，顺序不可倒」）。D 组由 10 条变 13 条。
- `model-essay.md` §五 3 **补第三个出口**：找不到对应短语的要领，先问「删掉学生会不会真少一件工具」，是真工具就补进核心技法行，不是才降为提醒或删；§〇 一屏卡第 4 条同步点出。
- `review-rubric.md` 维三「示范文细读三问」**扩为五问**，补上 §五 3 与 §五 5——此前冷审依据里只有双标准一条，另两条在 rubric 无落点，冷审自然接不住。

改完复核：机检 E 的锚点句仍从 §四之三 运行时取得 17 条、tone_gate 全绿，解析锚未破。

## ⚠ 同日仲裁推翻了本轮的一条判定，并查出我改规则时犯的循环论证

六上四那条「起笔与 ③ 反例同型」，派一位**不知作者身份**的 fresh agent 独立仲裁后**判不违规、不改稿**。仲裁查出三件事，前两件是三位盲评与我都没看到的：

1. **§五 5 的立条先例当年并未改示范文起笔**（三上《续写故事》，commit `93d6c31`）——处置是收准 ③ 的判词落点＋在师话里加一句显式点破（「不是说不许写第二天，老师这一篇也写到第二天，差别在于……」）。条文里「同型即改示范文」这个处置口与它自己的先例背离。
2. **我把评估结论倒推成了规则**：0915 那次修补往 `checklist.md` 里加的形态枚举（「同从声响起／同从我＋动作起／同从环境交代起皆属同型」）是从这桩争议的判决反推的，等于拿结论加固规则、再用加固后的规则反证结论。**已撤**。
3. 报告 2.3 节「正是 §五 5 明列的『同样从环境交代起』」系**误引**（§五 5 从未列过形态）；「三次独立判断都指向同型」也不准确——0914 冷审 B4 原话是「不命中规则本意，交你确认」，属报明文不认实质。

本案不违规的实质理由：③ 的正例段与反例段**逐字共用同一句开头**（控制变量），学生不可能推出「环境起笔＝跑偏」；③ 的判词从头到尾判的是「没有坎」、没碰过起笔；而「环境在开头交代」写在本课核心技法行、旁批表首行、三档标准优秀档，还是教材题面三条要求之一，改掉起笔等于让示范文不演本课技法，撞 §四之三 5「咬合优先」。

**§五 5 已改为判据精确化**（不是开例外口）：判的是「③ 判词实际判掉的那个点」上同不同型；两种情形不算同型——① ③ 正反两段**逐字共用**该特征；② 该特征**写在本课核心技法行里**。两个口子都是可核对的客观事实而非判断题；唯一滥用路径「为豁免而反向补短语」由 §五 3 的「先判是不是真工具」堵住。

**教训（比结论更要紧）：改规则时若判据来自某桩正在争议的个案，先停下来查立条来历与先例怎么处置的。** 我当时只看条文字面、没查 history，就把个案判决写成了通则。防辩护条款挡得住「作者当场自行推翻冷评」，挡不住「作者把冷评结论固化进规则」——后者要靠查来历。

**How to apply：**
- 再评规则效力照此法：**盲评＋按查项分工横向量＋带一份病症已知的校准样本**；校准针（某条规则改过方向的，看 agent 判不判得对）零成本且能当场识别出跑旧口径的 agent。
- 主 agent 自著的篇目必须派 fresh agent 评，且**不得推翻冷评结论**，异议只进附录存档。本轮乙的 C3 就是这么处理的。
- **挂账（0915 当日曾结三篇，现只剩两篇作数）**：六上四补坎处环境出力＋要领补进技法行＋换掉与正例同模具的锚点句（起笔同型经仲裁判不违规，加显式点破句）；六上二延长旁批表一格引句；**六上三当日曾以《去菜市场》结过这笔账，但该稿与其后继《电话手表》版已于同日先后删稿（用户拍板，均未留 git 工作区副本），⚠ 这笔账现回到未结状态**——重写时须重新满足 §二 素材域，走楼梯／去菜市场／电话手表三个方向都已被否，不要绕回去。当时冷审另揪出的三处咬合错（构思表第四格与师话「表上只有那一句」矛盾、段数断言说成七段实为六段、旁批表两条真工具未进核心技法行）随稿作废，但**都是重写时会再犯的类型，值得当自检项**。**余五上一《我的心爱之物》未结**——它配套 9 件齐、标准包已上线、PPT 已注入动画，重写牵动全线，单独排一轮。
