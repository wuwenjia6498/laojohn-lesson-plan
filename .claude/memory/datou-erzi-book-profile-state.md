**四个必须记住的事实陷阱**：
- **书目信息全空**：docx 无封面页、版权页、署名，作者/出版社/ISBN/字数/页数/出版年一律「(待补充)」。本书家喻户晓，**越是这样越容易凭印象补写作者、动画片情节、续作角色——一律不得写入**。同 [[xiaogou-xiaofangzi-book-profile-state]] 的无署名情形。
- **同一童谣两个版本**：「大头大头，下雨不愁……」在《新邻居》是四句、在《开心极了的大胡子》是六句（多「人家有大头，我有妈妈的手」）。须按篇逐字取，不得混用。
- **称谓边界**：第二辑正文一律称小头爸爸为「爸爸」、不出现「小头爸爸」四字，引用第二辑不得替换；「小眼睛」是女孩（原文「这是我的女儿」）。
- **画文冲突 11/17 幅**（本仓迄今最高比例）：鸟的颜色、床底下是谁、洋娃娃数量与睁闭眼、口袋形状、说背不动却在背、房子是谁做的、门牌号、坐还是站、外婆体型。**外婆形象在四幅图里胖瘦发色全不同**，角色归属靠原文锚句（胸前白兰花）与动作锁定、不靠长相；**任何环节不得拿图讲「外婆有多胖」**。

**docx 转换缺陷四处**：`小……·头`（多间隔号）、`良有`、`忘V记了`、段末孤零零一个`你`；另《数呼噜》中段一行「88」是页码残留、把那句话从中间劈开。全篇问号感叹号是**半角**，档案引文已转全角、字词未改。
