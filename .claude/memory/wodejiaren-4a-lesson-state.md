2026-08-25 教材换题重写第一例。2026 秋统编四上第二单元习作由《小小“动物园”》换成《我的家人》，
产出 `写作课详案输出\四上-第二单元-我的家人-写作课详案.md` ＋ docx（两步链已跑）。
**联网核实：四上八个单元只有第二单元换题，其余七课不受影响；本单元课文未变（仍是提问策略单元）。**
旧课全套产物按用户拍板**原地保留不动**（见 [[xiaoxiao-dongwuyuan-4a-ppt-chain-state]]）。

**Why（换题不是改稿，是重写——两题技法内核不同）：**

旧题＝把家人比作动物（找喻体、写相似点）；新题＝结合具体事例写出特点、把印象最深的地方写出来（挑事例、由事定人）。
**两版唯一逐字相同的只有评改活动**（读给同桌听查不通顺／回家读给家人听请他们评评像不像），示范文·对照表·三档标准·构思表·PPT 全部作废。

**How to apply（下次遇到教材换题，照这个顺序走）：**

- **第 0 步必须是改事实源，不是写详案**——写作课的官方来源是 `archive/`，新题在仓内零命中，不补就动笔＝伪造官方条款。
  五处：`archive/grade4-vol1.md`（**旧节保留并标「已停用」、新节另起**，因为旧详案还在、不能失去依据）／`archive/index.md`／
  `course-map.md` 题目行＋文体线链／`situation-anchors.md` 锚点行／`unit-texts.md`。
  教材原文以**用户拍的教材照片**为准（一手来源，优先于联网）；教材页没印的重难点/教学建议**联网核实教参**后写入并留来源与日期，评价量表核不到就显式标「推定」。
- **`unit-texts.md` 的旧结论即使不变也要整节重写**：判据是「课文最突出的写法是不是**正是本课这一招**」，换题后「这一招」变了，旧论证自动失效。本课结论仍是不引（形态 A），但理由从「不承担比喻」改为「不承担用一件事写出一个人」。
- **文体线链一改，三篇既有详案的提纲表第 3 行会静默过期**（猜猜他是谁／身边那些有特点的人／“漫画”老师），须同步改并各自重渲 docx。宣传物料（招生海报／馆内海报／宣讲中间稿）也印着旧链，本轮未改。

**★ 差异轴：写人线上四上的位置只能是「反转」**

三下《身边那些有特点的人》已完整教过「先一句话点出他是个什么样的人，再用一件最能作证的事写清楚」，
连审题辨析装置都是「反复说爱看书／只讲饭点抽书那一件事」——**“概括 vs 一件事”三下已经教完**。
故四上不能再以「常常→有一回」为主技法（原地踏步），必须反转方向：
**三下＝特点→事（先给称号找事作证）；四上＝事→特点（先挑印象最深的那一件，再看它说明他是个什么样的人）**，难点落在**取舍**，正对教材新增的「把印象最深的地方写出来」。
联网核到的教参目标原话「通过印象最深、最能反映家人特点的事例，写出家人的特点」正好印证。

**★ 由此派生一条通用裁决：「倒过来」指的是构思顺序，不是成文顺序**

冷审 Pass A 指出本课差异轴与 `workflow-engine` 写人档降压铁律（第 2 节开场第一句就快写点题中心句）天然相抵。
用户拍板**守铁律、补一个出口**。理由：本课教的是「怎么想到这个特点」（从事出发），不是「文章不许有中心句」；
而⑥要写的那句中心句，正是学生从事里看出来、填在选事表最后一格的那个词——两者不矛盾。
出口＝「想让读的人自己看出来的，把这句先写在稿纸最下面一行，整段写完再决定要不要搬上去」。
⑦自检表第四条「把开头那句盖住，光读中间这件事，还看得出他是个什么样的人」同时兑现了这个出口的验证办法。

**本课特有的两个做法（可复用）：**

- **教材气泡当公共素材源**，破「不拿授课老师家人举例」的硬约束（池 4，写家人的题目最易踩）：
  ①用教材五段话做钩子（请学生挑一位最想认识的 → 老师追问「他怎么个会讲法」→ 学生自己撞见缺口），
  ③把教材那句「姥爷每天练书法、一年三百六十五天从不间断」当场添成一件事，④⑤示范文与构思表都写这位姥爷。
  素材源自教材页、可逐字核对，既不自造也不落到老师家人身上。
- **⑦第二层反馈＝改完之后同桌对表**：听的人只说一句「你写的这位是个什么样的人」，作者翻回选事表最后一格自己填的那个词比对。
  这是差异轴唯一的当堂验收动作，且放在自改**之后**，同时承担 L4「这样改好在哪」的回收。

**⚠ 生成时踩的四个坑（冷审抓的，下次直接防）：**

1. **引教材原句时擅自加了词**——教材没有「非常有毅力」四个字，我加了。后果不止是伪摘录：十行之后老师说「我从头到尾没说过『有毅力』三个字，可这三个字你们自己说出来了」，**学生其实刚听老师说过，本课最关键的一次演示当场作废**。凡引教材/档案原句，逐字比对再落笔。
2. **③的单点示范剧透了④的指向性问题**——③念的示范段里已含「手在抖」和那句原话，④的六问里有三问学生只是在回忆十分钟前听过的同一段。已把③剪到「写到天黑」为止，把那两处整个留给④。**此前记的是①剧透③（跨维查项七），③剧透④是同族新形态。**
3. **审题辨析两段与示范文只写「念给学生听」**，但十行后要求「回头数一数第一段里有几件事」「哪一句让你知道姥爷写得吃力」——纯听记做不到，须按〔材料〕体例补投屏出示、念完不撤屏。
4. **提纲表核心技法行写成了禁令式**（「不先给他下结论」），与正文「两种都能用、最好搭着用」当场冲突；而提纲表是老师备课第一眼看到的那一行。正向表述规则的五个落点里，**提纲表那一处最容易漏**。

**同族句模第四次复发**：③接住选反例学生的起手（「你的道理老师听得出来／确实不糙」）在换题重写的新稿里**又出现了**，
说明根在生成侧默认款、与题目无关。已按 `variation-pools.md` 清单里早就写着的建议换形——
**由选反例的学生自己说它好在哪，教师只接一句「这几样你们都看准了」，不复述反例优点**；
清单同步补两条独立 bullet 并加了一条「首选解法是换设计、不是再加变体」的批注。见 [[twentyyears-hometown-5a-lesson-state]]。

**Pass B 另发现一种新撞款**：⑤引出构思表的整段与**基准篇**《推荐一个好地方》近逐字（此前实测的照抄都发生在相邻单元之间）——
**照抄源是「正样本」本身**。措辞已打散，话轮也换了一串（改为先出示教师填好的表、口头答挑事理由，再发空表让学生填，与基准篇顺序相反）。
