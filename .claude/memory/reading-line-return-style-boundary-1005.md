2026-10-05 写作课做了两个月后回到读书会（试写书目《稻草人》），用户问：写作线积累的规则与记忆、加上模型换代，会不会影响读书会？

**评估结论**：读书会技能本体稳（MEMORY 读书会区 15 条经验逐条 grep 均已固化进 checklist/style-and-format/lesson-templates/review-rubric；共享引擎契约未变；台账 08 月四点 A 块 6/7/7/8 类未破阈值）。风险全在接缝：① 冷审 Pass B 依据原写死为写作线 style-criteria，读书会无判据源；② MEMORY 约七成是写作线，易串味（取消三维目标、禁 `**`、45 分钟精细配时、`【】`替代小标题、规范书面语体）；③ 写作线通用经验未回流；④ 模型换代影响只能实测。

**用户拍板语体**：08 月以前读书会文风「还可以」，写作线是因自身文风不理想才一路优化——故**读书会延续「散文化口语，亲切」，不引入写作线约束**。理由：写作线的药治的是讲抽象技法时的电报体/生造词/隐喻化动词，读书会是围绕故事讨论，没有这个病；且生成时加措辞约束本身伤文风（见 [[constraint-layering-generation-vs-coldreview-0804]]）。写作线 `prose-exemplars.md` 样本一至五本就是 AI 之前的人工读书会稿，读书会只借样本原文锚定“口语亲切”，不用卡头特征条。

**已落地（1005）**：style-and-format 语体条补样本锚点＋写作线工具不适用声明；「不分级的通用底线」补承接复述/禁预演总结/禁自报弱点三条（checklist 同步一勾）；review-rubric 新增 Pass B 节；detail-review §1.5 依据栏按线分；SKILL「生成后的优化」补多轮改稿二次冷审（源 [[local-edits-need-second-cold-review-0918]]）；CLAUDE §6 加「师话语体」行；写作线样本卡头登记被读书会引用。

**试写基线结果（1005·《稻草人》L3）**：Pass B 仅 3 类/10 处（8 月四本 6–8 类），回炉闸未触发，≤5 字短句 1.1%（8 月 3.4–6.9%），无写作线串味——**文风不需加约束**。但 Pass A 抓到生成侧真伤：照抄图单判读（插-03「浅浅一层水」与真图不符）、把转述写成亲见（小草看医生）、分组后指令落空、同日两节装载超时。结论：新模型的病在结构自检与事实细节，不在措辞；**图单「画面描述」也要打开真图核，不能整句搬**。台账 #45。

**How to apply**：写读书会时别把写作线 MEMORY 条目当通则；只有已写进 lesson-plan 规则的才适用。试写《稻草人》后对比篇幅/师话密度、Pass B 类数、串味、语体贴近样本一至五，再决定是否进一步改规则（如“偏薄补丁”改双向）。
