**设计取舍（下一篇记事类题目直接可查）**：
- 差异轴：记事线四上档＝「按顺序写清起因经过结果、经过分步」＋「最要紧的一步写具体（看到的、听到的、想到的）」，六上两篇分别是点面结合与围绕一字选材详略，不撞。「详略」只按档案措辞说成「其他几步交代清楚就过去」，不上升成六上的术语。
- 真实情境不造载体：教材题面自带「读给同学听，请同学说说是否写清楚了」，读者＝同桌（机构班不同校、彼此不在场），成败标准＝听完能用一两句说出起因结果＋指得出写得最细的那一步，作者对照构思表第七行圈的那一步——客观对表、不靠学生自报。
- 开场＝图像揭示式·发现者：投屏教材「初试身手」左图跑步比赛（三名蓝衣同学在跑、场边挥三角小彩旗与啦啦队手花），问「最后谁得了第一」学生答不出，点破「读你作文的人和看图的人一样不在场」。四上此前五篇已用满 情景代入／实物道具／悬念提问／素材追问／换人小实验 与 发现者／尝试者／回忆者／好奇者 四种姿态，姿态只能与四上一同款（发现者，相隔四篇）。
- ② 热身＝同桌互讲一分钟＋听者挑「最要紧的是哪一下」＋讲者当场演那一下（演练类），选事前置判据「说得出第一二三步的才选」；与三上《写日记》的「快报新鲜事」差在听者挑一下＋当场演。
- ③ 审题两段同写捉蚊子、首句逐字相同：反例起因细、感受真，只把经过压成一句「费了好大的劲，找了半天，终于把它打死了」；正例经过三步、中间一步含看到／听到／想到三样。判据落在「读完能不能说出蚊子怎么被捉住的」。课文匹配度极高（习作单元），命名处投屏「梳理与交流」四条（学生读第三、第四条），收束处引《小木船》文后题「转眼几个月过去了」让学生判略写。
- 示范文＝同龄「我」放学一个人被困小区电梯十一分钟（题材域：小区生活意外小事，避开四上已用的旅行／养育手作／家庭内景×2／神话穿越与三上写日记的校园班级）。第二段（按紧急呼叫）185 字为最长段，与师话「第二段最长」实测一致。
- ⑦ 三种情况自判（起因结果漏了／同桌指的步与圈的步不同／都对上）各配一条改法，情况写在稿纸上角驱动自改。
