四上第三单元《写观察日记》写作课详案 2026-08-02 全新写成并出 docx（旧稿此前已删，与旧稿无承继）。本课最难的一关是**档案作前环节写着「提前一周布置观察」，机构课两节连排给不了**——落地方案（锚点表「课堂用前后对比图/带已养几天的实物」的具体化）：

- 教师课前隔三天各发一杯同一袋黄豆（第 1／3／6 天），上课并排出示并报出各自下水的真实日期星期 → 学生一眼看到的就是同一样东西三个时间点的真实样子，替老师「补记」这几天的日记。**日期真实、变化真实、当堂可观察，不靠虚构也不靠课外准备**；来不及发的退回三张隔天对比照片。
- ⚠ **豆子必须按发豆芽的常规做法「泡一夜→沥干→湿布捂养、每天冲两回」，不能全程闷在水里**（六天必发酸发臭，全课唯一的实物锚当场垮掉）；教具块另附「课前一天揭布确认，坏了改用对比照片」的异常处理。这是 0802 冷审拎出的最高优先级隐患，初稿写的正是「同样的水量泡满六天」。
- 成败标准与主反馈就势落在实物上：念一则，听的人端着豆子盘找出他写的那一处，**指得出＝写清楚了**。这比「互读说说发现了什么变化」更可验证，且是官方反馈活动的实物验证式落地。
- 主技法＝一天一则、每则只抓变了的那一处（先点出→用「原来……现在……／渐渐地」写清→末了一句心情），正对档案难点「连续日记里避免天天重复」；审题辨析两段对照就用「把第一天说过的又说一遍」当反例。

**开场姿态通则（0802 用户三轮逐句改出来的，写任何用教具起头的课都适用）**：教具本来就是老师为这堂课准备的，**别给老师编一段「本来打算做、结果没做成」的懊恼来制造由头**——学生一眼看得出假，而且「没写记录」是没去做、不是没做成，措辞上也兜不圆。正解是坦白直说：「这三杯是我特意为今天这两节课发的……我没有做记录，就等着你们今天来记。」抛任务随之改成「交给你们来记」，收尾也不说「替老师补回来了」。真诚比戏剧性重要。

三条生成侧教训：① 本课的成败判断语（指得出／在杯子上找着）极易超 [池7 单篇至多两次] ——**判定口径是「动作指令不计、评价判断才计」**，否则整篇没法写；② 口令短语「变了的那一处」「原来什么样、现在什么样」初稿各 7–8 次，须按池8 压回 ≤4，出路是换成具体所指（皮怎么松的、缝里挤出了什么），不是换同义词。
