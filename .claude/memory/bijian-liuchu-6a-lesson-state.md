**用户 0914 晚第三点（示范文空间硬伤）**：「张明趴在窗口往后面看，鞋盒就在第三丛底下，没有盖子」两层错——① 方向：首段已定丁香在教学楼后面、香气从**后窗**飘进教室，看丁香只能是趴后窗**往外**看，「往后面看」读成室内扭头；② 知情边界（§六 第 3 问）：隔雨从窗口看不见丛底下鞋盒有没有盖子（第五段王寒冰还得蹲下拨枝子才看见进了水），他知道没盖子是因为窝是他做的。已改为「趴在后窗往外看，那排丁香在雨里模模糊糊的。鞋盒就在第三丛底下，他做窝的时候没有加盖子」——把「看见的」与「知道的」分开写，⑤ 参考答案同步。**教训：写虚构故事的示范文，首段一旦交代了方位（楼前楼后、哪扇窗、谁在哪），后文每个「看」字都要回首段核一遍朝向与视线可达。**

**同日通读示范文再查出两处（用户要求复查）**：① **动作物理不成立**——「王寒冰把鞋盒端出来，倒掉水」而麻雀还在盒里，倒水鸟会掉出来；改「护着麻雀把水倒出来」，顺带这个护的动作正演出她的转变。② **生物常识与时间线**——「羽毛还没长齐」的雏鸟一天只喂一次面包屑活不了一星期；改成受伤幼鸟「一边翅膀垂着，飞不起来」，捡到时间由「上星期」改「星期一」，与王寒冰那句「这个星期你第三次了」（周一二三各一次）严丝合缝。**两处的共同查法＝把每个动词当真事演一遍**（倒水时鸟在哪、一天喂一次够不够、这一星期各天干了什么），比通读顺不顺管用。判为合理留白不改的两处：王寒冰为何径直走到第三丛（她三次抓到他、结尾已蹲在那里，正是反转的力量所在）；鞋盒端回教室后秘密怎么保（外套裹住已作交代）。
