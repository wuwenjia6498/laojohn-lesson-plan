**逻辑审八处（可复用的查法，写同类稿直接适用）**：
1. **自己问的话自己没守住**——问「在X开口之前文里写了什么」，收的答案里有一件是X开口时才说的；查法＝教师总结里逐件回原文定位，看是否落在自己划的范围内。
2. **「答案写在题面上」**——朗读范围只到转折，则「从哪一句变方向」必是末句；**装置的边界不能与要验的答案重合**（与[[feedback-device-three-way-consistency-0915]]同族，六上三已踩过一次，本篇是第二次）。
3. **「三种情形，四种学生」**——⑥ 明写允许「结果来不及写先停在转折处」，⑦ 的分流却假定「最后」一空是「填得不一样」而非空的；**凡上一环节开的口子，下一环节的分流必须有对应出口**，否则装置自己造成失败。查法＝把上一环节所有「允许／例外」句抄出来，逐句到分流表里找位置。
4. **问了判断题却不给答案**——③「哪一段更符合要求」全篇无回答，而学生的反对理由（第二段没写完）正撞教材「把故事写完整」；**审题辨析可以「不判优劣」，但那就不能用判断题的问法**。
5. 师话与括注数字打架（一分钟 vs 2 分钟）。
6. **布置的观察任务盖不住要收的答案**（只让看手脚眼睛，参考答案一半是台词）。
7. **给了两条路却只备一条路的样例**（两种起笔，三个样例全是环境起笔）——与「点名可行做法只点一种」同族的反面。⚠ 补样例时**别改写示范文句子**（撞 essay_audit ②「疑似改写须打回」），也别用参考答案里已有的那个例子（会让参考答案变成复述师话）。
8. **把留白说成因果**——「雨也让王寒冰站了起来」文章一字没写；改成「她为什么站起来，作者一个字没有写，读的人却猜得到」，留白仍是留白。
