3. `situation-anchors.md` 情境列的词语组
4. 详案 38 处（词语组只是其一，**审题辨析两段、平淡版、加波折版、构思表、示范文、旁批表、第2课时首句示例全部连坐**）

**三条只有实做才知道的坑**：

- **教师侧配套是 2 页硬闸门**：示范文换长一点、delivery 里多加两句提醒，就溢出到 3 页且渲染器直接报警。示范文受「与详案一字不差」红线约束不能压，只能回压 `delivery.envs` 的旁注文本——本次压了三条才回到 2 页。
- **单元号错位可能因换版而消失**：仓内 `course-map.md` 记三上·三＝续写故事／四＝我来编童话，2026-08-21 实证与教材对调，**2026 秋版已改回与仓内一致**。旧的「引课文不点单元号」措辞规则对这两课**已作废**，见 `unit-texts.md` §0.5 的红框。
- **新教材新增的格式要求要找落点、不能只写进档案**：本次「题目居中」落在四处（示范文带标题行＋旁批表首行／第2课时首句示例改成「第一行留给题目」／修改收束加一段起题目师话／三档标准基础过关档）；「修改符号」按 [[writing-lesson-revision-symbols-natural-use]] 判为已会能力，自然用、不重教。
