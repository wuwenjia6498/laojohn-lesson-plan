2026-09-21 立 `laojohn-lesson-video`：写作课详案 + PPT + 教师用配套 →
15–25 分钟备课视频（PPT 画面逐页推进 + AI 配音 + 硬字幕）。
**填的是仓内至今空着的师训位**——销售材料里「有师训吗？」一直答「总部还在定」。

**四项用户拍板**：受众＝加盟商老师上课前自学；形态＝PPT 录屏＋AI 配音；
时长 15–25 分钟；画面源＝**外部终稿 pptx 临时拷回**（在知悉页码失配风险后仍这么定，
方案据此加了 `align_check` 显式闸门）；教材插图照常出图、打「内部备课使用」水印；
TTS 优先复用现有密钥。

**Why 旁白是「备课解说」不是照念师话**：老师手里已有详案（逐字稿）、PPT、教师速览三份纸，
缺的是有人带他走一遍。实测五上一师话 6772 字，照念 24 分钟且零增量；
改成每页 150–200 字的解说约 18 分钟。**真正的增量是教师用 json 的 `delivery.envs`
三色旁注（keep 必守／free 可放开／why 为什么）+ warns**——这层此前只印在一张 A4 上，
从没人展开讲过。

**How to apply**：八步链、两道闸门、共享件清单见 `SKILL.md`；写法判据唯一源＝
`references/narration-style.md`（生成/机检/人工审稿三处共读，`write_narration.py`
直接读它原文注入 prompt，不另存口径）。

四条经验值得别处复用：
- **页码权威源是详案内联页标**，不是页标映射 json — [[pagemap-json-page-offset-0921]]
- **逐句合成 TTS**：字幕边界＝音频实测边界，零漂移，**不需要 TTS 返回字级时间戳**，
  选型时不必为这项能力付溢价；副产物是某句念错只重合成那一句
- **起手式靠提示词治不住，要程序轮换**：首版 23 页里 23 页 locate 都以「这一页是」开头，
  逐页看毫无毛病、连着听像复读机。改成按全局页号从 `LOCATE_OPENERS` 指定角度。
  同族经验见 [[writing-correction-tool-0818]]
- **照搬检测要判比例与最长连续段，不判片段命中**：技法名、学生任务指令、情境设定
  本来就必须与详案一字不差，按「出现过相同的 12 字」判会一口气误报 7 处

⚠ **字幕烧不上去的坑（查了半天）**：concat 图片序列是「每页一帧」，
`duration` 只告诉容器这帧显示多久，滤镜链实际只见到 25 帧。`subtitles` 按帧 PTS
取字幕，整页只会烧上起始那一刻的一条（多半是空的）——看起来就像字幕根本没生效。
**修法：`subtitles` 前面插 `fps=N`**，用输出端的 `-r` 代替不行。
❌ 别去怀疑 libass 或中文字体（`-f lavfi -i color=white` 单测一下就知道滤镜是好的）；
❌ `-ss 10 -i file` 抽帧验证会误导你（输入 seek 重置时间戳），`-ss` 要放在 `-i` 之后。

## ⚠ 选通道要先加载配置（静默 bug，0921 踩过）

`ttsclient.make_tts()` 读 `TTS_PROVIDER` 决定用哪个通道，而这个值写在
`tts.config.json` 里。原先 `_load_env()` 只在各通道 `__init__` 里调——
等于「先选通道、后读配置」，config 里的 TTS_PROVIDER **永远读不到**，
静默落回默认的 aihubmix。

**后果**：换好火山音色跑全量，188 句全是用 OpenAI 英文音色合成的。
**它完全静默**：不报错、有音频、时长正常，唯一破绰是失败句的报错前缀写着
`aihubmix 合成失败`（若那一批恰好一句不失败，就彻底发现不了）。
辅助迹象：实测语速 3.89 字/秒（aihubmix 的速度）而不是火山的 5.1+。

**两道修法都已落地**：`make_tts()` 开头先 `_load_env()`；
`synth_voice.py` 开跑前打印「通道 X · 音色 Y · 语速 Z」做哨兵。

**通则**：凡「用哪个后端」这类选择性配置，读它之前必须确保配置已加载，
并在日志里把实际生效的值打出来——默认值兼容的错误最难发现。

## 用户看第一支片后提的四条（0921，已全部落地）

1. **不要报点击次数**。「一共四次点击」这类老师自己点课件时就看到了，
   页页报一遍只是占时间。改了三处：判据的 locate 素材表、prompt 硬线、
   `LOCATE_OPENERS` 里那条「用点击节奏开头」。
2. **片头要极简**。只说几年级哪一册、第几单元的习作、题目是什么、写哪一类。
   不说「这支视频会带你逐页看…」这类导览话。cover 预算 80 → 45 字。
3. **⚠ 讲评环节只在详案里，实际 PPT 已删**——跨课次事实。
   详案给它留着页标，分镜就会当它是一页真 PPT。三上一实测：详案标 P25 是讲评页、
   PPT 的 P25 其实是 THE END，成片里就出现「THE END 配着讲评旁白」。
   `drop_appendix()` 缺省丢掉（`--keep-appendix` 留口）；**丢掉后腾出的那一页回到 tail_unused、
   由 outro 认领，正好对上 THE END**，一举两得。
4. **字幕不准叠在课件上**。课件底部常是本页的关键论点
   （实测 p09 那行「这不叫特点」正是全页结论），叠上去就盖住了。
   改成**底部加字幕带**：输出 1920x1232（课件 1080 + 带 152），浅灰白底 + 深灰字、
   无描边无底框。⚠ **带高要按两行算**（wrap 会折行，旁白均 28 字，两行是常态）：
   实际字号 = FontSize/384*输出高，要求 MarginV_px + 两行高 ≤ BAR_H，
   否则第一行顶进课件区（120/150 两档都溢出过）。水印 y 要钉 SLIDE_H，不能用 h。

## 两条提示词工程经验（0921 调片尾时打出来的）

**① few-shot 范例会被逐字照抄。**
片尾反复写元叙述（「这一页没有具体教学任务」），连加三条禁令都治不住；
给一个正面范例立刻就对了——**但它把范例几乎逐字搬了过去**。
当时范例写的恰好是本课内容，所以没出错；换个课次就是张冠李戴。
**对策：范例一律用「另一个场景」的内容**（片尾范例用写景课），
并写明「只看语气和结构，内容一个字都不要搬」。

**② 素材不贴切时，模型会自己编一条。**
教师用 json 的 `delivery.envs` 末条常是合并条（`⑥–⑧`），挂到具体某页时内容对不上。
实测：s24（订成图鉴）拿到的 why 讲的是「快问快答」，模型觉得不贴切，
就自己编了「为班级留下共同记忆」「仪式感和责任感」——典型 AI 腔升华。
判据里写了「why 没素材就不写」不够，模型把「有素材但不贴切」当成了「该我发挥」。
**对策：明写「这条素材可能不针对本页，不贴切就不写，绝不准自己编一条意义出来」。**

**③ 机检的禁用词要分清「旁白在说」还是「在引述屏幕」。**
片尾 locate 引述页面标题『 THE END · 下次课再见 』被判成客套话。
客套话这一类先剔引语再查；AI 腻套语与替总部承诺不豁免（引语里也不该有）。

## ⚠ locate 不准描述画面（0921 用户两次点名）

「屏幕上写着『先在心里选定一个人』」「封面上印着…」这类句子等于白说——
**老师正看着屏幕，把标题念一遍没有任何信息量**。
`locate` 要回答的是「这一页拿来干什么」，不是「这一页长什么样」。

**根因在轮换池自己**：`LOCATE_OPENERS` 原来六个角度里有三个写着
「从屏幕上…说起」，等于指派模型去念屏幕。已全换成有实质信息的角度
（在整节课里的位置、要解决什么问题、接上一页的结果、在技法链上的作用…），
并加了机检 `SCREEN_DESC`。

**⚠ 第二次返工学到的：轮换池要给「开头怎么起」，不能只给「写什么角度」。**
把六个角度全换成有实质信息的之后，内容确实不同了，但因为条条都是「说这一页…」，
落笔后 **22 条 locate 里 19 条以「这一页」开头（86%）**——角度换了，调没换，
听感上跟之前的「屏幕上…」一样单调。现在池子里直接写「以『学生刚…』起头」
这种句式指令，并加了硬线「以这一页开头的本批最多一页」。

**机检也漏了**：起手式重复只比前 6 字，而「这一页」正好 3 字，
19/22 同头完全报不出来。已改成前 3 字与前 6 字都查（3 字阀值 35%）。
**通则：做「同头」检测时，窗口长度要盖住最常见的短起手词（三字词）。**

**通则：轮换池里的每一条都是在指派模型写什么。**池子里混进一条坏角度，
全片就有六分之一的页会写成那个样子，而逐页审很难看出是系统性问题。

## 片头片尾的形态（0921 晚定稿）

- **两者都不写 `locate`**。封面印着什么、末页写着 THE END，老师自己看得见，
  再描述一遍就是凑话。片头＝`do` + `bridge`，片尾＝只有 `do`。
- **片头就两句**：几年级哪一册、第几单元的习作、题目、写哪一类，完了就进正课。
  实测 55 字。机检的 90 字下限是给教学页定的，**结构页得单独分档**
  （`PAGE_RANGE`），否则等于逼着写废话。
- ⚠ **片尾是课后回顾，不是课堂进行中**。实测写出过「巡视时盯住两点」——
  那时候课已经上完了，根本没学生可巡。根因是**我给的范例里就带着「巡视的时候」**，
  模型把这个动作词搬过来了。已把范例改成纯回顾口气，并加了机检
  `OUTRO_BANNED`（巡视/收作品/收上来/走一圈/当堂）。
  **教训：范例里的每一个动词都会被搬走，写范例要逐词检查时间线。**

## 配音改 V3 接口 + 讲解指令（0921 晚）

用户要求「模拟老师真实上课的说话状态：语气自然亲切、有讲解感、
有停顿与思考感、重点放慢加重」。查完文档的结论：

- **豆包 TTS 2.0 不支持 SSML 的 `<prosody>`/`<emphasis>`**，SSML 只有 `<break>`。
  语气只能靠 **V3 的 `additions.context_texts`——用自然语言下指令**
  （文档原话示例：「你可以说慢一点吗？」）。**这是从「念稿」到「讲课」的唯一开关。**
- **V1 接口官方写明不支持 2.0 音色**（`*_uranus_bigtts`），而我们一直在用这个组合。
  已改 V3 单向流式 `/api/v3/tts/unidirectional`。
- 另一件只有 V3 给的：**`additions.section_id`**，多次串行合成共享上下文。
  我们是逐句合成，没它每句都独立起调、整片语气会碎。全片共用一个 id。
- `audio_params.speech_rate` 是 **[-50,100] 的整数偏移**，与 V1 的 `speed_ratio`（倍率）不是一回事。
  按语块分级：locate/bridge +6、do 0、why/risk -6（`synth_voice.ROLE_RATE`）。幅度必须小，大了就是表演。

**三个踩过的坑（都会让人查错方向）**：
1. **`additions` 是 JSON 字符串不是对象**（同 V1 的 `extra_param`）。传 dict 报
   `cannot unmarshal object into ... of type string`。
2. **响应里 `code=20000000` 不是错误，是流正常结束**（message 就是 "OK"）。
   当成错误会让每次合成都「失败」，而数据其实已经收齐了。
3. ⚠ **配置文件里的旧值会静默盖掉代码新默认值——这是同一天第二次踩**。
   代码默认改成 V3 端点了，`tts.config.json` 里还写着 V1 地址，
   于是拿 V1 端点发 V3 的 body，报 3031（后端处理错误）——这条报错完全看不出是端点错了。
   **排查手法：拿裸 requests 直接发一发，成功就说明问题在客户端读配置这一层。**
   同族第一次：`TTS_PROVIDER` 写在 config 里但选通道时还没加载。

⚠ **改指令必须让缓存键跟着变**：`key_of` 的 `extra` 已包进指令与语速偏移，
不包的话改了指令重跑会全部命中旧缓存，听着没变化还以为指令无效。

## 火山语音已开通（0921）

控制台 `console.volcengine.com/speech` → 「豆包语音合成模型2.0」。
**APP ID 8950210010**，token 在 `scripts	ts.config.json`（gitignored）。
开通的是**正式版后付费**：不限字数、**0.0003 元/字**（一支片子 5473 字 ≈ 1.6 元，
17 课次全做 ≈ 28 元）、并发 10、**送 99 款音色**（官方字面只说送两款）。

三个实测事实：
- **`cluster` 用 `volcano_tts`**，大模型音色（`*_uranus_bigtts`）也是这个值，一次跑通。
- **语速 5.29 字/秒**（speed=1.0），远快于 AiHubMix 的 3.5——
  同一份 5473 字旁白从 22.7 分钟降到 18 分钟，**不必再用 --speed 1.1 硬加速**。
- 开通确认框写明「免费额度失效、无法回退试用版」，不可逆；当时试用包已过期故无实质损失。

⚠ **顶部那个「签约数据授权换免费额度」没做也不建议做**：省下的是几十块，
而授权范围涉不涉及课件与详案内容判断不了。

⚠ **AiHubMix 的 TTS 够跑管线不够交付**：`/v1/audio/speech` 复用现有
`AIHUBMIX_API_KEY`、零开通，但只有六个 OpenAI 英文音色，念中文是洋腔，
**实测 3.5 字/秒**（要 `--speed 1.1` 才压进 25 分钟）。火山 Seed Speech
**不能复用仓内 ARK_API_KEY**，是独立产品线要单独开通。定音色要盲听，别看官网 demo。

## 增量占比机检（机检第九项 · 0921 晚加）

张祖庆视角审第一支片的旁白稿，取数报出一组要命的数字：
**do 57% / why 17% / risk 3%（12 页里只有 3 页有）／增量合计 20%，而旁白总字数是详案师话的 94%**。
结论：那支片大半时间在陪老师把详案读了一遍。

于是把「这支片到底有没有给出它承诺的东西」做成可机械判定的三个数字
（`audit_narration.py` 的 `check_increment`，阈值表与实测数据在 `references/narration-style.md` §三.3）。

两条不可推断的：

- ⚠ **「上游素材薄」报警不是写稿的错，是该课次本身撑不起一支片**。
  实测：三上一只有 **3 条**卡点素材（`参考：` 0 行、〔应答〕 0 条），
  六上四有 **23 条**（17+3+3）。差七倍多。
  根因是三上一是早期课次，`参考：` 与〔应答〕体例当时还没定型——
  **这不是旁白写得更用力就能补上的，得回头补详案**。
  所以这项机检要在写稿之前（`build_shotlist` 一出就）就看。
- **卡点素材有四个来源，前两个一直没被用起来**：
  教师用配套的 `warns`/`nono`（整课只六七条，摊到二十几页远远不够）、
  **详案里的 `参考：`**（它就是一张卡点地图：学生会往哪几个方向答、哪个方向是偏的）、
  **〔应答·……〕答偏预案**（现成的「答偏了怎么办」，而那正是新手最怕的时刻）、
  `source.stage` 里带判断的舞台指令。

## ⚠ 凡是写进判据文档的例句，都会被逐字抄（0921 一天内犯三次）

三次现场，同一个根因：

| 犯处 | 现象 | 抄的是哪句 |
|---|---|---|
| 片尾 | 写出「巡视时盯住两点」，而片尾是课后回顾、根本没学生可巡 | 我给的 few-shot 范例里就带「巡视的时候」 |
| `locate` | 22 条里 19 条以「这一页」开头，轮换池换了角度没换调 | 池子里 6 个角度都是「说这一页…」 |
| `do` | 29 页里 **27 页**以「这一页」开头，其中 **15 页一字不差** | `narration-style.md` 的 do 范例「这一页只有一件事不能错」 |

**两条操作约束（改判据文档前必读）：**

1. **判据里的例句只写内容，不写起头句式。**
   要示范语气就从句中切入；起头交给程序的轮换池。
   few-shot 范例必须用**另一节课的内容**并写明「一个字都不要搬」。
2. **轮换池要给每一个反复出现的块，不是只给第一个出问题的块。**
   locate 治住之后病立刻挪到 do，再治就挪到 risk。
   现在 `LOCATE_OPENERS`/`DO_OPENERS`/`RISK_OPENERS` 三池按页号取模并行。
   同族：批改工具的 OPENERS 也是「靠提示词说别重复治不住」（见 writing-correction-tool-0818）。

## 片长不再以师话字数为锚（0921 改）

旧版 `tune_budget` 把全片归一化到「师话字数 × 0.93」。
而张祖庆视角报出的病灯恰恰就是「旁白总字数是详案师话的 94%」——
**拿师话字数当锚，等于从预算层就把「陪老师读一遍详案」写死了。**

现在：页型基准 + **卡点素材加码**（refs、〔应答〕、warns、nono 都算）直接得总量，
只在溢出 4300–6800 时才按比例拉回。六上四实测 5210 → 6805 字，
重点页预算 150 → 335。
⚠ `--target-chars` 的 CLI 默认值已改 `None`——给硬默认（5200）会永久盖住新逻辑且完全静默，
同 CLAUDE.md §3 `insert_images_docx.py` 那条红线。

## ⚠ 逐页点名的副作用：轮换池指令会漏进正文（0921）

`LOCATE_/DO_/WHY_/RISK_OPENERS` 四池按页号取模、逐页点名后，起手式重复治住了，
但冒出反向的毛病——**模型把指令那半句也抄进了台词**：

> 指令：「从学生的变化起头：这一步过了，他们才能…」
> 写出来：「**学生的变化起头：**这一步过了，他们才能理解…」

五上四 s09 实测一处（六上四、三上一各 0 处，所以不是必现、只会偶发，
靠通读不一定逮得到）。已装机检 `OPENER_LEAK`（判 FAIL），prompt 里也加了一句说明。

**这条的普遍意义**：把约束从「通则」改成「逐页点名」能提高执行率，
但点名用的措辞本身会变成新的污染源——**两头都要看**。

## ⚠ 切片里缺的基础事实，模型不会空着，它会编（0922）

用户拿两张播放器截图指出：画面是 **P2「01 写作指导课」**（第 1 课时的分隔页），
旁白却两次说成「**第二节课**」。

根因**不在模型**：`shot_brief()` 交给模型的单页切片里，**压根没有「第几课时」这个字段**。
而课时分隔页的师话、舞台指令都是空的——模型手里只有眉标四个字，于是自己编了一个课时号。
它编了两次：s20（第 2 课时）蒙对，s02（第 1 课时）蒙错。

三处已修：切片补 **`第几课时`**、补 **`本课时包含的环节`**（分隔页没素材，
靠它才说得出这一节干什么，改完念出的五个环节与画面副标题一字不差）、
机检加 **`课时说错` 判 FAIL**（把说出口的课时数字与分镜单 `lesson` 对账）。

**两条可复用的：**

1. **写切片函数时，先问「这一页最基本的身份事实齐了没有」**——
   第几课时、第几环节、这一页在整节课的什么位置。缺了模型就编，而且编得很流畅。
2. ⚠ **这类错机检查不出来，因为它文本自身没毛病，是「旁白与画面对不上」。**
   前面那些毛病（起手式重复、照搬详案、翻页播报）都是「写得不好」，这一条是「说错了」——
   **老师看着屏幕一眼就露馅**。所以出片后要固定抽查课时分隔页那几帧，
   光看 srt 和机检报告发现不了。

## 配音调参的三条结论（0922 用户试听定案）

- **`RATE_BASE = 0`，别再往负值调。** 用户先反馈「原来语速偏快了点」，试过 -10，
  实测**太慢、听着不自然**（拖腔），当场回退到 0。渊博小叔在 0 基准上就是自然讲课的
  速度（实测 5.04~5.15 字/秒）。⚠ 角色之间的 ±6 起伏是该留的那层（locate +6、
  do 0、why/risk −6），放慢整体不等于把起伏抹平。
- **`DEFAULT_INSTRUCTION` 0921 转写时漏了一整句。** 用户原话七条要求，
  当时压缩改写成指令，**把「偶尔一点点自然的重复、迟疑或接续感，让人感觉是在边想边讲」
  整句删掉了**，只传了五条半。0922 补回「思考感／接续感／偶尔一点自然迟疑」。
  ⚠ 教训：**把用户的原话压缩成 prompt 时，逐条对账一遍**——漏掉的往往正是最难的那条。
- **「重复」没写进指令**：让 TTS 自造重复词容易直接变成结巴。真要有重复，
  得写进旁白文本（判据里禁口语碎片，两边会打架），代价大得多。

⚠ **指令进了 TTS 缓存 key**，所以改指令＝全片重合成（约 200 句、1.8 元），
改之前先用单页试听：单独调 `ttsclient` 合成一页拼成 mp3，**不碰正片的 `audio/`**。
一次只改一个变量，否则听不出是哪一处的功劳。

## 首尾三页的口径（0922 用户定）

用户原话：「开头前二个页面和结尾页面的内容承载太多」。给了 A（每页只留一件事）
与 B（保留信息、只压重复）两案，**选 B**，另加两条调整：

- **封面只说年级单元和题目**，别的一概不讲。
  ⚠ 连带：**「两节课连排：第一节…第二节…」这类话不要写**——每课都一样，
  听着模板化。`cover` 预算随之从 80 下调到 **40**。
- **片尾要有收束句**：`end` 的结构定为**「一句收束 ＋ 一个落点」**
  （「这一课的备课讲解就到这里。」＋ 上课前该动手做什么）。
  ⚠ **收束句不等于客套话**——禁的是「期待下次课」「祝教学顺利」这类空洞寒暄，
  不是「讲完了」这个信号。客套词表不动。
- 三页共同修掉的：封面不讲提纲结构（后面每页都在讲，开头说＝剧透）；
  课时分隔页的 locate 与 do 不各讲一遍同一件事；片尾 do 与 end 里同一句追问只留一处。

**文字要通俗平实**（用户 0922 两次点名）：不用破折号拼长句、不用四项排比、
不写「最值钱的部分」这类营销腔、不用「班情」这类行话。
