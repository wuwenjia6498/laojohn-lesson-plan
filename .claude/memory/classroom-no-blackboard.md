用户拍板（2026-07-05）：实际上课的教室**没有黑板/白板**。课案详案里**禁写「板书 / 记到黑板 / 黑板上的大图 / 写在黑板 / 立在黑板」等依赖黑板的老师动作**。

**替代口径 = 学生学习单为主（不依赖任何设备）**：可视化图（气泡图/鱼骨图/人物关系图/维恩图、写作课的构思表/五感表/评价量表）本就是发给学生填的学习单、图在学生手上；老师的角色是**口头把大家说的归拢、请学生补到自己的单子上**，而非在黑板上另画一张集体大图汇总。预制框架/示意（如全书结构「地图」）改为**老师口述、学生在本子上跟着记**；后文回指该产物不写「老师画的那张图」，改「我们一起记下的那张」。

**Why**：呼兰河传详案曾出现 4 处板书表述（记到黑板/板书/补进黑板大气泡图/汇总到黑板鱼骨图）被用户指出与真实教室条件冲突。

**How to apply**：生成/检查详案时全文检索 `黑板`/`板书`/`白板` 应零残留；图的汇总一律走「学习单 + 老师口头归拢」。已固化三处——lesson-plan `references/style-and-format.md`「课内话术骨架·课堂无黑板/白板」+ `references/checklist.md`「话术格式」组；writing-lesson `references/checklist.md`「E. 逐字稿与格式」组。两 skill 共用同一课堂物理条件。关联 [[hulanhe-lesson-plan-state]]。
