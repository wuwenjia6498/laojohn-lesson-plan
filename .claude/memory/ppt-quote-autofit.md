`laojohn-ppt` 读书会 profile 的「原文齐读」页(`layouts_reading.render_quote`)新增**超长引文字号自适应**(2026-07-13,为《汉修》十问全文页而做):默认 24pt/1.8 行距估算放得下就完全不动(向后兼容);放不下才沿梯 (24,1.8)→(22,1.65)→(20,1.5)→(18,1.4)→(17,1.35)→(16,1.3)→(15,1.3)→(14,1.25) 降档,估算系数与写作 profile 示范文同源(字宽1.15/行高1.1,保守宁小勿出血)。

**Why**:旧版固定 24pt,长引文(如整封信、十问清单)会溢出米色书页底、"——节选自"掉到卡片外(汉修导读课 P04/P14 实测已出血,用户截图可证)。

**How to apply**:是渲染器闸门行为、中间稿无需声明;**存量已烘 pptx 不自动变,重烘才生效**——重烘旧课件时若发现原文齐读页字号变小,是在修出血、非回归。引导问题 QA 版式(add_qa_textbox)**没有**同类自适应,三问三答会溢出:内容侧解决(压短参考/拆页),见汉修交流课1 P16 拆 P17 案例。[[hanxiu-lesson-plan-state]]
