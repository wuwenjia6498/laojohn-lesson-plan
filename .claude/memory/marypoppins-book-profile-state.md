**头号事实陷阱（已写进档案第九节·下游必看）**：
1. **源电子版错字"纳翰"应为"约翰"**——第一章班克斯先生登报句把双胞胎男婴约翰误印成"纳翰"；正名以第九章章题"约翰和巴巴拉的故事"为准，下游勿沿用错字。
2. **玛丽阿姨对奇事一律否认**，书中从不由她证实魔法；奇事"是真的"只由实物证据旁证（蛇皮腰带/不见的手套/指南针/肖像画）。勿写成"玛丽承认了魔法"。
3. **第五章"跳舞的牛"是玛丽口述的故事（故事中的故事）**，非胡同现实事件。
4. **亲属关系以书内明说为准**：眼镜蛇是玛丽"妈妈那一方"的表哥、贾透法先生是玛丽的"阿伯特叔叔"；伯特(卖火柴画家)书中只写朋友、未点破恋爱，勿断言。
5. **第六章环球四站(因纽特/非洲/"中国"[原书把中日混为一谈有译注]/印第安)带明显时代族裔刻板描写**，事实层记录，下游涉及须知是1934原作局限。
6. 谐音玩笑："贾透法"谐"假头发"，他其实秃头不戴假发，勿当真实特征。
