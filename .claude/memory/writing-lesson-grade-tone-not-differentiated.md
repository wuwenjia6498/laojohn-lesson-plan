用户 2026-08-17 问「五年级写作课案的措词语气有没有调到五年级这个阶段」。这是**要判断、不是指出问题**——我一开始误当成质疑、连着两轮拿选择题反问用户，被制止（「我并没有明确是否合适五年级，是要你来判断」）。**用户问「有没有做到 X」时，先自己核查给结论，不要把判断权推回去。**

**Why（核查结论分三层，别混成一句「语气不对」）：**

1. **用词／称呼／例子／话题** —— 到位。无低幼词、无安抚话、无拼音兜底；旧帆布包、滑板练急停这类例子对五年级不偏小。动词叠用（摸一摸／说一说）是各学段通行课堂语，不算失守。
2. **技法深度** —— 到位。落在 `technique-levels.md` L5 边界（典型事例选材／描写方法／场景细节），未停 L3、未拔 L6。
3. **讲法的思维层级** —— **没到位**。三条技法全由老师宣布、⑦评改三条全是操作指令、三处替学生把话说完。

**关键：这不是单篇写坏，是全线没做过口气分级。** 三上《猜猜他是谁》／四上《推荐一个好地方》／五上《我的心爱之物》的 ③ 环节结构完全同构（两段对照 → 老师点评 → 老师宣布写法），四上那篇还是用户亲手逐句改定的行文基准。根因与 [[writing-lesson-stage7-interaction-form-gap]] 同型：**有要求、无判据、无检查位**——口气栏每级只有一句抽象话，checklist 只有一句「口气符合该级边界」，rubric 五维完全不含，两遍冷审因此都没抓到。

**How to apply：**

- **降两级反问是最省力的检验法**：把这份稿降两级给低学段用，要改动哪几处？**一处都改不动 = 口气没分级**。已写进 checklist C 组与 rubric 新增的「六、跨维查项」。
- 已补三处（2026-08-17）：`technique-levels.md` §二加「口气栏的落地动作」表（L3–L6 × ③技法怎么抵达／⑤构思怎么引导／⑦评改问什么）＝唯一源；`checklist.md` C 组拆成两条并展开三个可查位置；`review-rubric.md` 加「六、跨维查项」（不计入五维，因为它跨 ③⑤⑦，塞进任何一维都会漏）。
- **顺带订正**：`technique-levels.md` 原写「口气的完整分级口径可参读 grade-structure.md」——**那个文件只有阅读能力／策略／题材分级，没有口气栏**，指向落空，已改。
- **课堂上的「比较维度」也要随学段升（2026-08-17 用户补：「不要以长短来判断，毕竟已五年级了」）**：审题辨析承认反例的长处时，原稿写「它确实写得多／比第二段长出一截」——**拿篇幅当比较维度，等于把判断口径降到低学段**。改说实质：「颜色尺寸都交代了、画面也有」。同理，规则里的字数比对只是**粗筛**，不是判据（判据是「A 段在具体不具体这维上输不输」）。这是口气分级在**具体话术**上的一个落点，比「谁归纳、谁判断」更细，容易漏。
- **「比较维度随学段升」这条也管 `参考：` 行，不只管师话（2026-08-17 补，用户在五上《“漫画”老师》点出）**：审题辨析的拟真选错项原写「第一段吧，第一段写得多」——**学生拿字数多少当判据，同样是把口径降到低学段**。五年级选反例的真实理由是「它才像一篇写人的作文」：改成「第一段把她的样子、脾气、爱好都写到了」＋「我们平时写人不都是这么写的」。**后者尤其值得留**——它把学生的作文惯性摆到台面上，教师那句「样样都写、一样没写足，读完像看了一张名单」才有靶子。检查位：写完把全篇 `参考：` 行拉出来通看一遍（该篇 15 条里只此一条踩线，其余如「好像哪一样都记得一点」「第一种没意思，谁都这么写」是对的）。
- **口气分级 ≠ 技法深度**，两者各管一层：技法深度合规而口气没分级，是两条独立结论，报告要分开写。
- **反向护栏**：L5 的「让学生归纳」是在已有例子上追一两问，不是另起探究环节拖长课时；不能要求学生归纳例子里没演过的东西；术语的名字仍由教师首现。

## 2026-08-28 复发：新形态是「技法深度」那一层，且成因与 0817 不同

用户读完新写的五上《故事新编》详案，一句话判：「详案文字风格和引导方式还是较偏低段孩子。」按上面三层核，**这一次是第 2 层和第 3 层同时失守**，而 0817 那次第 2 层是到位的——所以别以为补了 0817 那三处检查位就够了。

- **第 3 层（思维层级）照旧复发**：③ 两段对照的差别由老师一口气说破；倒推链是老师一问一答领着走、学生每次只答一个词（「拔萝卜」「吃撑了」「跑不动了」）；技法名老师直接宣布，还写了「给它起个好记的名字」。**降两级反问一试就露**：这三段原样给三年级用，一处都不用改。
- **第 2 层（技法深度）是新形态，也是这次的实质欠账**：不是越档、也不是停在低档，而是**档案重点是并列短语，我只落实了好落实的那一半**。《故事新编》档案重点原话＝「找到一个创新的切入点，把故事重新编得**有趣合理**」，优秀档＝「情节既**合理**又**出人意料**」。整堂只教了「合理／后面接得住」——**而「接得住」恰恰是三年级《续写故事》就够得着的高度**（想象线三上那一档正是「接得住前文」）。缺的那一半「值不值得改／是不是一眼就想得到」，才是五年级该有的判断层。

**Why**：并列短语里总有一半更容易做成教学动作（「接得住」有明确判据、能出对照样例），另一半偏判断、偏品味（「有趣」「出人意料」），生成时会不自觉地滑向好落实的那个，而**丢掉的那一半往往正是本学段的高度所在**——低学段的同类任务通常只要求前一半。两层因此连动：技法只剩低档那一半，讲法自然也退回「老师宣布、学生照做」。

**How to apply（新增一个检查位，比降两级反问更早）**：

- **把档案「教学重难点」那句话按短语拆开，逐个问「它落在详案哪个环节、哪一句」**。落不到具体环节的那个短语，就是漏掉的那一半；漏掉的若是判断类短语（有趣／出人意料／值不值／打动人），几乎必然同时把口气拉回低段。
- 拆解时**连优秀档一起看**——档案三档里的「优秀进阶」写的常是本学段真正的天花板（本例：「既合理又出人意料」），比重难点那句更直白。
- 本例的补法（可照搬到同类「合理性＋新意」双要求的题目）：小组各自倒推一条都接得住的路 → 两组并排念 → 追问「你要是评委更愿意读哪一条、为什么」→ 教师收拢出「接得住只是底线，底线之上还有一处改得值不值」。判断层由此变成一个真实的课堂动作，而不是一句形容词。
- ⚠ **顺带注意时长**：把判断层加进 ③ 会撑爆环节（本例一度算到 17 分钟）。出路不是压缩判断层，而是**把「怎么把那一幕写具体」整块移到 ④ 示范文环节**——那本来就是句子层的位置（`model-essay.md` §四之二），③ 专管构思与选材，两边都更顺。

### 同日第二个形态：师话「替学生把话说完」四类（用户连点三句）

同一份稿改完上面两层之后，用户仍连着点了三句「这也一样问题」。三句本身都不违任何机检、也不违语气适龄红线的字面（不是「别怕」「没关系」那种安抚），但读着都低段。归纳成四类，**它们是生成侧的默认款，每一类都要在交付前逐句扫**：

1. **夸学生的反应**（不是夸内容）——「你们接得这么快」「你们立刻听出来了」。夸内容可以（那是反馈具体化），夸反应速度是低段的课堂节奏确认。
2. **复述学生刚做过的事**——学生刚答完「兔子睡着了」，老师又把原故事讲一遍；或学生刚判断完，老师再把他们做的动作叙述一遍。学生自己知道刚才干了什么。
3. **正反两面掰开讲同一条标准**——「答得上＝就算编成了；要是答不上，那就还差一道」。说一遍就够；掰开讲还会顺手带出**软化词**（「还差一道」＝怕说「没做到」），那是安抚的变体。
4. **替学生预演失败的样子**——「要是大家听完，只能说『他把结局改了，别的跟原来一模一样』」。老师先把学生会怎么失败演一遍，等于替他把话说完。

**判据一句话：这句话删掉，学生手上少了什么可做的东西吗？** 少 → 留；只是少了一句确认、一层解说、一个反面例子 → 删。

**改法不是删标准，是换姿态**：把成败标准说成一条交出去的规矩，一次说清、不对举、不软化——「这两句就是今天判成没成的标准。听的人拿它判你，你自己写的时候也照着对一对。」（原句三个病全在，改后一句解决。）**收尾同族**：原收尾又把成败标准复述一遍并给学生盖章「那就是编成了」，改成陈述当堂事实、不盖章——「同一批老故事，原来什么样全班都知道；今天从你们手里出来的，一人一个不一样的版本。」

**⚠ 别扫过头（同批实测的四个假阳性，都该保留）**：条件句「他要是根本不知道原来是什么样，你改得再巧他也听不出来」是给学生的**选材依据**；「三四步能推到就行，不必长」是**任务边界**；「不要紧的地方一句带过」里的「不要紧」＝次要，不是安抚；③「这几样你们都看准了」是审题辨析规则**硬性要求**的「先接住选反例的学生」。判据仍是上面那一句，不是见「要是／就行／不要紧」就改。
