2026-06-30 决定写作课分支独立化走「方案②」：**产品/内容/呈现/物料层让写作课成独立竖线，但 docx 生成器 + PPT 底层渲染原语坚持单一共享源、永不 fork**。

**为什么**：写作课 PPT 将来要视觉/页型大改、且写作课其他物料已有具体规划；但代码引擎（helpers/parser/docx）是有 bug 史的横切层（字体槽顺序、表格自适应、弯引号都是修一处即重烘焙全部），fork 会让 bug 修两遍+副本漂移，违反 CLAUDE.md §3 禁副本铁律。关键洞察：**视觉大改 ≠ 必须 fork 引擎**——新视觉/新页型 = 新增 renderer + theme 变体（加法），底层原语 100% 可复用。排除了「维持薄覆盖只清理」（被大改否决）和「完全 fork 含引擎副本」（违 §3）。
