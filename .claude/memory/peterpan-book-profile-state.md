《小飞侠彼得·潘》书籍档案已建档完成（2026-07-05）。

- **版本**：名家名译版 .mobi，巴里 著 / 杨静远 译；用 python `mobi` 库抽 book.html→纯文本通读（译序+正文十七章《彼得和温迪》+附录《彼得·潘在肯辛顿公园》选译三节：彼得·潘/画眉的巢/公园关门的时候）。
- **等级**：用户拍板 **L4**（建议 4 课时）。出版社/出版年/ISBN/字数全缺 = (待补充)；**无固定页码**，一律章节定位。译序末"2010年1月"是落款、非出版年。
- **头号事实陷阱**：正文与附录是**两个不同文本**——正文彼得是永无乡队长、会飞、杀胡克；附录彼得是出生七天、失去信心不会飞、被困蛇湖小岛、造画眉船、请所罗门鸦。下游讲"彼得的故事"默认指正文，引附录情节须标"出自附录"，**绝不缝在一条线索里**。"窗子关上换了别的小孩"两处出处不同（正文11章彼得口述 vs 附录叙述者），勿混。
- **其他陷阱**：胡克**没有真名可引**（正文14章明说"胡克不是他的真姓名"，全书未给真名，勿编）；译名以本版为准（叮克铃/永无乡/遗失的孩子们/永无鸟/虎莲，勿换坊间译名）；遗失的孩子共6个(图图/尼布斯/斯莱特利/卷毛/孪生子2人)无女孩，射中温迪的是**图图**；橡子/顶针/吻三词别混（彼得回赠的"吻"是橡子、橡子扣挡箭救温迪）；铁钩替**右手**；结局非纯悲剧(温迪"心甘情愿长大")。
- 关键片段 11 条+备用引文池 11 条，均逐字成段、保留原书弯引号。参见 [[book-profile-quote-full-passage]]、[[book-profile-full-read-redline]]。
- 建档惯例复盘：**可引用原文成段块不要加外层包裹引号**（我首版加了外层引号，fix_quotes 顺序配对把内部对话弯引号配反了；去掉外层、成段块紧跟冒号呈现即与骑鹅/汉修档案一致、fix_quotes 也不再出错）。
