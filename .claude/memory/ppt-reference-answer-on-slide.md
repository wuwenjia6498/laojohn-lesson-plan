> ⚠ **答案颜色口径已被 2026-10-06 改写**：读书会新样式（中间稿声明 `主题色`）的答案用本书主题色深色档，红色只留给 LOGO 和关键词，见 [[reading-ppt-v9-human-optimized-1006]]。本条只对旧样式存量稿成立。

2026-06-29 决定：详案凡老师提问后给出 `参考：` 答案处，PPT 同步把答案做进去、红字。用户拍板四点：① 点击逐段揭示(先出问题、点一下再出红色答案，每段各一击)；② 引导问题 + 要点小结两类页型都加，但仅当详案该处确有 `参考：`（纯思辨/发散题不强加）；③ 红字用品牌红 `#C0392B`(COLOR_RED_ACCENT)；④ 只改技能机制，《洞》《格列佛》等旧 PPT 暂不重烘焙、下次出新课自然生效。

**中间稿约定**：要点列表里某条 `- 问题` 下紧跟一行 `参考：答案`（缩进 2 空格、紧贴该条、中间不空行），解析器挂到上一条要点。整页任一条带 `参考：` 即切"问答交错"版式。

**实现**（[[ppt-click-reveal-animation]] 同一条点击机制扩展）：
- `parser.py`：Page 增 `bullet_answers` 平行列表（与 bullets 等长，""=无答案）；`REF_RE` 识别 要点块内 `参考：` 行。
- `helpers.py`：新增 `add_qa_textbox`——圈号问题(正文色 404040)+红字答案(C0392B)交错单文本框，返回逐段点击分组 `[[(spid,pidx)]…]`，问题段/答案段各自成组。
- `layouts.py`：`render_guide`/`render_summary` 有答案时走 add_qa_textbox（要点小结此时**不用红方块编号、改圈号问答**），无答案保持原渲染（向后兼容，全页无参考即行为不变）。
- 文档：field-extraction §5 新增「参考答案上屏」（反转了旧「参考不上屏」禁令）、ppt-draft SKILL 字段表+自检、ppt SKILL 契约+动画表。
- `--no-anim`/系统不支持动画时全部静态显示（问题黑、答案红），不损坏。

已烘焙测试稿验证：问题 404040、答案 C0392B、逐段 clickEffect 数对（3 问 3 答=6 击）；smoke PASS、三脚本编译 OK。examples 旧 FAIL(P12→P14/环节序号)是 pre-existing、非本次引入。

**《格列佛游记》应用（2026-06-29）**：用户拍板「维持黑字、仅少数页补红字」——格列佛 4 课时深度引导问题页的参考答案**当初提炼时就已做成黑字要点**（标题=问题、要点=答案，如交流1 P06/P10、交流2 P04/P08/P09/P13），全部维持不动；开放/思辨表态题（三选一/思辨单/监控自查/我的问题/读后感受）详案只给方向、无标准答案，不强加。逐页筛后**全书仅导读课 P13「放电影」**符合"纯追问+屏上无答案+详案有实质参考"，补了一行红字参考答案。4 份 PPT 已重烘（导读课 P13 变、其余 3 份内容不变仅刷新渲染器）；讲稿/详案页标未动（页数页序不变）。**故格列佛 PPT 只有导读课 P13 一处红字属预期、非遗漏。**
