## ⚠ 配套侧 dry-run 是共享规则表的第二回归面（比结论更重要）

首跑 42 份就照出 `polish_rules.py` 四条排除漏洞，详案线自 0911 起跑了多篇都没露：**开头一句→开第一句**（规则 15，9 处）、**仍要是老师编的→仍如果**（规则 14）、**跟去看／跟没跟上→和**（规则 6）、**你们之间→大家之间**（规则 2，「你和心爱之物之间」）。原因：详案师话里「开头一句」多写在被保护的表格／旁批里，配套派生文案把它们写进了可改层。四条已补进 `polish_rules.py` 的 exclude（只加排除、改法不变，详案线严格少改不多改）。**改 polish_rules 后两家都要 `--dry-run` 回归**，配套侧一条命令 `polish_materials.py --all --dry-run` 扫全部课次。

**Why**：不再指望 agent 对照表自查；已定案的做成脚本，语体靠整段样本定调，与详案线同一套判据、同一张规则表，配套文案不再是文风治理的第二套口径。

**How to apply**：出配套三侧前读 SKILL 第 2 步指向的样本卡 → 写 json → 机检 D（dry-run 看 diff → 落盘 → 看报告残余候选 → 人工判五项：升华式收尾／不是而是／越越越／名词化黑话／跨课同构）→ 渲染。新词条**只加 `polish_rules.py`**，加完两家 dry-run。`JARGON_EXTRA` 里没列「判据」——0901 定稿教师页保留了「这一对比就是全课的判据」，用户认可。picture-materials（看图写话配套）不在本次范围、仍是文风真空（它属看图写话线，该桥接自己线的去 AI 味规则，不能同用 style-criteria）。相关：[[writing-materials-style-bridge-0901]]（已被本条替代）、[[writing-style-two-directions-conflict-0831]]。
