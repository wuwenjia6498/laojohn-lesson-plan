写作课详案的主技法若是「多件套」（如「他的动作／他说的一句话／我心里的想法」三样、「对比＋变化词＋细节」三样），**环节③的学生练笔就必须逐件都练到**，不能只练前两件、把最后一件推给④示范文或⑦评改。

**Why：** 2026-08-02《四上·我和＿＿过一天》冷审实测——③定型说「慢在三样上」，练笔却只要求「第一句写他动手的样子，第二句让他开口」，第三样「我心里」学生在动笔前一句都没产出过；而 L3+ 示范文后置规则决定④在⑤之后，学生填构思表那一格时还没见过这一样的写法。稿子自己在⑦写下「多半少的是你心里那一句」——等于生成侧已预判了这个缺口却没堵。机检与 checklist 都抓不到（要素数一致那条查的是「例子数＝结论数」，不查「练笔覆盖数＝技法件数」）。

**How to apply：** 定稿前做一张对账表：主技法的每一件 × 「②/③里学生是否口头或笔头产出过一次」。缺的那件，或在③练笔加一句（③时长 +1 分钟，从①匀——①创设情境常有 1–1.5 分盈余），或在④旁批表带读到该要素那一行时追加一次口头补句。同族对账见 [writing-lesson-label-and-turn-discipline]（②→⑤素材对账）与 [lesson-plan-per-step-load-audit]。
