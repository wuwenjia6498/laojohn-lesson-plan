**头号陷阱（已写进档案第 14 条使用提醒）**：
- 篇名是本译本固定叫法，不可换通行译名——是《夜莺与蔷薇》不是「夜莺与玫瑰」、《打鱼人和他的灵魂》不是「渔夫和他的灵魂」。
- 两个「宫」极易混：《快乐王子》是**无愁宫**，《少年国王》是**欢乐宫**。
- 《忠实的朋友》是「故事中的故事」（梅花雀讲给河鼠听），内层对话在原书中带外层引号包裹、且多处**无收尾引号**；磨面师全篇只点名一次「大修」。
- 结局都不是圆满：《星孩》末段明写「只活了三年，他死后继承他的却是一个很坏的国王」；《打鱼人和他的灵魂》末句写坟地此后寸草不生、人鱼不再来。
- 无页码（流式），下游写「第X页」即编造；字数/页数/获奖三项电子版未载，机读块留「(待补充)」。
