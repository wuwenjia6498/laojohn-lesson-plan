四上第四单元《我和＿＿过一天》（想象·神话人物）详案 2026-08-02 定稿，md＋docx 齐，已过 tone_gate 与 detail-review 冷审（A 块 8 项已改，B1–B6 六项全按推荐落定）。

**可复用的一手 ——「当场换人试装」（技法引出装置）**：老师念完自己写的一段（马良给六楼楼道画扶手），当场把段里的「马良」整个换成「孙悟空」、别的一字不动再念一遍，学生自己听出垮在哪；再反问「换成孙悟空，这件事他会怎么办」。它把「事配不配得上人」这个抽象判据变成当场可听见的一件事，比讲道理有效得多。**凡要写出人物特点/身份感的题目（写人、想象、故事新编、变形记）都能照搬**，换的对象换成本课人物即可。配套的成败标准也一并可复用：「把名字划掉换上同桌的名字，故事一个字都不用改」＝没写成。

**想象线差异轴（已写进 variation-ledger）**：三上「接得住前文／编完整＋一处波折」→ 四上「事由人定：挑一件非他不可的事、把他动手那一幕写慢」→ 四下《故事新编》《奇思妙想》接下一档。

**两个避重判断留档**：① 官方情境是「奇幻故事会」，与三上《我来编童话》的童话故事会同名同族，按距离化规则退到「不讲整篇、不评创意，只判人物立没立住」的差异形态，载体一并不设（班级故事集已被三上占用）；② 开场钩子类型与隔篇的《小小“动物园”》同为悬念提问式，靠语气姿态错开（本篇发现者／动物园回忆者），与紧邻的《写观察日记》（实物道具式）不同款，合规。
