lesson-plan(读书会详案) 2026-07-01 引入「三类文本 × 课型设计重点」差异化：同一套课型(导读/交流1/交流2/思辨应用)面对 **故事小说类 / 非虚构文本 / 经典文学名著** 三类文本，设计重心不同(源自老约翰官方对照表截图)。

**判定 = 名著优先·三选一互斥**，顺序：先判非虚构 → 再判经典名著(名著优先，既是小说又是名著归名著；闸门=稳定传播译介史·常列经典名著书目，克制，别把所有获奖/名家书塞名著列) → 否则故事小说类。依据=档案 `类型`字段+体裁常识(属体裁归类、非事实层，不违反"事实不凭记忆"红线)。回归：格列佛=经典名著、洞/俗世奇人=故事小说类。

**落地形态②=独立矩阵+各课型轻量标注**(不重写各课型菜单)：`lesson-templates.md` 开头加权威对照表+判定规则+L1–L2折叠规则(取导读列+交流1列为单节交流课主线、思辨应用列落收尾成果环节)，各课型只补一行`> 按文本类型择重`指针；`SKILL.md` 工作流加 2b 判定步+第4步防张冠李戴；`checklist.md` 结构组加一项。判定仅内部设计驱动、不改详案输出格式。

**Why:** 旧模板全以故事/小说视角写成，科普书被套"预测故事/人物塑造"、经典名著缺"作者时代背景+文学赏析+跨文本文化思考"这条线。
**How to apply:** 生成详案时先判文本类型，再按"课型×类型"取对照表该格重点落环节。不涉及 CLAUDE.md/下游物料/writing-lesson(写作课平行分支)。契合 [[reading-plan-not-vistool]] 所在的 lesson-plan 菜单式"组合求异"哲学。
