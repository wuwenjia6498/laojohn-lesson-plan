对外物料里的「主题」「书籍特色」等字段，要写家长一看就懂的大众说法，不能用备课分析腔或 AI 腔（2026-10-16 小狗的小房子三处反馈）。

- **机读块 `主题` 是对外字段**：海报直接印它。《小狗的小房子》原为「友情 / 互相帮助 / 逞强与真本事 / 相处中的分歧」，用户嫌不像书籍主题，改为「友情 / 互相帮助 / 关爱与付出」。档案正文「八、本书涉及的主题词」是备课分析，可以细，**两处分开、改机读块不动第八节**。
- **抢先看「书籍主题」要与海报主题对齐**（同一本书对外口径一致）。
- **「书籍特色」写真正的特色**（体例、语言、对话、结构等），不写情节描述（「两个人看见的不一样」被判不像特色）；也别造词（「句子会放画面」被判太 AI，改「语言生动形象」+书中原句为例）。
- 措辞层机械坑：海报主题栏一行约 17 字，四项带长词会折行（「默默付／出」），宁可缩成三项；抢先看单行过长会伸出页眉线右端，改完必看渲染图。

**Why:** 这些物料面向家长招生/导读，备课术语和 AI 造词让人看不懂，也显得不像正经书介。
**How to apply:** 建档填机读块 `主题`、生成海报/抢先看/书目卡时，按这条自检；改主题要同时改机读块、海报 json、抢先看 json 三处。与 [[reading-materials-follow-plan-strictly-1008]] 同族（物料措辞层）。
