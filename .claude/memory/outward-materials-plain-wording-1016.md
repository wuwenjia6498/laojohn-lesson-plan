对外物料里的「主题」「书籍特色」等字段，要写家长一看就懂的大众说法，不能用备课分析腔或 AI 腔（2026-10-16 小狗的小房子三处反馈）。

- **机读块 `主题` 是对外字段**：海报直接印它。《小狗的小房子》原为「友情 / 互相帮助 / 逞强与真本事 / 相处中的分歧」，用户嫌不像书籍主题，改为「友情 / 互相帮助 / 关爱与付出」。档案正文「八、本书涉及的主题词」是备课分析，可以细，**两处分开、改机读块不动第八节**。
- **抢先看「书籍主题」要与海报主题对齐**（同一本书对外口径一致）。
- **「书籍特色」写真正的特色**（体例、语言、对话、结构等），不写情节描述（「两个人看见的不一样」被判不像特色）；也别造词（「句子会放画面」被判太 AI，改「语言生动形象」+书中原句为例）。
- **别为塞进一行把话压到词不达意**：「小狗和小猫争吵“小猫钓鱼”还是“小狗钓鱼”」「从做的事里读出没写出来的着急」都被判没说完、看不懂。句子先写完整（谁、做什么、所以呢），放不下再想排版。
- 排版机械坑：海报主题栏一行约 17 字，四项带长词会折行（「默默付／出」），宁可缩成三项。**抢先看叶节点不自动折行**（模板 `white-space: pre`），超长会把整页等比缩小、字变很小；一行约 30 字以内，长句在 label 里写 JSON `\n` 手动断成两行（Bash 写 json 时注意别写成真换行，会解析失败）。改完必看渲染图。

**1021 复发＋立规（和大人一起读（一））**：海报主题「观察与发现 / 动脑想办法 / 认真做事的方法 / 家的温暖」又被判不像主题，用户要求按当当等电商的通用说法写并立规。第一轮改成「亲情 / 观察力 / 想象力 / 传统文化」又被否：太空、换本书也成立，且成语故事只是传统故事、不是「传统文化」。用户说原方向（观察/动脑/做事方法/亲情）是对的，只换表达 → 定稿「细心观察 / 开动脑筋 / 做事讲方法 / 亲情温暖」。**内容取这本书讲到的、措辞取书介常见说法，两头（空大词、备课腔）都不行。**规则已写进 `laojohn-book-profile/SKILL.md` 机读块节（唯一源）、模板注释行、`laojohn-course-poster/SKILL.md` B 类表下。判据：放到书店书介里像不像人话，且换一本书就不成立。同批两条措辞反馈：书目卡/阅读指南内容简介里「小猫咪穿上四只鞋子问遍院子里的朋友」没说完（没看过书的人不知所云）→ 补出结果；并列几篇故事、其中一句带内部逗号时改用分号隔开。社群反馈「门外一回……一回……」判太 AI，改成「第一幅图里……第二幅图里……」。

**Why:** 这些物料面向家长招生/导读，备课术语和 AI 造词让人看不懂，也显得不像正经书介。
**How to apply:** 建档填机读块 `主题`、生成海报/抢先看/书目卡时，按这条自检；改主题要同时改机读块、海报 json、抢先看 json 三处。与 [[reading-materials-follow-plan-strictly-1008]] 同族（物料措辞层）。
