用户指出《格列佛游记》阅读指南「拓展阅读建议」泛泛而谈（原文「请老师或图书馆员推荐一两本…」），要**点名具体同类书或改编影片**、给具体建议。

根因：reading-guide SKILL 原规则为防幻觉，规定拓展书目只能取自课案、否则放「请老师推荐/待补占位」，**不臆造具体书名**。这直接导致泛泛而谈。

**Why & 政策决定（用户拍板）：** 在「拓展阅读建议」这**一栏**放宽「绝不凭记忆补事实」红线——允许写模型常识里**广为人知、确定存在**的同类名作/知名改编影视（书名·作者·片名·年份须公认确证，成品人工校对）。**放行仅限"另一部广为人知的作品"这类常识，绝不外延到本书自身**——本书的书目信息·情节·人物·页码仍唯一锁书籍档案。吃不准某作是否真存在/真同类就不写那条，宁缺毋滥。

**How to apply:** 已固化——SKILL.md「拓展阅读建议」栏重写（优先点名书目/影片、新增「同类作品(点名)」「改编影视(点名)」角度、加"红线作用域"约束、明禁"请老师推荐/待补"泛泛占位）；rendering.md 自检项同步改。**已执行**：格列佛阅读指南三件套(JSON→HTML→PDF via render_win.py)改为 3 条具体推荐（《动物农场》/2010电影《格列佛游记》杰克·布莱克/《爱丽丝梦游仙境》），每条≤70字、PDF 目检版式正常。注意 reading-guide JSON 字符串内引用词语用全角弯引号“”（2026-07-22 拍板禁「」，此处原「用「」」口径已作废）、书名用《》，不用 ASCII 引号（否则破 JSON）；渲染跑 `python scripts/render_win.py <json> <out_base>`（脚本内已设 Playwright 路径）。此放行**仅 reading-guide 拓展栏**，其余技能维持红线。
