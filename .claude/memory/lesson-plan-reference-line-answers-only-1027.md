「参考：」行只放参考答案；教师复述、追问、收口、评价口径一律另起一行——说出口的写「师：」（可带（追问）（收口）括注），纯操作说明写单独括号行，追问后的答案再起一个「参考：」；没有问题在前、只是老师在讲的话不得冠「参考：」。

**Why:** 2026-10-27 用户审《总有一天会强大》时点出 20 多处「参考：①②③。教师复述……追问：“……”引导学生指出……」挤在一行，逻辑乱；用户原话「这条是你的重大失误，写入规则吧，一定要避免再犯」。生成侧以前没有任何一条规则管这件事，反而「承接要复述」那条让模型把复述塞进参考行。

**How to apply:** 规则在 lesson-plan `style-and-format.md` 话术格式节＋`checklist.md` 话术格式组（带 grep 机检）。存量详案多半有同样写法，按需回改；改稿后跑 grep 只剩误报（「保健老师」之类、标明是老师写的示例）。相关 [[local-edits-need-second-cold-review-0918]]。
