写作课详案暴露「导演腔」同质化——比成品句癖(小星星)深一层的**教师组织课堂的行为套路与点评措辞**:同一 skill 用同一套"导演手法"排每堂课,单篇合理、5篇并置露馅。用户靠手感抓出两例(「请平时不太举手的学生」「就算成功了」),机检坐实为系统性(2026-07-08 实测5篇:「一下(子)就」22次·全中、「先别急」11、「谁愿意/谁先来」11、「立起来/活生生」16(压在猜猜他是谁)、「干巴巴/流水账」24(压在写日记)、「怦怦直跳」14)。

**根因=生成侧规则把金句当"示范措辞"写死**,模型照抄→篇篇雷同(如 workflow-engine `:156`「有意点平时不爱举手的孩子」、④"一下子就看见"问法、`:171` 讲评"本事"收尾+ `:173` 指两篇为样例对照)。batch_ngram_scan 扫字面 n-gram 抓不到「不太举手↔不常举手」同义变体和三连问骨架——**必须从规则改起**。

**四层治理已落地(2026-07-08)**:① variation-pools「禁止逐字复用」增「导演腔套路」3条(一下子就看见/平时不举手/今天不是完成一篇作文升格句);② 新增**池6「课堂发令词」**(转正题/点名/催收束/正向反馈四功能点,前三跨篇轮换、④反馈进"具体化红线"空夸词单篇≤1);③ 新增**池7「教学讲评用语替换池」**(写活了/不具体/心理描写词三组,单篇密度封顶+跨篇轮换,不拉黑——是技法词);④ **治本**改 workflow-engine 5处金句→意图+池轮换(⑦已把"平时不举手"改为覆盖面要求)。联动:checklist E组 `:64/65/66` 三条横审机检、G组指纹12→13字段(+发令词)、ledger `:30` 同步、review-rubric 维〇加导演腔grep、batch_ngram_scan 补第三类分流。治理方式分档:禁用(高频口头禅)/轮换(发令词)/降频替换(教学黑话,不禁)。

**方法论(值得常态化)**:人读出腔调 → 机检定频次 → 分层归池。每攒5-6篇人工横读一次找"腔调",再脚本量化。

**web 协作合并教训(手术式并入·勿盲拷)**:用户把整 SKILL 文件夹给 web 端 Claude 改、拿回6个文件。**不能整文件夹覆盖**:① 网页往返把新内容全角引号打成 ASCII(违铁律,会印进 docx)——需逐处回修全角、`fix_quotes_md.py` 不认反引号码内豁免不能盲跑;② web 基底比本地旧,`variation-ledger.md` 缺2行本地已有台账(续写故事/漫画)——盲拷会静默丢记录。做法:以本地当前版为基,diff 出 web 的删改(除 ledger 外都是有意治本重写、pools/rubric 纯新增),wholesale 拷贝5个 clean 文件 + ledger 只 surgical 改 `:30` 保全部行 + 逐处 ASCII→全角。

**存量5篇已回改覆盖(2026-07-08)**:用户交 web 端 Claude 按新 SKILL 改写全部5篇(不止2样例),我评估后覆盖。评估要点:改写是逐行措辞替换、行数一致、零情节/事实/占位改动、零 ASCII 引号腐化(这次往返没打坏引号,与 SKILL 那次不同)。**web 引入3处缺陷已修**:①续写故事总结把范文「怦怦直跳」误写「心提到嗓子眼」(范文/审题/旁批仍怦怦直跳)→自相矛盾,改回;②漫画「两段，，」双逗号;③写日记讲解「咯噔」被改「那一惊」但参考/范文/旁批仍咯噔→改回。**另补2处 web 漏掉的残留**:猜猜:65/写日记:69 学生互动分享括注里「优先点平时少举手的」(web 只改了提示层 `[教师组织…]`、漏了括注)→改「覆盖面广些」,至此「平时…举手」模板句全5篇清零(=用户最初点名的病症根除)。**可接受残留(未强求)**:「一下子就」猜猜3/写日记5 未压到≤1、写日记「流水账/干巴巴」仍14(记事课核心诊断词、多合理)。覆盖用 Python `newline=''` 保 CRLF、不整文件cp(防 EOL 漂移)。docx 未重渲(如需交付再跑)。见 [[writing-lesson-antihomogenization-upgrade]]。
