2026-07-26 把「校内同步习作·写作课详案」的标题与环节命名体例定稿，存量 5 份（猜猜他是谁/写日记/续写故事/这儿真美/漫画的启示）全部整改，并固化进 skill。

**定稿体例**（唯一源 = `laojohn-writing-lesson/references/title-naming.md`，2026-07-26 由仓根搬入，与 picture-writing 的同名文件对称但**方向相反**、不可互相套用）：

- 时长一律 `（约 N 分钟）`——带「约」、数字两侧各一个半角空格。`（8分钟）`／`（8 分钟）`／`（约8分钟）` 三种全不合规。方括号教师提示块段首的环节级时长同此；**叙述性句子里的时间不动**（`师（全班，18 分钟时轻声提醒一次）`、`一共 20 分钟`、`每位约 1 分钟`）。
- 区间写 `（约 3–5 分钟）`，连接号 `–`，不写「3 到 5」「3-5」。
- 环节名内禁夹带教学预案——`｜可压缩：…` 整段移到该环节正文第一行作 `> **可压缩预案**：…` 引用块批注，**原样搬运不改写**。
- 环节五全线统一 `出示示范文，发现写法`；**「教师出示样稿」已废止**。
- 附录三行全线统一：`## 附:习作讲评指导环节(可选 · 单次课课后用 / 系列课作下次课开场用)` / `### 讲评流程(每篇约 3–5 分钟，围绕本课技法点)` / `### 收尾(点回技法、引向今后的写作)`。
- 副标格式 `三年级上册·第一单元 校内同步写作（体裁）`——含单元号，体裁括注可选。
- **不做口语化改造**：「创设情境／学写法／交流评议／构思表」是校内语文老师的行业通用语，保留即专业；看图写话那套 `｜` 分隔、`######` 小字副标、`——副题` 一律不适用（见 [[picture-writing-title-naming]]）。

**★ 根因（同类问题的排查起点）**：5 份详案格式各不相同、而非整齐错成一种，是因为**同一 skill 内两处规则源自相矛盾**——`workflow-engine.md` L116/171/172 一直写的是正确的带空格版，`lesson-structure.md` L56/57 写的是 `（X分钟）`／`（约5分钟）` 无空格版，生成时抓到哪份就长成哪样。**改任何体例前先全 skill 搜一遍该体例出现在几个文件里**，只改一处等于没改。

已同步修正：`lesson-structure.md` 六处（副标格式、两处时长举例、删「或教师出示样稿」、附录标题、附录三节措辞）+ 新增「环节时长与环节名长度」硬规则条；`checklist.md` 新增时长/环节名长度机检项、附录条对齐；`SKILL.md` 把 title-naming.md 列入「每次必读」。
