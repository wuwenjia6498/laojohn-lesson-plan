读书会整套文件打包输出按用户定稿命名（来源：用户桌面「命名规则.docx」，样例 L3《稻草人》）：
- 顶层 `<年级><上/下>《书名》`，如 `3上《稻草人》`；上下册不知道就写「上」，用户后期手改。
- 三个子文件夹＋根目录一份测评：`教师用\`（`《书》教学逐页讲稿\` 子目录、各课 pptx、`《书》教学思维导图.pdf`、`《书》课案详案.docx`）、`宣传推广、日常服务类\`（海报 jpg、课程反馈话术 docx、书目卡 jpg）、`学生用\`（`《书》（学生用资料）.pdf/.pptx`、抢先看 pdf、阅读指南 pdf）、根目录 `《书》阅读测评.docx`。
- 文件名一律「《书名》+物料名」，书名后不加 `-`/`_`；讲稿 `《书》导读课-逐页讲稿.docx`。
- **「阅读单」在交付包里一律改称「学生用资料」**（用户特别强调别忘）；教学导图改称「教学思维导图」。

**Why:** 之前命名不规范，用户每次要手动改。
**How to apply:** 打包一律跑 `laojohn-course-package/assets/package_course.py`（已按此实现：年级取档案「等级：Lx」，`--term 下` 指定下册）；手工归集或改脚本时也守这套口径。旧口径（`<书名>\课件PPT\课件下游物料\阅读单\逐页讲稿`）作废，存量旧包未重打。配图版详案用户样例未涉及，暂按 `《书》课案详案-配图.docx` 一并收进教师用。
