**★ 教训一：两张对照图的标签接反了，而线索我自己提过却放过了**

用户给「图一＝新五上三、图二＝旧四下八」并列了两个文件路径，我按**路径出现顺序**配标签，实际用户是按**另一个顺序**说的。
后果是三处新旧差异全部反向，整份计划的核心事实错了。**当时有两条线索都指向接反**：
① 页码——五上三应在书前部（46）、四下八在书末（131），我读到「图二 p46」时明确嘀咕过「与四下八在书末对不上」，**却把它放过了**；
② 用户上一轮刚说「《猎人海力布》《牛郎织女》是新版课文，旧版的是宝葫芦、巨人的花园、海的女儿」——而题面里的「利用宝葫芦」呼应的正是**旧版**单元课文，
这句话本身就是答案，我没有把它和题面里的宝葫芦联系起来。
**通则**：这与 [[wodejiaren-4a-lesson-state]] 那条「称谓/数字/篇名逐字项须逐项复核，别一笔归为版本差异」同族，但形态更基础——
**自己已经嘀咕出口的疑点，必须当场追到底**；放过一个自提疑点的代价，是它下游的所有推论一起错。
**多图对照时，别靠给定顺序配标签，用图内可校验的锚（页码、与已知事实的呼应）反查一遍。**

**★ 教训二：archive 的四段正文与教材页题面是两层东西，不能互相顶替**

原以为「按新题面修补搬运来的正文」，实测发现指导件正文里**根本没有**宝葫芦/坐井观天/漏/誊抄/天气变化任何一处——
它是教学归纳（选故事找切口、四条创新路径、参考结构…），教材页题面是另一层（四个结局选项、五类情节示例、另选篇目）。
所以四段正文可**逐字原样搬**（已程序化搬运并比对 1590 字＝1590 字），而**教材题面必须单独成节入档**，否则新详案要引题面时仍是零依据。
新节因此是六节：一~四搬运 + `### 五、教材页题面（一手逐字）` + `### 六、本节来源留痕`。
⚠ 留痕里显式标了两条：评价标准三档**仍是四年级学段基准**（迁册后学段升了一级，用前须复核）；
「乌龟用上滑轮鞋」是**指导件自身举例**、非教材原文，勿当教材原文引。

**★ 教训三：换题会让「判据表里的实例」失效，不只是那一条结论失效**

`unit-texts.md` 五上三旧判是「形态 B＋C，最危险」，而它是**全表 C 形态（方向相反）的唯一实例**。
换题后 C 自动失效（旧题缩写＝讲短 vs 创造性复述＝讲长是相反；新题故事新编与创造性复述**方向一致**），
于是三形态表的 C 行**暂无现行实例**，`workflow-engine.md:95` 引它作唯一举例的那句也一起失效。
**改一条结论前，先 grep 它有没有被别处当作判据的实例引用。**
新判＝形态 A＋B，仍不引；**最硬的旁证是教材自己**——题面举的可新编篇目全是寓言（龟兔赛跑/狐假虎威/漏），一篇本单元课文都没提。
