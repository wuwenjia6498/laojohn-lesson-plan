2026-07-28 按《看图写话_课程总地图-0728.docx》定稿同步 SKILL 排期，只改了 `course-map.md` 与 `ability-ladder.md` 两个文件（用户指令严格限定范围）。**0723/v4 的课次坐标全部作废**，[[picture-writing-course-map-v4-0723]] 里凡涉具体第 N 次的内容只作历史读。

**总盘子未动**：64 次 ＝ 方法课 24／练习课 24／回顾课 5／综合课 7／展示课 4（已脚本核计通过）。方法课学期分布由 6／5／6／7 改为 **6／4／7／7**。

**四条实质改动（不是改名，是换教学内容）**：
1. **期8「按方位看」跨学期移**：一下第5次 → **二上第4次**。连带年级档由一年级改二年级、支架层由基础层改**进阶层**。副作用：它现在排在期6 细节四问（二上第2次）之后，`ability-ladder` 三条推导规则第 1 条原来举的「按方位看 vs 细节四问」矛盾例已失效，已换成想象线的「三句连起来（序7）早于补对话（序9）」新例。
2. **期10 由「心里话：写心情」→「三句连起来」**（一下第1次）：**方法替换非改名**，写心情降为本课第三句，训练点改「顺序连句」。补的是「一句话 → 三段式」之间缺的台阶。
3. **期18 由「标点的表情」→「句号与逗号」，拆两个课次教**：一上第9次只教句号＋认读问号感叹号；**逗号并入一下第3次期5《三段式》**（单句阶段用不上逗号）。⚠ 方法名＝「句号与逗号」，但 §四 课题写的是「句号：一句话在哪里停」——两者是不同字段，别当成不一致去「改正」。
4. **期6 细节四问拆两半**：二上第2次方法课**只教【两看】**（动作、表情），语言与心理【两想】放二上第3次练习课（不增课次，练习课承担新授量）。提示卡按分教点分次发，第2次发【两看】面即止。

**其它变动**：期4 四要素**教学范围缩小**——只要直接看得见的时间（太阳月亮/季节物），**不再从水洼灯光反推**；期12 同图多解改**给定三选一变式**（换主角／换起因／换结局）；二上第14次对话推进**无专属练习课**（并入第15次综合课）；二下第2次转折**含当堂练笔**（原第2次练习课并入，第2节按练习课写作量配足）；新增二上第1次、二下第1次两节开学回顾课。

**术语（0728 定）**：「段」三义分家——三段式/一图一**小节**＝意思层（写成一整块不换行）；连句成**段**＝篇幅量；**自然段二下第12次才教，此前全文不出现「自然段」这个说法**。「四段故事」改「四格故事」；一下三段式课删「题目居中」。

**第二轮（同日）定稿的四件事**：
- **期5 三段式支架＝四次课撤架梯度**（一下 3 满／4 半／5 弱／12 无）。第一轮「下调一档」是过头的——前面有台阶不等于三段式不难，**方法课仍给满支架**。
- **期6 课型定位不变**（二上第3次仍是练习课，两问/四问是同一方法分次交付），但**第3次第1节骨架特殊**：方法回顾＋补【两想】两问(15')→新图圈画→当堂写作。提示卡两张薄卡分次发。
- **期10 心情降到底**：不做心情词分类教学，只要第三句有个心情词、不能只有「开心」；分类与积累交接给**一下第15次综合课**。「顺序连句」是**台账用语不进正文**，课堂说「三步说一件事」。
- **⚠「心情」≠「心里话」，分界＝看得见／看不见**（易错，我先按「自己 vs 人物」写窄了一次）：**心情＝从表情读出来的、看得见**（一下第1次第三句起）；**心里话＝推想出来的内心活动、看不见**，写成「他想：……」（一下第8次回顾课起头）。这条正好对上细节四问——**心情属【两看】的表情，心里话属【两想】的心理**，即「看得见的用眼睛找，看不见的照着画面想」两半。整条线：心情(一下1)→心里话(一下8)→二上第2、3次系统化为两看两想。**§二 想象线那格「写心里话」指的是「看不见」那一半**，不能拿期10 第三句去顶。据此查出 §四 两处已改：一下第5次删「/心里话」（越阶）、一下第15次「心思」→「心里话」（同时也是对外总地图要改的）。下一轮进 `terminology.md`。
- **期18 课次—课题映射写死**：句号＝一上第9次《句号：一句话在哪里停》；逗号＝一下第3次随《三段式》教。**台账主责在期18、教学落点在期5**。
