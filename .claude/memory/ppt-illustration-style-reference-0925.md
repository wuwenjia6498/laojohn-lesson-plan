2026-09-25 用户对六上五配图版不满意（该版是在原版式上找空地塞图，图只有 2–3in、零出血、没有吉祥物）。用户给了三套「添图前｜外部人工添图后」对照件（`桌面\添加课件PPT图片做比较\`：三上四我来编童话、五上二“漫画”老师、五上三故事新编），要求照这个风格来。

**量化特征（三套一致）**
- **覆盖面**：有图的页占 65–83%（17/25、19/32、24/29）。基本一页一张主图，只有「书目／故事卡片」页一页放 3–4 张缩略图。
- **图很大**：单张占版面面积的中位数是 9–20%，最大到 50–60%。对比我那版 4–10%，差得很远。
- **出血**：约三分之一的图贴页边或出血，最常见的是人物从右下角被页边裁掉，像「坐在页里」。
- **每课一个吉祥物**：一个孩子形象的半身抠图（约 1.1–1.9 × 2.0in），立在页题条右端（x≈14.2–14.8，y≈0.6）。页题条同时拉长到约 x=15、改成本课主题色（粉、绿、蓝灰各一）。吉祥物出现在 80% 以上的内容页，分节页、表格页、稿纸页不放。
- **形状**：rect 为主，约三成是 roundRect，偶尔用 ellipse 做圆形小插图嵌进卡片。

**版式手法（不只是加图，是以图为主重排）**
1. 正文压到左侧约 60% 宽，图占右侧 35–45%，常出血到右边或下边。
2. 正文区衬一条通栏浅色底带（浅黄、浅绿、浅桃），图压在底带边缘。
3. 三到四张卡片的页：卡片表头改成彩色（绿、橙、红三件套），卡片顶部放缩略图或圆形小插图。
4. 提示句换成「手指图标 + 一行字」，取代原来页脚的纯文字行。
5. 封面：人物出血到右下角，压在渐变横幅上。分节页整体换成主题色。
6. 图和内容直接对应：故事角色（龟兔、番茄茄子），每本书一个物件或封面，活动页配教室里的孩子，讲评页配老师。

**两处不跟**：外部件顺手改了文字（去掉破折号、换措辞），还并页、插了稿纸页。这属于外部 PPT 审查链的事（见 [[ppt-chain-index]]），添图工序不碰文字。

**六上五试点（v3，同日两轮反馈后）**：工具是 `laojohn-ppt/tools/illustrate_pptx.py`，由版式清单驱动（op：swap／add／geom／band／font），清单放在 `课件配图工具/课件产出/<项目>/ppt配图版式.json`。用户点名的几处，后来都定成了通则：
- **抠底要连水彩底晕一起抠**：只认纯白会在人物身后留下米色、浅绿的晕块。判据改成「高亮且低饱和」；只从边缘上「是底」的像素起泛洪，不然贴边的头发会被抠穿；出血的那一侧用 `keep` 不起抠。
- **添图不是在原版式上找空地，是连版式一起改**：
  - 两卡并排、图挤在角上的页，改成两卡上下叠放、图占右栏（P23、P26）。
  - 两栏排满的页，把各行压矮，腾出右下角放大图（P27）。
  - 图放右上时，底框要恢复通栏（P25）。
  - 页题条下面夹着一句说明的页，要把正文整体下移，给说明句留出一行（P09、P11）。
- **大色块概念标签换成「标签胶囊＋插图」**（P14）。胶囊仍放在最上面：这块色块往往是第一击动画，挪到图下面就会回跳。
- **判断题页的配图不能画出答案**：P09 原先画的是第二段的喂粥，改画两段共有的「发烧量体温」。
- **gpt-image（Azure）对「孩子＋床上＋嘴里含着」会误判成色情内容而拒图**：改成坐姿、手拿体温计就能过。

**v4（同日第三轮）两条定论**：
- **抠图后期治不好，改成源头直出透明底**。页目图自带水彩底晕，后期抠总有残边，用户第三次点名。gpt-image 的 edits 接口带上 `background=transparent` 就能直出 RGBA PNG，工具是 `课件配图工具/scripts/gen_cutouts.py`，清单写在项目 JSON 的 `抠图件` 里。`imgclient.GptImageClient.generate` 为此加了可选参数 `background`，缺省 None，不传时行为不变。
- **「融入」靠的是依托**：人物下沿要落在浅色底带的底边或页面底边上，底带放在正文区之下，人物腰部被截断。人物放在白底上、四周什么都不挨，就会「飘」。页脚提示句要让出人物那一栏的宽度。
- 同时落地的：页题条改浅蓝灰 E3E9F2、分节页纯色 7F93B0（theme）；页脚提示句前加手指图标，图标入仓在 `品牌资产/图标/手指点击.png`（tip_icon）；卡片表头上色（fill）。
- 生图坑：「小红旗」会被画成国旗，要写明「纯红色三角旗，无图案」。「一只手」要写明「只画一只手、看不到人」。

**分节页、结尾页不加图（0925 用户定，全线适用）**：用户试看后否了，工具里 `is_section` 会自动跳过这两类页。封面照常放人物。

**⚠ 同步口径**：`课件产出/**` 下的 jpg/png（页目、抠图、吉祥物）按 .gitignore 不入库，只有版式清单和项目 JSON 进仓。换机器后重跑 `illustrate_pptx.py` 前，要先用 `run_lesson.py` 和 `gen_cutouts.py` 重出图（会有生图费用，画面也会和本机不同）；桌面成品本身也不同步。

**How to apply：** 以后给课件添图，按「吉祥物＋主图大、出血＋底带重排」这套做，不要再在原版式里找空地塞小图。素材侧要多备两样东西：吉祥物抠图（2–3 个姿势）、人物抠图（透明底，用于出血）。表格页、稿纸页、分节页不放主图。
