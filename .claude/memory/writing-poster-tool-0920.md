2026-09-20 用户拿外部做的《学会写日记》（三上二）海报样张，要求做「按写作课详案自动出每单元习作海报」的工具。当天立项并做完三上二样张。

**四项用户拍板（改方案前先看这四条）**
1. 中央插画＝**每单元 AI 生图**（否掉「按六文体建固定图库」与「人工提供」）：`gen_illustration.py` importlib 复用 `课件配图工具\scripts\imgclient.py`（Gemini 通道），判读四问，**判读失败记 unknown 不记 fail**（照 verify_rules 的 judge_failed 闸门）。插画入库（重渲不出来的输入资产），候选图不入库。
2. 毛笔标题字＝下载 **OFL「Ma Shan Zheng」入库** `assets/fonts/`（一次性联网取工具件，用户授权；**以 woff2 存**——ttf 5.7MB 过不了 pre-commit 的 5MB 软拦，读取需 fontTools+brotli）；渲染时 fontTools 子集化只嵌标题几个字（html 0.8MB 而非 7.8MB）。**title 须避开全角 `＿＿`**，该字体无此字。
3. 底部地址/电话/行动句＝根目录 **`品牌资产\校区信息.json`**，空则整行隐藏；**初建留空**——样张上的宁波地址与手机号是占位，不得抄进对外物料。
4. **独立 skill**（2026-07 用户定「写作课配套独立于读书会重设计」，course-poster 写作模式当时已删、不重开），只借 `_jpg_render.py` 同一条 JPG 引擎；**先出三上二一份样张验收，过关再批量**。

**Why（不可从代码推断的几条）**
- 文字层能全自动，是因为 `lesson-structure.md` §四 把首页/课时/环节结构锁死；24 份实测两个课时 H2 全恒定，但第 1 课时环节名各不相同（「打开思路」只在《写日记》），所以卡③第 1 行不能写死，只许 AI 用环节名短语微调。
- 副标题不在固定行号（11 份第 2 行、13 份第 3 行）、4 份无括号文体、1 份无空格——抽取按内容匹配不按行号。
- `.gitignore` 不能写 `写作课海报输出/**/*.jpg`，会把 `-插画.jpg` 一起吞掉；现用 `*-习作海报.jpg` + `*.候选.jpg` 两条。
- 本机 Git Bash 的 quoted heredoc 会把 `\` 折成 `\`，超长 heredoc 静默截断——脚本里的反斜杠用 chr(92) 或分两段写。

**How to apply**
- 排下一课次海报：`extract_fields.py` → 填 C 类 7 处（契约 `references/data_schema.md`，配套 json 有句先复用）→ `gen_illustration.py` → `render_writing_poster.py`。机检拦「占位/直引号/emoji/待补充」。
- ⚠ **logo 源 `品牌资产\logo.png` 只有 292px 宽**，海报 200px 位在 2 倍截图下略软；用户换 ≥600px 的 logo 重渲即清晰，位置不动（单一源）。
- 打包 `laojohn-writing-package` **暂不收海报**（对外招生件是否进交付包留用户定）。
- 未做：其余 23 份详案的 C 类与生图（解析回归 24/24 已过）；`校区信息.json` 地址电话待用户填。
**手绘风格库接入（同日下午追加）**：用户级 skill `handdraw-style-prompter`（274 个编号风格，MIT，装在 `%USERPROFILE%\.claude\skills\`、不在仓）接进 `gen_illustration.py`：`illustration.style`／`--style` 给编号 ⇒ 提示词换成「风格名+参考作者+正向特征+主体+固定约束+参考图隔离声明」并把参考图作 `images` 传给 Gemini（该库对 Gemini 判「能力未知」⇒ 特征+参考图双保险）。**两项拍板**：不设全线默认、按单元自选（不填走通用水彩前缀）；索引整份拷进 `assets/handdraw/styles.json`，参考图只拷用过的编号进 `assets/handdraw/refs/`（首次用自动拷、入库，同事机器不装风格库也能重生）。三上二试过 #169 彩铅、#222 钢笔淡彩，均一次判读通过；库里大半风格写人，特征带「人物」的编号与无人约束打架，静物友好清单在 `references/illustration-prompt.md`。浏览器工具打不开 file:// 画廊，只能手动开。

**⚠ 插画画面口径（同日晚用户纠正）**：首版口径「只画物件、不画人」出来的全是本子＋笔＋橡皮，用户否掉：「不是和详案内容相关的画面」。现行口径＝**画面取本课情境**，按序取：示范文最关键的那一刻 › 教材题面／创设情境 › 学写法正例；可有小学生／教师，**只禁文字**（黑板屏幕纸面留白）；题面本身是物件时才画静物并置 `no_people: true`。判读 `has_person` 默认只记不拦。三上二改成「放学路上蹲看蚂蚁搬饼干渣」、三上三改成「推门看见蜡烛气球与屏幕里的爸妈」，均一次判读通过。

**⚠ 文案母版 0921 再改版：三卡＝递进三层（现行）**。用户给《写日记》示例定盘：卡①**写作痛点 · 教法**（痛点与教法合并，「不少孩子…」＋「教会孩子…」两段）→ 卡②**能力收获**（「告别…」起句）→ 卡③**成长收获**。形态同时从碎行短语改成**书面连贯整句**（`lines` 是整段数组、浏览器自动折行，禁手工断行），`head` ≤10 字（模板按字数自动缩字号保证单行）、每卡正文 ≤60 字。**卡③是唯一放宽口**：允许「这份真切，是成长里无可替代的宝藏」这类价值判断式表述、不必逐句反查详案；卡①卡② 仍句句来自详案。三上一/二/三/四四份已按新母版重写重渲，余 59 份沿用。

**卡③ 0921 晚改通栏独立块**（用户：「成长收获独立于前面二条，是精神生长升华类信息」）：卡①② 并列上排、保持纯色卡面；**现行＝三条竖排，均为「左标题｜竖分隔线｜右正文」横排**，第三条同结构异外观。⚠ **异外观不能靠换一种底色**——先做的「前两条色块＋第三条白底」被判「不协调」；**现行（0922 定）＝三条同一底色 + 无阴影**：`--tone-a`（明度 .83，由取色注入，缺省 #EEDAB8），三条一律**去 box-shadow、纯色平铺**（底部橙色报名条的阴影保留，它是行动点）。第三条**不靠底色区分**，只靠左缘 6px 橙条＋橙调栏目名带短横线＋标题不挂深棕竖条＋多 12px 间距。⚠ **底色分档这条路走过三轮全被否**：白底（不协调）→ 三档递进（.855/.815/.775）→ 两档略深（.83/.785）→ 同色。**别再提议用底色深浅区分层级。**左栏统一定宽 380px（**三条竖线靠它对齐，改定宽就错位**），标题 36px 封顶按 374px 自动缩，正文 24px 排右栏、每条 ≤70 字。

⚠ **版式走过三版，后两版都是被高度逼出来的**：① 三卡并列（4928px）→ ② 两卡并列＋卡③ 竖排居中通栏，用户否「太占位置、海报被拉长不少、也不紧凑」（5554px）→ ③ 卡③ 改横排（5138px）→ ④ 用户定「前两张也做成这个样式，三张竖下来，第三张做出区别」＝现行（5024px）。**结论：横排比竖排省，三条同构比混排还省**，别再回竖排居中。**判据是层级不同，不是好看**——前两张答「怎么教／学会什么」，卡③ 答「为什么值得学」。JS 按 `kind === 'spirit'` 分流外观，**改 kind 命名会让第三条掉回纯色卡样式**。

**版式 0921 同步改：卡片叠压插画**（用户给初版海报截图作参考——插画与卡片连成一块，不是上下两段）。落法＝插画基准高 720→920px、`.cards` `margin-top:-140px` + `z-index:2` + 加重阴影；无图时 `.illu.empty + .cards` 回落 4px 不重叠。（图钉圆点试过一版，用户否掉，已删。）**插画须同时放大，压一截才有意义**——新增可选字段 `illustration.zoom`（缺省 1＝920px，JS 覆盖容器高；`object-fit:cover` 下容器越高图越大、左右微裁）与 `illustration.focus`（object-position）。**实测区间 1.05–1.2**：三上一 1.2／三上二 1.15／三上三 1.05／三上四 1.1；**1.25 会把画面裁到页边、水彩淡出边被切出硬边**（三上四实测，已回调）。定值判据＝四周留白多的调大、满幅到边的调小。**连带约束：`illustration.subject` 的画面主体要落在上 2/3**，下缘 140px 会被卡片遮住；主体被盖的正确动作是改 subject 重生图，**不是改模板重叠量**（63 张统一版式）。

**底色 0921 改「浅淡呼应」**（用户问底色能否跟插画走）。**主底奶油 `#FFF6E3` 不动**——插画生图背景写死同色，一换整页底色插画就露出色块，要换得连插画一起重生，已否；改的只是装饰层：两处径向光晕 + 牛皮纸卡色相，由 `render_writing_poster.py` 的 `illu_hues()` 从插画自动取色注入（`/*__THEME__*/` 覆盖 `:root`）。⚠ **自动取色区分度实测很弱**：取的是面积最大的高饱和色，常落在皮肤／木头／砖墙上，四张插画自动结果全在 24–35° 暖橙，摆一起几乎看不出差别。**顶层 `theme_hue`（0–360）手填才拉得开**，实测童话菜园 85 绿、教室场景 205 蓝明显更贴画面，已落这两张；另两张（三上一/二）本就是暖调，留自动。取色带排除逻辑（`0.055≤h≤0.17 且 s<.62 且 v>.72` 的纸底木色带排除），改它前先想到这条，否则又平均成同一个橙。

**0921 用户四改（现行）**：① **logo 换 1200×414 透明底 png**（用户给的高清源，原 292×110 白底放大发虚已解决），模板**去掉 `mix-blend-mode:multiply`**——换回白底图必须加回来，否则奶油底上出白方块；logo 宽 250→270px。⚠ `品牌资产\logo.png` 是 8 个脚本共用的单一源，比例由 2.655 变 2.899，**已逐处核过：没有一处同时写死宽高**（都只给一边、另一边 auto），docx 封面走 `logo-01.jpg` 不受影响，故只有 ±9% 尺寸微差、不会拉伸变形；读书会线各物料下次重渲才跟着变。② 卡片**改纯色**（牛皮纸斜纹＋渐变已撤），连带把取色的卡片色相偏移从 ±16° 收到 ±8°、饱和 .58→.52——大面积纯色下 ±16 会明显偏粉、不像纸。③ 卡③栏目名**「精神滋养」→「成长收获」**。④ `logo_uri()` 的 Lanczos 上采样兜底保留（源图够宽就自动不介入）。⑤ 新增 `illustration.punch`（CSS 滤镜 saturate/contrast/brightness，原图不动）救淡图——**双向可调**——三上三铅笔淡彩 **1.3**（1.45 暗部发闷）、三上一浓彩 **0.78**（0.68 褪色发灰）；**浓淡问题先调 punch，别重生**。
