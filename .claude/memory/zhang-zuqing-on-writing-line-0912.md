2026-09-11 用户问「zhang-zuqing-perspective 能在写作课线上发挥什么作用」，0912 落地。

## 结论

- **价值在审不在写**。24 篇一手原文里只有约 8 条判据有一手根基（目标唯一性／伪问题／观众测试／工具加法审计／教练式示范／任务三要件／评改颗粒度／反套路）。现有 rubric 已覆盖「好词好句」（model-essay 笔法锚点＋红线 6）与「向机构表功」（维五）；真空白是四处：环节内减法与装载量、伪问题通篇清点、假活跃（活动产出没人接）、师生话语比。
- **落点＝`writing-lesson/references/review-rubric.md` 跨维查项九「装载量与真问题」**（三张强制清单：伪问题清点表／活动产出对账表／装载量清点表，全归 B 块）。不做 Pass C（0901 已撤过一次，「没有锚点的模糊目标比规则腔更危险」）、不进 checklist（管合规不管质量）、不动生成侧（0911 换靶后注意力预算不再加读物）。
- **两处张力用户已拍板**：① 减法只在框架内（七环节／两节 45／逐字稿／`参考：`备答是产物规格，不评价其存在）；② 体系级审计允许质疑骨架，但结论只进报告，改不改由用户定。
- **他反对逐字稿教案**（「把教案写长了，课就短了」「学生的回答岂是你可以预先写出来的」）——接入时的处理法＝审「课」不审「稿」：逐字稿是给加盟商老师上课的说明书，观众是老师不是检查者。

- **师生话语比不能当判据**：字数比 4.4:1 与 6:1，但按课堂时间估学生动手反而在前；两个 agent 都自弃。真正有信号的是「四次归纳全由教师说出」，那归跨维六「谁归纳」。已写进跨维九反向刹车⑤，别再拿字数比划线。

措辞级 3 条：rubric 维四「虽要热闹」四字与同文件「不为热闹而热闹」自相矛盾；「覆盖面广」四处（checklist F／WE／SKILL）把人头数当学习证据；SKILL「游戏化优先」与 lesson-structure 禁游戏化叫法两头拧。结构级 5 条：撤池 5 篇内「≥3 次互动至少两种形态」硬规则；rubric 维四「插一段站起来读」须排除⑥；附加讲评块改按需生成；审题辨析半步改依需；三档表只归教师、学生只留一句自评（置信最低）。

## 不能当判据的（写任何条目时禁用）

原生态作文／牧养想象／新体验作文／百字微影评（一手零出现）；「好词好句是劣质化妆品」（仅 C 级二手源，只作取向）；学生层面「内驱力」（skill 自标偏软）；SKILL.md「明确禁止使用的内容」全表。引原话只认 `references/sources/articles/` 与 research 08/09 两份校对版，不用 03-expression-dna 样本库。

**Why**：这套 skill 是人格设定型，直接扮演进流水线会带免责句噪音且判据无法机读；抽成三张清单后与 rubric 六至八的「为什么单列／强制动作／分流」体例同型，冷审 agent 无需读 skill 本体。

**How to apply**：冷审 Pass A 照 rubric 九跑即可；想让「他」临时看某一篇时直接调 skill 扮演（聊课模式），报告归 `_张祖庆试审-*` 命名。体系审计那 8 条拍板前别动 rubric 维四／checklist F／池 5。相关：[[constraint-layering-generation-vs-coldreview-0804]]、[[writing-style-two-directions-conflict-0831]]、[[no-self-report-mechanisms]]、[[lesson-plan-per-step-load-audit]]。

## 两种用法的实测差异（0912 · 外部扮演聊课《心爱之物》三轮 vs 仓内判据抽取《漫画老师》）

- **趋同三条**（说明抽取没抽丢主干）：修改段几分钟塞六件事／答案在纸面上的伪问题／同一例子或尺子用两遍——都在跨维九。
- **外部扮演多产出三样仓内产不出的**：① 三档优先级标记（源于 01「砍成一张纸」→ 02「职初教师要加法」的自我反转，是「详案给谁用」的元层判断；仓内定位声明把这类建议提前掐掉）；② 示范文细读三问（范文自犯本课反例之病／旁批表漏收最好句／范文够不够得着）——**已补进 rubric 维三**；③ 课文佐证从一句扩成环节。
- **外部代价＝手里没有事实源与红线**：给《珍珠鸟》写了带引号“原文”；用了 skill 自标未核实的「牧童放羊」；按校内班规模说「四十几个孩子」；产物文件名不带 `_`、标题后缀与新增 H2 偏离体例、`**` 触 tone_gate FAIL。
- **How to apply**：想要元层／文本细读类意见→用扮演聊课模式，但产物回仓前必须过 unit-texts 核实、tone_gate、体例三关；想要可直接落 A/B 块的清点→用 rubric 九。两者不互替。「三档优先级标记」**0912 用户拍板不推广**：三档里「学生卡住时才用」＝既有 `〔应答·触发情形〕`、「有时间再做」＝既有 `> **可压缩预案**：` 引块，唯一新增的「点名本课三到五件命脉」收益不抵体例改动面（title-naming／style_front_page／tone_gate 标题解析／17 篇回改）。《心爱之物》`_优化版` 仅作个案。日后若要「命脉清单」，最小形态＝文首授课提示块加一句「本课非做不可的 N 件（≤5）」，标题不动。
