2026-09-18 四上五《生活万花筒》开场投屏教材「初试身手」左图，详案写成「接力赛、场边同学举彩球、有人正在接棒」。用户看图指出：**图上没有接棒动作，场边同学举的是三角形小彩旗和啦啦队手花**。开图核对属实：三名蓝衣同学在跑道上跑，无接力棒。

**根因**：写详案时按图单「读图口径」（动笔不开图，文字已进 unit-texts）照抄了图单与 unit-texts 里的画面描述，而那两处的描述本身就是建条时写错的，错误顺着链条一路进了投屏提示、师话、参考答案、收尾回照、指纹块、台账和记忆七处。

**Why**：画面描述一旦进师话与 `参考：`，就是老师当堂要照读、学生要照答的东西，图上没有的动作学生一看就知道不对，课当场穿帮；且 `lesson-structure.md` §四本就写了「图到位后必须逐张目视核对图单的画面描述再写详案」。

**How to apply**：
- 图单「动笔不开图」只对**页上文字**成立（题面、要素、旁批、文后题）；**凡要描述画面**（投屏舞台提示、师话点画面、`参考：` 里学生说看到什么、回照句）一律先 Read 原图目视，再落笔。
- 目视后若发现图单／unit-texts 的画面描述有误，**当场回改那两处并标订正日期**，否则下一篇照抄再错。
- 画面描述里不写图上看不见的动作与物件（「接棒」「举球」这类是脑补的赛事常识，不是画面）。
