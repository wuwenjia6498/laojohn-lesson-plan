2026-08-24 给 `laojohn-ppt` 加了**第三个 profile：宣讲（`文体：宣讲`）**，产出面向加盟商的
《同步写作课上线宣讲》16:9 可编辑 pptx（初稿 47 页，用户删去师训与开课落地整章等 11 页后定为 36 页）。此前仓内**没有任何横版演示件先例**——所有对外
物料都是竖版单页或长图，两次「课程上架通知」是手写 HTML 截图、无脚本无留痕。

**改动面积**：新建 `layouts_promo.py`（12 页型 + 自带 `_END`）＋ `theme_promo.py`（配色取已发布
招生海报的品牌红 `#C8352B` + 四阶色，不沿用课件深灰蓝）；`build_ppt.py` 分派点改字典查表；
`parser.py` 只加 8 个页型名 + 一个课型无关的 `备注：` 字段（写进 pptx 演讲者备注页）。
`helpers.py` / `layouts_common.py` / 两个既有 layouts **一个字没改**，回归逐页形状数零差异。

**四个静默坑（都不报错，只有看图或看 diff 才发现）：**

1. **`封面` 与 `环节标题` 两个页型名任何 profile 都不许改**——`build_ppt.py` 里「首页不是封面
   就自动补一页」「按环节标题自动编章节序号」是课型无关逻辑，判据就是这两个字符串。改名会同时
   丢掉自动封面判定与章节编号，**完全静默**。
2. **`要点：` 块里不以 `- ` / `1. ` / `参考：` 开头的裸行会被 parser 直接丢弃**。我给卡片写的
   第二行说明就这么没了，PPT 照样烘得出来、机检也查不出，只是卡里少半截字。多段内容一律用
   全角 `｜` 接在同一条 bullet 上。
3. **一页多图只能用 `场景：图=…｜名=…｜问=…` 重复行**；`配图建议：图=` 一页只保留第一条路径
   （`parser.py` 既有行为 `if m_img and not current.image_path`）。
4. **`add_image_cover` 是 cover 语义，放文档截图必错**——A4 竖版塞进横框会被裁掉大半页正文。
   promo 自写了 20 行 `add_image_contain`（并让白卡贴合图片实际比例，否则两侧留大片空白卡面，
   看着像图没加载）。**没动 `helpers.py`**。

**顺带修掉一个既有静默坑**：原分派点是「非写作即读书会」的三元式，`文体：写作课`（多打一个字）
会静默落回读书会 renderer、整份稿按错版式烘出来还不报错。改查表后显式报错。

**版式溢出机检查不出来**（框没越界，是框里的字满出来压住下一块）。写了个按字宽估行数的
估算器放 scratchpad，报 ratio>1.05 的框；巨型数字（章节序号、数据面板大数）是稳定误报，
因为数字字形实际高度远小于字号。

交付物同住 `写作课相关宣传文件\同步写作课上线宣讲\`（整目录 gitignore）：中间稿 md（内容源）
+ pptx + `shots.json` + `imgs\`。⚠ **git 无法在被排除的目录内用 `!` 重新包含文件**，所以中间稿
放这里就是永久不入库、同事拉不到——这是用户拍板选的。

**⚠ 对外宣讲件的文风，守的是详案那同一条语言红线**（0824 用户退回重写一次）。初稿我按
「大白话有力量」写，用力过猛滑进商业口水：先看盘子有多大 / 能力怎么往上长 / 唯一护城河 /
一份教案打天下 / 质量不塌 / 拿得出手。用户一句「不够符合教学风格」退回。判据就是仓内既有的
那条——**禁市井网络口语，也禁过度学术术语，统一用中性准确的实操词**；对外件不豁免，加盟商
是教育从业者不是消费者。反向刹车同样成立：不要矫枉过正改成学术腔，「写不出来的孩子还是
写不出来」这类有力的实话要留着，**只去黑话，不去具体**。全篇 75 处。

同一次通读还照出两个**不是风格问题**的硬伤，都是「按内部文档写、没对真实产物」造成的：
  · **流程图顺序与真实详案相反**——我按 workflow-engine 的 ③④⑤ 编号写成「示范文 → 构思支架」，
    而三份详案实际都是「借助构思表，理清思路」→「出示示范文，发现写法」（L3 以上示范文后置，
    防套写）。**编号顺序 ≠ 上课顺序，必须对着真实详案的 `### ` 标题核。**
  · 环节名用了内部工作名（真实情境抛任务／全感官唤醒／自由倾吐），而老师手上详案是教案式
    平实名。两边对不上，加盟商听完一翻详案就穿帮。四种起步法名（快问快答采访法／限时倾泻法）
    同理，`workflow-engine.md` 本来就写明「不照搬进详案做环节标题」。
  · 顺带：标题写「七个环节」而图上画 8 格（第 6 环节含起步与续写两半），数字自相矛盾。
