writing-lesson 第2课时(当堂写作与评改课)开场、动笔前**统一增加「降压起步」环节**(约5分钟)，让学生零评判地写出初稿第一组句子再滑进自由写作。

**定位**：属环节⑥(自由倾吐)的开场半环，**不新增第八环节、不破"七环节"骨架**；在详案里渲染成该课时第一个 `### 一、`(自由写作顺延为二、评改为三)。第2节时间重配：降压起步5 + 自由写作17 + 评改23 = 45(⑥总时长仍22)。

**三条铁律**：①绝不套"一句扩三句"/纯写法复述；②素材继承强制——必须让学生拿出第1节⑤构思表、基于已有关键词、开场点名定位到具体格子；③策略矩阵按文体4选1：写人→快问快答采访法 / 写景·状物·观察·说明→**聚焦细看法** / 记事·叙事→慢镜头回放法 / 想象·抒情·读后感·倡议→限时倾泻法(矩阵不列的按性质就近归)。**(2026-06-28：原"取景框导演法"已改名「聚焦细看法」——空捏取景框手势在教室凭记忆写景不贴切、是无功能空动作；改为"看着构思表圈出的一处→分步落笔:看清颜色形状/凑近细节/加声音,每步一句(原写的"脑中放大看清"后也按"动作须有功能"红线去掉)",实质不变、去掉手势包装。全 SKILL+两 demo 已同步。)** **(2026-06-28 同日:写人「快问快答」再按特点类型分问——做派类[性格/招牌动作/爱好/品质,有「做某事」场景]走动作/表情/声音;纯外貌类[静态长相、无「这件事」可问]改走「看清/比/像」[借聚焦细看法的描写路径],且外貌类在⑥再配一件能体现它的事。起因:学生圈的最特别处可能是外貌,三问空转。只写人有此分支[人有多维特点],其他文体支架对象单一不需要。规格在 workflow:104,checklist B② 与 demo《猜猜》已落。)** **(2026-06-28 再续:做派/外貌两套问须等量引导——不要把外貌压成一句路由。demo《猜猜》已去掉单独路由行,改成在 动作/表情/声音 每一问后各挂一句外貌换问 + 一例[颜色形状·卷毛 / 比谁特别·高半头 / 像什么],三拍对齐;workflow:104 加注"两套问等量展开、各配例子,别让外貌那套只剩一句";env2 点题句也补了外貌例「她呀,一头卷头发」。)**

**强制输出三件套**：锚定旧知 + 策略执行(含代入感教师直接引语+学生配合动作) + 当堂落笔(写`学生动笔写作`并顺接自由写作)。**环节名一律平实教案式**(如"聚焦一处,写下第一组句子""借助构思表,写下第一句")——降压起步**无**"游戏化标题例外"(该旧例外已被语言风格红线第四条推翻、覆盖所有年级，见 [[style-redline-covers-edits]])；四个支架名(快问快答/聚焦细看/慢镜头/限时倾泻)是写给生成器的内部方法名、不进详案标题；环节名与师话不得同年级逐字复用(轻规则、不进六项指纹块)。

**(2026-06-28 续·降压只写细节句 / Model 2)**：描写类(写人/写景/状物)**降压只写第一组「具体描写句」,点题中心句不在降压写、留到 ⑥ 自由写作的开头点出**(写人「我们班有个同学,是个急性子」、写景「××真美」),由正文首句中心句统领、再接降压细节句。起因:用户嫌《猜猜》降压"点题句+过渡+路由+三问"多阶段**绕**;而《这儿真美》本就这么做(降压只细节、点题句在自由写作开头)、读着清爽。于是把这更清爽的口径定为正式 spec——**改了 workflow-engine.md L124 描写类条 + checklist B②⑤**(原"降压先写点题中心句再写细节"作废)。《猜猜》降压重构成 拿卡→路由+三问→连读bridge 三步(点题句移到第2课时②开头);《这儿真美》本已合规、未改。叙事类(慢镜头高潮句可直接作 hook)、倾泻类不受影响。

**(2026-06-28 再定·撤回上面的 Model 2,改「单链·中心句先写」=当前口径)**：两份 demo 再冷审都独立指出 Model 2 有**接缝**——降压先写细节句、正文开头却要先写中心句再把细节放后面,「先写的放第二行」,L3 易困惑。故**撤回 Model 2**,改为:**描写类降压第一句就快写点题中心句**(开头空两格、最省事的一句:写人「我们班有个同学,是个急性子」/ 写景「××真美」),**随后用支架细节问题写两三句具体的,一条快问快答链问到底、不分阶段**(中心句即链首,不另起起手句/过渡)。**写序=正文序、接缝消失,仍不绕**——绕来自「分阶段」不来自「含中心句」;这不是退回最早那个「起手句+过渡+路由+三问」的绕版,区别在单链不分阶段。已改 workflow:124 + checklist B②⑤ + 两份 demo 降压(env2 不再重写中心句、直接续写)。**配套两改**:① 写景聚焦细看第三步「加声音」→「加感觉(声音/气味/触感)」(补②看听闻摸四感里漏的闻·摸);② 写人外貌轨由「逐问挂括号」收成**做派为主 + 一句换问(看清/比/像,挂在第二句) + ④示范文旁批后补一段外貌成段微示范**(冷审指出逐问挂会维度错位、且圈外貌的学生无成段样)。

**Why**：降低面对空白稿纸的最大压力，把第一组句子从笔下"骗"出来。
**How to apply**：固化全触点——workflow-engine.md(环节⑥-起步规格+矩阵+输出结构)、lesson-structure.md(§一骨架/§二切分/§三标题对照/§五流程)、checklist.md(B组结构项+E组标题例外)、SKILL.md(工作流第4步)、review-rubric.md(⑥净书写须含降压起步落笔)。关联 [[writing-lesson-core-literacy-goals]] [[style-redline-covers-edits]]。
