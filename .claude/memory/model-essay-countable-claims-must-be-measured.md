2026-09-09 六上一《变形记》冷审 Pass B 实测撞出：⑤环节师话说「最长的是铁槽子那一段，前面写醒来、写被攥住都只用了两三句就带过去了」，
逐段计字实际是 ① 15 ② **128** ③ 72 ④ 50 ⑤ **113** ⑥ 94 ⑦ 68 ⑧ 66——**最长的是第 2 段（醒来），被师话说成了「两三句」**。八段的段数无误，只有长短判断反了。

**Why**：这类断言是**学生当堂能数出来**的，一数就露，教师无从圆场；而整个「详略」教学点正押在这个判断上（后接「挑一件写详细，别的交代一句就过去」）。
写详案时是先写示范文、再写讲解，讲解里的「哪一段最长」凭的是写作意图（我打算让铁槽段最详细），**不是成文后的实际长度**——意图与成品之间的漂移，通读时看不出来，只有计数能看出来。

**How to apply**：

1. **凡师话里出现可数断言就实测**：共几段、哪一段最长/最短、用了几句、多少字、出现几次。一行 python 计字即可，不要靠读。
   高发位＝⑤出示示范文后的「发现写法」问答，其次是⑦评改标准里引示范文做样板处。
2. **改法优先改示范文、不优先改师话**——本篇选的是把第 2 段从 128 字压到 81 字（删自我端详「圆的，扁的，边上还有一圈细齿」与「光里有灰在慢慢地飘」），让铁槽段真的最长。
   理由：改师话（把「哪一段最长」换成「为什么写得这么细」）会削弱「以长短看详略」这个学生**可指认**的判据，而这正是本课要教的东西。
   顺带解掉了 Pass A 另一条——示范文 802 字超 L6 区间（500–600＋）33%。**两个问题常常同源：段落铺陈过度。**
3. **压段前先查旁批表引句是否落在这一段**（本篇「那些布纹一道一道，深得像田埂之间的沟」正在第 2 段内，压完须回验仍逐字可引）。
   下游若已产出，还要连改配套两侧 `_data.json` 范文页、批改标准包、PPT 示范文页——见 [[model-essay-swap-downstream-chain]]；本篇下游三件都没做，零成本。
4. **采纳冷审报告后新增的师话，必须复跑 `tone_gate`**：本次补第五栏铺垫时，新写的两句自己带进了一个引出式破折号和一个超配额短语（「的那一件事」5→7 次），
   Pass B 刚删掉的毛病被我又加回来。**冷审改完不是终点，落定后还要再过一遍机检。**
