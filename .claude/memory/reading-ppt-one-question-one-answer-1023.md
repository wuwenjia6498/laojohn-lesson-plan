2026-10-23 用户：「PPT做的都是乱的，逻辑不对」，亲手把《和大人一起读（四）》导读课第1–33页改完（桌面 `和大人一起读（四）-导读课.pptx`），要求照她的逻辑改34页以后。她的逻辑「根据详案来，一问一答要对得上」，从手改件归纳出四条：

1. **一问配一答**：答案只回答本页问出的那个问题。标题里有两问、或标题一问＋要点又一问时，拆成编号 1、2，每问下面紧跟它自己的答案（她把第31页标题问句挪进正文当①，配上「不怕，她还抬起手……」）。
2. **标题不放没答案的问句**：标题装不下问答对应时改成陈述（「手指伸直和攥成拳头，对比看看」），真正的问题挪进带编号的要点；收束页/预告页标题若是答案不在本页的问句（「狼到底想了什么办法？」），改陈述。
3. **答案接得上问题语境**：如「妈妈嘱咐了哪几件事」的答案前补「出门后的三件事：」，不在范围内的另加括注说明（「趁天热之前动身……这是出门前的事」）；原文齐读页标题若是问句，页上要补答案（「第二次说的是颜色」）。
4. **页码精确到那一页**：引文页码按实际所在页拆细（P2-3→P3，P42-44→P42-43/P43-44）；标题写「两件事」下面就只能两条。

**动画**：每击只出一样——①编号＋问题同击出现 → ②它的答案（多条答案一条一击）→ ③下一个编号＋问题 → ④它的答案。引擎原来把标题问题静态显示、答案挂在别的问题下出，用户逐页重排了。

**How to apply**：写读书会中间稿时逐页过这四条；引导问题页标题若是问句，要点里不能再出另一个问题，否则拆成两条编号问题各配答案。改外部/手改件用 `laojohn-ppt/tools/pptx_text_edit.py`（clone_shape＋克隆点击 par 重映射 spid，删形状后清空点击 par）。中间稿与引擎尚未按此改造（标题问句目前一律静态显示），交流课和后续书须照此人工复核。
