面向家长的宣传片（含读书会 3 分钟体系介绍片 `D:\my-Workspace\04-projects\dushuhui-promo\system3min\内容规划.md`）只讲家长关心的事：孩子的问题、孩子在课上做什么、孩子会有什么变化、家长怎么看到进步、和校内语文的关系。逐字稿教案、配套课件、参考答案、教研体系、课型名、测评维度术语这类老师侧/加盟商侧内容不讲。

**Why:** 2026-10-20 用户否掉了 ⑥ 教研段（「从文本解读、教学目标到每一个提问都写进逐字稿……面对家长，这不用讲」），并要求「牢牢记住这支视频是面对家长的」。产品说明 PDF 是写给加盟商的，直接搬会变成产品手册腔。

**How to apply:** 从产品说明取事实后，逐句问「家长听了会在乎吗、听得懂吗」；术语换成孩子的动作和变化（例：「转化运用」→「读懂了多少、哪里还没读透」）。家长侧收获的现成说法在 `D:\my-Workspace\02-notes\children-literature\课程资料\L1L2/L3L4/L5L6试听课解读.md`「如何向家长讲述孩子的收获」节。相关：[[promo-video-presenter-line-0927]]
