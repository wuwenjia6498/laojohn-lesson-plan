用户拍板（2026-07-20）：详案里思维工具的解释**尽量简化**，且**不必标注是否首次出现**——「仅凭单一课案，也很难判断」。

**Why**：根因在 `visualization-tools.md` 的判据原文——"判据不是工具名听起来难，而是**该工具在本年级/本期是否首次出现**"。生成侧只看得见这一本书，**判断不了这批学生此前学没学过某个工具**，模型没法判断就把这个假设直接写进师话（`因是首次出现，简短讲清`、`六面体首次出现`）和 PPT 页标（`新工具`）——等于把无从核实的假设印进老师讲稿，讲错了当场露怯。冗长讲解则是另一半：模型爱先描述工具"长什么样"（`鱼骨图长得像一条鱼的骨头，从鱼头拖出主骨，斜插出大刺…`、`它像一枚骰子`、`就像一段台阶`），形状描写占掉大半，学生照着填反而更慢。

**How to apply**：
- 判据换成**工具本身结构绕不绕**（六面体、鱼骨图要开小环节；表格、气泡图、维恩图一两句带过）——这个单本可判。
- 讲解只说**"怎么填 + 有什么用"**。不描述形状、不写"很简单/不难/它的样子是"式铺垫、不说"一个可视化思维工具"（术语腔，对学生别扭）。✅`鱼骨图这样填：鱼头写要追究的结果；每根大刺写一股原因；大刺下面写书里的依据。它的用处，是看清一件事往往由多个原因合起来造成。`
- **保留有教学价值的"用处说明"**，别过度清洗：从需求引出工具的写法是好写法（绿山墙"一个结果由好多个原因合起来促成 → 鱼骨图"，未动）；师话里的通用逐面解释若与下方表格「要讨论的问题」列重复，则删师话留表格（骑鹅六面体即此例）。

已固化（2026-07-20）：`visualization-tools.md` 执行清单「陌生/复杂工具先教方法」改判据 + 补正反例（唯一源）、落地范例 B 要点同步、`checklist.md` 可视化工具组加"首次出现/新工具"全文检索项。

存量已清 7 本（含各自 docx 重渲）：呼兰河传（4 工具 + 4 处 `新工具` 页标改为 `XX图用法`）、伊凡（对比图/阶梯图/气泡图）、格列佛（讽刺逻辑图/阶梯图）、海鸥乔纳森（六面体）、骑鹅（六面体去骰子比喻+删与表格重复的逐面解释）、萨哈拉（树形图）、快乐王子（六面体）。**扫描词要用宽口径**：`新工具|首次出现|它的样子是|简单的工具|先讲讲什么是|像一枚|像一段台阶|像一副`——只搜"很简单/不难"会漏（伊凡气泡图那处即漏网后二次扫到）。

## 追加（同日）：工具**选型**的学段适配

用户又指 L6《呼兰河传》导读课的**气泡图**「难度和形式上偏低」。查下来 SKILL 表里气泡图那栏本就写着"低年级友好"，但没有任何硬约束拦住高段选它；更隐蔽的问题是**工具没落实本节声明的重点策略**（该课【过程方法】写"重点显性训练联结与提问"，气泡图只落实描述，"提问"仅靠环节末一句口头交代）。

**判据（已写进 visualization-tools.md 执行清单）**：选完工具先问——**这个工具要求学生做的思维动作是什么？** 只是"想几个词填进空格"就是偏低。**L5–L6 主工具至少含一项**：归类判断／找依据／对照冲突／因果追溯／递进分期。气泡图那栏已改为**限 L1–L4、L5–L6 不得作主工具**。rubric 维二「难度配得上学段」补了这个判例，并新增一条「工具真正落实了本节声明的重点策略」。

**改法示范（呼兰河导读课）**：气泡图 → **两副面孔对照表**。材料没变（还是那四段听读）、时长没变（20 分钟），思维动作从"想词"升级为"归类＋举证＋提问"：把四段归到明亮/沉重两半 → 各写"从哪一句听出来的" → 由两半冲突写下自己的问题。**教学落点是刻意制造的分歧**：扎彩铺那段两边都能放（扎得阔气体面 vs 看客觉得活着不如死了），老师不裁决，让学生自己撞见全书内核。阅读单用 `stance` 模板承载（claim 横幅＋左右两栏＋底部落问题，`verdict.options: []` 只留书写线）。

**跨书查重的现实**：L5/L6 近作里维恩图/对比图/思维导图/阶梯图都已连用 3 本以上，没有"干净又适配"的现成工具可换——所以正解不是换个工具名，而是**把同一个任务升级到该学段的思维层级**，同型复用有书本位理由即可（本例是"同一座城的两副面孔"而非"两个对象比异同"）。

**存量待定**：`俗世奇人-课案详案.md`（L5）第1课时也拿气泡图当主工具（15 分钟，"中间写'奇人'、周围写 5–8 个形容词"），按新规则同样偏低——**已报给用户、未擅改**（rubric 明确"工具要不要换"属教学判断项，须用户拍板）。伊凡（L4）用气泡图在允许范围内，不动。
