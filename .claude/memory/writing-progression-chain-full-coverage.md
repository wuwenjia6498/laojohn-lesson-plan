**补全规则（改表须照此重算，勿手工增删）**：归线＝§三「文体」列**首段**（「应用·X」全归应用·说理线、「记事·X」归记事线、「观察·记事」归观察·说明线、「写人·记事」归写人线）；分档＝教材**册次**（三上→六下，无任务的册跳过），一册一档用 ` → ` 连、档内按单元序用 `/` 并列；63 序号不重不漏（写人7/写景状物7/记事15/想象12/应用·说理16/观察·说明6）。与旧版一处归属改动：**作品梗概**（应用·概括）由观察·说明线移入应用·说理线。

**Why**：代表题目版只覆盖 25–36 题，多数课的本课题目不在自己线上（换版后《漫画的启示》直接掉出链外），首页「同类习作顺序」行标不出「（本课）」落点。全覆盖后凡统编任务必在链上，「本课不在链上怎么标」的口径问题从根上消失；留空只剩自拟题一种情形。

**How to apply**：写详案首页那行＝照录 §四 整行、半角 `/` 转全角「／」、本课题目后紧跟「（本课）」；**找不到本课题目＝文体归错，回表核，绝不许添题凑**。链长属正常，不得为缩短删题。

**同期实证的引擎坑（比链本身更容易再犯）**：题目里的填空位**必须全角「＿＿」，禁半角 `____`**——`md_to_laojohn_docx.py` 的 `_INLINE_BOLD_RE`（`__.+?__`）会把跨题目的两处半角下划线当成对加粗标记吃掉，实测「…游____ → 心爱之物/____即景」渲成「…游__ → 心爱之物/即景」，**静默、不报错**。涉及四题：他＿＿了/游＿＿/＿＿即景/我和＿＿过一天。全角不触发该正则，故不动共享引擎（5 个消费者，不值当）。同类风险见 [[write-tool-normalizes-curly-quotes]]。

**追溯留痕**：旧原件的长链可从 git 取回验证——`git show b889e14:.claude/skills/laojohn-writing-lesson/assets/课程总地图_同步习作_接入六阶体系.docx`（该 docx 入库）。此次核实：现行 md 的长链与旧原件逐字一致，转录环节没走样，变的是原件本身。
