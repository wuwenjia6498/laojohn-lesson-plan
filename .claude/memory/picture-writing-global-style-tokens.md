2026-07-21 配图质感升级：抽查发现成品图停在「AI 默认儿童插画档」（塑料光泽/糖果色/均质黑描边），根因＝画风散在每张 `生图提示词` 里各写各的、无全局注入点。

改法（最小改动、不重构生图验收主流程）：
- 新增 `references/style-tokens.md` 为人读唯一源，运行时源＝`scripts/imgspec_parser.py` 顶部 `ANCHOR_STYLE_TOKEN`/`LIBRARY_STYLE_TOKEN` 两常量，**两处须一字一致**（已互相注释指向）。
- `build_prompt()` 按角色在末尾自动追加令牌：锚图 clean 档（收在「清晰可数可圈」，可读性优先于美观＝硬红线）、例库图 atmos 档（放氛围），两档媒介/描边/配色/光线基调同源以免图生图打架。
- `generate_images.py` 的 `_STYLE_REF_INSTR` 补正面质感＋同一份负面清单，防模型图生图回弹默认卡通。
- `image-spec.md` 新增「画风令牌」小节＋两示例已删风格话术；`风格/比例` 字段今后只写比例。

链路：锚图令牌定调 → 例库图图生图跟随（沿用 [[picture-writing-image-style-lock]] 的既有机制，是升级不是推翻）。

**Why:** 文字形容词控不住画风是本 SKILL 的老结论；单一全局令牌把「唯一能定调的那张锚图」拉起来，全期跟着起来。

**How to apply:** 调画风只改**三处**且同步，令牌是否奏效只能跑真图人工看（机器验收判不出画风）。存量期1/期6 规格里的旧形容词**已于同日清空**（10 处）。

**⚠ 两处已改为三处（2026-07-27 起，本条上文的"两常量"口径过时）**：常量已改名为 `MAIN_STYLE_TOKEN`／`ALT_STYLE_TOKEN`（练笔图与主图同走 clean 档），第三处＝`generate_images.py` 的 `_STYLE_REF_INSTR` 里硬编码的质感描述句——**它是图生图回弹防线，漏改则每张跟随图都被参考图指令拽回旧媒介**。三处口径与「勿在第四处写风格」的规矩见 `references/style-tokens.md` 文件头。

**⚠ 0727–0728 厚涂平面档改造已终止、勿重启**（十余轮未成，失败点在模型对人脸的先验而非措辞）：现行仍是 A/B 两档水彩淡彩叠彩铅。同期的 A 级全期锚图链 0728 停用、0730 从脚本摘除（见 [[picture-writing-b-level-char-ref-landed]]）。过程实录归档在 `docs/handoff/归档_厚涂平面档改造全过程-0727to0728.md`，止损令与净收益表留在 `style-tokens.md`「已终止」节——**想换画风档先读那节**。

**期6 实测（同日跑完，锚图四版）**：令牌一上质感立刻从卡通档变水彩档（纸纹/笔触/低饱和/柔和方向光），可读性未受损。但迭代四轮才收敛，教训＝**碰巧生成对却没写进规格的东西，下一次重生一定丢**——不只物件，人物形态·动作姿态·光影同样适用（v2 甩头＋圆脸没写死，v3 修水珠时双双丢失）。已补进 `image-spec.md` 实测经验两条（含"脸上沾水珠会被画成汗、须规定水的来路与形态"）。期6 三图已全部重出统一画风、docx 双版重渲＋首页版式化，备份已删。
