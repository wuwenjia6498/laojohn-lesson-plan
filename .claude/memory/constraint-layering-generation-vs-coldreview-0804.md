2026-08-04 用户提出「正式写课案时约束太多会影响发挥、文字想法被固化，措辞类约束放冷审执行是不是更合适」。实测后按此改制，**两条详案线（writing-lesson / picture-writing）已落地**。

**实测把判断修正了一点**：生成时手里约 **1400 行**规则（writing：workflow-engine 199＋lesson-structure 250＋variation-pools 436＋course-map 232＋situation-anchors 130＋正样本 117；picture 同量级），但**措辞层只占约一成**。问题不在总量，在作用方式——其余九成是**一次性决策**（选场景原型、定技法档、查锚点），选完不再干扰造句；措辞层是**唯一一层在写每句话的同时都要逐句过一遍**的规则。仓内早有同向实证：池8 改版说明写着「一条六篇零达标的规则是不可执行的规则，不是六篇都烂」。

**分层判据（唯一一条）：修这一处，要不要动教学设计？** 要动→生成层（错了只能重写）；不动→冷审 Pass B。**拿不准就留生成层。**

**已落地：**
1. 两线各建 `references/generation-brief.md`——生成时必守硬线的**索引**（只摘要＋指向原处，不复制判据）；§二列后移条款清单，防生成侧顺手又去自查。
2. 两线 SKILL 生成步骤改为「**只读生成简报＋正样本**，事实源随用随查」，并写明本步不再逐句自查措辞层。
3. 措辞层条款**原文一字未动**，只加「执行层」标注块：writing 红线第 5①②③／6②–⑦／7 整条＋池6/7/8＋逐字复用近似变体；picture §13.2/13.3/13.6/13.7/13.8/13.10＋§13.9 护栏。
4. `detail-review` 新增第 1.5 步：**复盘拆两遍、各派 fresh agent**——Pass A 结构与教学（原五维），Pass B 行文（对着正样本逐句读）。Pass B 三条职权：**成批直改**（按类汇报、仍禁 find-replace）、**回炉闸**（挑三段读出声，两段不像就停手、建议重写、交用户拍板，不自己重写）、**反向护栏照守**。
5. 两线 review-rubric 各加「Pass B 行文审查项」节（只列归属、判据回原处读）；checklist 措辞条标「归 Pass B」。

**⚠ 没有后移的（别一起摘掉，它们改起来要动设计）：** writing＝红线第 1–4 条与第 5 条④、`参考：`标签纪律与追问链拆分、术语首现权、反同质化**零件层**（池0–5）；picture＝§13.1 句式模具、**§13.4 参考粗糙档＋链条**（链条断了冷审补不回来）、§13.5 术语硬替换表（已机检）、§14 标签纪律。

**Why:** 生成时把注意力还给「这堂课怎么上、这句话老师会怎么说」；措辞的密度、配额、轮换交付前统一过一遍，比边写边自查更省力也更准。

**How to apply:** 写详案＝读生成简报＋正样本即可，别再翻整份 lesson-structure 逐条比对；交付前必跑两遍冷审。⚠ **改这些规则文件时不得破坏 tone_gate 的四个运行时解析锚**（`load_pool6_words`／`load_pool7_words` 的池6「原高频」行与池7「→轮换」行、`load_redline_ban_words` 的「禁用词（出现即改）：」行、`load_forbidden_phrases` 的 `## 已知「禁止逐字复用」` 节——该节内**禁止新增 `- ` bullet**，会被当成新的禁用句；用 `>` 引块）。回归基线：池6 六词、池7 A5/B4/C3、红线 17、逐字复用 40、terminology 8。**待验证＝下一份新课案的实测**（初稿文风有没有变差、Pass B 的 A 块条目数、是否触发回炉闸）。相关：[[writing-lesson-prose-style-benchmark-0804]]、[[picture-writing-prose-style-benchmark-0804]]。
