# 出图反例对照（2026-08-04 · 二上第 2 次《细节四问·【两看】》三张图的真实返工记录）

**这几张图为什么存在。** `image-spec.md` 2026-08-04 新增的三条硬线全是**文字禁令、一张对照图都没有**——与写作线当初「只有禁令、没有正样本，规则合并了稿子没扫过」是同一个局面（那次的补救是建 `prose-style-benchmark.md`）。本目录给那三条硬线各配一组**正反真图**，判据不必再靠想象。

**看法**：每张图**左＝反例（错的那一版）**，红线右侧**＝正例（定稿版）**。四组都取自同一课次的真实返工，不是构造出来的示意图。

| 图 | 对应 `image-spec.md` 的哪一条 | 左（反例）错在哪 | 右（正例）怎么写才对 |
|---|---|---|---|
| `01_狗的头-未回头vs已回头.jpg` | §A「**逆着运动方向的朝向**，四件几何写全了仍然不够」 | 规格写了「一边跑一边把头向画面右后方转过来回看男孩」＋瞳孔＋视线共三件，出图**头照常朝行进方向**、一点没回。模型默认服从运动方向 | 补两句：给**头与身体的相对关系**（「头几乎侧对着自己的行进方向」比「转 90 度」好执行）＋**两条偷懒禁令**（严禁头朝行进方向、**严禁只把眼珠转过来而头不转**） |
| `02_眉毛-内低外高向中间压vs拱起眉头不皱.jpg` | §A「**表情类五官要写两端的相对高低，不能写形容词**」 | 规格写「两条眉毛向上**高高扬起**、眉心不皱起」，出图是**内端低、外端高、向中间压**，读作皱眉发怒——与正文「他没有皱眉头 → 所以又急又好笑」那一轮问答正好相反 | 写两端相对高低＋眉间状态：「靠近鼻子那一端**明显高于**外端、整条向斜上方挑起；两条眉毛之间没有竖纹、眉头不向下压、不向鼻梁中间聚拢」 |
| `03_嘴-噘嘴vs抿成一条线.jpg` | 同上条（嘴形是同族） | 规格写「**抿着嘴**」——结果词，模型用**噘嘴**速记顶替：嘴唇向前撅成一个圆、腮帮鼓起，读作嘟嘴撒娇或生气 | 「上下嘴唇压成**一条横线**、嘴角轻轻向下；**严禁向前噘起、严禁腮帮鼓起**」 |
| `04_猫爪-悬空vs扣住箱沿.jpg` | §A「**同一处画面写两条要求时，先自问能不能在同一个姿势里共存**」 | 同时写了「把小猫**提得离开箱底**、后腿悬空」与「两只前爪**扒住箱沿**不松开」——物理上打架，猫整只被提出来爪子就够不着。模型二选一，选了前者，另一条**静默落空** | 改成「**后半身仍在箱内、只提起前半身**」，两件才同时成立；爪子再写成几何：「肉垫搭在箱沿上边缘、五个脚趾向下弯钩、扣住箱沿外侧面」 |

**四组的共同点，也是最该记住的一句**：**这四处机器验收全部打了勾**（`--verify-only` 通过 ≠ 可交付），全靠人工放大看图挑出来。眉形走向、嘴形、朝向、两条要求能否共存，都已列进 `image-spec.md`「机器验收判不出这几类」清单。
