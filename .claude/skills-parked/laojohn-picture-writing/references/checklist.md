# 交付前自检清单（checklist）

逐项核验，未过即返工。**带 ★ 的为本技能特有红线，优先核。**

## ★ 图位规格门禁类
- [ ] ★ 每个用图位是否都先有《图位规格书》？正文无「裸引用图」（出现“如图”却无对应规格）？
- [ ] ★ **三图位齐备**：主图（`主-0N`）／练笔图（`练-0N`）／备选图（`备-0N`）三位是否交齐？练笔图是否写了 `同族关系:`（同角色·同场景·下一时刻）？**纯口头课不豁免**（2026-07-26 拍板：口头独立说也换练笔图）。缺的图写「待出图」列入待办，**不得留空冒充已有**。机检：跑 `imgspec_parser.py` 看「三图位齐备」一行。
- [ ] ★ **四问类主图含「意外点」**：清单里有 `□ 意外点＝…` 项，且能在图上明确指认（**一票否决**：指认不出即退回重出／修图加一处反常）。非四问类课不强制。机检只判有没有写，**画得对不对必须人工看图**。
- [ ] ★ **例文所用图 ≠ 学生当堂写作所用图**（例文＝主图，当堂写作＝练笔图）。同图即返工。
- [ ] ★ **当堂写作前含〔换图速看〕**（1~2 分钟、只问不写、带全班用本课方法口头过一遍新图）；它是写作环节前的**子步骤、不单列成环节**（环节时长须为 5 的倍数），时间从示范例文环节内部挤出、全课总时长不变。
- [ ] ★ **例文 vs 规格清单 越清单核查（分头做）**：示范例文逐句拆开，每个具体画面细节都能在**主图**清单中定位；**学生任务提示、兜底填空条、过关判定与评价例句**逐句能在**练笔图**清单中定位。定位不到的 → 删除，或移入“合理想象”段并明示。
- [ ] ★ 圈画指令/观察问题是否都指向规格清单内真实声明的元素（圈画在主图、写作提示在练笔图，各回各的清单）？没有“圈出规格里没有的东西”。
- [ ] ★ 每个图位是否声明了「承担训练点」，且画面据此包含可教元素（如「细节四问」课含可圈画细节）？未做到 → 该图“干净但教学贫乏”，返工补元素要求。
- [ ] ★ 推断不唯一处（季节/关系/时段）是否用多解口吻，未替学生强行定论？
- [ ] ★ **画面季节/时令与开课学期一致**：图中人物衣着与景物须匹配本课实际开课时间（如一上（秋）第 1 次＝初秋九月 → 短袖/薄长袖，不出现毛衣、围巾、厚外套、满树黄叶、雪）。季节口径写进工单区、对全图统一声明。
- [ ] ★ **画面人物完整性**：每个出现的孩子**头部完整可见**，不被书本/家具/画框边缘遮挡或裁切成“无头”——低龄学生会当场追问、干扰教学。
- [ ] ★ **画面人物族裔＝中国/东亚儿童**：每个孩子须**黑发、黑眼、东亚面孔、黄种人肤色**（模型默认画成西方浅发白人，须在提示词与清单/验收里正面写死，连“黑色短发”颜色词也要写）。**机器验收判不出族裔/发色，主图务必人工再看一眼。**
- [ ] ★ 文末「生图工单」区开头是否写入「⚠ 回插前逐项验收」提示？工单本身是否汇总齐全？（**提示写在工单区、不占第一页**——老师翻开第一页该看见教学内容，不是生产流程说明；同理「提升点类型」「真实性口径」等给生成方看的字段一律下沉文末自检）
- [ ] ★ **两附录区已包注释**：「附：生图工单」「附：真实性自检」两区是否各自整体包进 `<!-- ... -->`（`<!--`/`-->` 独立成行、区内无 `-->` 字样）？「附：本课支架与说写格式小提醒」是否**未被误包**（它是唯一进 docx 的附录）？正文是否无「详录见文末真实性自检」这类指向注释区的悬空转引？
- [ ] **题材与出场角色与 `topic-registry.md` 一致**（机检：详案正文出现的角色名 vs 总表「出场角色」列；题材大类 vs「题材大类」列）。总表中该课次缺行的，**先补行再生成**，不得现场自拟。

## ★ 教学厚度（治「合规但空」——一上第 1 次（会看）首稿曾整环节零师话、三张图零追问）
- [ ] **师话密度**：每个 ≥5 分钟的环节是否**至少有 1 句 `师：`**？占时最长的环节是不是师话最少的那个？（逐字稿的价值在于老师能照着上，环节只写 bullet 指令＝把最难的现场应对留白了）
- [ ] **图位不闲置**：每个用图位在正文是否**至少有 1 条追问或 1 条 `参考：`**？只有「依次出示例-0X」这类指令的图＝图片墙，返工。
- [ ] **每图追问点不重复**：多图练说时，各图是否用了**不同的追问点**（如两人图练「谁」怎么说全、动物图练「不是人也能说三素句」、群像图练「怎么选主角」）？全图同问＝浪费规格。
- [ ] **错答应答**：`参考：` 是否**至少 2 处**给出学生说偏/说不全时的教师应答话术（如只说人不说地点、把「在哪里」答成「在她家」、答非所问），而非清一色理想答案？
- [ ] **训练点教了要练**：提纲表「教学内容」行列出的**每一个**训练点，正文是否都有对应的**学生练习动作**？（只在师话里说了方法、后续没让学生用过 = 教而未练，返工）
- [ ] **分层是设计不是标签**：课内分层是否**至少 1 处**落成三手柄之一——不同支架／不同任务／不同图（见 `scaffold-cards.md` §一「分层是设计，不是标签」）？「程度好的可以说得更具体一点」这类无当堂动作的写法＝标签，不算。
- [ ] **分层不写年级指向**：分层任务是否写成了学情条件而非年级？检索「二年级孩子」「一年级孩子换」应为零——同一份详案只服务一个年级，写年级会让人误以为教室里坐着两个学段（二年级插班生走独立衔接课，见 `SKILL.md`「衔接课」节）。
- [ ] **支架声明**：本课支架**发到哪一层、哪些该撤**是否已显式写明？**声明只发基础层的课次，其分层必须落在「不同任务／不同图」上**——发了本课训练点之外的层＝越阶（如一上「会看」课发细节拓展支架＝提前上二上「细节四问」），见 `scaffold-cards.md` §一越阶闸门。
- [ ] **评价可判定**：评价三级（基础/良好/优秀）是否配了「不算过关/算过关/加分」对照例句（§10.2）？**每一处分层任务是否交代了达标线落在哪一档**（如「换任务的孩子以『加分』为达标线」），而不是派了任务却不说怎么算完成？点评环节是否给了**至少 2 条可照读的夸奖句**（§10.1），而非只写维度名？
- [ ] **课后延伸**：是否有一条轻量课后动作（家校说图/积累本，§11）？
- [ ] **决策批注（双向查）**：非显然的教学决策（顺序、取舍、为何不讲某点）是否用 `（注：…）` 写明理由（§12）？反向（计数 ≤3/课时 与修订留痕词由 tone_gate 机检）：逐条判是否**一句话、只给结论性理由**，不写论证过程与算式推导。

## ★ 回插终检（交付后由用户在生图回插时执行，SKILL 在头部提示）
- [ ] ★ 工单区两块核验表（**方法点图规格核验表**／**三图位交付清单**）是否逐项打了钩、「图上指认：」逐条填了实物位置？空着或填不出＝该项落空，退回重出（`image-spec.md` 文末格式）。

- [ ] ★ **对着真图逐句读一遍正文里描述画面的动词与方位，手脚支撑点必须裁局部放大再判（2026-08-05 立）**：不是核「有没有画」，是核「说得准不准」。凡「扶/撑/捏/推」「靠着/贴着/放在」这类动词，以及「谁在谁旁边、谁朝哪边」，都要在真图上指一次再落笔；师话、参考答案、〔圈画核对〕、示范例文四处**同一动作必须同一说法**。⚠ **手脚有没有接触到东西，AI 判不准，判到第三轮还会判反**——二上第 3 次那只手来回判了四轮（侧板外沿→扶住书架→"停在半空"→放大后又改回"撑住成立"），**最后由用户直接改图定案：原图那只手确实是悬空的**。三条操作判据：① 涉及支撑、接触、抓握的部位，**裁 20%–25% 画幅放大看**，但放大也只是提高概率、**不构成结论**；② **先问这个姿势物理上成不成立**——蹲着的人必然有一只手撑住，画面里若真是悬着，那是图错了、不是措辞问题，该改图；③ **与用户判读冲突时以用户为准，不要用"我放大看过"去压**（本轮就是这么绕了一圈）。
- [ ] ★ **同框角色的衣着厚薄一致（2026-08-05 立）**：把图里两个角色**并排比一次**——一个长袖一个短袖就是两个季节，必退回改图。根因是班底角色的「常穿」两长两短，逐角色照抄就会出这个问题；写规格时**先定全图厚薄、再套各角色主色**（口径与换算表见 `assets/角色册/角色设定.md` §〇、`image-spec.md` 通用约束第 1 条）。**机器判不出，只看单个角色也发现不了。**
- [ ] ★ **表情"过火"时先换「谁说谁听」，不是改形容词（2026-08-05 立）**：真图人物反应大、事件却小（一本书插反配上睁圆的眼睛、张开的嘴），说明**这个反应缺一个引起它的人**。先别润色语气——**改由画面上另一个人发动情节**（谁刚走过来、谁怀里抱着东西，那多半就是发动点），让惊讶变成"被叫住"的反应，画面一处不用改。二上第 3 次实例：原稿小满自己瞥见插反的书、喊「小欢你快过来看看」（**而小欢本来就站在他旁边**，根本不用叫）；改成小欢抱着一摞书走过来放书、一眼看见并出声提醒，小满听见才转头，整幅画立刻顺了，**语言这一问归小欢、心理这一问归小满，两人各承一问**。⚠ 只调语气那一轮被用户判为仍不顺，**别停在改形容词**。
