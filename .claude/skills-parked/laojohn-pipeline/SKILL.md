# 老约翰 · 下游物料一键编排

把一本书的**全部下游配套物料**按序生成。本技能是**编排/运行手册**——逐个委托下游 skill，自己只负责：① 前置检查；② 统一环境约定；③ 失败隔离；④ 最终汇总与人工待办。

## 适用前提

上游已就绪（本技能**不生成**它们）：
- `读书会详案输出\<书名>-课案详案.md`（由 laojohn-lesson-plan 产出）
- `读书会书籍档案\<书名>书籍档案.md`（由 laojohn-book-profile 产出，**机读块基本信息已尽量填全**）
- `读书会书籍封面\<书名>.<ext>`（jpg/png/webp，书名不带书名号）

## 第 1 步 · 前置检查（硬闸，缺则停）

执行前先确认（用 `(Get-Location).Path` 确认 `<项目根目录>` 实际盘符，移动硬盘盘符会变）：

1. 课案、书籍档案两份**必须存在**——缺任一即停下告知用户，不要硬跑。
2. 封面图存在性——缺失不阻断（封面走占位/留空），但要在最终汇总里提示用户补图。
3. 打开书籍档案的 `## 海报/指南元数据` 机读块，**扫一眼基本信息齐不齐**（出版社/字数/页数/作者/类型/主题/获奖…）。缺的字段照「缺失留空」规则走，并在汇总里列出，提示用户回填档案后重跑。
4. 跟用户确认**要出哪些物料**（默认全套 6 项；可只挑子集）。PPT 链是否一并跑（见第 3 步·可选）。

## 第 2 步 · 环境约定与全局规则

**唯一源＝ `references/downstream-common.md`**（本 skill 自带）。路径与环境（`python` 不用 `python3`、`PYTHONUTF8=1`、Playwright 回退）、两段式流程、事实源只认机读块、缺失留空的三种呈现、绝不联网、丢弃教学性细节、输出目录与命名、JSON 是内容源头与交付、文字体例、封面共用目录、通用 FAQ——全在那份文件里，六个下游 SKILL.md 也指向它。

**编排时把这份文件连同各物料的 SKILL.md 一起读**，不要凭本页记忆代劳。本页只保留编排层自己的动作（前置检查 / 委托顺序 / 失败隔离 / 汇总）。

渲染类命令的标准前缀：
```bash
PYTHONUTF8=1 python <脚本> ...
```

## 第 3 步 · 按序生成（逐个委托下游 skill）

对每个选定物料，**调用对应下游 skill**（其 SKILL.md 内含完整字段/红线规则），把书名与上游路径作为输入传入，并带上第 2 步的通用纪律。**两段式脚本物料**（书目卡 / 海报）流程是「① extract 抽骨架 → ② AI 填 C 类 → ③ render 渲染」；**AI 组稿物料**（阅读指南 / 两种导图 / 反馈话术）是「AI 按 schema 组 JSON → render」。

| 序 | 物料 | 委托 skill | 输出目录 | 形态 |
|----|------|-----------|----------|------|
| (可选 0) | 投屏 PPT | laojohn-ppt-draft → laojohn-ppt | `读书会课件中间稿输出\` / `读书会课件PPT输出\` | 中间稿.md+讲稿.md → .pptx |
| 1 | 书目卡 | laojohn-book-card | `读书会配套输出\<书名>\` | JPG+HTML+JSON |
| 2 | 招生海报 | laojohn-course-poster | `读书会配套输出\<书名>\` | JPG+HTML+JSON |
| 3 | 阅读指南 | laojohn-reading-guide | `读书会配套输出\<书名>\` | PDF+HTML+JSON |
| 4 | 抢先看导图 | laojohn-lesson-mindmap | `读书会配套输出\<书名>\` | PDF+HTML+JSON |
| 5 | 教学导图 | laojohn-teaching-mindmap | `读书会配套输出\<书名>\` | PDF+HTML+JSON |
| 6 | 反馈话术 | laojohn-course-feedback | `读书会配套输出\<书名>\` | docx+md+content.json |

- **PPT 链是可选前置**（较重、自成两步）；用户没特别要就先跳过，默认只跑 1–6。
- **封面**：书目卡/海报渲染脚本走 `--covers 读书会书籍封面`；阅读指南需把封面转 base64 注入 JSON 的 `cover_image`（自包含 HTML）。
- **口径一致**：同一本书的字数/出版社/作者等在各物料间须一致（都来自档案机读块，天然一致；若手动改过要回头对齐）。

## 第 4 步 · 失败隔离

某个物料失败（脚本报错、缺料、渲染挂掉）时：**记下该项失败原因，继续下一个**，不要中断整条流水线。全部跑完后在汇总里区分「已生成 / 失败（附原因）」。

## 第 5 步 · 交付汇总

全部跑完，给用户一张总表：
- 每个物料：✅ 已生成（列产物路径）/ ❌ 失败（附原因）。
- **需人工补的占位清单**：档案机读块里仍为「(待补充)」的字段（→ 物料里相应留空）、海报获奖区（默认隐藏，有奖人工填）、未匹配到的封面图。
- 提醒：补全档案机读块或封面后，重跑对应物料即可刷新（改 JSON→重渲染）。

## 边界（不做）

- 不生成课案详案（→ laojohn-lesson-plan）、不建书籍档案（→ laojohn-book-profile）。
- 本流水线只编排读书会（整本书阅读）的下游物料；写作课（习作课）是独立平行分支，不走本流水线。
- 本技能不直接写内容/不自带脚本，只编排既有 skill；各物料的字段规则、反编造红线以各自 SKILL.md 为准。
