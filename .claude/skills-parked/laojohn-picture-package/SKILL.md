# 老约翰 · 看图写话整套文件打包（成品归集）

把一次看图写话课的成品从各输出目录里**复制归集**进一个干净的交付文件夹，方便整套发给老师/家长。本技能**只搬运、不生成**——所有内容早已由上游各 skill 产出。

## 产出结构（固定 · 与读书会/写作课打包同构）

```
看图写话整套文件打包输出\<课次>\
├── 课堂用图\            ← 看图写话详案输出\<课次>\图位\*.png（主-0N/练-0N/备-0N，投屏与打印用）
├── 配套物料\            ← 看图写话配套输出\<课次>\*.pdf（支架小卡/兜底纸条/看图写话稿纸/教师家长页）
└── <课次>-配图.docx     ← 看图写话详案输出\<课次>\（放打包根目录，主交付件一眼可见）
```

`<课次>` = 详案文件名 stem，如 `二上（秋）第 1 次 · 方法课`（含空格与 `·`，命令行务必整体加引号）。

**看图写话线没有 PPT／讲稿链**（不进 `laojohn-ppt-draft`→`laojohn-ppt`），所以没有「课件PPT」「逐页讲稿」两个子目录——图直接投屏，讲的话在详案里。

## 收哪些文件（默认：仅对外成品）

| 分类 | 子目录 | 默认收的成品 |
|------|--------|------------|
| 看图写话详案 | （根目录） | **择优只收一份 `.docx`**：有 `<课次>-配图.docx` 就只收它；没有才回落收无图版 `<课次>.docx`。详案 `.md` 与 `-生图提示词.txt` 是源/内部件，默认不收 |
| 课堂用图 | `课堂用图\` | 图位 `.png`（主图/练笔图/备选图）；`_验收报告.md` 是内部核验件默认不收；`图位\_历史\` `_画风测试\` `_合格基线\` 等子目录一律不收 |
| 配套物料 | `配套物料\` | 四件印刷件 `.pdf`；`.html` / `_data.json` 是源，默认不收 |

- **详案择优是本技能特有的一条**：交付包里永远只有一份详案，老师不会拿错。若收的是无图版，脚本会在汇总里显式警告「图还没回插」——**这时应先跑 `insert_images_docx.py` 回插再重跑打包**，而不是把无图版发出去。
- **默认过滤掉可编辑源与内部件**（md/txt/json/html、被择优淘汰的无图版 docx、`_验收报告.md`），交付包保持干净；`--with-sources` 时一并打包。
- **纯口头课配套只有「支架小卡+教师家长页」两件**（无稿纸/兜底纸条），属正常形态，不算缺料。

## 执行

先用 `(Get-Location).Path` 确认实际盘符（移动硬盘盘符会变，禁止硬编码），再在**项目根目录**下跑：

```bash
# 本机用 python（不是 python3）；脚本里有 ✓ 等字符，务必带 PYTHONUTF8=1
PYTHONUTF8=1 python ".claude/skills/laojohn-picture-package/assets/package_picture.py" "<课次>"
```

常用参数：

```bash
# 先演练看清单、不实际复制（推荐第一步先 dry-run 核对哪些缺料）
PYTHONUTF8=1 python ".claude/.../package_picture.py" "二上（秋）第 1 次 · 方法课" --dry-run

# 连可编辑源与内部件(md/txt/json/html/无图版docx/验收报告)一起打包
PYTHONUTF8=1 python ".claude/.../package_picture.py" "二上（秋）第 1 次 · 方法课" --with-sources

# 直接打包到桌面/指定路径（覆盖默认 看图写话整套文件打包输出\<课次>）
PYTHONUTF8=1 python ".claude/.../package_picture.py" "二上（秋）第 1 次 · 方法课" --dest "C:/Users/xx/Desktop/第1次"
```

- 课次名是**三个输出目录共用的同一个 stem**（详案课次目录及其内四件文件、配套子目录、打包子目录），空格与 `·` 一个都不能少；一个文件都没命中时脚本会自动列出 `看图写话详案输出\` 下各课次目录名，照抄即可。详案侧现在是 `看图写话详案输出\<课次>\<课次>.md`（一课次一目录，2026-08-03 起），图位仍是 `…\<课次>\图位\`、路径未变。
- **复制不移动**：各原始输出目录是单一事实源，归集后原目录原封不动。
- 目标已存在则**覆盖同名文件**（重跑即刷新；不会删掉目标里你手动加的别的文件）。

## 工作流

1. **确认课次标识**与盘符（`(Get-Location).Path`）。
2. **先 `--dry-run`**：看清单，确认三类都命中、没有因课次名不符而漏收。
3. 决定是否 `--with-sources`（默认否，交付包更干净）。
4. **正式复制**，把脚本汇总（每类复制了几个文件 + 缺料/无图版警告）转述给用户。
5. **缺料不阻断**：某物料还没生成（如配套没做）→ 该分类标「缺」，照常打包其余，并提示用户「先去生成 XX 再重跑打包即可补进」。

## 边界（不做）

- **不生成任何内容**：缺哪份就去对应 skill 生成（详案→laojohn-picture-writing、配套印刷件→laojohn-picture-materials、图→按详案生图工单出图并回插），再回来重跑打包。
- **不生图、不回插、不验收**：收到无图版详案只警告，不代跑 `insert_images_docx.py`。
- 不改、不删、不移动原始输出目录里的文件（只读取并复制出去）。
- 读书会书目的打包走 laojohn-course-package，同步习作写作课走 laojohn-writing-package。
